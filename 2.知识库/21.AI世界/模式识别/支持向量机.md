### 核心重点精讲

#### 1. SVM 的核心思想 (必考简述题)
*   **一句话定义**：SVM 是一个在特征空间中寻找**最大间隔 (Maximum Margin)** 的线性分类器。
*   **通俗理解**：找一刀把两类数据切开，不仅要切开，还要让刀离最近的数据点（两边）都**越远越好**。这样泛化能力最强（不容易过拟合）。

#### 2. 超平面与间隔 (PPT 8-15) —— 计算题基础
*   **超平面方程**：$w^T x + b = 0$
    *   $w$：法向量，决定平面的方向。
    *   $b$：位移项，决定平面与原点的距离。
*   **点到超平面的距离**：
    $$r = \frac{|w^T x + b|}{||w||}$$
*   **两个关键概念 (易混淆，考判断/填空)**：
    *   **函数间隔 (Functional Margin)** $\hat{\gamma} = y_i(w^T x_i + b)$：
        *   问题：如果 $w$ 和 $b$ 同时扩大10倍，超平面没变，但函数间隔变大了。这不科学，不能直接用来做优化目标。
    *   **几何间隔 (Geometrical Margin)** $\gamma = \frac{\hat{\gamma}}{||w||}$：
        *   **这就是真实的物理距离**。我们优化的目标就是这个。

#### 3. 学习目标 (PPT 16-18) —— 考公式背诵/填空
我们想让几何间隔最大化。
*   **原始目标**：$\max \frac{1}{||w||}$
*   **转化后的数学目标**（为了方便求导和计算）：
    $$\min \frac{1}{2} ||w||^2$$
*   **约束条件**：$y_i(w^T x_i + b) \ge 1$
    *   *(意思是：所有样本点都必须在间隔边界以外，且被正确分类)*

#### 4. 什么是支持向量 (Support Vector)? (必考名词解释)
*   **定义**：训练数据集中，距离分离超平面**最近**的那些样本点。
*   **数学特征**：使得约束条件等号成立的点，即满足 $y_i(w^T x_i + b) = 1$ 的点。
*   **作用**：**SVM 的决策边界只由支持向量决定**，其他普通样本点删掉也无所谓（鲁棒性好）。

### 🔥 老师押题时间（第一部分）

#### **题型1：简述/名词解释**
1.  **简述支持向量机 (SVM) 的基本思想。**
    *   *答题要点*：SVM 是一种二分类模型。它的基本模型是定义在特征空间上的**间隔最大**的线性分类器。其核心思想是找到一个超平面，使得不同类别的样本点到该平面的最小距离（间隔）最大化，从而提高模型的泛化能力。
2.  **什么是支持向量 (Support Vector)？它在SVM中有什么作用？**
    *   *答题要点*：支持向量是距离分类超平面最近的那些训练样本点（满足 $y_i(w^T x_i + b) = 1$）。它们决定了超平面的位置，其他样本点对模型没有影响。

#### **题型2：简单计算题**
**题目：** 假设二维空间中有两个类别的点。
正类点 $x_1 = (3, 3)^T, x_2 = (4, 3)^T$，标记 $y=+1$。
负类点 $x_3 = (1, 1)^T$，标记 $y=-1$。
已知分类超平面方程为 $x^{(1)} + x^{(2)} - 4 = 0$（即 $w=(1,1)^T, b=-4$）。
1.  判断 $x_1$ 和 $x_3$ 是否被正确分类。
2.  计算点 $x_1$ 到超平面的**几何间隔**。

**解题思路：**
1.  **分类判断**：代入 $y(w^T x + b)$ 看是否大于0。
    *   对于 $x_1 (3,3)$：$1 \times (3+1\times3 - 4) = 2 > 0$。正确。
    *   对于 $x_3 (1,1)$：$-1 \times (1+1\times1 - 4) = -1 \times (-2) = 2 > 0$。正确。
2.  **几何间隔计算**：公式 $r = \frac{|w^T x + b|}{||w||}$
    *   $||w|| = \sqrt{1^2 + 1^2} = \sqrt{2}$
    *   函数间隔 $\hat{\gamma} = |3+3-4| = 2$
    *   几何间隔 $r = \frac{2}{\sqrt{2}} = \sqrt{2}$

#### **题型3：判断题**
1.  (判断) 在线性可分SVM中，如果我们把所有训练样本的坐标扩大两倍，那么求得的几何间隔也会变大。
    *   *答案*：对。（物理距离变远了）。
2.  (判断) 移除非支持向量的样本点，会改变SVM训练出的超平面。
    *   *答案*：错。（SVM只由支持向量决定，非支持向量移除了没影响）。
