# 语音识别

声音-->声学特征-->模型处理-->token

声学特征（ acoustic features）有：
- 频谱
- 能量
- MFCC、filter bank？他们两个怎么记住
![[_attachments/image/自己总结-1779241757390.jpeg]]
使用声学特征的好处，是将复杂的声音降维为简单，易处理的声学特征。将连续语音信号，转化为时间序列的声学特征，便于模型处理，提升模型效果。

token 的分类
- Phoneme 音素，与发音直接有关，便于语音识别。需要额外的 **Lexicon（词典）** 把 word 映射成 phoneme 序列
- Grapheme 字符，词表小，以一个字母/字为单位。但是没有语义
- Word 词，语义比较完成，但词表非常大，容易出现 OOV 问题。
- Morpheme ，语素，是最小的有意义单位。介于字符与词之间
- Byte 字节，和语言无关，固定序列长度

常用的语音识别模型架构是，seq2seq。
以其中处理序列模型为 RNN/LSTM 为例，他们都是输入上一个 token，输出下一个 token。模型设计使得上一个 token 也包含历史 token
- Encoder，**一次性输入完整的声学特征序列**，声学特征，然后模型输出对其的理解。具体的“理解”含义是① 提取内容信息；② **去除说话人差异**；③ **去除噪声**
- Decoder，结合上一个 token，与 Encoder 给出的理解，用 attention 机制，经过一个 softmax输出下一个 token

这种 seq2seq 模型可命名为 LAS
**LAS：Listen, Attend and Spell**
- Listen，就是 Encoder
- Attend，就是 attention 注意力机制
- Spell，就是 Decoder

训练时的小点
- Beam Search，每步保留概率最高的 B 条路径，最后选总分最高的
- Teacher forcing，训练时用真实标签 token 作为输入，而不是模型自己上一步输出的 token。这样做训练较为稳定，缺点是推理与训练不一致

## 押题参考答案

### 【题 1 答案】

**流程**：Waveform → DFT → Spectrogram → 通过 Mel Filter Bank → log → **Filter Bank 特征**；再做 DCT → **MFCC**。

**区别**：

- MFCC 比 Fbank 多一步 DCT，做了去相关，维度更低（典型 39 维）
- Fbank 维度更高、保留更多信息、相邻维度相关性强，更适合深度学习模型
- MFCC 适用于传统 GMM-HMM 系统；现代 DNN 系统更常用 Fbank

### 【题 2 答案】

- **Phoneme**：发音最小单位，需 Lexicon 映射；声学相关性强但需要专家知识 1
- **Grapheme**：字母/汉字；词表小、无 OOV，但单个字符无语义
- **Word**：词表大（英文可达数十万），语义完整，但易 OOV
- **Morpheme**：词素，介于 Grapheme 和 Word 之间，兼顾粒度和语义
- **Byte**：固定 256 词表，**与语言无关**，可处理多语言混合

**Word 有 OOV**：词表是固定的，新词/罕见词无法表示；**Byte 无 OOV**：任何 UTF-8 文本都能用 256 个字节表示。

### 【题 3 答案】

**LAS = Listen, Attend, and Spell**

- **Listen**（Encoder）：输入声学特征，输出高层表示  3
    - 三个作用：① 提取内容信息；② **去除说话人差异**；③ **去除噪声** 3
- **Attend**（Attention）：在每个解码步对 Encoder 输出加权，得到上下文向量 c
- **Spell**（Decoder）：结合 c 和上一步输出，通过 softmax 预测下一个 token

### 【题 4 答案】

- (1) **错**。Beam Search 是确定性搜索算法，保留 Top-B 条路径找全局最优；Top-k 采样是随机采样，用于增加多样性
- (2) **错**。Teacher Forcing 只在**训练阶段**使用真实标签；推理阶段无标签可用，只能用模型自己的上一步输出
- (3) **错**。语音是高采样率的向量序列，**T >> N**（每秒约 100 帧特征，但每秒往往只有几个字）1

**解码过程**：`Φ好好ΦΦ棒棒棒ΦΦ棒`

**CTC vs LAS 主要差异**：

|维度|CTC|LAS|
|---|---|---|
|Decoder|仅 linear classifier 6|RNN + Attention|
|输入输出对齐|T 输入→T 输出，需 Φ 2|T 输入→N 输出，attention 对齐|
|独立性假设|每步输出独立|自回归（有依赖）|
|训练|需要枚举所有对齐求和|Teacher Forcing 直接训练|

### 【题 6 答案】

|模型|输入-输出关系|
|---|---|
|LAS|T 输入 → N 输出，全局 attention|
|CTC|T 输入 → T 输出（含 Φ）2|
|RNA|1 输入 → 1 输出 6|
|RNN-T|1 输入 → 多输出 6|
|Neural Transducer|1 个 window → 多输出 6|
|MoChA|可伸缩 window → 多输出 6|

**MoChA 改进**：Neural Transducer 的 window 大小固定且按固定步长移动；MoChA 让 window **位置可学习、伸缩自如**，更灵活地对齐输入输出 6。

### 【题 7 答案】

**Teacher Forcing**：训练 Decoder 时，每一步输入用**真实的上一个 token**而不是模型预测的 token。

**为何稳定**：训练初期模型预测很差，若用模型自身输出会导致错误累积、梯度难以收敛；用真实 token 保证每一步输入正确，loss 更稳定。

**Exposure Bias 问题**：训练时输入永远是正确 token，推理时却必须用模型自身（可能错误）的输出 → 训练和推理分布不一致，一旦预测错就可能越错越离谱。缓解方法：Scheduled Sampling（按概率混合使用真实/预测 token）。
# 语音识别模型
- LAS = seq2seq 老大哥
- CTC = LAS 把 Decoder 简化成 linear + 加 Φ
- RNA = CTC 的进化（输入 1 出 1，但有依赖）
- RNN-T = RNA 的进化（输入 1 可出多）
- Neural Transducer = RNN-T + window
- MoChA = Neural Transducer + 可移动 window

LAS：以 RNN 为例，RNN 模型本身是，每个时间步输入一个向量+上一时间步模型的**隐状态**
在 Encoder 中，输入向量是当前时间步的声学特征。（这与我们会把整个时间的声学特征送给 encoder 不矛盾）
在 Decoder 中，每个时间步输入一个向量是上一步 token。此时与上一步隐状态结合，产生当前状态。然后呢！利用 Encoder
此时 Encoder 已经有了所有帧数的输出，Decoder 会拿当前自己的隐状态，问 Attention 机制，现在该去看音频哪部分。Attention 算出 10-30 帧权重大，吐出了属于当前步的 **上下文向量**。Decoder 会把隐状态和上下文向量拼接一起。

- Decoder 每一步的流程更精确的描述是：  
    **上一步隐状态 zₜ₋₁ → Attention 查询 Encoder 输出 → 得到上下文 cₜ → (zₜ₋₁, 上一步 token embedding, cₜ) 一起算出 zₜ → 经 softmax 得到当前 token 分布**。




CTC：不要 Decoder 了，直接 Encoder 每一帧输出理解后接一个 linear+softmax，所以每一帧都会输出 token，不过会输出 Blank 占位符。
训练比较难，因为不知道每帧对应哪个 token，需要**穷举所有合法对齐路径并求和**（前向-后向算法）

**RNA:
= Recurrent Neural Aligner**它的定位是：

- **CTC** 的 decoder 每一帧独立输出 → **没有上下文依赖**
- **RNA** 在 CTC 基础上**加入了输出之间的依赖**（即当前输出会依赖前一个输出），但仍然 **一个输入向量 → 一个输出 token**21。
- 所以 RNA 是 CTC 的进化（添加依赖性），而不是直接进化到 RNN-T。

RNN-T：
- ENcoder 和 seq2seq 一样，提取所有时间的**声学特征**
- Prediction Network 呢，输入“已经真实输出的历史 token”（比如已经输出了 d、e），输出一 个**语言特征**。
- Joint Network 是它把【当前第 t 帧的声学特征】和【历史输出带来的语言特征】把两者**联合编码**（一般是相加或拼接后过非线性层）然后经过一层网络和 Softmax，**输出最终的 Token 或 Blank**。
- RNN-T 没有传统的 Attention Decoder。Prediction Network + Joint Network 共同承担"解码"角色，但严格来说**没有 LAS 那样的 Decoder**。

和 LAS 的区别是，是逐帧对齐，不是靠 Attention 软对齐。




Neural Transducer ：
RNN-T + window，RNN-T 在处理第 $t$ 帧时，它**看不到**第 $t+1$ 帧的声音。块内就比较均衡。块内 ENcoder 有理解，所以兼顾了流式处理与上下文理解


MoChA：
Neural Transducer + 可移动 window
**window 大小是固定的，但 window 的位置（起始点）是模型动态决定的**（"伸缩自如"指的是移动位置，而不是窗口尺寸可变）


| 模型                | 输入输出对应关系           | 是否流式 | 输出依赖  |
| ----------------- | ------------------ | ---- | ----- |
| LAS               | 多对多（attention 全局）  | ❌    | ✅     |
| CTC               | T → T（含 Φ）         | ✅    | ❌（独立） |
| RNA               | T → T（含 Φ）         | ✅    | ✅     |
| RNN-T             | 1 输入可出多输出          | ✅    | ✅     |
| Neural Transducer | window 内 attention | ✅    | ✅     |
| MoChA             | window 位置可移动       | ✅    | ✅     |

## 押题答案

**1. LAS 三阶段**：

- **Listen**：Encoder（通常金字塔 BLSTM）将声学特征编码为高层表示，提取内容信息、去除说话人变化和噪声 6。
- **Attend**：每个解码步用当前 Decoder 隐状态查询 Encoder 输出，得到上下文向量 cₜ。
- **Spell**：Decoder 结合上一步 token、隐状态、上下文，自回归生成下一个 token。

**2. CTC 的输出独立问题**：CTC Decoder 是 linear classifier，每帧输出仅由该帧 Encoder 输出决定，不依赖上下文输出 2。后果：相邻帧之间可能不一致 → 出现**重复、结巴**或拼写错误，需要外接语言模型修正。

**3. CTC 解码规则**：先把连续相同的 token 合并为一个，再删除所有 Φ。例如 `ΦddΦeΦeΦpp → d e e p → deep`；`ddΦeeeΦpp → d e p → dep`（注意 Φ 把两段相同 token 隔开就不合并）3。

**4. RNA / RNN-T 的进化**：

- RNA 相比 CTC：让当前输出**依赖于前一个输出 token**（引入循环依赖）2。
- RNN-T 相比 RNA：允许**一个输入向量产生多个 token**（通过反复决策直到输出 ∅ 才前进到下一帧）1。

**5. Neural Transducer 的动机**：LAS 的 attention 必须看到整段序列才能解码 → 不能流式。Neural Transducer 把序列分成固定 **window (chunk)**，attention 只在 window 内部计算 → **既保留 attention 的上下文能力，又支持流式**15。

**6. MoChA vs Neural Transducer**：Neural Transducer 的 window 是**固定切分**的；MoChA 的 window **大小固定但位置由模型动态决定**，可以"滑动"到合适位置 → 对齐更灵活 1。

**7. CTC 解码 `ΦccΦaaΦtt`**：合并重复 → `ΦcΦaΦt` → 去 Φ → **`cat`**。

**8. RNN-T 结构**（文字描述）：

- Encoder：输入，输出声学表示。
- Prediction Network：输入历史已生成 token（不含 ∅），输出语言表示。
- Joint Network： → softmax → 输出下一个 token 或 ∅。若输出 ∅ 则 t+1，否则 u+11。

**9. 三模型对比**：

|维度|LAS|CTC|RNN-T|
|---|---|---|---|
|流式|❌|✅|✅|
|输出依赖|✅|❌|✅|
|对齐方式|全局 soft attention|帧级独立分类|单调对齐 + ∅ 推进|

**10. 实时字幕系统选择**：应选 **RNN-T** 或 **MoChA**。

- **RNN-T**：天然单调流式、输出有依赖、工业界主流（Google 上线）。
- **MoChA**：保留 attention 的精度，且可流式。
- **不选 LAS**：必须看完整段，延迟太大。
- **不选 CTC**：输出独立易出错，需外挂 LM。



# 语言模型

最原始的语言模型就是给一个序列 w₁…wN 计算概率：


$$P (w_1, w_2, ..., w_N) = \prod_{t=1}^{N} P (w_t \mid w_1, ..., w_{t-1})$$

为了解决这个问题，N-gram 提出马尔可夫假设
**“下一个词出现的概率，只跟它前面最近的 $N-1$ 个词有关，再往前的历史统统不管了！”**

$$P (w_t \mid w_1, ..., w_{t-1}) \approx P (w_t \mid w_{t-N+1}, ..., w_{t-1})$$  

 N-gram 模型里存的内容，就是词表，通过词表计算各种 P，然后算出当前推理所需要的 P。

问题，一是词与词之间无关，二是没有上下文记忆（只有 N 个词 ），三是 OOV 问题，词表很稀疏。



现代语言模型不是用离散词表，而是用 **词向量 / 子词 / token embedding** 表示

把这种先把词，转换为向量的模型，叫Continuous LM
