# 基本概念
随机实验，
出现的每一种情况都是一个样本点，
所有样本点集合为样本空间
随机事件的是样本空间的子集。

#### **随机事件通常是多个样本点吗？**

*   它可以包含**多个**样本点。例如：掷骰子，“点数大于 3”这个事件包含三个样本点：$\{4, 5, 6\}$。
*   它可以只包含**一个**样本点。例如：掷骰子，“点数是 6”这个事件只包含：$\{6\}$。
*   它可以包含**全部**样本点（必然事件 $\Omega$）。
*   它甚至可以**不包含任何**样本点（不可能事件 $\varnothing$）。


由单个样本点组成的集合成为基本事件

#### **基本事件和随机事件的区别是？**

*   **基本事件（Elementary Event）：** 特指只包含**一个**样本点的集合。它是构成所有事件的最小单位，不能再拆分了。
    *   *例子：* 掷骰子，$\{1\}$ 是一个基本事件。
*   **随机事件（Random Event）：** 这是一个**广义的概念**。任何样本空间的子集都叫随机事件。
    *   **区别：** “基本事件”一定是“随机事件”，但“随机事件”不一定是“基本事件”。‘



#### 事件 A 发生，是对未来某一现象的陈述？
**是的。** 在实验开始前，事件 $A$ 是我们的一种**预期或描述**（例如：“明天会下雨”）。

但从数学严谨的角度来说：
*   **事件 $A$ 本身是一个集合**（它描述了所有符合条件的可能结果）。
*   **“事件 $A$ 发生”** 这个动作，是指实验结束后，实际观察到的那个**唯一的样本点 $\omega$**，刚好落在了集合 $A$ 里面

#### 这个事件 A 到底是样本点还是多个样本点？
事件 $A$ ，全称应是随机事件，永远是一个“集合“，


# 事件关系运算


### 1. 事件间的关系
| 关系名称      | 符号表示                                           | 概率论含义                 | 集合论对应          |
| :-------- | :--------------------------------------------- | :-------------------- | :------------- |
| **包含**    | $A \subset B$                                  | 若 $A$ 发生，则 $B$ 必发生    | 子集             |
| **相等**    | $A = B$                                        | $A, B$ 互为包含，发生情况完全相同  | 集合相等           |
| **互斥**    | $A \cap B = \varnothing$                       | $A, B$ 不能同时发生         | 不相交            |
| **对立**    | $A \cup B = \Omega$ 且 $A \cap B = \varnothing$ | $A, B$ 必有一个发生，且仅有一个发生 | 补集 ($\bar{A}$) |
| **完备事件组** | $\bigcup A_i = \Omega$ 且两两互斥                   | 实验结果必落在且仅落在其中一个事件中    | 样本空间的划分        |


描述：
A 和B 至少发生一个的情况下，AB 恰有一个发生的概率
$A\bar B \cup B\bar A | A \cup B$  



### 2. 事件的运算
*   **并（和事件）**: $A \cup B$ 
    *   含义：$A$ 与 $B$ 中**至少有一个**发生。
*   **交（积事件）**: $A \cap B$ (或 $AB$)
    *   含义：$A$ 与 $B$ **同时**发生。
*   **差（差事件）**: $A - B$
    *   含义：$A$ 发生，但 $B$ **不发生**。公式：$A - B = A \bar{B} = A - (AB)$。
       <font color="#ff0000">概率论中没定义负事件，-A 是无意义的，不要运算</font>
*   **逆（对立事件）**: $\bar{A}$
    *   含义：$A$ **不发生**。公式：$\bar{A} = \Omega - A$。

---

### 3. 运算定律 (与集合论一致)
1.  **交换律**: $A \cup B = B \cup A$ ； $AB = BA$
2.  **结合律**: $(A \cup B) \cup C = A \cup (B \cup C)$ 
3.  **分配律**: 
    *   $A(B \cup C) = (AB) \cup (AC)$
    *   $A \cup (BC) = (A \cup B)(A \cup C)$
4.  **摩根律 (De Morgan's Laws) ⭐**:
    *   $\overline{A \cup B} = \bar{A} \cap \bar{B}$  (不发生的并 = 不发生的交)
    *   $\overline{A \cap B} = \bar{A} \cup \bar{B}$  (不发生的交 = 不发生的并)

考研数一中，这两个公式是概率论第一章最核心的基础公式。具体展开方式如下：

---

#### 一、 $P(A \cup B \cup C)$ 的展开公式（广义加法公式 / 容斥原理）

$$P(A \cup B \cup C) = P(A) + P(B) + P(C) - P(AB) - P(AC) - P(BC) + P(ABC)$$
理解记忆（不用死记）：
* **加单项：** 先把三个单独事件的面积加起来 $P(A) + P(B) + P(C)$。
* **减双交：** 此时两两重叠的部分（$AB, AC, BC$）被多算了一次，所以要减掉一次 $- P(AB) - P(AC) - P(BC)$。
* **加三交：** 在减双交的过程中，三个事件共同重叠的最核心部分 $ABC$ 被多减了一次（减空了），所以最后必须补加回来 $+ P(ABC)$。

---

#### 二、 $P(ABC)$ 的展开公式

$P(ABC)$（即三个事件**同时发生**的概率）根据题目给出的条件不同，有 **3 种展开方式**：

 1. 通用情况（乘法公式 / 链式法则）—— 适合已知条件概率
$$P(ABC) = P(A) \cdot P(B|A) \cdot P(C|AB)$$

* **逻辑：** 事情 $A,B,C$ 同时发生 = $A$ 先发生 $\times$ 在 $A$ 发生条件下 $B$ 发生 $\times$ 在 $A,B$ 都发生条件下 $C$ 发生。（注： $A,B,C$ 的顺序可以任意调换，例如也可以写成 $P(C) \cdot P(B|C) \cdot P(A|BC)$）。

 2. 特殊情况一：$A, B, C$ 相互独立 —— 最高频考点
如果题目明确说明 $A, B, C$ **相互独立**，直接拆成各自概率相乘：
$$P(ABC) = P(A) \cdot P(B) \cdot P(C)$$

 3. 特殊情况二：从加法公式反推 —— 适合已知并集概率
如果题目给出了 $P(A \cup B \cup C)$ 以及两两交集的概率，把加法公式移项即可：
$$P(ABC) = P(A \cup B \cup C) - P(A) - P(B) - P(C) + P(AB) + P(AC) + P(BC)$$




### 4. 核心概率性质
*   **非负性**: $0 \le P(A) \le 1$
*   **规范性**: $P(\Omega) = 1, \quad P(\varnothing) = 0$
*   **加法公式**: $P(A \cup B) = P(A) + P(B) - P(AB)$
    *   *若 $A, B$ 互斥，则 $P(A \cup B) = P(A) + P(B)$*
*   **减法公式**: $P(A - B) = P(A) - P(AB)$
*   **逆事件公式**: $P(\bar{A}) = 1 - P(A)$

---

**Tip:** 在处理复杂逻辑时，优先使用 **摩根律** 将“长杠”拆分为“短杠”，或将多个事件的并转化为交。

# 对概率的理解
实验中，事件发生的频率，稳定在概率附近。

公理化定义：
如果对于随机实验的每个实验，赋予一个实数，
这个实数有
1.  **非负性**：$0 \le P(A) \le 1$
2.  **规范性**：$P(\Omega) = 1, \quad P(\varnothing) = 0$
3.  **可列可加性**：若 $A_1, A_2, \dots$ 两两互斥，则 $P(\cup A_i) = \sum P(A_i)$

A 事件上的实数是 P (A)，叫概率
注意，
### P (A)=0，推不出 A 是空集，为何？
*   **几何概型的例子：**
    想象你往一个面积为 $1$ 的靶盘上随机扔一根无限细的针。
    *   **样本空间 $\Omega$**：靶盘上所有的点（无数多个）。
    *   **事件 $A$**：针尖恰好扎在靶盘中心那个**精确的点**上。
    *   **分析**：一个点的面积是 $0$。根据几何概率公式 $\frac{\text{点面积}}{\text{总面积}} = \frac{0}{1} = 0$。
    *   **结论**：$P(A) = 0$，但是中心点确实**存在**（$A \neq \varnothing$），针尖**理论上可以**扎在上面。

*   **专业术语：**
    我们称 $P(A)=0$ 的事件为**“几乎处处不发生”**。在连续型随机变量中，取任何一个特定值的概率都是 $0$，但那个值显然是样本空间的一部分。
    
    
### P (A)=1, 也推不出 A 是必然事件，或者那个Ω，为何？
*核心直觉：概率为 1 并不意味着“绝对发生”，只是意味着“不发生的概率为 0”。**

*   **同样的靶盘例子：**
    *   **样本空间 $\Omega$**：整个靶盘。
    *   **事件 $A$**：针尖扎在**除了中心点以外**的任何地方。
    *   **分析**：由于中心点的概率是 $0$，那么整个靶盘减去这一个点，剩下的概率依然是 $1 - 0 = 1$。
    *   **结论**：$P(A) = 1$，但 $A$ 并不等于 $\Omega$（因为它漏掉了一个中心点）。

*   **专业术语：**
    我们称 $P(A)=1$ 的事件为**“几乎必然发生” (Almost Surely, a.s.)**。

## 概率性质与公式

> [!TIP] 核心逻辑
> 概率 $P(A)$ 就是集合 $A$ 的“大小”占比。所有公式的推导都源于：**不要重复计算重叠部分**。


### 2. 核心计算公式
| 名称       | 公式                                                            | 备注                |
| :------- | :------------------------------------------------------------ | :---------------- |
| **单调性**  | 若 $A \subset B$，则 $P(A) \le P(B)$                             | 小集合概率 $\le$ 大集合概率 |
| **逆事件**  | $P(\bar{A}) = 1 - P(A)$<br>同事件运算                              | “正面算不动，就从背面算”     |
| **减法公式** | $P(A - B) = P(A) - P(AB)$，同事件运算，<br>A-B=A-AB                  | 发生 $A$ 但不发生 $B$   |
| **加法公式** | $P(A \cup B) = P(A) + P(B) - P(AB)$<br>                       | **最常用**。减去重叠的一份   |
| **广义加法** | $P(A \cup B \cup C) = \sum P(A_i) - \sum P(A_i A_j) + P(ABC)$ | 包含排斥原理 (容斥)       |


### 3. 特殊关系下的简化
*   **若 $A, B$ 互斥 ($AB = \varnothing$)**:
    *   $P(A \cup B) = P(A) + P(B)$
    *   $P(A - B) = P(A)$
*   **若 $A \subset B$**:
    *   $P(B - A) = P(B) - P(A)$

---

### 4. 重点公式对比 (集合 vs 概率)
| 集合描述                                         | 概率等式                                 | 直观理解                      |
| :------------------------------------------- | :----------------------------------- | :------------------------ |
| $A \subset B$                                | $P(B) = P(A) + P(B-A)$               | 大面积 = 小面积 + 环形面积          |
| $\overline{A \cup B} = \bar{A} \cap \bar{B}$ | $P(\text{都不发生}) = P(\bar{A}\bar{B})$ | 摩根律套个 $P$ 依然成立            |
| $A = (A-B) \cup (AB)$                        | $P(A) = P(A-B) + P(AB)$              | 全等于“只在 $A$ 不在 $B$” + “都在” |


1.  **$P(A \cup B) = P(A) + P(B)$ 只有在 $A, B$ 互斥时才成立！** 平时做题千万别忘了减去中间重叠的 $P(AB)$。
2.  **$P(A-B)$ 不一定等于 $P(A)-P(B)$**。只有当 $B \subset A$ 时才成立。如果 $B$ 有一部分在 $A$ 外面，减去 $P(B)$ 就减多了。**永远记得减去的是“交集” $P(AB)$**。

# 古典概型和几何概型

可以把它们统一理解为：
$$P(A) = \frac{\text{事件 } A \text{ 所占的“大小”}}{\text{整个样本空间 } \Omega \text{ 的“大小”}}$$

相同点与核心逻辑
*   **古典概型**：样本点是有限的、离散的。这个“大小”就是**个数**。
*   **几何概型**：样本点是无限的、连续的。这个“大小”就是**几何测度**（长度、面积、体积）。
*   **核心前提**：**等可能性**。在古典概型中，每个点出现的概率相等；在几何概型中，落入相同大小区域的概率相等。


*   在古典概型里，$\{1\}$ 和 $\{1, 2\}$ 概率肯定不一样。
*   在几何概型里，区间 $[0, 1]$ 和 $(0, 1)$ 的概率是**一模一样**的。
*   **陷阱**：题目问“恰好等于某数”的概率，在几何概型（连续型）中永远是 $0$。如果你在计算中纠结包含不包含边界，那是白费力气。



古典概型中的“无序”与“有序”
这是古典概型最容易错的地方：
*   *例子：* 同时掷两个硬币，求“一正一反”的概率。
    *   如果你认为结果是 {正正, 反反, 正反}，概率就是 $1/3$（这是错的，因为“正反”和“反正”其实占了两个位置）。
*   **避坑指南**：在古典概型中，为了保证“等可能性”，**要把物体想象成是有编号的**（即便题目说它们完全一样）。

| 特性         | 古典概型 (Classical)           | 几何概型 (Geometric)                        |
| :--------- | :------------------------- | :-------------------------------------- |
| **样本点个数**  | 有限 (Finite)                | 无限 (Infinite/Uncountable)               |
| **等可能性定义** | 每个样本点概率相等                  | 相同测度的区域概率相等                             |
| **计算公式**   | $P(A) = \frac{k}{n}$ (个数比) | $P(A) = \frac{L_A}{L_\Omega}$ (长/面/体积比) |
| **基本单位**   | 一个样本点有固定概率                 | 单个点的概率为 0                               |
| **常见模型**   | 抽球、掷骰子、分牌                  | 等人问题、投针、射击瞄准                            |

# 条件概率


**定义：** 已知事件 $B$ 发生的条件下，事件 $A$ 发生的概率。
$$P(A|B) = \frac{P(AB)}{P(B)} \quad (P(B) > 0)$$
*   **直观理解**：在 $B$ 已经确定的“样本空间”里，看看 $AB$ 同时发生的面积占了多少。样本空间缩减！
*   **性质**：条件概率 $P(\cdot|B)$ 依然满足概率的三大公理（非负、规范、可加）。

---

2. 乘法公式 (Multiplication Rule)
由定义变形得到，用于求“几个事件同时发生”的概率：
*   **两个事件**：$P(AB) = P(B)P(A|B) = P(A)P(B|A)$
*   **多个事件（链式法则）**：
    $$P(A_1A_2A_3) = P(A_1)P(A_2|A_1)P(A_3|A_1A_2)$$
    *   *理解：* 就像多米诺骨牌，先让第一个倒下，再算第一个倒下后第二个倒下的概率，依此类推。

**直观理解：这就是一个“闯关游戏”。**
你要想让 $A_1, A_2, A_3$ 全部发生，必须按顺序走完这三步：
1.  **第一步**：$A_1$ 得发生（概率是 $P(A_1)$）。
2.  **第二步**：**在 $A_1$ 已经发生的基础上**，$A_2$ 也要发生（概率是 $P(A_2|A_1)$）。
3.  **第三步**：**在前两个都发生的基础上**，$A_3$ 也要发生（概率是 $P(A_3|A_1A_2)$）。



全概率公式 (Total Probability Theorem) —— “化整为零”
如果事件组 $B_1, B_2, \dots, B_n$ 是样本空间的一个**划分**（互斥且并集为 $\Omega$），则对于任何事件 $A$：
$$P(A) = \sum_{i=1}^{n} P(B_i)P(A|B_i)$$
*   **直观理解**：为了算出 A 发生的总概率，先穷举所有可能导致 A 发生的原因（$B_i$），把每条路径的概率加起来。
*   **应用场景**：当你发现 $P(A)$ 直接算很难，但“在某种前提下”很好算时。


贝叶斯公式 (Bayes' Theorem) —— “由果溯因”
这是全概率公式的逆向思考：已知结果 $A$ 发生了，求它是由于原因 $B_k$ 导致的概率。
$$P(B_k|A) = \frac{P(B_k)P(A|B_k)}{\sum_{i=1}^{n} P(B_i)P(A|B_i)}$$
*   **结构**：$\text{后验概率} = \frac{\text{某条路径的概率}}{\text{所有路径的总概率}}$
*   **意义**：根据观测到的结果（证据 $A$），修正对初始原因（先验 $B_k$）的认知。


# 独立
 独立性 (Independence)
**定义：** 如果 $A, B$ 是否发生互不影响，则称它们独立。
*   **等价判定式**：$P(AB) = P(A)P(B)$ ⭐ (最常用)
*   **条件概率视角**：$P(A|B) = P(A)$
*   **推论**：若 $A, B$ 独立，则 $\bar{A}$ 与 $B$、$A$ 与 $\bar{B}$、$\bar{A}$ 与 $\bar{B}$ 也全部互相独立。
“独立”的本质是：**关于 $B$ 的任何消息，都无法改变我对 $A$ 发生概率的判断。**
*   既然“$B$ 发生了”这个消息对 $A$ 没影响。
*   那么“$B$ 没发生”这个消息，对 $A$ 肯定也同样没影响。
*   所以 $A$ 与 $\bar{B}$ 必然也独立。

**数学推导（Obsidian 建议背下）：**
已知 $P(AB) = P(A)P(B)$，我们要证 $P(A\bar{B}) = P(A)P(\bar{B})$。
1.  我们知道 $A = AB \cup A\bar{B}$（发生 A 只有两种情况：要么 B 也发生，要么 B 不发生）。
2.  因为 $AB$ 和 $A\bar{B}$ 互斥，所以 $P(A) = P(AB) + P(A\bar{B})$。
3.  移项：$P(A\bar{B}) = P(A) - P(AB)$。
4.  代入独立条件：$P(A\bar{B}) = P(A) - P(A)P(B) = P(A)(1 - P(B))$。
5.  即：$P(A\bar{B}) = P(A)P(\bar{B})$。**证毕！**


---



1.  **“互斥”与“独立”的区别**：
    *   **互斥 ($AB = \varnothing$)**：意味着它们**关系极深**，一个发生另一个必不发生。
    *   **独立**：意味着它们**毫无瓜葛**。
    *   *注意：* 如果 $P(A)>0, P(B)>0$，互斥和独立**不可能同时成立**。

2.  **$P(A|B)$ 与 $P(AB)$ 的区别**：
    *   $P(AB)$：在**全宇宙 $\Omega$** 中，看 $A$ 和 $B$ 同时发生的概率。
    *   $P(A|B)$：在** $B$ 的小宇宙**中，看 $A$ 发生的概率。

3.  **计算技巧**：
    在贝叶斯公式的题目里，通常先列出**全概率公式**（分母），然后再把其中一项拎出来做分子。分母就是所有可能的分支，分子就是你关心的那条分支。
    
> [!WARNING] 互斥与独立的关系
> 1.  **互斥 $\implies$ 不独立**（因为 $A$ 发生， $B$ 必不发生，信息影响极大）。
> 2.  **独立 $\implies$ 不互斥**（因为如果独立， $A$ 发生对 $B$ 没影响，$B$ 还有机会发生，所以 $AB \neq \varnothing$）。
> 3.  **结论**：互斥和独立是两个维度的描述，**除了其中一个概率为 0 的极端情况外，两者不能共存。**
