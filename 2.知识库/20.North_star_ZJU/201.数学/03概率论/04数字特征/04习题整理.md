## 🗺️ 决策树（考场 10 秒定位）

```text
看到数字特征题，先扫题干找关键词：
│
├─ 问"总数 / 总次数 / 个数 / 种数"的 E 或 D
│   └─→ §1.1 示性变量分解（绝不求分布律）
│
├─ 出现 g(X)：|X|、min、max、X²、1/(X+1)、分段
│   └─→ §1.2 LOTUS 直接积分（绝不求 Y 的密度）
│
├─ 出现 ∑(多项式)·(分布律) 的级数
│   └─→ §1.3 认结构 → 反写成 E[g(T)]
│
├─ 问 ρ 或 Cov
│   ├─ 题干给了 ρ=±1 ────────→ §2.1 写 Y=aX+b，列 E/D 方程组
│   ├─ 能发现"总和恒定"或同源 ─→ §2.2 只看斜率符号，秒出 ±1
│   ├─ 有对称性 / 混合 / 三角 ──→ §2.3 大概率 ρ=0（且不独立）
│   └─ 全是正态的线性组合 ────→ §2.4 不相关 ⟺ 独立
│
├─ 出现 max / min / 极差 / 第k小
│   └─→ §3 次序统计量三件套
│
├─ 密度/分布函数写成 aF₁+bF₂ 或 af₁+bf₂ (a+b=1)
│   └─→ §4 混合分布：特征线性叠加
│
└─ 出现 θ̂ / 无偏 / 估计量的方差
    └─→ §5 无偏性恒等式 + 频数打包
```

# §1 期望方差的「拆解」动作
> **总纲**：数字特征题的最高境界是**只求特征，不求分布**。
> 凡是你开始动手求分布律 / 求密度，先停 3 秒，问一句"能不能拆？"

## §1.1 示性变量（0-1）分解法 ⭐⭐⭐ 最高频

**识别信号**
- 问的是「**总个数 / 总次数 / 总种数 / 配对成功对数 / 命中次数**」的 $E$ 或 $D$
- 直觉上求分布律要穷举一堆情况

**标准动作**
1. 把总数拆成 $X = c + \sum_{i=1}^{n} X_i$，其中 $c$ 是死数字（常数底座）
2. 令 $X_i = 1$（第 $i$ 个事件发生）/ $0$（不发生），算出单个 $p_i$
3. $E(X) = c + \sum p_i$ ← 无脑求和，**不管独立不独立**
4. $D(X) = \sum D(X_i) + 2\sum_{i<j}\mathrm{Cov}(X_i,X_j)$ ← **必须先判独立**

**防坑点（方差专属）**
| 场景 | 处理 |
|---|---|
| 独立（不同袋子摸球、有放回、独立样本） | 直接 $D=\sum p_i(1-p_i)$ |
| 不独立（不放回、总数固定、同一批球分色） | 老实加 $2\mathrm{Cov}$，或改用 §5.2「打包成二项」 |

**🔗 挂载区**
- [[03 强化习题#1 颜色种数期望（示性变量分解）]] — 盒中 $m$ 种颜色球，有放回抽 $n$ 次，求抽到的**颜色种数** $E(X)$
  → 令 $X_i=1$（第 $i$ 种颜色至少出现一次），$p_i = 1-(1-\frac1m)^n$，$E(X)=m\left[1-\left(\frac{m-1}{m}\right)^n\right]$
  ⚠️ 这里 $X_i$ **不独立**，但求期望不受影响 —— 这是本题的全部命门
- [[03 强化习题#10 三袋摸球：常数+0-1 分解]] — 3号袋白球数：$X = 3 + X_1 + X_2$，两袋独立 → 方差直接相加
- [[03 强化习题#16 频数无偏估计 T 及其方差]] — 频数方差 $D(N_2+N_3)$：令 $Y_k=1(X_k\in\{2,3\})$，独立 → $n\theta(1-\theta)$
- *（新题追加于此）*

## §1.2 LOTUS：随机变量函数的期望 ⭐⭐⭐

**识别信号**
- 要求 $E[g(X)]$，且 $g$ 长得复杂：$|X|$、$\min\{|X|,1\}$、$\max$、分段函数、$X^2$、$\frac{1}{X+1}$

**标准动作**
$$E[g(X)] = \int_{-\infty}^{+\infty} g(x) f_X(x)\,\mathrm{d}x \qquad\text{（离散：}\sum g(x_k)p_k\text{）}$$
1. **永远不求 $Y=g(X)$ 的密度**
2. 按 $g$ 的**分段点**拆区间
3. 拆完第一反应查**奇偶性**，对称区间化为 $2\int_0^{+\infty}$

**核心认知**（易错点）
> 无论 $g(x)$ 在某段上是常数 1 还是别的，**权重永远是 $f_X(x)\mathrm{d}x$**。
> 因为积分自变量是 $x$，决定"$x$ 出现可能性"的只有 $X$ 自己的分布。

**🔗 挂载区**
- [[03 强化习题#12 E[min{|X|,1}]：LOTUS 分段积分]] — $E[\min\{|X|,1\}]$，$X\sim$ 柯西 $\frac{1}{\pi(1+x^2)}$
  → 三段拆分 + 偶函数减半 → $\frac{\ln 2}{\pi}+\frac12$
- *（新题追加于此）*

## §1.3 级数「认结构」反写成期望 ⭐⭐

**识别信号**
- 化简过程中卡在一个求和式：$\sum (\text{多项式}) \times (\text{某分布的分布律})$

**标准动作**
1. 把 $\sum$ 后面扫成两块：$\sum \underbrace{g(t)}_{\text{取值}} \cdot \underbrace{P(T=t)}_{\text{概率}}$
2. 认出后面那块是哪个分布（几何/泊松/二项）
3. 整个式子 $= E[g(T)]$，然后线性拆开
4. $E(T^2) = D(T) + [E(T)]^2$ ← 默写公式，彻底绕开级数求和

**🔗 挂载区**
- [[03 强化习题#2 伪装几何分布求 E、D（级数认结构）]] — $P\{X=k\}=\frac{a^k}{(1+a)^{k+1}}$ 求 $E,D$
  → 识破这是伪装的**几何分布**（$p=\frac{1}{1+a}$，从 0 计数），$\sum(t^2+t)p(1-p)^{t-1} = E(T^2+T)$
  → 答案 (A) $a,\ a(1+a)$
- *（新题追加于此）*

## §1.4 线性性质暴力拆分 ⭐

**识别信号**：要求 $E(U\pm V)$、$D(aX+b)$

**标准动作**
- $E$ 恒可拆：$E(U-V)=E(U)-E(V)$，**不需要独立、不需要联合分布**
- $D$ 要小心：$D(U\pm V)=D(U)+D(V)\pm 2\mathrm{Cov}(U,V)$
- $D(aX+b)=a^2D(X)$ ← **常数不影响方差**（平移不改变波动）

**🔗 挂载区**
- [[03 强化习题#13 (0,1) 取 n 个数：极差期望 + 计数二项]] (I) — 极差 $d = U-V$ 的期望，拆成 $E(U)-E(V)$ 各自算一维
  ⚠️ 陷阱是去求 $(U,V)$ 的二维联合分布 —— 必死
- *（新题追加于此）*

# §2 相关系数 ρ 的「看不算」动作
> **总纲**：求 $\rho$ 时，「**算**」永远是下策，「**看**」才是上策。
> 先花 10 秒扫一遍有没有隐藏的线性关系 / 对称性，没有再动笔算 $\mathrm{Cov}$。

## §2.1 已知 ρ=±1 → 反推线性关系 ⭐⭐⭐

**识别信号**：题干直接给 $\rho_{XY}=1$ 或 $-1$

**标准动作（3 步肌肉记忆）**
1. 草稿纸写下 $\;Y = aX+b\;$（因为 $|\rho|=1 \iff P\{Y=aX+b\}=1$）
2. **定符号**：$\rho=1 \Rightarrow a>0$；$\rho=-1 \Rightarrow a<0$ ← 选项符号不对的直接划掉
3. **列方程组**（$Y$ 与 $aX+b$ 同分布 ⟹ 各阶特征全相等）
   $$\begin{cases} E(Y)=aE(X)+b \\ D(Y)=a^2 D(X) \end{cases}$$
   先由方差解 $a$（取符号），再由期望解 $b$

**🔗 挂载区**
- [[03 强化习题#5 ρ=1 反推线性关系]] — $X\sim U(0,1),\ Y\sim U(1,4),\ \rho=1$，求 $Y$ 与 $X$ 关系
  → $\frac{9}{12}=a^2\cdot\frac{1}{12} \Rightarrow a=3$；$2.5=3(0.5)+b \Rightarrow b=1$ → $Y=3X+1$
- *（新题追加于此）*

---

## §2.2 同源线性变换 → 只看斜率符号 ⭐⭐⭐

**识别信号（两类）**
- **A 类｜总和恒定**：「总共 $n$ 个，分成两类」（正/反面、合格/次品、命中/未命中）
  → 立刻写 $Y=n-X$，此时 $\rho_{XY}=-1$
- **B 类｜同源**：$U,V$ 都能写成**同一个** $X$ 的线性函数

**秒杀定理**
$$U=aX+b,\quad V=cX+d \quad\Longrightarrow\quad \rho_{UV}=\mathrm{sgn}(ac)$$
$ac>0 \Rightarrow \rho=1$；$ac<0 \Rightarrow \rho=-1$。**全程不算方差协方差。**

**🔗 挂载区**
- [[03 强化习题#6 总和恒定：同源线性看符号]] — 掷 $n$ 次硬币，$U=X+3Y,\ V=6X+Y$，求 $\rho_{UV}$
  → 代入 $Y=n-X$：$U=-2X+3n,\ V=5X+n$，$ac=-10<0$ → $\rho=-1$，10 秒
- *（新题追加于此）*

## §2.3 ρ=0 但不独立（"不相关 ⇏ 独立"的反例库）⭐⭐⭐

**识别信号**
- 求「$a$ 为何值时 $X$ 与 $Y$ 不相关」
- 密度是**混合正态**
- $U,V$ 是**三角函数**、**平方**、**绝对值**等非线性同源函数
- 分布关于某点**对称**

**标准动作**
1. 归到 $\mathrm{Cov}(X,Y) = E(XY) - E(X)E(Y) = 0$
2. 大量用**奇偶性 / 对称性**杀积分（"偶倍奇零"）
3. 问独立性 → **只要不是二维正态，就闭眼答"不独立"**，然后找反例：
   - 暴力法：代一个点验 $f(x_0,y_0) \ne f_X(x_0)f_Y(y_0)$
   - 或指出**支撑集不是矩形**

**🔗 挂载区**
- [[03 强化习题#7 Y=|X-a| 求不相关的 a]] — $X\sim U(-1,1)$，$Y=|X-a|$，求 $a$ 使 $X,Y$ 不相关
  → 解 $\mathrm{Cov}=0$ 定 $a$（$a=0$），注意 $Y$ 是 $X$ 的非线性函数，$\rho=0$ 但**强依赖**
- [[03 强化习题#8 混合二维正态：不相关但不独立]] — $f=\frac12\varphi_1+\frac12\varphi_2$（$\rho_1=\frac13,\rho_2=-\frac13$）
  → 边缘都是 $N(0,1)$；$E(XY)=\frac12(\frac13)+\frac12(-\frac13)=0 \Rightarrow \rho=0$；但**不独立**
  → 💡 **背下这个终极反例**："两个二维正态的线性组合不再是二维正态"，所以没有"不相关⟺独立"的特权
- [[03 强化习题#9 U=sinX、V=cosX 求 ρ（非线性同源）]] — $X\sim U[0,\frac\pi2]$，$U=\sin X,\ V=\cos X$，求 $\rho_{UV}$
  → 非线性同源 ⟹ $|\rho|\ne 1$；单调反向 ⟹ $\rho<0$ → 选 D（$-1<\rho<0$）
  → 对比 §2.2：**线性**同源才出 $\pm1$，**非线性**同源只能出严格介于之间
- *（新题追加于此）*

## §2.4 二维正态特权：不相关 ⟺ 独立 ⭐⭐⭐

**识别信号**：所有变量都由**独立正态**经**线性组合**得到

**标准动作（3 步链条）**
1. **升维**：$(X_1,X_2)$ 服从二维正态 ⟹ 其线性组合 $(U,V)$ **仍服从二维正态**
2. **算 Cov**：$\mathrm{Cov}(U,V)=0$ ⟹ 不相关 ⟹（**因为是二维正态**）**独立**
3. **升级**：$U,V$ 独立 ⟹ 任意函数 $g(U),h(V)$ 也独立

> ⚠️ 第 1 步的"故 $(U,V)$ 服从二维正态"这句话**必须写在卷面上**，否则第 2 步的等价性无依据，扣分。

**🔗 挂载区**
- [[03 强化习题#15 第三问 正态平方的独立性（不相关⟺独立）]] (III) — $X_1,X_2$ iid $N(0,1)$，问 $(X_1+X_2)^2$ 与 $(X_1-X_2)^2$ 是否独立
  → $\mathrm{Cov}(X_1+X_2,X_1-X_2)=D(X_1)-D(X_2)=0$ → $U\perp V$ → $U^2\perp V^2$，**独立**
- [[03 强化习题#14 Z=X+Y（离散+均匀）求 ρ_XZ]] — $X\perp Y$，$P\{X=0\}=P\{X=1\}=\frac12$，$Y\sim U[0,1]$，求 $Z=X+Y$ 的分布与 $\rho_{XZ}$
  → $\rho_{XZ}$ 用 $\mathrm{Cov}(X,X+Y)=D(X)$（独立⟹$\mathrm{Cov}(X,Y)=0$）
  → 📌 **通用套路**：$\rho_{X,X+Y}=\sqrt{\frac{D(X)}{D(X)+D(Y)}}$，这类"变量与自己的和"的相关系数直接套
- *（新题追加于此）*

# §3 次序统计量（max / min / 极差）⭐⭐

**识别信号**：出现 $\max$、$\min$、极差、"最大的那个数"、"第一名"、比较大小

## §3.1 三件套公式（必须默写级）
设 $X_1,\dots,X_n$ iid，分布函数 $F$，密度 $f$：

| 量 | 分布函数 | 密度 |
|---|---|---|
| $U=\max$ | $F_U(u)=[F(u)]^n$ | $f_U=n[F(u)]^{n-1}f(u)$ |
| $V=\min$ | $F_V(v)=1-[1-F(v)]^n$ | $f_V=n[1-F(v)]^{n-1}f(v)$ |

**推导锚**：$\max\le u \iff$ 每个都 $\le u$；$\min > v \iff$ 每个都 $> v$（**最小值用反面思考**）

## §3.2 对称性秒杀（选填专用）
$n$ 个 iid **连续型**变量，指定其中某一个是最小/最大的概率恒为 $\frac{1}{n}$。
（全排列 $n!$ 种等可能；连续型保证两两相等概率为 0）

## §3.3 比较大小的大题模板
$$P\{U>V\} = \int_{-\infty}^{+\infty} F_V(u)\,f_U(u)\,\mathrm{d}u$$
三步走：**设元降维 → 求被比较者的 $F_V$ → 列单积分**（写出这一步就是得分点）

## 🔗 挂载区
- [[03 强化习题#11 比较大小：min 的对称性秒杀]] — $P\{X_n > \min\{X_1,\dots,X_{n-1}\}\}$
  → 转对立事件 = "$X_n$ 是全 $n$ 个中最小" = $\frac1n$ → 答案 $\frac{n-1}{n}$
  → 大题写法：$\int [1-F]^{n-1}f\,\mathrm{d}x$ 凑微分 $=\frac1n$
- [[03 强化习题#13 (0,1) 取 n 个数：极差期望 + 计数二项]] (I) — $(0,1)$ 内取 $n$ 个数，极差 $d$ 的期望
  → $E(U)=\frac{n}{n+1},\ E(V)=\frac{1}{n+1} \Rightarrow E(d)=\frac{n-1}{n+1}$
  → 💡 **直觉验算**：$n$ 个点把线段切成 $n+1$ 段，每段期望长 $\frac{1}{n+1}$，$d$ 跨越中间 $n-1$ 段
- *（新题追加于此）*

# §4 混合分布：特征线性叠加 ⭐⭐

**识别信号**
- $F(x)=aF_1(x)+bF_2(x)$ 或 $f(x,y)=a\varphi_1+b\varphi_2$，且 $a+b=1$

**核心认知（"平行宇宙"模型）**
上帝按概率 $a$ / $b$ 抛硬币决定你进入宇宙 1 还是宇宙 2，你观测到的就是混合结果。

**标准动作**
1. **一切"期望型"特征都线性叠加**：$E(X)=aE_1(X)+bE_2(X)$，$E(X^2)$、$E(XY)$、边缘密度**同理**
2. ⚠️ **方差绝不能直接叠加！** 必须走 $D(X)=E(X^2)-[E(X)]^2$
   $$E(X^2)=aE_1(X^2)+bE_2(X^2) = a[D_1+\mu_1^2]+b[D_2+\mu_2^2]$$
3. 问独立性 → **闭眼答"不独立"**（混合已破坏二维正态结构，见 §2.3）

**🔗 挂载区**
- [[03 强化习题#3 混合正态分布求方差]] — $F(x)=0.2\Phi(x)+0.8\Phi\!\left(\frac{x-4}{2}\right)$，求 $D(X)$
  → 宇宙1：$N(0,1)$；宇宙2：$N(4,4)$
  → $E(X)=0.2(0)+0.8(4)=3.2$
  → $E(X^2)=0.2(1+0)+0.8(4+16)=0.2+16=16.2$
  → $D(X)=16.2-3.2^2=16.2-10.24=5.96$ → 选 (B)
  → ⚠️ 选项 (A) 5.49 / (C) 5.31 就是给"直接叠加方差"的人准备的陷阱
- [[03 强化习题#8 混合二维正态：不相关但不独立]] — 混合二维正态求边缘、$\rho$、独立性（详见 §2.3）
- *（新题追加于此）*

# §5 与数理统计的接口 ⭐⭐
> 数字特征是第七章（参数估计）的**计算引擎**。套卷里这类题常出现在大题第 2 问。

## §5.1 无偏性 → 恒等式系数对比
**标准动作**
1. 无偏 $\iff E(\hat\theta) \equiv \theta$ **恒成立**
2. 用期望线性性展开，整理成 $\theta$ 的多项式
3. **对照系数**：常数项 = 0，一次项 = 1，高次项 = 0 → 解出待定常数

**🔗 挂载区**
- [[03 强化习题#16 频数无偏估计 T 及其方差]] — $T=a_1N_1+a_2N_2+a_3N_3$ 无偏估计 $\theta$
  → 频数本质是二项：$E(N_i)=n\,p_i$
  → 展开 $=n[a_1+(a_2-a_1)\theta+(a_3-a_2)\theta^2]$ → 对照得 $a_1=0,\ a_2=a_3=\frac1n$
- [[03 强化习题#4 折叠正态定无偏系数]] — $\hat\sigma = a|X_1-X_2|$，$E(\hat\sigma)=\sigma$ 求 $a$
  → $X_1-X_2\sim N(0,2\sigma^2)$，用**折叠正态**结论 $E|Z|=\sqrt{\frac{2}{\pi}}\sigma_Z$
  → $E|X_1-X_2| = \sqrt{\frac2\pi}\cdot\sqrt2\sigma = \frac{2\sigma}{\sqrt\pi}$ → $a=\frac{\sqrt\pi}{2}$ → (A)
  → 💡 **必背**：$Z\sim N(0,\sigma^2) \Rightarrow E|Z|=\sqrt{\frac2\pi}\,\sigma$，$E(Z^2)=\sigma^2$

## §5.2 频数（$N_i$）的处理三原则
1. **单个频数是二项**：$N_i \sim B(n,p_i)$，故 $E(N_i)=np_i,\ D(N_i)=np_i(1-p_i)$
2. **频数之和先打包，绝不算协方差**：
   $$N_i+N_j \sim B(n,\ p_i+p_j) \quad\text{（合并事件，再当一个新二项）}$$
3. 万一必须硬算：$\mathrm{Cov}(N_i,N_j) = -n p_i p_j$（$i\ne j$，负号来自总数固定）

**🔗 挂载区**
- [[03 强化习题#16 频数无偏估计 T 及其方差]] — $D(T)=D\!\left(\frac{N_2+N_3}{n}\right)$
  → 打包 $N_2+N_3\sim B(n,\theta)$ → $\frac{\theta(1-\theta)}{n}$
  → 两条通法（0-1分解 / 硬算协方差）都能到，考场选第一条

## 6.1 分布的 E / D
| 分布 | $E$ | $D$ |
|---|---|---|
| $B(1,p)$ | $p$ | $p(1-p)$ |
| $B(n,p)$ | $np$ | $np(1-p)$ |
| $P(\lambda)$ | $\lambda$ | $\lambda$ |
| 几何 $G(p)$（从1计数） | $\frac1p$ | $\frac{1-p}{p^2}$ |
| $U(a,b)$ | $\frac{a+b}{2}$ | $\frac{(b-a)^2}{12}$ |
| $E(\lambda)$ | $\frac1\lambda$ | $\frac{1}{\lambda^2}$ |
| $N(\mu,\sigma^2)$ | $\mu$ | $\sigma^2$ |
| $\chi^2(n)$ | $n$ | $2n$ |

## 6.2 高频"非标准"结论
- $E(X^2) = D(X)+[E(X)]^2$ ← **最高频变形**
- $Z\sim N(0,\sigma^2) \Rightarrow E|Z| = \sqrt{\frac{2}{\pi}}\,\sigma$（折叠正态）
- $X\sim U(0,1),\ n$ 个 iid：$E(\max)=\frac{n}{n+1},\ E(\min)=\frac{1}{n+1}$
- $\rho_{X,\,X+Y} = \sqrt{\dfrac{D(X)}{D(X)+D(Y)}}$（$X\perp Y$）
- $\mathrm{Cov}(X+Y,\ X-Y) = D(X)-D(Y)$
- 四大可加性：泊松 / 正态 / 二项（同 $p$）/ 卡方

## 6.3 独立 · 不相关 关系图
```text
                    独立
                     ↓ （永远成立）
                   不相关 (ρ=0)
                     ↑ （仅当 (X,Y) 服从二维正态时成立）

反例库（不相关但不独立）：
  · 混合二维正态       → §2.3 / 题8
  · Y = |X-a|, X~U对称 → §2.3 / 题7
  · U=sinX, V=cosX     → §2.3 / 题9（这个连 ρ=0 都不成立，但同理说明非线性）
```
