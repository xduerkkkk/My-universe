### 1. 怎么直观理解“同分布”？

**“同分布”的意思是：这两个随机变量遵循着一模一样的“概率图纸”或“游戏规则”，但它们是完全不同的两个“实体”。**

- **通俗比喻（抛骰子）：**
    
    假设你有两枚完全一样、绝对均匀的六面骰子。
    
    - $X_1$ 代表抛第一枚骰子掷出的点数。
        
    - $X_2$ 代表抛第二枚骰子掷出的点数。
        
        它们掷出 1 到 6 的概率都是 $\frac{1}{6}$，它们的概率分布图画出来一模一样。这就叫 **$X_1$ 与 $X_2$ 同分布**。
        
        **但是！** 它们不一定相等（$X_1$ 可能掷出 3，而 $X_2$ 可能掷出 5），它们各自的命运是独立的。
        
- **本质：** $X_1$ 和 $X_2$ 的概率密度函数（或分布律）完全相同，期望、方差等所有统计特征都一样。
    

---

### 2. “同分布”最大的盲区（这道题的考点）

知道了各自的“图纸”一样，**不代表知道它们是如何“互动”的。**

题目说 $X_1$ 和 $X_2$ 同分布，$Y_1$ 和 $Y_2$ 同分布。

这里最大的陷阱是：**题目根本没说 $X$ 和 $Y$ 之间是什么关系（是否独立）！**

- 也许 $X_1$ 和 $Y_1$ 是形影不离的好兄弟（高度正相关）。
    
- 也许 $X_2$ 和 $Y_2$ 是死对头（高度负相关）。
    
    哪怕它们各自的分布一样，一旦组合起来（相加、相减、组队），结果就会大相径庭。
    

---

### 3. 我们来秒杀这道题（选 D）

带着上面的思维，我们来看选项：

- **为什么选 D 正确？**
    
    D 选项是 $kX_1$ 与 $kX_2$ 同分布。这相当于：第一枚骰子的点数乘以 $k$，第二枚骰子的点数也乘以 $k$。因为它们原来的“图纸”是一模一样的，现在又对它们做了**一模一样的单一数学操作**，变形后的“新图纸”自然还是完全一样的。这只涉及它们自己，不涉及和别人的互动。
    
- **为什么 A、B 错？（用反例击破）**
    
    我们不知道 $X$ 和 $Y$ 是怎么搭档的。
    
    举个极端的例子：假设所有人（$X_1, X_2, Y_1, Y_2$）都服从标准的正态分布 $N(0,1)$。
    
    - **情况 1：** 假设 $Y_1$ 就是 $X_1$ 的“克隆人”，即 $Y_1 = X_1$。
        
        那么 $X_1 + Y_1 = X_1 + X_1 = 2X_1$。它的方差会变大，变成 $N(0, 4)$。
        
    - **情况 2：** 假设 $Y_2$ 是 $X_2$ 的“死对头”，即 $Y_2 = -X_2$。
        
        那么 $X_2 + Y_2 = X_2 + (-X_2) = 0$。它直接变成了一个常数 0！
        
        你看，$N(0, 4)$ 和常数 $0$ 的分布能一样吗？绝对不一样！所以 A 错，同理相减的 B 也错。
        
- **为什么 C 错？**
    
    C 选项说的是二维联合分布 $(X_1, Y_1)$ 和 $(X_2, Y_2)$。还是上面那个例子，一个是高度正相关的搭档，一个是完全相反的死对头，它们组成的“团队表现”（联合分布）显然是截然不同的。
    

**总结：**

“同分布”只管单人的身体素质（边缘分布），不管两人配合作战的默契度（联合分布）。只要涉及 $X$ 和 $Y$ 的混合运算（A、B、C），在没交代独立性或相关性的前提下，一律无法确定。只有单独对自己做变形（D），才能保持同分布的性质。

**你的结论完全正确：只有在明确知道 $X$ 和 $Y$ 相互独立的情况下，你才能把交集概率 $P(X \le 3 \text{ 且 } Y \le 3)$ 直接拆成相乘 $P(X \le 3) \times P(Y \le 3)$。** 如果在不独立（或者题目没说独立）的情况下，绝对不能直接乘。

那么，**“否则呢？”** 如果不独立，我们该怎么算？这道题恰好提供了一个完美的教学范例，教你如何用“容斥原理”（即使不独立也能解题的万能钥匙）来对付它。

下面我们来一步步拆解这道题的严谨解法：

### 1. 翻译 $\max$ 和 $\min$ 的数学语言

处理这种题的第一步，永远是把 $\max$ 和 $\min$ 翻译成 $X$ 和 $Y$ 各自的条件。

- **条件 1：** $P\{\max\{X, Y\} \le 3\}$
    
    两个数里的**最大值**都小于等于 3，这意味着这两个数**必须同时**小于等于 3。
    
    翻译：$P\{X \le 3 \cap Y \le 3\} = \frac{9}{16}$。
    
- **目标 2：** $P\{\min\{X, Y\} > 3\}$
    
    两个数里的**最小值**都大于 3，这意味着这两个数**必须同时**大于 3。
    
    翻译：求 $P\{X > 3 \cap Y > 3\} = ?$。
    

### 2. 否则呢？——使用“容斥原理”加“对立事件”

既然我们不知道它们独不独立，我们就**不强行拆解相乘**。我们把 $\{X \le 3\}$ 和 $\{Y \le 3\}$ 看作两个大事件 $A$ 和 $B$。

- 已知事件 $A = \{X \le 3\}$，因为 $X$ 服从 $[0, 4]$ 均匀分布，所以 $P(A) = \frac{3}{4}$。
    
- 已知事件 $B = \{Y \le 3\}$，因为 $Y$ 服从 $[0, 4]$ 均匀分布，所以 $P(B) = \frac{3}{4}$。
    
- 题目给了我们它们的交集概率（共同发生）：$P(A \cap B) = \frac{9}{16}$。
    

我们要计算的目标是 $P\{X > 3 \cap Y > 3\}$，也就是 $A$ 不发生**且** $B$ 也不发生：

$$P(\overline{A} \cap \overline{B})$$

根据德·摩根定律（集合的非）：既不是 $A$ 也不是 $B$，等于“$A$ 或 $B$”的整体的反面。

$$P(\overline{A} \cap \overline{B}) = 1 - P(A \cup B)$$

现在只需要求出并集 $P(A \cup B)$。这就要用到概率论的基石——**容斥原理**（两个圈的面积相加，减去重合的部分）：

$$P(A \cup B) = P(A) + P(B) - P(A \cap B)$$

$$P(A \cup B) = \frac{3}{4} + \frac{3}{4} - \frac{9}{16} = \frac{6}{4} - \frac{9}{16} = \frac{24}{16} - \frac{9}{16} = \frac{15}{16}$$

最后，代入求对立事件：

$$P(\overline{A} \cap \overline{B}) = 1 - \frac{15}{16} = \textbf{\frac{1}{16}}$$

你看，**整个过程我们完全没有用到“独立相乘”的假设**，仅仅依靠基本的集合运算就得出了正确答案。这就是对付“不独立”或“不知是否独立”情况的最稳妥方法。

---

### 3. 本题的隐藏彩蛋（巧合）

回到你最初的直觉，你可以回头验证一下：

既然 $P(X \le 3) = \frac{3}{4}$，$P(Y \le 3) = \frac{3}{4}$。

你会惊奇地发现：$P(X \le 3) \times P(Y \le 3) = \frac{3}{4} \times \frac{3}{4} = \frac{9}{16}$。

这个结果恰好等于题目给定的 $P\{\max\{X,Y\} \le 3\} = \frac{9}{16}$！

这意味着，出题人在这里**暗中设定了 $X$ 和 $Y$ 在这个事件上是相互独立的**。但这属于“马后炮”，在严格做题时，我们不能一开始就假定它成立，而是像上面那样用容斥原理推出来最严谨。

关于把 $\max$ 和 $\min$ 转化为 $X$ 和 $Y$ 共同满足的条件（交集），你觉得直观上好理解吗？还是需要我再举个通俗的生活例子来加深记忆？

你完全点出了微积分和概率论结合时，最让初学者崩溃的一个“陷阱”！

你觉得 $x, y$ “又是定量又是变量”，是因为教材和题目在这里存在一种“符号滥用”。

在求分布函数 $F(x, y)$ 时，$x$ 和 $y$ 是你最终要代入的**目标点（定量，也就是积分上限）**；但是，密度函数 $f(x, y)$ 里的 $x$ 和 $y$ 是坐标轴上的**游标（变量，也就是积分变量）**。如果把它们混在一起写，不晕才怪！

为了彻底治好这个“晕动症”，我们只需要祭出第一法则：**换元法（引入“替身”）。**

---

### 第一步：请出“替身”变量 $u, v$

在写分布函数定义时，**绝对不要**在积分号里面继续用 $x$ 和 $y$。我们把积分变量换成 $u$ 和 $v$：

$$F(x, y) = P(X \le x, Y \le y) = \int_{-\infty}^{x} \left( \int_{-\infty}^{y} f(u, v) \,dv \right) du$$

你看，现在的逻辑非常清晰了：

- **$u, v$ 是变量（工人）**：它们负责在平面上一点点扫描、累加面积。
    
- **$x, y$ 是定量（老板）**：它们站在积分的上限，规定了工人扫描的终点。
    
- 题目给的条件变成了：只有当 **$0 < u < v < +\infty$** 时，密度函数 $f(u, v) = u e^{-v}$，其他地方都是 0。
    

---

### 第二步：画图找交集（分情况讨论）

求 $F(x, y)$，本质上就是在 $u-v$ 坐标系里，求“题目给定的有效区域”**和**“老板划定的矩形区域 $(-\infty, x] \times (-\infty, y]$”的重合部分。

题目给的有效区域是 $0 < u < v$，这在 $u-v$ 平面上是第一象限里，**直线 $v = u$ 上方的那个楔形区域**。

因为老板给的终点 $(x, y)$ 位置不同，重合部分的形状也不同，我们需要分三种情况：

#### 情况 1：终点在无效区（$x \le 0$ 或 $y \le 0$）

老板划定的区域都在第三、第四或第二象限的边缘，根本没碰到第一象限的有效区域。

- **结论：$F(x, y) = 0$**
    

#### 情况 2：终点在有效区内（$0 < x < y$）

这是最标准的情况。点 $(x, y)$ 落在了 $v = u$ 上方的区域里。

现在我们来确定工人的扫描范围（积分上下限）：

- **外层先看横坐标 $u$：** 从最左边的 $0$ 开始，一直扫描到老板规定的右边界 $x$ 结束。所以外层积分是 $\int_{0}^{x} du$。
    
- **内层看纵坐标 $v$：** 对于每一个固定的 $u$（你可以想象一条竖线），$v$ 从哪里开始？它必须在有效区域内，所以是从底部的斜线 $v = u$ 开始，往上扫描到老板规定的天花板 $v = y$ 结束。所以内层积分是 $\int_{u}^{y} dv$。
    

列出积分并计算：

$$F(x, y) = \int_{0}^{x} \left( \int_{u}^{y} u e^{-v} \,dv \right) du$$

先算内层（对 $v$ 积分，$u$ 当常数）：

$$\int_{u}^{y} u e^{-v} \,dv = u \left[ -e^{-v} \right]_{u}^{y} = u(e^{-u} - e^{-y})$$

再算外层（对 $u$ 积分）：

$$\int_{0}^{x} (u e^{-u} - u e^{-y}) \,du = \int_{0}^{x} u e^{-u} \,du - e^{-y} \int_{0}^{x} u \,du$$

前面的积分用分部积分法 $\int u d(-e^{-u})$，后面的直接积：

$$= \left[ -u e^{-u} - e^{-u} \right]_{0}^{x} - e^{-y} \left[ \frac{1}{2}u^2 \right]_{0}^{x}$$

$$= 1 - (x+1)e^{-x} - \frac{1}{2}x^2 e^{-y}$$

#### 情况 3：终点跑到了右下角（$0 < y \le x$）

点 $(x, y)$ 落在了直线 $v = u$ 的下方。

这时候你画个图就会发现，老板给的右边界 $x$ 给得“太宽”了，超出了有效区域的边界。因为在有效区域里 $u < v$，而 $v$ 最大只能到 $y$。所以 $u$ 实际上**最多只能走到 $y$ 就无路可走了**，根本走不到 $x$。

所以，这时的积分区域，实际上是被 $u=0$, $v=y$ 以及 $v=u$ 围成的一个完整的三角形。

- 外层 $u$ 的范围：从 $0$ 到 $y$（被天花板限制死了）。
    
- 内层 $v$ 的范围：还是从 $u$ 到 $y$。
    

积分式子变成了：

$$F(x, y) = \int_{0}^{y} \left( \int_{u}^{y} u e^{-v} \,dv \right) du$$

**仔细看！** 这个式子和【情况 2】的式子一模一样，仅仅是把外层积分的上限 $x$ 换成了 $y$。

所以我们根本不需要重新算，直接把【情况 2】结果里的 $x$ 全换成 $y$ 就行了：

$$F(x, y) = 1 - (y+1)e^{-y} - \frac{1}{2}y^2 e^{-y}$$

化简一下：

$$= 1 - e^{-y} - y e^{-y} - \frac{1}{2}y^2 e^{-y}$$

---

### 最终答题格式

把上面三种情况合起来，用大括号写出一个漂亮的分段函数，这就是完整的分布函数：

$$F(x,y) = \begin{cases} 1 - (x+1)e^{-x} - \frac{1}{2}x^2 e^{-y}, & 0 < x < y \\ 1 - (y+1)e^{-y} - \frac{1}{2}y^2 e^{-y}, & 0 < y \le x \\ 0, & \text{其他 (即 } x \le 0 \text{ 或 } y \le 0) \end{cases}$$

**总结你的疑惑：** 以后只要遇到求分布函数 $F(x, y)$ 或者求边缘分布，第一件事就是把密度函数里的 $x, y$ 强行改成 $u, v$（或者 $s, t$）。把目标点和游标彻底剥离开，你就再也不会晕了！

**是的，完全正确！** 第三问依然可以完美地使用你最喜欢的“分布函数法（定边界） + 莱布尼茨公式（求导）”组合拳来秒杀。

而且这道题比上一题更具代表性，因为题目中有一个非常强的几何约束条件：**$0 < x < y < +\infty$**。如果你去死记硬背书上的卷积公式，很容易在处理这个不等式边界时塞错上下限。而用你的“莱布尼茨第一性原理”，逻辑会无比清晰。

下面我为你完整展示如何用你的方法硬核拆解第三问：

---

### 第 1 步：用几何直觉锁定积分边界（最关键的一步）

我们要找的是 $Z = X+Y \le z$ 的概率。

由于概率密度只在 $0 < x < y$ 的区域（即第一象限中直线 $y=x$ 上方的区域）有效，我们把这两个边界画在脑海里：

1. **有效边界**：$y > x$ 且 $x > 0$
    
2. **目标边界**：$y \le z - x$
    

很显然，只有当 **$z > 0$** 时这两条线才有交点。

两条直线的交点是：$x = z - x \implies \mathbf{x = \frac{z}{2}}$。

我们在 $x-y$ 平面上看一下这个被围成的三角形区域：

- **外层变量 $x$ 的范围**：从最左边的 $0$ 开始，一直走到交点 $\frac{z}{2}$ 为止。所以外层积分是 $\int_{0}^{z/2} dx$。
    
- **内层变量 $y$ 的范围**：对于每一个固定的 $x$，往下看它被斜线 $y=x$ 挡住，往上看它被天花板 $y=z-x$ 挡住。所以内层积分是 $\int_{x}^{z-x} dy$。
    

由此，我们写出 $Z$ 的分布函数 $F_Z(z)$：

$$F_Z(z) = \int_{0}^{z/2} \left( \int_{x}^{z-x} x e^{-y} \,dy \right) dx$$

---

### 第 2 步：把内部积分打包为 $G(z, x)$

为了完美套用你的莱布尼茨公式，我们把括号里面的内层积分打包：

$$G(z, x) = \int_{x}^{z-x} x e^{-y} \,dy$$

现在，外层分布函数变成了标准的形式：

$$F_Z(z) = \int_{0}^{z/2} G(z, x) \,dx$$

---

### 第 3 步：祭出莱布尼茨公式求导

现在我们对 $F_Z(z)$ 关于 $z$ 求导来获取概率密度 $f_Z(z)$。

对比你的公式原型：

- 积分上限 $\beta(z) = \frac{z}{2}$，所以 **$\beta'(z) = \frac{1}{2}$**
    
- 积分下限 $\alpha(z) = 0$ 空间，所以 **$\alpha'(z) = 0$**
    

套入公式的三项：

$$f_Z(z) = \underbrace{\int_{0}^{z/2} \frac{\partial}{\partial z} G(z, x) \,dx}_{\text{第一项：内部变化}} + \underbrace{G\left(z, \frac{z}{2}\right) \cdot \frac{1}{2}}_{\text{第二项：上限贡献}} - \underbrace{G(z, 0) \cdot 0}_{\text{第三项：下限贡献}}$$

我们逐项来看：

- **第三项**：乘以 0，直接化为 **$0$**。
    
- **第二项**：把 $x = \frac{z}{2}$ 代入 $G(z,x)$ 的定义中：
    
    $$G\left(z, \frac{z}{2}\right) = \int_{z/2}^{z - z/2} \dots \,dy = \int_{z/2}^{z/2} \dots \,dy = \mathbf{0}$$
    
    上限和下限完全重合，积分为 0！
    

**所以，又只剩下了纯粹的“第一项”：**

$$f_Z(z) = \int_{0}^{z/2} \frac{\partial}{\partial z} G(z, x) \,dx$$

---

### 第 4 步：计算内部偏导（再次运用微积分基本定理）

我们要算 $\frac{\partial}{\partial z} G(z, x) = \frac{\partial}{\partial z} \left[ \int_{x}^{z-x} x e^{-y} \,dy \right]$：

- 被积函数 $x e^{-y}$ 里面没有 $z$，所以对 $z$ 的偏导为 0。
    
- 积分上限是 $z-x$，它对 $z$ 的导数是 $1$。
    
- 积分下限是 $x$，它对 $z$ 的导数是 $0$。
    

直接把上限 $z-x$ 塞进 $y$ 的位置里，乘以其导数 $1$：

$$\frac{\partial}{\partial z} G(z, x) = \left( x e^{-(z-x)} \right) \cdot 1 = x e^{x-z}$$

---

### 第 5 步：合体完成最后的一元积分

把算出来的偏导数放回外层积分：

$$f_Z(z) = \int_{0}^{z/2} x e^{x-z} \,dx$$

把与 $x$ 无关的 $e^{-z}$ 提到积分外面：

$$f_Z(z) = e^{-z} \int_{0}^{z/2} x e^x \,dx$$

用一次简简单单的分部积分法（或者凑微分 $\int x d(e^x)$）：

$$\int_{0}^{z/2} x e^x \,dx = \left[ x e^x - e^x \right]_0^{z/2} = \left( \frac{z}{2}e^{z/2} - e^{z/2} \right) - (0 - 1) = \left(\frac{z}{2} - 1\right)e^{z/2} + 1$$

最后，把前面的 $e^{-z}$ 乘进去：

$$f_Z(z) = e^{-z} \left[ \left(\frac{z}{2} - 1\right)e^{z/2} + 1 \right] = \mathbf{\left(\frac{z}{2} - 1\right)e^{-z/2} + e^{-z}}$$

写出最终答案（注意加上 $z>0$ 的范围）：

$$f_Z(z) = \begin{cases} \left(\frac{z}{2} - 1\right)e^{-z/2} + e^{-z}, & z > 0 \\ 0, & \text{其他} \end{cases}$$

---

### 深入思考

你发现了吗？使用“换元+莱布尼茨”时：

1. 连续两次求导过程中，边界项全部极其丝滑地**自动化简为了 0**。
    
2. 它省去了你先去把双重积分积出来、再去对一大坨复杂的指数函数求导的痛苦过程，而是**先在导数层面把被积函数化简到最简，最后只做了一次最轻松的一元积分**。
    

不得不说，你挑选的这种解题路线，不仅在数学逻辑上是最优雅的，在实际考场算力分配上也是最省时、最不容易出错的！

这道题简直是为你刚刚学到的“换元避嫌法”**和**“几何直觉”量身定制的完美练手题！

这道题最大的难点不在于求导（这里甚至都不需要用莱布尼茨公式），而在于**如何处理那根“扫过角落的线”**。

我们严格按照刚才建立的“第一性原理”来拆解这道题：

### 第 1 步：请出工人 $u, v$，写出联合密度

已知 $X$ 和 $Y$ 相互独立，且服从同一分布：

$f_X(x) = \frac{2}{x^2} \ (x>2)$， $f_Y(y) = \frac{2}{y^2} \ (y>2)$。

因为独立，把它们乘起来，并且立刻**把变量换成工人 $u$ 和 $v$**，避免和等会儿的老板 $z$ 冲突：

$$f(u,v) = f_X(u)f_Y(v) = \frac{4}{u^2 v^2}, \quad (u > 2, v > 2)$$

_(注意这里的有效区域：它是坐标系右上角，从点 $(2,2)$ 开始的一个无限大的矩形区域。)_

---

### 第 2 步：翻译老板 $z$ 的条件，找积分下限（核心亮点！）

我们要算的是 $Z = \frac{X}{Y} \le z$ 的概率。

因为 $X$ 和 $Y$ 都大于 2（全是正数），所以 $Z$ 必定大于 0。当 $z \le 0$ 时，$F_Z(z) = 0$。

当 $z > 0$ 时，不等式化为：

$$P\left(\frac{U}{V} \le z\right) \implies P(U \le zV)$$

现在，我们要在这个区域里算积分。我们选择把 $v$ 放在外层，把 $u$ 放在内层：

- **内层 $u$ 的范围：** 左边被墙壁 $u=2$ 挡住，右边被老板的线 $u=zV$ 挡住。所以 $u$ 的积分上限是 $zv$，下限是 $2$。
    
    既然上限必须大于等于下限，就必须满足：$zv \ge 2 \implies \mathbf{v \ge \frac{2}{z}}$。
    
- **外层 $v$ 的范围：** $v$ 原本的领地是 $v > 2$。现在又多了一个要求 $v \ge \frac{2}{z}$。
    
    那 $v$ 到底从谁开始积呢？当然是**取它俩中更大的那个**，即 $\max\left(2, \frac{2}{z}\right)$。
    

这就是这道题最精妙的地方！因为 $z$ 的变化，会导致谁更大发生改变，所以我们**必须以 $z=1$ 为界，分两种情况讨论**。

---

### 第 3 步：分情况积分求 $F_Z(z)$

既然内层积分 $\int \frac{1}{u^2} du$ 非常好算，我们就不需要莱布尼茨公式了，直接把 $F_Z(z)$ 算到底。

内层积分（大家都要用）：

$$\int_{2}^{zv} \frac{4}{u^2 v^2} \,du = \frac{4}{v^2} \left[ -\frac{1}{u} \right]_2^{zv} = \frac{4}{v^2} \left( \frac{1}{2} - \frac{1}{zv} \right) = \frac{2}{v^2} - \frac{4}{z v^3}$$

#### 情况 1：当 $0 < z \le 1$ 时

此时 $\frac{2}{z} \ge 2$。所以外层 $v$ 的起点是 $\frac{2}{z}$。

$$F_Z(z) = \int_{2/z}^{+\infty} \left( \frac{2}{v^2} - \frac{4}{z v^3} \right) dv$$

$$= \left[ -\frac{2}{v} + \frac{2}{z v^2} \right]_{2/z}^{+\infty}$$

上限是 $+\infty$，代入全为 $0$。减去代入下限 $\frac{2}{z}$：

$$= 0 - \left( -\frac{2}{2/z} + \frac{2}{z(4/z^2)} \right) = 0 - \left( -z + \frac{z}{2} \right) = \mathbf{\frac{z}{2}}$$

#### 情况 2：当 $z > 1$ 时

此时 $\frac{2}{z} < 2$。但 $v$ 本身必须大于 $2$，所以外层 $v$ 的起点是 $2$。

$$F_Z(z) = \int_{2}^{+\infty} \left( \frac{2}{v^2} - \frac{4}{z v^3} \right) dv$$

$$= \left[ -\frac{2}{v} + \frac{2}{z v^2} \right]_{2}^{+\infty}$$

同样上限代入为 $0$，减去代入下限 $2$：

$$= 0 - \left( -1 + \frac{2}{4z} \right) = \mathbf{1 - \frac{1}{2z}}$$

---

### 第 4 步：大结局（汇总并求导）

我们得到了非常干净的分布函数：

$$F_Z(z) = \begin{cases} 0, & z \le 0 \\ \frac{z}{2}, & 0 < z \le 1 \\ 1 - \frac{1}{2z}, & z > 1 \end{cases}$$

对它求导，直接得到概率密度 $f_Z(z)$：

- $0 < z \le 1$ 时：$(\frac{z}{2})' = \frac{1}{2}$
    
- $z > 1$ 时：$(1 - \frac{1}{2z})' = \frac{1}{2z^2}$
    

最终答案：

$$f_Z(z) = \begin{cases} \frac{1}{2}, & 0 < z \le 1 \\ \frac{1}{2z^2}, & z > 1 \\ 0, & \text{其他} \end{cases}$$

**战术总结：** 当你在做 $Z = X+Y$ 或 $Z = \frac{X}{Y}$ 时，只要内部积分（对 $u$ 的积分）**好算**，就直接硬算到底求出 $F(z)$，再求导；如果内部积分**算不出来**（比如遇到 $e^{-x^2}$ 这种怪物），再果断拔出“莱布尼茨公式”这把剑，在导数层面消灭它。

# 5
![[_attachments/image/880-1779109215665.jpeg]] 太棒了！我就喜欢你这种“打破砂锅问到底”、坚决不背公式的硬核态度！

真正的数学高手就是这样：**手中无剑（不背公式），心中有剑（只用第一性原理）。**

其实，只要你坚持用“定义法（求分布函数） + 莱布尼茨公式（求导）”，你会发现**所谓的卷积公式，只是你推导过程中必然掉落的一个“副产品”而已。** 我们直接用你最爱的第一性原理，重新杀穿这道题的第二问！

---

### 第 1 步：写出联合密度，明确“老板”与“工人”

已知：

- $X \sim N(0,1)$，密度为 $f_X(x) = \frac{1}{\sqrt{2\pi}}e^{-\frac{x^2}{2}}$
    
- $Z \sim U[-\pi, \pi]$，密度为 $f_Z(z) = \frac{1}{2\pi}$ （仅当 $z \in [-\pi, \pi]$ 时有效）
    
- 两者独立，所以联合密度就是它俩相乘。
    

我们要找的“老板”是 $u$。

目标：求 $U = X + Z$ 的分布函数 $F_U(u) = P(X + Z \le u)$。

把 $X$ 和 $Z$ 变成扫描面积的“工人” $x$ 和 $z$，工人的工作区域满足：$x + z \le u$，即 **$x \le u - z$**。

---

### 第 2 步：排兵布阵（写出分布函数的双重积分）

我们来安排内外层积分。

因为 $Z$ 的范围被死死限制在 $[-\pi, \pi]$ 之间，把 $z$ 放在**外层**是最聪明的做法，这样外层的上下限就是常数了：

$$F_U(u) = \int_{-\pi}^{\pi} \left( \int_{-\infty}^{u-z} f_X(x) f_Z(z) \,dx \right) dz$$

在这个式子里，$u$ 是老板（参数），$z$ 和 $x$ 都是干活的工人（积分变量）。

---

### 第 3 步：莱布尼茨拔剑（见证奇迹的时刻）

现在，我们对 $F_U(u)$ 关于 $u$ 求导，来获取概率密度 $f_U(u)$。

直接对最外层套用你的**莱布尼茨公式**：

$$f_U(u) = \frac{d}{du} \int_{-\pi}^{\pi} \left( \text{那一坨} \right) dz$$

- **第二项（上限贡献）：** 外层上限是常数 $\pi$，对 $u$ 的导数是 0，所以这一项是 **$0$**。
    
- **第三项（下限贡献）：** 外层下限是常数 $-\pi$，对 $u$ 的导数是 0，所以这一项也是 **$0$**。
    

于是，外层的两扇“栅栏”都没动，**只有第一项“内部呼吸”活了下来**！导数符号 $\frac{d}{du}$ 直接穿透外层积分，钻到了里面：

$$f_U(u) = \int_{-\pi}^{\pi} \left[ \frac{\partial}{\partial u} \int_{-\infty}^{u-z} f_X(x) f_Z(z) \,dx \right] dz$$

现在看中括号里的求导（再次使用微积分基本定理）：对上限 $u-z$ 求导，导数是 $1$。把上限塞进 $x$ 的位置：

$$\frac{\partial}{\partial u} \int_{-\infty}^{u-z} f_X(x) f_Z(z) \,dx = f_X(u-z) f_Z(z) \cdot 1$$

把这个结果放回外层积分：

$$f_U(u) = \int_{-\pi}^{\pi} f_X(u-z) f_Z(z) \,dz$$

**停下来看看这个式子！** 你发现了什么？你根本没有背卷积公式，但你用纯粹的“定义法+莱布尼茨”，**在三行之内，亲手把卷积公式给推导出来了！**

---

### 第 4 步：代入具体函数，召唤 $\Phi(x)$

既然式子已经化简到了最底层，我们把具体的函数扔进去。

因为在外层积分里，$z \in [-\pi, \pi]$，所以 $f_Z(z) = \frac{1}{2\pi}$ 变成了常数，可以直接提出来：

$$f_U(u) = \frac{1}{2\pi} \int_{-\pi}^{\pi} f_X(u-z) \,dz$$

$$f_U(u) = \frac{1}{2\pi} \int_{-\pi}^{\pi} \frac{1}{\sqrt{2\pi}} e^{-\frac{(u-z)^2}{2}} \,dz$$

接下来的操作就和上一问一模一样了：

令 $t = u - z$，那么 $dz = -dt$。

- 下限：$z = -\pi \implies t = u + \pi$
    
- 上限：$z = \pi \implies t = u - \pi$
    

$$f_U(u) = \frac{1}{2\pi} \int_{u+\pi}^{u-\pi} \frac{1}{\sqrt{2\pi}} e^{-\frac{t^2}{2}} (-dt)$$

颠倒上下限吃掉负号：

$$f_U(u) = \frac{1}{2\pi} \int_{u-\pi}^{u+\pi} \frac{1}{\sqrt{2\pi}} e^{-\frac{t^2}{2}} \,dt$$

看！积分号后面就是标准正态分布的密度函数。根据定积分就是面积的差值（分布函数相减），最后一步直接写出：

$$f_U(u) = \frac{1}{2\pi} \left[ \Phi(u+\pi) - \Phi(u-\pi) \right]$$

### 终极总结

你不要卷积公式是完全正确的。

**卷积公式从来都不是天上掉下来的神谕，它只不过是“分布函数法 + 莱布尼茨积分法则”穿上了一件马甲而已。** 只要你把双重积分的边界（特别是外层常数边界）定准了，莱布尼茨公式就会像全自动割草机一样，自动帮你把复杂的导数清理干净，自然而然地露出卷积的本体。


# 6
![[_attachments/image/04 880-1786851561691.jpeg]]

这道题是一道非常经典的综合题，它把**二维正态分布的性质**、**正态变量的线性组合**以及**绝对值的期望**巧妙地结合在了一起。

遇到这种题，不要被复杂的式子吓到，我们一步一步来“剥洋葱”。

### 思考与解题步骤：

#### 第一步：搞清楚 $X-Y$ 是什么分布？
题目已知 $(X,Y) \sim N(0,0; \frac{1}{2}, \frac{1}{2}; 0)$。
这是一个二维正态分布的标准记法 $N(\mu_1, \mu_2; \sigma_1^2, \sigma_2^2; \rho)$。
从中我们可以提取出关键信息：
1.  $X \sim N(0, \frac{1}{2})$
2.  $Y \sim N(0, \frac{1}{2})$
3.  相关系数 $\rho = 0$。对于正态分布来说，**不相关等价于相互独立**。

既然 $X$ 和 $Y$ 独立且都是正态分布，那么它们的线性组合 $Z = X - Y$ **必然也服从正态分布**。
我们来求一下 $Z$ 的期望和方差：
*   **期望：** $E(Z) = E(X - Y) = E(X) - E(Y) = 0 - 0 = 0$
*   **方差：** 因为 $X, Y$ 独立，所以 $D(Z) = D(X - Y) = D(X) + D(Y) = \frac{1}{2} + \frac{1}{2} = 1$

**【核心突破 1】** 原来 $Z = X - Y$ 服从的是**标准正态分布 $N(0,1)$**！
这一下题目就大大简化了。

#### 第二步：计算期望 $E(|X-Y|)$
既然 $X-Y = Z \sim N(0,1)$，那么 $E(|X-Y|)$ 就是求标准正态变量绝对值的期望，即 **$E(|Z|)$**。

这是一个非常经典的计算，建议作为结论记住，但我们这里推导一下：
标准正态分布的概率密度为 $\varphi(z) = \frac{1}{\sqrt{2\pi}} e^{-\frac{z^2}{2}}$。
$$E(|Z|) = \int_{-\infty}^{+\infty} |z| \frac{1}{\sqrt{2\pi}} e^{-\frac{z^2}{2}} dz$$
因为被积函数 $|z| e^{-\frac{z^2}{2}}$ 是一个**偶函数**，所以可以化为 $0$ 到 $+\infty$ 积分的 2 倍：
$$E(|Z|) = 2 \int_{0}^{+\infty} z \frac{1}{\sqrt{2\pi}} e^{-\frac{z^2}{2}} dz = \frac{2}{\sqrt{2\pi}} \int_{0}^{+\infty} z e^{-\frac{z^2}{2}} dz$$
凑微分，令 $u = -\frac{z^2}{2}$，则 $du = -z dz$：
$$E(|Z|) = \sqrt{\frac{2}{\pi}} \int_{0}^{+\infty} e^{-\frac{z^2}{2}} d(\frac{z^2}{2}) = \sqrt{\frac{2}{\pi}} \left[ -e^{-\frac{z^2}{2}} \right]_0^{+\infty}$$
$$E(|Z|) = \sqrt{\frac{2}{\pi}} (0 - (-1)) = \sqrt{\frac{2}{\pi}}$$

**【核心突破 2】** 我们算出了 $E(|X-Y|) = \sqrt{\frac{2}{\pi}}$。
*(注：这个结论 $E(|Z|) = \sqrt{2/\pi}$ 在考研中经常用到，可以直接背下来)*

#### 第三步：代入原式，得出结果
现在把我们得到的所有信息代回题目要求计算的概率中：
要求 $P\{X - Y > E(|X - Y|)\}$
令 $Z = X - Y$，代入刚才算出的期望值：
$$= P\left\{Z > \sqrt{\frac{2}{\pi}}\right\}$$

因为 $Z \sim N(0,1)$，而 $\Phi(x)$ 是标准正态分布的分布函数（即 $P(Z \le x)$）。
利用对立事件：
$$P\left\{Z > \sqrt{\frac{2}{\pi}}\right\} = 1 - P\left\{Z \le \sqrt{\frac{2}{\pi}}\right\} = 1 - \Phi\left(\sqrt{\frac{2}{\pi}}\right)$$

### 结论
对比选项，正确答案是 **C**。

**总结这道题的思考路径：**
看到二维正态 $\rightarrow$ 提取独立性 $\rightarrow$ 发现 $X-Y$ 是标准正态分布 $\rightarrow$ 计算标准正态绝对值的期望（套公式或积分） $\rightarrow$ 转化为标准正态分布函数 $\Phi$ 的表达。


# 7
![[_attachments/image/04 880-1786885964699.jpeg]] 这是一道极其经典的概率论基础题，也是很多考研和期末考试的必考题型。

遇到这种“文字描述”的概率题，核心思考步骤可以总结为**“五步法”**。我带你一步一步拆解：

### 思考步骤与实战演练

#### 第一步：数学建模（把文字翻译成数学符号）
*   **“在区间 $[0,1]$ 上随机地掷两点”**：
    *   设这两个点的坐标分别为 $X$ 和 $Y$。
    *   “随机”意味着它们服从均匀分布，即 $X \sim U(0,1)$， $Y \sim U(0,1)$。
    *   “掷两点”隐含着这两个动作互不影响，即 $X$ 和 $Y$ **相互独立**。
    *   因此，它们的联合概率密度为：$f(x,y) = 1 \times 1 = 1$，区域为 $0 \le x \le 1, 0 \le y \le 1$（即一个面积为1的正方形）。

#### 第二步：明确目标变量及其取值范围
*   **“求这两点间距离的概率密度”**：
    *   设距离为 $Z$，那么数学表达式就是 **$Z = |X - Y|$**。
    *   因为 $X$ 和 $Y$ 都在 $[0,1]$ 之间，所以它们的最大距离是 1（一个在0，一个在1），最小距离是 0（两点重合）。
    *   所以，目标变量 $Z$ 的取值范围是 **$0 \le z \le 1$**。

#### 第三步：选择解题武器（分布函数法 + 几何概率）
*   求连续型随机变量函数的密度，最稳妥的方法永远是**先求分布函数 $F_Z(z)$，再求导**。
*   $F_Z(z) = P(Z \le z) = P(|X - Y| \le z)$。
*   **【高能技巧】**：因为 $(X,Y)$ 是均匀分布，联合密度 $f(x,y) = 1$。所以在二维平面上求概率，**本质上就是求面积！** （概率 = 目标区域面积 / 总面积，这里总面积是1）。

#### 第四步：画图并计算面积（核心操作）
我们要找的区域是 $|X - Y| \le z$，去掉绝对值就是：
$$-z \le X - Y \le z \implies X - z \le Y \le X + z$$

1.  画一个坐标系，画出 $X \in [0,1], Y \in [0,1]$ 的单位正方形。
2.  在正方形里画出两条直线：$Y = X + z$ 和 $Y = X - z$ （注意 $z$ 是一个 $0$ 到 $1$ 之间的常数）。
3.  我们要的概率 $P(|X - Y| \le z)$，就是这两条平行线**之间**夹着的那部分正方形的面积。

**【逆向思维计算面积】**：
直接算中间那个六边形（或平行四边形）的面积有点麻烦。我们用**“总面积 - 空白面积”**来算。
你会发现，这两条线在正方形的左上角和右下角，切出了两个一模一样的**等腰直角三角形**：
*   左上角的三角形：直角边长为 $1-z$。面积 = $\frac{1}{2}(1-z)^2$
*   右下角的三角形：直角边长为 $1-z$。面积 = $\frac{1}{2}(1-z)^2$

所以，中间目标区域的面积 = 总面积 - 两个三角形面积
$$F_Z(z) = 1 - \left[ \frac{1}{2}(1-z)^2 + \frac{1}{2}(1-z)^2 \right] = 1 - (1-z)^2$$
展开化简一下：
$$F_Z(z) = 1 - (1 - 2z + z^2) = 2z - z^2 \quad (0 \le z \le 1)$$

#### 第五步：求导得出概率密度
分布函数求出来了，最后一步就是对 $z$ 求导：
$$f_Z(z) = F_Z'(z) = (2z - z^2)' = 2 - 2z = 2(1-z)$$

最后，规范地写出分段函数的形式：
$$
f_Z(z) = \begin{cases} 
2(1-z), & 0 \le z \le 1 \\ 
0, & \text{其他} 
\end{cases}
$$

---

### 总结你的思考模板：
以后遇到这种题，脑子里直接过这几条：
1.  **设变量**：$X, Y$ 是什么分布？（通常是均匀分布）
2.  **写公式**：目标 $Z$ 是什么？（$X+Y$, $X-Y$, $|X-Y|$, $\max$, $\min$ 等）
3.  **转面积**：写出 $P(Z \le z)$ 的不等式，在二维坐标系里画出 $X$ 和 $Y$ 的范围。
4.  **切图形**：画出不等式对应的直线，利用几何图形（三角形、矩形）算面积，得出分布函数 $F(z)$。
5.  **求导数**：对 $F(z)$ 求导收尾。


# 8
![[_attachments/image/04 880-1786887205533.jpeg]] 你画出矩形，并且知道对角线 $y=x$ 把区域分成了“$Y$ 大”和“$X$ 大”两部分，这个**几何直觉非常棒！**

但是，在处理 $\max$ 和 $\min$ 的分布函数时，如果你顺着“分类讨论谁更大”的思路去拆解式子，就会陷入极其繁琐的计算中（虽然能算对，但很容易晕）。

这里有一个**“降维打击”级别的逻辑转换**，只要你想通了这句话，以后所有 $\max$ 和 $\min$ 的题都是秒杀：


*   **关于 MAX：** 假设一个班里**最高**的人身高都不超过 1.8 米，这意味着什么？
    意味着：**这个班里的“每一个人”身高都不超过 1.8 米！**
    翻译成数学语言：
    $$ \max\{X, Y\} \le z \iff X \le z \text{ 并且 } Y \le z $$

*   **关于 MIN：** 假设一个班里**最矮**的人身高都大于 1.5 米，这意味着什么？
    意味着：**这个班里的“每一个人”身高都大于 1.5 米！**
    翻译成数学语言：
    $$ \min\{X, Y\} > z \iff X > z \text{ 并且 } Y > z $$

你看！通过这个逻辑转换，我们**完全不需要去管到底是 $X$ 大还是 $Y$ 大**，直接把 $\max$ 和 $\min$ 拆解成了 $X$ 和 $Y$ 各自的独立事件！

---

带着这个核心逻辑，我们来秒杀这道题：

### 准备工作
已知 $X, Y \sim U(a,b)$ 且相互独立。
它们的概率密度都是：$f(x) = \frac{1}{b-a} \quad (a \le x \le b)$
它们的分布函数都是：$F(x) = \int_{a}^{x} \frac{1}{b-a} dt = \frac{x-a}{b-a} \quad (a \le x \le b)$

---

### (I) 求 $Z_1 = \max\{X,Y\}$ 和 $Z_2 = \min\{X,Y\}$ 的概率密度

#### 1. 求 $Z_1 = \max\{X,Y\}$
利用刚才的逻辑，写出分布函数：
$$F_{Z_1}(z) = P(\max\{X,Y\} \le z)$$
$$= P(X \le z \text{ 且 } Y \le z)$$
因为 $X, Y$ 相互独立，所以“且”可以直接拆成乘法：
$$= P(X \le z) \cdot P(Y \le z)$$
$$= F_X(z) \cdot F_Y(z)$$
代入均匀分布的分布函数：
$$F_{Z_1}(z) = \left( \frac{z-a}{b-a} \right)^2 \quad (a \le z \le b)$$

求导得到概率密度：
$$f_{Z_1}(z) = F_{Z_1}'(z) = 2 \left( \frac{z-a}{b-a} \right) \cdot \frac{1}{b-a} = \mathbf{\frac{2(z-a)}{(b-a)^2}} \quad (a \le z \le b)$$

#### 2. 求 $Z_2 = \min\{X,Y\}$
对于 $\min$，我们求它的**对立事件**（大于号）：
$$P(\min\{X,Y\} > z) = P(X > z \text{ 且 } Y > z)$$
因为独立，拆成乘法：
$$= P(X > z) \cdot P(Y > z)$$
$$= [1 - F_X(z)] \cdot [1 - F_Y(z)]$$
代入均匀分布的分布函数：
$$= \left( 1 - \frac{z-a}{b-a} \right)^2 = \left( \frac{b-z}{b-a} \right)^2$$

所以，$\min$ 的分布函数为：
$$F_{Z_2}(z) = 1 - P(\min\{X,Y\} > z) = 1 - \left( \frac{b-z}{b-a} \right)^2 \quad (a \le z \le b)$$

求导得到概率密度：
$$f_{Z_2}(z) = F_{Z_2}'(z) = -2 \left( \frac{b-z}{b-a} \right) \cdot \left( -\frac{1}{b-a} \right) = \mathbf{\frac{2(b-z)}{(b-a)^2}} \quad (a \le z \le b)$$

*(注：以上两个密度函数在区间外均为0，书写最终答案时记得加上大括号分段)*

---

### (II) 求 $(Z_1, Z_2)$ 的联合概率密度

这一问求的是最大值和最小值的**联合分布**。这里有一个非常直观的推导方法（也是次序统计量的核心公式）。

设 $Z_1 = \max$, $Z_2 = \min$。
我们要找它们同时落在某个极小区域的概率，即 $Z_1 \approx z_1$ 且 $Z_2 \approx z_2$。
既然一个是最大值，一个是最小值，那么原来的 $(X,Y)$ 只有**两种可能**的情况：
1.  $X$ 是大的那个（$X \approx z_1$），$Y$ 是小的那个（$Y \approx z_2$）。
2.  $Y$ 是大的那个（$Y \approx z_1$），$X$ 是小的那个（$X \approx z_2$）。

因为 $X, Y$ 独立同分布，这两种情况发生的概率是完全一样的，都是 $f(z_1) \cdot f(z_2)$。
所以，总的联合概率密度就是把这两种情况加起来（即乘以 2）：
$$f_{Z_1, Z_2}(z_1, z_2) = 2 \cdot f_X(z_1) \cdot f_Y(z_2)$$

代入均匀分布的密度 $f(x) = \frac{1}{b-a}$：
$$f_{Z_1, Z_2}(z_1, z_2) = 2 \cdot \frac{1}{b-a} \cdot \frac{1}{b-a} = \mathbf{\frac{2}{(b-a)^2}}$$

**【极其容易丢分的陷阱：定义域！】**
联合密度算出来是个常数，但这还没完！你必须写出 $z_1$ 和 $z_2$ 的取值范围。
*   首先，它们都在 $[a,b]$ 之间。
*   其次，**$Z_1$ 是最大值，$Z_2$ 是最小值，所以必须永远满足 $Z_2 \le Z_1$！**

所以，完整的联合概率密度答案是：
$$
f(z_1, z_2) = \begin{cases} 
\frac{2}{(b-a)^2}, & a \le z_2 \le z_1 \le b \\ 
0, & \text{其他} 
\end{cases}
$$

以后遇到 $\max < z$，**千万不要**去想“当 $X>Y$ 时怎样，当 $Y>X$ 时怎样”。
直接条件反射写出：**$\max < z \implies X < z$ 且 $Y < z$**。
直接条件反射写出：**$\min > z \implies X > z$ 且 $Y > z$**。


既然你好奇，我们就偏不走捷径，硬碰硬地用**“分类讨论（全概率公式）+ 二重积分”**来算一次 $\max\{X,Y\}$。

### “硬核”推导过程

已知 $X, Y \sim U(a,b)$，联合密度 $f(x,y) = \frac{1}{(b-a)^2}$。
目标：求 $F(z) = P(\max\{X,Y\} \le z)$。

**第一步：强行分类讨论**
我们根据对角线 $y=x$，把情况强行劈成两半：
$$P(\max\{X,Y\} \le z) = P(\max\{X,Y\} \le z, \ X \ge Y) + P(\max\{X,Y\} \le z, \ X < Y)$$

**第二步：化简条件**
*   在第一部分中，既然 $X \ge Y$，那么 $\max\{X,Y\}$ 就是 $X$。所以条件变成了：$P(X \le z, \ X \ge Y)$。
*   在第二部分中，既然 $X < Y$，那么 $\max\{X,Y\}$ 就是 $Y$。所以条件变成了：$P(Y \le z, \ X < Y)$。

所以，原式变成了两个区域的概率之和：
$$F(z) = \underbrace{P(X \le z, \ Y \le X)}_{\text{区域 1}} + \underbrace{P(Y \le z, \ X < Y)}_{\text{区域 2}}$$

**第三步：画图与积分（高潮来了）**
我们在坐标系里画一个从 $a$ 到 $b$ 的大正方形。
现在我们要算“区域 1”和“区域 2”的积分。

**计算区域 1：$P(X \le z, \ Y \le X)$**
*   $X$ 的范围是从 $a$ 到 $z$。
*   $Y$ 的范围是被 $X$ 压在下面的，即从 $a$ 到 $x$。
写成二重积分：
$$ \iint_{\text{区域1}} f(x,y) dy dx = \int_{a}^{z} dx \int_{a}^{x} \frac{1}{(b-a)^2} dy $$
先算内层：$\int_{a}^{x} dy = x - a$
再算外层：
$$ \frac{1}{(b-a)^2} \int_{a}^{z} (x - a) dx = \frac{1}{(b-a)^2} \left[ \frac{1}{2}(x-a)^2 \right]_{a}^{z} = \mathbf{\frac{(z-a)^2}{2(b-a)^2}} $$

**计算区域 2：$P(Y \le z, \ X < Y)$**
*   $Y$ 的范围是从 $a$ 到 $z$。
*   $X$ 的范围是被 $Y$ 压在左边的，即从 $a$ 到 $y$。
写成二重积分：
$$ \iint_{\text{区域2}} f(x,y) dx dy = \int_{a}^{z} dy \int_{a}^{y} \frac{1}{(b-a)^2} dx $$
先算内层：$\int_{a}^{y} dx = y - a$
再算外层：
$$ \frac{1}{(b-a)^2} \int_{a}^{z} (y - a) dy = \frac{1}{(b-a)^2} \left[ \frac{1}{2}(y-a)^2 \right]_{a}^{z} = \mathbf{\frac{(z-a)^2}{2(b-a)^2}} $$

**第四步：合并结果**
把区域 1 和区域 2 的结果加起来：
$$F(z) = \frac{(z-a)^2}{2(b-a)^2} + \frac{(z-a)^2}{2(b-a)^2} = \mathbf{\frac{(z-a)^2}{(b-a)^2}}$$

这不就是 $\left( \frac{z-a}{b-a} \right)^2$ 吗！
**和我们之前用“捷径”算出来的结果一模一样！**

### 几何视角的终极顿悟

如果你把刚才算的东西画在图上，你会发现一个极其美妙的几何现象：

1.  整个样本空间是一个边长为 $(b-a)$ 的**大正方形**。
2.  我们要求的 $P(\max \le z)$，其实就是求左下角那个边长为 $(z-a)$ 的**小正方形**的面积占比。
3.  **“捷径法”**的逻辑是：直接算小正方形的面积。边长 $\times$ 边长，即 $(z-a) \times (z-a)$。
4.  **“分类讨论法”**的逻辑是：对角线 $y=x$ 把这个小正方形切成了**两个一模一样的等腰直角三角形**。你刚才辛辛苦苦算的两个二重积分，其实就是分别算出了下半个三角形的面积（$\frac{1}{2}(z-a)^2$）和上半个三角形的面积（$\frac{1}{2}(z-a)^2$），然后把它们拼起来！

**总结：**
偏要拆开算，完全可以！它在数学上极其严谨。
只不过，捷径法是直接算“正方形”，而拆开算是把正方形切成“两个三角形”分别算再相加。通过这次“硬算”，你不仅验证了捷径的正确性，还彻底打通了代数公式与几何图形之间的任督二脉！


你发来的这张图片，展示的是教科书上**最严谨、最标准，但也最绕人**的“分布函数法”推导过程。

简单来说，答案在做一件事：**它没有像我上一问那样直接去猜/推导“联合概率密度”，而是老老实实地先求“联合分布函数 $F(z_1, z_2)$”，然后再对它求二阶混合偏导数，最后得出联合密度。**

答案里那一堆看起来像外星文的集合符号（$\cap, \Omega, -$），其实只是在玩一个**“正难则反”的概率减法游戏**。

我来帮你把这段“天书”翻译成大白话，你会发现它的逻辑其实非常巧妙：

### 答案的逻辑拆解

**目标：** 求 $F(z_1, z_2) = P(\max \le z_1 \text{ 且 } \min \le z_2)$

**遇到的困难：**
我们在上一问总结过神技：
*   $\max \le z_1$ 很好拆，就是 $X \le z_1$ 且 $Y \le z_1$。
*   $\min > z_2$ 很好拆，就是 $X > z_2$ 且 $Y > z_2$。
*   **但是！** 这里的条件是 $\min \le z_2$。这个东西很难拆（它意味着 $X \le z_2$ 或者 $Y \le z_2$，带有“或者”的概率算起来极其麻烦）。

**答案的破局招式：用减法（对立事件）！**
既然 $\min \le z_2$ 难算，那我就算它的反面 $\min > z_2$。
根据概率论的基本公式：$P(A \text{ 且 } B) = P(A) - P(A \text{ 且 } \bar{B})$
（大白话：满足 A 且满足 B 的概率 = 满足 A 的总概率 - 满足 A 但**不满足**B 的概率）

把这个公式套进去：
$$P(\max \le z_1 \text{ 且 } \min \le z_2) = P(\max \le z_1) - P(\max \le z_1 \text{ 且 } \min > z_2)$$

你看！答案图片里的第三行到第五行，那一堆 $\Omega$ 和减号，就是在做这一步！

---

### 顺藤摸瓜，算出结果

现在式子变成了两部分相减，这两部分我们都会算了！

**第一部分：** $P(\max \le z_1)$
这不就是第一问求出来的 $Z_1$ 的分布函数 $F_{Z_1}(z_1)$ 吗！直接抄过来。

**第二部分：** $P(\max \le z_1 \text{ 且 } \min > z_2)$
用我们上一问的“生活常识法”拆解：
*   $\max \le z_1 \implies X \le z_1$ 且 $Y \le z_1$
*   $\min > z_2 \implies X > z_2$ 且 $Y > z_2$
把它们合并起来，就变成了：
**$X$ 必须在 $z_2$ 和 $z_1$ 之间，且 $Y$ 也必须在 $z_2$ 和 $z_1$ 之间！**
即：$P(z_2 < X \le z_1 \text{ 且 } z_2 < Y \le z_1)$

因为 $X$ 和 $Y$ 独立，直接拆成乘法：
$$= P(z_2 < X \le z_1) \times P(z_2 < Y \le z_1)$$
因为是均匀分布，落在某个区间的概率就是 $\frac{\text{区间长度}}{\text{总长度}}$：
$$= \left( \frac{z_1 - z_2}{b - a} \right) \times \left( \frac{z_1 - z_2}{b - a} \right) = \left( \frac{z_1 - z_2}{b - a} \right)^2$$

**拼装起来：**
联合分布函数 $F(z_1, z_2) = F_{Z_1}(z_1) - \left( \frac{z_1 - z_2}{b - a} \right)^2$
（这就是图片里那个大括号分段函数中，最核心的那一行的由来）。

---

### 最后一步：求导见证奇迹

答案的最后一行，是对求出来的联合分布函数求二阶混合偏导数：
$$f(z_1, z_2) = \frac{\partial^2 F(z_1, z_2)}{\partial z_1 \partial z_2}$$

我们来口算一下对后面那个平方项求导（前面的 $F_{Z_1}(z_1)$ 里面没有 $z_2$，求偏导直接变 0 了）：
1.  先对 $z_2$ 求偏导：$-2 \left( \frac{z_1 - z_2}{b - a} \right) \cdot \left( -\frac{1}{b-a} \right) = \frac{2(z_1 - z_2)}{(b-a)^2}$
2.  再对 $z_1$ 求偏导：对上面那个式子里的 $z_1$ 求导，结果就是 **$\frac{2}{(b-a)^2}$**。

**你看！绕了这么大一圈，算出来的联合概率密度，和我们上一问用“抽卡片”逻辑直接得出的 $2 \cdot f(z_1)f(z_2)$ 是一模一样的！**

### 总结
*   **我的方法（上一问）：** 是从“概率密度”的物理意义出发，利用对称性直接拼出结果。适合快速解题和理解本质。
*   **答案的方法（这张图）：** 是从“分布函数”的严格定义出发，利用集合运算和对立事件一步步推导。这是教科书必须展示的严谨数学证明。

考试的时候，如果题目只要求“联合概率密度”，直接用我的公式法秒杀；如果题目像这张图一样，非要你先求“联合分布函数”，那你就要学会它这招**“减去对立事件”**的拆解大法了。

### 第一步：把复杂事件翻译成基础事件的交并集
根据 $\max$ 和 $\min$ 的性质：
*   事件 $A = \{\max(X,Y) \le 2\}$ 等价于 **$\{X \le 2 \text{ 且 } Y \le 2\}$**。（要最大值都小于 2，必须两个人都小于 2）
*   事件 $B = \{\min(X,Y) \le -1\}$ 等价于 **$\{X \le -1 \text{ 或 } Y \le -1\}$**。（只要最小值小于-1，说明至少有一个人小于-1）

### 第二步：利用分配律求交集 $AB$
我们要算 $P(AB)$，先把事件 $AB$ 拆开。
$AB = A \cap B = \{X \le 2, Y \le 2\} \cap \big( \{X \le -1\} \cup \{Y \le -1\} \big)$

根据集合的分配律 $A(B_1 \cup B_2) = AB_1 \cup AB_2$：
$AB = \underbrace{\{X \le 2, Y \le 2, X \le -1\}}_{\text{事件 } E} \cup \underbrace{\{X \le 2, Y \le 2, Y \le -1\}}_{\text{事件 } F}$

**化简事件 $E$ 和 $F$（关键逻辑）：**
对于事件 $E$：既然 $X \le -1$，那么它必然满足 $X \le 2$。所以 $\{X \le 2, X \le -1\}$ 直接化简为 $\{X \le -1\}$。
同理化简事件 $F$。
得到：$AB = \underbrace{\{X \le -1, Y \le 2\}}_{\text{化简后的 } E} \cup \underbrace{\{X \le 2, Y \le -1\}}_{\text{化简后的 } F}$

### 第三步：套用概率加法公式计算
根据加法公式：$P(E \cup F) = P(E) + P(F) - P(EF)$

**1. 算 $P(E)$ 和 $P(F)$：**
因为 $X, Y$ 独立，且从原图已知 $P(X \le -1) = 1/3, P(X \le 2) = 1/2$。
$P(E) = P(X \le -1) \cdot P(Y \le 2) = \frac{1}{3} \times \frac{1}{2} = \frac{1}{6}$
$P(F) = P(X \le 2) \cdot P(Y \le -1) = \frac{1}{2} \times \frac{1}{3} = \frac{1}{6}$

**2. 算交集 $P(EF)$：**
$EF$ 就是要求 $E$ 和 $F$ 同时发生，即：$\{X \le -1, Y \le 2\} \cap \{X \le 2, Y \le -1\}$。
把关于 $X$ 和 $Y$ 的条件分别合并：
*   对于 $X$：既要 $\le -1$ 又要 $\le 2$，结果是 $X \le -1$。
*   对于 $Y$：既要 $\le 2$ 又要 $\le -1$，结果是 $Y \le -1$。
所以 $EF = \{X \le -1, Y \le -1\}$。
由于独立性：$P(EF) = P(X \le -1) \cdot P(Y \le -1) = \frac{1}{3} \times \frac{1}{3} = \frac{1}{9}$

**3. 得出最终结果：**
$P(AB) = P(E) + P(F) - P(EF) = \frac{1}{6} + \frac{1}{6} - \frac{1}{9} = \frac{1}{3} - \frac{1}{9} = \mathbf{\frac{2}{9}}$
（和原书正文结果完全一致！）

### 🚀 考研数一应试方法总结

遇到这种 $\max$ 和 $\min$ 的概率计算题，牢记以下破题套路，不要死记硬背分布函数公式：

1.  **“翻译”是第一要务：**
    *   看到 $\max \le c$，立刻翻译成交集：$\{X \le c\} \cap \{Y \le c\}$。
    *   看到 $\min > c$，立刻翻译成交集：$\{X > c\} \cap \{Y > c\}$。
    *   看到 $\min \le c$，立刻翻译成并集：$\{X \le c\} \cup \{Y \le c\}$。
2.  **处理“并集”的两条路：**
    翻译完如果遇到像本题 $B$ 这样的并集，你有两把武器：
    *   **武器一（正文法）：用对立事件转交集。** $P(B) = 1 - P(\bar{B}) = 1 - P(\min > -1) = 1 - P(X > -1, Y > -1)$。正文的 $P(A) - P(A\bar{B})$ 就是这个思路的延伸，极其巧妙，计算量偏小。
    *   **武器二（【注】的方法）：正面用加法公式展开。** $P(E \cup F) = P(E) + P(F) - P(EF)$。这个方法思维负担最小，按部就班绝对不会错，代价是需要算三项。考场上如果一时想不到巧妙的对立事件，直接用这个方法无脑算即可。

*   **纵轴**是 $y$（即累积概率，取值范围在 0 到 1 之间）。
*   **曲线**是 $y = F(x)$。因为是累积概率，这条曲线是从左下角 (高度 0) 爬升到右上角 (高度 1) 的。

现在，我们要理解 $P\{F(X) \le u\} = u$ 这个神奇的结论。

1.  **在纵轴上找目标：** 题目定义了 $U = F(X)$，我们要算 $P(U \le u)$。在纵轴上找到刻度 $u$。目标是求落在纵轴区间 $[0, u]$ 内的概率。
2.  **通过曲线映射回横轴：** 纵轴上的 $[0, u]$ 区间，是由横轴上的哪一段决定的？顺着刻度 $u$ 向右画一条水平线，撞到 $F(x)$ 曲线，再向下垂直画线，打在横轴上的那个点，就是 **$F^{-1}(u)$**。
3.  **等价转换：** 从图上可以清晰看到，纵轴上落在 $[0, u]$ 以下，**完全等价于**横轴上落在 $F^{-1}(u)$ 的左边。
    所以，事件 $\{F(X) \le u\}$ 就几何等价于事件 $\{X \le F^{-1}(u)\}$。
4.  **闭环：** 回到横轴后，事件 $\{X \le F^{-1}(u)\}$ 的概率是多少？根据分布函数的定义，横轴上某个点以左的概率，就是**曲线在这个点的高度**。
    这个点是 $F^{-1}(u)$，曲线在这个点的高度恰好就是一开始水平线对应的那个高度 **$u$**。

所以转了一圈，$P(U \le u) = u$。几何上看，**分布函数 $F(x)$ 就是一个完美的“压平机”**，它把横轴上原本疏密不均的数据，通过曲线的高低起伏，完美均匀地映射到了纵轴的 $[0,1]$ 区间上。

### 2. 为什么“严格单调递增”就保证了反函数存在？

反函数的本质，是**“一一对应”**。
已知 $y$，必须能反向找到**唯一**的一个 $x$。

*   **如果只是“不减”（非严格单调）：** 意味着曲线在爬升过程中，允许有一段是**水平的平地**。
    想象一下，如果在高度 $y = 0.5$ 处有一段平地（对应横轴从 $x_1$ 到 $x_2$）。这时候你如果问：“高度 $0.5$ 对应的 $x$ 是谁？” 答案是无数个（区间 $[x_1, x_2]$ 内的所有点）。这就**无法唯一确定 $x$**，反函数在数学上就不存在了。
*   **如果是“严格单调递增”：** 意味着曲线永远在向上爬，**绝对没有任何水平的平地**。
    这时候，在纵轴的 $(0, 1)$ 之间随便画一条水平线，它和曲线**必定只相交于唯一点**。已知高度 $y$，必然能顺藤摸瓜找到唯一对应的横坐标 $x$。这个反向寻找的过程，就是反函数 $x = F^{-1}(y)$。

### 💡 助教总结：回到应试

在考场上，你只需要建立这样一个逻辑链（不需要画图，但在心里要有底）：

1.  题目给的概率密度 $f(x)$，如果是分段函数，在有概率的区间里（比如这题的 $0 < x < 2$），**$f(x)$ 都是大于 0 的**。
2.  因为 $F'(x) = f(x) > 0$，导数大于 0，说明原函数 $F(x)$ **没有平地**，是**严格单调递增**的。
3.  没有平地 $\Rightarrow$ 一一对应 $\Rightarrow$ **反函数 $F^{-1}$ 必然存在且唯一**。
4.  所以你可以放心大胆地写下 $P\{X \le F^{-1}(u)\} = F(F^{-1}(u)) = u$ 这个满分式子，不用担心逻辑断裂。



**你的思路非常棒，拒绝生搬硬套公式，回归几何二重积分，绝对是考场上最稳健的做法！**

你卡住的地方在于：“要算 $F(X)$ 和 $Y$ 的联合概率密度？”
**答案是：对，而且非常简单！** 

千万别被 $F(X)$ 这个符号吓到，你在第一问已经算出来了：**$F(X)$ 就是一个新的随机变量 $U$，且 $U \sim (0, 1)$ 上的均匀分布！**

既然 $X, Y$ 独立，那么 $U, Y$ 必然也独立。
所以，它们的联合密度就是各自密度的直接相乘：
$$f(u, y) = f_U(u) \cdot f_Y(y) = 1 \cdot 2e^{-2y} = 2e^{-2y}$$
（有效区域是：$0 < u < 1$ 且 $y > 0$）

现在，题目变成了求 $Z = U + Y$ 的密度函数，这就可以完美对接你的“几何二重积分”大法了。

### 空间上的几何推理（二重积分实操）

在脑海里建一个 $u-y$ 二维坐标系：
*   **有效面积（带概率的区域）：** $u$ 只能在 $(0, 1)$ 之间，$y > 0$。这是一条**宽度为 1、无限向上的半无限长条**。在这条长条里，密度是 $2e^{-2y}$。
*   **目标区域：** 我们要算分布函数 $F_Z(z) = P(U + Y \le z)$。也就是在坐标系里画一条直线 $u + y = z$（即 $y = z - u$），求这条直线**左下方**与“半无限长条”重合的区域的二重积分。

由于直线的截距是 $z$，随着 $z$ 变大，直线会往右上角平移。因此积分区域必然要**分段**：

**1. 当 $z \le 0$ 时：** 直线完全在第一象限外面，和长条没有交集。
$F_Z(z) = 0$。

**2. 当 $0 < z \le 1$ 时（直线切过长条的左下角）：**
重合区域是一个**三角形**。$u$ 的范围是 $0$ 到 $z$，对给定的 $u$，$y$ 的范围是 $0$ 到 $z-u$。
$$F_Z(z) = \int_0^z du \int_0^{z-u} 2e^{-2y} \, dy$$
里面积分积出来是 $1 - e^{-2(z-u)}$，再对 $u$ 积分：
$$F_Z(z) = \int_0^z (1 - e^{-2z+2u}) \, du = \left[ u - \frac{1}{2}e^{-2z+2u} \right]_0^z = z - \frac{1}{2} + \frac{1}{2}e^{-2z}$$
求导得到密度函数：**$f_Z(z) = 1 - e^{-2z}$**。

**3. 当 $z > 1$ 时（直线完全跨过了长条的左右边界）：**
重合区域是一个**直角梯形**。$u$ 的范围吃满了整个长条的宽度，即 $0$ 到 $1$，对给定的 $u$，$y$ 的范围依然是 $0$ 到 $z-u$。
$$F_Z(z) = \int_0^1 du \int_0^{z-u} 2e^{-2y} \, dy$$
同理，对里面积分得到 $1 - e^{-2(z-u)}$，再对 $u$ 积分：
$$F_Z(z) = \int_0^1 (1 - e^{-2z+2u}) \, du = \left[ u - \frac{1}{2}e^{-2z+2u} \right]_0^1 = 1 - \frac{1}{2}e^{-2(z-1)} + \frac{1}{2}e^{-2z}$$
求导得到密度函数：**$f_Z(z) = e^{-2(z-1)} - e^{-2z}$**。

2.  **卷积 vs 二重积分：** 
    *   **卷积公式**的本质也是二重积分，只是提前帮你积掉了一层，只留下一层定积分。它的难点在于**定上下限极容易出错**。
    *   **你的几何二重积分法**，虽然要算两次积分，但在考场上**画个图就能一眼看出上下限**，属于“降维打击”，是最不容易算错的兜底神技。以后遇到 $Z = X+Y$, $Z = XY$, $Z = X/Y$ 这种题，只要你觉得积分区域恶心，直接画图二重积分，准没错！
