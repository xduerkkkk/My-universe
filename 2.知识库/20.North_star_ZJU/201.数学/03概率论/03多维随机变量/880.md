### 1. 怎么直观理解“同分布”？

**“同分布”的意思是：这两个随机变量遵循着一模一样的“概率图纸”或“游戏规则”，但它们是完全不同的两个“实体”。**

- **通俗比喻（抛骰子）：**
    
    假设你有两枚完全一样、绝对均匀的六面骰子。
    
    - $X_1$ 代表抛第一枚骰子掷出的点数。
        
    - $X_2$ 代表抛第二枚骰子掷出的点数。
        
        它们掷出 1 到 6 的概率都是 $\frac{1}{6}$，它们的概率分布图画出来一模一样。这就叫 **$X_1$ 与 $X_2$ 同分布**。
        
        **但是！** 它们不一定相等（$X_1$ 可能掷出 3，而 $X_2$ 可能掷出 5），它们各自的命运是独立的。
        
- **本质：** $X_1$ 和 $X_2$ 的概率密度函数（或分布律）完全相同，期望、方差等所有统计特征都一样。
    

---

### 2. “同分布”最大的盲区（这道题的考点）

知道了各自的“图纸”一样，**不代表知道它们是如何“互动”的。**

题目说 $X_1$ 和 $X_2$ 同分布，$Y_1$ 和 $Y_2$ 同分布。

这里最大的陷阱是：**题目根本没说 $X$ 和 $Y$ 之间是什么关系（是否独立）！**

- 也许 $X_1$ 和 $Y_1$ 是形影不离的好兄弟（高度正相关）。
    
- 也许 $X_2$ 和 $Y_2$ 是死对头（高度负相关）。
    
    哪怕它们各自的分布一样，一旦组合起来（相加、相减、组队），结果就会大相径庭。
    

---

### 3. 我们来秒杀这道题（选 D）

带着上面的思维，我们来看选项：

- **为什么选 D 正确？**
    
    D 选项是 $kX_1$ 与 $kX_2$ 同分布。这相当于：第一枚骰子的点数乘以 $k$，第二枚骰子的点数也乘以 $k$。因为它们原来的“图纸”是一模一样的，现在又对它们做了**一模一样的单一数学操作**，变形后的“新图纸”自然还是完全一样的。这只涉及它们自己，不涉及和别人的互动。
    
- **为什么 A、B 错？（用反例击破）**
    
    我们不知道 $X$ 和 $Y$ 是怎么搭档的。
    
    举个极端的例子：假设所有人（$X_1, X_2, Y_1, Y_2$）都服从标准的正态分布 $N(0,1)$。
    
    - **情况 1：** 假设 $Y_1$ 就是 $X_1$ 的“克隆人”，即 $Y_1 = X_1$。
        
        那么 $X_1 + Y_1 = X_1 + X_1 = 2X_1$。它的方差会变大，变成 $N(0, 4)$。
        
    - **情况 2：** 假设 $Y_2$ 是 $X_2$ 的“死对头”，即 $Y_2 = -X_2$。
        
        那么 $X_2 + Y_2 = X_2 + (-X_2) = 0$。它直接变成了一个常数 0！
        
        你看，$N(0, 4)$ 和常数 $0$ 的分布能一样吗？绝对不一样！所以 A 错，同理相减的 B 也错。
        
- **为什么 C 错？**
    
    C 选项说的是二维联合分布 $(X_1, Y_1)$ 和 $(X_2, Y_2)$。还是上面那个例子，一个是高度正相关的搭档，一个是完全相反的死对头，它们组成的“团队表现”（联合分布）显然是截然不同的。
    

**总结：**

“同分布”只管单人的身体素质（边缘分布），不管两人配合作战的默契度（联合分布）。只要涉及 $X$ 和 $Y$ 的混合运算（A、B、C），在没交代独立性或相关性的前提下，一律无法确定。只有单独对自己做变形（D），才能保持同分布的性质。

**你的结论完全正确：只有在明确知道 $X$ 和 $Y$ 相互独立的情况下，你才能把交集概率 $P(X \le 3 \text{ 且 } Y \le 3)$ 直接拆成相乘 $P(X \le 3) \times P(Y \le 3)$。** 如果在不独立（或者题目没说独立）的情况下，绝对不能直接乘。

那么，**“否则呢？”** 如果不独立，我们该怎么算？这道题恰好提供了一个完美的教学范例，教你如何用“容斥原理”（即使不独立也能解题的万能钥匙）来对付它。

下面我们来一步步拆解这道题的严谨解法：

### 1. 翻译 $\max$ 和 $\min$ 的数学语言

处理这种题的第一步，永远是把 $\max$ 和 $\min$ 翻译成 $X$ 和 $Y$ 各自的条件。

- **条件 1：** $P\{\max\{X, Y\} \le 3\}$
    
    两个数里的**最大值**都小于等于 3，这意味着这两个数**必须同时**小于等于 3。
    
    翻译：$P\{X \le 3 \cap Y \le 3\} = \frac{9}{16}$。
    
- **目标 2：** $P\{\min\{X, Y\} > 3\}$
    
    两个数里的**最小值**都大于 3，这意味着这两个数**必须同时**大于 3。
    
    翻译：求 $P\{X > 3 \cap Y > 3\} = ?$。
    

### 2. 否则呢？——使用“容斥原理”加“对立事件”

既然我们不知道它们独不独立，我们就**不强行拆解相乘**。我们把 $\{X \le 3\}$ 和 $\{Y \le 3\}$ 看作两个大事件 $A$ 和 $B$。

- 已知事件 $A = \{X \le 3\}$，因为 $X$ 服从 $[0, 4]$ 均匀分布，所以 $P(A) = \frac{3}{4}$。
    
- 已知事件 $B = \{Y \le 3\}$，因为 $Y$ 服从 $[0, 4]$ 均匀分布，所以 $P(B) = \frac{3}{4}$。
    
- 题目给了我们它们的交集概率（共同发生）：$P(A \cap B) = \frac{9}{16}$。
    

我们要计算的目标是 $P\{X > 3 \cap Y > 3\}$，也就是 $A$ 不发生**且** $B$ 也不发生：

$$P(\overline{A} \cap \overline{B})$$

根据德·摩根定律（集合的非）：既不是 $A$ 也不是 $B$，等于“$A$ 或 $B$”的整体的反面。

$$P(\overline{A} \cap \overline{B}) = 1 - P(A \cup B)$$

现在只需要求出并集 $P(A \cup B)$。这就要用到概率论的基石——**容斥原理**（两个圈的面积相加，减去重合的部分）：

$$P(A \cup B) = P(A) + P(B) - P(A \cap B)$$

$$P(A \cup B) = \frac{3}{4} + \frac{3}{4} - \frac{9}{16} = \frac{6}{4} - \frac{9}{16} = \frac{24}{16} - \frac{9}{16} = \frac{15}{16}$$

最后，代入求对立事件：

$$P(\overline{A} \cap \overline{B}) = 1 - \frac{15}{16} = \textbf{\frac{1}{16}}$$

你看，**整个过程我们完全没有用到“独立相乘”的假设**，仅仅依靠基本的集合运算就得出了正确答案。这就是对付“不独立”或“不知是否独立”情况的最稳妥方法。

---

### 3. 本题的隐藏彩蛋（巧合）

回到你最初的直觉，你可以回头验证一下：

既然 $P(X \le 3) = \frac{3}{4}$，$P(Y \le 3) = \frac{3}{4}$。

你会惊奇地发现：$P(X \le 3) \times P(Y \le 3) = \frac{3}{4} \times \frac{3}{4} = \frac{9}{16}$。

这个结果恰好等于题目给定的 $P\{\max\{X,Y\} \le 3\} = \frac{9}{16}$！

这意味着，出题人在这里**暗中设定了 $X$ 和 $Y$ 在这个事件上是相互独立的**。但这属于“马后炮”，在严格做题时，我们不能一开始就假定它成立，而是像上面那样用容斥原理推出来最严谨。

关于把 $\max$ 和 $\min$ 转化为 $X$ 和 $Y$ 共同满足的条件（交集），你觉得直观上好理解吗？还是需要我再举个通俗的生活例子来加深记忆？

你完全点出了微积分和概率论结合时，最让初学者崩溃的一个“陷阱”！

你觉得 $x, y$ “又是定量又是变量”，是因为教材和题目在这里存在一种“符号滥用”。

在求分布函数 $F(x, y)$ 时，$x$ 和 $y$ 是你最终要代入的**目标点（定量，也就是积分上限）**；但是，密度函数 $f(x, y)$ 里的 $x$ 和 $y$ 是坐标轴上的**游标（变量，也就是积分变量）**。如果把它们混在一起写，不晕才怪！

为了彻底治好这个“晕动症”，我们只需要祭出第一法则：**换元法（引入“替身”）。**

---

### 第一步：请出“替身”变量 $u, v$

在写分布函数定义时，**绝对不要**在积分号里面继续用 $x$ 和 $y$。我们把积分变量换成 $u$ 和 $v$：

$$F(x, y) = P(X \le x, Y \le y) = \int_{-\infty}^{x} \left( \int_{-\infty}^{y} f(u, v) \,dv \right) du$$

你看，现在的逻辑非常清晰了：

- **$u, v$ 是变量（工人）**：它们负责在平面上一点点扫描、累加面积。
    
- **$x, y$ 是定量（老板）**：它们站在积分的上限，规定了工人扫描的终点。
    
- 题目给的条件变成了：只有当 **$0 < u < v < +\infty$** 时，密度函数 $f(u, v) = u e^{-v}$，其他地方都是 0。
    

---

### 第二步：画图找交集（分情况讨论）

求 $F(x, y)$，本质上就是在 $u-v$ 坐标系里，求“题目给定的有效区域”**和**“老板划定的矩形区域 $(-\infty, x] \times (-\infty, y]$”的重合部分。

题目给的有效区域是 $0 < u < v$，这在 $u-v$ 平面上是第一象限里，**直线 $v = u$ 上方的那个楔形区域**。

因为老板给的终点 $(x, y)$ 位置不同，重合部分的形状也不同，我们需要分三种情况：

#### 情况 1：终点在无效区（$x \le 0$ 或 $y \le 0$）

老板划定的区域都在第三、第四或第二象限的边缘，根本没碰到第一象限的有效区域。

- **结论：$F(x, y) = 0$**
    

#### 情况 2：终点在有效区内（$0 < x < y$）

这是最标准的情况。点 $(x, y)$ 落在了 $v = u$ 上方的区域里。

现在我们来确定工人的扫描范围（积分上下限）：

- **外层先看横坐标 $u$：** 从最左边的 $0$ 开始，一直扫描到老板规定的右边界 $x$ 结束。所以外层积分是 $\int_{0}^{x} du$。
    
- **内层看纵坐标 $v$：** 对于每一个固定的 $u$（你可以想象一条竖线），$v$ 从哪里开始？它必须在有效区域内，所以是从底部的斜线 $v = u$ 开始，往上扫描到老板规定的天花板 $v = y$ 结束。所以内层积分是 $\int_{u}^{y} dv$。
    

列出积分并计算：

$$F(x, y) = \int_{0}^{x} \left( \int_{u}^{y} u e^{-v} \,dv \right) du$$

先算内层（对 $v$ 积分，$u$ 当常数）：

$$\int_{u}^{y} u e^{-v} \,dv = u \left[ -e^{-v} \right]_{u}^{y} = u(e^{-u} - e^{-y})$$

再算外层（对 $u$ 积分）：

$$\int_{0}^{x} (u e^{-u} - u e^{-y}) \,du = \int_{0}^{x} u e^{-u} \,du - e^{-y} \int_{0}^{x} u \,du$$

前面的积分用分部积分法 $\int u d(-e^{-u})$，后面的直接积：

$$= \left[ -u e^{-u} - e^{-u} \right]_{0}^{x} - e^{-y} \left[ \frac{1}{2}u^2 \right]_{0}^{x}$$

$$= 1 - (x+1)e^{-x} - \frac{1}{2}x^2 e^{-y}$$

#### 情况 3：终点跑到了右下角（$0 < y \le x$）

点 $(x, y)$ 落在了直线 $v = u$ 的下方。

这时候你画个图就会发现，老板给的右边界 $x$ 给得“太宽”了，超出了有效区域的边界。因为在有效区域里 $u < v$，而 $v$ 最大只能到 $y$。所以 $u$ 实际上**最多只能走到 $y$ 就无路可走了**，根本走不到 $x$。

所以，这时的积分区域，实际上是被 $u=0$, $v=y$ 以及 $v=u$ 围成的一个完整的三角形。

- 外层 $u$ 的范围：从 $0$ 到 $y$（被天花板限制死了）。
    
- 内层 $v$ 的范围：还是从 $u$ 到 $y$。
    

积分式子变成了：

$$F(x, y) = \int_{0}^{y} \left( \int_{u}^{y} u e^{-v} \,dv \right) du$$

**仔细看！** 这个式子和【情况 2】的式子一模一样，仅仅是把外层积分的上限 $x$ 换成了 $y$。

所以我们根本不需要重新算，直接把【情况 2】结果里的 $x$ 全换成 $y$ 就行了：

$$F(x, y) = 1 - (y+1)e^{-y} - \frac{1}{2}y^2 e^{-y}$$

化简一下：

$$= 1 - e^{-y} - y e^{-y} - \frac{1}{2}y^2 e^{-y}$$

---

### 最终答题格式

把上面三种情况合起来，用大括号写出一个漂亮的分段函数，这就是完整的分布函数：

$$F(x,y) = \begin{cases} 1 - (x+1)e^{-x} - \frac{1}{2}x^2 e^{-y}, & 0 < x < y \\ 1 - (y+1)e^{-y} - \frac{1}{2}y^2 e^{-y}, & 0 < y \le x \\ 0, & \text{其他 (即 } x \le 0 \text{ 或 } y \le 0) \end{cases}$$

**总结你的疑惑：** 以后只要遇到求分布函数 $F(x, y)$ 或者求边缘分布，第一件事就是把密度函数里的 $x, y$ 强行改成 $u, v$（或者 $s, t$）。把目标点和游标彻底剥离开，你就再也不会晕了！

**是的，完全正确！** 第三问依然可以完美地使用你最喜欢的“分布函数法（定边界） + 莱布尼茨公式（求导）”组合拳来秒杀。

而且这道题比上一题更具代表性，因为题目中有一个非常强的几何约束条件：**$0 < x < y < +\infty$**。如果你去死记硬背书上的卷积公式，很容易在处理这个不等式边界时塞错上下限。而用你的“莱布尼茨第一性原理”，逻辑会无比清晰。

下面我为你完整展示如何用你的方法硬核拆解第三问：

---

### 第 1 步：用几何直觉锁定积分边界（最关键的一步）

我们要找的是 $Z = X+Y \le z$ 的概率。

由于概率密度只在 $0 < x < y$ 的区域（即第一象限中直线 $y=x$ 上方的区域）有效，我们把这两个边界画在脑海里：

1. **有效边界**：$y > x$ 且 $x > 0$
    
2. **目标边界**：$y \le z - x$
    

很显然，只有当 **$z > 0$** 时这两条线才有交点。

两条直线的交点是：$x = z - x \implies \mathbf{x = \frac{z}{2}}$。

我们在 $x-y$ 平面上看一下这个被围成的三角形区域：

- **外层变量 $x$ 的范围**：从最左边的 $0$ 开始，一直走到交点 $\frac{z}{2}$ 为止。所以外层积分是 $\int_{0}^{z/2} dx$。
    
- **内层变量 $y$ 的范围**：对于每一个固定的 $x$，往下看它被斜线 $y=x$ 挡住，往上看它被天花板 $y=z-x$ 挡住。所以内层积分是 $\int_{x}^{z-x} dy$。
    

由此，我们写出 $Z$ 的分布函数 $F_Z(z)$：

$$F_Z(z) = \int_{0}^{z/2} \left( \int_{x}^{z-x} x e^{-y} \,dy \right) dx$$

---

### 第 2 步：把内部积分打包为 $G(z, x)$

为了完美套用你的莱布尼茨公式，我们把括号里面的内层积分打包：

$$G(z, x) = \int_{x}^{z-x} x e^{-y} \,dy$$

现在，外层分布函数变成了标准的形式：

$$F_Z(z) = \int_{0}^{z/2} G(z, x) \,dx$$

---

### 第 3 步：祭出莱布尼茨公式求导

现在我们对 $F_Z(z)$ 关于 $z$ 求导来获取概率密度 $f_Z(z)$。

对比你的公式原型：

- 积分上限 $\beta(z) = \frac{z}{2}$，所以 **$\beta'(z) = \frac{1}{2}$**
    
- 积分下限 $\alpha(z) = 0$ 空间，所以 **$\alpha'(z) = 0$**
    

套入公式的三项：

$$f_Z(z) = \underbrace{\int_{0}^{z/2} \frac{\partial}{\partial z} G(z, x) \,dx}_{\text{第一项：内部变化}} + \underbrace{G\left(z, \frac{z}{2}\right) \cdot \frac{1}{2}}_{\text{第二项：上限贡献}} - \underbrace{G(z, 0) \cdot 0}_{\text{第三项：下限贡献}}$$

我们逐项来看：

- **第三项**：乘以 0，直接化为 **$0$**。
    
- **第二项**：把 $x = \frac{z}{2}$ 代入 $G(z,x)$ 的定义中：
    
    $$G\left(z, \frac{z}{2}\right) = \int_{z/2}^{z - z/2} \dots \,dy = \int_{z/2}^{z/2} \dots \,dy = \mathbf{0}$$
    
    上限和下限完全重合，积分为 0！
    

**所以，又只剩下了纯粹的“第一项”：**

$$f_Z(z) = \int_{0}^{z/2} \frac{\partial}{\partial z} G(z, x) \,dx$$

---

### 第 4 步：计算内部偏导（再次运用微积分基本定理）

我们要算 $\frac{\partial}{\partial z} G(z, x) = \frac{\partial}{\partial z} \left[ \int_{x}^{z-x} x e^{-y} \,dy \right]$：

- 被积函数 $x e^{-y}$ 里面没有 $z$，所以对 $z$ 的偏导为 0。
    
- 积分上限是 $z-x$，它对 $z$ 的导数是 $1$。
    
- 积分下限是 $x$，它对 $z$ 的导数是 $0$。
    

直接把上限 $z-x$ 塞进 $y$ 的位置里，乘以其导数 $1$：

$$\frac{\partial}{\partial z} G(z, x) = \left( x e^{-(z-x)} \right) \cdot 1 = x e^{x-z}$$

---

### 第 5 步：合体完成最后的一元积分

把算出来的偏导数放回外层积分：

$$f_Z(z) = \int_{0}^{z/2} x e^{x-z} \,dx$$

把与 $x$ 无关的 $e^{-z}$ 提到积分外面：

$$f_Z(z) = e^{-z} \int_{0}^{z/2} x e^x \,dx$$

用一次简简单单的分部积分法（或者凑微分 $\int x d(e^x)$）：

$$\int_{0}^{z/2} x e^x \,dx = \left[ x e^x - e^x \right]_0^{z/2} = \left( \frac{z}{2}e^{z/2} - e^{z/2} \right) - (0 - 1) = \left(\frac{z}{2} - 1\right)e^{z/2} + 1$$

最后，把前面的 $e^{-z}$ 乘进去：

$$f_Z(z) = e^{-z} \left[ \left(\frac{z}{2} - 1\right)e^{z/2} + 1 \right] = \mathbf{\left(\frac{z}{2} - 1\right)e^{-z/2} + e^{-z}}$$

写出最终答案（注意加上 $z>0$ 的范围）：

$$f_Z(z) = \begin{cases} \left(\frac{z}{2} - 1\right)e^{-z/2} + e^{-z}, & z > 0 \\ 0, & \text{其他} \end{cases}$$

---

### 深入思考

你发现了吗？使用“换元+莱布尼茨”时：

1. 连续两次求导过程中，边界项全部极其丝滑地**自动化简为了 0**。
    
2. 它省去了你先去把双重积分积出来、再去对一大坨复杂的指数函数求导的痛苦过程，而是**先在导数层面把被积函数化简到最简，最后只做了一次最轻松的一元积分**。
    

不得不说，你挑选的这种解题路线，不仅在数学逻辑上是最优雅的，在实际考场算力分配上也是最省时、最不容易出错的！

这道题简直是为你刚刚学到的“换元避嫌法”**和**“几何直觉”量身定制的完美练手题！

这道题最大的难点不在于求导（这里甚至都不需要用莱布尼茨公式），而在于**如何处理那根“扫过角落的线”**。

我们严格按照刚才建立的“第一性原理”来拆解这道题：

### 第 1 步：请出工人 $u, v$，写出联合密度

已知 $X$ 和 $Y$ 相互独立，且服从同一分布：

$f_X(x) = \frac{2}{x^2} \ (x>2)$， $f_Y(y) = \frac{2}{y^2} \ (y>2)$。

因为独立，把它们乘起来，并且立刻**把变量换成工人 $u$ 和 $v$**，避免和等会儿的老板 $z$ 冲突：

$$f(u,v) = f_X(u)f_Y(v) = \frac{4}{u^2 v^2}, \quad (u > 2, v > 2)$$

_(注意这里的有效区域：它是坐标系右上角，从点 $(2,2)$ 开始的一个无限大的矩形区域。)_

---

### 第 2 步：翻译老板 $z$ 的条件，找积分下限（核心亮点！）

我们要算的是 $Z = \frac{X}{Y} \le z$ 的概率。

因为 $X$ 和 $Y$ 都大于 2（全是正数），所以 $Z$ 必定大于 0。当 $z \le 0$ 时，$F_Z(z) = 0$。

当 $z > 0$ 时，不等式化为：

$$P\left(\frac{U}{V} \le z\right) \implies P(U \le zV)$$

现在，我们要在这个区域里算积分。我们选择把 $v$ 放在外层，把 $u$ 放在内层：

- **内层 $u$ 的范围：** 左边被墙壁 $u=2$ 挡住，右边被老板的线 $u=zV$ 挡住。所以 $u$ 的积分上限是 $zv$，下限是 $2$。
    
    既然上限必须大于等于下限，就必须满足：$zv \ge 2 \implies \mathbf{v \ge \frac{2}{z}}$。
    
- **外层 $v$ 的范围：** $v$ 原本的领地是 $v > 2$。现在又多了一个要求 $v \ge \frac{2}{z}$。
    
    那 $v$ 到底从谁开始积呢？当然是**取它俩中更大的那个**，即 $\max\left(2, \frac{2}{z}\right)$。
    

这就是这道题最精妙的地方！因为 $z$ 的变化，会导致谁更大发生改变，所以我们**必须以 $z=1$ 为界，分两种情况讨论**。

---

### 第 3 步：分情况积分求 $F_Z(z)$

既然内层积分 $\int \frac{1}{u^2} du$ 非常好算，我们就不需要莱布尼茨公式了，直接把 $F_Z(z)$ 算到底。

内层积分（大家都要用）：

$$\int_{2}^{zv} \frac{4}{u^2 v^2} \,du = \frac{4}{v^2} \left[ -\frac{1}{u} \right]_2^{zv} = \frac{4}{v^2} \left( \frac{1}{2} - \frac{1}{zv} \right) = \frac{2}{v^2} - \frac{4}{z v^3}$$

#### 情况 1：当 $0 < z \le 1$ 时

此时 $\frac{2}{z} \ge 2$。所以外层 $v$ 的起点是 $\frac{2}{z}$。

$$F_Z(z) = \int_{2/z}^{+\infty} \left( \frac{2}{v^2} - \frac{4}{z v^3} \right) dv$$

$$= \left[ -\frac{2}{v} + \frac{2}{z v^2} \right]_{2/z}^{+\infty}$$

上限是 $+\infty$，代入全为 $0$。减去代入下限 $\frac{2}{z}$：

$$= 0 - \left( -\frac{2}{2/z} + \frac{2}{z(4/z^2)} \right) = 0 - \left( -z + \frac{z}{2} \right) = \mathbf{\frac{z}{2}}$$

#### 情况 2：当 $z > 1$ 时

此时 $\frac{2}{z} < 2$。但 $v$ 本身必须大于 $2$，所以外层 $v$ 的起点是 $2$。

$$F_Z(z) = \int_{2}^{+\infty} \left( \frac{2}{v^2} - \frac{4}{z v^3} \right) dv$$

$$= \left[ -\frac{2}{v} + \frac{2}{z v^2} \right]_{2}^{+\infty}$$

同样上限代入为 $0$，减去代入下限 $2$：

$$= 0 - \left( -1 + \frac{2}{4z} \right) = \mathbf{1 - \frac{1}{2z}}$$

---

### 第 4 步：大结局（汇总并求导）

我们得到了非常干净的分布函数：

$$F_Z(z) = \begin{cases} 0, & z \le 0 \\ \frac{z}{2}, & 0 < z \le 1 \\ 1 - \frac{1}{2z}, & z > 1 \end{cases}$$

对它求导，直接得到概率密度 $f_Z(z)$：

- $0 < z \le 1$ 时：$(\frac{z}{2})' = \frac{1}{2}$
    
- $z > 1$ 时：$(1 - \frac{1}{2z})' = \frac{1}{2z^2}$
    

最终答案：

$$f_Z(z) = \begin{cases} \frac{1}{2}, & 0 < z \le 1 \\ \frac{1}{2z^2}, & z > 1 \\ 0, & \text{其他} \end{cases}$$

**战术总结：** 当你在做 $Z = X+Y$ 或 $Z = \frac{X}{Y}$ 时，只要内部积分（对 $u$ 的积分）**好算**，就直接硬算到底求出 $F(z)$，再求导；如果内部积分**算不出来**（比如遇到 $e^{-x^2}$ 这种怪物），再果断拔出“莱布尼茨公式”这把剑，在导数层面消灭它。
