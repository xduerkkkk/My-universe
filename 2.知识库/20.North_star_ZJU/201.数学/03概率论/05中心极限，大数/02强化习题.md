老师设 $Z_i$ 是在**将题目向中心极限定理（CLT）的标准模板上靠拢**。

我们分三步理清这个过程：

---

### 第一步：为什么要设 $Z_i = X_{2i} - X_{2i-1}$？

中心极限定理（CLT）研究的是**一堆独立同分布变量相加 $\sum Z_i$**。

看题目给的 $Y_n$：
$$Y_n = c \sum_{i=1}^n \frac{X_{2i} - X_{2i-1}}{\sqrt{n}} = \frac{c}{\sqrt{n}} \sum_{i=1}^n (X_{2i} - X_{2i-1})$$

求和符号 $\sum_{i=1}^n$ 里面那一整坨是 $(X_{2i} - X_{2i-1})$。
* 当 $i=1$ 时，是 $X_2 - X_1$
* 当 $i=2$ 时，是 $X_4 - X_3$
* $\dots$
* 当 $i=n$ 时，是 $X_{2n} - X_{2n-1}$

每一个括号里的下标都没有重复，所以把它们分别打包记为 **$Z_1, Z_2, \dots, Z_n$**，这 $n$ 个新变量是**相互独立且同分布的**！
此时：
$$Y_n = \frac{c}{\sqrt{n}} \sum_{i=1}^n Z_i$$

---

### 第二步：中心极限定理的“标准模板”长什么样？

对于独立同分布的 $Z_1, \dots, Z_n$：
1. **期望**：$E(Z_i) = E(X_{2i}) - E(X_{2i-1}) = 1 - 1 = 0$
2. **方差**（独立变量相减，方差相加）：$D(Z_i) = D(X_{2i}) + D(X_{2i-1}) = 1 + 1 = 2$

根据**独立同分布中心极限定理**，只要把 $\sum_{i=1}^n Z_i$ **标准化**（减期望，除以标准差），大样本下就服从 $N(0,1)$：
$$\frac{\sum_{i=1}^n Z_i - n E(Z_i)}{\sqrt{n D(Z_i)}} \sim N(0, 1)$$

把 $E(Z_i)=0$ 和 $D(Z_i)=2$ 带进去：
$$\frac{\sum_{i=1}^n Z_i - 0}{\sqrt{2n}} = \frac{1}{\sqrt{2}} \sum_{i=1}^n \frac{Z_i}{\sqrt{n}} \sim N(0, 1)$$

---

### 第三步：对比系数，直接得出 $c$

* 理论上标准化的结果是：$\mathbf{\frac{1}{\sqrt{2}}} \sum_{i=1}^n \frac{Z_i}{\sqrt{n}} \sim N(0, 1)$
* 题目给的 $Y_n$ 是：$\mathbf{c} \sum_{i=1}^n \frac{Z_i}{\sqrt{n}}$

两者要完全一致，$c$ 必须等于：
$$c = \frac{1}{\sqrt{2}}$$

---

### 考研应试速算法（考场 15 秒搞定）

填空题直接抓**方差归一化**：
1. 题目要求 $Y_n \sim N(0, 1)$，说明当 $n$ 充分大时，$Y_n$ 的方差必须满足 $D(Y_n) = 1$。
2. 直接算 $Y_n$ 的方差：
   $$D(Y_n) = D\left( \frac{c}{\sqrt{n}} \sum_{i=1}^n (X_{2i} - X_{2i-1}) \right)$$
   提系数平方，各独立项方差相加：
   $$= \frac{c^2}{n} \cdot \sum_{i=1}^n [D(X_{2i}) + D(X_{2i-1})] = \frac{c^2}{n} \cdot n \cdot (1 + 1) = 2c^2$$
3. 令 $D(Y_n) = 2c^2 = 1 \implies c = \frac{1}{\sqrt{2}}$（因为 $c > 0$）。

概率论中的大数定律/极限定理应用题，本质是**“应用文字翻译题”**。

这类题目有一套固定的**“三步建模与解法分析法”**：

---

### 第一步：把实际问题“翻译”为数学符号（建模）

1. **设样本容量**：设这批产品生产了 $n$ 件。
2. **设 0-1 变量（最关键的简化技巧）**：
   设 $X_i = \begin{cases} 1, & \text{第 } i \text{ 件产品合格} \\ 0, & \text{第 } i \text{ 件产品不合格} \end{cases}$ （$i = 1, 2, \dots, n$）
   * 期望：$E(X_i) = p = 0.8$
   * 方差：$D(X_i) = p(1-p) = 0.8 \times 0.2 = 0.16$
3. **表示实际合格率（样本均值）**：
   实际合格率就是 $\bar{X} = \frac{1}{n}\sum_{i=1}^n X_i$。
   * $E(\bar{X}) = 0.8$
   * $D(\bar{X}) = \frac{D(X_i)}{n} = \frac{0.16}{n}$
4. **翻译目标不等式**：
   “合格率在 76% 与 84% 之间” $\iff 0.76 \le \bar{X} \le 0.84 \iff \mathbf{|\bar{X} - 0.8| \le 0.04}$。
   题目要求其概率不小于 90%：
   $$\mathbf{P\left\{ |\bar{X} - 0.8| \le 0.04 \right\} \ge 0.90}$$

---

### 第二步：识别题目工具（判断用“切比雪夫”还是“中心极限定理”）

翻译出目标式 $P\left\{ |\bar{X} - 0.8| \le 0.04 \right\} \ge 0.90$ 后，考研中有两种考法：

#### 方法一：切比雪夫不等式法（若题尾**未给出**正态分布表 $\Phi(x)$）
直接利用切比雪夫不等式的对立形式 $P\{|Y - E(Y)| < \varepsilon\} \ge 1 - \frac{D(Y)}{\varepsilon^2}$：
$$P\{ |\bar{X} - 0.8| \le 0.04 \} \ge 1 - \frac{D(\bar{X})}{(0.04)^2} = 1 - \frac{\frac{0.16}{n}}{0.0016} = 1 - \frac{100}{n}$$
令下界满足要求：
$$1 - \frac{100}{n} \ge 0.90 \implies \frac{100}{n} \le 0.1 \implies \mathbf{n \ge 1000}$$
*(即至少生产 1000 件)*

---

#### 方法二：中心极限定理法 / 棣莫弗-拉普拉斯定理（若题尾**给出了** $\Phi(x)$ 的值，如 $\Phi(1.645)=0.95$）
将 $\bar{X}$ 标准化为标准正态变量 $Z \sim N(0, 1)$：
$$P\{ |\bar{X} - 0.8| \le 0.04 \} = P\left\{ \left| \frac{\bar{X} - 0.8}{\sqrt{0.16/n}} \right| \le \frac{0.04}{\sqrt{0.16/n}} \right\} = P\left\{ |Z| \le 0.1\sqrt{n} \right\}$$
根据正态分布对称区间性质：
$$2\Phi(0.1\sqrt{n}) - 1 \ge 0.90 \implies \Phi(0.1\sqrt{n}) \ge 0.95$$
查表得 $\Phi(1.645) = 0.95$，所以：
$$0.1\sqrt{n} \ge 1.645 \implies \sqrt{n} \ge 16.45 \implies n \ge 270.6 \implies \mathbf{n \ge 271}$$
*(即至少生产 271 件)*

---

### 三、应试分析总结口诀

1. **见“合格率/比例”** $\to$ 设 $0-1$ 变量，合格率化为样本均值 $\bar{X}$；
2. **见“区间对称偏离”** $\to$ 化为绝对值误差 $|\bar{X} - \mu| \le \varepsilon$；
3. **看题尾给没给正态表**：
   * **没给表** $\to$ 必须用**切比雪夫不等式**；
   * **给了表** $\to$ 必须用**中心极限定理标准化**。
