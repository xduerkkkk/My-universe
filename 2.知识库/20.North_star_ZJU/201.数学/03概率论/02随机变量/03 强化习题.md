# 1
![[_attachments/image/03 强化习题-1786497688880.jpeg]]

老师在这里判断右连续的逻辑，核心在于看**复合函数的内层变量 $t = g(x)$ 在 $x \to a^+$ 时，到底是从“右边”还是从“左边”逼近**。

根据右连续的定义：要验证 $G(x)$ 在 $x = a$ 处**右连续**，必须检验：
$$\lim_{x \to a^+} G(x) \stackrel{?}{=} G(a)$$

下面为你对比解析 **A 为什么对（保持右连续）**，以及 **B/D 为什么错（破坏右连续）**：

---

### 一、验证 A 选项 $G(x) = F(2x - 1)$（为什么右连续？）

1. 设内层函数 $t = 2x - 1$。
2. 我们要算右极限 $\lim_{x \to a^+} F(2x - 1)$：
   * 当 $x \to a^+$ 时（即 $x > a$ 且向 $a$ 靠近），由于 $g(x) = 2x - 1$ 是**单调递增**的，所以：
     $$t = 2x - 1 > 2a - 1$$
   * 也就是说，$t$ 是从 $2a - 1$ 的**右侧**向 $2a - 1$ 靠近，即 **$t \to (2a - 1)^+$**。
3. 把换元代入极限：
   $$\lim_{x \to a^+} F(2x - 1) = \lim_{t \to (2a - 1)^+} F(t)$$
4. 因为已知 $F$ 本身是分布函数，**$F$ 必然满足右连续**，所以 $\lim_{t \to t_0^+} F(t) = F(t_0)$：
   $$= F(2a - 1) = G(a)$$
5. **结论：** 极限等于函数值 $G(a^+)=G(a)$，成功验证了 $G(x) = F(2x - 1)$ **满足右连续**！

---

### 二、对比 B 选项 $G(x) = F(1 - x)$（为什么破坏了右连续？）

1. 设内层函数 $t = 1 - x$。
2. 我们算右极限 $\lim_{x \to a^+} F(1 - x)$：
   * 当 $x \to a^+$ 时（即 $x > a$），由于 $g(x) = 1 - x$ 带负号，是**单调递减**的，所以：
     $$t = 1 - x < 1 - a$$
   * 重点来了！**$t$ 是从 $1 - a$ 的“左侧”向 $1 - a$ 靠近的！** 即 **$t \to (1 - a)^-$**。
3. 把换元代入极限：
   $$\lim_{x \to a^+} F(1 - x) = \lim_{t \to (1 - a)^-} F(t) = F\big((1 - a)^-\big)$$
4. $F\big((1 - a)^-\big)$ 是 $F$ 在该点的**左极限**。如果 $F$ 在这里有跳跃间断点，左极限就不等于函数值 $F(1-a)$。
5. **结论：** 右极限算出来变成了左极限，**右连续被破坏成了左连续**，所以 B 选项不能作为分布函数！
   *(同理，D 选项 $1 - F(-x)$ 内层也是 $-x$，也是单调递减，右极限也会变成左极限，同样破坏右连续！)*

---

### 三、补充 C 选项 $F(x^2)$ 错在哪？

$C$ 选项问题出在**极限**上：
当 $x \to -\infty$ 时，$x^2 \to +\infty$，所以 $\lim_{x \to -\infty} F(x^2) = F(+\infty) = 1$。
但规范的分布函数必须满足 $\lim_{x \to -\infty} G(x) = 0$，所以 C 错在负无穷处的极限。

---

### 💡 考研秒杀口诀（分布函数变换题）

对于 $F\big(g(x)\big)$ 这类复合变换：

1. **内层 $g(x)$ 严格单调递增（且能把 $-\infty \to -\infty, +\infty \to +\infty$）** $\rightarrow$ 保留右连续、单调性与极限，**必然仍为分布函数**（如 $2x - 1, 3x+5$ 等线性递增变换，秒选！）。
2. **内层 $g(x)$ 单调递减（带负号，如 $-x, 1-x$）** $\rightarrow$ “右变左”，破坏右连续。
3. **内层 $g(x)$ 非单调（如 $x^2, |x|$）** $\rightarrow$ 破坏 $-\infty$ 处的极限。

# 2
![[_attachments/image/03 强化习题-1786497967493.jpeg]]

这道题是考研中极其经典的**混合型随机变量（既有离散点，又有连续区间）求分布函数**的题目。

我为你分两部分解答你的疑惑：**一是为什么系数是 $\frac{1}{2}$**，**二是老师写的那“三步流程”到底怎么用**。

---

### 一、为啥是 $\frac{d(I)}{2}$？（怎么确定比例系数）

题目条件说：“在 $\{-1 < X < 1\}$ 的条件下，取值的条件概率与区间长度 $d(I)$ 成正比”。

1. **写出正比关系：**
   $$P\{X \in I \mid -1 < X < 1\} = k \cdot d(I)$$
   （其中 $k$ 是常数，$d(I)$ 是子区间 $I$ 的长度）。

2. **利用全概/全集求 $k$：**
   如果我们把子区间 $I$ 直接取为**整个区间 $(-1, 1)$**：
   * 这个子区间的长度 $d(I) = 1 - (-1) = 2$。
   * 在给定条件 $\{-1 < X < 1\}$ 下，$X$ 落入 $(-1, 1)$ 的条件概率必然是 **$1$**（因为条件本身就是落在这个区间里）。

   代入正比公式：
   $$k \cdot 2 = 1 \implies k = \frac{1}{2}$$

3. **得出结论：**
   所以条件概率就是 **$\frac{d(I)}{2}$**！
   *(用语言理解：在 $(-1,1)$ 内条件概率均匀分布，区间长度为 $2$，所以单位长度的概率就是 $\frac{1}{2}$)*。

---

### 二、剩下的求解过程（怎么算出 $F(x)$）

1. **先求连续区间的总概率：**
   因为绝对值不超过 1（即 $X \in [-1, 1]$ 的总概率为 1），扣除两个离散点：
   $$P\{-1 < X < 1\} = 1 - P\{X=-1\} - P\{X=1\} = 1 - \frac{1}{8} - \frac{1}{4} = \frac{5}{8}$$

2. **求任意子区间 $I \subset (-1, 1)$ 的无条件概率：**
   由乘法公式：
   $$P\{X \in I\} = P\{X \in I \mid -1 < X < 1\} \cdot P\{-1 < X < 1\} = \frac{d(I)}{2} \cdot \frac{5}{8} = \frac{5 \cdot d(I)}{16}$$

3. **分段写出 $F(x) = P\{X \le x\}$：**
   * **当 $x < -1$ 时：** $F(x) = 0$
   * **当 $-1 \le x < 1$ 时：** 包含点 $X = -1$ 的概率，加上 $(-1, x]$ 区间上的概率（长度为 $x - (-1) = x + 1$）：
     $$F(x) = P\{X = -1\} + P\{-1 < X \le x\} = \frac{1}{8} + \frac{5(x + 1)}{16}$$
   * **当 $x \ge 1$ 时：** 包含了所有概率， $F(x) = 1$

---

### 三、老师写的这 3 个条件是“流程化做题”吗？

**是的！这是求解【混合型随机变量分布函数】的标准流水线！**

遇到这种题，画出数轴后，按以下三步走：

1. **① 找关键点（分界点）：**
   找出所有**有概率值的孤立点**（如 $x=-1, 1$）以及**连续区间的端点**。它们就是分段函数的拆分点。
2. **② 区间划分“左闭右开”：**
   因为分布函数要求**右连续**，所有分段区间一律划分为：
   $$x < -1,\quad -1 \le x < 1,\quad x \ge 1$$
   （端点取等号一律放在**右侧**的大于号处）。
3. **③ 分段累加求 $F(x)$：**
   从左往右扫描，把一路积累过来的概率（离散点概率 + 连续区间概率）加起来，即可写出完整的分段函数 $F(x)$。
