### 核心直觉外挂：去中心化

任何一个随机变量 $X$，我们都可以把它减去自己的期望，变成一个新的变量 $X^* = X - E(X)$。

这个新变量有什么神奇之处呢？它的期望变成 0 了！即 $E(X^*) = 0$。

因为方差和协方差描述的都是变量“偏离均值的程度”，把坐标原点平移到均值上，**丝毫不会改变方差和协方差的大小**。

所以在推导直觉时，我们**直接假设所有随机变量的期望都是 0**（即 $E(X)=0, E(Y)=0$）。

一旦期望为 0，公式瞬间清爽无比：

- **方差的定义退化为：** $D(X) = E(X^2)$ （自己乘自己，即平方）
    
- **协方差的定义退化为：** $Cov(X,Y) = E(XY)$ （互相乘，即交叉项）
    

有了这个外挂，我们再来看图 2 和图 3 的公式，你会发现它们全都是初中代数展开式！

### 图 2 & 图 3 公式直觉推导

#### 1. 和/差的方差公式

**公式：** $D(X \pm Y) = D(X) + D(Y) \pm 2Cov(X,Y)$

**严谨直觉：**

把它当成初中的完全平方公式 $(a \pm b)^2 = a^2 + b^2 \pm 2ab$。

$$D(X \pm Y) = E[(X \pm Y)^2]$$

$$= E[X^2 \pm 2XY + Y^2]$$

利用期望的线性性质（加号可以直接拆开）：

$$= E(X^2) + E(Y^2) \pm 2E(XY)$$

根据我们前面的“外挂”替换回去：

$$= D(X) + D(Y) \pm 2Cov(X,Y)$$

**直觉结论：** 两个变量相加减的方差，就是各自的方差，加上（或减去）两倍的交叉项（协方差）。如果独立，交叉项为 0，就只剩方差相加了。

#### 2. 协方差的系数提取

**公式：** $Cov(aX, bY) = abCov(X,Y)$

**严谨直觉：**

把它当成简单的乘法结合律。

$$Cov(aX, bY) = E[(aX)(bY)]$$

$$= E(ab \cdot XY)$$

常数 $ab$ 直接提到期望外面：

$$= ab \cdot E(XY)$$

$$= abCov(X,Y)$$

**直觉结论：** 协方差是乘积关系，所以各自乘上的系数，最后都会乘在一起被提出来。

#### 3. 协方差的分配律

**公式：** $Cov(X_1 \pm X_2, Y) = Cov(X_1, Y) \pm Cov(X_2, Y)$

**严谨直觉：**

把它当成多项式乘法的分配律 $(a \pm b)c = ac \pm bc$。

$$Cov(X_1 \pm X_2, Y) = E[(X_1 \pm X_2)Y]$$

$$= E[X_1Y \pm X_2Y]$$

$$= E(X_1Y) \pm E(X_2Y)$$

$$= Cov(X_1, Y) \pm Cov(X_2, Y)$$

**直觉结论：** 协方差具有完美的线性分配律，遇到多项式，直接像乘法一样拆开进去相乘即可。

#### 4. 三个变量和的方差

**公式：** $D(X+Y+Z) = D(X)+D(Y)+D(Z) + 2Cov(X,Y) + 2Cov(Y,Z) + 2Cov(X,Z)$

**严谨直觉：**

把它当成三个数的完全平方公式 $(a+b+c)^2 = a^2+b^2+c^2 + 2ab+2bc+2ac$。

$$D(X+Y+Z) = E[(X+Y+Z)^2]$$

展开平方：

$$= E[X^2 + Y^2 + Z^2 + 2XY + 2YZ + 2XZ]$$

直接对应替换：

$$= D(X) + D(Y) + D(Z) + 2Cov(X,Y) + 2Cov(Y,Z) + 2Cov(X,Z)$$


**为什么这个建立在 $E(X)=0$ 假设上的“外挂”，能够直接推广到所有一般情况？**

这背后有一个极其重要的概率论思想：**平移不变性 (Translation Invariance)**。

简单来说：**方差和协方差只关心变量之间的“相对距离”和“相对运动”，完全不在乎它们的“绝对位置”。**

### 代数视角的严谨解释（只需三步）

我们用代数把这个逻辑链条闭环。假设 $X$ 和 $Y$ 是**随便什么**随机变量（均值不为 0）。

**第一步：给变量“脱去”均值的外衣**

我们定义两个新变量：

$X^* = X - E(X)$

$Y^* = Y - E(Y)$

显然，这两个新变量的均值 $E(X^*) = 0$ 且 $E(Y^*) = 0$。它们满足我们的“外挂”条件！

**第二步：利用“方差无视常数”的性质**

因为 $E(X)$ 和 $E(Y)$ 只是两个固定的常数，而在方差和协方差的计算中，加减一个常数是毫无影响的（因为大家都一起平移了，相对距离没变）。所以：

- $D(X^*) = D(X - 常数) = D(X)$
    
- $D(Y^*) = D(Y - 常数) = D(Y)$
    
- $Cov(X^*, Y^*) = Cov(X - 常数, Y - 常数) = Cov(X,Y)$
    

**第三步：用“外挂”搭桥，再完美替换回来**

以 $D(X+Y)$ 的公式推导为例，我们看看它是怎么无缝过渡的：

我们要求的是一般情况 $D(X+Y)$。

我们把 $X$ 和 $Y$ 拆开：

$$D(X+Y) = D\big((X^* + E(X)) + (Y^* + E(Y))\big)$$

重新组合一下：

$$D(X+Y) = D\big((X^* + Y^*) + (E(X) + E(Y))\big)$$

看！后面那个大括号里全都是**常数**。根据“方差无视常数”的原则，直接把它们扔掉：

$$D(X+Y) = D(X^* + Y^*)$$

此时，我们要处理的是 $D(X^* + Y^*)$。因为 $X^*$ 和 $Y^*$ 均值为 0，**我们的外挂合法生效了**！直接套用外挂推出来的结果：

$$D(X^* + Y^*) = D(X^*) + D(Y^*) + 2Cov(X^*, Y^*)$$

最后，根据第二步，把带星号的替换回原来的样子：

$$= D(X) + D(Y) + 2Cov(X,Y)$$

**结论：** 因为任何一个变量都可以写成“**均值为 0 的变量 + 一个常数**”，而方差和协方差在运算中会自动“吃掉”所有常数，所以我们在推导时直接假设均值为 0，是**在数学上完全等价且合法**的。这在数学上叫做“不失一般性 (Without loss of generality)”。
