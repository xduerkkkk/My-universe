# 2
![[_attachments/image/02 强化习题-1787187928819.jpeg]]


老师这个做法的核心思想是：**“前后均分，化整为零，利用独立性直接套公式”**。

如果不做这个拆分，把 $2\bar{X}$ 直接代入硬算展开，会有大量交叉项算到崩溃。下面把每一步的动机和妙处给你讲透：

---

### 一、核心破局点：把 $2\bar{X}$ 拆成“前半段均值 + 后半段均值”

题目一共有 $2n$ 个样本，老师把它们**前后对半切开**：
* **前半段** $n$ 个数：$X_1, \dots, X_n$，定义其均值为 $\bar{X}_{\text{前}} = \frac{1}{n}\sum_{i=1}^n X_i$
* **后半段** $n$ 个数：$X_{n+1}, \dots, X_{2n}$，定义其均值为 $\bar{X}_{\text{后}} = \frac{1}{n}\sum_{i=1}^n X_{n+i}$

#### 观察全样本均值 $\bar{X}$ 的关系：
$$\bar{X} = \frac{1}{2n}\sum_{i=1}^{2n} X_i = \frac{1}{2}\left( \bar{X}_{\text{前}} + \bar{X}_{\text{后}} \right) \implies \mathbf{2\bar{X} = \bar{X}_{\text{前}} + \bar{X}_{\text{后}}}$$

于是，括号里的式子被**极其工整地分组匹配**：
$$X_i + X_{n+i} - \mathbf{2\bar{X}} = \underbrace{(X_i - \bar{X}_{\text{前}})}_{\text{只含前半段}} + \underbrace{(X_{n+i} - \bar{X}_{\text{后}})}_{\text{只含后半段}}$$

---

### 二、展开平方：为什么瞬间变得极好算？

利用 $(a+b)^2 = a^2 + b^2 + 2ab$，把统计量 $Y$ 展开为三部分：

$$Y = \underbrace{\sum_{i=1}^n (X_i - \bar{X}_{\text{前}})^2}_{\text{第一项}} + \underbrace{\sum_{i=1}^n (X_{n+i} - \bar{X}_{\text{后}})^2}_{\text{第二项}} + \underbrace{2\sum_{i=1}^n (X_i - \bar{X}_{\text{前}})(X_{n+i} - \bar{X}_{\text{后}})}_{\text{第三项（交叉项）}}$$

两边取期望 $E(Y)$，每一项都可以**口算**：

#### 1. 第一项（前半段样本的离差平方和）：
这是 $n$ 个样本的标准离差平方和，由我们刚讲过的结论：
$$E\left[\sum_{i=1}^n (X_i - \bar{X}_{\text{前}})^2\right] = \mathbf{(n-1)\sigma^2}$$

#### 2. 第二项（后半段样本的离差平方和）：
同理，也是 $n$ 个样本的离差平方和：
$$E\left[\sum_{i=1}^n (X_{n+i} - \bar{X}_{\text{后}})^2\right] = \mathbf{(n-1)\sigma^2}$$

#### 3. 第三项（交叉项，奇迹在这里）：
* 前半段样本 $\{X_1,\dots,X_n\}$ 和后半段样本 $\{X_{n+1},\dots,X_{2n}\}$ 是**完全相互独立的**！
* 独立变量乘积的期望等于期望的乘积：
  $$E\left[(X_i - \bar{X}_{\text{前}})(X_{n+i} - \bar{X}_{\text{后}})\right] = \underbrace{E(X_i - \bar{X}_{\text{前}})}_{=0} \cdot \underbrace{E(X_{n+i} - \bar{X}_{\text{后}})}_{=0} = \mathbf{0}$$
* 所以交叉项的期望**全部等于 0**！

---

### 三、最终结果与应试启发

三项相加，直接出答案：
$$E(Y) = (n-1)\sigma^2 + (n-1)\sigma^2 + 0 = \mathbf{2(n-1)\sigma^2}$$

---

### 考场切入点总结
看到题目出现形如 **$X_i + X_{n+i} - 2\bar{X}$**（或者下标对称分组）：
1. **第一反应**：立刻想到拆解 $2\bar{X} = \bar{X}_1 + \bar{X}_2$；
2. **目的**：把不独立的整体，拆成两组**相互独立**的子样本，让交叉项在求期望时自动为 $0$；
3. **套公式**：每一组直接套用 $E\left[\sum_{i=1}^n(X_i-\bar{X})^2\right] = (n-1)\sigma^2$。

# 4
![[_attachments/image/02 强化习题-1787196359013.jpeg]]


这是考研题非常喜欢出的**“自定义符号陷阱”**！

---

### 一、看清题干的自定义记号

* **课本的标准样本方差**是：$S^2 = \frac{1}{n-1}\sum_{i=1}^n (X_i - \bar{X})^2$（前面带 $\frac{1}{n-1}$）。
* **但这道题自己定义了**：
  $$S_2^2 \overset{\text{题干定义}}{=} \sum_{i=1}^n (X_i - \bar{X})^2 \quad (\mathbf{题干故意没有除以 } n-1)$$

所以题干的 $S_2^2$ 本质上等于 **$(n-1)S^2$**。

---

### 二、按照定义重新组装 $t$ 分布

既然 $S_2^2 = \sum_{i=1}^n (X_i - \bar{X})^2$，根据定理三，它的分布是：
$$\frac{S_2^2}{\sigma^2} \sim \chi^2(n-1)$$

现在我们老老实实套用 $t$ 分布的定义：$\mathbf{T = \frac{N(0,1)}{\sqrt{\chi^2(n-1) \,/\, (n-1)}}}$：

1. **分子（标准正态）**：
   $$Z = \frac{\bar{X} - \mu}{\sigma / \sqrt{n}} \sim N(0, 1)$$

2. **分母（根号下卡方除以自由度）**：
   $$\sqrt{\frac{S_2^2 / \sigma^2}{n - 1}} = \frac{S_2}{\sigma \sqrt{n - 1}}$$

3. **上下相除并化简**：
   $$T = \frac{\frac{\bar{X} - \mu}{\sigma / \sqrt{n}}}{\frac{S_2}{\sigma \sqrt{n - 1}}} = \frac{\bar{X} - \mu}{S_2} \cdot \frac{\sigma \sqrt{n - 1}}{\sigma / \sqrt{n}} = \frac{\bar{X} - \mu}{S_2} \cdot \sqrt{n(n-1)} = \mathbf{\frac{\bar{X} - \mu}{S_2}\sqrt{n^2 - n}}$$

对比选项，**正确答案直接锁定 (B)**。

---

### 考场防坑技巧
遇到带下标的 $S_1^2, S_2^2, S^*$ 等符号：
* **第一步**：先看题干定义有没有除以 $n-1$（辨别它是“纯平方和”还是“标准样本方差”）；
* **第二步**：不要直接默写课本结论，严格按“**分子 $N(0,1) \div \sqrt{\text{卡方/自由度}}$**”进行繁分式化简。


# 5

![[_attachments/image/02 强化习题-1787197821798.jpeg]]**你的第一反应完全正确！你的直觉非常准，因为它骨子里就是一个 $t$ 分布——只不过被“平方”了。**

请对比下面两个式子：

---

### 一、还原真相：它就是 $t$ 统计量的平方

如果按照上一问的**双样本 $t$ 统计量**（这里 $n_1=n_2=n, \mu_1=\mu_2=0$）：
$$T = \frac{(\bar{X} - \bar{Y}) - 0}{S_w \sqrt{\frac{1}{n} + \frac{1}{n}}} = \frac{\bar{X} - \bar{Y}}{\sqrt{\frac{(n-1)S_X^2 + (n-1)S_Y^2}{2n - 2}} \sqrt{\frac{2}{n}}} = \mathbf{\frac{\sqrt{n}(\bar{X} - \bar{Y})}{\sqrt{S_X^2 + S_Y^2}} \sim t(2n - 2)}$$

现在看题目给你的统计量：
$$F = \frac{n(\bar{X} - \bar{Y})^2}{S_X^2 + S_Y^2}$$

两眼一对比就会发现：
$$F = \left[ \frac{\sqrt{n}(\bar{X} - \bar{Y})}{\sqrt{S_X^2 + S_Y^2}} \right]^2 = \mathbf{T^2}$$

---

### 二、套用核心定理：$t^2$ 必为 $F$

我们在三大分布性质里讲过一个**考研必背的秒杀定理**：

> **若 $T \sim t(k)$，则 $T^2 \sim F(1, k)$**

因为这里的 $T \sim t(2n - 2)$，对其整体平方后：
$$T^2 \sim \mathbf{F(1, 2n - 2)}$$

---

### 考场火眼金睛（如何区分 $t$ 和 $F$）

看到**“分子是均值差、分母是方差和”**这种结构时：

* **如果形式是“一次方 / 分母带根号”**：
  $$\frac{\sqrt{n}(\bar{X} - \bar{Y})}{\sqrt{S_X^2 + S_Y^2}} \implies \mathbf{t(2n - 2)}$$
* **如果形式是“二次方 / 分母无根号”**（即把上面的式子整体平方）：
  $$\frac{n(\bar{X} - \bar{Y})^2}{S_X^2 + S_Y^2} \implies \mathbf{F(1, 2n - 2)}$$

记住这个对应关系，考场上看到平方直接写第一自由度为 1 的 $F$ 分布。
