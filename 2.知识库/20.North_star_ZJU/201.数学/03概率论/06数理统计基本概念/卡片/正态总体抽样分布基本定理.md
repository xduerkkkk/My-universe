这 5 个结论统称为**“正态总体抽样分布基本定理”**，是考研数一概率统计最核心的支柱。

我们逐一拆解：为什么 $\bar{X}$ 与 $S^2$ 独立，以及 (2)、(4)、(5) 是如何层层推导出来的。

---

### 一、为什么 $\bar{X}$ 与 $S^2$ 相互独立？

这是正态分布独有的**正交独立性**。

#### 1. 代数本质（证明协方差为 0）
* 样本方差 $S^2 = \frac{1}{n-1}\sum_{i=1}^n (X_i - \bar{X})^2$，它**完全由所有的离差项 $(X_i - \bar{X})$ 决定**。
* 如果能证明 $\bar{X}$ 与每一个 $(X_i - \bar{X})$ 都独立，那么 $\bar{X}$ 自然与它们的函数 $S^2$ 独立。
* 因为 $\bar{X}$ 和 $(X_i - \bar{X})$ 都是正态变量的线性组合，它们服从**二维正态分布**。对于二维正态变量，**“独立 $\iff$ 协方差为 0”**。

我们来算它们的协方差 $\text{Cov}(\bar{X}, X_i - \bar{X})$：
$$\begin{aligned}
\text{Cov}(\bar{X}, X_i - \bar{X}) 
&= \text{Cov}(\bar{X}, X_i) - \text{Cov}(\bar{X}, \bar{X}) \\
&= \text{Cov}\left(\frac{1}{n}\sum_{j=1}^n X_j, X_i\right) - D(\bar{X}) \\
&= \frac{1}{n} D(X_i) - \frac{\sigma^2}{n} \\
&= \frac{\sigma^2}{n} - \frac{\sigma^2}{n} = \mathbf{0}
\end{aligned}$$
协方差恒为 0 $\implies$ $\bar{X}$ 与每个 $X_i - \bar{X}$ 相互独立 $\implies$ $\mathbf{\bar{X} \text{ 与 } S^2 \text{ 相互独立}}$。

#### 2. 空间几何理解（正交投影）
在 $n$ 维空间中，样本向量 $\vec{X} = (X_1, \dots, X_n)$ 被分解到了两个**相互垂直（正交）**的子空间：
* 一个是沿法向量 $(1, 1, \dots, 1)^T$ 的 **1 维直线**，对应样本均值 $\bar{X}$；
* 另一个是垂直于该直线的 **$n-1$ 维超平面**，对应离差向量 $(X_i - \bar{X})$，即 $S^2$。

因为正态分布在空间中是完全各向同性的（球对称），**投射到两个相互正交空间上的分量必定相互独立**。

---

### 二、式子 (2) 怎么推的？

目标：推导 $\bar{X} \sim N\left(\mu, \frac{\sigma^2}{n}\right)$ 及标准化。

1. **确定是正态分布**：$\bar{X} = \frac{1}{n}\sum_{i=1}^n X_i$ 是 $n$ 个独立正态变量的线性组合，必定服从正态分布。
2. **算期望**：$E(\bar{X}) = \frac{1}{n}\sum_{i=1}^n E(X_i) = \frac{1}{n}(n\mu) = \mu$。
3. **算方差**（独立变量方差可加，系数平方提出来）：
   $$D(\bar{X}) = D\left(\frac{1}{n}\sum_{i=1}^n X_i\right) = \frac{1}{n^2}\sum_{i=1}^n D(X_i) = \frac{1}{n^2}(n\sigma^2) = \frac{\sigma^2}{n}$$
4. **标准化**：减期望除以标准差：
   $$\frac{\bar{X} - E(\bar{X})}{\sqrt{D(\bar{X})}} = \mathbf{\frac{\bar{X} - \mu}{\sigma / \sqrt{n}} \sim N(0, 1)}$$

---

### 三、式子 (4) 怎么推的？

目标：推导 $\frac{(n-1)S^2}{\sigma^2} \sim \chi^2(n-1)$。

利用经典的**方差分解恒等式**（配凑 $\pm\bar{X}$）：
$$\sum_{i=1}^n (X_i - \mu)^2 = \sum_{i=1}^n \left[(X_i - \bar{X}) + (\bar{X} - \mu)\right]^2$$
展开后交叉项为 0（因 $\sum(X_i-\bar{X})=0$），化简得：
$$\sum_{i=1}^n (X_i - \mu)^2 = \sum_{i=1}^n (X_i - \bar{X})^2 + n(\bar{X} - \mu)^2$$

两边同时除以 $\sigma^2$：
$$\underbrace{\sum_{i=1}^n \left(\frac{X_i - \mu}{\sigma}\right)^2}_{\text{左边}} = \underbrace{\frac{(n-1)S^2}{\sigma^2}}_{\text{右边第 1 项}} + \underbrace{\left(\frac{\bar{X} - \mu}{\sigma / \sqrt{n}}\right)^2}_{\text{右边第 2 项}}$$

观察三部分的分布：
* **左边**：$n$ 个独立标准正态的平方和，服从 $\chi^2(n)$；
* **右边第 2 项**：由式子 (2) 知它是单个标准正态的平方，服从 $\chi^2(1)$；
* **关键性**：由结论 (1)，$\bar{X}$ 与 $S^2$ 独立，所以**右边两项相互独立**。

根据卡方分布的**自由度可加性**：
$$\text{左边自由度} = \text{右边第 1 项自由度} + \text{右边第 2 项自由度} \implies n = \text{自由度} + 1$$
解得右边第 1 项自由度为 $n - 1$，即：
$$\mathbf{\frac{(n-1)S^2}{\sigma^2} \sim \chi^2(n-1)}$$

---

### 四、式子 (5) 怎么推的？

目标：推导 $\frac{\bar{X} - \mu}{S / \sqrt{n}} \sim t(n-1)$。

利用 $t$ 分布的构造定义：$T = \frac{U}{\sqrt{V / k}} \sim t(k)$（要求 $U \sim N(0,1), V \sim \chi^2(k)$ 且独立）。

1. **取分子 $U$**：式子 (2) 中的 $U = \frac{\bar{X} - \mu}{\sigma / \sqrt{n}} \sim N(0, 1)$。
2. **取分母卡方 $V$**：式子 (4) 中的 $V = \frac{(n-1)S^2}{\sigma^2} \sim \chi^2(n-1)$，对应自由度 $k = n-1$。
3. **独立性**：由结论 (1)，分子只含 $\bar{X}$，分母只含 $S^2$，二者相互独立。
4. **组装**：
   $$T = \frac{U}{\sqrt{V / (n-1)}} = \frac{\frac{\bar{X} - \mu}{\sigma / \sqrt{n}}}{\sqrt{\frac{(n-1)S^2 / \sigma^2}{n-1}}} = \frac{\frac{\bar{X} - \mu}{\sigma / \sqrt{n}}}{\frac{S}{\sigma}} = \mathbf{\frac{\bar{X} - \mu}{S / \sqrt{n}} \sim t(n-1)}$$
   未知参数 $\sigma$ 刚好上下约去。

---

### 考场逻辑链小结
$$(2) \implies \bar{X} \text{ 标准化为 } N(0,1)$$
$$\left. \begin{array}{l} (1) \text{ 独立性} \\ (2) \bar{X} \sim N \\ (3) \text{ 总体卡方} \end{array} \right\} \implies (4) \text{ 样本方差为 } \chi^2(n-1)$$
$$\left. \begin{array}{l} (1) \text{ 独立性} \\ (2) N(0,1) \\ (4) \chi^2(n-1) \end{array} \right\} \implies (5) \text{ 比值构造出 } t(n-1)$$**是的！这三个式子正是由前面的公式 (4) 和公式 (1) 直接推出来的。**

推导过程极其简单，全都是利用已知的卡方分布性质和独立性性质：

---

### 一、逐个推导过程

记卡方统计量为：
$$Y = \frac{(n-1)S^2}{\sigma^2} \sim \chi^2(n-1)$$

#### 1. 推导 $D(S^2) = \frac{2}{n-1}\sigma^4$（直接用卡方方差）
我们刚推导过：自由度为 $k$ 的卡方分布，其**方差为 $2k$**。
所以：
$$D(Y) = D\left(\chi^2(n-1)\right) = \mathbf{2(n-1)}$$

把 $Y$ 的定义式代入方差（常数提出来要平方）：
$$D(Y) = D\left( \frac{n-1}{\sigma^2} S^2 \right) = \left(\frac{n-1}{\sigma^2}\right)^2 D(S^2)$$

两边画等号：
$$\left(\frac{n-1}{\sigma^2}\right)^2 D(S^2) = 2(n-1) \implies \mathbf{D(S^2) = \frac{2}{n-1}\sigma^4}$$

---

#### 2. 推导 $E(S^2) = \sigma^2$（直接用卡方期望）
自由度为 $k$ 的卡方分布，其**期望为 $k$**。
$$E(Y) = E\left(\frac{n-1}{\sigma^2} S^2\right) = n-1 \implies \frac{n-1}{\sigma^2} E(S^2) = n-1 \implies \mathbf{E(S^2) = \sigma^2}$$

---

#### 3. 推导 $\text{Cov}(\bar{X}, S^2) = 0$（直接用公式 (1) 的独立性）
* 在正态总体下，结论 (1) 证明了 $\bar{X}$ 与 $S^2$ **相互独立**；
* 两个变量只要相互独立，其协方差**必然为 0**：
  $$\mathbf{\text{Cov}(\bar{X}, S^2) = 0}$$

---

### 二、考研核心避坑点（底下的【注】在考什么？）

考研选择题非常喜欢在这里挖坑，重点考察**适用条件**：

| 结论 | 是否需要“正态总体”前提？ | 考研辨析核心 |
| :--- | :--- | :--- |
| $E(\bar{X}) = \mu$ | **任何分布恒成立** | 只要期望存在就成立 |
| $D(\bar{X}) = \frac{\sigma^2}{n}$ | **任何分布恒成立** | 只要相互独立、方差存在就成立 |
| $E(S^2) = \sigma^2$ | **任何分布恒成立** | $S^2$ 是通用的无偏估计 |
| $\mathbf{D(S^2) = \frac{2}{n-1}\sigma^4}$ | **必须在正态总体下才成立！** | 非正态总体的 $D(S^2)$ 与四阶矩有关，不等于此式 |
| $\mathbf{\text{Cov}(\bar{X}, S^2) = 0}$ | **必须在正态总体下才成立！** | 非正态总体下两者通常不独立且协方差不为 0 |
| $\mathbf{\frac{(n-1)S^2}{\sigma^2} \sim \chi^2(n-1)}$ | **必须在正态总体下才成立！** | 非正态总体的样本方差不服从卡方分布 |

**考场警惕**：如果题干只说“总体 $X$ 的期望为 $\mu$，方差为 $\sigma^2$”（**没提正态**），如果选项里出现卡方分布或者 $D(S^2) = \frac{2}{n-1}\sigma^4$，**直接判定为错误选项**。
