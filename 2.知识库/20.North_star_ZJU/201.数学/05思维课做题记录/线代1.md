求 $A^n$ 的思维决策树（四套神兵利器）

考场上看到求高阶幂 $A^n$，按以下优先级顺序匹配：

1. **看秩是否为 1**（若 $r(A)=1 \implies A = \boldsymbol{\alpha}\boldsymbol{\beta}^\mathrm{T}$）：
   公式直接出：$A^n = (\operatorname{tr} A)^{n-1} A$。
2. **算一下 $A^2$**（考研 $70\%$ 的规律题在算完 $A^2$ 后就会出现 $kA$ 或 $kE$）：
   算两个位置发现是常数倍单位阵或原矩阵，直接归纳。
3. **主对角线全同、非对角线全同**：
   直接拆成 $A = aE + bJ$（利用全 $1$ 矩阵 $J^2 = nJ$ 的性质二项式展开或求特征值）。
4. **主对角线相同，其余为严格三角阵**：
   拆成 $A = kE + B$（利用幂零矩阵 $B^k = O$ 二项式截断展开，即上一道例 2.4）。
5. **通法（大题压轴保底）**：
   求特征值、特征向量，相似对角化 $A^n = P \Lambda^n P^{-1}$。

# 方程组

![[_attachments/image/Pasted image 20261024205432.jpeg]]
- 知识点
	
	1. **写出 (II) 的通解形式**：
	   $$\boldsymbol{x} = k_1\boldsymbol{\alpha}_1 + k_2\boldsymbol{\alpha}_2 = \begin{pmatrix} -k_1 \\ 2k_1 - k_2 \\ 2k_1 - k_2 \\ k_1 \end{pmatrix}$$
	2. **把这个解强行塞进方程组 (I)**（因为公共解必须同时满足 (I)）：
	   $$\begin{cases} x_1 + x_2 = (-k_1) + (2k_1 - k_2) = 0 \\ x_2 - x_4 = (2k_1 - k_2) - k_1 = 0 \end{cases} \implies k_1 - k_2 = 0 \implies k_1 = k_2$$
	3. **回代定解**：
	   取 $k_1 = k_2 = 1$，得到公共解：
	   $$\boldsymbol{x} = \boldsymbol{\alpha}_1 + \boldsymbol{\alpha}_2 = (-1, 1, 1, 1)^T$$
	   所以非零公共解为 $k(-1, 1, 1, 1)^T \ (k \neq 0)$。
