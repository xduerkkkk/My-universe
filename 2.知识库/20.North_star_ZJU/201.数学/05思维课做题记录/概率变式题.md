我的第一反应是变成 0.2X +0.8Y X 满足标准正态 Y 满足（4，4）的标准正态，准备算 D，但发现，X 与 Y 不独立？

你的方法从根源上就错了。你掉进了考研概率论最经典的陷阱：**混淆了“分布函数的线性组合”与“随机变量的线性组合”**。

### 1. 纠偏：为什么不能写成 $X = 0.2X_1 + 0.8X_2$？

我们直接看空间上的图像（概率密度曲线）和实际物理意义：

* **如果是随机变量相加 $X = 0.2X_1 + 0.8X_2$**：
  根据上一题讲的，正态变量的线性组合**依然是正态分布**。它的概率密度图像是把两个正态分布融合，在中间生成一个新的、**单峰的**钟形曲线。
* **本题是分布函数相加 $F(x) = 0.2F_1(x) + 0.8F_2(x)$**：
  两边求导，概率密度是 $f(x) = 0.2f_1(x) + 0.8f_2(x)$。
  在空间图像上，它是把 $N(0,1)$ 的钟形曲线压扁到原来的 $0.2$ 倍，把 $N(4,4)$ 的钟形曲线压扁到原来的 $0.8$ 倍，然后直接画在同一个坐标系里叠加。这叫**混合正态分布**，它的图像在 $x=0$ 和 $x=4$ 处有两个波峰（**双峰曲线**），它根本就不是正态分布！

**理解性推理（全概率公式的视角）：**
$F(x) = 0.2F_1(x) + 0.8F_2(x)$ 真正的含义是**分步抽样**：
你手里有两个箱子，1 号箱装的是服从 $X_1 \sim N(0,1)$ 的随机数，2 号箱装的是服从 $X_2 \sim N(4, 2^2)$ 的随机数。
现在你先掷一个不均匀的硬币，**有 $0.2$ 的概率去 1 号箱抽一个数作为 $X$，有 $0.8$ 的概率去 2 号箱抽一个数作为 $X$**。每次抽样你只去一个箱子，根本不存在 $X_1$ 和 $X_2$ 同时出现去相加的情况，所以也完全谈不上它俩独不独立。

---

### 2. 核心原理：怎么算它的期望和方差？

既然密度函数是 $f(x) = 0.2f_1(x) + 0.8f_2(x)$，而**积分具有线性性质**，这就决定了：**只有“期望（一阶矩、二阶矩）”才能按 $0.2$ 和 $0.8$ 直接拆开算！**

对于任意函数 $g(X)$ 的期望：
$$E[g(X)] = \int_{-\infty}^{+\infty} g(x)[0.2f_1(x) + 0.8f_2(x)]dx = 0.2 E[g(X_1)] + 0.8 E[g(X_2)]$$

* **期望 $E(X)$ 是线性的**，可以直接加权：
  $$E(X) = 0.2 E(X_1) + 0.8 E(X_2)$$
* **二阶原点矩 $E(X^2)$ 也是线性的**，也可以直接加权：
  $$E(X^2) = 0.2 E(X_1^2) + 0.8 E(X_2^2)$$
* **唯独方差 $D(X)$ 不能直接加权！** 因为 $D(X) = E(X^2) - [E(X)]^2$，后面那个平方项 $[E(X)]^2$ 破坏了线性关系，绝对不能写成 $0.2D(X_1) + 0.8D(X_2)$。

---

### 3. 回到应试方法（考场标准动作）

考场上只要看到 $F(x) = p F_1(x) + q F_2(x)$ 或 $f(x) = p f_1(x) + q f_2(x)$ 这种结构，求 $D(X)$ 只有唯一套路：**列表算 $E(X)$ 和 $E(X^2)$，最后用 $D(X) = E(X^2) - [E(X)]^2$ 汇总。**

**第一步：翻译出两个基础分布的参数**
* $\Phi(x) = \Phi\left(\frac{x-0}{1}\right) \implies X_1 \sim N(0, 1^2)$，即 $E(X_1)=0, \ D(X_1)=1$
* $\Phi\left(\frac{x-4}{2}\right) \implies X_2 \sim N(4, 2^2)$，即 $E(X_2)=4, \ D(X_2)=4$
*(注意：标准正态分布函数定义为 $\Phi\left(\frac{x-\mu}{\sigma}\right)$，分母的 $2$ 是标准差 $\sigma$，所以方差是 $2^2=4$，千万别看成方差是 $2$)*。

**第二步：分别求出各自的 $E(X_i^2)$（利用公式 $E(X^2) = D(X) + [E(X)]^2$）**
* $E(X_1^2) = 1 + 0^2 = 1$
* $E(X_2^2) = 4 + 4^2 = 20$

**第三步：按权重 $0.2$ 和 $0.8$ 合成 $E(X)$ 和 $E(X^2)$**
* $E(X) = 0.2 \times 0 + 0.8 \times 4 = 3.2$
* $E(X^2) = 0.2 \times 1 + 0.8 \times 20 = 0.2 + 16 = 16.2$

**第四步：算最终方差 $D(X)$**
$$D(X) = E(X^2) - [E(X)]^2 = 16.2 - 3.2^2 = 16.2 - 10.24 = 5.96$$
**选 B。**

这种题型在考研数学中通常被称为**“混合分布的数字特征”**（或称“分布函数/密度函数的凸组合问题”）。

为了帮你彻底剥离它和“随机变量线性组合”的混淆，我先给你立一个**考场一眼识别的铁律**，然后给你出 3 道极具代表性的变式题，把考研在这块能挖的坑全覆盖掉。

### 考场识别铁律：看系数 $0.2$ 和 $0.8$ 乘在哪里！

1. **乘在变量上（变量组合）：** $Z = 0.2 X + 0.8 Y$
   * **求方差：** 直接用公式 $D(Z) = 0.2^2 D(X) + 0.8^2 D(Y) + 2 \times 0.2 \times 0.8 \text{Cov}(X,Y)$。**系数要平方，且必须考虑相关性！**
2. **乘在函数外（混合分布）：** $F_Z(z) = 0.2 F_X(z) + 0.8 F_Y(z)$ 或 $f_Z(z) = 0.2 f_X(z) + 0.8 f_Y(z)$
   * **求方差：** **完全不用管 $X,Y$ 独不独立**。系数绝对不平方！只能老老实实拆成 $E(Z)$ 和 $E(Z^2)$ 加权，最后算 $E(Z^2) - [E(Z)]^2$。

### 针对性变式训练（建议先在草稿纸上做完再看底部答案）

#### 【变式 1：同参数下的直接对比（彻底打醒混淆）】
设随机变量 $X_1 \sim N(0, 1)$，$X_2 \sim N(4, 2^2)$，且 $X_1$ 与 $X_2$ 相互独立。
* 设随机变量 $Y = 0.2 X_1 + 0.8 X_2$，其分布函数记为 $F_Y(y)$；
* 设随机变量 $Z$ 的分布函数为 $F_Z(z) = 0.2 F_{X_1}(z) + 0.8 F_{X_2}(z)$。

请分别求出：(1) $E(Y)$ 和 $E(Z)$； (2) $D(Y)$ 和 $D(Z)$； (3) 将 $F_Y(y)$ 用标准正态分布函数 $\Phi(\cdot)$ 表示出来，看看它和 $F_Z(z)$ 长相有什么本质不同。

#### 【变式 2：密度函数形式的伪装（跨越正态分布）】
设连续型随机变量 $X$ 的概率密度函数为：
$$f(x) = \begin{cases} 0.5 e^{-x}, & x > 0 \\ 0.25, & -2 \le x \le 0 \\ 0, & \text{其他} \end{cases}$$
求 $E(X)$ 和 $D(X)$。
*(提示：不要傻傻去硬算积分，观察 $f(x)$ 是由哪两个你熟知的经典分布拼接混合而成的，用混合分布的套路秒杀)*

#### 【变式 3：实际应用背景的翻译（全概率公式逆向）】
某工厂有甲、乙两条生产线生产同一种零件。甲生产线占总产量的 $40\%$，其生产的零件长度 $X_1$（单位：cm）服从正态分布 $N(10, 1)$；乙生产线占总产量的 $60\%$，其生产的零件长度 $X_2$ 服从正态分布 $N(12, 3)$。现从该厂生产的零件仓库中**随机抽取一个零件**，记其长度为 $X$。
求：(1) $X$ 的分布函数 $F(x)$（用 $\Phi$ 表示）； (2) $D(X)$。
*(思考：抽出来的这一个零件的长度 $X$，应该写成 $X = 0.4 X_1 + 0.6 X_2$ 吗？)*

### 答案与解析

#### 【变式 1 解析】
**(1) 求期望：**
* $E(Y) = 0.2 E(X_1) + 0.8 E(X_2) = 0.2 \times 0 + 0.8 \times 4 = 3.2$
* $E(Z) = 0.2 E(X_1) + 0.8 E(X_2) = 3.2$
*(结论：两种操作下，期望的计算结果是完全一样的！因为期望本身就是线性算子，这也是最容易让人误以为方差也能这么干的原因。)*

**(2) 求方差：**
* $Y$ 是**变量的线性组合**，且 $X_1, X_2$ 独立：
  $$D(Y) = 0.2^2 D(X_1) + 0.8^2 D(X_2) = 0.04 \times 1 + 0.64 \times 4 = 0.04 + 2.56 = 2.6$$
* $Z$ 是**混合分布**，就是你刚问的原题，按三步走套路：
  $$E(Z^2) = 0.2 E(X_1^2) + 0.8 E(X_2^2) = 0.2 \times 1 + 0.8 \times (4 + 4^2) = 16.2$$
  $$D(Z) = E(Z^2) - [E(Z)]^2 = 16.2 - 3.2^2 = 5.96$$

**(3) 分布函数的长相差异：**
* 因为 $X_1, X_2$ 独立正态，它们的线性组合 $Y$ **依然是一个纯粹的正态分布**！
  由上可知 $Y \sim N(3.2, 2.6)$，所以它的分布函数只有一个 $\Phi$：
  $$F_Y(y) = \Phi\left(\frac{y - 3.2}{\sqrt{2.6}}\right)$$
* 而 $F_Z(z) = 0.2\Phi(z) + 0.8\Phi\left(\frac{z-4}{2}\right)$ 是两个 $\Phi$ 的加权和。现在看清它俩在式子结构上的天壤之别了吗？

---

#### 【变式 2 解析】
**识别结构：**
观察发现，当 $x>0$ 时，$e^{-x}$ 是参数为 $\lambda = 1$ 的**指数分布** $X_1 \sim E(1)$ 的密度函数；当 $-2 \le x \le 0$ 时，$\frac{1}{2} = 0.5$ 是区间 $[-2, 0]$ 上的**均匀分布** $X_2 \sim U(-2, 0)$ 的密度函数。
因此，原密度函数本质上就是混合分布：
$$f(x) = 0.5 f_1(x) + 0.5 f_2(x)$$

**套用应试模板：**
1. **读出基础分布参数：**
   * $X_1 \sim E(1) \implies E(X_1) = 1, \ D(X_1) = 1 \implies E(X_1^2) = 1 + 1^2 = 2$
   * $X_2 \sim U(-2, 0) \implies E(X_2) = \frac{-2+0}{2} = -1, \ D(X_2) = \frac{(0 - (-2))^2}{12} = \frac{1}{3} \implies E(X_2^2) = \frac{1}{3} + (-1)^2 = \frac{4}{3}$
2. **按权重 $0.5$ 和 $0.5$ 合成：**
   * $E(X) = 0.5 \times 1 + 0.5 \times (-1) = 0$
   * $E(X^2) = 0.5 \times 2 + 0.5 \times \frac{4}{3} = 1 + \frac{2}{3} = \frac{5}{3}$
3. **算最终方差：**
   $$D(X) = E(X^2) - [E(X)]^2 = \frac{5}{3} - 0^2 = \frac{5}{3}$$
*(比你去分段硬算 $\int_{-2}^0 x^2 \cdot 0.25 dx + \int_0^{+\infty} x^2 \cdot 0.5 e^{-x} dx$ 快得多，而且绝不会算错分部积分！)*

---

#### 【变式 3 解析】
**核心推理：**
你只抽了**一个**零件，它要么来自甲厂，要么来自乙厂，绝不可能是“把甲厂的一个零件砍下 $40\%$ 再加上乙厂零件的 $60\%$ 粘在一起”，所以**绝对不能写成 $X = 0.4 X_1 + 0.6 X_2$**！

**(1) 求分布函数：**
根据全概率公式，抽出的零件长度小于等于 $x$ 的概率为：
$$F(x) = P(X \le x) = 0.4 P(X_1 \le x) + 0.6 P(X_2 \le x) = 0.4 \Phi(x - 10) + 0.6 \Phi\left(\frac{x - 12}{\sqrt{3}}\right)$$
*(看，这就是混合分布的物理起源！另外注意 $X_2 \sim N(12, 3)$，这里的 $3$ 是方差 $\sigma^2$，所以分母是标准差 $\sqrt{3}$。)*

**(2) 求方差 $D(X)$：**
1. **读参数与二阶矩：**
   * $X_1 \sim N(10, 1) \implies E(X_1)=10, \ D(X_1)=1 \implies E(X_1^2) = 1 + 10^2 = 101$
   * $X_2 \sim N(12, 3) \implies E(X_2)=12, \ D(X_2)=3 \implies E(X_2^2) = 3 + 12^2 = 147$
2. **加权合成：**
   * $E(X) = 0.4 \times 10 + 0.6 \times 12 = 4 + 7.2 = 11.2$
   * $E(X^2) = 0.4 \times 101 + 0.6 \times 147 = 40.4 + 88.2 = 128.6$
3. **最终方差：**
   $$D(X) = E(X^2) - [E(X)]^2 = 128.6 - 11.2^2 = 128.6 - 125.44 = 3.16$$

为了帮你彻底把刚才的“三步切入法”变成肌肉记忆，我从易到难、从不同考察角度给你设计了**3 道变式题**。

建议你先拿草稿纸自己列一下式子，再看下面的解析。

### 变式一：离散点移到“区间内部”（考验数轴分段能力）

**【题目】**
设随机变量 $X$ 的取值范围在 $[0, 2]$ 上，已知 $P\{X = 1\} = \frac{1}{3}$。在事件 $\{X \neq 1\}$ 发生的条件下，$X$ 在 $[0, 2]$ 内的任一不含 $1$ 的子区间上取值的条件概率与该子区间长度成正比。试求 $X$ 的分布函数 $F(x)$。

**【思考切入点】**
1. **看数轴分配**：总概率为 $1$。在中间点 $x = 1$ 处截留了 $\frac{1}{3}$ 的概率；剩下的 $1 - \frac{1}{3} = \frac{2}{3}$ 的概率，均匀地平铺在 $[0, 1) \cup (1, 2]$ 这个总长度为 $2$ 的区间上。
2. **怎么分段？**：因为 $x=1$ 有一个集中的概率点，尺子从左往右扫的时候，在跨过 $1$ 的瞬间会发生概率的“突变（跳跃）”。所以 $x$ 的范围必须以 $0, 1, 2$ 为界，分成**四段**讨论！

**【应试标准解答】**
由题意，总区间长度为 $2$，连续部分的总概率为 $P\{X \neq 1\} = 1 - \frac{1}{3} = \frac{2}{3}$。
* **当 $x < 0$ 时**：$F(x) = 0$。
* **当 $0 \le x < 1$ 时**：尺子还没扫到点 $1$，只扫了连续区间 $[0, x]$。
  $$F(x) = P\{0 \le X \le x\} = P\{X \neq 1\} \cdot P\{0 \le X \le x \mid X \neq 1\} = \frac{2}{3} \cdot \frac{x - 0}{2} = \frac{x}{3}$$
* **当 $1 \le x < 2$ 时**：尺子扫过了点 $1$！所以要把点 $1$ 的概率加上。
  $$F(x) = P\{X = 1\} + P\{0 \le X \le x, X \neq 1\} = \frac{1}{3} + \frac{2}{3} \cdot \frac{x - 0}{2} = \frac{x + 1}{3}$$
* **当 $x \ge 2$ 时**：$F(x) = 1$。

*(自我检查：在 $x=1$ 处，右极限 $\frac{2}{3}$ 减去左极限 $\frac{1}{3}$ 等于 $\frac{1}{3}$，刚好是 $P\{X=1\}$，完美！)*

### 变式二：条件概率换成“非均匀分布”（考验推广能力）

**【题目】**
设随机变量 $X \ge 0$，且 $P\{X = 0\} = \frac{1}{4}$。在事件 $\{X > 0\}$ 发生的条件下，$X$ 服从参数为 $\lambda = 2$ 的指数分布。试求 $X$ 的分布函数 $F(x)$。

**【思考切入点】**
这道题把“与长度成正比（均匀分布）”直接换成了“指数分布”，区间也变成了无穷区间 $[0, +\infty)$，但**套路一模一样**！
1. **看数轴分配**：在原点 $x=0$ 处放了 $\frac{1}{4}$ 的概率；剩下的 $1 - \frac{1}{4} = \frac{3}{4}$ 的概率，按照指数分布的规律铺在 $(0, +\infty)$ 上。
2. **套乘法公式**：只要 $x \ge 0$，就把 $\{X \le x\}$ 拆成 $\{X = 0\}$ 和 $\{0 < X \le x\}$。

**【应试标准解答】**
已知 $P\{X > 0\} = 1 - P\{X = 0\} = \frac{3}{4}$。
* **当 $x < 0$ 时**：$F(x) = 0$。
* **当 $x \ge 0$ 时**：
  $$F(x) = P\{X \le x\} = P\{X = 0\} + P\{0 < X \le x\}$$
  利用乘法公式：
  $$P\{0 < X \le x\} = P\{X > 0\} \cdot P\{0 < X \le x \mid X > 0\}$$
  因为条件下服从 $E(2)$，直接背出指数分布的分布函数公式：$P\{0 < X \le x \mid X > 0\} = 1 - e^{-2x}$。
  代入得：
  $$F(x) = \frac{1}{4} + \frac{3}{4}(1 - e^{-2x}) = 1 - \frac{3}{4}e^{-2x}$$

---

### 变式三：考研真题常见包装——“削顶/截尾”模型（混合分布的生成）

*(注：这是数一非常喜欢考的**随机变量函数的分布**，本质就是咱们上面做的题！)*

**【题目】**
设随机变量 $X$ 在 $[-1, 2]$ 上服从均匀分布，现定义一个新的随机变量 $Y = \begin{cases} 0, & X \le 0 \\ X, & X > 0 \end{cases}$。试求 $Y$ 的分布函数 $F_Y(y)$。

**【思考切入点】**
1. **理解物理/空间意义**：$X$ 本来把 $1$ 的概率均匀铺在 $[-1, 2]$（长度 3）上。现在规定：只要 $X \le 0$，$Y$ 就统统变成 $0$。
   这相当于**拿一把铲子，把 $[-1, 0]$ 这一段上的所有概率，全部铲起来堆到了 $y = 0$ 这一个点上！** 而在 $(0, 2]$ 区间上，概率保持原来的均匀平铺不变。
2. **转化为原题**：
   * 堆在 $y=0$ 处的概率是多少？就是原来 $X$ 落在 $[-1, 0]$ 的概率：$P\{Y = 0\} = P\{-1 \le X \le 0\} = \frac{0 - (-1)}{2 - (-1)} = \frac{1}{3}$。
   * 剩下的 $(0, 2]$ 区间上，$Y$ 就是 $X$，概率与长度成正比。

**【应试标准解答】**
* **当 $y < 0$ 时**：因为 $Y$ 最小就是 $0$，所以 $F_Y(y) = 0$。
* **当 $0 \le y < 2$ 时**：
  $$F_Y(y) = P\{Y \le y\} = P\{Y = 0\} + P\{0 < Y \le y\}$$
  将 $Y$ 还原为 $X$ 的事件：
  $$F_Y(y) = P\{X \le 0\} + P\{0 < X \le y\} = P\{X \le y\}$$
  因为 $X \sim U(-1, 2)$，直接算长度比：
  $$F_Y(y) = \frac{y - (-1)}{2 - (-1)} = \frac{y + 1}{3}$$
* **当 $y \ge 2$ 时**：$F_Y(y) = 1$。

---

### 助教总结
做完这三道题你会发现，不管外衣怎么换（均匀分布、指数分布、还是截尾函数），**核心动作永远只有两个**：
1. 在数轴上找到**哪个点被单独塞了概率**（离散点），以这个点为界去分段。
2. 求 $F(x)$ 时，只要跨过了这个点，就写成 **“点概率 + 区间概率”**，区间概率直接用条件概率乘法公式（或原本的连续分布）算出来即可。
