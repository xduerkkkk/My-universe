# 独立
![[_attachments/image/概率1-1791685108863.jpeg]]

* **若题干明确说明“$X, Y$ 相互独立”**（占 99% 的考题）：
  * **坚决取反**！把“或”变成“且”，凑出 $P(AB) = P(A)P(B)$ 拆成乘积算。
* **若题干【完全不提独立性】，且同时出现了 $\max$ 与 $\min$**（本题这种冷门技巧）：
  * **绝不能取反成另一种符号**，必须用**容斥加法公式** $P(A \cup B) = P(A) + P(B) - P(AB)$，把无法拆开的未知的联合项直接整体代换掉！

“上半”

考研数一中，计算 **$E(|U - V|)$（两个独立同分布于 $U[0, L]$ 的随机变量之差的绝对值）** 属于可以当作结论直接秒杀的模型：

- **模型本质**：在长度为 $L$ 的线段上，独立随机扔两个点 $U$ 和 $V$。
- **对称性结论**：这两个点将整个区间 $[0, L]$ 截成了 **3 段**：
  1. 第一段：$[0, \min(U,V)]$
  2. 第二段（中间段）：$[\min(U,V), \max(U,V)]$，其长度即为 $|U - V|$
  3. 第三段：$[\max(U,V), L]$
- **期望均分原理**：由于在区间内均匀撒点，这 3 段线段在统计上的地位是完全平等的，因此它们的**平均长度（数学期望）完全相等**：
  $E(\text{任意一段}) = \frac{\text{区间总长}}{\text{被分成的段数}} = \frac{L}{3}$

在本题中，区间总长 $L = \pi$，被两个点切成 3 段，中间那段长度正是 $|U - V|$，直接写出答案：
$E(X) = E(|U - V|) = \frac{\pi}{3}$

# 抽象分布函数
![[_attachments/image/概率1-1792550545802.jpeg]]

- 理解不到位
  在考场上，**算区间概率千万别去拆成“点概率 + 内部概率”拼凑**，直接背死这四条基本定义公式：$$\begin{aligned}
P\{a < X \le b\} &= F(b) - F(a) \quad (\text{最基本的左开右闭}) \\
P\{a \le X \le b\} &= F(b) - F(a^-) \quad (\text{双闭区间：减去 } a \text{ 的左极限}) \\
P\{a < X < b\} &= F(b^-) - F(a) \quad (\text{双开区间：取 } b \text{ 的左极限}) \\
P\{a \le X < b\} &= F(b^-) - F(a^-)
\end{aligned}$$
考场实战秒杀（看 A 选项）：
A 选项问的是 $P\{0 \le X \le 1\}$（双闭区间）：
$$P\{0 \le X \le 1\} = F(1) - F(0^-)$$
* $F(1) = 1 - e^{-1}$
* $F(0^-) = 0$（看 $x < 0$ 的表达式）
* 两者相减：
  $$P\{0 \le X \le 1\} = (1 - e^{-1}) - 0 = \mathbf{1 - e^{-1}}$$
**5 秒钟，A 直接拿下！根本不用去讨论中间和各点到底发生了什么。**

再看 C 选项验证：
$$P\{0 < X \le 1\} = F(1) - F(0) = (1 - e^{-1}) - \frac{1}{2} \neq 1 - e^{-1} \implies \text{C 错}$$

遇到分段分布函数求概率：
* **包含左端点，就用 $F(a^-)$（左极限）；不包含左端点，就用 $F(a)$。**
* **包含右端点，就用 $F(b)$；不包含右端点，就用 $F(b^-)$（左极限）。**
直接套这个规则做减法，永远不会算错。
