# 齐次线性方程组
- r=n，有唯一零解。此时把矩阵按列视角看，同维映射，映射到 0，只有一个向量能做到。（因为同维映射就是 1 比 1 对应）
- r<n，把高维映射到低维的 0，对应的有高维许多向量。n-r 个线性无关解是？ 举例，3 维映射到二维，有某条线全部映射为 0，所有的解，都可以看作“1 个（3-2 个）”线性无关解的组合（这里是伸缩）... 但 3 维到 1 维我很难想象

基础解系就是，第二种情况下的线性无关向量？
不仅仅是“几个线性无关向量”，而是**极大线性无关组**。刚才那个 3 维到 1 维的例子里，被映射为 0 的是一个平面。你在这个平面上随便找两个不共线（线性无关）的向量 $\xi_1$ 和 $\xi_2$，它们就是基础解系。它们构成了这个平面的“骨架”或“基”。数量必然是 $n-r$ 个。

通解是基础解析的线性组合

### 第一步：化阶梯型矩阵（找“规矩”和“自由人”）

**你在图里看到的：** 矩阵经过一系列加减乘除（初等行变换），变成了带有“阶梯”的样子。非零行有 3 行，所以秩 $r(A) = 3$。

**背后的空间意义：** 原本的矩阵方程看起来乱七八糟，初等行变换的本质是**“换一个更清晰的视角（坐标系）来看这个映射”**。

化成阶梯型后，情况彻底明朗了：

- **找主元（阶梯拐角处的元素）：** 图中的第 1、2、4 列（对应 $x_1, x_2, x_4$）是阶梯的支柱，它们叫**“约束变量”**（或者叫主变量）。它们是被规矩死死限制住的。
    
- **找自由变量（没有台阶的列）：** 图中被红框圈出来的第 3、5 列（对应 $x_3, x_5$），它们头上没有主元压着。它们就是**“自由变量”**。
    

**连接之前的理解：**

5 维空间，秩是 3（保留了 3 个维度的规矩）。$5 - 3 = 2$，说明有 2 个维度被“压扁”了，变成了自由的空间。**这 $n-r=2$ 个自由变量 $x_3, x_5$，就是用来描述那个被压扁的 2 维空间的坐标！** 因为它们自由，所以你可以随便给它们取值。

---

### 第二步：给自由变量赋值（搭建“骨架”）

**你在图里看到的：** * 图 1 中（老师手写），直接给 $x_3, x_5$ 分别赋值 $(1, 0)$ 和 $(0, 1)$。

- 图 2 中（讲义），稍微变了个花样，令 $x_3 = k_1$，$x_5 = 3k_2$（相当于取了 $(1,0)$ 和 $(0,3)$）。
    

**背后的空间意义：**

既然被压扁的解空间是一个 2 维的平面，我们需要找 2 根“骨架”（基础解系）把它撑起来。

怎么保证找出来的两根骨架是**线性无关**（不在一条直线上）的呢？

最简单粗暴、绝不翻车的方法，就是轮流让自由变量取 1 和 0。

- 第一次：让 $x_3=1, x_5=0$。算出第一个解 $\xi_1$。这代表了解空间里的“x 轴方向”。
    
- 第二次：让 $x_3=0, x_5=1$。算出第二个解 $\xi_2$。这代表了解空间里的“y 轴方向”。
    

_(注：图 2 讲义里故意令 $x_5 = 3k_2$，完全是为了**凑整数**，因为矩阵第三行有个 $3x_4 - x_5 = 0$，如果 $x_5$ 取 1，$x_4$ 就是 $1/3$。为了避免写分数，讲义取了 3。这只是计算技巧，本质还是为了得到两个不共线的向量。)_

---

### 第三步：回代求出所有变量（画出完整的骨架）

**你在图里看到的：** 把确定的 $x_3, x_5$ 的值，代回到阶梯型方程里，算出 $x_4, x_2, x_1$。最终写成了两个长长的列向量 $\xi_1$ 和 $\xi_2$。

**背后的空间意义：**

自由变量 $x_3, x_5$ 只是定下了“基调”，但一个完整的 5 维向量必须有 5 个分量。

“回代”的过程，就是**根据那 3 条没被破坏的规矩（非零行方程），把剩下的分量补齐**。

最终得到的 $\xi_1$ 和 $\xi_2$ 就是在这个 5 维空间中，确确实实指向那个被压扁的 2 维平面的两根标准基向量。

---

### 第四步：写出通解（血肉丰满）

**你在图里看到的：** 最后把解写成 $x = k_1\xi_1 + k_2\xi_2$。

**背后的空间意义：**

骨架搭好了。现在，任何一个想要映射为 0 的 5 维向量，都只能在这个由 $\xi_1$ 和 $\xi_2$ 撑起的 2 维平面里活动。

怎么表达这个平面里的所有点？就是把这两根骨架进行**任意的线性组合**（伸长、缩短、反向、相加）。$k_1, k_2$ 就是组合的比例系数。

### 总结打通：

你看，计算步骤里的每一步，都在完美执行我们之前的理论：

1. **化阶梯求秩** $\rightarrow$ 看看到底降了几维，确立自由度（$n-r$）。
    
2. **挑出自由变量** $\rightarrow$ 找到代表这几个自由维度的坐标轴。
    
3. **取 $(1,0)$ 和 $(0,1)$** $\rightarrow$ 强制提取出**线性无关**的基底向量（骨架）。
    
4. **加上常数 $k$ 组合** $\rightarrow$ 用骨架生成整个解空间（通解）。

## 近似解

![](../../../../../assets/image/01笔记-1775099045788.jpeg)1. **画面的基础：** 那个平行四边形，就是矩阵 $A$ 的列向量 $\alpha_1, \alpha_2$ 撑起来的那个平面（纸面）。
    
2. **目标 $b$ 在外面：** 向量 $b$ 斜着指向上方，它不在纸面上。所以原方程 $Ax = b$ 找不到那个 $x$。
    
3. **退而求其次（找投影）：** 既然够不到 $b$，我们在平面上找一个**离 $b$ 最近的点**。怎么找？从 $b$ 向平面作一条**垂线**！
    
4. **垂足 $Ax_0$：** 垂线落在平面上的那个点（垂足），既然在平面上，它一定能被 $A$ 线性表示，我们管这个垂足叫 $Ax_0$。这个 $x_0$ 就是我们要找的“最优解”。
    
5. **垂直（正交）的威力：** 向量 $b$ 减去向量 $Ax_0$，得到的是那条**垂直于平面的误差向量**（图里写的 $b - Ax_0$）。
    
    - 既然它垂直于整个平面，那它必定垂直于平面里的每一根骨架（即 $A$ 的列向量 $\alpha_1, \alpha_2$）。
        
    - 向量垂直 $\iff$ 内积为 0 $\iff$ 转置相乘为 0。
        
    - 所以，$\alpha_1^T(b - Ax_0) = 0$ 且 $\alpha_2^T(b - Ax_0) = 0$。
        
6. **拼成矩阵：** 把 $\alpha_1^T, \alpha_2^T$ 竖着拼起来，就是矩阵 $A^T$。
    
    老师得出了核心等式：
    
    $$A^T(b - Ax_0) = 0$$
    
    把它展开：
    
    $$A^Tb - A^TAx_0 = 0 \implies A^TAx_0 = A^Tb$$
    

**老师想表达的终极意思是：**

不管 $b$ 在不在平面上，你**永远**都可以向平面作一条垂线，找到那个垂足。这就意味着，方程 $A^TAx = A^Tb$ **永远是有解的**（至少有一个解 $x_0$）。所以这题秒选 (B)。

### 答案解析的“代数视角”（秩的夹逼定理）

考试阅卷的时候，如果你写“因为可以作垂线，所以有解”，老师可能不给你满分，因为这不够“代数严谨”。解析给的是纯用“秩（Rank）”来证明的方法。

回到我们第一回合聊的铁律：**判断方程有没有解，就看“系数矩阵的秩”是否等于“增广矩阵的秩”**。

这道题的方程是 $A^TAx = A^Tb$。

- 系数矩阵是 $A^TA$
    
- 增广矩阵是 $[A^TA, A^Tb]$
    

解析的目标就是要证明：**$r(A^TA) = r([A^TA, A^Tb])$**。它是怎么证的呢？用“夹击”：

1. **一个核心前置定理（记住它）：** $r(A) = r(A^TA) = r(A^T)$。矩阵自己、转置、以及它俩相乘，这三者的秩永远相等。（这是线代里的一个硬核定理）。
    
2. **看增广矩阵的右半边：** 解析巧妙地把增广矩阵提了一个 $A^T$ 出来：
    
    $$[A^TA, A^Tb] = A^T[A, b]$$
    
3. **利用矩阵乘法的性质：** 两个矩阵相乘，秩不会变大，即 $r(XY) \le r(X)$。
    
    所以：$r(A^T[A, b]) \le r(A^T)$。
    
    因为 $r(A^T) = r(A) = r(A^TA)$，所以我们得到：
    
    **$r([A^TA, A^Tb]) \le r(A^TA)$** （这说明增广矩阵的秩没有变大）
    
4. **反向逻辑：** 另一方面，系数矩阵 $A^TA$ 只是增广矩阵 $[A^TA, A^Tb]$ 的一部分（左半边）。你加了一列进去，秩**不可能变小**。
    
    所以：**$r(A^TA) \le r([A^TA, A^Tb])$**
    
5. **得出结论：** 既要 $\le$，又要 $\ge$，那只能是**相等**！
    
    $$r(A^TA) = r([A^TA, A^Tb])$$
    
    既然秩相等，根据“拼矩阵”的铁律，方程**必有解**。

# 公共解
![](../../../../../assets/image/01笔记-1775101773883.jpeg)
情况 ①已知 A 的骨架和 B 的具体长相

**写出 A 公司的所有人：** 用 A 的基础解系写出它的通解 $x = k_1\xi_1 + k_2\xi_2 + \dots + k_s\xi_s$。这个 $x$ 此时代表了 A 解空间里的**任意**一个点。
    
- **让他们考 B 的卷子（代入 $Bx=0$）：** 把这串东西塞进 $B$ 里：$B(k_1\xi_1 + k_2\xi_2 + \dots + k_s\xi_s) = 0$。
    
    把括号拆开，就变成了：$k_1(B\xi_1) + k_2(B\xi_2) + \dots + k_s(B\xi_s) = 0$。
    
    _注意：因为 $B$ 是具体的矩阵，$\xi$ 是具体的列向量，所以 $B\xi_1, B\xi_2$ 算出来就是几个具体的实数向量！_
    
- **求出 $k$ 之间的限制关系：** 算到这一步，实际上变成了一个关于 $k_1, k_2, \dots$ 的新方程组。
    
    **重点看老师下面手写的这部分：** 假设你解出 $k_2 = -k_1$, $k_3 = 2k_1$。这意味着什么？意味着原本 $k_1, k_2, k_3$ 是 3 个自由飞翔的变量（3 维空间），现在为了满足 B 的条件，它们被死死限制住了，只剩 $k_1$ 一个自由人了。
    
- **回代，找到真正的公共骨架：**
    
    把 $k_2, k_3$ 替换掉，放回原来的通解里：
    
    $x = k_1\xi_1 + (-k_1)\xi_2 + (2k_1)\xi_3 = k_1(\xi_1 - \xi_2 + 2\xi_3)$。
    
    看到了吗？这就是老师最下面那个大黑框圈起来的 $\xi$！原本 A 有 3 根骨架，经过 B 的筛选后，组合成了 **1 根新的终极骨架 $(\xi_1 - \xi_2 + 2\xi_3)$**，它代表的就是公共解空间！

情况 ②已知 A 的骨架和 B 的骨架
1. **两头表示同一个人 $\gamma$：** 左边用 A 的骨架拼：$\gamma = k_1\xi_1 + k_2\xi_2 + \dots + k_s\xi_s$
    
    右边用 B 的骨架拼：$\gamma = l_1\eta_1 + l_2\eta_2 + \dots + l_t\eta_t$
    
    因为是同一个人，所以它们**必须相等**！
    
2. **移项，变成一个巨大的齐次方程组：**
    
    把带 $l$ 的那一坨全部移到左边：
    
    $k_1\xi_1 + \dots + k_s\xi_s - l_1\eta_1 - \dots - l_t\eta_t = 0$
    
    这其实就是一个以 $[\xi_1, \dots, \xi_s, -\eta_1, \dots, -\eta_t]$ 为列向量拼成的**大矩阵**，乘以系数向量 $[k_1, \dots, k_s, l_1, \dots, l_t]^T = 0$ 的方程！
    
3. **解这个大方程：**
    
    对这个大矩阵做初等行变换，求出 $k$ 和 $l$ 的关系。一旦你解出了具体的 $k_1, k_2 \dots$（比如解出 $k_1 = c$），把它代回到左边的 $\gamma = k_1\xi_1 + \dots$ 中，算出来的那个具体的向量，就是公共解。
    

**总结一下老师的意思：**

求公共解，核心就是**“代入”和“设等式”**。

- 有具体矩阵 B，就把 A 的通解当成 $x$ **代入** B 的方程里，去求系数 $k$ 的限制条件。
    
- 只有两边的骨架，就把它们生成的通解**设相等**，强行构造出一个新的大方程组去解。
