### 1. $n$ 次方差与和的展开公式 ($a^n \pm b^n$)

这是考研中最常碰到的代数变形，尤其在求极限和矩阵运算中。

**公式：**

- **$n$ 次方差（对所有正整数 $n$ 都成立）：**
    
    $$a^n - b^n = (a - b)(a^{n-1} + a^{n-2}b + a^{n-3}b^2 + \cdots + ab^{n-2} + b^{n-1})$$
    
- **$n$ 次方和（仅当 $n$ 为奇数时成立）：**
    
    $$a^n + b^n = (a + b)(a^{n-1} - a^{n-2}b + a^{n-3}b^2 - \cdots - ab^{n-2} + b^{n-1})$$
    
    _(注意：第二项开始，符号是正负交替的)_
    

**原理讲解：**

这两个公式的本质其实是**等比数列求和**的逆运算。

我们来看等比数列求和公式：$S = 1 + q + q^2 + \cdots + q^{n-1}$。

如果在等式两边同乘 $(1 - q)$，利用“错位相减”的思想，中间项会全部抵消，最后只剩下：

$$(1 - q)(1 + q + q^2 + \cdots + q^{n-1}) = 1 - q^n$$

现在，我们把 $q$ 换成 $\frac{b}{a}$，并在等式两边同乘 $a^n$，立刻就能得到 $a^n - b^n$ 的展开式！

对于 $a^n + b^n$，只需要在 $n$ 为奇数时，把 $b$ 替换成 $-b$，即可推出和的公式（因为当 $n$ 为奇数时，$(-b)^n = -b^n$）。

**考研应用场景：**

- **高数（求极限）：** 遇到形如 $\lim_{x \to 1} \frac{x^n - 1}{x - 1}$ 的问题，直接展开分子约分。
    
- **线代（矩阵多项式）：** 证明矩阵的幂次，例如已知 $A^3 = E$（即 $A^3 - E = 0$），可以通过 $(A - E)(A^2 + A + E) = 0$ 来寻找特征值或逆矩阵。

### 2. 二项式定理 (Binomial Theorem)

这是概率论（二项分布）和高数（高阶导数）的绝对核心。

**公式：**

$$(a + b)^n = \sum_{k=0}^{n} C_n^k a^{n-k} b^k = C_n^0 a^n + C_n^1 a^{n-1}b + C_n^2 a^{n-2}b^2 + \cdots + C_n^n b^n$$

其中组合数 $C_n^k = \frac{n!}{k!(n-k)!}$。

**原理讲解：**

原理是**组合数学中的乘法原理**。

$(a+b)^n$ 等于 $n$ 个 $(a+b)$ 连乘：$(a+b)(a+b)\cdots(a+b)$。

展开的过程中，我们需要从这 $n$ 个括号中，每次挑出一个字母相乘。如果我们从其中 $k$ 个括号里挑出了 $b$，那么剩下的 $(n-k)$ 个括号里必然挑出的是 $a$，乘积就是 $a^{n-k}b^k$。

那么，“从 $n$ 个括号里挑出 $k$ 个括号给 $b$” 共有多少种挑法呢？正好是组合数 $C_n^k$ 种。这就是为什么每一项前面都有一个 $C_n^k$ 作为系数。

**考研应用场景：**

- **高数（莱布尼茨公式）：** 求两个函数乘积的高阶导数 $(uv)^{(n)}$，公式结构与二项式定理完全一致，只是把指数换成了求导阶数。
    
- **线代（矩阵的幂）：** 如果要求 $(A+B)^n$，当且仅当 **$AB = BA$（矩阵可交换）**时，可以直接套用二项式定理。考研常考让 $B$ 为一个幂零矩阵（比如 $B^3=0$），这样展开后后面的项全为零，大大简化计算。

### 3. 等比数列求和极限 (无穷递缩等比数列)

在考查“幂级数”（无穷级数）时，这是最基础的母函数。

**公式：**

当 $|q| < 1$ 时，

$$\sum_{n=0}^{\infty} aq^n = a + aq + aq^2 + \cdots = \frac{a}{1 - q}$$

**原理讲解：**

有限项的等比数列求和是 $S_n = \frac{a(1 - q^n)}{1 - q}$。

当 $|q| < 1$（即 $q$ 是个真分数）且 $n \to \infty$ 时，$q^n$ 会无限趋近于 0。因此分子上的 $q^n$ 消失了，极限结果就变成了非常简洁的 $\frac{a}{1 - q}$。

**考研应用场景：**

- **高数（幂级数展开与求和）：** 考研要求把复杂函数展开成幂级数，或者求幂级数的和函数。几乎所有题目最终都会通过求导或积分，转化为 $\frac{1}{1-x} = \sum_{n=0}^{\infty} x^n$ 这一基本形式来求解。

### 4. 重点三角恒等变形（降幂与和差化积）

很多同学高数积分积不出，不是因为微积分没学好，而是三角公式忘了。不需要全背，但**降幂公式**和**积化和差**必记。

**核心公式：**

- **降幂公式（极高频）：**
    
    $$\sin^2 x = \frac{1 - \cos 2x}{2}, \quad \cos^2 x = \frac{1 + \cos 2x}{2}$$
    
- **积化和差（考不定积分时常用）：**
    
    $$\sin A \cos B = \frac{1}{2}[\sin(A+B) + \sin(A-B)]$$
    

**原理讲解：**

- **降幂公式**来源于余弦的二倍角公式：$\cos 2x = \cos^2 x - \sin^2 x$。联立 $\sin^2 x + \cos^2 x = 1$，即可解出 $\sin^2 x$ 和 $\cos^2 x$。它的伟大之处在于**把“二次方”降维成了“一次方”**。
    
- **积化和差**来源于正弦/余弦的和差角公式展开（如 $\sin(A+B) = \sin A \cos B + \cos A \sin B$）。将两式相加减即可得出。
    

**考研应用场景：**

- **高数（积分）：** 在计算 $\int \sin^2 x dx$ 时，直接积是做不出的，必须用降幂公式转化为一阶的 $\cos 2x$ 才能积分。计算 $\int \sin 3x \cos 5x dx$ 时，必须用积化和差拆开成两个独立的正弦函数。
