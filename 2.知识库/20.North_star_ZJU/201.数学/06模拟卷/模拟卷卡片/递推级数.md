### 一、第一步：一眼看穿 $\{u_n\}$ 的真面目（高数第一章常识）

看到递推式 $u_0 = 0, \; u_{n+1} = \sqrt{2 + u_n}$：
1. 代前两项：$u_1 = \sqrt{2}, \; u_2 = \sqrt{2 + \sqrt{2}}$，明显**单调递增**；
2. 极限是多少？令 $A = \sqrt{2 + A} \implies A^2 - A - 2 = 0 \implies \boldsymbol{A = 2}$！
3. 所以 $u_n$ 是**从 0 单调递增趋向于 2** 的（即 $0 \le u_n < 2$，且 $\lim_{n \to \infty} u_n = 2$）。

*(顺手一瞥：既然 $u_n \uparrow 2$，那么根号里的 $2 - u_n \downarrow 0$，即通项 $\sqrt{2 - u_n}$ 单调递减趋于 0！根据莱布尼茨准则，这个交错级数**至少是收敛的**！现在唯一的问题就是：加了绝对值后，正项级数 $\sum \sqrt{2 - u_n}$ 收不收敛？即是不是**绝对收敛**？)*

### 二、第二步：用我们今天学的“两项递推算比值”直接秒杀！

为了判断正项级数 $\sum \sqrt{2 - u_n}$ 收不收敛，我们把整个根号记作 **$a_n = \sqrt{2 - u_n}$**。
根据我们今天总结的铁律：**给了两项递推式，判正项级数敛散性，直接算后一项比前一项的极限 $\lim_{n \to \infty} \frac{a_{n+1}}{a_n}$！**

把 $\frac{a_{n+1}}{a_n}$ 写出来，并把题目给的 $u_{n+1} = \sqrt{2 + u_n}$ 往分子里代：
$$\frac{a_{n+1}}{a_n} = \frac{\sqrt{2 - u_{n+1}}}{\sqrt{2 - u_n}} = \sqrt{\frac{2 - \sqrt{2 + u_n}}{2 - u_n}}$$

**【高能时刻：初中数学“平方差有理化”！】**
看着分子上的 $2 - \sqrt{2 + u_n}$，怎么把讨厌的根号消掉？
分子分母同时乘以 **$2 + \sqrt{2 + u_n}$**！
那么分子就变成了平方差：$2^2 - \left(\sqrt{2 + u_n}\right)^2 = 4 - (2 + u_n) = \boldsymbol{2 - u_n}$！
**居然和分母的 $(2 - u_n)$ 一模一样，直接约掉了！**

你看化简后的式子有多漂亮：
$$\frac{a_{n+1}}{a_n} = \sqrt{\frac{2 - u_n}{(2 - u_n)\left(2 + \sqrt{2 + u_n}\right)}} = \sqrt{\frac{1}{2 + \sqrt{2 + u_n}}}$$

现在，直接让 $n \to \infty$（记得第一步算出的 $\lim_{n \to \infty} u_n = 2$ 吗？往里代！）：
$$\lim_{n \to \infty} \frac{a_{n+1}}{a_n} = \sqrt{\frac{1}{2 + \sqrt{2 + 2}}} = \sqrt{\frac{1}{2 + 2}} = \sqrt{\frac{1}{4}} = \boldsymbol{\frac{1}{2} < 1}$$

**后一项比前一项的极限等于 $\frac{1}{2} < 1$！**
根据比值审敛法，加绝对值后的正项级数 $\sum \sqrt{2 - u_n}$ **收敛**！
所以原级数 **绝对收敛**！

### 三、还有没有更装逼、更快的“三角换元秒杀法”？（5 秒看穿本质）

如果你对三角函数的半角公式敏感，看到 $\sqrt{2 + u_n}$ 和 $\sqrt{2 - u_n}$，可以利用 $\cos 0 = 1$ 和半角公式 $\sqrt{\frac{1 + \cos \theta}{2}} = \cos \frac{\theta}{2}$：
*   $u_0 = 0 = 2 \cos \frac{\pi}{2}$
*   $u_1 = \sqrt{2} = 2 \cos \frac{\pi}{2^2}$
*   $u_2 = \sqrt{2 + \sqrt{2}} = 2 \cos \frac{\pi}{2^3}$
*   以此类推，直接写出通项：**$u_n = 2 \cos \frac{\pi}{2^{n+1}}$**！

代进目标通项 $\sqrt{2 - u_n}$（用半角公式 $1 - \cos \theta = 2 \sin^2 \frac{\theta}{2}$）：
$$\sqrt{2 - u_n} = \sqrt{2\left(1 - \cos \frac{\pi}{2^{n+1}}\right)} = 2 \sin \frac{\pi}{2^{n+2}} \sim \frac{\pi}{2^{n+1}}$$
它居然就是一个公比为 **$\frac{1}{2}$** 的等比级数！当然**绝对收敛**！

### 四、这道题你应该总结出什么条件反射？

不用管三角换元（那是技巧），你只需要记住**正面硬刚的通法条件反射**：
1. 看到递推式 $u_{n+1} = f(u_n)$（设极限为 $A$，本题 $A=2$），且级数通项里含有 **$|A - u_n|$**（本题是 $\sqrt{2 - u_n}$）；
2. **第一反应永远是算比值极限 $\lim_{n \to \infty} \left|\frac{A - u_{n+1}}{A - u_n}\right|$**！
   *   把 $u_{n+1} = f(u_n)$ 代入分子，有根号就**分子有理化**，没根号就用**拉格朗日中值定理（或洛必达/导数定义）**，分子分母的 $(A - u_n)$ 100% 会直接约掉，算出来的极限就是导数 $|f'(A)|$（或它的开方）！
   *   只要这个比值极限 $< 1$，级数就直接**绝对收敛**！

# 例题

来！专门针对刚才总结的**“递推式 $u_{n+1} = f(u_n)$ 判级数敛散性（或求收敛半径）”**，给你出 **3 道考研最核心的同类型例题**。

在做之前，先把我们刚提炼出的**“黄金秒杀定理”**亮出来：
如果 $u_{n+1} = f(u_n)$，且 $\lim_{n \to \infty} u_n = A$（其中 $A = f(A)$），那么当 $n \to \infty$ 时，后一项与极限的距离，比上前一项与极限的距离：
$$\lim_{n \to \infty} \frac{u_{n+1} - A}{u_n - A} = \lim_{n \to \infty} \frac{f(u_n) - f(A)}{u_n - A} = \boldsymbol{f'(A)} \quad (\text{这就是导数的定义！})$$
*   **如果 $|f'(A)| < 1$（且不为 0）**：说明比值极限 $<1$，$\sum |u_n - A|$ 直接**绝对收敛**（若用来求幂级数 $\sum (u_n - A) x^n$ 的收敛半径，则 $R = \frac{1}{|f'(A)|}$）！
*   **如果 $f'(A) = 1$**：比值法失效（此时 $u_n$ 衰减极慢，通常是 $\frac{1}{n}$ 级别），ต้อง用我们前面讲的**“做差裂项法”**！

### 【例题区】（试着用上面的比值法/导数法做一下，答案在下面）

*   **【例 1】（无根号分式递推：通法练手）**
    设 $u_1 = 1, \; u_{n+1} = \frac{2 + u_n}{1 + u_n} \; (n=1,2,\cdots)$，判断级数 $\sum_{n=1}^{\infty} (u_n - \sqrt{2})$ 的敛散性（绝对收敛、条件收敛还是发散？），并求幂级数 $\sum_{n=1}^{\infty} (u_n - \sqrt{2}) x^n$ 的收敛半径 $R$。

*   **【例 2】（超越函数递推：$f'(A) < 1$ 一眼秒杀）**
    设 $u_1 = 1, \; u_{n+1} = \ln(1 + u_n)$，判断级数 $\sum_{n=1}^{\infty} \sin u_n$？（不对，改考更经典的）：
    设 $u_1 = 1, \; u_{n+1} = \frac{1}{2}\sin u_n$，判断级数 $\sum_{n=1}^{\infty} (-1)^n u_n$ 的敛散性，并求 $\sum_{n=1}^{\infty} u_n x^n$ 的收敛半径 $R$。

*   **【例 3】（高能预警：$f'(A) = 1$ 比值法失效，触发“裂项桥”！）**
    设 $u_1 = 1, \; u_{n+1} = \sin u_n$（注意前面没有 $\frac{1}{2}$ 了！），判断级数 $\sum_{n=1}^{\infty} u_n^3$ 与 $\sum_{n=1}^{\infty} u_n$ 的敛散性。

### 【标准规范答案与解析】

#### 【例 1】解析（比值通分法 / 导数秒杀法）
1. **看极限 $A$**：解 $A = \frac{2+A}{1+A} \implies A^2 = 2 \implies A = \sqrt{2}$。
2. **算比值极限 $\lim_{n \to \infty} \left|\frac{u_{n+1} - \sqrt{2}}{u_n - \sqrt{2}}\right|$**：
   *   **方法一（考场大题代数通分）**：
       $$u_{n+1} - \sqrt{2} = \frac{2 + u_n}{1 + u_n} - \sqrt{2} = \frac{2 + u_n - \sqrt{2} - \sqrt{2}u_n}{1 + u_n} = \frac{(1 - \sqrt{2})(u_n - \sqrt{2})}{1 + u_n}$$
       把 $(u_n - \sqrt{2})$ 除过去取绝对值极限（代入 $u_n \to \sqrt{2}$）：
       $$\lim_{n \to \infty} \left|\frac{u_{n+1} - \sqrt{2}}{u_n - \sqrt{2}}\right| = \lim_{n \to \infty} \frac{\sqrt{2} - 1}{1 + u_n} = \frac{\sqrt{2} - 1}{\sqrt{2} + 1} = (\sqrt{2} - 1)^2 < 1$$
   *   **方法二（小题导数公式 3 秒秒杀）**：
       令 $f(x) = \frac{2+x}{1+x} = 1 + \frac{1}{1+x}$，则 $|f'(\sqrt{2})| = \frac{1}{(1+\sqrt{2})^2} = (\sqrt{2}-1)^2 < 1$。
3. **结论**：
   因为加绝对值后的比值极限为 $(\sqrt{2}-1)^2 < 1$，故级数 $\sum (u_n - \sqrt{2})$ **绝对收敛**！
   幂级数的收敛半径为比值极限的倒数：$R = \frac{1}{(\sqrt{2}-1)^2} = (\sqrt{2}+1)^2 = 3 + 2\sqrt{2}$。

---

#### 【例 2】解析（极限 $A = 0$ 的标准模型）
1. **看极限 $A$**：由 $0 < u_{n+1} = \frac{1}{2}\sin u_n < \frac{1}{2}u_n$，易知 $\lim_{n \to \infty} u_n = 0$（这里 $A=0$，所以 $|u_n - A|$ 就是 $u_n$ 本身！）。
2. **算比值极限 $\lim_{n \to \infty} \frac{u_{n+1}}{u_n}$**：
   $$\lim_{n \to \infty} \frac{u_{n+1}}{u_n} = \lim_{n \to \infty} \frac{\frac{1}{2}\sin u_n}{u_n} = \frac{1}{2} \cdot 1 = \frac{1}{2} < 1$$
   *(因为 $u_n \to 0$，所以 $\frac{\sin u_n}{u_n} \to 1$)*。
3. **结论**：
   正项级数 $\sum u_n$ 的后一项比前一项极限为 $\frac{1}{2} < 1$，故原交错级数 $\sum (-1)^n u_n$ **绝对收敛**！
   幂级数 $\sum u_n x^n$ 的收敛半径 $R = \lim_{n \to \infty} \frac{u_n}{u_{n+1}} = 2$。

---

#### 【例 3】解析（当比值极限 $=1$ 时，如何联动我们今天学的“裂项桥”！）
1. **先试比值法**：
   这里 $u_n \downarrow 0$，但如果你算比值：$\lim_{n \to \infty} \frac{u_{n+1}}{u_n} = \lim_{n \to \infty} \frac{\sin u_n}{u_n} = \boldsymbol{1}$！
   **比值极限等于 1，比值法失效！**
2. **立刻切换我们今天在【7.19】总结的“数项与级数联动法（做差裂项桥）”！**
   因为 $u_{n+1} = \sin u_n$，且 $u_n \to 0$，我们用泰勒展开把 $\sin u_n$ 展开到三次方：
   $$u_{n+1} = \sin u_n = u_n - \frac{1}{6}u_n^3 + o(u_n^3)$$
   移项湊出**相邻两项的差 $u_n - u_{n+1}$**：
   $$u_n - u_{n+1} = \frac{1}{6}u_n^3 + o(u_n^3) \implies \lim_{n \to \infty} \frac{u_n - u_{n+1}}{u_n^3} = \frac{1}{6}$$
   **看到了吗？！这完全回到了我们今天讲的【7.19】蓝框核心结论！**
   *   因为数列 $\{u_n\}$ 收敛（极限为 0），所以裂项级数 $\sum (u_n - u_{n+1})$ **必收敛**！
   *   而 $u_n^3$ 与 $(u_n - u_{n+1})$ 是同阶无穷小（比值极限为 $\frac{1}{6}$），由正项级数比较审敛法知：**$\sum u_n^3$ 必收敛**！
   *   *(至于 $\sum u_n$，通过 $\frac{1}{u_{n+1}^2} - \frac{1}{u_n^2} \to \frac{1}{3}$ 施笃兹定理可知 $u_n \sim \sqrt{\frac{3}{n}}$，所以 $\sum u_n$ **发散**)*。

### 终极复盘：今天这两大招是怎么无缝衔接的？
遇到递推式 $u_{n+1} = f(u_n)$（极限为 $A$）：
1. **先算比值 $\lim \left|\frac{u_{n+1}-A}{u_n-A}\right| = |f'(A)|$**：只要它 $<1$，直接按等比级数秒杀（绝对收敛）！
2. **万一算出来 $|f'(A)| = 1$（比值法失效）**：直接把 $f(u_n)$ 泰勒展开，移项做出 **$u_{n+1} - u_n$**，瞬间接上【7.19】的裂项桥 $\sum (u_{n+1} - u_n)$ 秒杀！
