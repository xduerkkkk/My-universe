### 第一步：隐含的维度规律（大空间与小空间）

已知 $A_{m \times n} B_{n \times m} = E_m$。

单位矩阵 $E_m$ 的秩是 $m$。根据矩阵乘法的秩不等式 $r(AB) \le \min(r(A), r(B))$，我们可以得出：

- $m \le r(A) \le \min(m, n)$
    
- $m \le r(B) \le \min(n, m)$
    

这就强制要求 **$m \le n$**。

为了方便几何想象，我们假设 $m=2$（二维平面，小空间），$n=3$（三维立体，大空间）。

### 第二步：解构矩阵 B 的几何意义（“升维”与单射）

矩阵 $B$ 的维度是 $n \times m$（比如 $3 \times 2$）。它的作用是把向量从 $\mathbb{R}^m$ 映射到 $\mathbb{R}^n$（把二维平面的向量，搬到三维空间里）。

- **代数推导：** 前面算出 $r(B) = m$（列满秩）。
    
- **几何图像：** $B$ 的列向量是线性无关的。这意味着 $B$ 把二维平面“原封不动”地、不发生任何折叠地放进了一个三维空间里，形成了一个倾斜的二维平面（即 $B$ 的列空间）。
    
- **解的意义：** 因为没有折叠，所以不可能有两个不同的二维向量被映射到三维空间中的同一点。特别地，除了原点自己，没有任何非零向量会被映射到原点。
    
- **结论：** 方程组 $BX = 0$ **仅有零解**。由于它只是三维空间中的一个薄片（不占满三维），所以随便在三维空间找个点 $\beta$，$BX = \beta$ 大概率是**无解**的（除非 $\beta$ 刚好落在那个薄片上）。
    

### 第三步：解构矩阵 A 的几何意义（“降维”与满射）

矩阵 $A$ 的维度是 $m \times n$（比如 $2 \times 3$）。它的作用是把向量从 $\mathbb{R}^n$ 映射回 $\mathbb{R}^m$（把三维空间的点，投影回二维平面）。

- **代数推导：** 前面算出 $r(A) = m$（行满秩）。
    
- **几何图像：** $AB = E$ 这个等式就像是一个完整的“旅行”。你从二维平面的点 $X$ 出发，被 $B$ 搬到了三维空间变成了 $BX$。然后，矩阵 $A$ 出手了，它把 $BX$ 这个三维点，**完美地、精准地投影回了最初的起点 $X$**。
    
- **解的意义：** 既然 $A$ 能够把 $B$ 创造的三维斜面完美投影覆盖整个二维平面（因为 $A(BX) = X$ 对所有二维向量 $X$ 都成立），说明 $A$ 的投影“火力”覆盖了整个目标空间 $\mathbb{R}^m$。
    
- **结论：** 无论你在目标平面上随便指一个目标 $\alpha$，总能找到三维空间里的点（至少是那个被 $B$ 搬过去对应的点）投影过来击中它。因此，方程组 $AX = \alpha$ **必然有解**。（不仅有解，因为是从高维往低维压，通常是有无穷多解，所以选“有唯一解”的 A 选项错误）。
    

---

### 总结选项分析

- **A 错误：** $A$ 把高维向低维压缩，必然会把很多点压到同一个位置，所以 $AX=\alpha$ 通常是无穷多解，不可能唯一。
    
- **B 错误：** $\beta$ 如果不在 $B$ 的列空间（那个三维里的二维薄片）里，$BX=\beta$ 直接无解，不可能有无穷多解。
    
- **C 错误：** $A$ 把高维向低维压缩，必定存在非零的三维向量被直接垂直投影到二维的原点上（即核空间/零空间不只有 0），所以 $AX=0$ 有非零解。
    
- **D 正确：** $A$ 覆盖全场（满射），所以 $AX=\alpha$ **必有解**；$B$ 一一对应不重叠（单射），所以 $BX=0$ **仅有零解**。

### 1. 核心思想：什么是“公共解”？

既然是公共解，也就是某个向量 x，它既满足方程组 ①，又满足方程组 ②。

- 因为它满足 ①，所以它一定可以由 ① 的基础解系（α1​,α2​）线性表出，也就是：x=k1​α1​+k2​α2​。
    
- 因为它满足 ②，所以它也一定可以由 ② 的基础解系（β1​,β2​）线性表出，也就是：x=l1​β1​+l2​β2​。
    

### 2. 建立等式（搭桥）

既然这两个式子表达的是同一个向量 x，那它们必然相等。于是就有了注里的第一句话：

k1​α1​+k2​α2​=l1​β1​+l2​β2​

为了解这个方程，我们把带有未知数（k1​, k2​, l1​, l2​）的项全部移到等号左边：

k1​α1​+k2​α2​−l1​β1​−l2​β2​=0

### 3. 把向量展开成具体的方程组

现在，把你在第 (I) 问求出来的具体向量代进去：

- α1​=(−1,1,0,1) T
    
- α2​=(0,0,1,0) T
    
- β1​=(0,1,1,0) T
    
- β2​=(−1,−1,0,1) T
    

按照分量把上面的等式展开，就会得到一个全新的含有 4 个未知数（k1​, k2​, l1​, l2​）的齐次线性方程组（就是注里那个带大括号的方程组）：

- 第一个分量：−k1​+0⋅k2​−0⋅l1​−(−1) l2​=0⟹−k1​+l2​=0
    
- 第二个分量：k1​+0⋅k2​−l1​−(−1) l2​=0⟹k1​−l1​+l2​=0
    
- （以此类推...）
    

### 4. 求解系数关系并回代

解这个关于 k, l 的方程组，你会得到它们之间的比例关系：l1​=k2​=2k1​=2l2​。

**最关键的一步来了：求出了比例关系后，公共解 x 到底是什么？** 别忘了我们的初衷，公共解是 x=k1​α1​+k2​α2​。现在你已经知道 k2​=2k1​ 了，直接把它代回去：

x=k1​α1​+2k1​α2​=k1​(α1​+2α2​)

把具体的 α1​ 和 α2​ 算一下：

(−1,1,0,1) T+2 (0,0,1,0) T=(−1,1,2,1) T

所以公共解就是 k1​(−1,1,2,1) T。（注里为了书写方便，把 k1​ 重新记作了 k）。

_(你当然也可以把关系代入 l1​β1​+l2​β2​，算出来的结果绝对是一模一样的，因为它们本就是相等的。)_

---

### 总结：两种方法对比

- **正文方法（联立方程组法）：** 简单粗暴，直接把 A 和 B 拼起来求零空间。如果题目**已知方程组的具体表达式**，用这个方法最快，不易算错。
    
- **注的方法（基向量表出法）：** 逻辑更强。如果一道题**没有告诉你方程组的具体形式，只给了你两个空间的基向量**，你就只能被迫用这个方法去求交集。所以这个方法必须掌握，它是求两个子空间交集（V1​∩V2​）的标准解法。

你没看懂这一步，是因为这里用到了一个非常霸道、但也非常精妙的数学逻辑，叫做**恒等式原理**（也就是答案里那句神秘的“由 $k$ 的任意性”）。

这恰好和你上一个问题中探讨的“为什么能取 $k=0$”是完全一脉相承的逻辑！

我们把答案的这一大段，拆解成三个清晰的步骤来理解：

### 第一步：大前提——什么是“同解”？

既然题目说方程组 ① 和方程组 ② **同解**，这就意味着：**方程组 ① 的所有解，必须无条件地满足方程组 ②。**

在第一问中，你已经求出了方程组 ① 的通解：

- $x_1 = -2 + k$
    
- $x_2 = -4 + k$
    
- $x_3 = -5 + 2k$
    
- $x_4 = k$
    

这四个式子组合在一起，就是一个“万能钥匙”。只要你随便给 $k$ 一个数字，算出来的一组 $x$，就必定能让方程组 ① 成立。

既然它们“同解”，那么这把“万能钥匙”，也**必定能完美解开方程组 ② 的每一个方程**。

### 第二步：“强行代入”与“合并同类项”（核心操作）

既然万能钥匙能开锁，我们就直接把它插进方程组 ② 的第一个方程里试试。

方程组 ② 的第一个方程是：$x_1 + ax_2 - x_3 - x_4 = -5$

把包含 $k$ 的通解全部代进去：

$$(-2+k) + a(-4+k) - (-5+2k) - k = -5$$

接下来，我们把左边展开，并**把带有 $k$ 的项放在一起，不带 $k$ 的常数项放在一起**：

$$(-2 - 4a + 5) + (1 + a - 2 - 1)k = -5$$

化简一下：

$$(3 - 4a) + (a - 2)k = -5$$

### 第三步：见证“由 $k$ 的任意性”的魔法时刻

现在盯着上面这个化简后的式子：$(3 - 4a) + (a - 2)k = -5$。

这里就是你最困惑的地方。我们来做个思想实验：

别忘了，**$k$ 是一个任意常数**！它可以是 0，可以是 1，可以是 10000。

- 假如 $(a-2)$ 不等于 0（比如等于 1），那么当 $k$ 狂魔乱舞地变化时，等式左边也会跟着狂魔乱舞，它怎么可能永远等于右边死死钉住的 $-5$ 呢？
    
- **唯一能让这个等式在 $k$ 无论取什么值时都成立的办法，就是让 $k$ 的系数彻底归零！** 这样 $k$ 怎么变都无所谓了。
    

这就是答案中所说的“由 $k$ 的任意性”。

所以，必须强制令 $k$ 的系数为 0：

$$a - 2 = 0 \implies a = 2$$

同时，我们把 $a=2$ 代入常数部分验证一下：$3 - 4(2) = 3 - 8 = -5$，完美等于等式右边！

---

**按照同样的逻辑，秒杀 $b$ 和 $c$：**

1. **代入 ② 的第二个方程：** $bx_2 - x_3 - 2x_4 = -11$
    
    $$b(-4+k) - (-5+2k) - 2k = -11$$
    
    展开并合并：
    
    $$(-4b + 5) + (b - 2 - 2)k = -11$$
    
    $$(-4b + 5) + (b - 4)k = -11$$
    
    由 $k$ 的任意性，强杀系数：$b - 4 = 0 \implies \mathbf{b = 4}$。
    
    （验证常数：$-4(4) + 5 = -11$，正确）
    
2. **代入 ② 的第三个方程：** $x_3 - 2x_4 = -c + 1$
    
    $$(-5+2k) - 2k = -c + 1$$
    
    这里 $k$ 自己就抵消掉了（$2k - 2k = 0$），剩下：
    
    $$-5 = -c + 1 \implies \mathbf{c = 6}$$
    

---

### 尾声：答案最后为什么还要再算一遍？

你可能会问，算到 $a=2, b=4, c=6$，题目不就做完了吗？为什么答案下面还要把这三个数代回方程组 ②，又求了一遍通解？

这是因为数学上的严谨性。

我们上面通过代入，只能证明“方程组 ① 的解，全都能满足方程组 ②”（即 ① 的解集是 ② 的子集）。

但这有没有可能方程组 ② 非常宽松，它除了包含 ① 的解，还有一些属于自己的额外解呢？

为了证明它们是彻彻底底的“同解”（解集完全相等），答案把求出来的 $a, b, c$ 塞回去，实打实地对方程组 ② 的增广矩阵做了一次初等行变换。最后发现，算出来的通解长得和 ① 一模一样，这就形成了完美的逻辑闭环。

### 第一步：确定需要几个解？

既然要求方程组 $A^*x = 0$ 的基础解系，我们先得知道基础解系里有几个向量。

根据公式：解向量个数 $k = n - r(A^*)$。

因为你已经得出 $r(A^*) = 1$，所以：

$$k = n - 1$$

**目标明确：我们需要去寻找 $n-1$ 个线性无关的解向量。**

### 第二步：解从哪里来？（黄金公式桥梁）

在线性代数里，看到 $A$ 和 $A^*$ 凑在一起，必须条件反射地想到那个最伟大的黄金公式：

$$A^*A = |A|E$$

题目已知 $|A| = 0$，所以这个公式变成了：

$$A^*A = O$$

这个 $O$ 是零矩阵。我们把矩阵 $A$ 按**列**分块，设 $A = [\alpha_1, \alpha_2, \dots, \alpha_n]$，代入进去看会发生什么：

$$A^* [\alpha_1, \alpha_2, \dots, \alpha_n] = [A^*\alpha_1, A^*\alpha_2, \dots, A^*\alpha_n] = [0, 0, \dots, 0]$$

看到了吗？这直接说明：**$A^*\alpha_1 = 0, A^*\alpha_2 = 0, \dots, A^*\alpha_n = 0$**。

**结论爆点：** 矩阵 $A$ 的**每一个列向量** $\alpha_j$，天生就是方程组 $A^*x = 0$ 的解！

### 第三步：如何挑出 $n-1$ 个线性无关的解？（利用 $A_{11} \neq 0$）

现在我们手头有 $n$ 个解（$A$ 的 $n$ 个列向量 $\alpha_1$ 到 $\alpha_n$），但我们只需要挑出 $n-1$ 个，而且它们必须是**线性无关**的。

这时候题目给的最后一个条件 **$A_{11} \neq 0$** 就要发威了。

什么是 $A_{11}$？它是删掉矩阵 $A$ 的**第 1 行、第 1 列**后，剩下的那个 $(n-1) \times (n-1)$ 阶子式的行列式（再乘上 $(-1)^{1+1}$）。

既然这个子式不等于 0，根据行列式的性质，这意味着：**这个子式所在的 $n-1$ 列是线性无关的**。

这 $n-1$ 列是哪些列？因为删掉了第 1 列，所以剩下的正是 $A$ 的**第 2 列到第 $n$ 列**！

- **代数逻辑推导：** 如果一个矩阵的某个局部（切掉第一行之后的部分）是线性无关的，那么把切掉的脑袋安回去（变成完整的列向量），整体也**必然是线性无关**的。
    

所以，矩阵 $A$ 的列向量 $\alpha_2, \alpha_3, \dots, \alpha_n$ 构成了 $n-1$ 个线性无关的向量。

---

### 最终定案

既然 $\alpha_2, \alpha_3, \dots, \alpha_n$ 是 $A^*x = 0$ 的解，且它们线性无关，数量又刚好是 $n-1$ 个，那么它们就是我们要找的基础解系！

**答案书写格式：**

1. **基础解系为：** 矩阵 $A$ 的第 2 列到第 $n$ 列向量，即 $\alpha_2, \alpha_3, \dots, \alpha_n$。
    
2. **通解为：**
    
    $$x = k_2\alpha_2 + k_3\alpha_3 + \dots + k_n\alpha_n$$
    
    （其中 $k_2, k_3, \dots, k_n$ 为任意常数，$\alpha_j$ 为 $A$ 的第 $j$ 个列向量）
    

是不是有一种“踏破铁鞋无觅处，得来全不费工夫”的感觉？这类题目的套路就是：**用 $A^*A=0$ 定解的范围，用非零代数余子式定谁是那几个独立的基。

# 5
![[_attachments/image/03 880-1779026259500.jpeg]]
这是一道非常经典的“抽象矩阵方程题”。

遇到这种题，你首先要给自己洗脑：**千万别去猜矩阵里面具体的数字是什么！** 这类题的核心考点只有一个，就是“矩阵乘向量的本质”。

**核心心法：**

矩阵 $A$ 乘以列向量 $x$，本质上就是**对矩阵 $A$ 的列向量进行线性组合**，组合的系数就是向量 $x$ 里的元素。

即：$Ax = x_1\alpha_1 + x_2\alpha_2 + x_3\alpha_3$

带着这个心法，我们分三步来把这道题生吞活剥：

### 第一步：榨干已知条件（解密矩阵 A）

题目给出了 $Ax = \beta$ 的通解：$x = (1, 2, -1)^T + k(1, -2, 3)^T$。

我们知道，通解 = 特解 + 齐次基础解系。我们把这两部分拆开看：

1. **特解提供 $\beta$ 的表达式：**
    
    代入特解 $x^* = (1, 2, -1)^T$，说明 $Ax^* = \beta$。
    
    翻译成列向量的线性组合就是：
    
    **$1\cdot\alpha_1 + 2\cdot\alpha_2 - 1\cdot\alpha_3 = \beta$** (记住这个式子，马上要用)
    
2. **基础解系提供列向量之间的隐藏关系：**
    
    代入齐次解 $\eta = (1, -2, 3)^T$，说明 $A\eta = 0$。
    
    翻译出来就是：
    
    **$1\cdot\alpha_1 - 2\cdot\alpha_2 + 3\cdot\alpha_3 = 0$** (这也非常关键)
    

---

### 第二步：扒掉矩阵 B 的伪装

题目说 $B = (\alpha_1, \alpha_2, \alpha_3, \beta + \alpha_3)$，它是一个 $4\times 4$ 的矩阵。

第 4 列那个 $\beta$ 看起来很碍眼，我们把第一步求出来的 $\beta = \alpha_1 + 2\alpha_2 - \alpha_3$ 代进去替换掉它：

第 4 列 $= (\alpha_1 + 2\alpha_2 - \alpha_3) + \alpha_3 = \alpha_1 + 2\alpha_2$

所以，矩阵 B 的真面目其实是：

**$B = (\alpha_1, \alpha_2, \alpha_3, \alpha_1 + 2\alpha_2)$**

---

### 第三步：求解 $By = \alpha_1 - \alpha_2$

现在回到终极目标，求通解。老规矩：**通解 = 特解 + 齐次解**。我们设向量 $y = (y_1, y_2, y_3, y_4)^T$。

那么 $By$ 就是：**$y_1\alpha_1 + y_2\alpha_2 + y_3\alpha_3 + y_4(\alpha_1 + 2\alpha_2)$**

#### 1. 先找特解（凑一个能让等式成立的 $y^*$）

我们要让 $By = \alpha_1 - \alpha_2$。

直接观察：怎么凑出 $1\alpha_1 - 1\alpha_2$ 呢？

最简单的办法就是让前两列去凑，后两列歇着。

令 $y_1 = 1, y_2 = -1, y_3 = 0, y_4 = 0$。

验证一下：$B(1, -1, 0, 0)^T = 1\alpha_1 - 1\alpha_2 + 0 + 0 = \alpha_1 - \alpha_2$。完美！

__我们得到了一个特解：$y= (1, -1, 0, 0)^T$ 



#### 2. 再找齐次解（解方程 $By = 0$）

令 $By = 0$，即：

$y_1\alpha_1 + y_2\alpha_2 + y_3\alpha_3 + y_4(\alpha_1 + 2\alpha_2) = 0$

把同类项合并一下：

**$(y_1 + y_4)\alpha_1 + (y_2 + 2y_4)\alpha_2 + y_3\alpha_3 = 0$**

还记得我们在第一步得到的那个隐藏关系吗？

已知只有 $1\alpha_1 - 2\alpha_2 + 3\alpha_3 = 0$ （因为 $Ax=0$ 只有一个基础解系）。

这就意味着，上面这个式子里的系数，必须和 $(1, -2, 3)$ 成比例！

我们设比例系数为 $c$（任意常数），那么必须满足：

- $y_1 + y_4 = c$
    
- $y_2 + 2y_4 = -2c$
    
- $y_3 = 3c$
    

把 $y_1, y_2, y_3$ 用 $c$ 和 $y_4$ 表示出来：

$y_1 = c - y_4$

$y_2 = -2c - 2y_4$

$y_3 = 3c$

$y_4 = y_4$ (它自己是个自由变量)

把它写成向量的形式：

$\begin{pmatrix} y_1 \\ y_2 \\ y_3 \\ y_4 \end{pmatrix} = \begin{pmatrix} c - y_4 \\ -2c - 2y_4 \\ 3c \\ y_4 \end{pmatrix} = c \begin{pmatrix} 1 \\ -2 \\ 3 \\ 0 \end{pmatrix} + y_4 \begin{pmatrix} -1 \\ -2 \\ 0 \\ 1 \end{pmatrix}$

你看！因为有两个自由变量（$c$ 和 $y_4$），所以我们得到了**两个**基础解系！

（这很合理，因为矩阵 B 有 4 列，但它的秩和 A 一样是 2，所以基础解系个数 = $4 - 2 = 2$ 个）。

### 最终定案

把我们求出来的“特解”和“两个基础解系”拼在一起（令常数 $c=c_1$, $y_4=c_2$），就是最终答案：

**方程组的通解为：**

$y = \begin{pmatrix} 1 \\ -1 \\ 0 \\ 0 \end{pmatrix} + c_1 \begin{pmatrix} 1 \\ -2 \\ 3 \\ 0 \end{pmatrix} + c_2 \begin{pmatrix} -1 \\ -2 \\ 0 \\ 1 \end{pmatrix}$ （$c_1, c_2$ 为任意常数）
