# 合同矩阵
### 第一幕：为什么突然冒出“线性变换 $x = Cy$”？（动机）

结合我们上一回合讲的几何深意，二次型 $f(x) = x^T A x$ 描述的是一个几何图形（比如一个椭圆）。

- **现实困境：** 如果矩阵 $A$ 里面有交叉项（比如 $x_1 x_2$），这个椭圆在 $x$ 坐标系里就是**歪的**。歪的椭圆非常难研究，我们想把它**摆正**。
    
- **如何摆正？** 既然椭圆是歪的，那我们干脆**把坐标轴给转过去**，去迎合这个椭圆！
    
- **线性变换登场：** 在线性代数里，“换坐标系（旋转、拉伸坐标轴）”的数学操作，就叫做**可逆线性变换**，写成公式就是 **$x = Cy$**。
    
    - $x$ 是旧坐标（歪的视角）。
        
    - $y$ 是新坐标（正的视角）。
        
    - $C$ 就是连接新旧视角的“翻译官”（过渡矩阵）。
        

**总结：** 书上突然讲线性变换 $x = Cy$，不是为了炫技，而是为了**“换个视角看图形”**。这是化简二次型的唯一手段！

---

### 第二幕：为什么会出来 $C^T A C$？（代数桥梁）

既然我们决定要戴上 $C$ 这副新眼镜（新坐标系 $y$）来看原来的图形，那我们就必须把原来的方程 $f(x) = x^T A x$ 翻译成 $y$ 的语言。

这就是你图里中间那段穿脱衣服一样的代数推导：

1. 把 $x = Cy$ 代入原式： $f(x) = (Cy)^T A (Cy)$
    
2. 利用转置的穿脱原则 $(AB)^T = B^T A^T$，拆开前面的括号： $y^T C^T A C y$
    
3. 因为矩阵乘法有结合律，我们把中间那一坨紧紧抱在一起： $y^T (C^T A C) y$
    

此时，我们发现中间的 **$C^T A C$** 也是一个实对称矩阵。为了书写方便，我们给它起个新名字，叫 **$B$**。

于是，新坐标系下的方程变成了：**$g(y) = y^T B y$**

**总结：** $C^T A C$ 不是凭空捏造的，它是做坐标变换时，矩阵转置法则 $(Cy)^T$ 必然导致的一个代数副产物。

---

### 第三幕：为什么要发明“合同”这个词？（核心命名）

现在，我们手头有两个矩阵：

- **$A$：** 旧坐标系下，那个歪椭圆的“身份证”。
    
- **$B$：** 新坐标系下，同一个椭圆摆正后的“身份证”。
    

数学家需要定义一种关系，来表明**“矩阵 $A$ 和矩阵 $B$ 其实描述的是同一个几何图形，只是看的坐标系不同”**。

既然 $B$ 是由 $A$ 通过 $C^T A C$ 变过来的，数学家就给这种特殊的关系赋予了一个专属名词——**合同（Congruence）**。记作 $A \simeq B$。

正如你图片最下方那句高亮的话所说：**“A 表征的是形态，B 表征的也是形态，无非是同一个事物在不同参照系下的不同形态。”**



# 标准型规范型
标准型是二次型没有交叉项的情况，规范型是进一步，标准型的系数为+-1，
![[01视频笔记-1775874928562.jpeg]]

找一个普通的可逆矩阵 $C$，做变换 $x = Cy$。最后得到 $C^T A C = \Lambda$（对角阵）。
普通的可逆矩阵 $C$ 就像是对坐标系进行“整容”。你不仅可以旋转坐标轴，还可以**随意拉伸、压缩、甚至把坐标轴压扁倾斜（斜交）**。只要你能把那个歪的图形强行揉捏成一个正的（没有交叉项），怎么扯都行。
因为你对空间进行了暴力拉伸，所以最后化出来的对角阵 $\Lambda$ 上的数字，**根本不是原来的特征值**！它们只是一堆能反映图形是椭圆还是双曲线的数字而已。


- 不准用普通的 $C$，必须找一个极其高贵的**正交矩阵 $Q$**，做变换 $x = Qy$。
- **$Q^{-1} = Q^T$**，并且由此推导出了一个无敌等式：**$Q^T A Q = Q^{-1} A Q = \Lambda$**。
- 正交矩阵 $Q$ 代表的是**纯粹的刚体旋转**。它就像是“正骨”，绝对不允许拉伸或挤压坐标轴，只能把原本互相垂直的坐标系原封不动地旋转一个角度，刚好对准图形的长短轴。
- 那么最后算出来的那个对角阵 $\Lambda$，主对角线上的元素就不再是阿猫阿狗了，它们**必须是、且绝对是矩阵 $A$ 最纯正的特征值（$\lambda_1, \lambda_2 \dots$）！**

# 惯性定理
**“你们随便怎么拉伸、压缩坐标轴（乘不同的 $C$），算出来的系数大小确实会变。但是！系数的【正负号数量】是绝对不可能改变的！”**

- **$p$（正惯性指数）：** 就是化简后，系数为正数的个数。
    
- **$q$（负惯性指数）：** 就是化简后，系数为负数的个数。
    

**为什么这个发现这么牛？背后的几何深意是什么？**

因为系数的正负，决定了这个几何图形最底层的**拓扑结构（也就是骨架）**！

- **正号 ($+$)：** 代表图形在这个维度上是**向上弯曲**的（像一个开口向上的碗）。
    
- **负号 ($-$)：** 代表图形在这个维度上是**向下弯曲**的（像马鞍的边缘）。
    
- **零 ($0$)：** 代表图形在这个维度上是**平坦**的（没有弯曲，像个圆柱面）。
    

惯性定理的几何意义就是：**你可以用可逆线性变换把一个“小碗”拉伸成一个“大宽盘子”（改变系数值），但你绝对不可能通过拉伸，把一个“碗”变成一个“马鞍”！**

## 配方法
**第一步：先把 $x_1$ 关进“小黑屋”**

老师在第一行画了横线：$x_1^2 + 2x_1x_2 + 2x_1x_3$。这是原式中所有包含 $x_1$ 的项。

老师想找一个完全平方公式，把它们一口吞进去。

回想一下公式：$(a+b+c)^2 = a^2 + b^2 + c^2 + 2ab + 2ac + 2bc$

为了凑出 $2x_1x_2$ 和 $2x_1x_3$，我们可以强行构造一个 $(x_1 + x_2 + x_3)^2$。

但是，这个括号展开后，除了我们想要的项，还会多出一些“副产物”（$x_2^2 + x_3^2 + 2x_2x_3$）。

所以必须把副产物减掉：

$$x_1^2 + 2x_1x_2 + 2x_1x_3 = \mathbf{(x_1 + x_2 + x_3)^2} - x_2^2 - x_3^2 - 2x_2x_3$$

_目标达成：_ $x_1$ 已经被死死锁在加粗的括号里了，外面再也没有游离的 $x_1$ 了！

**第二步：收拾残局（处理 $x_2$ 和 $x_3$）**

把刚才减掉的“副产物”，跟原式剩下的那部分（$- x_2^2 - 2x_2x_3 - x_3^2$）合并。

副产物 + 剩下的 = $- 2x_2^2 - 4x_2x_3 - 2x_3^2$

老师提取了一个 $-2$，变成了：

$$-2(x_2^2 + 2x_2x_3 + x_3^2)$$

运气非常好，括号里刚好又是一个完美的完全平方：

$$-2(x_2 + x_3)^2$$

_目标达成：_ 所有的 $x_2$ 和 $x_3$ 也被锁进第二个括号了！

---

### 结局：配方之后的“华丽变身”

现在，原式被老师凑成了这个样子：

$$f = (x_1 + x_2 + x_3)^2 - 2(x_2 + x_3)^2$$

**这一步到底意味着什么？这就是见证奇迹的时刻！**

我们直接令括号里的东西等于**“新坐标系”**的变量：

- 令 $y_1 = x_1 + x_2 + x_3$
    
- 令 $y_2 = x_2 + x_3$
    
- 令 $y_3 = x_3$ （为了凑齐三维空间，强行加一个，哪怕它系数是 0）
    

把这些 $y$ 代回上面的式子，二次型瞬间变成了：

$$f = 1 \cdot y_1^2 - 2 \cdot y_2^2 + 0 \cdot y_3^2$$


## 正交变换法
### 配方法 vs 正交变换，两把永远有效的屠龙刀

既然你已经明白了所有二次型都可以用这两种方法，那考场上到底用哪个？这就变成了**战术选择**问题：

| **对比项**  | **配方法 (普通线性变换 x=Cy)**              | **正交变换法 (x=Qy)**                               |
| -------- | ---------------------------------- | ---------------------------------------------- |
| **计算难度** | **极低**。就是初中生都会的凑完全平方。              | **极高**。要求特征根、解方程组求特征向量、施密特正交化、单位化（带一堆根号）。      |
| **适用范围** | 任何二次型。                             | 任何二次型。                                         |
| **化简结果** | 系数是乱七八糟的数（只保证正负号数量对）。              | 系数**完美对应**矩阵的特征值 $\lambda_1, \lambda_2, \dots$ |
| **几何意义** | 暴力拉伸坐标系（改变图形大小比例）。                 | 纯粹的刚体旋转（保持图形原本的形状大小）。                          |
| **考试场景** | 题目只问“规范形/标准形”、求“正负惯性指数”、判断“正定/负定”。 | 题目**明文规定**“用正交变换化为标准形”，或者后续要求 $A^n$。           |


![[01视频笔记-1775879748290.jpeg]]第二问的终极目标是：找出一个正交矩阵 $Q$，使得 $Q^TAQ = B$。

- **直线强攻：** 直接设 $Q = \begin{bmatrix} x_1 & x_2 \\ x_3 & x_4 \end{bmatrix}$，代入方程硬解。这绝对会算到吐血，此路不通。
    
- **曲线救国（小三角战术）：** 既然直接从 $A$ 走到 $B$ 很难，但我们知道 $A$ 和 $B$ 都能轻易地化为**同一个标准形 $\Lambda$**（对角阵）！那我们为什么不找个“中介”呢？
    

这就是右下角那个三角形的含义：

1. **左边这条路：** 把 $A$ 对角化。我们自己算出一个正交矩阵 $Q_1$，使得 $Q_1^T A Q_1 = \Lambda$。
    
2. **右边这条路：** 把 $B$ 对角化。我们再算出一个正交矩阵 $Q_2$，使得 $Q_2^T B Q_2 = \Lambda$。
    

既然它们俩的终点都是同一个 $\Lambda$，那我们就可以在 $\Lambda$ 这里把两条路**对接**起来！

这就是图里这句核心等式：

$$Q_1^T A Q_1 = Q_2^T B Q_2$$

---

### 第三重境界：代数变形，提取最终的 $Q$

现在我们有了桥梁 $Q_1^T A Q_1 = Q_2^T B Q_2$，但我们的目标是把它变成 $Q^TAQ = B$ 的样子（也就是要把 $B$ 旁边清空）。

怎么清空 $B$ 旁边的 $Q_2^T$ 和 $Q_2$ 呢？利用正交矩阵的性质（逆等于转置）！

- 在等式**左边**，同时乘上 $(Q_2^T)^{-1}$，也就是乘上 $Q_2$。
    
- 在等式**右边**，同时乘上 $Q_2^{-1}$，也就是乘上 $Q_2^T$。
    

我们来操作一下：

$$Q_2 \cdot (Q_1^T A Q_1) \cdot Q_2^T = Q_2 \cdot (Q_2^T B Q_2) \cdot Q_2^T$$

右边的 $Q_2 Q_2^T$ 直接变成了单位阵 $E$ 抵消掉了，只剩下 $B$：

$$(Q_2 Q_1^T) A (Q_1 Q_2^T) = B$$

根据矩阵转置的穿脱原则 $(XY)^T = Y^T X^T$，前面的 $(Q_2 Q_1^T)$ 刚好就是 $(Q_1 Q_2^T)^T$！

所以等式变成了：

$$(Q_1 Q_2^T)^T A (Q_1 Q_2^T) = B$$

你对比一下目标方程 $Q^T A Q = B$。

**看！中间那个括号里的东西，不就是我们梦寐以求的 $Q$ 吗！**

**结论完美诞生：$Q = Q_1 Q_2^T$。**

# 正定二次型
对于任意的非零向量 $x$，都有 $x^T A x > 0$。

如果你把二次型看作一个三维空间里的曲面高度：$z = f(x_1, x_2) = x^T A x$。

- **代数意义：** 无论你往 $x_1, x_2$ 里代入什么数字（只要不是原点 0），算出来的高度 $z$ **绝对是正数**。
    
- **几何意义：** 这个曲面在原点 $(0,0)$ 处触底（高度为 0），然后**在每一个方向上都严格向上弯曲**。它没有任何一个方向是往下垂的，也没有任何一个方向是平的。
    
- **物理意象：** 它就是一个完美无缺、连一滴水都不会漏的**“碗”**。
    

这也就是为什么它的特征值必须**全都是正数**（正惯性指数 $p=n$）。因为每一个特征值代表一个主轴方向的弯曲趋势，全部是正的，就意味着全方位向上翘。


正定矩阵等价结论：
第一派系：特征值与惯性指数
- **条件：$A$ 的特征值 $\lambda_i > 0$**
    - **解释：** 特征值代表每个主轴方向的“弯曲趋势”。如果所有的 $\lambda$ 都是正数，说明这个图形在所有维度上都是**向上弯曲的**。这当然就是一个完美的“碗”（正定）。

- **条件：正惯性指数 $p = n$** 
    - **解释：** 既然所有特征值都是正数，那你把它化成标准形后，系数全都是正数。一共有 $n$ 个变量，正数系数就有 $n$ 个，所以 $p=n$。
 
 第二派系：矩阵 $E$ 与 $A = D^T D$
请把目光移向**老师在右侧的手写板书**，这是理解这一派系的核心！

- **条件：$A \simeq E$（与单位阵合同）**
    - **板书破译：** 老师写了 $x^T A x = y^T \Lambda y = a_1 y_1^2 + \dots + a_n y_n^2$。
    - 因为矩阵是正定的，所以所有的系数 $a_i$ 都是正数（比如 $4y_1^2 + 9y_2^2$）。
        
    - **骚操作来了：** 既然都是正数，我们就可以对它们开根号，把系数“吃”进变量里！
        
        令 $z_1 = \sqrt{a_1}y_1$，令 $z_2 = \sqrt{a_2}y_2 \dots$
        
    - 代入进去，式子瞬间变成了 **$z_1^2 + z_2^2 + \dots + z_n^2$**！
        
    - 这个极其干净的式子，它对应的矩阵是什么？就是主对角线全是 1 的**单位矩阵 $E$**！
    - **结论：** 任何一个正定二次型，只要你经过合适的坐标拉伸（合同变换），最终都能变成最完美的单位矩阵 $E$。


- **条件：存在可逆矩阵 $D$，使 $A = D^T D$**

    - **解释：** 既然 $A$ 和 $E$ 合同，根据合同的定义，一定存在一个可逆矩阵 $C$，使得 $C^T A C = E$。
    - 我们在等式两边左乘 $(C^T)^{-1}$，右乘 $C^{-1}$，得到 $A = (C^T)^{-1} E C^{-1}$。
    - 令 $D = C^{-1}$，这个式子就变成了 **$A = D^T D$**。
    - 这就好比在实数界里，任何一个正数 $a > 0$，都可以写成某个数平方 $a = d^2$。在矩阵界，正定矩阵 $A$ 也可以写成“某个矩阵的平方” $D^T D$。

第三派系：（顺序主子式）

- **条件：$A$ 的全部顺序主子式均大于 0**
    
    - **为什么要发明这个条件？**
        
        前面说的求特征值 $\lambda_i > 0$ 固然好，但如果是 $3 \times 3$ 或者 $4 \times 4$ 的矩阵，让你在考场上徒手解三次、四次方程求特征值，你绝对会算到崩溃。
        
        数学家西尔维斯特（Sylvester）发明了这个判别法，让你**根本不需要求特征值**，直接算行列式就能鉴定正定矩阵！
        
    - **什么是“顺序主子式”？（看图最下方）**
        
        就像是“剥洋葱”一样，从矩阵的左上角开始，从小到大框取方阵，算它们的行列式。
        
        - 一阶：左上角第一个数 $|a_{11}|$。
            
        - 二阶：左上角 $2 \times 2$ 的行列式。
            
        - 三阶：左上角 $3 \times 3$ 的行列式。
            
        - 以此类推，直到整个矩阵的行列式 $|A|$。
            
    - **几何直觉：**
        
        你要验证一个多维空间里的“碗”是不是完美的，你可以一层一层维度去验证。
        
        - 先看一维（$a_{11} > 0$）：好，在这个线上它是向上弯的。
            
        - 再看二维（二阶主子式 $> 0$）：好，在这个平面切面上它也是向上弯的。
            
        - 一路验证到 $n$ 维全部大于 0：鉴定完毕，这绝对是个 360 度无死角的完美圆碗！
