# 上三角矩阵
上三角矩阵特征值就是主对角线上的元素

# 特征值式子
![[_attachments/image/01不熟悉-1784861406786.jpeg]] 为什么有 $n-1$ 个特征值为 0？（空间视角）

特征值的定义是求 $Ax = \lambda x$。
我们先看看 $\lambda = 0$ 的情况，也就是求 $Ax = 0$。

因为矩阵 $A$ 是一个 $n$ 阶方阵，且秩 $r(A) = 1$。
根据我们刚刚在上一关用过的“神级定理”：
**基础解系的个数 = $n - r(A) = n - 1$**。

这说明什么？说明方程组 $Ax = 0$ 有 $n-1$ 个线性无关的解向量。
把解向量套入特征值公式：$Ax = 0x$。
这不就完美证明了：**必定有 $n-1$ 个线性无关的特征向量，它们对应的特征值全是 0！**
这就是图片中 $\lambda_2 = \dots = \lambda_n = 0$ 的由来。

---

### 第三步：唯一非零的特征值是怎么来的？（代数视角）

我们已经知道 $n$ 个特征值里有 $n-1$ 个是 $0$ 了。怎么找最后那个“独苗” $\lambda_1$？

**方法一：利用迹（Trace）的无敌推论**
我们在最早的对话中推导过，矩阵的迹（主对角线元素之和）等于特征值之和。
$tr(A) = \lambda_1 + \lambda_2 + \dots + \lambda_n$
既然 $\lambda_2$ 到 $\lambda_n$ 全是 0，那么自然得出：
**$\lambda_1 = tr(A)$**。

**方法二：利用特征值定义（最震撼的秒杀法）**
既然 $A = \alpha\beta^T$，我们根据特征值定义 $Ax = \lambda x$，大胆地猜想一下：**如果把 $\alpha$ 作为特征向量 $x$ 代进去，会发生什么化学反应？**

计算 $A\alpha$：
$A\alpha = (\alpha\beta^T)\alpha$
根据矩阵乘法的结合律，我们可以改变括号的位置：
$A\alpha = \alpha(\beta^T\alpha)$

**前方高能！** 我们在第一步说过，$\beta^T\alpha$ 是一个**数字（常数）**！
既然它是一个数字，我们把它挪到前面去写：
**$A\alpha = (\beta^T\alpha) \alpha$**

你对比一下特征值的标准定义：**$Ax = \lambda x$**。
长得是不是一模一样？！
这里 $x$ 就是 $\alpha$，而那个常数 $\lambda$ 就是 $\beta^T\alpha$！
所以，这个矩阵的另一个特征值就是 **$\lambda_1 = \beta^T\alpha$**（也就等于 $\alpha^T\beta$）。


# 正交的知二求一
![[_attachments/image/01不熟悉-1785026832175.jpeg]]


这张图片是关于**线性代数**的复习笔记，它将三个看似不同、但本质上都在考查同一个核心概念的知识点归纳在了一起。

这个核心概念就是：**在三维空间（包含 3 个元素的向量）中，利用“正交（垂直）”关系，通过两个已知的线性无关向量，求第三个与它们都正交的向量。** （在计算上，这通常可以通过求这两个已知向量的**叉乘/外积**来快速得出）。

下面为你逐一拆解这三个知识点到底在说啥：

### 1. 第一块：三阶实对称阵
*   **字面意思**：对于一个 3×3 的实对称矩阵，如果你已经知道了它的两个线性无关的特征向量，你可以求出第三个特征向量，且这个特征向量与前两个都垂直（正交）。
*   **背后原理**：实对称矩阵有一个非常重要的性质——**不同特征值对应的特征向量必定相互正交**。即使特征值有重根，也可以找到正交的特征向量。在三维空间中，如果你已经有了两个不平行的向量，要找第三个与它们都垂直的向量，方向是唯一确定的（或者说它们构成了一组正交基）。

### 2. 第二块：系数矩阵列数为三的齐次方程组 ($Ax = 0$)
*   **字面意思**：讨论含有 3 个未知数的方程组 $Ax = 0$。
    *   矩阵 $A$ 的每一行（行向量）和方程的解（解向量）是互相垂直的。
    *   知道 $A$ 的两行，就能求出一个解。
    *   知道两个解，就能反推 $A$ 的一行。
*   **背后原理**：矩阵乘法 $Ax = 0$ 的本质，就是矩阵 $A$ 的每一个行向量与列向量 $x$ 进行内积（点乘），结果为 0。**内积为 0 意味着正交（垂直）**。
    *   因为列数是 3，所以向量是三维的。
    *   如果你知道 $A$ 的两个线性无关的行向量，要求解 $x$，就是求一个同时垂直于这两个行向量的向量 $x$。
    *   反之同理，知道两个解向量，求系数矩阵的行向量，也是找垂直关系。

### 3. 第三块：$AB = 0$
*   **字面意思**（结合上下文补全被字幕挡住的部分）：两个矩阵相乘等于零矩阵。
    *   知道 $A$ 的两个线性无关的行向量，可以求 $B$ 的列向量。
    *   知道 $B$ 的两个线性无关的列向量，可以求 $A$ 的行向量。
*   **背后原理**：与第二点极其相似。根据矩阵乘法的规则，$AB=0$ 意味着 **$A$ 的每一个行向量，与 $B$ 的每一个列向量正交（垂直）**。如果限定在三维向量的前提下，依然是“知二求一”的正交问题。


做这类笔记的人是在总结**考研数学或期末考试中的“秒杀技巧”**。

这三个知识点虽然分别属于“特征值问题”、“方程组问题”和“矩阵运算问题”，但解题套路完全一样：**只要你在题目中发现了隐藏的“三维向量”和“正交（垂直）”关系，并且已知了两个向量，你就可以直接用这两个向量做叉积（或者解一个简单的二元方程组），瞬间求出你需要的未知向量。** 这种跨章节的归纳能极大提高做题速度。

# 实对称矩阵

**1. 特征值必为实数**
证明思路（可能考大题）：设 $Ax=\lambda x$，两边取共轭转置结合 $A^T=A$，可推出 $\lambda=\bar\lambda$。
应试用法：遇到"实对称矩阵，判断特征值是否为实数"直接秒答；这个性质也常作为证明题的中间步骤。

**2. 不同特征值对应的特征向量互相正交**
不仅线性无关，而且正交（一般矩阵只保证线性无关）。
应试用法：正交相似对角化时，不同特征值的向量不用施密特正交化，直接单位化即可。

**3. 必可相似对角化，且能用正交矩阵对角化**
即存在正交矩阵 $Q$，使 $Q^{-1}AQ=Q^TAQ=\Lambda$（对角阵）。
这是实对称矩阵最重要的性质，几乎每年都以计算题或证明题出现。

**4. k 重特征值必有 k 个线性无关特征向量**
即代数重数=几何重数，$n-r(A-\lambda E)=k$。
应试用法：这条保证了性质 3 成立，也常用来反推参数（已知重根，用秩条件求矩阵中的未知数）。

**5. 同一特征值对应的特征向量子空间内，做施密特正交化**
重根对应的特征向量本身不一定正交，需要正交化处理，再单位化。

**6. 正交相似对角化标准解题步骤**（大题必考，务必熟练）
- 第一步：求特征值 $|A-\lambda E|=0$
- 第二步：对每个特征值求特征向量（解 $(A-\lambda E)x=0$）
- 第三步：若某特征值是重根，对应的多个特征向量做施密特正交化
- 第四步：所有特征向量单位化
- 第五步：按顺序排成正交矩阵 $Q$，则 $Q^TAQ=\Lambda$（对角元素顺序与 Q 中列向量顺序对应）

**7. 与正定性的联系**
- 正定 $\Leftrightarrow$ 特征值全大于 0
- 半正定 $\Leftrightarrow$ 特征值全大于等于 0
- 负定 $\Leftrightarrow$ 特征值全小于 0
这是判断二次型正定性的一条常用途径（另外两条是顺序主子式和合同变换）。

**8. 秩 = 非零特征值个数**（因为可对角化，$r(A)=r(\Lambda)$）

**9. 若 A、B 都是实对称矩阵，则 A 相似于 B ⟺ A 与 B 特征值完全相同**
一般矩阵相似需要更强条件，但实对称矩阵因为都可对角化，直接看特征值是否相同即可判定相似性，这是简化解题的关键点。

---

**应试建议**：
- 大题：几乎一定考"给定实对称矩阵 A，求正交矩阵 Q 使 $Q^TAQ$ 为对角阵"，套用第 6 条步骤，注意重根时不要漏掉正交化步骤，这是最容易失分的地方。
- 选择/填空：常考"不同特征值特征向量正交"这条性质的直接应用（比如已知两个特征向量正交，反求参数）。
- 证明题：常结合"特征值为实数"的证明思路（利用 $A^T=A$ 和共轭）。
- 与二次型结合：正定性判断经常和特征值符号一起考，记住等价条件。

## k 重特征值必有 k 个线性无关特征向量的理解
你的秩零度理解完全到位了，压平面那个例子说得很准。断掉的地方是一个很具体的点：**"非零特征值个数"这个数，是从哪里减出来的。** 我把这一步补上，第二层就通了。

先摆一个总账。特征多项式 $|A-\lambda E|$ 是 $\lambda$ 的 $n$ 次多项式，$n$ 次多项式恰好有 $n$ 个根（重根按重数数）。所以：

$$\text{所有特征值的代数重数加起来}=n$$

这个总账是死的，永远是 $n$。现在把这 $n$ 个特征值分成两堆：等于 0 的，和不等于 0 的。于是

$$\text{非零特征值个数}=n-(\lambda=0\ \text{的代数重数})$$

这就是你要的那一步。当题目说"特征值是 $2,5,0,0$"，它列的就是这 $n=4$ 个根，你数出非零的有 2 个，本质就是 $4-2$，减掉的是 0 的**代数**重数。

再看另一条路。你已经推出来了：

$$r(A)=n-\dim\text{Null}(A)=n-(\lambda=0\ \text{的几何重数})$$

现在把两个式子并排放：

$$\text{非零特征值个数}=n-\boxed{\text{代数重数}}$$
$$r(A)=n-\boxed{\text{几何重数}}$$

两边都是 $n$ 减一个东西。要让它们相等，只需要框里两个数相等，也就是**特征值 0 的代数重数 = 几何重数**。

这就是全部逻辑。"秩 = 非零特征值个数"不是什么独立的新性质，它就是秩零度定理，外加一个条件：0 这个特征值没有缺斤少两。注意条件只压在 $\lambda=0$ 身上，其他特征值缺不缺根本不影响秩。

### 算 $A=\begin{pmatrix}0&1\\0&0\end{pmatrix}$

**代数重数**，老实解特征方程：

$$|A-\lambda E|=\begin{vmatrix}-\lambda&1\\0&-\lambda\end{vmatrix}=\lambda^2=0$$

得 $\lambda=0,0$，所以 $\lambda=0$ 的代数重数是 2。总账 $n=2$ 对上了。

**几何重数**，你之前问"这咋解"，其实就是套第一层那条链，别被 $\lambda=0$ 带乱：

$$(A-0\cdot E)x=0\quad\Longrightarrow\quad Ax=0$$

$A$ 本身就是那个矩阵，$r(A)=1$（第一行 $(0,1)$ 非零，第二行全零）。所以

$$\text{几何重数}=n-r(A-0E)=2-1=1$$

也可以直接解：$\begin{pmatrix}0&1\\0&0\end{pmatrix}\begin{pmatrix}x_1\\x_2\end{pmatrix}=0$ 展开只有一条有效方程 $x_2=0$，解是 $x_1$ 任意、$x_2=0$，即 $k\begin{pmatrix}1\\0\end{pmatrix}$，一条直线，1 维。

**失效对账**：

$$\text{非零特征值个数}=2-2=0,\qquad r(A)=2-1=1$$

$0\ne 1$，公式崩了。崩的原因就是框里 2 和 1 不等。

### 为什么会缺：借你"压平面"的语言

用你自己的说法。这个 $A$ 干了什么？$e_1\mapsto 0$，$e_2\mapsto e_1$。

所以它把二维平面压成了 $e_1$ 那条直线，像空间 1 维（秩 1），被压掉的是 $e_1$ 方向那条线，零空间 1 维。**一次作用只压掉了 1 维。**

但特征多项式 $\lambda^2$ 说 0 有 2 重。这 2 重体现在哪？算一下 $A^2=0$：作用两次，整个平面全归零。也就是说，这个矩阵的"总坍缩能力"确实是 2 维，但它不是一步压完的—— $e_2$ 第一步没死，它被剪切**平移进了 $e_1$ 的地盘**，第二步才跟着死。

代数重数数的是"总共要坍缩几维（分几步不管）"，秩看到的是"第一步压掉几维"。剪切让这两个数错开了。

还有一个很利索的判据：这里 $\text{Null}(A)=\text{Im}(A)=\text{span}(e_1)$，零空间和像空间**完全重合**。$e_2$ 就是躲进了这块重合区，才逃过第一步。

### 实对称为什么绝对不会缺

对实对称矩阵，$\text{Im}(A)$ 和 $\text{Null}(A)$ 是**互相垂直**的（这就是前面"主轴互相垂直"的另一副面孔：零空间是特征值 0 那些轴撑起来的，像空间是非零特征值那些轴撑起来的，不同特征值的轴彼此垂直）。垂直意味着两块地盘只在原点相交，谁也躲不进谁那里。

没有藏身处，就没有"下一步才死"这回事：该坍缩的方向第一步全部坍缩完。所以代数重数和几何重数在 $\lambda=0$ 处必然相等，公式成立。

对照 $\text{diag}(2,0,0)$：$\text{Null}$ 是 $x_2x_3$ 平面，$\text{Im}$ 是 $x_1$ 轴，垂直，不重合。$r(A)=1=$ 非零特征值个数。

### 回到应试

判断能不能用这条公式，就问一句：**0 是单根还是重根。**

- **0 是单根**：几何重数被夹死（$\ge 1$ 因为它是特征值，$\le$ 代数重数 $=1$），必然等于 1。所以 $r(A)=n-1$，**任何矩阵都能直接用，不需要对称、不需要可对角化**。这是白送的分。
- **0 是重根，但题目说了实对称 / 可相似对角化**：条件保证代数=几何，直接用 $r(A)=$ 非零特征值个数。
- **0 是重根，题目啥都没说**：不能用。$r(A)$ 只能确定一个范围，得老实去解 $Ax=0$。

这正好是第四层第 7、8 题。$4\times4$、特征值 $2,5,0,0$、无任何条件：0 的代数重数 2，几何重数只知道在 $1$ 到 $2$ 之间，所以 $r(A)=4-\text{几何重数}\in\{2,3\}$，定不下来。换成 $2,5,7,0$：0 是单根，几何重数锁定 1，$r(A)=3$ 铁定。再补一句"实对称"回到 $2,5,0,0$：几何重数 $=2$，$r(A)=2$。

现在你把第 7、8、9 题自己复述一遍（不看上面），能顺下来这块就真的过了。


# 反对称矩阵

**题眼反射：看到 $A^T = -A$（反对称矩阵），大脑要立刻弹出这三个性质！**
1.  **二次型必为 0（无敌绝杀技）**：对于任意列向量 $x$，**$x^T A x \equiv 0$** 永远成立。（本题就是考了这个，只不过把 $A$ 换成了 $A^{-1}$）。
2.  **逆矩阵同性**：如果它可逆，它的逆矩阵 $A^{-1}$ 也是反对称矩阵；它的伴随矩阵 $A^*$ 在 $n$ 为偶数时是反对称，奇数时是对称的。
3.  **奇数阶必不可逆（附赠彩蛋）**：如果 $A$ 是奇数阶矩阵，那么 $|A| = 0$。
    *(推理：$|A^T| = |-A| \implies |A| = (-1)^n|A|$。当 $n$ 为奇数时，$|A| = -|A|$，故 $|A|=0$)*。
    *(这也反向说明了，本题中既然 $|A| \neq 0$，那么这道题里的 $A$ 一定是个**偶数阶**矩阵！出题人在这里的设计是严丝合缝的！)*
