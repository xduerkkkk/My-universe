# 物理应用


| 物理量名称                        | 数学表达式（以三重积分为例）                                                                                                                                              | 理解与考点辨析                                                                                     |
| :--------------------------- | :---------------------------------------------------------------------------------------------------------------------------------------------------------- | :------------------------------------------------------------------------------------------ |
| **质量 $M$**                   | $M = \iiint_\Omega \rho(x,y,z) dV$                                                                                                                          | 基础考点，纯粹求被积函数为 $\rho$ 的积分。                                                                   |
| **质心 (Center of Mass)**      | $\bar{x} = \frac{1}{M}\iiint_\Omega x\rho \, dV$<br>$\bar{y} = \frac{1}{M}\iiint_\Omega y\rho \, dV$<br>$\bar{z} = \frac{1}{M}\iiint_\Omega z\rho \, dV$    | **质量加权平均位置**。<br>若 $\rho$ 和 $\Omega$ 同时关于某平面对称，质心必落在该对称面上（利用对称性直接定坐标，免积）。                   |
| **形心 (Centroid)**            | 即 $\rho = \text{常数}$ 时的质心：<br>$\bar{x} = \frac{1}{V}\iiint_\Omega x \, dV$                                                                                  | **纯几何中心**。注意经常用**形心公式逆用**求积分：<br>$\iiint_\Omega z \, dV = \bar{z} \cdot V$（知道形心高和体积，直接算积分）。 |
| **转动惯量 (Moment of Inertia)** | 绕 $z$ 轴：$I_z = \iiint_\Omega (x^2+y^2)\rho \, dV$<br>绕 $x$ 轴：$I_x = \iiint_\Omega (y^2+z^2)\rho \, dV$<br>对原点：$I_O = \iiint_\Omega (x^2+y^2+z^2)\rho \, dV$ | **距离平方 $\times$ 质量微元**。<br>被积函数由“点到轴/点的距离平方”决定。                                             |
| **第一类线/面积分**                 | 弧长质量：$M = \int_L \rho \, ds$<br>曲面质量：$M = \iint_\Sigma \rho \, dS$                                                                                          | 形式与三重积分完全一致，只是微元从 $dV$ 换成了 $ds$ 或 $dS$。                                                     |



# 几何公式

### 雅可比
如果有变量代换：$x = x(u, v),\ y = y(u, v)$，雅可比行列式定义为一阶偏导数组成的行列式：
$$J = \frac{\partial(x, y)}{\partial(u, v)} = 
\begin{vmatrix} 
\frac{\partial x}{\partial u} & \frac{\partial x}{\partial v} \\ 
\frac{\partial y}{\partial u} & \frac{\partial y}{\partial v} 
\end{vmatrix}$$

* **最经典的例子（普通极坐标）**：
  $x = r\cos\theta,\ y = r\sin\theta$
  $$J = 
  \begin{vmatrix} 
  \cos\theta & -r\sin\theta \\ 
  \sin\theta & r\cos\theta 
  \end{vmatrix} 
  = r\cos^2\theta - (-r\sin^2\theta) = r$$
  所以平时背的公式 $dxdy = r\,drd\theta$，里面的 $r$ **就是雅可比行列式的结果**！

# 不等式
对**任意实数** $a, b$（无论正负）：
1. 由 $(|a| - |b|)^2 \ge 0 \implies a^2 + b^2 \ge 2|ab|$ （因为 $|a|^2 = a^2$）
2. 由绝对值性质：$-|ab| \le ab \le |ab|$

把它们连在一起，就得到了考研中最完整的**“全景不等式链”**：
$$-(a^2 + b^2) \le 2ab \le 2|ab| \le a^2 + b^2$$

带不带绝对值，用哪个不等式完全取决于目的




# 泰勒

## - **$\sin(x)$ 的展开式：**
    
    $$\sin(x) = x - \frac{1}{3!}x^3 + \frac{1}{5!}x^5 - \frac{1}{7!}x^7 + o(x^8)$$
## **$\arcsin(x)$ 的展开式：**
    
    $$\arcsin(x) = x + \frac{1}{6}x^3 + \frac{3}{40}x^5 + \frac{5}{112}x^7 + o(x^8)$$

## **$\tan(x)$ 的展开式：**
    
    $$\tan(x) = x + \frac{1}{3}x^3 + \frac{2}{15}x^5 + \frac{17}{315}x^7 + o(x^8)$$

## **$\arctan(x)$ 的展开式：**
    
    $$\arctan(x) = x - \frac{1}{3}x^3 + \frac{1}{5}x^5 - \frac{1}{7}x^7 + o(x^8)$$
    
##   **$\ln(1+x)$ 的展开式：**
    
    $$\ln(1+x) = x - \frac{1}{2}x^2 + \frac{1}{3}x^3 - \frac{1}{4}x^4 + o(x^4)$$
    

- **$e^x$ 的展开式：**
    
    $$e^x = 1 + x + \frac{1}{2!}x^2 + \frac{1}{3!}x^3 + o(x^3)$$
    
    _(化简后即为：$1 + x + \frac{1}{2}x^2 + \frac{1}{6}x^3 + o(x^3)$)_
    

    
    _(化简后即为：$x - \frac{1}{6}x^3 + \frac{1}{120}x^5 - \frac{1}{5040}x^7 + o(x^8)$)_
    
- **$\cos(x)$ 的展开式：**
    
    $$\cos(x) = 1 - \frac{1}{2!}x^2 + \frac{1}{4!}x^4 - \frac{1}{6!}x^6 + o(x^7)$$
    
    _(化简后即为：$1 - \frac{1}{2}x^2 + \frac{1}{24}x^4 - \frac{1}{720}x^6 + o(x^7)$)_
    

    
##  **$(1+x)^\alpha$ 的展开式（广义二项式定理）：**
    
    $$(1+x)^\alpha = 1 + \alpha x + \frac{\alpha(\alpha-1)}{2!}x^2 + \frac{\alpha(\alpha-1)(\alpha-2)}{3!}x^3 + o(x^3)$$
    
- **$\frac{1}{1-x}$ 的展开式：**
    
    $$\frac{1}{1-x} = 1 + x + x^2 + x^3 + o(x^3)$$
    
- **$\frac{1}{1+x}$ 的展开式：**
    
    $$\frac{1}{1+x} = 1 - x + x^2 - x^3 + o(x^3)$$
