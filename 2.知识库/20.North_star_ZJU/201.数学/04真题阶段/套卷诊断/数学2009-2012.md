## 第二类曲线积分
![[_attachments/image/数学2009-2012-1788494923910.jpeg]]

我们依然针对你这道题的折线路径 $L$（起点 $(-1,0)$，顶点 $(0,1)$，终点 $(1,0)$），分别剖析**“含有 $\ln y$”**和**“含有无法消去的绝对值”**这两种情况：它们在几何上意味着什么、为什么破坏了格林公式、考场上该怎么破。


### 情况一 ：出现 $\ln y$（边界无定义/瑕积分风险）

1. 题目变式
计算曲线积分：
$$I = \int_L \ln(y+1)\,\mathrm{d}x + x^2\,\mathrm{d}y$$
*(注：如果直接出 $\ln y$，起点 $(-1,0)$ 处 $y=0$ 本身就无定义，属于出题失误；考研最标准的高级挖坑法是 $\ln(y+1)$，起点终点有定义，但在补线时会出事；或者终点在上方，但你补线补到了无定义区。)*

为彻底看清本质，我们假设路径在上方：折线从 $(-1,1) \to (0,2) \to (1,1)$，计算：
$$I = \int_L (\ln y)\,\mathrm{d}x + x^2\,\mathrm{d}y$$

2. 为什么不能随便补线用格林？
* **直觉盲区**：有人为了凑对称，图省事直接连一条线段到 $x$ 轴（$y=0$），把区域封到 $x$ 轴上。
* **致命崩塌**：一旦你的闭合区域碰到了 $y=0$（$x$ 轴），由于 $\ln(0)$ 无定义，被积函数在边界上**爆裂（趋于无穷大）**，偏导数 $\frac{\partial P}{\partial y} = \frac{1}{y}$ 在 $y=0$ 处直接不存在！格林公式要求的“在闭区域上具有一阶连续偏导数”被彻底摧毁。

 3. 应试破解策略：**“规避雷区”安全补线**
* **做法**：既然不能补到 $y=0$，那就在**函数的安全定义域内**补线！
  * 补一条直线段 $L_1$：从 $(1,1)$ 水平连到 $(-1,1)$（沿直线 $y=1$）。
  * 此时围成的三角形区域全部在 $y \ge 1$ 的范围内，$\ln y$ 和 $\frac{1}{y}$ 处处光滑连续，**格林公式满血复活**！
* **快速计算**：
  * $\frac{\partial Q}{\partial x} - \frac{\partial P}{\partial y} = 2x - \frac{1}{y}$
  * 顺时针方向：$\oint_{L + L_1} = -\iint_D \left(2x - \frac{1}{y}\right)\mathrm{d}\sigma$
    * 对称性：$2x$ 在关于 $y$ 轴对称的区域上积分为 $0$。
    * 只剩普通二重积分：$\iint_D \frac{1}{y}\mathrm{d}\sigma$。
  * 减去补线 $L_1$（$y=1 \implies \mathrm{d}y=0$）：$\int_{L_1} \ln(1)\,\mathrm{d}x = 0$。

> **应试法则 1**：补线是自由的，**不要死脑筋非去补坐标轴**。哪里安全、好算，就往哪里补线闭合。

### 情况二：被积函数带有无法消去的绝对值

将原题改为：
$$I = \int_L |x|y\,\mathrm{d}x + x^2\,\mathrm{d}y$$
折线仍然是 $y = 1 - |x|$，从 $(-1,0)$ 到 $(1,0)$。

 2. 为什么格林公式会变得极度难用（甚至不敢用）？
* **偏导数不连续风险**：
  被积函数中含有 $|x|$。
  $P(x,y) = |x|y$，求对 $y$ 的偏导：$\frac{\partial P}{\partial y} = |x|$。
  虽然 $|x|$ 是连续的，但如果题目是 $P(x,y) = x|y|$ 这种对 $x$ 求偏导，就会在坐标轴上出现分段甚至导数不存在点。
* **区域积分割裂**：
  就算条件满足，使用格林公式化为二重积分后：
  $$\iint_D (2x - |x|)\mathrm{d}\sigma$$
  被积函数带绝对值，无法利用整体奇偶性直接消去，**你必须把三角形区域 $D$ 沿 $y$ 轴强行劈成左右两块**分别算二重积分。

 3. 应试破解策略：**“弃格林，选定积分分段硬代”**
遇到带有无法统一化简的绝对值，**格林公式的简洁优势已经荡然无存**，继续补线用格林是“杀鸡用牛刀反被牛踢”。此时果断执行**第二类曲线积分的第一定义（定积分代入法）**：

* 路径天生就是按正负 $x$ 分段的：
  * **第一段 $L_1$（$x \in [-1, 0]$）**：
    方程为 $y = 1 - (-x) = 1 + x \implies \mathrm{d}y = \mathrm{d}x$。
    此时 $|x| = -x$（绝对值自动拆掉！）。
    $$\int_{L_1} = \int_{-1}^0 \left[ (-x)(1+x) + x^2 \right]\mathrm{d}x = \int_{-1}^0 (-x)\,\mathrm{d}x = \left[ -\frac{1}{2}x^2 \right]_{-1}^0 = \frac{1}{2}$$
  * **第二段 $L_2$（$x \in [0, 1]$）**：
    方程为 $y = 1 - x \implies \mathrm{d}y = -\mathrm{d}x$。
    此时 $|x| = x$。
    $$\int_{L_2} = \int_0^1 \left[ x(1-x)\,\mathrm{d}x + x^2(-\mathrm{d}x) \right] = \int_0^1 (x - 2x^2)\,\mathrm{d}x = \left[ \frac{1}{2}x^2 - \frac{2}{3}x^3 \right]_0^1 = \frac{1}{2} - \frac{2}{3} = -\frac{1}{6}$$
* **求和**：$I = \frac{1}{2} + \left(-\frac{1}{6}\right) = \frac{1}{3}$。

**耗时不到 1 分钟，且步步踩在初等微积分的安全区。**

### 应试决策树（考场 5 秒判断法）

拿到第二类曲线积分 $\int_L P\mathrm{d}x + Q\mathrm{d}y$：

```text
               是否存在绝对值 / 分段复杂表达式？
                       /             \
                    [是]             [否]
                     /                 \
        果断拆段，直接参数化代入算定积分       检查 P, Q 在目标区域内是否有“无定义点/奇点”
                                                /                  \
                                            [有奇点]               [处处光滑]
                                               /                      \
                                  挖洞(转化为算小圆周)        放心补最简单的线，用格林公式
                                  或利用几何意义(转角Δθ)     结合对称性化简二重积分
```

我考场上的想法是，写出这个 P (XY)，就完全等于二分之一 P (X)，所以选了 A

“连续型 $X$” 与 “离散型 $Y$” 的混合（相乘 $XY$ 或相加 $X+Y$）**：
  1. **第一反应**：绝不要直接找密度，**必须从分布函数 $F_Z(z) = P(Z \le z)$ 走全概率公式！**
  2. **第二反应**：检查离散变量取某些值时，会不会导致 $Z$ 变成常数（如 $Y=0 \implies Z=0$）。如果会，这个常数点就**必然是间断点**！


或者核心一句话，看 P (XY) 是否有某点概率值大于 0，那点就是 F (XY) 的间断点
  $$P(Z = 0) \ge P(Y = 0) \cdot P(X \cdot 0 = 0) = P(Y = 0) \cdot 1 > 0$$
  此时 $Z = 0$ 处聚集了正概率，**在 $z = 0$ 处产生 1 个间断点**。
