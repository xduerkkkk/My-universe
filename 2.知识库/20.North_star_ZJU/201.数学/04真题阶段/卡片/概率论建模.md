# 二项分布建模

原题之所以能秒杀，是因为抓住了二项分布的数学本质：**只要每次试验相互独立，且单次“成功”的概率 $p$ 相同，不管你在现实中把什么定义为“成功”（黑球、白球甚至硬币正面），总成功次数直接服从 $B(n_1+n_2, p)$**。

在考研数一中，这种**“看似是两件完全不同的事，但因单次概率相等而融合成同一个二项分布”**的思想极其高频。以下精选两道最经典的真题改编题：

---

### 经典改编一：跨道具的“同概率”合并（硬币与骰子）

> **【题目】** 
> 掷一颗质地均匀的六面骰子 4 次，记出现“点数能被 2 整除”的次数为 $X$；接着抛掷一枚均匀硬币 3 次，记出现“正面朝上”的次数为 $Y$。
> 求 $P\{X + Y = 3\}$。

#### 1. 常规做法的痛苦
如果列全概率公式，要分四种互斥情况：$(X=3,Y=0)$、$(X=2,Y=1)$、$(X=1,Y=2)$、$(X=0,Y=3)$，分别算组合数再相加，极易算错。

#### 2. 模型重构秒杀
- 掷骰子能被 2 整除（出现 2, 4, 6）的单次概率：$p_1 = \frac{3}{6} = \frac{1}{2}$；
- 掷硬币正面朝上的单次概率：$p_2 = \frac{1}{2}$；
- 两次试验完全独立，且**单次成功的概率完全相等（均为 $p = \frac{1}{2}$）**。

因此，数学本质就是**一共进行了 $4 + 3 = 7$ 次独立的伯努利试验，每次成功概率都是 $\frac{1}{2}$**！
总成功次数直接服从二项分布：
$X + Y \sim B\left(7, \frac{1}{2}\right)$

直接一步写出答案：
$P\{X + Y = 3\} = C_7^3 \left(\frac{1}{2}\right)^3 \left(\frac{1}{2}\right)^4 = \frac{35}{128}$

---

### 经典改编二：正反面视角的“互补转化”（考研神仙对称题）

> **【题目】** 
> 甲抛掷一枚均匀硬币 4 次，记正面朝上的次数为 $X$；乙抛掷同一枚硬币 3 次，记**反面朝上**的次数为 $Y$。
> 求 $P\{X + Y = 3\}$。

#### 1. 思维卡点
很多同学看到甲关注“正面”，乙关注“反面”，觉得这是两个相反的目标，不敢往一起并。

#### 2. 模型重构秒杀
因为硬币均匀，甲摸到正面的概率是 $\frac{1}{2}$，乙摸到反面的概率**也是 $\frac{1}{2}$**。
两者依然是“7 次独立试验，每次关注的事件概率均为 $\frac{1}{2}$”：
$X + Y \sim B\left(7, \frac{1}{2}\right)$
答案同样直接是 $C_7^3 \left(\frac{1}{2}\right)^7 = \frac{35}{128}$。

### 高阶拓展：甲比乙正面多的“零计算”秒杀

> **【真题高频原型】** 甲抛掷硬币 $n+1$ 次，乙抛掷硬币 $n$ 次，求甲正面朝上次数多于乙正面朝上次数的概率（即求 $P\{X > Y\}$）。

**传统做法**：双重级数求和，计算量爆炸。

**利用“反面重构”思维秒杀**：
1. 记乙抛出**反面**的次数为 $Y'$，显然 $Y' = n - Y$。
2. 于是目标概率等价变形为：
   $P\{X > Y\} = P\{X > n - Y'\} = P\{X + Y' \ge n + 1\}$
3. 注意：$X$ 是甲的正面数（单次概率 $\frac{1}{2}$），$Y'$ 是乙的反面数（单次概率也是 $\frac{1}{2}$）。
4. 所以 $X + Y'$ 表示**两人总共抛掷 $(2n+1)$ 次硬币中，特定面出现的总次数**：
   $X + Y' \sim B\left(2n+1, \frac{1}{2}\right)$
5. 在 $2n+1$ 次试验中，“成功次数 $\ge n+1$”的概率，由于二项分布关于中心完全对称（要么正面多，要么反面多，且不可能打平），其概率严格等于：
   $P\{X > Y\} = \mathbf{\frac{1}{2}}$

### 考研数一应试直觉法则

考场上识别这个模型的**金钥匙**只有一条：
**“两阶段、各自分开做，只要算出来的单次概率 $p_1 = p_2$，立马撕掉题目给的现实外衣，直接把总次数相加当作一个大二项分布处理！”**
