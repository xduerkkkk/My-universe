



> **核心逻辑**：对程序性错误（抄写/符号/漏项/漏绝对值/漏+C），**快算 + 快查** 优于 **全程慢算监控**。
> 算的时候信任手、专注计算、进 flow；一道算完，跑**一次专项检查 pass**。检查时成本低、捕获率高；全程监控会挤占工作记忆、拖慢并制造新错误。
> 清单是**暂存区不是永久表**：一条病灶内化成反射后就毕业删掉（出口一直排水，所以记得越多清单反而不膨胀）。

## 🟥 L1 普适检查动作（检查 pass 必跑的 3–5 条元动作）

> 几乎每题都可能出，固化成"算完后"的固定扫描动作。

- [ ] **括号**：一定一定检查括号！（层级、配对、负号作用域）
- [ ] **符号正负**：不等式变号、格林/二重积分方向带不带负号、变号步骤
- [ ] **长距离抄写核对**：设方程组、代入原式 → 笔尖点着逐项核对（项数/幂次/正负）
- [ ] **定义域 / 范围**：范围写全、端点、绝对值
- [ ] **收尾符号**：不定积分 +C、最后写成 `a=xxx` 落到草稿纸（不脑内移项）

## 🟨 L2 情境触发（嵌在动作里，题面唤起，零成本——不用背）

**检查 pass 的具体做法**：不是"重读"（会脑补会漏），而是——
1. 重新**推导**关键转折步（抄方程、代入、变号那几处）；
2. 扫一遍**合理性/量级**（范围、正负、量级对不对）；
3. 过一遍上面 L1 五条元动作。

### 高数
- 根号下平方 → 条件反射**绝对值**
- 看到距离 → 条件反射**绝对值**
- 洛必达 → 先同时洛再约分（别先导上面顺手约了下面）
- 没用泰勒 → 检查精度丢失；$1^\infty$ 便捷公式=等价无穷小，别无脑用
- 二重积分区域 → 定限必须**画线**（y>x / x>y 别看茬），看方向定正负号
- 积分代上下限 → 别脑中化简（如 $xy^2$ 积 y 上1下-1，实为0）
- $\ln x$ 的 x 带指数 → 指数清晰写到前面放出去
- 三重积分 → **不能代曲面方程**（其他可代）
- 格林公式 → 到 dxdy 那步**才**写外面正负号
- 曲面题 → 不自己"加盖子"，除非题目明说"围成的闭曲面/立体表面"
- 收敛域验端点、收敛区间不验；奇偶分情况查下标

### 线代
- 初等行变换做完 → 不仅查消元过程，还要查**各行与原来相比有没有抄错**
- 看好矩阵**几阶**，别默认 3 阶
- 二次型可逆/正交变换 → 注意**顺序**

### 概率论
- 遇"加号且独立" → 动词是"拆成和"：$D(\sum X_i)=\sum D(X_i)$
- 遇"倍数常数" → 动词是"提出来平方"：$D(kX)=k^2 D(X)$（括号内仅一个变量时）
- 求 $D(X)$ → 条件反射 $E(X^2)-(E(X))^2$
- 凑正态 → 注意分母、通分
- 二维分布函数（如 X+2Y）→ 注意最后画的图是 Y≥ 还是 ≤、绕 y=0 还是 x=0
- 分子分母都含概率 → 不跳步，草稿分别写一次
- 同一随机变量别当独立：$P(a\le T\le b)\ne P(T\ge a)\cdot P(T\le b)$，用分布函数
- $\bar x$ 不是常数，算 E 要用公式；检查是否有 $C_x^x$ 组合数
- 有括号隔开的两层指数 → "相乘"不是"算次方"

# 高数




- 洛必达，先同时洛再约分！以免先导上面的然后顺手给下面的约了
- 要是没用泰勒，一定要检查下是否精度丢失，注意，那个 1 的无穷次方的便捷公式就算没用泰勒，算是等价无穷小，所以要注意！不要无脑用！
- 不等式有负号，负数乘过去变号，但我又有一次把负号弄没。不等式相关运算多检查！

- 不定积分积完+C！
- 算积分，发现 x 区域负无穷正无穷函数都是无穷，别急着抵消！一定是发散的。只有收敛的才能抵消。
- 所有积分完代上下限的，别脑中化简，比如 $xy^2积y$ 上 1，下 -1，脑中化简容易留个 x。实际是 0
- ln x 的 x 上面有指数，清晰地把指数写到前面！放出去！
- 二重积分区域，y>x 和 x>y 老是看茬！定限时，必须画线
- 一看到二重积分积分区域，看好方向，到底要不要带负号！


- 收敛域，需要检验端点，收敛区间不需要。
- 奇偶分情况时，检查下标！

- 根号下平方，一定记得绝对值！
- 写的 x-x+a-1=1 然后答案写 a=1 。是消参之后大脑的携带！不要脑内移项，要求啥，最后必须写成 a=xxx，写到草稿纸上！

- 三重积分不能代曲面方程！其他的都可以代
- 格林公式时，一定是到二重积分 dxdy 那一步再把外面的正负号写出来
- 看到距离，条件反射绝对值！
- 告诉曲面那就是曲面，不要自己“加盖子”（14-18）除非题目明确说明 **“由……围成的闭曲面（或立体表面）”**，否则**绝不包含**顶面、底面或任何封口面。

# 概率论 ：



1. **遇到加号且独立 $\implies$ 动词是“拆成和”**：
   $D(X_1 + X_2 + \dots + X_n) = D(X_1) + D(X_2) + \dots + D(X_n)$
   *(独立变量的方差具有**可加性**，逐项相加，加 $n$ 项自然就是 $n$ 倍)*。
2. **遇到倍数常数 $\implies$ 动词是“提出来平方”**：
   $D(k X) = k^2 D(X)$
   *(只有括号里面只有**一个**变量、前面乘了数字时，才平方提出来)*。
（22 年最后一大题）


- 一定要把范围写好！（手稿 P71）


- 把**同一个随机变量**当成独立的了。请记住铁律：
 $$P(a \le T \le b) \neq P(T \ge a) \cdot P(T \le b)$$
用分布函数求！



- 凑正态分布时，一定注意分母！通分！


- 检查是否有 Cxx
- 求 D (x)，条件反射想到求 E (x 方)-(E (x)) 方
- 分子分母都有概率计算时，不要跳步！草稿写一次分母的计算，写一次分子的计算
- 算二维分布函数，X+2Y，这种，一定注意, 最后画的图是 Y>=还是<=
  
  注意是绕 y=0 还是 x=0 ![[_attachments/image/数学杜绝粗心-1791258290846.jpeg]]

- 别把 $\bar x$ 看成常数了！算其 E 要用公式算
- **有括号隔开，两层指数直接“相乘”，不是“算次方”！**
