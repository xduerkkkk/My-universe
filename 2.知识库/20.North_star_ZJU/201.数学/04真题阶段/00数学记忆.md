从 $n$ 个不同元素中取出 $k$ 个元素的组合数（$k \le n$）：

$$C_n^k = \frac{n!}{k!(n - k)!}$$

或者写成展开形式（分子从 $n$ 开始往下乘 $k$ 个数，分母是从 $1$ 乘到 $k$）：
$$C_n^k = \frac{n(n - 1)(n - 2)\cdots(n - k + 1)}{k!}$$

在莱布尼茨公式求高阶导数时，因为多项式一般最高也就 2 次或 3 次，你**只需要记住这几个最常出现的化简**：

* $k = 1$：$C_n^1 = n$
* $k = 2$：$C_n^2 = \frac{n(n - 1)}{2! \times 1} = \frac{n(n - 1)}{2}$
* $k = 3$：$C_n^3 = \frac{n(n - 1)(n - 2)}{3!} = \frac{n(n - 1)(n - 2)}{6}$

# 理解


唯一本质理解：$A = o(B)$ 代表“以 $B$ 为基准，$A$ 相比之下微不足道”

它的严格数学算式永远只有一条：
$$\lim \frac{A}{B} = 0$$
把 $B$ 放在分母当标尺，**比值为 0，意味着分子 $A$ 相比于分母 $B$，连一个零头都算不上**


以及，无论是 x 趋于无穷还是 0，指数越大，越高阶

# 几何公式

### 雅可比
如果有变量代换：$x = x(u, v),\ y = y(u, v)$，雅可比行列式定义为一阶偏导数组成的行列式：
$$J = \frac{\partial(x, y)}{\partial(u, v)} = 
\begin{vmatrix} 
\frac{\partial x}{\partial u} & \frac{\partial x}{\partial v} \\ 
\frac{\partial y}{\partial u} & \frac{\partial y}{\partial v} 
\end{vmatrix}$$

* **最经典的例子（普通极坐标）**：
  $x = r\cos\theta,\ y = r\sin\theta$
  $$J = 
  \begin{vmatrix} 
  \cos\theta & -r\sin\theta \\ 
  \sin\theta & r\cos\theta 
  \end{vmatrix} 
  = r\cos^2\theta - (-r\sin^2\theta) = r$$
  所以平时背的公式 $dxdy = r\,drd\theta$，里面的 $r$ **就是雅可比行列式的结果**！

# 不等式
对**任意实数** $a, b$（无论正负）：
1. 由 $(|a| - |b|)^2 \ge 0 \implies a^2 + b^2 \ge 2|ab|$ （因为 $|a|^2 = a^2$）
2. 由绝对值性质：$-|ab| \le ab \le |ab|$

把它们连在一起，就得到了考研中最完整的**“全景不等式链”**：
$$-(a^2 + b^2) \le 2ab \le 2|ab| \le a^2 + b^2$$

带不带绝对值，用哪个不等式完全取决于目的


**$\ln(1+t) < t$ 恒成立**

 **$e^x \ge 1+x$**（$x \in \mathbb{R}$，下凸曲线在切线上方，当且仅当 $x=0$ 取等号）


* 当 $x > 0$ 时：$x - \frac{x^2}{2} < \ln(1+x) < x$
* 当 $x > 0$ 时：$1 + x + \frac{x^2}{2} < e^x$


几何来源：单位圆中“正弦线 < 弧长 < 正切线”。
* **$\sin x < x < \tan x$**
* **$\arctan x < x < \arcsin x$**
* **组合链条**：在 $(0, \frac{\pi}{2})$ 内由小到大排列为：
  $$\sin x < \arctan x < x < \arcsin x < \tan x$$

*进阶强化（泰勒截断）*：
* 当 $x > 0$ 时：$x - \frac{x^3}{6} < \sin x < x$
* 当 $x \neq 0$ 时：$1 - \frac{x^2}{2} < \cos x < 1$
