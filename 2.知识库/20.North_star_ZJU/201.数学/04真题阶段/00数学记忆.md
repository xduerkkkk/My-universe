### 特征

矩阵分解成俩个矩阵后，原矩阵特征值通常不是这两个特征值和，除非俩特值向量一样。所以可以拆E！

正交矩阵的实特征值是 1 或-1！


**谱映射定理（特征值映射定理）**：
> 若 $Ax = \lambda x$（$x \ne \mathbf{0}$），则对于任意多项式 $f(t)$，都有 $f(A)x = f(\lambda)x$。
> 当题目给出矩阵方程 **$f(A) = \mathbf{0}$** 时，代入得 $f(\lambda)x = \mathbf{0} \implies \mathbf{f(\lambda) = 0}$。
> 即：**矩阵满足什么多项式方程，它的特征值 $\lambda$ 就必须满足代数方程**。

- **条件**：$A^2 = A$（即 $A^2 - A = 0$）
- **转化**：$\lambda^2 - \lambda = 0 \implies \lambda(\lambda - 1) = 0 \implies \mathbf{\lambda \text{ 只能是 } 0 \text{ 或 } 1}$。

- **条件**：$A^2 = E$（即 $A^2 - E = 0$）
- **转化**：$\lambda^2 - 1 = 0 \implies \mathbf{\lambda \text{ 只能是 } 1 \text{ 或 } -1}$。

- 设 $A$ 为实对称矩阵，且满足 $A^3 + A = \mathbf{0}$，求 $A$。
- **转化**：
  $\lambda^3 + \lambda = 0 \implies \lambda(\lambda^2 + 1) = 0$。
  解这个方程得到根为：$\lambda = 0, \pm i$。
- **降维打击**：
  考研核心定理——**实对称矩阵的特征值必须全部是实数！**
  所以虚根 $\pm i$ 被强行杀掉，$\lambda$ 只能全部为 $0$。
  又因为实对称矩阵必可相似对角化（相似于全 0 矩阵 $\Lambda = \mathbf{0}$）：
  $A = P \mathbf{0} P^{-1} \implies \mathbf{A = 0}$（直接证明了 $A$ 是零矩阵）。

### 配方理解秩
$AB = C$ 
（$A$ 行相关 $\implies C$ 行必相关）；
（$C$ 行无关 $\implies A$ 行必无关）；

右乘行满秩 $r(BA) = r(B)$，
左乘列满秩 $r(AB) = r(B)$
在 $BA$ 中，$B$ 是配方，$A$ 的行是材料。
    $A$ **行满秩**，说明底层材料彼此**绝对线性无关（健全）**。底层的基底没有任何内部虚假抵消，所以配方 $B$ 具有多少维的独立性，组合出来的成品 $BA$ 就完整保留多少维的独立性：
    $$k^T(BA) = \mathbf{0} \iff (k^T B) A = \mathbf{0} \iff k^T B = \mathbf{0} \implies r(BA) = r(B)$$
  * **左乘**：在 $AB$ 中，$A$ 列满秩，意味着变换 $A$ 是**单射（不降维、解空间只有原点）**，配方 $B$ 张出的子空间在映射后完全保维。

$BA = E_m$（乘积是单位矩阵）
是第一行的特殊情况 
提供配方的 **$B$ 的各行绝不能有任何内部相关**（否则成品必继承相关性），所以 **$B$ 必须行满秩**；
同理，从列视角看，输入变换的 **$A$ 的各列也绝不能有任何坍塌**，所以 **$A$ 必须列满秩**。



问“谁是谁的解 / 谁能表示谁”时：
写出 **$A = PB$** $\implies$ **$Ax = PBx$**。
B 行可以表示 A 行，则存在 PB = A 那 Bx=0 的 x 一定能让 PBx = 0 ，即 B 的解一定都是 A 的解；
由于 P 不一定满秩，反过来 PBx = 0 的 x 不一定是 Bx = 0 的 x ，所以 A 的解不一定是 B 的解。

### 分式分解

**分子的次数，永远比括号里的“底数（质因式）”低一次，和外面的幂次无关！**

有理分式展开只有以下两种基本模型：

底数是一次式 $(x-a)^k$（包括 $t^2 = (t-0)^2$）
* 底数 $t$ 是一次，比它低一次就是 **0 次（常数）**。
* 逐级降幂展开，**每一项的分子全都必须是常数**！
* **示例**：
  $$\frac{1}{(t-1)^3} \implies \frac{A}{t-1} + \frac{B}{(t-1)^2} + \frac{C}{(t-1)^3} \quad (\text{分子全为常数})$$

底数是实数内不可分解的二次式 $(x^2+px+q)^k$
* 底数是二次，比它低一次就是 **1 次（$Ax+B$）**。
* 逐级降幂展开，**每一项的分子全都设为一次式**。
* **示例**：
  $$\frac{1}{(x^2+1)^2} \implies \frac{Ax+B}{x^2+1} + \frac{Cx+D}{(x^2+1)^2}$$



导数存在，则要么连续，要么震荡


### 莱布尼茨公式求高阶导数
在莱布尼茨公式求高阶导数时，因为多项式一般最高也就 2 次或 3 次，你**只需要记住这几个最常出现的化简**：

* $k = 1$：$C_n^1 = n$
* $k = 2$：$C_n^2 = \frac{n(n - 1)}{2! \times 1} = \frac{n(n - 1)}{2}$
* $k = 3$：$C_n^3 = \frac{n(n - 1)(n - 2)}{3!} = \frac{n(n - 1)(n - 2)}{6}$

#### 期望

若是二维变量的期望，去思考二维联合概率密度，尤其说独立就是送你联合概率密度表达式


**求谁的期望，被积变量就是谁，后面乘上它自己的概率密度**。

请对比以下两个方向：

 方向 1：正着给——告诉你变量关系，求分布函数
已知 $Y = 2X + 1$，求 $F_Y(y)$：
$F_Y(y) = P(Y \le y) = P(2X + 1 \le y) = P\left(X \le \frac{y - 1}{2}\right) = F_X\left(\frac{y - 1}{2}\right)$
- **你看：因为解不等式需要移项除以 2，所以分布函数里的自变量变成了 $\frac{y-1}{2}$！**

方向 2：反着给——告诉你分布函数，反求变量关系（本题）
已知 $F_Y(y) = F_X(2y + 1)$，求 $Y$ 与 $X$ 的关系：
$P(Y \le y) = P(X \le 2y + 1) = P\left(\frac{X - 1}{2} \le y\right)$
两端“$\le y$”对齐，立马看出：
$Y \overset{d}{=} \frac{X - 1}{2}$

### 组合数
从 $n$ 个不同元素中取出 $k$ 个元素的组合数（$k \le n$）：

$$C_n^k = \frac{n!}{k!(n - k)!}$$

或者写成展开形式（分子从 $n$ 开始往下乘 $k$ 个数，分母是从 $1$ 乘到 $k$）：
$$C_n^k = \frac{n(n - 1)(n - 2)\cdots(n - k + 1)}{k!}$$

### 二维正态

| 命题方向                 | 结论真伪         | 核心考点 / 记忆口诀                                                                            |
| :------------------- | :----------- | :------------------------------------------------------------------------------------- |
| **二维 $\implies$ 一维** | **真**        | 降维不丢正态性（联合正态，边缘一定正态）                                                                   |
| **一维 $\implies$ 二维** | **假**（一般情况下） | 边缘正态推不出联合正态（必须加**独立**才成立）                                                              |
| **线性组合 $aX + bY$**   | **看前提！**     | 只要是“**联合正态**”或是“**独立的一维正态**”，线性组合必为正态；若仅告知“$X, Y$ 分别正态”而不提联合/独立，其和 $X+Y$ **不一定是正态分布**！ |




| 已知前提 | 是否不相关（$\rho=0$）？ | 是否相互独立？ | 是否是二维正态 $(X, Y) \sim N$？ |
| :--- | :---: | :---: | :---: |
| **$(X, Y) \sim N$，且 $\rho = 0$** | **是** | **是**（正态特权） | 本身就是 |
| **$X \sim N, Y \sim N$ 且相互独立** | **是**（独立必不相关） | **是** | **是**（参数 $\rho=0$） |
| **$X \sim N, Y \sim N$ 且仅不相关** | **是** | **否 / 不一定** | **否 / 不一定** |

> **一句话总结**：
> 要想使用“不相关 $\iff$ 独立”，**必须先保证已经是二维正态联合分布**；如果仅仅是两个一维正态，就算不相关，也不能互推！

Pdx+Qdy，当我们发现 Q 对 x 偏导等于P 对 y偏导，
1. 我们可以说P 是某个连续可导函数对x 偏导，Q 是对y 偏导，
   那么对此式子求积分，则可以求得原函数。在下限和上限求积分，则是原函数上限的值减去下限的值
2. 点 1 已经说明了积分结果与路径无关，从格林公式这也能理解，取一条线与积分路径围成封闭的，积分结果是二重积分减去取的线的积分，可二重积分结果是 0，所以取决于取的线的积分，只要无无定义点，想怎么取怎么取。

# 几何公式

### 雅可比
如果有变量代换：$x = x(u, v),\ y = y(u, v)$，雅可比行列式定义为一阶偏导数组成的行列式：
$$J = \frac{\partial(x, y)}{\partial(u, v)} = 
\begin{vmatrix} 
\frac{\partial x}{\partial u} & \frac{\partial x}{\partial v} \\ 
\frac{\partial y}{\partial u} & \frac{\partial y}{\partial v} 
\end{vmatrix}$$

* **最经典的例子（普通极坐标）**：
  $x = r\cos\theta,\ y = r\sin\theta$
  $$J = 
  \begin{vmatrix} 
  \cos\theta & -r\sin\theta \\ 
  \sin\theta & r\cos\theta 
  \end{vmatrix} 
  = r\cos^2\theta - (-r\sin^2\theta) = r$$
  所以平时背的公式 $dxdy = r\,drd\theta$，里面的 $r$ **就是雅可比行列式的结果**！

# 不等式
对**任意实数** $a, b$（无论正负）：
1. 由 $(|a| - |b|)^2 \ge 0 \implies a^2 + b^2 \ge 2|ab|$ （因为 $|a|^2 = a^2$）
2. 由绝对值性质：$-|ab| \le ab \le |ab|$

把它们连在一起，就得到了考研中最完整的**“全景不等式链”**：
$$-(a^2 + b^2) \le 2ab \le 2|ab| \le a^2 + b^2$$

带不带绝对值，用哪个不等式完全取决于目的


**$\ln(1+t) < t$ 恒成立**

 **$e^x \ge 1+x$**（$x \in \mathbb{R}$，下凸曲线在切线上方，当且仅当 $x=0$ 取等号）


* 当 $x > 0$ 时：$x - \frac{x^2}{2} < \ln(1+x) < x$
* 当 $x > 0$ 时：$1 + x + \frac{x^2}{2} < e^x$


几何来源：单位圆中“正弦线 < 弧长 < 正切线”。
* **$\sin x < x < \tan x$**
* **$\arctan x < x < \arcsin x$**
* **组合链条**：在 $(0, \frac{\pi}{2})$ 内由小到大排列为：
  $$\sin x < \arctan x < x < \arcsin x < \tan x$$

*进阶强化（泰勒截断）*：
* 当 $x > 0$ 时：$x - \frac{x^3}{6} < \sin x < x$
* 当 $x \neq 0$ 时：$1 - \frac{x^2}{2} < \cos x < 1$
