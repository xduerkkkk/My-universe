
你想起来的是**二阶常系数非齐次微分方程“剥离 $e^{\lambda x}$”的核心公式**！不过你把系数顺序记反了一点点。

---

### 一、正确的公式（记住“几阶导配几阶导”）

设特征多项式为 $L(r) = r^2 + pr + q$（也就是你图里的 $f(r)$）。
对于方程 $y'' + py' + qy = P_n(x) e^{\lambda x}$，令 $y^* = u(x) e^{\lambda x}$，代入原方程并消去 $e^{\lambda x}$ 后，会精准化简为：

$$u'' + L'(\lambda) u' + L(\lambda) u = P_n(x)$$

**防记混口诀（类似泰勒展开）**：
* $u$（0 阶导）配 $L(\lambda)$（0 阶导）
* $u'$（1 阶导）配 $L'(\lambda)$（1 阶导）
* $u''$（2 阶导）配 $\frac{1}{2!} L''(\lambda)$（就是 $1$）

---

### 二、这个公式干嘛用的？（两大神级作用）

#### 作用 1：彻底看懂“为什么设特解要乘 $x^k$”（不用死背）
拿你图里的题 $P_n(x) = x$ 为例，方程剥离 $e^{\lambda x}$ 后就是：
$$u'' + f'(\lambda) u' + f(\lambda) u = x$$

* **非特征根（$f(\lambda) \neq 0$）**：$u$ 这一项还在。右边是 1 次多项式，左边 $u$ 设为 **1 次** $ax+b$ 就够了。（注：图里 A 选项错在漏了常数项 $b$，因为 $u'$ 会产生常数，需要 $b$ 去抵消。）
* **单根（$f(\lambda) = 0, f'(\lambda) \neq 0$）**：$u$ 这一项没了，方程退化成 $u'' + f'(\lambda) u' = x$。既然 $u'$ 是 1 次的，积分一次，$u$ 就得是 **2 次**的，且常数项求导就没了，所以设为 $x(ax+b) = ax^2 + bx$。
* **二重根（$f(\lambda) = 0, f'(\lambda) = 0$）**：$u$ 和 $u'$ 全没了，方程退化成：
  $$u'' = x$$
  $u''$ 是 1 次的，积分两次，$u$ 就得是 **3 次**的（1 次项和常数项求二阶导全为 0，省掉不写），所以设为 $x^2(ax+b) = ax^3 + bx^2$，正好对应图里的 **(C)**！

#### 作用 2：考场大题算特解的“防算错神技”
大题让你求 $y'' + py' + qy = P_n(x) e^{\lambda x}$ 的具体特解时，**千万别傻傻把 $y^* = u(x)e^{\lambda x}$ 用乘法法则求两遍导**（算到怀疑人生还容易错）。
直接用这个公式把 $e^{\lambda x}$ 剥掉，只剩多项式求导：
* 尤其遇到**二重根**时，方程直接退化成 $u'' = P_n(x)$，**连待定系数都不用设，直接对 $P_n(x)$ 积分两次**，5 秒出特解（比如这题 $u'' = x \implies u = \frac{1}{6}x^3 \implies y^* = \frac{1}{6}x^3 e^{\lambda x}$）！
* **大题写步骤注意**：考场上用这招在草稿纸上秒算出特解系数后，卷面上只需写“设特解 $y^* = \dots$，代入原方程解得 $a = \dots, b = \dots$”即可，既稳拿满分又省出大把时间。






冲刺阶段绝对不让你背复杂套路。下面这个**“剥壳公式”**只需要记**一行式子**，就能通杀所有二阶常系数非齐次微分方程 $y'' + py' + qy = P(x)e^{\lambda x}$ 的特解，**彻底告别硬求导算错**。

### 一、唯一要记的公式（零负担）
特征多项式你本来就要写，记作 $L(r) = r^2 + pr + q$。
设特解为 $y^* = u(x)e^{\lambda x}$，把 $e^{\lambda x}$ 剥掉之后，剩下的多项式 $u(x)$ 满足：

$$u'' + L'(\lambda)u' + L(\lambda)u = P(x)$$

**为什么成立（2 句话理解，绝不会忘）**：
给 $u(x)e^{\lambda x}$ 求导，每求一次导，$e^{\lambda x}$ 都会多吐出一个 $\lambda$，本质上就是把特征多项式里的 $r$ 替换成 $r+\lambda$。
把 $L(r+\lambda) = (r+\lambda)^2 + p(r+\lambda) + q$ 按 $r$ 的幂次展开，就是：
$$r^2 + (2\lambda+p)r + (\lambda^2+p\lambda+q)$$
系数正好就是 **$1$、$L'(\lambda)$、$L(\lambda)$**！其中 $r^2$ 对应 $u''$，$r$ 对应 $u'$，常数项对应 $u$。

---

### 二、拿刚才图一实战演示（10 秒出 $a, b$）
原方程：$y'' - 5y' + 6y = xe^{2x}$
1. 写特征多项式并求导（顺手的事）：
   * $L(r) = r^2 - 5r + 6$
   * $L'(r) = 2r - 5$
2. 代入右边指数 $\lambda = 2$：
   * $L(2) = 0$（因为是单根，必然为 $0$）
   * $L'(2) = 2(2) - 5 = -1$
3. 直接写出 $u$ 的方程：
   $$u'' - u' = x$$
4. 代入 $u = ax^2 + bx$（此时 $u' = 2ax + b, \ u'' = 2a$，**心算级难度**）：
   $$2a - (2ax + b) = x \implies -2ax + (2a - b) = x$$
   立刻对比系数：$-2a = 1, \quad 2a - b = 0 \implies a = -\frac{1}{2}, \quad b = -1$。

*(如果是**二重根**，则 $L(\lambda)=0$ 且 $L'(\lambda)=0$，方程直接退化成 $u'' = P(x)$，连 $a, b$ 都不用设，**把 $P(x)$ 直接积分两次**就出 $u(x)$！)*

### 四、立刻动手练 4 道（覆盖全部 3 种情况）
只求特解 $y^*$，拿出草稿纸，**限时 3 分钟**，用上面的公式秒掉它们：

1. **单根热身**：$y'' - 3y' + 2y = (2x + 1)e^x$
2. **单根进阶（系数不为 $\pm 1$）**：$y'' + y' - 6y = (10x + 7)e^{2x}$
3. **二重根（体验直接积分的快感）**：$y'' - 4y' + 4y = (6x - 2)e^{2x}$
4. **不是特征根**：$y'' - y' - 2y = (4x + 9)e^{3x}$

---

### 核对答案（算完再看）

1. **$L(1)=0, \ L'(1)=-1$**
   * $u'' - u' = 2x + 1$，设 $u = ax^2 + bx$
   * $2a - (2ax + b) = 2x + 1 \implies a = -1, \ b = -3$
   * **答案**：$y^* = (-x^2 - 3x)e^x$

2. **$L(2)=0, \ L'(2)=5$**
   * $u'' + 5u' = 10x + 7$，设 $u = ax^2 + bx$
   * $2a + 5(2ax + b) = 10ax + (2a + 5b) = 10x + 7 \implies a = 1, \ b = 1$
   * **答案**：$y^* = (x^2 + x)e^{2x}$

3. **$L(2)=0, \ L'(2)=0$（二重根直接积分两次！）**
   * $u'' = 6x - 2 \implies u' = 3x^2 - 2x \implies u = x^3 - x^2$
   * **答案**：$y^* = (x^3 - x^2)e^{2x}$

4. **$L(3)=4, \ L'(3)=5$（非根不乘 $x$）**
   * $u'' + 5u' + 4u = 4x + 9$，设 $u = ax + b$（注意 $u'' = 0$）
   * $5a + 4(ax + b) = 4ax + (5a + 4b) = 4x + 9 \implies a = 1, \ b = 1$
   * **答案**：$y^* = (x + 1)e^{3x}$

这 4 道全对的话，这辈子二阶微分方程特解的计算你就再也不会错了。做完直接发下一批线面大题！
