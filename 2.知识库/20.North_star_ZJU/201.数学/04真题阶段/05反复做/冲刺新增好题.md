## 收什么、怎么记

- **收**：题目贴近真题，这次没能独立做出，或同一计算／审题动作反复错，确实值得隔几天再写。不因题源是模拟卷就一律排除，但不批量接入现有模拟卷记录；偏难特殊手法先不收。
- **每题最少留三样**：题源题号＋题干或截图＋一句“我卡在哪一行”。有原笔记就链接，不必再搬一遍长解析；订正时补关键起手和下次检查动作即可。
- **怎么复做**：先遮住答案独立写；卡住才查，隔2—3天再做。顺了就在原条目补一句“复测已顺”，不搬文件，不另建统计表。
- **与旧库一起用**：有近期未解决题，优先处理；没有就按现有训练库继续。不能让这个文件变成另一份每天必须清空的任务。

**死记这套万能 2 步模板（全概率公式 + 左闭右开铁律）**：
设 $A$ 为启动失败（$P(A)=p$），$\bar{A}$ 为启动成功（$P(\bar{A})=1-p$）。对任意 $y$，无脑先写全概率：
$$F_Y(y) = P(Y \le y) = P(A)P(Y \le y \mid A) + P(\bar{A})P(Y \le y \mid \bar{A})$$

然后把数轴按跳跃点（$0$ 和 $2$）切成**左闭右开**三段：
1. **当 $y < 0$ 时**：工作时间不可能为负，直接 $F_Y(y) = 0$。
2. **当 $0 \le y < 2$ 时**：
   * 若启动失败（$A$ 发生），则 $Y=0 \le y$ 必然成立 $\implies P(Y \le y \mid A) = 1$；
   * 若启动成功（$\bar{A}$ 发生），因 $y < 2$ 未到定时关机时间，$\{Y \le y\} \iff \{X \le y\} \implies P(Y \le y \mid \bar{A}) = 1 - e^{-\frac{y}{10}}$。
   * 代入全概率：
     $$F_Y(y) = p \cdot 1 + (1-p)\left(1 - e^{-\frac{y}{10}}\right) = 1 - (1-p)e^{-\frac{y}{10}}$$
3. **当 $y \ge 2$ 时**：最多工作 $2$ 小时，必然 $Y \le y$，直接 $F_Y(y) = 1$。

合并写成标准分段函数（注意变量统一用 $y$）：
$$F_Y(y) = \begin{cases} 0, & y < 0 \\ 1 - (1-p)e^{-\frac{y}{10}}, & 0 \le y < 2 \\ 1, & y \ge 2 \end{cases}$$

> **防错铁律**：分布函数永远**右连续**，所以分段区间永远是**左闭右开**（$y < 0,\; 0 \le y < 2,\; y \ge 2$），绝不写 $y \le 0$！写完把端点 $y=0$ 代入中间段，正好等于 $p$（右连续），1 秒验算完毕！

1. 题目求“可逆矩阵 $P$”，使 $P^T P = A$（比如 $\|PX\|^2 = X^T A X$）
**不插 $Q^T Q$，直接把 $\Lambda$ 劈成两半，往前配转置：**
$$A = Q \Lambda^{\frac{1}{2}} \Lambda^{\frac{1}{2}} Q^T = \big(\Lambda^{\frac{1}{2}} Q^T\big)^T \big(\Lambda^{\frac{1}{2}} Q^T\big)$$
直接取 **$P = \Lambda^{\frac{1}{2}} Q^T$**。（显然可逆，且只需数乘 $Q^T$ 的各行，零矩阵乘法！）

#### 2. 题目求“实对称矩阵 $P$”，使 $P^2 = A$（或同时满足 $P^T = P$ 和 $P^T P = A$）
**中间插一个 $Q^T Q$，凑成自己乘自己：**
$$A = Q \Lambda^{\frac{1}{2}} (Q^T Q) \Lambda^{\frac{1}{2}} Q^T = \big(Q \Lambda^{\frac{1}{2}} Q^T\big)^2$$
直接取 **$P = Q \Lambda^{\frac{1}{2}} Q^T$**。（显然实对称且可逆！）
