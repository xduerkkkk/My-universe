
# 相似、合同、秩

**$A = P^T P$（$P$ 可逆）是“正定矩阵”的充要条件**！

特征值相同，还要几何和代数重数都相同，才相似。所以光特征值相同不够，还要看几何重数

合同，乘的矩阵和转置矩阵都是可逆矩阵（定义的吗？） 相似和合同秩都相同。
p+q=秩。


判相似：
  

```
步骤 1【看特征值】
计算 |λE - A| 和 |λE - B|
├── 特征值不全相同 ───────────────> 必不相似！
└── 特征值完全相同 ───────────────> 走步骤 2

步骤 2【看是否可对角化】
├── 两者都能对角化 ───────────────> 必相似！(都相似于同一对角阵)
├── 一个能对角化，一个不能 ───────> 必不相似！
└── 两者都不能对角化 ─────────────> 走步骤 3

步骤 3【不可对角化时的终极交锋】
计算各自特征向量个数 n - r(λE - M)
├── 特征向量个数不相等 ───────────> 必不相似！
└── 特征向量个数相等 ─────────────> 计算 (λE - M)² 的秩是否相等 (考研99%止步于此)
```


判合同：
**对称阵无论与谁合同，都必是对称阵**

```
步骤 0【验明正身（前提）】
检查矩阵 A 和 B 是否都是实对称矩阵（A^T = A, B^T = B）
├── 只要有一个不是 ───────────────> 考研大纲外 / 直接判定不适用二次型合同理论
└── 两者都是实对称矩阵 ───────────> 走步骤 1

步骤 1【必要条件快速排雷（3秒秒杀）】
看矩阵的「秩」和「行列式符号」
├── 秩不相等（r(A) ≠ r(B)） ──────> 必不合同！
├── 行列式正负号不同（|A|·|B| < 0）─> 必不合同！ (因 |B| = |C|²·|A|，符号必一致)
└── 秩相同 且 行列式符号同号 ─────> 走步骤 2

步骤 2【求正、负惯性指数 (p, q)】
根据题型特征，选最高效的计算方式：
├── 题型A（给了二次型表达式）：用【配方法】直接数正负平方项个数
├── 题型B（给了具体数字矩阵）：求【特征值】，只看正负号，不关心具体数值
└── 题型C（已知两者相似 A~B）：根据【实对称阵相似必合同】，直接判定合同！

步骤 3【终极裁决】
对比两者的正惯性指数 p 和 负惯性指数 q
├── (p_A, q_A) 完全等于 (p_B, q_B) ──> 必合同！
└── 只要 p 或 q 有一个不相等 ───────> 必不合同！
```

**如果一个矩阵和对称矩阵合同，那它自己也必须是对称矩阵！**


1.  **$A^T A$ 和 $A A^T$ 永远是对称半正定矩阵**（特征值全 $\ge 0$）。
2.  **秩守恒**：$r(A^T A) = r(A A^T) = r(A)$。
3.  **正定判定**：$A^T A$ 为正定矩阵 $\iff r(A) = n$（即 $A$ 的列向量组线性无关，满列秩）。

# 正交矩阵，实对称矩阵，正定矩阵

正交矩阵，QQ^T=E，每一列每一行都是单位向量，必定能定义为某个矩阵的特征向量们
其所有特征值模长一定是 1


实对称矩阵是 Q=Q^T 
讨论正定矩阵，一定是在实对称矩阵基础上，

实对称矩阵特征值代数重数和几何重数是相同的

正交矩阵一定可逆

正定矩阵一定可逆

只有**实对称矩阵**的特征值才保证全是实数。正交矩阵经常有虚数特征值

在考研真题中，看到 **$A = P^\mathrm{T} P$** 且 **$P$ 可逆**：
* 脑子里立刻形成肌肉记忆：**它等价于说“$A$ 是正定矩阵”**。
* 如果题目没说 $P$ 可逆（只是一般矩阵），那 $A = P^\mathrm{T} P$ 只能推出 **$A$ 半正定**（$\|PX\|^2 \ge 0$）。


# 施密特？知一求二？

### 一、 “知一求二”在考研中的两种打法

题目已知 $\boldsymbol{q}_3 = \left(\frac{\sqrt{2}}{2}, 0, \frac{\sqrt{2}}{2}\right)^\mathrm{T}$，要求另外两个与它互相垂直的单位向量 $\boldsymbol{q}_1, \boldsymbol{q}_2$。

#### 打法 1：解方程法（通法）
* **空间逻辑：** $\boldsymbol{q}_3$ 是法向量，垂直于它的所有向量构成平面 $\boldsymbol{q}_3^\mathrm{T} \boldsymbol{x} = 0 \implies x_1 + x_3 = 0$。
* **操作：** 找该方程的两个线性无关解 $\boldsymbol{\alpha}_1, \boldsymbol{\alpha}_2$，再正交化、单位化。

#### 打法 2：三维空间特有的“叉乘法”（极快，免去方程求解）
* **空间逻辑：** 三维空间中，两个正交向量的**外积（叉乘）**必然同时垂直于这两个向量，且长度就是两向量围成的面积。
* **操作：**
  1. 凭肉眼直接观察，找一个与 $\boldsymbol{q}_3$ 显然正交的单位向量（比如只要让点积为 0）：
     直接令 $y$ 轴方向 $\boldsymbol{q}_1 = (0, 1, 0)^\mathrm{T}$，显然 $\boldsymbol{q}_1 \cdot \boldsymbol{q}_3 = 0$ 且模长为 1。
  2. 第二个向量 $\boldsymbol{q}_2$ **不用解方程，直接叉乘**：
     $$\boldsymbol{q}_2 = \boldsymbol{q}_3 \times \boldsymbol{q}_1 = \begin{vmatrix} \boldsymbol{i} & \boldsymbol{j} & \boldsymbol{k} \\ \frac{\sqrt{2}}{2} & 0 & \frac{\sqrt{2}}{2} \\ 0 & 1 & 0 \end{vmatrix} = \left(-\frac{\sqrt{2}}{2}, \, 0, \, \frac{\sqrt{2}}{2}\right)^\mathrm{T}$$
  这样 $\boldsymbol{q}_1, \boldsymbol{q}_2, \boldsymbol{q}_3$ 两两正交且全为单位向量，耗时不到 10 秒。

### 二、施密特正交化的本质与“避坑技巧”

如果在打法 1 中，你求出的基础解系 $\boldsymbol{\alpha}_1, \boldsymbol{\alpha}_2$ **并不正交**，就必须用施密特正交化。

#### 1. 施密特的几何本质：投影相减
公式：$\boldsymbol{\beta}_2 = \boldsymbol{\alpha}_2 - \frac{(\boldsymbol{\alpha}_2, \boldsymbol{\beta}_1)}{(\boldsymbol{\beta}_1, \boldsymbol{\beta}_1)} \boldsymbol{\beta}_1$
* **几何意义：** 后半部分 $\frac{(\boldsymbol{\alpha}_2, \boldsymbol{\beta}_1)}{(\boldsymbol{\beta}_1, \boldsymbol{\beta}_1)} \boldsymbol{\beta}_1$ 正好是 $\boldsymbol{\alpha}_2$ 在 $\boldsymbol{\beta}_1$ 方向上的**正交投影向量**。
* 用原向量减去它在 $\boldsymbol{\beta}_1$ 上的投影分量，剩下的部分自然就和 $\boldsymbol{\beta}_1$ 垂直了。

#### PS ：三维

1. **前面两步做了什么？**
   * $\boldsymbol{\beta}_1$ 确定了一条直线；
   * $\boldsymbol{\beta}_2$ 垂直于 $\boldsymbol{\beta}_1$；
   * 此时，互相垂直的 $\boldsymbol{\beta}_1$ 和 $\boldsymbol{\beta}_2$ **共同张成了一个二维平面 $\Pi$**。

2. **$\boldsymbol{\beta}_3$ 的目标是什么？**
   * 我们要找一个与 $\boldsymbol{\beta}_1$ 和 $\boldsymbol{\beta}_2$ 都垂直的向量，也就是说，**$\boldsymbol{\beta}_3$ 必须垂直于整个平面 $\Pi$（即平面的法向量）**。

3. **如何得到平面的垂线（法向量）？**
   * $\boldsymbol{\alpha}_3$ 是一个斜插在平面外的空间向量。
   * 要让它垂直于平面，只需要：
     $$\boldsymbol{\beta}_3 = \boldsymbol{\alpha}_3 - (\boldsymbol{\alpha}_3 \text{ 在平面 } \Pi \text{ 上的正交投影})$$

4. **为什么公式是减去两项？**
   * 因为平面 $\Pi$ 内部的两个基底 $\boldsymbol{\beta}_1$ 和 $\boldsymbol{\beta}_2$ 已经是**互相垂直**的了（形成了笛卡尔直角坐标系）。
   * 所以，$\boldsymbol{\alpha}_3$ 在平面 $\Pi$ 上的总投影向量，**正好等于它在 $\boldsymbol{\beta}_1$ 轴上的投影分量与在 $\boldsymbol{\beta}_2$ 轴上的投影分量之和**：
     $$\text{平面上的总投影} = \underbrace{\frac{(\boldsymbol{\alpha}_3, \boldsymbol{\beta}_1)}{(\boldsymbol{\beta}_1, \boldsymbol{\beta}_1)} \boldsymbol{\beta}_1}_{\boldsymbol{\beta}_1 \text{方向的投影分量}} + \underbrace{\frac{(\boldsymbol{\alpha}_3, \boldsymbol{\beta}_2)}{(\boldsymbol{\beta}_2, \boldsymbol{\beta}_2)} \boldsymbol{\beta}_2}_{\boldsymbol{\beta}_2 \text{方向的投影分量}}$$

把这两个分量同时从 $\boldsymbol{\alpha}_3$ 中扣除，剩下的向量 $\boldsymbol{\beta}_3$ 就和这个平面彻底垂直了。
#### 2. 应试改版技巧：如何“主动避开”施密特正交化？
在求重特征值的特征向量时，解基础解系选取自由变量是有技巧的，**可以人为构造出互相正交的解，彻底跳过施密特化简**：

对于方程 $x_1 + x_3 = 0$（自由未知量是 $x_2, x_3$）：
* 第一个解向量让 $x_2 = 1, x_3 = 0$，得 $\boldsymbol{\alpha}_1 = (0, 1, 0)^\mathrm{T}$。
* 为了让第二个解向量 $\boldsymbol{\alpha}_2$ 与 $\boldsymbol{\alpha}_1$ 垂直，两者的点积必须为 0，即必须有 $0 \cdot x_1 + 1 \cdot x_2 + 0 \cdot x_3 = 0 \implies x_2$ 必须为 0！
* 于是第二个解令 $x_2 = 0, x_3 = 1$，得 $\boldsymbol{\alpha}_2 = (-1, 0, 1)^\mathrm{T}$。

此时 $\boldsymbol{\alpha}_1 \cdot \boldsymbol{\alpha}_2 = 0$ **自动正交**，直接各自单位化即可，省去了带入施密特分式算繁琐内积的步骤。

### 考研应试总结

1. **三维空间“知一求二”**：首选“**肉眼观察一个 + 叉乘生成第三个**”，这是数一特有的速度优势（因为只有数一考向量代数与空间解析几何）。
2. **多维/重特征值“解方程求特征向量”**：利用**自由变量置零法**人为制造正交，非万不得已不算施密特公式，防算错。
