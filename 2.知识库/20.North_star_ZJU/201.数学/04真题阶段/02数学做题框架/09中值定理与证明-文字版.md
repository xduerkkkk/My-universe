> [!abstract] 先记住总心法
> 中值证明题不是“猜中值点”，而是把待证式翻译成一个熟悉定理能产生的形式：
> **待证式 → 构造辅助函数/切分区间 → 罗尔、拉格朗日、柯西、泰勒或介值定理 → 展开并回代。**
>
> 你真正要练的不是背一堆孤立套路，而是看到式子后问：
> 1. 要找几个中值点？
> 2. 目标里出现几阶导数？
> 3. 目标能不能写成某个 `F'(ξ)=0`？
> 4. 两个中值点能不能分离在两个子区间里？
> 5. 题目有没有“分母可能为 0”的风险？

## 0. 考场分诊：先不要急着算

### 第一步：圈出待证式的结构

| 题眼 | 优先方法 | 你要做的事 |
|---|---|---|
| 只有一个 `ξ`，目标含 `f'(ξ)` 与端点值 | 常数 K 值法 / 原函数法 | 把中值部分设为 `K`，构造 `F(a)=F(b)` |
| `f(ξ)、f'(ξ)` 混在一起，且像乘积求导 | 原函数法 | 反解出一个 `F'(x)`，再用罗尔 |
| 同时出现 `f(ξ)`、`f'(ξ)` 的比值或两个函数的比值 | 柯西中值定理 | 构造 `u(x),v(x)`，让导数比正好等于目标 |
| 含 `f''(ξ)`、`f'''(ξ)`、绝对值最值、区间中点 | 泰勒公式法 | 选展开点，左右展开，再相加/相减/放缩 |
| 两个中值点各自独立出现 | 双中值可分离 | 分区间分别用拉格朗日/柯西 |
| 两个中值点相互纠缠，或目标是乘积 | 几何切分 / 双中值转单中值 | 先找一个公共点，再在两侧取中值 |
| 结论中导数在分母 | 介值定理纵向切分 | 先保证每段纵向增量非零，避免除以 0 |
| 结论含 `max/min` 或“存在某点使导数很大” | 最值 + 费马 / 泰勒 / 积分放缩 | 先找最值点，再把最值翻译为极值或增量 |

### 第二步：检查定理条件

- 罗尔：`F` 在 `[a,b]` 连续、在 `(a,b)` 可导，且 `F(a)=F(b)`。
- 拉格朗日：`F` 在 `[a,b]` 连续、在 `(a,b)` 可导。
- 柯西：`u,v` 都满足连续/可导条件，并且 `v'(x)` 不为 0（使用比值时还要注意分母）。
- 泰勒：根据余项阶数检查相应阶导数存在；展开点与中值点的位置要写清楚。
- 介值定理：先确认连续，再确认两端异号或目标值夹在两端函数值之间。
- 任何“同除以 `f(ξ)` 或 `f'(ξ)`”的步骤，都必须先证明它不为 0。

# 1. 四个基础定理：不是背定义，是背“产出形式”

## 1.1 罗尔定理：制造 `F'(ξ)=0`

若 `F(a)=F(b)`，则存在 `ξ∈(a,b)`，使得

$$F'(ξ)=0.$$

**最常用翻译：**

> 看到待证式很复杂，先把 `ξ` 暂时换成 `x`，把目标整体当作 `F'(x)`。只要能再找到两个点使 `F` 相等，就能用罗尔定理。

典型目标：

$$f''(ξ)+p(ξ)f'(ξ)=0$$

若能构造

$$F(x)=f'(x)e^{\int p(x)\,dx},$$

就有 `F'(ξ)=0` 等价于目标。

## 1.2 拉格朗日中值定理：把平均斜率变成某个导数

$$f'(ξ)=\frac{f(b)-f(a)}{b-a}.$$

几何语言：

> 区间端点连线的割线斜率 = 曲线上某个点的切线斜率。

最常用在：分段、切分纵坐标、比较斜率、制造两个不同的中值点。

## 1.3 柯西中值定理：把两个增量比变成两个导数比

$$\frac{f(b)-f(a)}{g(b)-g(a)}=\frac{f'(ξ)}{g'(ξ)}.$$

看到 `f(ξ)-ξf'(ξ)`、`f'(ξ)/g'(ξ)`、三角函数或指数函数混合时，优先想：

> “我能不能把目标写成两个函数导数的比？”

## 1.4 泰勒中值定理：把函数增量变成高阶导数

以 `x_0` 为展开点的三阶形式：

$$f(x)=f(x_0)+f'(x_0)(x-x_0)+\frac{f''(x_0)}{2!}(x-x_0)^2+\frac{f'''(ξ)}{3!}(x-x_0)^3.$$

二阶形式：

$$f(x)=f(x_0)+f'(x_0)(x-x_0)+\frac{f''(ξ)}{2}(x-x_0)^2.$$

**口诀：**

> 以 `x` 为中心，左右对称展开 `x±h`：相减通常留下 `f'(x)`，相加通常留下 `f''(ξ)`；但不一定非要对称，关键是让条件和目标中多余的项消失。

# 2. 常数 K 值法：把中值部分先冻结成常数

## 2.1 核心思想

拉格朗日中值定理本身可以写成

$$f(b)-f(a)=(b-a)f'(ξ).$$

如果目标中端点 `a,b` 和中值 `ξ` 能够分离，就令

$$K=\text{只含端点的那一边}=\text{只含中值的那一边}.$$

然后把 `b` 换成一般变量 `x`，得到一个函数 `F(x)`，使

$$F(a)=F(b).$$

最后用罗尔定理。

## 2.2 标准四步

1. **分离：** 把目标整理成“端点表达式 = 中值表达式”。
2. **设 K：** 令两边共同的值为 `K`。
3. **构造零式：** 把 `ξ` 换成 `x`，移项得 `F(x)=0` 的形式。
4. **核对端点：** 验证 `F(a)=F(b)`，再用罗尔定理，展开 `F'(ξ)=0`。

## 2.3 为什么死板套 `f(x)-f(a)-(x-a)K` 会失效？

这个函数只适合目标本身就是

$$f'(ξ)=K.$$

如果目标里还多了 `f(ξ)`、`ξf'(ξ)`、`ξ^2f'(ξ)` 等结构，必须**修正构造函数**：

- 乘/除一个恰当的 `x`、`e^x`、`x^r`；
- 把 `f(x)` 和 `f'(x)` 重新组合成乘积导数；
- 必要时先求一次中值，再在嵌套区间内再用一次中值；
- 若含高阶导数，改用泰勒或高阶柯西，而不是硬套一次罗尔。

这就是“中值可分离法”的真正含义：**可分离的是端点信息与中值信息，不是所有题都长成同一个模板。**

# 3. 柯西中值法：遇到比值，先找两个母函数

## 3.1 `f(ξ)-ξf'(ξ)` 型

若 `0<a<b`，目标为

$$f(ξ)-ξf'(ξ)=\frac{bf(a)-af(b)}{b-a},$$

不要硬凑，直接取

$$u(x)=f(x),\qquad v(x)=x$$

或更常见地取

$$u(x)=\frac{f(x)}x,\qquad v(x)=\frac1x.$$

柯西中值定理给出某个 `ξ`：

$$\frac{f(b)/b-f(a)/a}{1/b-1/a}
=\frac{(f(x)/x)'|_{x=ξ}}{(1/x)'|_{x=ξ}}
=f(ξ)-ξf'(ξ).$$

整理左边就得到目标端点表达式。

## 3.2 `ξ²f'(ξ)` 型

若目标为

$$\frac{f(b)-f(a)}{b-a}=\frac{ξ^2f'(ξ)}{ab},$$

令

$$K=\frac{ab[f(b)-f(a)]}{b-a}.$$

由于

$$f(b)-f(a)=K\left(\frac1a-\frac1b\right),$$

构造

$$G(x)=f(x)+\frac Kx.$$

于是 `G(a)=G(b)`，由罗尔定理：

$$G'(ξ)=f'(ξ)-\frac K{ξ^2}=0,$$

即

$$ξ^2f'(ξ)=K.$$

这类题的识别点是：目标里有 `ξ²f'(ξ)`，就尝试加入 `K/x`。

## 3.3 指数、三角函数混合

- 看到 `f'(ξ)+f(ξ)`：想 `(e^xf(x))'=e^x[f'(x)+f(x)]`。
- 看到 `f'(ξ)/e^ξ`：配对 `f(x)` 与 `e^x` 使用柯西。
- 看到 `sin ξ、cos ξ`：考虑分别和 `sin x`、`-cos x` 配对。
- 看到 `f'(η)tan((a+b)/2)` 一类式子：通常分别对 `f` 与 `-cos x`、`f` 与 `sin x` 使用柯西，再消去同一个端点增量。

## 3.4 高阶柯西：先消掉低阶初值

若 `L,H` 在 `a` 处的前 `n` 阶导数都为 0：

$$L(a)=L'(a)=\cdots=L^{(n)}(a)=0,$$

$$H(a)=H'(a)=\cdots=H^{(n)}(a)=0,$$

则可以连续使用柯西中值定理，得到某个 `ξ∈(a,b)`：

$$\frac{L(b)}{H(b)}=\frac{L^{(n+1)}(ξ)}{H^{(n+1)}(ξ)}.$$

实战步骤：

1. 先把待证式整理成“分子/分母 = 高阶导数比”；
2. 令 `L(x),H(x)` 为分子、分母的变量版本；
3. 核对它们在同一点的低阶导数是否全部消失；
4. 连续使用柯西，不要把它误写成洛必达。

> [!example] 📌 真题挂载（一行一题）
> - [ ] 证 $\frac{f(a)-f(\xi)}{g(\xi)-g(b)}=\frac{f'(\xi)}{g'(\xi)}$（$g'\neq0$）→ $G=(f(x)-f(a))(g(x)-g(b))$，$G(a)=G(b)=0$ 用罗尔；比值结论不一定非要柯西，乘积构造+罗尔也行

# 4. 原函数法：所有复杂证明题的总发动机

## 4.1 本质

原函数法不是“真的去求一个积分”，而是寻找一个函数 `F`，使得

$$F'(x)=\text{待证式左边}-\text{待证式右边}.$$

于是目标等价于 `F'(ξ)=0`。接下来只需要想办法制造

$$F(a)=F(b),$$

再用罗尔定理。

**固定动作：**

1. 将 `ξ` 暂时换成 `x`；
2. 把目标移项；
3. 观察每一项是否是某个乘积、幂函数、指数函数或对数函数的导数；
4. 得到 `F'(x)` 后，找两个 `F` 值相等的点；
5. 应用罗尔，展开结论。

> [!question] 为什么说原函数法就是"解微分方程 + 挪C"？
> 目标始终只有一个：**找到 $F$ 使 $F'(x)=$ 待证式(左 − 右)**。"解微分方程 + 挪C"不是另一个方法，而是**看不出 $F$ 时把它逼出来的一套机械操作**，本质仍是找原函数。
>
> **① 为什么"解方程"能吐出 $F$？** 依据这条恒等关系：
> $$\text{通解 }\Phi(x,f,f')=C \;\Longleftrightarrow\;\Phi'(x)=0 \;\Longleftrightarrow\;\text{待证式}=0.$$
> 例：解 $f'+pf=0$ 得 $f\,e^{\int p}=C$，左边 $F=f\,e^{\int p}$ 就是原函数，且 $F'=e^{\int p}(f'+pf)$。
>
> **② "挪C"在挪什么？** 通解里有几个任意常数，就消到只剩**一个** $C$，再把 $C$ 单独挪到右边，剩下那一边就是 $F$。例：二阶 $f''+f=0$ 通解 $f=C_1\sin x+C_2\cos x$ 有两个常数，求导一次消去一个，得 $f\cos x-f'\sin x=C_2$，左边就是 $F$。
>
> **③ 必须点破的"骗局"：** 正式证明里**从没假设 $f$ 真的解这个方程**。解方程只是"制造 $F$ 的模板"；真正进证明的三步是：直接求导验证 $G'(x)=\text{非零因子}\times\text{待证式}$ → 验证 $G(a)=G(b)$ → 罗尔给出 $G'(\xi)=0$。

## 4.2 暴力积分法：能分离就分离

例如目标为

$$f''(x)+f^2(x)[f'(x)]^2=0.$$

若在当前局部可以除以 `f'(x)`，则

$$\frac{f''(x)}{f'(x)}+f^2(x)f'(x)=0.$$

识别原函数：

$$\frac{f''}{f'}=(\ln|f'|)',\qquad f^2f'=\left(\frac13f^3\right)'.$$

积分得

$$\ln|f'(x)|+\frac13f^3(x)=C,$$

再指数化，得到

$$G(x)=f'(x)e^{f^3(x)/3}=C.$$

于是 `G'(x)=0` 就等价于原目标。

> [!warning] 除法风险
> 上面的“除以 `f'(x)`”只能在已知 `f'(x)≠0` 或已经分区间排除零点时使用。证明题中不要把“形式上能凑出来”误当成“逻辑上允许除”。

## 4.3 积分因子：一阶线性结构的万能构造

如果目标可整理为

$$h'(x)+p(x)h(x)=q(x),$$

积分因子为

$$\mu(x)=e^{\int p(x)dx}.$$

乘上以后：

$$[\mu(x)h(x)]'=\mu(x)q(x).$$

- 齐次情形 `q=0`：
  $$h(x)e^{\int p(x)dx}=C.$$
- 非齐次情形：
  $$h(x)e^{\int p(x)dx}-\int q(x)e^{\int p(x)dx}dx=C.$$

### 典型识别

目标若是

$$f''(ξ)+f(ξ)=0,$$

可把 `h=f'` 看成一阶系统，也可直接乘 `sin x` 或 `cos x`：

$$[f'(x)\sin x-f(x)\cos x]'=f''(x)\sin x+f(x)\sin x,$$

所以构造

$$F(x)=f'(x)\sin x-f(x)\cos x.$$

也可以乘 `2f'(x)` 得到能量型原函数：

$$2f'(x)[f''(x)+f(x)]=0,$$

从而

$$[(f'(x))^2+f^2(x)]'=0.$$



## 4.4 不显含 x 的二阶方程：必要时降阶

当式子只含 `f、f'、f''`，不单独含 `x`，例如

$$f''+[ff']^2=0,$$

可令

$$y=f(x),\qquad p=y'=f'(x),\qquad y''=p\frac{dp}{dy}.$$

这样把二阶方程降成关于 `p,y` 的一阶可分离方程。

但如果直接观察出

$$\frac{f''}{f'}+f^2f'=0,$$

就优先用“分离 + 凑原函数”，比完整降阶更快。

## 4.5 双中值转单中值：积分因子直接秒构造

常见目标：已知 `f(0)=0,f(1)=1`，证明存在不同的 `ξ_1,ξ_2`，使

$$a f'(ξ_1)+b f'(ξ_2)=a+b,\qquad a,b>0.$$

先把第二个中值写成一个函数值商：

$$f'(ξ_2)=\frac{f(ξ_1)-f(0)}{ξ_1}=\frac{f(ξ_1)}{ξ_1}.$$

单中值目标变成

$$a x f'(x)+b f(x)=(a+b)x.$$

除以 `ax`：

$$f'(x)+\frac b{ax}f(x)=\frac{a+b}a.$$

积分因子：

$$\mu(x)=x^{b/a}.$$

于是

$$\left[x^{b/a}(f(x)-x)\right]'=0.$$

构造

$$G(x)=x^{b/a}(f(x)-x).$$

因为 `G(0)=G(1)=0`，罗尔给出 `ξ_1∈(0,1)`：

$$a f'(ξ_1)+b\frac{f(ξ_1)}{ξ_1}=a+b.$$

再在 `[0,ξ_1]` 上用拉格朗日：存在 `ξ_2∈(0,ξ_1)`，使

$$f'(ξ_2)=\frac{f(ξ_1)}{ξ_1}.$$

代回即得

$$a f'(ξ_1)+b f'(ξ_2)=a+b.$$

**关键优势：** `0<ξ_2<ξ_1<1`，两个点天然不同。

## 4.6 条件用不上怎么办？先翻译条件，再重新构造

有些题构造出 `G'(ξ)=0` 后，只能得到一个端点条件，例如 `G(a)=0`，却得不到 `G(b)=0`。这时不要硬套罗尔，应该：

1. 用 `G` 反解出 `f` 或 `f'`；
2. 把题目关于 `f` 的条件全部翻译成 `G` 的点值、积分值或符号条件；
3. 对 `G(c)=0, G(c)>0, G(c)<0` 分类；
4. 配合介值定理、积分中值定理、零点定理寻找第二个相等点；
5. 再用罗尔。

这是一条通用的“降维”策略：**构造后暂时忘掉原函数，只研究辅助函数。**

> [!example] 📌 真题挂载（一行一题）
> - [ ] 证 $\exists\,\xi$：$f''(\xi)=f(\xi)$（$f(a)=f(b)=\int_a^b f=0$）→ 解 $f''=f$ 得 $f=C_1e^x+C_2e^{-x}$，消常数得 $F=e^{-x}(f'+f)$——"解方程+挪C"样板
> - [ ] 证 $\exists\,\xi$：$f''(\xi)+[f(\xi)f'(\xi)]^2=0$（$f'(0)=f'(1)=0$）→ 不显含 $x$，凑 $\ln|f'|+\tfrac13 f^3=C$（见 4.4）
> - [ ] 证 $f(x)f''(x)+[f'(x)]^2=0$ 至少两实根（$f(1)>0,\ \lim_{x\to0^+}\frac{f(x)}x<0$）→ $G=ff'$（$G'=ff''+(f')^2$），凑 $G$ 三个零点后罗尔两次
> - [ ] 证 $\exists\,\xi$：$\xi f''(\xi)+(1+\xi)f'(\xi)=1+\xi$（$f(0)=0,f(1)=1$）→ 把 $f'$ 当未知，化一阶线性用积分因子
> - [ ] 证 $\exists\,\xi$：$f''(\xi)=\frac{3f'(\xi)}{1-2\xi}$（$f(0)=f'(0),\ f(\tfrac12)=0$）→ 解方程+挪C（一阶线性/分离变量）
> - [ ] 证 $f(x)<e^x$（$f(0)=1,\ f'(x)<f(x)$）→ 移项乘 $e^{-x}$ 得 $G=fe^{-x}$ 单调减，原函数法解不等式

# 5. 拉格朗日几何意义法：割线不重合，就一定有更陡的切线

设

$$k=\frac{f(b)-f(a)}{b-a}.$$

连接端点得到割线。若 `f` 不是线性函数，则存在 `c∈(a,b)` 不在割线上。

- 若 `(c,f(c))` 在割线上方，则前半段 `[a,c]` 的平均斜率大于 `k`，在 `[a,c]` 用拉格朗日，得到某点 `ξ` 使 `f'(ξ)>k`。
- 若 `(c,f(c))` 在割线下方，则前半段斜率小于 `k`，不能得到目标；应改在后半段 `[c,b]` 用拉格朗日。因为 `c-b<0`，除以负数后不等号翻向，得到后半段存在 `ξ` 使 `f'(ξ)>k`。

> [!tip] 应试口诀
> **高走前半段，低走后半段。**
>
> 低点时不要死磕 `[a,c]`；那里的不等号方向正好相反。

# 6. 2020 型最大值/导数估计：积分链条逼出刚性

典型条件：`f∈C^1[0,2]`，`f(0)=f(2)=0`，令

$$M=\max_{[0,2]}|f(x)|.$$

## 6.1 证明存在 `ξ` 使 `|f'(ξ)|≥M`

设 `|f(c)|=M`。分别看两段：

$$M=\left|\int_0^c f'(x)dx\right|\le\int_0^c|f'(x)|dx,$$

$$M=\left|\int_c^2 f'(x)dx\right|\le\int_c^2|f'(x)|dx.$$

若 `|f'(x)|<M` 处处成立，那么两段分别严格小于 `Mc` 与 `M(2-c)`，相加得到

$$2M<2M,$$

矛盾。因此存在某个 `ξ` 使

$$|f'(ξ)|\ge M.$$

也可以用拉格朗日直接看：两段长度 `c` 与 `2-c` 中至少有一段长度不超过 1，端点函数值相差为 `M`，该段平均斜率绝对值至少为 `M`。

## 6.2 若 `|f'|≤M`，则只能有 `M=0`

若 `M>0`，上面的链条所有不等号都必须取等号，于是

$$\int_0^c(M-|f'(x)|)dx=0,\qquad
\int_c^2(M-|f'(x)|)dx=0.$$

被积函数连续且非负，只能恒为 0：

$$|f'(x)|\equiv M.$$

由于 `f'` 连续，且只可能取 `M` 或 `-M`，在连通区间上不能跳变，所以 `f'` 恒正或恒负，`f` 严格单调；但 `f(0)=f(2)`，只能矛盾。故 `M=0`，即 `f≡0`。

# 7. 泰勒公式法：重点是”在哪里展开”

## 7.1 展开点选择原则

展开点不要凭感觉，先化简目标，再反解需要什么：

- 条件给 `f'(0)=0`：优先在 0 展开；
- 条件给两端导数：考虑分别在 `a,b` 展开；
- 目标有 `f''(ξ)`：选能消掉常数项和一次项的点；
- 目标有绝对值最值：在最值点 `c` 展开；
- 目标有对称区间：在中点展开，或以 `x` 为中心展开 `x±h`。

## 7.2 对称展开：相减出一阶，相加出二阶

在 `x` 处：

$$f(x+h)=f(x)+hf'(x)+\frac{h^2}{2}f''(ξ_1)+\cdots,$$

$$f(x-h)=f(x)-hf'(x)+\frac{h^2}{2}f''(ξ_2)+\cdots.$$

相减时，偶次项抵消，突出 `f'(x)`；相加时，奇次项抵消，突出 `f''` 或更高偶阶项。

例如已知 `|f|≤M_0, |f''|≤M_2`，由

$$f(x+h)=f(x)+hf'(x)+\frac{h^2}{2}f''(ξ),$$

放缩得到

$$|f'(x)|\le\frac{2M_0}{|h|}+\frac{|h|M_2}{2}.$$

取

$$|h|=2\sqrt{\frac{M_0}{M_2}},$$

得到

$$|f'(x)|\le2\sqrt{M_0M_2}.$$

若已知 `|f|≤M_0, |f'''|≤M_3`，对称展开并优化参数可得 Landau 型估计：

$$|f'(x)|\le\sqrt[3]{9M_0^2M_3}.$$

## 7.3 绝对值最大值点：先翻译成原函数极值点

若 `|f(c)|` 在区间上取得最大值，不能直接说 `(|f|)'(c)=0`，因为 `|f|` 可能不可导。

正确写法：

1. 若端点函数值为 0 且最大值大于 0，则 `c∈(a,b)`；
2. 若 `f(c)>0`，由 `|f(x)|≤|f(c)|` 得 `f(x)≤f(c)`，所以 `c` 是 `f` 的极大值点；
3. 若 `f(c)<0`，则 `f(x)≥f(c)`，所以 `c` 是 `f` 的极小值点；
4. 由费马引理：
   $$f'(c)=0.$$

## 7.4 典型估计：端点为 0 且 `|f''|≥1`

设 `f(a)=f(b)=0`，令 `|f(c)|` 为最大值。以 `c` 展开端点，并利用 `f'(c)=0`：

$$|f(c)|\ge\frac{(c-a)^2}{2},\qquad
|f(c)|\ge\frac{(b-c)^2}{2}.$$

`c-a` 与 `b-c` 至少有一个不小于 `(b-a)/2`，故

$$\max_{[a,b]}|f(x)|\ge\frac18(b-a)^2.$$

## 7.5 端点导数为 0：两端展开 + 待定位置

若 `f'(a)=f'(b)=0`，要估计 `f(b)-f(a)` 与 `f'''(ξ)`，可在 `a,b` 两侧展开到三阶，再把余项相加。展开点位置可能需要待定，令

$$t=\frac{x-a}{b-a}.$$

将系数化成关于 `t` 的方程，常会得到 `t=1/3` 或 `2/3`。这不是“凭空猜三等分”，而是通过让两个余项系数配平反解出来的。

# 8. 真正的双中值：先判断”可分离”还是”纠缠”

## 8.1 双中值可分离：按区间分段

典型目标：若 `f(0)=0,f(1)=1`，`λ_i>0`，令

$$S=\lambda_1+\cdots+\lambda_n,$$

证明存在互不相同的 `ξ_i`，使

$$\sum_{i=1}^n\frac{\lambda_i}{f'(ξ_i)}=S.$$

### 为什么切分纵坐标？

拉格朗日告诉我们

$$\frac1{f'(ξ_i)}=\frac{\Delta x_i}{\Delta y_i}.$$

若人为令每段纵向增量

$$\Delta y_i=\frac{\lambda_i}{S},$$

则

$$\frac{\lambda_i}{f'(ξ_i)}=S\Delta x_i.$$

所有横向区间加起来正好是 1，所以总和为 `S`。

### 严谨取点：必须逐段向右找

令

$$f(x_i)=\frac{\lambda_1+\cdots+\lambda_i}{S}.$$

用介值定理依次在缩小的区间中取点：

$$0=x_0<x_1<\cdots<x_n=1.$$

注意：不能无脑在整个 `[0,1]` 上分别找 `x_i`，因为函数可能震荡，得到的横坐标会乱序，既不能保证 `ξ_i` 不同，也不能保证区间长度相加为总长度。

在每段 `[x_{i-1},x_i]` 用拉格朗日：

$$f'(ξ_i)=\frac{\lambda_i/S}{x_i-x_{i-1}},$$

所以

$$\frac{\lambda_i}{f'(ξ_i)}=S(x_i-x_{i-1}).$$

相加：

$$\sum_{i=1}^n\frac{\lambda_i}{f'(ξ_i)}
=S\sum_{i=1}^n(x_i-x_{i-1})=S.$$

## 8.2 双中值几何型：目标是乘积，就找副对角线

若 `f(0)=0,f(1)=1`，要证明存在不同的 `ξ,η` 使

$$f'(ξ)f'(η)=1,$$

不要先找 `f(c)=c`，因为 `f(x)-x` 两端都是 0，不能保证内部有交点。

正确找副对角线 `y=1-x`：

$$G(x)=f(x)-(1-x).$$

有

$$G(0)=-1<0,\qquad G(1)=1>0,$$

由零点定理，存在 `c∈(0,1)`，使

$$f(c)=1-c.$$

分别在两段用拉格朗日：

$$f'(ξ)=\frac{1-c}{c},\qquad ξ∈(0,c),$$

$$f'(η)=\frac{c}{1-c},\qquad η∈(c,1).$$

相乘得

$$f'(ξ)f'(η)=1.$$

**几何本质：** 第一段的“高”正好等于第二段的“宽”，第二段的“高”正好等于第一段的“宽”，两个斜率互为倒数。

## 8.3 设未知数函数法：把第二个中值写成第一个的函数值商

当目标是

$$a f'(ξ_1)+b f'(ξ_2)=a+b,$$

可先在 `[0,ξ_1]` 上使用拉格朗日，使

$$f'(ξ_2)=\frac{f(ξ_1)-f(0)}{ξ_1}.$$

于是原问题先转成单中值问题，再使用上一节的积分因子构造。这是“先找一个点，再在嵌套区间找第二个点”。

# 9. 双中值分母陷阱：先保非零，再谈相除

## 9.1 为什么“去分母凑微分”可能不合法？

若目标含

$$\frac1{f'(ξ_1)},\qquad \frac1{f(ξ_1)},$$

直接把它们乘过去，可能会得到一个漂亮的导数等式；但罗尔定理给出的点恰好可能满足

$$f(ξ_1)=0\quad\text{或}\quad f'(ξ_1)=0,$$

此时你无法再除回来，原式甚至没有定义。

**所以：代数等价变形必须双向合法。**

## 9.2 最稳妥方法：介值定理切高度

例如 `f(0)=0,f(1)=1`，要证存在不同的 `ξ_1,ξ_2` 使

$$\frac1{f'(ξ_1)}+\frac1{f'(ξ_2)}=2.$$

先由介值定理取 `c`：

$$f(c)=\frac12.$$

在 `[0,c]` 和 `[c,1]` 分别使用拉格朗日：

$$f'(ξ_1)=\frac{1/2}{c},\qquad
f'(ξ_2)=\frac{1/2}{1-c}.$$

因此

$$\frac1{f'(ξ_1)}=2c,\qquad
\frac1{f'(ξ_2)}=2(1-c),$$

相加即得 2。

这里每段纵向增量都是 `1/2≠0`，所以分母从源头上安全；同时

$$0<ξ_1<c<ξ_2<1,$$

两个点天然不同。

## 9.3 高级补洞法：最后一个零点

若确实要使用某个含 `1/f(ξ)` 的辅助函数，可以设零点集合

$$Z=\{x∈[0,1]:f(x)=0\},$$

取其最右零点 `x_0=sup Z`，在 `[x_0,1]` 上用罗尔，使中值点落在 `(x_0,1)`，从而保证 `f(ξ)≠0`。这在理论上严谨，但考场书写复杂；通常优先使用“切高度法”。

# 10. 一页式”拿到题就照做”流程

1. **数中值点：** 一个点、两个点，还是要找一串点？
2. **看最高阶导：** `f'` 优先拉格朗日/原函数；`f''、f'''` 优先泰勒/高阶柯西。
3. **看分母：** 有 `1/f(ξ)`、`1/f'(ξ)`，先问能否保证非零。
4. **看端点：** `f(a)=f(b)` → 罗尔；端点增量 → 拉格朗日；两个函数比值 → 柯西。
5. **看几何：** 目标是乘积或两个斜率互为倒数 → 找 `y=1-x` 等能让增量交叉消去的线。
6. **看权重：** `λ_i/f'(ξ_i)` → 按纵坐标切成 `λ_i/S`，并按顺序逐段取点。
7. **看复杂导数：** 试着写成 `F'(x)`；凑不出时尝试积分因子。
8. **看 max/min：** 先证明最值点是内点，再把 `|f|` 的最值翻译成 `f` 的极值，使用费马。
9. **看高阶估计：** 先决定展开点，再决定相加还是相减；最后用 `t=(x-a)/(b-a)` 优化位置。
10. **最后复核：** 中值点属于哪个区间？是否互不相同？每次除法是否有依据？定理条件是否写全？

# 11. 最小记忆卡：只背这些触发器

- `F(a)=F(b)` → 罗尔 → `F'(ξ)=0`。
- `端点差/区间长` → 拉格朗日 → 平均斜率。
- `两个增量之比` → 柯西 → 两个导数之比。
- `高阶导、对称、max/min` → 泰勒。
- `f'(ξ)+p(ξ)f(ξ)` → 积分因子 `e^{∫p}`。
- `f''+f` → 乘 `sin/cos`，或乘 `2f'` 得能量守恒。
- `不显含 x` 的二阶式 → 可降阶；能凑就先凑。
- `λ_i/f'(ξ_i)` → 纵向按权重切分，横向长度相加。
- `f'(ξ)f'(η)=1` → 找 `f(c)=1-c`，两边拉格朗日。
- `分母含中值函数/导数` → 不要盲目去分母，优先切高度保非零。
- “高走前半段，低走后半段”。
- 绝对值最大值点：正是极大，负是极小，先费马得 `f'(c)=0`。

> [!quote] 最后的理解
> 这些题表面上在考“存在某个 ξ”，本质上都在考一件事：
> **能否把一个看起来没有结构的结论，改写成某个函数的导数、某段的平均斜率、某个高阶余项，或者若干段增量的总和。**
>
> 只要完成这次翻译，后面的中值点通常不是猜出来的，而是定理自动吐出来的。
