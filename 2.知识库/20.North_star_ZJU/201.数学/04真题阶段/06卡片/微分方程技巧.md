这个快算法（算子法/留数法的结论）是考研求常系数非齐次特解 $y^*$ 的**第一神技**。掌握它，别人算 3 分钟的特解，你 **5 秒钟口算**直接写答案。

---

### 一、什么是“求特解系数 $A$ 的快算法”？

针对方程右边是 **纯指数函数 $d \cdot e^{\lambda x}$**（$d$ 是常数）的情况，比如 $y'' - 2y' - 3y = 5e^{3x}$。

我们先写出左边的**特征多项式 $P(r)$**（比如上面就是 $P(r) = r^2 - 2r - 3$）。
平时我们要把 $\lambda$ 代入 $P(r)$ 看它是不是根。现在直接把**设特解**和**求系数 $A$** 合并成一步：

#### 情况 1：$\lambda$ 不是特征根（即 $P(\lambda) \neq 0$）
* **设法**：$y^* = A e^{\lambda x}$
* **直接写答案**：把 $\lambda$ 直接代进特征多项式作分母！
  $$y^* = \frac{d}{P(\lambda)} e^{\lambda x}$$

#### 情况 2：$\lambda$ 是特征方程的单根（即 $P(\lambda) = 0$，但一阶导 $P'(\lambda) \neq 0$）
* **为什么平时很慢**：因为多乘了一个 $x$（设 $y^* = A x e^{\lambda x}$），代回原方程求二阶导、三阶导时要用乘积求导法则，非常容易算错！
* **为什么可以用导数快算（理解本质）**：
  当把 $y^* = A x e^{\lambda x}$ 代入原方程左边时，整理出来必然是：
  $$A \cdot \big[ x \cdot \underbrace{P(\lambda)}_{=0} + P'(\lambda) \big] e^{\lambda x} = d \cdot e^{\lambda x}$$
  因为 $\lambda$ 是特征根，$x$ 前面的 $P(\lambda)$ 自动变成 $0$ 消失了！只剩下 **$A \cdot P'(\lambda) = d$**！
* **直接写答案**：分母为 0 怎么办？**对特征多项式求一次导，再把 $\lambda$ 代进去作分母**（就像洛必达法则一样）！
  $$y^* = \frac{d}{P'(\lambda)} x e^{\lambda x}$$

#### 情况 3：$\lambda$ 是二重根（即 $P(\lambda) = 0, P'(\lambda) = 0$，但二阶导 $P''(\lambda) \neq 0$）
* **直接写答案**：分母求一次导还是 0？那就**求两次导**代进去，别忘了 $x^2$ 求导有个 $2!$（即 $2$）：
  $$y^* = \frac{d}{P''(\lambda)} \frac{x^2}{2!} e^{\lambda x}$$

### 二、手把手带你算刚才那道题

刚才那题：$y''' - 2y'' - 3y' = 1 \cdot e^{3x}$（这里 $d = 1, \lambda = 3$）。
1. **写特征多项式**：$P(r) = r^3 - 2r^2 - 3r$。
2. **代 $\lambda = 3$ 试试**：$P(3) = 27 - 18 - 9 = 0$。（分母为 0，说明是特征根，特解要乘 $x$）。
3. **对 $P(r)$ 求一次导**：$P'(r) = 3r^2 - 4r - 3$。
   把 $\lambda = 3$ 代入导数：$P'(3) = 3(9) - 4(3) - 3 = 12 \neq 0$（说明是单根）。
4. **直接写出特解**：
   $$y^* = \frac{1}{P'(3)} x e^{3x} = \frac{1}{12} x e^{3x}$$
**结束！根本不需要对 $A x e^{3x}$ 求哪怕一次导！**

* **例题 2**：$y'' - 3y' + 2y = 5e^{2x}$
* **例题 3**：$y'' - 4y' + 4y = 6e^{2x}$
* **例题 4（高阶）**：$y''' - y' = 4e^{-x}$

### 四、答案与秒杀解析

#### 【例题 1 解析】
1. 特征多项式：$P(r) = r^2 - 3r + 2$，右边 $\lambda = 4, d = 3$。
2. 直接代 $r = 4$：$P(4) = 16 - 12 + 2 = 6 \neq 0$（不是根，直接当分母）。
3. **特解**：$y^* = \frac{3}{P(4)} e^{4x} = \frac{3}{6} e^{4x} = \mathbf{\frac{1}{2} e^{4x}}$。

#### 【例题 2 解析】
1. 特征多项式：$P(r) = r^2 - 3r + 2$，右边 $\lambda = 2, d = 5$。
2. 代 $r = 2$：$P(2) = 4 - 6 + 2 = 0$（为 0，是根！）。
3. 求一次导：$P'(r) = 2r - 3$，代入 $r = 2$ 得 $P'(2) = 4 - 3 = 1 \neq 0$（单根，乘 $x$）。
4. **特解**：$y^* = \frac{5}{P'(2)} x e^{2x} = \frac{5}{1} x e^{2x} = \mathbf{5 x e^{2x}}$。

#### 【例题 3 解析】
1. 特征多项式：$P(r) = r^2 - 4r + 4 = (r-2)^2$，右边 $\lambda = 2, d = 6$。
2. 显然 $r = 2$ 是**二重根**（即 $P(2)=0, P'(2)=0$）。
3. 求两次导：$P''(r) = 2$（常数）。
4. **特解**（二重根配 $\frac{x^2}{2!}$）：$y^* = \frac{6}{P''(2)} \frac{x^2}{2} e^{2x} = \frac{6}{2} \cdot \frac{x^2}{2} e^{2x} = \mathbf{\frac{3}{2} x^2 e^{2x}}$。

#### 【例题 4 解析】
1. 特征多项式：$P(r) = r^3 - r$，右边 $\lambda = -1, d = 4$。
2. 代 $r = -1$：$P(-1) = -1 - (-1) = 0$（是根！）。
3. 求一次导：$P'(r) = 3r^2 - 1$，代入 $r = -1$ 得 $P'(-1) = 3(-1)^2 - 1 = 2 \neq 0$（单根，乘 $x$）。
4. **特解**：$y^* = \frac{4}{P'(-1)} x e^{-x} = \frac{4}{2} x e^{-x} = \mathbf{2 x e^{-x}}$。

*(记住：这个公式只针对右边是**纯指数 $d \cdot e^{\lambda x}$**（或者常数 $d = d \cdot e^{0x}$）时有效。如果右边是 $(2x+1)e^{\lambda x}$ 这种带多项式的，还是老老实实待定系数法，但考研真题里 80% 都是纯指数，用这招能省下大量时间！)*
