### 卡片 1：两个抽象级数相乘/组合（如【7.11】【7.14】）
*   **视觉特征**：已知 $\sum a_n$（或 $\sum n u_n$）和 $\sum b_n$（或 $\sum \frac{v_n}{n}$）的敛散性，问乘积 $\sum a_n b_n$ 或平方 $\sum a_n^2 b_n^2$ 的敛散性。
*   **唯一核心手法（配凑 + 有界放缩）**：
    1. **先找绝对值（正项前提）**：只要条件里**没给正项、没给绝对值**（只说 $\sum b_n$ 收敛），直接用交错级数 $a_n = b_n = \frac{(-1)^n}{\sqrt{n}}$ **一秒证伪**！
    2. **一旦有了正项/绝对值**：
       *   利用“级数收敛 $\implies$ 通项 $\to 0 \implies$ 当 $n$ 大时 **$|a_n| < 1$（且平方比本身更小：$a_n^2 \le |a_n|$）**”；
       *   把目标拆成已知两项相乘（如 $|u_n v_n| = |n u_n| \cdot \left|\frac{v_n}{n}\right|$），把收敛的那个通项直接放缩成 $<1$ 消掉，剩下的跟绝对收敛的那个比大小，**必绝对收敛**！

### 卡片 2：数列 $\{b_n\}$ 与级数 $\sum a_n$ 联动（如【7.19】）
*   **视觉特征**：给了一个含相邻两项差 **$(b_{n+1} - b_n)$** 和 $a_n$ 的等式，问“数列 $\{b_n\}$ 收敛”与“级数 $\sum a_n$ 收敛”的关系。
*   **唯一核心手法（架设裂项桥）**：
    1. **搭桥翻译**：在草稿纸上写下 $\text{数列 } \{b_n\} \text{ 收敛} \iff \text{正项裂项级数 } \sum (b_{n+1} - b_n) \text{ 收敛}$。
    2. **做除法**：直接算比值 **$\frac{a_n}{b_{n+1} - b_n}$**，利用 $\{b_n\}$ 的单调有界（如 $b_n \ge 1$ 或 $\lim b_n = k > 0$），套正项级数比较审敛法，兩者一荣俱荣、一损俱损！

### 卡片 3：递推数列 $\{a_n\}$ 判敛散 / 求收敛半径（如【7.64】【7.67】【7.68】及根号题）
*   **视觉特征**：不给通项，只给关于 $a_n$ 的递推式。
*   **唯一核心手法（数项数，分两路）**：
    1. **如果是“两项递推”**（如 $2n a_n = (n+\frac{3}{2})a_{n-1}$，或 $u_{n+1} = \sqrt{2+u_n}$）：
       *   **直接除过去算比值极限** $\lim \left|\frac{a_{n+1}}{a_n}\right|$！（有根号就分子有理化，一般函数 $u_{n+1}=f(u_n)$ 就求导数 $|f'(A)|$）。
       *   比值极限 $<1$ 就绝对收敛；倒数就是精准的收敛半径 $R$。
    2. **如果是“三项递推”**（如 $a_{n+1} = a_n + a_{n-1}$，算不出比值极限）：
       *   题目必是让你证“当 $|x| < r$ 时收敛（即 $R \ge r$）”。
       *   **倒推锁定目标**：由 $|x| < r \implies \left|\frac{x}{r}\right| < 1 \implies$ 目标等比级数是 $\sum \frac{1}{r^n}|x|^n$；
       *   **数学归纳法**：直接用归纳法硬证 **$|a_n| \le \left(\frac{1}{r}\right)^n$**，然后套比较审敛法秒杀！

---

### 卡片 4：定积分定义的数列 $a_n = \int_0^1 \dots dx$（如【7.76】）
*   **视觉特征**：$a_n$ 是一个带着 $n$ 次方的定积分。
*   **唯一核心手法（能积就分部，不能积就夹逼）**：
    1. **好积的组合**（如 $x^2(\ln x)^n$，$x^n e^x$）：**分部积分降幂**，凑出 $a_n$ 与 $a_{n-1}$ 的两项递推式。
    2. **积不出的组合**（如 $\int_0^1 \frac{x^n}{1+x^2} dx$）：**把除 $x^n$ 以外的部分放缩成最大最小值 $[m, M]$**，提出来后直接夹出 $\frac{m}{n+1} \le a_n \le \frac{M}{n+1}$，说明 $a_n \sim \frac{C}{n}$，收敛半径直接为 $1$！

---

### 卡片 5：交错级数判敛的三大陷阱与拆项大招（如【例 7】【7.47.1】【7.15】）
*   **视觉特征**：级数带着 $(-1)^n$。
*   **三大核心手法**：
    1. **严禁直接等价代换**：只有加了绝对值变成正项级数后，才能用 $\sim$ 等价代换；不加绝对值时严禁等价！
    2. **看到 $(-1)^n (a_n + a_{n+1})$**：不要用莱布尼茨，直接写出前 3 项，**一正一负裂项相消**求部分和 $S_n$ 的极限！
    3. **遇到分母震荡不单调 $\frac{(-1)^n}{n(1+\alpha_n)}$**：用恒等式 $\frac{1}{1+\alpha_n} = 1 - \frac{\alpha_n}{1+\alpha_n}$ **拆成两项**（主部 $\sum \frac{(-1)^n}{n}$ 收敛 + 余项绝对收敛）。
    4. **条件收敛的奇偶铁律**：若正项交错级数 $\sum (-1)^{n-1} u_n$ 条件收敛，则加括号的 $\sum (u_{2n-1} - u_{2n})$ **必收敛**，而单独的奇数项 $\sum u_{2n-1}$ 和偶数项 $\sum u_{2n}$ **必双双发散**！

### 卡片 6：抽象幂级数变系数、变指数求收敛区间（如【7.39】【7.42】）
*   **视觉特征**：已知 $\sum a_n (x-x_0)^n$ 在某点收敛，求 $\sum n a_n^2 (x-x_1)^{4n+1}$ 的收敛区间。
*   **唯一核心手法（根值打包 / 换元 + 半径跟随变化）**：
    1. **看系数怎么变，半径 $R$ 就怎么变**：乘除 $n$ 的多项式 $R$ **不变**；系数平方 $a_n^2$，半径就**平方 $R^2$**；系数乘 $c^n$，半径就**除以 $|c|$**。
    2. **看谁括起来做了 $n$ 次方（设为 $u$）**：直接解不等式 **$|u| < R_{\text{新}}$**，一步得出收敛区间！
