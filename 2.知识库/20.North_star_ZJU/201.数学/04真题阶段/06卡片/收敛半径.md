这类题考研命题的所有花样，底层逻辑**全由柯西-阿达马公式（根值法）支配**：
$$R = \frac{1}{\limsup_{n\to\infty} \sqrt[n]{|c_n|}}$$

设已知原级数 $\sum_{n=1}^\infty a_n x^n$ 的收敛半径为 **$R$**（$0 < R < +\infty$）。
以下把考研可能考到的所有变形整理成**四大类终极对照表**：

---

### 一、系数操作型（下标 $n$ 不变，只对 $a_n$ 动手术）

| 级数形式 | 新收敛半径 $R_{\text{新}}$ | 理解性推理（柯西根值法本质） |
| :--- | :--- | :--- |
| **$\sum c a_n x^n$** ($c \neq 0$) | **$R$** | 常数开 $n$ 次方极限为 1：$\sqrt[n]{\ |c\|} \to 1$ |
| **$\sum n^k a_n x^n$** 或 **$\sum \frac{a_n}{n^k} x^n$** | **$R$** | 多项式开 $n$ 次方极限为 1：$\sqrt[n]{n^k} \to 1$（逐项求导、积分不改半径） |
| **$\sum a_n^m x^n$** ($m > 0$) | **$R^m$** | $\sqrt[n]{\ |a_n\|^m} = (\sqrt[n]{\|a_n\|})^m \to \left (\frac{1}{R}\right)^m \implies R_{\text{新}} = R^m$ |
| **$\sum \frac{1}{a_n} x^n$** | **$\frac{1}{R}$** | $\sqrt[n]{\frac{1}{\ |a_n\|}} = \frac{1}{\sqrt[n]{\|a_n\|}} \to R \implies R_{\text{新}} = \frac{1}{R}$ |
| **$\sum (c^n a_n) x^n$** ($c \neq 0$) | **$\frac{R}{\ |c\|}$** | $\sqrt[n]{\ |c\|^n \|a_n\|} = \|c\| \sqrt[n]{\|a_n\|} \to \frac{\|c\|}{R} \implies R_{\text{新}} = \frac{R}{\|c\|}$ |

> **应试口诀**：**乘除 $n$ 毫无影响；系数平方，半径平方；指数提纯放分母。**

---

### 二、下标抽样型（系数变成 $a_{kn}$，但 $x$ 还是 $x^n$）

| 级数形式 | 新收敛半径 $R_{\text{新}}$ | 理解性推理 |
| :--- | :--- | :--- |
| **$\sum a_{2n} x^n$** | **$R^2$** | $\sqrt[n]{\ |a_{2n}\|} = \left (\sqrt[\mathbf{2n}]{\|a_{2n}\|}\right)^{\mathbf{2}} \to \left (\frac{1}{R}\right)^2 \implies R_{\text{新}} = R^2$ |
| **$\sum a_{kn} x^n$** ($k \in \mathbb{N}^+$) | **$R^k$** | 抽取间隔为 $k$ 的子序列，开方指标差了 $k$ 倍：$\implies R_{\text{新}} = R^k$ |

---

### 三、自变量幂次型（系数不变，但 $x^n$ 变成 $x^{kn}$）

这类题**严禁用根值法硬算，统一用“整体代换法”解不等式**：

| 级数形式 | 新收敛半径 $R_{\text{新}}$ | 理解性推理（整体代换） |
| :--- | :--- | :--- |
| **$\sum a_n x^{2n}$** | **$\sqrt{R}$** | 令 $t = x^2$。收敛要求 $\ |t\| < R \implies \|x^2\| < R \implies \|x\| < \sqrt{R}$ |
| **$\sum a_n x^{kn}$** | **$\sqrt[k]{R}$** | 令 $t = x^k$。收敛要求 $\ |t\| < R \implies \|x^k\| < R \implies \|x\| < \sqrt[k]{R}$ |

---

### 四、复合与抵消型（考研命题最高频陷阱）

出题人最喜欢把**第二类（下标变）**和**第三类（次数变）**杂糅在一起考：

#### 1. 完全抵消型（如上一道真题）
* **形式**：$\sum a_{kn} x^{kn}$
* **推导**：
  * 令 $t = x^k$，级数变成 $\sum a_{kn} t^n$；
  * 根据第二类规则，关于 $t$ 的收敛半径为 $R_t = R^k$；
  * 收敛要求：$\|t\| < R_t \implies \|x^k\| < R^k \implies \|x\| < R$。
* **结论**：**$R_{\text{新}} = R$（完全抵消，半径不变！）**
* **直观理解**：系数挑了第 $kn$ 项，自变量也挑了第 $kn$ 次方，两者步调完全一致，效果刚好互相抵消。

#### 2. 加减组合型（木桶效应）
设 $\sum a_n x^n$ 半径为 $R_1$，$\sum b_n x^n$ 半径为 $R_2$：
* 若 **$R_1 \neq R_2$**：级数 $\sum (a_n \pm b_n)x^n$ 的收敛半径为 **$\min(R_1, R_2)$**（取决于短板）。
* 若 **$R_1 = R_2$**：级数 $\sum (a_n \pm b_n)x^n$ 的收敛半径 **$\ge R_1$**（主项可能刚好抵消导致半径扩大，比如 $a_n = 1, b_n = 1 + \frac{1}{2^n}$）。

---

### 考场秒杀口诀（遇题直接对号入座）

> **系数变 $m$ 次方，半径就作 $m$ 次方；**  
> **自变量变 $k$ 次方，半径就开 $k$ 次方；**  
> **下标与自变量同倍数变化，直接抵消不用慌！**





# 比值、根值审敛法为什么都与 1 比较？

**本质原因：它们的参照基准都是等比级数（几何级数）$\sum q^n$。**

* **等比级数的结论**：$\sum q^n$ 在 $q \ge 0$ 时，公比 $q < 1$ 收敛，$q \ge 1$ 发散。临界点正是 $1$。
* **根值法原理**：
  若 $\lim_{n \to \infty} \sqrt[n]{u_n} = \rho < 1$，由极限保号性，当 $n$ 充分大时，恒有 $\sqrt[n]{u_n} \le q < 1$（其中 $q$ 是介于 $\rho$ 与 1 之间的常数）。两边取 $n$ 次方得到：
  $u_n \le q^n$
  通项被一个公比小于 1 的等比级数的通项死死压住，由比较审敛法可知，它必然收敛。
* **比值法原理**：
  若 $\lim_{n \to \infty} \frac{u_{n+1}}{u_n} = \rho < 1$，说明序列每往后走一步，衰减的比例稳定在 $\rho$ 附近。当 $n$ 充分大时，同样有 $\frac{u_{n+1}}{u_n} \le q < 1$。
  将式子累乘得到 $u_n \le C \cdot q^n$，本质仍然是被等比级数控制。

**因此，1 就是“指数衰减（收敛）”与“指数增长/不衰减（发散）”的分水岭。**


#  $x$ 可以取负数，$a_n$ 也有正有负，为什么能用正项级数的结论？

**核心链条：绝对收敛 + 阿贝尔第一定理。**

#### 1. 绝对值的介入
我们直接考察幂级数的绝对收敛性，即构造正项级数 $\sum_{n=0}^{\infty} |a_n x^n| = \sum_{n=0}^{\infty} |a_n| |x|^n$。
对这个**正项级数**使用比值法：
$\lim_{n \to \infty} \frac{|a_{n+1}| |x|^{n+1}}{|a_n| |x|^n} = |x| \lim_{n \to \infty} \left| \frac{a_{n+1}}{a_n} \right|$
正项级数收敛的条件是极限小于 1：
$|x| \lim_{n \to \infty} \left| \frac{a_{n+1}}{a_n} \right| < 1 \implies |x| < \lim_{n \to \infty} \left| \frac{a_n}{a_{n+1}} \right| = R$

#### 2. 为什么绝对收敛能代表整个幂级数？
因为阿贝尔第一定理给出了空间分布结构：
* 在数轴上，一旦某个点 $x_0$ 使得级数收敛，那么在对称区间 $(-|x_0|, |x_0|)$ 内部的所有点，其衰减速度都会比 $x_0$ 处更快，因此**内部每一个点都必然绝对收敛**。
* 一旦某个点 $x_1$ 使得级数发散，则在该点之外（$|x| > |x_1|$），通项连趋于 0 都做不到，必然发散。

**结论**：除了区间的两个孤立端点 $x = \pm R$ 之外，**幂级数收敛的全部内部区域，本质上全是绝对收敛**。既然在内部全是绝对收敛，就等价于研究正项级数 $\sum |a_n x^n|$，所以正项级数的比值法、根值法自然完美迁移到了收敛半径的公式中。

### 四、考研应试解题法则

做数一真题时，落实为以下固定流程：

1. **求收敛半径 $R$**：
   * 标准幂级数 $\sum a_n x^n$：直接算 $\rho = \lim \left|\frac{a_{n+1}}{a_n}\right|$ 或 $\lim \sqrt[n]{|a_n|}$，则 $R = \frac{1}{\rho}$（注意系数值全带绝对值）。
   * 缺项或含 $x^{2n}$ 等复合项：不要死套 $R$ 公式，直接对通项取绝对值当作正项级数，令 $\lim_{n \to \infty} \left| \frac{u_{n+1}(x)}{u_n(x)} \right| < 1$ 解出关于 $x$ 的不等式。
2. **求收敛域**：
   * 先由半径定出开区间 $(-R, R)$（此区间内无需判断，必绝对收敛）。
   * **端点单独代入**：将 $x = R$ 和 $x = -R$ 分别代入原级数，转化为具体的常数项级数。此时若出现正负交替，用**莱布尼茨判别法**或绝对收敛性判定；若为正项级数，用比较审敛法的极限形式判别。
