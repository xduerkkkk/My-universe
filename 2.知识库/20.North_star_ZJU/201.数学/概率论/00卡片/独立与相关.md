红圈中给出了四个等价命题（$\Leftrightarrow$ 表示互为充要条件）：

**$X$ 与 $Y$ 不相关 $\Leftrightarrow Cov(X,Y) = 0 \Leftrightarrow D(X \pm Y) = D(X) + D(Y) \Leftrightarrow E(XY) = E(X)E(Y)$**

我们一步步来推导它们为什么是等价的：

#### 1. $X$ 与 $Y$ 不相关 $\Leftrightarrow Cov(X,Y) = 0$

- **推导**：这是根据相关系数 $\rho_{XY}$ 的定义直接得出的。相关系数的公式为：
    
    $$\rho_{XY} = \frac{Cov(X,Y)}{\sqrt{D(X)}\sqrt{D(Y)}}$$
    
    因为分母是标准差的乘积（通常假定方差大于 0），所以当且仅当分子协方差 $Cov(X,Y) = 0$ 时，相关系数 $\rho_{XY} = 0$，即 $X$ 与 $Y$ 不相关。
    

#### 2. $Cov(X,Y) = 0 \Leftrightarrow E(XY) = E(X)E(Y)$

- **推导**：根据协方差的计算公式展开：
    
    $$Cov(X,Y) = E[(X - E(X))(Y - E(Y))]$$
    
    将其乘开：
    
    $$Cov(X,Y) = E(XY - X \cdot E(Y) - Y \cdot E(X) + E(X)E(Y))$$
    
    根据期望的线性性质（常数的期望是其本身，常数可以提出来）：
    
    $$Cov(X,Y) = E(XY) - E(X)E(Y) - E(Y)E(X) + E(X)E(Y)$$
    
    $$Cov(X,Y) = E(XY) - E(X)E(Y)$$
    
    显然，当且仅当 $Cov(X,Y) = 0$ 时，必有 $E(XY) - E(X)E(Y) = 0$，即 $E(XY) = E(X)E(Y)$。
    

#### 3. $Cov(X,Y) = 0 \Leftrightarrow D(X \pm Y) = D(X) + D(Y)$

- **推导**：根据方差的展开公式：
    
    $$D(X \pm Y) = D(X) + D(Y) \pm 2Cov(X,Y)$$
    
    当且仅当 $Cov(X,Y) = 0$ 时，后面的尾巴 $\pm 2Cov(X,Y)$ 就变成了 0，公式就退化为：
    
    $$D(X \pm Y) = D(X) + D(Y)$$

### 二、 “独立”条件下的性质及推导

正如你图片右下角的笔记所写：**“独立 $\Rightarrow$ 不相关”**。独立是一个比不相关**强得多**的条件。

如果 $X$ 和 $Y$ 相互独立，不仅意味着它们没有线性关系，而且意味着**它们没有任何形式的关系**（一个变量的取值完全不影响另一个变量的概率分布）。

在 $X$ 和 $Y$ **相互独立**的条件下，上述几个数字特征的性质如下：

#### 1. 核心性质：$E(XY) = E(X)E(Y)$

- **推导**（以连续型随机变量为例）：
    
    如果 $X$ 和 $Y$ 独立，那么它们的联合概率密度函数等于边缘概率密度函数的乘积，即 $f(x,y) = f_X(x)f_Y(y)$。
    
    $$E(XY) = \int_{-\infty}^{\infty} \int_{-\infty}^{\infty} xy f(x,y) dx dy$$
    
    代入独立的条件：
    
    $$E(XY) = \int_{-\infty}^{\infty} \int_{-\infty}^{\infty} xy f_X(x)f_Y(y) dx dy$$
    
    分离积分变量：
    
    $$E(XY) = \left( \int_{-\infty}^{\infty} x f_X(x) dx \right) \left( \int_{-\infty}^{\infty} y f_Y(y) dy \right)$$
    
    $$E(XY) = E(X)E(Y)$$
    
    _(离散型同理，把积分换成求和符号即可)_
    

#### 2. 由核心性质推导出的其他性质：

因为独立必然导致 $E(XY) = E(X)E(Y)$，所以根据我们在第一部分推导的公式，多米诺骨牌就会连锁倒下：

- **协方差为零**：$Cov(X,Y) = E(XY) - E(X)E(Y) = 0$
    
- **相关系数为零（即不相关）**：$\rho_{XY} = 0$
    
- **和/差的方差**：$D(X \pm Y) = D(X) + D(Y)$

### 总结：独立与不相关的关系

结合你的图片，可以总结出这样一条逻辑链：

1. **相互独立 $\Rightarrow$ $E(XY) = E(X)E(Y)$ $\Rightarrow Cov(X,Y) = 0 \Rightarrow$ 不相关。** （独立一定不相关）
    
2. **不相关 $\Rightarrow Cov(X,Y) = 0 \Rightarrow E(XY) = E(X)E(Y)$。** 但是推不出相互独立！（不相关未必独立，因为不相关只排除了线性关系，可能还存在 $Y = X^2$ 这样的非线性关系）。

### 1. 独立推啥？ (老大出马，全场拿下)

如果你已知 $X$ 和 $Y$ **相互独立**，你可以理直气壮地推出以下所有结论：

- **推不相关：** $X$ 和 $Y$ 一定不相关。
    
- **推协方差为 0：** $Cov(X, Y) = 0$
    
- **推期望相乘：** $E(XY) = E(X)E(Y)$
    
- **推方差可加：** $D(X \pm Y) = D(X) + D(Y)$
    
- **推函数独立：** 即便是它们的函数，比如 $X^2$ 和 $e^Y$，依然相互独立。
    

### 2. 不相关推啥？ (小弟出马，只能推自己人)

如果你已知 $X$ 和 $Y$ **不相关**，你**只能**推出和它等价的那几个数学特征，**绝对推不出独立**（除非有特殊前提）。

- **推协方差为 0：** $Cov(X, Y) = 0$
    
- **推期望相乘：** $E(XY) = E(X)E(Y)$
    
- **推方差可加：** $D(X \pm Y) = D(X) + D(Y)$
    
- ❌ **绝对推不出独立！** （因为可能存在 $Y=X^2$ 这样的非线性关系，它们显然不独立，但算出来是不相关的）。
    

### 3. 啥能推独立？ (怎么才能当老大？)

想要证明 $X$ 和 $Y$ 独立，条件非常苛刻，通常只有以下两条路：

- **靠定义硬推：** 证明它们的联合概率等于边缘概率的乘积，即 $f(x,y) = f_X(x)f_Y(y)$ 或 $P(AB) = P(A)P(B)$。
    
- **靠“天选”特例（常考考点）：** 如果已知 $X$ 和 $Y$ 服从**二维正态分布**，那么此时“不相关 $\Rightarrow$ 相互独立”。（只有在这个特殊分布下，小弟才能代表老大）。
    

### 4. 啥能推不相关？ (怎么才能当小弟？)

推不相关非常容易，途径很多：

- **独立能推它：** 已知独立 $\Rightarrow$ 不相关。
    
- **公式倒推：** 只要你算出 $Cov(X,Y) = 0$，就能推不相关。
    
- **公式倒推：** 只要你发现 $E(XY) = E(X)E(Y)$，就能推不相关。
    
- **公式倒推：** 只要你发现 $D(X+Y) = D(X) + D(Y)$，就能推不相关。
