# 基本概念
随机实验，
出现的每一种情况都是一个样本点，
所有样本点集合为样本空间
随机事件的是样本空间的子集。

#### **随机事件通常是多个样本点吗？**

*   它可以包含**多个**样本点。例如：掷骰子，“点数大于 3”这个事件包含三个样本点：$\{4, 5, 6\}$。
*   它可以只包含**一个**样本点。例如：掷骰子，“点数是 6”这个事件只包含：$\{6\}$。
*   它可以包含**全部**样本点（必然事件 $\Omega$）。
*   它甚至可以**不包含任何**样本点（不可能事件 $\varnothing$）。


由单个样本点组成的集合成为基本事件

#### **基本事件和随机事件的区别是？**

*   **基本事件（Elementary Event）：** 特指只包含**一个**样本点的集合。它是构成所有事件的最小单位，不能再拆分了。
    *   *例子：* 掷骰子，$\{1\}$ 是一个基本事件。
*   **随机事件（Random Event）：** 这是一个**广义的概念**。任何样本空间的子集都叫随机事件。
    *   **区别：** “基本事件”一定是“随机事件”，但“随机事件”不一定是“基本事件”。‘



#### 事件 A 发生，是对未来某一现象的陈述？
**是的。** 在实验开始前，事件 $A$ 是我们的一种**预期或描述**（例如：“明天会下雨”）。

但从数学严谨的角度来说：
*   **事件 $A$ 本身是一个集合**（它描述了所有符合条件的可能结果）。
*   **“事件 $A$ 发生”** 这个动作，是指实验结束后，实际观察到的那个**唯一的样本点 $\omega$**，刚好落在了集合 $A$ 里面

#### 这个事件 A 到底是样本点还是多个样本点？
事件 $A$ ，全称应是随机事件，永远是一个“集合“，


# 事件关系运算


### 1. 事件间的关系
| 关系名称      | 符号表示                                           | 概率论含义                 | 集合论对应          |
| :-------- | :--------------------------------------------- | :-------------------- | :------------- |
| **包含**    | $A \subset B$                                  | 若 $A$ 发生，则 $B$ 必发生    | 子集             |
| **相等**    | $A = B$                                        | $A, B$ 互为包含，发生情况完全相同  | 集合相等           |
| **互斥**    | $A \cap B = \varnothing$                       | $A, B$ 不能同时发生         | 不相交            |
| **对立**    | $A \cup B = \Omega$ 且 $A \cap B = \varnothing$ | $A, B$ 必有一个发生，且仅有一个发生 | 补集 ($\bar{A}$) |
| **完备事件组** | $\bigcup A_i = \Omega$ 且两两互斥                   | 实验结果必落在且仅落在其中一个事件中    | 样本空间的划分        |


描述：
A 和B 至少发生一个的情况下，AB 恰有一个发生的概率
$A\bar B \cup B\bar A | A \cup B$  



### 2. 事件的运算
*   **并（和事件）**: $A \cup B$ 
    *   含义：$A$ 与 $B$ 中**至少有一个**发生。
*   **交（积事件）**: $A \cap B$ (或 $AB$)
    *   含义：$A$ 与 $B$ **同时**发生。
*   **差（差事件）**: $A - B$
    *   含义：$A$ 发生，但 $B$ **不发生**。公式：$A - B = A \bar{B} = A - (AB)$。
       <font color="#ff0000">概率论中没定义负事件，-A 是无意义的，不要运算</font>
*   **逆（对立事件）**: $\bar{A}$
    *   含义：$A$ **不发生**。公式：$\bar{A} = \Omega - A$。

---

### 3. 运算定律 (与集合论一致)
1.  **交换律**: $A \cup B = B \cup A$ ； $AB = BA$
2.  **结合律**: $(A \cup B) \cup C = A \cup (B \cup C)$ 
3.  **分配律**: 
    *   $A(B \cup C) = (AB) \cup (AC)$
    *   $A \cup (BC) = (A \cup B)(A \cup C)$
4.  **摩根律 (De Morgan's Laws) ⭐**:
    *   $\overline{A \cup B} = \bar{A} \cap \bar{B}$  (不发生的并 = 不发生的交)
    *   $\overline{A \cap B} = \bar{A} \cup \bar{B}$  (不发生的交 = 不发生的并)

---

### 4. 核心概率性质
*   **非负性**: $0 \le P(A) \le 1$
*   **规范性**: $P(\Omega) = 1, \quad P(\varnothing) = 0$
*   **加法公式**: $P(A \cup B) = P(A) + P(B) - P(AB)$
    *   *若 $A, B$ 互斥，则 $P(A \cup B) = P(A) + P(B)$*
*   **减法公式**: $P(A - B) = P(A) - P(AB)$
*   **逆事件公式**: $P(\bar{A}) = 1 - P(A)$

---

**Tip:** 在处理复杂逻辑时，优先使用 **摩根律** 将“长杠”拆分为“短杠”，或将多个事件的并转化为交。

# 对概率的理解
实验中，事件发生的频率，稳定在概率附近。

公理化定义：
如果对于随机实验的每个实验，赋予一个实数，
这个实数有
1.  **非负性**：$0 \le P(A) \le 1$
2.  **规范性**：$P(\Omega) = 1, \quad P(\varnothing) = 0$
3.  **可列可加性**：若 $A_1, A_2, \dots$ 两两互斥，则 $P(\cup A_i) = \sum P(A_i)$

A 事件上的实数是 P (A)，叫概率
注意，
### P (A)=0，推不出 A 是空集，为何？
*   **几何概型的例子：**
    想象你往一个面积为 $1$ 的靶盘上随机扔一根无限细的针。
    *   **样本空间 $\Omega$**：靶盘上所有的点（无数多个）。
    *   **事件 $A$**：针尖恰好扎在靶盘中心那个**精确的点**上。
    *   **分析**：一个点的面积是 $0$。根据几何概率公式 $\frac{\text{点面积}}{\text{总面积}} = \frac{0}{1} = 0$。
    *   **结论**：$P(A) = 0$，但是中心点确实**存在**（$A \neq \varnothing$），针尖**理论上可以**扎在上面。

*   **专业术语：**
    我们称 $P(A)=0$ 的事件为**“几乎处处不发生”**。在连续型随机变量中，取任何一个特定值的概率都是 $0$，但那个值显然是样本空间的一部分。
    
    
### P (A)=1, 也推不出 A 是必然事件，或者那个Ω，为何？
*核心直觉：概率为 1 并不意味着“绝对发生”，只是意味着“不发生的概率为 0”。**

*   **同样的靶盘例子：**
    *   **样本空间 $\Omega$**：整个靶盘。
    *   **事件 $A$**：针尖扎在**除了中心点以外**的任何地方。
    *   **分析**：由于中心点的概率是 $0$，那么整个靶盘减去这一个点，剩下的概率依然是 $1 - 0 = 1$。
    *   **结论**：$P(A) = 1$，但 $A$ 并不等于 $\Omega$（因为它漏掉了一个中心点）。

*   **专业术语：**
    我们称 $P(A)=1$ 的事件为**“几乎必然发生” (Almost Surely, a.s.)**。

## 概率性质与公式

> [!TIP] 核心逻辑
> 概率 $P(A)$ 就是集合 $A$ 的“大小”占比。所有公式的推导都源于：**不要重复计算重叠部分**。


### 2. 核心计算公式
| 名称       | 公式                                                            | 备注                |
| :------- | :------------------------------------------------------------ | :---------------- |
| **单调性**  | 若 $A \subset B$，则 $P(A) \le P(B)$                             | 小集合概率 $\le$ 大集合概率 |
| **逆事件**  | $P(\bar{A}) = 1 - P(A)$<br>同事件运算                              | “正面算不动，就从背面算”     |
| **减法公式** | $P(A - B) = P(A) - P(AB)$，同事件运算，<br>A-B=A-AB                  | 发生 $A$ 但不发生 $B$   |
| **加法公式** | $P(A \cup B) = P(A) + P(B) - P(AB)$<br>                       | **最常用**。减去重叠的一份   |
| **广义加法** | $P(A \cup B \cup C) = \sum P(A_i) - \sum P(A_i A_j) + P(ABC)$ | 包含排斥原理 (容斥)       |


### 3. 特殊关系下的简化
*   **若 $A, B$ 互斥 ($AB = \varnothing$)**:
    *   $P(A \cup B) = P(A) + P(B)$
    *   $P(A - B) = P(A)$
*   **若 $A \subset B$**:
    *   $P(B - A) = P(B) - P(A)$

---

### 4. 重点公式对比 (集合 vs 概率)
| 集合描述                                         | 概率等式                                 | 直观理解                      |
| :------------------------------------------- | :----------------------------------- | :------------------------ |
| $A \subset B$                                | $P(B) = P(A) + P(B-A)$               | 大面积 = 小面积 + 环形面积          |
| $\overline{A \cup B} = \bar{A} \cap \bar{B}$ | $P(\text{都不发生}) = P(\bar{A}\bar{B})$ | 摩根律套个 $P$ 依然成立            |
| $A = (A-B) \cup (AB)$                        | $P(A) = P(A-B) + P(AB)$              | 全等于“只在 $A$ 不在 $B$” + “都在” |


1.  **$P(A \cup B) = P(A) + P(B)$ 只有在 $A, B$ 互斥时才成立！** 平时做题千万别忘了减去中间重叠的 $P(AB)$。
2.  **$P(A-B)$ 不一定等于 $P(A)-P(B)$**。只有当 $B \subset A$ 时才成立。如果 $B$ 有一部分在 $A$ 外面，减去 $P(B)$ 就减多了。**永远记得减去的是“交集” $P(AB)$**。
