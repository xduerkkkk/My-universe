# 基本概念
随机实验，
出现的每一种情况都是一个样本点，
所有样本点集合为样本空间
随机事件的是样本空间的子集。

#### **随机事件通常是多个样本点吗？**

*   它可以包含**多个**样本点。例如：掷骰子，“点数大于 3”这个事件包含三个样本点：$\{4, 5, 6\}$。
*   它可以只包含**一个**样本点。例如：掷骰子，“点数是 6”这个事件只包含：$\{6\}$。
*   它可以包含**全部**样本点（必然事件 $\Omega$）。
*   它甚至可以**不包含任何**样本点（不可能事件 $\varnothing$）。


由单个样本点组成的集合成为基本事件

#### **基本事件和随机事件的区别是？**

*   **基本事件（Elementary Event）：** 特指只包含**一个**样本点的集合。它是构成所有事件的最小单位，不能再拆分了。
    *   *例子：* 掷骰子，$\{1\}$ 是一个基本事件。
*   **随机事件（Random Event）：** 这是一个**广义的概念**。任何样本空间的子集都叫随机事件。
    *   **区别：** “基本事件”一定是“随机事件”，但“随机事件”不一定是“基本事件”。‘



#### 事件 A 发生，是对未来某一现象的陈述？
**是的。** 在实验开始前，事件 $A$ 是我们的一种**预期或描述**（例如：“明天会下雨”）。

但从数学严谨的角度来说：
*   **事件 $A$ 本身是一个集合**（它描述了所有符合条件的可能结果）。
*   **“事件 $A$ 发生”** 这个动作，是指实验结束后，实际观察到的那个**唯一的样本点 $\omega$**，刚好落在了集合 $A$ 里面

#### 这个事件 A 到底是样本点还是多个样本点？
事件 $A$ ，全称应是随机事件，永远是一个“集合“，


# 事件关系运算


### 1. 事件间的关系
| 关系名称      | 符号表示                                           | 概率论含义                 | 集合论对应          |
| :-------- | :--------------------------------------------- | :-------------------- | :------------- |
| **包含**    | $A \subset B$                                  | 若 $A$ 发生，则 $B$ 必发生    | 子集             |
| **相等**    | $A = B$                                        | $A, B$ 互为包含，发生情况完全相同  | 集合相等           |
| **互斥**    | $A \cap B = \varnothing$                       | $A, B$ 不能同时发生         | 不相交            |
| **对立**    | $A \cup B = \Omega$ 且 $A \cap B = \varnothing$ | $A, B$ 必有一个发生，且仅有一个发生 | 补集 ($\bar{A}$) |
| **完备事件组** | $\bigcup A_i = \Omega$ 且两两互斥                   | 实验结果必落在且仅落在其中一个事件中    | 样本空间的划分        |


描述：
A 和B 至少发生一个的情况下，AB 恰有一个发生的概率
$A\bar B \cup B\bar A | A \cup B$  



### 2. 事件的运算
*   **并（和事件）**: $A \cup B$ 
    *   含义：$A$ 与 $B$ 中**至少有一个**发生。
*   **交（积事件）**: $A \cap B$ (或 $AB$)
    *   含义：$A$ 与 $B$ **同时**发生。
*   **差（差事件）**: $A - B$
    *   含义：$A$ 发生，但 $B$ **不发生**。公式：$A - B = A \bar{B} = A - (AB)$。
       <font color="#ff0000">概率论中没定义负事件，-A 是无意义的，不要运算</font>
*   **逆（对立事件）**: $\bar{A}$
    *   含义：$A$ **不发生**。公式：$\bar{A} = \Omega - A$。

---

### 3. 运算定律 (与集合论一致)
1.  **交换律**: $A \cup B = B \cup A$ ； $AB = BA$
2.  **结合律**: $(A \cup B) \cup C = A \cup (B \cup C)$ 
3.  **分配律**: 
    *   $A(B \cup C) = (AB) \cup (AC)$
    *   $A \cup (BC) = (A \cup B)(A \cup C)$
4.  **摩根律 (De Morgan's Laws) ⭐**:
    *   $\overline{A \cup B} = \bar{A} \cap \bar{B}$  (不发生的并 = 不发生的交)
    *   $\overline{A \cap B} = \bar{A} \cup \bar{B}$  (不发生的交 = 不发生的并)

---

### 4. 核心概率性质
*   **非负性**: $0 \le P(A) \le 1$
*   **规范性**: $P(\Omega) = 1, \quad P(\varnothing) = 0$
*   **加法公式**: $P(A \cup B) = P(A) + P(B) - P(AB)$
    *   *若 $A, B$ 互斥，则 $P(A \cup B) = P(A) + P(B)$*
*   **减法公式**: $P(A - B) = P(A) - P(AB)$
*   **逆事件公式**: $P(\bar{A}) = 1 - P(A)$

---
**Tip:** 在处理复杂逻辑时，优先使用 **摩根律** 将“长杠”拆分为“短杠”，或将多个事件的并转化为交。
