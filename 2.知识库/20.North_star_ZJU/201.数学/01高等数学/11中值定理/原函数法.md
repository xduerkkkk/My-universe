## 偏技巧，**两边乘以适当的“积分因子”，直接写出原函数**


“原函数法”的本质是：**寻找一个式子 $F(x)$，使得 $F'(x) = 0 \iff$ 待证结论。**

* **一阶问题（前两个例子）：** 比较简单，通过简单的移项、分离变量两边积分就能直接看出 $F(x)$。
* **二阶问题（第三个例子）：** 形式变成了 $f''(x) + f(x) = 0$。本质上它就是一个**二阶常系数齐次微分方程**。
  * 我们通过特征方程 $r^2+1=0$ 解出通解 $f(x) = C_1\sin x + C_2\cos x$；
  * 因为通解有两个常数，通过求导消去一个常数后，化出 $F(x) = C$ 的形式（如 $f(x)\cos x - f'(x)\sin x = C$）；
  * **这个过程最终的目的，依然是找到了原函数 $F(x)$。** 所以它没有脱离原函数法，只是找原函数的工具升级成了求解二阶微分方程。

---

这个结论完全可以直接“凑”出原函数（无需解特征方程）

如果你不想完整走一遍“特征方程 $\to$ 通解 $\to$ 消常数”的流程，也可以用一阶原函数法的思想——**两边乘以适当的“积分因子”，直接写出原函数**：

 方案一：乘 $\sin x$ 或 $\cos x$（直接识别乘积求导法则）
待证式：$f''(x) + f(x) = 0$
* **两边同乘 $\sin x$：**
  $$f''(x)\sin x + f(x)\sin x = 0$$
  注意到：
  $$[f'(x)\sin x - f(x)\cos x]' = f''(x)\sin x + f'(x)\cos x - f'(x)\cos x + f(x)\sin x = f''(x)\sin x + f(x)\sin x$$
  两边直接积分即得：
  $$f'(x)\sin x - f(x)\cos x = C \implies F(x) = f'(x)\sin x - f(x)\cos x$$

* **两边同乘 $\cos x$：**
  同理可得：
  $$[f'(x)\cos x + f(x)\sin x]' = 0 \implies F(x) = f'(x)\cos x + f(x)\sin x$$

---

 方案二：乘 $2f'(x)$（物理中的能量守恒 / 经典可降阶原函数）
这也是考研和竞赛中极高频的一种直接构造法：
* 待证式两边同乘 $2f'(x)$：
  $$2f'(x)f''(x) + 2f(x)f'(x) = 0$$
* 观察原函数：
  * $2f'(x)f''(x) = [(f'(x))^2]'$
  * $2f(x)f'(x) = [f^2(x)]'$
* 两边积分直接得到：
  $$[f'(x)]^2 + f^2(x) = C \implies F(x) = [f'(x)]^2 + f^2(x)$$
  *(对 $F(x)$ 用罗尔定理：$F'(\xi) = 2f'(\xi)[f''(\xi) + f(\xi)] = 0$，只要 $f'(\xi) \neq 0$ 也能证出结论)*

## 可能要降阶，和微分方程一样
![[_attachments/image/原函数法-1787456006083.jpeg]]

这道题的待证式是：
$$f''(x) + [f(x)f'(x)]^2 = 0$$

1. **它是非线性的：** 里面出现了平方项 $[f(x)f'(x)]^2$，无法像上一题 $f''(x) + f(x) = 0$ 那样直接列特征方程 $r^2+1=0$。
2. **它属于标准题型：** 式子里**只有 $f(x), f'(x), f''(x)$，没有单独的自变量 $x$**（即高数里典型的“不显含 $x$ 的二阶微分方程”）。
3. **消除思维负担：** 考研高数中这类方程有一套死板的机械套路：
   $$\text{令 } y = f(x), \quad p = y' = f'(x), \quad y'' = p\frac{dp}{dy}$$
   代入后，原本复杂的二阶非线性方程立刻退化成大一最基础的**一阶可分离变量方程**，不需要任何灵感就能算出来。




实际上，如果你对导数结构比较敏感，**完全不需要换元引入 $p$ 和 $y$**，直接用第一张图讲的“移项/除式子积分”：

1. **写出待证式：**
   $$f''(x) + f^2(x)[f'(x)]^2 = 0$$

2. **两边同除以 $f'(x)$：**
   $$\frac{f''(x)}{f'(x)} + f^2(x)f'(x) = 0$$

3. **直接识别原函数（凑微分）：**
   * 第一项：$\frac{f''(x)}{f'(x)} = \big(\ln|f'(x)|\big)'$
   * 第二项：$f^2(x)f'(x) = \big(\frac{1}{3}f^3(x)\big)'$

4. **两边直接积分：**
   $$\ln|f'(x)| + \frac{1}{3}f^3(x) = C_1$$
   两边取指数 $e^{\dots}$：
   $$|f'(x)| \cdot e^{\frac{1}{3}f^3(x)} = e^{C_1} \implies f'(x)e^{\frac{1}{3}f^3(x)} = C$$

5. **直接得到辅助函数：**
   $$G(x) = f'(x)e^{\frac{1}{3}f^3(x)}$$

你看，这个结果和降阶法算出来的完全一模一样，而且只需要两步。
