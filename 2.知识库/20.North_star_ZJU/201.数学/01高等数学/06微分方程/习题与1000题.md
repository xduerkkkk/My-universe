## 6 化简
![[习题与1000题-1773803405309.jpeg]]
### 第一步：降阶与分离变量

题目：$xy'' + 3y' = 0$

因为方程里缺了 $y$，所以我们果断使用你说的换元法：

令 $y' = p$，那么 $y'' = \frac{dp}{dx}$。

代入原方程，就从二阶降到了一阶：

$$x\frac{dp}{dx} + 3p = 0$$

把 $p$ 和 $x$ 各回各家（分离变量）：

$$x\frac{dp}{dx} = -3p$$

$$\frac{dp}{p} = -\frac{3}{x}dx$$

---

### 第二步：第一次积分与常数的“华丽变身”

等号两边同时积分：

$$\int \frac{1}{p} dp = \int -\frac{3}{x} dx$$

积分出来以后，**常数第一次登场**：

$$\ln|p| = -3\ln|x| + C$$

> **💡 核心知识点：对数常数的“凑脸熟”技巧**
> 
> 到了这一步，左边是 $\ln$，右边也有 $\ln$。如果你把常数写成孤零零的 $C$，下一步解 $p$ 的时候就会变成 $p = e^{-3\ln|x| + C}$，特别难看。
> 
> **怎么办？** 因为 $C$ 是可以在 $(-\infty, +\infty)$ 随便取的任意常数，那我们完全可以把它写成 $\ln|C_1|$ 的形式（因为 $\ln$ 的值域也是实数集）。
> 
> 这样写纯粹是为了等会儿能利用对数的加法公式合并！

我们把 $C$ 换成 $\ln|C_1|$，并利用对数法则（$-3$ 放进指数里）：

$$\ln|p| = \ln|x^{-3}| + \ln|C_1|$$

$$\ln|p| = \ln|C_1 x^{-3}|$$

现在两边都有 $\ln|\dots|$，直接脱掉对数符号：

$$p = \pm C_1 x^{-3}$$

> **💡 核心知识点：正负号的“黑洞吸收”**
> 
> 这里的 $\pm C_1$ 看着很烦。但你想，$C_1$ 本来就是个任意正常数，前面加个 $\pm$，它就变成了一个**可以为正、可以为负的全新任意常数**。
> 
> 为了书写干净，数学家们会毫不留情地把 $\pm$ 号直接“吸收”进常数里，重新命名为一个新的常数。为了省字母，通常还是写成 $C_1$（此时的 $C_1$ 包含了正负）。

所以，化简后我们得到了极其干净的 $p$：

$$p = C_1 x^{-3}$$

---

### 第三步：第二次积分与常数的再次合并

别忘了，我们的 $p$ 其实是 $y'$：

$$\frac{dy}{dx} = C_1 x^{-3}$$

为了求 $y$，我们把 $dx$ 乘过去，进行**第二次积分**：

$$dy = C_1 x^{-3} dx$$

$$y = \int C_1 x^{-3} dx$$

根据幂函数的积分公式 $\int x^n dx = \frac{x^{n+1}}{n+1}$：

$$y = C_1 \left( \frac{x^{-2}}{-2} \right) + C_2$$

此时，**第二次积分产生了第二个常数 $C_2$**。

> **💡 核心知识点：系数的“黑洞吸收”**
> 
> 我们来看这一坨：$C_1 \cdot \frac{1}{-2}$。
> 
> 刚才说了，常数是个无底洞。一个任意常数 $C_1$ 乘以一个具体的数字 $-\frac{1}{2}$，结果依然是一个任意常数！
> 
> 所以，我们再次发动“黑洞吸收”大法，令新的 $C_1^* = -\frac{1}{2} C_1$。
> 
> 在最终写答案时，为了美观，我们连星号都不写，直接用一个干净的 $C_1$ 来代表这一整坨。

于是，式子变成了最终的完美形态：

$$y = C_1 x^{-2} + C_2$$

或者写成分数形式：

$$y = \frac{C_1}{x^2} + C_2$$

### 多解法：欧拉
### 第一步：给它穿上“欧拉”的马甲（配凑次幂）

你可能会纳闷，欧拉方程的标准脸不是 $x^2y'' + pxy' + qy = 0$ 吗？这道题怎么少了一个 $x$？

没关系，既然它等号右边是 0，我们直接**等式两边同乘一个 $x$**，强行给它凑出完美的“等维匹配”：

$$x^2y'' + 3xy' = 0$$

看！现在它完全符合欧拉方程的特征了：二阶导配 $x^2$，一阶导配 $x^1$。这里的常数 $p=3, q=0$。

### 第二步：祭出换元法“秒杀公式”

按照我们上一节总结的欧拉方程套路，直接令 **$x = e^t$**（即 $t = \ln x$）。

不需要再苦哈哈地推导一遍链式法则了，直接默写那两个替换公式：

- $xy' \implies \frac{dy}{dt}$
    
- $x^2y'' \implies \frac{d^2y}{dt^2} - \frac{dy}{dt}$
    

把它们代入到我们刚才凑好的 $x^2y'' + 3xy' = 0$ 中：

$$(\frac{d^2y}{dt^2} - \frac{dy}{dt}) + 3(\frac{dy}{dt}) = 0$$

合并同类项，见证奇迹的时刻：

$$\frac{d^2y}{dt^2} + 2\frac{dy}{dt} = 0$$

或者写成我们更习惯的形式：**$y''(t) + 2y'(t) = 0$**。

你看！烦人的变系数 $x$ 瞬间灰飞烟灭，它变成了一个极其温顺的**常系数线性齐次微分方程**！

### 第三步：常规操作，解常系数方程

这下就是闭着眼睛都能解的送分题了。

写出特征方程：

$$r^2 + 2r = 0$$

提取公因式：

$$r(r + 2) = 0$$

解得两个不相等的实数特征根：**$r_1 = 0, r_2 = -2$**。

既然有两个不同的实根，按照公式，它的通解（注意此时自变量是 $t$）就是：

$$y = C_1 e^{0 \cdot t} + C_2 e^{-2t}$$

因为 $e^0 = 1$，所以化简为：

$$y = C_1 + C_2 e^{-2t}$$

### 第四步：脱下马甲，变回 $x$

最后一步，千万别忘了我们的自变量本来是 $x$。

因为我们一开始令了 $x = e^t$，所以 $e^{-2t}$ 可以写成 $(e^t)^{-2}$，也就是 **$x^{-2}$**。

把它代回去：

$$y = C_1 + C_2 x^{-2}$$

稍微整理一下排版：

$$y = C_1 + \frac{C_2}{x^2}$$


## 8 欧拉
![[习题与1000题-1773804473128.jpeg]]

**为什么书上要分 $x>0$ 和 $x<0$ 写那么一大坨？**

这是教科书必须保持的“严谨求生欲”。

因为第一步换元时 $t = \ln x$，对数函数里的 $x$ 必须大于 0！那万一题目里的 $x$ 是负数怎么办呢？

数学家就打了个补丁：如果 $x<0$，我们就令 $x = -e^t$，这样就能保证里面是正数。经过同样一套流程算下来，最后把两个结果合并时，为了兼容正负号，就在对数里面加上了绝对值，变成 **$\ln|x|$**，并且把常数项统一写成带绝对值的形式。

**考场实战建议：**

在考研或期末考的大题中，除非题目明确告诉你定义域，否则你默认 $x>0$ 去算，最后在写答案的时候，**顺手把 $\ln x$ 写成 $\ln|x|$**，这就能拿到满分，完全不需要像书上那样写两遍推导过程。

## 10 含积分，转化为微分方程
![[习题与1000题-1773805888338.jpeg]]
化为了一阶非齐次微分方程
### 第一步：极坐标化简（把纸老虎打回原形）

你看那个积分区域 $x^2+y^2 \le 4t^2$，这不就是一个半径为 $2t$ 的圆吗？被积函数里又有 $\sqrt{x^2+y^2}$。这简直就是把**“快用极坐标”**五个大字写在了脸上！

我们令 $x = r\cos\theta, y = r\sin\theta$。

- 积分区域变成了：$\theta$ 从 $0$ 到 $2\pi$，$r$ 从 $0$ 到 $2t$。
    
- 被积函数变成了：$f(\frac{r}{2})$。
    
- 面积微元 $dxdy$ 变成了：$r dr d\theta$（千万别忘了多出来的这个 $r$！）
    

把二重积分写出来：

$$\iint f\left(\frac{1}{2}\sqrt{x^2+y^2}\right) dxdy = \int_0^{2\pi} d\theta \int_0^{2t} f\left(\frac{r}{2}\right) r dr$$

前面那个 $\theta$ 的积分和后面毫无瓜葛，直接积出来就是 $2\pi$。

式子变成了：

$$2\pi \int_0^{2t} f\left(\frac{r}{2}\right) r dr$$

为了让式子看起来更舒服，我们再做一个简单的换元。令 $u = \frac{r}{2}$，那么 $r = 2u$，$dr = 2du$。

当 $r=0$ 时，$u=0$；当 $r=2t$ 时，$u=t$。

代进去：

$$2\pi \int_0^t f(u) \cdot (2u) \cdot (2du) = 8\pi \int_0^t u f(u) du$$

**见证奇迹的时刻：** 那个吓人的二重积分，经过极坐标变换，变成了一个极其清爽的一元变上限积分！

现在的原方程变成了这样：

$$f(t) = e^{4\pi t^2} + 8\pi \int_0^t u f(u) du$$

---

### 第二步：两边求导（积分方程 $\implies$ 微分方程）

还记得我们之前聊过的“变上限积分求导”吗？这里就是它的主场！

我们对等式两边同时关于 $t$ 求导：

- 左边求导：$f'(t)$
    
- 右边第一项求导（复合函数）：$e^{4\pi t^2} \cdot 8\pi t = 8\pi t e^{4\pi t^2}$
    
- 右边第二项求导（变上限积分，直接把上限 $t$ 塞进去替换 $u$）：$8\pi \cdot t f(t)$
    

把它们拼起来：

$$f'(t) = 8\pi t e^{4\pi t^2} + 8\pi t f(t)$$

移个项，整理一下队形：

$$f'(t) - 8\pi t f(t) = 8\pi t e^{4\pi t^2}$$

你看！它完美地褪去了所有伪装，变成了一个标准的**一阶线性微分方程**！

---

### 第三步：寻找初始条件（解的临门一脚）

解一阶微分方程，最后一定会产生一个任意常数 $C$。要解出这个 $f(t)$（特解），我们需要一个初始条件（比如 $t=0$ 时，$f(0)$ 等于几）。

这个条件去哪里找呢？**回到最原始的那个含有积分号的方程里去找！**

原方程：$f(t) = e^{4\pi t^2} + 8\pi \int_0^t u f(u) du$

我们让上限和下限相等，也就是令 $t = 0$：

$$f(0) = e^0 + 8\pi \int_0^0 u f(u) du$$

因为积分上下限都是 0，所以整个积分项就是 0。而 $e^0 = 1$。

所以我们白嫖到了一个初始条件：**$f(0) = 1$**。

---

**总结一下这道题的剧本：**

通过极坐标化简，再求导，我们最终得到的是一个**带有初始条件的一阶线性微分方程初值问题**：

$$\begin{cases} f'(t) - 8\pi t f(t) = 8\pi t e^{4\pi t^2} \\ f(0) = 1 \end{cases}$$

剧本我已经帮你写好了，剩下的就是纯纯的套公式体力活了。

## 8
速率，是 xx 对时间的导。这里是体积！
![[习题与1000题-1773883619268.jpeg]]### 第一步：把静态几何变成动态函数（区分 $z$ 和 $h$）

1. **水面的动态半径：** 当水面上升到高度 $h$ 时，水面边缘正好卡在曲线上，所以此时的半径 $y = f(h)$。
    
2. **水面的动态面积：** 你说的完全对，就是圆面积。
    
    $$S = \pi [f(h)]^2$$
    
    _(注意，这里的 $S$ 是会随着水面高度 $h$ 变化的，即 $S(h)$。)_
    
3. **水的动态体积：** 积分的上限不再是泛泛的 $z$，而是实实在在的水面高度 $h$。为了不和积分变量撞车，我们把积分里的变量叫作 $z$。
    
    $$V = \int_0^h \pi [f(z)]^2 dz$$
    

### 第二步：利用“链式法则”翻译题目条件（消灭时间 $t$）

题目给的是关于时间 $t$ 的变化率：

- 注水速率：$\frac{dV}{dt} = 3$
    
- 面积增大速率：$\frac{dS}{dt} = \pi$
    

但在我们的几何公式里，只有体积 $V$、面积 $S$ 和水深 $h$。怎么把 $t$ 联系起来呢？**用链式法则！**

**1. 翻译体积变化率（核心神操作！）：**

根据变上限积分求导定理，对刚才的体积公式 $V = \int_0^h \pi [f(z)]^2 dz$ 求导：

$$\frac{dV}{dt} = \frac{dV}{dh} \cdot \frac{dh}{dt}$$

因为 $\frac{dV}{dh}$ 就是积分上限求导，直接把 $h$ 塞进去，得到 $\pi [f(h)]^2$。而这正好就是水面面积 $S$！

所以：

$$\frac{dV}{dt} = S \cdot \frac{dh}{dt} = 3$$

这就推导出了一个极其关键的中间结论：**$\frac{dh}{dt} = \frac{3}{S}$** （水面上升的速度，等于注水速度除以水面面积）。

**2. 翻译面积变化率：**

同样用链式法则展开面积的变化率：

$$\frac{dS}{dt} = \frac{dS}{dh} \cdot \frac{dh}{dt} = \pi$$

现在，把上面算出来的 $\frac{dh}{dt} = \frac{3}{S}$ 代入进来：

$$\frac{dS}{dh} \cdot \frac{3}{S} = \pi$$

整理一下，我们得到了一个完全没有时间 $t$，只有面积 $S$ 和水深 $h$ 的**微分方程**：

$$\frac{dS}{dh} = \frac{\pi}{3} S$$

### 第三步：解微分方程，打通最后一公里

这就是一个最简单的一阶可分离变量微分方程：

$$\frac{dS}{S} = \frac{\pi}{3} dh$$

两边积分：

$$\ln S = \frac{\pi}{3} h + C_1$$

$$S = C e^{\frac{\pi}{3} h}$$

**找初始条件定常数：**

题目说“容器底面积为 16$\pi$”。底面积在哪？在 $z=0$（即水深 $h=0$）的地方！

所以当 $h=0$ 时，$S = 16\pi$。代入进去：

$$16\pi = C e^0 \implies C = 16\pi$$

于是我们得到了面积 $S$ 随水深 $h$ 变化的精确公式：

$$S = 16\pi e^{\frac{\pi}{3} h}$$

**原路返回，求目标曲线 $y=f(z)$：**

回到我们在第一步写的：面积 $S = \pi y^2$。

所以：

$$\pi y^2 = 16\pi e^{\frac{\pi}{3} h}$$

$$y^2 = 16 e^{\frac{\pi}{3} h}$$

开平方（因为 $y \ge 0$）：

$$y = f(h) = 4 e^{\frac{\pi}{6} h}$$

最后，把代表动态水深的 $h$，换回代表静态坐标轴的 $z$，就得到了这道题的最终答案：

$$y = f(z) = 4 e^{\frac{\pi}{6} z}$$

---

**复盘总结：**

这种“相关变化率”结合“变上限积分”的题目，核心心法就是：**勇敢地引入中间变量 $h(t)$ 作为积分上限，坚决不能让它和积分内部的坐标变量 $z$ 长得一样。** 只要做到这一点，用链式法则一搭桥，所有的式子立刻就顺理成章了。

## 10
![[习题与1000题-1773885349824.jpeg]]![[习题与1000题-1773885351210.jpeg]]
公式里的 $\int \varphi(x) e^x dx$ 是一个**不定积分**。但是题目给的 $\varphi(x)$ 是个抽象函数，你根本积不出来！而且后面还要证明不等式，不定积分带着个尾巴没法比大小。

**破局技巧：把“不定积分”强行写成“变上限积分”。**

在数学上，原函数 $\int f(x)dx$ 完全可以写成 $\int_0^x f(t)dt$ 的形式（这里的 $t$ 只是个占位符，叫阿猫阿狗都行，为了不和上限 $x$ 混淆）。

所以，我们把通解改写成：

$$y(x) = e^{-x} \left( \int_0^x \varphi(t) e^t dt + C \right)$$

接下来代入初始条件 $y(0) = 0$：

$$y(0) = e^0 \left( \int_0^0 \varphi(t) e^t dt + C \right)$$

因为积分上下限都是 0，所以积分项等于 0。

$0 = 1 \cdot (0 + C) \implies C = 0$

把 $C=0$ 代回去，特解就出来了：

$$y(x) = e^{-x} \int_0^x \varphi(t) e^t dt$$

你看，用公式做，结果和答案是一模一样的！


## 11


![[习题与1000题-1773886565913.jpeg]]

我们把你的思路拆成两半来看，告诉你哪里极其聪明，哪里又绝对不能这么做：

### 第一半（天才的捷径）：不换回 $x$，直接在 $t$ 世界算 $C$

**这步绝对可行，而且极其推荐！** 这叫“初始条件同步换元”，能帮你省去大量写 $\ln x$ 的麻烦。

- 题目给的初始条件是 $x = 1$ 时，$y = \frac{1}{4}$。
    
- 既然你的宇宙规则是 $x = e^t$，那么当 $x = 1$ 时，对应的 $t = \ln 1 = \mathbf{0}$。
    
- 所以，初始条件在 $t$ 世界里就变成了：**当 $t = 0$ 时，$y = \frac{1}{4}$**。
    

把 $t=0$ 代入你的通解 $y(t) = C e^{2t} - \frac{1}{2}t$：

$$y(0) = C e^0 - 0 = C$$

立刻得出 **$C = \frac{1}{4}$**。

你看，连平方和对数都不用算，直接秒出 $C$，这就是在 $t$ 域算常数的巨大优势！

现在的函数是：**$y(t) = \frac{1}{4}e^{2t} - \frac{1}{2}t$**。

---

### 第二半（致命陷阱）：直接求 $\int_0^1 y(t) dt$ 算平均值？

**这步绝对不行！** 这是考研定积分大题里失分率极高的一个错觉。

函数在区间上的“平均值”是一个严格的几何定义：**曲线下方的面积 $\div$ 底边的实际物理长度**。

$$\text{平均值} = \frac{\int_1^e y(x) dx}{e - 1}$$

如果你强行把它转到 $t$ 域，你会漏掉两个极其关键的东西：

**1. 漏了微分项（凑微分的代价）：**

定积分换元时，**$dx$ 绝对不能直接变成 $dt$**！

因为 $x = e^t$，两边求微分得到：

$$dx = e^t dt$$

如果你只积 $\int_0^1 y(t) dt$，你等于把那个缩放比例 $e^t$ 给硬生生吃掉了，面积全算错了。

**2. 漏了原始区间的长度：**

即便你把积分换到了 $t$ 域，算出来的也是“总面积”。求平均值时，除以的必须依然是**原来 $x$ 轴上的真实长度 $(e - 1)$**，而绝对不能是 $t$ 轴上的长度 $(1 - 0)$。

---

### 正确的 $t$ 域积分姿势

如果你坚持不想回到 $x$ 域，想纯在 $t$ 域把这道题刚到底，正确的列式应该是这样的：

$$\text{平均值} = \frac{1}{e - 1} \int_0^1 y(t) \cdot e^t dt$$

我们把算出来的 $y(t)$ 代进去实际算一下，看看是不是和之前的结果一样：

$$\int_0^1 \left( \frac{1}{4}e^{2t} - \frac{1}{2}t \right) e^t dt$$

$$= \int_0^1 \left( \frac{1}{4}e^{3t} - \frac{1}{2}t e^t \right) dt$$

这个积分非常好算：

- 前半部分：$\int_0^1 \frac{1}{4}e^{3t} dt = \left[ \frac{1}{12}e^{3t} \right]_0^1 = \frac{e^3 - 1}{12}$
    
- 后半部分（依然是分部积分）：$\int_0^1 \frac{1}{2}te^t dt = \frac{1}{2} \left[ te^t - e^t \right]_0^1 = \frac{1}{2} ( (e - e) - (0 - 1) ) = \frac{1}{2}$
    

相减得到总面积：$\frac{e^3 - 1}{12} - \frac{1}{2} = \frac{e^3 - 7}{12}$

最后除以原区间长度 $e-1$：

$$\text{平均值} = \frac{e^3 - 7}{12(e - 1)}$$

你看！和我们之前老老实实换回 $x$ 算出来的结果**分毫不差**！

**总结你的实战策略：**

- **定常数 $C$ 时：** 强烈建议像你第一步想的那样，在 $t$ 域直接定，既快又准。
    
- **算定积分/平均值时：** 建议还是**换回 $x$ 域再去积**。因为如果你留在 $t$ 域，你不仅要记得乘上极其容易忘的微分后缀 $e^t$，还要面对两个指数函数相乘（$e^{2t} \cdot e^t = e^{3t}$）的变形，反而增加了出错的风险。

## 计算技巧![[习题与1000题-1773889436205.jpeg]]
你想想，你要设 $y^* = (a_0x^4 + a_1x^3 + a_2x^2)e^x$。对它求一阶导，要用乘积求导法则，会搞出一大串；再求二阶导，项数直接翻倍，写出来能占半页纸，极其容易算错正负号！

这道题其实藏着一个**极其逆天的降维打击技巧**。我们绝对不用待定系数法去硬刚，而是用**“变量代换法”**（本质上就是算子法的平替，而且大题完全给分）。

只要遇到等号右边是 **多项式 $\times \ e^{\lambda x}$**，且撞车了（尤其是这种二重根撞车），直接用这个套路，三行出答案！

---

### 神仙技巧：直接令 $y = u(x)e^x$

我们不要去设什么 $a_0, a_1$，那个太笨了。

既然右边有 $e^x$，我们就顺水推舟，直接令特解为：

$$y = u \cdot e^x$$

（这里的 $u$ 是一个关于 $x$ 的未知函数，我们等会去抓它）。

**第一步：准备好导数原材料（利用乘积求导）**

- $y = u e^x$
    
- $y' = u' e^x + u e^x = (u' + u)e^x$
    
- $y'' = (u'' + u')e^x + (u' + u)e^x = (u'' + 2u' + u)e^x$
    

**第二步：代入原方程左边（见证奇迹的时刻）**

原方程左边是 $y'' - 2y' + y$。把上面三坨代进去，把 $e^x$ 提在最外面：

$$e^x \big[ (u'' + 2u' + u) - 2(u' + u) + u \big]$$

我们在中括号里合并一下同类项，你会发现：

- $u'$ 的系数：$2 - 2 = 0$
    
- $u$ 的系数：$1 - 2 + 1 = 0$
    

全部抵消了！！左边极其清爽地只剩下了：

$$u'' e^x$$

> **💡 为什么会这么巧？**
> 
> 因为原方程的特征根是 $r=1$ 的**二重根**。只要是二重根，代入 $y=ue^{\lambda x}$ 后，$u$ 和 $u'$ 的项**必定100%全部抵消**，绝对只剩下 $u''$！这是数学规律。

**第三步：接上等号右边，直接积分**

既然左边化简成了 $u'' e^x$，原方程等号右边是 $2(3x^2 - 2)e^x = (6x^2 - 4)e^x$。

连起来：

$$u'' e^x = (6x^2 - 4)e^x$$

两边同时砍掉 $e^x$：

$$u'' = 6x^2 - 4$$

这还算什么微分方程？这直接退化成了高中的**连续求两次积分**！

对 $6x^2 - 4$ 积第一次分，得到 $u'$：

$$u' = 2x^3 - 4x$$

再积第二次分，得到 $u$：

$$u = \frac{1}{2}x^4 - 2x^2$$

_(因为我们只求特解，所以不需要加常数 $C$)_。

**第四步：大功告成**

把算出来的 $u$ 放回我们一开始设的 $y = u e^x$ 里：

$$y^* = \left(\frac{1}{2}x^4 - 2x^2\right)e^x$$

如果你把它展开，就是 $x^2(\frac{1}{2}x^2 - 2)e^x$。

对比书上设的 $x^2(a_0x^2 + a_1x + a_2)e^x$。

你会发现 $a_0 = \frac{1}{2}, a_1 = 0, a_2 = -2$。跟答案一模一样！


![[习题与1000题-1773889854146.jpeg]]
对于带有 $\sin$ 或 $\cos$ 的非齐次项，如果你老老实实地设 $y^* = A\sin x + B\cos x$，然后求一阶导、求二阶导，再代入原方程去解那个包含 $A$ 和 $B$ 的二元一次方程组……说实话，不仅累，而且极其容易在正负号上翻车。

面对三角函数，数学界也有两个**“降维打击”**的神仙级技巧。一个是利用我们在前几节打下的基础（复指数法），另一个就是传说中的终极外挂（微分算子法）。

我们直接拿图片里这道原题 **$y'' + 4y' + 5y = 8\cos x$** 来演示，让你感受一下什么叫“丝滑出答案”。

---

### 屠龙技一：复指数法（给三角函数穿上 $e$ 的马甲）

你之前已经完美掌握了应对 $e^{\lambda x}$ 的方法。那我们为什么不把三角函数变成 $e$ 呢？

根据欧拉公式：$e^{ix} = \cos x + i\sin x$。

所以，$8\cos x$ 其实就是 **$8e^{ix}$ 的实部**！

**第一步：狸猫换太子**

我们不去解原来的方程，我们去解一个带有虚数 $i$ 的新方程：

$$y'' + 4y' + 5y = 8e^{ix}$$

这里的 $\lambda = i$。因为特征根是 $-2 \pm i$，所以 $\lambda = i$ **没有撞车**！

**第二步：用 $e$ 的套路直接秒**

既然没撞车，直接设特解为 $y^* = C e^{ix}$。

代入方程（指数函数求导就是把系数拿下来）：

$$C(i)^2 e^{ix} + 4C(i)e^{ix} + 5C e^{ix} = 8e^{ix}$$

把 $e^{ix}$ 砍掉，把 $i^2 = -1$ 代入：

$$C(-1 + 4i + 5) = 8 \implies C(4 + 4i) = 8$$

$$C = \frac{8}{4 + 4i} = \frac{2}{1 + i}$$

分子分母同乘 $(1 - i)$ 实现分母实数化：

$$C = \frac{2(1 - i)}{(1+i)(1-i)} = \frac{2(1 - i)}{2} = 1 - i$$

**第三步：现出原形**

我们解出来的复数特解是：

$$y^* = (1 - i)e^{ix} = (1 - i)(\cos x + i\sin x)$$

把它展开：

$$= (\cos x + \sin x) + i(\sin x - \cos x)$$

因为原题的 $8\cos x$ 是实部，所以我们**只取实部**：

$$y^* = \cos x + \sin x$$

一行方程组都没解，直接出答案！
