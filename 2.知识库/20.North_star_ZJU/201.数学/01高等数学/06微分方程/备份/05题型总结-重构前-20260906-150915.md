### 03 880 题 1｜一阶齐次方程：指数解的“不为零”陷阱

> 来源：[[03 880]]

![[_attachments/image/880-1779327921837.jpeg]]

这道题出得非常经典，你对选项 B 的直觉很准确！你觉得 $P(x)$ 的条件像“废话”，这是很多同学做微分方程理论题时的共同感受。但实际上，**这道题的题眼（或者说唯一的“陷阱”）恰恰就藏在 $P(x)$ 的条件里。**

这道题核心考查的知识点是：**一阶齐次线性微分方程的解的结构，以及指数函数的绝对不为零的性质。**

我们先来把这个方程“扒光”，看看它的解到底长什么样。

对于一阶齐次线性方程 $y' + P(x)y = 0$，它的**通解公式**是固定的：

$$y = C e^{-\int P(x) dx}$$

（其中 $C$ 是任意常数）

既然题目说 $y_1(x)$ 和 $y_2(x)$ 是两个**不同**的特解，那它们一定可以写成：

- $y_1(x) = C_1 e^{-\int P(x) dx}$
    
- $y_2(x) = C_2 e^{-\int P(x) dx}$
    
    因为是“不同”的特解，所以 $C_1 \neq C_2$。
    

现在我们带着这个“透视镜”，来看看 $P(x)$ 的条件到底是干什么用的，以及各个选项。

#### $P(x)$ 的条件有什么用？

1. **“$P(x)$ 在 $(-\infty, +\infty)$ 内连续”：**
    
    - **作用：保命。** 只有 $P(x)$ 连续，它才可以积分（$\int P(x) dx$ 存在），方程在整个实数轴上才有意义，保证了解的存在性和唯一性。这是数学严谨性的要求。
        
2. **“$P(x)$ 不恒为 0”：**
    
    - **作用：绝杀。** 这就是专门为了判断 **选项 A** 准备的。如果 $P(x) \equiv 0$，那么原方程就变成了 $y' = 0$，解就是 $y = C$（常数）。题目特意强调它不全为 0，就是告诉你：**这个方程的解，大概率不是常数，而是带有指数的变量函数。**
        

#### 逐个击破选项

我们令两解之差为 $\Delta y(x) = y_1(x) - y_2(x)$，代入刚才的公式：

$$\Delta y(x) = (C_1 - C_2) e^{-\int P(x) dx}$$

令 $K = C_1 - C_2$。因为两特解不同，所以 **$K \neq 0$**。

所以，$\Delta y(x) = K e^{-\int P(x) dx}$。

- **B 选项：$C[y_1(x) - y_2(x)]$ 是通解 （正确）**
    
    这是你已经知道的。把 $\Delta y$ 乘上任意常数 $C$，得到 $C \cdot K e^{-\int P(x) dx}$。因为 $C \cdot K$ 本质上还是一个“任意常数”，所以它完美地覆盖了通解的公式形式。
    
- **C 选项：$y_1(x) - y_2(x)$ 在任一点不为 0 （正确）**
    
    我们看 $\Delta y(x) = K e^{-\int P(x) dx}$。
    
    这里用到了微积分里极其重要的一个常识：**指数函数 $e^{\text{任何东西}}$ 永远大于 0，绝对不可能等于 0。**
    
    前面又已知 $K \neq 0$，所以这两者相乘，在任何一个 $x$ 点都不可能为 0。
    
- **D 选项：$\frac{y_2 (x)}{y_1 (x)} \equiv \text{常数}$  （正确）**
    
    直接相除：
    
    $$\frac{y_2(x)}{y_1(x)} = \frac{C_2 e^{-\int P(x) dx}}{C_1 e^{-\int P(x) dx}} = \frac{C_2}{C_1}$$
    
    $C_2$ 和 $C_1$ 都是具体的常数，所以结果当然是一个常数。（这其实说明一阶齐次方程的所有非零解都是**线性相关**的）。
    
- **A 选项：$y_1(x) - y_2(x) = \text{常数}$ （错误 —— 也就是本题的正确答案）**
    
    我们看 $\Delta y(x) = K e^{-\int P(x) dx}$。
    
    这个式子什么时候才能是一个常数？只有当指数部分 $-\int P(x) dx = \text{常数}$ 时才成立。
    
    而 $-\int P(x) dx = \text{常数}$，对其求导，意味着 **$P(x)$ 必须等于 0**。
    
    但题目**明确规定了“$P(x)$ 不恒为 0”**！所以 $e^{-\int P(x) dx}$ 必然是一个随 $x$ 变化的函数，绝不可能是一个常数。
    
题目问的是“错误的是”，所以选 **A**。这道题本质上就是在考你知不知道一阶齐次的解全都长着一副“常数乘以指数函数”的面孔。

### 03 880 题 2｜漏解：分离变量时别把零解关在门外

> 来源：[[03 880]]

![[_attachments/image/880-1779331461825.jpeg]]**![[_attachments/image/880-1779331463472.jpeg]]

这个“漏解”问题可以说是微分方程分离变量法里最经典的“暗礁”，无数人在考场上在这里翻过船。

“漏解”的本质，其实就是数学里最基础、最不容违背的一条铁律：**除数不能为 0**。

我们来一步步拆解，看看这个解是怎么走丢的，以及以后怎么把它抓回来。

#### 1. 解是怎么“漏”掉的？（案发现场回放）

你看解析里的这一步：

从 $x \cdot \frac{du}{dx} = \tan u$

变成了 $\cot u du = \frac{dx}{x}$ （也就是 $\frac{1}{\tan u} du = \frac{1}{x} dx$）

这一步，你是怎么把 $\tan u$ 弄到左边分母上去的？是**等式两边同时除以 $\tan u$**。

既然你做了“除法”，你就必须默默地承担一个数学前提：**假设 $\tan u \neq 0$**。

换句话说，从这一步开始，你后续算出来的所有结果，都是在“$\tan u$ 不等于 0”这个平行宇宙里发生的。

**但现实是，$\tan u$ 是可以等于 0 的！**

如果 $\tan u = 0$，那么 $u = 0$（也就是 $y = 0$）。

我们把 $y = 0$ 代回最原始的方程 $y' = \frac{y}{x} + \tan\frac{y}{x}$：

- 左边：$y' = 0$
    
- 右边：$\frac{0}{x} + \tan(0) = 0 + 0 = 0$
    
    左边等于右边，完美成立！这说明 $y=0$ 本来就是原方程的一个合法解。
    

就因为你在分离变量时，粗暴地除了一个 $\tan u$，导致 $y=0$ 这个合法解被当成“除以 0 的非法情况”给一脚踢开了。这就是所谓的“漏解”。

#### 2. 答案是怎么把它“救”回来的？（常数 $C$ 的魔术）

在那个“$\tan u \neq 0$”的平行宇宙里，你千辛万苦积分积出了一个结果：

$\sin u = \pm e^{C_1} \cdot x$

为了书写方便，我们令 $C = \pm e^{C_1}$，得到 $\sin u = Cx$。

**注意此时 $C$ 的身份：** 因为 $e$ 的任何次幂都不可能等于 $0$，所以此时的 $C$ 必须满足 **$C \neq 0$**。

这个时候，猛然想起我们之前还弄丢了一个 $y = 0$（即 $u = 0$）的解。

我们试着把这个走丢的解 $u = 0$ 代入到我们刚算出来的公式 $\sin u = Cx$ 里看看：

$\sin(0) = Cx \implies 0 = Cx \implies C = 0$

奇迹发生了！我们发现，**如果允许常数 $C = 0$，那么 $\sin u = Cx$ 这个公式，就能完美地把刚才漏掉的 $y=0$ 给包含进去！**

所以，答案的最后一步，就是把 $C \neq 0$ 这个限制条件给抹掉，宣告：“上面常数也可以为零，则原方程的通解为 $\sin\frac{y}{x} = Cx \ (C\text{为任意常数})$”。

这不仅是形式上的统一，更是把漏掉的解合法地收编了。

#### 3. 以后怎么注意它？（防漏解 2 步法）

在做分离变量的题目时，想要不漏解，以后每次做除法时，在心里走一遍这个“安检流程”：

- **第一步：揪出嫌疑人。**
    
    当你写下 $\frac{dy}{g(y)} = f(x)dx$ 这一步时，立刻看一眼分母 $g(y)$。令 **$g(y) = 0$**，解出来的 $y = a, y = b \dots$ 就是可能被你漏掉的“嫌疑解”。（在本题中，就是令 $\tan u = 0$，得到 $u=0$）。
    
- **第二步：核对保护伞。**
    
    继续往下算你的积分，得出含有常数 $C$ 的通解公式。然后把刚才的“嫌疑解”代入这个公式，看看能不能求出一个具体的 $C$ 值（通常是 $C=0$）。
    
    - **如果能求出 $C$**：说明这个漏解可以通过给 $C$ 取特定值被公式“吸收”。你只需要像答案那样，写一句“当 $C=0$ 时也成立，故 $C$ 为任意常数”即可。
        
    - **如果求不出 $C$（产生矛盾）**：说明这个解极其倔强，无法被你的通解公式吸收。这时候，你必须在答案最后单独把它写出来，叫做“奇解”（通解公式无法覆盖的解）。
        

总结一下，漏解并不可怕，它只是在提醒你：**不要盲目地除以一个含有未知数的式子，除之前，先问问它如果是 0 会发生什么。**

### 03 880 题 3｜反向齐次方程：全是 x/y 就换未知函数

> 来源：[[03 880]]

![[_attachments/image/880-1779376791834.jpeg]]
#### 第一层考点：“反向”齐次微分方程（最稳妥的常规路线）

**识别特征：** 你看方程里到处都是 $\frac{x}{y}$。

平时我们做的齐次方程，特征是 $\frac{y}{x}$，然后我们令 $u = \frac{y}{x}$。但这里反过来了！

**破解方法：角色互换。**

既然全是 $\frac{x}{y}$，那我们就把 $y$ 当作自变量，把 $x$ 当作未知函数。

令 $u = \frac{x}{y}$，即 $x = uy$。

两边对 $y$ 求导（或者取微分）：$dx = u dy + y du$。

我们把 $x = uy$ 和 $dx$ 全都代入原方程：

$$(1 + e^u)(u dy + y du) + e^u(1 - u)dy = 0$$

展开并把含有 $dy$ 和 $du$ 的项分别合并：

$$u(1 + e^u)dy + y(1 + e^u)du + e^u dy - u e^u dy = 0$$

$$(u + u e^u + e^u - u e^u)dy + y(1 + e^u)du = 0$$

$$(u + e^u)dy + y(1 + e^u)du = 0$$

接下来就是大家最喜爱的**分离变量**环节：

$$\frac{1 + e^u}{u + e^u} du = -\frac{1}{y} dy$$

两边同时积分。这里又藏了一个很美的考点：**分子刚好是分母的导数**！$(u + e^u)' = 1 + e^u$。

所以左边积分直接出对数：

$$\ln|u + e^u| = -\ln|y| + C_1$$

（题目已知 $y>0$，所以可以去掉绝对值）

$$\ln(u + e^u) + \ln y = C_1$$

$$\ln(y(u + e^u)) = C_1$$

去掉对数符号，令 $C = e^{C_1}$：

$$y(u + e^u) = C$$

最后，把 $u = \frac{x}{y}$ 换回来：

$$y\left(\frac{x}{y} + e^{\frac{x}{y}}\right) = C$$

$$x + ye^{\frac{x}{y}} = C$$

这就是通解。思路非常连贯，只要认出 $\frac{x}{y}$ 并且敢于把 $x$ 和 $y$ 互换，后面全是水到渠成。

#### 第二层考点：凑微分法（“魔法”秒杀路线）

如果你对微积分的“盘感”极好，这道题完全可以在 **3 行之内**秒杀。这也是出题人暗戳戳想考你的高级技巧。

我们把原方程直接强行展开，不去管什么 $\frac{x}{y}$，就硬拆：

$$dx + e^{\frac{x}{y}}dx + e^{\frac{x}{y}}dy - \frac{x}{y}e^{\frac{x}{y}}dy = 0$$

你看后面这一长串 $e^{\frac{x}{y}}dx + e^{\frac{x}{y}}dy - \frac{x}{y}e^{\frac{x}{y}}dy$，是不是感觉像某个东西求导展开后的残骸？

我们试着用乘积法则去逆推。它里面有 $e^{\frac{x}{y}}$，又有 $dx$ 和 $dy$，我们试着对 $ye^{\frac{x}{y}}$ 求一下全微分：

$$d(ye^{\frac{x}{y}}) = e^{\frac{x}{y}}dy + y \cdot d(e^{\frac{x}{y}})$$

$$= e^{\frac{x}{y}}dy + y \cdot e^{\frac{x}{y}} \cdot d(\frac{x}{y})$$

$$= e^{\frac{x}{y}}dy + y \cdot e^{\frac{x}{y}} \cdot \left(\frac{y dx - x dy}{y^2}\right)$$

$$= e^{\frac{x}{y}}dy + e^{\frac{x}{y}}dx - \frac{x}{y}e^{\frac{x}{y}}dy$$

**奇迹出现了！** 这刚好和我们展开后的后三项**一模一样**！

所以，原方程展开后，可以直接写成：

$$dx + d(ye^{\frac{x}{y}}) = 0$$

也就是：

$$d(x + ye^{\frac{x}{y}}) = 0$$

两边一积分，直接出答案：

$$x + ye^{\frac{x}{y}} = C$$

#### 总结

- **看到 $\frac{y}{x}$：** 齐次方程，令 $y = ux$。
    
- **看到 $\frac{x}{y}$：** “反向”齐次方程，令 $x = uy$。
    
- **看到式子虽然乱，但指数/分式极其对称：** 试着拆开，看能不能用 $d(xy), d(\frac{x}{y}), d(e^{xy})$ 这类全微分公式强行凑出来。凑出来了就是秒杀

### 02 习题 6｜缺 y 的二阶方程：令 p=y′ 降阶，或伪装成欧拉方程

> 来源：[[02习题与1000题]]

![[习题与1000题-1773803405309.jpeg]]
#### 第一步：降阶与分离变量

题目：$xy'' + 3y' = 0$

因为方程里缺了 $y$，所以我们果断使用你说的换元法：

令 $y' = p$，那么 $y'' = \frac{dp}{dx}$。

代入原方程，就从二阶降到了一阶：

$$x\frac{dp}{dx} + 3p = 0$$

把 $p$ 和 $x$ 各回各家（分离变量）：

$$x\frac{dp}{dx} = -3p$$

$$\frac{dp}{p} = -\frac{3}{x}dx$$

---

#### 第二步：第一次积分与常数的“华丽变身”

等号两边同时积分：

$$\int \frac{1}{p} dp = \int -\frac{3}{x} dx$$

积分出来以后，**常数第一次登场**：

$$\ln|p| = -3\ln|x| + C$$

> **💡 核心知识点：对数常数的“凑脸熟”技巧**
> 
> 到了这一步，左边是 $\ln$，右边也有 $\ln$。如果你把常数写成孤零零的 $C$，下一步解 $p$ 的时候就会变成 $p = e^{-3\ln|x| + C}$，特别难看。
> 
> **怎么办？** 因为 $C$ 是可以在 $(-\infty, +\infty)$ 随便取的任意常数，那我们完全可以把它写成 $\ln|C_1|$ 的形式（因为 $\ln$ 的值域也是实数集）。
> 
> 这样写纯粹是为了等会儿能利用对数的加法公式合并！

我们把 $C$ 换成 $\ln|C_1|$，并利用对数法则（$-3$ 放进指数里）：

$$\ln|p| = \ln|x^{-3}| + \ln|C_1|$$

$$\ln|p| = \ln|C_1 x^{-3}|$$

现在两边都有 $\ln|\dots|$，直接脱掉对数符号：

$$p = \pm C_1 x^{-3}$$

> **💡 核心知识点：正负号的“黑洞吸收”**
> 
> 这里的 $\pm C_1$ 看着很烦。但你想，$C_1$ 本来就是个任意正常数，前面加个 $\pm$，它就变成了一个**可以为正、可以为负的全新任意常数**。
> 
> 为了书写干净，数学家们会毫不留情地把 $\pm$ 号直接“吸收”进常数里，重新命名为一个新的常数。为了省字母，通常还是写成 $C_1$（此时的 $C_1$ 包含了正负）。

所以，化简后我们得到了极其干净的 $p$：

$$p = C_1 x^{-3}$$

---

#### 第三步：第二次积分与常数的再次合并

别忘了，我们的 $p$ 其实是 $y'$：

$$\frac{dy}{dx} = C_1 x^{-3}$$

为了求 $y$，我们把 $dx$ 乘过去，进行**第二次积分**：

$$dy = C_1 x^{-3} dx$$

$$y = \int C_1 x^{-3} dx$$

根据幂函数的积分公式 $\int x^n dx = \frac{x^{n+1}}{n+1}$：

$$y = C_1 \left( \frac{x^{-2}}{-2} \right) + C_2$$

此时，**第二次积分产生了第二个常数 $C_2$**。

> **💡 核心知识点：系数的“黑洞吸收”**
> 
> 我们来看这一坨：$C_1 \cdot \frac{1}{-2}$。
> 
> 刚才说了，常数是个无底洞。一个任意常数 $C_1$ 乘以一个具体的数字 $-\frac{1}{2}$，结果依然是一个任意常数！
> 
> 所以，我们再次发动“黑洞吸收”大法，令新的 $C_1^* = -\frac{1}{2} C_1$。
> 
> 在最终写答案时，为了美观，我们连星号都不写，直接用一个干净的 $C_1$ 来代表这一整坨。

于是，式子变成了最终的完美形态：

$$y = C_1 x^{-2} + C_2$$

或者写成分数形式：

$$y = \frac{C_1}{x^2} + C_2$$

#### 多解法：欧拉
#### 第一步：给它穿上“欧拉”的马甲（配凑次幂）

你可能会纳闷，欧拉方程的标准脸不是 $x^2y'' + pxy' + qy = 0$ 吗？这道题怎么少了一个 $x$？

没关系，既然它等号右边是 0，我们直接**等式两边同乘一个 $x$**，强行给它凑出完美的“等维匹配”：

$$x^2y'' + 3xy' = 0$$

看！现在它完全符合欧拉方程的特征了：二阶导配 $x^2$，一阶导配 $x^1$。这里的常数 $p=3, q=0$。

#### 第二步：祭出换元法“秒杀公式”

按照我们上一节总结的欧拉方程套路，直接令 **$x = e^t$**（即 $t = \ln x$）。

不需要再苦哈哈地推导一遍链式法则了，直接默写那两个替换公式：

- $xy' \implies \frac{dy}{dt}$
    
- $x^2y'' \implies \frac{d^2y}{dt^2} - \frac{dy}{dt}$
    

把它们代入到我们刚才凑好的 $x^2y'' + 3xy' = 0$ 中：

$$(\frac{d^2y}{dt^2} - \frac{dy}{dt}) + 3(\frac{dy}{dt}) = 0$$

合并同类项，见证奇迹的时刻：

$$\frac{d^2y}{dt^2} + 2\frac{dy}{dt} = 0$$

或者写成我们更习惯的形式：**$y''(t) + 2y'(t) = 0$**。

你看！烦人的变系数 $x$ 瞬间灰飞烟灭，它变成了一个极其温顺的**常系数线性齐次微分方程**！

#### 第三步：常规操作，解常系数方程

这下就是闭着眼睛都能解的送分题了。

写出特征方程：

$$r^2 + 2r = 0$$

提取公因式：

$$r(r + 2) = 0$$

解得两个不相等的实数特征根：**$r_1 = 0, r_2 = -2$**。

既然有两个不同的实根，按照公式，它的通解（注意此时自变量是 $t$）就是：

$$y = C_1 e^{0 \cdot t} + C_2 e^{-2t}$$

因为 $e^0 = 1$，所以化简为：

$$y = C_1 + C_2 e^{-2t}$$

#### 第四步：脱下马甲，变回 $x$

最后一步，千万别忘了我们的自变量本来是 $x$。

因为我们一开始令了 $x = e^t$，所以 $e^{-2t}$ 可以写成 $(e^t)^{-2}$，也就是 **$x^{-2}$**。

把它代回去：

$$y = C_1 + C_2 x^{-2}$$

稍微整理一下排版：

$$y = C_1 + \frac{C_2}{x^2}$$

### 02 1000 题 8｜相关变化率：把几何关系翻译成微分方程

> 来源：[[02习题与1000题]]

速率，是 xx 对时间的导。这里是体积！
![[习题与1000题-1773883619268.jpeg]]### 第一步：把静态几何变成动态函数（区分 $z$ 和 $h$）

1. **水面的动态半径：** 当水面上升到高度 $h$ 时，水面边缘正好卡在曲线上，所以此时的半径 $y = f(h)$。
    
2. **水面的动态面积：** 你说的完全对，就是圆面积。
    
    $$S = \pi [f(h)]^2$$
    
    _(注意，这里的 $S$ 是会随着水面高度 $h$ 变化的，即 $S(h)$。)_
    
3. **水的动态体积：** 积分的上限不再是泛泛的 $z$，而是实实在在的水面高度 $h$。为了不和积分变量撞车，我们把积分里的变量叫作 $z$。
    
    $$V = \int_0^h \pi [f(z)]^2 dz$$
    

#### 第二步：利用“链式法则”翻译题目条件（消灭时间 $t$）

题目给的是关于时间 $t$ 的变化率：

- 注水速率：$\frac{dV}{dt} = 3$
    
- 面积增大速率：$\frac{dS}{dt} = \pi$
    

但在我们的几何公式里，只有体积 $V$、面积 $S$ 和水深 $h$。怎么把 $t$ 联系起来呢？**用链式法则！**

**1. 翻译体积变化率（核心神操作！）：**

根据变上限积分求导定理，对刚才的体积公式 $V = \int_0^h \pi [f(z)]^2 dz$ 求导：

$$\frac{dV}{dt} = \frac{dV}{dh} \cdot \frac{dh}{dt}$$

因为 $\frac{dV}{dh}$ 就是积分上限求导，直接把 $h$ 塞进去，得到 $\pi [f(h)]^2$。而这正好就是水面面积 $S$！

所以：

$$\frac{dV}{dt} = S \cdot \frac{dh}{dt} = 3$$

这就推导出了一个极其关键的中间结论：**$\frac{dh}{dt} = \frac{3}{S}$** （水面上升的速度，等于注水速度除以水面面积）。

**2. 翻译面积变化率：**

同样用链式法则展开面积的变化率：

$$\frac{dS}{dt} = \frac{dS}{dh} \cdot \frac{dh}{dt} = \pi$$

现在，把上面算出来的 $\frac{dh}{dt} = \frac{3}{S}$ 代入进来：

$$\frac{dS}{dh} \cdot \frac{3}{S} = \pi$$

整理一下，我们得到了一个完全没有时间 $t$，只有面积 $S$ 和水深 $h$ 的**微分方程**：

$$\frac{dS}{dh} = \frac{\pi}{3} S$$

#### 第三步：解微分方程，打通最后一公里

这就是一个最简单的一阶可分离变量微分方程：

$$\frac{dS}{S} = \frac{\pi}{3} dh$$

两边积分：

$$\ln S = \frac{\pi}{3} h + C_1$$

$$S = C e^{\frac{\pi}{3} h}$$

**找初始条件定常数：**

题目说“容器底面积为 16$\pi$”。底面积在哪？在 $z=0$（即水深 $h=0$）的地方！

所以当 $h=0$ 时，$S = 16\pi$。代入进去：

$$16\pi = C e^0 \implies C = 16\pi$$

于是我们得到了面积 $S$ 随水深 $h$ 变化的精确公式：

$$S = 16\pi e^{\frac{\pi}{3} h}$$

**原路返回，求目标曲线 $y=f(z)$：**

回到我们在第一步写的：面积 $S = \pi y^2$。

所以：

$$\pi y^2 = 16\pi e^{\frac{\pi}{3} h}$$

$$y^2 = 16 e^{\frac{\pi}{3} h}$$

开平方（因为 $y \ge 0$）：

$$y = f(h) = 4 e^{\frac{\pi}{6} h}$$

最后，把代表动态水深的 $h$，换回代表静态坐标轴的 $z$，就得到了这道题的最终答案：

$$y = f(z) = 4 e^{\frac{\pi}{6} z}$$

---

**复盘总结：**

这种“相关变化率”结合“变上限积分”的题目，核心心法就是：**勇敢地引入中间变量 $h(t)$ 作为积分上限，坚决不能让它和积分内部的坐标变量 $z$ 长得一样。** 只要做到这一点，用链式法则一搭桥，所有的式子立刻就顺理成章了。

**为什么书上要分 $x>0$ 和 $x<0$ 写那么一大坨？**

这是教科书必须保持的“严谨求生欲”。

因为第一步换元时 $t = \ln x$，对数函数里的 $x$ 必须大于 0！那万一题目里的 $x$ 是负数怎么办呢？

数学家就打了个补丁：如果 $x<0$，我们就令 $x = -e^t$，这样就能保证里面是正数。经过同样一套流程算下来，最后把两个结果合并时，为了兼容正负号，就在对数里面加上了绝对值，变成 **$\ln|x|$**，并且把常数项统一写成带绝对值的形式。

**考场实战建议：**

### 04 大观 3｜不是常规指数：缺项直接捁出 y=1 这个齐次解

> 来源：[[04大观习题]]

![[_attachments/image/04大观习题-1782220419707.jpeg]]
想考啥呢？

#### 第一步：发现“秘密武器”——观察缺项

齐次方程的形式是：
$$y'' + p(x)y' = 0$$

仔细观察这个方程，你会发现：**它里面没有 $y$ 这一项（只有二阶导 $y''$ 和一阶导 $y'$）**。

#### 第二步：顺藤摸瓜，“捡”出一个齐次特解

因为方程不含 $y$ 项，我们可以大胆地代入最简单的常数：**$y = 1$** 试试：
* 求导：$y' = 0$
* 再求导：$y'' = 0$

代入齐次方程左边：
$$y'' + p(x)y' = 0 + p(x) \cdot 0 = 0$$

等式完美成立！
这说明：不管 $p(x)$ 是什么复杂的函数，**常数 $y = 1$ 必定是该齐次方程的一个特解**。

---

#### 第三步：两秒钟拼装通解

我们知道，二阶非齐次方程的通解结构为：
$$y = C_1 \cdot \text{【齐次特解1】} + C_2 \cdot \text{【齐次特解2】} + \text{【非齐次特解】}$$

现在，我们的拼图全部齐了：
* **齐次特解 1**：题目直接告诉了是 $x^{-3}$；
* **齐次特解 2**：我们刚才顺手“捡”到的 $1$；（由于 $\frac{x^{-3}}{1} \neq \text{常数}$，它们显然线性无关，可以作为基底）
* **非齐次特解**：题目直接给出了 $x^3$。

把它们代入通解公式，直接拼装：
$$y = C_1 x^{-3} + C_2 \cdot 1 + x^3$$

也就是：
$$y = C_1 x^{-3} + C_2 + x^3$$

### 03 880 题 4｜指数特解与“神仙技巧”：撞根时要改设

> 来源：[[03 880]]

![[_attachments/image/880-1779415151800.jpeg]]
你的直觉和观察力非常敏锐！你发现了一个极其关键的点：**你笔记里的那个“神仙技巧”确实不能直接照搬到这道题上！** 你觉得没看懂原理、且觉得本题不能使用，这完全是正确的。因为你笔记里的那道题和现在这道题，在“特征根”上有着本质的区别。

我们来一步步拆解，先揭秘那个“神仙技巧”的底层原理，然后再用**两种方法**（常规法和改进版的降维打击法）把当前这道题秒杀。

#### 一、揭秘笔记里的“神仙技巧”原理（为什么会全部抵消？）

在你之前的笔记里，原方程是 $y'' - 2y' + y = f(x)$。

它的特征方程是 $r^2 - 2r + 1 = 0$，解得**二重根 $r = 1$**。

在微积分里，微分算子有一个非常优美的性质（也叫**指数移位法则**）。当方程左边对应的是 $(r - \lambda)^2$ 形式，如果你刚好代入 $y = u \cdot e^{\lambda x}$，那么算子对 $e^{\lambda x}$ 求导的那些繁琐项，会和原方程的系数**完美中和**，最后绝对只剩下 $u'' e^{\lambda x}$。

因为你笔记里的特征根是 $r=1$，所以当你代入 $y = u \cdot e^{1 \cdot x}$ 时，$u'$ 和 $u$ 必定全部死光。这是数学结构决定的必然结果，不是巧合！这个技巧的核心就是：**利用方程自身的特征根，去吞噬掉低阶导数项。**

#### 二、为什么当前的题不能用 $y = ue^x$？

我们来看看图片里的这道题：

方程左边：$y'' + 2y' + y$

特征方程：$r^2 + 2r + 1 = 0 \implies (r+1)^2 = 0$

解得**二重根 $r = -1$**。

而方程右边的非齐次项是：$xe^x$，它的指数是 $\lambda = 1$。

- **特征根 $r = -1$**
    
- **右边指数 $\lambda = 1$**
    

它们**没有撞车！** $(-1 \neq 1)$。

如果你在这道题里强行令 $y = ue^x$，代入左边后会变成 $e^x(u'' + 4u' + 4u)$。因为指数不匹配，它不仅没有抵消，反而变得更复杂了。这就是你觉得这道题不能用的原因。

既然没有撞车，这道题我们该怎么做？这里给你展示两条路：

#### 三、解法一：常规的“待定系数法”（这题其实不难算）

因为没有撞车，我们猜特解的形式非常简单，不需要乘什么 $x^2$。

非齐次项是一次多项式 $\times \ e^x$，所以我们直接猜：

$$y_p = (ax + b)e^x$$

求导准备：

- $y_p' = ae^x + (ax+b)e^x = (ax + a + b)e^x$
    
- $y_p'' = ae^x + (ax+a+b)e^x = (ax + 2a + b)e^x$
    

代入原方程 $y'' + 2y' + y = xe^x$：

$$e^x \big[ (ax + 2a + b) + 2(ax + a + b) + (ax + b) \big] = xe^x$$

把中括号里同类项合并：

$$4ax + (4a + 4b) = x$$

对比左右两边系数：

- $x$ 的系数：$4a = 1 \implies a = \frac{1}{4}$
    
- 常数项：$4a + 4b = 0 \implies b = -\frac{1}{4}$
    

所以，特解就是 $y_p = \frac{1}{4}(x - 1)e^x$。你看，没有撞车的时候，待定系数法其实也只有三行！

#### 四、解法二：为你独家定制的“改进版神仙技巧”（强行降维打击）

如果你就是不想猜特解，就想用你笔记里的“神仙代换”爽一把，能不能行？

**绝对可以！但你用错替身了。**

要产生“全部抵消只剩二阶导”的奇迹，**代换的指数必须是方程左边的特征根！**

本题特征根是 $r = -1$，所以我们要令：

$$y = v \cdot e^{-x}$$

**见证奇迹的时刻：**

把它代入左边 $y'' + 2y' + y$，根据我们刚才讲的原理，它绝对会清爽地全部抵消，只剩下：

$$v'' e^{-x}$$

这时候，我们让它等于等式右边：

$$v'' e^{-x} = xe^x$$

把 $e^{-x}$ 移过去：

$$v'' = xe^{2x}$$

看到了吗？微分方程直接被降维成了**纯积分问题**！我们只需要对 $xe^{2x}$ 连续积分两次就能求出 $v$。

1. **第一次积分（分部积分法）：**
    
    $v' = \int xe^{2x} dx = \frac{1}{2}xe^{2x} - \int \frac{1}{2}e^{2x} dx = \frac{1}{2}xe^{2x} - \frac{1}{4}e^{2x}$
    
2. **第二次积分：**
    
    $v = \int (\frac{1}{2}xe^{2x} - \frac{1}{4}e^{2x}) dx$
    
    $= \frac{1}{2} (\frac{1}{2}xe^{2x} - \frac{1}{4}e^{2x}) - \frac{1}{8}e^{2x}$
    
    $= \frac{1}{4}xe^{2x} - \frac{1}{4}e^{2x} = \frac{1}{4}(x-1)e^{2x}$
    

算出了 $v$，代回我们设的公式 $y_p = v e^{-x}$：

$$y_p = \big[ \frac{1}{4}(x-1)e^{2x} \big] \cdot e^{-x} = \frac{1}{4}(x-1)e^x$$

和待定系数法算出来的**完全一模一样**！这就是数学的殊途同归。

#### 五、终结本题：代入初值，算出通解

无论是哪种方法，我们现在有了齐次通解和特解：

1. **齐次解（特征根 $r=-1$ 二重）：** $y_c = (C_1 + C_2 x)e^{-x}$
    
2. **特解：** $y_p = \frac{1}{4}(x - 1)e^x$
    

**方程总通解为：**

$$y = (C_1 + C_2 x)e^{-x} + \frac{1}{4}(x - 1)e^x$$

**代入初始条件求常数：**

1. 由 $y(0) = 0$：
    
    $C_1 + \frac{1}{4}(-1) = 0 \implies C_1 = \frac{1}{4}$
    
2. 先求导，准备代入第二个条件：
    
    $y' = C_2 e^{-x} - (C_1 + C_2 x)e^{-x} + \frac{1}{4}e^x + \frac{1}{4}(x - 1)e^x$
    
    代入 $y'(0) = 0$：
    
    $C_2 - C_1 + \frac{1}{4} - \frac{1}{4} = 0 \implies C_2 - \frac{1}{4} = 0 \implies C_2 = \frac{1}{4}$
    

最终结果，填在横线上的答案就是：

$$y = \frac{1}{4}(x+1)e^{-x} + \frac{1}{4}(x-1)e^x$$

总结一下：你笔记里的“神仙技巧”本质上是基于特征根的换元积分法，它是对付“撞车”题目的终极武器；而面对这道“没撞车”的题目，直接待定系数反而更省事。但如果你掌握了原理，任何题目其实都在你的掌控之中！

### 03 880 题 5｜从特解反读特征根：拆开 e 的组合再判断撞车

> 来源：[[03 880]]

![[_attachments/image/880-1779418466245.jpeg]] 如果按照常规思路，把 $y^*$ 求一阶导、二阶导硬代入原方程去解 $a, b, c$，不仅计算量大到让人怀疑人生，而且极容易算错。

其实，出题人就是想考你对上一回我们讲的“特解设置规则（特别是撞车规则）”的逆向理解。只要你看透了它的本质，这道题不需要任何复杂的求导，几句话就能直接“读”出答案。

我们来玩一把剥丝抽茧的游戏：

#### 第一步：拆解特解（分离嫌疑人）

题目给的特解是：$y^* = e^{-x}(1 + xe^{2x})$。

我们把它拆开，得到两项：

$$y^* = e^{-x} + xe^x$$

#### 第二步：利用“基因隔离”寻找齐次解

原方程是 $y'' + ay' + by = ce^x$，等号右边**只有 $e^x$ 这一种基因**。

我们把特解 $y^*$ 扔进等式左边的微分算子（粉碎机）里。因为导数是线性的，所以：

左边 = 对 $(e^{-x})$ 的一通求导操作 + 对 $(xe^x)$ 的一通求导操作。

- 思考一下：对 $e^{-x}$ 求导再怎么加加减减，永远只会产生 $e^{-x}$ 的倍数，**绝不可能**变异出 $e^x$。
    
- 但等式右边极其干净，**只有 $c e^x$，没有 $e^{-x}$！**
    

这意味着什么？这就意味着 $e^{-x}$ 被扔进左边的算子后，结果**必须等于 0**（悄无声息地消失了）！

既然代入左边等于 0，这说明 **$e^{-x}$ 根本不是什么特解，它是原方程的一个“齐次解”！**

也就是说，**特征方程有一个根 $r_1 = -1$。**

#### 第三步：利用“撞车规则”逆推第二个根

现在我们来看剩下的一半：$xe^x$。

它代入左边后，必须等于右边的 $ce^x$。

- 右边的非齐次项是 $ce^x$，提取指数 DNA $\lambda = 1$。
    
- 既然特解长成了 **$x \cdot e^x$** 的形式，为什么前面会多出来一个 $x$？
    
- 根据我们上一回总结的规则：**只有当右边指数 $\lambda$ 刚好是特征根（发生撞车）时，特解才需要乘 $x$ 来补救！**
    

因为这里乘的是 $x^1$（不是 $x^2$），说明发生了**单根撞车**。

既然 $\lambda = 1$，这就逆推出了：**特征方程的另一个根 $r_2 = 1$。**

#### 第四步：组装通解（见证奇迹的合并）

现在我们已经完全破解了原方程的底牌：

两个特征根是 $r_1 = -1$ 和 $r_2 = 1$。

所以，齐次通解为：

$$y_c = C_1e^{-x} + C_2e^x$$

根据“通解 = 齐次通解 + 特解”，我们把题目给的特解加进去：

$$y = C_1e^{-x} + C_2e^x + (e^{-x} + xe^x)$$

整理一下同类项：

$$y = (C_1 + 1)e^{-x} + C_2e^x + xe^x$$

**最后一步的魔法：**

既然 $C_1$ 是“任意常数”，那么 $C_1 + 1$ 本质上还是一个“任意常数”！我们直接把它重新叫做 $C_1$ 即可。

最终答案直接出炉：

$$y = C_1e^{-x} + C_2e^x + xe^x$$

**总结你的笔记：已知特解推通解怎么做？**

1. **先拆开**：把给定的特解展开成几项相加。
    
2. **找内鬼**：看看特解里哪一项的长相跟等号右边完全扯不上关系。这项代进去必定等于 0，它直接暴露了齐次解（特征根）。
    
3. **看撞车**：看看剩下的项里有没有多乘 $x$ 或 $x^2$。根据右边非齐次项的指数，反推剩下的特征根。
    
4. **组装并吸收**：写出齐次通解加上给定的特解。特解里必定有一部分会被通解里的常数 $C$ 直接“吸收合并”掉，剩下的就是最简通解。

### 02 计算技巧 1｜二重根撞车：令 y=u(x)e^x 降维

> 来源：[[02习题与1000题]]

![[习题与1000题-1773889436205.jpeg]]
你想想，你要设 $y^* = (a_0x^4 + a_1x^3 + a_2x^2)e^x$。对它求一阶导，要用乘积求导法则，会搞出一大串；再求二阶导，项数直接翻倍，写出来能占半页纸，极其容易算错正负号！

这道题其实藏着一个**极其逆天的降维打击技巧**。我们绝对不用待定系数法去硬刚，而是用**“变量代换法”**（本质上就是算子法的平替，而且大题完全给分）。

只要遇到等号右边是 **多项式 $\times \ e^{\lambda x}$**，且撞车了（尤其是这种二重根撞车），直接用这个套路，三行出答案！

---

#### 神仙技巧：直接令 $y = u(x)e^x$

我们不要去设什么 $a_0, a_1$，那个太笨了。

既然右边有 $e^x$，我们就顺水推舟，直接令特解为：

$$y = u \cdot e^x$$

（这里的 $u$ 是一个关于 $x$ 的未知函数，我们等会去抓它）。

**第一步：准备好导数原材料（利用乘积求导）**

- $y = u e^x$
    
- $y' = u' e^x + u e^x = (u' + u)e^x$
    
- $y'' = (u'' + u')e^x + (u' + u)e^x = (u'' + 2u' + u)e^x$
    

**第二步：代入原方程左边（见证奇迹的时刻）**

原方程左边是 $y'' - 2y' + y$。把上面三坨代进去，把 $e^x$ 提在最外面：

$$e^x \big[ (u'' + 2u' + u) - 2(u' + u) + u \big]$$

我们在中括号里合并一下同类项，你会发现：

- $u'$ 的系数：$2 - 2 = 0$
    
- $u$ 的系数：$1 - 2 + 1 = 0$
    

全部抵消了！！左边极其清爽地只剩下了：

$$u'' e^x$$

> **💡 为什么会这么巧？**
> 
> 因为原方程的特征根是 $r=1$ 的**二重根**。只要是二重根，代入 $y=ue^{\lambda x}$ 后，$u$ 和 $u'$ 的项**必定100%全部抵消**，绝对只剩下 $u''$！这是数学规律。

**第三步：接上等号右边，直接积分**

既然左边化简成了 $u'' e^x$，原方程等号右边是 $2(3x^2 - 2)e^x = (6x^2 - 4)e^x$。

连起来：

$$u'' e^x = (6x^2 - 4)e^x$$

两边同时砍掉 $e^x$：

$$u'' = 6x^2 - 4$$

这还算什么微分方程？这直接退化成了高中的**连续求两次积分**！

对 $6x^2 - 4$ 积第一次分，得到 $u'$：

$$u' = 2x^3 - 4x$$

再积第二次分，得到 $u$：

$$u = \frac{1}{2}x^4 - 2x^2$$

_(因为我们只求特解，所以不需要加常数 $C$)_。

**第四步：大功告成**

把算出来的 $u$ 放回我们一开始设的 $y = u e^x$ 里：

$$y^* = \left(\frac{1}{2}x^4 - 2x^2\right)e^x$$

如果你把它展开，就是 $x^2(\frac{1}{2}x^2 - 2)e^x$。

对比书上设的 $x^2(a_0x^2 + a_1x + a_2)e^x$。

你会发现 $a_0 = \frac{1}{2}, a_1 = 0, a_2 = -2$。跟答案一模一样！

### 02 计算技巧 2｜三角非齐次项：复指数法免解二元组

> 来源：[[02习题与1000题]]

![[习题与1000题-1773889854146.jpeg]]
对于带有 $\sin$ 或 $\cos$ 的非齐次项，如果你老老实实地设 $y^* = A\sin x + B\cos x$，然后求一阶导、求二阶导，再代入原方程去解那个包含 $A$ 和 $B$ 的二元一次方程组……说实话，不仅累，而且极其容易在正负号上翻车。

面对三角函数，数学界也有两个**“降维打击”**的神仙级技巧。一个是利用我们在前几节打下的基础（复指数法），另一个就是传说中的终极外挂（微分算子法）。

我们直接拿图片里这道原题 **$y'' + 4y' + 5y = 8\cos x$** 来演示，让你感受一下什么叫“丝滑出答案”。

---

#### 屠龙技一：复指数法（给三角函数穿上 $e$ 的马甲）

你之前已经完美掌握了应对 $e^{\lambda x}$ 的方法。那我们为什么不把三角函数变成 $e$ 呢？

根据欧拉公式：$e^{ix} = \cos x + i\sin x$。

所以，$8\cos x$ 其实就是 **$8e^{ix}$ 的实部**！

**第一步：狸猫换太子**

我们不去解原来的方程，我们去解一个带有虚数 $i$ 的新方程：

$$y'' + 4y' + 5y = 8e^{ix}$$

这里的 $\lambda = i$。因为特征根是 $-2 \pm i$，所以 $\lambda = i$ **没有撞车**！

**第二步：用 $e$ 的套路直接秒**

既然没撞车，直接设特解为 $y^* = C e^{ix}$。

代入方程（指数函数求导就是把系数拿下来）：

$$C(i)^2 e^{ix} + 4C(i)e^{ix} + 5C e^{ix} = 8e^{ix}$$

把 $e^{ix}$ 砍掉，把 $i^2 = -1$ 代入：

$$C(-1 + 4i + 5) = 8 \implies C(4 + 4i) = 8$$

$$C = \frac{8}{4 + 4i} = \frac{2}{1 + i}$$

分子分母同乘 $(1 - i)$ 实现分母实数化：

$$C = \frac{2(1 - i)}{(1+i)(1-i)} = \frac{2(1 - i)}{2} = 1 - i$$

**第三步：现出原形**

我们解出来的复数特解是：

$$y^* = (1 - i)e^{ix} = (1 - i)(\cos x + i\sin x)$$

把它展开：

$$= (\cos x + \sin x) + i(\sin x - \cos x)$$

因为原题的 $8\cos x$ 是实部，所以我们**只取实部**：

$$y^* = \cos x + \sin x$$

一行方程组都没解，直接出答案！

### 04 大观 13｜多个非齐次特解做差：构造齐次基底

> 来源：[[04大观习题]]

![[_attachments/image/04大观习题-1782394374751.jpeg]]
![[_attachments/image/04大观习题-1782394363211.jpeg]]


图 1 我做的过程和批注一样很巧妙得消到解图 2 不能像图 1 这样做吗？ 答案只是代入**完全可以！而且用你这种“结构分析法”来做图 2，不仅完全行得通，而且在数学逻辑上比答案给出的“强行代入法”更加优雅、高级，具有更强的通用性。**

我们完全套用图 1 的逻辑，来对图 2 进行一次完美的“降维打击”：

---

#### 第一步：做差，找出齐次方程的解

已知非齐次方程的三个特解为：
$$y_1 = 1, \quad y_2 = e^{-x}, \quad y_3 = 2e^{-x}$$

根据“**两个非齐次特解之差是对应齐次方程的解**”：
* $y_3 - y_2 = 2e^{-x} - e^{-x} = e^{-x} \implies$ **$e^{-x}$ 是齐次解**。
* $y_3 - y_1 = 2e^{-x} - 1 \implies$ **$2e^{-x} - 1$ 是齐次解**。

---

#### 第二步：线性组合，简化齐次方程的基底

由于齐次解的线性组合仍然是齐次解，我们将上面得到的两个齐次解进行组合：
$$\text{齐次解} = 2 \cdot (e^{-x}) - (2e^{-x} - 1) = 1$$

所以，**$1$（即 $e^{0x}$）也是该齐次方程的一个解**！

至此，我们非常漂亮地集齐了两个线性无关的齐次解：
* **$1$ （对应特征根 $r_1 = 0$）**
* **$e^{-x}$ （对应特征根 $r_2 = -1$）**

---

#### 第三步：写出齐次方程（确定左端项）

既然特征根为 $r_1 = 0, \ r_2 = -1$，那么对应的特征方程为：
$$r(r + 1) = 0 \implies r^2 + r = 0$$

所以，该微分方程的**左端项**必定为：
$$y'' + y' = \dots$$

---

#### 第四步：确定右端项 $f(x)$

设该方程为 $y'' + y' = f(x)$。
我们直接把任意一个已知特解（比如最简单的 $y_1 = 1$）代入左边：
$$f(x) = y_1'' + y_1' = (1)'' + (1)' = 0 + 0 = 0$$

所以右端项 $f(x) = 0$。

最终方程为：
$$y'' + y' = 0$$

---

#### 为什么答案不用你这种方法，而是用“强行代入”？

主要是因为图 2 这道题给的三个特解（$1$、 $e^{-x}$、 $2e^{-x}$）实在是**太简单、太特殊**了。
* 答案的作者偷了懒，觉得直接设 $y'' + ay' + by = f(x)$ 然后把常数 $1$ 带进去能直接秒出 $b = f(x)$，所以才写了代入法。

但答案的这种“代入法”有一个**致命的局限性**：如果右端项 $f(x)$ 不是常数，而是一个复杂的函数（比如 $f(x) = x \sin x$），代入法会直接卡死。

而你掌握的这种**“结构做差法”是 100% 通用的**，无论题目出得多难，只要给出了非齐次的特解，用这套方法都能无往而不利。考研中非常推荐保留并熟练使用你的这一套思路！

### 04 大观 14｜新题型：系数是 p(x)、q(x)，别擅自当常数

> 来源：[[04大观习题]]

![[_attachments/image/04大观习题-1782395505653.jpeg]]

![[_attachments/image/04大观习题-1782395515929.jpeg]]


做到这一步，我就设原方程 ay''+by'+cy = 0 把 x 和 x 方分别带进去，比对系数，只能得 abc 都是 0. 问题出在哪？
一、【直接答案】
$x^2y'' - 2xy' + 2y = (x^2 - 2x + 2)e^x$
（或写成 $y'' - \frac{2}{x}y' + \frac{2}{x^2}y = (1 - \frac{2}{x} + \frac{2}{x^2})e^x$）

二、【我的错因分析】
你凭空捏造了**“常系数”**这个条件。
题目只说了是“二阶线性非齐次微分方程”，其标准形式是 $y'' + p(x)y' + q(x)y = f(x)$，前面的系数 $p(x)$ 和 $q(x)$ 是关于 $x$ 的函数！
你设 $ay''+by'+cy = 0$，默认了 $a,b,c$ 是常数。在二阶常系数齐次方程中，如果解里含有 $x$ 和 $x^2$，意味着特征方程必然有三重根 $r=0$（对应的解是 $C_1 + C_2x + C_3x^2$），这至少是一个**三阶**微分方程（$y'''=0$）。二阶常系数微分方程根本装不下 $x$ 和 $x^2$ 这两个线性无关解。这就是为什么你比对系数只能得出 $a=b=c=0$ 的死胡同。

三、【考场思维链 (限时模拟)】
Step 1：抓取题眼，提取齐次解
利用非齐次解的性质：特解 - 特解 = 齐次解。
立刻得到两个线性无关的齐次解：$Y_1 = y_2 - y_1 = x$，$Y_2 = y_3 - y_1 = x^2$。

Step 2：反推齐次方程（两种方法，任选其一）
**常规法（待定系数代入）：**
设齐次方程为 $y'' + p(x)y' + q(x)y = 0$。
把 $x$ 代入：$0 + p(x)\cdot 1 + q(x)\cdot x = 0 \implies p(x) = -x \cdot q(x)$
把 $x^2$ 代入：$2 + p(x)\cdot 2x + q(x)\cdot x^2 = 0$
将上式代入下式：$2 + (-x \cdot q(x)) \cdot 2x + x^2 q(x) = 0 \implies 2 - x^2 q(x) = 0 \implies q(x) = \frac{2}{x^2}$。
进而 $p(x) = -\frac{2}{x}$。
得到齐次方程：$y'' - \frac{2}{x}y' + \frac{2}{x^2}y = 0$，化简为 $x^2y'' - 2xy' + 2y = 0$。

**秒杀法（行列式构造）：**
已知两个基础解 $y_1, y_2$，齐次方程可直接由行列式 $\begin{vmatrix} y & y_1 & y_2 \\ y' & y_1' & y_2' \\ y'' & y_1'' & y_2'' \end{vmatrix} = 0$ 写出。
$\begin{vmatrix} y & x & x^2 \\ y' & 1 & 2x \\ y'' & 0 & 2 \end{vmatrix} = y(2-0) - y'(2x-0) + y''(2x^2-x^2) = x^2y'' - 2xy' + 2y = 0$。

Step 3：关键动作（反求非齐次项 $f(x)$）
方程左边已经有了，设原方程为 $x^2y'' - 2xy' + 2y = f(x)$。
怎么求 $f(x)$？直接把已知的一个特解 $y_1 = e^x$ 扔进左边算出来即可！
$f(x) = x^2(e^x)'' - 2x(e^x)' + 2(e^x) = x^2e^x - 2xe^x + 2e^x = e^x(x^2 - 2x + 2)$。
拼装结束。

四、【严密逻辑推敲 (防杠指南)】
为什么已知两个线性无关解就能唯一确定一个二阶线性齐次方程（系数化为 1 的标准型）？
根据线性常微分方程理论，设方程为 $y'' + p(x)y' + q(x)y = 0$。将解 $Y_1, Y_2$ 代入，得到关于 $p(x), q(x)$ 的线性代数方程组：
$Y_1' p(x) + Y_1 q(x) = -Y_1''$
$Y_2' p(x) + Y_2 q(x) = -Y_2''$
由克莱姆法则（Cramer's Rule），其系数矩阵的行列式 $W(Y_1, Y_2) = Y_1 Y_2' - Y_2 Y_1'$ 正是朗斯基行列式。因为 $Y_1=x, Y_2=x^2$ 线性无关，且在 $x \neq 0$ 时 $W(x, x^2) = x(2x) - x^2(1) = x^2 \neq 0$，所以该方程组必然有唯一解 $p(x)$ 和 $q(x)$。
这保证了考场上通过代入法解 $p(x), q(x)$ 在底层逻辑上是绝对完备且唯一的。

五、【陷阱与触发器总结】
致命陷阱：看到“线性微分方程”直接脑补成“常系数线性微分方程”。考研题中如果系数是常数，命题人一定会明说“常系数”。没写这三个字，系数必然带 $x$。

思维触发器：
IF 给出多个特解求原微分方程，
THEN 肌肉记忆连招：**相减得齐次解 $\to$ 设 $y''+p(x)y'+q(x)y=0$ 代入解出 $p,q$（或直接用三阶行列式） $\to$ 将任意一个特解代回左侧求出右侧的 $f(x)$**。严禁假定系数为常数 $a, b, c$。

## 五、定性分析、极限与积分应用

### 02 习题 10｜含积分方程：极坐标、求导，把积分题变成微分方程

> 来源：[[02习题与1000题]]

![[习题与1000题-1773805888338.jpeg]]
化为了一阶非齐次微分方程
#### 第一步：极坐标化简（把纸老虎打回原形）

你看那个积分区域 $x^2+y^2 \le 4t^2$，这不就是一个半径为 $2t$ 的圆吗？被积函数里又有 $\sqrt{x^2+y^2}$。这简直就是把**“快用极坐标”**五个大字写在了脸上！

我们令 $x = r\cos\theta, y = r\sin\theta$。

- 积分区域变成了：$\theta$ 从 $0$ 到 $2\pi$，$r$ 从 $0$ 到 $2t$。
    
- 被积函数变成了：$f(\frac{r}{2})$。
    
- 面积微元 $dxdy$ 变成了：$r dr d\theta$（千万别忘了多出来的这个 $r$！）
    

把二重积分写出来：

$$\iint f\left(\frac{1}{2}\sqrt{x^2+y^2}\right) dxdy = \int_0^{2\pi} d\theta \int_0^{2t} f\left(\frac{r}{2}\right) r dr$$

前面那个 $\theta$ 的积分和后面毫无瓜葛，直接积出来就是 $2\pi$。

式子变成了：

$$2\pi \int_0^{2t} f\left(\frac{r}{2}\right) r dr$$

为了让式子看起来更舒服，我们再做一个简单的换元。令 $u = \frac{r}{2}$，那么 $r = 2u$，$dr = 2du$。

当 $r=0$ 时，$u=0$；当 $r=2t$ 时，$u=t$。

代进去：

$$2\pi \int_0^t f(u) \cdot (2u) \cdot (2du) = 8\pi \int_0^t u f(u) du$$

**见证奇迹的时刻：** 那个吓人的二重积分，经过极坐标变换，变成了一个极其清爽的一元变上限积分！

现在的原方程变成了这样：

$$f(t) = e^{4\pi t^2} + 8\pi \int_0^t u f(u) du$$

---

#### 第二步：两边求导（积分方程 $\implies$ 微分方程）

还记得我们之前聊过的“变上限积分求导”吗？这里就是它的主场！

我们对等式两边同时关于 $t$ 求导：

- 左边求导：$f'(t)$
    
- 右边第一项求导（复合函数）：$e^{4\pi t^2} \cdot 8\pi t = 8\pi t e^{4\pi t^2}$
    
- 右边第二项求导（变上限积分，直接把上限 $t$ 塞进去替换 $u$）：$8\pi \cdot t f(t)$
    

把它们拼起来：

$$f'(t) = 8\pi t e^{4\pi t^2} + 8\pi t f(t)$$

移个项，整理一下队形：

$$f'(t) - 8\pi t f(t) = 8\pi t e^{4\pi t^2}$$

你看！它完美地褪去了所有伪装，变成了一个标准的**一阶线性微分方程**！

---

#### 第三步：寻找初始条件（解的临门一脚）

解一阶微分方程，最后一定会产生一个任意常数 $C$。要解出这个 $f(t)$（特解），我们需要一个初始条件（比如 $t=0$ 时，$f(0)$ 等于几）。

这个条件去哪里找呢？**回到最原始的那个含有积分号的方程里去找！**

原方程：$f(t) = e^{4\pi t^2} + 8\pi \int_0^t u f(u) du$

我们让上限和下限相等，也就是令 $t = 0$：

$$f(0) = e^0 + 8\pi \int_0^0 u f(u) du$$

因为积分上下限都是 0，所以整个积分项就是 0。而 $e^0 = 1$。

所以我们白嫖到了一个初始条件：**$f(0) = 1$**。

---

**总结一下这道题的剧本：**

通过极坐标化简，再求导，我们最终得到的是一个**带有初始条件的一阶线性微分方程初值问题**：

$$\begin{cases} f'(t) - 8\pi t f(t) = 8\pi t e^{4\pi t^2} \\ f(0) = 1 \end{cases}$$

剧本我已经帮你写好了，剩下的就是纯纯的套公式体力活了。

### 02 1000 题 10｜变上限积分：为证明不等式改写原函数

> 来源：[[02习题与1000题]]

![[习题与1000题-1773885349824.jpeg]]![[习题与1000题-1773885351210.jpeg]]
公式里的 $\int \varphi(x) e^x dx$ 是一个**不定积分**。但是题目给的 $\varphi(x)$ 是个抽象函数，你根本积不出来！而且后面还要证明不等式，不定积分带着个尾巴没法比大小。

**破局技巧：把“不定积分”强行写成“变上限积分”。**

在数学上，原函数 $\int f(x)dx$ 完全可以写成 $\int_0^x f(t)dt$ 的形式（这里的 $t$ 只是个占位符，叫阿猫阿狗都行，为了不和上限 $x$ 混淆）。

所以，我们把通解改写成：

$$y(x) = e^{-x} \left( \int_0^x \varphi(t) e^t dt + C \right)$$

接下来代入初始条件 $y(0) = 0$：

$$y(0) = e^0 \left( \int_0^0 \varphi(t) e^t dt + C \right)$$

因为积分上下限都是 0，所以积分项等于 0。

$0 = 1 \cdot (0 + C) \implies C = 0$

把 $C=0$ 代回去，特解就出来了：

$$y(x) = e^{-x} \int_0^x \varphi(t) e^t dt$$

你看，用公式做，结果和答案是一模一样的！

### 02 1000 题 11｜换元后定常数与平均值：积分变量别混

> 来源：[[02习题与1000题]]

![[习题与1000题-1773886565913.jpeg]]

我们把你的思路拆成两半来看，告诉你哪里极其聪明，哪里又绝对不能这么做：

#### 第一半（天才的捷径）：不换回 $x$，直接在 $t$ 世界算 $C$

**这步绝对可行，而且极其推荐！** 这叫“初始条件同步换元”，能帮你省去大量写 $\ln x$ 的麻烦。

- 题目给的初始条件是 $x = 1$ 时，$y = \frac{1}{4}$。
    
- 既然你的宇宙规则是 $x = e^t$，那么当 $x = 1$ 时，对应的 $t = \ln 1 = \mathbf{0}$。
    
- 所以，初始条件在 $t$ 世界里就变成了：**当 $t = 0$ 时，$y = \frac{1}{4}$**。
    

把 $t=0$ 代入你的通解 $y(t) = C e^{2t} - \frac{1}{2}t$：

$$y(0) = C e^0 - 0 = C$$

立刻得出 **$C = \frac{1}{4}$**。

你看，连平方和对数都不用算，直接秒出 $C$，这就是在 $t$ 域算常数的巨大优势！

现在的函数是：**$y(t) = \frac{1}{4}e^{2t} - \frac{1}{2}t$**。

---

#### 第二半（致命陷阱）：直接求 $\int_0^1 y(t) dt$ 算平均值？

**这步绝对不行！** 这是考研定积分大题里失分率极高的一个错觉。

函数在区间上的“平均值”是一个严格的几何定义：**曲线下方的面积 $\div$ 底边的实际物理长度**。

$$\text{平均值} = \frac{\int_1^e y(x) dx}{e - 1}$$

如果你强行把它转到 $t$ 域，你会漏掉两个极其关键的东西：

**1. 漏了微分项（凑微分的代价）：**

定积分换元时，**$dx$ 绝对不能直接变成 $dt$**！

因为 $x = e^t$，两边求微分得到：

$$dx = e^t dt$$

如果你只积 $\int_0^1 y(t) dt$，你等于把那个缩放比例 $e^t$ 给硬生生吃掉了，面积全算错了。

**2. 漏了原始区间的长度：**

即便你把积分换到了 $t$ 域，算出来的也是“总面积”。求平均值时，除以的必须依然是**原来 $x$ 轴上的真实长度 $(e - 1)$**，而绝对不能是 $t$ 轴上的长度 $(1 - 0)$。

---

#### 正确的 $t$ 域积分姿势

如果你坚持不想回到 $x$ 域，想纯在 $t$ 域把这道题刚到底，正确的列式应该是这样的：

$$\text{平均值} = \frac{1}{e - 1} \int_0^1 y(t) \cdot e^t dt$$

我们把算出来的 $y(t)$ 代进去实际算一下，看看是不是和之前的结果一样：

$$\int_0^1 \left( \frac{1}{4}e^{2t} - \frac{1}{2}t \right) e^t dt$$

$$= \int_0^1 \left( \frac{1}{4}e^{3t} - \frac{1}{2}t e^t \right) dt$$

这个积分非常好算：

- 前半部分：$\int_0^1 \frac{1}{4}e^{3t} dt = \left[ \frac{1}{12}e^{3t} \right]_0^1 = \frac{e^3 - 1}{12}$
    
- 后半部分（依然是分部积分）：$\int_0^1 \frac{1}{2}te^t dt = \frac{1}{2} \left[ te^t - e^t \right]_0^1 = \frac{1}{2} ( (e - e) - (0 - 1) ) = \frac{1}{2}$
    

相减得到总面积：$\frac{e^3 - 1}{12} - \frac{1}{2} = \frac{e^3 - 7}{12}$

最后除以原区间长度 $e-1$：

$$\text{平均值} = \frac{e^3 - 7}{12(e - 1)}$$

你看！和我们之前老老实实换回 $x$ 算出来的结果**分毫不差**！

**总结你的实战策略：**

- **定常数 $C$ 时：** 强烈建议像你第一步想的那样，在 $t$ 域直接定，既快又准。
    
- **算定积分/平均值时：** 建议还是**换回 $x$ 域再去积**。因为如果你留在 $t$ 域，你不仅要记得乘上极其容易忘的微分后缀 $e^t$，还要面对两个指数函数相乘（$e^{2t} \cdot e^t = e^{3t}$）的变形，反而增加了出错的风险。

### 04 大观 17｜有界解：选积分下限消灭指数爆炸

> 来源：[[04大观习题]]

![[_attachments/image/04大观习题-1782443343293.jpeg]]


一、【直接答案】
是的，通解公式积分的下限确实可以“随意写”，因为**改变下限等价于改变任意常数 $C$ 的取值**。但在这道题里，写成 $-\infty$ 绝不是随意的，而是为了**消灭无穷大**而量身定制的唯一解。

二、【我的错因分析】
你觉得“上下限可以随意写”，是因为你没有看穿**微积分基本定理与一阶线性微分方程通解公式的底层绑定关系**。
在通解公式 $y = e^{-\int P(x)dx} \left[ \int Q(x)e^{\int P(x)dx} dx + C \right]$ 中，里面那个变限积分的下限本来就是任意的一个常数 $a$。
由于 $\int_a^x = \int_b^x + \int_a^b$，其中 $\int_a^b$ 是个常数，它会被外面的 $+C$ 直接吸收掉。因此，你写下限为 $0$、下限为 $1$、或者下限为 $-\infty$，只要积分收敛，在**加了 $+C$ 的前提下**，它们表示的解空间是完全等价的。
但本题答案的鸡贼之处在于：它直接把下限选为 $-\infty$ 并令 $C=0$。这不是在“随便写”，而是在**反向推导出一个特定常数 $C$，使得函数在 $x \to -\infty$ 时不发生爆炸**。你被答案跳跃的逻辑蒙蔽了。

三、【考场思维链 (限时模拟)】
Step 1：写出常规通解，暴露危险项
老老实实写出通解（习惯性按下限为 0 写）：
$y(x) = e^{-x} \left[ \int_0^x e^t f(t) dt + C \right] = C e^{-x} + e^{-x} \int_0^x e^t f(t) dt$
题目要求这个解在整个实数轴 $\mathbf{R}$ 上有界。
立刻观察极限行为：当 $x \to +\infty$ 时，$e^{-x} \to 0$（安全）；**当 $x \to -\infty$ 时，$e^{-x} \to +\infty$（极度危险，可能导致无界）**。

Step 2：强行镇压无穷大（求出特定的 C）
为了不让 $y(x)$ 在 $x \to -\infty$ 时爆炸，中括号里面的那一坨必须趋于 $0$，去中和外面的 $+\infty$。
即必须满足：$\lim_{x \to -\infty} \left[ \int_0^x e^t f(t) dt + C \right] = 0$
解得：$C = -\int_0^{-\infty} e^t f(t) dt = \int_{-\infty}^0 e^t f(t) dt$。
（注：因为 $|f(t)| \le M$，所以 $\int_{-\infty}^0 e^t M dt = M$，该广义积分绝对收敛，这个 $C$ 是存在且合法的。）

Step 3：拼装备用（第一题得证）
把求出的特定 $C$ 代回原式：
$y(x) = e^{-x} \left[ \int_0^x e^t f(t) dt + \int_{-\infty}^0 e^t f(t) dt \right]$
根据积分区间可加性，直接拼成：
$y(x) = e^{-x} \int_{-\infty}^x e^t f(t) dt$。
这就是答案中那步“令 $C=0$ 且下限为 $-\infty$”的真实来历！最后加个绝对值不等式放缩，直接秒杀。

四、【严密逻辑推敲 (防杠指南)】
1. **通解下限的等价性证明**：
设解为 $y_1(x) = e^{-x}(\int_a^x e^t f(t) dt + C_1)$，换一个下限 $b$，解为 $y_2(x) = e^{-x}(\int_b^x e^t f(t) dt + C_2)$。
$y_1(x) = e^{-x}(\int_b^x e^t f(t) dt + \int_a^b e^t f(t) dt + C_1)$。
由于 $\int_a^b e^t f(t) dt$ 是常数，令 $C_2 = \int_a^b e^t f(t) dt + C_1$，则 $y_1 \equiv y_2$。所以下限确实可以随便取，只要 $C$ 是任意的。

2. **第一题有界性的严格证明**：
我们已经构造出特解 $y^*(x) = e^{-x} \int_{-\infty}^x e^t f(t) dt$。
对任意 $x \in \mathbf{R}$，取绝对值放缩：
$|y^*(x)| = \left| e^{-x} \int_{-\infty}^x e^t f(t) dt \right| \le e^{-x} \int_{-\infty}^x e^t |f(t)| dt$ （因为 $e^t > 0$，所以可以直接放进积分号）
由于题目已知 $f(x)$ 有界，即存在 $M>0$，使得 $|f(x)| \le M$。
继续放缩：
$\le e^{-x} \int_{-\infty}^x e^t \cdot M dt = M e^{-x} \left[ e^t \right]_{-\infty}^x = M e^{-x} (e^x - 0) = M$。
即对任意实数 $x$，都有 $|y^*(x)| \le M$。严格证明了该解有界。

五、【陷阱与触发器总结】
致命陷阱：
1. **照猫画虎乱定下限**：看到这道题的答案直接设 $-\infty$，以后遇到微分方程题一律把下限设为 $-\infty$ 或 $\infty$。如果外面配的是 $e^x$ 而不是 $e^{-x}$，积分 $\int_{-\infty}^x e^{-t}f(t) dt$ 就会发散，整个推导瞬间崩溃。
2. **逻辑倒置**：答案是“因为知道了需要用 $\int_{-\infty}^x$ 才能有界，所以故意令 $C=0$ 凑出这个形式”，而不是“只要令 $C=0$，它就恰好有界”。

思维触发器：
IF 求解**全实数轴 $\mathbf{R}$ 上的有界解/周期解**，
THEN 肌肉记忆：**立刻检查外侧指数函数在 $x \to +\infty$ 和 $x \to -\infty$ 哪一端会趋向无穷大**。如果 $x \to -\infty$ 时爆炸，利用常数 $C$ 强迫积分下限变为 $-\infty$；如果 $x \to +\infty$ 时爆炸，强迫积分下限变为 $+\infty$。这是微分方程中控制边界发散的唯一手段。

#### 第一问实战：证明（I）

**方程**：$\frac{\text{d}x}{\text{d}t} + a(t)x = 0$，自变量 $t \in [0, +\infty)$。

##### 1. 写出带上下限的解
根据黄金法则，区间起点是 $0$，所以我们把积分下限设为 $0$，上限设为 $t$。
分离变量法可得：
$$\frac{\text{d}x}{x} = -a(t)\text{d}t$$
两边同时从 $0$ 积到 $t$：
$$\int_{x(0)}^{x(t)} \frac{1}{u}\text{d}u = -\int_0^t a(s)\text{d}s$$
$$\ln|x(t)| - \ln|x(0)| = -\int_0^t a(s)\text{d}s$$
化简得到通解：
$$x(t) = C e^{-\int_0^t a(s)\text{d}s} \quad (\text{其中 } C = x(0) \text{ 是任意常数})$$

##### 2. 开始证明（充要条件 $\iff$）

* **充分性（$\impliedby$）**：已知 $\int_0^{+\infty} a(t)\text{d}t$ 发散。
  因为 $a(t) \ge 0$，所以其积分随着 $t \to +\infty$ 只能趋于 $+\infty$：
  $$\lim_{t \to +\infty} \int_0^t a(s)\text{d}s = +\infty$$
  那么代入解的表达式：
  $$\lim_{t \to +\infty} x(t) = \lim_{t \to +\infty} C e^{-\int_0^t a(s)\text{d}s} = C \cdot e^{-\infty} = 0$$
  充分性证毕！

* **必要性（$\implies$）**：已知每一个解都满足 $\lim_{t \to +\infty} x(t) = 0$。
  我们取一个非零解（即 $C \neq 0$）。要让下式成立：
  $$\lim_{t \to +\infty} C e^{-\int_0^t a(s)\text{d}s} = 0$$
  因为 $C \neq 0$，所以指数部分必须趋于 $-\infty$，也就是说：
  $$\lim_{t \to +\infty} \int_0^t a(s)\text{d}s = +\infty$$
  这就说明广义积分 $\int_0^{+\infty} a(t)\text{d}t$ 必须发散。必要性证毕！

---

#### 第二问实战：证明（II）

**方程**：$\frac{\text{d}x}{\text{d}t} + ax = f(t)$，其中 $a > 0$，$f(t)$ 连续且有界。

##### 1. 写出带上下限的解
我们背过的非齐次线性微分方程通解公式是：
$$x(t) = e^{-\int P\text{d}t} \left[ \int Q e^{\int P\text{d}t}\text{d}t + C \right]$$
这里 $P(t) = a$（常数），$Q(t) = f(t)$。同样地，区间是 $[0, +\infty)$，**我们把所有积分的下限都写成 $0$**：
$$x(t) = e^{-\int_0^t a\text{d}s} \left[ \int_0^t f(s) e^{\int_0^s a\text{d}\tau}\text{d}s + C \right]$$

因为 $a$ 是常数，里面的积分非常好算：
$$\int_0^t a\text{d}s = at, \quad \int_0^s a\text{d}\tau = as$$
代入进去，通解就变成了极为干净、没有任何模糊积分号的形式：
$$x(t) = e^{-at} \left[ \int_0^t f(s) e^{as}\text{d}s + C \right] = C e^{-at} + e^{-at}\int_0^t f(s) e^{as}\text{d}s$$

##### 2. 开始证明有界性
我们要证明无论 $C$ 取什么值，$x(t)$ 在 $t \ge 0$ 时都是有界的。
因为 $f(t)$ 有界，设 $|f(t)| \le M$。我们对 $x(t)$ 取绝对值放大：

$$|x(t)| \le |C|e^{-at} + e^{-at}\int_0^t |f(s)| e^{as}\text{d}s$$
$$|x(t)| \le |C|e^{-at} + M e^{-at}\int_0^t e^{as}\text{d}s$$

计算这个定积分：$\int_0^t e^{as}\text{d}s = \frac{e^{at} - 1}{a}$。代回上式：
$$|x(t)| \le |C|e^{-at} + M e^{-at} \cdot \frac{e^{at} - 1}{a}$$
$$|x(t)| \le |C|e^{-at} + \frac{M}{a}\left(1 - e^{-at}\right)$$

因为 $a > 0$ 且 $t \ge 0$，所以指数项 $e^{-at}$ 是一个介于 $0$ 到 $1$ 之间的数（$0 < e^{-at} \le 1$）。
因此：
* $|C|e^{-at} \le |C|$
* $\frac{M}{a}\left(1 - e^{-at}\right) \le \frac{M}{a}$

最终我们得到：
$$|x(t)| \le |C| + \frac{M}{a}$$
因为 $|C| + \frac{M}{a}$ 是一个固定的常数，这说明所有的解 $x(t)$ 在 $[0, +\infty)$ 上都是有界的。证明完毕！

#### 📌 终极总结

以后做这类题，千万不要直接用带有不确定常数的不定积分号 $\int$。请在动笔的第一步就完成两件事：
1. **看定义域起点**：如果是 $[0, +\infty)$，所有积分下限写 $0$。
2. **改写变量**：上限写 $t$（或 $x$），积分内部的自变量改成 $s$（或 $\tau$）。
