# 1 ![[_attachments/image/880-1779327921837.jpeg]]

这道题出得非常经典，你对选项 B 的直觉很准确！你觉得 $P(x)$ 的条件像“废话”，这是很多同学做微分方程理论题时的共同感受。但实际上，**这道题的题眼（或者说唯一的“陷阱”）恰恰就藏在 $P(x)$ 的条件里。**

这道题核心考查的知识点是：**一阶齐次线性微分方程的解的结构，以及指数函数的绝对不为零的性质。**

我们先来把这个方程“扒光”，看看它的解到底长什么样。

对于一阶齐次线性方程 $y' + P(x)y = 0$，它的**通解公式**是固定的：

$$y = C e^{-\int P(x) dx}$$

（其中 $C$ 是任意常数）

既然题目说 $y_1(x)$ 和 $y_2(x)$ 是两个**不同**的特解，那它们一定可以写成：

- $y_1(x) = C_1 e^{-\int P(x) dx}$
    
- $y_2(x) = C_2 e^{-\int P(x) dx}$
    
    因为是“不同”的特解，所以 $C_1 \neq C_2$。
    

现在我们带着这个“透视镜”，来看看 $P(x)$ 的条件到底是干什么用的，以及各个选项。

### $P(x)$ 的条件有什么用？

1. **“$P(x)$ 在 $(-\infty, +\infty)$ 内连续”：**
    
    - **作用：保命。** 只有 $P(x)$ 连续，它才可以积分（$\int P(x) dx$ 存在），方程在整个实数轴上才有意义，保证了解的存在性和唯一性。这是数学严谨性的要求。
        
2. **“$P(x)$ 不恒为 0”：**
    
    - **作用：绝杀。** 这就是专门为了判断 **选项 A** 准备的。如果 $P(x) \equiv 0$，那么原方程就变成了 $y' = 0$，解就是 $y = C$（常数）。题目特意强调它不全为 0，就是告诉你：**这个方程的解，大概率不是常数，而是带有指数的变量函数。**
        

### 逐个击破选项

我们令两解之差为 $\Delta y(x) = y_1(x) - y_2(x)$，代入刚才的公式：

$$\Delta y(x) = (C_1 - C_2) e^{-\int P(x) dx}$$

令 $K = C_1 - C_2$。因为两特解不同，所以 **$K \neq 0$**。

所以，$\Delta y(x) = K e^{-\int P(x) dx}$。

- **B 选项：$C[y_1(x) - y_2(x)]$ 是通解 （正确）**
    
    这是你已经知道的。把 $\Delta y$ 乘上任意常数 $C$，得到 $C \cdot K e^{-\int P(x) dx}$。因为 $C \cdot K$ 本质上还是一个“任意常数”，所以它完美地覆盖了通解的公式形式。
    
- **C 选项：$y_1(x) - y_2(x)$ 在任一点不为 0 （正确）**
    
    我们看 $\Delta y(x) = K e^{-\int P(x) dx}$。
    
    这里用到了微积分里极其重要的一个常识：**指数函数 $e^{\text{任何东西}}$ 永远大于 0，绝对不可能等于 0。**
    
    前面又已知 $K \neq 0$，所以这两者相乘，在任何一个 $x$ 点都不可能为 0。
    
- **D 选项：$\frac{y_2 (x)}{y_1 (x)} \equiv \text{常数}$  （正确）**
    
    直接相除：
    
    $$\frac{y_2(x)}{y_1(x)} = \frac{C_2 e^{-\int P(x) dx}}{C_1 e^{-\int P(x) dx}} = \frac{C_2}{C_1}$$
    
    $C_2$ 和 $C_1$ 都是具体的常数，所以结果当然是一个常数。（这其实说明一阶齐次方程的所有非零解都是**线性相关**的）。
    
- **A 选项：$y_1(x) - y_2(x) = \text{常数}$ （错误 —— 也就是本题的正确答案）**
    
    我们看 $\Delta y(x) = K e^{-\int P(x) dx}$。
    
    这个式子什么时候才能是一个常数？只有当指数部分 $-\int P(x) dx = \text{常数}$ 时才成立。
    
    而 $-\int P(x) dx = \text{常数}$，对其求导，意味着 **$P(x)$ 必须等于 0**。
    
    但题目**明确规定了“$P(x)$ 不恒为 0”**！所以 $e^{-\int P(x) dx}$ 必然是一个随 $x$ 变化的函数，绝不可能是一个常数。
    
题目问的是“错误的是”，所以选 **A**。这道题本质上就是在考你知不知道一阶齐次的解全都长着一副“常数乘以指数函数”的面孔。

这个“漏解”问题可以说是微分方程分离变量法里最经典的“暗礁”，无数人在考场上在这里翻过船。

“漏解”的本质，其实就是数学里最基础、最不容违背的一条铁律：**除数不能为 0**。

我们来一步步拆解，看看这个解是怎么走丢的，以及以后怎么把它抓回来。

### 1. 解是怎么“漏”掉的？（案发现场回放）

你看解析里的这一步：

从 $x \cdot \frac{du}{dx} = \tan u$

变成了 $\cot u du = \frac{dx}{x}$ （也就是 $\frac{1}{\tan u} du = \frac{1}{x} dx$）

这一步，你是怎么把 $\tan u$ 弄到左边分母上去的？是**等式两边同时除以 $\tan u$**。

既然你做了“除法”，你就必须默默地承担一个数学前提：**假设 $\tan u \neq 0$**。

换句话说，从这一步开始，你后续算出来的所有结果，都是在“$\tan u$ 不等于 0”这个平行宇宙里发生的。

**但现实是，$\tan u$ 是可以等于 0 的！**

如果 $\tan u = 0$，那么 $u = 0$（也就是 $y = 0$）。

我们把 $y = 0$ 代回最原始的方程 $y' = \frac{y}{x} + \tan\frac{y}{x}$：

- 左边：$y' = 0$
    
- 右边：$\frac{0}{x} + \tan(0) = 0 + 0 = 0$
    
    左边等于右边，完美成立！这说明 $y=0$ 本来就是原方程的一个合法解。
    

就因为你在分离变量时，粗暴地除了一个 $\tan u$，导致 $y=0$ 这个合法解被当成“除以 0 的非法情况”给一脚踢开了。这就是所谓的“漏解”。

### 2. 答案是怎么把它“救”回来的？（常数 $C$ 的魔术）

在那个“$\tan u \neq 0$”的平行宇宙里，你千辛万苦积分积出了一个结果：

$\sin u = \pm e^{C_1} \cdot x$

为了书写方便，我们令 $C = \pm e^{C_1}$，得到 $\sin u = Cx$。

**注意此时 $C$ 的身份：** 因为 $e$ 的任何次幂都不可能等于 $0$，所以此时的 $C$ 必须满足 **$C \neq 0$**。

这个时候，猛然想起我们之前还弄丢了一个 $y = 0$（即 $u = 0$）的解。

我们试着把这个走丢的解 $u = 0$ 代入到我们刚算出来的公式 $\sin u = Cx$ 里看看：

$\sin(0) = Cx \implies 0 = Cx \implies C = 0$

奇迹发生了！我们发现，**如果允许常数 $C = 0$，那么 $\sin u = Cx$ 这个公式，就能完美地把刚才漏掉的 $y=0$ 给包含进去！**

所以，答案的最后一步，就是把 $C \neq 0$ 这个限制条件给抹掉，宣告：“上面常数也可以为零，则原方程的通解为 $\sin\frac{y}{x} = Cx \ (C\text{为任意常数})$”。

这不仅是形式上的统一，更是把漏掉的解合法地收编了。

### 3. 以后怎么注意它？（防漏解 2 步法）

在做分离变量的题目时，想要不漏解，以后每次做除法时，在心里走一遍这个“安检流程”：

- **第一步：揪出嫌疑人。**
    
    当你写下 $\frac{dy}{g(y)} = f(x)dx$ 这一步时，立刻看一眼分母 $g(y)$。令 **$g(y) = 0$**，解出来的 $y = a, y = b \dots$ 就是可能被你漏掉的“嫌疑解”。（在本题中，就是令 $\tan u = 0$，得到 $u=0$）。
    
- **第二步：核对保护伞。**
    
    继续往下算你的积分，得出含有常数 $C$ 的通解公式。然后把刚才的“嫌疑解”代入这个公式，看看能不能求出一个具体的 $C$ 值（通常是 $C=0$）。
    
    - **如果能求出 $C$**：说明这个漏解可以通过给 $C$ 取特定值被公式“吸收”。你只需要像答案那样，写一句“当 $C=0$ 时也成立，故 $C$ 为任意常数”即可。
        
    - **如果求不出 $C$（产生矛盾）**：说明这个解极其倔强，无法被你的通解公式吸收。这时候，你必须在答案最后单独把它写出来，叫做“奇解”（通解公式无法覆盖的解）。
        

总结一下，漏解并不可怕，它只是在提醒你：**不要盲目地除以一个含有未知数的式子，除之前，先问问它如果是 0 会发生什么。**

### 第一层考点：“反向”齐次微分方程（最稳妥的常规路线）

**识别特征：** 你看方程里到处都是 $\frac{x}{y}$。

平时我们做的齐次方程，特征是 $\frac{y}{x}$，然后我们令 $u = \frac{y}{x}$。但这里反过来了！

**破解方法：角色互换。**

既然全是 $\frac{x}{y}$，那我们就把 $y$ 当作自变量，把 $x$ 当作未知函数。

令 $u = \frac{x}{y}$，即 $x = uy$。

两边对 $y$ 求导（或者取微分）：$dx = u dy + y du$。

我们把 $x = uy$ 和 $dx$ 全都代入原方程：

$$(1 + e^u)(u dy + y du) + e^u(1 - u)dy = 0$$

展开并把含有 $dy$ 和 $du$ 的项分别合并：

$$u(1 + e^u)dy + y(1 + e^u)du + e^u dy - u e^u dy = 0$$

$$(u + u e^u + e^u - u e^u)dy + y(1 + e^u)du = 0$$

$$(u + e^u)dy + y(1 + e^u)du = 0$$

接下来就是大家最喜爱的**分离变量**环节：

$$\frac{1 + e^u}{u + e^u} du = -\frac{1}{y} dy$$

两边同时积分。这里又藏了一个很美的考点：**分子刚好是分母的导数**！$(u + e^u)' = 1 + e^u$。

所以左边积分直接出对数：

$$\ln|u + e^u| = -\ln|y| + C_1$$

（题目已知 $y>0$，所以可以去掉绝对值）

$$\ln(u + e^u) + \ln y = C_1$$

$$\ln(y(u + e^u)) = C_1$$

去掉对数符号，令 $C = e^{C_1}$：

$$y(u + e^u) = C$$

最后，把 $u = \frac{x}{y}$ 换回来：

$$y\left(\frac{x}{y} + e^{\frac{x}{y}}\right) = C$$

$$x + ye^{\frac{x}{y}} = C$$

这就是通解。思路非常连贯，只要认出 $\frac{x}{y}$ 并且敢于把 $x$ 和 $y$ 互换，后面全是水到渠成。

### 第二层考点：凑微分法（“魔法”秒杀路线）

如果你对微积分的“盘感”极好，这道题完全可以在 **3 行之内**秒杀。这也是出题人暗戳戳想考你的高级技巧。

我们把原方程直接强行展开，不去管什么 $\frac{x}{y}$，就硬拆：

$$dx + e^{\frac{x}{y}}dx + e^{\frac{x}{y}}dy - \frac{x}{y}e^{\frac{x}{y}}dy = 0$$

你看后面这一长串 $e^{\frac{x}{y}}dx + e^{\frac{x}{y}}dy - \frac{x}{y}e^{\frac{x}{y}}dy$，是不是感觉像某个东西求导展开后的残骸？

我们试着用乘积法则去逆推。它里面有 $e^{\frac{x}{y}}$，又有 $dx$ 和 $dy$，我们试着对 $ye^{\frac{x}{y}}$ 求一下全微分：

$$d(ye^{\frac{x}{y}}) = e^{\frac{x}{y}}dy + y \cdot d(e^{\frac{x}{y}})$$

$$= e^{\frac{x}{y}}dy + y \cdot e^{\frac{x}{y}} \cdot d(\frac{x}{y})$$

$$= e^{\frac{x}{y}}dy + y \cdot e^{\frac{x}{y}} \cdot \left(\frac{y dx - x dy}{y^2}\right)$$

$$= e^{\frac{x}{y}}dy + e^{\frac{x}{y}}dx - \frac{x}{y}e^{\frac{x}{y}}dy$$

**奇迹出现了！** 这刚好和我们展开后的后三项**一模一样**！

所以，原方程展开后，可以直接写成：

$$dx + d(ye^{\frac{x}{y}}) = 0$$

也就是：

$$d(x + ye^{\frac{x}{y}}) = 0$$

两边一积分，直接出答案：

$$x + ye^{\frac{x}{y}} = C$$

### 总结

- **看到 $\frac{y}{x}$：** 齐次方程，令 $y = ux$。
    
- **看到 $\frac{x}{y}$：** “反向”齐次方程，令 $x = uy$。
    
- **看到式子虽然乱，但指数/分式极其对称：** 试着拆开，看能不能用 $d(xy), d(\frac{x}{y}), d(e^{xy})$ 这类全微分公式强行凑出来。凑出来了就是秒杀
