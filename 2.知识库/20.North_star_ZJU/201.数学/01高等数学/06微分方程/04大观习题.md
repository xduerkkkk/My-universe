# 3 - 【】不是常规的指数，看你慌不慌
![[_attachments/image/04大观习题-1782220419707.jpeg]]
想考啥呢？

### 第一步：发现“秘密武器”——观察缺项

齐次方程的形式是：
$$y'' + p(x)y' = 0$$

仔细观察这个方程，你会发现：**它里面没有 $y$ 这一项（只有二阶导 $y''$ 和一阶导 $y'$）**。

### 第二步：顺藤摸瓜，“捡”出一个齐次特解

因为方程不含 $y$ 项，我们可以大胆地代入最简单的常数：**$y = 1$** 试试：
* 求导：$y' = 0$
* 再求导：$y'' = 0$

代入齐次方程左边：
$$y'' + p(x)y' = 0 + p(x) \cdot 0 = 0$$

等式完美成立！
这说明：不管 $p(x)$ 是什么复杂的函数，**常数 $y = 1$ 必定是该齐次方程的一个特解**。

---

### 第三步：两秒钟拼装通解

我们知道，二阶非齐次方程的通解结构为：
$$y = C_1 \cdot \text{【齐次特解1】} + C_2 \cdot \text{【齐次特解2】} + \text{【非齐次特解】}$$

现在，我们的拼图全部齐了：
* **齐次特解 1**：题目直接告诉了是 $x^{-3}$；
* **齐次特解 2**：我们刚才顺手“捡”到的 $1$；（由于 $\frac{x^{-3}}{1} \neq \text{常数}$，它们显然线性无关，可以作为基底）
* **非齐次特解**：题目直接给出了 $x^3$。

把它们代入通解公式，直接拼装：
$$y = C_1 x^{-3} + C_2 \cdot 1 + x^3$$

也就是：
$$y = C_1 x^{-3} + C_2 + x^3$$

# 13 【！图 2】

![[_attachments/image/04大观习题-1782394374751.jpeg]]
![[_attachments/image/04大观习题-1782394363211.jpeg]]


图 1 我做的过程和批注一样很巧妙得消到解图 2 不能像图 1 这样做吗？ 答案只是代入**完全可以！而且用你这种“结构分析法”来做图 2，不仅完全行得通，而且在数学逻辑上比答案给出的“强行代入法”更加优雅、高级，具有更强的通用性。**

我们完全套用图 1 的逻辑，来对图 2 进行一次完美的“降维打击”：

---

### 第一步：做差，找出齐次方程的解

已知非齐次方程的三个特解为：
$$y_1 = 1, \quad y_2 = e^{-x}, \quad y_3 = 2e^{-x}$$

根据“**两个非齐次特解之差是对应齐次方程的解**”：
* $y_3 - y_2 = 2e^{-x} - e^{-x} = e^{-x} \implies$ **$e^{-x}$ 是齐次解**。
* $y_3 - y_1 = 2e^{-x} - 1 \implies$ **$2e^{-x} - 1$ 是齐次解**。

---

### 第二步：线性组合，简化齐次方程的基底

由于齐次解的线性组合仍然是齐次解，我们将上面得到的两个齐次解进行组合：
$$\text{齐次解} = 2 \cdot (e^{-x}) - (2e^{-x} - 1) = 1$$

所以，**$1$（即 $e^{0x}$）也是该齐次方程的一个解**！

至此，我们非常漂亮地集齐了两个线性无关的齐次解：
* **$1$ （对应特征根 $r_1 = 0$）**
* **$e^{-x}$ （对应特征根 $r_2 = -1$）**

---

### 第三步：写出齐次方程（确定左端项）

既然特征根为 $r_1 = 0, \ r_2 = -1$，那么对应的特征方程为：
$$r(r + 1) = 0 \implies r^2 + r = 0$$

所以，该微分方程的**左端项**必定为：
$$y'' + y' = \dots$$

---

### 第四步：确定右端项 $f(x)$

设该方程为 $y'' + y' = f(x)$。
我们直接把任意一个已知特解（比如最简单的 $y_1 = 1$）代入左边：
$$f(x) = y_1'' + y_1' = (1)'' + (1)' = 0 + 0 = 0$$

所以右端项 $f(x) = 0$。

最终方程为：
$$y'' + y' = 0$$

---

### 为什么答案不用你这种方法，而是用“强行代入”？

主要是因为图 2 这道题给的三个特解（$1$、 $e^{-x}$、 $2e^{-x}$）实在是**太简单、太特殊**了。
* 答案的作者偷了懒，觉得直接设 $y'' + ay' + by = f(x)$ 然后把常数 $1$ 带进去能直接秒出 $b = f(x)$，所以才写了代入法。

但答案的这种“代入法”有一个**致命的局限性**：如果右端项 $f(x)$ 不是常数，而是一个复杂的函数（比如 $f(x) = x \sin x$），代入法会直接卡死。

而你掌握的这种**“结构做差法”是 100% 通用的**，无论题目出得多难，只要给出了非齐次的特解，用这套方法都能无往而不利。考研中非常推荐保留并熟练使用你的这一套思路！


# 14 新题型 -【】
![[_attachments/image/04大观习题-1782395505653.jpeg]]

![[_attachments/image/04大观习题-1782395515929.jpeg]]


做到这一步，我就设原方程 ay''+by'+cy = 0 把 x 和 x 方分别带进去，比对系数，只能得 abc 都是 0. 问题出在哪？
一、【直接答案】
$x^2y'' - 2xy' + 2y = (x^2 - 2x + 2)e^x$
（或写成 $y'' - \frac{2}{x}y' + \frac{2}{x^2}y = (1 - \frac{2}{x} + \frac{2}{x^2})e^x$）

二、【我的错因分析】
你凭空捏造了**“常系数”**这个条件。
题目只说了是“二阶线性非齐次微分方程”，其标准形式是 $y'' + p(x)y' + q(x)y = f(x)$，前面的系数 $p(x)$ 和 $q(x)$ 是关于 $x$ 的函数！
你设 $ay''+by'+cy = 0$，默认了 $a,b,c$ 是常数。在二阶常系数齐次方程中，如果解里含有 $x$ 和 $x^2$，意味着特征方程必然有三重根 $r=0$（对应的解是 $C_1 + C_2x + C_3x^2$），这至少是一个**三阶**微分方程（$y'''=0$）。二阶常系数微分方程根本装不下 $x$ 和 $x^2$ 这两个线性无关解。这就是为什么你比对系数只能得出 $a=b=c=0$ 的死胡同。

三、【考场思维链 (限时模拟)】
Step 1：抓取题眼，提取齐次解
利用非齐次解的性质：特解 - 特解 = 齐次解。
立刻得到两个线性无关的齐次解：$Y_1 = y_2 - y_1 = x$，$Y_2 = y_3 - y_1 = x^2$。

Step 2：反推齐次方程（两种方法，任选其一）
**常规法（待定系数代入）：**
设齐次方程为 $y'' + p(x)y' + q(x)y = 0$。
把 $x$ 代入：$0 + p(x)\cdot 1 + q(x)\cdot x = 0 \implies p(x) = -x \cdot q(x)$
把 $x^2$ 代入：$2 + p(x)\cdot 2x + q(x)\cdot x^2 = 0$
将上式代入下式：$2 + (-x \cdot q(x)) \cdot 2x + x^2 q(x) = 0 \implies 2 - x^2 q(x) = 0 \implies q(x) = \frac{2}{x^2}$。
进而 $p(x) = -\frac{2}{x}$。
得到齐次方程：$y'' - \frac{2}{x}y' + \frac{2}{x^2}y = 0$，化简为 $x^2y'' - 2xy' + 2y = 0$。

**秒杀法（行列式构造）：**
已知两个基础解 $y_1, y_2$，齐次方程可直接由行列式 $\begin{vmatrix} y & y_1 & y_2 \\ y' & y_1' & y_2' \\ y'' & y_1'' & y_2'' \end{vmatrix} = 0$ 写出。
$\begin{vmatrix} y & x & x^2 \\ y' & 1 & 2x \\ y'' & 0 & 2 \end{vmatrix} = y(2-0) - y'(2x-0) + y''(2x^2-x^2) = x^2y'' - 2xy' + 2y = 0$。

Step 3：关键动作（反求非齐次项 $f(x)$）
方程左边已经有了，设原方程为 $x^2y'' - 2xy' + 2y = f(x)$。
怎么求 $f(x)$？直接把已知的一个特解 $y_1 = e^x$ 扔进左边算出来即可！
$f(x) = x^2(e^x)'' - 2x(e^x)' + 2(e^x) = x^2e^x - 2xe^x + 2e^x = e^x(x^2 - 2x + 2)$。
拼装结束。

四、【严密逻辑推敲 (防杠指南)】
为什么已知两个线性无关解就能唯一确定一个二阶线性齐次方程（系数化为 1 的标准型）？
根据线性常微分方程理论，设方程为 $y'' + p(x)y' + q(x)y = 0$。将解 $Y_1, Y_2$ 代入，得到关于 $p(x), q(x)$ 的线性代数方程组：
$Y_1' p(x) + Y_1 q(x) = -Y_1''$
$Y_2' p(x) + Y_2 q(x) = -Y_2''$
由克莱姆法则（Cramer's Rule），其系数矩阵的行列式 $W(Y_1, Y_2) = Y_1 Y_2' - Y_2 Y_1'$ 正是朗斯基行列式。因为 $Y_1=x, Y_2=x^2$ 线性无关，且在 $x \neq 0$ 时 $W(x, x^2) = x(2x) - x^2(1) = x^2 \neq 0$，所以该方程组必然有唯一解 $p(x)$ 和 $q(x)$。
这保证了考场上通过代入法解 $p(x), q(x)$ 在底层逻辑上是绝对完备且唯一的。

五、【陷阱与触发器总结】
致命陷阱：看到“线性微分方程”直接脑补成“常系数线性微分方程”。考研题中如果系数是常数，命题人一定会明说“常系数”。没写这三个字，系数必然带 $x$。

思维触发器：
IF 给出多个特解求原微分方程，
THEN 肌肉记忆连招：**相减得齐次解 $\to$ 设 $y''+p(x)y'+q(x)y=0$ 代入解出 $p,q$（或直接用三阶行列式） $\to$ 将任意一个特解代回左侧求出右侧的 $f(x)$**。严禁假定系数为常数 $a, b, c$。

# 17  有界 -[ ]

![[_attachments/image/04大观习题-1782443343293.jpeg]]


一、【直接答案】
是的，通解公式积分的下限确实可以“随意写”，因为**改变下限等价于改变任意常数 $C$ 的取值**。但在这道题里，写成 $-\infty$ 绝不是随意的，而是为了**消灭无穷大**而量身定制的唯一解。

二、【我的错因分析】
你觉得“上下限可以随意写”，是因为你没有看穿**微积分基本定理与一阶线性微分方程通解公式的底层绑定关系**。
在通解公式 $y = e^{-\int P(x)dx} \left[ \int Q(x)e^{\int P(x)dx} dx + C \right]$ 中，里面那个变限积分的下限本来就是任意的一个常数 $a$。
由于 $\int_a^x = \int_b^x + \int_a^b$，其中 $\int_a^b$ 是个常数，它会被外面的 $+C$ 直接吸收掉。因此，你写下限为 $0$、下限为 $1$、或者下限为 $-\infty$，只要积分收敛，在**加了 $+C$ 的前提下**，它们表示的解空间是完全等价的。
但本题答案的鸡贼之处在于：它直接把下限选为 $-\infty$ 并令 $C=0$。这不是在“随便写”，而是在**反向推导出一个特定常数 $C$，使得函数在 $x \to -\infty$ 时不发生爆炸**。你被答案跳跃的逻辑蒙蔽了。

三、【考场思维链 (限时模拟)】
Step 1：写出常规通解，暴露危险项
老老实实写出通解（习惯性按下限为 0 写）：
$y(x) = e^{-x} \left[ \int_0^x e^t f(t) dt + C \right] = C e^{-x} + e^{-x} \int_0^x e^t f(t) dt$
题目要求这个解在整个实数轴 $\mathbf{R}$ 上有界。
立刻观察极限行为：当 $x \to +\infty$ 时，$e^{-x} \to 0$（安全）；**当 $x \to -\infty$ 时，$e^{-x} \to +\infty$（极度危险，可能导致无界）**。

Step 2：强行镇压无穷大（求出特定的 C）
为了不让 $y(x)$ 在 $x \to -\infty$ 时爆炸，中括号里面的那一坨必须趋于 $0$，去中和外面的 $+\infty$。
即必须满足：$\lim_{x \to -\infty} \left[ \int_0^x e^t f(t) dt + C \right] = 0$
解得：$C = -\int_0^{-\infty} e^t f(t) dt = \int_{-\infty}^0 e^t f(t) dt$。
（注：因为 $|f(t)| \le M$，所以 $\int_{-\infty}^0 e^t M dt = M$，该广义积分绝对收敛，这个 $C$ 是存在且合法的。）

Step 3：拼装备用（第一题得证）
把求出的特定 $C$ 代回原式：
$y(x) = e^{-x} \left[ \int_0^x e^t f(t) dt + \int_{-\infty}^0 e^t f(t) dt \right]$
根据积分区间可加性，直接拼成：
$y(x) = e^{-x} \int_{-\infty}^x e^t f(t) dt$。
这就是答案中那步“令 $C=0$ 且下限为 $-\infty$”的真实来历！最后加个绝对值不等式放缩，直接秒杀。

四、【严密逻辑推敲 (防杠指南)】
1. **通解下限的等价性证明**：
设解为 $y_1(x) = e^{-x}(\int_a^x e^t f(t) dt + C_1)$，换一个下限 $b$，解为 $y_2(x) = e^{-x}(\int_b^x e^t f(t) dt + C_2)$。
$y_1(x) = e^{-x}(\int_b^x e^t f(t) dt + \int_a^b e^t f(t) dt + C_1)$。
由于 $\int_a^b e^t f(t) dt$ 是常数，令 $C_2 = \int_a^b e^t f(t) dt + C_1$，则 $y_1 \equiv y_2$。所以下限确实可以随便取，只要 $C$ 是任意的。

2. **第一题有界性的严格证明**：
我们已经构造出特解 $y^*(x) = e^{-x} \int_{-\infty}^x e^t f(t) dt$。
对任意 $x \in \mathbf{R}$，取绝对值放缩：
$|y^*(x)| = \left| e^{-x} \int_{-\infty}^x e^t f(t) dt \right| \le e^{-x} \int_{-\infty}^x e^t |f(t)| dt$ （因为 $e^t > 0$，所以可以直接放进积分号）
由于题目已知 $f(x)$ 有界，即存在 $M>0$，使得 $|f(x)| \le M$。
继续放缩：
$\le e^{-x} \int_{-\infty}^x e^t \cdot M dt = M e^{-x} \left[ e^t \right]_{-\infty}^x = M e^{-x} (e^x - 0) = M$。
即对任意实数 $x$，都有 $|y^*(x)| \le M$。严格证明了该解有界。

五、【陷阱与触发器总结】
致命陷阱：
1. **照猫画虎乱定下限**：看到这道题的答案直接设 $-\infty$，以后遇到微分方程题一律把下限设为 $-\infty$ 或 $\infty$。如果外面配的是 $e^x$ 而不是 $e^{-x}$，积分 $\int_{-\infty}^x e^{-t}f(t) dt$ 就会发散，整个推导瞬间崩溃。
2. **逻辑倒置**：答案是“因为知道了需要用 $\int_{-\infty}^x$ 才能有界，所以故意令 $C=0$ 凑出这个形式”，而不是“只要令 $C=0$，它就恰好有界”。

思维触发器：
IF 求解**全实数轴 $\mathbf{R}$ 上的有界解/周期解**，
THEN 肌肉记忆：**立刻检查外侧指数函数在 $x \to +\infty$ 和 $x \to -\infty$ 哪一端会趋向无穷大**。如果 $x \to -\infty$ 时爆炸，利用常数 $C$ 强迫积分下限变为 $-\infty$；如果 $x \to +\infty$ 时爆炸，强迫积分下限变为 $+\infty$。这是微分方程中控制边界发散的唯一手段。

### 第一问实战：证明（I）

**方程**：$\frac{\text{d}x}{\text{d}t} + a(t)x = 0$，自变量 $t \in [0, +\infty)$。

#### 1. 写出带上下限的解
根据黄金法则，区间起点是 $0$，所以我们把积分下限设为 $0$，上限设为 $t$。
分离变量法可得：
$$\frac{\text{d}x}{x} = -a(t)\text{d}t$$
两边同时从 $0$ 积到 $t$：
$$\int_{x(0)}^{x(t)} \frac{1}{u}\text{d}u = -\int_0^t a(s)\text{d}s$$
$$\ln|x(t)| - \ln|x(0)| = -\int_0^t a(s)\text{d}s$$
化简得到通解：
$$x(t) = C e^{-\int_0^t a(s)\text{d}s} \quad (\text{其中 } C = x(0) \text{ 是任意常数})$$

#### 2. 开始证明（充要条件 $\iff$）

* **充分性（$\impliedby$）**：已知 $\int_0^{+\infty} a(t)\text{d}t$ 发散。
  因为 $a(t) \ge 0$，所以其积分随着 $t \to +\infty$ 只能趋于 $+\infty$：
  $$\lim_{t \to +\infty} \int_0^t a(s)\text{d}s = +\infty$$
  那么代入解的表达式：
  $$\lim_{t \to +\infty} x(t) = \lim_{t \to +\infty} C e^{-\int_0^t a(s)\text{d}s} = C \cdot e^{-\infty} = 0$$
  充分性证毕！

* **必要性（$\implies$）**：已知每一个解都满足 $\lim_{t \to +\infty} x(t) = 0$。
  我们取一个非零解（即 $C \neq 0$）。要让下式成立：
  $$\lim_{t \to +\infty} C e^{-\int_0^t a(s)\text{d}s} = 0$$
  因为 $C \neq 0$，所以指数部分必须趋于 $-\infty$，也就是说：
  $$\lim_{t \to +\infty} \int_0^t a(s)\text{d}s = +\infty$$
  这就说明广义积分 $\int_0^{+\infty} a(t)\text{d}t$ 必须发散。必要性证毕！

---

### 第二问实战：证明（II）

**方程**：$\frac{\text{d}x}{\text{d}t} + ax = f(t)$，其中 $a > 0$，$f(t)$ 连续且有界。

#### 1. 写出带上下限的解
我们背过的非齐次线性微分方程通解公式是：
$$x(t) = e^{-\int P\text{d}t} \left[ \int Q e^{\int P\text{d}t}\text{d}t + C \right]$$
这里 $P(t) = a$（常数），$Q(t) = f(t)$。同样地，区间是 $[0, +\infty)$，**我们把所有积分的下限都写成 $0$**：
$$x(t) = e^{-\int_0^t a\text{d}s} \left[ \int_0^t f(s) e^{\int_0^s a\text{d}\tau}\text{d}s + C \right]$$

因为 $a$ 是常数，里面的积分非常好算：
$$\int_0^t a\text{d}s = at, \quad \int_0^s a\text{d}\tau = as$$
代入进去，通解就变成了极为干净、没有任何模糊积分号的形式：
$$x(t) = e^{-at} \left[ \int_0^t f(s) e^{as}\text{d}s + C \right] = C e^{-at} + e^{-at}\int_0^t f(s) e^{as}\text{d}s$$

#### 2. 开始证明有界性
我们要证明无论 $C$ 取什么值，$x(t)$ 在 $t \ge 0$ 时都是有界的。
因为 $f(t)$ 有界，设 $|f(t)| \le M$。我们对 $x(t)$ 取绝对值放大：

$$|x(t)| \le |C|e^{-at} + e^{-at}\int_0^t |f(s)| e^{as}\text{d}s$$
$$|x(t)| \le |C|e^{-at} + M e^{-at}\int_0^t e^{as}\text{d}s$$

计算这个定积分：$\int_0^t e^{as}\text{d}s = \frac{e^{at} - 1}{a}$。代回上式：
$$|x(t)| \le |C|e^{-at} + M e^{-at} \cdot \frac{e^{at} - 1}{a}$$
$$|x(t)| \le |C|e^{-at} + \frac{M}{a}\left(1 - e^{-at}\right)$$

因为 $a > 0$ 且 $t \ge 0$，所以指数项 $e^{-at}$ 是一个介于 $0$ 到 $1$ 之间的数（$0 < e^{-at} \le 1$）。
因此：
* $|C|e^{-at} \le |C|$
* $\frac{M}{a}\left(1 - e^{-at}\right) \le \frac{M}{a}$

最终我们得到：
$$|x(t)| \le |C| + \frac{M}{a}$$
因为 $|C| + \frac{M}{a}$ 是一个固定的常数，这说明所有的解 $x(t)$ 在 $[0, +\infty)$ 上都是有界的。证明完毕！

---

### 📌 终极总结

以后做这类题，千万不要直接用带有不确定常数的不定积分号 $\int$。请在动笔的第一步就完成两件事：
1. **看定义域起点**：如果是 $[0, +\infty)$，所有积分下限写 $0$。
2. **改写变量**：上限写 $t$（或 $x$），积分内部的自变量改成 $s$（或 $\tau$）。
