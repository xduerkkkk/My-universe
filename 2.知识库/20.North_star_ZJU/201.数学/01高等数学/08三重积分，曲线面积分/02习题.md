你的直觉 $z = \sqrt{5 - y^2}$ 在**二维平面**里是完全正确的。但是，这道题的积分区域不再是一块平面的铁皮，而是一个**三维立体的空间区域**。

产生 $x^2$ 的根本原因，在于题目中的这句话：**“绕 $z$ 轴旋转一周所得的空间区域”**。

下面为你拆解这个由二维变三维的过程：

### 1. 旋转前的二维状态

在 $yOz$ 平面上，原本的曲线方程确实是 $y^2 + z^2 = 5$。

如果题目只让你在这个二维面上求面积，那么上限毫无疑问就是 $z = \sqrt{5 - y^2}$。此时，这个世界上根本没有 $x$ 轴。

### 2. 旋转过程的几何本质

想象一下，把 $yOz$ 平面上的这条曲线绕着 $z$ 轴像圆规一样转一圈，它就变成了一个**三维的曲面（球面）**。

在这个旋转过程中，曲面上任意一点的特征是：

- **高度 $z$ 保持不变**。
    
- **该点到 $z$ 轴的水平距离，始终等于最初在平面上的距离**。
    

在原来的二维平面里，一个点到 $z$ 轴的距离就是 $\vert{}y\vert{}$（距离的平方是 $y^2$）。

但是，一旦转到了三维空间里，这个点有了 $x$ 坐标和 $y$ 坐标。在三维空间中，任意一点 $(x, y, z)$ 到 $z$ 轴的水平距离变成了 $\sqrt{x^2 + y^2}$（距离的平方是 $x^2 + y^2$）。

### 3. 求解旋转曲面的代数法则

为了保证旋转出来的三维面上，所有点到 $z$ 轴的距离与原来保持一致，数学上有一个通用的代数替换法则：

> **绕某个轴旋转，就保留原方程中该轴的变量不动，将另一个变量的平方替换为“水平距离的平方（即 $x^2 + y^2$）”。**

- 本题是绕 $z$ 轴旋转。
    
- 原二维方程：$y^2 + z^2 = 5$
    
- **替换操作**：保留 $z^2$，把 $y^2$ 强行替换为 $(x^2 + y^2)$。
    
- 得到三维旋转曲面方程：$(x^2 + y^2) + z^2 = 5$
    

现在，你要在这个三维方程里把 $z$ 解出来，作为积分的上限：

$$z^2 = 5 - (x^2 + y^2)$$

$$z^2 = 5 - x^2 - y^2$$

因为题目限制了 $z \ge 0$（上半部分），所以开根号取正：

$$z = \sqrt{5 - x^2 - y^2}$$

### 总结

如果只有 $\sqrt{5 - y^2}$，它在三维空间里表示的是一个**无限延伸的抛物柱面**，而不是一个封闭的球体“盖子”。只有同时包含了 $x^2$ 和 $y^2$，它才在 $X$ 和 $Y$ 两个方向上都受到约束，形成了一个完美的穹顶（球面）。

# 3  二重积分对称性平移，不熟悉了
![[_attachments/image/02习题-1783827350133.jpeg]]

这两处处理方法的本质都是在解决**截面 $D_z$ 的圆心不在原点**这一难点。

在固定高度 $z$ 时，由方程 $x^2 + (y-z)^2 \le (1-z)^2$ 可知，截面 $D_z$ 是一个半径为 $R = 1-z$，圆心位于 **$(0, z)$** 的圆。因为圆心发生了偏移，直接使用常规极坐标会非常复杂。

以下为你详细拆解这两种处理方法的底层逻辑：

### 方法一：印刷答案的“极坐标平移法”

印刷答案采用的是代数上的**变量代换**。既然圆心在 $(0, z)$，那么我们就把极坐标的极点强行平移到 $(0, z)$ 这个位置。

1. **设定平移极坐标**：
    
    令 $x = r\cos\theta$，**$y - z = r\sin\theta$**。
    
    稍微移项，就得到了书上写的：$y = z + r\sin\theta$。
    
2. **代入被积函数与积分限**：
    
    此时，极径 $r$ 的范围就是从圆心到边界：$0 \le r \le 1-z$。
    
    角度 $\theta$ 是完整的一圈：$0 \le \theta \le 2\pi$。
    
    被积函数 $y$ 变成了 $(z + r\sin\theta)$，面积元素 $dxdy$ 变成了 $r\,drd\theta$。
    
3. **计算过程的消元**：
    
    内层积分变成了：$\int_{0}^{2\pi} d\theta \int_{0}^{1-z} (z + r\sin\theta) r \,dr$。
    
    仔细观察含有 $\sin\theta$ 的那一项：$\int_{0}^{2\pi} r^2 \sin\theta \,d\theta$。由于正弦函数在完整周期 $[0, 2\pi]$ 上的积分为 $0$，这一项直接消掉了。最终只剩下与 $z$ 相关的项。这种方法逻辑严密，是通法。
    

### 方法二：手写笔记的“配凑对称性法”

手写笔记采用的是几何与物理上的**奇偶对称性**，这种方法计算量极小，非常巧妙。

1. **核心思路（凑项）**：
    
    手写笔记在计算 $\iint_{D_z} y \,dxdy$ 时，故意把被积函数 $y$ 拆成了两部分：**$y = (y-z) + z$**。
    
    为什么要减一个 $z$ 又加一个 $z$？是为了**强行去凑边界方程里的 $(y-z)$**。
    
2. **拆分积分**：
    
    原积分被拆分为两块：
    
    $$\iint_{D_z} y \,dxdy = \iint_{D_z} (y-z) \,dxdy + \iint_{D_z} z \,dxdy$$
    
3. **利用对称性消灭第一项**：
    
    对于 $\iint_{D_z} (y-z) \,dxdy$：
    
    积分区域 $D_z$ 的方程是 $x^2 + (y-z)^2 \le (1-z)^2$。你可以把 $(y-z)$ 想象成一个新的变量（比如设 $v = y-z$），此时积分区域变成了一个**关于 $v=0$（即 $y=z$ 这条线）完全对称的标准圆**。
    
    被积函数 $(y-z)$ 本身是一个**奇函数**。在对称区间上对奇函数积分，结果必然为 $0$。所以这一项直接划掉，也就是笔记中标注为 $0$ 的原因。
    
4. **化简第二项（提取常数）**：
    
    对于剩下的 $\iint_{D_z} z \,dxdy$：
    
    因为当前是在求二重积分（关于 $x, y$ 积分），所以 **$z$ 必须被视作常数**，可以直接提到积分号外面：
    
    $$z \iint_{D_z} dxdy$$
    
    而 $\iint_{D_z} dxdy$ 的几何意义就是**截面 $D_z$ 的面积**。我们已知这是一个半径为 $(1-z)$ 的圆，所以它的面积就是 $\pi(1-z)^2$。
    
    最终，内层二重积分直接化简为：$z \cdot \pi(1-z)^2$。
    

### 总结对比

印刷答案的方法侧重于**代数硬算**，通过平移坐标系并利用三角函数的周期积分消去复杂项；而手写笔记侧重于**几何洞察**，通过“凑”出关于圆心对称的奇函数项，利用对称性将其归零，直接利用圆的面积公式得出结果。在考场上，强烈建议掌握手写笔记的方法，能大幅降低计算失误率。

# 9 投影转换法原理

![[_attachments/image/02习题-1783995307663.jpeg]]



手写笔记使用的是我们之前讲过的**转换投影法（直接代公式口诀）**，这是考场上拿分的最快手段。而下方印刷体的官方答案，并没有直接抛出那个口诀公式，而是**从第二类曲面积分的最底层定义出发，一步步推导出了你手写部分的那个式子**。

可以说，官方答案向你展示了那个“加负号、求偏导”口诀的**严谨数学来源**。下面我为你详细拆解官方答案的这几步推导逻辑：

### 第一步：寻找指向“下侧”的法向量

官方答案没有死记公式的正负号，而是老老实实去求曲面的法向量。

已知曲面方程为 $z = \sqrt{x^2+y^2}$。官方将其改写为隐函数形式：

$$F(x, y, z) = \sqrt{x^2+y^2} - z = 0$$

曲面的法向量 $\mathbf{n}$ 就是该隐函数的梯度（即分别对 $x, y, z$ 求偏导）：

$$\mathbf{n} = (F'_x, F'_y, F'_z) = \left( \frac{x}{\sqrt{x^2+y^2}}, \frac{y}{\sqrt{x^2+y^2}}, -1 \right)$$

因为已知 $z = \sqrt{x^2+y^2}$，所以官方答案把分母替换成了 $z$：

$$\mathbf{n} = \left( \frac{x}{z}, \frac{y}{z}, -1 \right)$$

**关键验证**：这个法向量的 $z$ 分量是 **$-1$**。因为 $-1 < 0$，说明这个法向量是指向下方（与 $z$ 轴正向成钝角）的，完美符合题目要求的“**下侧**”。

### 第二步：建立方向余弦的比例关系（解答图片中的核心式子）

在数学分析中，第二类曲面积分可以转化为第一类曲面积分（对面积的积分），公式为：

$$\iint_{\Sigma} P\mathrm{d}y\mathrm{d}z + Q\mathrm{d}z\mathrm{d}x + R\mathrm{d}x\mathrm{d}y = \iint_{\Sigma} (P\cos\alpha + Q\cos\beta + R\cos\gamma) \mathrm{d}S$$

其中，$\cos\alpha, \cos\beta, \cos\gamma$ 是法向量 $\mathbf{n}$ 的**方向余弦**。

既然方向余弦代表法向量的方向，它们必然与法向量的三个分量成正比。这就是官方答案给出那个连等式的原因：

$$\frac{\cos\alpha}{\frac{x}{z}} = \frac{\cos\beta}{\frac{y}{z}} = \frac{\cos\gamma}{-1}$$

### 第三步：乾坤大挪移（替换被积函数）

通过上面的比例关系，官方答案做了一个极妙的代换。我们可以用 $\cos\gamma$ 把 $\cos\alpha$ 和 $\cos\beta$ 表达出来：

- $\cos\alpha = -\frac{x}{z} \cos\gamma$
    
- $\cos\beta = -\frac{y}{z} \cos\gamma$
    

将其代入到积分式子中，提取公因式 $\cos\gamma$：

$$P\cos\alpha + Q\cos\beta + R\cos\gamma = \left[ P\left(-\frac{x}{z}\right) + Q\left(-\frac{y}{z}\right) + R \right] \cos\gamma$$

**注意观察**：这里的 $\frac{x}{z}$ 其实就是 $\frac{\partial z}{\partial x}$，$\frac{y}{z}$ 就是 $\frac{\partial z}{\partial y}$。所以方括号里的内容，已经变成了你手写笔记里的核心部分！

### 第四步：面积投影与最终的符号（万剑归宗）

现在积分变成了：

$$\iint_{\Sigma} \left[ P\left(-\frac{\partial z}{\partial x}\right) + Q\left(-\frac{\partial z}{\partial y}\right) + R \right] \cos\gamma \mathrm{d}S$$

接下来是把空间曲面微元 $\mathrm{d}S$ 投影到 $xOy$ 平面上的二重积分微元 $\mathrm{d}x\mathrm{d}y$。

几何投影关系为：**$\mathrm{d}x\mathrm{d}y = \vert{}\cos\gamma\vert{} \mathrm{d}S$**。

这里是最容易出错的地方，也是官方答案严谨的体现：

因为题目取的是**下侧**，法向量朝下，所以法向量与 $z$ 轴的夹角 $\gamma$ 是钝角，这意味着 **$\cos\gamma < 0$**。

由于 $\cos\gamma$ 是负数，那么绝对值 $\vert{}\cos\gamma\vert{} = -\cos\gamma$。

因此，投影关系变成了：$\mathrm{d}x\mathrm{d}y = -\cos\gamma \mathrm{d}S$，移项即得到：

$$\cos\gamma \mathrm{d}S = -\mathrm{d}x\mathrm{d}y$$

把这个结果代回上一步的积分式：

$$\iint_{D_{xy}} \left[ P\left(-\frac{\partial z}{\partial x}\right) + Q\left(-\frac{\partial z}{\partial y}\right) + R \right] (-\mathrm{d}x\mathrm{d}y)$$

将最外层的负号提取到积分号外面：

$$-\iint_{D_{xy}} \left[ P\left(-\frac{\partial z}{\partial x}\right) + Q\left(-\frac{\partial z}{\partial y}\right) + R \right] \mathrm{d}x\mathrm{d}y$$

**结论**：经过这严密的四步推导，官方答案最终推导出的式子，与你手写笔记中直接套用口诀写出的式子（外加一个负号代表下侧，内部带偏导数）**一模一样**。官方展示了“原理”，而你手写的口诀是抽离出来的“计算工具”。

**破局的关键在于：投影到 $yz$ 平面（或者 $xz$ 平面）。** 

因为题目说“从 $x$ 轴正向看去”，这恰好就是我们看 $yz$ 平面的标准视角！下面我用你图 3 里“消元降维”的思路，一步步带你解这道题，你会发现它比图 3 的例题还要简单，连第一型曲面积分都不用转化。

---

### 解法：消元降维 + $yz$ 平面格林公式

**第一步：消元降维（把 $x$ 换掉）**
由平面方程 $y = x\tan\theta$，因为 $\theta \neq 0$，我们可以得出 $x = y\cot\theta$。
所以，微元关系是：**$dx = \cot\theta dy$**。

把它们代入原曲线积分 $I = \oint_{\Gamma} (y-z)dx + (z-x)dy + (x-y)dz$ 中，消去 $x$ 和 $dx$：
$$I = \oint_{\Gamma_{yz}} (y-z)(\cot\theta dy) + (z - y\cot\theta)dy + (y\cot\theta - y)dz$$
整理一下合并同类项（把 $dy$ 放在一起）：
$$I = \oint_{\Gamma_{yz}} [y\cot\theta - z\cot\theta + z - y\cot\theta] dy + (y\cot\theta - y) dz$$
$$I = \oint_{\Gamma_{yz}} (z - z\cot\theta) dy + (y\cot\theta - y) dz$$

**第二步：确定投影区域（算面积）**
把 $x = y\cot\theta$ 代入球面方程 $x^2 + y^2 + z^2 = a^2$ 中：
$$(y\cot\theta)^2 + y^2 + z^2 = a^2$$
$$y^2(\cot^2\theta + 1) + z^2 = a^2$$
因为 $1 + \cot^2\theta = \csc^2\theta = \frac{1}{\sin^2\theta}$，所以方程化为：
$$\frac{y^2}{\sin^2\theta} + z^2 = a^2$$
这就是曲线 $\Gamma$ 在 $yz$ 平面上的投影。可以看出，它是一个**椭圆**。我们设它围成的区域为 $D_{yz}$。
根据椭圆面积公式 $S = \pi \times \text{长半轴} \times \text{短半轴}$：
这个椭圆在 $y$ 方向的半轴长是 $a|\sin\theta|$，在 $z$ 方向的半轴长是 $a$。
所以投影区域 $D_{yz}$ 的面积：**$S_{D} = \pi \cdot a|\sin\theta| \cdot a = \pi a^2 |\sin\theta|$**

**第三步：用格林公式（注意方向！）**
现在我们有了一个 $yz$ 平面上的线积分：$\oint_{\Gamma_{yz}} P(y,z) dy + Q(y,z) dz$
其中 $P = z - z\cot\theta$， $Q = y\cot\theta - y$。

算一下偏导：
$\frac{\partial Q}{\partial y} = \cot\theta - 1$
$\frac{\partial P}{\partial z} = 1 - \cot\theta$
所以 $\frac{\partial Q}{\partial y} - \frac{\partial P}{\partial z} = (\cot\theta - 1) - (1 - \cot\theta) = 2\cot\theta - 2$。

**最关键的一步来了：判断正负号。**
题目说“从 $x$ 轴正向看去，$\Gamma$ 为顺时针方向”。
当我们把曲线投影到 $yz$ 平面时，我们的视角恰好就是站在 $x$ 轴正半轴往回看（右边是 $y$ 轴，上面是 $z$ 轴）。因此，投影在 $yz$ 平面上的曲线 $\Gamma_{yz}$ 也是**顺时针**的。
而格林公式 $\oint = \iint$ 是建立在逆时针（正向）的基础上的。如果是顺时针，必须要在二重积分前面**加一个负号**。

所以：
$$I = - \iint_{D_{yz}} \left( \frac{\partial Q}{\partial y} - \frac{\partial P}{\partial z} \right) dydz$$
$$I = - \iint_{D_{yz}} (2\cot\theta - 2) dydz$$

**第四步：积分计算（比你图例 3 简单多了！）**
你看，被积函数 $(2\cot\theta - 2)$ 里面既没有 $y$ 也没有 $z$，它完全是一个**常数**！
这就是你图 3 里写的“死皮赖脸化为常数”，只不过这里是纯天然的常数。
我们直接把它提出来，剩下的积分就是面积：
$$I = -(2\cot\theta - 2) \iint_{D_{yz}} 1 dydz = (2 - 2\cot\theta) \cdot S_{D}$$
把刚才算的面积 $S_{D} = \pi a^2 |\sin\theta|$ 代入：
$$I(\theta) = (2 - 2\frac{\cos\theta}{\sin\theta}) \cdot \pi a^2 |\sin\theta|$$

**第五步：分情况找最大值**
我们把绝对值拆开看看：
*   **当 $0 < \theta < \frac{\pi}{2}$ 时**：$\sin\theta > 0$，所以 $|\sin\theta| = \sin\theta$
    $I(\theta) = (2 - 2\frac{\cos\theta}{\sin\theta}) \cdot \pi a^2 \sin\theta = 2\pi a^2(\sin\theta - \cos\theta)$
*   **当 $-\frac{\pi}{2} < \theta < 0$ 时**：$\sin\theta < 0$，所以 $|\sin\theta| = -\sin\theta$
    $I(\theta) = (2 - 2\frac{\cos\theta}{\sin\theta}) \cdot \pi a^2 (-\sin\theta) = -2\pi a^2(\sin\theta - \cos\theta) = 2\pi a^2(\cos\theta - \sin\theta)$

接下来就是高中三角函数的求最值了：
*   对于 $2\pi a^2(\sin\theta - \cos\theta) = 2\pi a^2 \sqrt{2}\sin(\theta - \frac{\pi}{4})$，在 $(0, \frac{\pi}{2})$ 范围内，最大趋近于 $2\pi a^2$。
*   对于 $2\pi a^2(\cos\theta - \sin\theta) = 2\pi a^2 \sqrt{2}\cos(\theta + \frac{\pi}{4})$，在 $(-\frac{\pi}{2}, 0)$ 范围内，当 $\theta = -\frac{\pi}{4}$ 时，取得最大值 **$2\sqrt{2}\pi a^2$**。

因为 $2\sqrt{2} > 2$，所以最大值就是 **$2\sqrt{2}\pi a^2$**。
