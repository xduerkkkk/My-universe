## ## 步骤一：明确 $D_1$ 的积分范围

第一象限的小三角形 $D_1$ 边界为 $y=0$，$x=\frac{\pi}{2}$ 轴以及 $y=x$。

- 如果先对 $y$ 积，范围是：$0 \le x \le \frac{\pi}{2}, 0 \le y \le x$。
    
- 为了能凑微分积掉 $x$，我们需要**交换积分次序**，改为先对 $x$ 积。
    
- 交换后的范围为：**$0 \le y \le \frac{\pi}{2}, y \le x \le \frac{\pi}{2}$**。
    

因此，目标积分为：

$$I = 2 \iint_{D_1} f(x,y) \, dxdy = 2 \int_{0}^{\frac{\pi}{2}} dy \int_{y}^{\frac{\pi}{2}} \sin x \cos x \sqrt{\cos^2 x + \sin^2 y} \, dx$$

## ## 步骤二：计算内层关于 $x$ 的积分

我们对内层积分进行凑微分。令 $u = \cos^2 x + \sin^2 y$，则 $du = -2 \sin x \cos x \, dx$，即 $\sin x \cos x \, dx = -\frac{1}{2} du$。

### 1. 严格转换积分上下限：

- 当 $x = y$（下限）时：$u = \cos^2 y + \sin^2 y = \mathbf{1}$
    
- 当 $x = \frac{\pi}{2}$（上限）时：$u = \cos^2\frac{\pi}{2} + \sin^2 y = \mathbf{\sin^2 y}$
    

### 2. 计算内层结果：

$$\int_{1}^{\sin^2 y} \sqrt{u} \left(-\frac{1}{2}\right) du = \frac{1}{2} \int_{\sin^2 y}^{1} u^{\frac{1}{2}} du = \frac{1}{2} \cdot \left[ \frac{2}{3} u^{\frac{3}{2}} \right]_{\sin^2 y}^{1} = \frac{1}{3} \left( 1 - (\sin^2 y)^{\frac{3}{2}} \right)$$

### 3. 关键的绝对值脱钩：

因为在 $D_1$ 区域中，**$y$ 的范围被严格限制在 $[0, \frac{\pi}{2}]$ 之间**。

在这个一象限区间内，$\sin y \ge 0$，所以 $(\sin^2 y)^{\frac{3}{2}} = |\sin y|^3 = \sin^3 y$。

所以内层积分的最终简纯结果为：

$$\frac{1}{3} (1 - \sin^3 y)$$

## ## 步骤三：计算外层关于 $y$ 的积分

将内层结果带回，前面有你推导出的 **$2$ 倍** 系数：

$$I = 2 \cdot \int_{0}^{\frac{\pi}{2}} \frac{1}{3} (1 - \sin^3 y) \, dy = \frac{2}{3} \int_{0}^{\frac{\pi}{2}} (1 - \sin^3 y) \, dy$$

利用华里士公式（点火公式）可得 $\int_{0}^{\frac{\pi}{2}} \sin^3 y \, dy = \frac{2}{3}$：

$$I = \frac{2}{3} \left( [y]_{0}^{\frac{\pi}{2}} - \frac{2}{3} \right) = \frac{2}{3} \left( \frac{\pi}{2} - \frac{2}{3} \right) = \frac{\pi}{3} - \frac{4}{9}$$

一、【直接答案】
$\frac{4}{3}$

二、【我的错因分析】
你对该化简产生疑惑的根本原因在于：**对“绝对值符号 = 偶函数 + 对称域”的联动机制缺乏绝对的考场反射。** 初始坐标系下的区域对称性及被积函数的偶极性已验证。你没有看透，这里的化简仅仅是剥离绝对值外壳的必然操作——利用双轴对称性将积分压缩至第一象限，从而换取丢掉绝对值符号的计算特权。

三、【考场思维链 (限时模拟)】
**Step 1：抓取题眼**
看到积分域 $D$ 包含 $\sqrt{|x|} + \sqrt{|y|}$，被积函数包含 $2\sqrt{|x|} + 3\sqrt{|y|}$，立刻条件反射：全盘绝对值，必含四象限完美对称。

**Step 2：快速试错/化简**
区域 $D$ 与被积函数的偶偶结合判定完毕。抛弃分块积分的冗余想法。

**Step 3：关键动作**
直接将域收缩至第一象限 $D_1$，系数乘 4，强行褪去绝对值。
提取 $4 \iint_{D_1} (2\sqrt{x} + 3\sqrt{y}) dxdy$。
利用 $D_1$ 内部关于 $y=x$ 对称的隐藏属性，合并系数直接跃进：
$I = 4 \times 5 \iint_{D_1} \sqrt{x} dxdy = 20 \times \frac{1}{15} = \frac{4}{3}$。结束战斗。

四、【严密逻辑推敲 (防杠指南)】
二重积分双轴对称性的底层依据：
若积分域 $D$ 关于 $x$ 轴、$y$ 轴均对称，且被积函数满足 $f(-x, y) = f(x, -y) = f(-x, -y) = f(x, y)$，则绝对成立 $\iint_D f(x,y)dxdy = 4\iint_{D_1} f(x,y)dxdy$。
本题中，$f(x,y) = 2\sqrt{|x|} + 3\sqrt{|y|}$，显然带有双偶性。进入 $D_1$（第一象限）后，因 $x \ge 0, y \ge 0$，恒有 $|x|=x, |y|=y$。代数形式的严格等价代换就此完成，无需顾虑后续计算的符号突变。

五、【陷阱与触发器总结】
**致命陷阱：**
在草稿纸上画图时，把 $D_1$ 的边界 $\sqrt{x} + \sqrt{y} = 1$ 错当成四分之一圆弧去套极坐标，导致后续积分表达式彻底失控。

**思维触发器：**
**IF** 看到积分域和被积函数的变量全部被套上 $|x|$ 和 $|y|$，
**THEN** 肌肉记忆立刻执行：直接抹掉所有绝对值符号，将积分域写为 $x \ge 0, y \ge 0$ 的第一象限子域，并给整个积分式乘以 4。

# 16，二重积分就是个细心
![[_attachments/image/大观-1783394112635.jpeg]]

一、【直接答案】
$\frac{2}{3} - \frac{\pi}{2}$

二、【我的错因分析】
你算错的根本原因在于：**你找错了图形的几何中心，平移的“靶点”完全偏离。**
你令 $u = x-2$，仅仅是因为积分上限是 2。但在考场上，平移的唯一目的是**凑出图形的对称轴**。
下边界 $y = \sqrt{2x-x^2}$ 两边平方化简是 $(x-1)^2 + y^2 = 1 (y \ge 0)$，这是一个圆心在 $(1,0)$ 的上半圆。积分区间 $x \in [0, 2]$ 恰好关于 $x=1$ 完美对称。
你平移到 $x-2$，直接把原本完美的对称图形破坏成了偏心图形，这不仅没有降维，反而徒增了极其复杂的代数计算，走入了死胡同。

三、【考场思维链 (限时模拟)】
**Step 1：抓取题眼（透视区域）**
看到 $y = \sqrt{2x-x^2}$，立刻配方：$(x-1)^2 + y^2 = 1$。
大脑瞬间勾勒出区域 $D$：外轮廓是一个 $x \in [0,2], y \in [0,2]$ 的正方形，底部被挖去了一个以 $(1,0)$ 为圆心、半径为 $1$ 的上半圆。
这是典型的“复杂区域”，立刻触发**“割补法”**。设正方形区域为 $R$，半圆区域为 $D_1$，则 $I = \iint_R - \iint_{D_1}$。

**Step 2：快速试错/化简（极速降维）**
分别盯住两块极其规则的区域，执行**“找中心，强平移”**。
1. **看正方形 $R$**：中心在 $(1,1)$。
强行凑对称：$x-y = (x-1) - (y-1)$。
$\iint_R [(x-1) - (y-1)] dxdy = 0 - 0 = 0$（正方形关于 $x=1$ 和 $y=1$ 均对称，奇函数直接斩杀）。
得出绝对结论：正方形上的积分为 $0$。

**Step 3：关键动作（击杀半圆）**
2. **看半圆 $D_1$**：圆心在 $(1,0)$，对称轴为 $x=1$。
此时立刻执行正确的平移：令 $u = x-1, v = y$。
半圆上的积分 $\iint_{D_1} (x-y) dxdy = \iint_{D_1} [(x-1) + 1 - y] dxdy$。
盯住 $(x-1)$：奇函数，直接划掉！
只剩 $\iint_{D_1} (1-y) dxdy = \iint_{D_1} 1 dxdy - \iint_{D_1} y dxdy$。
第一项是半圆面积：$\frac{\pi}{2}$。
第二项是半圆的极坐标重心积分：令 $x-1=r\cos\theta, y=r\sin\theta$。
$\int_0^\pi d\theta \int_0^1 r\sin\theta \cdot r dr = \int_0^\pi \sin\theta d\theta \cdot [\frac{r^3}{3}]_0^1 = 2 \times \frac{1}{3} = \frac{2}{3}$。
所以半圆部分积分为：$\frac{\pi}{2} - \frac{2}{3}$。

汇总：$I = \iint_R - \iint_{D_1} = 0 - (\frac{\pi}{2} - \frac{2}{3}) = \frac{2}{3} - \frac{\pi}{2}$。2 分钟结束战斗。

四、【严密逻辑推敲 (防杠指南)】
如果你非要直接在原区域 $D$ 上做平移计算，数学上的严谨过程如下：
令 $u = x-1, v = y$。
原积分区域 $D$ 转化为 $D^*$：$-1 \le u \le 1$，$\sqrt{1-u^2} \le v \le 2$。
$I = \iint_{D^*} (u + 1 - v) dudv$。
由于区域 $D^*$ 关于 $v$ 轴（即 $u=0$）对称，且 $u$ 是奇函数，$\iint_{D^*} u dudv = 0$。
剩下的部分化为累次积分：
$I = \int_{-1}^1 du \int_{\sqrt{1-u^2}}^2 (1-v) dv$
内层积分：$\int_{\sqrt{1-u^2}}^2 (1-v) dv = [v - \frac{1}{2}v^2]_{\sqrt{1-u^2}}^2 = (2 - 2) - (\sqrt{1-u^2} - \frac{1-u^2}{2}) = -\sqrt{1-u^2} + \frac{1-u^2}{2}$。
外层积分：
第一部分 $\int_{-1}^1 -\sqrt{1-u^2} du$，这就是底边为 $2$ 的半圆面积的相反数，即 $-\frac{\pi}{2}$。
第二部分 $\int_{-1}^1 \frac{1}{2}(1-u^2) du = 2 \times \frac{1}{2} \int_0^1 (1-u^2) du = [u - \frac{u^3}{3}]_0^1 = \frac{2}{3}$。
两者相加，严格等于 $\frac{2}{3} - \frac{\pi}{2}$。
可以看出，不用割补法，代数计算的复杂度和出错率依然会陡增。

五、【陷阱与触发器总结】
**致命陷阱：**
1. 看到边界 $x=2$ 就去令 $u=x-2$。平移不是为了把积分限变成 0，而是为了**把图形的几何对称轴移到坐标轴上**。
2. 在由“直线+圆弧”围成的非标准区域中强行做二重积分。

**思维触发器：**
**IF** 看到积分区域是由外围直角多边形（如矩形）和内部圆弧组成的“缺角/挖洞”图形，
**THEN** 肌肉记忆立刻执行：**放弃直接积分，启动割补法。** 强行将大矩形和半圆分开算，并通过 $(x-x_0)$ 平移强行制造奇函数进行秒杀。
