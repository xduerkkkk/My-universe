1. **心形线 (Cardioid)** —— 本题主角
    
    - **极坐标方程：** $r = a(1 \pm \cos\theta)$ 或 $r = a(1 \pm \sin\theta)$ $(a>0)$
        
    - **特征：** 像一个有点凹陷的心形或者屁股。
        
    - **方向口诀：** “正负决定开口，余弦左右，正弦上下”。
        
        - $r = a(1 + \cos\theta)$：开口向左，重心偏右（尖点在原点，最远点在 x 轴正半轴）。
            
        - $r = a(1 - \cos\theta)$：开口向右，重心偏左。
            
        - $r = a(1 + \sin\theta)$：开口向下，重心偏上。
            
2. **双纽线 (Lemniscate)**
    
    - **直角坐标方程：** $(x^2+y^2)^2 = a^2(x^2-y^2)$
        
    - **极坐标方程：** $r^2 = a^2\cos2\theta$
        
    - **特征：** 像一个横着的数字“8”或者无穷大符号 $\infty$。记住它只在横着的方向有图像（因为 $\cos2\theta$ 必须 $\ge 0$）。
        
3. **星形线 (Astroid)**
    
    - **直角坐标方程：** $x^{\frac{2}{3}} + y^{\frac{2}{3}} = a^{\frac{2}{3}}$
        
    - **参数方程：** $x = a\cos^3t, \quad y = a\sin^3t$
        
    - **特征：** 像一个内凹的四角星，全对称。求弧长和面积极其爱考。
        
4. **摆线 (Cycloid)**
    
    - **参数方程：** $x = a(t - \sin t), \quad y = a(1 - \cos t)$
        
    - **特征：** 像一排连绵的拱门。通常只考第一拱（$t$ 从 $0$ 到 $2\pi$）。
        
5. **阿基米德螺线**
    
    - **极坐标方程：** $r = a\theta$
        
    - **特征：** 像蚊香一样一圈圈往外绕。
        
6. **玫瑰线 (Rose Curve)**
    
    - **极坐标方程：** $r = a\sin(2\theta)$（四瓣玫瑰） 或 $r = a\sin(3\theta)$（三瓣玫瑰）。

### 回到你发的这道题 (利用图形秒杀一半计算)

题目求 $r \le 1$ 与 $r \le 1+\cos\theta$ 所围区域的形心坐标。

如果你认识图形，这题的思路就会无比清晰：

1. **画图与对称性：**
    
    - $r=1$ 是一个圆心在原点、半径为 1 的圆。
        
    - $r=1+\cos\theta$ 是一个尖点在原点，向右鼓起的心形线。
        
    - 这两个图形都**关于 x 轴上下对称**！
        
    - **神仙结论：** 既然积分区域关于 x 轴对称，密度均匀，那么它的形心一定在 x 轴上！所以，纵坐标 **$\bar{y} = 0$**。你只需要算 $\bar{x}$ 就行了，直接省去一半工作量！
        
2. **找交点（定积分限）：**
    
    联立两个方程：$1 = 1+\cos\theta \Rightarrow \cos\theta = 0$。
    
    在 $[-\pi, \pi]$ 范围内，解得交点极角为 $\theta = \frac{\pi}{2}$ 和 $\theta = -\frac{\pi}{2}$。
    
3. **拆分区域：**
    
    在这个交点角度之内（右半边），边界是谁？在交点角度之外（左半边），边界又是谁？通过图形一目了然。
