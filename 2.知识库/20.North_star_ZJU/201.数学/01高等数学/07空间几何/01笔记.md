# 曲面


## 旋转曲面
**核心考点：旋转曲面的生成法则。** 
法则口诀：**绕谁旋转，谁保持不变；将另一个变量替换为 $\pm\sqrt{剩余两变量平方和}$。

我们先用最常考的情境来解释：**假设在 $yOz$ 坐标面上有一条曲线（母线），它的方程是 $f(y, z) = 0$。现在让它绕着 $z$ 轴旋转。**

让我们闭上眼睛想象一下，在这条曲线上随便抓取一个点，记作 **$P_0(0, y_0, z_0)$**。当这条曲线绕着 $z$ 轴旋转时，这个点 $P_0$ 也会跟着绕 $z$ 轴转圈。

在它转圈形成一个圆的过程中，有两个“绝对不变量”：

1. **高度不变（绕谁，谁不变）：** 它在 $z$ 轴方向上的高度始终死死钉在 $z_0$ 上。所以旋转后生成的曲面上任意一点 $P(x, y, z)$，其高度 **$z = z_0$**。
    
2. **到旋转轴的距离不变（半径恒定）：** 刚开始时，点 $P_0(0, y_0, z_0)$ 到 $z$ 轴的距离就是它的 $y$ 坐标的绝对值，即 $|y_0|$。旋转到空间任意位置 $P(x, y, z)$ 后，这个点到 $z$ 轴的距离是 $\sqrt{x^2 + y^2}$。因为是同一个圆的半径，所以必须有 **$\sqrt{x^2 + y^2} = |y_0|$**。
    

稍微变个形，脱掉绝对值，就变成了：**$y_0 = \pm\sqrt{x^2 + y^2}$**。

**代数替换的终极一步：**

最开始我们选的点 $P_0(0, y_0, z_0)$ 是在这条曲线上的，所以它满足原方程：$f(y_0, z_0) = 0$。

现在，我们把找到的两个不变量关系代进去：

- 把 $z_0$ 替换成 $z$
    
- 把 $y_0$ 替换成 $\pm\sqrt{x^2 + y^2}$
    

原方程就变成了：**$f(\pm\sqrt{x^2 + y^2}, z) = 0$**。这就是口诀“绕谁谁不变，另一个替换为平方和开根号”的绝对真理来源。



### 如果原式子中 $x, y, z$ 都有怎么办？（万能消参法）

这是一个非常核心的进阶问题。

口诀只适用于**母线原本就躺在某个坐标面内**（比如原本方程里只有 $x$ 和 $y$，或者只有 $y$ 和 $z$）的“降维打击”场景。

如果原式子中 $x,y,z$ 都有，说明我们要旋转的是一条**空间曲线**。空间曲线通常由两个方程联立给出（即两个曲面的交线）：

$$\begin{cases} F(x, y, z) = 0 \\ G(x, y, z) = 0 \end{cases}$$

此时，**绝对禁止直接使用口诀**，而是要退回到我们刚才推导口诀的本质逻辑——**“万能消参法”**。

**通用解题模板（以绕 $z$ 轴旋转为例）：**

1. **设点：** 设原空间曲线上有一动点 $P_0(x_0, y_0, z_0)$，旋转后生成的曲面上有一动点 $P(x, y, z)$。
    
2. **列原方程：** 因为 $P_0$ 在原曲线上，所以：
    
    $$\begin{cases} F(x_0, y_0, z_0) = 0 \\ G(x_0, y_0, z_0) = 0 \end{cases}$$
    
3. **列旋转不变量条件：** 绕 $z$ 轴转，高度不变，到 $z$ 轴距离不变：
    
    $$\begin{cases} z_0 = z \\ x_0^2 + y_0^2 = x^2 + y^2 \end{cases}$$
    
4. **终极目标：** 你现在手里有上面这 4 个方程。你的目标是通过代数变形，**把带下标的 $x_0, y_0, z_0$ 彻底消灭掉**，只留下 $x, y, z$ 的方程。剩下的那个干干净净的方程，就是旋转曲面的方程！
    

### 举个经典的硬核例子

**题目：** 将空间直线 $L$: $\begin{cases} x = 1 \\ y = z \end{cases}$ 绕 $z$ 轴旋转一周，求生成的旋转曲面方程。

**解答过程：**

1. 设直线上点 $P_0(x_0, y_0, z_0)$，旋转面上点为 $P(x, y, z)$。
    
2. 列原方程：$\begin{cases} x_0 = 1 \\ y_0 = z_0 \end{cases}$
    
3. 列旋转条件（绕 $z$ 轴）：$\begin{cases} z_0 = z \\ x_0^2 + y_0^2 = x^2 + y^2 \end{cases}$
    
4. 开始消灭 $x_0, y_0, z_0$：
    
    - 将 $z_0 = z$ 代入原方程，得到 **$y_0 = z$**。
        
    - 现在我们知道 $x_0 = 1$ 且 $y_0 = z$。把它们塞进距离等式 $x_0^2 + y_0^2 = x^2 + y^2$ 中。
        
    - 得到：**$1^2 + z^2 = x^2 + y^2$**。
        

稍微移项整理，最终方程为：**$x^2 + y^2 - z^2 = 1$**。


# 方向导数和梯度

，**只有当函数可微时，向量 $(f_x, f_y)$ 才有资格被称为“梯度”**。


### 为什么可微才能用“方向导数公式法”？

方向导数的**公式法**长这样：

$$\frac{\partial f}{\partial \mathbf{l}} = f_x \cos\alpha + f_y \cos\beta$$

这个公式的本质是**线性叠加**（Linear Superposition）。它默认了一个极其强硬的前提：**任意方向的斜率，都可以由 X 方向的斜率和 Y 方向的斜率按比例拼凑出来。**

- **什么时候可以拼凑？** 只有当这个点附近是一个完美的“平缓斜坡”（切平面）时，无论你朝哪个方向走，高度的变化都可以精确地分解为 X 轴投影的贡献和 Y 轴投影的贡献。这就是“可微”提供的保证。可微时的全微分公式 $\Delta z \approx f_x \Delta x + f_y \Delta y$ 正是这种线性叠加的数学表达。
    
- **不可微时会发生什么？** 如果函数不可微，说明该点附近不是一个平坦的切平面（比如存在褶皱、断层或尖点）。此时，X 轴和 Y 轴方向的偏导数可能完好无损，但你在东北方向迈出一步，高度的变化规律完全不服从 X 和 Y 方向的线性组合。这时候如果强行套用公式，算出来的结果是完全错误的。
    

### 三、不可微时，为什么必须用“定义法”？它到底是什么？

当函数不可微，公式法彻底失效时，我们只能回到最原始的武器：**定义法**。

方向导数的定义式是一个**单侧极限**：

$$\lim_{t \to 0^+} \frac{f(x_0 + t\cos\alpha, y_0 + t\cos\beta) - f(x_0, y_0)}{t}$$

**定义法的底层逻辑：降维打击。**

不管这个 3D 曲面有多么扭曲、多皱、多么不可微，定义法的操作都是：

1. 站在点 $(x_0, y_0)$。
    
2. 严格沿着给定的方向（由角度 $\alpha, \beta$ 决定）切一刀。
    
3. 这“一刀”切下去，复杂的 3D 曲面立刻变成了一条 2D 空间里的普通曲线。
    
4. 然后，在这个单一的路径上，计算一元函数的导数（也就是这条线上该点的切线斜率）。
