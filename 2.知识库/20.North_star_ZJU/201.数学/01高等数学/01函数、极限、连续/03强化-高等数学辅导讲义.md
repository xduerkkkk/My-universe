## 奇偶性

在函数可导的基础下，奇函数的导函数是偶函数，偶函数的导函数是奇函数。

反过来呢，在函数连续的情况下，奇函数的原函数都是偶函数（原函数不止一个）
偶函数的原函数，只有+C 的 C=0 才是奇函数。

**奇函数在 $x=0$ 处有定义，它必须过原点 $(0,0)$。** 设 $f(x)$ 是偶函数，它的原函数族是 $F(x) = \int_0^x f(t)dt + C$。为了让 $F(x)$ 成为奇函数，它必须满足 $F(0) = 0$。代入计算：$F(0) = \int_0^0 f(t)dt + C = 0 + C = C$。因此，**为了满足奇函数必须过原点的几何性质，$C$ 必须等于 $0$**。




> **不过原函数的表述，和变上限积分表的表述的区别是？**
 
如果你用不定积分（原函数）表述，偶函数 $f(x)$ 的原函数是 $\int f(x) dx = F(x) + C$。为了挑出那个唯一的奇函数，你必须手动去寻找合适的 $C$ 让 $F(0) + C = 0$。

但如果你用**变上限积分**表述，事情就变得非常优雅：

只要下限取 $0$，即 $\Phi(x) = \int_{0}^{x} f(t) dt$，那么利用积分区间的对称性：

$$ \Phi(-x) = \int_{0}^{-x} f(t) dt $$

令 $u = -t$，$du = -dt$，由于 $f(x)$ 是偶函数（$f(-u) = f(u)$），可得：

$$ \int_{0}^{-x} f(t) dt = \int_{0}^{x} f(-u) (-du) = -\int_{0}^{x} f(u) du = -\Phi(x) $$

所以，$\Phi(x) = \int_{0}^{x} f(t) dt$ **直接就是**那个唯一的奇函数。

## 周期性

可导的周期函数，其导函数为周期函数
反过来不一定，原因**不是**那个“C”，+C 代表上下平移，想象上下平移是否破坏性质，**不破坏周期性质！**

周期函数的原函数（当提到原函数，就默认此时的周期函数连续），不一定是周期函数。

这里需要仔细推导。
设变限积分，F (x)=f (t) 在 0 到 x 的积分，写 F (x+T)，最后可推 F (x) 是周期函数的充要条件是 f (x) 在一个周期内积分为 0.
![[_attachments/image/03强化-高等数学辅导讲义-1779593680375.jpeg]]



但这个推导能推出周期函数的原函数是周期函数的充要条件是 f (x) 在一个周期内积分为 0 吗？

可以，因为任意一个原函数都可以写成这种形式：

$$ F(x) = \int_0^x f(t) dt + C $$
这是核心。
