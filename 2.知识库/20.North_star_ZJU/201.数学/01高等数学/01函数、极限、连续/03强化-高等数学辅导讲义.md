## 单调性
导数大于 0，能推严格单调增；严格单调增，能推导数大于等于 0；
导数大于等于 0 ，与单调不减（不严格单调增）互相推

严格单调和导数的关系：
一点导数大于 0，$f'(x_0) > 0$，意味着在 $x_0$ 附近，右边的点比它高，左边的点比它低。
但不意味**在 $x_0$ 点的某邻域内严格单调增加。** 这叫做“区间单调性”。！


导函数的介质性
**核心难点辨析：** 为什么不能直接用连续函数的介值定理？

答：因为已知条件只给了“$f(x)$ 可导”，**并没有说 $f'(x)$ 连续**。遇到不连续的导函数，基础介值定理失效，必须通过“原函数的极值点特性”来证明。

### 第一部分：先证推论（寻找导数为 $0$ 的点）

**【推论内容】**

设 $f(x)$ 在区间 $[a, b]$ 上可导，且端点导数异号（即 $f'_+(a) \cdot f'_-(b) < 0$），则至少存在一点 $\xi \in (a, b)$，使得 $f'(\xi) = 0$。

**【证明思路：极值点处导数为零（费马引理）】**

1. 因为 $f(x)$ 在 $[a, b]$ 上可导，所以必定在 $[a, b]$ 上连续。
    
2. 根据闭区间连续函数性质，**$f(x)$ 在 $[a, b]$ 上必有最大值 $M$ 和最小值 $m$**。
    
3. 不妨设 $f'_+(a) > 0$ 且 $f'_-(b) < 0$（一头向上走，一头向下走）：
    
    - 因为 $f'_+(a) > 0$（起点处的趋势是上升的），所以在 $a$ 的右侧附近，函数值必然大于 $f(a)$。因此，$f(a)$ 绝对不可能是整个区间的最大值 $M$。
        
    - 因为 $f'_-(b) < 0$（终点处的趋势也是从上面降下来的），所以在 $b$ 的左侧附近，函数值必然大于 $f(b)$。因此，$f(b)$ 也绝对不可能是最大值 $M$。
        
4. 既然最大值 $M$ 不在端点 $a$ 处，也不在端点 $b$ 处，那它**必定在开区间 $(a, b)$ 内部的某一点 $\xi$ 处取得**。
    
5. 根据费马引理：内部的极值点，只要可导，其导数必为 0。
    
    故存在 $\xi \in (a, b)$，使得 $f'(\xi) = 0$。推论得证。
    

### 第二部分：再证定理（寻找导数为 $\mu$ 的点）

**【定理内容】**

设 $f(x)$ 在区间 $[a, b]$ 上可导，$\mu$ 为介于 $f'_+(a)$ 与 $f'_-(b)$ 之间的任何值，则至少存在一点 $\xi \in (a, b)$，使得 $f'(\xi) = \mu$。

**【证明思路：引入“参考直线”，转化为求导数为 0 的问题】**

1. **构造辅助函数（相对距离法）：**
    
    令 $F(x) = f(x) - \mu x$。
    
    _(几何意义：考察曲线 $f(x)$ 与斜率为 $\mu$ 的直线 $y=\mu x$ 之间的距离差)_
    
2. **验证新函数的端点导数：**
    
    求导得 $F'(x) = f'(x) - \mu$。
    
    分别计算左右端点的导数：
    
    - $F'_+(a) = f'_+(a) - \mu$
        
    - $F'_-(b) = f'_-(b) - \mu$
        
3. **利用已知条件判定符号：**
    
    因为 $\mu$ 介于 $f'_+(a)$ 与 $f'_-(b)$ 之间。
    
    不妨设 $f'_+(a) < \mu < f'_-(b)$。
    
    则必有：
    
    - $F'_+(a) = f'_+(a) - \mu < 0$
        
    - $F'_-(b) = f'_-(b) - \mu > 0$
        
        得出结论：$F'_+(a) \cdot F'_-(b) < 0$（新函数的端点导数异号）。
        
4. **调用推论：**
    
    由第一部分的推论可知，必然存在一点 $\xi \in (a, b)$，使得 $F'(\xi) = 0$。
    
5. **得出最终结论：**
    
    $F'(\xi) = f'(\xi) - \mu = 0$
    
    即 $f'(\xi) = \mu$。定理得证！

导数连续的推理，导数有界的推论


## 奇偶性

在函数可导的基础下，奇函数的导函数是偶函数，偶函数的导函数是奇函数。

反过来呢，在函数连续的情况下，奇函数的原函数都是偶函数（原函数不止一个）
偶函数的原函数，只有+C 的 C=0 才是奇函数。

**奇函数在 $x=0$ 处有定义，它必须过原点 $(0,0)$。** 设 $f(x)$ 是偶函数，它的原函数族是 $F(x) = \int_0^x f(t)dt + C$。为了让 $F(x)$ 成为奇函数，它必须满足 $F(0) = 0$。代入计算：$F(0) = \int_0^0 f(t)dt + C = 0 + C = C$。因此，**为了满足奇函数必须过原点的几何性质，$C$ 必须等于 $0$**。




> **不过原函数的表述，和变上限积分表的表述的区别是？**
 
如果你用不定积分（原函数）表述，偶函数 $f(x)$ 的原函数是 $\int f(x) dx = F(x) + C$。为了挑出那个唯一的奇函数，你必须手动去寻找合适的 $C$ 让 $F(0) + C = 0$。

但如果你用**变上限积分**表述，事情就变得非常优雅：

只要下限取 $0$，即 $\Phi(x) = \int_{0}^{x} f(t) dt$，那么利用积分区间的对称性：

$$ \Phi(-x) = \int_{0}^{-x} f(t) dt $$

令 $u = -t$，$du = -dt$，由于 $f(x)$ 是偶函数（$f(-u) = f(u)$），可得：

$$ \int_{0}^{-x} f(t) dt = \int_{0}^{x} f(-u) (-du) = -\int_{0}^{x} f(u) du = -\Phi(x) $$

所以，$\Phi(x) = \int_{0}^{x} f(t) dt$ **直接就是**那个唯一的奇函数。

## 周期性

## 有界
闭区间连续推闭区间有界，
开区间连续+端点极限值存在，推开区间有界

![[_attachments/image/03强化-高等数学辅导讲义-1779627281153.jpeg]]

 导函数有界 $\implies$ 原函数有界（真相：限速能限制你跑多远吗？）

**已知条件：** 导数有界，意味着“你被限速了”（比如最高速度不能超过 $120\text{ km/h}$），或者说这座山坡的坡度永远不能超过某个特定的角度（比如 45 度）。

**结论一：如果在无限区间 $(-\infty, +\infty)$ 上 —— 绝对推不出原函数有界！**

- **直觉画面：** 虽然你被限速了，不能开得太快，但是如果你有**无限的时间**（无限区间），你一直以 $120\text{ km/h}$ 的速度往前开，你最终能到达宇宙的边缘吗？当然能！你的总里程（原函数）依然会飞向无穷大。
    
- **经典反例：** $f(x) = x$。它的导数 $f'(x) = 1$（极其完美的有界，速度永远是 1）。但是 $f(x)$ 在无限区间上海拔是无界的，一条直线斜着插向无限高。
    

**结论二：如果在有限区间 $(a, b)$ 上 —— 绝对能推断出原函数有界！**

- **直觉画面：** 你的最高速度是 $120\text{ km/h}$（导数有界），并且你**最多只能开 2 个小时**（区间有限）。就算你一秒钟都不休息，油门踩到底，你最多也就跑 $240\text{ km}$。你的活动范围绝对被死死锁在了一个特定的半径内。
    
- **几何画面：** 山坡的坡度不超过 45 度，且山底的水平宽度只有 $100$ 米。那这座山撑死也就 $100$ 米高。它不可能长成直入云霄的无界形态。

## 数列极限
![[_attachments/image/03强化-高等数学辅导讲义-1779679188702.jpeg]]
数列极限要注意的地方是，n 趋于无穷时的极限，有前有限项无关。


### 最值
数列如果发散，不一定有最值，因为每一下一项都可能创造新“最值”，如-1n 次方乘 n 
对于收敛数列，最大值最小值至少有一个存在，
具体判别为

设 $\lim_{n \to \infty} x_n = a$。判别的核心只看一件事：**数列的前有限项，有没有冲破极限 $a$ 这个海平面？**

 

- **法则 A（冲破天花板）：** 只要存在某一项 $x_k > a$，则数列**必有最大值**。
    
- **法则 B（击穿地板）：** 只要存在某一项 $x_k < a$，则数列**必有最小值**。
    

基于这两块基石，收敛数列的所有情况可以直接分为以下 **4 种绝杀类型**：

类型一：单向仰望型（只能从下方逼近）

- **特征：** 所有的 $x_n < a$ （例如 $x_n = 2 - \frac{1}{n}$，极限是 $2$）。
    
- **判别：** 因为永远无法达到 $a$，所以**无最大值**（永远在破纪录）；但因为所有项都小于 $a$（满足法则 B），所以**必有最小值**（起点那一项往往就是最小的）。
    
 类型二：单向俯视型（只能从上方逼近）

- **特征：** 所有的 $x_n > a$ （例如 $x_n = 2 + \frac{1}{n}$，极限是 $2$）。
    
- **判别：** 因为一直在往下跌落逼近 $a$，所以**无最小值**；但因为所有项都大于 $a$（满足法则 A），所以**必有最大值**（起点往往就是最大的）。
    
 类型三：反复横跳型（震荡逼近）

- **特征：** 既有 $x_n > a$，又有 $x_n < a$ （例如 $x_n = 2 + \frac{(-1)^n}{n}$）。
    
- **判别：** 既冲破过天花板，又击穿过地板（同时满足法则 A 和 B）。所以**最大值和最小值都存在！** 它们必定隐藏在前面震荡幅度最大的那几次当中。
    
类型四：彻底躺平型（常数数列）

- **特征：** 所有的 $x_n = a$ （例如 $1, 1, 1\dots$）。
    
- **判别：** 这是唯一的特例。虽然它没有严格大于或小于 $a$，但根据定义，**最大值和最小值都存在，且都等于 $a$。**

## 极限计算

变上限积分的等价无穷小：


定理原话：如果当 $x \to 0$ 时，$f(x) \sim g(x)$（连续），那么：

$$\int_0^x f(t)dt \sim \int_0^x g(t)dt$$


- **场景：** 比如让你求 $\int_0^x \ln(1+t)dt$ 在 $x \to 0$ 时的等价无穷小。
    
- **动作：** 别去算什么分部积分！直接盯着里面的 $\ln(1+t)$。
    
- **替换：** 因为 $\ln(1+t) \sim t$，所以：
    
    $$\int_0^x \ln(1+t)dt \sim \int_0^x t dt = \frac{1}{2}x^2$$
    
    就这么简单！一个恶心的积分，瞬间变成了一个极其简单的多项式 $\frac{1}{2}x^2$。
