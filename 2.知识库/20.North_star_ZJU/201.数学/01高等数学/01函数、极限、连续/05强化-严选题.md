
# 1 数列，捏造反例
![[_attachments/image/04强化-严选题，880拓展-1779677207891.jpeg]]

我直接塞给你**两个“专门用来打脸”的数列模型**。以后遇到这种题，直接套这两个模型去撞击选项：

1. **“交错开关”模型：** $\{1, 0, 1, 0, \dots\}$。它没有极限，也不趋于无穷，专门用来制造“乘积为 0”的假象。
    
2. **“跷跷板”模型：** $x_n = n$ (越来越大)，$y_n = \frac{1}{n}$ (越来越小)。专门用来制造“乘积是个常数（有界）”的假象。

带着这两个武器，我们来逐个击破：

 (A) 选项打脸测试

**原话：** 若 $\lim_{n \to \infty} x_n y_n = 0$，则必有 $\lim_{n \to \infty} x_n = 0$ 或 $\lim_{n \to \infty} y_n = 0$。

- **召唤“交错开关”模型：**
    
    设 $x_n = \{1, 0, 1, 0, 1, 0, \dots\}$
    
    设 $y_n = \{0, 1, 0, 1, 0, 1, \dots\}$
    
- **看乘积：** 对应项相乘，永远是 $1 \times 0$ 或 $0 \times 1$。所以乘积数列 $x_n y_n = \{0, 0, 0, 0, \dots\}$。它的极限完美等于 $0$。条件满足。
    
- **看结论：** $x_n$ 的极限是 $0$ 吗？不是，它在 $0$ 和 $1$ 之间反复横跳，极限根本**不存在**！$y_n$ 同理。
    
- **结论：** (A) 被打脸，淘汰。
    
    _(直觉：两个人轮流上班，公司永远有人在。但你不能说“其中一个人永远在上班”。)_
    

 (B) 选项打脸测试

**原话：** 若 $\lim_{n \to \infty} x_n y_n = \infty$，则必有 $\lim_{n \to \infty} x_n = \infty$ 或 $\lim_{n \to \infty} y_n = \infty$。

- **稍微改装一下“交错开关”模型：** 把 $1$ 换成 $n$。
    
    设 $x_n = \{1, n, 1, n, 1, n, \dots\}$
    
    设 $y_n = \{n, 1, n, 1, n, 1, \dots\}$
    
- **看乘积：** 对应项相乘，$x_n y_n = \{n, n, n, n, \dots\}$。随着 $n$ 变大，这个乘积的极限肯定是 $\infty$。条件满足。
    
- **看结论：** $x_n$ 趋于 $\infty$ 吗？不是！趋于 $\infty$ 的定义是“最终永远比任何数都大”。但 $x_n$ 每隔一步就会掉回 $1$（比如第 100 项是 $100$，第 101 项又变成了 $1$）。所以它极限不存在，并不趋于 $\infty$。
    
- **结论：** (B) 被打脸，淘汰。
    

 (C) 选项打脸测试

**原话：** 若 $x_n y_n$ 有界，则必有 $x_n$ 与 $y_n$ 都有界。

- **召唤“跷跷板”模型：**
    
    设 $x_n = n$
    
    设 $y_n = \frac{1}{n}$
    
- **看乘积：** $x_n y_n = n \times \frac{1}{n} = 1$。乘积永远是 $1$，绝对被死死关在盒子里（有界）。条件满足。
    
- **看结论：** $x_n = n$ 有界吗？显然没有，它冲向了正无穷。
    
- **结论：** (C) 被打脸，淘汰。
    

(D) 为什么它是对的？（提供一个绝佳的几何直觉）

只剩下 (D) 了，它是正确答案。

**原话：** 若 $x_n y_n$ 无界，则必有 $x_n$ 无界或 $y_n$ 无界。

我们不玩枯燥的代数，直接用**几何画面**来秒杀它：

把 $x_n$ 看作一个矩形的**长**，把 $y_n$ 看作矩形的**宽**。

那么 $x_n y_n$ 就是这个矩形的**面积**。

- **题目条件：“面积无界”** $\implies$ 意味着这个矩形的面积在不断膨胀，大到连宇宙都装不下。
    
- **现在反过来想（反证法）：** 如果长（$x_n$）和宽（$y_n$）**都有界**（被关在盒子里）会怎样？
    
    假设长永远不超过 $10$ 米，宽永远不超过 $5$ 米。
    
    那这个矩形的面积撑死了也就 $10 \times 5 = 50$ 平方米。它怎么可能膨胀到宇宙都装不下呢？！
    
- **结论：** 既然面积能膨胀到无限大（无界），那必然是它的**长**或者**宽**（或者两者一起），突破了牢笼，伸向了无限远。
    

所以，面积无界 $\implies$ 至少有一条边无界。

这就是 (D) 选项的物理真理！


<font color="#ff0000">主要记住，数列中，无界不一定是无穷，也有可能是震荡</font>

### 命题 (1)、(2)、(3)：死于“分母爆炸”

你看这三个式子，它们都有一个共同的致命特征：**$\varphi(x)$ 跑到了分母上**（命题 2 的指数 $1/\varphi(x)$ 也是分母）。

- **命题 (1)**：分母是 $\varphi(x)$
    
- **命题 (2)**：分母是 $\varphi(x)$
    
- **命题 (3)**：导数定义的替换，分母也是 $\varphi(x)$
    

**【一击毙命的反例】：**

如果我直接让 **$\varphi(x) = 0$**（常数数列/函数，极限显然也是 0，完全符合题意）。

你把 $\varphi(x) = 0$ 代入前三个式子看看：

- (1) 变成了 $\frac{\sin 0}{0}$
    
- (2) 变成了 $(1+0)^{\frac{1}{0}}$
    
- (3) 变成了 $\frac{f(x_0) - f(x_0)}{0}$
    

发现了吗？**分母直接变成 0 了！** 在数学里，分母为 0 是死罪，连定义域都没有，式子本身都没有意义，还谈什么极限等于几？

**【更高级的神经病反例】：**

就算不让它一直等于 0，让它等于我们之前见识过的那个“疯狂踩雷”的内层函数：**$\varphi(x) = x \sin \frac{1}{x}$**。

当 $x \to 0$ 时，这个 $\varphi(x)$ 会无数次地等于 0。只要它无限次地等于 0，前三个命题的分母就会无限次地爆炸，极限根本**不存在**！

> **补丁**：要想让 (1)(2)(3) 正确，题干必须加上 6 个保命大字：**“且 $\varphi(x) \neq 0$”**（在 $x \to 0$ 的去心邻域内）。

### 命题 (4)：死于“复合函数的陷阱”

这个命题最能唬人。

**原话：** 若 $\lim_{u \to 0} f(u) = A$，则 $\lim_{x \to 0} f(\varphi(x)) = A$。

**【直觉盲区】：**

你觉得 $x \to 0$ 时 $\varphi(x) \to 0$。所以外面那层函数就相当于 $f(u)$ 里 $u \to 0$，那结果不就是 $A$ 吗？

**【致命漏洞】：**

极限 $\lim_{u \to 0} f(u) = A$ 是一个“去心”的概念。它只承诺了当 $u$ **靠近但不等于 0** 的时候，函数值趋于 $A$。**它根本不管 $f(0)$ 到底等于几！**

**【一击毙命的反例】：**

想象一个“断头台”函数 $f(u)$：

- 当 $u \neq 0$ 时，$f(u) = 0$
    
- 当 $u = 0$ 时，$f(0) = 100$
    
    显然，$\lim_{u \to 0} f(u) = 0$ （所以 $A = 0$）。
    

现在，我们让内层函数 $\varphi(x) = 0$（常数）。

我们来算左边：$f(\varphi(x)) = f(0) = 100$。

所以，$\lim_{x \to 0} f(\varphi(x)) = \lim_{x \to 0} 100 = 100$。

它等于 $A$ (也就是 0) 吗？根本不等于！

因为内层函数 $\varphi(x)$ 太调皮了，它没有乖乖地“逼近 0”，而是**直接踩在了 0 上面**。结果刚好触发了 $f(u)$ 在 0 那个点上的异常值（100）。

> **补丁**：要想让 (4) 正确，必须满足以下两个条件**之一**：
> 
> 1. $\varphi(x) \neq 0$ （不准踩雷）
>     
> 2. 外层函数 $f(u)$ 在 $u=0$ 处**连续** （这样 $f(0)$ 就刚好等于 $A$，踩雷也不怕）。

# 4 错用中值定理

![[_attachments/image/05强化-严选题-1780278062773.jpeg]]

### 案发现场复盘：中值定理的“死胡同”

你要处理的核心部分是：$\lim_{x \to 0} \frac{\int_0^x f(t) dt}{x^2}$

**第一步：发动积分中值定理（操作正确）**

你令 $\int_0^x f(t) dt = f(\xi) \cdot x$，其中 $\xi$ 是介于 $0$ 和 $x$ 之间的一个点（$0 < \xi < x$）。

把它代入原式，极限变成了：

$$\lim_{x \to 0} \frac{f(\xi) \cdot x}{x^2} = \lim_{x \to 0} \frac{f(\xi)}{x}$$

**第二步：试图利用已知条件（死亡陷阱开始）**

已知 $f(0)=0, f'(0)=2$，所以根据导数定义，你知道当自变量趋于 $0$ 时，$\lim \frac{f(\text{变量})}{\text{变量}} = 2$。

为了凑出这个形式，你给式子乘除一个 $\xi$：

$$\lim_{x \to 0} \frac{f(\xi)}{\xi} \cdot \frac{\xi}{x}$$

- 第一部分：因为 $x \to 0$，被夹在中间的 $\xi$ 也必然趋于 $0$。所以 $\lim_{\xi \to 0} \frac{f(\xi)}{\xi} = 2$。这毫无问题。
    
- **致命的第二部分：$\lim_{x \to 0} \frac{\xi}{x}$ 等于多少？？？**
    

### 为什么你算不下去（或算错）了？

中值定理只告诉了你：**$\xi$ 在 $0$ 和 $x$ 之间**。

它**绝对没有**告诉你 $\xi$ 到底在哪个具体位置！

随着 $x$ 的缩小，$\frac{\xi}{x}$ 这个比例到底趋于 $\frac{1}{2}$、$\frac{1}{3}$ 还是 $\frac{3}{4}$？**你根本不知道！**

- **常见的错觉（可能是你算错的原因）：** 很多同学在这个时候大脑会偷偷“放水”，把 $\xi$ 当成 $x$，认为 $\frac{\xi}{x} = 1$，然后得出最终极限是 $2 \times 1 = 2$。这在数学上是极其荒谬的，因为 $\xi$ 永远躲在区间内部，绝不能等于端点 $x$。
    
- **事实真相：** 在这道题里，因为 $f(t)$ 在 $0$ 附近近似于一条直线（$y=2t$），所以那个神秘的 $\xi$ 其实刚好在区间的中点，即 $\xi \approx \frac{x}{2}$。如果代入进去：$2 \times \frac{1}{2} = 1$，这才是正确的答案。但问题是，**中值定理无法帮你算出这个 $\frac{1}{2}$**。
    

### 破解这类题的两大正统武器

以后遇到带有 $\int_0^x$ 的极限，请立刻把中值定理关进小黑屋，拿出下面这两把武器：

#### 武器一：洛必达法则（书上的标准解法，粗暴有效）

既然是 $\frac{0}{0}$ 型，直接对分子分母求导。

变上限积分求导，直接把上限 $x$ 塞进去，瞬间把积分号扒掉：

$$\lim_{x \to 0} \frac{\int_0^x f(t)dt}{x^2} \xrightarrow{\text{洛必达}} \lim_{x \to 0} \frac{f(x)}{2x} = \frac{1}{2} \lim_{x \to 0} \frac{f(x)}{x} = \frac{1}{2} \times 2 = 1$$

干脆利落，没有任何悬念。

#### 武器二：等价无穷小/泰勒展开（高手的秒杀技）

既然已知 $f(0)=0, f'(0)=2$，那在 $x \to 0$ 时，$f(x)$ 的第一阶泰勒展开（也就是等价无穷小）就是 **$f(x) \sim 2x$**。

你不要去积那个抽象的 $f(t)$，你直接积它的“平替” $2t$：

$$\int_0^x f(t) dt \sim \int_0^x 2t dt = t^2 \Big|_0^x = x^2$$

代回原式：

$$\lim_{x \to 0} \frac{x^2}{x^2} = 1$$

不用求导，不用找 $\xi$，三秒钟直接看出答案是 $1$。

### 第一层：为什么“直接等价替换”会面临被扣分的风险？

微积分里有一条铁律：**等价无穷小替换，原则上只能在“乘除法”或者“有限项加减法”中自由使用。**

你看这道题，它是 $n$ 项相加。并且，随着 $n \to \infty$，**相加的项数也在趋于无穷！**

**【无限项累加的“蝴蝶效应”】**

当你用 $\frac{k}{n^2}$ 去替换 $\ln(1+\frac{k}{n^2})$ 时，你其实丢掉了一个误差尾巴。

根据泰勒公式，真实情况是：

$$\ln\left(1+\frac{k}{n^2}\right) = \frac{k}{n^2} - \frac{1}{2}\left(\frac{k}{n^2}\right)^2 + o\left(\dots\right)$$

- 对于单独的一项，那个被丢掉的误差 $-\frac{1}{2}\frac{k^2}{n^4}$ 确实微不足道。
    
- **但是！你有 $n$ 项啊！**
    
- 如果把这些微小的误差全部加起来：$\sum_{k=1}^n \left(-\frac{1}{2}\frac{k^2}{n^4}\right) = -\frac{1}{2n^4} \sum k^2 \approx -\frac{1}{2n^4} \cdot \frac{n^3}{3} = -\frac{1}{6n}$。
    
- 万幸的是，在这道题里，当 $n \to \infty$ 时，总误差 $-\frac{1}{6n}$ 也趋于 $0$。所以你直接替换得出了正确答案。
    

**命题人的陷阱：** 如果哪天换一道题，误差累加起来不趋于 0，而是趋于一个常数，你的“直接替换法”就会当场暴毙，连怎么死的都不知道。

阅卷老师看到你对“无限项和”直接使用等价无穷小，如果严格一点，是可以直接扣步骤分的，因为你**没有证明误差趋于 0**。

### 第二层：答案的“免死金牌”——夹逼准则

为了做到 100% 的数学严谨，答案祭出了这个极其经典的对数不等式：

当 $x > 0$ 时，**$\frac{x}{1+x} < \ln(1+x) < x$**

这个不等式就像一个绝对安全的“防护罩”，它不是在做粗略的替换，而是在做**严格的边界锁定**。我们把题目的 $x = \frac{k}{n^2}$ 代进去，来看看它是怎么锁死极限的。

#### 1. 天花板（右边的上界）

右边是不等式 $\ln(1+x) < x$。

所以原式总和：

$$\sum \ln\left(1+\frac{k}{n^2}\right) < \sum \frac{k}{n^2}$$

这不就是你大脑里“直接等价替换”出来的式子吗！

右边的极限很好算：$\lim \frac{1}{n^2} \frac{n(n+1)}{2} = \frac{1}{2}$。

这说明：**真实结果绝对不会超过 $\frac{1}{2}$。**

#### 2. 地板（左边的下界）

左边是不等式 $\ln(1+x) > \frac{x}{1+x}$。代入 $x = \frac{k}{n^2}$：

$$\frac{\frac{k}{n^2}}{1+\frac{k}{n^2}} = \frac{k}{n^2+k}$$

所以原式总和必须大于 $\sum \frac{k}{n^2+k}$。

这东西怎么求极限？答案在这里用了一个“夹逼准则”里最常用的“分母放缩统一法”**： 因为 $k$ 是从 $1$ 变到 $n$ 的，所以分母里那个乱动的 $k$ 最大也就是 $n$。如果我们**把所有的分母都强行换成最大的 $n^2+n$，分数必定变小（这就是答案红线画的那一步）：

$$\sum \frac{k}{n^2+k} \ge \sum \frac{k}{n^2+n}$$

现在分母统一了，直接把分子加起来：

$$= \frac{1}{n^2+n} \sum k = \frac{1}{n^2+n} \cdot \frac{n(n+1)}{2} = \frac{1}{2}$$

左边地板的极限竟然也是 $\frac{1}{2}$！

#### 3. 绝杀

天花板是 $\frac{1}{2}$，地板也是 $\frac{1}{2}$。

中间那个复杂的对数和，只能被死死夹成了 $\frac{1}{2}$。最后别忘了题目要求的是 $\lim x_n$，所以结果是 $e^{\frac{1}{2}}$。

**【严密推导】：**

为了看清楚，我们把 $\sin x$ 展开一阶（用泰勒或等价替换思想）：

$\sin x = x + o(x)$

代入原极限式：

$$\lim_{x \to 0} \left( \frac{x + o(x)}{x^2} + \frac{f(x)}{x} \right) = \lim_{x \to 0} \left( \frac{1}{x} + \frac{o(x)}{x^2} + \frac{f(x)}{x} \right) = 2$$

把包含分母 $x$ 的项合并起来：

$$\lim_{x \to 0} \frac{1 + f(x)}{x} = 2$$

_(注：$\frac{o(x)}{x^2}$ 这一项，其实如果你把 $\sin x$ 展到三阶 $\sin x = x - \frac{1}{6}x^3 + o(x^3)$，那一项就是 $-\frac{1}{6}x \to 0$，可以直接扔掉。为了简单，我们直接合并主要矛盾)_

**【致命一击】：**

看这个新式子 $\lim_{x \to 0} \frac{1 + f(x)}{x} = 2$。

分母 $x \to 0$。如果分子不趋于 0，这个极限必定爆炸。

既然极限存在（等于 2），那**分子必须趋于 0**！

所以 $\lim_{x \to 0} (1 + f(x)) = 0$。

因为 $f(x)$ 可导必连续，所以 $1 + f(0) = 0$。

**顺利拿下第一滴血：$f(0) = -1$。**

### 第二步：利用导数定义，活捉 $f'(0)$

上一步我们得到了一个极其珍贵的式子：

$$\lim_{x \to 0} \frac{1 + f(x)}{x} = 2$$

并且知道了 $f(0) = -1$。

**【思考过程】：**

微积分里，看到 $\frac{f(x) - \text{常数}}{x}$ 这种结构，一定要像条件反射一样想到**导数的定义式**！

**【严密推导】：**

既然 $f(0) = -1$，那么 $1$ 就可以写成 $-f(0)$。我们把上面的式子化一下妆：

$$\lim_{x \to 0} \frac{f(x) - (-1)}{x} = \lim_{x \to 0} \frac{f(x) - f(0)}{x - 0} = 2$$

这简直就是把 $f'(0)$ 的定义式直接拍在了你脸上！

**顺利拿下双杀：$f'(0) = 2$。**

### 第三步：降维打击，秒杀最终极限

现在我们手里有粮了：$f(0) = -1$，$f'(0) = 2$。

要求最终的极限：

$$\lim_{x \to 0} \frac{x}{f(x) + e^x}$$

**【思考过程】：**

先代入 $x=0$ 试试水：

分子 = $0$

分母 = $f(0) + e^0 = -1 + 1 = 0$

这是个标准的 $\frac{0}{0}$ 型极限！

这里你有两种武器可以选择：

- **武器 A（洛必达法则）：** 上下求导。但要注意，题目只说 $f(x)$ 可导，没说它的导数连续。用洛必达有一点点“不严谨”的风险（虽然考研里通常能混过去）。
    
- **武器 B（泰勒展开/局部线性化）：** 这是最王道、最安全的做法！因为已知函数值和一阶导数，直接写出它在 $x=0$ 处的等价无穷小（一阶泰勒）。
    

**【严密推导（武器 B）】：**

根据一阶泰勒展开（也就是 $f(x) \approx f(0) + f'(0)x$）：

$$f(x) = -1 + 2x + o(x)$$

指数函数 $e^x$ 的等价展开：

$$e^x = 1 + x + o(x)$$

把它们俩狠狠地塞进分母里，进行同类项抵消：

分母 = $(-1 + 2x) + (1 + x) + o(x) = 3x + o(x)$

原极限瞬间变成了小学除法：

$$\lim_{x \to 0} \frac{x}{3x + o(x)} = \lim_{x \to 0} \frac{1}{3 + \frac{o(x)}{x}} = \frac{1}{3}$$

![[_attachments/image/05强化-严选题-1780285980052.jpeg]] ### 第一步：用“模板”给分母做体检

判断 $n$ 项求和到底用什么方法，**只看分母的变化幅度！**

- **模板 A（夹逼准则）：** 分母的变化量，比分母的主体阶数低。比如 $n^2+1, n^2+2, \dots, n^2+n$。变化量是 $n$（一阶），主体是 $n^2$（二阶）。
    
- **模板 B（定积分）：** 分母的变化量，跟分母的主体阶数**一样大**。比如这道题的 $n^2+1^2, n^2+2^2, \dots, n^2+n^2$。变化量最大是 $n^2$，主体也是 $n^2$。阶数一样大（齐次），**百分之百要用定积分定义！**
    

### 第二步：识别分子的“干扰项”并拆分

既然确定了是定积分的场子，我们就来凑定积分的标准形式。

写出这道题的通项（第 $k$ 项）：

$$a_k = \frac{n + \frac{1}{k}}{n^2 + k^2}$$

- **主体部分：** 分子里的 $n$，和分母的 $n^2+k^2$ 非常般配，刚好能凑出 $\frac{1}{n}$ 和 $\frac{k}{n}$。
    
- **干扰部分：** 分子里的 $\frac{1}{k}$。当 $n \to \infty$ 时，比起庞大的 $n$，这个 $\frac{1}{k}$（最大也就是 1）简直就是一粒灰尘。
    

**【核心操作：拆！】**

把求和公式一分为二：

$$S_n = \underbrace{\sum_{k=1}^n \frac{n}{n^2 + k^2}}_{\text{第一部分：主力军}} + \underbrace{\sum_{k=1}^n \frac{\frac{1}{k}}{n^2 + k^2}}_{\text{第二部分：小灰尘}}$$

### 第三步：各个击破（模板双开）

**1. 处理主力军（套用定积分模板）：**

提取公因式，强行凑出 $\frac{1}{n}$ 和 $\frac{k}{n}$：

$$\sum_{k=1}^n \frac{n}{n^2 + k^2} = \frac{1}{n} \sum_{k=1}^n \frac{n^2}{n^2 + k^2} = \frac{1}{n} \sum_{k=1}^n \frac{1}{1 + (\frac{k}{n})^2}$$

这就是完美的黎曼和！直接转化为定积分：

$$\lim_{n \to \infty} \frac{1}{n} \sum_{k=1}^n \frac{1}{1 + (\frac{k}{n})^2} = \int_0^1 \frac{1}{1+x^2} dx = \arctan x \Big|_0^1 = \frac{\pi}{4}$$

**2. 处理小灰尘（套用夹逼准则模板）：**

这是一个极小的量，我们只需要证明它趋于 0 即可。

因为 $k \ge 1$，所以分子 $\frac{1}{k} \le 1$。

我们对它进行**放大（找天花板）**：

$$0 < \sum_{k=1}^n \frac{\frac{1}{k}}{n^2 + k^2} \le \sum_{k=1}^n \frac{1}{n^2 + 1^2} < \sum_{k=1}^n \frac{1}{n^2} = n \cdot \frac{1}{n^2} = \frac{1}{n}$$

左边是 $0$，右边是 $\frac{1}{n}$。当 $n \to \infty$ 时，两边都趋于 $0$。

所以根据夹逼准则，这部分极限为 $0$。
