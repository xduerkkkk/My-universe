### 一、图二笔记为什么对？（空间与函数对应关系理解）

#### 1. 变量与对应点绝不相同
反函数本质上是**交换了自变量与因变量**（在平面几何上是关于直线 $y = x$ 做镜像对称）：
* 原函数把点 $x_0$ 映射到 $y_0$，即 $y_0 = f(x_0)$，曲线上的点是 $(x_0, y_0)$；
* 反函数 $g$ 是把 $y_0$ 映射回 $x_0$，即 $x_0 = g(y_0)$，反函数曲线上的对应点是 $(y_0, x_0)$。

#### 2. 导数的倒数关系是“在同一点的切线斜率”
从微元法看：
$$g'(y_0) = \left.\frac{dx}{dy}\right|_{y=y_0} = \frac{1}{\left.\frac{dy}{dx}\right|_{x=x_0}} = \frac{1}{f'(x_0)}$$

**误区警示**：
如果你写 $g'(x) = \frac{1}{f'(x)}$，等号左边的 $x$ 是反函数的输入（属于原函数的值域），等号右边的 $x$ 却是原函数的输入（属于原函数的定义域），**字母虽然都写成 $x$，但数学含义完全是两码事**！
严谨的复合形式应为：
$$g'(x) = \frac{1}{f'\big(g(x)\big)}$$
所以求 $g'(3)$ 时，绝对不是去算 $\frac{1}{f'(3)}$，而是必须先找到谁能让 $f(x_0) = 3$（即 $g(3) = x_0$），然后得到：
$$g'(3) = \frac{1}{f'(x_0)}$$
这正是图二笔记总结的解题口诀：**“先找原像点，再取导数倒数”**。

### 二、图一题目解析（怎么理解与求解）

**题目条件**：
1. $f'(1) = 3$；
2. $g(x)$ 是 $f(x)$ 的反函数；
3. $\int_2^{f(\ln x + 1)} g(t) dt = x \ln x$；
4. 求 $g'(3)$。

#### 第一步：求 $f(1)$ 是多少（关键突破口）
在积分等式中，变上限是 $f(\ln x + 1)$。
为了利用 $x = 1$ 处的条件，令 $x = 1$：
- 右边：$1 \cdot \ln 1 = 0$
- 左边：$\int_2^{f(\ln 1 + 1)} g(t) dt = \int_2^{f(1)} g(t) dt$

因此：
$$\int_2^{f(1)} g(t) dt = 0 \implies f(1) = 2$$
*(由于反函数存在，原函数必单调，被积函数非零，故上下限相等)*。

#### 第二步：等式两边对 $x$ 求导（提取出 $f(x)$ 的信息）
对原等式 $\int_2^{f(\ln x + 1)} g(t) dt = x \ln x$ 两边关于 $x$ 求导：
- **左边求导**（变上限积分求导 + 链式法则）：
  $$g\big(f(\ln x + 1)\big) \cdot \left[ f(\ln x + 1) \right]'$$
  **奇迹来了**：因为 $g$ 和 $f$ 互为反函数，复合之后直接变回自变量本身！即 $g\big(f(\square)\big) = \square$：
  $$g\big(f(\ln x + 1)\big) = \ln x + 1$$
  而后面的导数项为：$f'(\ln x + 1) \cdot \frac{1}{x}$。
  所以左边导数 $= (\ln x + 1) \cdot f'(\ln x + 1) \cdot \frac{1}{x}$。

- **右边求导**：
  $$(x \ln x)' = \ln x + 1$$

两边联立：
$$(\ln x + 1) \cdot f'(\ln x + 1) \cdot \frac{1}{x} = \ln x + 1$$
两边约去 $\ln x + 1$（$x$ 在 1 附近不为 0），得到：
$$f'(\ln x + 1) = x$$

#### 第三步：求 $g'(3)$（落实图二笔记的方法）
要求 $g'(3)$：
1. **找原像**：令 $f(x_0) = 3$。
   我们已经知道 $f'(u)$ 的规律：令 $u = \ln x + 1 \iff x = e^{u-1}$，
   所以：
   $$f'(u) = e^{u-1}$$
   积分回去：$f(u) = \int e^{u-1}du = e^{u-1} + C$。
   由于第一步求出 $f(1) = 2$，代入得 $e^{1-1} + C = 2 \implies 1 + C = 2 \implies C = 1$。
   因此：
   $$f(u) = e^{u-1} + 1$$
   现在令 $f(x_0) = 3$：
   $$e^{x_0 - 1} + 1 = 3 \implies e^{x_0 - 1} = 2 \implies x_0 = \ln 2 + 1$$

2. **用图二笔记的反函数求导公式**：
   $$g'(3) = \frac{1}{f'(x_0)}$$
   因为 $f'(x_0) = e^{x_0 - 1} = 2$，所以：
   $$g'(3) = \frac{1}{2}$$

### 三、应试总结

1. **审题警觉**：题目只要出现反函数与原函数的复合，如 $g(f(u))$ 或 $f(g(u))$，立刻化简为自变量 $u$（这道题变上限积分导数利用这个性质直接化简）。
2. **反函数求导动作**：
   求 $g'(b)$ 时，在草稿纸上永远分两步：
   - 第一步：解方程 $f(a) = b$，锁定横坐标 $a$；
   - 第二步：计算 $g'(b) = \frac{1}{f'(a)}$。
   切记**不要把 $b$ 直接代进 $f'(x)$ 的分母里**！
