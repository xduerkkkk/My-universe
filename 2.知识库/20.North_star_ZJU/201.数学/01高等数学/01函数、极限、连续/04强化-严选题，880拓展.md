# 辅导讲义例题


**【题目已知】**

设函数 $f(x)$ 在 $(-\infty, +\infty)$ 内连续，且 $F(x) = \int_{0}^{x} (x - 2t)f(t)dt$。

### 第 (1) 问：若 $f(x)$ 为偶函数，证明 $F(x)$ 也是偶函数。

**【证法一】：定义法 + 换元积分法（最通用）**

_核心思路：计算 $F(-x)$，通过变量代换证明其等于 $F(x)$。_

$$F(-x) = \int_{0}^{-x} (-x - 2t)f(t)dt$$

令 $t = -u$，则 $dt = -du$。

当 $t = 0$ 时，$u = 0$；当 $t = -x$ 时，$u = x$。

代入积分式：

$$F(-x) = \int_{0}^{x} (-x + 2u)f(-u)(-du)$$

因为 $f(x)$ 为偶函数，所以 $f(-u) = f(u)$。提取负号整理：

$$F(-x) = -\int_{0}^{x} (-x + 2u)f(u)du = \int_{0}^{x} (x - 2u)f(u)du = F(x)$$

故 $F(x)$ 也是偶函数。

**【证法二】：拆分积分 + 奇偶性运算法则（最巧妙）**

_核心思路：将变限积分拆开，利用“偶函数的变限积分是奇函数”、“奇函数的变限积分是偶函数”直接判断。_

首先将积分拆开：

$$F(x) = x\int_{0}^{x} f(t)dt - 2\int_{0}^{x} tf(t)dt$$

分项分析奇偶性：

1. 第一项 $x\int_{0}^{x} f(t)dt$：已知 $f(t)$ 是**偶**函数，所以 $\int_{0}^{x} f(t)dt$ 是**奇**函数。$x$ 也是**奇**函数。根据“奇 $\times$ 奇 = 偶”，所以第一项整体是**偶函数**。
    
2. 第二项 $2\int_{0}^{x} tf(t)dt$：因为 $t$ 是奇函数，$f(t)$ 是偶函数，所以被积函数 $tf(t)$ 是**奇**函数。奇函数的变限积分是**偶**函数，所以第二项是**偶函数**。
    

两个偶函数相减依然是偶函数，故 $F(x)$ 是偶函数。

### 第 (2) 问：若 $f(x)$ 单调不增，证明 $F(x)$ 单调不减。

**【前置推导（求导必做）】**

要证 $F(x)$ 单调不减，只需证 $F'(x) \ge 0$。

先对拆分后的 $F(x)$ 求导：

$$F(x) = x\int_{0}^{x} f(t)dt - 2\int_{0}^{x} tf(t)dt$$

$$F'(x) = \int_{0}^{x} f(t)dt + xf(x) - 2xf(x) = \int_{0}^{x} f(t)dt - xf(x)$$

针对这个导数结果，有以下三种方法证明其大于等于 0：

**【证法一】：利用积分中值定理**（对应板书绿字 ①）

对 $\int_{0}^{x} f(t)dt$ 使用第一积分中值定理：存在 $\xi$ 介于 $0$ 和 $x$ 之间，使得 $\int_{0}^{x} f(t)dt = f(\xi) \cdot x$。

代入导数式：

$$F'(x) = xf(\xi) - xf(x) = x[f(\xi) - f(x)]$$

- **当 $x > 0$ 时**：$0 < \xi < x$。因为 $f(x)$ 单调不增，所以 $f(\xi) \ge f(x)$，即 $f(\xi) - f(x) \ge 0$。此时正数乘非负数，$F'(x) \ge 0$。
    
- **当 $x < 0$ 时**：$x < \xi < 0$。因为 $f(x)$ 单调不增，所以 $f(\xi) \le f(x)$，即 $f(\xi) - f(x) \le 0$。此时负数乘非正数，$F'(x) \ge 0$。
    
- **当 $x = 0$ 时**：$F'(0) = 0 \ge 0$。
    

综上，$F'(x) \ge 0$，$F(x)$ 单调不减。

**【证法二】：利用定积分的估值性质 / 放缩法**（对应板书绿字 ②）

_核心依据：$m(b-a) \le \int_{a}^{b} f(x)dx \le M(b-a)$ _

- **当 $x > 0$ 时**：积分区间为 $[0, x]$。因 $f(t)$ 单调不增，区间上的最小值为 $f(x)$。
    
    故 $\int_{0}^{x} f(t)dt \ge \int_{0}^{x} f(x)dt = xf(x)$。
    
    所以 $F'(x) = \int_{0}^{x} f(t)dt - xf(x) \ge xf(x) - xf(x) = 0$。
    
- **当 $x < 0$ 时**：积分区间为 $[x, 0]$。因 $f(t)$ 单调不增，区间上的最大值为 $f(x)$。
    
    在区间 $[x, 0]$ 上，$\int_{x}^{0} f(t)dt \le \int_{x}^{0} f(x)dt = -xf(x)$。
    
    两边乘以负号：$-\int_{x}^{0} f(t)dt \ge xf(x)$，即 $\int_{0}^{x} f(t)dt \ge xf(x)$。
    
    所以 $F'(x) \ge 0$ 依然成立。
    

**【证法三】：构造成一个新积分（最简洁）**（对应板书绿字 ③）

将 $xf(x)$ 逆向写成积分的形式：$xf(x) = \int_{0}^{x} f(x)dt$。

代入导数式合并：

$$F'(x) = \int_{0}^{x} f(t)dt - \int_{0}^{x} f(x)dt = \int_{0}^{x} [f(t) - f(x)]dt$$

- **当 $x > 0$ 时**：积分上限大于下限。被积变量 $t \in [0, x]$，即 $t \le x$。因为 $f$ 单调不增，所以 $f(t) \ge f(x)$，被积函数 $[f(t) - f(x)] \ge 0$。正区间积非负函数，结果 $\ge 0$。
    
- **当 $x < 0$ 时**：积分上限小于下限。被积变量 $t \in [x, 0]$，即 $t \ge x$。因为 $f$ 单调不增，所以 $f(t) \le f(x)$，被积函数 $[f(t) - f(x)] \le 0$。负区间积非正函数，结果依然 $\ge 0$。
    

综上所述，恒有 $F'(x) \ge 0$。故 $F(x)$ 单调不减。

# 严选题
## 1 数列，捏造反例
![[_attachments/image/04强化-严选题，880拓展-1779677207891.jpeg]]

我直接塞给你**两个“专门用来打脸”的数列模型**。以后遇到这种题，直接套这两个模型去撞击选项：

1. **“交错开关”模型：** $\{1, 0, 1, 0, \dots\}$。它没有极限，也不趋于无穷，专门用来制造“乘积为 0”的假象。
    
2. **“跷跷板”模型：** $x_n = n$ (越来越大)，$y_n = \frac{1}{n}$ (越来越小)。专门用来制造“乘积是个常数（有界）”的假象。
    

带着这两个武器，我们来逐个击破：

 (A) 选项打脸测试

**原话：** 若 $\lim_{n \to \infty} x_n y_n = 0$，则必有 $\lim_{n \to \infty} x_n = 0$ 或 $\lim_{n \to \infty} y_n = 0$。

- **召唤“交错开关”模型：**
    
    设 $x_n = \{1, 0, 1, 0, 1, 0, \dots\}$
    
    设 $y_n = \{0, 1, 0, 1, 0, 1, \dots\}$
    
- **看乘积：** 对应项相乘，永远是 $1 \times 0$ 或 $0 \times 1$。所以乘积数列 $x_n y_n = \{0, 0, 0, 0, \dots\}$。它的极限完美等于 $0$。条件满足。
    
- **看结论：** $x_n$ 的极限是 $0$ 吗？不是，它在 $0$ 和 $1$ 之间反复横跳，极限根本**不存在**！$y_n$ 同理。
    
- **结论：** (A) 被打脸，淘汰。
    
    _(直觉：两个人轮流上班，公司永远有人在。但你不能说“其中一个人永远在上班”。)_
    

 (B) 选项打脸测试

**原话：** 若 $\lim_{n \to \infty} x_n y_n = \infty$，则必有 $\lim_{n \to \infty} x_n = \infty$ 或 $\lim_{n \to \infty} y_n = \infty$。

- **稍微改装一下“交错开关”模型：** 把 $1$ 换成 $n$。
    
    设 $x_n = \{1, n, 1, n, 1, n, \dots\}$
    
    设 $y_n = \{n, 1, n, 1, n, 1, \dots\}$
    
- **看乘积：** 对应项相乘，$x_n y_n = \{n, n, n, n, \dots\}$。随着 $n$ 变大，这个乘积的极限肯定是 $\infty$。条件满足。
    
- **看结论：** $x_n$ 趋于 $\infty$ 吗？不是！趋于 $\infty$ 的定义是“最终永远比任何数都大”。但 $x_n$ 每隔一步就会掉回 $1$（比如第 100 项是 $100$，第 101 项又变成了 $1$）。所以它极限不存在，并不趋于 $\infty$。
    
- **结论：** (B) 被打脸，淘汰。
    

 (C) 选项打脸测试

**原话：** 若 $x_n y_n$ 有界，则必有 $x_n$ 与 $y_n$ 都有界。

- **召唤“跷跷板”模型：**
    
    设 $x_n = n$
    
    设 $y_n = \frac{1}{n}$
    
- **看乘积：** $x_n y_n = n \times \frac{1}{n} = 1$。乘积永远是 $1$，绝对被死死关在盒子里（有界）。条件满足。
    
- **看结论：** $x_n = n$ 有界吗？显然没有，它冲向了正无穷。
    
- **结论：** (C) 被打脸，淘汰。
    

(D) 为什么它是对的？（提供一个绝佳的几何直觉）

只剩下 (D) 了，它是正确答案。

**原话：** 若 $x_n y_n$ 无界，则必有 $x_n$ 无界或 $y_n$ 无界。

我们不玩枯燥的代数，直接用**几何画面**来秒杀它：

把 $x_n$ 看作一个矩形的**长**，把 $y_n$ 看作矩形的**宽**。

那么 $x_n y_n$ 就是这个矩形的**面积**。

- **题目条件：“面积无界”** $\implies$ 意味着这个矩形的面积在不断膨胀，大到连宇宙都装不下。
    
- **现在反过来想（反证法）：** 如果长（$x_n$）和宽（$y_n$）**都有界**（被关在盒子里）会怎样？
    
    假设长永远不超过 $10$ 米，宽永远不超过 $5$ 米。
    
    那这个矩形的面积撑死了也就 $10 \times 5 = 50$ 平方米。它怎么可能膨胀到宇宙都装不下呢？！
    
- **结论：** 既然面积能膨胀到无限大（无界），那必然是它的**长**或者**宽**（或者两者一起），突破了牢笼，伸向了无限远。
    

所以，面积无界 $\implies$ 至少有一条边无界。

这就是 (D) 选项的物理真理！


<font color="#ff0000">主要记住，数列中，无界不一定是无穷，也有可能是震荡</font>
