解方程是叫“杀鸡用牛刀”**

根据泰勒公式，$y(x)$ 在 $x=0$ 附近可以展开为：

$$y(x) = y(0) + y'(0)x + \frac{y''(0)}{2!}x^2 + \frac{y'''(0)}{3!}x^3 + o(x^3)$$

**第二步：找系数（利用已知条件“白嫖”）**

- 题目直接送了两个系数：$y(0) = 0, y'(0) = 0$。
    
- 代入模板，发现前两项都没了！
    
    $$y(x) = 0 + 0 + \frac{y''(0)}{2}x^2 + \dots$$
    
- 这说明，决定 $y(x)$ 阶数和系数的关键，就是 **$y''(0)$**。
    
**第三步：榨取微分方程的剩余价值**

怎么求 $y''(0)$？绝对不要去解方程求导！**微分方程本身就是一个天然的等式。**

题目给了方程：$y'' + 2y' + y = e^{3x}$

这个方程对所有的 $x$ 都成立，当然在 $x=0$ 处也成立。我们直接把 $x=0$ 狠狠地代入进去：

$$y''(0) + 2y'(0) + y(0) = e^0$$

把已知的 $y(0)=0, y'(0)=0$ 代进去：

$$y''(0) + 0 + 0 = 1 \implies \mathbf{y''(0) = 1}$$


把算出来的 $y''(0) = 1$ 塞回第一步的模板里：

$$y(x) = \frac{1}{2}x^2 + o(x^2)$$

大功告成！当 $x \to 0$ 时，$y(x)$ 最主要的成分就是 $\frac{1}{2}x^2$。

所以：**$y(x) \sim \frac{1}{2}x^2$**。

![[_attachments/image/06强化-880综合拓展-1780366600356.jpeg]]

已知方程是 $x(1+\ln x) = n$。当 $n \to \infty$ 时，等式右边趋于无穷大。等式左边是一个单调递增的函数，为了让左边也趋于无穷大，它的自变量 $x$（也就是我们的根 $f(n)$）必须也趋于无穷大。所以：**$\lim_{n \to \infty} f(n) = +\infty$**。既然趋于无穷大，那数列 $\{f(n)\}$ 必然**发散**。
我们要研究 $\frac{f(n)}{n}$ 的极限。

题目已知 $f(n)$ 是根，代入方程得到绝对真理：

$$n = f(n)[1+\ln f(n)]$$

我们直接把目标式子里的分母 $n$ 替换掉：

$$\lim_{n \to \infty} \frac{f(n)}{n} = \lim_{n \to \infty} \frac{f(n)}{f(n)[1+\ln f(n)]}$$

分子分母的 $f(n)$ 完美约掉：

$$= \lim_{n \to \infty} \frac{1}{1+\ln f(n)}$$

刚才我们在第一步已经知道，当 $n \to \infty$ 时，$f(n) \to +\infty$。

那么 $\ln f(n)$ 也会趋于 $+\infty$。

所以，这个极限的分母趋于无穷大，整个极限**等于 0**。

既然极限存在且等于 0，说明数列 $\{\frac{f(n)}{n}\}$ **收敛**。

**结论：B 选项错误。**

### 第三步：祭出“取对数大法”绝杀最后一关（判断 C 和 D）

这是全题最精彩的一步。目标是求极限：

$$\lim_{n \to \infty} \frac{f(n)\ln n}{n}$$

分母的 $n$ 我们知道怎么替换了，但分子多了一个讨厌的 **$\ln n$**。怎么办？

对绝对真理式 $n = f(n)[1+\ln f(n)]$ **两边同时取对数**！

$$\ln n = \ln \left( f(n)[1+\ln f(n)] \right)$$

利用对数的乘法拆分性质 $\ln(AB) = \ln A + \ln B$：

$$\ln n = \ln f(n) + \ln[1+\ln f(n)]$$

现在，我们把 $\ln n$ 和 $n$ 全部用 $f(n)$ 替换掉，代入目标极限：

$$\frac{f(n)\ln n}{n} = \frac{f(n) \cdot \left( \ln f(n) + \ln[1+\ln f(n)] \right)}{f(n)[1+\ln f(n)]}$$

同样，把外面的 $f(n)$ 约掉：

$$= \frac{\ln f(n) + \ln[1+\ln f(n)]}{1+\ln f(n)}$$

接下来，这是一个典型的 $\frac{\infty}{\infty}$ 型极限。我们对分子分母**同时除以主导项 $\ln f(n)$**：

$$= \frac{1 + \frac{\ln[1+\ln f(n)]}{\ln f(n)}}{\frac{1}{\ln f(n)} + 1}$$

当 $n \to \infty$ 时，令 $u = \ln f(n) \to +\infty$。

- 分母：$\frac{1}{u} + 1 \to 1$
    
- 分子：那一坨 $\frac{\ln(1+u)}{u}$，根据洛必达法则或者直觉（对数增长远慢于幂函数），它的极限是 $0$。所以分子 $\to 1 + 0 = 1$。
    

最终极限：

$$\lim_{n \to \infty} \frac{f(n)\ln n}{n} = \frac{1}{1} = \mathbf{1}$$

### 第一步：考场上的“偷天换日”（秒出候选答案）

做选择题，第一反应永远是“假设它收敛，看看极限到底是多少”。

假设数列 $\{x_n\}$ 收敛，且极限为 $a$。

我们在不等式 $x_{n+1} < 2 - \frac{1}{x_n}$ 两端同时取极限（注意：取极限后，严格的小于号 `<` 会变成小于等于号 `$\le$`）：

$$a \le 2 - \frac{1}{a}$$

现在来解这个不等式。因为是正项数列，所以 $a \ge 0$。两边同乘 $a$：

$$a^2 \le 2a - 1$$

移项整理：

$$a^2 - 2a + 1 \le 0$$

即：

$$(a - 1)^2 \le 0$$

任何实数的平方都不可能小于 0，所以它只能**等于 0**！

也就是说：**$a = 1$**。

**【结论】：** 如果这个数列收敛，它的极限**只能是 1**。直接排除了 A 和 C。接下来，我们只需要证明它确实收敛就行了。

### 第二步：核心破局——“作差法”判断单调性

怎么证明它收敛？老规矩：**单调有界准则**。

要判断单调性，最暴力的手法就是让**后一项减去前一项（$x_{n+1} - x_n$）**，看看结果是正还是负。

我们把题目给的不等式利用起来：

已知 $x_{n+1} < 2 - \frac{1}{x_n}$，所以：

$$x_{n+1} - x_n < 2 - \frac{1}{x_n} - x_n$$

接下来，对右边进行通分合并（这是全题最爽的一步）：

$$2 - \frac{1}{x_n} - x_n = \frac{2x_n - 1 - x_n^2}{x_n}$$

把分子的负号提出来：

$$= \frac{-(x_n^2 - 2x_n + 1)}{x_n}$$

$$= \frac{-(x_n - 1)^2}{x_n}$$

**【审判时刻】：**

- 题目说了是“正项数列”，所以分母 $x_n > 0$（正数）。
    
- 分子是一个完全平方数带个负号，即 $-(x_n - 1)^2 \le 0$（非正数）。
    
    所以，整个分数必然 $\le 0$。
    

这就意味着：

$$x_{n+1} - x_n < 0 \implies x_{n+1} < x_n$$

**【结论】：** 这是一个**严格单调递减**的数列！

这题我提出个 x 方，能得出 a=-1，但 b 似乎无所谓啊，是几都不影响结果是 0
### 第一层：破除你的“错觉”

我还原一下你提取 $x^2$ 的思路：

原式 $\implies \lim_{x \to \infty} x^2 \left( \frac{\sqrt[3]{1-x^6}}{x^2} - a - \frac{b}{x^2} \right) = 0$

你心想：当 $x \to \infty$ 时，$\frac{b}{x^2}$ 趋于 $0$，所以它没用了，直接扔掉。

然后括号里的前面部分趋于 $-1$，所以 $-1 - a = 0$，得出 $a = -1$。

**【致命破绽】：**

你忘了括号外面还乘着一个极其庞大的 $x^2 \to \infty$！

$\frac{b}{x^2}$ 虽然趋于 $0$，但如果把它和外面的 $x^2$ 重新乘起来：

$$x^2 \cdot \left( \frac{b}{x^2} \right) = b$$

你看！它根本不是 $0$，它是一个实实在在的常数 $b$！你把它当成 $0$ 提前扔掉，就等于把最终结果里的 $b$ 给强行抹杀了。

> **考场铁律：** 在乘法结构中（外面乘着趋于无穷大的项），括号里那些趋于 $0$ 的“小尾巴”**绝对不能提前当成 0 扔掉**，因为它们乘以外面的无穷大，可能会“死灰复燃”变成常数！

### 第二层：正统解法（泰勒展开的降维打击）

遇到这种 $x \to \infty$ 且带有根号的题，最稳妥、绝对不会丢精度的王道解法是：**强行提出最高次幂，构造出趋于 0 的项，然后用泰勒公式（广义二项式）展开。**

**第一步：给根号“洗底”**

为了能用泰勒公式，我们要把 $\sqrt[3]{1-x^6}$ 里面最大的 $-x^6$ 强行提出来：

$$\sqrt[3]{1-x^6} = \sqrt[3]{-x^6 \left(1 - \frac{1}{x^6}\right)} = -x^2 \left(1 - \frac{1}{x^6}\right)^{\frac{1}{3}}$$

**第二步：泰勒展开（精确打击）**

因为 $x \to \infty$，所以 $-\frac{1}{x^6} \to 0$。我们把它当成一个整体 $u$。

套用公式 $(1+u)^\alpha = 1 + \alpha u + o(u)$：

$$\left(1 - \frac{1}{x^6}\right)^{\frac{1}{3}} = 1 + \frac{1}{3} \left(-\frac{1}{x^6}\right) + o\left(\frac{1}{x^6}\right) = 1 - \frac{1}{3x^6} + o\left(\frac{1}{x^6}\right)$$

把外面的 $-x^2$ 乘回去：

$$-x^2 \left( 1 - \frac{1}{3x^6} + o\left(\frac{1}{x^6}\right) \right) = -x^2 + \frac{1}{3x^4} + o\left(\frac{1}{x^4}\right)$$

**第三步：代回原极限，合并同类项**

现在，把这串真实的底牌代回原题目：

$$\lim_{x \to \infty} \left( -x^2 + \frac{1}{3x^4} - ax^2 - b \right) = 0$$

把同次幂的项放在一起：

$$\lim_{x \to \infty} \left[ (-1 - a)x^2 - b + \frac{1}{3x^4} \right] = 0$$

**第四步：宣判结果**

要让这个式子在 $x \to \infty$ 时等于 $0$，它里面的每一项都必须配合：

1. **$x^2$ 的项不能爆炸**，所以系数必须为 0：$-1 - a = 0 \implies \mathbf{a = -1}$
    
2. **常数项也不能留下**，所以必须为 0：$-b = 0 \implies \mathbf{b = 0}$
    
3. 最后剩下的 $\frac{1}{3x^4}$，当 $x \to \infty$ 时自然趋于 $0$，完美符合题意。
    

所以，最终答案是：**$a = -1, \ b = 0$**。
