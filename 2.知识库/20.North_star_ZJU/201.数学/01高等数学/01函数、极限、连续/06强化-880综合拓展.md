解方程是叫“杀鸡用牛刀”**

根据泰勒公式，$y(x)$ 在 $x=0$ 附近可以展开为：

$$y(x) = y(0) + y'(0)x + \frac{y''(0)}{2!}x^2 + \frac{y'''(0)}{3!}x^3 + o(x^3)$$

- 题目直接送了两个系数：$y(0) = 0, y'(0) = 0$。
    
- 代入模板，发现前两项都没了！
    
    $$y(x) = 0 + 0 + \frac{y''(0)}{2}x^2 + \dots$$
    
- 这说明，决定 $y(x)$ 阶数和系数的关键，就是 **$y''(0)$**。
    
**第三步：榨取微分方程的剩余价值**

怎么求 $y''(0)$？绝对不要去解方程求导！**微分方程本身就是一个天然的等式。**

题目给了方程：$y'' + 2y' + y = e^{3x}$

这个方程对所有的 $x$ 都成立，当然在 $x=0$ 处也成立。我们直接把 $x=0$ 狠狠地代入进去：

$$y''(0) + 2y'(0) + y(0) = e^0$$

把已知的 $y(0)=0, y'(0)=0$ 代进去：

$$y''(0) + 0 + 0 = 1 \implies \mathbf{y''(0) = 1}$$


把算出来的 $y''(0) = 1$ 塞回第一步的模板里：

$$y(x) = \frac{1}{2}x^2 + o(x^2)$$

大功告成！当 $x \to 0$ 时，$y(x)$ 最主要的成分就是 $\frac{1}{2}x^2$。

所以：**$y(x) \sim \frac{1}{2}x^2$**。

已知方程是 $x(1+\ln x) = n$。当 $n \to \infty$ 时，等式右边趋于无穷大。等式左边是一个单调递增的函数，为了让左边也趋于无穷大，它的自变量 $x$（也就是我们的根 $f(n)$）必须也趋于无穷大。所以：**$\lim_{n \to \infty} f(n) = +\infty$**。既然趋于无穷大，那数列 $\{f(n)\}$ 必然**发散**。
我们要研究 $\frac{f(n)}{n}$ 的极限。

- [ ] !

题目已知 $f(n)$ 是根，代入方程得到

$$n = f(n)[1+\ln f(n)]$$

我们直接把目标式子里的分母 $n$ 替换掉：

$$\lim_{n \to \infty} \frac{f(n)}{n} = \lim_{n \to \infty} \frac{f(n)}{f(n)[1+\ln f(n)]}$$

分子分母的 $f(n)$ 完美约掉：

$$= \lim_{n \to \infty} \frac{1}{1+\ln f(n)}$$

刚才我们在第一步已经知道，当 $n \to \infty$ 时，$f(n) \to +\infty$。

那么 $\ln f(n)$ 也会趋于 $+\infty$。

所以，这个极限的分母趋于无穷大，整个极限**等于 0**。

既然极限存在且等于 0，说明数列 $\{\frac{f(n)}{n}\}$ **收敛**。

**结论：B 选项错误。**

第三步：祭出“取对数大法”绝杀最后一关（判断 C 和 D）

这是全题最精彩的一步。目标是求极限：

$$\lim_{n \to \infty} \frac{f(n)\ln n}{n}$$

分母的 $n$ 我们知道怎么替换了，但分子多了一个讨厌的 **$\ln n$**。怎么办？

对绝对真理式 $n = f(n)[1+\ln f(n)]$ **两边同时取对数**！

$$\ln n = \ln \left( f(n)[1+\ln f(n)] \right)$$

利用对数的乘法拆分性质 $\ln(AB) = \ln A + \ln B$：

$$\ln n = \ln f(n) + \ln[1+\ln f(n)]$$

现在，我们把 $\ln n$ 和 $n$ 全部用 $f(n)$ 替换掉，代入目标极限：

$$\frac{f(n)\ln n}{n} = \frac{f(n) \cdot \left( \ln f(n) + \ln[1+\ln f(n)] \right)}{f(n)[1+\ln f(n)]}$$

同样，把外面的 $f(n)$ 约掉：

$$= \frac{\ln f(n) + \ln[1+\ln f(n)]}{1+\ln f(n)}$$

接下来，这是一个典型的 $\frac{\infty}{\infty}$ 型极限。我们对分子分母**同时除以主导项 $\ln f(n)$**：

$$= \frac{1 + \frac{\ln[1+\ln f(n)]}{\ln f(n)}}{\frac{1}{\ln f(n)} + 1}$$

当 $n \to \infty$ 时，令 $u = \ln f(n) \to +\infty$。

- 分母：$\frac{1}{u} + 1 \to 1$
    
- 分子：那一坨 $\frac{\ln(1+u)}{u}$，根据洛必达法则或者直觉（对数增长远慢于幂函数），它的极限是 $0$。所以分子 $\to 1 + 0 = 1$。
    

最终极限：

$$\lim_{n \to \infty} \frac{f(n)\ln n}{n} = \frac{1}{1} = \mathbf{1}$$

做数列收敛的题，第一反应永远是“假设它收敛，看看极限到底是多少”。

假设数列 $\{x_n\}$ 收敛，且极限为 $a$。

我们在不等式 $x_{n+1} < 2 - \frac{1}{x_n}$ 两端同时取极限（注意：取极限后，严格的小于号 `<` 会变成小于等于号 `$\le$`）：

$$a \le 2 - \frac{1}{a}$$

现在来解这个不等式。因为是正项数列，所以 $a \ge 0$。两边同乘 $a$：

$$a^2 \le 2a - 1$$

移项整理：

$$a^2 - 2a + 1 \le 0$$

即：

$$(a - 1)^2 \le 0$$

任何实数的平方都不可能小于 0，所以它只能**等于 0**！

也就是说：**$a = 1$**。

**【结论】：** 如果这个数列收敛，它的极限**只能是 1**。直接排除了 A 和 C。接下来，我们只需要证明它确实收敛就行了。


怎么证明它收敛？老规矩：**单调有界准则**。

要判断单调性，最暴力的手法就是让**后一项减去前一项（$x_{n+1} - x_n$）**，看看结果是正还是负。

我们把题目给的不等式利用起来：

已知 $x_{n+1} < 2 - \frac{1}{x_n}$，所以：

$$x_{n+1} - x_n < 2 - \frac{1}{x_n} - x_n$$

接下来，对右边进行通分合并（这是全题最爽的一步）：

$$2 - \frac{1}{x_n} - x_n = \frac{2x_n - 1 - x_n^2}{x_n}$$

把分子的负号提出来：

$$= \frac{-(x_n^2 - 2x_n + 1)}{x_n}$$

$$= \frac{-(x_n - 1)^2}{x_n}$$


- 题目说了是“正项数列”，所以分母 $x_n > 0$（正数）。
    
- 分子是一个完全平方数带个负号，即 $-(x_n - 1)^2 \le 0$（非正数）。
    
    所以，整个分数必然 $\le 0$。
    

这就意味着：

$$x_{n+1} - x_n < 0 \implies x_{n+1} < x_n$$

**【结论】：** 这是一个**严格单调递减**的数列！

这题我提出个 x 方，能得出 a=-1，但 b 似乎无所谓啊，是几都不影响结果是 0

卡点：又是只顾整体忽略全局，外面还有个 x 方呢

我还原一下你提取 $x^2$ 的思路：

原式 $\implies \lim_{x \to \infty} x^2 \left( \frac{\sqrt[3]{1-x^6}}{x^2} - a - \frac{b}{x^2} \right) = 0$

你心想：当 $x \to \infty$ 时，$\frac{b}{x^2}$ 趋于 $0$，所以它没用了，直接扔掉。

然后括号里的前面部分趋于 $-1$，所以 $-1 - a = 0$，得出 $a = -1$。

**【致命破绽】：**

你忘了括号外面还乘着一个极其庞大的 $x^2 \to \infty$！

$\frac{b}{x^2}$ 虽然趋于 $0$，但如果把它和外面的 $x^2$ 重新乘起来：

$$x^2 \cdot \left( \frac{b}{x^2} \right) = b$$

你看！它根本不是 $0$，它是一个实实在在的常数 $b$！你把它当成 $0$ 提前扔掉，就等于把最终结果里的 $b$ 给强行抹杀了。



第二层：正统解法（泰勒展开的降维打击）

遇到这种 $x \to \infty$ 且带有根号的题，最稳妥、绝对不会丢精度的王道解法是：**强行提出最高次幂，构造出趋于 0 的项，然后用泰勒公式（广义二项式）展开。**

**第一步：给根号“洗底”**

为了能用泰勒公式，我们要把 $\sqrt[3]{1-x^6}$ 里面最大的 $-x^6$ 强行提出来：

$$\sqrt[3]{1-x^6} = \sqrt[3]{-x^6 \left(1 - \frac{1}{x^6}\right)} = -x^2 \left(1 - \frac{1}{x^6}\right)^{\frac{1}{3}}$$

**第二步：泰勒展开（精确打击）**

因为 $x \to \infty$，所以 $-\frac{1}{x^6} \to 0$。我们把它当成一个整体 $u$。

套用公式 $(1+u)^\alpha = 1 + \alpha u + o(u)$：

$$\left(1 - \frac{1}{x^6}\right)^{\frac{1}{3}} = 1 + \frac{1}{3} \left(-\frac{1}{x^6}\right) + o\left(\frac{1}{x^6}\right) = 1 - \frac{1}{3x^6} + o\left(\frac{1}{x^6}\right)$$

把外面的 $-x^2$ 乘回去：

$$-x^2 \left( 1 - \frac{1}{3x^6} + o\left(\frac{1}{x^6}\right) \right) = -x^2 + \frac{1}{3x^4} + o\left(\frac{1}{x^4}\right)$$

**第三步：代回原极限，合并同类项**

现在，把这串真实的底牌代回原题目：

$$\lim_{x \to \infty} \left( -x^2 + \frac{1}{3x^4} - ax^2 - b \right) = 0$$

把同次幂的项放在一起：

$$\lim_{x \to \infty} \left[ (-1 - a)x^2 - b + \frac{1}{3x^4} \right] = 0$$

**第四步：宣判结果**

要让这个式子在 $x \to \infty$ 时等于 $0$，它里面的每一项都必须配合：

1. **$x^2$ 的项不能爆炸**，所以系数必须为 0：$-1 - a = 0 \implies \mathbf{a = -1}$
    
2. **常数项也不能留下**，所以必须为 0：$-b = 0 \implies \mathbf{b = 0}$
    
3. 最后剩下的 $\frac{1}{3x^4}$，当 $x \to \infty$ 时自然趋于 $0$，完美符合题意。
    

所以，最终答案是：**$a = -1, \ b = 0$**。

要求上面的极限，我们必须知道当 $n \to \infty$ 时，$x_n$ 趋于几。

不用去严密证明（除非是大题要写过程），我们在草稿纸上用“直觉反证法”秒杀它：

- 已知 $x_n \in (0, 1)$。
    
- 等式是 $x_n^n = \cos x_n$。
    
- 当 $n$ 趋于无穷大时，如果 $x_n$ 不靠近 1（比如 $x_n$ 一直停留在 $0.5$ 左右），那么 $x_n^n$ （比如 $0.5^\infty$）就会被无情地**碾压成 0**。
    
- 如果左边变成 $0$ 了，那右边 $\cos x_n$ 也必须是 $0$，这就意味着 $x_n$ 得趋于 $\frac{\pi}{2}$（大约 1.57）。
    
- 但题目明说了 $x_n$ 在 $(0,1)$ 之间，怎么可能跑到 1.57 去？**矛盾！**
    

所以唯一的解释是：为了不让 $x_n^n$ 变成 0，$x_n$ 必须拼命地靠近 1（因为 $1^\infty$ 才有机会活下来）。

**结论：$\lim_{n \to \infty} x_n = 1$**。

你有没有发现，用你的方法硬洛，二次求导的计算量非常恐怖，极易算错？

答案为了避开这个“求导地狱”，用了一招极其高明的“变量代换（反向换元）”。

仔细看红框下面答案写的这句天书：

$\left[\frac{\ln(1+t)}{t} - 1\right]^2 \sim \left(-\frac{t}{2}\right)^2 = \frac{t^2}{4}$

**它到底在干嘛？**

我们令 $u = \frac{\ln(1+t)}{t}$。当 $t \to 0$ 时，$u \to 1$。

答案不是把 $u$ 展开成 $t$，而是**把分母的 $t$ 强行变成了 $u$！**

根据泰勒公式：

$u - 1 \sim -\frac{1}{2}t$

两边同乘 $-2$，得到：

**$t \sim -2(u - 1)$**

两边平方，得出分母的等价替换：

**$t^2 \sim 4(u - 1)^2$**

现在，见证奇迹的时刻到了。答案把原本关于 $t$ 的极限，彻底变成了关于 $u$ 的极限：

$$\lim_{t \to 0} \frac{e^u - e u}{t^2} \implies \lim_{u \to 1} \frac{e^u - e u}{4(u - 1)^2}$$

这时候你再去对 $u$ 洛必达，简直就像喝水一样简单！

- **第一次洛必达（对 $u$ 求导）**：$\frac{e^u - e}{8(u - 1)}$
    
- **第二次洛必达（对 $u$ 求导）**：$\frac{e^u}{8}$
    
    代入 $u = 1$，瞬间得到 **$\frac{e}{8}$**！

注意，
n+1 分之 n 乘 lnn，不能直接把 n+1 分之 n 变为 1！

### 第一重失误：你弄丢了原题里的一个 $n$![[_attachments/image/06强化-880综合拓展-1780405704445.jpeg]]

你对比一下原题的公式和你红笔写的第一个大分式：

- **原题分子：** $n \cdot (\sqrt[n]{n+1} - \dots)$
    
- **你的红笔：** $\frac{\frac{\ln(1+n)}{n} - \frac{\ln n}{n+1}}{\frac{1}{n}\ln n}$
    

发现了吗？原题分子最前面明明乘着一个巨大的 **$n$**，你在红笔列式子的时候，**直接把它给弄丢了！**

因为你丢了这个 $n$，你算出来的那个 $= \frac{\ln(1+n)}{\ln n} - \frac{n}{n+1}$，其实只是真实表达式的 **$\frac{1}{n}$**。

所以，真实完整的化简结果应该是：

$$n \cdot \left( \frac{\ln(n+1)}{\ln n} - \frac{n}{n+1} \right)$$

### 第二重失误：无视了 $\infty \times 0$ 陷阱（致命打脸）

现在我们把弄丢的 $n$ 补回来。

你刚才算出括号里那坨东西的极限是 $1 - 1 = 0$。

如果你直接把它代进去，整个极限就变成了：

$$\lim_{n \to \infty} n \cdot 0$$

这可是微积分里最臭名昭著的 **$\infty \times 0$ 型未定式**！

你绝对不能说 $\infty \times 0 = 0$。括号里的东西虽然趋于 $0$，但外面那个 $n$ 趋于无穷大，它们俩“神仙打架”，最后到底是谁赢，必须用泰勒公式把括号里的精度展开得更细才行。


我们对括号里的两项分别做精确的泰勒展开：

1. **第一项：** $\frac{\ln(n+1)}{\ln n} = \frac{\ln n + \ln(1+\frac{1}{n})}{\ln n} = 1 + \frac{\ln(1+\frac{1}{n})}{\ln n} \sim 1 + \frac{\frac{1}{n}}{\ln n} = 1 + \frac{1}{n\ln n}$
    
2. **第二项：** $\frac{n}{n+1} = \frac{1}{1+\frac{1}{n}} \sim 1 - \frac{1}{n}$
    

现在，把它们真刀真枪地减一下（保留细节）：

$$\left(1 + \frac{1}{n\ln n}\right) - \left(1 - \frac{1}{n}\right) = \frac{1}{n\ln n} + \frac{1}{n}$$

提取公因式 $\frac{1}{n}$：

$$= \frac{1}{n} \left( 1 + \frac{1}{\ln n} \right)$$

### 绝杀时刻：外面那个 $n$ 的复仇

把我们刚才补回来的那个 $n$ 乘上去：

$$n \cdot \left[ \frac{1}{n} \left( 1 + \frac{1}{\ln n} \right) \right] = 1 + \frac{1}{\ln n}$$

当 $n \to \infty$ 时，$\frac{1}{\ln n} \to 0$。

所以，最终真正的极限是 **$1 + 0 = 1$**！

![[_attachments/image/06强化-880综合拓展-1780452060325.jpeg]] ### 第一步：拿下 (I) 问 —— 几何直觉与代数碾压

**【考场思路】**：

题目让你证 $f(k+1) \le \int_k^{k+1} f(x) dx \le f(k)$。

这其实就是著名的“积分中值定理”**或者**“定积分保号性”的直接应用。

- **几何视角（看一眼就懂）：**
    
    因为 $f(x)$ 是递减的（往下走），所以在 $[k, k+1]$ 这个宽度为 1 的区间里：
    
    - 左端点最高，高为 $f(k)$。以它为高的矩形，面积是 $f(k) \times 1 = f(k)$，这显然比曲线下方的面积大（天花板）。
        
    - 右端点最低，高为 $f(k+1)$。以它为高的矩形，面积是 $f(k+1) \times 1 = f(k+1)$，这显然比曲线下方的面积小（地板）。
        
    - 中间真实的曲线下面积，就是定积分 $\int_k^{k+1} f(x) dx$。
        

**【答题卡满分写法】**：

因为 $f(x)$ 在 $[0, +\infty)$ 上单调减少，

所以对于任意 $x \in [k, k+1]$，都有：

$$f(k+1) \le f(x) \le f(k)$$

对这个不等式在 $[k, k+1]$ 上同时取定积分：

$$\int_k^{k+1} f(k+1) dx \le \int_k^{k+1} f(x) dx \le \int_k^{k+1} f(k) dx$$

因为 $\int_k^{k+1} 1 dx = (k+1) - k = 1$，常数可以直接提出来，所以：

$$f(k+1) \le \int_k^{k+1} f(x) dx \le f(k)$$

（第一问证毕，2分钟稳稳拿分。）

### 第二步：破解 (II) 问前半部分 —— “对号入座”与“累加大法”

**【考场思路】**：

题目要我们证 $\ln(1+n) \le 1 + \frac{1}{2} + \dots + \frac{1}{n} \le 1 + \ln n$。

开始“对号入座”：

1. 看看中间那坨和式，通项是 $\frac{1}{k}$。
    
2. 结合第一问的 $f(k)$，傻子都能看出来，命题人是在按着你的头让你令 **$f(x) = \frac{1}{x}$**！
    

我们把 $f(x) = \frac{1}{x}$ 代入第一问的结论：

$$\frac{1}{k+1} \le \int_k^{k+1} \frac{1}{x} dx \le \frac{1}{k}$$

把中间的积分积出来，得到：

$$\frac{1}{k+1} \le \ln(k+1) - \ln k \le \frac{1}{k}$$

接下来，这是全题最容易卡住的地方：**怎么把它变成题目要求的累加形式？**

我们需要把 $k$ 从 1 跑到 $n$ 进行累加。这里我们要**分左右两边来处理，并且稍微调整一下步数**（这是考研最爱考的细节陷阱）。

**【证左边：$\ln(1+n) \le 1 + \frac{1}{2} + \dots + \frac{1}{n}$】**

我们取不等式的**右半边**：$\ln(k+1) - \ln k \le \frac{1}{k}$

让 $k$ 从 $1$ 累加到 $n$：

$$\sum_{k=1}^n (\ln(k+1) - \ln k) \le \sum_{k=1}^n \frac{1}{k}$$

左边发生了神奇的“裂项相消”（中间项全部抵消）：

$$(\ln 2 - \ln 1) + (\ln 3 - \ln 2) + \dots + (\ln(n+1) - \ln n) = \ln(n+1) - \ln 1 = \ln(n+1)$$

所以：

$$\ln(n+1) \le 1 + \frac{1}{2} + \dots + \frac{1}{n}$$

（左边证毕！）

**【证右边：$1 + \frac{1}{2} + \dots + \frac{1}{n} \le 1 + \ln n$】**

我们取不等式的**左半边**：$\frac{1}{k+1} \le \ln(k+1) - \ln k$

注意！为了凑出 $1 + \frac{1}{2} + \dots + \frac{1}{n}$，我们**只让 $k$ 从 $1$ 累加到 $n-1$**：

$$\sum_{k=1}^{n-1} \frac{1}{k+1} \le \sum_{k=1}^{n-1} (\ln(k+1) - \ln k)$$

左边变成了：$\frac{1}{2} + \frac{1}{3} + \dots + \frac{1}{n}$

右边裂项相消变成了：$\ln n - \ln 1 = \ln n$

所以得出：

$$\frac{1}{2} + \frac{1}{3} + \dots + \frac{1}{n} \le \ln n$$

不等式两边**同时加上 1**：

$$1 + \frac{1}{2} + \dots + \frac{1}{n} \le 1 + \ln n$$

（右边证毕！）

### 第三步：绝杀 (II) 问后半部分 —— 夹逼准则收尾

现在，不等式链已经彻底焊死了：

$$\ln(1+n) \le 1 + \frac{1}{2} + \dots + \frac{1}{n} \le 1 + \ln n$$

题目要求 $\lim_{n \to \infty} \frac{1 + \frac{1}{2} + \dots + \frac{1}{n}}{\ln n}$。

遇到这种“被夹在中间求极限”的，直接上**夹逼准则**！

我们将不等式的三边，同时除以 $\ln n$ （因为 $n>1$ 时 $\ln n > 0$，不等号方向不变）：

$$\frac{\ln(1+n)}{\ln n} \le \frac{1 + \frac{1}{2} + \dots + \frac{1}{n}}{\ln n} \le \frac{1 + \ln n}{\ln n}$$

现在看两头的极限（当 $n \to \infty$）：

- **左边极限：** $\lim_{n \to \infty} \frac{\ln(1+n)}{\ln n} = \lim_{n \to \infty} \frac{\ln[n(1+\frac{1}{n})]}{\ln n} = \lim_{n \to \infty} \frac{\ln n + \ln(1+\frac{1}{n})}{\ln n} = \lim_{n \to \infty} \left( 1 + \frac{\ln(1+\frac{1}{n})}{\ln n} \right) = 1 + 0 = \mathbf{1}$
    
- **右边极限：** $\lim_{n \to \infty} \frac{1 + \ln n}{\ln n} = \lim_{n \to \infty} \left( \frac{1}{\ln n} + 1 \right) = 0 + 1 = \mathbf{1}$
    

两头都被死死夹成了 1，所以中间的极限也只能是 **1**。

大功告成！
