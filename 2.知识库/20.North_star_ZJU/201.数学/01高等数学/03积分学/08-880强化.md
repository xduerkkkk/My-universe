如果这是解答题，画图不能作为严谨步骤，我们需要用**对称区间积分性质（利用 $t = -x$ 拆区间法）**来证明。

#### 证明 ①：
$$\int_{-\pi}^{\pi} f(x) \sin x \text{d}x = \int_{-\pi}^{0} f(x) \sin x \text{d}x + \int_{0}^{\pi} f(x) \sin x \text{d}x$$
对前半部分令 $t = -x$，可化为 $-\int_{0}^{\pi} f(-t) \sin t \text{d}t$。合并后得：
$$\int_{-\pi}^{\pi} f(x) \sin x \text{d}x = \int_{0}^{\pi} [f(x) - f(-x)] \sin x \text{d}x$$
* 因为 $f'(x) < 0$（单调递减），且在区间 $(0, \pi)$ 内有 $x > -x$，所以 $f(x) < f(-x) \implies f(x) - f(-x) < 0$。
* 在 $(0, \pi)$ 内 $\sin x > 0$。
* 乘积恒小于 0，因此积分值 **$< 0$**。

#### 证明 ④：
同理，利用对称性拆区间合并，可得：
$$\int_{-\pi}^{\pi} f(x) \cos x \text{d}x = \int_{0}^{\pi} [f(x) + f(-x)] \cos x \text{d}x$$
令 $g(x) = f(x) + f(-x)$，由于 $f''(x) > 0$，容易证得 $g(x)$ 是一个偶函数且在 $x > 0$ 时单调递增。
我们把积分在 $\frac{\pi}{2}$ 处断开，并对后半部分采用区间再现公式，最终可以整理为：
$$\int_{0}^{\frac{\pi}{2}} [g(x) - g(\pi - x)] \cos x \text{d}x$$
* 因为 $g(x)$ 在 $x > 0$ 时单调递增，且 $x < \pi - x$，所以 $g(x) < g(\pi - x) \implies g(x) - g(\pi - x) < 0$。
* 在 $(0, \frac{\pi}{2})$ 内 $\cos x > 0$。
* 乘积恒小于 0，因此积分值 **$< 0$**。

### 解法一：区间拆分消去法（最直观）

我们将分子上的积分拆成两部分，并对第一部分进行**换元**：

#### 1. 拆开积分并换元
原极限中的分子为：
$$I = \int_{x_0}^x f(t + \Delta x) \text{d}t - \int_{x_0}^x f(t) \text{d}t$$

对于第一部分 $\int_{x_0}^x f(t + \Delta x) \text{d}t$，我们令 $u = t + \Delta x$（即 $t = u - \Delta x$）：
* 当 $t = x_0$ 时，$u = x_0 + \Delta x$；
* 当 $t = x$ 时，$u = x + \Delta x$；
* 微分关系为 $\text{d}t = \text{d}u$。

代入换元，第一部分变为：
$$\int_{x_0 + \Delta x}^{x + \Delta x} f(u) \text{d}u \quad (\text{即} \int_{x_0 + \Delta x}^{x + \Delta x} f(t) \text{d}t)$$

#### 2. 区间拆分与项抵消
现在，分子变成了：
$$I = \int_{x_0 + \Delta x}^{x + \Delta x} f(t) \text{d}t - \int_{x_0}^x f(t) \text{d}t$$

利用定积分对区间的可加性，我们将第一部分积分区间 $[x_0 + \Delta x, x + \Delta x]$ 拆成三段：
$$\int_{x_0 + \Delta x}^{x + \Delta x} f(t) \text{d}t = \int_{x_0 + \Delta x}^{x_0} f(t) \text{d}t + \int_{x_0}^x f(t) \text{d}t + \int_x^{x + \Delta x} f(t) \text{d}t$$

代回原式后，我们发现**中间的 $\int_{x_0}^x f(t) \text{d}t$ 被完美减掉（抵消）了**！
只剩下两端：
$$I = \int_x^{x + \Delta x} f(t) \text{d}t + \int_{x_0 + \Delta x}^{x_0} f(t) \text{d}t = \int_x^{x + \Delta x} f(t) \text{d}t - \int_{x_0}^{x_0 + \Delta x} f(t) \text{d}t$$

#### 3. 求极限
现在代入极限式中：
$$\lim_{\Delta x \to 0} \frac{I}{\Delta x} = \lim_{\Delta x \to 0} \frac{1}{\Delta x} \int_x^{x + \Delta x} f(t) \text{d}t - \lim_{\Delta x \to 0} \frac{1}{\Delta x} \int_{x_0}^{x_0 + \Delta x} f(t) \text{d}t$$

根据积分中值定理或导数定义，当 $\Delta x \to 0$ 时：
* $\frac{1}{\Delta x} \int_x^{x + \Delta x} f(t) \text{d}t \to f(x)$
* $\frac{1}{\Delta x} \int_{x_0}^{x_0 + \Delta x} f(t) \text{d}t \to f(x_0)$

所以，最终极限结果为：
$$f(x) - f(x_0)$$

### 解法二：导数定义法（概念最清晰）

我们可以把这个极限看作是一个**函数关于自变量 $\Delta x$ 的导数**。

#### 1. 构造辅助函数
为了书写方便，我们令 $y = \Delta x$，构造关于 $y$ 的函数：
$$H(y) = \int_{x_0}^x f(t + y) \text{d}t$$

显而易见，当 $y = 0$ 时：
$$H(0) = \int_{x_0}^x f(t) \text{d}t$$

那么，原极限式可以写为：
$$\lim_{y \to 0} \frac{\int_{x_0}^x f(t + y) \text{d}t - \int_{x_0}^x f(t) \text{d}t}{y} = \lim_{y \to 0} \frac{H(y) - H(0)}{y}$$
这正好就是函数 $H(y)$ 在 $y = 0$ 处的**导数定义**，即：
$$\text{原极限} = H'(0)$$

#### 2. 换元求导
我们对 $H(y)$ 内部做换元 $u = t+y$：
$$H(y) = \int_{x_0 + y}^{x + y} f(u) \text{d}u$$

根据微积分基本定理（变限积分求导公式），对 $y$ 求导：
$$H'(y) = f(x + y) \cdot \frac{\text{d}(x+y)}{\text{d}y} - f(x_0 + y) \cdot \frac{\text{d}(x_0+y)}{\text{d}y} = f(x + y) - f(x_0 + y)$$

#### 3. 代入 $y=0$
所以，极限值 $H'(0)$ 为：
$$H'(0) = f(x) - f(x_0)$$
