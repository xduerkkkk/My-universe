如果这是解答题，画图不能作为严谨步骤，我们需要用**对称区间积分性质（利用 $t = -x$ 拆区间法）**来证明。

#### 证明 ①：
$$\int_{-\pi}^{\pi} f(x) \sin x \text{d}x = \int_{-\pi}^{0} f(x) \sin x \text{d}x + \int_{0}^{\pi} f(x) \sin x \text{d}x$$
对前半部分令 $t = -x$，可化为 $-\int_{0}^{\pi} f(-t) \sin t \text{d}t$。合并后得：
$$\int_{-\pi}^{\pi} f(x) \sin x \text{d}x = \int_{0}^{\pi} [f(x) - f(-x)] \sin x \text{d}x$$
* 因为 $f'(x) < 0$（单调递减），且在区间 $(0, \pi)$ 内有 $x > -x$，所以 $f(x) < f(-x) \implies f(x) - f(-x) < 0$。
* 在 $(0, \pi)$ 内 $\sin x > 0$。
* 乘积恒小于 0，因此积分值 **$< 0$**。

#### 证明 ④：
同理，利用对称性拆区间合并，可得：
$$\int_{-\pi}^{\pi} f(x) \cos x \text{d}x = \int_{0}^{\pi} [f(x) + f(-x)] \cos x \text{d}x$$
令 $g(x) = f(x) + f(-x)$，由于 $f''(x) > 0$，容易证得 $g(x)$ 是一个偶函数且在 $x > 0$ 时单调递增。
我们把积分在 $\frac{\pi}{2}$ 处断开，并对后半部分采用区间再现公式，最终可以整理为：
$$\int_{0}^{\frac{\pi}{2}} [g(x) - g(\pi - x)] \cos x \text{d}x$$
* 因为 $g(x)$ 在 $x > 0$ 时单调递增，且 $x < \pi - x$，所以 $g(x) < g(\pi - x) \implies g(x) - g(\pi - x) < 0$。
* 在 $(0, \frac{\pi}{2})$ 内 $\cos x > 0$。
* 乘积恒小于 0，因此积分值 **$< 0$**。

### 解法一：区间拆分消去法（最直观）

我们将分子上的积分拆成两部分，并对第一部分进行**换元**：

#### 1. 拆开积分并换元
原极限中的分子为：
$$I = \int_{x_0}^x f(t + \Delta x) \text{d}t - \int_{x_0}^x f(t) \text{d}t$$

对于第一部分 $\int_{x_0}^x f(t + \Delta x) \text{d}t$，我们令 $u = t + \Delta x$（即 $t = u - \Delta x$）：
* 当 $t = x_0$ 时，$u = x_0 + \Delta x$；
* 当 $t = x$ 时，$u = x + \Delta x$；
* 微分关系为 $\text{d}t = \text{d}u$。

代入换元，第一部分变为：
$$\int_{x_0 + \Delta x}^{x + \Delta x} f(u) \text{d}u \quad (\text{即} \int_{x_0 + \Delta x}^{x + \Delta x} f(t) \text{d}t)$$

#### 2. 区间拆分与项抵消
现在，分子变成了：
$$I = \int_{x_0 + \Delta x}^{x + \Delta x} f(t) \text{d}t - \int_{x_0}^x f(t) \text{d}t$$

利用定积分对区间的可加性，我们将第一部分积分区间 $[x_0 + \Delta x, x + \Delta x]$ 拆成三段：
$$\int_{x_0 + \Delta x}^{x + \Delta x} f(t) \text{d}t = \int_{x_0 + \Delta x}^{x_0} f(t) \text{d}t + \int_{x_0}^x f(t) \text{d}t + \int_x^{x + \Delta x} f(t) \text{d}t$$

代回原式后，我们发现**中间的 $\int_{x_0}^x f(t) \text{d}t$ 被完美减掉（抵消）了**！
只剩下两端：
$$I = \int_x^{x + \Delta x} f(t) \text{d}t + \int_{x_0 + \Delta x}^{x_0} f(t) \text{d}t = \int_x^{x + \Delta x} f(t) \text{d}t - \int_{x_0}^{x_0 + \Delta x} f(t) \text{d}t$$

#### 3. 求极限
现在代入极限式中：
$$\lim_{\Delta x \to 0} \frac{I}{\Delta x} = \lim_{\Delta x \to 0} \frac{1}{\Delta x} \int_x^{x + \Delta x} f(t) \text{d}t - \lim_{\Delta x \to 0} \frac{1}{\Delta x} \int_{x_0}^{x_0 + \Delta x} f(t) \text{d}t$$

根据积分中值定理或导数定义，当 $\Delta x \to 0$ 时：
* $\frac{1}{\Delta x} \int_x^{x + \Delta x} f(t) \text{d}t \to f(x)$
* $\frac{1}{\Delta x} \int_{x_0}^{x_0 + \Delta x} f(t) \text{d}t \to f(x_0)$

所以，最终极限结果为：
$$f(x) - f(x_0)$$

---

### 解法二：导数定义法（概念最清晰）

我们可以把这个极限看作是一个**函数关于自变量 $\Delta x$ 的导数**。

#### 1. 构造辅助函数
为了书写方便，我们令 $y = \Delta x$，构造关于 $y$ 的函数：
$$H(y) = \int_{x_0}^x f(t + y) \text{d}t$$

显而易见，当 $y = 0$ 时：
$$H(0) = \int_{x_0}^x f(t) \text{d}t$$

那么，原极限式可以写为：
$$\lim_{y \to 0} \frac{\int_{x_0}^x f(t + y) \text{d}t - \int_{x_0}^x f(t) \text{d}t}{y} = \lim_{y \to 0} \frac{H(y) - H(0)}{y}$$
这正好就是函数 $H(y)$ 在 $y = 0$ 处的**导数定义**，即：
$$\text{原极限} = H'(0)$$

#### 2. 换元求导
我们对 $H(y)$ 内部做换元 $u = t+y$：
$$H(y) = \int_{x_0 + y}^{x + y} f(u) \text{d}u$$

根据微积分基本定理（变限积分求导公式），对 $y$ 求导：
$$H'(y) = f(x + y) \cdot \frac{\text{d}(x+y)}{\text{d}y} - f(x_0 + y) \cdot \frac{\text{d}(x_0+y)}{\text{d}y} = f(x + y) - f(x_0 + y)$$

#### 3. 代入 $y=0$
所以，极限值 $H'(0)$ 为：
$$H'(0) = f(x) - f(x_0)$$

根据极限结果，我们得到了一个关于 $f(x)$ 的一阶微分方程：
$$\frac{f'(x) \sin x}{f(x)} = \frac{\sin x - x \cos x}{x}$$

$$\frac{f'(x)}{f(x)} = \frac{1}{x} - \frac{\cos x}{\sin x} = \frac{1}{x} - \cot x$$

$$f(x) = \frac{C x}{\sin x}$$

$$f(x) = \frac{x}{\sin x}$$

你的做法（求出 $f(x)$ 表达式 $\to$ 反求出 $g(x)$ 表达式 $\to$ 求导代入）在数学上是**完全正确**的，在遇到能轻松写出反函数的题目时也完全可行。

但答案采用的方法是高数中极为经典的**“反函数求导法则”**。这个方法不需要你求出反函数 $g(x)$ 的具体表达式，就能直接算出某一点的导数值。

下面我为你拆解一下最后这几步的逻辑，以及为什么这个方法更强大：

---

### 1. 核心武器：反函数求导法则

如果 $y = f(x)$ 与 $x = g(y)$ 互为反函数，那么它们在对应点处的导数互为倒数：
$$g'(y_0) = \frac{1}{f'(x_0)} \quad \left(其中\ y_0 = f(x_0)，即\ g(y_0) = x_0\right)$$

这就是：**反函数的导数 = 原函数导数的倒数。**

---

### 2. 答案最后几步的推导过程

我们要计算的是 $g'(3)$：
1. **寻找对应点**：
   这里的自变量是 $y_0 = 3$。我们要找对应的 $x_0$ 是多少，也就是满足 $f(x_0) = 3$ 的那个 $x_0$。
   根据题目条件（或代入 $f(x) = \text{e}^{x-1} + 2 = 3$），我们知道：
   $$f(1) = 3 \implies g(3) = 1$$
   所以，对应点为 $(x_0, y_0) = (1, 3)$。

2. **套用公式**：
   根据反函数求导法则：
   $$g'(3) = \frac{1}{f'(1)}$$

3. **求 $f'(1)$ 并代入**：
   我们已知 $f(x) = \text{e}^{x-1} + 2$，对其求导：
   $$f'(x) = \text{e}^{x-1}$$
   代入 $x=1$：
   $$f'(1) = \text{e}^{1-1} = \text{e}^0 = 1$$
   所以：
   $$g'(3) = \frac{1}{f'(1)} = \frac{1}{1} = 1$$

第一部分：$\lim_{n \to \infty} \sum_{k=1}^n \frac{k}{2n^2 + k}$ —— 考查【夹逼定理】

#### 💡 怎么看出来的？（考点识别特征）
观察分母：大头是 $2n^2$，而变化的部分是 $k$（一阶）。
* 分母的次方（$2$ 次方）**大于**分子的次方（$1$ 次方）。
* 这种“分母变化微弱（分母的大头太强，加个 $k$ 几乎不影响大小）”的求和，**无法直接凑出 $\frac{k}{n}$ 形式的定积分**，必须优先考虑**夹逼定理**。

#### 🎯 快速计算过程：
因为 $1 \le k \le n$，我们可以把分母中的 $k$ 放大和缩小：
$$\frac{k}{2n^2 + n} \le \frac{k}{2n^2 + k} \le \frac{k}{2n^2 + 1}$$
两边同时求和（利用 $\sum_{k=1}^n k = \frac{n(n+1)}{2}$）：
$$\frac{n(n+1)}{2(2n^2 + n)} \le \sum_{k=1}^n \frac{k}{2n^2 + k} \le \frac{n(n+1)}{2(2n^2 + 1)}$$
当 $n \to \infty$ 时，左、右两边的极限都是：
$$\lim_{n \to \infty} \frac{n^2 + n}{4n^2 + 2n} = \frac{1}{4}$$
根据**夹逼定理**，第一部分的极限值为 **$\frac{1}{4}$**。

---

### 第二部分：$\lim_{n \to \infty} \sum_{k=1}^n \ln\left(\frac{n+k}{n}\right)^{\frac{1}{n}}$ —— 考查【定积分定义】

#### 💡 怎么看出来的？（考点识别特征）
我们先把对数的幂次提到前面：
$$\sum_{k=1}^n \frac{1}{n} \ln\left(1 + \frac{k}{n}\right)$$
* 它的特征太明显了：外面有一个 **$\frac{1}{n}$**，里面所有的变量都完美打包成了 **$\frac{k}{n}$** 的形式。
* 只要满足 **$\frac{1}{n} \sum f\left(\frac{k}{n}\right)$** 这种标准格式，就是百分之百在考查**定积分定义**。

#### 🎯 快速计算过程：
根据定积分定义 $\lim_{n \to \infty} \frac{1}{n} \sum_{k=1}^n f(\frac{k}{n}) = \int_0^1 f(x) \text{d}x$，我们直接把 $\frac{k}{n}$ 替换为 $x$：
$$\int_0^1 \ln(1+x) \text{d}x$$
利用分部积分法（或换元 $u = 1+x$）：
$$\int_1^2 \ln u \text{d}u = [u\ln u - u]_1^2 = (2\ln 2 - 2) - (0 - 1) = 2\ln 2 - 1$$
所以，第二部分的极限值为 **$2\ln 2 - 1$**。

我们要计算的极限为：
$$\lim_{x \to 0^+} \frac{\int_x^{+\infty} \frac{\text{e}^{-t}}{t} \text{d}t}{\ln \frac{1}{x}}$$

1. **看分母**：
   当 $x \to 0^+$ 时，$\frac{1}{x} \to +\infty$，所以：
   $$\lim_{x \to 0^+} \ln \frac{1}{x} = +\infty$$

2. **看分子**：
   分子是一个无穷区间上的积分。我们把它在 $t=1$ 处拆开：
   $$\int_x^{+\infty} \frac{\text{e}^{-t}}{t} \text{d}t = \int_x^1 \frac{\text{e}^{-t}}{t} \text{d}t + \int_1^{+\infty} \frac{\text{e}^{-t}}{t} \text{d}t$$
   * 后半部分 $\int_1^{+\infty} \frac{\text{e}^{-t}}{t} \text{d}t$ 是一个收敛的**常数**（因为在 $[1, +\infty)$ 上 $\frac{\text{e}^{-t}}{t} \le \text{e}^{-t}$，积出来是有限值）。
   * 前半部分在 $t \to 0^+$ 时，$\text{e}^{-t} \to 1$，所以被积函数相当于 $\frac{1}{t}$。而我们知道 $\int_x^1 \frac{1}{t}\text{d}t = -\ln x \to +\infty$。
   * 因此，整个分子在 $x \to 0^+$ 时也趋于 **$+\infty$**。

**结论**：这是一个标准的 **$\frac{\infty}{\infty}$** 型未定式，可以直接使用**洛必达法则**。

---



既然自变量是 $x$，我们对分子和分母分别关于 $x$ 求导：

1. **分母求导**：
   我们先将分母化简：$\ln \frac{1}{x} = -\ln x$。
   对其关于 $x$ 求导：
   $$\frac{\text{d}}{\text{d}x} (-\ln x) = -\frac{1}{x}$$

2. **分子求导（变限积分求导）**：
   分子是 $\int_x^{+\infty} \frac{\text{e}^{-t}}{t} \text{d}t$。
   * 注意：因为上限 $+\infty$ 是常数，下限 $x$ 是自变量。
   根据变限积分求导公式，对其关于 $x$ 求导（下限求导要多一个负号）：
   $$\frac{\text{d}}{\text{d}x} \int_x^{+\infty} \frac{\text{e}^{-t}}{t} \text{d}t = -\frac{\text{e}^{-x}}{x}$$

---


现在，我们将分子分母求导后的结果代回原极限式：

$$\lim_{x \to 0^+} \frac{\left( \int_x^{+\infty} \frac{\text{e}^{-t}}{t} \text{d}t \right)'}{\left( \ln \frac{1}{x} \right)'} = \lim_{x \to 0^+} \frac{-\frac{\text{e}^{-x}}{x}}{-\frac{1}{x}}$$

两边的负号抵消，并且分子分母上的 $\frac{1}{x}$ **完美消去**：

$$= \lim_{x \to 0^+} \text{e}^{-x}$$

当 $x \to 0^+$ 时，$\text{e}^{-x} \to \text{e}^0 = 1$。
