如果这是解答题，画图不能作为严谨步骤，我们需要用**对称区间积分性质（利用 $t = -x$ 拆区间法）**来证明。

#### 证明 ①：
$$\int_{-\pi}^{\pi} f(x) \sin x \text{d}x = \int_{-\pi}^{0} f(x) \sin x \text{d}x + \int_{0}^{\pi} f(x) \sin x \text{d}x$$
对前半部分令 $t = -x$，可化为 $-\int_{0}^{\pi} f(-t) \sin t \text{d}t$。合并后得：
$$\int_{-\pi}^{\pi} f(x) \sin x \text{d}x = \int_{0}^{\pi} [f(x) - f(-x)] \sin x \text{d}x$$
* 因为 $f'(x) < 0$（单调递减），且在区间 $(0, \pi)$ 内有 $x > -x$，所以 $f(x) < f(-x) \implies f(x) - f(-x) < 0$。
* 在 $(0, \pi)$ 内 $\sin x > 0$。
* 乘积恒小于 0，因此积分值 **$< 0$**。

#### 证明 ④：
同理，利用对称性拆区间合并，可得：
$$\int_{-\pi}^{\pi} f(x) \cos x \text{d}x = \int_{0}^{\pi} [f(x) + f(-x)] \cos x \text{d}x$$
令 $g(x) = f(x) + f(-x)$，由于 $f''(x) > 0$，容易证得 $g(x)$ 是一个偶函数且在 $x > 0$ 时单调递增。
我们把积分在 $\frac{\pi}{2}$ 处断开，并对后半部分采用区间再现公式，最终可以整理为：
$$\int_{0}^{\frac{\pi}{2}} [g(x) - g(\pi - x)] \cos x \text{d}x$$
* 因为 $g(x)$ 在 $x > 0$ 时单调递增，且 $x < \pi - x$，所以 $g(x) < g(\pi - x) \implies g(x) - g(\pi - x) < 0$。
* 在 $(0, \frac{\pi}{2})$ 内 $\cos x > 0$。
* 乘积恒小于 0，因此积分值 **$< 0$**。

看到 $f(0)=0, f'(0)=6$。
**大脑瞬间反应：**
*   这不就是泰勒展开的第一项吗？
*   在 $x \to 0$ 附近，函数可以直接近似为一条直线：$f(x) \approx f(0) + f'(0)x = 0 + 6x$。
*   **提取核心武器：** 当 $x \to 0$ 时，$f(x) \sim 6x$。

### 第二步：速算 $\alpha(x)$ 的阶数（耗时 10 秒）
已知 $\alpha(x) = \int_{0}^{x^3} f(t) dt$。
**考场内心 OS：**
*   把积分里的 $f(t)$ 直接用 $6t$ 替换掉。
*   $\int 6t \, dt$ 积出来是 $3t^2$。
*   把上限 $x^3$ 代入进去：$3 \cdot (x^3)^2 = 3x^6$。
*   **得出结论：** $\alpha(x) \sim 3x^6$。

### 第三步：速算 $\beta(x)$ 的阶数（耗时 10 秒）
已知 $\beta(x) = \left[ \int_{0}^{x} f(t) dt \right]^3$。
**考场内心 OS：**
*   先算括号里面的积分。同样把 $f(t)$ 替换成 $6t$。
*   $\int_{0}^{x} 6t \, dt$ 积出来就是 $3x^2$。
*   外面还有一个三次方：$(3x^2)^3 = 27x^6$。
*   **得出结论：** $\beta(x) \sim 27x^6$。

### 第四步：对比定论（耗时 5 秒）
*   现在我们要比较 $\alpha(x)$ 和 $\beta(x)$。
*   $\alpha(x)$ 是 $3x^6$ 级别的。
*   $\beta(x)$ 是 $27x^6$ 级别的。
*   它们的 $x$ 次数都是 6 次，说明它们是**同阶**的。
*   但是前面的系数一个是 3，一个是 27（它们的比值是 $\frac{3}{27} = \frac{1}{9} \neq 1$），说明它们**不互相等价**。
*   **得出最终结果：** 同阶但非等价无穷小，选 A。

### 考场思维总结与避坑指南

1.  **核心技巧：“局部线性化代换”**
    遇到涉及变上限积分的无穷小比较，只要被积函数在积分下限（通常是 0）处的值为 0 且可导，直接用 $f'(0)x$ 去替换原函数。这比用洛必达法则求导快无数倍，且不容易算错系数。
2.  **严谨性补充（防杠）：**
    为什么考场上敢直接在积分号里用等价无穷小代换？
    因为根据微积分原理，如果 $f(t) \sim g(t)$ 且 $g(t)$ 不变号，那么 $\int_0^x f(t)dt \sim \int_0^x g(t)dt$。这里 $f(t) \sim 6t$，满足定理条件。考场上直接用这个结论即可，不需要现场证明。

*   **题眼：** 积分号内出现了 $f(x+a)$ 或 $f(t+\Delta x)$ 这种**平移项**，且题目**仅告知连续**。
*   **触发操作：不要在积分号内凑微分/导数，直接换元！把括号里的复杂变量转移到积分上下限去！**

### 解法一：区间拆分消去法（最直观）

我们将分子上的积分拆成两部分，并对第一部分进行**换元**：

#### 1. 拆开积分并换元
原极限中的分子为：
$$I = \int_{x_0}^x f(t + \Delta x) \text{d}t - \int_{x_0}^x f(t) \text{d}t$$

对于第一部分 $\int_{x_0}^x f(t + \Delta x) \text{d}t$，我们令 $u = t + \Delta x$（即 $t = u - \Delta x$）：
* 当 $t = x_0$ 时，$u = x_0 + \Delta x$；
* 当 $t = x$ 时，$u = x + \Delta x$；
* 微分关系为 $\text{d}t = \text{d}u$。

代入换元，第一部分变为：
$$\int_{x_0 + \Delta x}^{x + \Delta x} f(u) \text{d}u \quad (\text{即} \int_{x_0 + \Delta x}^{x + \Delta x} f(t) \text{d}t)$$

#### 2. 区间拆分与项抵消
现在，分子变成了：
$$I = \int_{x_0 + \Delta x}^{x + \Delta x} f(t) \text{d}t - \int_{x_0}^x f(t) \text{d}t$$

利用定积分对区间的可加性，我们将第一部分积分区间 $[x_0 + \Delta x, x + \Delta x]$ 拆成三段：
$$\int_{x_0 + \Delta x}^{x + \Delta x} f(t) \text{d}t = \int_{x_0 + \Delta x}^{x_0} f(t) \text{d}t + \int_{x_0}^x f(t) \text{d}t + \int_x^{x + \Delta x} f(t) \text{d}t$$

代回原式后，我们发现**中间的 $\int_{x_0}^x f(t) \text{d}t$ 被完美减掉（抵消）了**！
只剩下两端：
$$I = \int_x^{x + \Delta x} f(t) \text{d}t + \int_{x_0 + \Delta x}^{x_0} f(t) \text{d}t = \int_x^{x + \Delta x} f(t) \text{d}t - \int_{x_0}^{x_0 + \Delta x} f(t) \text{d}t$$

#### 3. 求极限
现在代入极限式中：
$$\lim_{\Delta x \to 0} \frac{I}{\Delta x} = \lim_{\Delta x \to 0} \frac{1}{\Delta x} \int_x^{x + \Delta x} f(t) \text{d}t - \lim_{\Delta x \to 0} \frac{1}{\Delta x} \int_{x_0}^{x_0 + \Delta x} f(t) \text{d}t$$

根据积分中值定理或导数定义，当 $\Delta x \to 0$ 时：
* $\frac{1}{\Delta x} \int_x^{x + \Delta x} f(t) \text{d}t \to f(x)$
* $\frac{1}{\Delta x} \int_{x_0}^{x_0 + \Delta x} f(t) \text{d}t \to f(x_0)$

所以，最终极限结果为：
$$f(x) - f(x_0)$$

---

### 解法二：导数定义法（概念最清晰）

我们可以把这个极限看作是一个**函数关于自变量 $\Delta x$ 的导数**。

#### 1. 构造辅助函数
为了书写方便，我们令 $y = \Delta x$，构造关于 $y$ 的函数：
$$H(y) = \int_{x_0}^x f(t + y) \text{d}t$$

显而易见，当 $y = 0$ 时：
$$H(0) = \int_{x_0}^x f(t) \text{d}t$$

那么，原极限式可以写为：
$$\lim_{y \to 0} \frac{\int_{x_0}^x f(t + y) \text{d}t - \int_{x_0}^x f(t) \text{d}t}{y} = \lim_{y \to 0} \frac{H(y) - H(0)}{y}$$
这正好就是函数 $H(y)$ 在 $y = 0$ 处的**导数定义**，即：
$$\text{原极限} = H'(0)$$

#### 2. 换元求导
我们对 $H(y)$ 内部做换元 $u = t+y$：
$$H(y) = \int_{x_0 + y}^{x + y} f(u) \text{d}u$$

根据微积分基本定理（变限积分求导公式），对 $y$ 求导：
$$H'(y) = f(x + y) \cdot \frac{\text{d}(x+y)}{\text{d}y} - f(x_0 + y) \cdot \frac{\text{d}(x_0+y)}{\text{d}y} = f(x + y) - f(x_0 + y)$$

#### 3. 代入 $y=0$
所以，极限值 $H'(0)$ 为：
$$H'(0) = f(x) - f(x_0)$$

你的做法（求出 $f(x)$ 表达式 $\to$ 反求出 $g(x)$ 表达式 $\to$ 求导代入）在数学上是**完全正确**的，在遇到能轻松写出反函数的题目时也完全可行。

但答案采用的方法是高数中极为经典的**“反函数求导法则”**。这个方法不需要你求出反函数 $g(x)$ 的具体表达式，就能直接算出某一点的导数值。

下面我为你拆解一下最后这几步的逻辑，以及为什么这个方法更强大：

---

### 1. 核心武器：反函数求导法则

如果 $y = f(x)$ 与 $x = g(y)$ 互为反函数，那么它们在对应点处的导数互为倒数：
$$g'(y_0) = \frac{1}{f'(x_0)} \quad \left(其中\ y_0 = f(x_0)，即\ g(y_0) = x_0\right)$$

这就是：**反函数的导数 = 原函数导数的倒数。**

---

### 2. 答案最后几步的推导过程

我们要计算的是 $g'(3)$：
1. **寻找对应点**：
   这里的自变量是 $y_0 = 3$。我们要找对应的 $x_0$ 是多少，也就是满足 $f(x_0) = 3$ 的那个 $x_0$。
   根据题目条件（或代入 $f(x) = \text{e}^{x-1} + 2 = 3$），我们知道：
   $$f(1) = 3 \implies g(3) = 1$$
   所以，对应点为 $(x_0, y_0) = (1, 3)$。

2. **套用公式**：
   根据反函数求导法则：
   $$g'(3) = \frac{1}{f'(1)}$$

3. **求 $f'(1)$ 并代入**：
   我们已知 $f(x) = \text{e}^{x-1} + 2$，对其求导：
   $$f'(x) = \text{e}^{x-1}$$
   代入 $x=1$：
   $$f'(1) = \text{e}^{1-1} = \text{e}^0 = 1$$
   所以：
   $$g'(3) = \frac{1}{f'(1)} = \frac{1}{1} = 1$$

第一部分：$\lim_{n \to \infty} \sum_{k=1}^n \frac{k}{2n^2 + k}$ —— 考查【夹逼定理】

#### 💡 怎么看出来的？（考点识别特征）
观察分母：大头是 $2n^2$，而变化的部分是 $k$（一阶）。
* 分母的次方（$2$ 次方）**大于**分子的次方（$1$ 次方）。
* 这种“分母变化微弱（分母的大头太强，加个 $k$ 几乎不影响大小）”的求和，**无法直接凑出 $\frac{k}{n}$ 形式的定积分**，必须优先考虑**夹逼定理**。

#### 🎯 快速计算过程：
因为 $1 \le k \le n$，我们可以把分母中的 $k$ 放大和缩小：
$$\frac{k}{2n^2 + n} \le \frac{k}{2n^2 + k} \le \frac{k}{2n^2 + 1}$$
两边同时求和（利用 $\sum_{k=1}^n k = \frac{n(n+1)}{2}$）：
$$\frac{n(n+1)}{2(2n^2 + n)} \le \sum_{k=1}^n \frac{k}{2n^2 + k} \le \frac{n(n+1)}{2(2n^2 + 1)}$$
当 $n \to \infty$ 时，左、右两边的极限都是：
$$\lim_{n \to \infty} \frac{n^2 + n}{4n^2 + 2n} = \frac{1}{4}$$
根据**夹逼定理**，第一部分的极限值为 **$\frac{1}{4}$**。

---

### 第二部分：$\lim_{n \to \infty} \sum_{k=1}^n \ln\left(\frac{n+k}{n}\right)^{\frac{1}{n}}$ —— 考查【定积分定义】

#### 💡 怎么看出来的？（考点识别特征）
我们先把对数的幂次提到前面：
$$\sum_{k=1}^n \frac{1}{n} \ln\left(1 + \frac{k}{n}\right)$$
* 它的特征太明显了：外面有一个 **$\frac{1}{n}$**，里面所有的变量都完美打包成了 **$\frac{k}{n}$** 的形式。
* 只要满足 **$\frac{1}{n} \sum f\left(\frac{k}{n}\right)$** 这种标准格式，就是百分之百在考查**定积分定义**。

#### 🎯 快速计算过程：
根据定积分定义 $\lim_{n \to \infty} \frac{1}{n} \sum_{k=1}^n f(\frac{k}{n}) = \int_0^1 f(x) \text{d}x$，我们直接把 $\frac{k}{n}$ 替换为 $x$：
$$\int_0^1 \ln(1+x) \text{d}x$$
利用分部积分法（或换元 $u = 1+x$）：
$$\int_1^2 \ln u \text{d}u = [u\ln u - u]_1^2 = (2\ln 2 - 2) - (0 - 1) = 2\ln 2 - 1$$
所以，第二部分的极限值为 **$2\ln 2 - 1$**。

我们要计算的极限为：
$$\lim_{x \to 0^+} \frac{\int_x^{+\infty} \frac{\text{e}^{-t}}{t} \text{d}t}{\ln \frac{1}{x}}$$

1. **看分母**：
   当 $x \to 0^+$ 时，$\frac{1}{x} \to +\infty$，所以：
   $$\lim_{x \to 0^+} \ln \frac{1}{x} = +\infty$$

2. **看分子**：
   分子是一个无穷区间上的积分。我们把它在 $t=1$ 处拆开：
   $$\int_x^{+\infty} \frac{\text{e}^{-t}}{t} \text{d}t = \int_x^1 \frac{\text{e}^{-t}}{t} \text{d}t + \int_1^{+\infty} \frac{\text{e}^{-t}}{t} \text{d}t$$
   * 后半部分 $\int_1^{+\infty} \frac{\text{e}^{-t}}{t} \text{d}t$ 是一个收敛的**常数**（因为在 $[1, +\infty)$ 上 $\frac{\text{e}^{-t}}{t} \le \text{e}^{-t}$，积出来是有限值）。
   * 前半部分在 $t \to 0^+$ 时，$\text{e}^{-t} \to 1$，所以被积函数相当于 $\frac{1}{t}$。而我们知道 $\int_x^1 \frac{1}{t}\text{d}t = -\ln x \to +\infty$。
   * 因此，整个分子在 $x \to 0^+$ 时也趋于 **$+\infty$**。

**结论**：这是一个标准的 **$\frac{\infty}{\infty}$** 型未定式，可以直接使用**洛必达法则**。

---



既然自变量是 $x$，我们对分子和分母分别关于 $x$ 求导：

1. **分母求导**：
   我们先将分母化简：$\ln \frac{1}{x} = -\ln x$。
   对其关于 $x$ 求导：
   $$\frac{\text{d}}{\text{d}x} (-\ln x) = -\frac{1}{x}$$

2. **分子求导（变限积分求导）**：
   分子是 $\int_x^{+\infty} \frac{\text{e}^{-t}}{t} \text{d}t$。
   * 注意：因为上限 $+\infty$ 是常数，下限 $x$ 是自变量。
   根据变限积分求导公式，对其关于 $x$ 求导（下限求导要多一个负号）：
   $$\frac{\text{d}}{\text{d}x} \int_x^{+\infty} \frac{\text{e}^{-t}}{t} \text{d}t = -\frac{\text{e}^{-x}}{x}$$

---


现在，我们将分子分母求导后的结果代回原极限式：

$$\lim_{x \to 0^+} \frac{\left( \int_x^{+\infty} \frac{\text{e}^{-t}}{t} \text{d}t \right)'}{\left( \ln \frac{1}{x} \right)'} = \lim_{x \to 0^+} \frac{-\frac{\text{e}^{-x}}{x}}{-\frac{1}{x}}$$

两边的负号抵消，并且分子分母上的 $\frac{1}{x}$ **完美消去**：

$$= \lim_{x \to 0^+} \text{e}^{-x}$$

当 $x \to 0^+$ 时，$\text{e}^{-x} \to \text{e}^0 = 1$。

题会做，但换元的逻辑链自己还是不能很好描述

题目给出的条件是：
$$f(\sin^2 x) = \frac{x}{\sin x}$$

我们令 $t = \sin^2 x$，那么要想求出 $f(t)$ 的表达式，我们就必须把右边的 $x$ 和 $\sin x$ 用 $t$ 表示出来。
两边开平方：
$$\sin x = \pm \sqrt{t}$$

**问题来了：这里到底是取 $+$ 还是取 $-$？**
* 如果取 $+$，那么 $\sin x = \sqrt{t}$，对应的 $x = \arcsin \sqrt{t}$；
* 如果取 $-$，那么 $\sin x = -\sqrt{t}$，对应的 $x = -\arcsin \sqrt{t}$。

如果我们在不确定的情况下随便挑一个，或者不管它，那么写出来的 $f(t)$ 表达式在严谨的数学上就是**未定义的（因为一个自变量 $t$ 不能对应两个不同的函数值）**。

为了确定到底是正还是负，我们必须去寻找 **$x$ 的范围证据**。

---

### 2. 证据在哪里？——隐藏在被积函数的“定义域”里

我们去哪里找 $x$ 的范围？答案在我们要计算的积分里：
$$I = \int \frac{\sqrt{x}}{\sqrt{1-x}} f(x)\text{d}x$$

要让这个积分有意义，被积函数必须有定义，也就是说**根号下的式子必须非负**：
1. 因为有 $\sqrt{x}$，所以必须 $x \ge 0$。
2. 因为有 $\sqrt{1-x}$，所以必须 $1-x \ge 0 \implies x \le 1$。

把这两个条件合起来，我们得到了 $x$ 的范围：
$$0 \le x \le 1$$

---

### 3. 用证据破案：确定正负号与反三角函数

现在我们手握证据 $x \in [0, 1]$，就可以理直气壮地做出决定了：

1. **确定 $\sin x$ 的符号**：
   因为 $\pi/2 \approx 1.57$，所以区间 $[0, 1]$ 完全落在第一象限 $[0, \pi/2]$ 内。
   在第一象限，正弦值显然是非负的，即 **$\sin x \ge 0$**。
   所以，我们果断抛弃负号，确定：
   $$\sin x = \sqrt{t}$$

2. **确定 $x$ 的表达式**：
   因为 $x \in [0, 1]$ 落在反三角函数 $\arcsin$ 的主值区间 $[-\pi/2, \pi/2]$ 内，所以我们可以直接写：
   $$x = \arcsin \sqrt{t}$$
   （*注：如果 $x$ 落在第二象限，我们就得写成 $x = \pi - \arcsin \sqrt{t}$ 了！*）

有了这两点，我们才能严丝合缝地写出：
$$f(t) = \frac{\arcsin \sqrt{t}}{\sqrt{t}}$$

### 💡 换元的本质是什么？

看完上面的拆解，相信你对换元的本质会有新的认识：

**换元不是简单的“字母替换”，而是在特定区间内建立起两个变量之间“一一对应”的函数关系。**

1. 如果不交代区间，开方出来的 $\pm$ 会让你无所适从。
2. 如果不交代区间，反三角函数（如 $\arcsin$）就无法直接去求。

虽然在平时做题时，由于出题人往往默认了区间合适，你不去管它也能撞对答案；但在考研的大题阅卷中，**如果没有这一步定义域的说明，直接写 $x = \arcsin\sqrt{t}$ 会被扣掉步骤分**。

### 路径 A：答案的换元（令 $u = -\sin x$）—— 顺风顺水

答案得到的是：
$$I = 8 \int \text{e}^u \cdot \frac{u}{(1+u)^2} \text{d}u$$

#### 为什么答案喜欢这个式子？
因为这里的 $\text{e}^u$ 指数是**正的**，它能直接套用高数中最著名的**秒杀公式**：
$$\int \text{e}^u [ g(u) + g'(u) ] \text{d}u = \text{e}^u g(u) + C$$

我们把分式拆开：
$$\frac{u}{(1+u)^2} = \frac{(u+1) - 1}{(1+u)^2} = \frac{1}{1+u} - \frac{1}{(1+u)^2}$$
设 $g(u) = \frac{1}{1+u}$，则其导数 $g'(u) = -\frac{1}{(1+u)^2}$，刚好完美对齐公式！
所以直接秒杀：
$$I = 8 \cdot \frac{\text{e}^u}{1+u} + C \overset{u = -\sin x}{\underline{=\!=\!=\!=\!=\!}} \frac{8\text{e}^{-\sin x}}{1-\sin x} + C$$

---

### 路径 B：你的换元（令 $u = \sin x$）—— 略带逆风

如果你令 $u = \sin x$，你化简出来的中间式子是：
$$I = 8 \int \text{e}^{-u} \cdot \frac{u}{(1-u)^2} \text{d}u$$

#### 这个式子能做吗？
完全能做，但因为 $\text{e}^{-u}$ 带有**负号**，对应的秒杀公式会多一个负号，变形成：
$$\int \text{e}^{-u} [ g'(u) - g(u) ] \text{d}u = \text{e}^{-u} g(u) + C$$

我们也把你的分式拆开：
$$\frac{u}{(1-u)^2} = \frac{1 - (1-u)}{(1-u)^2} = \frac{1}{(1-u)^2} - \frac{1}{1-u}$$
设 $g(u) = \frac{1}{1-u}$，则其导数 $g'(u) = \frac{1}{(1-u)^2}$，这也刚好对齐了上面的公式！
所以积出来的结果是：
$$I = 8 \cdot \frac{\text{e}^{-u}}{1-u} + C \overset{u = \sin x}{\underline{=\!=\!=\!=\!=\!}} \frac{8\text{e}^{-\sin x}}{1-\sin x} + C$$

---

### 💡 总结：为什么答案要多此一举搞个负号？

对比两条路径，你会发现：
1. **最终答案完全一致**，都是 $\frac{8\text{e}^{-\sin x}}{1-\sin x} + C$。
2. 答案之所以在换元时故意凑出 $-\sin x = u$，就是为了**让 $\text{e}$ 的指数保持为正的 $u$**。
   * 如果指数是 $-u$，在后续的分部积分或凑微分中，极易因为漏掉负号（比如 $(\text{e}^{-u})' = -\text{e}^{-u}$）而导致算错。

### 方法一：等价无穷小 / 泰勒法（墙裂推荐！5 秒秒杀）

在积分区间 $u \in [0, 2]$ 内，因为 $x \to 0$，所以 $xu \to 0$ 是一个趋近于 $0$ 的局部小量。
我们可以直接在积分号内对 $\sin(xu)$ 进行最基础的泰勒展开：
$$\sin(xu) = xu + o(x)$$

*（注：因为是在有界闭区间 $[0, 2]$ 上积分，这种在积分号内展开的做法在数学上是完全严谨的，高阶余项积分后除以 $x$ 会直接趋于 $0$。）*

我们将 $\sin(xu) \approx xu$ 直接代入两个积分中：

1. **计算第一项**：
   $$\int_0^1 (1-u) \sin(xu) \text{d}u \approx \int_0^1 (1-u) \cdot xu \text{d}u = x \int_0^1 (u - u^2) \text{d}u$$
   $$= x \left[ \frac{u^2}{2} - \frac{u^3}{3} \right]_0^1 = \frac{1}{6}x$$

2. **计算第二项**：
   $$\int_1^2 (u-1) \sin(xu) \text{d}u \approx \int_1^2 (u-1) \cdot xu \text{d}u = x \int_1^2 (u^2 - u) \text{d}u$$
   $$= x \left[ \frac{u^3}{3} - \frac{u^2}{2} \right]_1^2 = x \left[ \left(\frac{8}{3} - 2\right) - \left(\frac{1}{3} - \frac{1}{2}\right) \right] = \frac{5}{6}x$$

3. **求极限**：
   将结果代回原极限式：
   $$\text{原式} = \lim_{x \to 0} \frac{1}{x} \left[ \frac{1}{6}x + \frac{5}{6}x \right] = \lim_{x \to 0} \frac{x}{x} = 1$$

通过这个方法，你甚至不需要用分部积分，口算就能得出答案！

---

### 方法二：分部积分法（补全书上的推导）

如果你想走完书上的正统步骤，我们需要对这两个积分分别使用分部积分法：

#### 1. 计算第一个积分 $J_1$
$$\int_0^1 (1-u) \sin(xu) \text{d}u = \int_0^1 (1-u) \text{d}\left( -\frac{\cos(xu)}{x} \right)$$
$$= \left[ -(1-u)\frac{\cos(xu)}{x} \right]_0^1 - \int_0^1 \left( -\frac{\cos(xu)}{x} \right) \text{d}(1-u)$$
因为 $\text{d}(1-u) = -\text{d}u$：
$$= \frac{1}{x} - \frac{1}{x} \int_0^1 \cos(xu) \text{d}u = \frac{1}{x} - \frac{\sin x}{x^2}$$

#### 2. 计算第二个积分 $J_2$
$$\int_1^2 (u-1) \sin(xu) \text{d}u = \int_1^2 (u-1) \text{d}\left( -\frac{\cos(xu)}{x} \right)$$
$$= \left[ -(u-1)\frac{\cos(xu)}{x} \right]_1^2 - \int_1^2 \left( -\frac{\cos(xu)}{x} \right) \text{d}(u-1)$$
$$= -\frac{\cos(2x)}{x} + \frac{1}{x} \int_1^2 \cos(xu) \text{d}u = -\frac{\cos(2x)}{x} + \frac{\sin(2x) - \sin x}{x^2}$$

#### 3. 代入求极限
将 $J_1 + J_2$ 代回极限式并除以 $x$：
$$\text{原式} = \lim_{x \to 0} \left[ \frac{1 - \cos(2x)}{x^2} + \frac{\sin(2x) - 2\sin x}{x^3} \right]$$

对这两个部分分别求极限：
* **第一部分**：利用等价无穷小 $1 - \cos \Delta \sim \frac{1}{2}\Delta^2$：
  $$\lim_{x \to 0} \frac{1 - \cos(2x)}{x^2} = \lim_{x \to 0} \frac{\frac{1}{2}(2x)^2}{x^2} = 2$$
* **第二部分**：对分子进行泰勒展开：
  $$\sin(2x) = 2x - \frac{4}{3}x^3 + o(x^3)$$
  $$2\sin x = 2x - \frac{1}{3}x^3 + o(x^3)$$
  $$\lim_{x \to 0} \frac{\sin(2x) - 2\sin x}{x^3} = \lim_{x \to 0} \frac{-x^3 + o(x^3)}{x^3} = -1$$

将两部分合并：
$$\text{原式} = 2 + (-1) = 1$$

# 19 -【】


![[_attachments/image/08-880强化-1782135341431.jpeg]] 当你看到一个和式极限 $\lim_{n \to \infty} \sum a_k$ 时，根据式子的特征，有以下三种清晰的走向：

#### 1. 纯【定积分定义】
* **特征**：式子中所有的 $k$ 和 $n$ 都是“齐次一阶”的。它们都以 $\frac{k}{n}$ 这种组合完美地成对出现，且外面能提取出一个干净的 $\frac{1}{n}$。没有任何杂质。
* **例子**：$\lim_{n \to \infty} \sum_{k=1}^n \frac{1}{n} \cdot 2^{\frac{k}{n}}$

#### 2. 纯【夹逼定理】
* **特征**：分母上的主力是高阶无穷大（如 $n^2, n^3$），而分子只有一阶的 $k$。你**无论如何也提不出 $\frac{k}{n}$ 的结构**。
* **例子**：$\lim_{n \to \infty} \sum_{k=1}^n \frac{k}{2n^2 + k}$（上一道题的左半部分）

#### 3. 【夹逼 + 定积分】组合拳（即本题）
* **特征**：你一眼就能看到极其明显的 $\frac{k}{n}$ 结构（暗示定积分），**但是分母或分子里夹杂着一两坨很恶心的“杂质”**（比如这道题分母里的 $\frac{1}{k}$，或者多出来的某个常数）。
* **策略**：
  1. 先用**夹逼定理**，把那些恶心的“杂质”放缩掉（变成常数或消失）；
  2. 杂质清除后，式子变干净了，再用**定积分定义**收尾。

---

### 二、 详细解题过程（组合拳演示）

对于本题：
$$S_n = \frac{2^{\frac{1}{n}}}{n+1} + \frac{2^{\frac{2}{n}}}{n+\frac{1}{2}} + \dots + \frac{2^{\frac{n}{n}}}{n+\frac{1}{n}}$$

#### 1. 第一步：用夹逼定理“清除杂质”
分母上的每一项都是 $n + \frac{1}{k}$（其中 $1 \le k \le n$）。这里的 $\frac{1}{k}$ 就是我们想清除的“杂质”。
因为 $1 \le k \le n$，显然有：
$$0 < \frac{1}{k} \le 1$$
所以，我们可以轻松给分母放缩：
$$n < n + \frac{1}{k} \le n + 1$$

由于分母越小，分式越大，我们对 $S_n$ 的每一项进行放缩：
$$\sum_{k=1}^n \frac{2^{\frac{k}{n}}}{n+1} \le S_n < \sum_{k=1}^n \frac{2^{\frac{k}{n}}}{n}$$

这就是夹逼定理的**左、右边界**。

---

#### 2. 第二步：用定积分定义“计算边界”

我们来看**右边界**的极限：
$$\lim_{n \to \infty} \sum_{k=1}^n \frac{2^{\frac{k}{n}}}{n} = \lim_{n \to \infty} \frac{1}{n} \sum_{k=1}^n 2^{\frac{k}{n}}$$
这已经是一个纯净的、标准的定积分定义了（把 $\frac{1}{n}$ 看作 $\text{d}x$，$\frac{k}{n}$ 看作 $x$）：
$$= \int_0^1 2^x \text{d}x = \left[ \frac{2^x}{\ln 2} \right]_0^1 = \frac{2^1 - 2^0}{\ln 2} = \frac{1}{\ln 2}$$

我们再来看**左边界**的极限：
$$\lim_{n \to \infty} \sum_{k=1}^n \frac{2^{\frac{k}{n}}}{n+1} = \lim_{n \to \infty} \frac{n}{n+1} \cdot \left( \frac{1}{n} \sum_{k=1}^n 2^{\frac{k}{n}} \right)$$
因为 $\lim_{n \to \infty} \frac{n}{n+1} = 1$，所以：
$$= 1 \cdot \frac{1}{\ln 2} = \frac{1}{\ln 2}$$

---

#### 3. 第三步：得出结论
由夹逼定理可知，原式的极限为：
$$\frac{1}{\ln 2}$$

这是一道非常著名且经典的数学不等式题（在数学分析中被称为 **厄米特-哈达玛不等式 Hermite-Hadamard Inequality**）。

你自己做时想不到切入点非常正常，因为这个不等式的本质隐藏在 $f''(x) > 0$ 的**几何直观（凹凸性）**中。

只要理解了它的几何图形，你不仅能瞬间记住证明方法，以后遇到类似的题也能一眼看穿。

---

### 💡 核心切入点：抓住 $f''(x) > 0$ 的两个几何法宝

二阶导数 $f''(x) > 0$ 意味着函数是**严格凹的（开口向上 / 凸函数）**。
严格凹函数有两个最著名、最核心的几何性质：

1. **割线（弦）在弧的上方**：连接曲线端点的线段，永远在曲线的上方。
2. **切线在弧的下方**：曲线上任意一点的切线，永远在曲线的下方。

我们将利用这两个性质，分别证明“右半部分”和“左半部分”：

---

### 一、证明右半部分：利用“割线（弦）在上方”

我们需要证明：
$$\frac{1}{b-a} \int_a^b f(x) \text{d}x < \frac{f(a) + f(b)}{2} \iff \int_a^b f(x) \text{d}x < (b-a) \frac{f(a) + f(b)}{2}$$

#### 1. 几何直观：
* 左边 $\int_a^b f(x) \text{d}x$ 是曲线下的面积。
* 右边 $(b-a) \frac{f(a)+f(b)}{2}$ 是连接两个端点 $(a, f(a))$ 和 $(b, f(b))$ 所构成的**梯形面积**。
* 因为曲线开口向上，曲线在弦的下方，所以曲线下的面积自然小于梯形面积。

#### 2. 严格代数证明：
连接两端点的割线方程为：
$$L(x) = f(a) + \frac{f(b) - f(a)}{b-a}(x - a)$$
因为 $f''(x) > 0$，所以对任意 $x \in (a, b)$，曲线都在割线下方：
$$f(x) < L(x)$$
两边在 $[a, b]$ 上取定积分：
$$\int_a^b f(x) \text{d}x < \int_a^b L(x) \text{d}x$$
因为 $L(x)$ 是一次函数（直线），积分结果就是梯形面积：
$$\int_a^b L(x) \text{d}x = (b-a) \frac{f(a)+f(b)}{2}$$
所以：
$$\int_a^b f(x) \text{d}x < (b-a) \frac{f(a)+f(b)}{2} \implies \frac{1}{b-a}\int_a^b f(x) \text{d}x < \frac{f(a)+f(b)}{2}$$
（右半部分证毕）

---

### 二、证明左半部分：利用“切线在下方”或“泰勒展开”

我们需要证明：
$$f\left(\frac{a+b}{2}\right) < \frac{1}{b-a} \int_a^b f(x) \text{d}x \iff (b-a) f\left(\frac{a+b}{2}\right) < \int_a^b f(x) \text{d}x$$

#### 1. 几何直观：
* 右边是曲线下的面积。
* 左边可以看作是曲线在**中点 $x_0 = \frac{a+b}{2}$ 处的切线下的面积**。因为切线永远在曲线下方，所以切线下的面积必然小于曲线下的面积。

#### 2. 严格代数证明（最标准的考研写法：泰勒展开法）：
我们将 $f(x)$ 在中点 $x_0 = \frac{a+b}{2}$ 处进行一阶泰勒展开（带拉格朗日余项）：
$$f(x) = f(x_0) + f'(x_0)(x - x_0) + \frac{f''(\xi)}{2}(x - x_0)^2 \quad (\xi \text{ 介于 } x \text{ 与 } x_0 \text{ 之间})$$
因为对任意 $x$，都有 $f''(x) > 0$，且当 $x \neq x_0$ 时 $(x - x_0)^2 > 0$。
所以余项部分 $\frac{f''(\xi)}{2}(x - x_0)^2 > 0$，我们直接去掉余项，得到一个不等式：
$$f(x) \ge f(x_0) + f'(x_0)(x - x_0) \quad (\text{仅在 } x=x_0 \text{ 时取等号})$$

由于两边不恒等，在 $[a, b]$ 上同时取定积分，不等号方向不变：
$$\int_a^b f(x) \text{d}x > \int_a^b [f(x_0) + f'(x_0)(x - x_0)] \text{d}x$$
我们把右边的积分积出来：
$$\int_a^b [f(x_0) + f'(x_0)(x - x_0)] \text{d}x = f(x_0)\int_a^b \text{d}x + f'(x_0)\int_a^b (x - x_0) \text{d}x$$
* 第一部分：$f(x_0)(b - a)$；
* 第二部分：因为 $x_0 = \frac{a+b}{2}$ 是中点，根据对称性（或者直接积分 $[(x-x_0)^2/2]_a^b$）：
  $$\int_a^b (x - x_0) \text{d}x = 0$$

所以右边积分的结果非常干净，就是：$f(x_0)(b-a)$。
从而：
$$\int_a^b f(x) \text{d}x > f\left(\frac{a+b}{2}\right)(b-a) \implies f\left(\frac{a+b}{2}\right) < \frac{1}{b-a}\int_a^b f(x) \text{d}x$$
（左半部分证毕）

---

### 🌟 总结你的“知识库升级”

以后看到 $f''(x) > 0$ 且带有**积分**的不等式证明：
1. **要证“积分值 < 端点值”** $\implies$ 往**“割线在曲线之上”**去想，用两点连线。
2. **要证“积分值 > 中点值”** $\implies$ 往**“切线在曲线之下（泰勒展开法）”**去想，在中点处展开。】
