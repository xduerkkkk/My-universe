### 任务 1：转化数据集标注格式 (`data/voc2yolo.py`)

这里需要填入 VOC2007 的所有类别，并完成归一化坐标的计算（宽高倒数以及宽高实际值）。

```python
# 修改为自己的数据类别 (补全剩余的19个类别)
classes = ["aeroplane", "bicycle", "bird", "boat", "bottle", "bus", "car", "cat", 
           "chair", "cow", "diningtable", "dog", "horse", "motorbike", "person", 
           "pottedplant", "sheep", "sofa", "train", "tvmonitor"]

# 修改为 VOCdevkit 文件夹所在路径 (根据实际存放位置填写，通常为如下格式)
wd = 'VOCdevkit/VOC2007/' 

def convert(size, box):
    # size[0]为宽，size[1]为高，取倒数用于后续归一化
    dw = 1.0 / size[0]  
    dh = 1.0 / size[1]  
    x = (box[0] + box[1])/2.0 - 1
    y = (box[2] + box[3])/2.0 - 1
    # 宽 = xmax - xmin，高 = ymax - ymin
    w = box[1] - box[0] 
    h = box[3] - box[2] 
    x = x*dw
    w = w*dw
    y = y*dh
    h = h*dh
    return (x,y,w,h)
```
