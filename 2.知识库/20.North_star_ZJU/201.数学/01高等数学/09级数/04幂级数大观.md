# 导积
幂级数求和的核心目标只有**一个**：**消掉通项中所有带 $n$ 的多项式系数，将其还原为最基础的等比级数 $\sum x^k = \frac{1}{1-x}$。**

微积分的运算机制决定了操作方向：
* **求导产生 $n$**：$(x^n)' = n x^{n-1} \implies$ **能消去分母上的 $n$**
* **积分产生 $\frac{1}{n}$**：$\int x^{n-1} dx = \frac{x^n}{n} \implies$ **能消去分子（乘积）上的 $n$**

---

### 情况一：分母含 $n$ ——【先导后积】

* **识别特征**：通项形如 $\sum \frac{x^n}{n}$ 或 $\sum \frac{x^{3n}}{3n+1}$（$n$ 在分母）。
* **操作逻辑**：**导消分母，积还原**。

#### 标准三步法：
1. **凑幂次**：乘除 $x^k$，让 $x$ 的指数与分母严格一致，设为辅助函数 $f(x)$。
   * 例如：$S(x) = \sum \frac{x^{3n}}{3n+1} \implies f(x) = xS(x) = \sum \frac{x^{3n+1}}{3n+1}$
2. **先求导**：对 $f(x)$ 求导，瞬间消掉分母，转化为等比级数求和：
   * $f'(x) = \sum x^{3n} = \frac{1}{1-x^3}$
3. **后积分**：利用牛顿-莱布尼茨公式对导函数积分，还原出 $f(x)$：
   * $f(x) = \int_0^x f'(t)\,dt = \int_0^x \frac{1}{1-t^3}\,dt \implies S(x) = \frac{f(x)}{x}$

---

### 情况二：分子（乘积）含 $n$ ——【先积后导】

* **识别特征**：通项形如 $\sum n x^n$ 或 $\sum n(n-1) x^n$（$n$ 在分子/系数位置）。
* **操作逻辑**：**积消系数，导还原**。

#### 标准三步法：
1. **提因子**：提取 $x$，让 $x$ 的指数比系数少 1，变为 $S(x) = x \sum n x^{n-1}$。
2. **先积分**：两边同时除以 $x$ 并积分，积分产生的分母把前面的系数 $n$ 抵消掉，化为等比级数：
   * $\int_0^x \frac{S(t)}{t}\,dt = \sum \int_0^x n t^{n-1}\,dt = \sum x^n = \frac{x}{1-x}$
3. **后求导**：对两边求导，还原出 $\frac{S(x)}{x}$：
   * $\frac{S(x)}{x} = \left(\frac{x}{1-x}\right)' = \frac{1}{(1-x)^2} \implies S(x) = \frac{x}{(1-x)^2}$

*(注：对于分子含 $n$ 的题目，也可以直接用前面讲过的**“配凑下降阶乘幂求导法”**，速度往往更快。)*

---

### 应试速记口诀

| 通项特征        | 对应运算     | 核心作用        | 操作流程                      |
| :---------- | :------- | :---------- | :------------------------ |
| **$n$ 在分母** | **先导后积** | 导数消分母，定积分还原 | 凑幂次 $\to$ 求导求和 $\to$ 积分还原 |
| **$n$ 在分子** | **先积后导** | 积分消系数，求导还原  | 降幂次 $\to$ 积分求和 $\to$ 求导还原 |
