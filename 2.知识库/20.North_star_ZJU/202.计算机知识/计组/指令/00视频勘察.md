# 指令格式

OP（操作码）+ A（地址码）
俩者加起来叫指令

地址码个数可分
- 零地址指令，无操作数，被操作的数是栈上的，操作完的数压回栈顶
- 一地址指令，对 A1 操作，再存回 A1
- 二地址指令，A2 作用到 A1 （如 A2-A1，A2+A1）. 然后存回 A1
- 三地址指令，A2 作用到 A1 （如 A2-A1，A2+A1）. 然后存回 A3
- 四地址指令，A2 作用到 A1 （如 A2-A1，A2+A1）. 然后存回 A3，下一个指令地址在 A4

指令长度，分半字、单字、双字长。
看所有指令，可分析出是定长/变长指令字结构
看所有指令，可分析出是定长操作码还是可变长操作码

指令类型
- 数据传送
- 算术逻辑
- 程序控制
- CPU 与 IO

# 寻址
指令寻址
要注意按什么编址，
- 顺序寻址，PC 存着下一个指令的地址。每次加“1”.注意不定长指令的话，要计算
- 跳转寻址
额，默认顺序寻址，特殊的 JMP 等就是跳转寻址

取指发现，接下来的指令是去一个地址。（由标志 1位看出）
此时我们说，这个地址叫数据寻址或偏移寻址或堆栈寻址：
数据寻址：隐含、立即数；直接、间接；寄存器、寄存器间接。

偏移寻址：借助已有地址
相对寻址（相对 PC）、基址寻址、变址寻址

操作码，寻址特征，形式地址

# 函数调用

1. **取指令**（指令在存哪里？PC 怎么变？）

3. **运算**（ALU 怎么算？标志位怎么变？）

#### 场景设定

**代码 A (Caller)**: `main` 函数，准备调用 `sum(1, 2)`。 **代码 B (Callee)**: `sum` 函数，执行 `return a + b`。

---

### 第一阶段：准备出发（指令与寻址）

- **C 代码**：`int a = 1;`
    
- **汇编 (MIPS/x86)**：`MOV R1, #1` (立即数) 或 `MOV [EBP-4], 1` (基址寻址)
    
- **挂载知识点**：
    
    1. **指令格式**：操作码 (MOV) + 地址码。
        
    2. **指令在主存**：是的！PC 指向内存中的代码段。
        
    3. **寻址方式**：
        
        - `#1` -> **立即寻址** (数在指令里)。
            
        - `[EBP-4]` -> **基址寻址** (面向操作系统的，访问局部变量)。
            

### 第二阶段：发起调用（控制流与栈）

- **C 代码**：`sum(a, b);`

- **汇编**：
    
    1. `PUSH 2`, `PUSH 1` (参数入栈)
        
    2. `CALL sum_addr`
        
- **挂载知识点**：
    
    1. **CISC vs RISC**：
        - x86 (CISC) 喜欢用栈传参。 
        - ARM/MIPS (RISC) 喜欢用寄存器传参 (R0-R3)。
            
    2. **CALL 指令的本质**：
        - **保存断点**：把 `PC + "1"` (返回地址) 压栈。
            
        - **计算跳转**：`PC_new = PC_old + 偏移量` -> **PC 相对寻址** (考点！)。
            

### 第三阶段：建立新世界（栈帧构建 - 机器层面核心）

- **C 代码**：`{ ... }` (进入 `sum` 函数体)
    
- **汇编 (Function Prologue)**：
    
    1. `PUSH EBP` (保存上层基址)
        
    2. `MOV EBP, ESP` (建立新基址)
        
    3. `SUB ESP, 8` (开辟局部变量空间)
        
- **挂载知识点**：
    
    1. **栈帧 (Stack Frame)**：这是 408 大题常客。
        
    2. **寄存器分工**：
        
        - **EBP/FP**：栈底指针（基准，不动）。
            
        - **ESP/SP**：栈顶指针（随 PUSH/POP 动）。
            
    3. **内存对齐**：为什么要减 8？可能为了字节对齐。
        

### 第四阶段：干活（运算与标志位）

- **C 代码**：`return a + b;`
    
- **汇编**：
    
    1. `MOV EAX, [EBP+8]` (取参数 a)
        
    2. `ADD EAX, [EBP+12]` (加参数 b)
        
- **挂载知识点**：
    
    1. **操作码设计**：定长 vs 变长。
        
    2. **标志位 (PSW)**：
        
        - 如果 `a+b` 超出了 int 范围 -> **OF (溢出)** 置 1。
            
        - 如果是无符号数加法 -> **CF (进位)** 置 1。
            
        - 结果是不是 0 -> **ZF (零标志)**。
            
    3. **大端/小端**：从内存取数据 `[EBP+8]` 时，字节序是怎么排的？
        

### 第五阶段：清理与返回（Ret 与 恢复）

- **C 代码**：`}` (函数结束)
    
- **汇编 (Function Epilogue)**：
    
    1. `MOV ESP, EBP` (释放局部变量)
        
    2. `POP EBP` (恢复上层基址)
        
    3. `RET`
        
- **挂载知识点**：
    
    1. **RET 指令**：
        
        - 本质是 `POP PC`。
            
        - 从栈顶弹出一个地址送给 PC，CPU 就自动跳回去了。
            
    2. **指令流水线**：
        
        - `RET` 这种跳转指令是流水线的“杀手”（控制冒险），可能导致流水线断流。
