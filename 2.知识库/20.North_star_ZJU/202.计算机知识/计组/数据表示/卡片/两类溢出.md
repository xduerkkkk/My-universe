### 为什么减法 $CF = C_{out} \oplus 1$？

我们要算无符号减法 $A - B$。

**CF 的物理定义是：不够减，需要借位，则 CF = 1；够减，CF = 0。**

但在 CPU 硬件里，**ALU 根本没有减法电路**！它算 $A - B$ 的时候，物理上执行的是：

$$A + \sim B + 1$$

（即 A 加上 B 的按位取反，再加一）。

现在，我们把这段硬件操作，翻译成严谨的数学代数式：

在一个 $n$ 位的系统中，数字 B 按位取反再加一（$\sim B + 1$），它的数学真值其实就是 **$2^n - B$**。

所以，ALU 内部真正在算的加法等式是：

$$SUM = A + (2^n - B) = (A - B) + 2^n$$

奇迹就藏在这个代数式里！我们分两种情况看：

- **情况 1：$A \ge B$（够减，数学上不需要借位，CF 应该为 0）**
    
    既然 $A \ge B$，那么 $(A - B) \ge 0$。
    
    代入公式：$SUM = (A - B) + 2^n \ge 2^n$。
    
    在二进制里，一个结果大于等于 $2^n$，意味着什么？意味着**必然会向最高位之外产生一个进位（$C_{out} = 1$）**！这个进位 $1$，代表的就是那个 $2^n$。
    
    **物理结论：** 够减 $\rightarrow$ 必然产生进位 $C_{out}=1$ $\rightarrow$ 此时不需要借位 CF=0。所以 $CF = \overline{C_{out}}$。
    
- **情况 2：$A < B$（不够减，数学上必须借位，CF 应该为 1）**
    
    既然 $A < B$，那么 $(A - B) < 0$。
    
    代入公式：$SUM = (A - B) + 2^n < 2^n$。
    
    结果小于 $2^n$，意味着什么？意味着**绝对不可能产生向外的进位（$C_{out} = 0$）**！
    
    **物理结论：** 不够减 $\rightarrow$ 必然没有进位 $C_{out}=0$ $\rightarrow$ 此时必须借位 CF=1。所以 $CF = \overline{C_{out}}$。

这两者能够完美等价，是因为在全加器电路中，**符号位的反转**和**进位的不一致**，在数学和逻辑门层面上是**同一个事件的两种表现形式**。

为了把底层硬件和人类逻辑联系起来，我们直接聚焦于**最高位（符号位）的那个 1-bit 全加器**。
这个全加器接收 3 个输入：两个操作数的符号位 $A_{sign}$ 和 $B_{sign}$，以及次高位传来的进位 $C_{n-1}$。
它产生 2 个输出：结果的符号位 $S_{sign}$，以及向外溢出的最高位进位 $C_n$。

加法逻辑公式是：$A_{sign} + B_{sign} + C_{n-1} = C_n$（进位）和 $S_{sign}$（本位留下的和）。

我们分三种情况拆解，看看硬件是如何和“同号变异号”完美对齐的：

### 1. 正数 + 正数 （$A_{sign} = 0, B_{sign} = 0$）
此时最高位的加法是：`0 + 0 + C_n-1`。
我们来看 $C_{n-1}$ 的不同取值会导致什么：
*   **如果 $C_{n-1} = 0$（没有进位上来）**：
    计算：`0 + 0 + 0 = 00`。
    结果：本位 $S_{sign} = 0$（正数，结果正确），最高位进位 $C_n = 0$。
    硬件判断：$C_n \oplus C_{n-1} = 0 \oplus 0 = 0$（不溢出）。
*   **如果 $C_{n-1} = 1$（次高位进了个 1 上来）**：
    计算：`0 + 0 + 1 = 01`。
    结果：本位 $S_{sign} = 1$（**正数+正数算出了负数，这就是你肉眼看到的符号变了**），最高位进位 $C_n = 0$。
    硬件判断：此时 $C_n(0)$ 和 $C_{n-1}(1)$ 必然不同，$0 \oplus 1 = 1$（溢出）。

**联系点：** 对于两个正数相加，**只要次高位进了个 1（$C_{n-1}=1$），一定会把最高位的 `0` 冲刷成 `1`（导致符号反转），同时也一定会导致 $C_n$ 无法产生进位（$C_n=0$），从而形成 $C_n \neq C_{n-1}$ 的硬件溢出条件。**

### 2. 负数 + 负数 （$A_{sign} = 1, B_{sign} = 1$）
此时最高位的加法是：`1 + 1 + C_n-1`。
*   **如果 $C_{n-1} = 1$（有进位上来）**：
    计算：`1 + 1 + 1 = 11`。
    结果：本位 $S_{sign} = 1$（负数，结果正确），最高位进位 $C_n = 1$。
    硬件判断：$C_n \oplus C_{n-1} = 1 \oplus 1 = 0$（不溢出）。
*   **如果 $C_{n-1} = 0$（次高位没进位上来）**：
    计算：`1 + 1 + 0 = 10`。
    结果：本位 $S_{sign} = 0$（**负数+负数算出了正数，符号又变了**），最高位进位 $C_n = 1$。
    硬件判断：此时 $C_n(1)$ 和 $C_{n-1}(0)$ 必然不同，$1 \oplus 0 = 1$（溢出）。

**联系点：** 对于两个负数相加，它们自带两个 `1`，必定会向外产生进位（$C_n=1$）。此时**如果次高位不送进位上来（$C_{n-1}=0$），最高位留下的和必然是 `0`（导致符号反转），同时也刚好构成了 $C_n \neq C_{n-1}$。**

### 3. 一正一负 （$A_{sign} = 1, B_{sign} = 0$ 或相反）
此时最高位的加法是：`1 + 0 + C_n-1`。
*   **如果 $C_{n-1} = 0$**：计算 `1 + 0 + 0 = 01` $\rightarrow S_{sign} = 1, C_n = 0$。硬件：$0 \oplus 0 = 0$。
*   **如果 $C_{n-1} = 1$**：计算 `1 + 0 + 1 = 10` $\rightarrow S_{sign} = 0, C_n = 1$。硬件：$1 \oplus 1 = 0$。

**联系点：** 因为一正一负提供了一个基础值 `1`，所以**无论 $C_{n-1}$ 进来什么值，$C_n$ 都一定会原封不动地把它传出去**（$C_{n-1}=0$ 则 $C_n=0$；$C_{n-1}=1$ 则 $C_n=1$）。这也就证明了，一正一负相加时，$C_n$ 和 $C_{n-1}$ 永远相等，异或结果永远是 0，**在硬件层面上绝对不可能触发溢出，这与人类逻辑中“异号相加不溢出”的结论完全咬合。**

### 总结
人类看的是**加法器留下来的结果（$S_{sign}$）**是否合乎常理；
硬件电路看的是**加法器进出两端的信号（$C_{n-1}$ 和 $C_n$）**是否一致。
全加器的内部布尔代数逻辑决定了：**当且仅当进出信号不一致时，留下来的符号位才会发生荒谬的反转**。两者是等价的。

# 有符号除法
![[两类溢出-1774424562490.jpeg]]


你的直觉非常敏锐。乘法是“让数值变大”，所以非常容易超出寄存器的位宽限制；而除法是“让数值变小”，因此在绝大多数情况下，**除法的商一定能装进原有的寄存器里，根本不会发生溢出。**

在计算机 408 考研的语境下，整数除法运算只有在 **3 种极端边界条件**下才会发生溢出。我们直接拆解这三个条件的触发机制：

### 条件 1：除数为 0（最常见的硬件异常）
*   **原理：** 任何数除以 0 结果趋向于无穷大，寄存器装不下。
*   **硬件处理：** 在启动那 $n$ 轮移位减法循环之前，控制逻辑会直接检查除数寄存器 B 是否为全 0。如果是，直接触发“除零异常”（Divide-by-zero Trap），强行中止运算。

### 条件 2：补码的不对称性（仅限有符号除法）
*   **触发条件：** **被除数是当前位宽能表示的最小负数，且除数是 -1。**
*   **原理拆解：** 以 4bit 有符号数为例，补码的表示范围是 $[-8, 7]$。
    如果你执行 $-8 \div -1$（即二进制的 `1000` $\div$ `1111`），正确的数学结果是 $+8$。
    但是，4bit 带符号位最多只能表示到 $+7$（`0111`）。$+8$ 的原码是 `01000`，需要 5 个 bit 才能装下。此时 4bit 的商寄存器 Q 装不下，发生溢出。
*   **硬件处理：** 硬件会在运算前进行特例检测：只要检测到被除数符号位为 1 且其余全 0（最小负数），同时除数全 1（-1），就直接报溢出。

---

前两个条件都属于“特例”。真正和我们刚才讲的**“移位、相减”硬件机制**相关的溢出，是下面这个最常考的核心考点：

### 条件 3：双字长除以单字长（$2n$ 位除以 $n$ 位）
*   **前提背景：** 在真正的 CPU（如 x86 架构指令集）中，为了和乘法（$n$ 位 $\times$ $n$ 位 = $2n$ 位）可逆，除法指令通常支持 **“$2n$ 位的被除数 $\div$ $n$ 位的除数 = $n$ 位的商”**。
    在刚才讲的 `[R, Q]` 结构中，如果被除数是 $2n$ 位，初始状态下会被完整塞满整个 8bit 的 `[R, Q]`（R 装高 4 位，Q 装低 4 位），除数 B 依然是 4 位，要求算出的商必须能装进 4 位的 Q 里。
*   **触发条件：** **被除数的高 $n$ 位（即初始时的 R） $\ge$ 除数 B**。
*   **数学证明：**
    假设 $2n$ 位被除数的值为 $X_{high} \cdot 2^n + X_{low}$。
    如果高位部分 $X_{high} \ge$ 除数 $Y$，那么：
    总被除数 $\ge Y \cdot 2^n + X_{low}$
    商 = 总被除数 $\div Y \ge (Y \cdot 2^n) \div Y = 2^n$
    在 $n$ 位寄存器中，无符号数最大只能表示 $2^n - 1$（例如 4bit 最大是 15，而 $2^4 = 16$）。商如果大于等于 $2^n$，必定溢出。
*   **硬件处理（如何判断）：**
    不需要算完才知道溢出！硬件在**最开始，也就是还未执行任何左移操作之前**，直接让 ALU 把初始的 R 减去除数 B。
    如果发现 $R - B \ge 0$（即不够减的条件不成立），说明商的位数一定会超过 $n$ 位。此时硬件直接报错并终止除法，从而节省无效的计算周期。

**总结指出：**
除法运算本身是降维的，不会像乘法那样动不动就超出位宽。你需要记忆的除法溢出，本质上都是**规格匹配问题**：要么是除零这种数学无解，要么是补码正负不对称导致的越界，要么是把大尺寸（$2n$ 位）强行塞入小尺寸（$n$ 位）时，高位部分太大装不下。
