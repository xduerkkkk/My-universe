5. D 机器字长和存储、地址字长的关系？哦没有地址字长，还有指令字长
   **机器字长**是指 CPU 一次能够直接处理的二进制数据的位数。是由 CPU 内部**通用寄存器的位数**和**算术逻辑单元（ALU）的位宽**决定的。我们常说的“64 位处理器”（64-bit CPU），指的就是它的通用寄存器是 64 位的，ALU 一次可以对 64 位的数据进行运算，即**机器字长为 64 位**。
   MDR 的位数等于**存储字长**（Storage Word Length）。
   MAR 的位数等于**地址码的长度（地址位数）**。
   
6. B
   !! 寄存器不是就指 CPU 的通用寄存器吗？ 再就是，如果题说”操作系统位数“，，这个位数就是 MAR 吗？
    
    一个 32 位的 CPU 内部，确实有 32 位的通用寄存器，但它同时也可能存在 16 位的段寄存器、1 位的状态标志寄存器、甚至 80 位的浮点寄存器或 128 位的向量寄存器。因此，“具有 32 位寄存器”不能作为定义 32 位微机的标准。**也不代表能同时处理 32 位数据**
    
    操作系统的位数，就是 MAR 的位数吗？
    我们常说的“64 位操作系统”，是指该操作系统是为 64 位 CPU 设计的。
	*   它的指针（内存地址）在软件层面是用 **64 位二进制数**来表示的。
	*   也就是说，在软件逻辑里，它的**虚拟地址空间**是 $2^{64}$ 字节。
	*   这里的“位数”对应的是 CPU 的**机器字长**（通用寄存器和指针的宽度）。
**MAR（主存地址寄存器）**连结的是物理地址总线，它的位数决定了**主存物理插槽能支持的最大物理内存容量**。
	*   **硬件上不需要 64 位的 MAR**：
	    虽然 64 位操作系统使用的地址指针是 64 位的，但世界上没有任何一台电脑能插得上 $2^{64}$ 字节（即 16 EB，约 170 亿 GB）的物理内存条。
	*   **实际的 MAR 位数**：
	    为了节省硬件成本和减少芯片引脚，现代 64 位 CPU 内部的 **MAR 往往只有 40 位到 48 位**。
	    *   如果 MAR 是 40 位，那么这台电脑最大支持的物理内存就是 $2^{40}\text{ B} = 1\text{ TB}$。
	    *   如果 MAR 是 48 位，最大支持的物理内存就是 $2^{48}\text{ B} = 256\text{ TB}$。
