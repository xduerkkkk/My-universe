### 一、总线收发控制信号（Xin 与 Xout）

这是最基础的信号，用于控制寄存器与内部公共总线的连接。

- **Xout = 1（输出有效）**：打开寄存器 X 的输出三态门。寄存器 X 里的数据被放到公共总线上。
    
    - 铁律：在同一个时钟周期内，**最多只能有一个 Xout 为 1**。因为总线只有一条，两个寄存器同时往外发数据会造成物理上的总线冲突（短路或数据破坏）。
        
- **Xin = 1（输入有效）**：打开寄存器 X 的输入锁存器。在此时钟周期的末尾（通常是下降沿），寄存器 X 会把当前总线上的数据抓取（锁存）到自己内部。
    
    - 机制：同一个周期内，可以有多个 Xin 同时为 1（总线上的同一份数据可以同时被多个寄存器接收）。
        

### 二、 功能部件操作信号（...op）

这些信号不是用来搬运数据的，而是用来向运算部件或存储部件下达“具体做什么”的指令。

1. **MEMop（Memory Operation，内存操作）**
    
    - **含义**：控制主存的读写。
        
    - **取值**：read（读主存，把目标地址的数据拿出来放到 MDR 寄存器）；write（写主存，把 MDR 的数据写入目标地址）。
        
2. **ALUop（ALU Operation，算术逻辑单元操作）**
    
    - **含义**：告诉 ALU 这一步做什么数学或逻辑运算。
        
    - **取值**：如 add（加法）、sub（减法）。如果这一步不需要算数，只是想把数据原封不动地穿过 ALU 传给下一级，通常取值为 mov 或 pass。
        
3. **MUXop（Multiplexer Operation，多路选择器操作）**
    
    - **含义**：MUX 是一个多选一的硬件开关。ALU 的输入端通常连接着 MUX。MUXop 决定了把哪一条线路的数据放进 ALU。
        
    - **机制**：在 408 常见的通路中，MUX 的一端连着内部总线，另一端连着常数发生器（比如产生常数 2 专门用来给 PC 加偏置）。MUXop 的值（如 0 或 1）决定了 ALU 是接收总线传来的数据，还是接收常数。
        
4. **SRop（Shift Register Operation，移位寄存器操作）**
    
    - **含义**：在这道题的微体系结构中，SR 挂在 ALU 的输出端。它负责对 ALU 算出的结果进行移位处理。
        
    - **取值**：shl（左移）、shr（右移）。如果不需要移位，就填 mov 或 pass，让结果直接穿透。



### 三、 ALU 算术逻辑与状态信号
- **EnFlags / Set PSW（状态标志位更新信号）**
    
    - 机制：ALU 算完一个结果后，会产生进位（C）、零（Z）、符号（S）、溢出（O）等状态电平。但这些电平默认不会被保存。只有当控制器发出 EnFlags=1 信号时，这些状态才会被锁存到 **PSW（程序状态字寄存器）** 中。
        
    - 前提条件：并非所有指令都会改变 PSW。比如数据搬运指令（MOV）在很多指令集中不改变状态，此时 EnFlags=0；而算术指令（ADD, SUB）通常 EnFlags=1。


### 四、时序同步信号（极易在微操作序列中漏掉）

- **WMFC（Wait for Memory Function Complete，等待访存完成）**
    
    - 机制：这是一个同步控制信号。CPU 运行极快，主存运行很慢。当 CPU 发出 read 或 write 后，必须发一个 WMFC 信号，告诉控制器：“在这个周期把时钟挂起，或者反复自旋，直到主存通过硬件连线返回一个‘传输确认（ACK）’信号，才能进入下一个微操作”。
        
    - 实战意义：在写微操作步骤时，只要有访存操作（发出读/写命令及地址），往往紧接着或者在同一步的末尾隐含着等待数据就绪的逻辑。
