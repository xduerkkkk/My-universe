## 0. 最高危清单：先背这些

1. 🔥 **“至少”要上取整**：算出 98.33%，问“至少”就选 99%，不是 98。
2. 🔥 **按字节编址 ≠ 数据位宽**：一个地址对应 1B；块大小 32B ⇒ 块内偏移 5 位。
3. 🔥 **组相联映射流程**：字节地址 → 除以块大小得主存块号 → 主存块号 mod Cache 组数 = 组号。
4. 🔥 **Cache 物理分组 ≠ 主存块按顺序塞组**：主存块进入 Cache 组靠取模轮转，不是“两个块一组顺序打包”。
5. 🔥 **流水线/交叉存储看稳态吞吐**：题问 T 时间内能提供多少信息，常看流水线填满后的稳定输出，不是冷启动全过程。
6. 🔥 **单体多字解决带宽，不解决容量**。
7. 🔥 **DRAM 地址复用是行/列地址复用**，不是 CPU 地址线/数据线复用。
8. 🔥 **虚存对应用程序员透明，对系统程序员/OS 不透明**。
9. 🔥 **Cache 缺失硬件处理；缺页 OS 软件处理；TLB 缺失看体系结构**。
10. 🔥 **主存-外存层次用全相联思想**，不是直接映射。

## 1. 存储器基本分类与概念边界

### 1.1 随机、顺序、直接存取

| 类型 | 典型设备 | 关键词 |
|---|---|---|
| 随机存取 RAM | RAM、ROM、Flash/SSD | 给地址即可访问，访问时间基本与位置无关 |
| 顺序存取 SAM | 磁带 | 必须顺序经过前面的内容 |
| 直接存取 DAM | 机械磁盘、光盘 | 先定位到小区域，再在区域内顺序找 |

⚠️ 408 中“**串行访问存储器**”通常包括：**磁带 + 磁盘 + 光盘**。

### 1.2 半导体、磁表面、光存储

- **半导体存储器**：RAM + ROM + Flash。不是 RAM 的同义词。
- **磁表面存储器**：磁盘、磁带。
- **光存储器**：CD/DVD 等。
- ⚠️ 半导体存储器不一定易失，因为 ROM/Flash 非易失。

### 1.3 主存、内存、RAM、ROM、BIOS

- **主存/内存**：CPU 可直接按地址访问的存储器，通常主要是 RAM，也可含少量 ROM。
- **RAM**：运行时主要工作区，易失。
- **ROM**：非易失，常存 BIOS/Bootloader。
- **操作系统**：平时在硬盘，启动后由 BIOS/Bootloader 把核心装入 RAM。
- **外存**：硬盘、SSD、光盘等，CPU 不能直接执行外存中的普通数据，需调入内存。

### 1.4 相联存储器 CAM

- 核心不是“按地址找”，而是**按内容找**。
- 硬件会把关键字与所有相关单元**并行比较**。
- TLB/快表常用相联存储器思想。

## 2. DRAM / SRAM / 刷新 / 地址复用

### 2.1 SRAM vs DRAM

| 项 | SRAM | DRAM |
|---|---|---|
| 单 bit 结构 | 约 6T | 1T1C |
| 速度 | 快 | 慢 |
| 集成度 | 低 | 高 |
| 成本 | 高 | 低 |
| 是否刷新 | 不刷新 | 需要刷新 |
| 常用位置 | Cache | 主存 |

✅ DRAM 集成度高：因为 1T1C 面积远小于 SRAM 的 6T。

### 2.2 DRAM 刷新方式

| 刷新方式 | 特点 | 易错点 |
|---|---|---|
| 集中刷新 | 一段时间集中刷新 | 有较长死时间 |
| 分散刷新 | 每个存取周期分摊刷新 | 宏观无死时间，但存取周期变长 |
| 异步刷新 | 每隔固定时间刷新一行 | 效率高，死区极短但理论上仍有 |

公式：**刷新间隔 = 最大刷新周期 / 行数**。  
例：2ms / 256 ≈ 7.8μs。

⚠️ 刷新会影响 CPU 对 DRAM 的访存；如果 CPU 此时访问 Cache/SRAM/ROM，则不感知。

### 2.3 地址复用

- DRAM 地址复用：**行地址和列地址分时使用同一组地址引脚**。
- 目的：减少地址引脚数量。
- 不要和 CPU 的“地址线/数据线复用”混淆。
- 地址线多 1 根，容量通常 ×2。

## 3. 多模块存储、交叉编址、单体多字

### 3.1 低位交叉编址

- 低位交叉：连续地址分散到不同模块，方便并行/流水访问。
- 4 个模块时看低 2 位：`00/01/10/11`。
- 多模块能提速的根因：**各模块有独立读写电路**。

公式：**模块数 m ≥ 存取周期 T / 总线传输周期 r**。

### 3.2 稳态吞吐题

解题思路：

1. 先判断是不是多体交叉/流水线。
2. 区分“首次取数延迟”和“流水线填满后每隔多久吐一次数据”。
3. 题问“在 T 时间内能提供多少信息”时，优先考虑**稳态吞吐率**。

例：四体交叉、每模块 32 位、总线周期 50ns，稳态下每 50ns 输出 32 位；200ns 输出 128 位。

### 3.3 单体多字

- 一次访存取出多个连续字。
- 解决：**速度/带宽不匹配**。
- 不解决：**主存容量不足**。
- 跳转指令会破坏空间局部性，使预取出的连续字浪费。

## 4. CPU 与存储器连接、片选、地址计算

### 4.1 片选题通用流程

1. 先看**基础芯片容量**，算出片内地址位数。
2. 再看系统总容量，算需要多少片、如何字扩展/位扩展。
3. 最后确定哪些高位地址线做片选。

⚠️ 不要用扩展后的整体容量去错算基础芯片的片内地址位数。

### 4.2 地址线编号

- 地址位从 **A0** 开始。
- 做题先标高位/低位，不要把“第几位”和 A 几搞混。
- 片选地址、首地址、末地址可以由片选条件 + 芯片容量直接推出。

### 4.3 固定计算坑

- `2^16 - 2^13 = 2^13(2^3 - 1)`，不是 `2^3`。
- 十六进制 `F = 15`，但从 0 开始数时它是第 16 个数。
- 看到“至少”“最大”“平均”“稳态”先圈出来。

## 5. Cache 核心题型

### 5.1 Cache 地址划分

通用结构：

```text
主存地址 = [ Tag | 行号/组号 | 块内偏移 ]
```

- 块内偏移位数 = log2(块大小 B)。
- 直接映射：有行号。
- 组相联：有组号。
- 全相联：无行号/组号，但仍有块内偏移，不是“整个地址都是 Tag”。

### 5.2 组相联映射模板

🔥 固定流程：

```text
字节地址 / 块大小 = 主存块号
主存块号 mod Cache 组数 = 组号
```

⚠️ 不能直接 `字节地址 mod 组数`。那取到的是低位偏移相关部分，可能只是碰巧对。

### 5.3 Cache 行附加位

| 位 | 作用 | 什么时候需要 |
|---|---|---|
| Tag | 判断是不是目标主存块 | 必需 |
| Valid 有效位 | 判断该行是否有效 | 必需 |
| Dirty 脏位/修改位 | 写回时判断是否要写回主存 | 写回法需要 |
| 替换/LRU 位 | 记录替换信息 | 组相联/全相联可能需要 |

直接映射只有一个候选位置，所以**不需要替换选择**。

### 5.4 比较器数量

| 映射方式 | Tag 比较次数 |
|---|---|
| 直接映射 | 1 次 |
| N 路组相联 | N 次 |
| 全相联 | 所有 Cache 行都比较 |

### 5.5 Cache 平均访问时间

- 同时访问 Cache 和主存：`Tavg = h·Tc + (1-h)·Tm`
- 先 Cache 后主存：`Tavg = h·Tc + (1-h)·(Tc + Tm)`

题目没说清时，要看教材默认语境；王道中常把硬件设计理解为并行/同时访问。

### 5.6 Cache 块大小与命中率

- 块大可利用空间局部性。
- 但 Cache 总容量固定时，块大 ⇒ 块数少 ⇒ 冲突/替换可能增加。
- 所以不能简单说“块越大命中率越高”。

### 5.7 指令 Cache 与数组访问

- 指令 Cache 空间局部性通常好，因为指令流多为顺序执行。
- 数组题要按代码数访存次数：`a[k] = a[k] + 1` 是读一次 + 写一次。
- 例：块 16B、int 4B ⇒ 一个块带 4 个元素；处理 4 个元素时有 4 读 + 4 写，首次访问该块缺失。

### 5.8 Cache 缺失装块时间

若题目没说明突发传输/多模块交叉，按最普通过程算：

```text
一次传输时间 = 发地址/命令 + 主存准备数据 + 总线传输
```

## 6. 虚拟存储、页表、TLB

### 6.1 块、页、页框

- Cache 单位：块 / 行。
- 虚拟地址空间单位：页。
- 物理主存单位：页框。

### 6.2 透明性

| 对象 | 虚拟存储是否透明 |
|---|---|
| 应用程序员 | 透明 |
| 系统程序员 / OS | 不透明 |

OS 要维护页表、处理缺页中断、管理页表基址寄存器等。

### 6.3 TLB / Cache / 缺页处理

| 事件 | 谁处理 |
|---|---|
| Cache 缺失 | 硬件 |
| TLB 缺失 | 硬件或软件，取决于体系结构 |
| 缺页 | OS 软件 |

边界条件：TLB 缺失后查页表，若有效位为 0 ⇒ 缺页 ⇒ OS 从外存调页。

### 6.4 快表与慢表

- TLB/快表在 CPU 内，不在主存。
- TLB 用相联存储器并行比较虚拟页号。
- 慢表在主存，访问慢。
- 每个进程通常有自己的页表；用户进程不能随便访问/修改页表。

### 6.5 Cache-主存 vs 主存-外存

| 层次 | 映射/替换特点 |
|---|---|
| Cache-主存 | 可直接映射/组相联/全相联；替换由硬件完成 |
| 主存-外存 | 页式虚存近似全相联；缺页替换由 OS 完成 |

主存-外存不用直接映射，因为磁盘代价太高，要尽量降低缺页率。

## 7. 外存与磁盘

### 7.1 RAID

- RAID 提高：可靠性、并行传输率。
- RAID 不提高：单盘磁记录密度。
- RAID 不一定提高磁盘利用率：RAID1 利用率 50%，RAID5 为 `(N-1)/N`。

### 7.2 扇区与数据块

- 扇区：磁盘物理最小读写单位。
- 数据块/block：文件系统/OS 逻辑单位，通常由 1 个或多个连续扇区组成。
- 数据块 ≥ 扇区。

### 7.3 磁盘平均存取时间

公式：

```text
T = 平均寻道时间 + 平均旋转延迟 + 数据传输时间 (+ 控制器延迟)
```

- 平均旋转延迟 = 半圈时间。
- 传输时间 = 一圈时间 × 扇区占整道比例。
- 有控制器延迟就加；没给就不加。

### 7.4 平均传输率 vs 最大传输率

- 平均传输率：用整圈时间摊。
- 最大传输率：只用磁头经过有效数据区的时间算。
- 有 gap/间隙时，最大传输率 > 平均传输率。

### 7.5 CHS 与总磁道数

- 总磁道数 = 每面磁道数 × 记录面数。
- 柱面：多个盘面上半径相同的磁道集合；同柱面切换磁头，不用重新寻道。

## 8. 最后一遍做题检查表

每道题开算前问自己：

1. 这是哪个层次？Cache-主存、主存-外存、DRAM、磁盘、CPU 连接？
2. 单位是什么？B、bit、字、块、页、页框、扇区、磁道？
3. 是平均、最大、至少，还是稳态？
4. 地址题有没有先画位段？有没有从 A0 开始？
5. Cache 题有没有先算块号，再算组号？
6. 磁盘题有没有加完整三件套：寻道 + 半圈 + 传输？
7. 虚存题有没有分清：Cache miss、TLB miss、缺页？
