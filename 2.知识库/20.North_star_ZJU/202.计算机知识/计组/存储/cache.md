
cache 用 sram，寄存器用的啥设计的？怎么比 cache 还快


主存对于 cache 来说，4M 的大小，22bit，可分为 12bit 的块号，每块 1kb。
为啥分块呢，因为 cache 自己也是分块的，所以让他俩一个单位。cache 块大小和主存块大小相等

cache 与主存的映射
全相联、直接映射、组相联

然后 cache 的有效位，我的理解只是为了主存的 0 块号服务啊！因为 cache 有个标记位记录这里是主存的哪一块，只有记录主存的第 0 块时有歧义


刚才讲的是，cache 的标记位记录这里是主存的哪一块，即主存的块号多少位，标记位就多少位。

但对于直接映射和组相联，我们可以减少标记位，因为 cache 行号本身就有所信息

全写法，写命中时，修改 cache 的同时也修改主存。搭配非写分配法： 若写不命中，直接写入主存

写回法，写命中时，只修改 cache。当 cache 要被替换时，才抹除 cache 同时顺便修改主存。搭配写分配法，若写不命中，把主存块调入 cache
