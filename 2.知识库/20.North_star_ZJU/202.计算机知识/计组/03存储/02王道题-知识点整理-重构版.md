> [!abstract] 章节主线
> 存储系统用“容量—速度—成本”分层折中：先明确编址单位与访问单位，再分析主存组织、地址译码、Cache/虚存映射和外存物理时延；所有计算都要区分编号、位数、冷启动与稳态。

## 1. 存储层次与访问方式

### 1.1 层次目标

| 层次 | 典型介质 | 主要目标 | 管理主体 |
|---|---|---|---|
| 寄存器 | 触发器 | 最低延迟 | CPU 硬件/指令 |
| Cache | SRAM | 缓解 CPU—主存速度差 | 硬件 |
| 主存 | DRAM | 当前运行程序和数据 | 硬件 + OS |
| 外存 | SSD/磁盘 | 大容量持久化 | OS/控制器 |
| 虚拟存储 | 主存 + 外存 | 扩展地址空间、按需调页 | 硬件翻译 + OS |

### 1.2 访问方式

| 方式 | 特征 | 典型例子 |
|---|---|---|
| 随机访问 | 任意地址时间基本与位置无关 | RAM、ROM 读访问 |
| 顺序访问 | 必须按顺序经过前面记录 | 磁带 |
| 直接访问 | 先定位局部区域，再顺序找到记录 | 机械磁盘 |
| 相联访问 | 按内容并行比较 | TLB、相联 Cache |

> [!warning] 旧版表述：SAM 和 DAM 被统称为“串行访问存储器”，磁盘/光盘均可直接机械套入。
> **校正**：这是部分教材的分类口径，核心仍应按“访问时间是否依赖位置、如何定位”判断。SSD 以半导体 Flash 实现，不应按机械磁盘的寻道模型分类。  
> **适用条件**：408 题目若给出教材术语，以该教材定义为准。

### 1.3 透明性

- 对应用程序员，Cache、物理页框和多数 I/O 细节通常透明。
- 对系统程序员，页表、缺页处理、Cache 维护等可能可见。
- “透明”必须带观察者：对谁透明、在哪个抽象层透明。

## 2. 半导体存储器

### 2.1 SRAM 与 DRAM

| 特性 | SRAM | DRAM |
|---|---|---|
| 单元 | 多晶体管双稳态结构 | 电容 + 访问晶体管 |
| 刷新 | 不需周期刷新 | 需刷新 |
| 读出 | 通常非破坏性 | 经典 DRAM 读出需再生 |
| 速度 | 快 | 较慢 |
| 密度/成本 | 密度低、贵 | 密度高、便宜 |
| 典型用途 | Cache | 主存 |

### 2.2 ROM 家族

- MROM：制造时固化。
- PROM：一次可编程。
- EPROM：紫外线擦除，通常整片擦。
- EEPROM：电擦写，可较细粒度更新。
- Flash：基于浮栅非易失存储，通常按块擦除。

“可随机读”是一种访问性质；“RAM”是教材中的器件类别。两者不要混用。

### 2.3 主存与固件边界

- 主存主体通常是 DRAM/RAM。
- 固件存储器是否纳入“主存”依体系结构和教材口径。
- BIOS/UEFI 是 PC 固件实现，不是“主存必须包含 BIOS ROM”的普遍定义。
- OS 持久副本在外存，运行时内核与活跃页进入 RAM。

## 3. DRAM 刷新与时序

### 3.1 四个时间概念

| 概念 | 含义 |
|---|---|
| 存取时间 | 请求到数据可用 |
| 存取周期 | 两次独立存取可连续开始的最小间隔 |
| 恢复/预充电 | 一次读写后的内部恢复阶段 |
| 刷新周期/保持时间要求 | 所有行必须在该宏观时限内刷新一遍 |

### 3.2 刷新方式

| 方式 | 组织 | 影响 |
|---|---|---|
| 集中刷新 | 一段时间连续刷新所有行 | 连续死区明显 |
| 分散刷新 | 每个存取周期固定插入刷新阶段 | 无长连续死区，但普通存取周期被拉长 |
| 异步刷新 | 在保持时间内均匀分散刷新行 | 折中，单次刷新仍可能占用资源 |

“无死区”通常指没有一段连续不可访问时间，不等于刷新没有任何带宽/延迟代价。

### 3.3 行列地址复用

- 逻辑地址共 n 位，拆为 r 位行地址与 c 位列地址，$r+c=n$。
- 同一组地址引脚分时输入行、列地址，地址引脚至少为 $max(r,c)$。
- 方阵是常见题设简化，不是所有 DRAM 芯片必须正方形。
- $N_{row}=2^r$，异步刷新间隔 $t_{ref}/N_{row}$。

> [!warning] 旧版表述：算刷新行数只能看单块芯片，绝对不能看拼装后总容量。
> **校正**：位扩展的多片芯片常可并行刷新同一行，因此按单片行数算；但字扩展、多 rank/bank 的刷新组织取决于控制方式和题设。  
> **检查**：先辨认多片是并联位扩展，还是增加地址空间的字扩展。

### 3.4 SDRAM

- “同步”描述命令/数据相对时钟的接口与流水时序。
- SDRAM 仍需刷新。
- 后续 DDR 通过双沿传输、bank 并行、突发传输提高带宽，不改变动态存储基本属性。

## 4. 主存组织与并行

### 4.1 单体多字

- 一次访问读出多个相邻字，增加数据通路宽度。
- 主要提高顺序吞吐，利用空间局部性。
- 组织方式本身不必然增加总 bit 容量；是否增容看是否增加存储单元/芯片。
- 跳转或跨步访问会浪费预取出的字。

### 4.2 多模块存储

| 组织 | 地址分配 | 特征 |
|---|---|---|
| 高位交叉 | 高位选模块 | 连续地址集中在同一模块，不利于连续并行 |
| 低位交叉 | 低位选模块 | 连续地址轮流落到不同模块，形成流水 |
| 同时启动 | 多模块同一时刻并行供数 | 常与宽总线/位扩展结合 |
| 轮流启动 | 模块错开 r 启动 | 稳态每 r 输出一个字 |

### 4.3 交叉存储公式

- 模块周期 T，连续启动间隔 r：$m\ge \lceil  T/r\rceil$。
- 稳态吞吐约为每 r 一个传送单位。
- n 个字从冷启动完成的时间常为首字延迟 + $(n-1)r$；总线传输另计时按题设加上。
- “T 时间内提供多少信息”必须确认从冷启动计时还是描述稳态带宽。

## 5. 存储芯片扩展与地址译码

### 5.1 三种扩展

- **位扩展**：增加每字位数；芯片共享地址线和片选，数据线分片连接。
- **字扩展**：增加可寻址字数；低位地址进片内，高位地址译码片选。
- **字位同时扩展**：每组先位扩展，再用多组字扩展。

### 5.2 计算模板

目标 $A\times B$，芯片 $a\times b$：

- 每组位扩展片数：$B/b$；
- 字扩展组数：$A/a$；
- 总片数：$(B/b)(A/a)$。

若单片有 $2^k$ 个编址单元：

- A0～A(k−1) 接片内地址；
- 更高位用于译码片选；
- 某片首地址：片选高位固定 + 低 k 位全 0；
- 末地址：片选高位固定 + 低 k 位全 1。

## 6. 磁盘与外存

### 6.1 几何术语

| 术语 | 含义 |
|---|---|
| 记录面 | 可记录数据的盘面 |
| 磁头 | 对应记录面的读写头 |
| 磁道 | 单个记录面上的同心圆 |
| 柱面 | 所有记录面上半径相同的磁道集合 |
| 扇区 | 设备物理传送/寻址单位 |
| 块 | OS/文件系统逻辑分配/I/O 单位 |

- 柱面数通常等于每面磁道数。
- 总磁道数 = 每面磁道数 × 记录面数。
- 块可包含一个或多个扇区，不能无条件说“数据块一定大于扇区”；也可能恰好等于一个扇区。

### 6.2 容量

$容量=记录面数\times 每面磁道数\times 每磁道扇区数\times 每扇区字节数$

- CAV：角速度恒定；若每磁道扇区数固定，内外磁道线密度不同。
- 分区记录：外圈可安排更多扇区，需分区求和。
- 区分非格式化容量、格式化容量、用户可用容量。

### 6.3 时间

$T_{access}=T_{seek}+T_{rotation}+T_{transfer}$

- 平均旋转延迟常取半圈：$30/RPM$ 秒。
- 传输时间可按读取扇区占一圈的比例计算。
- 寻道、旋转、传输必须分别对应“移动磁头、等待目标扇区、真正读写位流”。

## 7. Cache 基础

### 7.1 Cache 对软件透明

- CPU 产生主存地址；Cache 控制器判断命中。
- Cache 不占独立主存地址范围。
- 物理地址/虚拟地址 Cache 的具体组织不同，408 常见题通常直接给物理地址位段。

### 7.2 地址结构

| 映射 | 地址位段 |
|---|---|
| 直接映射 | Tag | Line | Offset |
| K 路组相联 | Tag | Set | Offset |
| 全相联 | Tag | Offset |

- Offset 位数 = $\log_2(块字节数)$（按字节编址）。
- 行数 = 数据容量/块大小。
- 组数 = 行数/K。
- Tag 位数 = 物理地址位数 − Set/Line 位 − Offset 位。

### 7.3 映射与比较

- 直接映射：块号 mod 行数 = 行号；比较 1 个 Tag。
- K 路组相联：块号 mod 组数 = 组号；并行比较组内 K 个 Tag。
- 全相联：块可进入任意行，逻辑上比较所有行 Tag。
- 直接映射没有候选选择，所以不需要替换算法。

### 7.4 地址到组号

字节地址 A：

1. $Block=\lfloor  A/BlockSize\rfloor$；
2. $Set=Block\bmod SetCount$。

不能跳过块号直接用字节地址对组数取模。十进制除法取模与二进制位段法完全等价。

## 8. Cache 容量与写策略

### 8.1 一行字段

| 字段 | 是否必有 | 说明 |
|---|---|---|
| Data | 是 | 块大小 ×8 bit |
| Tag | 是 | 区分映射到同一位置的主存块 |
| Valid | 通常是 | 当前行内容是否有效 |
| Dirty | 写回法需要 | 是否修改但未写回主存 |
| 替换状态 | 组内多路且算法需要时 | 位数依算法和实现 |

> [!warning] 旧版表述：n 路组相联 LRU/FIFO 每行需要 $\lceil \log_2n\rceil$ 位。
> **校正**：精确 LRU 状态位数和编码方式取决于实现，通常不是简单“每行固定排名位”即可概括；FIFO 也可按每组维护指针。  
> **答题条件**：严格按题目给出的替换位数/算法模型计算，不自行套通式。

### 8.2 写策略

| 维度 | 选项 | 影响 |
|---|---|---|
| 命中写 | 直写 / 写回 | 是否需要 Dirty |
| 不命中写 | 写分配 / 非写分配 | 是否先装块再写 |

数组读改写题必须先写出这两个维度，否则缺失次数可能不同。

### 8.3 平均访问时间

- **先 Cache 后主存**：$T_{avg}=T_c+(1-h)T_m$（若 $T_m$ 表示未命中后的额外主存代价）。
- **并行/同时访问**：命中与未命中路径公式取决于硬件与题目对 $T_m$ 的定义。
- 不存在“硬件默认一定同时访问”的通用结论；必须看题目模型。

## 9. 局部性与数组访问

- 指令流常顺序执行，通常有空间局部性，但分支会破坏。
- 数据数组按存储顺序访问也有强空间局部性。
- 二维数组题：先按行优先/列优先计算线性地址，再求块号与组号。
- 读改写 `a[k]=a[k]+1` 至少要区分一次读和一次写，并按写策略标命中/缺失。
- Cache 初始为空时先考虑强制缺失，再考虑容量与冲突缺失。

## 10. 虚拟存储、TLB 与 Cache

### 10.1 地址结构

- 逻辑地址 = 虚页号 + 页内偏移。
- 物理地址 = 页框号 + 页内偏移。
- 页与页框等大，因此偏移位不变。

### 10.2 三类缺失

| 事件 | 含义 | 处理 |
|---|---|---|
| TLB miss | 翻译缓存无表项 | 硬件 page walker 或软件异常，依体系结构 |
| Page fault | 页不在主存/权限等异常 | OS 处理；可能调页 |
| Cache miss | 数据块不在 Cache | Cache 硬件从下级补块 |

- TLB miss 不等于 page fault。
- TLB miss 不必然等于 Cache miss；二者是翻译缓存和数据缓存两个层次。
- 缺页发生后，目标页此前通常不可能以正常有效形式存在于物理 Cache 中，但答题仍应按题目访问流程区分事件。

### 10.3 映射与替换

- Cache—主存：硬件、高速、小块，可采用直接/组相联/全相联。
- 主存—外存：页面可装入任意可用页框，408 抽象中视作全相联；页表定位，OS 置换。
- “必须全相联”是教材抽象；实际系统还受 NUMA、页着色、设备 DMA 区域等约束。

## 11. 大题统一模板

### 11.1 交叉存储

识别 T、r、模块数、字长 → 判断低位/高位交叉 → 算首字延迟与稳态间隔 → 写总时间 → 用模块恢复约束自检。

### 11.2 芯片连接

目标容量/字长 → 位扩展片数 → 字扩展组数 → 片内低位地址 → 高位译码片选 → 首末地址 → 数据线/控制线连接。

### 11.3 Cache 位数

物理地址位数 → 块大小/Offset → 行数/组数 → Index/Set → Tag → 每行数据与元数据 → 总 bit。

### 11.4 数组 Cache

数组布局 → 元素字节地址 → 块号/组号 → 访问序列 → 写策略 → 命中/缺失 → 总时间。

### 11.5 磁盘

盘面/柱面/扇区参数 → 容量 → 地址字段 → 寻道/旋转/传输 → 总时间。

## 12. 易混概念

- **存取时间 vs 存取周期**：数据可用延迟 vs 下一次可开始间隔。
- **恢复 vs 刷新**：破坏性读出后的再生 vs 防漏电的周期动作。
- **行列地址复用 vs 地址/数据总线复用**：DRAM 芯片内寻址 vs CPU 引脚复用。
- **位扩展 vs 字扩展**：加字长 vs 加可寻址单元数。
- **模块编号 vs 第几个模块**：编号从 0 起。
- **块数据位 vs Offset 位**：存了多少 bit vs 块内选择需要多少地址位。
- **Cache 行/组 vs 主存块映射**：物理编组结构 vs 取模映射规则。
- **TLB miss vs page fault vs Cache miss**：翻译、驻留、数据缓存三个事件。

## 13. 绝对词检查

- “主存等于 RAM+BIOS ROM” → 检查教材/系统口径。
- “刷新一行一定恰好一个存取周期” → 看题设时序。
- “异步刷新没有死区” → 只有长连续死区很小，单次资源占用仍在。
- “指令 Cache 一定比数据 Cache 局部性好” → 只能说常见趋势。
- “平均访问默认同时访问 Cache 和主存” → 看硬件模型和公式定义。
- “TLB miss 必然 Cache miss/缺页” → 错，分层判断。
- “块一定大于扇区” → 可等于一个扇区。
- “精确 LRU 每行固定 $\log_2n$ 位” → 看实现/题设。
