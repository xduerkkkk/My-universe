# 1. 存储器分类与基本概念

## 1.1 按访问方式分类

- 随机存取：RAM、ROM。
- 顺序存取：磁带，SAM。
- 直接存取：磁盘、光盘，DAM。
- 串行访问存储器：408 语境下常把顺序存取和直接存取归为串行访问。

### 易混点

- “随机存取”强调访问时间与地址位置无关，不等于“一定可随便反复写”。
- ROM 具有随机存取性质，但由于写入困难/次数有限，不能简单等同于 RAM。
- 固态硬盘是闪存，实际访问特性和机械硬盘不同；王道/408 语境要看题目默认分类。

### 关联题

- 存储器概述 1：随机、顺序、直接存取。
- 存储器概述 13：透明性。
- 主存 14：ROM 与随机存取性质。

### 复盘口令

> 先看“访问时间是否依赖物理位置”，再看“是否易写/可改写”。

---

## 1.2 存取时间、存取周期、访存周期

- 存取时间：CPU 发出读/写命令，到数据稳定可用的时间。
- 存取周期：存储器连续两次独立访问之间的最小时间间隔。
- 访存周期：408 常规语境下基本等同于存取周期。

### 易混点

- 存取时间偏 CPU 视角，强调这次访问何时拿到数据。
- 存取周期偏芯片/存储器视角，强调下一次访问最早何时能开始。
- DRAM 中，读出后的恢复动作会影响存取周期。

### 关联题

- 存储器概述 2：存取周期、存取时间对比。
- 主存 15：DRAM 恢复、刷新、存取周期。

### 复盘口令

> 时间是“这次多久拿到”；周期是“两次之间最小间隔”。

# 2. 主存、内存、RAM、ROM、BIOS

## 2.1 主存/内存的边界

- 内存储器/主存：CPU 可以通过地址总线直接访问的存储器。
- 外存储器/辅存：硬盘、光盘等，CPU 不能直接访问，需调入主存。
- 主存通常包括：RAM 为主 + 少量 ROM。

## 2.2 BIOS/Bootloader 与操作系统

- BIOS/Bootloader 通常固化在 ROM 中。
- 操作系统平时存放在外存中。
- 开机后 BIOS/Bootloader 负责把 OS 核心加载到 RAM 中运行。

### 易混点

- “操作系统在硬盘”是静态存放位置。
- “操作系统运行时在内存”是执行位置。
- 主存不是只有 RAM，也可能包括少量 ROM。

### 关联题

- 主存 13：RAM、ROM、BIOS、操作系统位置。

### 复盘口令

> 判断主存/外存，只问 CPU 能不能直接寻址。

---

# 3. SRAM、DRAM 与半导体存储器

## 3.1 SRAM 与 DRAM 对比

| 项目 | SRAM | DRAM |
|---|---|---|
| 存储单元 | 触发器，常见 6T | 1T1C，电容存电 |
| 速度 | 快 | 慢 |
| 集成度 | 低 | 高 |
| 成本 | 高 | 低 |
| 是否刷新 | 不需要刷新 | 需要刷新 |
| 常见用途 | Cache | 主存 |

### 易混点

- DRAM 集成度高，是因为 1T1C 面积远小于 SRAM 的 6T 结构。
- DRAM 慢但容量大、便宜，适合主存。
- SRAM 快但贵，适合 Cache。

### 关联题

- 主存 5：DRAM 集成度为什么高。
- 主存 6：半导体存储器是否等于 RAM。

### 复盘口令

> SRAM 快而贵，DRAM 慢而密。

---

## 3.2 半导体存储器

- 半导体存储器是按材料/实现方式分类，不等于 RAM。
- 包含 RAM：SRAM、DRAM。
- 也包含 ROM：MROM、PROM、EPROM、EEPROM、Flash 等。

### 易混点

- 半导体存储器不一定易失，因为 ROM/Flash 也是半导体。
- 主存常用半导体存储器。

### 复盘口令

> 半导体是材料分类，RAM/ROM 是功能与访问属性分类。

---

# 4. DRAM 刷新专题

## 4.1 为什么要刷新

- DRAM 通过电容存储信息。
- 电容会漏电，所以需要周期性刷新。
- 不通电时数据立即丢失；“工作中漏电”是在通电条件下讨论保持数据的问题。

## 4.2 恢复与刷新

| 概念 | 触发原因 | 作用 | 是否和正常访问绑定 |
|---|---|---|---|
| 恢复 Recovery | 读操作破坏电容电荷 | 把刚读出的行重新写回 | 是，读后必须恢复 |
| 刷新 Refresh | 电容随时间自然漏电 | 定时把行读出再写回 | 否，由刷新电路/控制器定时触发 |

### 易混点

- 恢复是“刚刚读坏了，所以补回来”。
- 刷新是“时间久了会漏光，所以定期保命”。
- 刷新一行通常也占用一个存取周期。

### 关联题

- 主存 15：恢复、刷新、存取周期。
- 主存 16：异步刷新计算。
- 主存 17：刷新是否影响 CPU 访存。

### 复盘口令

> 恢复跟着读写走，刷新跟着时间走。

---

## 4.3 刷新方式

| 刷新方式 | 特点 | 死区/访存影响 |
|---|---|---|
| 集中刷新 | 在刷新周期末集中刷新所有行 | 有较长死时间 |
| 分散刷新 | 每个存取周期中安排刷新 | 宏观无集中死区，但存取周期变长 |
| 异步刷新 | 把所有行刷新均匀分散到刷新周期内 | 死区极短，效率较高 |

### 易混点

- 真正“无集中死区”的是分散刷新，但它牺牲了每次存取周期。
- 异步刷新不是完全没有影响，只是把影响分散得很小。

### 关联题

- 主存 4：DRAM 刷新方式。
- 主存 16：异步刷新信号间隔。

---

## 4.4 异步刷新计算模板

### 标准动作

1. 找单块 DRAM 芯片容量，如 64K×1。
2. 算单块芯片逻辑地址位数，如 64K = 2^16。
3. 默认 DRAM 地址复用且矩阵近似正方形，行地址位 = 总地址位 / 2。
4. 行数 = 2^行地址位。
5. 异步刷新信号间隔 = 最大刷新周期 / 行数。

### 易混点

- 行数只看单块芯片，不看拼装后的总容量。
- “每单元刷新间隔不超过 2ms”在计算中等价为“所有行在 2ms 内都要刷新一遍”。

### 关联题

- 主存 16：DRAM 异步刷新。

### 复盘口令

> 刷新按行刷；行数看单片；间隔 = 刷新周期 / 行数。

---

## 4.5 SDRAM 同步/异步

- 传统 DRAM：与 CPU/系统时钟异步，CPU 不知道何时完成，只能等待或握手。
- SDRAM：Synchronous DRAM，与系统时钟同步，按节拍传输。

### 关联题

- 主存 18：SDRAM。

### 复盘口令

> 同步/异步说的是是否跟系统时钟节拍协同。

---

# 5. 地址复用、位平面与 DRAM 组织

## 5.1 DRAM 地址复用

- DRAM 常把行地址和列地址分时送入同一组地址引脚。
- 目的：减少芯片地址引脚数量。
- 注意：这是 DRAM 芯片寻址中的行/列地址复用，不是 CPU 总线中的地址线/数据线复用。

### 易混点

- 逻辑地址线增加 1 根，容量翻倍。
- DRAM 外部地址引脚数量可能因行列复用而减少。
- 题目问“容量”还是问“引脚”，要分清。

### 关联题

- 主存 10：地址复用。
- 主存 19：地址线增加与容量。
- 主存 34：地址引脚与刷新。

### 复盘口令

> 容量看逻辑地址位；引脚看行列复用。

---

# 6. 主存扩展与 CPU 连接

## 6.1 位扩展、字扩展、字位同时扩展

- 位扩展：增加每个存储字的位数。
- 字扩展：增加存储字数量，即扩大地址空间。
- 字位同时扩展：容量和字长都扩。

## 6.2 片内地址与片选

### 标准动作

1. 看单片容量，算片内地址线数量。
2. 看目标容量，算需要多少片/多少组。
3. 低位地址通常接芯片内部地址端。
4. 剩余高位地址用于片选。

### 易混点

- 片内地址位数由基础芯片容量决定，不由扩展后的总容量决定。
- 判断片选在哪条地址线前，必须先算基础芯片可表示多少地址。
- 高位/低位描述要和题目地址范围严格对应。

### 关联题

- 存储器与 CPU 连接 7：片选、高低位、基础芯片地址位。
- 存储器与 CPU 连接 11：读题困难/图示题。
- 存储器与 CPU 连接 15：2 的幂计算错误。

### 复盘口令

> 先单片，再组数；低位进片内，高位做片选。

---

# 7. 多模块存储器、低位交叉、单体多字

## 7.1 多模块存储器

- 多模块存储器通过多个独立存储体并行/交叉工作，提高访问速度或带宽。
- 关键原因：各模块有独立读写电路，可以重叠访问。

### 关联题

- 主存 21：模块数 m ≥ T/r。
- 主存 22：四体低位交叉，总线周期。
- 主存 26：多模块提高速度的原因。

### 复盘口令

> 多模块快，是因为模块读写电路独立，可以流水重叠。

---

## 7.2 低位交叉编址

- 低位交叉：连续地址分散到不同模块。
- 高位交叉：一段连续地址在同一模块内。
- 低位交叉更适合连续访问，能形成流水。

### 标准动作

1. 判断模块数，如 4 体需要低 2 位，8 体需要低 3 位。
2. 把地址低位转为二进制。
3. 用低位决定模块号。

### 易混点

- 十六进制 F 是 1111，对应 0~F 的第 16 个状态。
- 低位交叉只看低位，不要被高位地址干扰。

### 关联题

- 主存 24：低位交叉与十六进制末位。

### 复盘口令

> 四体看低 2 位，八体看低 3 位。

---

## 7.3 模块数与流水线公式

- 存取周期：T。
- 总线传输周期：r。
- 为了连续流水不冲突，模块数通常满足：m ≥ T/r。

### 易混点

- 首个数据的延迟和稳定输出节拍不同。
- 连续读写看流水线，不是简单把每次访存时间相加。

### 关联题

- 主存 21、22、23、33。

### 复盘口令

> 看到 T 和 r，先想 m ≥ T/r，再画时间轴。

---

## 7.4 单体多字

- 单体多字：一个存储体一次读出多个连续字。
- 主要解决速度/带宽问题，不解决容量问题。
- 对顺序访问有效；跳转会破坏优势。

### 关联题

- 主存 25：单体多字。

### 复盘口令

> 单体多字提带宽，不扩容量；连续有效，跳转失效。

---

# 8. Cache 基本概念与局部性

## 8.1 Cache 的位置与作用

- Cache 位于 CPU 和主存之间。
- 作用：利用局部性缓解 CPU 与主存速度不匹配。

## 8.2 指令 Cache 和数据 Cache

- 指令流通常顺序执行，空间局部性较好。
- 数据访问模式更复杂，局部性取决于程序。

### 关联题

- Cache 9：指令 Cache 空间局部性。

### 复盘口令

> 指令常顺序，数据看模式。

---

# 9. Cache 地址映射与地址划分

## 9.1 三种映射方式

| 映射方式 | 主存块可放位置 | Tag 比较次数/比较器 |
|---|---|---|
| 直接映射 | 唯一 Cache 行 | 1 次 |
| 全相联 | 任意 Cache 行 | 所有行并行比较 |
| n 路组相联 | 指定组内任意一路 | n 次并行比较 |

### 易混点

- 直接映射没有替换选择，因为只有一个候选位置。
- 组相联是先定位组，再在组内比较 Tag。
- 主存块号 % 组数 定位到组，组内具体路由替换算法决定。

### 关联题

- Cache 12：组相联流程。
- Cache 25：直接映射无需替换。
- Cache 27：比较器数量。

### 复盘口令

> 直接映射比 1 个；全相联比所有；n 路组相联比 n 个。

---

## 9.2 地址划分模板

Cache 地址题先拆：

[ Tag | Index/组号 | Offset/块内地址 ]

- Offset：由块大小决定。
- Index/组号：由 Cache 行数或组数决定。
- Tag：剩余高位。

### 易混点

- 字块内地址就是块内偏移 Offset。
- 按字节编址时，块大小为 32B，则 Offset = 5 位。
- 数据块大小和地址位数不是一回事。

### 关联题

- Cache 19：字块内地址/Offset。
- Cache 33：按字节编址、块大小、Offset。

### 复盘口令

> Offset 看块大小，Index 看行/组数，Tag 是剩下的高位。

---

## 9.3 Cache 映射表/目录表容量

每个 Cache 行的元数据可能包括：

- Valid 有效位：通常必须有，1 bit。
- Tag 标记位：用于判断主存块是否匹配。
- Dirty 修改位：写回法需要。
- 替换控制位：LRU/FIFO 等可能需要；随机替换通常不需要。
- 数据位：块内真实数据。

### 易混点

- 映射表项不是主存地址全存，只存 Tag 等元数据。
- 直接映射 Tag = 主存块号位数 - Cache 行号位数。
- 组相联 Tag = 主存块号位数 - 组号位数。
- 题目问“Cache 总容量”时，可能要把数据位和控制位都算进去；题目问“数据容量”则只看数据。

### 关联题

- Cache 14：地址映射表漏有效位。
- Cache 21：Cache 容量、数据位、替换位。

### 复盘口令

> 表项至少 Tag + Valid；总容量看题目是否要求控制位。

---

# 10. Cache 缺失率与数组访问

## 10.1 数组访问题标准动作

1. 明确每条语句有几次访存。
2. 根据块大小算一个块能装几个数组元素。
3. 写出访问序列。
4. 判断首次访问缺失、后续命中、替换冲突。
5. 用缺失次数 / 总访存次数计算缺失率。

### 易混点

- a[k] = a[k] + 1 至少包含读 a[k] 和写 a[k]。
- 如果 int 为 4B，块大小为 16B，则一个块装 4 个 int。
- 写命中/写不命中策略会影响缺失率计算，题目没说时要按教材默认语境判断。

### 关联题

- Cache 31：数组访问缺失率。

### 复盘口令

> 先数访存，再看一块装几个元素。

---

# 11. 虚拟存储与页式地址转换

## 11.1 逻辑地址和物理地址

- 逻辑地址：页号 + 页内偏移。
- 物理地址：物理块号 + 块内偏移。
- 页大小 = 物理块大小，所以页内偏移和块内偏移位数相同。

### 易混点

- “有效位”有时不是 Valid bit，而是“表示该地址至少需要多少二进制位”。
- 地址转换只替换高位：页号 → 物理块号；低位偏移不变。

### 关联题

- Cache/虚拟存储 18：逻辑地址有效位、物理地址位数。
- 虚拟存储 4、7、14、22：相关基础题。

### 复盘口令

> 页号换块号，偏移原样抄。

---

# 12. 外存基础概念

## 12.1 磁盘/光盘/磁带分类

- 磁带：顺序存取。
- 磁盘：直接存取。
- 光盘：直接存取。

## 12.2 外存题复盘提醒

- 外存题容易把设备分类、访问方式、存储材料混在一起。
- 遇到机械磁盘题时，通常要区分寻道时间、旋转延迟、传输时间。

### 关联题

- 外存 1、2、3、8：当前 note 中有疑问标记，后续可继续补充。

# 13. 通用错因分类

## 13.1 读题类

典型表现：

- 忽略“至少/至多/不超过/不少于”。
- 没看清问的是“数据容量”还是“总容量”。
- 没看清问的是“地址线”还是“地址引脚”。

关联题：存储器概述 12，主存 19，主存 34，Cache 21。

### 复盘口令

> 算完不选，先回题干。

---

## 13.2 单位类

典型表现：

- B 和 bit 混淆。
- 32B 当成 32bit。
- Offset 位数和数据位数混淆。
- 十六进制 F 的状态数判断错。

关联题：主存 24，Cache 21，Cache 33。

### 复盘口令

> B 转 bit 要乘 8；位数取 log₂；两者不是一回事。

---

## 13.3 题型识别类

典型表现：

# 14. 章节复盘检查清单

## DRAM 检查

- [ ] 我能区分恢复和刷新吗？
- [ ] 我能解释集中/分散/异步刷新差异吗？
- [ ] 我能独立算异步刷新信号间隔吗？
- [ ] 我知道行数只看单块芯片吗？
- [ ] 我能解释 SDRAM 的“同步”是什么意思吗？

## 多模块存储检查

- [ ] 我知道低位交叉为什么适合连续访问吗？
- [ ] 我会用 m ≥ T/r 吗？
- [ ] 我能画时间轴区分首个延迟和稳定节拍吗？
- [ ] 我能区分单体多字和多体交叉吗？

## Cache 检查

- [ ] 我能熟练拆 Tag / Index / Offset 吗？
- [ ] 我知道 Valid、Dirty、替换位什么时候算吗？
- [ ] 我能区分数据容量和总容量吗？
- [ ] 我知道 n 路组相联要比较 n 个 Tag 吗？
- [ ] 我能做数组访问缺失率题吗？

## 虚拟存储检查

- [ ] 我能区分逻辑地址和物理地址吗？
- [ ] 我知道页内偏移和块内偏移为什么相同吗？
- [ ] 我能判断“有效位”到底是 Valid bit 还是地址位数吗？
