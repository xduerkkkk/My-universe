#### 1. 内中断（也叫 异常 / Exception）

**来源：** CPU 执行当前指令时自己搞砸了，或者自己主动发起的。它和外面发生什么事毫无关系。

- **陷阱 (Trap) - 故意的、主动的：**
    
    - **例子：** 系统调用（访管指令 `INT 0x80`，你之前问过的）、程序打断点调试。
        
    - **特点：** 期待发生的，处理完后，PC 指向的是**下一条指令**。
        
- **故障 (Fault) - 无意的、但能救回来：**
    
    - **例子：** 缺页（Page Fault）、除数为 0、TLB 缺失。
        
    - **特点：** 硬件发现有问题，停下来找操作系统帮忙。如果系统把页调进来了，PC 会指向**当前这条出故障的指令**，重新执行一遍！
        
- **终止 (Abort) - 无意的、且救不回来（硬件烂了）：**
    
    - **例子：** CPU 内部 Cache 奇偶校验错、控制器硬件故障。
        
    - **特点：** 直接抛出致命错误，通常强行杀死进程或直接蓝屏重启。
        

#### 2. 外中断（也叫 硬件中断 / Interrupt）

**来源：** 来源于 CPU 外部的设备（I/O 设备、定时器），与 CPU 当前正在执行的指令没有任何关系。异步发生。

- **可屏蔽中断 (INTR - Maskable)：**
    
    - **例子：** 键盘敲击、鼠标移动、网卡收到数据包、**DMA 传完 10000 个字的结束通知**、打印机缺纸。
        
    - **特点：** CPU 可以通过设置 `IF=0`（关中断）来暂时充耳不闻。
        
- **不可屏蔽中断 (NMI - Non-Maskable)：**
    
    - **例子：** 突然断电警告（极其致命！）、主存（外部 RAM）奇偶校验严重错误。
        
    - **特点：** CPU 无论有多忙，哪怕在关中断状态下，也必须立刻强行响应。这就像火警铃声，无论你在干嘛都必须跑。
        

**💡 考场秒杀口诀：**

- 只要看到跟“指令执行”本身相关的（除以 0、越界、缺页、系统调用），全都是**内中断（异常）**。
    
- 只要看到跟“外部设备”和“时间”相关的（鼠标、键盘、磁盘、时钟滴答），全都是**外中断**。
