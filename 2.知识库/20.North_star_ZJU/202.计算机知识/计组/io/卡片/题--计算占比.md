- **外设世界（多久来烦我一次？）：** 外设准备好一次数据需要的时间（设为 $T_{\text{外设}}$）。
    
- **CPU 世界（每次烦我多久？）：** CPU 处理一次中断耗费的时间（设为 $T_{\text{CPU}}$）。
    
- **占比公式：** $\text{占比} = \frac{T_{\text{CPU}}}{T_{\text{外设}}} \times 100\%$

![[王道题-1773149296610.jpeg]]
- **实战解剖第 47 题：**

1. **算 $T_{\text{外设}}$（多久来一次中断？）：**
    
    - 找缓冲器大小：题目说“数据缓冲寄存器为 32 位”。注意换算，32 位 = **4 个字节 (B)**。
        
    - 找传输速率：题目说“传输速率为 $50\text{kB/s}$”。（_💡 408 黄金防坑指南：在通信和传输速率里，k 永远是 1000，不是 1024！_）
        
    - 计算：缓冲器什么时候被填满（从而触发中断）？
        
        $T_{\text{外设}} = \frac{4\text{ B}}{50,000\text{ B/s}} = 0.00008\text{ s} = 80\mu\text{s}$。
        
2. **算 $T_{\text{CPU}}$（处理一次花多久？）：**
    
    - 找中断开销：题目说“每次中断开销为 1000 个时钟周期”。
        
    - 找 CPU 主频：“$1\text{GHz}$”。意味着 1 个时钟周期 = $\frac{1}{10^9}\text{ s} = 1\text{ns}$。
        
    - 计算：$T_{\text{CPU}} = 1000 \times 1\text{ns} = 1000\text{ns} = 1\mu\text{s}$。
        
3. **算占比：**
    
    - $\text{占比} = \frac{1\mu\text{s}}{80\mu\text{s}} = \frac{1}{80} = 0.0125 = \textbf{1.25\%}$。
        
    - **果断选 A！**





![[王道题-1773147933244.jpeg]]
    **障眼法：** “最长延迟时间为 50ns”。这个条件是什么意思？意思是外设发请求后，CPU 最晚可以在 50ns 内磨蹭着去响应。**但这 50ns 里 CPU 是在干自己的本职工作，并没有在干 I/O 的活！** 所以算 I/O 占比时，这个 50ns 纯属放屁，直接划掉！
    周期总时间 = $400ns$，占比 = $\frac{100}{400} \times 100\% = 25\%$
