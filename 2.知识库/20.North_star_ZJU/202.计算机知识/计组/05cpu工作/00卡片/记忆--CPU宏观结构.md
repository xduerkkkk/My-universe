完整的 CPU 宏观结构 = **控制器 (Control Unit)** + **运算器/数据通路 (Datapath)**。

为了让你在脑海中建立完整的 3D 模型，我把 CPU 拆解成这两大阵营：

#### 1. 控制器阵营（大脑区 —— 负责发号施令）

这里的部件不直接处理数据，只管“指挥”。

- **PC (程序计数器):** 存下一条要去主存取的指令地址。（指路明灯）
    
- **IR (指令寄存器):** 存刚取回来的机器指令。（拿着圣旨）
    
- **指令译码器 (ID):** 把 IR 里的操作码翻译出来。（翻译官）
    
- **操作控制器 (OC):** 就是咱们前面死磕的硬布线或微程序（CM/CMAR/CMDR 等）。它根据译码结果和时钟节拍，向全 CPU 发出具体的微操作电信号。（总司令部）
    

#### 2. 运算器/数据通路阵营（干活区 —— 负责处理数据）

这里是真正做加减乘除和存放临时数据的地方。

- **ALU (算术逻辑单元):** CPU 唯一真正能做算术运算和逻辑判断的核心电路。
    
- **通用寄存器组 (GPRs):** 程序员能直接访问的“工作台”，比如 $R_0 \sim R_{31}$，有些机器里还有个极其常用的特殊通用寄存器叫 **ACC (累加器)**。它们用来存操作数和运算结果，速度极快。
    
- **PSW (程序状态字 / 标志寄存器):** 紧挨着 ALU，用来存放 ALU 刚算完产生的一些特征标志（比如运算结果是否为零 $ZF$、是否溢出 $OF$、是否有进位 $CF$）。咱们上一问提到的条件转移指令，就是根据它来决定分支跳不跳的。
    

#### 3. 边界联络站（接口区）

这两个寄存器处于 CPU 和主存的交界处（在教材中，它们有时被归入控制器，有时被归入运算器，你理解它们的作用即可）。

- **MAR (存储器地址寄存器):** 存放 CPU 要访问的主存单元的地址。
    
- **MDR (存储器数据寄存器):** 存放 CPU 从主存读回来的数据，或者准备写进主存的数据。
    

**总结一下运转流程：**

控制器阵营的 **PC** 给出一个地址送给 **MAR**，主存把指令吐给 **MDR**，接着送给 **IR**。控制器阵营的 **OC** 经过译码发出一堆电信号。运算器阵营的 **ALU** 收到信号，从**通用寄存器**里拿两个数出来相加，把状态记在 **PSW** 里，最后把结果写回寄存器或者通过 **MDR** 写回主存。
