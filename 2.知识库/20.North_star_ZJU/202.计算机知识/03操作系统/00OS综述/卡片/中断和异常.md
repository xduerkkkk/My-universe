中断和异常是用户态转向内核态的唯一途径

实际上在此语境中，中断指外中断，异常指内中断。所谓“内外”，是在说指令之内外

- 外中断：可屏蔽中断，不可屏蔽中断，都是硬件请求或故障。是**指令之外**出问题。
  *如不可屏蔽中断是 CPU 核心**外部**的硬件通过专门的 NMI 引脚向 CPU 报错。比如：主板供电电压突然不稳、掉电警告、或者是机箱上的硬件复位按钮被按下了。*
- 内中断：故障，自陷，终止。是指令出现非法操作（故障），指令设计了一个调用（自陷），执行指令流时CPU 核心内部控制单元、ALU、内部级联错误终止（终止）
如何区分不可屏蔽中断和终止


| **维度**      | **不可屏蔽中断 (NMI)**            | **终止 (Abort)**                      |
| ----------- | --------------------------- | ----------------------------------- |
| **分类归属**    | **外中断**（Hardware Interrupt） | **内中断**（Exception）                  |
| **与当前指令关系** | **无关（异步）**。指令没犯错，外部硬件强行插队。  | **有关（同步/内部死锁）**。执行当前指令流时内部逻辑崩溃。     |
| **发生位置**    | CPU 核心外部（主板、总线、电源）          | CPU 核心内部（控制单元、ALU、内部级联错误）           |
| **典型案例**    | 内存条物理损坏（ECC 校验多位错）、电源掉电警告。  | 双重故障（Double Fault）、机器检查架构致命错误（MCE）。 |
| **结局**      | 视情况而定。可能打印错误后继续运行，也可能重启。    | **必死无疑**。程序直接被杀，或操作系统直接蓝屏挂起。        |

异常是一有问题就处理，执行指令是会检测到。
中断，是 CPU 在指令周期结束后，自行检测一下。
