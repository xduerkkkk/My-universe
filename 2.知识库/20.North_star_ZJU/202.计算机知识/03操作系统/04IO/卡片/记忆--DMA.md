四类寄存器

|寄存器|全称|作用|
|---|---|---|
|**MAR**|Memory Address Register|存放当前要访问的内存地址|
|**DC**|Data Counter（字节计数器）|存放剩余要传送的字节数|
|**DR**|Data Register|暂存每次传送的一个数据字|
|**CR**|Command Register|存放 CPU 下达的控制命令（读/写、设备号等）|
1. CPU → CR：写入命令字（"内存→磁盘"方向，设备号）

2. CPU → MAR：写入起始地址 1000

3. CPU → DC：写入传送字节数 512

然后 CPU 就去执行别的程序了，**总线交给 DMA**。

每传送一个字节，DMA 做如下操作：

┌─────────────────────────────────────────────────┐
│ 1. DMA 向总线发出 MAR 中的地址（当前=1000）       │
│    ──→ 内存根据地址把数据放到数据总线上            │
│                                                   │
│ 2. 数据总线上的数据 → DR（暂存一个字节）           │
│                                                   │
│ 3. DR 中的数据 → 送往磁盘控制器                   │
│                                                   │
│ 4. MAR ← MAR + 1  （地址自动+1，变成 1001）        │
│                                                   │
│ 5. DC  ← DC  - 1  （计数自动-1，变成 511）         │
│                                                   │
│ 6. 判断 DC == 0 ？                                │
│    ├─ 否 → 回到步骤 1，继续传下一个字节             │
│    └─ 是 → 传送结束，向 CPU 发中断                   │
└─────────────────────────────────────────────────┘

DMA 发出中断 → CPU 响应中断 → 执行中断服务程序：

- 检查传送是否出错
- 决定是否启动下一次 DMA 传送
