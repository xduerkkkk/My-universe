### 【综合自拟题】

**背景说明**：
某系统采用**分段存储管理方式**。程序员编写了一个包含两个源文件 `main.c` 和 `math.c` 的程序：
* `main.c` 包含主函数 `main()` 和未初始化的全局变量；
* `math.c` 包含辅助函数 `add()` 和已初始化的全局常量表。

经过**编译（Compile）**后，生成了两个独立的目标模块 `main.o` 和 `math.o`：
* `main.o` 内部的代码长度为 `0x0120` 字节；
* `math.o` 内部的代码长度为 `0x00E0` 字节。

**链接与装入配置**：
1. **静态链接阶段**：链接程序（Linker）将两个目标模块的代码合并为一个**代码段（Code Segment）**，并将全局变量与常量合并为一个**数据段（Data Segment）**。
   * 代码段分配为 **段号 0**，内部布局为：`main.o` 的代码放在起始处（偏移量 `0x0000` 开始），`math.o` 的代码紧随其后。
   * 数据段分配为 **段号 1**，总长度为 `0x0400` 字节。
   * 栈段分配为 **段号 2**，总长度为 `0x1000` 字节。
2. **进程加载与运行**：操作系统将该程序加载入内存，并为该进程建立了如下**段表（Segment Table）**：

| 段号 (Segment No.) | 段长 (Limit / Length) | 基址 (Base Address) | 存取权限 |
| :---: | :---: | :---: | :---: |
| 0 (代码段) | `0x0200` 字节 | `0x0004 0000` | 只读 / 可执行 |
| 1 (数据段) | `0x0400` 字节 | `0x0008 0000` | 读写 |
| 2 (栈段) | `0x1000` 字节 | `0x000A 0000` | 读写 |

**请回答下列问题**：
1. **【编译与链接阶段】** 在 `math.o` 模块中，函数 `add()` 相对于 `math.o` 模块开头的局部偏移量为 `0x0030`。
   * （1）经静态链接后，`add()` 在该进程**逻辑地址空间中的段号和段内偏移量**分别是多少？
   * （2）`main()` 中有一条调用 `add()` 的转移指令，在链接阶段链接器必须完成什么操作？
2. **【内存管理与 MMU 翻译阶段】** 当 CPU 执行指令访问逻辑地址 $A = \text{0x0000 0150}$（段号 $0$，段内偏移量 `0x0150`）时：
   * （1）MMU 是如何进行越界检查的？请写出比较不等式及判定结果。
   * （2）若未越界，该逻辑地址对应的**物理地址**是多少？
3. **【异常判断】** 若 CPU 试图写入逻辑地址 $B = \text{0x0000 0200}$（段号 $0$，段内偏移量 `0x0200`），将触发什么硬件异常？为什么？

### 【题目解析与知识点串联】

#### 1. 编译与链接阶段解析

* **（1）段内偏移量重定位计算**：
  * **机制**：编译阶段每个目标模块（`.o`）的地址都是从 `0x0000` 开始的相对逻辑地址。链接阶段（Linker）将多个模块的同类节（Section）进行合并与重定位。
  * **计算**：
    * 代码段（段号 0）的前半部分是 `main.o`（占用 `0x0000` ~ `0x011F`，共 `0x0120` 字节）。
    * `math.o` 拼接在 `0x0120` 之后。
    * `add()` 原本在 `math.o` 中的相对偏移为 `0x0030`。
    * 链接后 `add()` 的段内偏移量 $W = \text{0x0120} + \text{0x0030} = \text{0x0150}$。
    * 因此，`add()` 的逻辑地址为：**段号 $S = 0$，段内偏移量 $W = \text{0x0150}$**。

* **（2）链接器的重定位（Relocation）操作**：
  * **机制**：在编译 `main.c` 时，编译器不知道 `add()` 的确切位置，只能在调用处填入占位符（并在目标文件的重定位表中记录此项）。
  * **答案**：链接器在合并各段后，根据重新计算出的 `add()` 逻辑地址（`0x0150`），修正 `main()` 中调用指令的目标跳转地址（即**地址重定位 / 符号解析**）。

---

#### 2. 内存管理与 MMU 物理地址翻译解析

CPU 给出逻辑地址 $(S=0, W=\text{0x0150})$，段表基址寄存器提供段表始址。

```text
逻辑地址: [ 段号 S = 0 | 段内偏移量 W = 0x0150 ]
              │                     │
              ▼                     ▼
          查段表(S=0) ──> [ 段长 Limit = 0x0200, 基址 Base = 0x0004 0000 ]
                               │
            ┌──────────────────┴──────────────────┐
            ▼                                     ▼
     【越界检查】                              【地址相加】
  W (0x0150) < Limit (0x0200) ?          物理地址 = Base + W
  满足 (未越界)                           = 0x0004 0000 + 0x0150
                                         = 0x0004 0150
```

* **（1）越界检查步骤与不等式**：
  * **规则**：硬件 MMU 提取逻辑地址中的段内偏移量 $W$，与段表中的段长 $\text{Limit}$ 进行比较。
  * **严格边界条件**：必须满足 $W < \text{Limit}$。若 $W \ge \text{Limit}$ 则触发越界中断。
  * **判定**：当前 $W = \text{0x0150}$，段长 $\text{Limit} = \text{0x0200}$。因为 $\text{0x0150} < \text{0x0200}$，**检查通过，未越界**。

* **（2）物理地址计算**：
  * **公式**：$$\text{物理地址} = \text{段基址（Base）} + \text{段内偏移量（}W\text{）}$$
  * **计算**：$$\text{物理地址} = \text{0x0004 0000} + \text{0x0150} = \text{0x0004 0150}$$。

---

#### 3. 异常判断（边界与保护机制）

针对逻辑地址 $B (S=0, W=\text{0x0200})$，试图执行“写入”操作：

1. **越界异常（Segmentation Fault / 越界中断）**：
   * 偏移量 $W = \text{0x0200}$，而段长 $\text{Limit} = \text{0x0200}$（有效偏移范围是 `0x0000` $\sim$ `0x01FF`）。
   * 满足 $W \ge \text{Limit}$ 条件，**首先触发段越界中断**。
2. **存取控制异常（保护违例）**：
   * 即使未越界，段 0 的存取权限为“只读/可执行”，CPU 试图执行“写”操作，也会触发**段保护违例中断（非法访问异常）**。

### 【408 核心考点链条总结】

1. **编译阶段**：生成包含相对地址（从 0 编址）和重定位表的目标模块（`.o`）。
2. **链接阶段**：将多个 `.o` 中的代码、数据分门别类合并成逻辑段，完成**符号解析与重定位**，形成程序的**二维逻辑地址空间 $(S, W)$**。
3. **装入阶段**：OS 为进程分配离散的物理内存区域，在**段表**中登记每个段的“物理首地址（Base）”和“段大小（Limit）”。
4. **运行阶段**：CPU 执行指令 $\to$ MMU 硬件查段表 $\to$ **严格校验 $W < \text{Limit}$** $\to$ **物理地址 = $\text{Base} + W$**。
