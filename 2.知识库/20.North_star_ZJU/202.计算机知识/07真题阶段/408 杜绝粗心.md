## CO
- **CF 优先用“无符号比大小”，去转换成二进制，单纯看相减/相加是否借位/进位，不要去推加法器**（18-19 算的时候，把两个数都取反了....）
- Cache 的数据位里，偏移是 5 位，就放 2^5bit ？错! 注意是什么编址。cache 是把主存切实的数据搬过来，如果是字节编址，那就是 2^5B 
- Cache 映射，<font color="#ff0000">不要把主存地址</font>除以块数/组数算行/组，要先算出主存地址属于第几块主存块，那这个块号映射！
- 按字节编址，+1 个 int 元素，忘了乘 4！!! 直接给地址加了 1!
- **字段直接编码部分**：每个互斥类一个字段，字段里除了表示该类的各个微命令，还要留一个编码表示「本字段不发出任何微命令」
- 每次访存读或写，注意单位！看看取的是啥，是字？是什么类型数据？我们去的是首地址，那剩下的数据在剩下的地址怎么排列？一环扣一环！




遇到描述硬件信号流程的选项，不要顺着语流一带而过，必须在心里快速过一遍：
- **主语（源头）**：外部设备
- **谓语（动作）**：发
- **宾语（信号）**：中断结束信号

 - 题干关键词与草稿强制“首字连线”（25 年最后一题）
	题目往往问得很长：“作业区子网、管理区子网和生活区子网的子网地址分别是什么”。
	
	- 很多同学在草稿纸上推导时是按**逻辑顺序**推的（本题逻辑顺序：先由主机 H 推出**管理区**，再切大块算出**生活区**，最后剩下的是**作业区**）。
	    
	- 推完之后你脑子里是“管、生、作”，但卷面问的是“**作、管、生**”！你直接按推导顺序抄上去，就彻底串行了。
	
	
	拿到这种多个子网、多个参数的大题，**在草稿纸算出结果之前，先在试卷/答题卡上把带有全称的骨架空出来**：
	
	
	```
	作业区子网：__________________
	管理区子网：__________________
	生活区子网：__________________
	```
	
	或者严格标明序号：
	
	
	```
	(3) 
	1) 作业区子网：
	2) 管理区子网：
	3) 生活区子网：
	```
	
	- **绝对不要在答题纸上一行一行顺着现想现写！**
	- 先把坑按照试卷提问的顺序挖好，然后草稿纸上算出一个，往对应的坑里填一个。填的时候只认中文名字（“生活区填到生活区那一行”），彻底切断大脑的“推导惯性”。
