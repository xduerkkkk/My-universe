1. 有符号数比较指令（带符号整数，如 C 语言的 `int`）
用 **G (Greater)**、**L (Less)**、**E (Equal)** 组合命名：

| 助记符 | 英文全称 | 跳转条件（高级语言含义） | 底层硬件成立条件（标志位布尔逻辑） |
| :--- | :--- | :--- | :--- |
| **`je` / `jz`** | Jump if Equal / Zero | 相等 / 为零 | $\text{ZF} = 1$ |
| **`jne` / `jnz`** | Jump if Not Equal | 不相等 / 非零 | $\text{ZF} = 0$ |
| **`jg` / `jnle`** | Jump if Greater | 大于（$>$） | $\text{ZF} = 0 \text{ 且 } \mathbf{SF = OF}$ |
| **`jge` / `jnl`** | Jump if Greater or Equal | 大于等于（$\ge$） | $\mathbf{SF = OF}$ |
| **`jl` / `jnge`** | Jump if Less | 小于（$<$） | $\mathbf{SF \neq OF}$ |
| **`jle` / `jng`** | Jump if Less or Equal | 小于等于（$\le$） | $\text{ZF} = 1 \text{ 或 } \mathbf{SF \neq OF}$ |

> **关键机制硬核拆解（SF 与 OF 的关系）**：
> 做减法 $\text{dest} - \text{src}$ 时：
> * 若没有发生溢出（$\text{OF} = 0$），结果为负（$\text{SF}=1$）代表确实小于，$\text{SF} \neq \text{OF}$ 成立。
> * 若发生正溢出（两负数相减得到负极大超界变为正，$\text{OF} = 1$ 且 $\text{SF} = 0$），本质仍然是小于，$\text{SF} \neq \text{OF}$ 依然成立。
> * **结论**：只要 $\mathbf{SF \neq OF}$，有符号数的大小关系就必定是**小于**。这是 408 计组考题中最容易涉及硬件逻辑设计的考点。


无符号数比较指令（无符号整数，如 C 语言的 `unsigned int`、地址指针）
用 **A (Above)**、**B (Below)**、**E (Equal)** 组合命名：

| 助记符 | 英文全称 | 跳转条件（高级语言含义） | 底层硬件成立条件（标志位布尔逻辑） |
| :--- | :--- | :--- | :--- |
| **`ja` / `jnbe`** | Jump if Above | 高于 / 大于（$>$） | $\text{CF} = 0 \text{ 且 } \text{ZF} = 0$ |
| **`jae` / `jnb`** | Jump if Above or Equal | 高于等于（$\ge$） | $\text{CF} = 0$（无借位） |
| **`jb` / `jnae`** | Jump if Below | 低于 / 小于（$<$） | $\text{CF} = 1$（有借位） |
| **`jbe` / `jna`** | Jump if Below or Equal | 低于等于（$\le$） | $\text{CF} = 1 \text{ 或 } \text{ZF} = 1$ |

> **辨析**：无符号数比较只看进位/借位标志 **CF** 和零标志 **ZF**，绝对不看 SF 和 OF。

发送方：DIFS → RTS → SIFS → CTS → SIFS → 数据帧 → SIFS → ACK

是网卡编码调制传输介质所需的物理信号，接收端通过以太网帧头部的 8 字节前导码（7 字节同步码 10101010... + 1 字节帧开始定界符 SFD 10101011），锁定发送方的时钟频率与相位，实现**位同步**。，


数据帧，指的是首部+载荷+校验序列，不包括前导码。载荷最大是 1500 字节。
这个载荷，减去IP 首部 20B，1480B 是最大的报文段长度，报文段减去TCP 首部 20B，1460B 是最大的报文长度，最大的载荷，也就是MSS！

| 触发条件                 | CSMA/CD 的动作                                      | CSMA/CA 的动作                            |
| -------------------- | ------------------------------------------------ | -------------------------------------- |
| **原本就在空闲**（节点刚刚产生数据） | 等待 96 比特时间（IFG），**立即发**。                         | 侦听并连续空闲 **DIFS** 时间后，**立即发**（此时不需要退避）。 |
| **信道刚从“忙碌”变为空闲**     | 等待 96 比特时间（IFG），以概率 1 **立即发**（1-坚持，发生碰撞后再二进制退避）。 | **强制进入随机退避阶段**（不能马上发）。                 |
**退避窗口（CW, Contention Window）**：
   - 节点随机从区间 $[0, \text{CW}-1]$ 中选取一个整数 $r$，退避时间 $= r \times \text{SlotTime}$（时隙时间）。
   - 初始时 $\text{CW} = \text{CW}_{\min}$（例如 16 或 32）。
   - 如果发送失败（未在超时时间内收到 ACK），认为发生冲突，CW 翻倍（$\text{CW} = 2 \times \text{CW}$），直到上限 $\text{CW}_{\max}$（通常为 1024）。
   - 发送成功并收到 ACK 后，CW 立即重置为 $\text{CW}_{\min}$。
