# 静态链表

![[_attachments/image/DS冷门-1789982603440.jpeg]]



| 数据结构：静态链表                                | 操作系统：文件分配表（FAT）                |
| ---------------------------------------- | ------------------------------ |
| **数组下标<br><br>```<br>ii<br>```<br><br>** | **物理磁盘块号（Block Number）**       |
| **结点数据域 data**                           | **物理磁盘块里存储的实际文件内容**            |
| **游标 link**                              | **FAT 表项中记录的“下一块物理块号”**        |
| **空闲链表（备用链表）**                           | **FAT 中标记为“空闲”的可用磁盘块**         |
| **链尾标记 link = -1**                       | **文件结束标志（如 0xFFFFFFFF / EOF）** |

在操作系统里，采用隐式链接时，每个物理盘块的末尾要留出几个字节存放下一个盘块的物理指针；而 **FAT 则是把所有物理块的“指针域”单独抽出来，集中放在一个常驻内存的数组（即 FAT 表）里**。

这个 FAT 表，在数据结构上的本质就是一个**不带数据域、只保留了 link 字段的静态链表数组**。查找文件的过程，就是在 FAT 表里顺着数组下标不断读出下一个下标的过程。
