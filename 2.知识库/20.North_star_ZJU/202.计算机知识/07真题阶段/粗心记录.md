有时 (R) 是 R 间接寻址，有时 (R) 是 R 里面的值

| 场景           | 写法           | 实际含义              | 对应 C 语言语法   | 是否访存？       |
| ------------ | ------------ | ----------------- | ----------- | ----------- |
| **汇编指令代码**   | ADD R1, R2   | 取 R1 寄存器里的值       | x（直接用变量）    | **否**       |
| **汇编指令代码**   | ADD (R1), R2 | 把 R1 的值当指针，取内存数据  | *ptr（指针解引用） | **是**（访存1次） |
| **微操作/语义解释** | (R1) -> R2   | 取 R1 的值赋给 R2 寄存器  | R2 = R1     | **否**       |
| **微操作/语义解释** | ((R1)) -> R2 | 以 R1 为地址读内存，赋给 R2 | R2 = *R1    | **是**（访存1次） |
