# Cache 代码缺失率｜四步流程训练

沿用你这次练的做法：**先列硬件常数，再把代码翻译成块号；绕一圈才回来的，就盯住关键块，看有没有同组块插队。** 这份不按知识点重讲，7 道题换了数据，但草稿都按同一个顺序写。

来源：[[2.知识库/20.North_star_ZJU/202.计算机知识/07真题阶段/薄弱点/03计组cache缺失率|原笔记：四步法、六关和 score 原题]] · [[2.知识库/20.North_star_ZJU/202.计算机知识/07真题阶段/薄弱点/03计组Cache代码缺失率-分类渐进训练|分类渐进训练：T03、T05、T07、T10、T14–T18]]。

**下面各题统一约定：** 按字节编址，`int=4B`，数组按行优先存放。每个小问独立从空数据 Cache 开始；只统计题中数组读写，循环变量和 `sum` 在寄存器中；读缺失装整块，组相联按 LRU。不考虑预取和编译优化。

## 每题照抄这四行

```text
① 硬件：C=__，B=2^__ B，L=C/B=__，E=__ 路，S=L/E=__；S×E×B=__。
② 访存：每轮 R/W=__，题目要的分母 N=__；首址偏移=__，地址 → 块号 q=⌊地址/B⌋。
③ 状态：q mod S=__；下次用它之前，同组有谁来过？首轮/换段末状态=__。
④ 收口：M=__；检查 0≤M≤N；问次数、缺失率 M/N，还是命中率 1−M/N？
```

- **① 硬件。** `C` 只取数据区容量；直接映射就是 `E=1`。同组地址步长是 `S×B`。问位宽才继续写：块内偏移 `log₂B`，组号 `log₂S`，Tag 是地址总位宽减去这两项。
- **② 访存。** `a[i]+=1` 写成 `R(a[i]) → W(a[i])`；`sum+=a[i]` 若 `sum` 在寄存器中，只记一次数组读。二维数组用 `A+(r×列数+c)×元素字节数`，结构体用 `A+k×sizeof+字段偏移`。连续访问一段字节才用 `末块−首块+1`；跳步、只取某些字段时，不能把夹在中间但没访问的块也数进去。
- **③ 状态。** 同块连续用，且第一次已装入，就不必逐个模拟。要绕一圈才回访，就从上次访问该块算起，数**同组、不同的其他块**；在标准 LRU、这些访问都会参与缓存替换或刷新顺序的情况下，达到 `E` 个，原块就留不住。旧笔记的 `K` 把自己也数进去，所以是 `K>E`。先查其他组是否长得一样，再决定能否只看一组；**首轮、序列变化的交界轮**单推，确认轮末回到相同状态再乘。写缺失不分配时不插入该块；LRU 命中也要挪到最新。
- **③ 的按列速算。** 若行长正好是 `d` 个块，固定一列时，第 `r` 行的块号是 `q₀+r×d`。要找哪些行和第 0 行同组，就看 `r×d` 是不是 `S` 的倍数（把 `d/S` 约分，行号是约分后分母的倍数即可）。这里说的是首行块所在的组，不一定是真正的组 0。
- **④ 收口。** 空 Cache 起步，若统计全部访问，缺失数至少是实际访问的不同主存块数；它只是下限。如果只问读或只问写，分子、分母都要筛到同一种访问。直写产生的主存流量不是额外一次 CPU 的 Cache 访问。

> [!tip] 怎么练
> 第一次做 **01 → 02 → 03 → 07**，先把同一套起手和换段动作做顺；再拿 **04–06** 验证换了访问顺序也会做。答案都折叠。对答案时先找**哪一行开始错**，从那一行重做；只写对结果、但说不出“块什么时候被换掉”，不算过。

### 用做过的 score 原题走一遍

> [!faq]- 已做过的热身｜先默写四行，再对照
> **① 硬件**：`128B/32B=4` 行，直接映射 `S=4、E=1`，校验 `4×1×32=128B`。
>
> **② 访存**：`score[6][8]` 按列读，`N=48`。首址 `0x50=2×32+16`，一行 32B，故 `c=0…3` 的每列访问真实块号 `2,3,4,5,6,7`；`c=4…7` 换成 `3,4,5,6,7,8`（列号从 0 开始）。
>
> **③ 状态**：首列缺 6 次，轮末按 Cache 行 `0,1,2,3` 写成 `[4,5,6,7]`；前半段后续列每列缺 4 次，轮末不变。到 `c=4`，块 3 一上来就挤走行 3 的块 7，虽然 **7 在列开始时还在，轮到它时已经没了**；块 8 最后再挤走块 4。交界列是 `M H H H M M`，缺 3 次。轮末变成 `[8,5,6,7]`；新序列后面每列缺 4 次。
>
> **④ 收口**：`M=6+3×4+3+3×4=33`，缺失率 `33/48=11/16`。每次卡住先问自己：**我写的是轮初有哪些块，还是这一笔来之前还剩哪些块？**

## 01｜起手：位宽、错位、步长

32 位地址；Cache 数据区 `4KiB`，块 `32B`，2 路组相联。`int a[64]` 首址 `0x0010000C`。

```c
// A
for (int k=0; k<64; k++)    a[k] += 1;
// B
for (int k=0; k<64; k+=10)  a[k] += 1;
```

求 Tag、组号、块内偏移各占几位；A 的访问次数、缺失次数、**命中率**；B 的访问次数、缺失次数、**缺失率**。分别写出怎么数到实际访问的那些块。

> [!faq]- 01 核对｜最后一块不能靠“非对齐就加一”猜
> **① 硬件**：`C=2¹²B，B=2⁵B，L=2⁷，E=2，S=2⁶`；`64×2×32=4096`。Tag / 组号 / 块内偏移为 **21 / 6 / 5 位**。
>
> **② 访存**：A 是 `64×2=128` 次，首址偏移 12B，连续 256B，最后一个字节距首块起点 `12+256−1=267B`，所以访问相对块 `0…8`。B 的 `k=0,10,…,60`，共 7 次循环、14 次访存；距首块起点的地址是 `12+4k`，除以 32 得相对块 `0,1,2,4,5,6,7`。
>
> **③ 状态**：读缺失先装块，写紧跟着命中。A 同块连续用完才走，不再回头；B 每个被访问的块只碰到一个元素。故 A 缺 9 次，B 缺 7 次。
>
> **④ 收口**：A **命中率 `119/128`**；B **缺失率 `7/14=1/2`**。两问分母都包括写。

## 02｜同样全缺，先说是没装进来，还是装了又被挤掉

Cache 数据区 `128B`、块 `16B`、2 路。`int m[n][16]` 首址 `0x0`：

```c
for (int c=0; c<4; c++)
    for (int r=0; r<n; r++) m[r][c] = 0;
```

分别求缺失次数：A `n=2`、写分配；B `n=3`、写分配；C `n=2`、不写分配。三问都留下 `c=0` 的轮末状态。

> [!faq]- 02 核对｜同组槽位够不够，要在“会装块”的前提下判断
> **① 硬件**：`B=2⁴B，L=8，E=2，S=4`；同组步长 `4×16=64B`。
>
> **② 访存**：每笔纯写，`N=4n`。行长 `16×4=64B`，前 4 列在每行的首块；每列的块序列是 `0,4` 或 `0,4,8`，都去组 0。
>
> **③ 状态**：A 首列缺 2 次，轮末 `[0,4]`（左旧右新），之后全中。B 首列缺 3 次，轮末 `[4,8]`；下一列从 0 开始，依次挤走 4、8、0，轮末仍 `[4,8]`，每列全缺。C 写缺失不装块，首列后仍是 `[]`，往后也没有读把块装进来。
>
> **④ 收口**：A **2**，B **12**，C **8** 次缺失。B 是装了又被换掉；C 从没装进去。

## 03｜盯一个块之前，先看这一组能不能代表其他组

Cache 数据区 `128B`、块 `16B`、2 路。`int a[9][4]` 首址 `0x0`，比较两种读法：

```c
// A：按列
for (int c=0; c<4; c++) for (int r=0; r<9; r++) sum += a[r][c];
// B：按行
for (int r=0; r<9; r++) for (int c=0; c<4; c++) sum += a[r][c];
```

求两者缺失率。A 必须先写各组分到几个块，再决定哪些缺失能乘、哪些不能。

> [!faq]- 03 核对｜组 0 的规律只适用于组 0
> **① 硬件**：`B=2⁴B，4×2×16=128B`，4 组，每组 2 路。
>
> **② 访存**：两种 `N=9×4=36`。一行 `4×4=16B`，恰好对齐一块，行 `r` 就是块 `r`。A 每列访问 `0…8`；B 是把每一块连读 4 次再走。
>
> **③ 状态**：A 每列各组顺序分别是 `0,4,8 ｜ 1,5 ｜ 2,6 ｜ 3,7`。首列缺 9 次；组 0 轮末 `[4,8]`，之后每列组 0 仍缺 3 次；其余各组正好够放，首列后全中。B 一块读完才去下一块，只缺 9 次。
>
> **④ 收口**：A `(9+3×3)/36=1/2`；B `9/36=1/4`。想拿组 0 推全题时，先写其他三组都是 `K=2`，不是 `K=3`。

## 04｜第二遍反向：同样的块，不同的回访顺序

Cache 数据区 `64B`、块 `8B`、2 路。`int a[22]` 首址 `0x0`。两种方案都是第一遍 `i=0…21`，逐元素执行 `a[i]+=3`；第二遍执行同一句，A 仍从 `0` 到 `21`，B 改从 `21` 倒到 `0`。两遍之间不清 Cache。

分别求两方案的**全部数组访问缺失率**。草稿上至少留下组 0 第一遍结束时的 LRU 顺序，再推两种第二遍。

> [!faq]- 04 核对｜只数 K 不够，还得看这次是谁先被用到
> **① 硬件**：`B=2³B，L=8，E=2，S=4`。
>
> **② 访存**：每个元素一读一写，`N=2×22×2=88`。每块 2 个 int；第一遍块顺序 `0…10`，块内连续用完，每遍的写都紧跟对应读。
>
> **③ 状态**：第一遍缺 11 次，组 0 访问了 `0,4,8`，留下 `[4,8]`。A 第二遍还是 `0,4,8`，组 0 是 `MMM`；组 1、2 各自也有 3 个块，情况相同；组 3 只有 `3,7`，全中。第二遍缺 9 次。B 组 0 变成 `8,4,0`：`8` 命中后仍 `[4,8]`，`4` 命中后变 `[8,4]`，`0` 最后才缺失，换掉 8。组 1、2 同样各缺 1 次，组 3 全中，第二遍共缺 3 次。
>
> **④ 收口**：A **`20/88=5/22`**；B **`14/88=7/44`**。不能因为两遍的块集合一样，就把同向的抖动直接套给反向。

## 05｜跨数组：把三次访问画成一串，再按组拆开

Cache 数据区 `128B`、块 `16B`，采用写分配。`int a[8], b[8], c[8]` 的首址分别为 `0x00, 0x80, 0x110`。每轮明确按**先读 a、再读 b、最后写 c**执行 `c[i]=a[i]+b[i]`，`i=0…7`。

求缺失次数：A 直接映射；B 2 路组相联；C 在 B 的基础上仅把 `c` 首址改成 `0x100`。至少写出 `i=0` 和 `i=4` 两处的“块号 → 组号”。

> [!faq]- 05 核对｜不能把三数组默认看成同组
> **① 硬件**：`B=2⁴B，L=8`。A 有 8 组 1 路；B、C 有 4 组 2 路。
>
> **② 访存**：`N=8×3=24`。每 4 个元素换一次块。A、B 前一段块序列重复 `0,8,17`，后一段重复 `1,9,18`；C 将这两段的第三块分别改为 16、17。
>
> **③ 状态**：A 前段组号 `0,0,1`，后段 `1,1,2`。每段 a 和 b 次次互踢，c 只在段首缺一次；前段留下的 c 块到后段已经不用了。B 两段组号也分别是 `0,0,1` 和 `1,1,2`，但 a、b 能在同组共存；后一段的 a、b 会把上一段组 1 的旧 c 块挤走，但旧块不再访问。C 两段组号变成 `0,0,0` 与 `1,1,1`，每段都是三个块轮流抢两路，循环次次缺。
>
> **④ 收口**：A `2×(4×2+1)=` **18**；B `2×3=` **6**；C **24** 次缺失。不要把“每轮三次访问”直接当成“同组有三个块”。

## 06｜结构体：先写字段地址，再谈循环合并

Cache 数据区 `128B`、块 `16B`、2 路。数组 `p[12]` 首址 `0x0`，类型是 `struct Node { int x, y, pad[2]; }`，按所示顺序紧排，没有额外填充。

```c
// A：分开，写分配
for (int k=0; k<12; k++) p[k].x = 1;
for (int k=0; k<12; k++) sum += p[k].y;
// B：合并，写分配
for (int k=0; k<12; k++) {
    p[k].x = 1;
    sum += p[k].y;
}
```

求 A、B 的数据 Cache 缺失次数；若 B 改为不写分配，缺失次数又是多少？

> [!faq]- 06 核对｜能不能复用，取决于下一次访问是什么时候
> **① 硬件**：`B=2⁴B，L=8，E=2，S=4`。
>
> **② 访存**：结构体 `sizeof=16B`，`x` 地址 `16k`、`y` 地址 `16k+4`，都在块 `k`；`pad` 没访问。三问均 `N=12` 次写 `+12` 次读 `=24`。
>
> **③ 状态**：A 第一遍写分配缺 12 次；以组 0 为例，写 `0,4,8` 后留下 `[4,8]`，第二遍同序读这三个块全缺；其余组同样，第二遍再缺 12 次。B 每次写分配把块带进来，紧接着读 y 命中。B 改不写分配后，每个块的第一笔写缺失但不调块，接着读 y 仍缺失，由读装入；用完这个块就不再回头。
>
> **④ 收口**：A **24**，B **12**，B 不写分配 **24** 次缺失。合并改变的是“何时访问下一个字段”，不是访问总数。

## 07｜闭卷复测：换段列不能按稳定列算

`int a[5][4]` 首址 `0x18`。Cache 数据区 `64B`，块 `16B`。先算 A 直接映射，再算 B 2 路组相联。

```c
for (int c=0; c<4; c++)
    for (int r=0; r<5; r++) sum += a[r][c];
```

对两种 Cache 分别求每列缺失次数和总缺失率。不看样板，自己写四行；**交界列逐笔写 H/M，并留下轮末状态**。

> [!faq]- 07 核对｜从上一列的状态接着算，不清空，也不照搬上一列
> **① 硬件**：`B=2⁴B，L=4`。A `S=4、E=1`，B `S=2、E=2`。
>
> **② 访存**：`N=5×4=20`。行长 `16B`，`0x18=1×16+8`。`c=0,1` 每列块序列 `1,2,3,4,5`；`c=2,3` 变成 `2,3,4,5,6`。
>
> **③ 状态（A）**：`c=0` 缺 5 次；`c=1` 只有块 1、5 抢行 1，缺 2 次。`c=1` 结束按行号 `0…3` 是 `[4,5,2,3]`。`c=2` 逐笔：2→H、3→H、4→H、5→H、6→M（换掉 2），轮末 `[4,5,6,3]`。`c=3` 块 2、6 都去行 2，互相顶掉，缺 2 次。
>
> **③ 状态（B）**：每组写左旧右新。`c=0` 缺 5 次；`c=1` 奇数组的 `1,3,5` 都缺，偶数组 `2,4` 都中，缺 3 次。`c=1` 结束组 0 `[2,4]`、组 1 `[3,5]`。`c=2` 逐笔：2→H（组 0 变 `[4,2]`）、3→H（组 1 变 `[5,3]`）、4→H（组 0 变回 `[2,4]`）、5→H（组 1 变回 `[3,5]`）、6→M（换掉 2）。轮末组 0 `[4,6]`、组 1 `[3,5]`。`c=3` 偶数组的 `2,4,6` 都缺，奇数组 `3,5` 都中，缺 3 次。
>
> **④ 收口**：A 每列 **`5,2,1,2`**，总 **`10/20=1/2`**；B 每列 **`5,3,1,3`**，总 **`12/20=3/5`**。两种映射交界列都是 `HHHHM`，但后续稳定列不一样。

> [!summary] 练熟的标准
> 题目换一组数，你仍能自己写出：**硬件闭环 → 访存数和真实块序列 → 关键组的轮末状态 → 按题目问法收口**。只要第三步有疑问，就多写一轮状态，不用猜。
