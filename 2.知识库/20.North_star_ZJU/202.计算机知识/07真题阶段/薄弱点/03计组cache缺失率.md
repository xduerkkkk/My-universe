### 二、408 Cache 代码缺失标准做题 SOP（考场直接照着 4 步走）

#### 第 1 步：草稿纸顶行写“$2^n$ 常数表” + 闭环校验（10 秒）
- 严禁心算直接出位宽，必须写出 $2^n$：
  - 块大小 $= 2^b\text{B}$（牢记 $16\text{B}\to 4$，$32\text{B}\to 5$，$64\text{B}\to 6$）
  - 单个元素字节数（遇到结构体**先算 `sizeof`**）$\implies$ 每块元素数 $= \frac{\text{块大小}}{\text{元素字节数}}$
  - 总行数 $= \frac{\text{Cache 数据区}}{\text{块大小}}$；组数 $N = \frac{\text{总行数}}{\text{路数 } r}$（直接映射 $r = 1$）
- **闭环校验**：$N \times r \times \text{块大小} \stackrel{?}{=} \text{Cache 数据区}$。

#### 第 2 步：算总块数 + 查“两处一票否决陷阱”
1. **对齐检查**：看起始地址低 $b$ 位是否全 $0$。
   - 全 $0$（对齐）：$\text{总块数} = \frac{\text{元素个数} \times \text{元素字节数}}{\text{块大小}}$。
   - 非全 $0$（非对齐）：算首字节块号与末字节块号，总块数 $= \text{末块号} - \text{首块号} + 1$（当总字节数是块大小整数倍时，直接 $+1$ 块）。
2. **纯写检查**：若循环体是**纯写**（如 `a[k] = 0`）且题干明确**非写分配法** $\implies$ 不调块，次次缺失，直接填**总写次数**结束！

#### 第 3 步：盯死第 0 块判冲突（核心计算）
- **情况 A（紧挨着访问：一维顺序 / 二维按行 / 循环合并）**：零插队 $\implies$ 必不冲突 $\implies$ **缺失次数 $=$ 访问到的不同主存块总数**。
- **情况 B（绕一圈回访：二维按列 / 跨数组 / 分开的双循环）**：
  1. **算进第 0 组的活跃块数 $K$**：
     - 二维按列：把 $\frac{\text{每行块数} \times i}{\text{组数 } N}$ **约分到最简**，看分母剩 $D$，数 `0 ~ R-1` 里有几个 $D$ 的倍数（含 $0$），就是 $K$。
     - 跨数组（如 `a, b, c`）：算各数组首地址的块号差，对组数 $N$ 取余，看有几个落进同一组。
  2. **比路数 $r$**（前提：循环顺序访问 + LRU 替换，且各活跃组对称）：
     - **$K \le r$**：不冲突 $\implies$ **缺失次数 $=$ 访问到的不同主存块总数**；
     - **$K > r$**：抖动全缺 $\implies$ **缺失次数 $=$ 总访存次数**（命中率 $= 0\%$）。

#### 第 4 步：交卷前 5 秒“3 条保命自检”
1. **冷启动下限**：Cache 初始为空时，$\text{缺失次数} \ge \text{访问的不同主存块总数}$（绝不可能算成 24 次这种比总块数还小的数）。
2. **总访存次数**：`a[k] = 2 * a[k]` 是**读 + 写 $= 2$ 次**；`a[k] = 10` 或 `sum += a[k]` 是 **$1$ 次**。
3. **问啥答啥**：看清题干问的是 **缺失次数**、**缺失率** 还是 **命中率（$1 - \text{缺失率}$）**；写 32 位十六进制地址数一下够不够 8 位。

### 参考答案与核对（算完再看）

#### 硬件常数自检
- 块大小 $32\text{B} = 2^5\text{B}$（$1$ 块 $= 8$ 个 `int`）$\implies$ 块内偏移 $= \mathbf{5}$ 位。
- Cache 容量 $8\text{KB} = 2^{13}\text{B} \implies$ 总行数 $= 2^{13}/2^5 = 2^8 = 256$ 行。
- 2 路组相联（$r = 2$）$\implies$ 组数 $= 256 / 2 = 128 = 2^7 \implies$ 组号 $= \mathbf{7}$ 位。
- Tag $= 32 - 7 - 5 = \mathbf{20}$ 位。（*校验*：$2^7 \times 2^1 \times 2^5 = 2^{13}\text{B} = 8\text{KB}$）
- 同组冲突步长 $= 128\text{ 组} \times 32\text{B} = 4096\text{B} = 4\text{KB}$（即每间隔 $128$ 块进同一组）。

#### 第 1 题答案
1. Tag **$20$ 位**，组号 **$7$ 位**，块内偏移 **$5$ 位**。
2. - **总访存次数**：每次循环先读 `a[k]` 再写 `a[k]`（$2$ 次访存）$\implies 128 \times 2 = \mathbf{256}$ **次**（注意别写成 $128$ 次！）。
   - **缺失次数**：起始地址 `0x00100008` 块内偏移为 $8\text{B}$（$2$ 个 `int`），非对齐！
     - 块 $0$ 装 `a[0]..a[5]`（$6$ 个），中间 $15$ 块装 $15 \times 8 = 120$ 个，最后 `a[126]`、`a[127]` 溢出到第 $17$ 块。共跨 **$17$ 块** $\implies$ 缺失 **$17$ 次**。
   - **命中率**：$\frac{256 - 17}{256} = \frac{239}{256} \approx \mathbf{93.36\%}$。

#### 第 2 题答案
- 每行 $1024 \times 4\text{B} = 4\text{KB} = 128$ 块，所以 `m[0][0..7]`（块 $0$）、`m[1][0..7]`（块 $128$）、`m[2][0..7]`（块 $256$）全部映射到 **第 0 组**。
1. $N = 3$，写分配：$K = 3 > r = 2$，LRU 发生抖动，次次缺失 $\implies 8 \times 3 = \mathbf{24}$ **次**。
2. $N = 3$，非写分配：纯写缺失时根本不调块进 Cache，同样次次缺失 $\implies 8 \times 3 = \mathbf{24}$ **次**。（注意：数字一样，但原因完全不同！）
3. $N = 2$，写分配：$K = 2 \le r = 2$，第 0 组的 2 路刚好装下块 $0$ 和块 $128$，互不踢出，`j = 1..7` 全命中 $\implies \mathbf{2}$ **次**。

#### 第 3 题答案
- 每个 `struct node` 占 $8 \times 4\text{B} = 32\text{B} = \mathbf{1}$ **块**，且 `p[k].x` 和 `p[k].y` 位于**同一个主存块**中。`p[512]` 共占 $512$ 块（$16\text{KB}$）。
- **代码 A**：
  - 第 1 个循环访问块 $0 \sim 511$，冷启动缺失 $512$ 次。
  - 用三步法盯第 0 组：块 $0 \sim 511$ 中进第 0 组的是块 `0, 128, 256, 384`，共 $K = 512 / 128 = 4$ 块。因为 $K = 4 > r = 2$，第 1 个循环结束时，第 0 组里只剩 `[256, 384]`，**块 0 早被踢出**。
  - 第 2 个循环从头访问 `p[0].y`（块 $0$）时，块 $0$ 缺失并踢掉 $256$，后续块 $128, 256, 384$ 全部连锁缺失 $\implies$ 再缺 $512$ 次。
  - 总缺失 $= 512 + 512 = \mathbf{1024}$ **次**。
- **代码 B**：
  - `p[k].x = 1` 写缺失时（写分配）把整个第 `k` 块调入 Cache，紧接着的 `sum += p[k].y` **紧挨着访问同一块**，零插队，直接命中！
  - 总缺失 $= \mathbf{512}$ **次**。

### 统一硬件前提（6 题共用）
- 主存按字节编址，物理地址 $32$ 位，`int` 型占 $4\text{B}$。
- 指令 Cache 与数据 Cache 分离；**数据 Cache 容量为 $16\text{KB}$**，主存块大小 **$64\text{B}$**（$1$ 块 $= 16$ 个 `int`），采用 **4 路组相联**、**LRU 替换**。

> **做题前先花 3 秒算好这 3 个核心常数（全套题通用）：**
> - 块内偏移 $= \log_2 64 = 6$ 位；总行数 $= 16\text{KB} / 64\text{B} = 256$ 行；组数 $= 256 / 4 = 64$ 组（组号占 $6$ 位）。
> - **同组冲突步长** $= 64\text{ 组} \times 64\text{B} = 4096\text{B} = 4\text{KB}$（`0x1000`），即**相距 $4\text{KB}$ 整数倍的地址必进同一组**，且每组最多同时容纳 **$4$ 块**。

### 参考答案与逐关复盘（自己算完再核对）

#### 第 1 关：**16 次**
- `0x00400000` 低 $6$ 位全 $0$（块对齐）。数组共 $256 \times 4\text{B} = 1024\text{B} = 16$ 块。
- 先读 `a[k]` 时每块第 $1$ 个元素发生冷启动缺失并调入整块，后续写 `a[k]` 和同块其余 $15$ 个元素均命中 $\implies 16$ 次。

#### 第 2 关：**17 次**
- 起始地址 `0x00400010` 的块内偏移为 $16\text{B}$（$4$ 个 `int`）。
- 块 $0$（`0x00400000` $\sim$ `0x0040003F`）只能放 `a[0]..a[11]`（$12$ 个）；剩下 $244$ 个元素占满 $15$ 块（$240$ 个）后，最后 $4$ 个（`a[252]..a[255]`）溢出到第 $17$ 块。
- **速算公式**：首地址所在块号为 `0x00400000`（块 $0$），末字节地址为 `0x00400010 + 1024 - 1 = 0x0040040F`（块 $16$），共跨 $16 - 0 + 1 = 17$ 块 $\implies 17$ 次。

#### 第 3 关：**写分配 16 次；非写分配 256 次**
- **写分配法**：写 `a[0]` 缺失时把主存块调入 Cache，后续 `a[1]..a[15]` 写命中 $\implies 16$ 次。
- **非写分配法**：写 `a[0]` 缺失时直接写主存、**不调块进 Cache**，导致 `a[1]..a[255]` 每次都缺失 $\implies 256$ 次。

#### 第 4 关：**代码 A 为 512 次；代码 B 为 8192 次**
- 1 行 $= 16 \times 4\text{B} = 64\text{B} = 1$ 块，数组共 $512$ 块（$32\text{KB}$）。
- **代码 A（按行）**：虽然数组比 Cache 大，但每块连续用完 $16$ 次就不再回头访问，只发生冷启动缺失 $\implies 512$ 次。
- **代码 B（按列）**：内层循环 `i = 0..511` 按步长 $1$ 块扫完 $512$ 块，每个 Cache 组要映射 $512 / 64 = 8$ 块，超过组容量（$4$ 路）。在 LRU 下，扫完第 $0$ 列时，每组最早的 $4$ 块全被后 $4$ 块挤出；扫第 $1$ 列时从头访问又刚好每访问 $1$ 块就挤掉下一块 $\implies$ 全程 $100\%$ 缺失 $= 512 \times 16 = 8192$ 次。
- **附加题答案（`b[256][16]`）**：**256 次**！因为 $256 / 64 = 4$ 块/组，刚好塞满 4 路不发生替换，扫完第 $0$ 列（$256$ 次缺失）后，第 $1 \sim 15$ 列全部命中！

#### 第 5 关：**$N=4$ 时 4 次；$N=5$ 时 80 次**
- 行跨度 $= 4\text{KB} =$ 同组冲突步长，所有 `c[i][0..15]` 全部映射到 **第 0 组**。
- **$N = 4$**：$4$ 个块正好放进第 $0$ 组的 $4$ 路中，`j = 0` 缺失 $4$ 次，`j = 1..15` 全部命中 $\implies 4$ 次。
- **$N = 5$**：$5$ 个块抢 $4$ 个坑，LRU 下访问 `c[4][0]` 踢掉 `c[0][0]`，下一轮访问 `c[0][1]` 又踢掉 `c[1][0]` ……每次必缺 $\implies 16 \times 5 = 80$ 次。

#### 第 6 关：**4 路组相联 48 次；直接映射 768 次**
- **4 路组相联**：$16\text{KB}$ 是 $4\text{KB}$ 的整数倍，因此同一轮的 `a[k]`、`b[k]`、`c[k]` 映射到**同一组**。但每组有 $4$ 路，$3$ 个块 $\le 4$ 路，互不踢出。每个数组各占 $16$ 块，写分配下共 $16 \times 3 = 48$ 次。
- **直接映射**：$256\text{ 行} \times 64\text{B} = 16\text{KB}$，`a[k]`、`b[k]`、`c[k]` 映射到**同一行（仅 1 路）**。每轮循环中：读 `a[k]` 缺 $\to$ 读 `b[k]` 缺并踢掉 `a` $\to$ 写 `c[k]` 缺并踢掉 `b` $\to$ 下轮读 `a[k+1]` 又缺…… $3$ 次访存次次缺失 $\implies 256 \times 3 = 768$ 次。

**一句话收口（你做完这 6 关应该就通了）：**
判断缺失次数的本质就看一件事——**当程序再次用到同一个主存块里的下一个元素时，这个块有没有被踢出它所在的那个 Cache 组？**
- 没被踢出（且非写分配没跳过调块）$\implies$ **按占用的总块数算**（第 1、2、3a、4a、5a、6a 关）；
- 再次用到之前，同组已经涌入了超过“路数 $r$”个其他块（LRU 必踢出）$\implies$ **直接崩成按元素访问次数算**（第 4b、5b、6b 关）。



做 4、5、6 关时卡住，99% 是因为**试图在脑子里同时想象整个 Cache（几十个组、几百行）的运行画面**，信息量瞬间爆炸。

做这类题的真正思维方式，是把整个 Cache 压缩成**只盯死“第 0 组”和“第 0 块”**。因为 Cache 各组之间完全独立（第 1 组发生什么绝不会影响第 0 组），而循环对各组的操作又是完全对称的。

你只需要机械套用下面这个 **“盯死第 0 块”三步法**，4、5、6 关全是一模一样的套路：

### 核心思考方式：“盯死第 0 块”三步法

#### 第一步：看“回访间隔”——块 0 的第 1 个元素和第 2 个元素，是紧挨着访问，还是绕一圈再回来？
- **紧挨着访问**（比如访问完 `a[0]` 立刻访问 `a[1]`，中间没有别的块插队）：块 0 刚进 Cache 就一次性用完，**不可能被踢出** $\implies$ 直接数总共占了多少块，做完！
- **绕一圈才回来**（比如访问完 `b[0][0]` 后，跑去访问一堆别的块，下一轮才回来访问 `b[0][1]`）：**进入第二步**，查它回来之前有没有被挤出第 0 组。

#### 第二步：数“同组插队数 $K$”——这一圈里，总共有几个块（含块 0 自己）挤进了第 0 组？
怎么判断哪些块会挤进第 0 组？就用你刚学的**除留余数**（本题组数 $= 64$）：
- **看块号**：块号 $\bmod 64 = 0$ 的块（即 **块 0、块 64、块 128、块 192……每间隔 64 块**）全进第 0 组。
- **看地址**：每相距 $64\text{ 组} \times 64\text{B} = 4\text{KB}$ 的地址，全进同一组。

#### 第三步：拿 $K$ 和“路数 $r$”比大小（决定命运的一步）
第 0 组只有 $r$ 个位置（本题 4 路组相联 $r = 4$；直接映射 $r = 1$）：
- **若 $K \le r$**：坑位够用！这 $K$ 个块和平共处，**谁都不踢谁** $\implies$ 只有第 1 圈缺失，后面回访**全部命中**（缺失次数 $=$ 总块数）。
- **若 $K > r$**：坑位不够！在**循环按顺序访问 + LRU 替换**的前提下，每块都会在“下一次轮到自己之前”刚好被挤出去 $\implies$ **每一圈、每一个元素全缺失**（缺失次数 $=$ 总访存次数）。

### 用这三步，把 4、5、6 关慢动作拆给你看

#### 拆解第 4 关：`int b[512][16]`（1 行 $= 16$ 个 `int` $= 64\text{B} = 1$ 块）
先给每一行贴上块号标签：`b[0]` 是块 0，`b[1]` 是块 1，……，`b[511]` 是块 511。

1. **代码 A（按行访问）**
   - **第一步**：访问顺序是 `b[0][0] -> b[0][1] -> ... -> b[0][15]`，块 0 里的 16 个元素**紧挨着访问**，零插队。
   - **直接出答案**：数总块数 $= 512$ 次。（哪怕数组有 $100\text{GB}$，只要一块一次性用完不回头，就只按总块数算！）

2. **代码 B（按列访问）**
   - **第一步**：`j = 0` 时访问了 `b[0][0]`（块 0），接着去访问块 1、块 2、……、块 511，直到 `j = 1` 才回来访问 `b[0][1]`（块 0）。**绕了一大圈！进第二步。**
   - **第二步**：块 0 $\sim$ 块 511 里，块号 $\bmod 64 = 0$ 的有哪些？
     `0, 64, 128, 192, 256, 320, 384, 448` $\implies$ 一共 $K = 512 / 64 = \mathbf{8}$ 个块挤进了第 0 组！
   - **第三步**：比路数 $r = 4$。$K = 8 > 4$，装不下！
     盯死第 0 组这 4 个位置看 LRU 怎么踢人：
     - `j = 0` 扫完后，第 0 组里最后剩下的是最新的 4 块：`[256, 320, 384, 448]`（**块 0 早被踢了**）。
     - `j = 1` 回来找块 0（`b[0][1]`）：**缺！** 踢掉最老的 256，组里变成 `[320, 384, 448, 0]`。
     - 扫到 `i = 64` 找块 64：**缺！** 踢掉 320，变成 `[384, 448, 0, 64]`。
     - 每一块都是刚被踢、下一秒又要找它，全员多米诺骨牌失效！
   - **出答案**：$512 \times 16 = \mathbf{8192}$ 次。

3. **附加思考题：`int b[256][16]`（按列访问）**
   - **第二步**：块 0 $\sim$ 块 255 里，进第 0 组的是：`0, 64, 128, 192` $\implies K = 256 / 64 = \mathbf{4}$ 个块。
   - **第三步**：比路数 $r = 4$。$K = 4 \le 4$，**4 个块刚好坐满 4 个位置，一个都没踢！**
     - `j = 0` 扫完后，第 0 组里稳稳躺着 `[0, 64, 128, 192]`。
     - `j = 1` 回来找块 0：**命中！** 找块 64：**命中！** 后面 `j = 1..15` 全命中！
   - **出答案**：只有第 0 列冷启动缺失 $= \mathbf{256}$ 次。

#### 拆解第 5 关：`int c[N][1024]`（1 行 $= 1024 \times 4\text{B} = 4\text{KB} = 64$ 块）
先贴块号标签（只看我们访问的前 16 列）：
- `c[0][0..15]` 是**块 0**
- 第 0 行有 1024 个 `int`，占了整整 64 个块（块 0 $\sim$ 块 63），所以 `c[1][0..15]` 直接跳到了**块 64**！
- `c[2][0..15]` 是**块 128**，`c[3][0..15]` 是**块 192**，`c[4][0..15]` 是**块 256**。

- **第一步**：`j = 0` 访问完 `c[0][0]`（块 0）后，先往下扫 `c[1][0]`、`c[2][0]` ……，到 `j = 1` 才回来访问 `c[0][1]`（块 0）。进第二步。
- **第二步**：拿上面这 $N$ 个块号去 $\bmod 64$：`0, 64, 128, 192, 256` 余数全是 $0$，**全挤在第 0 组**！所以 $K = N$。
- **第三步**：比路数 $r = 4$：
  - **$N = 4$**：$K = 4 \le 4$，4 块占满 4 个坑，不踢人 $\implies$ 只有 `j = 0` 缺 $4$ 次，后面全命中 $\implies$ **$4$ 次**。
  - **$N = 5$**：$K = 5 > 4$，5 块抢 4 个坑：
    - `j = 0` 依次进 `0, 64, 128, 192`，第 5 个块 `256` 进来时**把块 0 踢了**，组里剩 `[64, 128, 192, 256]`。
    - `j = 1` 回来找块 0：**缺！** 踢掉 `64`；接着找 `64`：**缺！** 踢掉 `128` ……次次精准踩雷！
    - 总缺失 $= 16 \times 5 = \mathbf{80}$ 次。

#### 拆解第 6 关：`c[k] = a[k] + b[k]`（`a`、`b`、`c` 两两相距 $16\text{KB}$）
先换算间距：$16\text{KB} / 64\text{B} = \mathbf{256}$ **块**。
也就是说，`a` 从块 0 开始，`b` 从块 256 开始，`c` 从块 512 开始（相对偏移）。

- **第一步**：`k = 0` 时读 `a[0]`（块 0）、读 `b[0]`（块 256）、写 `c[0]`（块 512）；到 `k = 1` 才回来读 `a[1]`（仍在块 0 里）。中间插了块 256 和块 512，进第二步。

1. **4 路组相联（64 组，$r = 4$）**：
   - **第二步**：看组号（$\bmod 64$）。$0 \bmod 64 = 0$，$256 \bmod 64 = 0$，$512 \bmod 64 = 0$，**3 个块全进第 0 组**，$K = 3$。
   - **第三步**：比路数 $r = 4$。$K = 3 \le 4$，第 0 组放得下这 3 个块，**互不踢出**！
   - 所以 `k = 1..15` 全部命中，每个数组只按总块数算（各 16 块）$\implies 16 \times 3 = \mathbf{48}$ 次。

2. **改成直接映射（256 行，$r = 1$）**：
   - **第二步**：直接映射的“组数”就是总行数 $256$。看行号（$\bmod 256$）：$0 \bmod 256 = 0$，$256 \bmod 256 = 0$，$512 \bmod 256 = 0$，**3 个块全挤进第 0 行**，$K = 3$。
   - **第三步**：比路数 $r = 1$（每行只有 1 个坑）。$K = 3 > 1$！
     - `k = 0`：读 `a[0]`（缺，块 0 进坑）$\to$ 读 `b[0]`（缺，块 256 踢掉块 0）$\to$ 写 `c[0]`（缺，块 512 踢掉块 256）。
     - `k = 1`：回来读 `a[1]`（块 0 早被踢了，**缺！**）$\to$ 读 `b[1]`（**缺！**）$\to$ 写 `c[1]`（**缺！**）……
   - **出答案**：$256$ 轮 $\times$ 每轮 $3$ 次访存全缺 $= \mathbf{768}$ 次。

# 一、原题标准解题模板（三步降维法）

**【核心思想】** 不要在脑子里带着二维数组下标 `score[row][col]` 去模拟。先把二维数组直接翻译成**一维的主存块号序列**，标出每个块映射到的 Cache 行号，挑出“不冲突的块”和“冲突的块”，按列分段累加即可。

### 第一步：画内存块分布，把二维数组转化为“块号序列”
1. **计算块容量与数组行容量**：
   * 1 个 Cache 块 $= 32\text{B} = 8$ 个 `int`。
   * 数组 `score[6][8]` 每行也是 8 个 `int`（$32\text{B}$），即**数组每行长度恰好等于 1 个主存块**。
2. **拆分首地址 `0x00000050`**：
   * 块大小 $32\text{B} = 2^5\text{B} \rightarrow$ 地址**低 5 位（第 $0\sim 4$ 位）**为块内字节偏移。
   * Cache 共 $128\text{B} / 32\text{B} = 4 = 2^2$ 行 $\rightarrow$ 地址**第 $5\sim 6$ 位**为 Cache 行号。
   * 将首地址低 7 位展开为二进制：`0x50` $= \text{0101 0000}_2$：
     * **低 5 位**：`10000` $_2 = 16\text{B}$（即第 4 个 `int`，位于当前主存块的正中间）。
     * **第 $5\sim 6$ 位**：`10` $_2 = 2$（即首地址所在的主存块映射到 **Cache 第 2 行**）。
1. **写出每行对应的主存块号**：
   设首地址所在的主存块为 **$B_0$**。因为 `score[0][0]` 从 $B_0$ 的正中间开始存放，且数组每行长度为 8 个 `int`，所以**数组的每一行都被对半劈开**——前 4 列（`col = 0..3`）在左半块，后 4 列（`col = 4..7`）在紧邻的下一个块，且**上一行的后 4 列与下一行的前 4 列共用同一个主存块**：
   * `row = 0`：前 4 列在 **$B_0$**，后 4 列在 **$B_1$**
   * `row = 1`：前 4 列在 **$B_1$**，后 4 列在 **$B_2$**
   * `row = 2`：前 4 列在 **$B_2$**，后 4 列在 **$B_3$**
   * `row = 3`：前 4 列在 **$B_3$**，后 4 列在 **$B_4$**
   * `row = 4`：前 4 列在 **$B_4$**，后 4 列在 **$B_5$**
   * `row = 5`：前 4 列在 **$B_5$**，后 4 列在 **$B_6$**

---

### 第二步：标出 Cache 映射行号，划分“独占块”与“冲突块”
因为 $B_0$ 映射到 Cache 行 2，后续连续主存块的 Cache 行号依次加 1（对 4 取模）：
* **前 4 列（`col = 0, 1, 2, 3`）每次按行循环访问序列 $S_1$**：**$B_0, B_1, B_2, B_3, B_4, B_5$**
  对应 Cache 行号依次为：`2, 3, 0, 1, 2, 3`
  * **独占块（2 个）**：**$B_2$（行 0）、$B_3$（行 1）** $\rightarrow$ 序列内无其他块争抢，一旦装入即永远命中。
  * **冲突块（4 个）**：**$B_0$ 与 $B_4$ 抢行 2**，**$B_1$ 与 $B_5$ 抢行 3** $\rightarrow$ 每次循环都会互相顶替，每次必缺失。

* **后 4 列（`col = 4, 5, 6, 7`）每次按行循环访问序列 $S_2$**：**$B_1, B_2, B_3, B_4, B_5, B_6$**
  对应 Cache 行号依次为：`3, 0, 1, 2, 3, 0`
  * **独占块（2 个）**：**$B_3$（行 1）、$B_4$（行 2）** $\rightarrow$ 序列内无其他块争抢，永远命中。
  * **冲突块（4 个）**：**$B_1$ 与 $B_5$ 抢行 3**，**$B_2$ 与 $B_6$ 抢行 0** $\rightarrow$ 互相顶替，每次必缺失。

---

### 第三步：分段计算缺失次数
1. **第 1 列（`col = 0`）**：
   Cache 初始为空，依次访问 $B_0 \sim B_5$，全部冷缺失 $\rightarrow$ **缺失 6 次**。
   *(本列结束时，最后访问的 4 个块留在 Cache 中，即 **$\{B_2, B_3, B_4, B_5\}$**)*。
2. **第 $2\sim 4$ 列（`col = 1, 2, 3`，共 3 列）**：
   继续重复访问序列 $S_1$（$B_0 \sim B_5$）。每列都是 2 个独占块（$B_2, B_3$）命中，4 个冲突块（$B_0, B_1, B_4, B_5$）互相顶替缺失 $\rightarrow$ 每列缺失 4 次，共 $4 \times 3 =$ **12 次**。
   *(`col = 3` 结束时，Cache 中留存的依然是 **$\{B_2, B_3, B_4, B_5\}$**)*。
3. **第 5 列（`col = 4`，从序列 $S_1$ 切换到序列 $S_2$ 的交界列）**：
   当前 Cache 内为 $\{B_2(\text{行0}), B_3(\text{行1}), B_4(\text{行2}), B_5(\text{行3})\}$，依次访问序列 $S_2$（$B_1 \sim B_6$）：
   * 访问 $B_1$（行 3）：行 3 当前是 $B_5$ $\rightarrow$ **缺失**（$B_1$ 装入，顶掉 $B_5$）。
   * 访问 $B_2, B_3, B_4$：均在 Cache 中 $\rightarrow$ **连续 3 次命中**。
   * 访问 $B_5$（行 3）：刚在第一步被 $B_1$ 顶掉 $\rightarrow$ **缺失**（$B_5$ 装入，顶掉 $B_1$）。
   * 访问 $B_6$（行 0）：行 0 当前是 $B_2$ $\rightarrow$ **缺失**（$B_6$ 装入，顶掉 $B_2$）。
   * 本列合计 $\rightarrow$ **缺失 3 次**。
4. **第 $6\sim 8$ 列（`col = 5, 6, 7`，共 3 列）**：
   继续重复访问序列 $S_2$（$B_1 \sim B_6$）。每列都是 2 个独占块（$B_3, B_4$）命中，4 个冲突块（$B_1, B_2, B_5, B_6$）互相顶替缺失 $\rightarrow$ 每列缺失 4 次，共 $4 \times 3 =$ **12 次**。

* **总缺失次数** $= 6 + 12 + 3 + 12 = 33$ 次。
* **总访问次数** $= 6 \times 8 = 48$ 次。
* **Cache 缺失率** $= \frac{33}{48} = \mathbf{\frac{11}{16}}$（选 **C**）。

# 三、变式题标准解析

### 【变式 1 解析】—— 答案：$\mathbf{\frac{17}{24}}$（原题 D 选项的由来）
1. **第一步（化为块号序列）**：
   首地址 `0x40` $= \text{0100 0000}_2$，低 5 位块内偏移为 `00000` $_2 = 0$。
   这说明首地址**严格对齐在主存块的起始边界上**，数组的每一行（8 个 `int`）恰好完整装入 1 个主存块中，不发生跨块：
   `row = 0..5` 分别完整对应主存块 **$B_0, B_1, B_2, B_3, B_4, B_5$**。
2. **第二步（标出映射行号）**：
   全部 8 列（`col = 0..7`）访问的都是同一个块序列：**$B_0, B_1, B_2, B_3, B_4, B_5$**（Cache 行号依次为 `2, 3, 0, 1, 2, 3`）。
   * **独占块（2 个）**：$B_2$（行 0）、$B_3$（行 1）。
   * **冲突块（4 个）**：$B_0$ 与 $B_4$（抢行 2）、$B_1$ 与 $B_5$（抢行 3）。
3. **第三步（分段累加）**：
   * `col = 0`（第 1 列）：Cache 为空，6 个块全冷缺失 $\rightarrow$ **缺失 6 次**。
   * `col = 1..7`（后 7 列）：每列均为 2 个独占块命中、4 个冲突块缺失 $\rightarrow$ 每列缺失 4 次，共 $4 \times 7 =$ **28 次**。
   * **总缺失次数** $= 6 + 28 = 34$ 次。
   * **Cache 缺失率** $= \frac{34}{48} = \mathbf{\frac{17}{24}}$。

### 【变式 2 解析】—— 答案：$\mathbf{\frac{23}{24}}$
1. **第一步（化为块号序列）**：
   起始地址仍为 `0x00000050`，故主存块划分与原题完全一致：
   * 前 4 列（`col = 0..3`）每次访问序列 $S_1$：**$B_0, B_1, B_2, B_3, B_4, B_5$**。
   * 后 4 列（`col = 4..7`）每次访问序列 $S_2$：**$B_1, B_2, B_3, B_4, B_5, B_6$**。
2. **第二步（标出 Cache 组号并分析 LRU 替换）**：
   Cache 共 4 行，采用 2 路组相联，则分为 **2 个组（组 0、组 1）**，每组包含 **2 行（2 个空位）**。
   对于序列 $S_1$（$B_0 \sim B_5$），按块号对 2 取模：
   * 映射到**组 0** 的块有 **3 个**：**$B_0, B_2, B_4$**。
   * 映射到**组 1** 的块有 **3 个**：**$B_1, B_3, B_5$**。
   * **LRU 抖动现象**：每组只有 2 个空位，却有 3 个块按固定顺序循环访问。在 LRU 算法下，每装入一个新块，替换掉的恰好是下一个即将访问的最旧的块（例如组 0 中：装入 $B_2, B_4$ 后，下一轮访问 $B_0$ 会顶掉最旧的 $B_2$；紧接着访问 $B_2$ 又会顶掉 $B_4$；访问 $B_4$ 又会顶掉 $B_0$）。因此，在重复访问同一序列时，**组内所有块每次访问全部缺失**！
3. **第三步（分段累加）**：
   * `col = 0`（第 1 列）：全部冷缺失 $\rightarrow$ **缺失 6 次**。
   * `col = 1, 2, 3`（第 $2\sim 4$ 列）：发生 LRU 抖动，每列 6 个块全部缺失 $\rightarrow$ 每列缺失 6 次，共 $6 \times 3 =$ **18 次**。
     *(`col = 3` 结束时，组 0 内留存最后访问的 $\{B_2, B_4\}$，组 1 内留存最后访问的 $\{B_3, B_5\}$)*。
   * `col = 4`（第 5 列，交界列，访问序列变为 $B_1 \sim B_6$）：
     * 访问 $B_1$（组 1）：当前组 1 为 $\{B_3(\text{旧}), B_5(\text{新})\}$ $\rightarrow$ **缺失**，顶掉最旧的 $B_3$，组 1 变为 $\{B_5(\text{旧}), B_1(\text{新})\}$。
     * 访问 $B_2$（组 0）：当前组 0 为 $\{B_2(\text{旧}), B_4(\text{新})\}$ $\rightarrow$ **命中**！组 0 更新为 $\{B_4(\text{旧}), B_2(\text{新})\}$。
     * 访问 $B_3$（组 1）：刚被 $B_1$ 顶掉 $\rightarrow$ **缺失**，顶掉最旧的 $B_5$，组 1 变为 $\{B_1(\text{旧}), B_3(\text{新})\}$。
     * 访问 $B_4$（组 0）：在组 0 中 $\rightarrow$ **命中**！组 0 更新为 $\{B_2(\text{旧}), B_4(\text{新})\}$。
     * 访问 $B_5$（组 1）：刚被 $B_3$ 顶掉 $\rightarrow$ **缺失**，顶掉最旧的 $B_1$，组 1 变为 $\{B_3(\text{旧}), B_5(\text{新})\}$。
     * 访问 $B_6$（组 0）：当前组 0 为 $\{B_2(\text{旧}), B_4(\text{新})\}$ $\rightarrow$ **缺失**，顶掉最旧的 $B_2$，组 0 变为 $\{B_4(\text{旧}), B_6(\text{新})\}$。
     * 本列合计：仅 $B_2, B_4$ 命中 2 次 $\rightarrow$ **缺失 4 次**。
   * `col = 5, 6, 7`（后 3 列）：序列 $S_2$ 中组 0（$B_2, B_4, B_6$）和组 1（$B_1, B_3, B_5$）同样是 3 个块争抢 2 个位置，触发 LRU 抖动，每列全部缺失 $\rightarrow$ 每列缺失 6 次，共 $6 \times 3 =$ **18 次**。
   * **总缺失次数** $= 6 + 18 + 4 + 18 = 46$ 次。
   * **Cache 缺失率** $= \frac{46}{48} = \mathbf{\frac{23}{24}}$。

### 【变式 3 解析】—— 答案：$\mathbf{\frac{9}{20}}$
1. **第一步（化为块号序列）**：
   数组共 5 行（`row = 0..4`），起始地址为 `0x00000050`：
   * 前 4 列（`col = 0..3`）每次访问序列 $S_1$：**$B_0, B_1, B_2, B_3, B_4$**（共 5 个块）。
   * 后 4 列（`col = 4..7`）每次访问序列 $S_2$：**$B_1, B_2, B_3, B_4, B_5$**（共 5 个块）。
2. **第二步（标出映射行号，划分独占块与冲突块）**：
   * 序列 $S_1$（$B_0 \sim B_4$）对应 Cache 行号：`2, 3, 0, 1, 2`
     * **独占块（3 个）**：**$B_1$（行 3）、$B_2$（行 0）、$B_3$（行 1）** $\rightarrow$ 稳稳命中。
     * **冲突块（2 个）**：**$B_0$ 与 $B_4$ 抢行 2** $\rightarrow$ 互相顶替，每次必缺失。
   * 序列 $S_2$（$B_1 \sim B_5$）对应 Cache 行号：`3, 0, 1, 2, 3`
     * **独占块（3 个）**：**$B_2$（行 0）、$B_3$（行 1）、$B_4$（行 2）** $\rightarrow$ 稳稳命中。
     * **冲突块（2 个）**：**$B_1$ 与 $B_5$ 抢行 3** $\rightarrow$ 互相顶替，每次必缺失。
3. **第三步（分段累加）**：
   * `col = 0`（第 1 列）：5 个块全冷缺失 $\rightarrow$ **缺失 5 次**。
   * `col = 1, 2, 3`（第 $2\sim 4$ 列）：每列 3 个独占块命中，2 个冲突块（$B_0, B_4$）缺失 $\rightarrow$ 每列缺失 2 次，共 $2 \times 3 =$ **6 次**。
     *(`col = 3` 结束时，Cache 内留存的是最后访问的 4 个块：**$\{B_1, B_2, B_3, B_4\}$**)*。
   * `col = 4`（第 5 列，交界列，访问序列 $S_2$：$B_1, B_2, B_3, B_4, B_5$）：
     前 4 个块 $B_1, B_2, B_3, B_4$ 恰好全部在 Cache 中，**连续 4 次命中**！仅在访问最后一个块 $B_5$（行 3）时发生 **1 次缺失**（顶掉 $B_1$）。
   * `col = 5, 6, 7`（后 3 列）：每列 3 个独占块（$B_2, B_3, B_4$）命中，2 个冲突块（$B_1, B_5$）缺失 $\rightarrow$ 每列缺失 2 次，共 $2 \times 3 =$ **6 次**。
   * **总缺失次数** $= 5 + 6 + 1 + 6 = 18$ 次。
   * **总访问次数** $= 5 \times 8 = 40$ 次。
   * **Cache 缺失率** $= \frac{18}{40} = \mathbf{\frac{9}{20}}$。
