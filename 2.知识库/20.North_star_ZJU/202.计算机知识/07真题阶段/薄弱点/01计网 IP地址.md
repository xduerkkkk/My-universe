### 一、 A、B、C、D、E 五类 IP 地址界限

判断一个 IP 属于哪一类，**只看它的第一个字节（前 8 位）**。二进制最高位规则是硬边界：

| 类别 | 前导二进制位 | 首字节范围（十进制） | 网络号位数 / 主机号位数 | 默认子网掩码 | 备注 / 用途 |
| :---: | :---: | :---: | :---: | :---: | :--- |
| **A 类** | `0...` | **$1 \sim 126$** | 8 位 / 24 位 | `255.0.0.0` (/8) | $0$ 和 $127$ 保留（$0$ 见上题，$127$ 环回） |
| **B 类** | `10...` | **$128 \sim 191$** | 16 位 / 16 位 | `255.255.0.0` (/16) | 中型网络 |
| **C 类** | `110...` | **$192 \sim 223$** | 24 位 / 8 位 | `255.255.255.0` (/24) | 小型网络 |
| **D 类** | `1110...` | **$224 \sim 239$** | 无网络/主机号之分 | 无掩码 | **多播（组播）地址**，不可分配给单台主机 |
| **E 类** | `1111...` | **$240 \sim 255$** | 无网络/主机号之分 | 无掩码 | 保留用于科研 |

#### 考点极易扣分的“减 2”细节：
- **可分配网络数**：
  - A 类：$2^{7} - 2 = 126$ 个（扣除全 $0$ 的网络和 $127$ 环回网段）。
  - B 类：$2^{14} = 16384$ 个（从 $128.0.0.0$ 到 $191.255.0.0$ 全部合法，408 考纲按 RFC 规定无需减 2）。
  - C 类：$2^{21} = 2097152$ 个（同上，无需减 2）。
- **每个网络中的最大可用主机数**：
  - **必须全部减 2**（扣除该网段的“主机号全 0 的网络地址”和“主机号全 1 的直接广播地址”）。
  - A 类最大主机数：$2^{24} - 2$
  - B 类最大主机数：$2^{16} - 2 = 65534$
  - C 类最大主机数：$2^8 - 2 = 254$

### 二、私有（专用）IP 地址（RFC 1918）

**核心机制**：私有地址仅在机构内部局域网中使用，**因特网中的所有主干路由器遇到目的 IP 为私有地址的分组一律丢弃**。内部主机若要访问互联网，必须经过 **NAT（网络地址转换）** 将私有 IP 转换为全球唯一的公网 IP。

408 考查私有地址的范围是死记硬背的考点：

| 类别 | 私有 IP 地址范围 | CIDR 前缀 | 包含的网络块数量 |
| :---: | :--- | :---: | :---: |
| **A 类私网** | `10.0.0.0` $\sim$ `10.255.255.255` | `10.0.0.0/8` | 1 个 A 类网络 |
| **B 类私网** | `172.16.0.0` $\sim$ `172.31.255.255` | `172.16.0.0/12` | 16 个连续的 B 类网络 |
| **C 类私网** | `192.168.0.0` $\sim$ `192.168.255.255` | `192.168.0.0/16` | 256 个连续的 C 类网络 |

#### 记忆技巧：
- **A 类私网**：直接记 $10$，第一个字节为 $10$ 的全都是。
- **B 类私网**：基准是 $172$。第二字节范围是 **$16 \sim 31$**（共 $16$ 个网段，$16 + 16 - 1 = 31$）。
  - *常见迷惑选项*：`172.15.x.x` 或 `172.32.x.x`，这些不是私网地址，是**公网地址**。
- **C 类私网**：家用路由器最常见的 `192.168.x.x`，前两个字节固定。

### 三、考研常考的“边缘特殊地址”汇总

除上述分类外，选择题还会混入以下特殊保留段干扰：

1. **链路本地地址（APIPA，自动专用 IP）**：
   - 范围：`169.254.0.0/16`（`169.254.0.0` $\sim$ `169.254.255.255`）
   - **出现场景**：主机设置为自动获取 IP（DHCP），但局域网内 DHCP 服务器故障或不可达时，操作系统自动分配此段地址，仅用于本地子网临时连通，不可跨路由器通信。
2. **多播（组播）地址范围**：
   - 属于 D 类：`224.0.0.0` $\sim$ `239.255.255.255`
   - **特性**：**只能作为目的 IP 地址**（向一个组发送），绝不能作为源 IP 地址。
