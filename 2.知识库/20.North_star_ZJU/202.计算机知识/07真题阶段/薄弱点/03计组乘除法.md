### 一、彻底纠偏：到底谁在上面（$n$ 位），谁在下面（$2n$ 位）？

你现在的印象：*“乘法是被乘数放上面，除法反过来是被除数放上面”*——**后半句全错！**

在 ALU 乘除法硬件里，永远只有两个核心位置：
1. **上面那个固定不动的 $n$ 位寄存器（通常叫 $X$ 或 $Y$）**：它接在 ALU 的一个输入端，在整场运算中**绝对不移位、数值绝对不变**，只负责每次提供加减的基准数！
   - 乘法时：它是每次要加进去的**被乘数**。
   - 除法时：它是每次要减掉的**除数**！
2. **下面那个会左右移位的 $2n$ 位双倍长寄存器（高 $n$ 位叫 $A$ / `ACC`，低 $n$ 位叫 $Q$ / `MQ`）**：它才是真正干活的流水线车间！
   - 乘法是 **$n$ 位 $\times$ $n$ 位 $=$ $2n$ 位积**（从小变大）：开始时低 $n$ 位放乘数，高 $n$ 位清 $0$；算完后整个 $2n$ 位合起来就是**乘积**。
   - 除法是 **$2n$ 位被除数 $\div$ $n$ 位除数 $=$ $n$ 位商 $\dots$ $n$ 位余数**（从大变小）：开始时整个 $2n$ 位放的就是**被除数**（如果是 $n$ 位被除数，就高 $n$ 位补 $0$、低 $n$ 位放被除数，凑成 $2n$ 位！）；算完后，**高 $n$ 位留下的是余数，低 $n$ 位腾出来的地方刚好装满 $n$ 位商**！

**【一句话焊死位置关系】**：
**“被乘数”和“除数”是亲兄弟，永远焊死在上面那个不动的 $n$ 位寄存器里；**
**“乘数/乘积”和“被除数/余数+商”，永远住在下面那个会移位的 $2n$ 位大房子里！**

### 二、 3 分钟看穿运行过程（为什么一个右移，一个左移？）

#### 1. 乘法（原码一位乘）：看最低位 $\to$ 加被乘数 $\to$ **整体右移**
- **起始**：高 $n$ 位（部分积）清 $0$，低 $n$ 位放乘数 $Q$。
- **怎么算**：每次看最右边（$Q$ 的最低位）：
  - 是 $1$：高 $n$ 位就加上被乘数；
  - 是 $0$：高 $n$ 位加 $0$（不加）。
- **为什么右移？**：加完之后，连同高 $n$ 位和低 $n$ 位**整体往右移 1 位**！
  - 好处 1：把刚才用过的乘数最低位直接从最右边挤出去扔掉，把乘数下一位送到最右边等待检查！
  - 好处 2：高 $n$ 位算出来的部分积往右退一位，一步步退到低 $n$ 位里去，最后正好凑成 $2n$ 位的完整乘积！
- **溢出吗？**：$n$ 位乘 $n$ 位，用了 $2n$ 位来存，**绝对不可能溢出！**

#### 2. 除法（不恢复余数法 / 加减交替法）：**整体左移** $\to$ 减（或加）除数 $\to$ 看正负上商
除法就是乘法的录像带倒着放！
- **起始**：高 $n$ 位清 $0$，低 $n$ 位放 $n$ 位被除数（合起来是个 $2n$ 位的被除数）。**（这就证明题目里的 Ⅰ 完全正确！）**
- **为什么左移？**：手算除法时，我们是从被除数的最高位开始往下一位位拉数来试商的。在硬件里，把 $2n$ 位寄存器**整体往左移 1 位**，被除数的最高位就自动从低 $n$ 位跨进了高 $n$ 位（余数寄存器）里，正好拿去减除数！
- **怎么上商（核心机制）**：
  左移后，高 $n$ 位（余数 $R$）减去上面的除数 $Y$：
  - **够减（余数 $R \ge 0$，最高位符号位为 $0$）**：说明商得起，在最右边空出来的最低位**上商 `1`**！下一轮正常操作：**左移 $\to$ 继续减除数**。
  - **不够减（余数 $R < 0$，最高位符号位为 $1$）**：说明减多了！在最右边**上商 `0`**！
    - *恢复余数法（笨办法）*：赶紧把减多的除数加回来（$R + Y$），再左移，下一轮再减 $Y$（即 $2(R+Y) - Y = 2R + Y$）。
    - *不恢复余数法（聪明办法）*：**绝不原地加回来！** 既然刚才算出了推导式 $2R + Y$，那我直接带着负余数 $R$ **左移 1 位（变成 $2R$），下一轮改用“加除数（$+Y$）”**，结果不就一模一样是 $2R + Y$ 了吗？！**（这就证明题目里的 Ⅱ 和 Ⅳ 完全正确！）**

### 三、除法的“溢出机制”（题目里 Ⅲ 的巨坑！）

很多人以为“无符号数没有符号位，所以除法不会溢出”——**大错特错！题目里的 Ⅲ 是错的！**

#### 为什么除法一定会溢出？（大肚汉塞进小瓶子）
硬件除法器的固有形态是：**$2n$ 位被除数 $\div$ $n$ 位除数，但商寄存器只有 $n$ 位！**
哪怕你是无符号数，如果被除数很大、除数很小，算出来的**商完全可能超过 $n$ 位能表示的最大值**（即商装不进 $n$ 位寄存器里），这就叫**除法溢出**！

1. **最极端的例子：除数为 $0$（Divide by Zero）**
   - 任何数除以 $0$，商无穷大，$n$ 位肯定装不下，直接触发**除法溢出异常（Divide Error）**！
2. **一般溢出条件（怎么在求商前做溢出检查？）**
   - 设 $2n$ 位被除数的高 $n$ 位为 $R_0$，低 $n$ 位为 $Q_0$，除数为 $Y$。
   - 在正式开始左移求商之前（第 $0$ 步），硬件通常会先试探性地用高 $n$ 位减去一次除数（$R_0 - Y$）：
     - 如果还没左移呢，**高 $n$ 位就已经大于等于除数了（$R_0 \ge Y$，够减）**，说明商至少是 $2^n$ 级别，$n$ 位商寄存器必爆无疑，直接报**溢出**！
     - 只有当高 $n$ 位小于除数（$R_0 < Y$，不够减）时，才说明商一定小于 $2^n$，不会溢出，才能正常进入 $n$ 轮上商！
   - *(注：哪怕像本题 Ⅰ 那样把高 $n$ 位置 $0$，如果除数 $Y = 0$，依然满足 $R_0 = 0 \ge Y = 0$，依然会发生除 0 溢出！所以 Ⅲ 说“无符号除法不会发生溢出，无需做任何检查”是**绝对错误**的！)*

### 四、秒杀你截图的这道题

看题干四个叙述：
- **Ⅰ**：高 $n$ 位置 $0$、低 $n$ 位放被除数，凑成 $2n$ 位被操作数，进入循环。——**正确！**
- **Ⅱ**：为了判断每次加减后余数是正是负，哪怕是无符号数，余数寄存器最高位前也必须额外加 $1$ 位符号位（用来存够不够减产生的借位/负号）；余数为负下一步“加除数”，为正下一步“减除数”。——**正确！**
- **Ⅲ**：“无符号除法不会发生溢出，无需做任何检查”。——**错误！**（除数为 $0$ 必溢出；若高 $n$ 位 $\ge$ 除数也必溢出）。
- **Ⅳ**：“减得正上商 $1$、减得负上商 $0$ 并在下一轮改用加”，省去恢复余数的回退步骤。——**正确！**

因此，全部正确的是 **Ⅰ、Ⅱ、Ⅳ**！

### 五、考场救命口诀（背下这 4 句，乘除法所有题通杀）

冲刺阶段别看厚书了，就把这 4 句口诀抄在便签上：

1. **定位置**：**被乘、除数在楼上（$n$ 位不动）；乘数、被除住楼下（$2n$ 位移位）。**
2. **看方向**：**乘法看末位，加完往右退（右移）；除法拉高位，左移再加减（左移）。**
3. **交替除（不恢复余数）**：**够减（正）商 $1$ 下次减；不够（负）商 $0$ 下次加；最后余负再加回（恢复余数）。**
   *(注：最后一句“最后余负再加回”非常重要！如果第 $n$ 步算完，最终余数还是负的，必须单独加上一次除数，才能得到正确的正余数！)*
4. **判溢出**：**乘法双倍永不溢；除法高大（高 $n$ 位 $\ge$ 除数，或小数点前绝对值 $\ge$ 除数）必溢出！**

### 补丁 1：有符号乘法 —— 只考“原码一位乘”vs“补码一位乘（Booth 算法）”

在有符号乘法中，上面不动的是被乘数 $X$，下面 $2n$ 位移位的是部分积 $A$ 和乘数 $Q$。重点背下这两者的区别表（选择题高频考点）：

| 比较维度 | 原码一位乘法 | 补码一位乘法（Booth 算法） | 考场秒杀记忆锚点 |
| :--- | :--- | :--- | :--- |
| **符号位怎么处理？** | **符号位不参与运算！**<br>单独用一个异或门算：$S_X \oplus S_Q$，里面只算绝对值（跟无符号一模一样）。 | **符号位直接参与运算！**<br>全程用补码直接加减。 | 原码符号单飞（异或）；<br>补码符号一起算。 |
| **下面末位怎么看？** | 只看乘数最低 **1 位**（$Q_n$）：<br>• 是 $1$：加 $ |X|$<br>• 是 $0$：加 $0$ | 乘数最右边要**额外附加 1 位 $Q_{n+1}$**（初始为 $0$），每次看末尾 **2 位**（$Q_n Q_{n+1}$）：<br>• `00` 或 `11`（相同）：**加 $0$**<br>• `01`（前 0 后 1）：**加 $[X]_{\text{补}}$**<br>• `10`（前 1 后 0）：**减 $[X]_{\text{补}}$**（即加 $[-X]_{\text{补}}$） | Booth 算法多了个**附加位**！<br>口诀：**同则不加，$01$ 加正，$10$ 加负**。 |
| **移位怎么移？** | **逻辑右移** $n$ 次（高位补 $0$） | **算术右移** $n$ 次（高位补符号位！） | 原码补 $0$，补码补符。 |
| **最后一步区别** | 加 $n$ 次，右移 $n$ 次，结束。 | 加 $n+1$ 次，但**只右移 $n$ 次**！（最后第 $n+1$ 步只加减，**绝不移位**！）。 | **Booth 算法的灵魂坑点：最后一步不移位！** |

#### 【有符号乘法的“溢出”巨坑（C 语言结合题必考）】
刚才说硬件里 $n$ 位乘 $n$ 位放在 $2n$ 位寄存器里绝不溢出。
**但是！** 在 C 语言中，如果你写 `int c = a * b;`（把 $2n = 64$ 位的乘积强行截断存进 $n = 32$ 位的 `int` 变量 `c` 里），就会发生溢出！
- **考题问法**：CPU 怎么判断 $n$ 位有符号乘法的结果截断成 $n$ 位后有没有溢出？
- **精准判据**：看 $2n$ 位乘积的 **高 $n$ 位是否全等于低 $n$ 位的最高位（符号位）**！
  - 如果高 $n$ 位全是 $0$（对应正数）或全是 $1$（对应负数，即高 $n$ 位纯粹是低 $n$ 位符号位的扩展），说明有效数值全在低 $n$ 位里，**未溢出（`OF = 0`）**！
  - 否则，说明高 $n$ 位里有真正的有效数值被截断丢弃了，**发生溢出（`OF = 1`）**！
  *(对比：如果是**无符号乘法**截断为 $n$ 位，则只需看**高 $n$ 位是否全为 $0$**，不全为 $0$ 就溢出 `CF = 1`)*。

### 补丁 2：有符号除法 —— 原码恢复/不恢复余数法 vs 补码不恢复余数法

有符号除法在 408 里考得比乘法浅得多，只需要记住下面 3 条规则：

1. **原码加减交替除法（最简单，跟刚才学的无符号 99% 一样！）**：
   - **符号位单独异或**（$S_Q = S_X \oplus S_Y$），然后把被除数和除数全部取绝对值，**剩下的过程跟刚才讲的无符号不恢复余数法 100% 一模一样**！（够减商 $1$ 下次减，不够商 $0$ 下次加）。

2. **补码加减交替除法（符号位参与运算，只记口诀）**：
   因为余数 $R$ 和除数 $Y$ 都是带符号的补码，怎么知道该“减”还是该“加”，该上商 $1$ 还是 $0$？
   全部取决于 **余数 $R$ 与除数 $Y$ 的符号位是否相同（同号还是异号）**：
   - **怎么消掉余数？（同减异加）**：
     想让余数绝对值变小，$R$ 和 $Y$ **同号就做减法**（加 $[-Y]_{\text{补}}$），**异号就做加法**（加 $[Y]_{\text{补}}$）。
   - **怎么上商？（同 1 异 0）**：
     加减算完得到新余数后，看**新余数与除数 $Y$ 的符号**：**同号说明够减，上商 `1`；异号说明不够减，上商 `0`**！
   - **最后一步恒置 1（末位恒置 1 法）**：为了省去最后一步恢复余数，有时会把商的最低位强制置为 $1$（误差不超过 $2^{-n}$）。

3. **有符号除法什么时候溢出？（408 真题考过 3 次的超级常客！）**
   除了“除数为 $0$”和定点小数里“$|被除数| \ge |除数|$”之外，在 **C 语言定点补码整数除法** 中，只有**唯一一种**算术溢出情况：
   $$\mathbf{\text{最小负数} \div (-1) \quad (\text{即 } -2^{n-1} \div -1)}$$
   - **以 8 位补码为例**：最小负数是 $-128$（`1000 0000`），除以 $-1$，数学结果应该是 **$+128$**。
   - 但是 8 位补码能表示的最大正数只有 **$+127$**！$+128$ 根本装不下（变成了 `-128`），直接触发硬件溢出异常！
   - **以 32 位 `int` 为例**：`-2147483648 / -1`（即 `0x80000000 / -1`）**必发生有符号除法溢出！**（看到这个式子直接秒选溢出！）。

### 终极汇总：有符号乘除“考场三句半”

把这三句话加到你刚才的便签底下，整个定点数乘除法就彻底结案了：

1. **看符号**：**原码乘除符号单飞（异或）；补码乘除符号直接参战。**
2. **补码乘（Booth）**：**末位添 $0$ 看两位，同不加、$01$ 加正、$10$ 加负，算术右移最后一步不移位！**
3. **补码除与溢出**：**同减异加，同号商 $1$ 异号商 $0$；整数除法见到 `-2147483648 / -1`（最小负数除以 $-1$）无脑选溢出！**

### 真题级变式题（10 秒检验）

**【变式题】** 在 32 位补码整数运算器中，设变量 `x` 和 `y` 均为 `int` 型。下列 C 语言表达式在执行时，**一定不会**发生算术溢出的是（ ）。
A. `x = -2147483648; y = -1; int z = x / y;`
B. `x = -2147483648; int z = -x;`
C. `x = 65536; y = 65536; int z = x * y;`
D. `x = -2147483648; y = 2; int z = x / y;`

**【解析与答案】**
- **A**：最小负数 $-2^{31}$ 除以 $-1$，结果为 $+2^{31}$，超出 `int` 最大值 $2^{31}-1$，**必溢出**！
- **B**：对最小负数求负（`-x` 等价于 `0 - x` 或 `x * -1`），结果同样是 $+2^{31}$，`int` 装不下（在机器里 `-x` 算出来还是 `-2147483648`），**必溢出**！
- **C**：$2^{16} \times 2^{16} = 2^{32}$，截断赋给 32 位 `int` 变量 `z`（结果为 $0$），高 32 位不全等于低 32 位的符号位，**必溢出**！
- **D**：$-2^{31} \div 2 = -2^{30}$，完全在 `[-2^{31}, 2^{31}-1]` 范围内，**绝对不溢出**！
- **答案：D**。
