## 一、概念辨析（5 min）
写出以下概念的**定义 + 决定因素 + 一个易错点**：
- [ ] Cache的作用：缓解CPU-主存速度差，利用时间局部性和空间局部性
- [ ] Cache行（块）vs 主存块：  
  - Cache行：Cache中的存储单元，大小通常=主存块大小  
  - 主存块：主存按块组织，一次调入一整块到Cache
- [ ] 命中率 vs 缺失率：  
  - 命中率h = 命中次数 / 总访问次数  
  - 缺失率 = 1 - h  
  - 有效访问时间EAT = h × Cache访问时间 + (1-h) × (Cache访问时间 + 主存访问时间)
- [ ] 三种映射方式：直接映射 / 全相联映射 / 组相联映射（各自的地址划分、标记位数、冲突处理）

## 二、机制流程（8 min）
**完整画出**三种映射方式的地址划分和查找流程：

### 2.1 直接映射（Direct Mapped）
主存地址划分：`[标记（Tag）] [行号（Index）] [块内偏移（Offset）]`

**地址位数计算**：
- [ ] 块内偏移位数 = log₂(块大小)
- [ ] 行号位数 = log₂(Cache行数)
- [ ] 标记位数 = 总地址位数 - 行号位数 - 块内偏移位数

**查找流程**：
1. 根据行号Index定位Cache行（唯一确定）
2. 比较该行的Tag与主存地址的Tag
3. 若相等且有效位=1 → 命中
4. 否则 → 缺失，从主存调入

**主存块→Cache行映射**：主存块号 % Cache行数 = Cache行号

**优缺点**：
- 优点：硬件简单，速度快
- 缺点：冲突多（多个主存块映射到同一Cache行）

### 2.2 全相联映射（Fully Associative）
主存地址划分：`[标记（Tag）] [块内偏移（Offset）]`

**地址位数计算**：
- [ ] 块内偏移位数 = log₂(块大小)
- [ ] 标记位数 = 总地址位数 - 块内偏移位数
- [ ] 无行号（任何主存块可放入任何Cache行）

**查找流程**：
1. 并行比较所有Cache行的Tag与主存地址Tag
2. 若某行Tag相等且有效位=1 → 命中
3. 否则 → 缺失，按替换算法选择一行替换

**优缺点**：
- 优点：冲突少，命中率高
- 缺点：硬件复杂（需并行比较器），成本高

### 2.3 组相联映射（Set Associative）
主存地址划分：`[标记（Tag）] [组号（Set Index）] [块内偏移（Offset）]`

**地址位数计算**（N路组相联，Cache总行数C）：
- [ ] 块内偏移位数 = log₂(块大小)
- [ ] 组数 = C / N（N=路数）
- [ ] 组号位数 = log₂(组数)
- [ ] 标记位数 = 总地址位数 - 组号位数 - 块内偏移位数

**查找流程**：
1. 根据组号Set Index定位到某一组（唯一确定）
2. 在该组的N路中并行比较Tag
3. 若某路Tag相等且有效位=1 → 命中
4. 否则 → 缺失，按替换算法在该组内选择一路替换

**主存块→Cache组映射**：主存块号 % 组数 = 组号

**优缺点**：
- 优点：折中（冲突比直接映射少，硬件比全相联简单）
- 缺点：需组内替换算法

## 三、算法套路（6 min）
**列表对比**（三种映射方式）：

| 映射方式 | 地址划分 | 标记位数 | 冲突情况 | 替换算法 | 硬件复杂度 |
|---------|---------|---------|---------|---------|-----------|
| 直接映射 | Tag + Index + Offset | 最少 | 多（固定位置） | 不需要（直接替换） | 最简单 |
| 全相联 | Tag + Offset | 最多 | 少（任意位置） | 需要（全局选择） | 最复杂 |
| N路组相联 | Tag + Set + Offset | 中等 | 中等（组内竞争） | 需要（组内选择） | 中等 |

### 替换算法对比
| 算法 | 策略 | 实现难度 | 命中率 |
|------|------|---------|--------|
| 随机（RAND） | 随机选择 | 简单 | 一般 |
| FIFO | 最早调入的先替换 | 简单（队列） | 可能Belady异常 |
| LRU | 最久未使用的先替换 | 复杂（需时间戳/LRU位） | 较高 |
| LFU | 使用次数最少的先替换 | 复杂（需计数器） | 适合特定访问模式 |

## 四、计算题检查清单（4 min）
写出计算步骤模板：

### 4.1 地址划分计算
给定：主存地址32位，Cache 16KB，块大小64B，4路组相联
- [ ] 块内偏移位数 = log₂(64) = 6位
- [ ] Cache总行数 = 16KB / 64B = 256行
- [ ] 组数 = 256 / 4 = 64组
- [ ] 组号位数 = log₂(64) = 6位
- [ ] 标记位数 = 32 - 6 - 6 = 20位

### 4.2 主存块→Cache位置映射
给定：主存块号X，Cache 8行直接映射
- [ ] Cache行号 = X % 8

给定：主存块号X，16行4路组相联
- [ ] 组数 = 16 / 4 = 4组
- [ ] 组号 = X % 4
- [ ] 可放入第(X%4)组的任意一路

### 4.3 命中率计算
给定访问序列：A, B, C, A, D, B, E, F, A, C  
Cache 4行，LRU替换

**模拟步骤**：
1. 冷启动：前4次全缺失
2. 逐次访问，检查是否在Cache中
3. 若缺失，按LRU替换（淘汰最久未用的）
4. 命中率 = 命中次数 / 总访问次数

### 4.4 有效访问时间（EAT）
- [ ] EAT = h × t_cache + (1-h) × (t_cache + t_mem)
- [ ] 其中h=命中率，t_cache=Cache访问时间，t_mem=主存访问时间
- [ ] 注意：缺失时Cache和主存都要访问（先查Cache发现没有，再访问主存）

### 4.5 Cache总容量计算
给定：Cache 256行，每行64B数据 + 1位有效位 + 20位Tag
- [ ] 数据容量 = 256 × 64B = 16KB
- [ ] 标记容量 = 256 × (20bit + 1bit) / 8 = 672B
- [ ] 总容量 = 16KB + 672B

## 五、陷阱识别（2 min）
写出易错点：
- [ ] "直接映射的Tag位数最少？"（对！因为有Index位，Tag不用那么长）
- [ ] "全相联的Tag位数最多？"（对！因为没有Index，Tag要包含所有定位信息）
- [ ] "组相联的组数=路数？"（错！组数=总行数/路数）
- [ ] "主存块号=主存地址/块大小？"（对！但要整除，块号从0开始）
- [ ] "缺失时只访问主存？"（错！先访问Cache发现没有，再访问主存，共2次访问）
- [ ] "4路组相联意味着每组4行？"（对！N路=每组N行）
- [ ] "Cache容量只算数据？"（看题目！通常还要算Tag和有效位的开销）
