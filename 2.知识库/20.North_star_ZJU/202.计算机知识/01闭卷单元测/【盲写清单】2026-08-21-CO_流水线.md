## 四、计算题检查清单（4 min）
写**分步公式结构**：

- [ ] **同步 k 段、统一时钟 Δt**：T = (k + n - 1)Δt
- [ ] **各段时间不等**（卡 10，这是你的二刷错题）：T = Σtᵢ + (n-1)·max(tᵢ)  
  （第一条真实经过各段，后续按瓶颈间隔完成 —— 两个公式什么时候用哪个）
- [ ] **工程时钟周期**：T_clk = max(tᵢ) + t_latch（段间寄存器开销）
- [ ] **加速比**：S = 非流水时间 / 流水时间 = nk / (k + n - 1)，n→∞ 时 S → k
- [ ] **吞吐率**：TP = n / T
- [ ] **实际 CPI**：(k + n - 1 + 停顿周期数) / n
- [ ] 稳定状态下 m 段流水线 vs m 个并行处理部件的吞吐率（卡 9，这是你的二刷错题）
