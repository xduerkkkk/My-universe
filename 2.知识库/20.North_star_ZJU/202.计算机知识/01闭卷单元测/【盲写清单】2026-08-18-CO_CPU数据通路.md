## 一、概念辨析（5 min）
写出**定义 + 决定因素 + 一个易错点**：
- [ ] 状态元件/时序元件 vs 组合逻辑元件（各举 4 个；CPU 基本节奏是哪三步）
- [ ] 微操作/RTL vs 控制信号（`PC → MAR` 和 `PCout=1, MARin=1` 是同一层次吗）
- [ ] 五个层次链：机器指令 → 微程序 → 微指令 → 微操作 → 控制信号（各层定义）
- [ ] 机器级 PC/IR vs 微程序控制器内部 μPC/μIR（别混）
- [ ] PC 位数由什么决定（保存完整字节地址 vs 保存定长指令字地址，两种口径）

## 二、机制流程（8 min）
**步骤化写出**（按单总线模型，不是 MIPS 三操作数格式）：

- [ ] **最少节拍取指**：写出 T1/T2/T3 每拍的微操作 + 合并依据  
  自查：PC 作为内部总线唯一输出源时谁能同时锁存？PC+1 先存哪里？何时写回 PC？
- [ ] **单总线五条约束**：同一拍几个输出源？多个接收端能否同时锁存？ALU 两个输入怎么解决？能否越过 MUX/暂存器/移位器？主存—MDR 外部通路能否与内部总线并行？
- [ ] **数据通路大题六步法**（模板 1）：翻译语义 → 沿图找路 → 确定 ALU 两个入口 → 标记总线占用 → 合并并行动作 → 按题目语言作答
- [ ] **后自增寄存器间接寻址**（模板 2）：MAR 何时锁存旧地址 → 写回主存时 MAR 是否仍是旧地址 → 自增放在哪一步之后
- [ ] **微程序控制器工作流程**：CM/CS → μPC(CMAR) → μIR(CMDR) → 微地址形成部件（增量/条件/操作码映射）

## 三、算法套路（6 min）
**列表对比**：
- [ ] 单周期 / 多周期 / 流水线 CPU：CPI、时钟周期长度、部件是否复用
- [ ] 硬布线 vs 微程序控制器：产生控制信号方式、速度、修改难度
- [ ] 三种编码方式：直接编码 / 字段直接编码 / 字段间接编码（字长、并行性、速度）
- [ ] 水平型 vs 垂直型微指令：编码程度、字长、并行性、速度
- [ ] 异常与中断分类 + 返回位置（缺页为何重做当前指令？校验错为何常归入终止？）

## 四、计算题检查清单（4 min）
写**分步公式结构**：
- [ ] **微指令格式设计**（模板 4，按顺序算不要凭感觉切）：  
  直接控制字段 = N 个独立信号 → N 位  
  字段编码：某互斥组 nᵢ 个微命令 + 保留"无操作" → ⌈log₂(nᵢ+1)⌉ 位，总操作字段 = 各组求和  
  判别测试字段 = 按"条件数 + 不测试"编码  
  后继地址字段 = ⌈log₂W⌉（W = 控制存储器微指令字数）  
  控制存储器容量 = 微指令字数 × 微指令字长
- [ ] 若只给总字长 → 用剩余位反推地址位和可寻址字数，检查自洽
- [ ] 微程序控制器容量与机器指令条数的关系（卡 8：公共取指微程序占空间，不能平均分）
- [ ] PC 位数两种口径分别怎么算

## 五、陷阱识别（2 min）
- [ ] "只写 PC 自增，漏掉题目要求的完整取指过程"（你的大题失分点 1）
- [ ] "没利用图中已有直连路径，擅自加中转寄存器"（失分点 2，违反最少节拍）
- [ ] "凭语义直接写两个寄存器相加"（错：每个箭头必须有物理连线）
- [ ] "寄存器选择字段"和"下地址字段"混为一谈
- [ ] "PC 是所有指令地址的来源"（卡 1：转移指令呢）
- [ ] "PC 是寄存器所以属于五大部件的存储器"（卡 2：错）
- [ ] 同一字段中的微命令为何必须互斥（卡 7：译码后只能选出一个）
- [ ] 数据必须经移位器 SR 到总线时，即使不移位也要令 SR 直通再 SRout（模板 3）
