5. C?   ！
   并发性的严格定义是若干事件在同一时间间隔内发生。
   **为什么不是“同一时刻”？**
   同一时刻，CPU 只能处理一个事情。对人类的时间感知来说，1 秒很短，1 秒这个时间间隔跑了很多任务，就是并发。其实是 CPU 每一瞬间都切换任务，推进的。
6. <font color="#ff0000">D?</font> !!
   系统调用是操作系统为应用程序使用内核功能所提供的接口，如 `open()`、`read()`、`fork()`。你必须写代码才能调用它。**和系统命令的关系？** 
   系统命令是**可执行程序**（例如 Linux 下的 `ls`, `mkdir`, `ping`，或者 Windows 下的 `dir`, `tasklist`）。
   作为一个用户，在终端输入系统命令 mkdir my_folder（创建一个新文件夹）时，这个 mkdir 程序就会运行。这是一个**系统命令**。它为了让硬盘真正划出一块空间来建文件夹，在代码内部就必须向操作系统发出请求——也就是调用了底层名为 mkdir() 的**系统调用**。
   
   操作系统提供给编程人员的接口是系统调用，那库函数是？
   有些库函数（比如 `strcpy` 字符串复制、`sin` 三角函数）纯粹是数学计算，**不需要**找操作系统帮忙，它们就直接在用户空间把活干完了。
   有些库函数（比如 `printf` 打印、`fread` 读文件）涉及到硬件操作，它们在用户空间做完准备工作（比如排队缓冲）后，会**转手去调用底层的系统调用**（如 `write`），从而跨越边界，进入内核空间

3. <font color="#ff0000">B</font>?
   在单道环境下，内存里只有 1 个程序。它的执行是**绝对顺序**的
   多道程序设计的本质，就是把多个程序同时塞进内存，让它们**并发（Concurrent）执行**
   - **间断性（B）**：因为并发和抢占，一个程序不能一气呵成跑完，它走走停停（运行态 $\rightarrow$ 阻塞态 $\rightarrow$ 就绪态）。
    
- **共享性（D）**：内存里的多个程序同时共享 CPU、内存空间和外设资源。
    
- **制约性（A）**：因为要抢夺有限的共享资源，程序之间会产生同步和互斥的制约关系（比如 A 占了打印机，B 就必须排队等）。
  多道程序设计的核心代价，就是用“丧失执行的顺序性和可预见性”，换取了系统资源的极高利用率。
  A（充分利用 I/O）、C（提高吞吐率）、D（充分利用内存），这三个选项全都是【多道批处理系统】的终极 KPI！![[王道题-1773994557237.jpeg]]

# 运行环境
1. ？
   通用操作系统（如分时系统、多任务系统）对进程的 CPU 分配采用**动态调度算法**（如时间片轮转、多级反馈队列）。程序在就绪队列中排队等待分配时间片，不需要也无法提前“预订”绝对运行时间。只有**硬实时操作系统 (Hard RTOS)** 才会采用基于时间线的严格资源预订机制。
   现代通用操作系统均采用**虚拟内存管理机制**。用户程序在编译链接后生成的是**逻辑地址**（通常从 0 开始）。程序在加载或运行时，由操作系统的内存管理模块配合硬件 MMU（内存管理单元）动态完成逻辑地址到物理地址的重定位。用户程序无需也不能自行确定在物理内存中的起始起始地址。
   **编译器不属于操作系统。** 操作系统（内核）的核心职责是管理硬件资源并向上提供系统调用接口。编译器（如 GCC）是运行在用户态的**系统软件**或**应用软件**，它负责将高级语言翻译为机器码，其本身也需要依赖操作系统提供的系统调用才能运行。![[王道题-1773997050234.jpeg]]
