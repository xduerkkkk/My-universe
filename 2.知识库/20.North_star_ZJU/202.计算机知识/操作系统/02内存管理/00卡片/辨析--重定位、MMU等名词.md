程序的物理地址何时确定？
分为静态重定位和动态重定位。
静态重定位是程序装入内存的这一瞬间，地址转换一次性彻底完成。是用可重定位装入程序来实现的。

动态重定位，程序装入内存时，地址**绝不转换**，CPU 要执行程序的瞬间，才临时算出真实的物理地址。
使用重定位寄存器记录物理起始地址。
硬件地址变换机构用于计算，起始地址+偏移地址。（通常只包含加法器和重定位寄存器）
MMU，不仅包揽了动态重定位的加法工作，还顺带把查页表、查段表、越界检查、TLB 快表统统接管了。可以把 MMU 理解为“硬件地址变换机构”在分页/分段时代的完全体。

# 重定位寄存器 vs 界限寄存器

这俩是**连续分配（动态重定位）**里的概念，不是页式里的，别搞混。

- **重定位寄存器（基址寄存器）**：存进程在物理内存中的**起始地址**。逻辑地址访问时，物理地址 = 逻辑地址 + 重定位寄存器的值。作用是地址转换。
- **界限寄存器（限长寄存器）**：存进程的**最大逻辑地址 / 地址空间长度**。作用是越界保护。

一次访问流程：先拿逻辑地址和界限寄存器比，逻辑地址 ≥ 界限 → 越界，报异常；没越界再加上重定位寄存器得物理地址。

回答你的具体疑问：

- 界限寄存器里存的**不是页表基址**，存的是长度/上界。
- 页表基址存在专门的**页表基址寄存器（PTBR）**里（x86 是 CR3），这是页式的东西，跟重定位/界限寄存器是两套机制。

对应关系：

Text

连续分配： 重定位寄存器 (基址) + 界限寄存器 (长度)

页式分配： 页表基址寄存器 (PTBR) + 页表长度寄存器

页式里"页表长度寄存器"承担的越界检查角色，类似界限寄存器；但连续分配没有页表，所以不存页表基址。

# 3. MMU 里都有什么

MMU（内存管理单元）是硬件，核心组成：

- **TLB**：页表项高速缓存，加速虚页号→页框号查找，表项含虚页号、页框号、有效位、权限位。
- **地址转换逻辑**：完成拆分虚拟地址、查表、拼接物理地址（多级页表的逐级查找由它驱动，叫 page table walker）。
- **相关寄存器**：页表基址寄存器（PTBR/CR3）、页表长度寄存器等（这些有的算 MMU 内部，有的在 CPU，考试按"配合 MMU 工作"理解即可）。
- **保护检查逻辑**：越界检查、权限位检查，不通过就发异常信号。

连续分配用的重定位寄存器、界限寄存器，也可以理解为 MMU 早期/简单形态的地址转换与保护部件。
