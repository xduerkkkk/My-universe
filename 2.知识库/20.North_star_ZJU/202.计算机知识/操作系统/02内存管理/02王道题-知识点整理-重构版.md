> [!abstract] 章节主线
> 程序地址形成 → 装入与重定位 → 地址转换和保护 → 连续/分页/分段组织 → 请求分页与置换 → 工作集控制抖动。

## 一、先分清四种“空间”

| 概念 | 含义 | 主要决定因素 | 常见误区 |
|---|---|---|---|
| 逻辑/虚拟地址空间 | 进程可使用的地址编号范围 | 虚拟地址位数、体系结构与 OS 约定 | 直接等同于磁盘容量 |
| 物理地址空间 | 物理地址能够表示和访问的范围 | 物理地址位数、硬件实现 | 减去页表后就变小 |
| 可用物理内存 | 扣除内核、页表等占用后可分配的内存 | 实际内存和系统占用 | 与物理地址空间混用 |
| 驻留集 | 某进程当前在内存中的页面集合 | 分配策略、置换策略 | 与工作集必然相等 |

## 二、装入、链接与重定位

| 机制 | 完成时机 | 地址是否在运行时继续变换 | 关键条件 |
|---|---|---:|---|
| 绝对装入 | 编译/装入前已知位置 | 否 | 位置固定 |
| 静态重定位 | 装入时 | 否 | 重定位信息、重定位装入程序 |
| 动态重定位 | 每次访存 | 是 | 硬件地址变换机构及映射信息 |

- **静态链接**：装入前把目标模块和库连接成完整装入模块。
- **装入时动态链接**：装入期间遇到外部模块再链接。
- **运行时动态链接**：执行到需要的模块时再链接，适合共享库和按需加载。
- 分段按逻辑模块组织，因而更自然地表达模块共享、保护与动态链接；这不是说分页不能实现这些功能。

## 三、保护机制

1. OS 为进程建立地址映射与权限信息。
2. 进程切换时装入当前地址空间的有关控制信息。
3. MMU/TLB 等硬件在访存时执行转换和权限检查。
4. 越界、缺页或权限失败触发异常，由 OS 处理。

连续分配教材模型常见两种表达：

- 上下界寄存器直接检查物理地址范围；
- 基址/重定位寄存器＋限长寄存器：先检查逻辑地址，再完成地址平移。

## 四、连续分配

| 方法 | 主要碎片 | 特征 |
|---|---|---|
| 单一连续分配 | 系统区之外利用率低 | 最简单 |
| 固定分区 | 内部碎片 | 分区数和大小预先确定 |
| 动态分区 | 外部碎片 | 按进程需求动态划分，可结合紧凑 |

### 动态分区算法

- 首次适应：按地址搜索第一个可用块。
- 循环首次适应：从上次位置继续。
- 最佳适应：找最小可用块，容易留下微小碎片。
- 最坏适应：找最大块，可能快速消耗大空闲区。

紧凑会移动进程，因此要求运行时仍能修正地址，即动态重定位支持。

## 五、分页

### 地址结构

逻辑地址由页号和页内偏移构成；页面大小为 $2^k$ B 时，页内偏移占 $k$ 位。

### 基本权衡

| 页面较小 | 页面较大 |
|---|---|
| 页内碎片较少 | 页表项较少 |
| 页表更大 | 顺序传输效率可能更高 |
| 缺页与管理粒度更细 | 一次调入无用数据可能更多 |

### 多级页表

1. 先由页面大小确定页内偏移位数。
2. 剩余位数是虚页号。
3. 用“一个页表页能装多少表项”确定每级最多承担多少索引位。
4. 级数按覆盖全部虚页号位数决定。
5. 区分“覆盖整个虚拟空间的最大页表规模”和“当前实际建立的页表规模”。

## 六、分段与段页式

| 项目 | 分页 | 分段 |
|---|---|---|
| 划分依据 | 固定大小 | 逻辑模块 |
| 用户可见性 | 通常不可见 | 可见 |
| 地址表达 | 线性地址自动拆页号/偏移 | 段号＋段内偏移 |
| 碎片 | 页内碎片 | 外部碎片 |
| 共享保护 | 可实现 | 逻辑表达更自然 |

段页式：先按逻辑模块分段，每段内部再分页。段表项通常给出该段页表的始址和段长等信息，页表项再给出物理页框号。

## 七、请求分页与置换

### 三个特征

- 多次性：程序和数据可分多次调入。
- 对换性：运行期间页面可换入换出。
- 虚拟性：逻辑上扩充内存使用体验。

### 算法边界

| 算法 | 依据 | 是否典型栈算法 | 风险 |
|---|---|---:|---|
| OPT | 最晚将来访问 | 是 | 只能用于理论比较 |
| FIFO | 最早进入内存 | 否 | 可能 Belady 异常 |
| LRU | 最久未访问 | 是 | 精确实现成本高 |
| CLOCK | 访问位＋循环扫描 | 近似近期使用 | 不要机械等同 LRU 或 FIFO |

## 八、工作集与抖动

- 工作集反映进程在时间窗口内的局部性需求。
- 驻留集是当前实际在内存中的页面。
- 驻留集长期不能覆盖活跃工作集时，缺页频繁，可能发生抖动。
- 减少并发进程数、增加合适的驻留页框或采用工作集/PFF 控制，都可能缓解抖动。

## 九、校正与条件

> [!warning] 旧版：虚拟地址空间受外存大小直接限制
> **校正**：地址编号范围主要由虚拟地址位数决定；磁盘和提交策略限制可实际承诺的后备容量。  
> **适用条件**：若题目明确问“虚拟存储器可用容量”，再结合主存、外存和地址结构判断。

> [!warning] 旧版：物理地址空间＝总空间－页表/段表长度
> **校正**：管理结构占用的是物理内存容量，不改变物理地址空间的定义范围。  
> **适用条件**：题目问“用户可用内存”时才能按题设扣除。

> [!warning] 旧版：MMU 与动态重定位绑定
> **校正**：动态重定位需要硬件地址变换；MMU 还可承担分页、分段、保护和异常检测。  
> **适用条件**：连续分配教材题中可把基址/限长机构视为动态重定位硬件。

> [!warning] 旧版：工作集必为驻留集子集
> **校正**：驻留集覆盖工作集是理想管理目标，不是任何时刻都成立的定义关系。

## 十、绝对词检查

- “必须”：确认是抽象机制必须，还是某种具体硬件实现必须。
- “只有分段能共享/链接”：错误；应写“分段更自然”。
- “页框越多缺页一定越少”：只对满足栈性质的算法保证成立。
- “空间减去页表”：先确认问的是地址范围还是可用容量。


## 十一、地址转换的访存次数

| 情况 | 典型主存访存次数 |
|---|---:|
| 单级页表，无 TLB | 页表 1＋数据 1＝2 |
| TLB 命中 | 数据 1 |
| n 级页表，TLB 未命中 | n 级页表＋数据＝n+1 |
| 典型段页式，无快表 | 段表＋页表＋数据＝3 |

TLB 查询不是主存访问；若题目说明页表项、段表项已在高速缓存中，应按题设调整。

## 十二、页表项字段

| 字段 | 作用 | 典型异常/动作 |
|---|---|---|
| 页框号 | 给出物理页位置 | 完成地址拼接 |
| 有效/存在位 | 页面是否驻留 | 合法但不驻留时缺页 |
| 保护位 | 读、写、执行权限 | 权限失败触发保护异常 |
| 访问位 | 最近是否访问 | 辅助 CLOCK 等置换 |
| 修改位 | 驻留期间是否写过 | 淘汰时判断是否写回 |

页表项数量看虚拟页数，页框号位数看物理页框数；页表项总大小还要容纳控制位。

## 十三、程序链接与地址形成

源程序经编译/汇编形成目标模块；链接器解析模块间符号并形成逻辑地址布局；装入程序把模块放入内存；动态重定位系统在运行时再把逻辑地址转换为物理地址。

- 静态链接：运行前合并全部模块。
- 装入时动态链接：装入阶段解析模块。
- 运行时动态链接：执行到调用点再装入或绑定。

## 十四、内存映射文件与页缓冲

- 内存映射文件把文件区间映射到虚拟页，首次访问可通过缺页从文件调入。
- 共享映射可让多个进程映射相同文件页；私有映射可采用写时复制。
- 页缓冲队列保留刚淘汰的页，提供短期反悔机会并便于批量写回，但不消除工作集超过内存造成的抖动。

## 十五、计算题单位检查

1. 地址位数先区分页号和页内偏移。
2. 页表项数的单位是“项”，页表大小才是 Byte。
3. 每页可装表项数＝页面大小÷页表项大小。
4. 地址范围、可用容量、页表占用和实际驻留页数分别计算，不在同一式子中混写。
