# 第 36 题：“引入多余地址”是什么意思？

题目：

已知地址块：192.168.6.192/26  
问哪个地址块和它不重叠，且聚合后不会引入多余地址？

先算已知块：

192.168.6.192/26

`/26` 表示后 6 位是主机号，所以每块大小：

2^6 = 64 个地址

`/26` 的地址块边界是：

192.168.6.0/26       → 0 ~ 63  
192.168.6.64/26      → 64 ~ 127  
192.168.6.128/26     → 128 ~ 191  
192.168.6.192/26     → 192 ~ 255

所以已知块范围是：

192.168.6.192 ~ 192.168.6.255

---

## 什么叫“聚合后不引入多余地址”？

聚合就是把两个小地址块合成一个大地址块。

比如：

192.168.6.128/26  
+  
192.168.6.192/26

它们正好连续：

128 ~ 191  
192 ~ 255

合起来就是：

192.168.6.128 ~ 192.168.6.255

刚好可以表示成：

192.168.6.128/25

没有多出来的地址。

这就叫：

> 聚合后不引入多余地址。

---

反过来，如果用：

192.168.6.0/25  
+  
192.168.6.192/26

范围分别是：

0 ~ 127  
192 ~ 255

中间缺了：

128 ~ 191

如果强行聚合成一个大块，只能变成：

192.168.6.0/24

范围是：

0 ~ 255

这样就把原本没有的：

128 ~ 191

也包括进来了。

这些就是“多余地址”。

---

## 第 36 题答案

选项：

A. 192.168.6.0/25       → 0 ~ 127  
B. 192.168.6.0/26       → 0 ~ 63  
C. 192.168.6.128/26     → 128 ~ 191  
D. 192.168.6.192/27     → 192 ~ 223

已知块是：

192.168.6.192/26        → 192 ~ 255

只有 C：

192.168.6.128/26        → 128 ~ 191

和它正好相邻，且大小相同，可以聚合为：

192.168.6.128/25        → 128 ~ 255

所以第 36 题选：

C
