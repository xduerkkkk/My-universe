这些是 408 计算机网络中最核心的**专有名词缩写**。以下按功能分类，给出它们的全称、精确定义、所属层次及它们之间的换算关系：

---

### 一、体系结构与数据单元（PDU / SDU / PCI）

这是 OSI 参考模型中定义每层数据结构的三个标准术语：

```text
上层传下来的数据 ──> [   SDU (服务数据单元)   ]
                           │
本层加装首部/尾部 ──> [ PCI ] + [ SDU ] = [ PDU (本层的协议数据单元) ]
```

* **PDU（Protocol Data Unit，协议数据单元）**：
  * **含义**：**对等层之间传输的数据单位**。
  * 各层的 PDU 有特定的名称：
    * 传输层 PDU：**报文段（Segment, TCP）** / **用户数据报（Datagram, UDP）**
    * 网络层 PDU：**分组（Packet）** 或 **IP 数据报（IP Datagram）**
    * 数据链路层 PDU：**帧（Frame）**
    * 物理层 PDU：**比特（Bit）**
* **SDU（Service Data Unit，服务数据单元）**：
  * **含义**：**上一层交下来、要求本层传输的有效载荷（净数据 Payload）**。
* **PCI（Protocol Control Information，协议控制信息）**：
  * **含义**：**本层为了实现协议功能而在 SDU 前后加装的首部（Header）和尾部（Trailer）**。
  * **换算公式**：$$\mathbf{PDU = PCI + SDU}$$

### 二、报文长度限制（MTU 与 MSS，408 计算题核心）

这两个缩写决定了数据在网络中是否会被“分片”，必须严格区分它们所属的层次：

```text
|<─────────────────────── MTU (以太网默认 1500B) ──────────────────────>|
┌───────────────────────┬───────────────────────┬──────────────────────┐
│   IP 首部 (默认 20B)  │   TCP 首部 (默认 20B)  │  TCP 数据部分 (MSS)   │
└───────────────────────┴───────────────────────┴──────────────────────┘
|<─── IP 数据报总长度 ──>|                       |<─── MSS 默认 1460B ──>|
```

* **MTU（Maximum Transmission Unit，最大传输单元）**：
  * **所属层次**：**数据链路层**。
  * **定义**：单根物理链路的数据帧所能承载的**最大有效载荷（即包含 IP 首部的 IP 数据报总长度）**。
  * **标准数值**：以太网（Ethernet V2）的 MTU 固定为 **$1500\text{ 字节}$**。
* **MSS（Maximum Segment Size，最大报文段长度）**：
  * **所属层次**：**传输层（TCP 专属）**。
  * **定义**：TCP 报文段中**应用层数据部分（Payload）的最大长度**（**不包含** TCP 首部和 IP 首部）。
  * **计算公式**：
    $$\mathbf{MSS = MTU - IP首部长度 - TCP首部长度}$$
    在标准无选项的情况下（IP 首部 20B，TCP 首部 20B）：
    $$\mathbf{MSS} = 1500 - 20 - 20 = \mathbf{1460\text{ 字节}}$$

### 三、传输与拥塞控制相关缩写

* **cwnd（Congestion Window，拥塞窗口）**：
  * **发送方**根据网络拥塞程度自行维护的窗口大小（单位：字节数或 MSS）。
* **rwnd（Receiver Window，接收窗口）**：
  * **接收方**在 TCP 首部中通告的剩余接收缓存大小，用于流量控制。
* **ssthresh（Slow Start Threshold，慢开始门限）**：
  * TCP 拥塞控制的分水岭：$\text{cwnd} < \text{ssthresh}$ 时执行指数增长的**慢开始**；$\text{cwnd} \ge \text{ssthresh}$ 时切换为加法增大的**拥塞避免**。
* **ISN（Initial Sequence Number，初始序号）**：
  * TCP 三次握手建立连接时，双方各自随机生成的起始字节序号（即握手时的 $seq = x$ 或 $seq = y$）。

### 四、时间与寿命相关缩写

* **TTL（Time To Live，生存时间）**：
  * **所属层次**：网络层（IPv4 首部）。
  * **实际含义**：**跳数限制（Hop Limit）**。数据报每经过一个路由器该值减 1，为 0 时丢弃并回送 ICMP 超时报文，防止死循环。
* **RTT（Round-Trip Time，往返时间）**：
  * 从发送端发送一个数据报文开始，到发送端收到接收端回送的确认报文所经历的**总时间**。
* **RTO（Retransmission Time-Out，超时重传时间）**：
  * 发送方启动的重传定时器阈值。计算规则为 $\text{RTO} \ge \text{RTT}$（由平滑往返时间 SRTT 和离散度动态计算得出）。
* **MSL（Maximum Segment Lifetime，最长报文段寿命）**：
  * 报文段在网络工程中被允许存活的最长时间。TCP 四次挥手在 `TIME_WAIT` 状态必须停留 **$2\text{MSL}$**。
