## 1️⃣单播、广播和多播

### 单播（Unicast）

- **概念**：一个源 IP 对应一个目的 IP，点对点通信。
- **例子**：192.168.24.59/30 → 一个具体主机
- **特点**：
    - 每个分组只送给一个目的主机
    - 常规主机 IP 都是单播地址

### 广播（Broadcast）

- **概念**：发送给网络中所有主机。
- **类型**：
    1. **本地网络广播**（Local Broadcast）：`255.255.255.255`
        - 用于同一局域网内的主机发现或 DHCP 请求
    2. **定向广播**（Directed Broadcast）：网络号 + 全 1 主机号
        - 例如 172.31.128.255/18
        - 向该网络内所有主机发送
- **题目考点**：
    - 选单播/广播题时，看 **主机号部分是不是全 1**
    - D 类地址 224.x.x.x~239.x.x.x → 多播地址

---

### 例子对应选项（题 15）

- A. 172.31.128.255/18 → **广播**（定向广播，主机号全 1）
- B. 10.255.255.255 → 广播（如果子网掩码 255.0.0.0，对应网络广播）
- C. 192.168.24.59/30 → **单播**
- D. 224.105.5.211 → **多播**

## 2️⃣ 本地回环（Loopback）

- **IP 地址**：127.0.0.0/8
- **作用**：用于本机测试网络协议栈，不发送到网卡
- **规则**：
    - 可以作为 **目的 IP** → 测试本机服务
    - **不能作为源 IP** → 不用于真实数据报发送
- 题 16 对应：
    - 本地回环地址：127.0.0.1
    - 其他选项：
        - A. 10.10.10.1 → 私有网络地址
        - B. 255.255.255.0 → 子网掩码
        - C. 192.0.0.1 → 公网地址

## 3️⃣ 可分配给主机的 IP 地址

- **要求**：
    1. 不是广播地址（主机号全 1）
    2. 不是网络号（主机号全 0）
    3. 不是特殊保留地址（如 0.0.0.0/8）
    4. 不是回环地址（127.x.x.x）
- 题 17 对应：
    - A. 192.46.10.0 → 网络号，**不能分配给主机**
    - B. 110.47.10.0 → 网络号？具体看掩码，如果默认 /8，则是网络号 → 不可
    - C. 127.10.10.17 → 回环地址 → 不可
    - D. 211.60.256.21 → 注意 256 超过 0~255 → 不合法
- 正确可分配主机 IP 示例：任何合法、非网络号、非广播号、非回环、非保留地址

## 4️⃣ 特殊 IP 地址和使用规则

|地址|用途|可作为源|可作为目的|
|---|---|---|---|
|0.0.0.0|默认路由 / DHCP 客户端请求源|✅ 可作源（DHCP）|❌ 不作目的|
|255.255.255.255|本地广播|❌|✅|
|127.0.0.0/8|回环|❌|✅|
|D 类 224–239|多播|❌|✅|

- 题 18 错误说法：
    - “0.0.0.0 可以作为 DHCP 客户端的源 IP 地址” ✅ 正确
    - 题目问“说法错误的”，所以错误选项就是 **选 B 或 D？**
    - B. 路由器不会转发 255.255.255.255 → 正确
    - C. 127.0.0.1 可作为目的但不能作为源 → 正确
    - D. 路由器可以转发目的为全 1 的 IP 数据报 → 错误，因为广播不转发 → 错误选 D

## 5️⃣ IP 地址与子网掩码理解

- 网络号和广播号由 **IP + 子网掩码** 决定
- 公式：
    - 网络地址 = IP & 子网掩码
    - 广播地址 = 网络地址 | (~子网掩码)
- **可分配给主机的地址**：
    - 大于网络地址，小于广播地址
    - 举例：
        - 网络 192.168.1.0/24 → 可分配主机 192.168.1.1~192.168.1.254

## ✅ 知识点总结（IP 地址篇）

1. **单播、广播、多播**
    - 单播：主机号非全 0 / 全 1
    - 广播：主机号全 1（定向广播）或 255.255.255.255（本地广播）
    - 多播：D 类地址 224.0.0.0–239.255.255.255
2. **本地回环**
    - 127.0.0.0/8
    - 只能作目的 IP
    - 测试本机协议栈
3. **可分配主机 IP**
    - 非网络号（主机号全 0）
    - 非广播号（主机号全 1）
    - 非回环地址
    - 非保留特殊用途地址（如 0.0.0.0 除了 DHCP 源）
4. **特殊 IP 地址规则**
    - 0.0.0.0 → DHCP 客户端源地址
    - 255.255.255.255 → 本地广播，不转发
    - 127.x.x.x → 回环，只在本机
    - 224–239 → 多播，不能作为源
5. **子网掩码的作用**
    - 定义网络号和主机号位数
    - 用于判断网络范围、计算广播地址
    - 可分配主机地址范围 = 网络地址 + 1 → 广播地址 - 1
