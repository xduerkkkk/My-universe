题目：

现将一个 IP 网络划分为 4 个子网，  
若其中一个子网是 192.168.1.130/26，  
则下列网络中，不可能是另外 3 个子网之一的是？

注意：

192.168.1.130/26

它不是网络地址，而是这个子网里的某个地址。

`/26` 每块大小是 64：

192.168.1.0/26       → 0 ~ 63  
192.168.1.64/26      → 64 ~ 127  
192.168.1.128/26     → 128 ~ 191  
192.168.1.192/26     → 192 ~ 255

所以：

192.168.1.130/26

所在的真正子网是：

192.168.1.128/26

范围：

192.168.1.128 ~ 192.168.1.191

---

## “另一个子网”要满足什么？

如果原网络是：

192.168.1.0/24

现在划成 4 个子网，那么这 4 个子网必须：

1. 互不重叠  
2. 都在 192.168.1.0 ~ 192.168.1.255 内  
3. 合起来正好覆盖整个原网络  
4. 总数量正好是 4 个

已经有一个：

192.168.1.128/26      → 128 ~ 191

剩下的地址范围是：

0 ~ 127  
192 ~ 255

---

## 看选项

### A. `192.168.1.0/25`

范围：

0 ~ 127

可以。

剩下：

192 ~ 255

可以再分成两个 `/27`：

192.168.1.192/27      → 192 ~ 223  
192.168.1.224/27      → 224 ~ 255

这样 4 个子网是：

192.168.1.0/25  
192.168.1.128/26  
192.168.1.192/27  
192.168.1.224/27

刚好 4 个，所以 A 可能。

---

### B. `192.168.1.64/26`

范围：

64 ~ 127

可以。

另外可以是：

192.168.1.0/26        → 0 ~ 63  
192.168.1.128/26      → 128 ~ 191  
192.168.1.192/26      → 192 ~ 255

刚好 4 个 `/26` 子网，所以 B 可能。

---

### D. `192.168.1.224/27`

范围：

224 ~ 255

可以。

另外可以是：

192.168.1.0/25        → 0 ~ 127  
192.168.1.128/26      → 128 ~ 191  
192.168.1.192/27      → 192 ~ 223  
192.168.1.224/27      → 224 ~ 255

刚好 4 个，所以 D 可能。

---

### C. `192.168.1.96/27`

范围：

96 ~ 127

这个看起来也不重叠，但问题在于它会把前半段切碎。

现在已经有：

96 ~ 127  
128 ~ 191

还剩：

0 ~ 95  
192 ~ 255

其中：

192 ~ 255

可以用一个块表示：

192.168.1.192/26

但：

0 ~ 95

不能用一个合法 CIDR 块表示。

它至少要拆成：

192.168.1.0/26        → 0 ~ 63  
192.168.1.64/27       → 64 ~ 95

这样总共就变成：

192.168.1.0/26  
192.168.1.64/27  
192.168.1.96/27  
192.168.1.128/26  
192.168.1.192/26

一共 5 个子网。

但题目要求划成 4 个子网，所以 C 不可能。

第 40 题选：

C

---

# 4. 这类题的核心口诀

CIDR 地址块必须满足：  
大小是 2 的幂；  
起点必须按块大小对齐；  
子网之间不能重叠；  
划分后不能有空洞；  
题目说几个子网，就必须正好几个。

再记一句：

聚合不能多包地址；  
划分不能漏掉地址；  
子网之间不能重叠。

第 36 题考的是：

能不能精确聚合

第 40 题考的是：

能不能精确划分成指定数量的子网

第 37 题考的是：

传统点对点用 /30，新标准点对点可用 /31
