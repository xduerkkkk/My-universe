## 章节主线

```text
网络层服务模型
  ├─ 数据报 / 虚电路
  ├─ IPv4 数据报：编址、转发、分片、ICMP
  ├─ 本地交付辅助：ARP、DHCP
  ├─ 地址不足与边界转换：CIDR、聚合、NAT
  ├─ 下一代协议：IPv6
  ├─ 路由控制平面：RIP、OSPF、BGP
  └─ 特殊交付：多播、移动 IP、路由设备
```

网络层解决两个核心问题：**给端系统和接口赋予可路由的逻辑地址**，以及**让分组跨越多个异构网络到达目的地**。控制平面形成路由，数据平面按转发表逐分组转发。

## 1. 网络层服务模型

### 1.1 路由与转发

| 概念 | 所在平面 | 处理尺度 | 核心问题 |
|---|---|---|---|
| 路由 routing | 控制平面 | 网络范围、较慢 | 到某前缀有哪些路径，哪条更优？ |
| 转发 forwarding | 数据平面 | 每个分组、很快 | 到来的分组应从哪个接口发出？ |
| 路由表 RIB | 控制平面数据 | 多个候选 | 保存协议学到的路由与属性 |
| 转发表 FIB | 数据平面数据 | 最优结果 | 做最长前缀匹配并给出下一跳 |

### 1.2 数据报与虚电路

| 维度 | 数据报 | 虚电路 |
|---|---|---|
| 建立阶段 | 无 | 有 |
| 分组首部 | 完整目的地址 | 局部 VC 标识 |
| 路径 | 每个分组可独立选路 | 通常沿已建立路径 |
| 顺序 | 可能乱序 | 通常更易保序 |
| 路由器状态 | 不保存每条连接状态 | 保存 VC 映射状态 |
| 故障影响 | 后续分组可绕路 | 路径故障会破坏该 VC |
| 可靠性 | 与“无连接”不等价 | 与“面向连接”也不等价 |

> [!warning] 连接与可靠性必须拆开
> “建立连接”说明通信前后维护状态；“可靠”说明是否有确认、重传、去重和有序交付。二者相关但不是定义等价。

## 2. IPv4 数据报

### 2.1 首部主字段

| 字段 | 作用 | 高频条件 |
|---|---|---|
| Version | IPv4 为 4 | 首字节高 4 位 |
| IHL | 首部长度，单位 4B | 无选项时 5，即 20B |
| Total Length | 首部 + 数据 | 最大 65535B |
| Identification | 标识同一原始数据报的分片 | 同组分片相同 |
| DF / MF | 禁止分片 / 后面还有分片 | `DF=1` 时路由器不可分片 |
| Fragment Offset | 分片在原数据中的位置 | 单位 8B |
| TTL | 每经一路由器减 1 | 归零丢弃并通常回 ICMP |
| Protocol | 上层协议 | TCP=6，UDP=17，ICMP=1 |
| Header Checksum | 只检验 IPv4 首部 | 路由器修改 TTL 后重算 |
| Source / Destination | 端到端逻辑地址 | NAT、隧道等情况会改变/外封装 |

### 2.2 分片公式

> [!important] 单片最大载荷
> `payload_max = floor((MTU - IHL_bytes) / 8) × 8`  
> 适用条件：不是原始数据报的最后一片。  
> 易错：片偏移单位是 8B，而 Total Length 单位是 1B。

二次分片仍保持同一 Identification；偏移始终相对原始数据报。目的主机负责重组，中间路由器不重组。任何必要分片缺失，原数据报都无法完整交付。

## 3. IPv4 编址、子网与 CIDR

### 3.1 地址三件套

- **网络地址**：主机位全 0，表示前缀本身。
- **广播地址**：主机位全 1，表示该前缀内所有主机。
- **可用主机范围**：传统广播子网中为网络地址 +1 到广播地址 -1。

### 3.2 特殊地址

| 地址/前缀 | 教材语义 | 关键限制 |
|---|---|---|
| `0.0.0.0` | 未指定地址 | 常见于尚未配置 IP 的主机作源地址 |
| `0.0.0.0/0` | 默认路由 | 匹配所有地址，最长前缀规则下最后兜底 |
| `127.0.0.0/8` | 回环 | 不离开本机协议栈 |
| `255.255.255.255` | 受限广播 | 不经路由器转发 |
| `224.0.0.0/4` | IPv4 多播 | 只能作目的地址 |
| `10.0.0.0/8` | 私有地址 | 公网不直接路由 |
| `172.16.0.0/12` | 私有地址 | 公网不直接路由 |
| `192.168.0.0/16` | 私有地址 | 公网不直接路由 |

### 3.3 子网计算

- `network = IP & mask`
- `broadcast = network | (~mask)`
- 变化字节的块大小：`256 - mask_octet`
- 容纳 `N` 台普通主机：求最小 `h` 使 `2^h - 2 ≥ N`，前缀为 `/ (32-h)`。
- VLSM：先大后小；地址块起点必须按块大小对齐。

### 3.4 最长前缀匹配与路由聚合

路由器把目的 IP 与各前缀比较，选择**匹配位数最多**的条目。默认路由 `/0` 总能匹配，但只有没有更具体前缀时才使用。

无损聚合要求连续、对齐且覆盖范围恰好。聚合后若包含不存在或不应走该出口的地址，就会引入额外地址，需要更具体路由或丢弃路由来防止误转发。

## 4. ARP、DHCP、ICMP 与 NAT

### 4.1 ARP

```text
先判断目的 IP 是否同网段
  ├─ 同网段：ARP 查目的主机 MAC
  └─ 跨网段：ARP 查默认网关 MAC
```

IP 目的地址指向最终主机；以太网目的 MAC 只指向**本链路下一跳**。经过路由器后，旧帧被拆除，再按下一链路重新封装 MAC 首部。

### 4.2 DHCP

`Discover → Offer → Request → ACK`。DHCP 不只分配 IP，还可提供子网掩码、默认网关、DNS、租期等。Request 的广播有“公开选择、释放其他 Offer”的作用。

### 4.3 ICMP

- 差错报告：终点不可达、时间超过、参数问题等。
- 查询/诊断：Echo Request/Reply（ping）。
- 不对所有异常都回 ICMP；例如首部检验和错误、对某些 ICMP 差错报文、广播/多播场景等通常不再回差错报文，防止递归风暴。

### 4.4 NAT / NAPT

| 方向 | 匹配 | 修改 |
|---|---|---|
| 内网→外网 | 私网源 IP/源端口 | 公网源 IP/转换端口 |
| 外网响应→内网 | 公网目的 IP/转换端口 | 私网目的 IP/原端口 |

NAPT 借助端口让多台私网主机共享公网地址。它需要检查和修改传输层字段，因此打破了严格的分层透明性；无动态或静态映射的外部主动连接通常无法进入。

## 5. IPv6

- 地址 128 位；十六进制分组表示。
- 每组省略前导 0；整段全 0 可用一次 `::`。
- 基本首部固定 40B，字段更少；扩展信息放在扩展首部。
- 没有 IPv4 首部检验和，没有广播。
- 路由器不分片；源主机使用路径 MTU 发现并在需要时分片。
- IPv6 的“无路由器分片”不能误写成“IPv6 永远不能分片”。

## 6. 路由协议

### 6.1 RIP

- 距离向量，度量为跳数。
- 只与邻居交换路由信息；收到邻居条目后距离 +1、下一跳改为该邻居。
- 同一下一跳的路由要随邻居更新；不同下一跳只有更优时替换。
- 典型防环：水平分割、毒性逆转、触发更新；仍可能收敛慢。

### 6.2 OSPF

- 链路状态协议：邻居发现 → 同步 LSDB → SPF 计算。
- 五类报文：Hello、DBD、LSR、LSU、LSAck。
- LSA 是被传播的链路状态信息，LSU 是承载 LSA 的报文。
- 区域化降低单个区域的 LSDB 和 SPF 规模，但增加 ABR、汇总与跨区域 LSA 的复杂度。

### 6.3 BGP

- AS 之间的路径向量协议，使用 TCP 建立会话。
- 重要属性：AS_PATH 防 AS 级环路，NEXT_HOP 指明下一跳，LOCAL_PREF/MED 等支持策略。
- eBGP 通告时通常更新 NEXT_HOP；iBGP 默认可能保留外部下一跳，工程中常用 next-hop-self。
- iBGP 学到的路由默认不再通告给其他 iBGP 邻居，因此传统设计需要全互联；实际网络可用路由反射器等机制扩展。

## 7. 多播与移动 IP

### 7.1 IP 多播

- 单播：源发送 N 份；多播：源发送一份，路由器在树的分叉处复制。
- IGMP 只管理本网段成员关系；路由器之间另用多播路由协议建立转发树。
- IPv4 多播地址映射以太网 MAC 时，只取后 23 位，因此是 32:1，必须在 IP 层二次过滤。

### 7.2 移动 IP

- 归属地址保持稳定，转交地址反映当前位置。
- 归属代理保存绑定并将发往归属地址的分组隧道到 COA。
- 经典三角路由：通信节点到移动节点绕经 HA，移动节点返回可直接走普通路由。

## 8. 网络层设备与二层设备

| 设备 | 层次 | 转发依据 | 冲突域 | 广播域 |
|---|---|---|---|---|
| Hub | 物理层 | 不识别地址，复制比特 | 所有端口共享 | 所有端口共享 |
| Switch | 数据链路层 | 目的 MAC/CAM 表 | 每端口一个 | 默认仍同一广播域 |
| Router | 网络层 | 目的 IP/FIB | 每接口隔离 | 每接口隔离 |

交换机通过源 MAC 自学习。未知单播、广播和特定多播会泛洪；已知单播只发往命中端口。分析综合题时，必须把前置 ARP 对交换表的学习效果计入时间线。

## 9. 校正与条件

> [!warning] “虚电路服务由网络层保证可靠”
> **校正**：虚电路说明连接状态与路径/标签映射，不自动等于可靠；可靠性要看具体协议是否提供确认、重传和差错恢复。

> [!warning] “路由表就是转发表”
> **校正**：408 简化模型可近似；真实实现中 RIB 保存候选路由，FIB 保存供高速查找的最优转发表项。

> [!warning] “路由器绝不转发任何广播”
> **校正**：普通二层广播帧不会跨三层接口；但定向广播、DHCP Relay、组播/任播等有独立机制，必须按题目配置判断。

> [!warning] “综合题中 H2 收到数据帧 A”
> **校正**：题设 ARP 缓存与交换表初始为空，所以数据发送前先进行 ARP。R2 的 ARP 应答已经让交换机学到 R2 端口，随后 A 左段为已知单播，H2 不收到；A 经过 Hub 的右段由 H3、H4 收到。

## 10. 绝对词检查

- **“一定按序”**：虚电路通常沿固定路径，但还要看丢失、复制与具体服务保证。
- **“必须分片”**：还要看 DF；IPv6 路由器不分片。
- **“广播地址可跨路由”**：受限广播不行，定向广播也常被禁用。
- **“NAT 就是网络层地址替换”**：NAPT 还修改端口和传输层校验和。
- **“收到帧”**：区分物理到达网卡、MAC 过滤后接收、上交网络层三个层次。
