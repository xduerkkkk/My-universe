## 三、算法套路（6 min）
**列表对比 + 手算步骤**：

### 3.1 置换算法性质表
| 算法 | 依据 | 栈算法？ | Belady异常？ | 实现成本 |
|------|------|---------|--------------|---------|
| FIFO | 最早进入 | 否 | 可能 | 低（队列） |
| LRU  | 最久未用 | 是 | 否 | 高（需硬件/精确时间戳） |
| OPT  | 最晚将来访问 | 是 | 否 | 理论最优（不可实现） |
| CLOCK | 访问位+循环扫描 | — | 近似LRU | 中等 |

### 3.2 手算步骤模板
- [ ] **FIFO**：画队列，先进先出，页框增多可能反而缺页更多（Belady异常）
- [ ] **LRU**：每次访问更新"最后使用时间"，淘汰时间戳最早的（或用栈模拟）
- [ ] **CLOCK**：  
  - 初始所有访问位=0，指针指向某位置  
  - 访问时访问位置1  
  - 淘汰时：循环扫描，访问位=1→置0并跳过，访问位=0→淘汰  
  - **不要写成"CLOCK = LRU的简化"**（它是近似，但不等价）

## 四、计算题检查清单（4 min）
写出计算步骤模板：
- [ ] 缺页率计算：  
  - 冷启动阶段：前N次（N=页框数）必定全缺页（若序列长度≥N）  
  - 稳态阶段：按算法逐步模拟，数缺页次数  
  - 缺页率 = 缺页次数 / 总访问次数
- [ ] 有效访问时间（EAT）：  
  EAT = (1 - p) × 内存访问时间 + p × (页故障处理时间 + 内存访问时间)  
  其中p = 缺页率，页故障处理时间包括（换出脏页时间 + 调入新页时间 + 更新页表时间）
- [ ] 页表项字段大小：  
  - 页框号位数 = ⌈log₂(物理页框数)⌉  
  - 控制位：有效位1bit + 修改位1bit + 访问位1bit + 保护位（读/写/执行，通常2-3bit）  
  - 页表项总大小 = (页框号位数 + 控制位数) / 8 Byte（向上取整到字节）

## 五、陷阱识别（2 min）
写出你二刷仍错的点：
- [ ] "页框增加→缺页一定减少"（错！只对栈算法成立，FIFO可能Belady异常）
- [ ] "CLOCK = LRU"（错！CLOCK是近似，用访问位模拟，不是精确时间戳）
- [ ] "工作集⊆驻留集"（不一定！驻留集覆盖工作集是理想目标，不是定义关系）
- [ ] "页缓冲队列能消除抖动"（不能！它只提供短期反悔，不解决工作集>内存的根因）
- [ ] "虚拟地址空间大小=磁盘大小"（错！主要由地址位数决定，磁盘限制的是后备容量）
