### 一、后缀表达式求值的考场快速跟踪

在 408 考场中，后缀表达式求值通常考两类：
1. **直接算结果**（给具体数值）；
2. **考操作数栈的状态或最大深度**（如“求值过程中栈内最多同时存在几个元素”）。

#### 实例演示
求后缀表达式：`6 2 3 + - 8 4 / *` 的值及计算过程中的栈深度。

#### 1. 考场草稿纸画法：表格追踪法（100% 杜绝左右操作数搞反）
规则：从左向右扫描，遇到数字入栈；遇到运算符弹出两个数，**次栈顶（先入）在左，栈顶（后入）在右**，算完结果压回栈。

| 扫描字符 | 动作 | 操作数栈内状态（底 $\to$ 顶） | 说明 / 运算式 |
| :---: | :---: | :---: | :---: |
| `6` | 压栈 | $[6]$ | |
| `2` | 压栈 | $[6, 2]$ | |
| `3` | 压栈 | $[6, 2, 3]$ | **此时栈深达到局部峰值 3** |
| `+` | 计算 | $[6, 5]$ | 弹出 3(右), 2(左) $\to 2 + 3 = 5$ 压栈 |
| `-` | 计算 | $[1]$ | 弹出 5(右), 6(左) $\to \mathbf{6 - 5 = 1}$ 压栈（绝不能算 $5-6$） |
| `8` | 压栈 | $[1, 8]$ | |
| `4` | 压栈 | $[1, 8, 4]$ | **栈深再次达到 3** |
| `/` | 计算 | $[1, 2]$ | 弹出 4(右), 8(左) $\to \mathbf{8 / 4 = 2}$ 压栈 |
| `*` | 计算 | $[2]$ | 弹出 2(右), 1(左) $\to 1 \times 2 = 2$ |

* **最终计算结果**：$2$
* **栈的最大深度**：$3$（考选择题直接看哪一步压入的连续操作数最多）。

#### 2. 如果只求最终结果（超快“消消乐法”，无需画栈）：
在草稿纸上**从左到右寻找第一个“数 数 符”结构**，算出结果替换原位置，反复进行：
$$\begin{aligned}
& 6\ \underline{2\ 3\ +}\ -\ 8\ 4\ /\ * \\
\implies & \underline{6\ 5\ -}\ 8\ 4\ /\ * \\
\implies & 1\ \underline{8\ 4\ /}\ * \\
\implies & \underline{1\ 2\ *}\ \implies \mathbf{2}
\end{aligned}$$

### 二、 有可能考前缀表达式求值吗？

**会考，但概率远低于后缀。** 
408 偏爱后缀（逆波兰式），因为现代计算机栈架构自左向右流水线处理最契合后缀。如果真考前缀（波兰式）求值，它考查的核心考点只有一个：**扫描方向相反，操作数弹出顺序相反**。

#### 前缀表达式求值的绝对规则（与后缀对比记忆）：

| 维度 | **后缀表达式求值** | **前缀表达式求值** |
| :--- | :--- | :--- |
| **扫描方向** | **从左向右** | **从右向左**（核心差异！） |
| **遇到操作数** | 压入栈 | 压入栈 |
| **遇到运算符** | 弹出两个数计算，结果压栈 | 弹出两个数计算，结果压栈 |
| **弹出操作数的次序** | **先出的是右操作数 $R$，后出的是左操作数 $L$** | **先出的是左操作数 $L$，后出的是右操作数 $R$** |
| **计算公式** | 恒为 **$L \text{ op } R$** | 恒为 **$L \text{ op } R$** |

#### 前缀求值实战验证：
上述中缀表达式为 `(6 - (2 + 3)) * (8 / 4)`，其对应的前缀表达式为：
`* - 6 + 2 3 / 8 4`

**按前缀计算机算法模拟（必须从右往左扫）**：
1. 从右往左读：
   * 读 `4`：压栈，栈为 $[4]$
   * 读 `8`：压栈，栈为 $[4, 8]$
   * 读 `/`：弹出两个数。
     * **先弹出的是左操作数 $L = 8$**，
     * **后弹出的是右操作数 $R = 4$**。
     * 算 $L / R = 8 / 4 = 2$。结果 $2$ 压栈，当前栈为 $[2]$。
   * 读 `3`：压栈，栈为 $[2, 3]$
   * 读 `2`：压栈，栈为 $[2, 3, 2]$
   * 读 `+`：弹出 $L = 2, R = 3 \implies 2 + 3 = 5$ 压栈，当前栈为 $[2, 5]$。
   * 读 `6`：压栈，当前栈为 $[2, 5, 6]$。
   * 读 `-`：弹出 $L = 6, R = 5 \implies 6 - 5 = 1$ 压栈，当前栈为 $[2, 1]$。
   * 读 `*`：弹出 $L = 1, R = 2 \implies 1 \times 2 = 2$。
2. 扫描结束，栈顶元素为 **2**，结果完全一致。

> **考场一句话避坑口诀**：
> 算**后缀**从**左**往右扫，先出的是**右**操作数；
> 算**前缀**从**右**往左扫，先出的是**左**操作数。
> 两个算法中，运算永远是：**左 操作符 右**。
