### 变式题一：磁盘旋转调度（加入“修改并写回”陷阱）

某磁盘每个磁道划分为 8 个物理块（扇区），顺时针依次编号为 $1, 2, \dots, 8$。磁盘转速为 $16\text{ ms/转}$。
现有一个包含 8 条逻辑记录（$L_1 \sim L_8$）的文件存放在同一磁道上，初始时按照物理块号顺序依次存放（即块 1 放 $L_1$，块 2 放 $L_2$，……，块 8 放 $L_8$）。
设初始时磁头恰好位于物理块 1 的起始处。现运行一个批处理程序，必须按逻辑顺序依次对 $L_1 \sim L_8$ 进行如下操作：
**「读出记录 $\to$ CPU 处理 $3\text{ ms}$ $\to$ 将修改后的记录写回原物理块」**。

请回答下列问题：
1）在初始顺序分布下，完成全部 8 条记录的“读-处理-写回”共需多少毫秒？
2）若只要求完成“读出记录 $\to$ CPU 处理 $3\text{ ms}$”（**不需要写回**），为了使处理完 8 条记录的总时间最短，请给出优化后的物理块 $1 \sim 8$ 中存放的逻辑记录序列，并计算优化后比优化前（不写回情况下）缩短了多少毫秒？

### 变式题二：PV 操作综合（双向流转 + 组合装配）

某自动化车间有一个容量为 $10$ 的综合缓冲区 `BUF`（同一时刻只允许一个进程访问 `BUF`）。
系统中有两类供料进程 $P_A, P_B$ 和两类装配进程 $C_1, C_2$（每类进程均有**多个**并发实例）：
- 供料进程 $P_A$：不断生产零件 A 并放入 `BUF`（每次放 1 个）。
- 供料进程 $P_B$：不断生产零件 B 并放入 `BUF`（每次放 1 个）。
- 装配进程 $C_1$：每次需要从 `BUF` 中取出 **2 个零件 A** 进行组装。
- 装配进程 $C_2$：每次需要从 `BUF` 中取出 **1 个零件 A 和 1 个零件 B** 进行组装。

**严苛限制条件**：
1. 任何装配进程必须等自己所需的全部零件在 `BUF` 中**凑齐后**，才能进入 `BUF` **一次性全部取走**（不允许先从 `BUF` 拿走 1 个拿在手里，再等另 1 个）。
2. 为了防止零件 A 塞满整個缓冲区导致零件 B 无法放入（从而导致 $C_2$ 饿死甚至死锁），规定 `BUF` 中存放的**零件 A 的数量在任何时刻不得超过 8 个**。

请回答：
1）这一题能否直接用“排队锁 + 连续 `wait(full_A)`”来解决？为什么？
2）定义所需的信号量及必要的整型状态变量（给出初值与含义），并用 `wait()`、`signal()` 写出 $P_A, P_B, C_1, C_2$ 的同步与互斥代码。

### 变式题三：文件系统访盘次数（字节偏移定位 + 修改写回 + FCB 合并陷阱）

某文件系统的盘块大小为 $1\text{ KB}$（$1024\text{ B}$），盘块号（磁盘地址）占 $4\text{ B}$。
目录文件的每个目录项占 $64\text{ B}$，其中**直接包含了文件控制块（FCB）的全部信息**（即找到目录项就拿到了 FCB，不再单独占盘块）。
目录文件若占多个盘块，采用**显式链接（FAT 以外的块内单向链表）**方式组织，**每个目录盘块的开头 $4\text{ B}$ 存放下一个目录盘块的块号**。

普通文件采用混合索引结构，其 FCB（已在目录项内）中包含：
- $8$ 个直接地址项；
- $1$ 个一级间接地址项；
- $1$ 个二级间接地址项。

假设当前内存中**除了根目录 `/` 的第 1 个盘块常驻内存外**，其余任何盘块（包括根目录的后续盘块、子目录块、索引块、数据块）每次访问均需从磁盘读入，每读或写 1 个盘块均需启动磁盘 1 次。
已知：根目录 `/` 共有 $20$ 个目录项；子目录 `/usr` 共有 $50$ 个目录项。

请回答下列问题：
1）普通文件的最大长度是多少字节？（用 $B/KB/MB/GB$ 的精确累加式或具体数值表示均可）
2）现要将文件 `/usr/bin` 中**字节偏移量为 $10000\text{ B}$**（偏移量从 $0$ 开始计数）处的 1 个字节内容修改为 `'X'` 并落盘保存。完成该操作**最少**和**最多**各需启动磁盘多少次？

## 【标准答案与防坑解析】

### 变式题一解析：

#### 1. 基础参数提取：
*   磁道共 8 块，转一圈 $16\text{ ms} \implies$ 扫过 1 个物理块耗时 $= \frac{16\text{ ms}}{8} = 2\text{ ms}$。
*   处理时间 $3\text{ ms}$。

#### 2. 第 (1) 问解答（读 - 处理 - 写回原块）：
这是一个极具迷惑性的经典坑！我们跟踪 $L_1$（在块 1）：
1.  **读出 $L_1$**：磁头从块 1 起始处扫过块 1，耗时 $2\text{ ms}$，此时磁头到达**块 2 起始处**。
2.  **处理 $L_1$**：耗时 $3\text{ ms}$（磁头滑过 $1.5$ 个块，到达**块 3 的正中间**）。
3.  **写回 $L_1$（必须写回块 1！）**：必须等磁头重新转回**块 1 的起始处**才能开始写！
    从“块 3 正中间”转到“块 1 起始处”，需要滑过 $5.5$ 个块（耗时 $5.5 \times 2 = 11\text{ ms}$）。
    *(或者更简单的算法：从开始读块 1，到再一次回到块 1 起始处，刚好是整整一圈 $16\text{ ms}$！因为读 $2\text{ ms} +$ 处理 $3\text{ ms} = 5\text{ ms} < 16\text{ ms}$，所以处理完等磁头回到块 1 起始处，总计就是刚好转了 1 圈 $= 16\text{ ms}$！)*
4.  **执行写块 1**：当磁头在 $16\text{ ms}$ 时刻回到块 1 起始处时，开始写入 $L_1$，耗时 $2\text{ ms}$。
5.  **写完时的惊喜发现**：写完块 1 的瞬间（第 $18\text{ ms}$），磁头恰好位于**块 2 的起始处**！而下一条要读的记录 $L_2$ **正好就在块 2**！
    这意味着：**从写完 $L_1$ 切换到读 $L_2$ 的等待时间为 $0\text{ ms}$！**
6.  **总时间计算**：
    每一条记录的周期完全相同，且无缝衔接：
    每条记录耗时 $= \text{转一圈回到原块起始处}(16\text{ ms}) + \text{写入原块}(2\text{ ms}) = 18\text{ ms}$。
    8 条记录总时间 $= 8 \times 18\text{ ms} = \mathbf{144\text{ ms}}$。

#### 3. 第 (2) 问解答（不写回，只读+处理）：
1.  读 $L_1$ 耗时 $2\text{ ms}$（到块 2 起始处），处理 $3\text{ ms}$（滑过 $1.5$ 块，到达**块 3 的正中间**）。
2.  由于磁头在块 3 的中间，无法从中间开始读块 3，最早能读的完整块是**块 4**（再等半个块，即 $1\text{ ms}$ 即可到达块 4 起始处）。
3.  因此，每次读完并处理完一条记录，最快只能在 **每隔 3 个块（跨度为 $+3$）** 的位置放下一条记录！
    - $L_1$ 放 **块 1**
    - $L_2$ 放 $1 + 3 =$ **块 4**
    - $L_3$ 放 $4 + 3 =$ **块 7**
    - $L_4$ 放 $(7 + 3) \pmod 8 =$ **块 2**
    - $L_5$ 放 $2 + 3 =$ **块 5**
    - $L_6$ 放 $5 + 3 =$ **块 8**
    - $L_7$ 放 $(8 + 3) \pmod 8 =$ **块 3**
    - $L_8$ 放 $3 + 3 =$ **块 6**
    所以优化后的物理块 $1 \sim 8$ 存放序列为：**$L_1, L_4, L_7, L_2, L_5, L_8, L_3, L_6$**。
4.  **计算缩短的时间**（直接用秒杀法算等待时间之差）：
    - **优化前（顺序放）**：读完块 1（$2\text{ ms}$）+ 处理（$3\text{ ms}$）在块 3 中间，要等磁头转回块 2 起始处，一圈 $16\text{ ms} +$ 1 个块偏移 $2\text{ ms} = 18\text{ ms}$ 一个周期（其中包含 $2\text{ ms}$ 读 + $3\text{ ms}$ 处理 + **$13\text{ ms}$ 等待**）。
    - **优化后**：读（$2\text{ ms}$）+ 处理（$3\text{ ms}$）后，只需等半个块（**$1\text{ ms}$ 等待**）就能读下一块。
    - 每次切换节省等待时间 $= 13\text{ ms} - 1\text{ ms} = 12\text{ ms}$。
    - 8 条记录共切换 **7 次**，缩短时间 $= 7 \times 12\text{ ms} = \mathbf{84\text{ ms}}$。

### 变式题二解析：

#### 1）能否用排队锁 + 连续 `wait`？
**绝对不能！**
因为 $C_1$ 要 `AA`，$C_2$ 要 `AB`，两类进程所需的**资源种类不同且有交集（都包含 A）**。
如果 $C_1$ 抢到排队锁，拿走 1 个 A 后阻塞等待第 2 个 A，而此时缓冲区里有 1 个 A 和 9 个 B（缓冲区已满），原本 $C_2$ 可以拿走 1 个 A 和 1 个 B 腾出空间的，却被 $C_1$ 堵死，且 $P_A$ 也无法再放入 A，系统立即**死锁**。

#### 2）信号量定义与代码实现（状态变量 + 条件唤醒法）

```c
semaphore mutex = 1;       // 互斥访问缓冲区 BUF 及状态变量，初值为 1
semaphore empty = 10;      // BUF 的总空位数，初值为 10
semaphore limit_A = 8;     // 限制 BUF 中零件 A 最多不超过 8 个，初值为 8
semaphore avail_C1 = 0;    // C1（需2个A）的同步唤醒信号量，初值为 0
semaphore avail_C2 = 0;    // C2（需1A+1B）的同步唤醒信号量，初值为 0
int countA = 0, countB = 0;// 当前 BUF 中零件 A 和零件 B 的实际个数
```
codeC

```c
PA() {
    while (1) {
        生产 1 个零件 A;
        wait(limit_A);
        wait(empty);
        wait(mutex);
        将零件 A 放入 BUF;
        countA++;
        // 重点：一旦决定唤醒某人，当场把给他的零件从 count 中扣掉（代表已被预定）！
        if (countA >= 2) {
            countA -= 2;       // 这 2 个 A 已经拨给 C1 了，后续进程不准再算它们！
            signal(avail_C1);
        } else if (countA >= 1 && countB >= 1) {
            countA--;          // 这 1A+1B 已经拨给 C2 了，后续进程不准再算它们！
            countB--;
            signal(avail_C2);
        }
        signal(mutex);
    }
}

PB() {
    while (1) {
        生产 1 个零件 B;
        wait(empty);
        wait(mutex);
        将零件 B 放入 BUF;
        countB++;
        if (countA >= 1 && countB >= 1) {
            countA--;          // 当场预扣除 1A + 1B
            countB--;
            signal(avail_C2);
        }
        signal(mutex);
    }
}
```

### 变式题三解析：

#### 第 (1) 问：普通文件的最大长度
1.  每个索引块可存盘块号个数 $= \frac{1024\text{ B}}{4\text{ B}} = 256 = 2^8$ 个。
2.  最大数据块总数 $= 8 + 2^8 + (2^8)^2 = 8 + 256 + 65536 = 65800$ 块。
3.  **注意题目问的是“多少字节（最大长度）”，必须乘以盘块大小 $1\text{ KB}$**！
    最大长度 $= (8 + 2^8 + 2^{16}) \times 1\text{ KB} = 8\text{ KB} + 256\text{ KB} + 64\text{ MB} = \mathbf{65800\text{ KB}}$（或写 $67379200\text{ B}$）。

#### 第 (2) 问：修改 `/usr/bin` 偏移量 $10000\text{ B}$ 处并落盘的访盘次数
这里有 **4 个连环陷阱**，看看你避开了几个：

*   **陷阱 1：每个目录盘块能放几个目录项？**
    盘块大小 $1024\text{ B}$，开头留 $4\text{ B}$ 放指针，剩余 $1020\text{ B}$。
    每个目录项 $64\text{ B}$，每块可放目录项数 $= \left\lfloor \frac{1020}{64} \right\rfloor = \lfloor 15.9375 \rfloor = \mathbf{15\text{ 个}}$！（绝不是 $\frac{1024}{64} = 16$ 个！）
    - **根目录 `/`（共 20 项）**：占 $\lceil \frac{20}{15} \rceil = \mathbf{2\text{ 个盘块}}$（第 1 块 15 项，第 2 块 5 项）。题目说**只有根目录的第 1 个盘块常驻内存**！所以查根目录找 `usr`，最好情况在第 1 块（**0 次**访盘），最坏情况在第 2 块（需读入根目录第 2 块，**1 次**访盘）！
    - **子目录 `/usr`（共 50 项）**：占 $\lceil \frac{50}{15} \rceil = \mathbf{4\text{ 个盘块}}$（$15+15+15+5$）。查 `/usr` 找 `bin`，最好情况在第 1 块（**1 次**访盘），最坏情况在第 4 块（链式结构依次读 4 块，**4 次**访盘）。

*   **陷阱 2：还要单独读 FCB 吗？**
    题目明确说明：“每个目录项直接包含了 FCB 的全部信息”。所以读出 `bin` 所在的目录盘块时，**FCB 已经在内存里了，读 FCB 耗时 0 次**！

*   **陷阱 3：字节偏移量 $10000\text{ B}$ 在哪个索引级别？（定死的值，不分最好最坏！）**
    偏移量从 $0$ 开始，盘块大小 $1024\text{ B}$。
    偏移量 $10000\text{ B}$ 所在的逻辑块号 $= \left\lfloor \frac{10000}{1024} \right\rfloor = \mathbf{9\text{ 号逻辑块}}$（即文件的第 **10** 个数据块，因为 $0 \sim 9$ 共 10 块）。
    FCB 中只有 **前 8 个（$0 \sim 7$ 号块）是直接地址**！
    所以第 $9$ 号块**必定落在一级间接地址中**！
    因此，定位该数据块的过程是**固定不变**的：
    读一级索引块（**1 次**） $+$ 读第 9 号目标数据块（**1 次**） $= \mathbf{2\text{ 次}}$。

*   **陷阱 4：题目要求“修改为 `'X'` 并落盘保存”！**
    修改内存中的数据块后，必须将该数据块**写回磁盘**，这需要额外启动磁盘 **1 次**！（因为只是改了 1 个字节的内容，文件大小没变，FCB 和索引块都没变，只需写回这 1 个数据块）。

#### 汇总计算：
*   **【最少】启动磁盘次数**：
    查 `/` 第 1 块 ($0$) $+$ 查 `/usr` 第 1 块 ($1$) $+$ 读一级索引块 ($1$) $+$ 读目标数据块 ($1$) $+$ 写回目标数据块 ($1$) $= \mathbf{4\text{ 次}}$。
*   **【最多】启动磁盘次数**：
    查 `/` 第 2 块 ($1$) $+$ 查 `/usr` 第 4 块 ($4$) $+$ 读一级索引块 ($1$) $+$ 读目标数据块 ($1$) $+$ 写回目标数据块 ($1$) $= \mathbf{8\text{ 次}}$。
