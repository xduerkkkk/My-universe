#### **3. 下列指令中，有语法错误的是（ C ）。**
*   **考点**：汇编指令的“数据宽度”必须明确。
*   **解析**：
    *   A. `MOV [SI], AL`：源操作数 `AL` 是 8 位，所以 CPU 知道要往内存里写 1 个字节。**对。**
    *   B. `IN AL, DX`：标准 IO 指令。**对。**
    *   D. `MOV AX, [1200]`：目的操作数 `AX` 是 16 位，CPU 知道要读 2 个字节。**对。**
    *   **C. `MOV [BX+ST], 78`**：
        *   `78` 是立即数，既可以当 8 位看，也可以当 16 位看。
        *   `[BX+ST]` 是内存地址，也没说是字节单元还是字单元。
        *   **CPU 懵了**：“老板，你到底让我搬 1 个字节还是 2 个字节？”
        *   **修正**：必须写成 `MOV BYTE PTR [BX+ST], 78` 或者 `MOV WORD PTR ...`。
*   **警示**：以后写程序，如果两个操作数里没有寄存器（只有内存和立即数），一定要加 `PTR` 修饰符！

#### **5. 下列寻址方式中，段前缀不可省略的是（ B ）。**
*   **考点**：默认段规则（Segment Default）。**这是你之前问过但我没细讲的盲区！**
*   **规则复习**：
    *   **BP** (Base Pointer) 做基址时，默认段是 **SS** (堆栈段)。
    *   **BX, SI, DI** 做基址时，默认段是 **DS** (数据段)。
*   **解析**：
    *   A. `DS:[BX+ST]`：BX 默认就是 DS，写不写都一样。可省略。
    *   C. `SS:[BP]`：BP 默认就是 SS，写不写都一样。可省略。
    *   D. `DS:[DI]`：DI 默认就是 DS。可省略。
    *   **B. `DS:[BP+ST]`**：
        *   用了 `BP`，CPU 本能地想去 SS 段找数据。
        *   但你强制写了 `DS:`（段跨越前缀），告诉 CPU：“别去堆栈段，去数据段找！”
        *   这时候前缀**绝对不能省**，省了就跑偏到 SS 去了。

#### **7. 中断向量计算（0000H:003CH 单元...）（ C ）**
*   **考点**：类型号逆推 + 小端模式。**刚才刚练过，检验成果的时候到了！**
*   **步骤 1：算类型号**
    *   地址 `003CH`。
    *   类型号 = $3CH / 4 = \text{?}$
    *   $3CH = 3 \times 16 + 12 = 60$。$60 / 4 = 15 = 0FH$。
    *   或者直接 hex 除法：$3C / 4 = 0F$。
    *   **类型号是 0FH**。
*   **步骤 2：读向量（小端模式）**
    *   内存里依次是：`34H` (低), `FEH` (高), `00H` (低), `F0H` (高)。
    *   **IP** (前两字节) = `FE34H`。
    *   **CS** (后两字节) = `F000H`。
    *   入口地址 = `F000:FE34H`。
*   **答案**：C。

#### **9. X 的 8 位补码是 10110100，则 X 的 16 位补码是（ C ）。**
*   **考点**：符号扩展（Sign Extension）。**计组/微机通用考点。**
*   **原理**：
    *   把一个“窄”的有符号数变“宽”，**高位必须填符号位**（即最高位）。
    *   正数（最高位0）：前面全补 0。
    *   负数（最高位1）：前面全补 1。
*   **解析**：
    *   `10110100` 最高位是 **1**。
    *   扩展到 16 位，前面 8 位都要补 **1**。
    *   结果：`11111111 10110100`。
*   **答案**：C。
*   **指令关联**：汇编里的 `CBW` (Convert Byte to Word) 和 `CWD` 指令就是干这个的。

### 第二组：概念盲区（第 12、13 题）

这两题是你之前没遇到过的知识点。

#### **12. 对于以下各种中断，只有（ D ）需要硬件提供中断类型码。**
*   **考点**：中断向量的来源。
*   **解析**：
    *   A. `INTO`：溢出中断，固定类型号 4。CPU 内部产生的。
    *   B. `INT n`：指令里直接写了 $n$，CPU 自己知道。
    *   C. `NMI`：非屏蔽中断，固定类型号 2。硬件引脚决定，不需要外部给号。
    *   **D. `INTR`**：可屏蔽中断。
        *   CPU 收到 INTR 信号后，一脸懵逼：“谁找我？”
        *   必须由 **8259A**（硬件）通过数据总线把类型号送过来，CPU 才知道去哪查表。
*   **结论**：只有 INTR 需要外部硬件“喂”号码。

#### **13. 与 SRAM 相比，下面哪一个不是 DRAM 的特点（ C ）。**
*   **考点**：存储器原理（SRAM vs DRAM）。
*   **解析**：
    *   **SRAM (Static)**：
        *   用触发器存数据。
        *   **优点**：速度快，不用刷新。
        *   **缺点**：集成度低（一个bit要6个管子），贵，功耗大。
        *   *用途*：Cache。
    *   **DRAM (Dynamic)**：
        *   用电容存数据。
        *   **缺点**：电容会漏电，**必须定时刷新**（Refresh）。速度慢。
        *   **优点**：集成度高（一个bit只要1个管子），便宜。
        *   *用途*：内存条。
*   **答案**：C（“不需要刷新”是错的）。

#### **6. 连续执行 PUSH AX 和 POP BX 相当于执行（ A ）**

### 关于 8253 初值与读写格式的追问

1.  **“必须分两次写（11）”，其他情况呢？**
    *   **情况 A (01)**：只读写低 8 位。
        *   适用：初值 $N < 256$（例如 $N=100$）。
        *   代码：`MOV AL, 100` -> `OUT`。一次搞定。
    *   **情况 B (10)**：只读写高 8 位。
        *   适用：初值是 256 的倍数（例如 $N=512 = 0200H$）。低位默认为 0，只写高位 `02H`。
    *   **情况 C (11)**：先低后高。
        *   适用：绝大多数情况（$N > 255$ 且低位不为 0）。例如 $N=1000$ (`03E8H`)。
    *   **做题策略**：除非 $N$ 特别小，**默认都选 11**，最保险。

2.  **单位怎么能直接乘？**
    *   公式：$N = \text{时间} \times \text{频率}$
    *   **单位换算铁律**：
        *   秒 (s) $\times$ 赫兹 (Hz) = 1
        *   毫秒 (ms) $\times$ 千赫 (KHz) = 1
        *   **微秒 (us) $\times$ 兆赫 (MHz) = 1**
    *   **本题**：$5\text{ms} \times 1\text{MHz}$。
        *   把 ms 换成 us：$5\text{ms} = 5000\text{us}$。
        *   $5000\text{us} \times 1\text{MHz} = 5000$。
        *   *或者*：把 MHz 换成 Hz，ms 换成 s。
        *   $0.005\text{s} \times 1,000,000\text{Hz} = 5000$。
    *   **速算技巧**：$1\text{MHz}$ 就是 **1微秒数一下**。你要数多久？5毫秒（5000微秒）。那就数 5000 下呗。

### 程序分析题 1：ASCII 码转换

**逻辑分析**：
```assembly
CVT:
    CMP AL, 30H
    JC  L1          ; 如果 AL < 30H (比如 '0'的前面)，跳 L1 (ERROR)
    
    CMP AL, 3AH
    JNC L1          ; 如果 AL >= 3AH (比如 '9'的后面)，跳 L1 (ERROR)
                    ; 结论：只有当 30H <= AL <= 39H 时，继续向下。
                    ; 也就是 AL 是字符 '0'~'9'。

    AND AL, 0FH     ; 保留低4位。
                    ; '0'(30H) -> 00H
                    ; '9'(39H) -> 09H
                    ; 功能：把 ASCII 码转成数字。
    JMP L2          ; 结束

L1: MOV AL, 0FFH    ; 报错标志
L2: RET
```

**问题解答**：
1.  **初值 34H**：
    *   `30H <= 34H < 3AH`。符合范围。
    *   `34H AND 0FH` = **04H**。
    *   **结果**：`AL=04H`。
2.  **初值 8AH**：
    *   `8AH >= 3AH`。跳转 L1。
    *   **结果**：`AL=FFH`。
3.  **最多多少种结果？功能？**
    *   **结果种类**：
        *   数字 0-9 对应结果 `00H`~`09H`（10种）。
        *   非法字符对应结果 `FFH`（1种）。
        *   共 **11种**。
    *   **功能**：**将数字字符 ('0'-'9') 转换为对应的数值 (0-9)；若非数字字符，则返回错误码 FFH。**

**做题技巧**：
1.  **DW 存标号**：存的是标号的 **偏移地址**。
2.  **DD 存标号**：存的是 **偏移地址 + 段地址**。
3.  **EQU**：只是替换符号，不占内存，但在 `DW` 引用时会把值放进去。
