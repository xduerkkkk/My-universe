### 一、为什么 8086 步长是 2？（总线的真相）

**你的疑惑**：*“什么是总线？你不是都说了这俩款CPU都是16根地址线吗？”*

**真相**：
问题不在 **地址线 (Address Bus)**，而在 **数据线 (Data Bus)**！

1.  **什么叫总线？**
    *   **地址线**：告诉大家“我去哪里搬砖”。（8086/8088 I/O 都是 A0-A15，16根）。
    *   **数据线**：**用来搬砖的车道宽度**。这是两者的核心区别！

2.  **8088（窄车道）**：
    *   数据线只有 **8根 (D0-D7)**。
    *   就像一条单车道。
    *   CPU 访问内存/接口时，字节是**挨个排队**的。地址 0, 1, 2, 3... 顺次排列。
    *   8255（8位芯片）接上去，CPU $A_0$ 连芯片 $A_0$。
    *   **结果**：地址是连续的（220H, 221H...）。

3.  **8086（宽车道）**：
    *   数据线有 **16根 (D0-D15)**。
    *   就像一条双车道。为了快，它把**偶数地址**的数据放在 **低8位 (D0-D7)**，**奇数地址**的数据放在 **高8位 (D8-D15)**。
    *   **关键冲突**：8255 是个 **8位芯片**，它只有 8 根数据脚。
    *   **接法**：通常把 8255 接在 **低8位 (D0-D7)** 车道上。
    *   **后果**：因为低8位车道只走 **偶数地址**（0, 2, 4...）。所以 CPU 只能用偶数地址去访问它！
    *   **物理连接**：为了配合这种跳跃，必须错位连接（CPU $A_1$ 连芯片 $A_0$）。
    *   **结果**：地址步长变成 2（220H, 222H, 224H...）。

**结论**：以后做题，看到 **8088** 就按连续地址算；看到 **8086** 就要警惕是不是步长为 2。

### 二、端口命名与位序（D7 vs D0）

**1. 端口为什么这么命名？**
这是一个二进制的约定，没有任何深奥的玄学：
*   **00** (0) -> **A口** (老大)
*   **01** (1) -> **B口** (老二)
*   **10** (2) -> **C口** (老三)
*   **11** (3) -> **控制口** (管事的)
*   *知识点*：就是 $A_1, A_0$ 的真值表。

**2. 那个 1 字节的数，到底怎么写？**
**你的疑惑**：*8255从D7开始分析，那写的时候第一个bit是D7还是D0？*

**铁律**：**书写二进制数时，永远是从左到右，对应 D7 到 D0。**

*   **例子**：我们要写 8255 控制字。
    *   你分析逻辑时：先看 D7=1，再看 D0=...
    *   **但是写在纸上时**：
        `D7 D6 D5 D4 D3 D2 D1 D0`
        `1  0  0  0  1  0  0  1`
    *   **转十六进制**：`1000` -> **8**, `1001` -> **9**。
    *   **代码**：`MOV AL, 89H`。

**为什么感觉 8255 从 D7 分析？**
因为 D7 是**大分类开关**（决定是配置模式还是位操作），如果不看 D7，后面的 D6-D0 就没法解读。
**为什么感觉 8253 从 D0 分析？**
其实也是错觉。通常我们习惯从功能块分析（先看方式，再看读写），但写在纸上依然是 D7...D0。

### 三、核心代码“背诵版”总结

结合最后两道大题，这两段代码是微机原理的 **“万能模板”**，请务必背熟。

#### 1. 8255A 模板（初始化 + 查表输出）
**场景**：PA接灯(输出)，PB接开关(输入)。
**步骤**：算控制字 -> 写控制字 -> 读开关 -> 逻辑判断 -> 写灯。

```assembly
; --- 1. 初始化 (必写) ---
MOV DX, 控制口地址   ; 例如 223H
MOV AL, 控制字       ; 例如 82H (1-00-0-0-0-1-0: D7=1, A出, B入)
OUT DX, AL          ; 写入控制口

; --- 2. 读数据 (输入) ---
MOV DX, PB口地址     ; 例如 221H (B口)
IN  AL, DX          ; 读入开关状态到 AL

; --- 3. 处理逻辑 (可选) ---
AND AL, 0FH         ; 比如只保留低4位
CMP AL, 03H         ; 比如判断是不是等于 3
JNZ 某处             ; 不相等就跳走

; --- 4. 写数据 (输出) ---
MOV DX, PA口地址     ; 例如 220H (A口)
MOV AL, 数据         ; 比如 3FH (数字0的字形码)
OUT DX, AL          ; 点亮灯
```

#### 2. 8253 模板（初始化 + 写初值）
**场景**：通道0输出方波。
**步骤**：算控制字 -> 写控制字 -> 算初值 -> 写低8位 -> 写高8位。

```assembly
; --- 1. 写控制字 (定规矩) ---
MOV DX, 控制口地址   ; 例如 3F6H
; 格式: 通道(2位) 读写(2位) 方式(3位) 码制(1位)
; 例如: 00(通道0) 11(先低后高) 011(方式3方波) 0(二进制)
MOV AL, 36H         ; 0011 0110B
OUT DX, AL

; --- 2. 写初值 (定时间) ---
MOV DX, 数据口0地址  ; 例如 3F0H
MOV AX, 1000        ; 假设初值是 1000 (分频系数)

; 8253 只能一次吃 8 位，所以要喂两次
OUT DX, AL          ; 先喂低 8 位 (AL)
MOV AL, AH          ; 把高 8 位拿过来
OUT DX, AL          ; 再喂高 8 位 (AH)
```

**最后一句叮嘱**：
考试时，如果指令写错了（比如 `MOV` 写成 `MV`）通常扣分很少；但如果 **端口地址写错**（比如把数据发到了控制口），或者 **初值算错**，扣分会比较重。**一定要保证 DX 里的地址是对的！**

### **核心一：8253 长什么样？（PPT 第4-5页）**

想象 8253 是一个 **“倒计时闹钟集合”**。

1.  **三个通道**：它肚子里有 3 个独立的闹钟，叫 **计数器0, 1, 2**。
    *   每个闹钟都有 3 根线：
        *   **CLK (Clock)**：**心跳输入**。外面的时钟脉冲（比如 1MHz），每跳一下，闹钟就减 1。
        *   **GATE (门控)**：**开关**。高电平（开门）才让计数，低电平（关门）就暂停。
        *   **OUT (输出)**：**闹铃**。计数减到 0 了，这个引脚就变电平（或者输出波形）。

2.  **端口地址**：
    *   它有 4 个端口地址（比如 300H ~ 303H）：
        *   300H：找计数器 0。
        *   301H：找计数器 1。
        *   302H：找计数器 2。
        *   303H：**控制口**（这是发号施令的地方）。

---

### **核心二：怎么给它下命令？（控制字 - PPT 第7-8页）**

这是做题的**第一步**，必须会写“控制字”。
控制字是一个 **8位** 的二进制数，格式如下（死记硬背）：

| 高2位 (D7,D6)                      | 次2位 (D5,D4)                                    | 中3位 (D3,D2,D1)                          | 最低位 (D0)                    |
| :------------------------------- | :--------------------------------------------- | :-------------------------------------- | :-------------------------- |
| **选哪个闹钟？**                       | **怎么读/写？**                                     | **用哪种工作方式？**                            | **用二进制还是BCD？**              |
| 00: 计数器0<br>01: 计数器1<br>10: 计数器2 | **11: 先低后高** (最常用)<br>01: 只读写低8位<br>10: 只读写高8位 | 000: 方式0<br>010: 方式2<br>011: 方式3<br>... | **0: 二进制** (最常用)<br>1: BCD码 |

*   **例题**：我要用 **计数器0**，**先低后高**读写，工作在 **方式3**（方波），用 **二进制** 计数。
    *   **控制字**：`00` (选0) `11` (先低后高) `011` (方式3) `0` (二进制)
    *   **结果**：`0011 0110 B` = **`36H`**。
    *   **代码**：`MOV AL, 36H` -> `OUT 控制口, AL`。

---

### **核心三：6 种工作方式，重点看哪几个？（PPT 第9-26页）**

虽然有 6 种，但考试 90% 只考下面这 3 种：

1.  **方式 0 —— 计数结束中断 (PPT P9)**
    *   **人话**：**单次倒计时**。
    *   **动作**：
        1.  设个初值 N（比如 100）。
        2.  `OUT` 变低电平。
        3.  开始倒数：99, 98...
        4.  数到 0，`OUT` **变高电平**（一直高下去）。
    *   **用途**：产生中断信号。

2.  **方式 2 —— 分频器 (PPT P16)**
    *   **人话**：**打点器**（输出窄脉冲）。
    *   **动作**：数到 0，`OUT` 输出一个**短暂的低脉冲**，然后**自动重装初值**，重新倒数。
    *   **用途**：产生固定频率的脉冲（如 1秒钟跳一下）。

3.  **方式 3 —— 方波发生器 (PPT P19)**
    *   **人话**：**对称方波**。
    *   **动作**：前半段时间输出高，后半段时间输出低。**自动循环**。
    *   **用途**：产生声音、波形、驱动电机。

---

### **核心四：初值怎么算？（小学数学题）**

这也是做题必考。
> **初值 N = 输入频率 / 输出频率**

*   **例题**：输入时钟 CLK 是 **1MHz** ($10^6$ Hz)，我想让它产生 **1000Hz** 的方波。初值 N 是多少？
*   **计算**：$N = 1,000,000 / 1,000 = 1000$。
*   **代码**：把 1000 写进计数器。

---

### **总结：解题三部曲**

以后看到 8253 的题目，按这个套路走：

1.  **算初值**：$N = f_{in} / f_{out}$。
2.  **定方式**：
    *   要中断？选 **方式0**。
    *   要脉冲？选 **方式2**。
    *   要方波？选 **方式3**。
3.  **写代码**：
    *   先发 **控制字**（告诉它选哪个通道、哪种方式）。
    *   再发 **初值**（分两次发，先低8位，后高8位）。

搞懂了这个逻辑，再去读那几道作业题，你就会发现它们其实都在问这三件事。

# ch10
这份PDF的内容不是模数/数模转换，而是 **微机原理的核心重点——并行接口芯片 8255A**。

这一章在期末考试中通常占 **15-20分**（一道大题 + 填空/选择），在考研（计组/微机自命题）中也是**I/O接口设计的必考内容**。

8255A 的逻辑非常清晰，我把它拆解为 **4个核心考点**，你按照这个逻辑去记忆，效率最高。

---

### 考点一：内部结构与寻址（死记硬背）
**（对应PDF P4-5）**

这是做题的第一步，必须识别CPU在操作8255的哪个端口。

1.  **3个数据端口 + 1个控制端口**：
    *   **A口**：功能最强（PA0-PA7），支持全部3种方式（0, 1, 2）。
    *   **B口**：次强（PB0-PB7），支持方式0和1。
    *   **C口**：打杂的（PC0-PC7），可分为高4位和低4位。**在方式0下作数据口，在方式1/2下作联络信号线（状态线/控制线）。**
2.  **寻址逻辑（必背表）**：
    通过 `CS#`（片选，决定基地址）和 `A1, A0`（片内偏移）来选中。


| A1 | A0 | 选中端口 |
| :--- | :--- | :--- |
| 0 | 0 | **A口** |
| 0 | 1 | **B口** |
| 1 | 0 | **C口** |
| 1 | 1 | **控制口** (写控制字用) |

> **考研/期末 结合点**：
> 题目通常会给一个基地址（比如PDF P20的 `280H`），问你控制口的地址是多少？
> 答：基地址+3。即 `283H`。

---

### 考点二：控制字（重中之重）
**（对应PDF P9-10）**

8255A有两个控制字，**很容易混淆**，这是最容易扣分的地方。必须看 **D7位** 是0还是1。

#### 1. 方式选择控制字（D7=1）
这是用来**初始化**芯片的。
*   **格式**：`1 [A组方式] [PA输/出] [PC高输/出] [B组方式] [PB输/出] [PC低输/出]`
*   **助记口诀**：
    *   **D7必须是1**。
    *   **1是输入（Input），0是输出（Output）**。（想象 I 像 1，O 像 0）。
    *   **A组**包含：A口 + C口高4位。
    *   **B组**包含：B口 + C口低4位。

#### 2. C口置位/复位控制字（D7=0）
这是用来**单独控制C口的某一位**输出高低电平的。
*   **用途**：主要用于生成中断屏蔽位（INTE），或者用C口模拟开关控制。
*   **格式**：`0 X X X [D3-D1位选择] [D0置1/清0]`
*   **注意**：这个字必须写入**控制口**（地址A1A0=11），而不是写入C口数据口！

---

### 考点三：三种工作方式（理解核心）
**（对应PDF P11-19）**

*   **方式0（基本I/O）**：
    *   **特点**：**无握手信号**，单纯的数据进出。
    *   **场景**：接LED灯、接开关。（PDF P22-27的例子全是方式0）。
    *   **考法**：最简单，考代码编写。

*   **方式1（选通I/O，即握手）—— 难点！**
    *   **特点**：使用C口的线做**联络信号**（Strobe, ACK, Intra等）。
    *   **考研/计组 深度结合点**：
        *   **输入握手**：外设送来 `STB#` (选通)，8255回一个 `IBF` (Input Buffer Full, 缓冲满)。
        *   **输出握手**：CPU写数据，8255发 `OBF#` (Output Buffer Full)，外设取走后回 `ACK#`。
        *   **中断**：方式1支持中断，需要通过C口置位字设置 `INTE` (中断允许位) 为1。

*   **方式2（双向总线）**：
    *   只有 **A口** 能用。既能输也能出（如连接硬盘接口）。期末考试极少考方式2的具体连线，知道概念即可。

---

### 考点四：硬件设计与编程模板（大题通解）
**（对应PDF P20-27）**

考试大题通常是：**画图 + 初始化代码 + 读写代码**。

#### 1. 典型编程步骤（背下来）：
1.  **计算地址**：根据译码电路算出A、B、C、控制口的端口号。
2.  **写方式控制字**：
    *   分析题意：A口是入还是出？B口？C口？
    *   拼凑8位二进制数（D7=1...），算出十六进制。
    *   `MOV DX, 控制口地址` -> `MOV AL, 控制字` -> `OUT DX, AL`。
3.  **读写数据**：
    *   读数据（如读开关）：`MOV DX, A口地址` -> `IN AL, DX`。
    *   写数据（如点灯）：`MOV DX, B口地址` -> `MOV AL, 数据` -> `OUT DX, AL`。

#### 2. 实例解析（基于PDF P22）
题目：PA口接LED（输出），PB口接开关（输入）。地址280H-283H。
*   **分析**：PA输出=0，PB输入=1，方式0。
*   **控制字**：`1` (标志) `00` (方式0) `0` (PA出) `0` (PC高出) `0` (方式0) `1` (PB入) `0` (PC低出) = `1000 0010 B` = **82H**。
*   **核心代码**：
    ```assembly
    MOV DX, 283H   ; 控制口地址
    MOV AL, 82H    ; 方式控制字
    OUT DX, AL     ; 写入
    
    ; 读开关并送灯
    MOV DX, 281H   ; B口(开关)
    IN  AL, DX     ; 读入
    MOV DX, 280H   ; A口(灯)
    OUT DX, AL     ; 输出
    ```

    *   **统一编址 vs 独立编址**：8255在x86体系下用 `IN/OUT` 指令，属于**独立编址**（I/O映射）。如果是在ARM或MIPS下，通常是**统一编址**（内存映射），用 `MOV` 指令。这是计组考点。
    *   **中断机制**：8255的 `INTR` 引脚通常连到 `8259` 中断控制器上。复习到下一章（中断）时，要回过头来想：8255怎么产生中断信号？（答案：在方式1下，当数据准备好时，IBF/OBF有效会触发INTR）。
