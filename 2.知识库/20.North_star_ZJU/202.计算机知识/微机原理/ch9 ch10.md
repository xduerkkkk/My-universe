# ch9
![](../../../../assets/image/ch9%20ch10-1766905498482.jpeg)


没问题！第八章（中断）我们之前已经“扫盲”过了，所以直接进入 **第九章：定时器 8253/8254** 是完全正确的策略。

你说作业题“连题都很难看懂”，这是正常的。因为 **8253 是“控制字+工作方式”最复杂的一个芯片**，如果不先搞懂它的“脾气”，看题目就像看天书。

我用最直白的方式，帮你把 PPT 里的核心逻辑理清楚。搞懂了下面这三点，题目你就看懂了。

---

### **核心一：8253 长什么样？（PPT 第4-5页）**

想象 8253 是一个 **“倒计时闹钟集合”**。

1.  **三个通道**：它肚子里有 3 个独立的闹钟，叫 **计数器0, 1, 2**。
    *   每个闹钟都有 3 根线：
        *   **CLK (Clock)**：**心跳输入**。外面的时钟脉冲（比如 1MHz），每跳一下，闹钟就减 1。
        *   **GATE (门控)**：**开关**。高电平（开门）才让计数，低电平（关门）就暂停。
        *   **OUT (输出)**：**闹铃**。计数减到 0 了，这个引脚就变电平（或者输出波形）。

2.  **端口地址**：
    *   它有 4 个端口地址（比如 300H ~ 303H）：
        *   300H：找计数器 0。
        *   301H：找计数器 1。
        *   302H：找计数器 2。
        *   303H：**控制口**（这是发号施令的地方）。

---

### **核心二：怎么给它下命令？（控制字 - PPT 第7-8页）**

这是做题的**第一步**，必须会写“控制字”。
控制字是一个 **8位** 的二进制数，格式如下（死记硬背）：

| 高2位 (D7,D6) | 次2位 (D5,D4) | 中3位 (D3,D2,D1) | 最低位 (D0) |
| :--- | :--- | :--- | :--- |
| **选哪个闹钟？** | **怎么读/写？** | **用哪种工作方式？** | **用二进制还是BCD？** |
| 00: 计数器0<br>01: 计数器1<br>10: 计数器2 | **11: 先低后高** (最常用)<br>01: 只读写低8位<br>10: 只读写高8位 | 000: 方式0<br>010: 方式2<br>011: 方式3<br>... | **0: 二进制** (最常用)<br>1: BCD码 |

*   **例题**：我要用 **计数器0**，**先低后高**读写，工作在 **方式3**（方波），用 **二进制** 计数。
    *   **控制字**：`00` (选0) `11` (先低后高) `011` (方式3) `0` (二进制)
    *   **结果**：`0011 0110 B` = **`36H`**。
    *   **代码**：`MOV AL, 36H` -> `OUT 控制口, AL`。

---

### **核心三：6 种工作方式，重点看哪几个？（PPT 第9-26页）**

虽然有 6 种，但考试 90% 只考下面这 3 种：

1.  **方式 0 —— 计数结束中断 (PPT P9)**
    *   **人话**：**单次倒计时**。
    *   **动作**：
        1.  设个初值 N（比如 100）。
        2.  `OUT` 变低电平。
        3.  开始倒数：99, 98...
        4.  数到 0，`OUT` **变高电平**（一直高下去）。
    *   **用途**：产生中断信号。

2.  **方式 2 —— 分频器 (PPT P16)**
    *   **人话**：**打点器**（输出窄脉冲）。
    *   **动作**：数到 0，`OUT` 输出一个**短暂的低脉冲**，然后**自动重装初值**，重新倒数。
    *   **用途**：产生固定频率的脉冲（如 1秒钟跳一下）。

3.  **方式 3 —— 方波发生器 (PPT P19)**
    *   **人话**：**对称方波**。
    *   **动作**：前半段时间输出高，后半段时间输出低。**自动循环**。
    *   **用途**：产生声音、波形、驱动电机。

---

### **核心四：初值怎么算？（小学数学题）**

这也是做题必考。
> **初值 N = 输入频率 / 输出频率**

*   **例题**：输入时钟 CLK 是 **1MHz** ($10^6$ Hz)，我想让它产生 **1000Hz** 的方波。初值 N 是多少？
*   **计算**：$N = 1,000,000 / 1,000 = 1000$。
*   **代码**：把 1000 写进计数器。

---

### **总结：解题三部曲**

以后看到 8253 的题目，按这个套路走：

1.  **算初值**：$N = f_{in} / f_{out}$。
2.  **定方式**：
    *   要中断？选 **方式0**。
    *   要脉冲？选 **方式2**。
    *   要方波？选 **方式3**。
3.  **写代码**：
    *   先发 **控制字**（告诉它选哪个通道、哪种方式）。
    *   再发 **初值**（分两次发，先低8位，后高8位）。

搞懂了这个逻辑，再去读那几道作业题，你就会发现它们其实都在问这三件事。
准备好迎接题目了吗？


# ch10
这份PDF的内容不是模数/数模转换，而是 **微机原理的核心重点——并行接口芯片 8255A**。

这一章在期末考试中通常占 **15-20分**（一道大题 + 填空/选择），在考研（计组/微机自命题）中也是**I/O接口设计的必考内容**。

8255A 的逻辑非常清晰，我把它拆解为 **4个核心考点**，你按照这个逻辑去记忆，效率最高。

---

### 考点一：内部结构与寻址（死记硬背）
**（对应PDF P4-5）**

这是做题的第一步，必须识别CPU在操作8255的哪个端口。

1.  **3个数据端口 + 1个控制端口**：
    *   **A口**：功能最强（PA0-PA7），支持全部3种方式（0, 1, 2）。
    *   **B口**：次强（PB0-PB7），支持方式0和1。
    *   **C口**：打杂的（PC0-PC7），可分为高4位和低4位。**在方式0下作数据口，在方式1/2下作联络信号线（状态线/控制线）。**
2.  **寻址逻辑（必背表）**：
    通过 `CS#`（片选，决定基地址）和 `A1, A0`（片内偏移）来选中。

    | A1 | A0 | 选中端口 |
    | :--- | :--- | :--- |
    | 0 | 0 | **A口** |
    | 0 | 1 | **B口** |
    | 1 | 0 | **C口** |
    | 1 | 1 | **控制口** (写控制字用) |

    > **考研/期末 结合点**：
    > 题目通常会给一个基地址（比如PDF P20的 `280H`），问你控制口的地址是多少？
    > 答：基地址+3。即 `283H`。

---

### 考点二：控制字（重中之重）
**（对应PDF P9-10）**

8255A有两个控制字，**很容易混淆**，这是最容易扣分的地方。必须看 **D7位** 是0还是1。

#### 1. 方式选择控制字（D7=1）
这是用来**初始化**芯片的。
*   **格式**：`1 [A组方式] [PA输/出] [PC高输/出] [B组方式] [PB输/出] [PC低输/出]`
*   **助记口诀**：
    *   **D7必须是1**。
    *   **1是输入（Input），0是输出（Output）**。（想象 I 像 1，O 像 0）。
    *   **A组**包含：A口 + C口高4位。
    *   **B组**包含：B口 + C口低4位。

#### 2. C口置位/复位控制字（D7=0）
这是用来**单独控制C口的某一位**输出高低电平的。
*   **用途**：主要用于生成中断屏蔽位（INTE），或者用C口模拟开关控制。
*   **格式**：`0 X X X [D3-D1位选择] [D0置1/清0]`
*   **注意**：这个字必须写入**控制口**（地址A1A0=11），而不是写入C口数据口！

---

### 考点三：三种工作方式（理解核心）
**（对应PDF P11-19）**

*   **方式0（基本I/O）**：
    *   **特点**：**无握手信号**，单纯的数据进出。
    *   **场景**：接LED灯、接开关。（PDF P22-27的例子全是方式0）。
    *   **考法**：最简单，考代码编写。

*   **方式1（选通I/O，即握手）—— 难点！**
    *   **特点**：使用C口的线做**联络信号**（Strobe, ACK, Intra等）。
    *   **考研/计组 深度结合点**：
        *   **输入握手**：外设送来 `STB#` (选通)，8255回一个 `IBF` (Input Buffer Full, 缓冲满)。
        *   **输出握手**：CPU写数据，8255发 `OBF#` (Output Buffer Full)，外设取走后回 `ACK#`。
        *   **中断**：方式1支持中断，需要通过C口置位字设置 `INTE` (中断允许位) 为1。

*   **方式2（双向总线）**：
    *   只有 **A口** 能用。既能输也能出（如连接硬盘接口）。期末考试极少考方式2的具体连线，知道概念即可。

---

### 考点四：硬件设计与编程模板（大题通解）
**（对应PDF P20-27）**

考试大题通常是：**画图 + 初始化代码 + 读写代码**。

#### 1. 典型编程步骤（背下来）：
1.  **计算地址**：根据译码电路算出A、B、C、控制口的端口号。
2.  **写方式控制字**：
    *   分析题意：A口是入还是出？B口？C口？
    *   拼凑8位二进制数（D7=1...），算出十六进制。
    *   `MOV DX, 控制口地址` -> `MOV AL, 控制字` -> `OUT DX, AL`。
3.  **读写数据**：
    *   读数据（如读开关）：`MOV DX, A口地址` -> `IN AL, DX`。
    *   写数据（如点灯）：`MOV DX, B口地址` -> `MOV AL, 数据` -> `OUT DX, AL`。

#### 2. 实例解析（基于PDF P22）
题目：PA口接LED（输出），PB口接开关（输入）。地址280H-283H。
*   **分析**：PA输出=0，PB输入=1，方式0。
*   **控制字**：`1` (标志) `00` (方式0) `0` (PA出) `0` (PC高出) `0` (方式0) `1` (PB入) `0` (PC低出) = `1000 0010 B` = **82H**。
*   **核心代码**：
    ```assembly
    MOV DX, 283H   ; 控制口地址
    MOV AL, 82H    ; 方式控制字
    OUT DX, AL     ; 写入
    
    ; 读开关并送灯
    MOV DX, 281H   ; B口(开关)
    IN  AL, DX     ; 读入
    MOV DX, 280H   ; A口(灯)
    OUT DX, AL     ; 输出
    ```

### 针对你复习的建议

1.  **马上要做的**：
    *   **不用看** PDF后面复杂的时序图（P15, P18），那个是用来理解握手过程的，期末考试不会让你画时序图。
    *   **重点看** PDF P20-22 的例子。这是标准的考试题型。
    *   **注意** PDF P30 的例子使用了 `LOOP` 指令做循环跑马灯，这是考研常考的微机指令应用。

2.  **与计组/OS的结合（考研视角）**：
    *   **统一编址 vs 独立编址**：8255在x86体系下用 `IN/OUT` 指令，属于**独立编址**（I/O映射）。如果是在ARM或MIPS下，通常是**统一编址**（内存映射），用 `MOV` 指令。这是计组考点。
    *   **中断机制**：8255的 `INTR` 引脚通常连到 `8259` 中断控制器上。复习到下一章（中断）时，要回过头来想：8255怎么产生中断信号？（答案：在方式1下，当数据准备好时，IBF/OBF有效会触发INTR）。
