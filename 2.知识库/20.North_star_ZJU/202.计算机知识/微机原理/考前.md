### 一、8259A 考点终极总结（必背！）

8259A 是中断系统的核心，也是考试最喜欢抠细节的地方。

#### 1. 名字解释
*   **ICW (Initialization Command Word)**：初始化命令字。
    *   **作用**：刚上电时，用来定规矩（是单片还是级联？中断号从几开始？）。
    *   **记忆**：**必须按顺序写 ICW1 -> ICW2 -> (ICW3) -> (ICW4)**。
*   **OCW (Operation Command Word)**：操作命令字。
    *   **作用**：工作过程中，用来指挥它（屏蔽谁？结束谁？改变优先级？）。
    *   **记忆**：随时可写，没有顺序。

#### 2. 核心考点：ICW/OCW 的功能与地址
| 命令字 | 全名/功能 | 写入地址 | 核心考点 |
| :--- | :--- | :--- | :--- |
| **ICW1** | 初始化/触发方式 | **偶地址** ($A_0=0$) | $D_4=1$ 是特征位。 |
| **ICW2** | **中断类型号基值** | **奇地址** ($A_0=1$) | **最重要！** 比如写 `08H`，则 $IR_0 \to 08H$。 |
| **ICW3** | 级联控制 | 奇地址 | 只有级联时才写。主片记从片位置，从片记自己ID。 |
| **ICW4** | 模式设置 | 奇地址 | 通常设为 **8086模式** ($D_0=1$)。 |
| **OCW1** | **IMR (屏蔽字)** | **奇地址** | 1=屏蔽，0=允许。读写都要找它。 |
| **OCW2** | **EOI (结束中断)** | **偶地址** | **必考！** 中断服务程序结束前要发 `20H` (普通EOI) 给它。 |
| **OCW3** | 特殊屏蔽/读状态 | 偶地址 | 很少考。 |

#### 3. 常见小题陷阱
*   **优先级**：默认 $IR_0$ 最高，$IR_7$ 最低。
*   **屏蔽**：IMR 只能屏蔽 INTR（可屏蔽中断），管不了 NMI（非屏蔽中断）。
*   **EOI**：如果是 **全嵌套方式（默认）**，中断服务程序结束前必须发 `MOV AL, 20H` `OUT 20H, AL` (EOI命令)，否则 8259A 以为你还没干完活，不会放下一个中断进来。

### 二、中断系统考点总结（串联微机全过程）

**1. 中断是什么？（INT指令）**
*   **INT n**：这是 **软中断指令**。
    *   **动作**：执行这条指令 = 手动触发一个中断。
    *   **压栈**：**是的，INT 会压栈！** 就像 `CALL` 一样，它要保护现场以便回来。
    *   **压什么？**（顺序必背）：
        1.  **PUSH FLAGS** (标志寄存器)
        2.  **PUSH CS** (代码段)
        3.  **PUSH IP** (指令指针)
    *   **返回**：中断程序最后必须用 **`IRET`**（而不是 `RET`），它会按相反顺序把这三个家伙弹出来。

**2. 中断向量表（地址地图）**
*   **位置**：`00000H ~ 003FFH`（内存最低 1KB）。
*   **内容**：存放中断服务程序的 **入口地址 (IP:CS)**。
*   **计算**：`向量地址 = 类型号 × 4`。
*   **存放**：`IP低, IP高, CS低, CS高`（小端模式）。

**3. 硬件响应过程（INTR）**
*   **谁发的？** 8259A 的 INT 引脚 -> CPU 的 INTR 引脚。
*   **CPU 怎么回？** CPU 发两个 $\overline{INTA}$ 脉冲。
    *   第 1 个：告诉 8259A “准备好”。
    *   第 2 个：8259A 把 **类型号** 放上数据总线。
*   **CPU 干嘛？** 拿到类型号 -> 关中断 (`IF=0`) -> 压栈 -> 查表跳转。

**总结口诀**：
**初始化看顺序，操作看地址。**
**响应先压栈，返回 IRET。**
**向量乘 4 找地址，低 IP 高 CS。**
