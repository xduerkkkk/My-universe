### SAR SHR
####  DX:AX 构成的双字（有符号数）除以 2 的指令为（ C ）。

- **考点**：移位指令的区别（算术移位 vs 逻辑移位 vs 循环移位）。
    
- **解析**：
    
    - **除以 2**：等价于**右移 1 位**。
        
    - **有符号数**：必须用 **SAR** (Arithmetic Right Shift，算术右移)。因为 SAR 会**保留符号位**（最高位补符号位），而 SHR（逻辑右移）最高位补0，只适合无符号数。
        
    - **双字（32位）操作**：DX:AX 是 32 位。
        
        1. 先移高 16 位（DX）：SAR DX, 1。这步之后，DX 的最低位（原来的位0）被移进了 **CF** 标志位。
            
        2. 再移低 16 位（AX）：此时需要把刚才从 DX 掉出来的那个位（在 CF 里）塞进 AX 的最高位。这就需要 **带进位右移 RCR** (Rotate through Carry Right)。
            
    - **组合拳**：SAR DX, 1 + RCR AX, 1。

### **. 关于地址计算：DS × 16 + 偏移地址 是啥意思？**

**情景还原**：  
8086 CPU 是一台 **16位** 的机器，它的寄存器（BX, SI 等）只有 16位，最多只能表示 0 ~ 65535 (64KB) 的数字。  
**但是**，它的地址总线有 **20根**（20位），能访问 **1MB** 的内存（00000H ~ FFFFFH）。

**问题来了**：**怎么用 16位 的寄存器，去拼凑出一个 20位 的物理地址呢？**  
这就好比：你的房间号是 5位数（20位），但你的手里的卡片只能写 4位数（16位）。怎么办？

**解决方案（分段管理）**：需要两张卡片。

1. **段地址 (Segment)**：代表“小区号”。存放在 DS (数据段) 或 CS (代码段) 里。
    
2. **偏移地址 (Offset)**：代表“小区内的楼号”。存放在 BX 或 IP 里。
    

**计算规则**：**物理地址 = 段地址 × 16 + 偏移地址**

- **×16 是什么鬼？** 在十六进制里，乘以16等于**左移一位（后面补个0）**。
    
- **例子**：
    
    - DS = 3000H （小区号是 3000）
        
    - 偏移 = 2000H （楼号是 2000）
        
    - CPU内部计算器：先把 3000H 变成 30000H (左移一位，即乘以16)，然后加上 2000H。
        
    - **结果**：32000H。这就是最终发到地址总线上的 **20位物理地址**。
        

> **结论**：这个公式就是 Intel 为了在16位CPU上强行访问1MB内存搞出来的“拼凑大法”。

#### **Q1: 为什么只能操作 16位？**

**原因**：这是 8086 的硬件设计规定的。堆栈主要用来保存从寄存器里拿出来的数据（比如 AX, BX），或者保存函数调用时的返回地址（IP）。因为 8086 的寄存器和地址都是 **16位** 的，所以设计者规定：**堆栈操作必须一次进出 2个字节（1个字），不允许只进一半。** 这样效率最高，也能保持内存对齐。

#### **Q2: SP-2 还是 SP+2？栈底在哪？**

**情景**：想象你在**从天花板往下**盖一座楼。

- **栈底**：是**高地址**（比如 1000H），是最初的位置，不动。
    
- **栈顶 (SP)**：是**低地址**，随着数据进来，SP 往**低**处跑。
    

**动作解析**：

- **PUSH (入栈)**：
    
    1. **SP = SP - 2**：你也看出来了，栈顶SP要往上浮（往低地址走），腾出空间。
        
    2. **存数据**：把 16位数据写进去。
        
    3. **高低位顺序**：**小端模式 (Little Endian)**。低8位在低地址，高8位在高地址。
        
- **POP (出栈)**：
    
    1. **取数据**：先把数据读出来。
        
    2. **SP = SP + 2**：SP 往下沉（往高地址走），释放空间。

### **PSW 标志位：6个红绿灯**

这些标志位是 ALU（算术逻辑单元）算完一次后，自动留下的“案发现场痕迹”。

- **CF (Carry Flag) 进位标志**：**无符号数**溢出了。（像汽车里程表，9999 + 1 = 0000，进位了）。
    
- **ZF (Zero Flag) 零标志**：结果是不是 **0**。是0则ZF=1。（这是判断相等的关键）。
    
- **SF (Sign Flag) 符号标志**：结果是正还是负（看最高位是0还是1）。
    
- **OF (Overflow Flag) 溢出标志**：**有符号数**溢出了。（正+正=负，或者 负+负=正，脑子炸了）。
    
- **PF (Parity Flag) 奇偶标志**：结果里有偶数个1。（现在很少用了，不用管）。
    
- **AF (Auxiliary Flag) 辅助进位**：低4位向高4位的进位。（做BCD码运算用的，也不用深究）。
    

> **重点记 CF, ZF, SF, OF。**

#### **1. 查表 (Look-up Table)**

- **核心指令**：**XLAT** (Translate)
    
- **动作**：AL = [BX + AL]
    
    - **BX**：存表格的**首地址**（基址）。
        
    - **AL**：存你要查第几个（索引）。
        
    - **结果**：查到的内容直接覆盖回 **AL**。

    

#### **2. 堆栈 (Stack)**

- **核心指令**：**PUSH src** / **POP dest**
    
- **三条铁律（必考判断题）：**
    
    1. **单位是“字”**：只能压 16位（AX, BX, DS等），不能压 8位（AL, AH不行！）。
        
    2. **生长方向**：**从高向低**。
        
        - 入栈 (PUSH)：SP 减 2。
            
        - 出栈 (POP)：SP 加 2。
            
    3. **谁先进**：**高字节在高地址**（小端模式在堆栈里依然适用，但 push/pop 逻辑是高字节存高地址，看着像反的，其实符合逻辑）。
        
- **用途**：
    
    - **保护现场**：进入子程序前 PUSH AX, PUSH CX...
        
    - **子程序传参**：用堆栈把数据传给函数。
        

#### **3. 跳转 (Jump)**

- **无条件跳转**：**JMP**
    
    - **段内跳转**：只改 IP（短跳/近跳）。
        
    - **段间跳转**：同时改 CS 和 IP（远跳 Far Jump）。
        
- **条件跳转** (看标志位)：
    
    - **JZ / JE**：结果为 0 (相等) 则跳。
        
    - **JNZ / JNE**：结果不为 0 (不相等) 则跳。
        
    - **JB / JC**：低于 (无符号数 <) 则跳。
        
    - **JL**：小于 (有符号数 <) 则跳。
        
    - **JG**：大于 (有符号数 >) 则跳。
        

#### **4. %循环% (Loop)**

- **基本循环**：**LOOP label**
    
    - **动作**：CX = CX - 1，如果 CX != 0 就跳回 label。
        
    - **注意**：它只看 CX，不看标志位。
        
- **高级循环（搜索专用）**：
    
    - **LOOPNE / LOOPNZ**：CX 减 1，**并且** ZF=0 (不相等) 时才循环。
        
    - **场景**：在字符串里找 "A"。如果没找到 (不相等)，且次数没用完，就继续找。如果找到了 (相等，ZF=1)，立马退出循环。这就是你上机题 4.13 的考点。
        

#### **5. 排序 (Sort)**

- **核心算法**：**冒泡排序 (Bubble Sort)**
    
- **汇编实现模板（双重循环）**：
    
    - **外层**：控制轮数，用 CX。**注意：进入内层前必须 PUSH CX**。
        
    - **内层**：控制比较次数，也用 CX。
        
    - **比较**：MOV AL, [SI] -> CMP AL, [SI+1]。
        
    - **交换**：**XCHG AL, [SI+1]** -> MOV [SI], AL。
        
    - **恢复**：内层结束后 **POP CX**。
        



### **考点一：堆栈 (Stack) —— 数据逆序**

**【题型：程序分析题】**  
阅读下列程序段，说明其功能，并指出执行后 AX 和 BX 的内容。

codeAssembly

```
MOV AX, 1234H
    MOV BX, 5678H
    
    PUSH AX
    PUSH BX
    
    POP AX
    POP BX
```

**【解析】**  
这是一个利用堆栈 **“后进先出 (LIFO)”** 特性进行**数据交换**的经典操作。

1. PUSH AX：1234H 入栈（在栈底）。
    
2. PUSH BX：5678H 入栈（在栈顶）。
    
3. POP AX：**栈顶**的数据弹出来给 AX。此时栈顶是 5678H。所以 AX = 5678H。
    
4. POP BX：剩下的那个数据弹出来给 BX。即 1234H。所以 BX = 1234H。
    

**【答案】**

- **功能**：**交换 AX 和 BX 寄存器中的内容**。
    
- **结果**：AX = 5678H, BX = 1234H。
    

**【应试坑点】**

- 填空题常考：PUSH AX 执行后，SP 变大还是变小？
    
    - 答：**变小**（减2）。
        
- 改错题常考：PUSH AL。
    
    - 答：**错**！堆栈只能压 16 位（字），不能压 8 位。

### **考点二：循环 (Loop) —— 查找字符**

**【题型：程序填空题】**  
在内存 BUFFER 缓冲区中存放了 100 个字符。编写程序查找其中是否有字符 'A'。若找到，将 DI 指向该字符地址；若没找到，DI 置为 0。

codeAssembly

```
MOV CX, 100
    LEA DI, BUFFER
    MOV AL, 'A'

SEARCH:
    CMP [DI], AL      ; 比较当前字符和 'A'
    ________(1)_______  ; 【填空1】如果相等，就跳出循环去 FOUND
    
    INC DI            ; 指针后移
    ________(2)_______  ; 【填空2】继续循环
    
    ; 没找到的处理
    MOV DI, 0
    JMP EXIT

FOUND:
    ; 找到了，DI已经指向当前地址，不做操作直接退出
    JMP EXIT

EXIT: ...
```

**【解析】**

1. **填空1**：CMP 相等时，ZF=1。我们需要“相等就跳转”。
    
    - 答案：**JZ FOUND** (或 JE FOUND)。
        
2. **填空2**：标准循环指令。
    
    - 答案：**LOOP SEARCH**。
        

**【高阶考法（不用跳转指令）】**  
如果题目让你用 **串扫描指令** 怎么写？（这是你上机题 4.13 的变种）

codeAssembly

```
MOV CX, 100
    LEA DI, BUFFER
    MOV AL, 'A'
    CLD             ; 方向设为正向
    REPNE SCASB     ; 【必背】一直扫描，直到相等(Equal)或CX=0才停
    
    JZ FOUND        ; 如果是因为相等停下的，去FOUND
    MOV DI, 0       ; 否则就是没找到
```

### **考点三：排序 (Sort) —— 冒泡排序**

**【题型：代码改错/填空】**  
这也是你上机写过的大题，考试时通常以**填空**形式出现，考察**双重循环的结构**。

**题目**：对 ARRAY 数组中的 CX 个字节进行从小到大排序。请补全代码。

codeAssembly

```
MOV CX, Count     ; CX = 数组长度
    DEC CX            ; 外层循环次数 = N-1

OUTER:
    ________(1)_______  ; 【填空1】保护外层计数器！
    
    MOV BX, 0         ; 数组下标从0开始
    
INNER:
    MOV AL, ARRAY[BX]
    CMP AL, ARRAY[BX+1]
    
    ________(2)_______  ; 【填空2】如果 前<=后，不需要交换，跳过
    
    ; 交换逻辑
    XCHG AL, ARRAY[BX+1]
    MOV ARRAY[BX], AL

NEXT:
    INC BX
    LOOP INNER        ; 内层循环
    
    ________(3)_______  ; 【填空3】恢复外层计数器
    LOOP OUTER        ; 外层循环
```

**【解析】**

1. **填空1**：进入内层循环前，必须把外层的 CX 存起来，否则内层 LOOP 会把 CX 减到 0，外层就断了。
    
    - 答案：**PUSH CX**
        
2. **填空2**：冒泡排序是从小到大。如果前面的数 (AL) 小于等于后面的数，就是对的，不用换。
    
    - 答案：**JBE NEXT** (Jump if Below or Equal)。
        
    - (注：如果是无符号数用 JBE，有符号数用 JLE)
        
3. **填空3**：内层跑完了，要把外层的 CX 拿回来，准备下一轮外层循环。
    
    - 答案：**POP CX**
        

**【应试口诀】**

> **双重循环要排序，进入内层 PUSH CX。**  
> **内层出来 POP CX，千万别忘这一句。**

---

### **总结：看到这三类题怎么反应？**

1. **堆栈题**：
    
    - 看到 PUSH/POP 连续出现，就是在**颠倒顺序**或者**保护现场**。
        
    - 注意是 **Word (16位)** 操作。
        
2. **循环题**：
    
    - **找东西**：用 CMP + JE/JZ（找到了） 或者 LOOPNZ（没找到继续找）。
        
    - **单纯重复**：用 LOOP。
        
3. **排序题**：
    
    - **双重循环**：必考 PUSH CX 和 POP CX。
        
    - **交换**：必考 XCHG。
