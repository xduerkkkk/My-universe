### H01 下滤建大根堆并原地升序排序

**来源**：保留旧堆基础，将建堆与排序合成一题两步。

- [ ] 首次：能说明状态并独立写出
- [ ] 间隔复写：不看答案通过边界检查

**题干**：数组A采用0下标，先自底向上建大根堆，再原地升序排序；n可为0。手写下滤与建堆，不使用库；O(1)额外空间，分别分析建堆和排序时间。

**先手推自测**：[3,1,4,1,5]→[1,1,3,4,5]；空、单点、全等、负值；建堆后不一定整体有序。

> [!faq]- 识别模板、推导与完整代码｜先尝试再展开
>
> **考场识别 → [[2.知识库/20.North_star_ZJU/202.计算机知识/05数据结构/08算法题/03算法题模板#H1 堆的局部修复（基础）|H1 堆的局部修复（基础）]]**：“堆局部失序”向下调整；“原地升序”反复将最大根放到未排序区末。
>
> **关键状态**：SiftDownMax调用前，i的左右子树各自已是大根堆；n为当前堆的有效长度，不含已归位后缀。
>
> **解题步骤**
> 1. 保存根值x，每次选更大的孩子；若x已不小于孩子则停，否则孩子上移。
> 2. 从n/2-1到0依次下滤建堆。
> 3. 根与末项交换，缩短堆长，再下滤根。
>
> **为什么成立**：建堆按子树已成堆的顺序执行；每次交换把剩余最大值放到最终位置，前缀恢复堆后继续。
>
> **时间／额外空间**：建堆O(n)，排序O(n log(n+1))上界；空间O(1)，下滤为迭代。
>
> **易错核对**：0下标左孩子2i+1；下滤时选较大孩子；排序下滤长度是end而非end+1；建堆不是O(n log n)的紧界。
>
> **完整核心代码**（本卡单独配公共类型编译）
>
> ```cpp
> void SiftDownMax(int A[], int n, int i) {
>     int x = A[i];
>     for (int child = 2 * i + 1; child < n; child = 2 * i + 1) {
>         if (child + 1 < n && A[child + 1] > A[child]) child++;
>         if (x >= A[child]) break;
>         A[i] = A[child]; i = child;
>     }
>     A[i] = x;
> }
> void BuildMaxHeap(int A[], int n) {
>     for (int i = n / 2 - 1; i >= 0; i--) SiftDownMax(A, n, i);
> }
> void HeapSort(int A[], int n) {
>     BuildMaxHeap(A, n);
>     for (int end = n - 1; end > 0; end--) {
>         int temp = A[0]; A[0] = A[end]; A[end] = temp;
>         SiftDownMax(A, end, 0);
>     }
> }
> ```

### H02 固定容量保留最大的k项

**来源**：保留旧Top-k作为选练，不重复扩堆题。

- [ ] 首次：能说明状态并独立写出
- [ ] 间隔复写：不看答案通过边界检查

**题干**：任意整数数组A长n，0≤k≤n，不得修改A。将最大的k项写入result[]，内部只要求小根堆，不要求排序，重复按项计数。result与输入不重叠且容量≥k。O(n log(k+1)+k)时间，除result外O(1)工作空间；k=0无输出。

**先手推自测**：[3,1,5,2,5]、k=3→多重集[3,5,5]且内部小根堆；k=1取最大；k=0；k=n。

> [!faq]- 识别模板、推导与完整代码｜先尝试再展开
>
> **考场识别 → [[2.知识库/20.North_star_ZJU/202.计算机知识/05数据结构/08算法题/03算法题模板#H1 堆的局部修复（基础）|H1 堆的局部修复（基础）]]**：“保留最大k项”要随时淘汰入选项中最小的那个，所以保留小根堆，不是大根堆。
>
> **关键状态**：result保存已扫描部分最大的k项；堆根是这些入选项的最弱者。
>
> **解题步骤**
> 1. 前k项复制并建小根堆。
> 2. 后续值不大于堆根则跳过；更大就替换根再下滤。
> 3. 结束保持小根堆，无需再排序。
>
> **为什么成立**：每次新值只有比当前最小入选值更大才可能改善结果；替换后仍恰保留前缀最大k项。
>
> **时间／额外空间**：O(k+(n-k)log(k+1))上界，k=0常数返回；result输出占O(k)，其他工作空间O(1)。
>
> **易错核对**：最大k用小根堆；result未必升序；输入不改；k=0不能读堆根。
>
> **完整核心代码**（本卡单独配公共类型编译）
>
> ```cpp
> void SiftDownMin(int A[], int n, int i) {
>     int x = A[i];
>     for (int child = 2 * i + 1; child < n; child = 2 * i + 1) {
>         if (child + 1 < n && A[child + 1] < A[child]) child++;
>         if (x <= A[child]) break;
>         A[i] = A[child]; i = child;
>     }
>     A[i] = x;
> }
> void LargestK(const int A[], int n, int k, int result[]) {
>     if (k == 0) return;
>     for (int i = 0; i < k; i++) result[i] = A[i];
>     for (int i = k / 2 - 1; i >= 0; i--) SiftDownMin(result, k, i);
>     for (int i = k; i < n; i++) {
>         if (A[i] > result[0]) {
>             result[0] = A[i];
>             SiftDownMin(result, k, 0);
>         }
>     }
> }
> ```
