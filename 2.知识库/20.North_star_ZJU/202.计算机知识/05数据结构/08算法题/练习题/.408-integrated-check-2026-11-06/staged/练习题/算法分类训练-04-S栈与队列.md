### S01 三类括号匹配

**来源**：仅保留栈基础；兼作最简单字符序列题。

- [ ] 首次：能说明状态并独立写出
- [ ] 间隔复写：不看答案通过边界检查

**题干**：长度n的字符数组只含()[]{}六种括号，判断是否合法匹配；空序列为真。O(n)时间，可用O(n)栈，不依赖STL。

**先手推自测**：([{}])真；([)]假；)假；((假；空真。

> [!faq]- 识别模板、推导与完整代码｜先尝试再展开
>
> **考场识别 → [[2.知识库/20.North_star_ZJU/202.计算机知识/05数据结构/08算法题/03算法题模板#S1 后进先出（基础）|S1 后进先出（基础）]]**：“最近未闭合者最先匹配”后进先出，用栈保存左括号。
>
> **关键状态**：top=-1为空，stack[0..top]是尚未匹配的左括号。
>
> **解题步骤**
> 1. 左括号入栈。
> 2. 右括号时先检查非空，再看栈顶类型是否对应。
> 3. 对应则弹栈，否则失败；结束必须空栈。
>
> **为什么成立**：每个右括号只能与最近的未闭合左括号配对；栈精确保存这些左括号。
>
> **时间／额外空间**：O(n)／O(n)。
>
> **易错核对**：不能只统计左右括号数量；弹栈前检查空；本题输入只含六种括号。
>
> **完整核心代码**（本卡单独配公共类型编译）
>
> ```cpp
> bool BracketsMatch(const char A[], int n) {
>     char *stack = new char[n]();
>     int top = -1;
>     bool ok = true;
>     for (int i = 0; i < n && ok; i++) {
>         char c = A[i];
>         if (c == '(' || c == '[' || c == '{') stack[++top] = c;
>         else {
>             if (top == -1) { ok = false; break; }
>             char left = stack[top--];
>             if (!((left == '(' && c == ')') || (left == '[' && c == ']') ||
>                   (left == '{' && c == '}'))) ok = false;
>         }
>     }
>     ok = ok && top == -1;
>     delete[] stack;
>     return ok;
> }
> ```

### S02 单数字后缀表达式求值

**来源**：保留基础后缀求值，不设单调栈专题。

- [ ] 首次：能说明状态并独立写出
- [ ] 间隔复写：不看答案通过边界检查

**题干**：长度n的字符数组由单个数字0..9与二元运算符+、-、*组成，无空格。按后缀表达式求值，合法则通过answer返回int并返回true；非法返回false（此时answer不规定）。保证实际中间运算若发生均不溢出int；空序列非法。O(n)时间、O(n)栈。

**先手推自测**：23-→-1；23+4*→20；2+非法；23非法（多余操作数）；空非法。

> [!faq]- 识别模板、推导与完整代码｜先尝试再展开
>
> **考场识别 → [[2.知识库/20.North_star_ZJU/202.计算机知识/05数据结构/08算法题/03算法题模板#S1 后进先出（基础）|S1 后进先出（基础）]]**：“运算符在操作数之后”数字压栈，运算时最近两个数出栈。
>
> **关键状态**：栈存已求值但尚未参与后续运算的部分表达式结果；弹出的第一个是右操作数。
>
> **解题步骤**
> 1. 数字压栈。
> 2. 运算符须有至少两个操作数；先弹right，再弹left，结果入栈。
> 3. 未知字符失败；结束必须恰好剩一个结果。
>
> **为什么成立**：每个运算符将前面两个已完成子表达式缩成一个值，与后缀表达式递归结构一致。
>
> **时间／额外空间**：O(n)／O(n)。
>
> **易错核对**：减法不能反向；有一个结果不代表合法，最终必须恰一个；多位数解析不属于本题。
>
> **完整核心代码**（本卡单独配公共类型编译）
>
> ```cpp
> bool EvaluatePostfix(const char A[], int n, int &answer) {
>     int *stack = new int[n]();
>     int top = -1;
>     bool ok = true;
>     for (int i = 0; i < n && ok; i++) {
>         char c = A[i];
>         if (c >= '0' && c <= '9') stack[++top] = c - '0';
>         else if (c == '+' || c == '-' || c == '*') {
>             if (top < 1) { ok = false; break; }
>             int right = stack[top--], left = stack[top--];
>             int value = c == '+' ? left + right : (c == '-' ? left - right : left * right);
>             stack[++top] = value;
>         } else ok = false;
>     }
>     ok = ok && top == 0;
>     if (ok) answer = stack[0];
>     delete[] stack;
>     return ok;
> }
> ```
