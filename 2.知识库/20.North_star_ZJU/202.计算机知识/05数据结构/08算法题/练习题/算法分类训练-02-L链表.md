### L07 首尾交替重排

- [ ] 首次：能解释状态并写出代码
- [ ] 间隔复写：不看答案通过自测

**定位**：主练｜2019·41：按用户给出的题型改写。

**题干**：带头结点链表 L 的数据结点为 a1→a2→…→an，改排为 a1→an→a2→an-1→…；不改变数据域，不新建数据结点，O(1) 辅助空间。

**自测**：[1,2,3,4,5] → [1,5,2,4,3]；[1,2,3,4] → [1,4,2,3]；空表不变。

> [!faq]- 题解与完整核心代码｜先说状态，再核对
> **变量存什么**：`slow` 找前半尾；`pre` 是逆置后的后半首；`p/q` 交替连接两段。
>
> **解题步骤**
> 1. 快慢指针找前半尾，奇数长度把中间结点留在前半。
> 2. 保存后半首并断链，这一步防止后续重排成环。
> 3. 把后半链就地逆置，得到 an→an-1→… 的顺序。
> 4. 每次从后半取一个结点，插入当前前半结点后面，保存双方后继再改链。
>
> **手推一遍**：[1,2,3,4,5]：拆成123与45；后半逆为54；交替接成1→5→2→4→3。
>
> ```cpp
> void ReorderList(LinkList L) {
>     if (L->next == NULL || L->next->next == NULL) return;
>     LNode *slow = L->next;
>     LNode *fast = L->next;
>     while (fast->next != NULL && fast->next->next != NULL) {
>         slow = slow->next;
>         fast = fast->next->next;
>     }
>     LNode *p = slow->next;
>     slow->next = NULL;
>
>     LNode *pre = NULL;
>     while (p != NULL) {
>         LNode *next = p->next;
>         p->next = pre;
>         pre = p;
>         p = next;
>     }
>
>     p = L->next;
>     LNode *q = pre;
>     while (q != NULL) {
>         LNode *next1 = p->next;
>         LNode *next2 = q->next;
>         p->next = q;
>         q->next = next1;
>         p = next1;
>         q = next2;
>     }
> }
> ```
>
> **时间 / 额外空间**：O(n) / O(1)。
>
> **易错核对**：不是把所有结点压栈；断链和保存两个后继是最容易遗漏的地方。本卡已展开全部步骤，不依赖外部辅助函数。

### L09 两个链表的第一个公共结点

- [ ] 首次：能解释状态并写出代码
- [ ] 间隔复写：不看答案通过自测

**定位**：主练｜2012·42：共同后缀首结点；按用户题型改写。

**题干**：两条带头结点、无环的单链表 La、Lb 可能共享尾部，返回第一个公共数据结点地址；不存在返回 NULL。不修改、不释放结点。

**自测**：两条数据链长度5、3且共享最后2个结点 → 长链先走2步，再同步找到公共首；值相同但地址不同 → NULL。

> [!faq]- 题解与完整核心代码｜先说状态，再核对
> **变量存什么**：`length1/length2` 是数据结点数；`p/q` 对齐后到表尾的距离相同。
>
> **解题步骤**
> 1. 分别遍历两表统计长度，不把头结点计入。
> 2. 较长表先走长度差步，让两个指针到表尾的距离相同。
> 3. 同步后移，第一次地址相等就是公共后缀首；都到 NULL 表示无交点。
>
> ```cpp
> LNode *FirstCommonNode(LinkList La, LinkList Lb) {
>     int length1 = 0, length2 = 0;
>     for (LNode *p = La->next; p != NULL; p = p->next) length1++;
>     for (LNode *q = Lb->next; q != NULL; q = q->next) length2++;
>     LNode *p = La->next;
>     LNode *q = Lb->next;
>     while (length1 > length2) {
>         p = p->next;
>         length1--;
>     }
>     while (length2 > length1) {
>         q = q->next;
>         length2--;
>     }
>     while (p != q) {
>         p = p->next;
>         q = q->next;
>     }
>     return p;
> }
> ```
>
> **时间 / 额外空间**：O(n+m) / O(1)。
>
> **易错核对**：比的是 p==q，不是 p->data==q->data；本题有共享所有权，不能删除公共链上的结点。

### L14 链表倒数第 k 个结点

- [ ] 首次：能解释状态并写出代码
- [ ] 间隔复写：不看答案通过自测

**定位**：主练｜2009·42：按用户题型改写，保留“成功输出并返回1、失败返回0”的形式。

**题干**：带头结点链表 L，k 从1计数。只遍历一次，输出倒数第 k 个结点的数据并返回1；k≤0或表长不足 k 返回0，不输出。

**自测**：[1,2,3,4,5]，k=2 → 输出4，返回1；k=5 → 输出1；k=6或k=0 → 返回0；空表返回0。

> [!faq]- 题解与完整核心代码｜先说状态，再核对
> **变量存什么**：`p` 是先行指针，先走 k 步；`q` 从首个数据结点出发，之后与 p 同步。
>
> **解题步骤**
> 1. 若 k≤0，直接失败。
> 2. p 先走 k 步；没走够就遇到 NULL，说明结点不足。
> 3. q 从首结点出发，与 p 同步前进；p 到 NULL 时，q 恰为倒数第 k 个。
> 4. 输出 q->data，返回成功标志1。
>
> ```cpp
> int FindKthFromEnd(LinkList L, int k) {
>     if (k <= 0) return 0;
>     LNode *p = L->next;
>     for (int i = 0; i < k; i++) {
>         if (p == NULL) return 0;
>         p = p->next;
>     }
>     LNode *q = L->next;
>     while (p != NULL) {
>         p = p->next;
>         q = q->next;
>     }
>     printf("%d", q->data);
>     return 1;
> }
> ```
>
> **时间 / 额外空间**：O(n) / O(1)。
>
> **易错核对**：先行指针从数据首结点走 k 步、最后停在 NULL；不要与“先走 k-1 步、最后停在尾结点”的另一套循环混搭。

### L15 单链表按绝对值去重

- [ ] 首次：能解释状态并写出代码
- [ ] 间隔复写：不看答案通过自测

**定位**：主练｜2015·41：利用题目给出的有限值域。

**题干**：带头结点链表 L，所有数据满足 |data|≤maxValue，maxValue≥0。按原顺序只保留每个绝对值首次出现的结点，释放重复结点。所有结点由 new 单独创建且归本表所有。

**自测**：[21,-15,-15,-7,15]，maxValue=21 → [21,-15,-7]；[0,0] → [0]；[-3,3,-3] → [-3]。

> [!faq]- 题解与完整核心代码｜先说状态，再核对
> **变量存什么**：`visited[x]` 记录绝对值 x 是否已保留；`pre` 是 p 的前驱，删除后 pre 不移动。
>
> **解题步骤**
> 1. 申请 maxValue+1 个零标记，包含绝对值0。
> 2. 读取 p 的绝对值；没见过就标记，并让 pre、p 后移。
> 3. 已经见过则绕过 p 并 delete；p 回到 pre->next，pre 留在原处。
> 4. 扫描结束后释放标记数组。
>
> ```cpp
> void RemoveAbsDuplicates(LinkList L, int maxValue) {
>     int *visited = new int[maxValue + 1]();
>     LNode *pre = L;
>     LNode *p = L->next;
>     while (p != NULL) {
>         int value = p->data < 0 ? -p->data : p->data;
>         if (visited[value] == 0) {
>             visited[value] = 1;
>             pre = p;
>             p = p->next;
>         } else {
>             pre->next = p->next;
>             delete p;
>             p = pre->next;
>         }
>     }
>     delete[] visited;
> }
> ```
>
> **时间 / 额外空间**：O(n+maxValue) / O(maxValue+1)，零初始化标记数组也有成本。
>
> **易错核对**：按绝对值去重，不是按原值；删除后不能再访问 p->next。值域前提排除了 INT_MIN 的取负溢出。

### L01 单链表原地逆置

- [ ] 首次：能解释状态并写出代码
- [ ] 间隔复写：不看答案通过自测

**定位**：基础积木｜链表重排的前置操作；新版统一带头结点。

**题干**：带头结点单链表 L，原地逆置数据结点；头结点地址不变，不新建数据结点。

**自测**：L→1→2→3 → L→3→2→1；空表、单结点均合法。

> [!faq]- 题解与完整核心代码｜先说状态，再核对
> **变量存什么**：`pre` 是已逆置部分的首结点；`p` 是当前待处理结点；`next` 暂存原后继。
>
> **解题步骤**
> 1. pre 置空，p 从 L->next 开始，头结点不参加逆置。
> 2. 先保存 p 原来的后继，再让 p 指向 pre。
> 3. pre 前进到 p，p 前进到原后继；直到原表扫描结束。
> 4. 令 L->next=pre，把头结点接到逆置后的首结点。
>
> ```cpp
> void ReverseList(LinkList L) {
>     LNode *pre = NULL;
>     LNode *p = L->next;
>     while (p != NULL) {
>         LNode *next = p->next;
>         p->next = pre;
>         pre = p;
>         p = next;
>     }
>     L->next = pre;
> }
> ```
>
> **时间 / 额外空间**：O(n) / O(1)。
>
> **易错核对**：改 p->next 之前必须保存原后继；不能把头结点当数据结点一起逆置。

### L02 稳定归并两个有序链表

- [ ] 首次：能解释状态并写出代码
- [ ] 间隔复写：不看答案通过自测

**定位**：基础积木｜有序表操作；统一带头结点。

**题干**：La、Lb 是两条带头结点的非递减单链表，不共享结点。复用全部数据结点归并到 La，相等时先取 La 原结点；保留 Lb 的头结点并使 Lb 成为空表。

**自测**：La=[1,3]、Lb=[1,2] → La=[1(a),1(b),2,3]、Lb=[]；两空表仍为空。

> [!faq]- 题解与完整核心代码｜先说状态，再核对
> **变量存什么**：`p/q` 指向两条待归并剩余链；`tail` 指向结果表最后一个结点。
>
> **解题步骤**
> 1. 先用 p、q 保存两条数据链，再把结果尾指针放在 La 头结点。
> 2. 比较 p、q 的值，把较小结点尾插到结果；相等时先 p，保持稳定。
> 3. 一条耗尽后，直接接上另一条剩余链。
> 4. 清空 Lb->next，避免两个头结点继续指向同一批归并结果。
>
> ```cpp
> void MergeLists(LinkList La, LinkList Lb) {
>     LNode *p = La->next;
>     LNode *q = Lb->next;
>     LNode *tail = La;
>     while (p != NULL && q != NULL) {
>         if (p->data <= q->data) {
>             tail->next = p;
>             p = p->next;
>         } else {
>             tail->next = q;
>             q = q->next;
>         }
>         tail = tail->next;
>     }
>     tail->next = (p != NULL) ? p : q;
>     Lb->next = NULL;
> }
> ```
>
> **时间 / 额外空间**：O(n+m) / O(1)。
>
> **易错核对**：本训练保留两个头结点；若原题要求释放 Lb 头结点，则按其所有权约定另行处理，不要擅自删除数据结点。

### L05 找前半段尾并断链

- [ ] 首次：能解释状态并写出代码
- [ ] 间隔复写：不看答案通过自测

**定位**：基础积木｜链表重排的前置操作。

**题干**：带头结点链表 L，至少2个数据结点。前半保留 ceil(n/2) 个，后半 floor(n/2) 个；断开两段，返回后半首结点。

**自测**：[1,2,3,4,5] → 前[1,2,3]、后[4,5]；[1,2] → [1]与[2]。

> [!faq]- 题解与完整核心代码｜先说状态，再核对
> **变量存什么**：`slow` 每次走一步；`fast` 每次走两步；退出时 slow 是前半段尾。
>
> **解题步骤**
> 1. slow、fast 都从首个数据结点出发。
> 2. 只要 fast 后面还有两个结点，两者分别前进1步、2步。
> 3. 保存 slow->next 作为后半首，再令 slow->next=NULL 断链。
>
> ```cpp
> LNode *SplitHalf(LinkList L) {
>     LNode *slow = L->next;
>     LNode *fast = L->next;
>     while (fast->next != NULL && fast->next->next != NULL) {
>         slow = slow->next;
>         fast = fast->next->next;
>     }
>     LNode *second = slow->next;
>     slow->next = NULL;
>     return second;
> }
> ```
>
> **时间 / 额外空间**：O(n) / O(1)。
>
> **易错核对**：本函数前提 n≥2；重排题在调用相同逻辑前，先处理空表/单结点。断链前先保存后半首。
