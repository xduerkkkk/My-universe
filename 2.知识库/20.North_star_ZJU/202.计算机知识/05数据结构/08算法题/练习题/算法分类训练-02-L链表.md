### L01 带头结点单链表原地逆置

**来源**：保留旧逆置积木并统一带头结点。

- [x] 首次：能说明状态并独立写出
- [ ] 间隔复写：不看答案通过边界检查

**题干**：带头结点L的无环单链表，原地逆置所有数据结点，头结点地址不变。不得申请或释放结点，O(n)时间、O(1)空间。L本身非NULL，空表L->next==NULL。

**先手推自测**：空表不变；[1]不变；[1,2,3]→[3,2,1]，全部数据结点地址仍为原地址。

> [!faq]- 识别模板、推导与完整代码｜先尝试再展开
>
> **考场识别 → [[2.知识库/20.North_star_ZJU/202.计算机知识/05数据结构/08算法题/03算法题模板#L1 保存后继再改边|L1 保存后继再改边]]**：“改变next方向”先保存后继，再改边，再推进；头结点不参加逆置。
>
> **关键状态**：pre是已逆置前缀的新首，p是未处理首；next暂存原后继。
>
> **解题步骤**
> 1. pre=NULL，p=L->next。
> 2. 保存next=p->next，令p->next=pre。
> 3. pre=p，p=next；结束令L->next=pre。
>
> **为什么成立**：每轮将未处理前缀的一个结点移到已逆置链头，结点不丢失、不重复且最终以NULL结尾。
>
> **时间／额外空间**：O(n)／O(1)。
>
> **易错核对**：必须先存next；返回后尾next为NULL；不能把L一起逆进去。
>
> **完整核心代码**（本卡单独配公共类型编译）
>
> ```cpp
> void ReverseList(LinkList L) {
>     LNode *pre = NULL, *p = L->next;
>     while (p != NULL) {
>         LNode *next = p->next;
>         p->next = pre;
>         pre = p;
>         p = next;
>     }
>     L->next = pre;
> }
> ```

### L02 复用结点稳定归并两个有序链表

**来源**：保留旧归并好题，明确所有权。

- [x] 首次：能说明状态并独立写出
- [ ] 间隔复写：不看答案通过边界检查

**题干**：两条非递减无环带头链表A、B没有共享结点。复用全部数据结点，稳定归并到A；值相等先取A原结点，两个输入各自的相对次序保持。B最终为空，两个头结点均保留。不申请或释放结点；O(n+m)时间、O(1)空间。

**先手推自测**：A=[1,3,3]、B=[2,3]→A=[1,2,3,3,3]，B为空；相等项A原结点在B前；任一空。

> [!faq]- 识别模板、推导与完整代码｜先尝试再展开
>
> **考场识别 → [[2.知识库/20.North_star_ZJU/202.计算机知识/05数据结构/08算法题/03算法题模板#L2 摘点分流与尾插|L2 摘点分流与尾插]]**：“有序两链＋重接”比较未处理首，尾插较小者。
>
> **关键状态**：p,q是两条未处理链的首，tail是结果尾；头A只作哨兵。
>
> **解题步骤**
> 1. 暂存两表首，清空两个头的next，tail=A。
> 2. 比较p,q，较小者接到tail并推进该链，等值先A。
> 3. tail推进；最后把未耗尽的链整体接上。
>
> **为什么成立**：每次选未处理的最小值；等值优先顺序保证稳定；所有数据结点恰使用一次。
>
> **时间／额外空间**：O(n+m)／O(1)。
>
> **易错核对**：输入不能共享结点或头；B的旧数据现归A所有，不可按原B再次释放；相等取左侧。
>
> **完整核心代码**（本卡单独配公共类型编译）
>
> ```cpp
> void MergeSortedLists(LinkList A, LinkList B) {
>     LNode *p = A->next, *q = B->next, *tail = A;
>     A->next = B->next = NULL;
>     while (p != NULL && q != NULL) {
>         if (p->data <= q->data) { tail->next = p; p = p->next; }
>         else { tail->next = q; q = q->next; }
>         tail = tail->next;
>     }
>     tail->next = p != NULL ? p : q;
> }
> ```

### L03 有序链表减去另一表中的值

**来源**：自编：有序推进＋删除所有权。

- [x] 首次：能说明状态并独立写出
- [ ] 间隔复写：不看答案通过边界检查

**题干**：A、B是两条非递减无环带头链表，无共享结点，内部可重复。从A中删除并释放所有值在B中出现的结点，保留其余项及重复次数，B结构和值不变。结点由new创建；O(n+m)时间、O(1)空间。

**先手推自测**：A=[1,2,2,3,5]，B=[2,4]→A=[1,3,5]，B不变；B为空→A不变；全部删后A空。

> [!faq]- 识别模板、推导与完整代码｜先尝试再展开
>
> **考场识别 → [[2.知识库/20.North_star_ZJU/202.计算机知识/05数据结构/08算法题/03算法题模板#L2 摘点分流与尾插|L2 摘点分流与尾插]]**：“有序成员匹配＋删A不动B”是同步推进与前驱删除组合，不是无序每项都重扫B。
>
> **关键状态**：pre为A中已保留尾，p为待判A结点，q为B首个可能≥p值的位置。
>
> **解题步骤**
> 1. 对每个p，先将q推进到不小于p->data。
> 2. q等值则A结点应删：pre绕过p，delete，p回到pre->next。
> 3. 不匹配则保留，pre=p，p前进。
> 4. 等值时不必推进q，以便匹配A中的重复项。
>
> **为什么成立**：B有序且A处理值不减，q丢弃的小值不可能匹配后续A；前驱始终指向保留链尾。
>
> **时间／额外空间**：O(n+m)／O(1)。
>
> **易错核对**：删除后pre不前进；B数据结点不能释放；q相等后不推进才能一次删掉A的同值重复段。
>
> **完整核心代码**（本卡单独配公共类型编译）
>
> ```cpp
> void SubtractSortedList(LinkList A, LinkList B) {
>     LNode *pre = A, *p = A->next, *q = B->next;
>     while (p != NULL) {
>         while (q != NULL && q->data < p->data) q = q->next;
>         if (q != NULL && q->data == p->data) {
>             pre->next = p->next;
>             delete p;
>             p = pre->next;
>         } else { pre = p; p = p->next; }
>     }
> }
> ```
> 
> 
> ```cpp

>

>     struct LNode *next;

> // 408 考场满分风格答案
> void DifferenceList(LinkList A, LinkList B) {
>     // 边界检查：若链表指针为空，或 A/B 为空表，直接返回
>     if (A == NULL || B == NULL || A->next == NULL || B->next == NULL) {
>         return;
>     }
> 
>     LNode *pre = A;        // pre 始终指向 pa 的前驱结点，初始为 A 的头结点
>     LNode *pa = A->next;   // pa 遍历链表 A 的工作指针
>     LNode *pb = B->next;   // pb 遍历链表 B 的工作指针
> 
>     // 当两链表均未遍历完时，同步推进（归并思想）
>     while (pa != NULL && pb != NULL) {
>         if (pa->data == pb->data) {
>             // 1. 两值相等：从 A 中删除 pa，且 pb 保持不动（防 A 中有重复值漏删）
>             LNode *q = pa;         // 暂存待释放结点
>             pa = pa->next;         // pa 先后移
>             pre->next = pa;        // 前驱跳过被删结点，直接指向新 pa（注意 pre 不移！）
>             free(q);               // 安全释放内存，无内存泄漏
>         } 
>         else if (pa->data < pb->data) {
>             // 2. pa 较小：因链表非递减，B 后续元素更大，故该 pa 必不在 B 中，予以保留
>             pre = pa;              // 挪 pa 之前必须同步跟进 pre
>             pa = pa->next;
>         } 
>         else { // pa->data > pb->data
>             // 3. pb 较小：pb 追赶 pa
>             pb = pb->next;
>         }
>     }
>     // 循环结束时，若 pb 先空，A 剩余结点天然连在 pre 之后且均大于 B 中所有元素，无需额外处理
> }
> ```

### L04 按阈值稳定分成三组再连接

**来源**：旧稳定分组机制升级。

- [x] 首次：能说明状态并独立写出
- [ ] 间隔复写：不看答案通过边界检查

**题干**：带头单链表L按结点值与x的关系，稳定重排为小于x、等于x、大于x三段。复用全部数据结点，L地址不变，不申请或释放数据结点；O(n)时间、O(1)空间。

**先手推自测**：[3,1,2,4,2,0]、x=2→[1,0,2,2,3,4]；空、某组为空、全部等值；地址均保留。

> [!faq]- 识别模板、推导与完整代码｜先尝试再展开
>
> **考场识别 → [[2.知识库/20.North_star_ZJU/202.计算机知识/05数据结构/08算法题/03算法题模板#L2 摘点分流与尾插|L2 摘点分流与尾插]]**：“链表稳定分流”用每组头尾指针尾插，不照搬数组交换。
>
> **关键状态**：head[3]/tail[3]分别维护三组数据链首尾；p为未处理首，每次摘点先断旧边。
>
> **解题步骤**
> 1. 三组首尾初始化NULL。
> 2. 先保存p后继，再令p->next=NULL，根据值选择一组尾插。
> 3. 按组0、1、2串接，跳过空组，最后令结果尾next=NULL。
>
> **为什么成立**：每个结点恰进入一组；尾插保持组内原序，拼接只改变组间顺序。
>
> **时间／额外空间**：O(n)／O(1)，3组指针数量固定。
>
> **易错核对**：先存后继；摘点后断开旧链；不能用头插，否则组内逆序；头指针不是数据结点。
>
> **完整核心代码**（本卡单独配公共类型编译）
>
> ```cpp
> void StableThreeGroups(LinkList L, int x) {
>     LNode *head[3] = {NULL, NULL, NULL};
>     LNode *tail[3] = {NULL, NULL, NULL};
>     LNode *p = L->next;
>     while (p != NULL) {
>         LNode *next = p->next;
>         p->next = NULL;
>         int group = p->data < x ? 0 : (p->data == x ? 1 : 2);
>         if (head[group] == NULL) head[group] = p;
>         else tail[group]->next = p;
>         tail[group] = p;
>         p = next;
>     }
>     LNode *last = L;
>     for (int group = 0; group < 3; group++) {
>         if (head[group] != NULL) {
>             last->next = head[group];
>             last = tail[group];
>         }
>     }
>     last->next = NULL;
> }
> ```
```cpp
// 408 考场默认单链表结构体定义（卷面上若已给出则无需重写，不放心可写上）
typedef struct LNode {
    int data;
    struct LNode *next;
} LNode, *LinkList;

void PartitionList(LinkList L, int x) {
    // 边界条件检查：空表或没有数据结点，直接返回
    if (L == NULL || L->next == NULL) {
        return;
    }

    // 在栈上定义两个辅助头结点（不动态申请堆内存，严格符合题意且免去判空）
    LNode head_eq, head_gt;
    head_eq.next = NULL;
    head_gt.next = NULL;

    // 三个尾指针：r_lt 复用 L，r_eq 和 r_gt 指向辅助头结点
    LNode *r_lt = L;          // 小于 x 的链表尾指针
    LNode *r_eq = &head_eq;   // 等于 x 的链表尾指针
    LNode *r_gt = &head_gt;   // 大于 x 的链表尾指针

    LNode *p = L->next;       // p 为工作指针，指向当前待处理的第一个数据结点
    L->next = NULL;           // 将原头结点断链，置为空表状态

    // 遍历所有数据结点，按值尾插到对应链表（尾插法保证稳定性）
    while (p != NULL) {
        if (p->data < x) {
            r_lt->next = p;
            r_lt = p;         // 更新小于 x 链表的尾指针
        } else if (p->data == x) {
            r_eq->next = p;
            r_eq = p;         // 更新等于 x 链表的尾指针
        } else {
            r_gt->next = p;
            r_gt = p;         // 更新大于 x 链表的尾指针
        }
        p = p->next;          // 继续处理下一个结点
    }

    // 【核心防坑步】将三段链表首尾无缝拼接（巧妙处理某段为空的情况）
    r_lt->next = head_eq.next; // 小于段尾部 连上 等于段头部
    if (head_eq.next != NULL) {
        // 若等于段非空，则等于段的尾部是当前的合并尾部
        r_eq->next = head_gt.next; 
    } else {
        // 若等于段为空，则直接让小于段的尾部 连上 大于段的头部
        r_lt->next = head_gt.next; 
    }

    // 【致命防坑步】将整条链表的最后一个结点的 next 置空，防止出现环
    r_gt->next = NULL; 
    // 注：即使大于段为空，r_gt 指向 head_gt，令其 next 为 NULL 也完全合法且安全。
    // 但如果大于段为空，真正的尾结点可能是 r_eq 或 r_lt，它们的 next 已经在上面被赋值为 head_gt.next (即 NULL) 了，所以绝对安全！
}
```

### L05 删除所有大于原表平均值的结点

**来源**：保留旧L13好题。

>     }
>     LNode *pre = L, *p = L->next;
>     while (p != NULL) {
>         if ((long long)p->data * count > sum) {

### L07 判断链表回文并恢复原链

**题干**：带头无环单链表L，判断数据序列是否回文。允许临时改next，但返回前必须恢复全部原连接；不增删结点。O(n)时间、O(1)空间；空表与单点为真。

**先手推自测**：[1,2,1]真；[1,2,2,1]真；[1,2,3]假且原链必须完整；空真。

> [!faq]- 识别模板、推导与完整代码｜先尝试再展开
>
> **考场识别 → [[2.知识库/20.North_star_ZJU/202.计算机知识/05数据结构/08算法题/03算法题模板#L4 先定位再组合|L4 先定位再组合]]**：“前后对应＋单链无法逆向走＋要求恢复”拆成找中点、逆置后半、比较、恢复。
>
> **关键状态**：slow定位前半尾，奇数时包含中点；second是逆置后的后半首；ok记录比较而不提前返回。
>
> **解题步骤**
> 1. 快指针从首数据结点出发，每次走两步，定位slow。
> 2. 逆置slow之后的后半链并接回。
> 3. 从表首与second同时比较，后半耗尽即够。
> 4. 无论是否相等，都再次逆置后半并接回，再返回ok。
>
> **为什么成立**：前半与后半逆序逐项相等正是回文；中间项无需配对；两次逆置恢复相同结点连接。
>
> **时间／额外空间**：O(n)／O(1)。
>
> **易错核对**：比较失败不能立即return；奇数中点不参与后半；不要忘slow->next接回恢复结果。
>
> **完整核心代码**（本卡单独配公共类型编译）
>
> ```cpp
> LNode *ReverseDataChain(LNode *p) {
>     LNode *pre = NULL;
>     while (p != NULL) {
>         LNode *next = p->next;
>         p->next = pre; pre = p; p = next;
>     }
>     return pre;
> }
> bool IsPalindromeRestore(LinkList L) {
>     if (L->next == NULL || L->next->next == NULL) return true;
>     LNode *slow = L->next, *fast = L->next;
>     while (fast->next != NULL && fast->next->next != NULL) {
>         slow = slow->next;
>         fast = fast->next->next;
>     }
>     LNode *second = ReverseDataChain(slow->next);
>     slow->next = second;
>     LNode *p = L->next, *q = second;
>     bool ok = true;
>     while (q != NULL) {
>         if (p->data != q->data) ok = false;
>         p = p->next; q = q->next;
>     }
>     slow->next = ReverseDataChain(second);
>     return ok;
> }

### L08 摘出最长连续递增子链

**来源**：自编：扫描统计＋一次摘链组合。

- [ ] 首次：能说明状态并独立写出
- [ ] 间隔复写：不看答案通过边界检查

**题干**：带头无环单链表L，将最长连续严格递增的数据子链完整摘出，接到调用者提供的空带头链表R（R!=L）中，其余结点在L中保持原序。并列取原来最早的一段。空L时R仍空。两表不共享结点，不申请、不释放、不改data；O(n)时间、O(1)空间。

**先手推自测**：[1,2,0,1,2,-1]→R=[0,1,2]、L=[1,2,-1]；[1,2,0,1]并列取前段；全递增→L空；全相等→摘首项。

> [!faq]- 识别模板、推导与完整代码｜先尝试再展开
>
> **考场识别 → [[2.知识库/20.North_star_ZJU/202.计算机知识/05数据结构/08算法题/03算法题模板#L4 先定位再组合|L4 先定位再组合]]**：“连续段定位＋物理摘链”先只读找最优段的前驱和尾，再一次性改边；不在扫描时不断拆链。
>
> **关键状态**：currentPre/currentLength描述当前递增段；bestPre/bestTail保存最早最优段边界。
>
> **解题步骤**
> 1. 空表返回；用首项建立长度1的候选。
> 2. 沿原链扫描，下降或相等就开启新段，更新当前前驱。
> 3. 仅长度严格更大时保存bestPre与bestTail。
> 4. R->next指向bestPre->next；原前驱绕过该段；段尾next置NULL。
>
> **为什么成立**：相邻关系唯一确定所有极大递增段；最长段必为其中之一。扫描后一次摘出，不影响其他结点相对顺序。
>
> **时间／额外空间**：O(n)／O(1)。
>
> **易错核对**：R必须原本为空；长度1并列不能更新；要保存前驱而不是只有段首；摘走整表时头L仍保留。
>
> **完整核心代码**（本卡单独配公共类型编译）
>
> ```cpp
> void ExtractLongestIncreasingRun(LinkList L, LinkList R) {
>     if (L->next == NULL) return;
>     LNode *currentPre = L, *bestPre = L, *bestTail = L->next;
>     LNode *previous = L->next;
>     int currentLength = 1, bestLength = 1;
>     for (LNode *p = previous->next; p != NULL; p = p->next) {
>         if (p->data > previous->data) currentLength++;
>         else { currentPre = previous; currentLength = 1; }
>         if (currentLength > bestLength) {
>             bestLength = currentLength;
>             bestPre = currentPre; bestTail = p;
>         }
>         previous = p;
>     }
>     R->next = bestPre->next;
>     bestPre->next = bestTail->next;
>     bestTail->next = NULL;
> }
> ```

### L09 按地址找两个链表的共同后缀首结点

**题干**：两条无环带头链表A、B可能共享部分数据结点，但头结点不同。按地址找第一个公共数据结点，无交点返回NULL；不修改也不释放任何结点。O(n+m)时间、O(1)空间。

**先手推自测**：两链数据值相同但结点独立→NULL；A前缀长2、B前缀长1共享尾→返回该尾首地址；空链。

> [!faq]- 识别模板、推导与完整代码｜先尝试再展开
>
> **考场识别 → [[2.知识库/20.North_star_ZJU/202.计算机知识/05数据结构/08算法题/03算法题模板#L4 先定位再组合|L4 先定位再组合]]**：“无环共享尾＋地址相等”先消除长度差，再同步走，不是找值相同。
>
> **关键状态**：n,m是数据结点数；p,q在对齐后到各自末尾的剩余长度相同。
>
> **解题步骤**
> 1. 分别统计两链长度。
> 2. 长链先走长度差步。
> 3. 再同步走到p==q；若不相交最后二者同时为NULL。
>
> **为什么成立**：共享结点之后next相同，所以共享部分必为后缀；长度对齐使到共同首点的距离相等。
>
> **时间／额外空间**：O(n+m)／O(1)。
>
> **易错核对**：必须比较指针不是data；不能按两份独立链表释放共享尾；本题不处理环。
>
> **完整核心代码**（本卡单独配公共类型编译）
>
> ```cpp
> LNode *FirstSharedNode(LinkList A, LinkList B) {
>     int n = 0, m = 0;
>     for (LNode *p = A->next; p != NULL; p = p->next) n++;
>     for (LNode *q = B->next; q != NULL; q = q->next) m++;
>     LNode *p = A->next, *q = B->next;
>     while (n > m) { p = p->next; n--; }
>     while (m > n) { q = q->next; m--; }
>     while (p != q) { p = p->next; q = q->next; }
>     return p;
> }
> ```
