### 主练｜人数最均衡、总和差最大的分组

- [x] 独立思考并留下完整作答

整数数组 A，n≥2，允许负数和重复值。分成不相交两组 S1、S2，覆盖全部元素，且 |S1|=floor(n/2)、|S2|=ceil(n/2)。原地让前 floor(n/2) 个元素属于 S1，最大化 sum(S2)−sum(S1)，返回最大差值。不要求组内有序。

**“把数组里最小的一半数扔到数组前面，最大的一半数扔到后面，然后用后面所有大数的和，减去前面所有小数的和，把这个差值算出来返回。”**

```c
long long MaxGroupDiff(int A[], int n);
```

**要求**：不得完整排序。使用划分选择；说明平均 O(n)、最坏 O(n²)，额外空间 O(1)。  
**自测**：[4,1,7,2,9] → 小组{1,2}，大组{4,7,9}，差17；[-5,-2,3,8] → 18；[2,2,2] → 2。

### 主练｜无权图最短路径条数 <font color="#ff0000">不会</font>

- [ ] 独立思考并留下完整作答

无向简单图可不连通，顶点0..V−1，给定合法源点 s。求到各点最短边数 dist 和不同最短路径条数 ways，条数对 1000000007 取模。不可达 dist=−1、ways=0；s 到自身的空路径计1条。

```c
void ShortestWays(LGraph *G, int s, int dist[], long long ways[]);
```

**要求**：邻接表时间 O(V+E)，额外空间 O(V)。同一顶点最多入队一次。  
**自测**：边{0-1,0-2,1-3,2-3}，源0 → dist=[0,1,1,2]、ways=[1,1,1,2]；再加孤立4 → (−1,0)。

>     if (G == NULL || s < 0 || s >= G->vexnum) {
>         return;
>     }

>     for (int i = 0; i < V; i++) {

>         }
>     }
> 
>     // 步骤五：释放队列内存，防止内存泄漏

> #### 1. 算法设计思想
> 本题采用**单调递减栈**结合**虚拟双倍数组遍历**的思想：
> 1. **初始化**：将结果数组 `ans` 的全部 $n$ 个位置默认填为 `-1`。开辟一个容量为 $n$ 的整型数组模拟顺序栈，栈内存储**数组下标**，栈顶指针 `top = -1`。
> 2. **模拟循环遍历**：为了处理环形逻辑，让遍历指针 $i$ 从 $0$ 循环至 $2n - 1$。通过 `i % n` 获取当前考察的实际数组元素 `A[i % n]`。
> 3. **单调栈维护**：
>    - 比较当前元素 `A[i % n]` 与栈顶下标对应的元素 `A[stack[top]]`。
>    - 若当前元素严格大于栈顶元素，说明找到了栈顶元素的“下一个更大值”：弹出栈顶下标 `idx`，令 `ans[idx] = A[i % n]`。循环此过程直到栈为空或栈顶元素大于等于当前元素。
>    - 进栈限制：仅当 $i < n$（即第一轮扫描）时，才将当前下标 $i$ 压入栈中（第二轮扫描只充当“打擂者”帮助未匹配的栈内元素寻找答案，无需入栈）。
> 4. 遍历结束后，栈内残留的元素说明在整圈中均不存在比其更大的值，其对应的 `ans` 保持默认的 `-1`。释放栈空间即可。

> #### 2. 考场满分代码（原生指针 + 数组模拟栈）
> 
> ```c
> #include <stdio.h>
> #include <stdlib.h>
> 
> void NextGreaterCircular(int A[], int n, int ans[]) {
>     // 边界特判：空数组直接返回
>     if (A == NULL || ans == NULL || n <= 0) {
>         return;
>     }
> 
>     // 1. 初始化 ans 数组，默认全填 -1（处理无更大元素的情况）
>     for (int i = 0; i < n; i++) {
>         ans[i] = -1;
>     }
> 
>     // 2. 数组模拟顺序栈，栈内存储下标，容量至多为 n
>     int *stack = (int *)malloc(sizeof(int) * n);
>     int top = -1; // 栈顶指针，-1 为空
> 
>     // 3. 循环 2*n 次，利用 i % n 模拟环形访问
>     for (int i = 0; i < 2 * n; i++) {
>         int curIdx = i % n;
>         int curVal = A[curIdx];
> 
>         // 维护单调递减栈：若当前值严格大于栈顶下标对应的值，说明找到了目标
>         while (top != -1 && A[stack[top]] < curVal) {
>             int popIdx = stack[top--]; // 弹出栈顶下标
>             ans[popIdx] = curVal;      // 记录答案
>         }
> 
>         // 只有第一圈（i < n）的元素需要入栈等待寻找更大值
>         // 第二圈只需充当匹配角色，不重复入栈，确保栈不溢出且下标不覆盖
>         if (i < n) {
>             stack[++top] = curIdx;
>         }
>     }
> 
>     // 4. 释放动态分配的栈空间
>     free(stack);
> }
> ```
> 
> ---
> 
> #### 3. 复杂度分析
> * **时间复杂度**：$\mathcal{O}(n)$。
>   外层 `for` 循环严格执行 $2n$ 次。对于单调栈操作，前 $n$ 个元素的每个下标至多进栈一次、出栈一次。因此出入栈和条件比较的总次数不超过 $2n$ 次。均摊下来每个元素耗时为 $\mathcal{O}(1)$，总时间复杂度严格为 $\mathcal{O}(n)$，完全符合题意。
> * **空间复杂度**：$\mathcal{O}(n)$。
>   题目要求返回值通过调用者传入的 `ans` 数组携带（不计入额外空间）。算法本身仅额外动态开辟了一个容量为 $n$ 的辅助栈 `stack`，故额外空间复杂度为 $\mathcal{O}(n)$。
>

> 
> ### 四、 408 考场得分关键点提炼
> 
> 1. **栈里存“下标”还是存“数值”？**  
>    **务必存下标！** 很多考生写单调栈喜欢直接把 `A[i]` 压栈，出栈时懵了：“我知道比我大的数是哪个了，但我怎么知道要把答案写回 `ans` 的哪个位置？”记住考场法则：**涉及单调栈，一律压入下标 `i`，既能根据下标查出数值 `A[stack[top]]`，出栈时又能直接把答案写入 `ans[idx]`。**
> 2. **`if (i < n)` 是神来之笔**：  
>    如果不加这个限制，第二圈跑完栈会溢出（因为栈开的大小是 `n`），而且会把 `ans` 里的有效结果用第二轮的相同下标再次覆盖。加了 `if (i < n)`，栈的容量永远不会超过 $n$，既安全又节约空间。

### 主练｜链式二叉树是否为小根堆

- [ ] 独立思考并留下完整作答

给任意形态的二叉链表。判断它是否同时满足：①完全二叉树；②每个父结点 data≤孩子 data。重复值允许，空树定义为合法小根堆。不可只检查父子大小。

```c
int IsMinHeapTree(BTNode *root);
```

**要求**：时间 O(n)，额外空间 O(n)。顺序队列容量按实际入队对象计算。  
**自测**：根1、仅右孩子2 → 假；根2、左1、右3 → 假；根1、左2、右2 → 真。

> [!faq]- 卡住再看｜只给破题问题
> 局部的大小关系，能否推出整棵树的形状正确？遇到缺失孩子后还有实孩子意味着什么？

> [!faq]- 写完再核对｜关键路线、陷阱与模板
> 层序按“左槽、右槽”检查。遇到任意空槽设 gap，之后若再遇非空孩子即失败；非空孩子另检查父≤子。只让非空结点入队则容量 n 足够。不要把“有两个孩子或无孩子”当作完全性。
> 
> #### 1. 算法基本设计思想
> 1. **边界处理**：根据题意，若 `root == NULL`（空树），直接返回 1。
> 2. **算法选型**：采用**基于辅助队列的层次遍历**，同时完成“完全二叉树校验”和“小根堆堆序性校验”。
> 3. **状态标志位设计**：引入布尔变量 `must_be_leaf = 0`，用于标记“是否已遇到空子树”。按照完全二叉树的定义，一旦某个结点缺少左孩子或右孩子，其后遍历到的所有结点**必须全部为叶子结点**。
> 4. **遍历与双重校验**：
>    * 将根结点入队。
>    * 当队列非空时出队结点 $p$：
>      * **堆序性校验**：若左孩子存在且 $p\to data > p\to lchild\to data$，或右孩子存在且 $p\to data > p\to rchild\to data$，返回 0。
>      * **左孩子检验**：若左孩子存在，若此时 `must_be_leaf == 1`（违背完全二叉树连续性），返回 0；否则将左孩子入队。若左孩子不存在，说明自此之后的结点不能再有任何孩子，置 `must_be_leaf = 1`。
>      * **右孩子检验**：若右孩子存在，若此时 `must_be_leaf == 1`（左空右有，或此前已出现缺孩子），返回 0；否则将右孩子入队。若右孩子不存在，置 `must_be_leaf = 1`。
> 5. 若队列遍历完毕均未违规，返回 1。
> 
> ---
> 
> #### 2. 考场代码实现（C 语言原生指针与数组模拟队列风格）
> 
> ```c
> #include <stdio.h>
> #include <stdlib.h>
> 
> #define MAXSIZE 1000 // 考场假定二叉树结点上限
> 
> // 二叉链表结点结构
> typedef struct BTNode {
>     int data;
>     struct BTNode *lchild, *rchild;
> } BTNode;
> 
> /* 判断是否同时满足完全二叉树与小根堆性质 */
> int IsMinHeapTree(BTNode *root) {
>     // 边界条件：空树是合法小根堆
>     if (root == NULL) {
>         return 1;
>     }
> 
>     // 手写数组模拟队列（杜绝 STL）
>     BTNode *queue[MAXSIZE];
>     int front = 0, rear = 0;
> 
>     // 状态标志：一旦置为 1，后续出队的结点必须全部为叶子结点
>     int must_be_leaf = 0;
> 
>     // 根结点入队
>     queue[rear++] = root;
> 
>     while (front < rear) {
>         BTNode *p = queue[front++]; // 出队
> 
>         /* 1. 检查小根堆堆序性（父结点 data <= 孩子结点 data） */
>         if (p->lchild != NULL && p->data > p->lchild->data) {
>             return 0;
>         }
>         if (p->rchild != NULL && p->data > p->rchild->data) {
>             return 0;
>         }
> 
>         /* 2. 检查左孩子并判定完全二叉树形态 */
>         if (p->lchild != NULL) {
>             // 如果之前已出现空分支，此时居然又冒出左孩子，必不是完全二叉树
>             if (must_be_leaf) {
>                 return 0;
>             }
>             queue[rear++] = p->lchild; // 左孩子入队
>         } else {
>             // 左孩子缺失，后续所有结点必须全是叶子结点
>             must_be_leaf = 1;
>         }
> 
>         /* 3. 检查右孩子并判定完全二叉树形态 */
>         if (p->rchild != NULL) {
>             // 若左空右有（must_be_leaf 已为 1），或此前已出现残缺，必不是完全二叉树
>             if (must_be_leaf) {
>                 return 0;
>             }
>             queue[rear++] = p->rchild; // 右孩子入队
>         } else {
>             // 右孩子缺失，后续所有结点必须全是叶子结点
>             must_be_leaf = 1;
>         }
>     }
> 
>     // 顺利完成层次遍历，且满足所有约束
>     return 1;
> }
> ```
> 
> ---
> 
> #### 3. 复杂度分析与边界说明
> 
> *   **时间复杂度**：$O(n)$。
>     *   算法采用层次遍历，树中每个结点仅入队、出队一次。每次出队只做常数次比较和指针运算，因此时间复杂度为 $O(n)$（$n$ 为树中结点总数），达到理论最优。
> *   **空间复杂度**：$O(n)$。
>     *   辅助数组模拟队列的最大占用空间取决于二叉树最后一层的最大结点数（对于完全二叉树，最后一层最多约为 $n/2$ 个结点），故辅助空间复杂度为 $O(n)$。
> *   **边界与极端情况分析**：
>     1.  **空树（$root = NULL$）**：入口第一行直接拦截，返回 1，严格符合题意。
>     2.  **单结点树**：根结点入队并出队，无左右孩子，`must_be_leaf` 被置 1，队列为空，退出循环并返回 1，逻辑正确。
>     3.  **只有右孩子、没有左孩子（如根结点只有右孩子）**：
>         *   检查左孩子时命中 `else`，`must_be_leaf` 置为 1；
>         *   紧接着检查右孩子时命中 `p->rchild != NULL && must_be_leaf`，直接拦截返回 0，逻辑闭环。
>     4.  **重复值**：代码中使用严谨的 `p->data > child->data` 判定非法，若相等（`p->data == child->data`）完全放行，符合“允许重复值”的要求。

> 
> 因为有 `0` 的存在，如果直接用单个滑动窗口去统计“和恰好等于 $K$”，左指针遇到 `0` 移不移动都会出问题。
> 
> 408 最顶级的破局思维是**数学转化（转化法）**：
> $$\text{和恰好等于 } K \text{ 的子数组数} = (\text{和}\le K \text{ 的子数组数}) - (\text{和}\le K - 1 \text{ 的子数组数})$$
> 
> #### 为什么转化后就极其简单了？
> 因为 $A[i] \ge 0$，“**和 $\le M$**” 具有**严格的单调性**：
> * 只要当前窗口和 `sum <= M`，那么**以 `right` 结尾的所有子数组（共 `right - left + 1` 个）的和一定都 $\le M$**！
> * 这样完全不用管里面有多少个 0，滑动窗口直接畅通无阻！
> 
> ---
> 
> ### 四、 考场标准满分代码（C 语言风格）
> 
> ```c
> // 辅助函数：滑动窗口计算“和不超过 max_val 的非空连续子数组个数”
> long long atMost(int A[], int n, int max_val) {
>     if (max_val < 0) return 0; // 和不可能小于 0
> 
>     long long count = 0;
>     long long wid = 0; // 窗口内的和，用 long long 防溢出
>     int left = 0;
> 
>     for (int right = 0; right < n; right++) {
>         wid += A[right];
>         
>         // 当和超标时，收缩左边界（单调递减）
>         while (wid > max_val) {
>             wid -= A[left++];
>         }
>         
>         // 核心：此时以 right 结尾且和 <= max_val 的合法区间正好有 (right - left + 1) 个
>         count += (right - left + 1);
>     }
>     return count;
> }
> 
> // 主函数：求和恰好为 K 的子数组个数
> long long countSubarrays(int A[], int n, int k) {
>     if (n <= 0 || k < 0) return 0;
> 
>     // 恰好为 K = 最多为 K 的方案数 - 最多为 K-1 的方案数
>     return atMost(A, n, k) - atMost(A, n, k - 1);
> }
> ```
> 
> ---
> 
> ### 五、 复杂度分析
> * **时间复杂度**：$O(n)$。`atMost` 函数中，`left` 和 `right` 指针均最多遍历数组一次，调用两次 `atMost`，总耗时为 $2 \times O(n) = O(n)$，达到理论最优。
> * **空间复杂度**：$O(1)$。仅使用常数个辅助变量，无任何额外数组开销。
