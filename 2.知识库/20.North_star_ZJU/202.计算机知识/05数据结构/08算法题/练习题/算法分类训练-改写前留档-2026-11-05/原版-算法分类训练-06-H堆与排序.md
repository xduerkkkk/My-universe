## 本专题公共积木

相关题目的完整辅助函数放在这里；使用时必须一起默写，不能只写一行函数调用。

> [!faq]- 公共积木｜第一次学时可打开；复写时遮住
> ```c
> void DownMax(int A[],int n,int i) {
>     int x=A[i];
>     for(int c=2*i+1;c<n;c=2*i+1) {
>         if(c+1<n && A[c+1]>A[c]) c++;
>         if(x>=A[c]) break;
>         A[i]=A[c]; i=c;
>     }
>     A[i]=x;
> }
> void DownMin(int A[],int n,int i) {

> ```

### H01 下滤与自底向上建堆

- [ ] 首次：能解释状态并写出代码
- [ ] 间隔复写：不看答案通过自测

**题干**：原地建大根堆。每次 DownMax 调用前，i 的左右子树已各自成堆。

**自测**：[1,3,2] → [3,1,2]；空、单元素不调用下滤；父值≥两孩子。

> [!faq]- 题解与完整核心代码｜尝试后再展开
> **解题步骤**
> 1. 从最后非叶结点 n/2-1 向0下滤。
> 2. 完整下滤见本页公共积木，必须能手写。
>
> ```c
> void BuildMaxHeap(int A[],int n) {
>     for(int i=n/2-1;i>=0;i--) DownMax(A,n,i);
> }
> ```
>
> **时间 / 额外空间**：总建堆 O(n)，单次下滤 O(log(n+1)) / O(1)。
>
> **易错核对**：建堆不是 n 次逐个插入的 O(n log n) 上界；0-based最后非叶是 n/2-1。

### H02 原地堆排序

- [ ] 首次：能解释状态并写出代码
- [ ] 间隔复写：不看答案通过自测

**题干**：原地非递减排序，允许 n=0。

**自测**：[3,1,2,1] → [1,1,2,3]；[] → []。

> [!faq]- 题解与完整核心代码｜尝试后再展开
> **解题步骤**
> 1. 先建大根堆。
> 2. 根与堆末交换，剩余堆长度 end，下滤不含已归位末端。
>
> ```c
> void HeapSort(int A[],int n) {
>     BuildMaxHeap(A,n);
>     for(int end=n-1;end>0;end--) {
>         int t=A[0]; A[0]=A[end]; A[end]=t;
>         DownMax(A,end,0);
>     }
> }
> ```
>
> **时间 / 额外空间**：O(n log(n+1)) / O(1)。
>
> **易错核对**：end 传的是剩余长度，不是闭区间右端下标。

### H03 最大的 k 个元素

- [ ] 首次：能解释状态并写出代码
- [ ] 间隔复写：不看答案通过自测

**题干**：1≤k≤n；result 容量≥k，返回 k 个最大元素组成的小根堆，不要求结果有序；非法 k 返回0。

**自测**：[3,1,5,2,4], k=2 → 堆中{4,5}、根4；k=1 → 最大值；重复值按元素保留。

> [!faq]- 题解与完整核心代码｜尝试后再展开
> **解题步骤**
> 1. 前 k 项建小根堆。
> 2. 只在新元素大于堆根时替换并下滤。
>
> ```c
> int TopK(int A[],int n,int k,int result[]) {
>     if(k<1 || k>n) return 0;
>     for(int i=0;i<k;i++) result[i]=A[i];
>     for(int i=k/2-1;i>=0;i--) DownMin(result,k,i);
>     for(int i=k;i<n;i++) if(A[i]>result[0]) {
>         result[0]=A[i]; DownMin(result,k,0);
>     }
>     return k;
> }
> ```
>
> **时间 / 额外空间**：O(n log(k+1))，更细为 O(k+(n-k)log(k+1)) / 结果 O(k)，此外 O(1)。
>
> **易错核对**：堆根是保留集合里最小者即第k大，不是全数组最小值。
