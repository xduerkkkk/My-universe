### G01 连通分量数与最大连通块

- [ ] 首次：能解释状态并写出代码
- [ ] 间隔复写：不看答案通过自测

**题干**：无向图求连通分量数，同时通过 maxSize 返回最大分量结点数；孤立点也是分量。

**自测**：5个点，边0-1、1-2、3-4 → 分量2，最大3；空图 → 0、0。

> [!faq]- 题解与完整核心代码｜尝试后再展开
> **解题步骤**
> 1. 外层扫描全部顶点，每次未访问点发起 DFS，统计本轮规模。
> 2. 标记在进入时置1。
>
> ```c
> int VisitSize(Graph *g,int u,int vis[]) {
>     vis[u]=1; int count=1;
>     for(Arc *e=g->head[u];e;e=e->next)
>         if(!vis[e->to]) count+=VisitSize(g,e->to,vis);
>     return count;
> }
> int Components(Graph *g,int *maxSize) {
>     int vis[MAXV]={0},count=0; *maxSize=0;
>     for(int u=0;u<g->n;u++) if(!vis[u]) {
>         int s=VisitSize(g,u,vis); count++;
>         if(s>*maxSize) *maxSize=s;
>     }
>     return count;
> }
> ```
>
> **时间 / 额外空间**：O(V+E) / O(MAXV+V) 含递归栈；按 V 分配为 O(V)。
>
> **易错核对**：不能只从0遍历，否则漏不连通分量。

### G02 无向图判环

- [ ] 首次：能解释状态并写出代码
- [ ] 间隔复写：不看答案通过自测

**题干**：无向简单图（无重边、无自环），判断是否有环；可不连通。

**自测**：单边0-1 → 无环；三角形 → 有环；两个树分量 → 无环。

> [!faq]- 题解与完整核心代码｜尝试后再展开
> **解题步骤**
> 1. DFS 记录父顶点。
> 2. 已访问邻点若不是父结点即有环。
>
> ```c
> int CycleDFS(Graph *g,int u,int parent,int vis[]) {
>     vis[u]=1;
>     for(Arc *e=g->head[u];e;e=e->next) {
>         int v=e->to;
>         if(!vis[v]) { if(CycleDFS(g,v,u,vis)) return 1; }
>         else if(v!=parent) return 1;
>     }
>     return 0;
> }
> int UndirectedCycle(Graph *g) {
>     int vis[MAXV]={0};
>     for(int u=0;u<g->n;u++) if(!vis[u] && CycleDFS(g,u,-1,vis)) return 1;
>     return 0;
> }
> ```
>
> **时间 / 额外空间**：O(V+E) / O(V) 递归栈，另固定 vis[MAXV]。
>
> **易错核对**：无向边回父亲不算环；允许平行边时需边ID，不能直接套本版本。

### G03 BFS 二分图染色

- [ ] 首次：能解释状态并写出代码
- [ ] 间隔复写：不看答案通过自测

**题干**：无向图判断能否二染色；可不连通，自环会使其失败。

**自测**：偶环 → 真；三角形 → 假；孤立点 → 真；自环 → 假。

> [!faq]- 题解与完整核心代码｜尝试后再展开
> **解题步骤**
> 1. 颜色初始 -1。
> 2. 每个分量从颜色0开始，邻点取反色，遇同色边失败。
>
> ```c
> int Bipartite(Graph *g) {
>     int color[MAXV],q[MAXV];
>     for(int i=0;i<g->n;i++) color[i]=-1;
>     for(int s=0;s<g->n;s++) if(color[s]<0) {
>         int f=0,r=0; q[r++]=s; color[s]=0;
>         while(f<r) {
>             int u=q[f++];
>             for(Arc *e=g->head[u];e;e=e->next) {
>                 int v=e->to;
>                 if(color[v]<0) { color[v]=1-color[u]; q[r++]=v; }
>                 else if(color[v]==color[u]) return 0;
>             }
>         }
>     }
>     return 1;
> }
> ```
>
> **时间 / 额外空间**：O(V+E) / O(MAXV)，按 V 分配为 O(V)。
>
> **易错核对**：入队时染色防止重复入队；不能只测一个分量。

### G04 无权最短距离与最短路径条数

- [ ] 首次：能解释状态并写出代码
- [ ] 间隔复写：不看答案通过自测

**题干**：无重边的无权图，源 s 合法；求 dist 与 ways，条数对 1000000007 取模。不可达 dist=-1、ways=0。

**自测**：有向菱形0→1、0→2、1→3、2→3 → dist[3]=2、ways[3]=2；源自身0、1。

> [!faq]- 题解与完整核心代码｜尝试后再展开
> **解题步骤**
> 1. 首次到达设距离并入队。
> 2. 每条满足 dist[v]=dist[u]+1 的边都累加路径数，等距到达不再次入队。
>
> ```c
> void BFSWays(Graph *g,int s,int dist[],long long ways[]) {
>     int q[MAXV],f=0,r=0;
>     for(int i=0;i<g->n;i++) { dist[i]=-1; ways[i]=0; }
>     dist[s]=0; ways[s]=1; q[r++]=s;
>     while(f<r) {
>         int u=q[f++];
>         for(Arc *e=g->head[u];e;e=e->next) {
>             int v=e->to;
>             if(dist[v]<0) { dist[v]=dist[u]+1; q[r++]=v; }
>             if(dist[v]==dist[u]+1) ways[v]=(ways[v]+ways[u])%1000000007;
>         }
>     }
> }
> ```
>
> **时间 / 额外空间**：O(V+E) / O(MAXV)，按 V 分配为 O(V)，输出另计。
>
> **易错核对**：BFS只能直接求等权/无权最短路；首次访问就拒绝后续等距累加会少计。

### G05 拓扑排序与有向图判环

- [ ] 首次：能解释状态并写出代码
- [ ] 间隔复写：不看答案通过自测

**题干**：有向图输出一个拓扑序 order；若有环返回0，否则返回1，空图合法。

**自测**：0→1→2 → [0,1,2]；0↔1 → 返回0，部分输出不可当完整拓扑序。

> [!faq]- 题解与完整核心代码｜尝试后再展开
> **解题步骤**
> 1. 统计入度。
> 2. 入度0入队。
> 3. 取出结点，删除所有出边，入度变0再入队。
> 4. 数量不足 n 即有环。
>
> ```c
> int Topological(Graph *g,int order[]) {
>     int deg[MAXV]={0},q[MAXV],f=0,r=0,k=0;
>     for(int u=0;u<g->n;u++) for(Arc *e=g->head[u];e;e=e->next) deg[e->to]++;
>     for(int i=0;i<g->n;i++) if(!deg[i]) q[r++]=i;
>     while(f<r) {
>         int u=q[f++]; order[k++]=u;
>         for(Arc *e=g->head[u];e;e=e->next) if(--deg[e->to]==0) q[r++]=e->to;
>     }
>     return k==g->n;
> }
> ```
>
> **时间 / 额外空间**：O(V+E) / O(MAXV)，按 V 分配为 O(V)。
>
> **易错核对**：不修改图本体；有向环检测不能套无向图 parent 排除法。

### G06 最少学期数

- [ ] 首次：能解释状态并写出代码
- [ ] 间隔复写：不看答案通过自测

**题干**：边 u→v 表示 u 必须先修完，任意学期可并行修任意多门、每门一学期；有环返回 -1，否则返回最少学期，空图0。

**自测**：0→2、1→2、2→3 → 3学期；无边非空图 → 1；有环 → -1。

> [!faq]- 题解与完整核心代码｜尝试后再展开
> **解题步骤**
> 1. 拓扑 DP：semester[v]=max(semester[v],semester[u]+1)，源点为1。
> 2. 检查实际删除数量。
>
> ```c
> int MinSemesters(Graph *g) {
>     int deg[MAXV]={0},sem[MAXV],q[MAXV],f=0,r=0,count=0,best=0;
>     for(int u=0;u<g->n;u++) {
>         sem[u]=1;
>         for(Arc *e=g->head[u];e;e=e->next) deg[e->to]++;
>     }
>     for(int u=0;u<g->n;u++) if(!deg[u]) q[r++]=u;
>     while(f<r) {
>         int u=q[f++]; count++; if(sem[u]>best) best=sem[u];
>         for(Arc *e=g->head[u];e;e=e->next) {
>             int v=e->to;
>             if(sem[u]+1>sem[v]) sem[v]=sem[u]+1;
>             if(--deg[v]==0) q[r++]=v;
>         }
>     }
>     return count==g->n?best:-1;
> }
> ```
>
> **时间 / 额外空间**：O(V+E) / O(MAXV)，按 V 分配为 O(V)。
>
> **易错核对**：这是无限并行前提下最长依赖链，不是课程总数。

### G07 拓扑序是否唯一

- [ ] 首次：能解释状态并写出代码
- [ ] 间隔复写：不看答案通过自测

**题干**：返回 -1 表示有环，0 表示存在多个拓扑序，1 表示唯一；空图的空序列按唯一。

**自测**：链0→1→2 → 1；0→2、1→2 → 0；环加孤立点 → -1。

> [!faq]- 题解与完整核心代码｜尝试后再展开
> **解题步骤**
> 1. 每次取点前，若当前可选零入度点超过1，记录不唯一。
> 2. 最后仍优先判环。
>
> ```c
> int UniqueTopo(Graph *g) {
>     int deg[MAXV]={0},q[MAXV],f=0,r=0,k=0,unique=1;
>     for(int u=0;u<g->n;u++) for(Arc *e=g->head[u];e;e=e->next) deg[e->to]++;
>     for(int u=0;u<g->n;u++) if(!deg[u]) q[r++]=u;
>     while(f<r) {
>         if(r-f>1) unique=0;
>         int u=q[f++]; k++;
>         for(Arc *e=g->head[u];e;e=e->next) if(--deg[e->to]==0) q[r++]=e->to;
>     }
>     return k<g->n?-1:unique;
> }
> ```
>
> **时间 / 额外空间**：O(V+E) / O(MAXV)，按 V 分配为 O(V)。
>
> **易错核对**：看到多个候选不能直接返回0，因为剩余部分仍可能有环。

### G08 并查集连通分量

- [ ] 首次：能解释状态并写出代码
- [ ] 间隔复写：不看答案通过自测

**题干**：n≤MAXV 顶点与 m 条无向边 edges[m][2]；合并并求分量数。允许重复边、自环。

**自测**：n=4，边(0,1),(1,0),(2,2) → 3；无边 → n。

> [!faq]- 题解与完整核心代码｜尝试后再展开
> **解题步骤**
> 1. 初始化每点一集合。
> 2. 路径压缩+按大小合并，只有合并成功才减少分量数。
>
> ```c
> typedef struct { int p[MAXV],size[MAXV]; } DSU;
> void DSInit(DSU *d,int n) {
>     for(int i=0;i<n;i++) { d->p[i]=i; d->size[i]=1; }
> }
> int Find(DSU *d,int x) {
>     if(d->p[x]!=x) d->p[x]=Find(d,d->p[x]);
>     return d->p[x];
> }
> int Join(DSU *d,int a,int b) {
>     a=Find(d,a); b=Find(d,b);
>     if(a==b) return 0;
>     if(d->size[a]<d->size[b]) { int t=a; a=b; b=t; }
>     d->p[b]=a; d->size[a]+=d->size[b]; return 1;
> }
> int DSComponents(int n,int edges[][2],int m) {
>     DSU d; DSInit(&d,n); int count=n;
>     for(int i=0;i<m;i++) count-=Join(&d,edges[i][0],edges[i][1]);
>     return count;
> }
> ```
>
> **时间 / 额外空间**：O(V+E α(V)) 摊还 / O(MAXV)，按 V 分配为 O(V)。
>
> **易错核对**：按根合并，不是直接把任意原顶点的父亲指向另一个原顶点。

### G09 Kruskal 最小生成树

- [ ] 首次：能解释状态并写出代码
- [ ] 间隔复写：不看答案通过自测

**题干**：无向带权边数组，允许负权及重边；n≥1。成功写总权值并返回1，不连通返回0；允许改边顺序。

**自测**：三角形边权1,2,5 → 成功且和3；两个孤立点 → 失败；单点无边 → 成功和0。

> [!faq]- 题解与完整核心代码｜尝试后再展开
> **解题步骤**
> 1. 自写边堆排序，边按权升序。
> 2. 并查集判两端不连通才取边，选满 n-1 条才成功。复用上一题完整 DSU。
>
> ```c
> typedef struct { int u,v; long long w; } Edge;
> void EdgeDown(Edge a[],int n,int i) {
>     Edge x=a[i];
>     for(int c=2*i+1;c<n;c=2*i+1) {
>         if(c+1<n && a[c+1].w>a[c].w) c++;
>         if(x.w>=a[c].w) break;
>         a[i]=a[c]; i=c;
>     }
>     a[i]=x;
> }
> void EdgeSort(Edge a[],int n) {
>     for(int i=n/2-1;i>=0;i--) EdgeDown(a,n,i);
>     for(int end=n-1;end>0;end--) {
>         Edge t=a[0]; a[0]=a[end]; a[end]=t; EdgeDown(a,end,0);
>     }
> }
> int Kruskal(int n,Edge e[],int m,long long *sum) {
>     DSU d; DSInit(&d,n); EdgeSort(e,m);
>     int count=0; *sum=0;
>     for(int i=0;i<m && count<n-1;i++) if(Join(&d,e[i].u,e[i].v)) {
>         *sum+=e[i].w; count++;
>     }
>     return count==n-1;
> }
> ```
>
> **时间 / 额外空间**：O(V+E log(E+1)+E α(V)) / 固定 DSU O(MAXV)，排序 O(1)。
>
> **易错核对**：返回成功标志与权值分离，避免合法负权和 -1 与失败混淆。

### G10 Dijkstra 单源最短路

- [ ] 首次：能解释状态并写出代码
- [ ] 间隔复写：不看答案通过自测

**题干**：矩阵图，所有边权非负，n≥1，源 s 合法；输出 dist，不可达 INF。

**自测**：0→1权0、1→2权2、0→2权5 → [0,0,2]；孤立点 dist=INF。

> [!faq]- 题解与完整核心代码｜尝试后再展开
> **解题步骤**
> 1. dist 是源到点的当前最短估计。
> 2. 选最小未定点，若不存在有限距离则结束，再松弛其出边。
>
> ```c
> void Dijkstra(WGraph *g,int s,long long dist[]) {
>     int done[MAXV]={0};
>     for(int i=0;i<g->n;i++) dist[i]=INF;
>     dist[s]=0;
>     for(int k=0;k<g->n;k++) {
>         int u=-1;
>         for(int v=0;v<g->n;v++) if(!done[v] && (u<0 || dist[v]<dist[u])) u=v;
>         if(u<0 || dist[u]==INF) break;
>         done[u]=1;
>         for(int v=0;v<g->n;v++) if(!done[v] && g->w[u][v]!=INF) {
>             long long alt=dist[u]+g->w[u][v];
>             if(alt<dist[v]) dist[v]=alt;
>         }
>     }
> }
> ```
>
> **时间 / 额外空间**：O(V²) / O(MAXV)，按 V 分配为 O(V)，矩阵输入另计。
>
> **易错核对**：0权边是真边；负权图不能套 Dijkstra。

### G11 Prim 最小生成树

- [ ] 首次：能解释状态并写出代码
- [ ] 间隔复写：不看答案通过自测

**题干**：非空无向矩阵图，边权可负；成功写总权值并返回1，不连通返回0。

**自测**：三角形边权0,2,5 → 和2；两点边-1 → 成功且和-1；不连通 → 失败。

> [!faq]- 题解与完整核心代码｜尝试后再展开
> **解题步骤**
> 1. key[v] 是当前树集合连到 v 的最小边，不是源到 v 的路径长。
> 2. 每次选最小 key，再用单条边更新。
>
> ```c
> int Prim(WGraph *g,int s,long long *sum) {
>     int used[MAXV]={0}; long long key[MAXV];
>     for(int i=0;i<g->n;i++) key[i]=INF;
>     key[s]=0; *sum=0;
>     for(int k=0;k<g->n;k++) {
>         int u=-1;
>         for(int v=0;v<g->n;v++) if(!used[v] && (u<0 || key[v]<key[u])) u=v;
>         if(u<0 || key[u]==INF) return 0;
>         used[u]=1; *sum+=key[u];
>         for(int v=0;v<g->n;v++) if(!used[v] && g->w[u][v]<key[v]) key[v]=g->w[u][v];
>     }
>     return 1;
> }
> ```
>
> **时间 / 额外空间**：O(V²) / O(MAXV)，按 V 分配为 O(V)。
>
> **易错核对**：与 Dijkstra 外形像，更新式却是边权，不是 dist[u]+边权。

### G12 Floyd 多源最短路

- [ ] 首次：能解释状态并写出代码
- [ ] 间隔复写：不看答案通过自测

**题干**：矩阵图可含负权边但没有负权回路；输出任意两点最短距离，不可达 INF。

**自测**：0→1权2、1→2权-1 → d[0][2]=1；不可达保持INF。

> [!faq]- 题解与完整核心代码｜尝试后再展开
> **解题步骤**
> 1. k 为最外循环逐步放开中间顶点。
> 2. 两段都可达才加和。对角初始化为0与已有自环权的较小值。
>
> ```c
> void Floyd(WGraph *g,long long d[MAXV][MAXV]) {
>     for(int i=0;i<g->n;i++) for(int j=0;j<g->n;j++) {
>         d[i][j]=g->w[i][j];
>         if(i==j && d[i][j]>0) d[i][j]=0;
>     }
>     for(int k=0;k<g->n;k++) for(int i=0;i<g->n;i++) {
>         if(d[i][k]==INF) continue;
>         for(int j=0;j<g->n;j++) if(d[k][j]!=INF) {
>             long long alt=d[i][k]+d[k][j];
>             if(alt<d[i][j]) d[i][j]=alt;
>         }
>     }
> }
> ```
>
> **时间 / 额外空间**：O(V³) / 结果矩阵 O(V²)，除此之外 O(1)。
>
> **易错核对**：INF不能参与加法；完成后若某 d[i][i]<0，说明存在负权回路，违反本题前提。
