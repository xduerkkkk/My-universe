### S04 非递归中序遍历

- [ ] 首次：能解释状态并写出代码
- [ ] 间隔复写：不看答案通过自测

**定位**：基础积木｜显式栈；服务树题，不单开栈队列冲刺主线。

**题干**：二叉树结点数不超过 MAXSIZE，用显式栈中序输出到 result 数组并返回个数；输出数组容量足够，空树返回0。

**自测**：根2左1右3 → [1,2,3]；纯右链仍从根向下输出；空树→0。

> [!faq]- 题解与完整核心代码｜先说状态，再核对
> **变量存什么**：`top` 统一表示栈顶下标，空栈为-1；`p` 是当前要展开的子树；`count` 为输出个数。
>
> **解题步骤**
> 1. p 非空时沿左链逐个入栈；入栈先++top再写。
> 2. 左边走尽后弹出栈顶访问；弹栈先读再top--。
> 3. 把 p 转向刚访问结点的右孩子，继续同样过程。
> 4. 外层条件为 p 非空或栈非空，不能只判断 p。
>
> ```cpp
> int IterInorder(BTNode *p, int result[]) {
>     BTNode *stack[MAXSIZE];
>     int top = -1;
>     int count = 0;
>     while (p != NULL || top != -1) {
>         while (p != NULL) {
>             stack[++top] = p;
>             p = p->lchild;
>         }
>         p = stack[top--];
>         result[count++] = p->data;
>         p = p->rchild;
>     }
>     return count;
> }
> ```
>
> **时间 / 额外空间**：O(n) / 本固定数组分配 O(MAXSIZE)，实际最多存 O(h) 个指针；若按已知高度动态申请才是 O(h) 分配空间。
>
> **易错核对**：top=-1 这套约定与旧版top表示个数不同，压栈/出栈/判空须一起改；固定数组不必为了统一初始化而改成 new。
