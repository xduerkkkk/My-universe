### G07 拓扑序是否唯一

- [ ] 首次：能解释状态并写出代码
- [ ] 间隔复写：不看答案通过自测

**定位**：主练｜2024·41：按用户题型改写。

**题干**：有向图用公共约定的邻接表 ALGraph 存储。返回-1表示有环、无拓扑序；0表示拓扑序不唯一；1表示唯一。空图的空序列按唯一处理。

**自测**：0→1→2 → 1；0→2、1→2 → 0；0↔1 → -1；有独立点且另有环 → -1。

> [!faq]- 题解与完整核心代码｜先说状态，再核对
> **变量存什么**：`indegree[v]` 为剩余入度；`q[front..rear-1]` 为当前可选的零入度点；`count` 为已删除顶点数。
>
> **解题步骤**
> 1. 扫描所有边统计入度，把全部零入度点入队。
> 2. 每次选点前，若队列里超过一个候选，则至少有两种选择，记住“不唯一”。
> 3. 出队一个点，删除它的所有出边；相邻点入度减到0才入队。
> 4. 必须处理到最后：count小于顶点数时先判有环；否则再根据此前候选数判唯一。
>
> **手推一遍**：0→2、1→2：初始队列有0、1两个候选，记不唯一；删完0和1后2入队，最终确实无环，才返回0。
>
> ```cpp
> int UniqueTopo(const ALGraph &G) {
>     int n = G.vexnum;
>     int *indegree = new int[n]();
>     int *q = new int[n]();
>     for (int v = 0; v < n; v++) {
>         for (ArcNode *p = G.vertices[v].firstarc; p != NULL; p = p->nextarc) {
>             indegree[p->adjvex]++;
>         }
>     }
>     int front = 0, rear = 0;
>     for (int v = 0; v < n; v++) {
>         if (indegree[v] == 0) q[rear++] = v;
>     }
>     int count = 0;
>     bool unique = true;
>     while (front < rear) {
>         if (rear - front > 1) unique = false;
>         int v = q[front++];
>         count++;
>         for (ArcNode *p = G.vertices[v].firstarc; p != NULL; p = p->nextarc) {
>             int w = p->adjvex;
>             indegree[w]--;
>             if (indegree[w] == 0) q[rear++] = w;
>         }
>     }
>     delete[] indegree;
>     delete[] q;
>     if (count < n) return -1;
>     return unique ? 1 : 0;
> }
> ```
>
> **时间 / 额外空间**：O(V+E) / O(V) 辅助数组；图本身不计入额外空间。
>
> **易错核对**：发现多个零入度点时不要立刻返回0，剩余子图可能还有环；零入度选择必须逐轮检查，不是只看初始队列。

旧作答/批注：[[算法分类训练-改写前留档-2026-11-05/原版-算法分类训练-05-G图.md#G07 拓扑序是否唯一|改写前完整留档]]。

### G13 有向图 K 顶点（出度大于入度）

- [ ] 首次：能解释状态并写出代码
- [ ] 间隔复写：不看答案通过自测

**定位**：主练｜2023·41：按用户题型改写；用户已满分，安排间隔复写而非加量。

**题干**：有向图邻接表 ALGraph，统计出度严格大于入度的顶点数。顶点编号0..vexnum-1。

**自测**：0→1、2→1 → 顶点0和2，共2个；空图0；只含一条自环的顶点入度=出度，不计。

> [!faq]- 题解与完整核心代码｜先说状态，再核对
> **变量存什么**：`outdegree[v]` 统计从 v 发出的邻接项；`indegree[w]` 统计所有指向 w 的邻接项。
>
> **解题步骤**
> 1. 申请两个长度为顶点数的零数组。
> 2. 扫描 v 的每个邻接项 v→w，同时 outdegree[v]++、indegree[w]++。
> 3. 扫描所有顶点，对严格 outdegree>indegree 的点计数。
> 4. 释放两个辅助数组，返回计数。
>
> ```cpp
> int CountKVertices(const ALGraph &G) {
>     int n = G.vexnum;
>     int *indegree = new int[n]();
>     int *outdegree = new int[n]();
>     for (int v = 0; v < n; v++) {
>         for (ArcNode *p = G.vertices[v].firstarc; p != NULL; p = p->nextarc) {
>             outdegree[v]++;
>             indegree[p->adjvex]++;
>         }
>     }
>     int count = 0;
>     for (int v = 0; v < n; v++) {
>         if (outdegree[v] > indegree[v]) count++;
>     }
>     delete[] indegree;
>     delete[] outdegree;
>     return count;
> }
> ```
>
> **时间 / 额外空间**：O(V+E) / O(V)。
>
> **易错核对**：某顶点邻接表长度只能直接得到出度；求入度需要看全图所有邻接表。严格>，不是≥。

### G15 无向连通图 EL 路径判定

- [ ] 首次：能解释状态并写出代码
- [ ] 间隔复写：不看答案通过自测

**定位**：主练｜2021·41：用户记录14/15分，不是10分应用题，保留代码题主线。

**题干**：无向连通简单图，用邻接表 ALGraph 存储，每条无向边存两个邻接项，顶点数至少1。判断能否从某点出发恰好经过每条边一次；允许起终点相同。单顶点无边按存在零长度欧拉通路处理。

**自测**：三角形：奇度点0个→真；一条链：奇度点2个→真；中心连3片叶的星形：奇度点4个→假。

> [!faq]- 题解与完整核心代码｜先说状态，再核对
> **变量存什么**：`degree` 是当前顶点的邻接表长度，即无向图的度；`oddCount` 是奇度顶点数。
>
> **解题步骤**
> 1. 题干已保证无向连通，不重复写DFS验证连通性。
> 2. 逐顶点扫描邻接表，统计该点度数。
> 3. 度为奇数就累加oddCount。
> 4. 奇度点恰为0个或2个时存在所定义的通路，否则不存在。
>
> ```cpp
> bool HasELPath(const ALGraph &G) {
>     int oddCount = 0;
>     for (int v = 0; v < G.vexnum; v++) {
>         int degree = 0;
>         for (ArcNode *p = G.vertices[v].firstarc; p != NULL; p = p->nextarc) {
>             degree++;
>         }
>         if (degree % 2 == 1) oddCount++;
>     }
>     return oddCount == 0 || oddCount == 2;
> }
> ```
>
> **时间 / 额外空间**：O(V+E) / O(1)。
>
> **易错核对**：0个奇度点对应可闭合的欧拉回路，2个对应不同起终点的欧拉通路；本题允许两者。若题干未保证连通，必须另查所有有边顶点的连通性，不能只数奇度点。

### G14 有向图两顶点间是否存在通路

- [ ] 首次：能解释状态并写出代码
- [ ] 间隔复写：不看答案通过自测

**定位**：迁移选练｜自编结构内迁移；DFS/BFS 加目标条件，不标真题年份。

**题干**：有向图邻接表 ALGraph，start、target 是合法顶点。判断从 start 到 target 是否存在通路，本训练允许长度为0的通路，因此 start==target 为真。

**自测**：0→1→2：0到2真，2到0假；不连通图中不可达为假；含环也必须结束。

> [!faq]- 题解与完整核心代码｜先说状态，再核对
> **变量存什么**：`visited[v]` 在入队时置1；`q` 存待扩展顶点，front/rear 均从0开始。
>
> **解题步骤**
> 1. 起点等于终点直接成功；否则起点入队并立刻标记。
> 2. 逐个出队，检查它的所有出邻接点。
> 3. 发现目标就记成功；其余未访问点入队并标记，避免环导致反复入队。
> 4. 统一释放两个数组，再返回结果。
>
> ```cpp
> bool HasPath(const ALGraph &G, int start, int target) {
>     if (start == target) return true;
>     int n = G.vexnum;
>     int *visited = new int[n]();
>     int *q = new int[n]();
>     int front = 0, rear = 0;
>     q[rear++] = start;
>     visited[start] = 1;
>     bool found = false;
>     while (front < rear && !found) {
>         int v = q[front++];
>         for (ArcNode *p = G.vertices[v].firstarc; p != NULL; p = p->nextarc) {
>             int w = p->adjvex;
>             if (w == target) {
>                 found = true;
>                 break;
>             }
>             if (visited[w] == 0) {
>                 visited[w] = 1;
>                 q[rear++] = w;
>             }
>         }
>     }
>     delete[] visited;
>     delete[] q;
>     return found;
> }
> ```
>
> **时间 / 额外空间**：最坏 O(V+E) / O(V)，零初始化数组本身也要 O(V)。
>
> **易错核对**：有向通路有方向；每个顶点最多入队一次的前提是入队时就标记，不是出队后才标记。
