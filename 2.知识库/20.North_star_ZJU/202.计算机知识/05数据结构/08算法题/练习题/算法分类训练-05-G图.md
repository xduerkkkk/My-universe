### G01 统计成树的连通分量&

**来源与定位**：旧G01升级；保留第一批已评审解析，历史原文在trash归档。

- [ ] 首次：能解释状态并独立写出
- [ ] 间隔复写：不看答案通过自测

**题干**：无向简单图采用邻接表存储，无重边、无自环，允许不连通；每条无向边在两端各存一个邻接项。统计其中有多少个连通分量是一棵树，孤立顶点也算一棵树。

图可以为空，此时结果为0。不得修改原图，要求时间复杂度为$O(|V|+|E|)$，辅助空间为$O(|V|)$。

**自测（先手推）**

- 3个孤立顶点 → `3`；空图 → `0`。
- 三角形与一个孤立顶点 → `1`。
- 一条3顶点链和一个3顶点环，二者不连通 → `1`。
- 两个顶点之间只有一条边 → `1`，不是0。

> [!faq]- 分析与408风格参考解答｜尝试后展开
> **考场识别 → [[2.知识库/20.North_star_ZJU/202.计算机知识/05数据结构/08算法题/03算法题模板#G1 遍历范围与分量汇总|G1 遍历范围与分量汇总]]**：先找到一个分量再判断它：选G1全图遍历与分量汇总。
>
>
> **为什么选这题**：旧G01只统计分量规模。本题增加一项结构性质，但不引入新的高级图算法；清楚标为旧题升级，不把换任务包装成全新模板。
>
> **从定义到算法**
>
> 一轮DFS到达的点构成一个连通分量。对于已连通的无向简单图，点数为k时，恰有k−1条边等价于无环。因此遍历中同时统计点数和边数即可，不必对每个点重复启动判环。
>
> **变量含义**：`visited`跨分量保留；`vertexCount/degreeSum`每启动一轮DFS重置为0；`degreeSum`统计访问顶点的全部邻接项，不只是DFS树边。
>
> **编号步骤**
> 1. 全部顶点置未访问，答案置0。
> 2. 外层扫描顶点，每遇未访问点就启动一次DFS。
> 3. DFS进入顶点立即标记，点数加1；检查其每个邻接项时，`degreeSum`加1。
> 4. 本轮结束得到边数`degreeSum/2`。若等于`vertexCount-1`，答案加1。
> 5. 继续其他分量，最后释放标记数组。
>
> **小例子**：三角形点数3，邻接项数6，边数3，不等于2；孤立点点数1，邻接项数0，边数0，等于1−1。
>
> **正确性要点**：外层与标记保证各分量恰处理一次；所有邻接项都计数且每条边计两次，所得点边数准确；判据在“已经连通”的前提下使用。
>
> **时间／额外空间**：$O(|V|+|E|)$／$O(|V|)$，包含标记数组与最坏递归栈。空图为常数开销；非空规模按上述记法。
>
> **易错核对**：别只统计遇到未访问邻点时的边，那永远只得到DFS树边；不能拿全图总边数判断每个分量；不要漏孤立点；该版题干排除自环和重边。
>
> **完整核心代码**
>
> ```cpp
> void CountComponent(const ALGraph &G, int v, int visited[],
>                     int &vertexCount, int &degreeSum) {
>     visited[v] = 1;
>     vertexCount++;
>     for (ArcNode *p = G.vertices[v].firstarc; p != NULL; p = p->nextarc) {
>         degreeSum++;
>         int w = p->adjvex;
>         if (visited[w] == 0)
>             CountComponent(G, w, visited, vertexCount, degreeSum);
>     }
> }
>
> int TreeComponentCount(const ALGraph &G) {
>     int n = G.vexnum;
>     int *visited = new int[n]();
>     int answer = 0;
>     for (int v = 0; v < n; v++) {
>         if (visited[v] == 0) {
>             int vertexCount = 0, degreeSum = 0;
>             CountComponent(G, v, visited, vertexCount, degreeSum);
>             if (degreeSum / 2 == vertexCount - 1) answer++;
>         }
>     }
>     delete[] visited;
>     return answer;
> }
> ```

### G02 哪些顶点能够到达指定终点

**来源与定位**：保留第一批自编任务；不标真题年份或出题概率。

- [ ] 首次：能解释状态并独立写出
- [ ] 间隔复写：不看答案通过自测

**题干**：有向图以0/1邻接矩阵`A`存储，`A[u][v]=1`表示存在弧`u→v`。顶点编号为`0..n-1`，`1≤n≤MAXSIZE`，目标顶点`target`合法，图可能含环。

找出所有能够到达`target`的顶点，包含target自身（允许长度为0的通路）。按编号递增写入容量至少为n的`out[]`并返回个数。不得修改矩阵，要求最坏时间复杂度为$O(n^2)$，辅助空间$O(n)$。

**自测（先手推）**

- 弧`0→1→2`，`target=2` → `[0,1,2]`；`target=0` → `[0]`。
- 弧`0→1`与`2→1`，`target=1` → `[0,1,2]`。
- 弧`0→1,1→0`，另有孤立点`2`，`target=1` → `[0,1]`。
- 单顶点无边，目标0 → `[0]`。

> [!faq]- 分析与408风格参考解答｜尝试后展开
> **考场识别 → [[2.知识库/20.North_star_ZJU/202.计算机知识/05数据结构/08算法题/03算法题模板#G1 遍历范围与分量汇总|G1 遍历范围与分量汇总]]**：所有起点到同一终点：选G1反向可达；矩阵沿列读，无须重复跑n次。
>
>
> **为什么选这题**：不是把“从s能否到t”换个顶点编号，而是要求全部可行起点，并利用矩阵的列扫描改变问题方向。
>
> **朴素方法为什么慢**：从每个顶点各做一次矩阵DFS判能否到target，最坏$O(n^3)$。从target沿原图出边遍历则方向错误，只得到它能去哪里。
>
> **关键等价**：原图有路径`u→…→target`，当且仅当将每条弧反向后有路径`target→…→u`。矩阵不必真的转置：当前顶点为v时，扫描满足`A[u][v]!=0`的u，就在沿原图入边反向走。
>
> **变量含义**：`visited[u]`表示已从target沿反向边到达u，也就证明原图u能到target；v是当前反向遍历结点，u枚举它的前驱。
>
> **编号步骤**
> 1. 标记数组清零，从target发起反向DFS。
> 2. 进入v即标记，扫描矩阵第v列。
> 3. 若`A[u][v]`为1且u未访问，递归处理u。
> 4. 遍历结束按顶点编号扫描标记，将所有已访问顶点写入out。
> 5. 释放标记数组，返回写入个数。
>
> **小例子**：`0→1→2`从目标2开始：先找第2列的前驱1，再找第1列的前驱0。因此0、1、2都被标记，而不是从2沿空的出边立即结束。
>
> **正确性要点**：反向DFS恰好访问反向图中从target可达的顶点；反转路径的对应关系保证其恰好是原问题的答案集合。
>
> **时间／额外空间**：最多访问n个顶点，每个扫描n个矩阵格，$O(n^2)$／$O(n)$标记与递归栈。输入矩阵已有的$O(n^2)$存储不算额外工作空间；out另计输出空间。
>
> **易错核对**：必须读`A[u][v]`而非`A[v][u]`；没有复制或修改矩阵；target计入答案；入递归前已通过标记避免环上反复访问。
>
> **完整核心代码**
>
> ```cpp
> void ReverseDFS(const int A[][MAXSIZE], int n, int v, int visited[]) {
>     visited[v] = 1;
>     for (int u = 0; u < n; u++) {
>         if (A[u][v] != 0 && visited[u] == 0)
>             ReverseDFS(A, n, u, visited);
>     }
> }
>
> int VerticesReachingTarget(const int A[][MAXSIZE], int n, int target,
>                           int out[]) {
>     int *visited = new int[n]();
>     ReverseDFS(A, n, target, visited);
>     int count = 0;
>     for (int v = 0; v < n; v++)
>         if (visited[v] != 0) out[count++] = v;
>     delete[] visited;
>     return count;
> }
> ```

### G03 完成全部课程的最少学期数

**来源与定位**：旧G06重写；保留第一批已评审解析，历史原文在trash归档。

- [ ] 首次：能解释状态并独立写出
- [ ] 间隔复写：不看答案通过自测

**题干**：有向简单图采用邻接表存储，每个顶点为一门课程，弧`u→v`表示u必须在v之前的学期完成。每门课占一学期，每学期可并行学习任意多门满足先修条件的课程。

求修完全部课程至少需要几个学期；存在环时返回−1；没有课程时返回0。不得修改原图。要求时间复杂度为$O(|V|+|E|)$，辅助空间$O(|V|)$。

**自测（先手推）**

- 3门课均无依赖 → `1`；空图 → `0`。
- `0→1→2` → `3`。
- `0→2,1→2,2→3` → `3`。
- `0→1→2`和孤立点`3` → `3`，不是4。
- 只有`0→1,1→0` → `-1`；再加一门孤立课也仍返回`-1`。

> [!faq]- 分析与408风格参考解答｜尝试后展开
> **考场识别 → [[2.知识库/20.North_star_ZJU/202.计算机知识/05数据结构/08算法题/03算法题模板#G3 拓扑消除依赖|G3 拓扑消除依赖]]**：先修依赖且可并行：选G3拓扑消除依赖，并冻结每轮队列末尾。
>
>
> **为什么选这题**：旧G06已有这个合理任务。本次不继续复刻“拓扑序是否唯一”，而是恢复“拓扑过程服务于依赖安排”，并改为直观的队列分层写法。
>
> **从直觉到算法**
>
> 第一学期可以同时完成全部零入度点。删除它们后新出现的零入度点，最快只能下一学期完成。所以既要沿用拓扑删除，也要保存“本学期处理到哪里”为止。
>
> **变量含义**：`indegree`为尚未完成的先修课数；`q[front..rear-1]`为等待处理的可行课程；每学期开始冻结`end=rear`，只有当前`front..end-1`属于本学期；`processed`累计已完成课程数。
>
> **编号步骤**
> 1. 扫描全部弧计算入度；全部初始零入度点入队。
> 2. 队列非空时，学期数加1，并冻结end。
> 3. 只处理到end，删除这些课程的出边；新零入度课程追加到队尾，但不在本学期处理。
> 4. 重复分层处理直至队列为空。
> 5. 若processed小于n，则仍有环中的课程无法完成，返回−1；否则返回学期数。
>
> **为什么学期数最少**：本轮零入度课此前尚未完成的先修条件已经全部解除；所有满足条件的课都被尽早并行完成，推迟其中任何一门都不能让后续课程更早开始。
>
> **小例子**：`0→1→2`初始队列只有0。本学期处理0时把1追加，但end未改变，所以1必须等第二学期，而不是在一次while中顺带修完。
>
> **时间／额外空间**：$O(|V|+|E|)$／$O(|V|)$；每个点入出队至多一次，每条弧在统计入度与删除阶段各处理一次。
>
> **易错核对**：每弹出一门课就加1得到的是课程数；不冻结层末尾会把依赖链压进同一学期；有孤立课也不能掩盖其他分量中的环；不能修改原图去删除弧。
>
> **完整核心代码**
>
> ```cpp
> int MinimumTerms(const ALGraph &G) {
>     int n = G.vexnum;
>     int *indegree = new int[n]();
>     int *q = new int[n]();
>     for (int v = 0; v < n; v++) {
>         for (ArcNode *p = G.vertices[v].firstarc; p != NULL; p = p->nextarc)
>             indegree[p->adjvex]++;
>     }
>     int front = 0, rear = 0;
>     for (int v = 0; v < n; v++)
>         if (indegree[v] == 0) q[rear++] = v;
>     int terms = 0, processed = 0;
>     while (front < rear) {
>         int end = rear;
>         terms++;
>         while (front < end) {
>             int v = q[front++];
>             processed++;
>             for (ArcNode *p = G.vertices[v].firstarc; p != NULL; p = p->nextarc) {
>                 int w = p->adjvex;
>                 indegree[w]--;
>                 if (indegree[w] == 0) q[rear++] = w;
>             }
>         }
>     }
>     delete[] indegree;
>     delete[] q;
>     if (processed < n) return -1;
>     return terms;
> }
> ```

### G04 位于至少一条最短路径上的顶点

**来源与定位**：保留第一批自编任务；不标真题年份或出题概率。

- [ ] 首次：能解释状态并独立写出
- [ ] 间隔复写：不看答案通过自测

**题干**：无权无向简单图采用邻接表存储，允许不连通。给定两个不同的合法顶点`start,target`，找出所有位于**至少一条**start到target最短路径上的顶点，包含端点。

按编号递增写入容量至少为顶点数的`out[]`，返回个数；两点不连通时返回0。不得修改原图，不得枚举全部路径。要求时间复杂度为$O(|V|+|E|)$，辅助空间$O(|V|)$。

**自测（先手推）**

- 边`0—1,0—2,1—3,2—3`，start=0、target=3 → `[0,1,2,3]`，不能只返回某一条路径上的点。
- 在上图再接支路`1—4` → 仍为`[0,1,2,3]`。
- 边`0—1,1—2,0—2`，start=0、target=2 → `[0,2]`，顶点1能连通两端也不够。
- 起终点不连通 → 返回0。

> [!faq]- 分析与408风格参考解答｜尝试后展开
> **考场识别 → [[2.知识库/20.North_star_ZJU/202.计算机知识/05数据结构/08算法题/03算法题模板#G2 BFS标号与邻边约束|G2 BFS标号与邻边约束]]**：无权最短路的所有相关顶点：选G2距离标号，两端距离合成筛选条件。
>
>
> **为什么选这题**：让BFS产生的距离数组服务于新的集合判断，不用最短路条数取模等额外机制，也不枚举路径。
>
> **朴素方法为什么不合适**：枚举所有路径可能代价极大；一次BFS只记录一个前驱，又会漏掉其他同长最短路径上的顶点。
>
> **关键条件**：记从start、target到v的最短距离为`distStart[v]`、`distTarget[v]`，两端最短距离为D。v属于答案，当且仅当两侧可达且`distStart[v]+distTarget[v]==D`。
>
> **为什么这个条件成立**
> - 必要：一条最短路径上，经过v的前后两段都必须最短，否则整条路径还可缩短。
> - 充分：将start到v和v到target的最短路拼接，得到长度D的行走；若有重复顶点可去掉一个正长度回路，从而得到短于D的路，与D最短矛盾。因此存在经过v的最短路径。
>
> **变量含义**：两个距离数组对称地描述“离两端多远”；−1表示不可达；BFS队列入队时就确定距离，不重复入队；count为结果长度。
>
> **编号步骤**
> 1. 从start做BFS求全部distStart。
> 2. 若target不可达，答案为空，释放工作数组后返回0。
> 3. 否则从target再做一次BFS求distTarget。因为是无向图，这就是各点到target的距离。
> 4. 按编号扫描顶点，筛选满足关键条件者写入out。
> 5. 释放工作数组，返回count。辅助BFS也在本题完整展开。
>
> **小例子**：菱形图两条最短路`0—1—3`、`0—2—3`长度都为2。顶点1、2两侧距离和均为2，都会入选；支路4的距离和超过2，不入选。
>
> **时间／额外空间**：两次BFS加一次扫描仍为$O(|V|+|E|)$／$O(|V|)$。两个距离数组与一次BFS的队列在峰值时共为线性空间；out另计输出空间。
>
> **易错核对**：题目是“至少一条”，不是“每一条”；不能只查两侧可达；不能把不可达−1直接参与等式；有向图不能从target沿原出边照搬本解；本题不需要保存前驱或实际输出路径。
>
> **完整核心代码**
>
> ```cpp
> void BFSDistance(const ALGraph &G, int start, int dist[]) {
>     int n = G.vexnum;
>     int *q = new int[n]();
>     for (int v = 0; v < n; v++) dist[v] = -1;
>     int front = 0, rear = 0;
>     dist[start] = 0;
>     q[rear++] = start;
>     while (front < rear) {
>         int v = q[front++];
>         for (ArcNode *p = G.vertices[v].firstarc; p != NULL; p = p->nextarc) {
>             int w = p->adjvex;
>             if (dist[w] == -1) {
>                 dist[w] = dist[v] + 1;
>                 q[rear++] = w;
>             }
>         }
>     }
>     delete[] q;
> }
>
> int ShortestPathVertices(const ALGraph &G, int start, int target, int out[]) {
>     int n = G.vexnum;
>     int *distStart = new int[n]();
>     int *distTarget = new int[n]();
>     BFSDistance(G, start, distStart);
>     int count = 0;
>     if (distStart[target] != -1) {
>         BFSDistance(G, target, distTarget);
>         for (int v = 0; v < n; v++) {
>             if (distStart[v] != -1 && distTarget[v] != -1 &&
>                 distStart[v] + distTarget[v] == distStart[target])
>                 out[count++] = v;
>         }
>     }
>     delete[] distStart;
>     delete[] distTarget;
>     return count;
> }
> ```

> [!faq]- 识别模板、推导与完整代码｜先尝试再展开

> **考场识别 → [[2.知识库/20.North_star_ZJU/202.计算机知识/05数据结构/08算法题/03算法题模板#G1 遍历范围与分量汇总|G1 遍历范围与分量汇总]]**：“删点后连通性但不改结构”把该点预先标成不可进入；其余仍按全图分量遍历。

>
> **解题步骤**
> 1. visited全零，将blocked标1。
> 2. 外层枚举其他未访问顶点，启动DFS并令count加1。
> 3. DFS只访问未标记邻点，故不会经过blocked桥接两侧。
>
> **为什么成立**：遍历可使用的顶点和边恰是删点后的图；外层逐次找完各连通分量。
>
> **时间／额外空间**：O(V+E)／O(V)，含递归栈。
>
> **易错核对**：不能从外层再次启动blocked；原图本来不连通也要扫描全部点；不是只数blocked的邻点。
>
> **完整核心代码**（本卡单独配公共类型编译）
>

>     for (ArcNode *p = G.vertices[v].firstarc; p != NULL; p = p->nextarc)

>     delete[] visited;
>     return count;
> }

### G06 用两种颜色检查相邻冲突

**来源**：保留旧BFS二分染色好题。

- [ ] 首次：能说明状态并独立写出
- [ ] 间隔复写：不看答案通过边界检查

**题干**：无向简单图采用邻接表存储，允许不连通。判断能否为每点染0或1，使每条边两端异色。空图为真；O(V+E)时间、O(V)空间，不改图。

**先手推自测**：三角形假；四边形真；孤立点真；只有某个后续分量有奇环也是假。

> [!faq]- 识别模板、推导与完整代码｜先尝试再展开
>
> **考场识别 → [[2.知识库/20.North_star_ZJU/202.计算机知识/05数据结构/08算法题/03算法题模板#G2 BFS标号与邻边约束|G2 BFS标号与邻边约束]]**：“相邻相反＋可能有环”BFS传播颜色，不是简单按DFS深度取奇偶而不检查已访问边。
>
> **关键状态**：color=-1未染色；0/1为已确定颜色，兼作访问标记；每个分量任选起点色0。
>
> **解题步骤**
> 1. color全部置-1，外层找未染色点。
> 2. 起点染0并入队；对未染色邻点赋1-color[v]并入队。
> 3. 若已染色邻点与当前同色，发现冲突；释放工作数组后返回false。
>
> **为什么成立**：每条边都检查异色约束；若无冲突，最终赋值本身就是合法方案；若冲突则该分量的交替约束不能同时满足。
>
> **时间／额外空间**：O(V+E)／O(V)。
>
> **易错核对**：int数组={-1}不会全部为-1；入队就染色；不可漏掉已染邻点间的边或后续分量。
>
> **完整核心代码**（本卡单独配公共类型编译）
>
> ```cpp
> bool IsBipartite(const ALGraph &G) {
>     int n = G.vexnum;
>     int *color = new int[n](), *q = new int[n]();
>     for (int v = 0; v < n; v++) color[v] = -1;
>     bool ok = true;
>     for (int start = 0; start < n && ok; start++) {
>         if (color[start] != -1) continue;
>         int front = 0, rear = 0;
>         color[start] = 0; q[rear++] = start;
>         while (front < rear && ok) {
>             int v = q[front++];
>             for (ArcNode *p = G.vertices[v].firstarc; p != NULL; p = p->nextarc) {
>                 int w = p->adjvex;
>                 if (color[w] == -1) { color[w] = 1 - color[v]; q[rear++] = w; }
>                 else if (color[w] == color[v]) { ok = false; break; }
>             }
>         }
>     }
>     delete[] color; delete[] q;
>     return ok;
> }
> ```

**先手推自测**：n=3，边(0,1),(1,2),(0,2),(1,1)→2；重复边第二次起冗余；n=0,m=0→0。

> [!faq]- 识别模板、推导与完整代码｜先尝试再展开

> **考场识别 → [[2.知识库/20.North_star_ZJU/202.计算机知识/05数据结构/08算法题/03算法题模板#G4 并查集合并|G4 并查集合并]]**：“动态加入连接＋问是否已连通”并查集；不是有向可达或最短路。
>
> **关键状态**：parent按代表根连接；size为根集合大小。只有两端根不同才合并；根相同即冗余。
>
> **解题步骤**
> 1. 每点独立成集合。
> 2. 逐边Find两端根。
> 3. 相同则答案加1，否则小集合挂到大集合并更新大小。
>
> **为什么成立**：归纳地，集合始终等于已加入边形成的连通块；同根边不增加连通性。
>

>
> **易错核对**：必须按根挂接；自环立即同根；并查集不能拿来判有向通路。
>
> **完整核心代码**（本卡单独配公共类型编译）
>
> ```cpp
> int FindRoot(int parent[], int v) {
>     if (parent[v] != v) parent[v] = FindRoot(parent, parent[v]);
>     return parent[v];
> }
> int RedundantEdges(int n, const int edges[][2], int m) {
>     int *parent = new int[n](), *size = new int[n]();
>     for (int v = 0; v < n; v++) { parent[v] = v; size[v] = 1; }
>     int answer = 0;
>     for (int i = 0; i < m; i++) {
>         int a = FindRoot(parent, edges[i][0]), b = FindRoot(parent, edges[i][1]);
>         if (a == b) { answer++; continue; }
>         if (size[a] < size[b]) { int temp = a; a = b; b = temp; }
>         parent[b] = a;
>         size[a] += size[b];
>     }
>     delete[] parent; delete[] size;
>     return answer;
> }
> ```

### G08 非负权矩阵图的单源最短距离

**来源**：保留一题教材算法兜底，不扩展四套实现。

- [ ] 首次：能说明状态并独立写出
- [ ] 间隔复写：不看答案通过边界检查

**题干**：有向非负权图用矩阵weight存储，n≥1，源s合法。无边记INF=INT_MAX/4，对角线为0；合法零权边记0；所有有限最短距离保证<INF。将源到各点最短距离写入dist[]，不可达记INF。不改矩阵，O(n²)时间、O(n)额外空间（dist输出另计）。

**先手推自测**：0→1权0，1→2权2，0→2权5→[0,0,2]；孤立点INF；不能把0当无边。

> [!faq]- 识别模板、推导与完整代码｜先尝试再展开
>
> **考场识别 → [[2.知识库/20.North_star_ZJU/202.计算机知识/05数据结构/08算法题/03算法题模板#G5 选最小再松弛（备查）|G5 选最小再松弛（备查）]]**：“非负带权最短路”不能用普通BFS层数；用选取未确定最小距离点＋松弛。
>
> **关键状态**：dist[v]为从源到v的当前最优上界；settled标记距离已最终确定；不是Prim的“接入一条边成本”。
>
> **解题步骤**
> 1. dist全INF，源为0；settled全0。
> 2. 选取未确定且dist最小的u；无有限候选则结束。
> 3. 确定u，遍历出边，用dist[u]+weight[u][v]改进dist[v]。
> 4. 重复至无可达候选或最多n次。
>
> **为什么成立**：非负边保证尚未确定的路径不能绕过更远点再缩短当前最小候选，因此u的距离可确定。
>
> **时间／额外空间**：O(n²)／O(n)工作空间，输入矩阵O(n²)和dist输出O(n)另列。
>
> **易错核对**：负权不适用；选点是最小dist，不是编号；INF不能当有限边；本题有限量<INF，求和<2INF不会int溢出。
>
> **完整核心代码**（本卡单独配公共类型编译）
>
> ```cpp
> void DijkstraDistances(const int weight[][MAXSIZE], int n, int s, int dist[]) {
>     const int INF = INT_MAX / 4;
>     int *settled = new int[n]();
>     for (int v = 0; v < n; v++) dist[v] = INF;
>     dist[s] = 0;
>     for (int step = 0; step < n; step++) {
>         int u = -1;
>         for (int v = 0; v < n; v++)
>             if (!settled[v] && (u == -1 || dist[v] < dist[u])) u = v;
>         if (u == -1 || dist[u] == INF) break;
>         settled[u] = 1;
>         for (int v = 0; v < n; v++) {
>             if (!settled[v] && weight[u][v] < INF &&
>                 dist[u] + weight[u][v] < dist[v])
>                 dist[v] = dist[u] + weight[u][v];
>         }
>     }
>     delete[] settled;
> }
> ```
