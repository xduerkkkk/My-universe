### A12 最小未出现正整数

- [x] 首次：能解释状态并写出代码
- [ ] 间隔复写：不看答案通过自测

**定位**：主练｜2018·41：按用户给出的题型改写。

**题干**：给定长度 n≥0 的整数数组 A，可含负数、0和重复值。不改 A，允许 O(n) 辅助空间，求未出现的最小正整数。

**自测**：[3,4,-1,1] → 2；[1,2,3] → 4；[0,-2] → 1；[] → 1。

> [!faq]- 题解与完整核心代码｜先说状态，再核对
> **变量存什么**：`visited[x]` 表示正整数 x 是否出现；只关心 1..n。
>
> **解题步骤**
> 1. 长度为 n，答案一定落在 1..n+1；若1..n全在，答案才是 n+1。
> 2. 申请 n+1 个标记，全部置0；下标0不用。
> 3. 扫描 A，只给 1≤A[i]≤n 的值打标记。
> 4. 从1向上找到第一个未出现值；返回前释放辅助数组。
>
> **手推一遍**：[3,4,-1,1]，n=4：标记1、3、4，从1检查，在2处首次遇到0。
>
> ```cpp
> int FirstMissingPositive(const int A[], int n) {
>     int *visited = new int[n + 1]();
>     for (int i = 0; i < n; i++) {
>         if (A[i] >= 1 && A[i] <= n) {
>             visited[A[i]] = 1;
>         }
>     }
>     int answer = n + 1;
>     for (int x = 1; x <= n; x++) {
>         if (visited[x] == 0) {
>             answer = x;
>             break;
>         }
>     }
>     delete[] visited;
>     return answer;
> }
> ```
>
> **时间 / 额外空间**：O(n) / O(n)（n=0 时只申请1格）。
>
> **易错核对**：不能把负数或大于 n 的数直接拿来当下标；这里不需要原地置换的另一套技巧。

### A18 Partition 与第 k 小

- [ ] 首次：能解释状态并写出代码
- [ ] 间隔复写：不看答案通过自测

**定位**：主练｜2022·42：最小 k 个数；本卡补齐与旧题“第k小”的联系。

**题干**：长度 n≥1，1≤k≤n，允许修改 A。先写第 k 小，再使 A 的前 k 项成为最小 k 个数（内部不要求有序）。

**自测**：[4,1,3,2]，k=2 → 第2小为2，前2项集合{1,2}；[2,2,1]，k=2 → 2；k=n → 全部。

> [!faq]- 题解与完整核心代码｜先说状态，再核对
> **变量存什么**：`pivot` 是枢轴值；划分后枢轴下标为 pos；`k-1` 是第 k 小在排序结果中的下标。
>
> **解题步骤**
> 1. 一次划分把枢轴放到最终秩位置，左边≤它，右边≥它。
> 2. 若 pos=k-1 已找到；pos 太大只查左段，太小只查右段。
> 3. 反复缩小闭区间，不对不需要的一侧排序。
> 4. 找到后前 k 项就是最小 k 个数，但它们内部仍可能无序。
>
> ```cpp
> int Partition(int A[], int low, int high) {
>     int pivot = A[low];
>     while (low < high) {
>         while (low < high && A[high] >= pivot) {
>             high--;
>         }
>         A[low] = A[high];
>         while (low < high && A[low] <= pivot) {
>             low++;
>         }
>         A[high] = A[low];
>     }
>     A[low] = pivot;
>     return low;
> }
>
> int SelectK(int A[], int n, int k) {
>     int low = 0;
>     int high = n - 1;
>     while (low <= high) {
>         int pos = Partition(A, low, high);
>         if (pos == k - 1) {
>             return A[pos];
>         }
>         if (pos > k - 1) {
>             high = pos - 1;
>         } else {
>             low = pos + 1;
>         }
>     }
>     return 0;  // 合法的 n、k 不会走到这里
> }
>
> void SmallestK(int A[], int n, int k) {
>     SelectK(A, n, k);  // 前 k 项即为答案，不要求内部有序
> }
> ```
>
> **时间 / 额外空间**：随机排列等平均分析前提下 O(n)，最坏 O(n²) / O(1)，此实现不使用递归。
>
> **易错核对**：第 k 小对应下标 k-1。首元素作枢轴并不保证每次折半；不能写“严格 O(n)”或“前 k 项已排序”。

### A19 人数最均衡且总和差最大的分组

- [ ] 首次：能解释状态并写出代码
- [ ] 间隔复写：不看答案通过自测

**定位**：主练｜2016·43：按用户题型改写；允许负数，并明确奇数长度。

**题干**：n≥2，把全部元素分为两组，人数之差≤1，使两组总和的绝对差最大。允许修改数组，只返回最大差，不要求最后数组一定保留最优分组布局。

**自测**：[1,2,3,4] → 4；[-100,-99,1] → 200；[5,5] → 0。

> [!faq]- 题解与完整核心代码｜先说状态，再核对
> **变量存什么**：`k=n/2` 是较小组人数；`total` 为总和；选 k 个数的和为 s 时，两组差为 |total-2s|。
>
> **解题步骤**
> 1. 先写完整 Partition/SelectK；下面已在本卡展开，不需跳到别处补代码。
> 2. 用快速选择把最小 k 个放到前面，计算这一极端的差。
> 3. 若 n 为偶数，另一个极端只是交换两组，直接返回。
> 4. 若 n 为奇数，还要检查最大 k 个组成较小组的情况；两种差取较大值。
>
> **手推一遍**：[-100,-99,1]：较小组只有1人。选-100，差2；选1，差200，所以负数情况下必须比较两个极端。
>
> ```cpp
> int Partition(int A[], int low, int high) {
>     int pivot = A[low];
>     while (low < high) {
>         while (low < high && A[high] >= pivot) high--;
>         A[low] = A[high];
>         while (low < high && A[low] <= pivot) low++;
>         A[high] = A[low];
>     }
>     A[low] = pivot;
>     return low;
> }
>
> int SelectK(int A[], int n, int k) {
>     int low = 0;
>     int high = n - 1;
>     while (low <= high) {
>         int pos = Partition(A, low, high);
>         if (pos == k - 1) return A[pos];
>         if (pos > k - 1) high = pos - 1;
>         else low = pos + 1;
>     }
>     return 0;
> }
>
> long long BalancedDifference(int A[], int n) {
>     int k = n / 2;
>     long long total = 0;
>     for (int i = 0; i < n; i++) total += A[i];
>
>     SelectK(A, n, k);
>     long long smallSum = 0;
>     for (int i = 0; i < k; i++) smallSum += A[i];
>     long long answer = total - 2 * smallSum;
>     if (answer < 0) answer = -answer;
>     if (n % 2 == 0) return answer;
>
>     SelectK(A, n, n - k);
>     long long largeSum = 0;
>     for (int i = n - k; i < n; i++) largeSum += A[i];
>     long long other = total - 2 * largeSum;
>     if (other < 0) other = -other;
>     if (other > answer) answer = other;
>     return answer;
> }
> ```
>
> **时间 / 额外空间**：快速选择的平均分析前提下 O(n)，最坏 O(n²) / O(1)。
>
> **易错核对**：奇数 n、允许负数时，不能只检查最小 k 个；这不是背一条“排序后对半切”就结束。long long 中间运算必须可表示。

### A20 后缀最大乘积（允许自身）

- [ ] 首次：能解释状态并写出代码
- [ ] 间隔复写：不看答案通过自测

**定位**：主练｜2025·41：用户给出的是题型标题，未提供原题的 j 范围；本卡沿用 i≤j 的训练定义。

**题干**：整数数组 A 可含正、负、0。求 result[i]=max{A[i]×A[j]｜i≤j<n}，允许自身；不改 A，输出与 A 不重叠。n≥0，乘积能用 long long 表示。原题若要求 i<j，改练留档中的 A21，不把两种定义混用。

**自测**：[-3,2,-4] → [12,4,16]；[0,-2] → [0,4]；[] → []。

> [!faq]- 题解与完整核心代码｜先说状态，再核对
> **变量存什么**：`suffixMin/suffixMax` 记录已纳入后缀的最小值/最大值；本题先纳入 A[i]，再计算答案。
>
> **解题步骤**
> 1. 从右向左扫描；因为 j≥i，所以先把当前值放入后缀极值。
> 2. A[i]≥0 时，乘后缀最大值最好。
> 3. A[i]<0 时，乘后缀最小值最好，负负可以得正。
> 4. 每步只保留两个极值，不必保存整个后缀；结果数组不算辅助工作空间。
>
> **手推一遍**：[-3,2,-4] 从右扫：-4的后缀极值均为-4，得16；2的后缀最大为2，得4；-3的后缀最小为-4，得12。
>
> ```cpp
> void SuffixMaxProduct(const int A[], int n, long long result[]) {
>     if (n == 0) return;
>     int suffixMin = A[n - 1];
>     int suffixMax = A[n - 1];
>     for (int i = n - 1; i >= 0; i--) {
>         if (A[i] < suffixMin) suffixMin = A[i];
>         if (A[i] > suffixMax) suffixMax = A[i];
>         if (A[i] >= 0) {
>             result[i] = (long long)A[i] * suffixMax;
>         } else {
>             result[i] = (long long)A[i] * suffixMin;
>         }
>     }
> }
> ```
>
> **时间 / 额外空间**：O(n) / O(1) 辅助空间，另有 O(n) 输出空间。
>
> **易错核对**：不能只维护后缀最大值；允许自身要先更新，禁止自身要先查询。两者最后一项的合法性不同。

旧作答/批注：[[算法分类训练-改写前留档-2026-11-05/原版-算法分类训练-01-A数组与线性表.md#A20 后缀最大乘积（允许自身）|改写前完整留档]]。

### A24 数组循环左移

- [ ] 首次：能解释状态并写出代码
- [ ] 间隔复写：不看答案通过自测

**定位**：主练｜2010·42：按用户给出的题型改写。

**题干**：长度 n≥0 的数组 A 循环左移 p 位，p≥0。要求 O(n) 时间、O(1) 辅助空间；不使用额外数组。

**自测**：[1,2,3,4,5]，p=2 → [3,4,5,1,2]；p=7 同结果；p=0不变；空数组不取模。

> [!faq]- 题解与完整核心代码｜先说状态，再核对
> **变量存什么**：`[0,p-1]` 是要移到后面的前段；`[p,n-1]` 是要移到前面的后段。
>
> **解题步骤**
> 1. n=0 时直接结束；否则先 p%=n，去掉整圈移动。
> 2. 分别逆置前 p 个与后 n-p 个元素，使两段各自倒序。
> 3. 再逆置整个数组：两段交换位置，段内次序同时恢复。
>
> **手推一遍**：12345 左移2：前段逆置成21345，后段逆置成21543，整体逆置得到34512。
>
> ```cpp
> void ReverseArray(int A[], int low, int high) {
>     while (low < high) {
>         int temp = A[low];
>         A[low] = A[high];
>         A[high] = temp;
>         low++;
>         high--;
>     }
> }
>
> void LeftRotate(int A[], int n, int p) {
>     if (n == 0) return;
>     p = p % n;
>     if (p == 0) return;
>     ReverseArray(A, 0, p - 1);
>     ReverseArray(A, p, n - 1);
>     ReverseArray(A, 0, n - 1);
> }
> ```
>
> **时间 / 额外空间**：O(n) / O(1)。
>
> **易错核对**：循环左移不是每次删除首项再插到末尾；后者重复 p 次可能是 O(np)。

### A25 两个等长升序序列的中位数

- [ ] 首次：能解释状态并写出代码
- [ ] 间隔复写：不看答案通过自测

**定位**：主练｜2011·42：训练定义为合并后第 n 小，即偶数总长度的较小中位数。

**题干**：A、B 都是长度 n≥1 的非递减数组。求合并后第 n 小的元素，不实际合并，要求 O(log n) 时间、O(1) 辅助空间。

**自测**：[1,3,5] 与[2,4,6] → 3；[1]与[2] → 1；[1,1]与[1,2] → 1。

> [!faq]- 题解与完整核心代码｜先说状态，再核对
> **变量存什么**：`[low1,high1]`、`[low2,high2]` 是等长候选区间；同时舍去相同数量的较小元素与较大元素。
>
> **解题步骤**
> 1. 比较两段中点；相等时就是所求中位数。
> 2. 若 A 的中点较小，舍弃 A 的一部分左端、B 的一部分右端；反之对称。
> 3. 区间长度为奇数时保留两个中点；为偶数时，小中点所在区间要额外舍弃该中点，维持两段等长。
> 4. 两段各剩一个数时，返回较小者。
>
> **手推一遍**：A=[1,3,5]，B=[2,4,6]：3<4，保留[3,5]与[2,4]；当前长2，3>2，保留[3]与[4]；较小者3。
>
> ```cpp
> int EqualLengthMedian(const int A[], const int B[], int n) {
>     int low1 = 0, high1 = n - 1;
>     int low2 = 0, high2 = n - 1;
>     while (low1 < high1) {
>         int mid1 = (low1 + high1) / 2;
>         int mid2 = (low2 + high2) / 2;
>         if (A[mid1] == B[mid2]) return A[mid1];
>         int length = high1 - low1 + 1;
>         if (A[mid1] < B[mid2]) {
>             low1 = (length % 2 == 0) ? mid1 + 1 : mid1;
>             high2 = mid2;
>         } else {
>             high1 = mid1;
>             low2 = (length % 2 == 0) ? mid2 + 1 : mid2;
>         }
>     }
>     return A[low1] < B[low2] ? A[low1] : B[low2];
> }
> ```
>
> **时间 / 额外空间**：O(log n) / O(1)。
>
> **易错核对**：不是两个中间数的平均值；奇偶判断看“当前候选区间长度”，不是一直看原 n。

### A26 数组主元素

- [ ] 首次：能解释状态并写出代码
- [ ] 间隔复写：不看答案通过自测

**定位**：主练｜2013·41：不存在返回 -1。

**题干**：找出长度 n≥0 的数组中出现次数严格大于 n/2 的主元素，不存在返回 -1，要求 O(n) 时间、O(1) 辅助空间。

**自测**：[2,1,2,2] → 2；[1,2,3] → -1；[1,1,2,2] → -1；[] → -1。

> [!faq]- 题解与完整核心代码｜先说状态，再核对
> **变量存什么**：`candidate` 为当前候选值；`count` 第一遍是抵消后的净票数，第二遍重新统计真实次数。
>
> **解题步骤**
> 1. 票数为0时，当前值成为新候选；相同值加票，不同值减票。
> 2. 不同值两两抵消，不会把真正超过半数的值完全抵消。
> 3. 但有候选不代表一定有主元素，必须第二遍验证。
> 4. 真实次数>n/2 才返回候选，否则返回 -1。
>
> ```cpp
> int Majority(const int A[], int n) {
>     int candidate = 0;
>     int count = 0;
>     for (int i = 0; i < n; i++) {
>         if (count == 0) {
>             candidate = A[i];
>             count = 1;
>         } else if (A[i] == candidate) {
>             count++;
>         } else {
>             count--;
>         }
>     }
>     count = 0;
>     for (int i = 0; i < n; i++) {
>         if (A[i] == candidate) count++;
>     }
>     return count > n / 2 ? candidate : -1;
> }
> ```
>
> **时间 / 额外空间**：O(n) / O(1)。
>

### A27 三个升序数组的三元组最小距离

- [ ] 首次：能解释状态并写出代码
- [ ] 间隔复写：不看答案通过自测

**定位**：主练｜2020·41：距离定义在本题明示，不与“三数之和/紧密三元组计数”混淆。

**题干**：三个非递减非空整数数组 A、B、C，长度分别 n、m、t。各取一项 a、b、c，使 |a-b|+|b-c|+|c-a| 最小；返回该最小距离。

**自测**：[1,4,10]、[2,15,20]、[10,12] → 10（10,15,10或10,15,12）；[1]、[1]、[1] → 0；[-5]、[0]、[3] → 16。

> [!faq]- 题解与完整核心代码｜先说状态，再核对
> **变量存什么**：`i/j/k` 指向三数组当前元素；`minValue/maxValue` 为当前三元组极值。距离恒等于 2×(maxValue-minValue)。
>
> **解题步骤**
> 1. 从三个数组开头取当前三元组，更新最小距离。
> 2. 若想缩小极差，推进当前最小值所在的数组；只推进非最小值不会改善当前最小值固定时的极差。
> 3. 若最小值并列，可任选一个推进；若距离已为0，可直接结束。
> 4. 任意一个数组耗尽后停止，不再有完整三元组。
>
> **手推一遍**：当前(1,2,10)，距离18，推进最小值1；得到(4,2,10)，距离16；再推进2所在的B，继续扫描，最优在(10,15,10)，距离10。
>
> ```cpp
> long long MinTripleDistance(const int A[], int n,
>                             const int B[], int m,
>                             const int C[], int t) {
>     int i = 0, j = 0, k = 0;
>     long long answer = LLONG_MAX;
>     while (i < n && j < m && k < t) {
>         int minValue = A[i];
>         int maxValue = A[i];
>         if (B[j] < minValue) minValue = B[j];
>         if (C[k] < minValue) minValue = C[k];
>         if (B[j] > maxValue) maxValue = B[j];
>         if (C[k] > maxValue) maxValue = C[k];
>         long long distance = 2 * ((long long)maxValue - minValue);
>         if (distance < answer) answer = distance;
>         if (answer == 0) break;
>         if (A[i] == minValue) i++;
>         else if (B[j] == minValue) j++;
>         else k++;
>     }
>     return answer;
> }
> ```
>
> **时间 / 额外空间**：O(n+m+t) / O(1)。
>
> **易错核对**：三个数组必须各取一个；不是在单数组找三数之和为0，也不是统计三元组数量。差值先转 long long 再减。

> [!faq]- 题解与完整核心代码｜先说状态，再核对
> **变量存什么**：`i` 扫描原数组；`k` 是已保留元素个数，也就是下一个写入位置。
>
> **解题步骤**
> 1. 从左到右读 A[i]；A[0..k-1] 始终是已去重的有效段。
> 2. 没有保留过元素，或当前值不等于最后保留值时，把它写到 A[k]。
> 3. 写入后 k 加1；最终返回 k，而不是原长度 n。
>
> ```cpp
> int Unique(int A[], int n) {
>     int k = 0;  // 已保留元素个数
>     for (int i = 0; i < n; i++) {
>         if (k == 0 || A[i] != A[k - 1]) {
>             A[k] = A[i];
>             k++;
>         }
>     }
>     return k;
> }
> ```
>
> **时间 / 额外空间**：O(n) / O(1)。
>
> **易错核对**：k==0 时不能先读 A[k-1]；数组本来就必须有序。

### A16 二分查找左右边界

- [ ] 首次：能解释状态并写出代码
- [ ] 间隔复写：不看答案通过自测

**定位**：基础积木｜闭区间二分；本次针对选中文段重写。

**题干**：非递减数组 A，长度 n≥0。分别返回第一个≥x、第一个>x 的下标；不存在返回 n。

**自测**：[1,2,2,4]，x=2 → 1、3；x=0 → 0、0；x=5 → 4、4；空数组 → 0、0。

> [!faq]- 题解与完整核心代码｜先说状态，再核对
> **变量存什么**：`[low,high]` 是待查闭区间；`answer` 是目前找到的最靠左候选，下标 n 表示还没找到。
>
> **解题步骤**
> 1. low=0、high=n-1、answer=n；空数组自然不进入循环。
> 2. A[mid] 满足条件时，先记住 mid，再到它左边找更早的候选。
> 3. 不满足时，mid 及其左侧都不可能满足，令 low=mid+1。
> 4. 两个函数只差一个条件：≥x 与 >x。
>
> **手推一遍**：A=[1,2,2,4]、x=2，找左边界：mid=1 满足，先记 answer=1，再把 high 改成0；检查下标0后结束，返回1。
>
> ```cpp
> int LowerBound(const int A[], int n, int x) {
>     int low = 0;
>     int high = n - 1;
>     int answer = n;
>     while (low <= high) {
>         int mid = low + (high - low) / 2;
>         if (A[mid] >= x) {
>             answer = mid;   // 记住候选，但继续向左找
>             high = mid - 1;
>         } else {
>             low = mid + 1;
>         }
>     }
>     return answer;
> }
>
> int UpperBound(const int A[], int n, int x) {
>     int low = 0;
>     int high = n - 1;
>     int answer = n;
>     while (low <= high) {
>         int mid = low + (high - low) / 2;
>         if (A[mid] > x) {
>             answer = mid;
>             high = mid - 1;
>         } else {
>             low = mid + 1;
>         }
>     }
>     return answer;
> }
> ```
>
> **时间 / 额外空间**：O(log(n+1)) / O(1)。
>
> **易错核对**：本页不用 [low,high) 的另一套边界约定；返回 n 后不能读取 A[n]。x 的个数为 UpperBound-LowerBound。
