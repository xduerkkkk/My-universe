### A01 稳定删除一个值域区间

**来源**：旧稳定删除题升级。

- [x] 首次：能说明状态并独立写出
- [ ] 间隔复写：不看答案通过边界检查

**题干**：给定任意整数数组A与长度n，原地删除所有值位于闭区间[low,high]的元素（low≤high），其他元素相对次序不变。返回新有效长度。要求O(n)时间、O(1)额外空间；n可为0。

**先手推自测**：[1,4,2,5,3]删[2,4] → 长度2、有效前缀[1,5]；全部删除→0；空数组→0。

> [!faq]- 识别模板、推导与完整代码｜先尝试再展开
>
> **考场识别 → [[2.知识库/20.North_star_ZJU/202.计算机知识/05数据结构/08算法题/03算法题模板#A1 读写前缀|A1 读写前缀]]**：“原地＋保序筛选”先想读写指针，不是一边删一边移动整个后缀。
>
> **关键状态**：r为下一个读取位置；A[0..w-1]是已读部分保留下来的稳定结果。w≤r，因此写入不会破坏尚未读取的数据。
>
> **解题步骤**
> 1. w置0，r从0扫描至n-1。
> 2. 值小于low或大于high才写入A[w++]。
> 3. 返回w；后面的旧内容无须清零。
>
> **为什么成立**：每个合法元素按原顺序写入且恰写一次，被删除元素不占结果位置。
>
> **时间／额外空间**：O(n)／O(1)。
>
> **易错核对**：返回长度不是最后下标；保留条件用“或”；不要求清空失效后缀。
>
> **完整核心代码**（本卡单独配公共类型编译）
>
> ```cpp
> int DeleteValueRange(int A[], int n, int low, int high) {
>     int w = 0;
>     for (int r = 0; r < n; r++)
>         if (A[r] < low || A[r] > high) A[w++] = A[r];
>     return w;
> }
> ```

### A02 有序数组压缩并记录重复次数

**来源**：旧有序去重题升级。

- [ ] 首次：能说明状态并独立写出
- [ ] 间隔复写：不看答案通过边界检查

**题干**：非递减数组A长度n，将不同值按升序原地保存在A前缀，在调用者提供的counts[]中同步保存每个值原来出现的次数。返回不同值个数，counts容量≥n。O(n)时间，除输出counts外O(1)工作空间。

**先手推自测**：[1,1,2,4,4,4] → 值[1,2,4]、次数[2,1,3]；[7,7]→[7]与[2]；空→0。

> [!faq]- 识别模板、推导与完整代码｜先尝试再展开
>
> **考场识别 → [[2.知识库/20.North_star_ZJU/202.计算机知识/05数据结构/08算法题/03算法题模板#A1 读写前缀|A1 读写前缀]]**：“有序重复段＋保序压缩”是读写前缀；相等项并入上一组，而非输出新项。
>
> **关键状态**：w是已建立组数；A[w-1]是最后一组的值，counts[w-1]是其频次；读指针r仍扫描原输入。
>
> **解题步骤**
> 1. 遇到第一项或与末组值不同，写新组并令频次为1。
> 2. 否则仅将末组频次加1。
> 3. 扫描结束返回w。
>
> **为什么成立**：非递减性保证每个值连续出现；一个值只会建立一组。覆盖位置不超过r，不影响未读区。
>
> **时间／额外空间**：O(n)／O(1)工作空间，counts输出容量O(n)。
>
> **易错核对**：必须有序；不能把w误当频次；本题输出数组不得与A重叠。
>
> **完整核心代码**（本卡单独配公共类型编译）
>
> ```cpp
> int CompressCounts(int A[], int n, int counts[]) {
>     int w = 0;
>     for (int r = 0; r < n; r++) {
>         if (w == 0 || A[r] != A[w - 1]) {
>             A[w] = A[r];
>             counts[w] = 1;
>             w++;
>         } else counts[w - 1]++;
>     }
>     return w;
> }
> ```

### A03 两个有序数组的集合交集&

**来源**：旧有序合并机制重设计。

- [ ] 首次：能说明状态并独立写出
- [ ] 间隔复写：不看答案通过边界检查

**题干**：两个非递减数组A、B分别长n、m，内部可重复。将两数组公共的不同值按升序写入out[]，每值只写一次，返回个数。out与输入不重叠且容量≥min(n,m)。不得修改输入，要求O(n+m)时间、O(1)工作空间（输出另计）。

**先手推自测**：A=[1,1,2,4]，B=[1,1,1,3,4] → [1,4]；任一空→空；不能输出两个1。

> [!faq]- 识别模板、推导与完整代码｜先尝试再展开
>
> **考场识别 → [[2.知识库/20.North_star_ZJU/202.计算机知识/05数据结构/08算法题/03算法题模板#A2 有序同步推进|A2 有序同步推进]]**：“两个有序序列＋匹配”同步推进；更小值在对面尚未扫描区不可能匹配。
>
> **关键状态**：i,j为两个首个未处理位置；out[0..k-1]是已确定的不同公共值。
>
> **解题步骤**
> 1. A[i]小则i前进，B[j]小则j前进。
> 2. 相等时若与out末值不同就写入；然后i、j均前进。
> 3. 任一数组结束就返回k。
>
> **为什么成立**：丢弃较小者不会错过匹配；相等值有一对即可确认为集合公共值，输出去重保证每值只一次。
>
> **时间／额外空间**：O(n+m)／O(1)工作空间。
>
> **易错核对**：集合交集不是多重集交集；输入有重复也只输出一个。
>
> **完整核心代码**（本卡单独配公共类型编译）
>
> ```cpp
> int ArrayIntersection(const int A[], int n, const int B[], int m, int out[]) {
>     int i = 0, j = 0, k = 0;
>     while (i < n && j < m) {
>         if (A[i] < B[j]) i++;
>         else if (A[i] > B[j]) j++;
>         else {
>             if (k == 0 || out[k - 1] != A[i]) out[k++] = A[i];
>             i++; j++;
>         }
>     }
>     return k;
> }
> ```

### A04 两个有序数组的最小绝对差

**来源**：保留旧A06好题。

- [x] 首次：能说明状态并独立写出
- [ ] 间隔复写：不看答案通过边界检查

**题干**：两个非空非递减整数数组A、B，长度n、m。任取A与B各一项，求最小绝对差，不修改输入。要求O(n+m)时间、O(1)空间，差用long long表示。

**先手推自测**：A=[1,5,10]、B=[3,8]→2；[-5]与[2]→7；相等值→0；INT_MIN与INT_MAX的差须提升类型。

> [!faq]- 识别模板、推导与完整代码｜先尝试再展开
>
> **考场识别 → [[2.知识库/20.North_star_ZJU/202.计算机知识/05数据结构/08算法题/03算法题模板#A2 有序同步推进|A2 有序同步推进]]**：“有序＋跨序列最优配对”先比较当前值；只推进较小的一方才可能缩小当前差。
>
> **关键状态**：i,j沿两数组只前进；best为已经检查过的配对的最小差。
>
> **解题步骤**
> 1. 用首对初始化best。
> 2. 检查当前差；若为0可直接返回。
> 3. A[i]<B[j]时i前进，否则j前进，直至一方耗尽。
>
> **为什么成立**：当A[i]≤B[j]时，用同一个A[i]配B的更后元素不会更好；故可丢弃A[i]。对另一侧对称。
>
> **时间／额外空间**：O(n+m)／O(1)。
>
> **易错核对**：两数组须非空；先转long long再减，不能int减完再转换；不用排序，因为输入已排序。
>
> **完整核心代码**（本卡单独配公共类型编译）
>
> ```cpp
> long long MinAbsoluteDifference(const int A[], int n, const int B[], int m) {
>     int i = 0, j = 0;
>     long long best = (long long)A[0] - B[0];
>     if (best < 0) best = -best;
>     while (i < n && j < m) {
>         long long difference = (long long)A[i] - B[j];
>         if (difference < 0) difference = -difference;
>         if (difference < best) best = difference;
>         if (best == 0) return 0;
>         if (A[i] < B[j]) i++;
>         else j++;
>     }
>     return best;
> }
> ```

### A05 有序数组中一个值域内有多少项&感觉容易忘

**来源**：旧二分边界题应用化。

- [ ] 首次：能说明状态并独立写出
- [ ] 间隔复写：不看答案通过边界检查

**题干**：非递减数组A长度n，允许重复。对给定low≤high，求值属于闭区间[low,high]的元素个数，不修改输入。要求O(log(n+1))时间、O(1)空间；n可为0。

**先手推自测**：[1,2,2,4,7]查询[2,4]→3；[3,3]→0；[1,7]→5；空→0。

> [!faq]- 识别模板、推导与完整代码｜先尝试再展开
>
> **考场识别 → [[2.知识库/20.North_star_ZJU/202.计算机知识/05数据结构/08算法题/03算法题模板#A4 二分边界|A4 二分边界]]**：“有序＋统计连续值域＋对数时间”转成两个边界，不逐项计数。
>
> **关键状态**：FirstAtLeast返回首个≥x的位置；FirstGreater返回首个>x的位置；不存在返回n。二分未决区间统一用闭区间[low,high]。
>
> **解题步骤**
> 1. 分别二分首个≥low的位置L、首个>high的位置R。
> 2. 每次命中条件记录mid为候选，继续向左找。
> 3. 返回R-L。
>
> **为什么成立**：有效元素恰好落在下标半开区间[L,R)，因此差即数量。
>
> **时间／额外空间**：O(log(n+1))／O(1)。
>
> **易错核对**：不要用high+1代替严格大于边界，high可能为INT_MAX；n是合法的“未找到”位置。
>
> **完整核心代码**（本卡单独配公共类型编译）
>
> ```cpp
> int FirstAtLeast(const int A[], int n, int x) {
>     int low = 0, high = n - 1, answer = n;
>     while (low <= high) {
>         int mid = low + (high - low) / 2;
>         if (A[mid] >= x) { answer = mid; high = mid - 1; }
>         else low = mid + 1;
>     }
>     return answer;
> }
> int FirstGreater(const int A[], int n, int x) {
>     int low = 0, high = n - 1, answer = n;
>     while (low <= high) {
>         int mid = low + (high - low) / 2;
>         if (A[mid] > x) { answer = mid; high = mid - 1; }
>         else low = mid + 1;
>     }
>     return answer;
> }
> int ValueRangeCount(const int A[], int n, int low, int high) {
>     return FirstGreater(A, n, high) - FirstAtLeast(A, n, low);
> }
> ```

### A06 有限值域内的缺失值与重复值

**来源**：计数数组基础重设计。

>     int pivot = A[low];
>     while (low < high) {
>         while (low < high && A[high] >= pivot) high--;
>         A[low] = A[high];
>         while (low < high && A[low] <= pivot) low++;
>         A[high] = A[low];
>     }
>     A[low] = pivot;
>     return low;

>
> **关键状态**：sum始终等于当前[left,right]的和；best为已找到最短长度，n+1表示尚未找到。
>
> **解题步骤**
> 1. 每次右端加入一项。
> 2. 只要sum仍达标，先更新长度，再移出左端；必须while收缩。
> 3. 最后没有合法长度则返回0。
>
> **为什么成立**：对每个右端，把可行起点推进到极限，过程中记录最短候选；left只向右，总次数≤n。
>
> **时间／额外空间**：O(n)／O(1)。
>
> **易错核对**：target必须>0；有负数时不能照搬；先记长度再删左端；不能只if收缩一次。
>
> **完整核心代码**（本卡单独配公共类型编译）
>
> ```cpp
> int ShortestAtLeast(const int A[], int n, long long target) {
>     int left = 0, best = n + 1;
>     long long sum = 0;
>     for (int right = 0; right < n; right++) {
>         sum += A[right];
>         while (sum >= target) {
>             int length = right - left + 1;
>             if (length < best) best = length;
>             sum -= A[left++];
>         }
>     }
>     return best == n + 1 ? 0 : best;
> }

### A14 最长连续严格递增段

**题干**：任意整数数组A，求最长的连续严格递增段。通过start返回起点，函数返回长度；并列取最早起点；空数组返回0且start=-1。不改A，O(n)时间、O(1)空间。

**先手推自测**：[1,2,0,1,2]→start=2、长度3；[1,2,0,1]→start=0、长度2；[2,2]→0和1；空→-1和0。

> [!faq]- 识别模板、推导与完整代码｜先尝试再展开
>
> **考场识别 → [[2.知识库/20.North_star_ZJU/202.计算机知识/05数据结构/08算法题/03算法题模板#A5 扫描汇总与历史最优|A5 扫描汇总与历史最优]]**：“连续段＋相邻关系”用一段当前状态，不是最长递增子序列，也不必排序。
>
> **关键状态**：currentStart是当前严格递增段的起点；bestLength和start为已知最早最优段。
>
> **解题步骤**
> 1. 空数组单独处理；其他以首项初始化。
> 2. 遇A[i]≤A[i-1]时将currentStart重置为i。
> 3. 仅当新长度严格超过best时更新，以保留最早并列解。
>
> **为什么成立**：任何连续严格递增段都包含在一个极大递增段中；扫描恰在断点重置，并检查所有段长度。
>
> **时间／额外空间**：O(n)／O(1)。
>
> **易错核对**：连续段不能跳过元素；相等会断开；并列更新要用>而非≥。
>
> **完整核心代码**（本卡单独配公共类型编译）
>
> ```cpp
> int LongestIncreasingRun(const int A[], int n, int &start) {
>     if (n == 0) { start = -1; return 0; }
>     int currentStart = 0, bestLength = 1;
>     start = 0;
>     for (int i = 1; i < n; i++) {
>         if (A[i] <= A[i - 1]) currentStart = i;
>         int length = i - currentStart + 1;
>         if (length > bestLength) { bestLength = length; start = currentStart; }
>     }
>     return bestLength;
> }
> ```

### A15 有序数组中的紧密三元组计数

**来源**：保留旧A11“好题”，修复旧版题答错配。

- [ ] 首次：能说明状态并独立写出
- [ ] 间隔复写：不看答案通过边界检查

**题干**：非递减整数数组A长n，C≥0。统计下标三元组i<j<k，使|A[i]-A[j]|+|A[j]-A[k]|≤C，重复值按不同下标计数。结果能用long long表示。不改输入，O(n)时间、O(1)空间。

**先手推自测**：[1,2,3,4]、C=2→2；[1,1,1,1]、C=0→4；n<3→0；INT范围端点相减须先提升。

> [!faq]- 识别模板、推导与完整代码｜先尝试再展开
>
> **考场识别 → [[2.知识库/20.North_star_ZJU/202.计算机知识/05数据结构/08算法题/03算法题模板#A7 条件单调的窗口|A7 条件单调的窗口]]**：“有序＋三个数的跨度限制”先化简绝对值，再固定最右端，窗口内组合计数。不是三数组最小距离，也不是无重复子串。
>
> **关键状态**：有序保证条件化为A[k]-A[i]≤C；left为固定right时最早合法起点，窗口内除right外有count=right-left个位置。
>
> **解题步骤**
> 1. right从0扫描；当跨度>C时while推进left。
> 2. 此时窗口所有值都落在合法跨度内。
> 3. 前两个下标从right左侧的count项任选两个，贡献count*(count-1)/2。
> 4. 累加各right的贡献。
>
> **为什么成立**：每组三元组有唯一最右下标right；其另外两项只需都处于合法窗口中，组合数既不重也不漏。
>
> **时间／额外空间**：O(n)／O(1)。
>
> **易错核对**：旧版此题错贴了最长无重复段代码，本次已重写；按下标计数不可去重；C≥0保证窗口不会越过right。
>
> **完整核心代码**（本卡单独配公共类型编译）
>
> ```cpp
> long long TightTriples(const int A[], int n, long long C) {
>     int left = 0;
>     long long answer = 0;
>     for (int right = 0; right < n; right++) {
>         while ((long long)A[right] - A[left] > C) left++;
>         long long count = right - left;
>         answer += count * (count - 1) / 2;
>     }
>     return answer;
> }
> ```
