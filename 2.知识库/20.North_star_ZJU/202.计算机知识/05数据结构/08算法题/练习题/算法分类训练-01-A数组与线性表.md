### A01 有序数组原地去重

- [ ] 首次：能解释状态并写出代码
- [ ] 间隔复写：不看答案通过自测

**题干**：非递减数组 A，原地使每个值只出现一次；返回有效长度，保留相对顺序。

**自测**：[] → 0；[1,1,2,2,3] → 长度3，前缀[1,2,3]。

> [!faq]- 题解与完整核心代码｜尝试后再展开
> **解题步骤**
> 1. 维护 A[0..w-1] 为已处理部分的去重结果。
> 2. 读到与末尾不同的值才写入。
>
> ```c
> int Unique(int A[], int n) {
>     int w=0;
>     for(int r=0;r<n;r++)
>         if(w==0 || A[r]!=A[w-1]) A[w++]=A[r];
>     return w;
> }
> ```
>
> **时间 / 额外空间**：O(n) / O(1)。
>
> **易错核对**：无序数组不能只与最后保留值比较。

### A03 有序数组两数之和

- [ ] 首次：能解释状态并写出代码
- [ ] 间隔复写：不看答案通过自测

**题干**：非递减数组中找两个不同下标，其和为 K；找到时通过 i,j 输出下标并返回1，否则返回0。

**自测**：[1,2,4,7], K=6 → (1,2)；[3], K=6 → 无解；[3,3] → 有解。

> [!faq]- 题解与完整核心代码｜尝试后再展开
> **解题步骤**
> 1. 左右端对撞。
> 2. 和小只能增左端，和大只能减右端。
>
> ```c
> int TwoSum(int A[], int n, long long K, int *i, int *j) {
>     int l=0,r=n-1;
>     while(l<r) {
>         long long s=(long long)A[l]+A[r];
>         if(s==K) { *i=l; *j=r; return 1; }
>         if(s<K) l++; else r--;
>     }
>     return 0;
> }
> ```
>
> **时间 / 额外空间**：O(n) / O(1)。
>
> **易错核对**：必须 l<r，不能重复用同一个元素。

>     for(int i=0;i<n;i++) {
>         while(j>=0 && (long long)A[i]+B[j]>K) j--;
>         ans+=j+1;
>     }
>     return ans;
> }
> ```
>
> **时间 / 额外空间**：O(n+m) / O(1)。

### A05 三数之和存在性

- [ ] 首次：能解释状态并写出代码
- [ ] 间隔复写：不看答案通过自测

**题干**：任意整数数组，判断是否有三个不同下标的数之和为0。允许修改数组。

**自测**：[-1,0,1,2] → 1；[0,0] → 0；[0,0,0] → 1。

> [!faq]- 题解与完整核心代码｜尝试后再展开
> **解题步骤**
> 1. 先用插入排序得到非递减序列，再固定 i、双指针找剩余两数。此处故意展开排序，后续可替换为堆排序。
>
> ```c
> int ThreeSum(int A[],int n) {
>     for(int i=1;i<n;i++) {
>         int x=A[i],j=i-1;
>         while(j>=0 && A[j]>x) { A[j+1]=A[j]; j--; }
>         A[j+1]=x;
>     }
>     for(int i=0;i<n-2;i++) {
>         int l=i+1,r=n-1;
>         while(l<r) {
>             long long s=(long long)A[i]+A[l]+A[r];
>             if(s==0) return 1;
>             if(s<0) l++; else r--;
>         }
>     }
>     return 0;
> }
> ```
>
> **时间 / 额外空间**：O(n²)，包括本实现的排序 / O(1)。
>
> **易错核对**：只判存在，无须去重输出；求和前转 long long。

### A06 两个有序数组最小绝对差

- [ ] 首次：能解释状态并写出代码
- [ ] 间隔复写：不看答案通过自测

**题干**：A、B 均非递减且非空，返回任取一元素的最小绝对差。

**自测**：[1,5,10] 与 [4,8] → 1；[INT_MIN] 与 [INT_MAX] → 4294967295。

> [!faq]- 题解与完整核心代码｜尝试后再展开
> **解题步骤**
> 1. 比较当前两数后只推进较小的一方。
> 2. 较大方不动才可能缩小差。
>
> ```c
> long long MinDiff(int A[],int n,int B[],int m) {
>     int i=0,j=0; long long ans=LLONG_MAX;
>     while(i<n && j<m) {
>         long long d=(long long)A[i]-B[j];
>         long long v=d<0?-d:d;
>         if(v<ans) ans=v;
>         if(d==0) return 0;
>         if(d<0) i++; else j++;
>     }
>     return ans;
> }
> ```
>
> **时间 / 额外空间**：O(n+m) / O(1)。
>
> **易错核对**：先提升再相减，不能 abs(int差值)。

### A07 最大最小交替重排

- [ ] 首次：能解释状态并写出代码
- [ ] 间隔复写：不看答案通过自测

**题干**：非递减数组 A，按最大、最小、次大、次小…重排。先写 O(n) 输出数组版，再写真正 O(1) 额外空间版；不假定值非负。

**自测**：[1,2,3,4,5] → [5,1,4,2,3]；[-3,-2,-1] → [-1,-3,-2]。

> [!faq]- 题解与完整核心代码｜尝试后再展开
> **解题步骤**
> 1. 输出数组版双端取值。
> 2. 原地版每次把剩余后缀最大值挪到前面（右移保序），再跳过紧随的最小值，时间换空间。
>
> ```c
> void AlternateBuffer(int A[],int n,int out[]) {
>     int l=0,r=n-1,k=0;
>     while(l<=r) {
>         out[k++]=A[r--];
>         if(l<=r) out[k++]=A[l++];
>     }
> }
> void AlternateInPlace(int A[],int n) {
>     for(int i=0;i<n;i+=2) {
>         int x=A[n-1];
>         for(int j=n-1;j>i;j--) A[j]=A[j-1];
>         A[i]=x;
>     }
> }
> ```
>
> **时间 / 额外空间**：输出数组版 O(n) / O(n)结果；原地版 O(n²) / O(1)。
>
> **易错核对**：旧题库题干写原地却申请数组；本卡明确给两种空间要求，不把复制回原数组叫 O(1)。

### A08 非负数组和不超过 K 的子数组数

- [ ] 首次：能解释状态并写出代码
- [ ] 间隔复写：不看答案通过自测

**题干**：A[i]≥0，统计非空连续子数组和≤K 的个数。

**自测**：[1,2,1], K=3 → 5；[0,0], K=0 → 3；K<0 → 0。

> [!faq]- 题解与完整核心代码｜尝试后再展开
> **解题步骤**
> 1. 加入右端后循环缩左端至合法。
> 2. 以 r 结尾的合法起点有 r-l+1 个。
>
> ```c
> long long AtMost(int A[],int n,long long K) {
>     if(K<0) return 0;
>     int l=0; long long sum=0,ans=0;
>     for(int r=0;r<n;r++) {
>         sum+=A[r];
>         while(sum>K) sum-=A[l++];
>         ans+=r-l+1;
>     }
>     return ans;
> }
> ```
>
> **时间 / 额外空间**：O(n) / O(1)。
>
> **易错核对**：负数破坏按和扩缩的单调性；和恰为K可用 AtMost(K)-AtMost(K-1)，需保证 K-1 可表示。

### A09 正数数组最短达标子数组

- [ ] 首次：能解释状态并写出代码
- [ ] 间隔复写：不看答案通过自测

**题干**：A[i]>0，target>0；返回和≥target 的最短非空子数组长度，不存在返回0。

**自测**：[2,3,1,2,4,3], target=7 → 2；[1,1], target=3 → 0。

> [!faq]- 题解与完整核心代码｜尝试后再展开
> **解题步骤**
> 1. 一旦达标，先记录长度再删左端，直到不达标。
> 2. 不可只缩一次。
>
> ```c
> int MinLen(int A[],int n,long long target) {
>     int l=0,best=n+1; long long sum=0;
>     for(int r=0;r<n;r++) {
>         sum+=A[r];
>         while(sum>=target) {
>             if(r-l+1<best) best=r-l+1;
>             sum-=A[l++];
>         }
>     }
>     return best==n+1?0:best;
> }
> ```
>
> **时间 / 额外空间**：O(n) / O(1)。
>
> **易错核对**：最短≥与最长≤的更新时机不同。

### A10 最长无重复字节段

> [!faq]- 题解与完整核心代码｜尝试后再展开
> **解题步骤**
> 1. last[x] 记上次位置。
> 2. 左边界取 max(left,last[x]+1)，不能回退。
>
> ```c
> int LongestUnique(const unsigned char A[],int n) {
>     int last[256],l=0,best=0;
>     for(int i=0;i<256;i++) last[i]=-1;
>     for(int r=0;r<n;r++) {
>         if(last[A[r]]>=l) l=last[A[r]]+1;
>         last[A[r]]=r;
>         if(r-l+1>best) best=r-l+1;
>     }
>     return best;
> }
> ```
>
> **时间 / 额外空间**：O(n+256) / O(256)。
>
> **易错核对**：last 的旧位置在窗口外时不能把 l 往回拉。

### A11 紧密三元组计数

**题干**：非递减数组，C≥0；统计 i<j<k 且 |A[i]-A[j]|+|A[j]-A[k]|≤C 的下标三元组；答案可用 long long 表示。

**自测**：[1,2,3,4], C=2 → 2；[1,1,1,1], C=0 → 4。

> [!faq]- 题解与完整核心代码｜尝试后再展开
> **解题步骤**
> 1. 先消绝对值为 A[k]-A[i]。
> 2. 对每个右端 r，找最小合法左端 l，贡献 C(r-l,2)。
>
> ```c
> long long CloseTriples(int A[],int n,long long C) {
>     int l=0; long long ans=0;
>     for(int r=0;r<n;r++) {
>         while((long long)A[r]-A[l]>C) l++;
>         long long count=r-l;
>         ans+=count*(count-1)/2;
>     }
>     return ans;
> }
> ```
>
> **时间 / 额外空间**：O(n) / O(1)。
>
> **易错核对**：计下标组合不去重；差值先提升类型。

**题干**：n≥1，1≤k≤n；原地返回第 k 小，允许重复。

**自测**：[3,1,2,2], k=3 → 2；[5], k=1 → 5；全相等不能死循环。

> [!faq]- 题解与完整核心代码｜尝试后再展开
> **解题步骤**
> 1. 挖坑划分。
> 2. p 与 k-1 比较，只缩向包含目标的一侧。
>
> ```c
> int Partition(int A[],int l,int r) {
>     int x=A[l];
>     while(l<r) {
>         while(l<r && A[r]>=x) r--;
>         A[l]=A[r];
>         while(l<r && A[l]<=x) l++;
>         A[r]=A[l];
>     }
>     A[l]=x; return l;
> }
> int Kth(int A[],int n,int k) {
>     int l=0,r=n-1,t=k-1;
>     while(l<=r) {
>         int p=Partition(A,l,r);
>         if(p==t) return A[p];

>     }
>     return 0; /* 合法输入不会到达 */
> }
> ```
>

### A19 人数最均衡且总和差最大的分组

- [ ] 首次：能解释状态并写出代码
- [ ] 间隔复写：不看答案通过自测

**题干**：n≥2，分两组，人数差≤1，使两组总和绝对差最大。允许修改数组，返回差值。

**自测**：[1,2,3,4,5] → 9；[-10,-9,-8] → 11；[-1,1] → 2。

> [!faq]- 题解与完整核心代码｜尝试后再展开
> **解题步骤**
> 1. 令较小组人数 k=floor(n/2)。固定组大小时，小组和的最小/最大值分别由最小k项/最大k项取得。
> 2. |total-2*sum| 在两端取最大。做两次选择并比较，不漏奇数n或负数。
>
> ```c
> long long MaxGroupGap(int A[],int n) {
>     int k=n/2;
>     Kth(A,n,k); /* 依赖本专题 Partition、Kth */
>     long long low=0,total=0,high=0;
>     for(int i=0;i<n;i++) { total+=A[i]; if(i<k) low+=A[i]; }
>     Kth(A,n,n-k+1);
>     for(int i=n-k;i<n;i++) high+=A[i];
>     long long x=total-2*low,y=total-2*high;
>     if(x<0) x=-x;
>     if(y<0) y=-y;
>     return x>y?x:y;
> }
> ```
>
> **时间 / 额外空间**：互异元素随机排列模型下选择平均 O(n)，最坏 O(n²) / O(1)。
>
> **易错核对**：偶数两端等价；奇数且有负数时，只取最小k项不一定最优，例如[-10,-9,-8]。两次选择后及时保存小组和。
