## C 类型与容量

所有专题代码采用 C11，不使用 STL。复制某道题测试时，先复制本页类型/头文件，再复制该专题公共积木及所需前置函数，最后加测试 main。相同类型只定义一次；每题并非独立带 main 的平台提交工程。

```c
#include <stdio.h>
#include <stdlib.h>
#include <limits.h>
#include <string.h>
#define CAP 4096
#define MAXV 128
#define INF (LLONG_MAX/4)
typedef struct LNode { int data; struct LNode *next; } LNode;
typedef struct BTNode { int data; struct BTNode *lchild,*rchild; } BTNode;
typedef struct Arc { int to; struct Arc *next; } Arc;
typedef struct { int n; Arc *head[MAXV]; } Graph;
typedef struct { int n; long long w[MAXV][MAXV]; } WGraph;
```

- 链表默认不带头结点；按编号取模题明确使用带头结点。`LNode` 数据域为 `data`。
- 树默认普通二叉树，字段 `lchild/rchild`；孩子兄弟最大度一题明确改解释。返回新根的函数，调用者必须接回返回值。
- 题目会释放的结点必须由动态内存分配、归本算法所有；共享尾与环入口题不释放结点。
- `CAP`、`MAXV` 是固定训练容量，不是题目证明的一部分。超容量先改容量或改用动态存储，不能让程序越界。队列 `r` 表示已入队总数，本套非循环数组队列不会复用已出队槽位。
- 本套各题给出的输入、缓冲区、源点、k、正数等前提视为调用者保证；只有题干明确要求的非法情况才在函数内处理。生产代码还需补容量检查、内存失败及完整错误处理。
- 固定数组实际空间记作 O(CAP)/O(MAXV)；若按输入规模分配，则给出常用的 O(n)/O(V) 表述。函数内全零初始化固定数组也有相应容量成本，不能在 n 很小时说严格 O(n)。
- 所有数值计算假定最终和、中间和、乘积等能用对应 `long long` 表示。调用前先据数据范围判断；只把 int 换成 long long 不等于任意精度。
- 图顶点编号0..n-1，邻接表 `Graph` 的无向边存双向邻接项；`WGraph` 无边用 `INF`，0权边不可抹掉。测试前须完整初始化矩阵，不能把未初始化元素当 INF。
- 本页 `WGraph` 体积较大，测试程序可用静态/全局变量或动态分配，避免在小栈环境同时放多个大矩阵。

## 三类自测

1. 正常：覆盖至少两次循环或两层递归。
2. 最小：空、单个、两元素；题目不允许空时不要拿越界调用当算法错误。
3. 易错：重复值、负数/0、删除首结点、退化树、不连通、有环、不可达中挑本题适用的一项。

## 验证口径

题解中的 C 代码按专题组合（本页公共类型＋专题公共积木＋本专题各题函数），已以 `gcc -std=c11 -Wall -Wextra -Werror -O2` 编译并运行测试。随机/穷举核对覆盖若干核心函数，不代表已形式证明每个函数或穷尽所有边界；打印路径等输出函数主要经代码核对和手推。详见 [[算法分类训练-整理与校验记录]]。
