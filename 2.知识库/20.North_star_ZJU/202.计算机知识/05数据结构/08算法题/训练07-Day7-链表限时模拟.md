## 题目｜现在开始读

给定带头结点的单链表 L，删除并释放所有值严格大于**原链表全部数据结点平均值**的结点，保持其余结点相对顺序，不在删除中重算平均值。

允许负数、空表和 L==NULL。保证总和、`结点值×结点数` 不超出 long long 范围。要求时间 O(n)、额外空间 O(1)。数据结点由动态内存分配，假定已包含 `<stdlib.h>`。

结构体已给，不用默写：

```c
typedef struct LNode {
    int data;
    struct LNode *next;
} LNode, *LinkList;
```

```c
void DeleteGreaterThanAverage(LinkList L);
```

> 结果：`[1,1]`；`[]`；`[-5]`。
>
> ```c
> void DeleteGreaterThanAverage(LinkList L) {
>     if (L == NULL) return;
>
>     long long sum = 0;
>     int count = 0;
>     LNode *p = L->next;
>     while (p != NULL) {
>         sum += p->data;
>         count++;
>         p = p->next;
>     }
>     if (count == 0) return;
>
>     LNode *pre = L;
>     p = L->next;
>     while (p != NULL) {
>         if ((long long)p->data * count > sum) {
>             pre->next = p->next;
>             free(p);
>             p = pre->next;
>         } else {
>             pre = p;
>             p = p->next;
>         }
>     }
> }
> ```
>
> 时间 O(n)、额外空间 O(1)。检查：统计量保持原值；空表不除零；乘法先提升类型；删后 pre 不动；free 后不读取旧 p。
