### 主练｜数据流最大的 k 个元素

- [ ] 独立思考并留下完整作答

依次读取 n 个整数，可重复，已知1≤k≤n。只能保存 k 个候选数，不允许保存/排序整个数据流。处理完后输出最大的 k 个数（内部顺序任意），并返回第 k 大；重复值按次数计。提供 Next() 逐个读数。

```c
int StreamTopK(int n, int k, int H[]);
```

**要求**：时间 O(n log(k+1))，额外空间 O(k)；用你自己写的小根堆，不用 priority_queue。
