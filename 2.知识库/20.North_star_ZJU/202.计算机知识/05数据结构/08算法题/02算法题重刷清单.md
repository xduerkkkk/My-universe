# 二、线性表、数组与双指针

## 1. 快速选择：求无序数组第 k 小元素

### 题目描述

给定长度为 `n` 的无序数组 `A[0...n-1]` 和整数 `k`，其中 `1 <= k <= n`。要求利用快速排序的划分思想，返回数组中第 `k` 小的元素。允许在数组上原地交换，不要求输出完整排序结果。

### 解题思路

`Partition` 完成一次划分后，枢轴位于最终有序位置 `pos`：左侧元素不大于枢轴，右侧元素不小于枢轴。若 `pos == k-1`，直接返回；否则只在包含目标位置的一侧继续划分。

### 考场风格完整代码

~~~c
int Partition(int A[], int low, int high) {
    int pivot = A[low];
    while (low < high) {
        while (low < high && A[high] >= pivot)
            high--;
        A[low] = A[high];

        while (low < high && A[low] <= pivot)
            low++;
        A[high] = A[low];
    }
    A[low] = pivot;
    return low;
}

int QuickSelect(int A[], int n, int k) {
    int low = 0, high = n - 1;
    int target = k - 1;

    while (low <= high) {
        int pos = Partition(A, low, high);
        if (pos == target)
            return A[pos];
        if (pos > target)
            high = pos - 1;
        else
            low = pos + 1;
    }
    return -1;  // k 不合法时的防御性返回
}
~~~

- 平均时间复杂度：`O(n)`；最坏 `O(n^2)`。
- 额外空间复杂度：迭代版 `O(1)`。
- 易错点：第 `k` 小对应下标 `k-1`；内层扫描必须保留 `low < high`。

## 2. 旋转有序数组求最小值

### 题目描述

长度为 `n` 的数组原本严格递增，经过一次旋转后得到 `A`，例如 `[4,5,6,1,2,3]`。数组中无重复元素。请在 `O(log n)` 时间内返回最小值。

### 解题思路

比较 `A[mid]` 与 `A[high]`：若 `A[mid] > A[high]`，最小值一定在 `mid` 右侧；否则最小值可能就是 `mid`，因此保留 `mid`，令 `high = mid`。

### 考场风格完整代码

~~~c
int FindMinInRotated(int A[], int n) {
    int low = 0, high = n - 1;

    while (low < high) {
        int mid = low + (high - low) / 2;
        if (A[mid] > A[high])
            low = mid + 1;
        else
            high = mid;
    }
    return A[low];
}
~~~

- 时间复杂度：`O(log n)`；空间复杂度：`O(1)`。
- 易错点：`A[mid] <= A[high]` 时不能写 `high = mid - 1`，因为 `mid` 可能就是最小值。

## 3. 非负数组中统计和不超过 k 的连续子数组

### 题目描述

给定长度为 `n` 的非负整数数组 `A` 和非负整数 `k`，统计所有连续非空子数组中元素和不超过 `k` 的数量。

### 解题思路

非负性保证窗口右移时和不会下降、左移时和不会上升。维护窗口 `[left,right]` 和 `sum`；当 `sum > k` 时不断右移 `left`。以 `right` 结尾的合法子数组有 `right-left+1` 个。

### 考场风格完整代码

~~~c
long long CountSubarrays(int A[], int n, int k) {
    int left = 0;
    long long sum = 0;
    long long count = 0;

    for (int right = 0; right < n; right++) {
        sum += A[right];
        while (left <= right && sum > k) {
            sum -= A[left];
            left++;
        }
        count += right - left + 1;
    }
    return count;
}
~~~

- 时间复杂度：`O(n)`；空间复杂度：`O(1)`。
- 易错点：如果数组允许负数，滑动窗口不再成立；此题的关键条件是“非负”。结果数量可能达到 `O(n^2)`，应使用 `long long`。

## 4. 统计两数组中满足和不超过上限的数对

### 题目描述

给定两个整数数组 `A[0...n-1]`、`B[0...m-1]`，统计有序下标对 `(i,j)` 的数量，使得 `A[i] + B[j] <= K`。要求尽可能高效。

### 解题思路

先将 `B` 排序。对每个 `A[i]`，二分查找 `B` 中最后一个不超过 `K-A[i]` 的位置，累加其前缀长度。若题目给出元素值范围很小，也可以用频次数组 + 前缀和替代排序。

### 考场风格完整代码

~~~c
void Swap(int *a, int *b) {
    int t = *a;
    *a = *b;
    *b = t;
}

int PartitionInt(int A[], int low, int high) {
    int pivot = A[low];
    while (low < high) {
        while (low < high && A[high] >= pivot) high--;
        A[low] = A[high];
        while (low < high && A[low] <= pivot) low++;
        A[high] = A[low];
    }
    A[low] = pivot;
    return low;
}

void QuickSort(int A[], int low, int high) {
    if (low >= high) return;
    int pos = PartitionInt(A, low, high);
    QuickSort(A, low, pos - 1);
    QuickSort(A, pos + 1, high);
}

int UpperBound(int A[], int n, int x) {
    int low = 0, high = n;
    while (low < high) {
        int mid = low + (high - low) / 2;
        if (A[mid] <= x)
            low = mid + 1;
        else
            high = mid;
    }
    return low;  // B 中 <= x 的元素个数
}

long long CountPairs(int A[], int n, int B[], int m, int K) {
    QuickSort(B, 0, m - 1);
    long long ans = 0;
    for (int i = 0; i < n; i++)
        ans += UpperBound(B, m, K - A[i]);
    return ans;
}
~~~

- 时间复杂度：排序 `O(m log m)`，查询 `O(n log m)`。
- 若题目明确值域为 `0...5n`，可改为计数数组 + 前缀和，达到 `O(n+m)`。

## 5. 有序数组原地去重

### 题目描述

给定非递减数组 `A[0...n-1]`，要求原地删除重复元素，使前 `len` 个位置保存不重复结果，并返回 `len`。

### 考场风格完整代码

~~~c
int RemoveDuplicates(int A[], int n) {
    if (n == 0) return 0;

    int len = 1;
    for (int i = 1; i < n; i++) {
        if (A[i] != A[len - 1]) {
            A[len] = A[i];
            len++;
        }
    }
    return len;
}
~~~

- 时间复杂度：`O(n)`；空间复杂度：`O(1)`。
- 这是“快慢指针维护有效区间”的基础题，适合与数组删除、移动元素综合改编。

## 6. 三数之和为 0

### 题目描述

给定整数数组 `A[0...n-1]`，判断是否存在三个下标互不相同的元素，使 `A[i]+A[j]+A[k]=0`。只要求判断是否存在，不要求输出所有三元组。

### 解题思路

先排序，固定第一个元素 `i`，再对区间 `[i+1,n-1]` 使用相向双指针。和小于 0 时左指针右移，大于 0 时右指针左移。

### 考场风格完整代码

~~~c
int ThreeSumZero(int A[], int n) {
    QuickSort(A, 0, n - 1);

    for (int i = 0; i < n - 2; i++) {
        int left = i + 1, right = n - 1;
        while (left < right) {
            int sum = A[i] + A[left] + A[right];
            if (sum == 0)
                return 1;
            if (sum < 0)
                left++;
            else
                right--;
        }
    }
    return 0;
}
~~~

- 时间复杂度：`O(n^2)`；空间复杂度：取决于排序实现，原地快排平均 `O(log n)` 递归栈。
- 408 更可能考“是否存在”“统计数量”或“写出双指针过程”，不必追求竞赛版去重输出。

## 7. 交替放置最大值和最小值

### 题目描述

给定非递减数组 `A[0...n-1]`，要求重排为：第一个位置放当前未使用元素中的最大值，第二个位置放最小值，第三个位置放次大值，第四个位置放次小值，依此交替进行。要求原地完成。

### 考场风格完整代码

~~~c
void AlternateMaxMin(int A[], int n) {
    int *B = (int *)malloc(sizeof(int) * n);
    int left = 0, right = n - 1, k = 0;

    while (left <= right) {
        if (k < n) B[k++] = A[right--];
        if (left <= right) B[k++] = A[left++];
    }
    for (int i = 0; i < n; i++)
        A[i] = B[i];
    free(B);
}
~~~

> [!tip] 题目若明确要求 `O(1)` 额外空间，需要进一步采用编码复用或交换技巧；408 常见版本通常不把这个变成位运算题。答题时先确认空间要求。

# 三、链表

## 8. 判断单链表是否对称（回文）

### 题目描述

给定带头结点的单链表 `L`，判断其数据序列是否关于中心对称。例如 `1→2→3→2→1` 是对称链表。要求尽量使用 `O(1)` 额外空间。

### 解题思路

快慢指针找中点；将后半段原地逆置；逐节点比较前半段和后半段；比较完成后可再逆置一次恢复链表。

### 考场风格完整代码

~~~c
LNode *Reverse(LNode *head) {
    LNode *prev = NULL, *p = head;
    while (p != NULL) {
        LNode *next = p->next;
        p->next = prev;
        prev = p;
        p = next;
    }
    return prev;
}

int IsSymmetric(LinkList L) {
    if (L == NULL || L->next == NULL || L->next->next == NULL)
        return 1;

    LNode *slow = L->next;
    LNode *fast = L->next;
    while (fast->next != NULL && fast->next->next != NULL) {
        slow = slow->next;
        fast = fast->next->next;
    }

    LNode *second;
    if (fast->next == NULL) {       // 奇数个数据结点
        second = slow->next;
    } else {                         // 偶数个数据结点
        second = slow->next;
        slow = slow->next;
    }

    second = Reverse(second);
    LNode *p = L->next;
    LNode *q = second;
    int ok = 1;
    while (q != NULL) {
        if (p->data != q->data) {
            ok = 0;
            break;
        }
        p = p->next;
        q = q->next;
    }
    return ok;
}
~~~

- 时间复杂度：`O(n)`；额外空间：`O(1)`。
- 这是链表综合题的五星题：快慢指针 + 逆置 + 比较。考场上可以不恢复链表，除非题目要求保持原结构。

## 9. 带头结点单链表插入排序

### 题目描述

给定带头结点的单链表 `L`，结点数据为整数。将其按非递减顺序原地排序，不申请新的数据结点。

### 考场风格完整代码

~~~c
void InsertionSortList(LinkList L) {
    if (L == NULL || L->next == NULL)
        return;

    LNode *p = L->next;
    L->next = NULL;  // L 只保留头结点，作为已排序表

    while (p != NULL) {
        LNode *r = p->next;  // 先保存后继
        LNode *pre = L;

        while (pre->next != NULL && pre->next->data <= p->data)
            pre = pre->next;

        p->next = pre->next;
        pre->next = p;
        p = r;
    }
}
~~~

- 时间复杂度：`O(n^2)`；空间复杂度：`O(1)`。
- 易错点：`r = p->next` 必须在修改 `p->next` 前完成。

## 10. 链表归并排序

### 题目描述

给定不带头结点的单链表头指针 `head`，要求使用归并排序按非递减顺序排序，时间复杂度为 `O(n log n)`，只允许使用常数级辅助指针（不计递归栈）。

### 考场风格完整代码

~~~c
LNode *MergeList(LNode *a, LNode *b) {
    LNode dummy;
    LNode *tail = &dummy;
    dummy.next = NULL;

    while (a != NULL && b != NULL) {
        if (a->data <= b->data) {
            tail->next = a;
            a = a->next;
        } else {
            tail->next = b;
            b = b->next;
        }
        tail = tail->next;
    }
    tail->next = (a != NULL) ? a : b;
    return dummy.next;
}

LNode *MergeSortList(LNode *head) {
    if (head == NULL || head->next == NULL)
        return head;

    LNode *slow = head;
    LNode *fast = head->next;
    while (fast != NULL && fast->next != NULL) {
        slow = slow->next;
        fast = fast->next->next;
    }

    LNode *right = slow->next;
    slow->next = NULL;

    LNode *leftPart = MergeSortList(head);
    LNode *rightPart = MergeSortList(right);
    return MergeList(leftPart, rightPart);
}

void SortHeadList(LinkList L) {
    if (L != NULL)
        L->next = MergeSortList(L->next);
}
~~~

- 时间复杂度：`O(n log n)`；递归栈 `O(log n)`。
- 链表排序若只要求“能排好且代码短”，写插入排序；若明确要求 `O(n log n)`，写归并排序。

## 11. 删除所有大于链表平均值的结点

### 题目描述

给定带头结点单链表 `L`，删除所有数据域大于全表平均值的结点，保持剩余结点相对顺序不变。

### 考场风格完整代码

~~~c
void DeleteGreaterThanAverage(LinkList L) {
    if (L == NULL) return;

    long long sum = 0;
    int count = 0;
    LNode *p = L->next;
    while (p != NULL) {
        sum += p->data;
        count++;
        p = p->next;
    }
    if (count == 0) return;

    LNode *pre = L;
    p = L->next;
    while (p != NULL) {
        if ((long long)p->data * count > sum) {
            pre->next = p->next;
            free(p);
            p = pre->next;
        } else {
            pre = p;
            p = p->next;
        }
    }
}
~~~

- 时间复杂度：`O(n)`；空间复杂度：`O(1)`。
- 用 `p->data * count > sum` 避免浮点数平均值带来的边界误差。

# 四、栈、队列与表达式

## 12. 括号匹配 / 奇偶消消栈

### 题目描述

给定只包含 `()[]{}` 的字符串，判断括号是否成对且嵌套匹配。遇到左括号入栈；遇到右括号时检查栈顶是否为对应左括号。

### 考场风格完整代码

~~~c
int IsMatch(char left, char right) {
    return (left == '(' && right == ')') ||
           (left == '[' && right == ']') ||
           (left == '{' && right == '}');
}

int BracketMatch(char str[]) {
    char stack[MAXSIZE];
    int top = -1;

    for (int i = 0; str[i] != '\0'; i++) {
        char c = str[i];
        if (c == '(' || c == '[' || c == '{') {
            stack[++top] = c;
        } else {
            if (top == -1 || !IsMatch(stack[top], c))
                return 0;
            top--;
        }
    }
    return top == -1;
}
~~~

- 时间复杂度：`O(n)`；空间复杂度：`O(n)`。
- 该题也可改成“相邻相同奇偶数字消去”：若当前元素与栈顶满足消去条件则弹栈，否则入栈，底层模板完全相同。

## 13. 后缀表达式求值

### 题目描述

给定以空格分隔的后缀表达式，操作数为整数，运算符为 `+ - * /`。从左到右扫描：操作数入栈；遇到运算符弹出右操作数和左操作数，计算后将结果入栈。表达式合法且除数不为 0。

### 考场风格完整代码

~~~c
int EvaluatePostfix(char expr[]) {
    int stack[MAXSIZE];
    int top = -1;
    int i = 0;

    while (expr[i] != '\0') {
        if (expr[i] == ' ') {
            i++;
            continue;
        }

        if (expr[i] >= '0' && expr[i] <= '9') {
            int value = 0;
            while (expr[i] >= '0' && expr[i] <= '9') {
                value = value * 10 + expr[i] - '0';
                i++;
            }
            stack[++top] = value;
        } else {
            char op = expr[i++];
            int right = stack[top--];
            int left = stack[top--];
            int value;
            if (op == '+') value = left + right;
            else if (op == '-') value = left - right;
            else if (op == '*') value = left * right;
            else value = left / right;
            stack[++top] = value;
        }
    }
    return stack[top];
}
~~~

- 时间复杂度：`O(n)`；空间复杂度：`O(n)`。
- 易错点：减法和除法必须保持 `left op right`，不能把两个操作数顺序写反。

## 14. 二叉树逆层序遍历

### 题目描述

给定二叉树，按“从最后一层到根、同一层从左到右”的顺序输出所有结点。例如普通层序为 `1 2 3 4 5`，逆层序应为 `4 5 2 3 1`。

### 解题思路

按“根、右、左”的顺序进行 BFS，并把出队结点压入栈。最后出栈即可得到“自下而上、同层从左到右”。

### 考场风格完整代码

~~~c
void ReverseLevelOrder(BTNode *root) {
    if (root == NULL) return;

    BTNode *queue[MAXSIZE];
    int front = 0, rear = 0;
    BTNode *stack[MAXSIZE];
    int top = -1;

    queue[rear++] = root;
    while (front < rear) {
        BTNode *p = queue[front++];
        stack[++top] = p;

        // 先右后左，弹栈后才是每层从左到右
        if (p->rchild != NULL) queue[rear++] = p->rchild;
        if (p->lchild != NULL) queue[rear++] = p->lchild;
    }

    while (top >= 0)
        printf("%d ", stack[top--]->data);
}
~~~

- 时间复杂度：`O(n)`；空间复杂度：`O(n)`。
- 这是本文件原有晴问算法链接题的完整 408 化版本。

# 五、二叉树与树的递归

## 15. 求二叉树繁茂程度 / 所有结点深度之和

### 题目描述

定义根结点深度为 `1`。二叉树的繁茂程度为：每一层结点数乘以该层深度后求和。请返回整棵树的繁茂程度。

### 解题思路

“每层结点数 × 深度”的总和，等价于“遍历每个结点，把它的深度加起来”。因此直接使用带 `depth` 参数的递归即可。

### 考场风格完整代码

~~~c
int Prosperity(BTNode *root, int depth) {
    if (root == NULL)
        return 0;

    return depth +
           Prosperity(root->lchild, depth + 1) +
           Prosperity(root->rchild, depth + 1);
}

int GetProsperity(BTNode *root) {
    return Prosperity(root, 1);
}
~~~

- 时间复杂度：`O(n)`；递归栈空间 `O(h)`。
- 若题目要求按层处理，也要会用“队列 + 当前层计数”模板；但单纯求深度统计时递归更短。

## 16. 求孩子-兄弟表示法树的最大度

### 题目描述

树采用孩子-兄弟链表表示：`firstchild` 指向第一个孩子，`nextbro` 指向下一个兄弟。定义结点的度为其孩子个数。请返回整棵树的最大度。

### 考场风格完整代码

~~~c
typedef struct TNode {
    int data;
    struct TNode *firstchild;
    struct TNode *nextbro;
} TNode;

int maxDegree;

int CountBrothers(TNode *p) {
    if (p == NULL) return 0;
    return 1 + CountBrothers(p->nextbro);
}

void FindMaxDegree(TNode *p) {
    if (p == NULL) return;

    int degree = CountBrothers(p->firstchild);
    if (degree > maxDegree)
        maxDegree = degree;

    FindMaxDegree(p->firstchild);
    FindMaxDegree(p->nextbro);
}

int GetMaxDegree(TNode *root) {
    maxDegree = 0;
    FindMaxDegree(root);
    return maxDegree;
}
~~~

- 时间复杂度：朴素写法最坏可能为 `O(n^2)`，因为重复统计兄弟链；若题目强调线性时间，可在一次递归中同时返回链长并更新最大值。

### 线性时间版本

~~~c
int bestDegree;

int ScanTree(TNode *p) {
    if (p == NULL) return 0;

    int childCount = ScanTree(p->firstchild);
    if (childCount > bestDegree)
        bestDegree = childCount;

    return 1 + ScanTree(p->nextbro);
}

int GetMaxDegreeLinear(TNode *root) {
    bestDegree = 0;
    ScanTree(root);
    return bestDegree;
}
~~~

## 17. 二叉查找树中序序列合法性判断

### 题目描述

给定二叉树，判断它是否为二叉查找树。要求对任意结点满足：左子树所有关键字小于结点，右子树所有关键字大于结点；假定关键字不重复。

### 考场风格完整代码

~~~c
int hasPrev;
int prevValue;

int CheckBST(BTNode *root) {
    if (root == NULL) return 1;

    if (!CheckBST(root->lchild))
        return 0;

    if (hasPrev && prevValue >= root->data)
        return 0;
    prevValue = root->data;
    hasPrev = 1;

    return CheckBST(root->rchild);
}

int IsBST(BTNode *root) {
    hasPrev = 0;
    return CheckBST(root);
}
~~~

- 时间复杂度：`O(n)`；空间复杂度：`O(h)`。
- 核心是“BST 的中序遍历严格递增”，不要只比较结点和左右孩子，那样不能覆盖整棵子树的约束。

## 18. 删除二叉树的所有叶结点

### 题目描述

给定二叉树，删除所有叶结点并释放其空间，返回删除后的新根。若根本身是叶结点，返回 `NULL`。

### 考场风格完整代码

~~~c
BTNode *DeleteLeaves(BTNode *root) {
    if (root == NULL)
        return NULL;

    if (root->lchild == NULL && root->rchild == NULL) {
        free(root);
        return NULL;
    }

    root->lchild = DeleteLeaves(root->lchild);
    root->rchild = DeleteLeaves(root->rchild);
    return root;
}
~~~

- 时间复杂度：`O(n)`；递归栈空间 `O(h)`。
- 这是典型的“递归函数返回新子树根”题型，删除结点时不能只 `free(root)` 而不把父结点指针改成 `NULL`。

## 19. 二叉树层序遍历并统计最大宽度

### 题目描述

给定二叉树，返回其最大层结点数。要求使用队列进行层序遍历。

### 考场风格完整代码

~~~c
int MaxWidth(BTNode *root) {
    if (root == NULL) return 0;

    BTNode *queue[MAXSIZE];
    int front = 0, rear = 0;
    int ans = 0;
    queue[rear++] = root;

    while (front < rear) {
        int levelEnd = rear;
        int width = 0;
        while (front < levelEnd) {
            BTNode *p = queue[front++];
            width++;
            if (p->lchild != NULL) queue[rear++] = p->lchild;
            if (p->rchild != NULL) queue[rear++] = p->rchild;
        }
        if (width > ans) ans = width;
    }
    return ans;
}
~~~

- 时间复杂度：`O(n)`；空间复杂度：`O(n)`。
- `levelEnd = rear` 表示当前层结束位置，是比“提前计算下一层”更不容易错的考场模板。

## 20. 无向图判断是否有环

### 题目描述

给定无向图的邻接表，判断图中是否存在环。图可能不连通。遍历无向边 `(v,u)` 时，如果 `u` 已访问且 `u` 不是当前顶点 `v` 的父结点，则发现环。

### 考场风格完整代码

~~~c
int visited[MAXV];

int DFSHasCycle(ALGraph *G, int v, int parent) {
    ArcNode *p = G->vertices[v].firstarc;
    while (p != NULL) {
        int u = p->adjvex;
        if (!visited[u]) {
            visited[u] = 1;
            if (DFSHasCycle(G, u, v))
                return 1;
        } else if (u != parent) {
            return 1;
        }
        p = p->nextarc;
    }
    return 0;
}

int HasUndirectedCycle(ALGraph *G) {
    for (int i = 0; i < G->numV; i++)
        visited[i] = 0;

    for (int i = 0; i < G->numV; i++) {
        if (!visited[i]) {
            visited[i] = 1;
            if (DFSHasCycle(G, i, -1))
                return 1;
        }
    }
    return 0;
}
~~~

- 时间复杂度：`O(V+E)`；空间复杂度：`O(V)`。
- 易错点：无向图不能把“访问过的邻居”一律判为环，必须排除父结点。

## 21. BFS 染色判断二分图

### 题目描述

给定无向图的邻接矩阵 `Edge`，判断是否能把顶点划分为两个互不相交的集合，使每条边的两个端点分属不同集合。图可能不连通。

### 考场风格完整代码

~~~c
int IsBipartite(MGraph G) {
    int color[MAXV] = {0};  // 0 未染色，1/2 为两个集合
    int queue[MAXV];

    for (int start = 0; start < G.numV; start++) {
        if (color[start] != 0)
            continue;

        int front = 0, rear = 0;
        color[start] = 1;
        queue[rear++] = start;

        while (front < rear) {
            int v = queue[front++];
            for (int u = 0; u < G.numV; u++) {
                if (G.Edge[v][u] == 0)
                    continue;

                if (color[u] == 0) {
                    color[u] = 3 - color[v];
                    queue[rear++] = u;
                } else if (color[u] == color[v]) {
                    return 0;
                }
            }
        }
    }
    return 1;
}
~~~

- 时间复杂度：邻接矩阵版 `O(V^2)`；邻接表版 `O(V+E)`。
- 这是“普通 BFS + 一个状态数组”的典型 408 改编，不要被“划分为两个集合”的数学表述吓住。

## 22. 并查集求无向图连通分量数

### 题目描述

给定无向图的邻接表，返回其连通分量个数。由于无向边在邻接表中通常存储两次，只处理 `i < j` 的边可避免重复。

### 考场风格完整代码

~~~c
int FindRoot(int parent[], int x) {
    if (parent[x] == x)
        return x;
    parent[x] = FindRoot(parent, parent[x]);
    return parent[x];
}

int CountComponents(ALGraph G) {
    int parent[MAXV];
    int count = G.numV;

    for (int i = 0; i < G.numV; i++)
        parent[i] = i;

    for (int i = 0; i < G.numV; i++) {
        ArcNode *p = G.vertices[i].firstarc;
        while (p != NULL) {
            int j = p->adjvex;
            if (i < j) {
                int ri = FindRoot(parent, i);
                int rj = FindRoot(parent, j);
                if (ri != rj) {
                    parent[ri] = rj;
                    count--;
                }
            }
            p = p->nextarc;
        }
    }
    return count;
}
~~~

- 时间复杂度：`O(V+E·α(V))`，实际可视为 `O(V+E)`；空间复杂度：`O(V)`。
- 也可以用 DFS/BFS 求连通分量；题目若出现“逐条加入边、判断是否成环”，优先想到并查集。

## 23. Kruskal 最小生成树核心

### 题目描述

给定带权连通无向图。题目已提供 `FindEdge()`，每次返回当前尚未处理的最小权边。请补全 Kruskal 算法，返回最小生成树的权值和。

### 解题思路

并查集维护当前连通分量。若一条边两端根不同，则选边并合并；若根相同，则该边会形成环，跳过。选到 `V-1` 条边即可停止。

### 考场风格完整代码

~~~c
typedef struct Edge {
    int ivex, jvex;
    int weight;
} Edge;

int MSTWeight(int vertexNum) {
    int parent[MAXV];
    for (int i = 0; i < vertexNum; i++)
        parent[i] = i;

    int edgeCount = 0;
    int sum = 0;

    while (edgeCount < vertexNum - 1) {
        Edge *e = FindEdge();  // 题目已提供：返回当前最小权边
        if (e == NULL)
            break;             // 图不连通或边已取完

        int ri = FindRoot(parent, e->ivex);
        int rj = FindRoot(parent, e->jvex);
        if (ri != rj) {
            parent[ri] = rj;
            sum += e->weight;
            edgeCount++;
        }
    }
    return sum;
}
~~~

- 若 `FindEdge()` 已封装排序，考场只需写并查集部分。
- 完整 Kruskal 的排序通常使用边集数组排序或小根堆；408 更常把这些封装掉，真正考“判环与并集合并”。

## 24. 拓扑排序判断有向图是否有环

### 题目描述

给定有向图的邻接表，使用 Kahn 算法输出一个拓扑序列；若无法输出全部 `V` 个顶点，说明图中存在有向环，返回失败。

### 考场风格完整代码

~~~c
int TopologicalSort(ALGraph G, int order[]) {
    int indegree[MAXV] = {0};
    int queue[MAXV];
    int front = 0, rear = 0;

    for (int i = 0; i < G.numV; i++) {
        ArcNode *p = G.vertices[i].firstarc;
        while (p != NULL) {
            indegree[p->adjvex]++;
            p = p->nextarc;
        }
    }

    for (int i = 0; i < G.numV; i++)
        if (indegree[i] == 0)
            queue[rear++] = i;

    int count = 0;
    while (front < rear) {
        int v = queue[front++];
        order[count++] = v;

        ArcNode *p = G.vertices[v].firstarc;
        while (p != NULL) {
            int u = p->adjvex;
            indegree[u]--;
            if (indegree[u] == 0)
                queue[rear++] = u;
            p = p->nextarc;
        }
    }
    return count == G.numV;
}
~~~

- 时间复杂度：`O(V+E)`；空间复杂度：`O(V)`。
- 典型改问：判断有向图是否有环、输出入度为 0 的顶点序列、课程先修关系。

## 25. 无权图单源最短路（BFS）

### 题目描述

给定无权图和源点 `s`，求源点到所有顶点的最短边数。不可达顶点距离记为 `-1`。

### 考场风格完整代码

~~~c
void UnweightedShortestPath(MGraph G, int s, int dist[]) {
    int queue[MAXV];
    int front = 0, rear = 0;

    for (int i = 0; i < G.numV; i++)
        dist[i] = -1;

    dist[s] = 0;
    queue[rear++] = s;

    while (front < rear) {
        int v = queue[front++];
        for (int u = 0; u < G.numV; u++) {
            if (G.Edge[v][u] != 0 && dist[u] == -1) {
                dist[u] = dist[v] + 1;
                queue[rear++] = u;
            }
        }
    }
}
~~~

- 时间复杂度：邻接矩阵 `O(V^2)`，邻接表 `O(V+E)`。
- BFS 第一次到达顶点时的层数就是最短距离，这是 408 图遍历与队列结合的高频变形。

## 26. Dijkstra 求带权图单源最短路

### 题目描述

给定带非负权值的有向图邻接矩阵 `W`，源点为 `s`。求 `s` 到各顶点的最短距离，不存在的边用 `INF` 表示。

### 考场风格完整代码

~~~c
void Dijkstra(MGraph G, int s, int dist[]) {
    int visited[MAXV] = {0};

    for (int i = 0; i < G.numV; i++) {
        dist[i] = G.Edge[s][i];
    }
    dist[s] = 0;

    for (int k = 0; k < G.numV; k++) {
        int v = -1;
        int minDist = INF;

        for (int i = 0; i < G.numV; i++) {
            if (!visited[i] && dist[i] < minDist) {
                minDist = dist[i];
                v = i;
            }
        }
        if (v == -1) break;
        visited[v] = 1;

        for (int u = 0; u < G.numV; u++) {
            if (!visited[u] && G.Edge[v][u] < INF &&
                dist[u] > dist[v] + G.Edge[v][u]) {
                dist[u] = dist[v] + G.Edge[v][u];
            }
        }
    }
}
~~~

- 邻接矩阵朴素实现时间复杂度：`O(V^2)`；空间复杂度：`O(V)`。
- 关键前提：边权非负。存在负权边时不能直接使用 Dijkstra。

## 27. 堆排序与 Top-K

### 题目描述

给定无序数组 `A[0...n-1]`，要求使用大根堆将数组按非递减顺序原地排序。进一步，若只要求找出最大的 `k` 个元素，可使用大小为 `k` 的小根堆维护当前最大的 `k` 个元素。

### 解题思路

大根堆中根结点是当前最大值。先自底向上建堆，然后反复将堆顶与末尾元素交换，并缩小堆的有效范围，再对根结点向下调整。

Top-K 版本维护一个大小为 `k` 的小根堆：先放入前 `k` 个元素；之后若新元素大于堆顶，就用它替换堆顶并向下调整。最终堆中保存的就是最大的 `k` 个元素。

### 考场风格完整代码

~~~c
void SiftDownMax(int A[], int n, int k) {
    int x = A[k];
    int child = 2 * k + 1;

    while (child < n) {
        if (child + 1 < n && A[child + 1] > A[child])
            child++;
        if (A[child] <= x)
            break;

        A[k] = A[child];
        k = child;
        child = 2 * k + 1;
    }
    A[k] = x;
}

void HeapSort(int A[], int n) {
    // 建立大根堆
    for (int i = n / 2 - 1; i >= 0; i--)
        SiftDownMax(A, n, i);

    // 每次把当前最大值放到数组末尾
    for (int end = n - 1; end > 0; end--) {
        int t = A[0];
        A[0] = A[end];
        A[end] = t;
        SiftDownMax(A, end, 0);
    }
}

void SiftDownMin(int A[], int n, int k) {
    int x = A[k];
    int child = 2 * k + 1;

    while (child < n) {
        if (child + 1 < n && A[child + 1] < A[child])
            child++;
        if (A[child] >= x)
            break;

        A[k] = A[child];
        k = child;
        child = 2 * k + 1;
    }
    A[k] = x;
}

// 返回值为 k 个最大元素组成的小根堆，堆内不保证有序
int TopK(int A[], int n, int k, int result[]) {
    if (k <= 0 || k > n)
        return 0;

    for (int i = 0; i < k; i++)
        result[i] = A[i];
    for (int i = k / 2 - 1; i >= 0; i--)
        SiftDownMin(result, k, i);

    for (int i = k; i < n; i++) {
        if (A[i] > result[0]) {
            result[0] = A[i];
            SiftDownMin(result, k, 0);
        }
    }
    return k;
}
~~~

- 堆排序时间复杂度：`O(n log n)`，额外空间复杂度：`O(1)`。
- Top-K 小根堆时间复杂度：`O(n log k)`，额外空间复杂度：`O(k)`。
- 易错点：0-based 堆中左孩子是 `2*k+1`，右孩子是 `2*k+2`；建堆从最后一个非叶结点 `n/2-1` 开始。

## 28. 合并两个有序单链表

### 题目描述

给定两个不带头结点的非递减单链表 `A` 和 `B`，将它们合并为一个非递减单链表。要求直接复用原结点，不申请新的数据结点。

### 解题思路

用 `tail` 指向结果链表的尾部。每次比较两个表头，将较小结点摘下接到 `tail` 后；某一条链表为空后，直接接上另一条剩余链表。

### 考场风格完整代码

~~~c
LNode *MergeSortedLists(LNode *A, LNode *B) {
    LNode dummy;
    LNode *tail = &dummy;
    dummy.next = NULL;

    while (A != NULL && B != NULL) {
        if (A->data <= B->data) {
            tail->next = A;
            A = A->next;
        } else {
            tail->next = B;
            B = B->next;
        }
        tail = tail->next;
    }

    tail->next = (A != NULL) ? A : B;
    return dummy.next;
}

// 若题目给的是两个带头结点链表，可这样调用：
void MergeHeadLists(LinkList A, LinkList B, LinkList C) {
    if (C == NULL) return;
    C->next = MergeSortedLists(A->next, B->next);
}
~~~

- 时间复杂度：`O(m+n)`；额外空间复杂度：`O(1)`。
- 这是链表归并排序、两个有序序列合并等综合题的基础子程序。
- 易错点：摘下结点时只移动对应链表指针，不要提前破坏未处理链表的后继关系。

## 29. 求两个单链表的第一个公共结点

### 题目描述

两个单链表可能在某个结点处相交。相交后，它们共享同一段后缀链表。给定两个不带头结点的链表头指针 `A`、`B`，返回它们的第一个公共结点；若不相交，返回 `NULL`。

### 解题思路

先分别求两条链表长度，让较长链表的指针先走长度差步。随后两个指针同步后移，第一次指针相等的位置就是第一个公共结点。这里必须比较结点地址，而不是比较数据域。

### 考场风格完整代码

~~~c
int ListLength(LNode *head) {
    int len = 0;
    while (head != NULL) {
        len++;
        head = head->next;
    }
    return len;
}

LNode *FirstCommonNode(LNode *A, LNode *B) {
    int lenA = ListLength(A);
    int lenB = ListLength(B);

    LNode *p = A;
    LNode *q = B;
    int diff;

    if (lenA > lenB) {
        diff = lenA - lenB;
        while (diff-- > 0)
            p = p->next;
    } else {
        diff = lenB - lenA;
        while (diff-- > 0)
            q = q->next;
    }

    while (p != NULL && q != NULL && p != q) {
        p = p->next;
        q = q->next;
    }
    return p;  // p == q，可能为 NULL
}
~~~

- 时间复杂度：`O(m+n)`；额外空间复杂度：`O(1)`。
- 易错点：公共结点的判断条件是 `p == q`，不是 `p->data == q->data`。
- 这道题和“判断链表是否相交”“求相交后的公共后缀长度”可以互相变式。

## 30. Prim 最小生成树

### 题目描述

给定带权无向图的邻接矩阵 `G.Edge`，不存在的边用 `INF` 表示。请从指定顶点 `start` 出发，使用 Prim 算法求最小生成树的权值和；若图不连通，返回 `-1`。

### 解题思路

`lowCost[i]` 表示当前生成树集合到顶点 `i` 的最小边权。每轮选择未加入集合且 `lowCost` 最小的顶点 `v`，将其加入生成树并累加 `lowCost[v]`，然后用 `v` 的邻边更新其他顶点的 `lowCost`。

### 考场风格完整代码

~~~c
int Prim(MGraph G, int start) {
    int selected[MAXV] = {0};
    int lowCost[MAXV];
    int sum = 0;

    for (int i = 0; i < G.numV; i++)
        lowCost[i] = G.Edge[start][i];

    selected[start] = 1;
    lowCost[start] = 0;

    for (int k = 1; k < G.numV; k++) {
        int v = -1;
        int minCost = INF;

        for (int i = 0; i < G.numV; i++) {
            if (!selected[i] && lowCost[i] < minCost) {
                minCost = lowCost[i];
                v = i;
            }
        }

        if (v == -1)
            return -1;  // 图不连通，无法生成一棵生成树

        selected[v] = 1;
        sum += lowCost[v];

        for (int i = 0; i < G.numV; i++) {
            if (!selected[i] && G.Edge[v][i] < lowCost[i])
                lowCost[i] = G.Edge[v][i];
        }
    }
    return sum;
}
~~~

- 邻接矩阵朴素实现时间复杂度：`O(V^2)`；额外空间复杂度：`O(V)`。
- Prim 适合从“顶点集合”角度理解最小生成树；Kruskal 适合从“边集合 + 并查集”角度理解。
- 易错点：不能把 `lowCost[i]` 写成从起点到 `i` 的最短路；它只表示“当前生成树集合到 `i` 的最小连接边”。

## 31. Floyd 多源最短路

### 题目描述

给定带权图的邻接矩阵，求任意两个顶点之间的最短距离。不存在的边用 `INF` 表示。要求直接在距离矩阵 `dist` 上完成更新。

### 解题思路

按中间顶点 `k` 逐步放宽限制：当允许使用 `0...k` 作为中间顶点时，判断路径 `i→k→j` 是否比当前的 `i→j` 更短。状态转移为：

`dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j])`。

### 考场风格完整代码

~~~c
void Floyd(MGraph G, int dist[MAXV][MAXV]) {
    for (int i = 0; i < G.numV; i++) {
        for (int j = 0; j < G.numV; j++)
            dist[i][j] = G.Edge[i][j];
        dist[i][i] = 0;
    }

    for (int k = 0; k < G.numV; k++) {
        for (int i = 0; i < G.numV; i++) {
            if (dist[i][k] >= INF)
                continue;
            for (int j = 0; j < G.numV; j++) {
                if (dist[k][j] < INF &&
                    dist[i][j] > dist[i][k] + dist[k][j]) {
                    dist[i][j] = dist[i][k] + dist[k][j];
                }
            }
        }
    }
}
~~~

- 时间复杂度：`O(V^3)`；额外空间复杂度：若原地覆盖距离矩阵则为 `O(V^2)` 存储结果。
- 关键前提：循环顺序必须是 `k-i-j`，不能随意交换。
- Floyd 允许处理负权边，但不能正确处理存在负权回路的普通最短路问题；408 常见版本一般默认不存在负权边。

# 八、补充题的优先级与复刷顺序

## A 级：必须在纸上完整默写

1. 链表找中点 + 后半段逆置 + 回文判断。
2. 单链表插入排序或归并排序。
3. 栈括号匹配、后缀表达式求值。
4. 二叉树逆层序遍历。
5. 二叉树深度统计 / 繁茂程度。
6. BST 中序判定、递归删除叶结点。
7. 无向图 DFS 判环。
8. BFS 染色判二分图。
9. 并查集求连通分量、Kruskal 核心。
10. 拓扑排序。
11. 堆排序 / Top-K。
12. 合并两个有序单链表，求两链表第一个公共结点。

## B 级：理解模板并至少手写一遍

1. 快速选择第 `k` 小。
2. 旋转有序数组二分求最小值。
3. 非负数组滑动窗口统计。
4. 三数之和双指针。
5. 无权图 BFS 最短路。
6. Dijkstra 朴素版。
7. Prim 最小生成树。
8. Floyd 多源最短路。

## C 级：了解即可，不要挤占真题时间

1. 十字链表判断有向完全图。
2. 过度依赖值域上限的计数数组优化。
3. 需要复杂位运算才能做到 `O(1)` 空间的原地重排。

> [!important] 图的特殊存储结构
> 十字链表属于有向图，`firstout/tlink` 用于出边链，`firstin/hlink` 用于入边链；邻接多重表属于无向图。它们很适合选择题和结构辨析题，但通常不值得在 408 第 41 题中背冗长结构体。若题目真的给出结构体，严格按照题干字段写，不要套用普通邻接表字段名。
