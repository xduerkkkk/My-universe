### 三、 408 风格匹配度与标准代码改写

在 408 阅卷中：

1. 不建议过度使用 vector 作为返回值，通常以 void 函数直接打印，或者传入数组指针。
    
2. 推荐使用 **原生 C 风格指针 + 静态数组模拟队列与栈**。
    

#### 408 规范改写代码（模拟队列 + 模拟栈）：

codeC++

```
#include <stdio.h>
#include <stdlib.h>

#define MAX_SIZE 1000 // 408 常用静态数组大小

// 假设 408 树节点定义
typedef struct TreeNode {
    int val;
    struct TreeNode *left;
    struct TreeNode *right;
} TreeNode;

// 逆层序遍历：自下而上、从左到右
void ReverseLevelOrder(TreeNode* root) {
    // 1. 边界条件：空树直接返回
    if (root == NULL) {
        return;
    }

    TreeNode* Q[MAX_SIZE]; // 模拟队列
    int front = 0, rear = 0;

    int S[MAX_SIZE];       // 模拟栈，保存最终要输出的节点值
    int top = -1;

    // 2. 根节点入队
    Q[rear++] = root;

    while (front < rear) {
        TreeNode* cur = Q[front++]; // 出队

        // 将出队元素压入栈中
        S[++top] = cur->val;

        // 注意：为了实现“自下而上、从左到右”，
        // 压栈前必须【先让左孩子入队，再让右孩子入队】！
        // 这样出队序列为：[根, 左, 右]，入栈后弹栈序列即为：[右, 左, 根]... 
        // 等等，仔细推理：
        // 若入队顺序为：左孩 -> 右孩
        // 出队序列为：1 -> 2 -> 3
        // 压栈序列为：1, 2, 3 (栈顶为3)
        // 弹栈序列为：3, 2, 1 (自下而上，从右到左) -> 不符合！
        // 
        // 正确入队顺序应为：【先右孩子入队，后左孩子入队】
        // 出队序列为：1 -> 3 -> 2
        // 压栈序列为：1, 3, 2 (栈顶为2)
        // 弹栈序列为：2, 3, 1 (自下而上，从左到右) -> 正确！

        if (cur->right != NULL) {
            Q[rear++] = cur->right;
        }
        if (cur->left != NULL) {
            Q[rear++] = cur->left;
        }
    }

    // 3. 依次出栈打印，实现逆层序输出
    while (top != -1) {
        printf("%d ", S[top--]);
    }
}
```
