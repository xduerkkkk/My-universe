# 链表


```c
typedef struct LNode {
    int data;               // 数据域
    struct LNode *link;     // 指针域（注意：在结构体内部还没有别名，必须写 struct LNode *）
} LNode, *LinkList;
```

需要新建一个在原题中不存在的全新实体”再用 malloc！


1. **向链表插入一个新元素**（例如将数字 x 插入链表）：

    
    ```c
    // 必须先申请一个新结点的内存，才能把 x 放进去
    LNode *s = (LNode*)malloc(sizeof(LNode));
    s->data = x;
    s->link = p->link;
    p->link = s;
    ```
    
2. **初始化一个带头结点的空链表**：

    ```c
    // 头结点是凭空制造出来的哨兵
    LinkList L = (LNode*)malloc(sizeof(LNode));
    L->link = NULL;
    ```
    
3. **算法需要辅助动态数组 / 辅助标记数组**：
    
    ```c
    // 例如图遍历时申请一个长度为 n 的 visited 数组
    int *visited = (int*)malloc(sizeof(int) * n);
    ```
