### 你原来那几个直觉，怎样补成体系

- **“桶数组”可以这么叫，但更精确是计数数组／频次数组／直接寻址表。** seen只记有无，freq记次数，last记最近位置；它不是所有场景都能替代哈希的万能数组，也不等于桶排序。链表的“桶”则是每组头尾指针。
- **树的向上／向下是信息流，不是全部题型。** 向上用返回值，向下用参数；改结构要返回新根；BST借中序顺序；对称需要两树同步；完全性借层序空位。它们可以组合，不是互斥分类。
- **图不只有 BFS、DFS、拓扑。** 这三个是遍历和依赖骨架；并查集处理合并连通性，Dijkstra/Floyd处理距离，Prim/Kruskal处理生成树。先认清求什么，再选代码。
- **模板不是函数名，而是“适用条件＋状态含义＋保持方式”。** 例如记住left/right，却忘了非负性，就会把求和窗口错误套到负数数组。

## 使用约定

- 以下是C99风格模块，函数彼此独立；常量容量均须按题目上限定义，数组下标默认0-based。
- 链表模板默认**不带头结点**，head指首个数据结点。题目若带头结点L，常用 `L->next = Reverse(L->next)` 接回；头结点不参加数据操作。
- 二叉树用 `BTNode{int data; BTNode *lchild,*rchild;}`；高度／栈深记h。图用邻接表，顶点0..V−1，无向图每条边有两个邻接项。
- 代码只写算法函数；堆/队列/栈容量、动态内存失败策略由题目约定。释放结点的前提是结点确由动态分配且归本函数所有。

## A 数组与线性表


### A1 读写指针

**识别**：稳定筛选、删除指定值、排序后去重。

**状态／不变量**：A[0..w−1]始终是已扫描部分的合法结果；r是下个待看元素。

1. w=0，r从0扫描。
2. 满足保留条件才写A[w++]；不要另开数组。
3. 返回w，不是最后有效下标。

**别套错**：无序数组去重不能只与上一个值比较；有序去重才能如此。

> [!faq]- 闭卷回忆后再展开｜C 骨架与变式
> ```c
> int UniqueSorted(int A[], int n) {
>     int w = 0;
>     for (int r = 0; r < n; ++r)
>         if (w == 0 || A[r] != A[w-1]) A[w++] = A[r];
>     return w;
> }
> ```
> 
> 删除指定x，只把if改为 A[r]!=x。空表由w==0与短路求值自然处理。

**回题练**：[[2.知识库/20.North_star_ZJU/202.计算机知识/05数据结构/08算法题/02算法题重刷清单#5. 有序数组原地去重|重刷清单 · 5. 有序数组原地去重]]


### A2 对撞与同向双指针

**识别**：有序区间找两数和、两个有序序列合并、统计可批量计数的数对。

**状态／不变量**：移动一个指针，必须能证明被越过的位置不再需要考虑。

1. 先判断是否需要排序，并把排序成本计入总复杂度。
2. 固定一部分变量，让剩下两个指针单调移动。
3. 命中时按题意决定返回、计数、输出并跳重。

**别套错**：“都是双指针”不意味着随便移动：三数之和要先固定i；统计下标对时重复值不能去重。


**求两数之和用对撞指针；求两数之差必须用同向指针（滑动窗口）！**

> [!faq]- 闭卷回忆后再展开｜C 骨架与变式
> ```c
> // A、B均已非递减；数不同下标对，不对值去重
> long long PairCount(int A[], int n, int B[], int m, long long K) {
>     int j = m - 1;
>     long long ans = 0;
>     for (int i = 0; i < n; ++i) {
>         while (j >= 0 && (long long)A[i] + B[j] > K) --j;
>         ans += j + 1;
>     }
>     return ans;
> }
> ```
> 
> 三数之和：固定i，l=i+1、r=n−1；和小则l++，和大则r--；求全部解需同时处理固定值及两端重复。

**回题练**：[[2.知识库/20.North_star_ZJU/202.计算机知识/05数据结构/08算法题/02算法题重刷清单#4. 统计两数组中满足和不超过上限的数对|重刷清单 · 4. 统计两数组中满足和不超过上限的数对]]；[[2.知识库/20.North_star_ZJU/202.计算机知识/05数据结构/08算法题/02算法题重刷清单#6. 三数之和为 0|重刷清单 · 6. 三数之和为 0]]


### A3 滑动窗口

**识别**：连续片段，加入右端、移除左端能O(1)维护状态，且边界可单调移动。

**状态／不变量**：窗口[l,r]与sum/freq/last必须一致；l只前进，不回退。

1. 先写加入右端后的状态变化。
2. 写while恢复合法性，或while仍满足目标时收缩。
3. 在正确时机更新长度／计数，不混淆目标。

**别套错**：负数会破坏普通“按和扩缩”的单调性；滑动窗口不是所有子数组题的通用解。

> [!faq]- 闭卷回忆后再展开｜C 骨架与变式
> ```c
> // A[i]>=0；数非空子数组，支持K<0
> long long AtMost(int A[], int n, long long K) {
>     if (K < 0) return 0;
>     int l = 0;
>     long long sum = 0, ans = 0;
>     for (int r = 0; r < n; ++r) {
>         sum += A[r];
>         while (sum > K) sum -= A[l++];
>         ans += r - l + 1;
>     }
>     return ans;
> }
> ```
> 
> - 非负和恰为K：AtMost(K)−AtMost(K−1)。
> - 正数最短和≥target：加入右端后，while(sum>=target)先更新最短长度、再删左端。
> - 无重复最长段：last全置−1；l=max(l,last[x]+1)，然后last[x]=r。
> - last=−1不能靠 int last[256]={−1} 完成：那只把第0项设−1，其他项变0，应循环初始化。

> [!faq]- 例子，所有满足“子数组内元素乘积严格小于 k的连续子数组的总数
> #### 1. 算法设计思想
> 采用**双指针滑动窗口（Sliding Window）**算法：
> 1. **边界特判**：若 $k \le 1$，由于数组全为正整数，乘积至少为 1，不可能严格小于 $k$，直接返回 0。
> 2. **双指针维护窗口**：定义左指针 `left = 0`，乘积累乘器 `prod = 1`。右指针 `right` 从 0 到 $n-1$ 逐步右移扩展窗口。
> 3. **窗口调整与计数**：
>    - 将当前元素纳入乘积：`prod *= nums[right]`。
>    - 若 `prod >= k` 且 `left <= right`，则持续右移左指针缩小窗口，并除以移出的元素 `prod /= nums[left++]`，直到窗口乘积再次小于 $k$。
>    - 此时以 `right` 为右端点且乘积小于 $k$ 的连续子数组个数恰好为当前窗口长度 `right - left + 1`，将该值累加至结果变量 `cnt` 中。
> 4. 遍历完成后，返回 `cnt`。
> 
> ---
> 
> #### 2. 考场满分代码（原生 C/C++ 风格）
> 
> ```c
> #include <stdio.h>
> 
> int numSubarrayProductLessThanK(int nums[], int n, int k) {
>     // 1. 边界漏洞防范：正整数相乘最小为1，若 k <= 1 则不存在任何解
>     if (k <= 1 || n <= 0 || nums == NULL) {
>         return 0;
>     }
> 
>     int left = 0;
>     long long prod = 1; // 用 long long 防止元素相乘产生短暂的整型溢出
>     int cnt = 0;
> 
>     // 2. 滑动窗口模板：右指针主动探索，左指针被动收缩
>     for (int right = 0; right < n; right++) {
>         prod *= nums[right];
> 
>         // 当乘积不满足条件时，收缩左边界
>         while (prod >= k && left <= right) {
>             prod /= nums[left];
>             left++;
>         }
> 
>         // 核心计数：包含 nums[right] 的合法连续子数组个数等于当前窗口长度
>         cnt += (right - left + 1);
>     }
> 
>     return cnt;
> }
> ```
> 
> ---
> 
> #### 3. 复杂度分析
> * **时间复杂度**：$\mathcal{O}(n)$。虽然代码中包含 `for` 和 `while` 嵌套，但在整个遍历过程中，左指针 `left` 和右指针 `right` 都只单向移动，最多各自移动 $n$ 次。每个元素最多进窗口一次、出窗口一次，故均摊时间复杂度为 $\mathcal{O}(n)$，达到了题目要求的最优解。
> * **空间复杂度**：$\mathcal{O}(1)$。算法仅使用了几个普通的整型变量（`left`, `right`, `prod`, `cnt`）进行指针和数值维护，不需要额外的辅助数组，故额外空间复杂度为 $\mathcal{O}(1)$。

> [!faq]- #### 【例题 1】长度最小的子数组（最经典的收缩型窗口）
> 
> **【题目描述】**
> 给定一个含有 $n$ 个正整数的数组和一个正整数 $target$。找出该数组中满足其和 $\ge target$ 的长度最小的**连续子数组**，并返回其长度。如果不存在符合条件的子数组，返回 0。
> * **示例**：`target = 7, nums = [2, 3, 1, 2, 4, 3]`
> * **输出**：`2`（最小连续子数组是 `[4, 3]`）
> 
> **【核心思路】**
> 1. 正整数保证单调性（加数变大，减数变小）。
> 2. 右指针 `right` 负责进数累加总和。
> 3. 当 `sum >= target` 时，说明当前区间**已经满足要求**，我们尝试**缩小它**以寻找更短的长度：不断记录当前长度 `right - left + 1`，并左移 `left`。
> 
> **【考场代码实现】**
> ```c
> int minSubArrayLen(int target, int nums[], int n) {
>     if (nums == NULL || n <= 0) return 0;
> 
>     int left = 0;
>     int sum = 0;
>     int minLen = n + 1; // 设为一个不可能达到的最大值，便于取最小
> 
>     for (int right = 0; right < n; right++) {
>         sum += nums[right]; // 1. 扩大窗口
> 
>         // 2. 窗口满足条件时，尝试收缩窗口找最小值
>         while (sum >= target) {
>             int curLen = right - left + 1;
>             if (curLen < minLen) {
>                 minLen = curLen;
>             }
>             sum -= nums[left]; // 移出左边界
>             left++;            // 收缩窗口
>         }
>     }
> 
>     return (minLen == n + 1) ? 0 : minLen;
> }
> // 复杂度：时间 O(n)，空间 O(1)
> ```
> 
> ---
> 
> #### 【例题 2】无重复字符的最长子串（结合哈希/频次数组的窗口）
> 
> **【题目描述】**
> 给定一个字符串 $s$ ，请你找出其中不含有重复字符的**最长子串**的长度。
> * **示例**：`s = "abcabcbb"`
> * **输出**：`3`（因为无重复字符的最长子串是 `"abc"`）
> 
> **【核心思路】**
> 1. 用一个大小为 128 的整型数组 `map`（直接用 ASCII 码下标模拟哈希表）记录每个字符出现的次数。
> 2. 右指针扫入新字符，将其计数 `+1`。
> 3. 若新字符进入后其频次 `> 1`，说明窗口内出现重复！此时**左指针必须右移**，并将移出的字符频次 `-1`，直到重复字符被移出为止。
> 4. 此时更新最长长度：`maxLen = max(maxLen, right - left + 1)`。
> 
> **【考场代码实现】**
> ```c
> #include <string.h>
> 
> int lengthOfLongestSubstring(char *s) {
>     if (s == NULL) return 0;
> 
>     int n = strlen(s);
>     if (n <= 1) return n;
> 
>     // 用普通数组模拟 ASCII 哈希表，记录字符出现频次，408 原生指针与数组风格
>     int count[128] = {0}; 
>     int left = 0;
>     int maxLen = 0;
> 
>     for (int right = 0; right < n; right++) {
>         char ch = s[right];
>         count[(int)ch]++; // 字符进入窗口
> 
>         // 若当前字符出现重复，左指针不断收缩，直到消除重复
>         while (count[(int)ch] > 1) {
>             count[(int)s[left]]--;
>             left++;
>         }
> 
>         // 此时窗口内必然无重复字符，更新最大长度
>         int curLen = right - left + 1;
>         if (curLen > maxLen) {
>             maxLen = curLen;
>         }
>     }
> 
>     return maxLen;
> }
> // 复杂度：时间 O(n)，空间 O(1)（仅使用了常数大小 128 的辅助数组）
> ```
> 
>

### A4 计数桶与直接寻址

**识别**：值域已知且小；见过没、出现次数、绝对值去重、字符频次。

**状态／不变量**：下标是值的编码，不是原数组位置；范围与偏移必须明确。

1. 明确映射：x、x+offset、abs(x)等。
2. 按用途选择seen/freq/last，正确初始化。
3. 处理一个元素后更新对应槽；统计需区分“先查询还是先加入”。

### A5 前缀和与前缀状态

**识别**：区间和、含负数子数组计数、当前状态与历史状态配对。

**状态／不变量**：P[j]−P[i]是区间[i,j−1]之和；频次表只包含当前前缀之前的前缀。

1. P[0]=0，别漏空前缀。
2. 和为K变成寻找历史值s−K。
3. 先计贡献，再把当前s放入频次表。

**别套错**：不能在K=0时先freq[s]++；一般整数值域不能盲目分配2n+1槽。

> [!faq]- 闭卷回忆后再展开｜C 骨架与变式
> ```c
> // 专用于A[i]为-1/0/1；保证2*n+1可分配且n为非负
> long long CountSigned(int A[], int n, int K) {
>     long long *freq = calloc((size_t)2*n+1, sizeof(*freq));
>     // 模块约定分配成功；生产代码需处理失败
>     int s = 0;
>     long long ans = 0;
>     freq[n] = 1;
>     for (int i = 0; i < n; ++i) {
>         s += A[i];
>         long long t = (long long)s - K;
>         if (t >= -n && t <= n) ans += freq[(int)t+n];
>         ++freq[s+n];
>     }
>     free(freq);
>     return ans;
> }
> ```
> 
> 一般整数用哈希计数（期望O(n)）或前缀值离散化+查询（通常O(n log n)）；本月D21限制值域，才能纯数组O(n)。前缀奇偶/余数也可同理，但必须先证明目标等价关系。

### A6 二分边界

**识别**：有序数据找第一个满足条件的位置；或能判定哪半区间有解。

**状态／不变量**：区间语义固定：下面lower_bound的候选边界在[l,r]，未判定元素区间为[l,r)。

1. l=0、r=n，mid=l+(r−l)/2。
2. A[mid]<x意味着mid及左边都不可能，l=mid+1；否则r=mid。
3. l==r即第一个≥x的位置，允许等于n。

**别套错**：不要把半开区间与r=mid−1混用；旋转数组需先识别哪一半有序；重复值可能令该判定退化。

> [!faq]- 闭卷回忆后再展开｜C 骨架与变式
> ```c
> int LowerBound(int A[], int n, int x) {
>     int l = 0, r = n;
>     while (l < r) {
>         int mid = l + (r-l)/2;
>         if (A[mid] < x) l = mid+1;
>         else r = mid;
>     }
>     return l;
> }
> ```
> 
> 无重复旋转数组最小值：闭区间[0,n−1]，A[mid]>A[r]则l=mid+1，否则r=mid；要求n≥1。查找任意目标见第4周D23，不把求最小模板原样套过去。

### A7 划分与快速选择

**识别**：第k小/大、只需分成大小两组而非全排序。

**状态／不变量**：Partition返回p后，枢轴位置已定，左≤pivot≤右；目标下标保持不变。

1. 明确k从1计数，target=k−1。
2. 划分后只进入含target的一侧。
3. p==target立即停止；迭代边界排除p。

**别套错**：首元素枢轴：平均O(n)、最坏O(n²)；单次划分O(n)不能推出整个选择最坏O(n)。

> [!faq]- 闭卷回忆后再展开｜C 骨架与变式
> ```c
> int Partition(int A[], int l, int r) {
>     int pivot = A[l];
>     while (l < r) {
>         while (l < r && A[r] >= pivot) --r;
>         A[l] = A[r];
>         while (l < r && A[l] <= pivot) ++l;
>         A[r] = A[l];
>     }
>     A[l] = pivot;
>     return l;
> }
> int SelectK(int A[], int n, int k) {
>     int l=0, r=n-1, target=k-1;
>     while (l <= r) {
>         int p=Partition(A,l,r);
>         if (p==target) return A[p];
>         if (p>target) r=p-1; else l=p+1;
>     }
>     return 0; // n>=1且1<=k<=n时不可达，不表示失败值
> }
> ```
> 
> 你的旧训练提醒“不等号！”保留在这里：扫描必须带l<r，重复元素时用>=与<=，确保边界推进。平衡分组先选最小floor(n/2)个，再计算total−2*smallSum。

## L 链表：改边之前先想所有权

三个固定问题：**首结点会不会变？有没有头结点？这条边改掉前后继存在哪里？**


### L1 逆置

**识别**：整体逆置、后半段逆置、区间逆置。

**状态／不变量**：prev是已逆置部分的新首结点；p是未处理部分首结点。

1. next=p->next先保存后继。
2. p->next=prev反转一条边，再令prev=p、p=next。
3. 结束返回prev；带头结点时L->next接返回值。

**别套错**：返回的不是旧head；不带头与带头接口不要混写。区间逆置还需保住两端接口。

> [!faq]- 闭卷回忆后再展开｜C 骨架与变式
> ```c
> LNode *Reverse(LNode *head) {
>     LNode *prev=NULL, *p=head;
>     while (p) {
>         LNode *next=p->next;
>         p->next=prev;
>         prev=p;
>         p=next;
>     }
>     return prev;
> }
> ```
> 
> 区间[left,right]头插法：dummy.next=head；pre指向left前驱，cur=pre->next。重复right−left次：
> ```c
> LNode *x=cur->next;
> cur->next=x->next;
> x->next=pre->next;
> pre->next=x;
> ```
> 
> 这里cur不往前走，它始终是已逆置区间的末结点。

### L2 归并与尾插

**识别**：两个有序链表、链表排序、并集／交集、按顺序组装结果。

**状态／不变量**：tail是输出末结点，a/b分别是两条尚未处理部分首结点。

1. 用局部dummy统一输出首结点。
2. 每次取较小者；稳定归并时相等取a。
3. 普通归并可以整段接剩余；集合去重不可以跳过剩余重复检查。

**别套错**：两条输入必须无环且不共享结点；否则原地归并可能成环。dummy本身不能作为返回指针。

> [!faq]- 闭卷回忆后再展开｜C 骨架与变式
> ```c
> LNode *Merge(LNode *a, LNode *b) {
>     LNode dummy={0,NULL}, *tail=&dummy;
>     while (a && b) {
>         if (a->data <= b->data) { tail->next=a; a=a->next; }
>         else { tail->next=b; b=b->next; }
>         tail=tail->next;
>     }
>     tail->next=a ? a : b;
>     return dummy.next;
> }
> ```
> 
> 组合：归并排序=找中点+**断链**+两边递归+Merge；并集=归并取点+与输出尾值去重+释放重复结点；交集还需明确未选结点是否允许销毁。

### L3 切分与组合

**识别**：中点、首尾配对、回文、相交、环入口、循环位移。

**状态／不变量**：快慢差速用于中点/环；长度差用于对齐；中点切开后才是独立链。

1. 先确定接口：返回前半尾，还是后半首？
2. 在纸上走n=1、2、3，确定奇偶约定。
3. 分解成可独立验证的模块，再接回结果。

**别套错**：快慢指针不是一个通用循环：找中点与判环的起点、终止条件不同。

> [!faq]- 闭卷回忆后再展开｜C 骨架与变式
> ```c
> // n>=1，返回前半段尾；奇数时前半段多一个
> LNode *FirstHalfTail(LNode *head) {
>     LNode *slow=head, *fast=head->next;
>     while (fast && fast->next) {
>         slow=slow->next;
>         fast=fast->next->next;
>     }
>     return slow;
> }
> // 环入口：不修改链表
> LNode *FindCycleEntry(LNode *head) {
>     LNode *slow=head, *fast=head;
>     while (fast && fast->next) {
>         slow=slow->next; fast=fast->next->next;
>         if (slow==fast) {
>             LNode *p=head;
>             while (p!=slow) { p=p->next; slow=slow->next; }
>             return p;
>         }
>     }
>     return NULL;
> }
> ```
> 
> - 切半：mid=FirstHalfTail(head)，b=mid->next，mid->next=NULL。
> - 首尾重排：切半→Reverse(b)→交替接，接前保存两链后继。
> - 回文并恢复：找前半尾→逆置后半→比较→再次逆置并接回；即使发现不等，也先恢复再返回。
> - 首个公共结点：两链先计长，长链先走差值，再按地址同步比较。
> - 循环左移：空表先返回→计长n→k%=n→k==0返回→第k个数据结点作新尾→连旧尾与旧首→从新尾处断开。

### L4 稳定分组

**识别**：链表按奇偶位置、值的类别、编号取模重排，组内需保序。

**状态／不变量**：每个桶有head[r]和tail[r]；已放入桶的结点与原链脱离。

1. 保存原后继next，并把p->next=NULL。
2. 算类别r，尾插而不是头插。
3. 按题意规定的桶顺序连接，释放辅助数组。

**别套错**：按编号与按值不是一回事；余数0先还是余数1先必须由题干决定。

> [!faq]- 闭卷回忆后再展开｜C 骨架与变式
> ```c
> // 片段：heads/tails已清空，0<=r<k
> LNode *next=p->next;
> p->next=NULL;
> if (heads[r]==NULL) heads[r]=p;
> else tails[r]->next=p;
> tails[r]=p;
> p=next;
> ```
> 
> 之后按r=0..k−1收集非空桶。k桶时间O(n+k)、额外空间O(k)；固定两个桶则O(1)空间。稳定性来自尾插，不来自“分了桶”。

### L5 删除与所有权

**识别**：删满足条件的结点、连续重复去重、按原均值删除。

**状态／不变量**：pre->next==p；pre是保留部分末结点，p是当前待判定点。

1. 先确定判定依据是否需要第一遍统计，如“原全表平均值”。
2. 删除时改pre->next、释放p，再令p=pre->next；pre不动。
3. 保留时才同时前进pre和p。

**别套错**：free后不读p->next；共享结点不能随意释放；“删除叶子”还要分原叶与新叶。

> [!faq]- 闭卷回忆后再展开｜C 骨架与变式
> ```c
> // 带头结点L；应先处理L==NULL
> LNode *pre=L, *p=L->next;
> while (p) {
>     if (/* 满足删除条件 */ 0) { // 使用时替换0为判定式
>         pre->next=p->next;
>         free(p);
>         p=pre->next;
>     } else {
>         pre=p;
>         p=p->next;
>     }
> }
> ```
> 
> 原平均值：先求sum/count，再比1LL*p->data*count>sum，不能用有截断的sum/count。绝对值去重：seen[key]则删，否则标记并保留。

## T 树：先决定信息如何流动

问自己：**当前结点做决定之前，缺的是孩子的报告，还是祖先带来的条件？结果是一个数、多个属性，还是一根新指针？**


### T1 自底向上汇总

**识别**：子树和／数量／高度／平衡性／满子树／共同祖先，需要孩子先交结果。

**状态／不变量**：函数返回“以当前root为根的整棵子树”的报告，不能混进父亲或兄弟的统计。

1. 定义Info，把当前层真正需要的字段写出。
2. 给空树定义组合所需的单位值：和0、数量0、高0、布尔合法通常为真。
3. 递归拿L/R→计算当前→返回完整Info。

**别套错**：每层重新遍历子树会变成O(n²)；多个字段不意味着一定要指针出参，结构体可以直接返回。

> [!faq]- 闭卷回忆后再展开｜C 骨架与变式
> ```c
> typedef struct { long long sum; int count, ans; } SuperInfo;
> SuperInfo Super(BTNode *root) {
>     if (!root) return (SuperInfo){0,0,0};
>     SuperInfo L=Super(root->lchild), R=Super(root->rchild), cur;
>     cur.sum=L.sum+R.sum+root->data;
>     cur.count=L.count+R.count+1;
>     cur.ans=L.ans+R.ans+(1LL*root->data*cur.count>=cur.sum);
>     return cur;
> }
> ```
> 
> | 任务 | 向上回传 | 当前层条件 |
> | --- | --- | --- |
> | 平衡检查 | height、ok | 左右均ok且高度差≤1 |
> | perfect满树 | height、ok | 左右均ok且等高 |
> | 最大满子树 | height、ok、size，另累计最大值 | 当前满才用当前size更新 |
> | 目标可能缺失的LCA | mask、ancestor | mask合成3才表示两个都在 |
> 
> 时间O(n)、栈O(h)。高度用−1代表失败与height≥0不冲突，是合法精简法；不能把可能为负的sum随意用−1当失败。

### T2 自顶向下传状态

**识别**：结点深度、根到叶路径和、路径内容、祖先规定的BST值域。

**状态／不变量**：参数代表“走到当前结点时祖先已决定的上下文”；进入左右子树时各拿正确的新状态。

1. 明确根的初始状态，如depth=1。
2. 本层更新状态，再传给孩子。
3. 共享路径数组等可变状态要回退；按值传递的depth/sum不用手动撤销。

**别套错**：“沿途和”不等于“子树和”；按值参数不会被兄弟分支改坏，共享数组会。

> [!faq]- 闭卷回忆后再展开｜C 骨架与变式
> ```c
> long long DepthSum(BTNode *root, int depth) {
>     if (!root) return 0;
>     return depth + DepthSum(root->lchild,depth+1)
>                  + DepthSum(root->rchild,depth+1);
> }
> ```
> 
> - 根到叶目标和：sum+=data；**叶子处**判断，不在中途凑到目标就结束。
> - BST上下界：左传(下界,data)，右传(data,上界)，边界必须能容纳int极值；另一种方法是中序。
> - 孩子-兄弟表示法：firstchild是下一层，nextbro是同一层；不能两个方向都depth+1。

### T3 返回新子树根

**识别**：删除／收缩／修剪／变换树，处理后当前根可能不再存在。

**状态／不变量**：函数的返回值是处理后仍有效的子树入口。

1. 先决定何时判定删除条件：针对原叶还是处理后的形态。
2. 调用孩子后，把返回指针写回lchild/rchild。
3. 保存替代指针后才能free当前结点；最终主调root=Transform(root)。

**别套错**：删除“原来的所有叶子”要在递归前认叶，否则可能把新叶也删光；收缩单分支用后序最清楚。

> [!faq]- 闭卷回忆后再展开｜C 骨架与变式
> ```c
> BTNode *Shrink(BTNode *root) {
>     if (!root) return NULL;
>     root->lchild=Shrink(root->lchild);
>     root->rchild=Shrink(root->rchild);
>     if ((root->lchild==NULL) != (root->rchild==NULL)) {
>         BTNode *child=root->lchild ? root->lchild : root->rchild;
>         free(root);
>         return child;
>     }
>     return root;
> }
> ```
> 
> 展平成先序右链是另一种改结构：右→左→根逆先序，维护prev后缀根，最后改root的左右指针。它不一定返回新根，但仍必须明确哪条边何时改，避免读到改写后的孩子。

### T4 中序维护历史状态

**识别**：BST验证、第k小、前驱后继、把BST顺序转链。

**状态／不变量**：中序访问的历史状态跨递归层共享，不能每层都重置pre或k。

1. 左子树先处理。
2. 当前结点与上一个已访问值比较，或扣减剩余名次。
3. 再处理右子树；显式栈时弹栈才算访问。

**别套错**：仅检查左孩子<根<右孩子不够；INT_MIN不能无条件当“从未访问”的前驱哨兵。

> [!faq]- 闭卷回忆后再展开｜C 骨架与变式
> ```c
> int CheckBST(BTNode *root, int *hasPrev, int *prev) {
>     if (!root) return 1;
>     if (!CheckBST(root->lchild,hasPrev,prev)) return 0;
>     if (*hasPrev && root->data<=*prev) return 0;
>     *hasPrev=1; *prev=root->data;
>     return CheckBST(root->rchild,hasPrev,prev);
> }
> // 调用前 int hasPrev=0, prev=0;
> int KthSmallest(BTNode *root, int k, BTNode *st[]) {
>     int top=0;
>     BTNode *p=root;
>     while (p || top) {
>         while (p) { st[top++]=p; p=p->lchild; }
>         p=st[--top];
>         if (--k==0) return p->data;
>         p=p->rchild;
>     }
>     return 0; // 题目保证1<=k<=n；非法k另定错误协议
> }
> ```
> 
> 验证BST O(n)/O(h)；第k小O(h+k)/O(h)，栈容量至少h。未维护子树规模时，不要声称任意树第k小都能O(log n)。

### T5 双树同步

**识别**：比较两棵树、镜像对称、对应位置是否一致。

**状态／不变量**：递归问题是“a与b这对根是否匹配”，不是各自单独判断。

1. 同时为空成功，恰一个为空失败。
2. 比较当前值。
3. 同树比较同方向，镜像比较交叉方向。

**别套错**：不能只比两边的遍历值序列而丢掉空位结构；同向和交叉别混。

>         && Mirror(a->lchild,b->rchild)

### T6 层序与空位

**识别**：层数、每层宽度、完全性、逆层序、链式堆形状。

**状态／不变量**：队列表示待处理结点；处理一层前固定该层边界，不把新入队孩子混进本层。

1. 普通层序只入非空结点，front=rear=0。
2. 按层时先保存end=rear或levelSize=rear−front。
3. 完全性检查要观察左、右槽位：出现空槽后再有实孩子即失败。

**别套错**：普通左到右BFS直接整体反转会把同层左右也反转；带NULL入队时顺序队列总容量不是n。

> [!faq]- 闭卷回忆后再展开｜C 骨架与变式
> ```c
> // 只把非空结点入队，Q容量>=结点总数n
> int IsComplete(BTNode *root, BTNode *Q[]) {
>     if (!root) return 1;
>     int front=0,rear=0,gap=0;
>     Q[rear++]=root;
>     while (front<rear) {
>         BTNode *p=Q[front++];
>         BTNode *child[2]={p->lchild,p->rchild};
>         for (int i=0;i<2;++i) {
>             if (!child[i]) gap=1;
>             else {
>                 if (gap) return 0;
>                 Q[rear++]=child[i];
>             }
>         }
>     }
>     return 1;
> }
> ```
> 
> - 链式小根堆：在非空孩子分支再检查p->data<=child[i]->data。
> - 最大层宽：每层开始用rear−front更新；只处理当时那一层。
> - 逆层序同层左→右：BFS时**右孩子先入队**，访问结点依次压数组栈，最后逆序输出；或按层收集再逆层输出。
> - 若采用“所有孩子含NULL都入队”，非空n结点会有2n+1次总入队，非循环队列需相应容量。

### S1 栈与表达式

**识别**：括号嵌套、后缀求值、中缀转后缀、后缀建表达式树。

**状态／不变量**：栈顶是最近尚未处理完的符号/值/子树根；弹出顺序决定运算次序。

1. 确定栈中元素类型：char、数值、结点指针不能混。
2. 操作数直接使用或入栈；运算符触发规约。
3. 输出或建树后，核对栈最终状态与所有权。

**别套错**：后缀先弹的是右操作数；减除法交换左右会错误。括号不能输出到后缀式。

> [!faq]- 闭卷回忆后再展开｜C 骨架与变式
> ```c
> // 后缀求值的核心片段：保证表达式合法，top是元素个数
> long long right=st[--top];
> long long left=st[--top];
> long long value=0;
> switch (op) {
>     case '+': value=left+right; break;
>     case '-': value=left-right; break;
>     case '*': value=left*right; break;
>     case '/': value=left/right; break; // 已保证除数非0及商可表示
> }
> st[top++]=value;
> ```
> 
> | 任务 | 栈中存什么 | 核心规则 |
> | --- | --- | --- |
> | 括号匹配 | 左括号 | 右括号需非空栈且类型对应，末尾栈空 |
> | 后缀求值 | 已求出的子表达式值 | 弹右再弹左，结果压回 |
> | 后缀建树 | 已建好的子树根 | 弹右根、左根，新运算结点挂接后压回 |
> | 中缀转后缀 | 运算符与左括号 | 本月仅左结合+−*/：弹出优先级≥当前的运算符 |
> 
> 中缀转换：数字/字母输出；(入栈；)弹到(并丢弃括号；其余按优先级处理。若加入右结合^或一元负号，必须重新规定规则，不直接套。

### S2 单调栈

**识别**：每个位置右侧/左侧首个更大或更小；后来的元素可以解决此前未定答案。

**状态／不变量**：栈存未解决的下标，按值保持单调；答案不会再修改。

1. 先给ans设无解值。
2. 新值可解决栈顶时，while连续弹出并填答案。
3. 把新下标入栈，每个下标最多入出一次。

**别套错**：严格更大要用<作弹出条件，相等暂不解决；存值会丢掉写回答案的位置。

> [!faq]- 闭卷回忆后再展开｜C 骨架与变式
> ```c
> void NextGreater(int A[], int n, int ans[], int st[]) {
>     int top=0;
>     for (int i=0;i<n;++i) ans[i]=-1;
>     for (int i=0;i<n;++i) {
>         while (top && A[st[top-1]]<A[i])
>             ans[st[--top]]=A[i];
>         st[top++]=i;
>     }
> }
> ```
> 
> 循环版扫描两圈，但只在第一圈压入下标；n=0别取模。时间O(n)是由“每个下标最多弹一次”证明，不是由代码看起来只有一个for证明。

### G1 DFS与BFS

**识别**：可达、连通块、无权最短路、最短路条数、二分染色。

**状态／不变量**：DFS/BFS的访问标记在发现时就设；BFS队列按离源距离非递减出队。

1. 问任务是“从s可达”还是“全图覆盖”；只有后者需要外层遍历未访问点。
2. 在发现/入队前标记，避免重复入队。
3. 在骨架上添加size、dist、parent、ways或color，而非另背一整份代码。

**别套错**：DFS访问深度不是一般图最短距离；求s最短路不应把别的分量改成dist=0。

> [!faq]- 闭卷回忆后再展开｜C 骨架与变式
> ```c
> int ComponentDFS(LGraph *G, int u, int vis[]) {
>     vis[u]=1;
>     int size=1;
>     for (ArcNode *e=G->first[u]; e; e=e->next)
>         if (!vis[e->adjvex]) size+=ComponentDFS(G,e->adjvex,vis);
>     return size;
> }
> void BFS(LGraph *G, int s, int dist[], int parent[]) {
>     int Q[MAXV],front=0,rear=0;
>     for (int i=0;i<G->vexnum;++i) dist[i]=parent[i]=-1;
>     dist[s]=0; Q[rear++]=s;
>     while (front<rear) {
>         int u=Q[front++];
>         for (ArcNode *e=G->first[u]; e; e=e->next) {
>             int v=e->adjvex;
>             if (dist[v]==-1) {
>                 dist[v]=dist[u]+1; parent[v]=u;
>                 Q[rear++]=v;
>             }
>         }
>     }
> }
> ```
> 
> - 全图最大连通块：vis全清0；每个未访问i调用ComponentDFS，更新最大size。
> - 最短路条数：首次发现复制ways[u]；已发现且dist[v]==dist[u]+1时累加，不再次入队。
> - 二分图：color初始化−1，未染邻点赋相反色；已染邻点仍需检查同色冲突；全图外层循环。
> - 无向简单图DFS判环：已访问邻点v且v!=parent时有环。
> - 有向图不能照搬“排除父亲”；用三色DFS检查递归栈回边，或Kahn检查处理数。
> 
> 邻接表O(V+E)/O(V)，邻接矩阵遍历通常O(V²)；源点BFS只访问可达部分，但初始化数组仍花O(V)。

### G2 拓扑消除依赖

**识别**：有向图判环、先修排序、最早完成、DAG上的递推、排序唯一性。

**状态／不变量**：队列中只有“尚未处理且当前剩余入度为0”的点；出队即所有前驱已处理。

1. 遍历边统计入度，所有零入度点入队。
2. 出队u，对每条u→v先做必要状态转移，再把indeg[v]减1。
3. 仅降至0才入队；结束检查输出数是否V。

**别套错**：不能一开始发现某点不是零入度就判环；也不能只看原图中是否有一个零入度点。

> [!faq]- 闭卷回忆后再展开｜C 骨架与变式
> ```c
> int Topo(LGraph *G, int order[]) {
>     int in[MAXV]={0}, Q[MAXV],front=0,rear=0,count=0;
>     for (int u=0;u<G->vexnum;++u)
>         for (ArcNode *e=G->first[u];e;e=e->next) ++in[e->adjvex];
>     for (int u=0;u<G->vexnum;++u) if (in[u]==0) Q[rear++]=u;
>     while (front<rear) {
>         int u=Q[front++]; order[count++]=u;
>         for (ArcNode *e=G->first[u];e;e=e->next)
>             if (--in[e->adjvex]==0) Q[rear++]=e->adjvex;
>     }
>     return count==G->vexnum;
> }
> ```
> 
> - 最少学期：semester全置1；处理边时semester[v]=max(semester[v],semester[u]+1)。
> - 唯一性：每次选择前若rear−front>1，则候选不唯一；结束**先排除有环**再判1/2。
> - DAG路径：按拓扑序对边做松弛/求最大，初始化区分“所有源都可起步”与“指定源可达”。
> 
> 时间O(V+E)、空间O(V)。以上是逐顶点顺序队列，不是必须写循环队列。

### G3 并查集

**识别**：合并已有连通关系、增量连通、Kruskal选边。

**状态／不变量**：Find(x)给集合代表；union成功表示原先是两个分量。

1. 初始化每点自成一组，size=1，comps=V。
2. 按代表判断是否需要合并，根按大小挂接。
3. 只在合并成功时comps--或累加所选边权。

**别套错**：并查集不记录一般最短距离；不能将有向可达性当成无向连通关系合并。

> [!faq]- 闭卷回忆后再展开｜C 骨架与变式
> ```c
> int Find(int parent[], int x) {
>     if (parent[x]!=x) parent[x]=Find(parent,parent[x]);
>     return parent[x];
> }
> int Unite(int parent[], int size[], int a, int b) {
>     a=Find(parent,a); b=Find(parent,b);
>     if (a==b) return 0;
>     if (size[a]<size[b]) { int t=a; a=b; b=t; }
>     parent[b]=a; size[a]+=size[b];
>     return 1;
> }
> ```
> 
> Kruskal：边按权升序→能合并才选→连成一组停止→结束未连通则失败。已有连通边先合并，再考虑付费边；不固定要求付费边选V−1条。压缩+按大小合并的多次操作摊还近似常数，严格记O(α(V))。

**回题练**：[[2.知识库/20.North_star_ZJU/202.计算机知识/05数据结构/08算法题/02算法题重刷清单#22. 并查集求无向图连通分量数|重刷清单 · 22. 并查集求无向图连通分量数]]；[[2.知识库/20.North_star_ZJU/202.计算机知识/05数据结构/08算法题/02算法题重刷清单#23. Kruskal 最小生成树核心|重刷清单 · 23. Kruskal 最小生成树核心]]


### G4 最短路与生成树

**识别**：有权最短距离、所有点对距离、全图最小连接代价。

**状态／不变量**：Dijkstra的dist[v]是从s到v的路径长；Prim的low[v]是当前树集合接v的一条最便宜边。

1. 先辨别是路径目标还是连接目标，再检查有向/无向、负权、连通性。
2. 朴素Dijkstra/Prim都选未确定且key最小点，但更新公式不同。
3. 不可达最小值仍为INF时及时停止或按题意报不连通。

**别套错**：有相似for循环不表示等价；Prim不能累加dist[u]+w更新，Dijkstra不能只拿边权w更新。

> [!faq]- 闭卷回忆后再展开｜C 骨架与变式
> | 算法 | 条件与目标 | 更新 | 常用复杂度 |
> | --- | --- | --- | --- |
> | BFS | 无权/等权，单源最少边数 | 首次发现dist[v]=dist[u]+1 | 邻接表O(V+E) |
> | Dijkstra | 非负权，单源最短距离 | dist[v]=min(dist[v],dist[u]+W[u][v]) | 矩阵O(V²) |
> | Floyd | 多源，允许负边但无负环 | d[i][j]=min(d[i][j],d[i][k]+d[k][j]) | O(V³) |
> | Prim | 无向带权图，最小生成树 | low[v]=min(low[v],W[u][v]) | 矩阵O(V²) |
> | Kruskal | 无向带权图，边排序+并查集 | 能合并才选边 | O(E log E) |
> 
> ```c
> // Floyd原地核；INF足够大且有限路径和不会溢出long long
> for (int k=0;k<V;++k)
>     for (int i=0;i<V;++i) {
>         if (d[i][k]==INF) continue;
>         for (int j=0;j<V;++j)
>             if (d[k][j]!=INF && d[i][j]>d[i][k]+d[k][j])
>                 d[i][j]=d[i][k]+d[k][j];
>     }
> ```
> 
> 初始化：Dijkstra为dist[s]=0、其余INF；Prim可为low[start]=0、其余INF，每轮纳入点后加low。两者都另设selected/used，不用“key等于0”兼做访问标记。MST允许负边，但本月练习另约非负以统一−1失败返回值。Floyd中k最外层不可随意改；交换i和j内层是允许的。完整朴素函数直接回原清单，不在此重复抄三份相近长代码。

## H 堆与排序的共同骨架


### H1 堆的边界维护

**识别**：堆排序、数据流Top-K、快速取得候选集中最弱/最强者。

**状态／不变量**：向下调整前，两棵子树已经是堆；只可能是当前根不满足父子偏序。

1. 保存待放根值x。
2. 每轮选择更合适的孩子（小根堆选更小、大根堆选更大）。
3. 若x已满足关系则停，否则孩子上移，最后放回x。

**别套错**：升序原地堆排序用大根堆，降序用小根堆；保留最大k个却用小根堆，不要死记“最大=大根堆”。

> [!faq]- 闭卷回忆后再展开｜C 骨架与变式
> ```c
> void SiftDownMin(int A[], int n, int i) {
>     int x=A[i];
>     for (int child=2*i+1;child<n;child=2*i+1) {
>         if (child+1<n && A[child+1]<A[child]) ++child;
>         if (x<=A[child]) break;
>         A[i]=A[child];
>         i=child;
>     }
>     A[i]=x;
> }
> void HeapSortDescending(int A[], int n) {
>     for (int i=n/2-1;i>=0;--i) SiftDownMin(A,n,i);
>     for (int end=n-1;end>0;--end) {
>         int t=A[0]; A[0]=A[end]; A[end]=t;
>         SiftDownMin(A,end,0); // end是剩余堆长度，不含已归位尾部
>     }
> }
> ```
> 
> - 大根堆：选较大孩子，把终止条件改为x>=A[child]，两处都改。
> - Top-K最大：先建k个数的小根堆；新x>根才替换下滤。根是第k大，k个候选未必有序。
> - 0-based左2i+1、右2i+2、父(i−1)/2；1-based左2i、右2i+1、父i/2。按题干选一种，不混用。
> - 自底向上建堆O(n)，一次下滤O(log n)，堆排序O(n log n)；Top-K精确覆盖k=1可写O(n log(k+1))。

### 每次提取模板的四问

1. **识别**：什么条件允许我用它？删掉这个条件，有什么反例？
2. **状态**：这个变量/返回值精确表示什么？不要只说“快慢指针”。
3. **保持**：一轮/一层做完，为何仍然成立？
4. **边界**：空、单个、重复、极值、断链、不可达中，哪个能击穿错误实现？

### 统一易错核对

- C中#define N 100是常量数组长度；块内const int N=100在C里不必是整型常量表达式，不能照搬C++的理解。VLA不要用={0}初始化，改循环。
- 固定长int a[N]={0}全零；={−1}或={INF}只给第0项该值，其他补0。指针NULL与整数填充问题也不要靠memset(-1)混为一谈。
- 比较和／积前先提升类型，如1LL*x*count，不能等int乘完溢出了再赋long long。
- 递归栈计入额外空间。递归链表归并排序O(log n)，普通树遍历O(h)，退化树h=n。
- 矩阵用0表示无边会与合法0权边冲突；无边用INF并避免INF参与加法。
- 题目“完整算法”必须展开关键模块或给出本页已定义的函数；不能把考点本身藏在一句“调用库函数”后。
