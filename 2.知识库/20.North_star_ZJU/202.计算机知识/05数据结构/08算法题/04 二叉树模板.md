# 需要从下自上传递很多参数  
你之前没用过非常正常！因为国内很多辅导书（包括王道）在讲题目时，为了省事，经常会用一些**“极其取巧的野路子”**，比如：
* 算平衡二叉树时，如果发现不平衡就 `return -1`，用 `-1` 这种“特殊值（哨兵）”同时兼顾了“是否平衡”和“高度”两个含义。

**但这种取巧是有极限的！** 
一旦遇到像上面那道题，要求同时传递 `sum`（可以是负数、0、正数）和 `count` 时，没有任何数字能拿来当哨兵，辅导书的取巧方法就彻底破产了。

而**结构体打包法**，在算法领域被称为**“树形递归/树形 DP 的标准解法”**。它是一把**万能钥匙**，所有向左右子树要多个信息的题目，代码长得一模一样！

看下面这两个高频真题考点，我用**完全一模一样的模板**写给你看：

### 示范一：判断是否是平衡二叉树（AVL 平衡性检查）

* **考点**：每个节点的左右子树高度差不超过 1，且左右子树自身也必须平衡。
* **问左右孩子要什么**：
  1. `height`：你子树有多高？
  2. `isBalanced`：你自己平不平衡？

```c
#include <stdio.h>
#include <stdlib.h>
#include <stdbool.h>

typedef struct TreeNode {
    int val;
    struct TreeNode *left;
    struct TreeNode *right;
} TreeNode;

// 1. 打包左右孩子需要汇报的信息
typedef struct {
    int height;      // 子树高度
    bool isBalanced; // 子树是否平衡
} Result;

// 2. 递归函数：标准模板
Result checkBalanced(TreeNode *root) {
    // 递归边界：空树高度为 0，且天然是平衡的
    if (root == NULL) {
        Result empty = {0, true};
        return empty;
    }

    // 问左孩子、右孩子要报告单
    Result left = checkBalanced(root->left);
    Result right = checkBalanced(root->right);

    // 汇总当前节点的信息
    Result cur;
    // (1) 当前高度 = 左右子树最大高度 + 1
    int maxH = (left.height > right.height) ? left.height : right.height;
    cur.height = maxH + 1;

    // (2) 当前平衡的条件：左平衡 && 右平衡 && 高度差不超过 1
    int diff = abs(left.height - right.height);
    if (left.isBalanced && right.isBalanced && diff <= 1) {
        cur.isBalanced = true;
    } else {
        cur.isBalanced = false;
    }

    return cur;
}

// 3. 题解入口
bool isBalancedTree(TreeNode *root) {
    return checkBalanced(root).isBalanced;
}
```

### 示范二：判断是否是满二叉树（国内 408 统考定义）

> **408 考纲定义**：满二叉树是指高度为 $h$，且节点总数为 $2^h - 1$ 的二叉树（所有叶子在最底层，所有非叶子都有两个孩子）。

* **考点**：
  * 左子树必须是满二叉树；
  * 右子树必须是满二叉树；
  * **左右子树的高度必须严格相等**！
* **问左右孩子要什么**：
  1. `height`：你子树的高度；
  2. `isFull`：你是不是满二叉树。

```c
// 1. 打包结构体
typedef struct {
    int height;
    bool isFull;
} FullResult;

// 2. 递归函数
FullResult checkFull(TreeNode *root) {
    // 空树高度为 0，是满二叉树
    if (root == NULL) {
        FullResult empty = {0, true};
        return empty;
    }

    // 问左右孩子要报告单
    FullResult left = checkFull(root->left);
    FullResult right = checkFull(root->right);

    FullResult cur;
    // 当前高度
    int maxH = (left.height > right.height) ? left.height : right.height;
    cur.height = maxH + 1;

    // 判定满二叉树核心：左满 && 右满 && 左右子树等高
    if (left.isFull && right.isFull && left.height == right.height) {
        cur.isFull = true;
    } else {
        cur.isFull = false;
    }

    return cur;
}

// 3. 题解入口
bool isFullBinaryTree(TreeNode *root) {
    return checkFull(root).isFull;
}
```

### 🎯 发现规律了吗？（这就是你的考场模板）

不管题目怎么变，只要涉及到“需要子树回传 2 个以上属性”，你的代码骨架**永远是这 5 步**：

```c
// 第 1 步：定义结构体
typedef struct {
    ... // 想要啥放啥
} Info;

Info dfs(TreeNode *root) {
    // 第 2 步：空树边界
    if (root == NULL) return (Info){...};

    // 第 3 步：直接向下搜
    Info left = dfs(root->left);
    Info right = dfs(root->right);

    // 第 4 步：算当前节点的值
    Info cur;
    cur.xxx = left.xxx + right.xxx ...;

    // 第 5 步：打包装箱扔给上一层
    return cur;
}
```

**为什么考场用这招必拿高分？**
1. **0 指针失误**：全篇一个 `*` 指针解引用都没有（除了遍历树本来的 `root->left`），绝不会发生“地址覆盖”的 Bug。
2. **逻辑极其自洽**：阅卷老师一眼就能看懂你的逻辑（“问左右子树要信息 $\to$ 拼装当前信息 $\to$ 返回”），直接给满分。
