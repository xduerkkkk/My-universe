### 主练｜最近公共祖先：目标可能缺失

- [ ] 独立思考并留下完整作答

普通二叉树，无父指针。给两个非空且地址不同的指针 p、q，它们不一定属于树。若两者都在树中，返回最近公共祖先；否则返回NULL。按指针身份匹配，不能按data。

```c
BTNode *LCAIfBoth(BTNode *root, BTNode *p, BTNode *q);
```

**要求**：时间 O(n)，额外空间 O(h)，一次后序汇总；不得对每个候选根重复搜索。  
**自测**：根1、左2（带左叶4）、右3：p=4、q=3 → 根1；p=2、q=4 → 结点2；q为树外同值3结点 → NULL。

### 主练｜BST 第 k 小：不用递归

- [ ] 独立思考并留下完整作答

给严格BST，n≥1、1≤k≤n。只用显式数组栈完成中序访问，返回第k小值；不得先把全部值存进数组，也不能用递归。栈容量由调用者保证至少为树高h。

```c

```

### 主练｜有序链表并集：复用结点并释放重复

- [ ] 独立思考并留下完整作答

两条非递减无环链表 A、B，均不带头结点、没有共享结点，每条表自身也可能重复。求集合并集：每种值仅保留一个结点，结果非递减；复用原结点，释放所有未保留结点。可用局部哨兵，不申请新数据结点；返回结果首结点。

```c
LNode *UnionSorted(LNode *A, LNode *B);
```

**要求**：时间 O(m+n)，额外空间 O(1)。输入结点均由动态分配，函数执行后调用者不能再使用旧A、B作为独立链表。  
**自测**：[1,1,3]+[1,2,2,3] → [1,2,3]，释放4个结点；[]+[2,2] → [2]，释放1个；[]+[] → NULL。

> [!faq]- 卡住再看｜只给破题问题
> 普通归并只负责有序，集合语义还要求什么？一侧耗尽后，另一侧可以直接整段接上吗？

> [!faq]- 写完再核对｜关键路线、陷阱与模板
> 每次取两链较小的首结点（相等优先A），先保存其后继并推进对应输入指针，再断开取出结点。若输出为空或值异于尾值则尾插，否则free。一侧耗尽仍逐个检查剩余重复值。不能free后再读next，也不能保留尾结点原next造成悬挂链接。
