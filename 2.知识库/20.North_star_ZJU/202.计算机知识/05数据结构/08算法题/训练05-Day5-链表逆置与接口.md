## 今天主练题｜逆置带头结点链表

给定**带头结点**链表 L，逆置所有数据结点，但保留同一个头结点。允许 L==NULL 或空表。不得申请新结点。时间 O(n)、额外空间 O(1)。

例：`头→1→2→3` 变成 `原头→3→2→1`。

```c
void ReverseList(LinkList L);
```

## 22–28 分钟｜自测与核对

1. 数据结点 `[1,2,3]`：新顺序和末结点 next 是什么？
2. 空表：是否保留原头结点？
3. `[8]`：有没有产生自环？

> [!faq]- 卡住才看｜只提示接口
> 改 p->next 之前先保存原后继。用 L->next 接住 Reverse 的返回值；头结点本身不参加逆置。

> [!faq]- 写完再看｜实现与指针意义
> 结果：`[3,2,1]` 且 1 的 next 为 NULL；空表保留原头；单结点 `[8]` 无环。
>
> ```c
> LNode *Reverse(LNode *head) {
>     LNode *prev = NULL, *p = head;
>     while (p != NULL) {
>         LNode *next = p->next;
>         p->next = prev;
>         prev = p;
>         p = next;
>     }
>     return prev;
> }
>
> void ReverseList(LinkList L) {
>     if (L == NULL) return;
>     L->next = Reverse(L->next);
> }
> ```
>
> 每轮开始 prev 是已逆置段首指针，p 是未处理段首指针，next 暂存原后继。时间 O(n)，额外空间 O(1)。
>
> Reverse(L) 会把头结点也卷进去；只调用 Reverse(L->next) 而不接返回值，会丢失新入口。
