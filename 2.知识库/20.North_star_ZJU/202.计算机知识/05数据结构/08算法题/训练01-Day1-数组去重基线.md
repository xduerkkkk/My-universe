## 题目｜现在开始读

给定非递减整数数组 `A[0..n-1]`，`n≥0`。原地删除重复值，使数组前 `len` 个位置按原顺序保存所有不同元素，返回 `len`。`len` 之后的内容不作要求。时间 `O(n)`、额外空间 `O(1)`。

例：`[1,1,2,2,3]` → 返回 `3`，有效前缀为 `[1,2,3]`。

```c
int RemoveDuplicates(int A[], int n);
```

## 23–28 分钟｜先手推，再展开

用原稿逐行走三个样例，记下返回值和有效前缀：

1. `[1,1,2,2,3]`
2. `[]`
3. `[7,7,7]`

> [!faq]- 时间到再展开｜测试结果与参考实现
> 结果：`3 / [1,2,3]`；`0 / []`；`1 / [7]`。
>
> 关键状态：`A[0..len-1]` 是已经处理部分的去重结果。空数组不能先读 A[0]。
>
> ```c
> int RemoveDuplicates(int A[], int n) {
>     if (n == 0) return 0;
>
>     int len = 1;
>     for (int i = 1; i < n; i++) {
>         if (A[i] != A[len - 1]) {
>             A[len] = A[i];
>             len++;
>         }
>     }
>     return len;
> }
> ```
>
> 时间 O(n)，额外空间 O(1)。不同写法只要满足题意并能说明正确性，也算通过。
