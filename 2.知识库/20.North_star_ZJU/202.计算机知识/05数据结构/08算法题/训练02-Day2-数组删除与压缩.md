## 今天主练题｜无序数组删除指定值（自拟变式）

给定任意整数数组 `A[0..n-1]` 和整数 x，`n≥0`。原地删除所有等于 x 的元素，保持其余元素相对顺序，返回有效长度。时间 O(n)、额外空间 O(1)；有效前缀之后不作要求。

例：`A=[3,1,3,2], x=3` → 返回 `2`，有效前缀 `[1,2]`。

```c
int RemoveValue(int A[], int n, int x);
```

## 22–28 分钟｜自测与核对

2. `[], x=3`
3. `[3,3,3], x=3`

> [!faq]- 卡住才看｜只提示状态
> 读指针遍历输入，写指针表示已保留元素的个数。决定是否保留的是“当前值是否等于 x”，不是与前一个值是否相同。

> [!faq]- 写完再看｜主练与热身参考实现
> 主练结果：`2 / [1,2]`；`0 / []`；`0 / []`。
>
> ```c
> int RemoveValue(int A[], int n, int x) {
>     int len = 0;
>     for (int i = 0; i < n; ++i) {
>         if (A[i] != x) A[len++] = A[i];
>     }
>     return len;
> }
> ```
>
> 热身：
>
> ```c
> int RemoveDuplicates(int A[], int n) {
>     if (n == 0) return 0;
>
>     int len = 1;
>     for (int i = 1; i < n; i++) {
>         if (A[i] != A[len - 1]) {
>             A[len] = A[i];
>             len++;
>         }
>     }
>     return len;
> }
> ```
>
> 两题时间均为 O(n)，额外空间 O(1)。保留条件、初始有效长度不同。
