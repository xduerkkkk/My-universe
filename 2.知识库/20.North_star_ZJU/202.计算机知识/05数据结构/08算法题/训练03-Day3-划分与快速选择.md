## 今天主练题｜无序数组第 k 小

给定整数数组 `A[0..n-1]`，保证 `n≥1`、`1≤k≤n`，允许重复值。返回按非递减排序后的第 k 个元素，重复值分别占位。允许改变数组，要求用划分选择，不完整排序。

例：`[4,1,4,2], k=3` → `4`。

```c
int QuickSelect(int A[], int n, int k);
```

## 22–28 分钟｜自测与核对

每个测试都用一份新数组：

1. `[4,1,4,2], k=3`
2. `[9], k=1`
3. `[2,2,2], k=2`

追踪一次区间收缩，检查重复值时是否可能死循环。

> [!faq]- 局部提示｜不会划分才看
> 先保存枢轴值。挖坑法：右侧找小值填左坑，左侧找大值填右坑；每次内部扫描都保留 low<high。最后把枢轴放回相遇位置。

> [!faq]- 写完再看｜参考实现
> 三个结果：`4、9、2`。
>
> ```c
> int Partition(int A[], int low, int high) {
>     int pivot = A[low];
>     while (low < high) {
>         while (low < high && A[high] >= pivot)
>             high--;
>         A[low] = A[high];
>
>         while (low < high && A[low] <= pivot)
>             low++;
>         A[high] = A[low];
>     }
>     A[low] = pivot;
>     return low;
> }
>
> int QuickSelect(int A[], int n, int k) {
>     int low = 0, high = n - 1;
>     int target = k - 1;
>
>     while (low <= high) {
>         int pos = Partition(A, low, high);
>         if (pos == target)
>             return A[pos];
>         if (pos > target)
>             high = pos - 1;
>         else
>             low = pos + 1;
>     }
>     return -1;  // 合法输入不会执行到这里；不作为参数检查
> }
> ```
>
> 平均时间 O(n)，最坏 O(n²)；迭代版额外空间 O(1)。target=k-1；新边界必须排除已确定位置 pos。
