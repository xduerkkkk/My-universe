每个测试用一份新数组：

> [!faq]- 核对新题｜不需要补写代码
> left/right 指向原数组剩余区间两端，写指针指向辅助数组 B 下一空位。交替取右端最大值与左端最小值填入 B，最后复制回 A。
>
> 每取一个都检查 left≤right，避免奇数长度中间值被取两次。空数组不进入循环。时间 O(n)、额外空间 O(n)。
>
> 两两取的变式只改每侧本轮最多取的数量，每取一次仍检查区间。例 `[1,2,3,4,5]` → `[5,4,1,2,3]`。
>
> 原清单第 7 题的“原地”表述与辅助数组示例不一致，所以本次明确允许辅助数组，不把此方案声称为 O(1) 空间。

> [!faq]- 核对旧题｜参考实现
> 三个返回值：`7、6、1`。
>
> ```c
> int Partition(int A[], int low, int high) {
>     int pivot = A[low];
>     while (low < high) {
>         while (low < high && A[high] >= pivot)
>             high--;
>         A[low] = A[high];
>
>         while (low < high && A[low] <= pivot)
>             low++;
>         A[high] = A[low];
>     }
>     A[low] = pivot;
>     return low;
> }
>
> int QuickSelect(int A[], int n, int k) {
>     int low = 0, high = n - 1;
>     int target = k - 1;
>
>     while (low <= high) {
>         int pos = Partition(A, low, high);
>         if (pos == target)
>             return A[pos];
>         if (pos > target)
>             high = pos - 1;
>         else
>             low = pos + 1;
>     }
>     return -1;  // 合法输入不会执行到这里；不作为参数检查
> }
> ```
>
> 平均 O(n)、最坏 O(n²)、迭代版额外空间 O(1)。看答案后补好的部分只算修正，不倒填独立正确。
