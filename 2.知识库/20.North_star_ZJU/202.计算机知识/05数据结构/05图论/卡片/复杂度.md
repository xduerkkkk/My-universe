### 一、先看你截图的这道题（核心避坑点）

**答案：选 D，即 $O(\max(|V|, |E|))$（等价于我们平时常写的 $O(|V| + |E|)$）。**

**为什么极其容易错选 C ($O(|E|)$)？**
* **有向图的邻接表结构**：由一个长度为 $|V|$ 的**顶点数组（表头结点）**和若干条挂在后面的**边链表（表结点，代表出边）**组成。所有边链表的结点总数等于有向图的边数 $|E|$。
* **求某顶点 $x$ 的入度**：意味着要找有多少条边指向 $x$。因为邻接表只存了每个顶点的“出边”，不知道谁指向了 $x$，所以必须**遍历整个邻接表**，统计在所有边链表中，顶点编号 `adjvex == x` 出现的总次数。
* **时间复杂度拆解**：
  1. 外层循环必须遍历长度为 $|V|$ 的顶点数组（哪怕某个顶点一条出边都没有，也得访问它的表头指针看是不是 `NULL`），这固定消耗 $O(|V|)$。
  2. 内层循环累计遍历所有边链表的全部结点，总共消耗 $O(|E|)$。
  3. 总时间复杂度为 **$O(|V| + |E|)$**。
* **为什么写作 $O(\max(|V|, |E|))$？**
  * 因为在非连通图或稀疏图中，无法保证 $|E|$ 一定大于 $|V|$（极端情况：有 $100$ 个顶点但只有 $0$ 条边，此时耗时由 $|V|$ 主导）。
  * 在渐近复杂度大 $O$ 记号中，两个非负变量相加 $O(A + B)$ 严格等价于 **$O(\max(A, B))$**。

### 二、 408 图论时间与空间复杂度全汇总

设图的顶点数为 $|V|$，边数（或弧数）为 $|E|$。

#### 1. 存储结构的空间复杂度（基础必背）

| 存储方式 | 无向图空间复杂度 | 有向图空间复杂度 | 精确细节说明 |
| :--- | :--- | :--- | :--- |
| **邻接矩阵** | $O(\lvert V\rvert^2)$ | $O(\lvert V\rvert^2)$ | 只与顶点数有关。若用压缩存储存无向图的三角矩阵，空间为 $\frac{\lvert V\rvert(\lvert V\rvert+1)}{2}$，量级仍为 $O(\lvert V\rvert^2)$。 |
| **邻接表** | $O(\lvert V\rvert + 2\lvert E\rvert) = O(\lvert V\rvert + \lvert E\rvert)$ | $O(\lvert V\rvert + \lvert E\rvert)$ | 无向图每条边在两个顶点的链表中各出现一次（共 $2\lvert E\rvert$ 个边结点）；有向图每条弧只出现一次（共 $\lvert E\rvert$ 个边结点）。 |
| **十字链表** | 不适用 | $O(\lvert V\rvert + \lvert E\rvert)$ | 专用于**有向图**。集成了邻接表和逆邻接表，既有出边指针也有入边指针。 |
| **邻接多重表** | $O(\lvert V\rvert + \lvert E\rvert)$ | 不适用 | 专用于**无向图**。一条边只用一个边结点表示（解决了邻接表存两份、删除边麻烦的问题）。 |

---

#### 2. 基本操作的时间复杂度（小题高频考点，即你截图的题型）

**注意**：以下关于“单个顶点 $v$”的操作，在邻接表中，有时写 $O(\text{度})$，但在最坏情况分析下，一个顶点的度最大可达 $|V|-1$。如果题目选项只有 $|V|$ 和 $|E|$，按表中标准选：

| 具体操作 | 邻接矩阵 | 邻接表 | 十字链表 (有向图) | 考察核心机制 |
| :--- | :--- | :--- | :--- | :--- |
| **判断 $u$ 到 $v$ 是否有边** | **$O(1)$** | $O(\text{outdeg}(u))$，最坏 $O(\lvert V\rvert)$ | $O(\text{outdeg}(u))$ | 矩阵直接下标访问 `A[u][v]`；链表必须顺着 $u$ 的出边链表线性查找。 |
| **求无向图某顶点 $v$ 的度** | **$O(\lvert V\rvert)$** | **$O(\text{deg}(v))$**，最坏 $O(\lvert V\rvert)$ | - | 矩阵需遍历第 $v$ 行全部 $\lvert V\rvert$ 个元素；邻接表只需遍历 $v$ 自己的那条链表（若表头提前存了 `count` 字段则为 $O(1)$，不说明默认没存）。 |
| **求有向图某顶点 $v$ 的出度** | **$O(\lvert V\rvert)$** | **$O(\text{outdeg}(v))$**，最坏 $O(\lvert V\rvert)$ | **$O(\text{outdeg}(v))$** | 矩阵遍历第 $v$ 行；邻接表只遍历 $v$ 自己的出边链表。 |
| **求有向图某顶点 $v$ 的入度** | **$O(\lvert V\rvert)$** | **$O(\lvert V\rvert + \lvert E\rvert)$** 或 $O(\max(\lvert V\rvert,\lvert E\rvert))$ | **$O(\text{indeg}(v))$** | **重灾区！** 矩阵只需遍历第 $v$ **列**，故为 $O(\lvert V\rvert)$；邻接表必须遍历全图；逆邻接表或十字链表只需顺着入边链走。 |
| **求全图所有顶点的度/入度/出度**| **$O(\lvert V\rvert^2)$** | **$O(\lvert V\rvert + \lvert E\rvert)$** | **$O(\lvert V\rvert + \lvert E\rvert)$** | 哪怕在邻接表中求“所有顶点的入度”，也只需要把整张邻接表遍历**一遍**，用数组累加即可，千万别乘以 $\lvert V\rvert$ 写成 $O(\lvert V\rvert\lvert E\rvert)$！ |
| **删除无向图的一条边 $(u,v)$** | **$O(1)$** | $O(\text{deg}(u) + \text{deg}(v))$，最坏 $O(\lvert V\rvert)$ | - | 矩阵改两个对称位置的值为 0；邻接表要在 $u$ 和 $v$ 的两条链表里分别找到对方并删除。 |

#### 3. 图的核心算法时间复杂度（大题与综合选择题核心）

**核心规律**：绝大多数图算法（BFS、DFS、拓扑排序、关键路径）的本质都是**“把整个图的数据结构完整摸一遍”**。
* 只要底层用的是**邻接矩阵**，摸一遍整张矩阵就是 **$O(|V|^2)$**。
* 只要底层用的是**邻接表**，摸一遍所有表头和边链表就是 **$O(|V| + |E|)$**。

具体全表如下：

| 算法名称 | 邻接矩阵实现 | 邻接表实现 | 辅助空间复杂度 | 关键细节与 408 考点提示 |
| :--- | :--- | :--- | :--- | :--- |
| **BFS (广度优先遍历)** | $O(\lvert V\rvert^2)$ | $O(\lvert V\rvert + \lvert E\rvert)$ | $O(\lvert V\rvert)$ (队列 + `visited`数组) | 求**无权图的单源最短路径**直接用 BFS，复杂度同本行。 |
| **DFS (深度优先遍历)** | $O(\lvert V\rvert^2)$ | $O(\lvert V\rvert + \lvert E\rvert)$ | $O(\lvert V\rvert)$ (递归工作栈 + `visited`) | 最坏空间出现在图退化为一条长链时，递归深度为 $\lvert V\rvert$；最好为星型图 $O(1)$（不含 `visited`）。 |
| **最小生成树：Prim** | **$O(\lvert V\rvert^2)$** | 朴素：$O(\lvert V\rvert^2)$<br>堆优化：$O(\lvert E\rvert\log\lvert V\rvert)$ | $O(\lvert V\rvert)$ | 408 默认考朴素版 $O(\lvert V\rvert^2)$，只与顶点数有关，适合**稠密图**。 |
| **最小生成树：Kruskal**| - (用边集数组) | **$O(\lvert E\rvert\log\lvert E\rvert)$** | $O(\lvert V\rvert + \lvert E\rvert)$ (并查集+存边) | 瓶颈在对边排序，只与边数有关，适合**稀疏图**。 |
| **最短路径：Dijkstra** | **$O(\lvert V\rvert^2)$** | 朴素：$O(\lvert V\rvert^2)$<br>堆优化：$O(\lvert E\rvert\log\lvert V\rvert)$ | $O(\lvert V\rvert)$ (`dist`, `path`, `final`数组) | **单源**最短路径。机制与 Prim 高度同构！若求**每对顶点**间的最短路径，需对每个顶点跑一次 Dijkstra，总耗时乘以 $\lvert V\rvert$，即矩阵下为 **$O(\lvert V\rvert^3)$**。 |
| **最短路径：Floyd** | **$O(\lvert V\rvert^3)$** | 不适用 (强依赖矩阵下标) | $O(\lvert V\rvert^2)$ (状态矩阵 $A$ 和 $Path$) | **多源（每对顶点）**最短路径。三层 `for` 循环死套，无论图多稀疏都是 $O(\lvert V\rvert^3)$。 |
| **拓扑排序 (Kahn/DFS)** | $O(\lvert V\rvert^2)$ | **$O(\lvert V\rvert + \lvert E\rvert)$** | $O(\lvert V\rvert)$ (栈/队列 + `indegree`数组)| 每次找入度为 0 的点入栈，出栈时将其邻接点入度减 1。每条边只触发一次减 1 操作。 |
| **关键路径 (AOE网)** | $O(\lvert V\rvert^2)$ | **$O(\lvert V\rvert + \lvert E\rvert)$** | $O(\lvert V\rvert + \lvert E\rvert)$ (存 $ve, vl, e, l$) | 包含一次正拓扑排序求 $ve$，一次逆拓扑排序求 $vl$，再遍历所有边求 $e$ 和 $l$，量级不变。 |

### 三、 针对 26 年这种考法的变式训练

既然 26 年刚考了“邻接表求单个顶点入度”，命题人极可能会在“存储结构转换”或“批量求度”上做文章。来做这道变式题检验一下：

**【变式题】**
已知有向图 $G=(V, E)$ 采用**邻接矩阵**存储，现要将其转换为对应的**逆邻接表**存储结构，并同时计算出图中**所有顶点的出度**存入一维数组 `outdegree[]` 中。完成上述全部操作的时间复杂度为（ ）。
A. $O(|V| + |E|)$
B. $O(|V| \cdot |E|)$
C. $O(|V|^2)$
D. $O(|V|^2 + |E|)$

---

**【解析与答案】**
**答案：C**

**精确拆解：**
1. **初始化逆邻接表的顶点表头数组**以及 `outdegree[]` 数组：长度为 $|V|$，耗时 $O(|V|)$。
2. **遍历原邻接矩阵**：
   * 邻接矩阵是一个 $|V| \times |V|$ 的二维数组。要找出所有的有向边 `<i, j>`，必须使用两层嵌套循环遍历矩阵的每一个元素 `A[i][j]`，这一步固定执行 $|V|^2$ 次判断，耗时 **$O(|V|^2)$**。
   * 当发现 `A[i][j] == 1`（存在从 $i$ 到 $j$ 的边）时：
     * 执行 `outdegree[i]++`，单次耗时 $O(1)$。
     * 采用**头插法**在逆邻接表中顶点 $j$ 的链表头部插入一个编号为 $i$ 的边结点，单次耗时 $O(1)$。
   * 整张图中共有 $|E|$ 条边，因此上述条件分支内部的操作总共执行 $|E|$ 次，耗时 $O(|E|)$。
3. **合并总时间复杂度**：
   $$T = O(|V|) + O(|V|^2) + O(|E|)$$
   因为在简单有向图中，必然满足 $|E| \le |V|(|V|-1) < |V|^2$，且 $|V| \le |V|^2$，所以 $|V|^2$ 恒为最高阶项（无需像 D 选项那样画蛇添足加上 $|E|$）。
   故最终时间复杂度严格为 **$O(|V|^2)$**，选 **C**。
