

### 一端入栈出栈

对于选择题判断“哪个出栈序列是不可能的”，千万不要再去脑内模拟了！记住下面这个绝对成立的**黄金规律**：

**前提条件：** 假设元素是按 $1, 2, 3, \dots, n$ 的从小到大的顺序入栈的。

**黄金规律：“对于出栈序列中的任意一个数，在它后面出栈且比它小的所有数，必须是严格降序排列的。”**

没看懂？我们直接上例子！

#### 验证示例 1：判断序列 `3, 1, 4, 2` 是否合法？

1. **看 3：** 在 3 后面出栈、且比 3 小的数有 `1, 2`。它们排列顺序是 `1, 2`（升序）。
    
2. **触发警报：** 必须是降序，这里却是升序，**直接判定非法！**（因为 3 出栈说明 1 和 2 都在栈里，栈是后进先出，被压在下面的 1 绝不可能比 2 先出来）。
    

#### 验证示例 2：判断序列 `4, 3, 5, 1, 2` 是否合法？

1. **看 4：** 后面比它小的有 `3, 1, 2`。顺序是 `3 -> 1 -> 2`。
    
2. **触发警报：** 出现了 `1 -> 2` 升序，**直接判定非法！**
    

#### 验证示例 3：判断序列 `4, 5, 3, 2, 1` 是否合法？

1. **看 4：** 后面比它小的有 `3, 2, 1`。是降序，合法。
    
2. **看 5：** 后面比它小的有 `3, 2, 1`。是降序，合法。
    
3. **看 3：** 后面比它小的有 `2, 1`。是降序，合法。
    
4. 一路绿灯，**判定合法！**


# 允许两端入队，一端出队


**适用场景：** 允许两端入队，一端出队

**底层逻辑：** 因为只能从一端出队，所以留在队列里的元素，最终出队的顺序必定是它们在队列里从左到右的死顺序。而在排队时，新来的元素只能插在队伍的最前面或最后面，**绝对插不到中间**。所以，如果几个元素被困在队列里，**最后进去的那个（最大的那个）绝不可能在中间**。


**秒杀规律：**

1. 随便盯住输出序列中的一个大数 $X$。
2. 找出在 $X$ 后面输出、且比 $X$ 小的所有数，把它们单独拿出来看。
3. 在这些数中，**绝对不能出现“小-大-小”的格局（即最大的数不能夹在中间）**。


**我们用这个法则秒杀第 20 题：**

已知入队顺序是 $a, b, c, d, e$（当成 1, 2, 3, 4, 5）。

- **看 A 选项 (2, 1, 3, 4, 5)：** 找大数 2，后面比 2 小的只有 1，没问题。找 3，后面没有比 3 小的。全部合法。
    
- **看 B 选项 (4, 2, 1, 3, 5)：** 找大数 4。后面比 4 小的数组成的序列是 `2, 1, 3`。在这个子序列里，最大的数是 3，它在最边上；剩下的 `2, 1` 中，最大的是 2，也在最边上。没有出现“两边小中间大”，合法。
    
- **看 C 选项 (4, 2, 3, 1, 5)：** 找大数 4。后面比 4 小的数组成的序列是 **`2, 3, 1`**。
    
    - **警报拉响！** 在 `2, 3, 1` 这个局部序列里，**最大的数 3 竟然夹在 2 和 1 中间！**
        
    - 这就是典型的“小-大-小”山峰格局。按照我们刚才的逻辑，3 是最晚进队列的，它本该在最左边或最右边，绝不可能挤到 2 和 1 中间。
        
    - 所以 C 选项**绝对不可能**得到，秒选 **C**！
        

#  允许一端入队，两端出队


**底层逻辑：** 元素只能从一端进去，所以在队列里永远是严格按顺序排成一列（比如 `4, 3, 2, 1`）。出队时，你可以从队头拿，也可以从队尾拿。这意味着，你每次拿出来的元素，**必须是当前困在队列里的元素中最大的，或者是最小的！**

**秒杀规律：**

1. 盯住输出序列中的一个大数 $X$。
    
2. 找出在 $X$ 后面输出、且比 $X$ 小的所有数组成的集合。
    
3. 这些数在输出时，**第一个输出的数，绝对不能是“夹在中间大小”的数。它必须是这堆数里最大的，或者是最小的。**
    

**验证前面背的口诀：为什么 4, 2, 3, 1 是输入受限的死局？**

1. 找到大数 4。后面比 4 小的集合是 `{1, 2, 3}`。
    
2. 4 出来之后，接着出来的是 **2**。
    
3. 但是在 `{1, 2, 3}` 里面，2 既不是最大（3），也不是最小（1），它是夹在中间的数！
    
4. 你想象一下队列里是 `4, 3, 2, 1`，你拿走了 4（剩下 `3, 2, 1`），你想拿 2？抱歉，3 堵在左边，1 堵在右边，2 根本出不来！
    
5. 违反规则，所以 `4, 2, 3, 1` 死局。
