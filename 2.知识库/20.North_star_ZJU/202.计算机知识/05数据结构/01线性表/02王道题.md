# 链表

2. B
3. <font color="#ff0000">C</font>!!
   链式存储，结点内的存储单元地址一定连续
   一个结点是一个整体的存储单元（在 C 里就是一个 `struct`），它包含数据域 + 指针域。这个 struct 是被当作一块完整内存申请出来的，内部的字段按声明顺序排在一段连续地址上。
4.  D没有规定存储方式存储什么逻辑结构对吧？
   "顺序存储方式只能用于存储线性结构" —— 这句话是**错的**。

顺序存储也能存非线性结构。典型例子：

- 完全二叉树可以用数组顺序存储（下标 i 的结点，左孩子在 2i，右孩子在 2i+1，父结点在 ⌊i/2⌋）。
- 图可以用邻接矩阵（二维数组）顺序存储。

所以存储方式和逻辑结构之间没有绑定关系：线性结构可以顺序存也可以链式存，非线性结构同样可以顺序存也可以链式存
