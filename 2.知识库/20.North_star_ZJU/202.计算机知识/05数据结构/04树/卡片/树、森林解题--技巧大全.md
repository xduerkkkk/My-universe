只有树的后根遍历特殊一点

| 遍历          | 规则                                                | 对应二叉树的遍历 |
| ----------- | ------------------------------------------------- | -------- |
| **树·先根遍历**  | 先访问根，再依次先根遍历根的每棵子树                                | **先序遍历** |
| **树·后根遍历**  | 先依次后根遍历根的每棵子树，再访问根                                | **中序遍历** |
| **树·层次遍历**  | 按层从上到下、每层从左到右（用队列实现）                              | 无严格对应    |
| **森林·先序遍历** | ① 访问第一棵树的根 → ② 先序遍历第一棵树的**子树森林** → ③ 先序遍历剩余树构成的森林 | **先序遍历** |
| **森林·中序遍历** | ① 中序遍历第一棵树的**子树森林** → ② 访问第一棵树的根 → ③ 中序遍历剩余树构成的森林 | **中序遍历** |


若某个结点同时存在左孩子 $L$ 和右孩子 $R$：
* 前序遍历中，相对顺序必为：$L \dots R$（根 $\to$ 左 $\to$ 右）
* 后序遍历中，相对顺序必为：$L \dots R$（左 $\to$ 右 $\to$ 根）
只要度为 2，$L$ 和 $R$ 在前序和后序中的相对先后顺序**绝对相同**，不可能整体逆序。
因此，前序与后序互逆，充要条件是**每个非叶结点都只有一个孩子**（单支树/链状树）。
