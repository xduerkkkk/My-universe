# 图论知识点整理

**来源**：[[01王道笔记]] · [[02王道题]]

## 章节主线

图论按“描述 → 存储 → 遍历 → 优化/应用”组织：

1. 顶点、边、度、路径、连通性与 DAG。
2. 邻接矩阵、邻接表、十字链表、邻接多重表。
3. DFS/BFS 及其复杂度、连通分量和环检测。
4. 最小生成树、最短路径、拓扑排序与关键路径。

## 核心概念

### 图的基本术语

- **图的阶**：顶点数 `|V|`。
- **有向图**：每条边有方向；顶点有入度、出度，弧总数等于所有顶点入度之和，也等于所有顶点出度之和。
- **无向图**：每条边无方向；顶点度数总和为 `2|E|`。
- **简单路径**：不重复顶点的路径；简单回路除首尾同点外不重复顶点。
- **连通图**：无向图任意两点间有路径；强连通图要求有向图任意两点间都存在有向路径。
- **连通分量**：极大连通子图；可以含环。
- **生成树**：连通图包含全部顶点的极小连通子图；无环且边数 `n−1`。非连通图的生成森林每个分量各取一棵生成树。

### 边数与连通性极值

- n 个顶点的无向图要“可能连通”，至少需要 `n−1` 条边。
- 要“保证任意图连通”，要超过最大非连通图的边数：`C(n−1,2)+1`。
- 固定 n、e 求连通分量最多：把 e 条边集中为最少顶点的完全图，其余顶点孤立。令 `x` 为满足 `C(x,2)≥e` 的最小整数，答案 `1+n−x`。
- 森林中若有 x 棵树，`e=n−x`，所以 `x=n−e`。

## 对比表

| 概念    | 核心区别         | 判断线索                             | 常见误区           |
| ----- | ------------ | -------------------------------- | -------------- |
| 连通分量  | 极大连通子图       | 不能再吸收顶点/边                        | 误以为必须无环        |
| 生成树   | 极小连通子图，含全部顶点 | n−1 条边、无环                        | 误称为连通分量        |
| 强连通   | 任意两点互相可达     | 允许经过中间点                          | 误读成任意两点直连      |
| 邻接矩阵  | 空间稳定，扫描邻居慢   | 矩阵行列                             | 遍历复杂度写成 O(n+e) |
| 邻接表   | 按实际边组织       | 顶点表+边表                           | 有向入度只看本顶点出链    |
| 十字链表  | 有向图，同时维护出/入边 | `firstin/firstout`、`hlink/tlink` | 用于无向图删边        |
| 邻接多重表 | 无向图共享边结点     | 一条边只存一份                          | 误当成有向入出链       |

### 图的存储

- **邻接矩阵**：无权图有边常记 1、无边记 0；带权图有边存权值、无边常存 `∞`，主对角线通常为 0。适合判断两点是否直接相邻、稠密图；空间 `O(n²)`。
- **邻接表**：顶点表大小 `n`；有向图边表结点数量 `e`，无向图通常存 `2e` 个表结点。适合稀疏图。
- **十字链表**：面向有向图；一条弧同时挂在弧尾的出边链和弧头的入边链。
- **邻接多重表**：面向无向图；一条边只存一个边结点，由两个端点共同链接，便于删边。

### DFS 与 BFS

- DFS：递归或显式栈；沿当前路径尽量深入，当前结点无未访问邻居时才回溯。
- BFS：队列；按距离源点的层次扩展。
- 复杂度：邻接矩阵均为 `O(n²)`；邻接表均为 `O(n+e)`。
- 无向图 BFS/DFS 可求连通分量；有向图环检测更稳妥的方法是 DFS 当前递归栈或拓扑排序。

### 最小生成树

- **Prim**：从一个顶点出发，逐步把离当前树最近的顶点接入。
- **Kruskal**：边按权值递增，若两端不在同一集合则选边并 Union；并查集用于防止成环。
- 边权互不相同时 MST 唯一；有相同权值时仍可能唯一，不能把“无重复权值”当必要条件。

### 最短路径

- **BFS**：无权图/等权图的单源最短路径。
- **Dijkstra**：非负权图的单源最短路径；每轮先松弛新确定顶点的邻边，再选最小 dist。
- **Floyd**：全源最短路径，可有负权边，但不能有负权回路；转移 `d[i][j]=min(d[i][j],d[i][k]+d[k][j])`。
- 邻接矩阵下单源 Dijkstra 为 `O(n²)`；对所有源点重复为 `O(n³)`；Floyd 为 `O(n³)`。

### 拓扑排序与关键路径

- **拓扑排序**：只适用于 DAG；反复取入度为 0 的顶点。最终输出少于 n 个顶点说明有环。
- **唯一性**：每一步入度为 0 的候选必须恰有一个；等价地，唯一序列中的每一对相邻顶点之间必须有前指向后的边。但可有额外的传递边，图不必只有一条链。
- 若按拓扑序给顶点编号，则所有弧 `i→j` 满足 `i<j`，邻接矩阵为上三角；只说“存在拓扑序”不保证矩阵形状。
- AOE 网中顶点是事件、边是活动；关键活动的时间余量为 0。

## 公式与条件

> [!important] 关键路径
> `ve(j)=max_i{ve(i)+w(i,j)}`；`vl(i)=min_j{vl(j)−w(i,j)}`。  
> 活动 `i→j`：`e=ve(i)`，`l=vl(j)−w(i,j)`，时差 `l−e`；时差为 0 才是关键活动。

> [!important] 连通性的边数底线
> 连通图至少 `n−1` 条边；`|E|<|V|−1` 时必不连通；保证连通至少 `C(n−1,2)+1` 条边。

> [!important] 邻接表/矩阵复杂度
> 图遍历采用邻接表为 `O(n+e)`，采用邻接矩阵为 `O(n²)`。

## 大题方法

1. **先判图型**：有向/无向、带权/无权、是否 DAG、是否有负边/负环。
2. **再判目标**：连通性、环、单源最短、全源最短、MST、关键路径。
3. **选择算法**：无权单源 BFS；非负权单源 Dijkstra；全源 Floyd；DAG 拓扑排序/关键路径。
4. **保持物理语义**：矩阵的 0/∞/权值，邻接表的出链/入链，活动边和事件点。
5. **边界校验**：检查是否存在多个入度 0 候选、多个关键路径、负权回路或孤立顶点。

## 易混概念

- **路径最短 vs 边数最少**：只有无权/等权时二者等价。
- **拓扑序唯一 vs 图唯一**：序列可唯一，但图上仍可有传递边。
- **Dijkstra 单源 vs 每对顶点**：一次 `O(n²)`，对 n 个源点要 `O(n³)`。
- **活动时间 vs 事件时间**：活动有 e/l，事件有 ve/vl。

## 校正与条件

> [!warning] 原批注：最小生成树唯一当且仅当所有边权都不同
> **校正**：边权互不相同是保证 MST 唯一的充分条件；存在相同权值时，MST 仍可能唯一。  
> **原因/条件**：唯一性取决于具体割/环结构，不仅取决于权值是否重复。

> [!warning] 原批注：拓扑序列唯一意味着图是严格线性链、每个点入度/出度都为 1
> **校正**：唯一拓扑序要求每一步只有一个入度为 0 的候选；相邻序列元素之间必须有边，但允许额外传递边，源点/汇点也不按普通内部点的入度/出度计。

> [!warning] 原批注：BFS 不能判断有向图环，因此所有 BFS 相关说法都错
> **校正**：纯 BFS 的无向图环检测可行；有向图应优先用 DFS 递归栈或拓扑排序。基于入度队列的拓扑排序虽然实现上像 BFS，但概念上不是普通 BFS。

## 绝对词检查

- “一定”：补充图的方向、权值和存储结构。
- “唯一”：区分算法输出序列唯一、MST 唯一和图本身唯一。
- “最短”：说明按边数还是按权值。
- “只要”：检查是否存在负权边、负环、并行候选或多条关键路径。
