### 一、为什么变成了 `->` 而不是 `.`？

这是 C 语言中最基础但也最容易手滑的语法规则。区别仅仅在于**参数是怎么传进来的**：

1. **之前的题（用 `.`）**：
   函数定义是 `int IsConnected(ALGraph G)`。
   这里传入的是 `G` 这个**结构体变量本身**（传值调用）。既然 `G` 是个实体，访问它的成员必须用点操作符：`G.numVertices`。
2. **这道题（用 `->`）**：
   函数定义是 `bool DFS(ALGraph *G, ...)`。
   注意看，这里多了个 `*`。传入的是一个**指向结构体的指针**（传址调用）。既然 `G` 只是个内存地址，访问它指向的成员必须用箭头操作符：`G->numVertices`。

**408 考场建议：**
考试时，如果不要求严格写死函数签名，**强烈建议统一写成 `(ALGraph &G)`（C++ 引用传递）**。这样不仅不用复制庞大的图结构（省内存），而且在函数体里面你可以**全程舒舒服服地用 `G.numVertices`**，完美避开 `->` 和 `.` 混用的灾难。

*顺便指出王道代码里的一个**致命 Bug**（图片第 6 行）：*
代码写着 `ArcNode *p = G->VerticesList[v];`。
这在语法上是完全错误的！`VerticesList[v]` 是一个 `VNode` 结构体，而 `p` 是个边节点指针。
正确的写法必须是：**`ArcNode *p = G->VerticesList[v].firstarc;`**（因为 `VerticesList[v]` 是数组里的实体元素，所以用 `.`，然后取它的 `firstarc` 指针）。

### 二、这里也能用“进门前打标记”的统一模板吗？

**完全可以！而且改写后，判断是否有环的逻辑会变得更加清晰。**

这道题的核心算法是**“无向图找环”**：如果在 DFS 过程中，碰到了一个已经访问过的顶点（`visited[u] == true`），并且这个顶点**不是你刚刚走过来的那个爹（`u != parent`）**，那就说明图里绝对有环。

我们用你总结的**“进门前打标记”**法则来重构这道题，代码会非常工整：

```c
// 统一模板重构版 DFS
bool DFS(ALGraph *G, int v, int parent) {
    // 进来不打标记了
    
    // 修正王道的 Bug，加上 .firstarc
    ArcNode *p = G->VerticesList[v].firstarc; 
    
    while (p != NULL) {
        int u = p->adjvex; // 拿到邻居 u
        
        if (visited[u] == false) {
            // 邻居没去过
            visited[u] = true;           // 【进门前打标记】
            if (DFS(G, u, v) == true) {  // 【进门深入，且告诉 u 它的爹是 v】
                return true;             // 如果子树找到了环，直接向上汇报
            }
        } 
        else {
            // 邻居去过了！检查它是不是回头路
            if (u != parent) {
                return true; // 既去过，又不是爹，绝对是遇到环了！
            }
        }
        p = p->nextarc;
    }
    return false; // 当前节点的所有分支都没环
}
```

主函数也配合你改写（同样应用了上一条的 `={0}` 快捷初始化）：

```c
int HasCycle(ALGraph *G) {
    bool visited[MAXV] = {false}; // 快捷初始化全为 false
    
    for (int v = 0; v < G->numVertices; v++) { // 遍历所有顶点，防非连通图
        if (visited[v] == false) {
            
            visited[v] = true;             // 【启动前，手动给起点打标记】
            if (DFS(G, v, -1) == true) {   // 启动！起点的爹是 -1（没有爹）
                return 1;                  // 发现环
            }
            
        }
    }
    return 0; // 全图都没环
}
```
