- **最少有多少个结点？** 前面 $h-1$ 层是全满的，第 $h$ 层只有一个孤零零的结点。
    
    算一下：前 $h-1$ 层满树结点数是 $2^{h-1} - 1$。加上第 $h$ 层那 1 个，总共最少是 $2^{h-1}$ 个。
    
- **最多有多少个结点？** 整棵树全满（即满二叉树）。
    
    算一下：总共最多是 $2^h - 1$ 个。
    

所以，无论你怎么折腾，一棵高度为 $h$ 的完全二叉树，它的结点数 $n$ 的绝对真理是：

$$2^{h-1} \le n \le 2^h - 1$$

这两个不同的推导，其实就是对这个不等式玩了两种不同的“变形戏法”。

---

### 第一种戏法：向上取整 $\lceil \dots \rceil$（对应第一张图）

这个推导的视角是想把不等式中间变成 $n+1$，凑出一个干净的 $2^h$。

1. 拿出我们的真理不等式：$2^{h-1} \le n \le 2^h - 1$
    
2. 左边稍微变一下。既然 $n \ge 2^{h-1}$，那 $n$ 肯定严格大于 $2^{h-1} - 1$。所以可以写成：
    
    $$2^{h-1} - 1 < n \le 2^h - 1$$
    
    _(这就是你第一张图第一行的右边)_
    
3. **大家一起加 1**：
    
    $$2^{h-1} < n + 1 \le 2^h$$
    
4. 大家一起取 $\log_2$：
    
    $$h - 1 < \log_2(n + 1) \le h$$
    
5. **关键逻辑来了：** 你看中间这个数 $\log_2(n+1)$，它被夹在 $h-1$ 和 $h$ 之间，并且可以等于 $h$。比如 $h=4$，那这个数就是 3 点几，或者刚好是 4。
    
    对一个 3 点几的数**向上取整**，结果是多少？是 4！
    
    所以，直接得出结论：
    
    $$h = \lceil \log_2(n+1) \rceil$$
    

---

### 第二种戏法：向下取整 $\lfloor \dots \rfloor$（对应第二张图）

这个推导的视角更直接一点，它想利用向下取整的特性。

1. 还是拿出我们的真理不等式：$2^{h-1} \le n \le 2^h - 1$
    
2. 右边稍微变一下。既然 $n$ 是整数，且 $n \le 2^h - 1$，这完全等价于说 $n$ 严格小于 $2^h$。所以可以写成：
    
    $$2^{h-1} \le n < 2^h$$
    
    _(这就是你第二张图推导的第一行)_
    
3. 大家一起取 $\log_2$：
    
    $$h - 1 \le \log_2n < h$$
    
4. **关键逻辑又来了：** 这次你看中间的数 $\log_2n$，它包含 $h-1$，然后往上走，但永远达不到 $h$。比如 $h=4$，那这个数就是从 3 开始，最大到 3.999...。
    
    对这种数**向下取整**，结果是多少？永远是 3（也就是 $h-1$）！
    
    所以得出：
    
    $$\lfloor \log_2n \rfloor = h - 1$$
    
5. 把 -1 移到等号另一边：
    
    $$h = \lfloor \log_2n \rfloor + 1$$
    

---

### 拿个具体数字来验算一下

这俩公式算出来的结果真的是一样的吗？我们试个例子，假设这棵树有 **$n = 10$** 个结点。

- **用第一个公式（向上取整）：**
    
    $h = \lceil \log_2(10+1) \rceil = \lceil \log_2(11) \rceil$
    
    因为 $2^3=8$，$2^4=16$，所以 $\log_2(11)$ 大概是 3.45。
    
    3.45 向上取整，高度 **$h = 4$**。
    
- **用第二个公式（向下取整）：**
    
    $h = \lfloor \log_2(10) \rfloor + 1$
    
    $\log_2(10)$ 大概是 3.32。
    
    3.32 向下取整是 3。加上 1，高度 **$h = 4$**。
    

**总结：**

逻辑就是同一个不等式的两种恒等变形。你只需要记住**第二种（$\lfloor \log_2n \rfloor + 1$）**就行了
