

**考场核心策略：不要试图在一个函数里把所有事情做完！**

判断大顶堆和判断小顶堆的逻辑同时写在一个递归里，脑容量很容易爆。
题目说节点数 $n \le 10^4$，数据量非常小。时间复杂度 $O(N)$ 遍历两遍树完全可以拿到满分！

**408 阅卷人最喜欢的写法（逻辑解耦法）：**
写一个判断大顶堆的辅助函数，再写一个判断小顶堆的辅助函数。
处理“单孩子”最简单的办法就是：**先判断孩子存不存在，存在我才比较。**

**满分代码（原生指针/标准 408 风格）：**

```cpp
#include <stdbool.h>

// 辅助函数 1：判断是否是大顶堆
bool isMaxHeap(TreeNode* root) {
    if (root == nullptr) return true; // 空树算作满足堆性质
    
    // 只要左孩子存在，且左孩子的值大于根节点，破坏大顶堆性质
    if (root->left != nullptr && root->left->val > root->val) 
        return false;
    
    // 只要右孩子存在，且右孩子的值大于根节点，破坏大顶堆性质
    if (root->right != nullptr && root->right->val > root->val) 
        return false;
        
    // 递归检查左右子树
    return isMaxHeap(root->left) && isMaxHeap(root->right);
}

// 辅助函数 2：判断是否是小顶堆
bool isMinHeap(TreeNode* root) {
    if (root == nullptr) return true; 
    
    if (root->left != nullptr && root->left->val < root->val) 
        return false;
        
    if (root->right != nullptr && root->right->val < root->val) 
        return false;
        
    return isMinHeap(root->left) && isMinHeap(root->right);
}

// 主函数：按照题目要求返回 0, 1, 2
int isHeap(TreeNode* root) {
    if (root == nullptr) return 0; // 根据题意，n>=2，这里做个兜底
    
    // 题目已知这是一棵完全二叉树，所以不需要检查完全二叉树的性质
    if (isMaxHeap(root)) {
        return 1;
    } 
    else if (isMinHeap(root)) {
        return 2;
    } 
    else {
        return 0;
    }
}
```

### 四、时间复杂度和空间复杂度分析

使用我为你改写的代码：
*   **时间复杂度：$O(N)$**。其中 $N$ 为节点总数。在最坏情况下（比如既不是大顶堆也不是小顶堆，但要遍历完才发现），我们遍历了两次树，复杂度为 $O(2N)$，渐进复杂度为 $O(N)$。对于 $10^4$ 的数据规模，$10^4$ 次操作在 C++ 中连 1 毫秒都用不到，**达到了题目要求的最优解**。
*   **空间复杂度：$O(\log N)$**。由于题目明确指出这是一棵**完全二叉树**，完全二叉树的高度 $h = \lfloor\log_2 N\rfloor + 1$。递归调用栈的最大深度就是树的高度，所以空间复杂度最优且稳定在 $O(\log N)$。






你提到的 “遍历 `i=0` 到 `i/2`” 思路完全正确，但有**两个极易丢分的边界细节**需要注意：

1. **循环终点（非叶节点的范围）**：
   假设数组长度为 `n`，下标从 `0` 开始。
   非叶子节点的正确下标范围是 `0` 到 `n/2 - 1`。因此循环条件写成 `i < n/2` 即可。
2. **“单孩子”越界处理**：
   在数组中处理“只有一个左孩子”的情况太简单了。左孩子的下标是 `2i + 1`，右孩子的下标是 `2i + 2`。只要下标 `< n` 就说明这个孩子存在，根本不需要判断指针是否为空！

### 二、 408 风格匹配度重写（一趟遍历，双重标记法）

既然变成了数组，我们连写两个辅助函数都不需要了。**直接用一趟遍历，设置两个标志位**，代码极致清爽，绝对是 408 阅卷人最爱看的“底层数组模拟”风格。

**满分代码（默认数组从下标 0 开始，长度为 n）：**

```c
int isHeapArray(int arr[], int n) {
    if (n < 2) return 0; // 兜底检查

    int isMax = 1; // 假设是大顶堆
    int isMin = 1; // 假设是小顶堆

    // 只需要遍历所有的非叶子节点，即 0 到 n/2 - 1
    for (int i = 0; i < n / 2; i++) {
        int left = 2 * i + 1;
        int right = 2 * i + 2;

        // 如果左孩子存在，进行比较
        if (left < n) {
            if (arr[i] < arr[left]) isMax = 0; // 只要比孩子小，就不可能是大顶堆
            if (arr[i] > arr[left]) isMin = 0; // 只要比孩子大，就不可能是小顶堆
        }

        // 如果右孩子存在，进行比较
        if (right < n) {
            if (arr[i] < arr[right]) isMax = 0;
            if (arr[i] > arr[right]) isMin = 0;
        }
        
        // 剪枝优化：如果既不是大顶堆也不是小顶堆，直接提前结束
        if (!isMax && !isMin) return 0;
    }

    if (isMax) return 1;
    if (isMin) return 2;
    return 0; // 理论上走不到这里，除非n=0或剪枝漏了
}
```

### 三、时间复杂度和空间复杂度（极致优化）

与之前给你的树形指针代码相比，数组解法在性能上得到了真正的升华：

* **时间复杂度：** $O(N)$。由于只遍历了一半的节点（$N/2$），常数项极小。而且数组在内存中是连续分配的，CPU 缓存命中率（Cache Locality）极高，实际运行速度比指针遍历快得多。**这是理论与实际双重意义上的最优解。**
* **空间复杂度：** **$O(1)$**。无需递归，没有函数调用栈的开销，只用了几个 `int` 类型的变量，空间复杂度从 $O(\log N)$ 降到了 $O(1)$！这是算法设计上的质变。

在 408 真题中，如果是出算法大题，你**一定要看清楚题目给的数组是从 `0` 开始存，还是从 `1` 开始存**。

* 如果像 C/C++ 原生数组一样**从 `0` 开始**：
  左孩子是 `2i + 1`，右孩子是 `2i + 2`，非叶节点是 `0` ~ `n/2 - 1`。
* 如果像《王道》教材里常写的那样，**下标 `0` 废弃不用，从 `1` 开始存**（共 n 个元素，数组长度 n+1）：
  左孩子是 `2i`，右孩子是 `2i + 1`，非叶节点是 `1` ~ `n/2`。（此时循环写 `for(int i = 1; i <= n/2; i++)`）。
