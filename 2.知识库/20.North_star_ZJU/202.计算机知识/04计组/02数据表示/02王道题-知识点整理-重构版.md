> [!abstract] 章节主线
> 同一段位模式没有天然的“数值意义”：先确定编码格式与位宽，再确定有/无符号、定点/浮点解释；运算后经过规格化和舍入，最后才判断范围、精度与异常。

## 1. 数值表示的三层

| 层次 | 要回答的问题 | 高频坑 |
|---|---|---|
| 位模式 | 当前有多少位、每位是什么 | 把 32 bit 与 32 B 混为一谈 |
| 编码规则 | 原码、补码、移码、IEEE 754，还是题设自定义浮点 | 把 IEEE 隐含位套到补码尾数题 |
| 类型/语义 | 有符号、无符号、整数、浮点、语言转换规则 | 同一位串在 CF 与 OF 视角下含义不同 |

**做题固定动作**：写位宽 → 写格式 → 写真值/类型 → 执行运算 → 检查舍入/溢出。

## 2. 整数编码与边界

### 2.1 n 位常见范围

| 编码    | 范围/规则                  | 边界提醒                  |
| ----- | ---------------------- | --------------------- |
| 无符号整数 | $[0,2^n-1]$            | 全 1 为最大值              |
| n 位补码 | $[-2^{n-1},2^{n-1}-1]$ | 正负不对称；最小负数无对应正数       |
| 移码    | 编码无符号值减 Bias           | Bias 由格式/题设确定，不能只凭位数猜 |

### 2.2 移码与偏置

- 通用公式：$E_{true}=E_{code}-Bias$。
- 教材移码可能取 $2^{n-1}$；IEEE k 位阶码取 $2^{k-1}-1$。
- 给定 0/1 数量求极值时，先按无符号权值安排高低位，再减偏置；补码则必须单独处理符号位权值。

### 2.3 类型转换：扩展与重解释分开

1. **位宽扩展**：有符号数通常符号扩展，无符号数零扩展。
2. **重解释**：位模式不变，按目标有/无符号类型读取。
3. **C 的通常算术转换**：先整型提升，再根据等级与可表示范围选共同类型。

> [!warning] 旧版表述：有符号和无符号混用时，全部强制当成无符号数处理。
> **校正**：这是常见但不完整的简化。当更高等级的有符号类型能表示无符号类型的全部值时，双方可转为该有符号类型。  
> **适用条件**：408 常见“同位宽 signed 与 unsigned”题中，有符号数通常被转为无符号。

## 3. 移位、补码运算与标志位

### 3.1 左移与右移

| 操作 | 空位填充 | 被移出位 | 语义边界 |
|---|---|---|---|
| 逻辑左移 | 低位补 0 | 高位丢弃 | 常用于无符号乘 $2^k$，但可能丢高位 |
| 算术左移 | 常见教材位操作同逻辑左移 | 高位丢弃 | 仅当结果可表示时才等价于有符号乘 $2^k$ |
| 逻辑右移 | 高位补 0 | 低位丢弃 | 无符号除 $2^k$ |
| 算术右移 | 高位补符号位 | 低位丢弃 | 负数取整方向依题设/语言实现 |

> [!warning] 旧版表述：算术左移最高位直接丢，没有补位操作。
> **校正**：高位确实被丢弃，但低位空位要补 0。真正需要判断的是丢位后是否破坏有符号真值。  
> **适用条件**：固定宽度机器数题。

### 3.2 OF 与 CF

| 标志 | 解释视角 | 加/减法问题 |
|---|---|---|
| CF/借位 | 无符号 | 是否产生最高进位，或减法是否不够减；具体 0/1 极性看题设 |
| OF | 有符号补码 | 数学结果是否越过补码范围 |
| SF | 结果位模式 | 结果最高位；有符号比较时需结合 OF |
| ZF | 位模式 | 结果是否全 0 |

- 加法 OF：两个同号数相加得到异号结果。
- 减法 OF：被减数与减数异号，且结果符号与被减数不同。
- 单符号位可用“进入符号位的进位 XOR 符号位进位”判 OF。
- 双符号位正常为 00/11，01 正溢出，10 负溢出。

## 4. 浮点表示的范围、精度与特殊值

### 4.1 IEEE 754 单/双精度

| 格式 | 符号 | 阶码 | 尾数字段 | 规格化有效精度 | Bias |
|---|---:|---:|---:|---:|---:|
| binary32 / float | 1 | 8 | 23 | 24 bit | 127 |
| binary64 / double | 1 | 11 | 52 | 53 bit | 1023 |

### 4.2 阶码模式

| 阶码 | 尾数 | 含义 | 隐含位 |
|---|---|---|---|
| 全 0 | 全 0 | ±0 | 0 |
| 全 0 | 非 0 | 非规格化数 | 0 |
| 非全 0/非全 1 | 任意 | 规格化有限数 | 1 |
| 全 1 | 全 0 | ±∞ | — |
| 全 1 | 非 0 | NaN | — |

### 4.3 范围与精度分工

- **阶码**主要决定数量级范围。
- **有效数位数**决定相邻可表示数的间距和相对精度。
- float 可精确表示所有 $|x|le 2^{24}$ 的整数；double 可精确表示所有 $|x|le 2^{53}$ 的整数。
- 超出连续整数区间后，仍有部分较大整数能精确表示，但相邻整数不再全部可表示。

> [!warning] 旧版表述：float 只能精确表示 $[-2^{24},2^{24}]$ 范围内的整数。
> **校正**：该区间是“所有整数连续精确可表示”的边界，不是所有可精确整数的最大绝对值。  
> **反例**：$2^{25}$ 本身仍能被 float 精确表示，但它附近的奇数不能全部表示。

### 4.4 正负对称的边界

- 有限非零 IEEE 浮点数按绝对值正负成对。
- 完整编码还包含 +0/-0、+∞/-∞ 和 NaN。
- 不要把这种符号位对称性套到补码整数；补码范围正负不对称。

## 5. 浮点运算流程

1. **对阶**：小阶向大阶对齐，较小数尾数右移。
2. **尾数运算**：加/减有效数。
3. **规格化**：左规或右规，并同步调整阶码。
4. **舍入**：根据 guard/round/sticky 位与舍入模式处理。
5. **异常检查**：判断上溢、下溢、无效运算、除零、不精确等。

### 5.1 规格化的作用

- 统一非零数表示并充分利用尾数字段。
- 不增加物理阶码位数，因而不单独扩大数量级范围。
- IEEE 非规格化数牺牲部分有效位，在 0 附近提供渐进下溢。

### 5.2 “大数吃小数”

- 阶码差越大，小数对阶右移越多。
- 是否完全无贡献，要结合有效精度 p、额外保护位以及舍入模式。
- 不能脱离题设死记“阶码差达到 25 一定无影响”。

### 5.3 舍入不只发生在算术末尾

- 真值装入 float/double 时可能舍入，例如十进制 0.1。
- 浮点运算对阶、规格化后也可能舍入。
- 强转和存储到较低精度格式时还会再次舍入。

## 6. 类型转换与表达式判断

| 转换 | 主要风险 | 稳定结论 |
|---|---|---|
| 32 位 int → float | 有效精度不足，可能舍入 | 范围通常够，不代表精确 |
| 32 位 int → double | 通常精确 | 53 位可覆盖所有 32 位 int |
| float → double | 精确扩展原有 float 值 | 不会恢复此前已丢精度 |
| float/double → int | 小数向 0 截断；越界 | C 中越界行为未定义 |

判断表达式时按以下顺序：

1. **先算什么**：括号与运算符决定在哪种类型中先运算。
2. **中间结果是否可表示**：整数溢出或浮点舍入是否已经发生。
3. **转换是否精确**：目标格式的范围和有效精度是否覆盖源值。
4. **是否要求恒等**：浮点加法一般不满足结合律，必须证明本题中间结果均精确。

> [!warning] 旧版表述：有符号 int 溢出按补码环绕；float 转 int 越界通常变成负数。
> **校正**：在 C 语言标准语境中，这两类越界都不能无条件按固定硬件结果推断。  
> **适用条件**：若题目明确采用固定宽度补码机器模型，才可按模 $2^n$ 环绕计算位模式。

## 7. 自定义浮点与 IEEE 分流

- 看到“float、double、IEEE 754”：使用 Bias、隐含位、特殊阶码、非规格化数规则。
- 看到“阶码和尾数均用补码、各含双符号位”：严格按题设自定义格式，不加 IEEE 隐含 1。
- 分母为 $2^n$ 的二进制分数可用“分子转二进制 + 小数点左移 n 位”。

## 8. 易混概念

- **表示范围 vs 精度**：阶码解决“多大/多小”，尾数解决“多细”。
- **位宽相同 vs 精度相同**：int 与 float 都可能是 32 bit，但有效整数精度不同。
- **编码转换 vs 数值转换**：位模式重解释不等于保持真值。
- **规格化数 vs 非规格化数**：隐含位分别为 1 与 0。
- **机器模型 vs C 语言标准**：教材补码环绕不能自动替代语言层未定义行为。
- **逻辑通用结论 vs 具体实现性能**：整数运算通常简单，但不能无条件断言在所有处理器上一定更快。

## 9. 绝对词检查

- “偏置一定是 $2^{n-1}$” → 检查格式。
- “有符号遇无符号一定转无符号” → 检查等级与可表示范围。
- “移出 1 一定溢出” → 检查有/无符号语义和结果范围。
- “阶码差 ≥25 一定无影响” → 检查精度、保护位与舍入模式。
- “float 区间外整数都不能精确表示” → 区分连续整数区间与离散可表示点。
- “浮点下溢一定不中断” → 检查异常标志、陷阱屏蔽与体系结构。
