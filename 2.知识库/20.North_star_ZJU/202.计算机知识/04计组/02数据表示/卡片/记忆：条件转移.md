![[_attachments/image/记忆：条件转移-1788167370459.jpeg]] ### 一、这里到底在干什么？（底层硬件机制）

在高级语言中写的 `if (a > b)`，在底层的 CPU 执行过程只有两步：

```
第一步：CMP a, b  ──> 底层做减法 (a - b)，丢弃计算差值，仅根据结果设置标志位 (ZF, CF, SF, OF)
第二步：Jcc 跳转  ──> 根据刚才生成的标志位，决定是否跳转 (跳到 if 块内还是跳过)
```

**关键点**：`CMP` 指令执行时，ALU 根本不知道你是有符号比较还是无符号比较，它会**同时生成所有 4 个标志位**。  
是由随后的**跳转指令（`Jcc`）**来决定“按什么规则解读这些标志位”：
* 如果编译器知道你比的是**无符号数**，就生成 **`JA / JB`** 系列指令（只看 $CF$ 和 $ZF$）。
* 如果编译器知道你比的是**带符号数**，就生成 **`JG / JL`** 系列指令（只看 $SF, OF$ 和 $ZF$）。

### 二、 标志位的严格硬件定义（408 必须掌握）

设执行减法 $A - B$（即 $A + \sim B + 1$）：

1. **$ZF$（零标志）**：
   * 结果全为 0 时 $ZF = 1$；否则 $ZF = 0$。
   * **含义**：$ZF = 1 \iff A == B$。
2. **$SF$（符号标志）**：
   * 直接等于结果的最高位（$SF = \text{Result}[n-1]$）。
   * **含义**：结果最高位是 1 则 $SF=1$（负），最高位是 0 则 $SF=0$（非负）。
3. **$CF$（无符号借位标志）**：
   * 减法中，不够减（$A < B$）需要借位时 $CF = 1$；够减时 $CF = 0$。
   * **含义**：无符号数比较时，$CF = 1 \iff A < B$。
4. **$OF$（带符号溢出标志）**：
   * 带符号减法中，若“正数 $-$ 负数 得 负数”或“负数 $-$ 正数 得 正数”，则发生溢出，$OF = 1$；否则 $OF = 0$。

### 三、 条件转移逻辑的推导与记忆法

无需死记逻辑表达式，按**英文缩写**与**数学本质**即可推导：

```
                ┌─ 无符号比较：用 Above / Below (高/低) ──> 看 CF (借位) 与 ZF
比较指令分为两派 ─┤
                └─ 带符号比较：用 Greater / Less (大/小) ──> 看 SF ⊕ OF (符号纠错) 与 ZF
```

#### 1. 通用比较（相等 / 不等）
* **`JE`** (Jump if Equal，相等)：差值为 0 $\rightarrow$ **$ZF = 1$**
* **`JNE`** (Jump if Not Equal，不等)：差值非 0 $\rightarrow$ **$ZF = 0$**

---

#### 2. 无符号比较（看借位 $CF$）
无符号数做减法 $A - B$：
* **`JB`** (Jump if **Below**，小于)：不够减，产生借位 $\rightarrow$ **$CF = 1$**。
* **`JAE`** (Jump if **Above or Equal**，大于等于)：`JB` 的反面，无需借位 $\rightarrow$ **$CF = 0$**。
* **`JBE`** (Jump if **Below or Equal**，小于等于)：产生借位 或 相等 $\rightarrow$ **$CF = 1 \lor ZF = 1$**。
* **`JA`** (Jump if **Above**，严格大于)：无借位 且 不相等 $\rightarrow$ **$CF = 0 \land ZF = 0$**。

---

#### 3. 带符号比较（看 $SF \oplus OF$）
带符号减法 $A - B$，判断大小的核心是看“真实差值的正负”：
* **若没有溢出（$OF = 0$）**：$SF$ 就是真实结果的正负。若 $A < B$，差为负，则 $SF = 1$。
* **若发生了溢出（$OF = 1$）**：说明差值的符号被硬件反转了（例如负数减正数下溢变正，此时本应 $A < B$，但 $SF = 0$）。
* **核心数学结论**：**$SF \oplus OF$ 永远等于“未溢出时的真实符号”**！
  * 当 $A < B$ 时，必有 **$SF \oplus OF = 1$**（即 $SF \ne OF$）。
  * 当 $A \ge B$ 时，必有 **$SF \oplus OF = 0$**（即 $SF = OF$）。

基于此推导指令：
* **`JL`** (Jump if **Less**，小于)：真实结果为负 $\rightarrow$ **$SF \oplus OF = 1$**（$SF \ne OF$）。
* **`JGE`** (Jump if **Greater or Equal**，大于等于)：真实结果非负 $\rightarrow$ **$SF \oplus OF = 0$**（$SF == OF$）。
* **`JLE`** (Jump if **Less or Equal**，小于等于)：小于 或 相等 $\rightarrow$ **$(SF \oplus OF = 1) \lor ZF = 1$**。
* **`JG`** (Jump if **Greater**，严格大于)：大于等于 且 不相等 $\rightarrow$ **$(SF \oplus OF = 0) \land ZF = 0$**。

---

### 四、 总结口诀表

| 比较类型      | 助记符关键字                     | 判定标志位                  | 核心判断条件                                          |
| :-------- | :------------------------- | :--------------------- | :---------------------------------------------- |
| **相等/不等** | `E` / `NE`                 | $ZF$                   | $ZF=1$ 为等，$ZF=0$ 为不等                            |
| **无符号数**  | `A` (Above) / `B` (Below)  | $CF$（与 $ZF$）           | 小于看借位（$CF=1$），大于看无借位且非零（$CF=0 \land ZF=0$）      |
| **带符号数**  | `G` (Greater) / `L` (Less) | $SF \oplus OF$（与 $ZF$） | 小于看异号（$SF \ne OF$），大于看同号且非零（$SF=OF \land ZF=0$） |
