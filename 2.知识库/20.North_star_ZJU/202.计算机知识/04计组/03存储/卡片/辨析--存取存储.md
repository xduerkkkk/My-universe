### 一、核心概念辨析：存取时间 vs 存取周期

在 408 的考查中，**“存取周期”与“存储周期”是同一个概念的不同称呼**（英文均为 Memory Cycle Time，符号常记为 $T$ 或 $T_m$）。

#### 1. 存取时间（Memory Access Time，记为 $T_A$）
* **定义**：从 CPU 发出有效地址和读/写命令开始，到数据线上的数据稳定有效（或写入操作完成）为止的时间。
* **物理本质**：纯粹的信号传输和门电路翻转延迟，衡量的是**“单次访问有多快”**。

#### 2. 存取周期 / 存储周期（Memory Cycle Time，记为 $T$）
* **定义**：存储器进行**连续两次独立**的读或写操作所必需的**最小时间间隔**。
* **物理本质**：操作时间 + 状态恢复时间，衡量的是**“访问频次能有多高”**。

#### 3. 二者的关系
$$\text{存取周期 } T = \text{存取时间 } T_A + \text{恢复时间 } T_{\text{恢复}}$$

* **条件与边界**：必然满足 $T > T_A$。
* **为何必须有恢复时间？**
  * 以 DRAM 为例：DRAM 依靠电容存储电荷，读出过程是“破坏性读出”（电荷会被放掉），在读出后芯片必须自动执行一次内部重写以恢复电荷；
  * 此外，位线预充电（Bit-line Precharge）也需要时间。这段时间内存储体处于“忙（Busy）”状态，禁止接收下一次访问请求。

---

### 二、 总线传输周期（Bus Cycle，记为 $r$ 或 $\tau$）

#### 1. 定义
CPU 通过系统总线向存储器传输一个存取字（读出或写入）所占用的时间，通常包含送地址、发控制信号、传输数据及总线握手。

#### 2. 它与存取周期 $T$ 的关系及题目推导
在实际系统中，存储体内部的电路动作（$T$）远慢于总线上的信号传输（$r$），即 $T \gg r$。

**本题考点机制推导（低位交叉流水线）**：
* 设有 $m$ 个存储体，采用低位交叉编址。
* CPU 以流水线方式工作：每隔一个总线传输周期 $r$，就向下一个存储体发起一次读/写请求。
* 当轮询了一圈、再次轮到同一个存储体时，总共消耗了 $m \times r$ 的时间。
* **无冲突流水线成立的充要条件**：当 CPU 再次访问该存储体时，该存储体上一次的存取周期 $T$ 必须已经彻底完成（已经度过了恢复期）。
  $$m \cdot r \ge T \implies m \ge \frac{T}{r}$$
* 代入题目数值：
  $$m \ge \frac{110\text{ ns}}{10\text{ ns}} = 11$$
  因此存储体数必须**大于或等于 11**（选 D）。若小于 11，流水线就会因为存储体未恢复而发生等待（冲突）。

---

### 三、 刷新周期（Refresh Period，专属于 DRAM）

#### 1. 定义
DRAM 单元的栅极电容漏电不会立刻丢失数据，电荷通常能维持毫秒级。**刷新周期**是指对 DRAM 的所有存储单元完整重写一遍的**最大允许时间间隔**（通常由芯片规格给出，常见值为 2ms、4ms 或 64ms）。

#### 2. 它与“存取周期 $T$”的关系
* **单行刷新耗时**：刷新是一行一行进行的。刷新本质上是“读出后原样重写”，因此**刷新一行所耗费的时间通常等于 1 个存取周期 $T$**（约几十到上百纳秒）。
* **宏观周期关系**：
  $$\text{刷新周期（如 } 2\text{ms）} \gg \text{存取周期 } T\text{（如 } 110\text{ns）}$$
  一个刷新周期（2ms）内，包含成千上万个存取周期。系统需要在这些存取周期中安排出一小部分用于刷新各行（集中刷新会有“死区”，分散刷新把每个读写周期延长为 $2T$，异步刷新将刷新间隔分散在 2ms 内部）。

### 四、 综合总结对照表

| 周期/时间术语        | 英文标识             | 物理意义                   | 典型时间量级                  | 核心公式/制约关系                                 |
| :------------- | :--------------- | :--------------------- | :---------------------- | :---------------------------------------- |
| **存取时间**       | $T_A$            | 单次读出或写入所需的时间延迟         | $10 \sim 50\text{ ns}$  | $T_A < T$                                 |
| **存取周期（存储周期）** | $T$              | 同一存储体**连续两次访问**的最小间隔   | $50 \sim 150\text{ ns}$ | $T = T_A + T_{\text{恢复}}$                 |
| **总线传输周期**     | $r$              | 总线上发送一个数据字所需的时间        | $5 \sim 20\text{ ns}$   | $r \ll T$；流水线要求 $m \ge \frac{T}{r}$       |
| **刷新周期**       | $t_{\text{ref}}$ | DRAM 所有单元完成一轮刷新的最大允许间隔 | $2 \sim 64\text{ ms}$   | 刷新单行时间 $\approx T$；$t_{\text{ref}} \gg T$ |
