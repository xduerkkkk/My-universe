# 作文背诵训练

> 素材来源：[[小作文背诵]]（7篇小作文母版）、[[大作文模板]]（3篇大作文母版）。小作文以小作文母版为准，大作文以大作文母版为准；母版修改后再同步对应内容。
> 本页实际有 **10类骨架、43个固定句编号提示、84个短语编号提示**。一个固定句提示可能包含几种写法，不等于只有43个英文句子。本文的“2C道歉信”对应小作文母版中的“3C道歉信”，只是编号不同。

## 〇、怎么用

**按下方完整计划和逐日表执行，不再临时挑“背哪组”。** 先遮答案回忆，再对照，只补卡住的地方；不先通读到熟悉再开始测。本轮从11月9日起排，不追补旧打卡日期。

- **骨架**：只看题目／类型，说出每段做什么，约1—3分钟，不逐字默写中文。
- **固定句**：看中文，闭卷写英文；槽位填一个自己会的内容。新条目先尝试一次，错的对照关键位置后再遮住写一次，不为当天背到完美反复拖时长。
- **短语**：看中文，闭卷写英文，重点检查介词、动词形式、搭配与拼写。原有 `@`、`！` 保留；下表已经优先安排相关复测。
- **标记**：想不出、靠提示或写错就在原条目后加 `❌`。同一条在两个不同日期都独立写对，再去掉标记；刚看完答案立即重写不算第二次过关。
- **输出**：11日小作文、14日大作文，都先不翻模板、不搜索，写完再查。题目换了就改内容，不能把不适用的图画描述、人物数量或句子主语硬塞进去。

### 每天做到哪里就停

- **普通首测／背诵日约35—45分钟**：复测5—7分钟；骨架1—3分钟；新增固定句与短语约20—30分钟；最后用指定句填实并标记。复测只改关键错处，不把全组重抄。
- **11日约30—35分钟**：复测＋15分钟小作文＋约10分钟核对修改，不再加新增条目。
- **14日约40—45分钟**：复测控制在约5分钟＋30分钟大作文＋约10分钟核对修改，不再加新增条目；仍占原英语时段，不额外延长整晚。
- **先处理真错项**：最近一次输出若有 `❌`，优先用最多3个错项替换当天固定句复测栏的同等数量条目，不额外叠加；不足则用表中原条目补足。其余错项保留原标记，后续接续，不强求每天清空。
- **当天新内容的执行顺序**：先固定句，再短语。达到时间上限仍未做完，就在首个未完条目标“下次续”，下一个普通背诵日先接这里，并减少等量新增；不在11／14日输出日硬补，也不次日双倍背。
- **不因一时顺利就退出**：复测不翻答案、关键语法和用词能独立写对才算通过。意思准确、语法正确的等价表达可保留，不因与母版非逐字一致就算错；专门背的固定搭配、倒装和虚拟语气要检查对应形式。

## 一、骨架链（只看标题，说出每段槽位）

> [!question]- 1A 建议信·对私（给朋友）
> - P1：收到来信（询问 X）→ 写信分享两条建议
> - P2：建议 1 做法 → 建议 1 好处 → 建议 2 做法 → Beyond 好处 A, also 好处 B, which 长远效果
> - P3：希望有用 → 祝愿

> [!question]- 1B 建议信·对公（给校长/部门）
> - P1：引起关注 + 就 X 提两条建议
> - P2：同 1A，句式换成对公版（it would be highly beneficial if you could / steps should also be taken to）
> - P3：希望采纳 → 感谢时间

> [!question]- 2A 邀请信
> - P1：寒暄 → 邀请参加 X
> - P2：活动时间地点 + 目的 → 鉴于你的专长，荣幸请你做 Y → Beyond A, also B, which 有益且有启发
> - P3：请确认时间 → 祝愿

> [!question]- 2B 感谢信
> - P1：寒暄 → 感谢你在 X 中的支持
> - P2：回顾：最打动我的是你的鼓励 → 具体：正是你做了… → 要不是你的指导，我不可能…（虚拟语气）
> - P3：再次感谢 → 祝愿

> [!question]- 2C 道歉信
> - P1：寒暄 → 道歉：无法按计划做 X
> - P2：遗憾：因突发事务调整日程 → 具体原因，与约定冲突 → 补救：能否改到… → 届时充分准备
> - P3：再次道歉 → 请确认时间 → 祝愿

> [!question]- 3 申请信
> - P1：正式申请 X 职位（某渠道发布）
> - P2：看完要求，确信自己有竞争力 → Beyond 技能 1, also 能力 2 → 曾任…, which 带来处理突发挑战的经验
> - P3：若给面试机会，乐意详谈 → 感谢
> - 推荐信：P1 换成 It is my great pleasure to write this letter to strongly recommend…，P2 把 I 换成 He/She

> [!question]- 4 Notice 通知
> - 格式：居中 NOTICE + 右上日期，右下落款写部门
> - P1：本通知旨在为[群体]宣布 X → 细节如下
> - P2：时间地点 + 目的 → 包含系列活动；Beyond A, also B → 请记住：参与者须…
> - P3：详情联系邮箱 → 期待参与

> [!question]- 大 1 个人品质（双图对比）
> - P1：双图对比引出 → 图 1 消极 whereas 图 2 积极 → 寓意：凸显 X 的重要性
> - P2：共识：X 是 Y 的基石 → 反面：面对挑战退缩只会陷入… → 正面：Conversely, by…, beyond A, also B → 谚语
> - P3：综上，大学生必须… → Only in this way can we…

> [!question]- 大 2 社会文化（单图群像）
> - P1：单图场景引出 → 具体：面带笑容…，字幕 → 寓意
> - P2：共识：X 是 Y 的基石 → 几个原因 → For one thing 生活水平提高、追求精神 → For another, beyond A, also B
> - P3：综上，应采取措施… → Only in this way can we…

> [!question]- 大 3 科技双刃剑（讽刺单图）
> - P1：讽刺场景 → 具体：不面对面交流而沉浸虚拟世界 → 寓意：警醒过度依赖
