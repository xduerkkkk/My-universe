sensible。来源于“make sense（有道理）”。指一个人做事有分寸、很清醒。
剩下全是感觉/情绪家庭

## - **sensitive**: (adj.) **敏感的；灵敏的；体贴的**
    
- 💡 辨析：指对外界刺激（情感、光、温度等）反应很快。可以指人“玻璃心/敏感”，也可以指仪器“灵敏”。
	
- 📌 搭配：highly sensitive to criticism (对批评高度敏感) / sensitive information (敏感信息)
        
##   **sentiment**: (n.) **情绪；观点；感情色彩**
    
    - 💡 辨析：考研经济类文章极高频词！常指大众或市场的整体情绪/态度。
        
    - 📌 搭配：market sentiment (市场情绪) / public sentiment (民意)
        
##    **sentimental**: (adj.) **伤感的；多愁善感的；感情用事的**
    
    - 💡 辨析：带有强烈的感情色彩，甚至有点“怀旧、矫情”的意味。
        
    - 📌 搭配：sentimental value (情感价值——比如奶奶留下的旧手表，不值钱但有 sentimental value)
        
##   **sensation**: (n.) **感觉；知觉；轰动（事件）**
    
    - 💡 辨析：相比 feeling，它更强调“感官上的刺激”或者引发了大众的“感官震撼”。
        
    - 📌 搭配：a burning sensation (灼烧感) / an internet sensation (网络红人/轰动全网的事)
# Build/Struct (建筑与基建)

construct，construction 倾向于搬砖盖楼
infrastructures 是特定的，基础建设，
architecture 就有点学术有点文艺，侧重于**“设计、艺术和宏观架构”**。计算机文章里指“计算机架构”。
- **construct**: (v.) **建造；构筑；创立（理论等）**
    
    - 💡 辨析：con (共同) + struct (建造) -> 把各个部分拼在一起建起来。不仅指建大楼，考研里常考**“构筑一个理论/模型”**。
        
    - 📌 搭配：construct a bridge (建桥) / construct a theory (构建理论)
        
- **construction**: (n.) **建设；建筑物；结构**
    
    - 📌 搭配：under construction (正在建设中)
        
- **infrastructure**: (n.) **基础设施；基础建设**
    
    - 💡 辨析：**infra- (在... 下面)** + structure (建筑) -> 建在城市底部的设施（如水电网、道路、通信）。考研社会经济类文章的核心词汇。
        
    - 📌 搭配：invest in infrastructure (投资基建)
        
- **architecture**: (n.) **建筑学；建筑风格；体系结构**
    
    - 💡 辨析：它不侧重于“搬砖盖楼”的物理过程，而是侧重于**“设计、艺术和宏观架构”**。计算机文章里指“计算机架构”。
        
    - 📌 搭配：modern architecture (现代建筑风格) / software architecture (软件架构)

- **inclusive**: (adj.) **包含全部的；包容的**
    
    - 💡 辨析：**in (里面)** + clus (关) -> 把大家都关在同一个圈子里 -> 包容的。现代外企最讲究的文化就是 Diversity & Inclusion (多元与包容)。
        
    - 📌 搭配：an inclusive society (包容的社会) / all-inclusive (全包的/一应俱全的)
        
- **exclusive**: (adj.) **独有的；排外的；高档的**
    
    - 💡 辨析：**ex (外面)** + clus (关) -> 把其他人都关在门外，只有 VIP 能进 -> 独享的/昂贵的。
        
    - 📌 搭配：exclusive interview (独家专访) / mutually exclusive (相互排斥的)
        

**【拉伸阵营：tend/tens = stretch (伸展)】**

- **extensive**: (adj.) **广泛的；大量的；广阔的**
    
    - 💡 辨析：**ex (向外)** + tens (拉伸) -> 向外不断延伸 -> 范围很广的。
        
    - 📌 搭配：extensive reading (泛读) / extensive damage (大面积的破坏)
        

**【花费阵营：pend/pens = pay (支付)】**

- **expensive**: (adj.) **昂贵的**
    
    - 💡 辨析：**ex (出)** + pens (钱) -> 把钱交出去 -> 费钱的。

## Exec-执行
execute
executive

- **execute**: (v.) **执行；实施；处决（死刑）**
    
    - 💡 辨析：把计划从头到尾“顺”下来 -> 执行。古代执行君王的命令往往是杀头，所以引申出“处死”。
        
    - 📌 搭配：execute a plan (执行计划) / execute a prisoner (处决囚犯)
        
- **executive**: (n./adj.) **主管；高管；行政部门 / 执行的；高级的**
    
    - 💡 辨析：负责“执行 (execute)”公司战略的人。
        
    - 📌 绝佳记忆法：**CEO** 的全称就是 Chief **Executive** Officer (首席执行官)。带 executive 的东西往往都很高级，比如 executive suite (总统套房/行政套房)。
        
    - 📌 搭配：senior executives (公司高层) / executive power (行政权)
        
    - 🔗 词汇扩展：**execution** (n. 实行；执行力；死刑)。例如：Good strategy, poor execution. (战略很好，执行力太差。)

# Mono- / -ous 家族

**【Mono- (单一) 阵营】**

##    **monotonous**: (adj.) **单调的；乏味的；毫无变化的**
    
- 💡 辨析：**mono (单一)** + **ton (tone 音调)** + ous -> 从头到尾只有一个音调 -> 听着让人想睡觉 -> 单调乏味的。
	
- 📌 搭配：a monotonous voice (单调的声音) / monotonous work (枯燥的工作)
	
##   **monopoly**: (n.) **垄断；独占**
    
- 💡 辨析：**mono (单一)** + **poly (卖)** -> 市场上只有一个人在卖东西 -> 垄断。
	
- 📌 搭配：have a monopoly on... (拥有对... 的垄断权)

##   **anonymous**: (adj.) **匿名的；无名的**
    
- 💡 辨析：**an- (无/没有)** + **onym (name 名字)** + ous -> 没有写名字的。
	
- 📌 搭配：an anonymous letter (匿名信) / an anonymous donor (匿名捐款人)
        
##   **spontaneous**: (adj.) **自发的；自然的；（人）率性的**
    
- 💡 辨析：指事情**没有经过事先计划**，自然而然就发生了。
	
- 📌 搭配：spontaneous applause (自发的热烈掌声)
        
    
##    **simultaneous**: (adj.) **同时发生的；同步的**

# Magn- (大) vs Stitut- (站立/建立)
magnitude
magnificent
substitute
constitute
constituent
constitution

**【Magn- 阵营 (大 / 宏伟)】**

- **magnitude**: (n.) **巨大；重要性；（地震的）震级；（恒星的）星等**
    
    - 💡 辨析：**magn** (大) + itude (状态)。指规模或重要性大得惊人。
        
    - 📌 搭配：an earthquake of magnitude 7.0 (7 级地震) / the magnitude of the problem (问题的严重性/巨大程度)
        
- **magnificent**: (adj.) **宏伟的；壮丽的；极好的**
    
    - 💡 辨析：**magn** (大) + fic (做/制造) + ent -> 造得很大的 -> 宏伟的。
        
    - 📌 搭配：a magnificent building (宏伟的建筑) / magnificent scenery (壮丽的景色)
        

**【Stitut- 阵营 (站立 / 建立)】** 词根 `stit/stitut` = stand (站)。

- **constitute**: (v.) **组成；构成；设立**
    
    - 💡 辨析：**con** (共同) + stitute (站) -> 大家站在一起 -> 构成/组成。
        
    - 📌 搭配：Women constitute 50% of the workforce. (女性占劳动力的 50%。)
        
- **constituent**: (n. / adj.) **选民；成分 / 构成的**
    
    - 💡 辨析：构成一个整体的“小单元”，用于政治就是“选民”（构成选区的基本单位），用于化学就是“成分”。
        
    - 📌 搭配：a constituent assembly (立宪会议) / chemical constituents (化学成分)
        
- **constitution**: (n.) **宪法；章程；体质**
    
    - 💡 辨析：把国家立国之本“建立 (constitute)”起来的文件，就是《宪法》。用于人身上，就是身体的“构成”，即体质。
        
    - 📌 搭配：the US Constitution (美国宪法) / a strong constitution (强壮的体格)
        
- **substitute**: (v. / n.) **代替；替代品；替补（队员）**
    
    - 💡 辨析：**sub** (在下面/作为后备) + stitute (站) -> 站在下面随时准备顶上去的人 -> 替补/替代。
        
    - 📌 搭配：substitute A for B (用 A 替代 B) / a sugar substitute (代糖)
        
    - 🔗 词汇扩展：**institution** (n. 机构/制度 —— in+stitut，建立在内部的体系)
