# 05 — 主题场景·考研高频语境词

> 按考研英语一真题的文章主题归类。法律、政治、经济、学术、社会 — 每个场景下，你需要瞬间反应出这些词的精确差异。
> 前四篇笔记按词根和拼写辨析，本篇按**考场实战语境**重新串联。

## ⚖️ 一、法律场景（Law & Court）

考研阅读常涉及美国法律体系、侵权法、知识产权等话题。以下词群决定了你对整篇文章的理解。

### 法庭角色三角

```
        法官 (judge/justice)
              ↑
     ┌────────┴────────┐
  原告/控方           被告/辩方
 plaintiff           defendant
 (prosecutor)        (the accused)
```

| 词                | 核心义    | 记忆锚点                          |
| ---------------- | ------ | ----------------------------- |
| **defendant**    | 被告；被告方 | defend(防守) → 在法庭上防守自己的人       |
| **plaintiff**    | 原告     | 控告别人的人（考研补充词）                 |
| **offender**     | 罪犯；冒犯者 | offend(冒犯) → 做了坏事的人           |
| **defender**     | 捍卫者    | 非法律用语！指"某主义的捍卫者"或体育"后卫"       |
| **convict** (v.) | 定罪     | con + vict(赢) → 控方在法庭上"征服"了被告 |
| **convict** (n.) | 囚犯     | 被法律征服的人                       |
| **evict**        | 驱逐（房客） | e(向外) + vict(征服) → 用法律手段把你踢出去 |
|                  |        |                               |

### 法庭程序术语

| 词                | 核心义         | 语境用法                                                              |
| ---------------- | ----------- | ----------------------------------------------------------------- |
| **verdict**      | 裁决          | ver(真实) + dict(说) → 说出真相。`The jury returned a verdict of guilty.` |
| **testify**      | 作证          | `testify in court` 出庭作证                                           |
| **prosecute**    | 起诉；检举       | pro(向前) + secu(跟随) → 在法庭上紧追不放                                     |
| **conviction**   | 定罪；坚定信念     | ① 法律层：定罪 ② 精神层：你的思想被某种道理彻底征服                                      |
| **jury**         | 陪审团         | `the jury finds sb. guilty`                                       |
| **jurisdiction** | 司法权；管辖权     | juris(法) + dict(说) + ion → "法律说了算的地方"                             |
| **judicial**     | 法庭的；司法的；公正的 | `judicial system` 司法系统                                            |
| **justice**      | 正义；司法；法官    | `bring sb. to justice` 绳之以法                                       |
| **justify**      | 证明…是正当的     | 🔥 写作高频。`justify the cost`                                        |
penal
### 争议与纠纷 — 精确层级

| 词                      | 侧重点                       | 程度   | 例句                                        |
| ---------------------- | ------------------------- | ---- | ----------------------------------------- |
| **debate**             | 正式、有理有据的双方观点陈述            | 最理性  | `a heated debate on education reform`     |
| **dispute**            | 具体两人/两公司/两国之间的吵架、打官司、领土争端 | 中等激烈 | `labor dispute`(劳资纠纷) / `border dispute`  |
| **controversy**        | 公众意见不一，持续时间长，涉及社会/道德话题    | 广泛   | `the controversy over AI ethics`          |
| **conflict**           | 激烈的、甚至肢体/武装的对抗；利益根本对立     | 最激烈  | `armed conflict` / `conflict of interest` |
| **contentious** (adj.) | 有争议的（高分形容词）               | —    | `a contentious issue`                     |

## 🏛️ 二、政治/制度场景（Politics & Institutions）

### 政体与制度

| 词 | 核心义 | 考点 |
|---|---|---|
| **federal** | 联邦的 | FBI = **Federal** Bureau of Investigation |
| **regime** | 政体；制度（常带贬义） | `the old regime` 旧政权 |
| **democracy** | 民主 | demo(人民) + cracy(统治) |
| **constitution** | 宪法；章程；体质 | 把国家立国之本"建立"起来的文件 |
| **legislation** | 立法；法规（集合名词） | `introduce new legislation` |
| **autonomy** | 自治；自主权 | auto(自己) + nomy(法律/管理) |
| **authority** | 权威；官方；专家 | 来自 author(作者/创始人) — 谁创造了，谁就有话语权 |

### 选举与代表

| 词 | 核心义 |
|---|---|
| **constituent** | 选民；成分。构成一个整体的"小单元" — 政治=选民，化学=成分 |
| **constituent assembly** | 立宪会议 |
| **candidate** | 候选人 |

## 💰 三、经济/商业场景（Economy & Business）

### 公司与产业

| 词 | 核心义 | 考点辨析 |
|---|---|---|
| **corporation** (n.) | 公司/企业（实体） | `Microsoft is a large corporation.` |
| **corporate** (adj.) | 公司的；法人的 | `corporate culture` 企业文化 / `corporate revival` 企业复苏 |
| **cooperate** (v.) | 合作 | co(一起) + operate(操作) |
| **manufacturing** (n.) | 制造业（行业产业） | `lump manufacturing and services together` |
| **manufacture** (v./n.) | 制造（动作或产品） | 区别于 manufacturing |
| **monopoly** (n.) | 垄断；独占 | mono(单一) + poly(卖) → 只有一个人在卖 |

### 市场与趋势

| 词 | 核心义 | 语境用法 |
|---|---|---|
| **prosperous** (adj.) | 繁荣的；富裕的 | `a prosperous economy` |
| **prosperity** (n.) | 繁荣 | — |
| **prospect** (n.) | 前景；展望 | `career prospects` / `economic prospects` |
| **subsidise** (v.) | 资助；给补贴 | `The government subsidises public transport.` |
| **subsidy** (n.) | 津贴；补贴 | — |
| **revenue** (n.) | 收入；税收 | re(回) + ven(来) → 回来的钱 |
| **aggregate** | 总计；总需求 | `aggregate demand` 总需求 / `in the aggregate` |
| **market sentiment** | 市场情绪 | 🔥 考研经济类文章极高频！ |

### 竞争与剥削

| 词 | 核心义 | 语境用法 |
|---|---|---|
| **competitive** | 竞争的；有竞争力的 | `a highly competitive market` |
| **competent** | 胜任的；有能力的 | `be competent to do sth.` |
| **exploit** | 开发/利用(中性)；剥削(贬义) | `exploit the potential` / `exploit cheap labor` |
| **friction** | 摩擦；冲突 | `trade friction` 贸易摩擦 |

## 🎓 四、学术/科技场景（Academic & Scientific）

### 论点与论证

| 词 | 核心义 | 考研实战定位 |
|---|---|---|
| **controversy** | 争议 | 涉及社会道德话题的公众争议 |
| **debate** | 辩论 | 正式、有理有据的观点陈述 |
| **perspective** | 视角；观点 | `from a historical perspective` 从历史视角看 |
| **evidence** | 证据 | e(出) + vid(看) + ence → 能看出来的事实 |
| **implicit** | 含蓄的；暗示的 | `implicit assumption` 隐含假设 |
| **explicit** | 明确的 | `explicit instructions` |
| **assume** | 假设 | 中性 |
| **presume** | 假定；擅自 | 偏"基于某依据就认为/甚至擅自" |

### 理论构建

| 词                  | 核心义         | 语境用法                         |
| ------------------ | ----------- | ---------------------------- |
| **construct** (v.) | 构筑（理论/模型）   | 考研里常指建理论而非盖楼                 |
| **philosophy**     | 哲学；人生观      | `management philosophy` 管理理念 |
| **psychology**     | 心理学         | p 不发音                        |
| **physiology**     | 生理学         | 注意不是心理学！                     |
| **sophisticated**  | 老练的；复杂的；精密的 | `sophisticated technology`   |
| **intellectual**   | 智力的；知识分子    | `intellectual property` 知识产权 |

### 数据分析

| 词 | 核心义 | 语境用法 |
|---|---|---|
| **magnitude** | 巨大；重要性；震级 | `the magnitude of the problem` |
| **fraction** | 小部分；分数 | `a fraction of a second` 一瞬间 |
| **aggregate** | 合计；总数 | `in the aggregate` |
| **assessment** | 评估 | `make an assessment` |
| **assess** (v.) | 评估；评定 | ad(向) + sess(坐) → 坐在旁边观察你 |

## 🫂 五、社会/情感场景（Society & Emotion）

### 情绪与态度

| 词               | 核心义        | 语境                                              |
| --------------- | ---------- | ----------------------------------------------- |
| **sentiment**   | 情绪；观点；感情色彩 | `public sentiment` 民意 / `market sentiment` 市场情绪 |
| **sensitive**   | 敏感的；灵敏的    | `highly sensitive to criticism`                 |
| **sentimental** | 伤感的；多愁善感的  | `sentimental value` 情感价值                        |
| **sensation**   | 感觉；知觉；轰动   | `an internet sensation` 网红/轰动全网                 |
| **frustration** | 挫败；灰心      | —                                               |

### 社会关系

| 词               | 核心义     | 语境                       |
| --------------- | ------- | ------------------------ |
| **solidarity**  | 团结一致    | 集体词 → 像固体一样团结            |
| **solitary**    | 孤独的；唯一的 | 个体词 → 只有这一个              |
| **solitude**    | 独处；幽静   | 中性/褒义，不等于 lonely         |
| **segregation** | 隔离；种族隔离 | se(分开) + greg(群) → 把人群分开 |
| **inclusive**   | 包容的     | `an inclusive society`   |
| **exclusive**   | 排他的；独有的 | `exclusive club` 高级会所    |

## 🧠 六、考研真题中的熟词生义（Bonus）

以下是在真题中容易被"常用义"坑掉的词，附真实语境。

| 词                | 你的直觉 | 真题中的真正含义                                  | 语境                                  |
| ---------------- | ---- | ----------------------------------------- | ----------------------------------- |
| **exploit**      | 剥削   | 也常考"开发/利用"（中性）                            | `exploit the potential`             |
| **conviction**   | 定罪   | 也考"坚定信念"                                  | `political conviction`              |
| **constitution** | 宪法   | 也考"体质"                                    | `a strong constitution`             |
| **capital**      | 首都   | 也考"资本" / "大写字母"                           | `human capital` 人力资本                |
| **doormat**      | 门垫   | 隐喻"受气包"                                   | `Don't be a doormat.`               |
| **shed**         | 小棚子  | 更常考"shed light on"(解释) / "shed tears"(流泪) | —                                   |
| **literally**    | 字面上  | 口语"毫不夸张地说/简直"                             | 超高频口头禅                              |
| **cradle**       | 摇篮   | 引申"发源地"                                   | `the cradle of civilization`        |
| **crow**         | 乌鸦   | 引申"得意洋洋地夸口/吹牛"                            | 想象公鸡伸长脖子大叫                          |
| **riddle**       | 谜语   | 原意"筛子" → 动词"布满窟窿"                         | `The car was riddled with bullets.` |
| **lump**         | 块    | 常考 `lump together` = 归并/混为一谈              | —                                   |
| **throne**       | 王座   | 你的感悟："Throne 的路上充满了 thorn"                | —                                   |
