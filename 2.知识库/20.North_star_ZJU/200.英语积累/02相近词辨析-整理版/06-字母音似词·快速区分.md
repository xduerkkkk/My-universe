# 06 — 字母音似词·快速区分

> 这些词组没有统一的词根，纯粹因为**字母排列相似**或**发音相近**而容易混淆。
> 适合考前快速扫一遍。每个组一句话锁定区分点。

---

## 一、-umble 结尾 →「笨拙、摇晃」

英语中 -umble 结尾常带有"笨拙/摇晃"的语感。

| 词 | 核心义 | Native 画面 |
|---|---|---|
| **tumble** | 滚落；暴跌 | 人在楼梯上失去重心，翻滚着摔下去。价格"跳水"也用 tumble |
| **fumble** | 摸索；笨拙地弄 | 穿厚手套在口袋里找钥匙。说话吞吞吐吐 = `fumble for words` |
| **humble** | 谦卑的；低微的 | 来自 humus(泥土/地面)。姿态放得很低，贴近地面 |
| **tremble** | 颤抖 | 因恐惧/寒冷/虚弱而发抖。区别于 vibrate(机械振动) |
| **thumb** | 大拇指 | 五个手指里最粗最笨的。`all thumbs` = 笨手笨脚 |

## 二、cr- 开头四兄弟

| 词 | 核心义 | 记忆锚点 |
|---|---|---|
| **crawl** | 爬行；缓慢移动 | 婴儿在地上爬。`Traffic crawls.` 交通拥堵如爬 |
| **crew** | 全体工作人员 | 船/飞机上穿制服的团队 |
| **crow** | 乌鸦；得意地夸口/吹牛 | 🐓 公鸡伸长脖子大叫 → 吹牛 |
| **clown** | 小丑 | 红鼻子、滑稽动作 |

---

## 三、sh- 开头 — 光与影

| 词 | 核心义 | 记忆锚点 |
|---|---|---|
| **shed** | 脱落；流出；小棚子 | 由内向外丢弃。`shed tears` 流泪 / `shed light on…` 解释/阐明 |
| **sheer** | 纯粹的；极薄的；垂直的 | 核心是"极其彻底、没有任何遮掩"。`sheer luck` 纯粹运气 / `a sheer cliff` 垂直悬崖 |
| **shade** | 阴凉处；阴影区域 | 模糊的"阴凉处"（vs shadow = 具体的影子） |

---

## 四、fr- 开头 — 破碎与芬芳

| 词 | 核心义 | 记忆锚点 |
|---|---|---|
| **frustration** | 挫败；灰心 | 来自 frustrate |
| **fraction** | 小部分；碎片；分数 | `a fraction of a second` 一瞬间 |
| **fracture** | 骨折；断裂 | X光片上的裂缝 |
| **fragment** | 碎片；片段 | 静态的"那片东西"。`a fragment of memory` |
| **friction** | 摩擦；冲突 | `trade friction` 贸易摩擦 |
| **fiction** | 虚构；小说 | `science fiction` |
| **fragrant** | 芳香的 | ⚠️ 不是破碎家族！来自"发出气味" |
| **pregnant** | 怀孕的 | ⚠️ 完全无关！pre(前)+gnatus(出生) → 出生之前的状态 |

## 五、th- 开头 — 王座 与 刺

| 词 | 核心义 | 你的感悟 |
|---|---|---|
| **throne** | 王座；王位 | Throne 的路上充满了 **thorn**（刺） |
| **thorn** | 刺；荆棘 | 名言：`Uneasy lies the head that wears a crown.` 欲戴王冠，必承其重 |

## 六、-lie 结尾 — 躺与谎言

| 词              | 核心义            | 词根拆解                                                              |
| -------------- | -------------- | ----------------------------------------------------------------- |
| **underlie**   | 位于…之下；是…的基础/起因 | under(下面) + lie(躺) → 躺在下面作为支撑                                     |
| **underlying** | 潜在的；根本的        | 🔥 极其高频。`the underlying cause`                                    |
| **belie**      | 掩饰；证明…是虚假的     | be(使) + lie(谎言) → 使之呈现假象。`Her calm face belied her inner terror.` |
| **overlie**    | 覆盖在…上面         | over + lie。多用于地质/物理覆盖                                             |

## 八、occupy 一家人

| 词                   | 核心义          | 考点                                         |
| ------------------- | ------------ | ------------------------------------------ |
| **occupy** (v.)     | 占据（空间/时间）；占领 | `occupy my mind` / `occupy a territory`    |
| **occupied** (adj.) | 被占用的；忙碌的     | 洗手间门上的"有人" / `keep oneself occupied`       |
| **occupation** (n.) | 职业；占领        | 比 job 更正式。`state your name and occupation` |

## 十、doormat & stove — 生活小意外隐喻

| 词           | 核心义    | 语境                                                |
| ----------- | ------ | ------------------------------------------------- |
| **doormat** | 门垫；受气包 | 在侵权法文章中指代"生活中的小意外"。口语：`Don't be a doormat.` 别当受气包 |
| **stove**   | 炉子     | 同上，也是文章里指代日常小意外的词                                 |

## 十一、democracy vs decorate — 长得像，无关

| 词             | 核心义 | 词源                   |
| ------------- | --- | -------------------- |
| **democracy** | 民主  | demo(人民) + cracy(统治) |
| **decorate**  | 装饰  | decor(美/装饰)          |

---

## 十二、fabric vs fabricate — 布料与谎言

| 词 | 核心义 | 记忆 |
|---|---|---|
| **fabric** | 织物；布料；结构 | `the fabric of society` 社会结构 |
| **fabricate** | 编造；伪造；制造 | 把"布料"编织成谎言 → 编造 |

---

## 十三、conspiracy vs conspicuous — 不是一家

| 词               | 核心义       | 词根                           |
| --------------- | --------- | ---------------------------- |
| **conspiracy**  | 阴谋；共谋     | con + spir(呼吸) → 一起密谋        |
| **conspicuous** | 显眼的；引人注目的 | con + spic(看) + uous → 大家都看到 |
contingency

## 十四、considerate vs considerable — 体贴 vs 大

| | considerate | considerable |
|---|---|---|
| **含义** | 体贴的 | 相当大的；可观的 |
| **后缀** | -ate(具有…特质) | -able(可…的→程度大) |

---

## 十五、perpetual vs perceptual — 永久 vs 感知

| 词 | 核心义 | 拆解 |
|---|---|---|
| **perpetual** | 永久的；持续的 | per(完全) + pet(追求) + ual → 一直在追求 |
| **perceptual** | 感知的 | per(穿透) + cept(拿) + ual → 穿透拿到 → 感知 |

---

## 十六、arouse vs rouse — 唤起 vs 唤醒

| 词 | 核心义 | 搭配 |
|---|---|---|
| **arouse** | 唤起；激起 | a(加强) + rouse。更常接"兴趣/情绪"。`arouse interest` |
| **rouse** | 唤醒；激起 | `rouse from sleep` 从睡梦中叫醒 |

---

## 十七、presumably vs presume vs assume

| 词              | 核心义   | 区别               |
| -------------- | ----- | ---------------- |
| **presumably** | 大概；想必 | 副词，推测口吻          |
| **presume**    | 假定；擅自 | 偏"基于某依据就认为/甚至擅自" |
| **assume**     | 假设；认为 | 中性，最常见的"假设"      |


---

## 十八、spontaneous vs simultaneous — 考研同框陷阱

| 词 | 核心义 | 记忆诀窍 |
|---|---|---|
| **spontaneous** | 自发的；自然的；率性的 | spon- 像 sponge(海绵) → 自己吸水膨胀 → 自发 |
| **simultaneous** | 同时发生的；同步的 | simul- 像 same → 同一个时间 → 同时 |

> 📌 考研英语最喜欢把这两个放在一起考！

---

## 十九、subsequent vs consequent — 时间 vs 逻辑

| 词 | 核心义 | 区分 |
|---|---|---|
| **sequence** | 顺序；序列 | 纯粹的先后的跟随 |
| **subsequent** | 随后的；后来的 | **时间上的跟随**。sub(后) + sequ(跟随) |
| **consequent** | 作为结果的 | **逻辑上的跟随**。con(随着) + sequ → 因果。`consequently` 因此 |

---

## 二十、procession vs possession — 走 vs 坐

| 词 | 核心义 | 词根 |
|---|---|---|
| **procession** | 行列；队伍；游行 | pro(向前) + cess(走) → 向前走的一队人 |
| **possession** | 拥有；占有；财产 | pos(权力) + sess(坐) → 坐在金币上展示所有权 |

---

## 二十一、defendant vs plaintiff vs offender — 法庭三兄弟

| 词 | 核心义 | 一句话区分 |
|---|---|---|
| **defendant** | 被告 | defend(防守) → 在法庭防守自己的人 |
| **plaintiff** | 原告 | 控告别人的人（补充词） |
| **offender** | 罪犯；冒犯者 | offend(冒犯) → 做了坏事的人 |

---

## 二十二、Syndrome vs Symptom vs Symphony vs Symposium — syn- 家族

| 词               | 核心义                    |
| --------------- | ---------------------- |
| **syndrome**    | 综合症；典型表现               |
| **symptom**     | 症状；征兆                  |
| **symphony**    | 交响乐（sym-一起 + phon声音）   |
| **symposium**   | 研讨会；专题论文集              |
| **sympathy**    | 同情；赞同（sym-一起 + path感情） |
| **sympathetic** | 同情的；赞同的                |
