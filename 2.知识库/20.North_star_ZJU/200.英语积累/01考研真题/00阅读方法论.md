# 真题阅读训练系统

> **本目录唯一入口。** 原始痕迹保留原貌；诊断只沉淀在 [[05认知画像]]。

## 1. 文件分工

| 用途 | 文件 | 角色 |
|---|---|---|
| 复盘入口 | [[05认知画像]] | **每天只看这个。** 按复现频次排序的病灶清单 |
| 证据库 | [[阅读/2009]]、[[阅读/2008]]、[[阅读/早年/2003]] 等 | 原始痕迹。不是复盘材料，只在画像指向时回查 |
| 词卡 | [[03真题语境辨义卡片 2000-2006]]、[[04真题语境辨义卡片 2007-2009]] | 语境义触发点 |
| 句模 | [[02搭配-句模库]] | 搭配槽位、逻辑方向、特殊句式 |
| 历史台账 | [[01阅读错因台账]] | 已冻结。按年份组织，只读参考 |
| 归档 | [[归档/00归档说明]] | 只读 |

**为什么画像是入口，年份笔记不是**：痕迹要保真、要乱、要留住当时的困惑；复盘材料要聚合、要短、要按优先级排。两个角色塞进一个文件，两边都不好用。

## 2. 单篇流程（40—60 分钟）

|       时间 | 动作                             |
| -------: | ------------------------------ |
|     5 分钟 | 打开画像，看**最活跃的 2 个病灶**的考场对策。不看别的 |
|    18 分钟 | 限时做题，标 H/M/L                   |
|     8 分钟 | 不看答案做证据审判（见 §4）                |
| 12—18 分钟 | 对答案，标记每道错题/改答题命中哪个病灶           |


**40 分钟压缩版**：砍掉证据审判，其余不动。

### 改答案门槛

只在**发现了新的具体词义证据**时才改。

这不是教条，是你自己的数据：累计改答记录里，理由为「重读后更顺 / 更贴主题」的全部由对改错；理由为「查到了具体词义」的多数有效。实时统计见 [[05认知画像]] 病灶 B。

## 3. AI 的职责边界

> 这一节是给 AI 看的规则。KK 粘贴痕迹后按此执行。

### 只写 KK 写不出来的东西

**禁止**：复述解析、逐题分析四个选项、把文章重新翻译、给每道题写等量分析。KK 已经自己对过答案了，他不需要第二份解析。

**要写**：跨篇模式匹配。本篇这个错，是已知病灶的第 N 次复现，还是新病灶？只有 AI 能把 7 年痕迹做交叉比对，这是唯一的不可替代价值。

### 单篇产出上限 10 行

写进年份笔记末尾，格式：

```md
## 收网｜YYYY TextN
- 病灶命中：A（第 N 次，词：xxx→xxx）、E（第 N 次）
- 新增病灶：无 / 提案见画像
- 元问题回答：（KK 问了才写，直接答，不绕）
- 未结账：QNN 你写了"仍不理解"，见画像未结账区
```

不写逐题判决表。不写「本篇 3 条下次动作」（会和画像里的对策重复）。

### 回写画像

每篇必须更新 [[05认知画像]]：复现计数 +1、更新「最近一次」、必要时调整状态箭头。**只有回写，台账才是账；不回写就只是堆积。**

### 新病灶的门槛

不是每个错误都配得上一个病灶。要求：
1. 可复现的**认知动作**，不是一次性失误
2. 能用 KK 自己的原话佐证
3. 描述具体到动作层面。「词汇量不足」「粗心」这类不算

宁可让病灶少而准。分类学把一个病拆成三个症状，就永远看不出它是一个病。

### 元问题最高优先级

KK 写下「我不理解」「不能被说服」「难道…吗」「有啥区别呢」时，**必须当场回答**。理由：内心不认同的题，复盘等于没做，下次还会那么选。答不完的进画像「未结账」区，不许沉底。

## 4. 证据审判四问

1. 题干问谁 / 什么？
2. 候选项的核心谓词是什么？（不许把精确词柔化成模糊大意）
3. 原文哪一句能完整支持？
4. 错误选项死在**哪个词**？——必须指出具体的词，不接受「重心不对」「感觉没用」

第 4 问是病灶 D 的直接对策。做对了也要能答出来。

## 5. 复习节奏

| 时点 | 做什么 |
|---|---|
| D+1 | 遮住解析，复述昨日错题的「证据位置—正确谓词—干扰项矛盾词」。不重选字母 |
| D+3 | 抽查画像里状态为「活跃」的病灶对策 + 相关词卡 |
| D+7（周日） | **周结算**：重算病灶频次、改答收益，判定退役 |

### 周结算（轻量，5 分钟）

只更新画像里的数字，不产生新文档：
- 各病灶复现计数
- 改答净收益（对改错 / 错改对）
- 连续 2 周未复现 → 状态改「观察」；连续 4 周 → 「已退役」，移出活跃区

### 其他时间块

- App 背单词 20 分钟保持不变
- 外刊每周 2—3 次、每次 15—20 分钟，只提炼主旨/态度/1 个关键句，不建词库
- 没有额外时间时优先保证真题

## 6. 题型与陷阱清单

**题型**：细节题（回定位句及前后句）｜推断题（只迈有证据的一小步）｜例证题（判断例子服务于哪个观点，看前后概括句）｜词句题（优先看固定表达和逻辑，不硬拆单词）｜主旨题（串各段功能，排除只覆盖局部的项）｜态度题（依据评价词、转折、论证方向）

**陷阱**：偷换主体/宾语｜无中生有｜半对半错｜跨段跨对象拼接｜程度范围可能性变化｜因果方向倒置｜局部细节冒充主旨｜真话但答非所问
