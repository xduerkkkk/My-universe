# 英语阅读 AI 整理规则

> 用途：KK 提交某年 Text 的做题痕迹后，AI 完成诊断并直接收进现有系统。**禁止创建新的错因库、词卡库、句模库或年度总结。**

## 1. 唯一可写入的文件

- 原始记录：对应年份笔记，如 [[阅读/2008]]；
- 错因：[[01阅读错因台账]]；
- 搭配/句模：[[02搭配-句模库]]；
- 语境词卡：[[03真题语境辨义卡片 2000-2006]] 或 [[04真题语境辨义卡片 2007-2009]]；
- 训练流程：[[00阅读方法论]]。

历史 Agent 产物统一放在 [[归档/00归档说明]]，只读，不作为新的追加入口。

## 2. 收网标准

AI 先完整分析，但每篇长期入库最多保留：

| 类型 | 数量 | 收录条件 |
|---|---:|---|
| 错因规则 | 1—3 条 | 会直接改变下次选项判断；包括做错或做对但机制不稳 |
| 语境词/词组 | 2—5 个 | 眼熟但触发慢、熟词生义、语境义误判、固定表达误拆 |
| 搭配/句模 | 1—3 个 | 具有可迁移的槽位、逻辑方向或特殊句式 |

同一内容已有卡片时，不重复建卡，只追加“复现年份/题目”和新的易错点。

## 3. 默认处理流程

当 KK 粘贴以 TEXT1 / TEXT2 / TEXT3 / TEXT4 开头的记录时：

1. 区分首答、审核后答案和最终答案；
2. 统计 H/M/L 与改答案效果；
3. 逐题指出：题干对象、选项核心谓词、原文证据、错误选项死因；
4. 给出本篇最多 3 条“下次动作”；
5. 在对应年份原始笔记末尾追加简短“AI 收网”；
6. 将合格内容追加到三个唯一主库；
7. 给出 D+1、D+3、D+7 的复习对象。

除非 KK 明确说“只讨论、不改文件”，否则在当前 vault 中默认直接完成上述整理，不再询问是否另建文件。

## 4. 禁止事项

- 不全量扩展每一个生词；
- 不把文章重新翻译一遍冒充复盘；
- 不用“100%必错、永远不选”等绝对规则；
- 不把同一内容同时制造成多份平行总结；
- 不为追求整齐而改写 KK 的原始做题痕迹；
- 不把第一次偶然失误直接升级成庞大的长期词族。
