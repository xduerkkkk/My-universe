# 真题语境辨义卡片

> 合并自原 `03真题语境辨义卡片 2000-2006` 与 `04真题语境辨义卡片 2007-2010` 两个年份文件，2026-07-28。文件名不再带年份，之后新增卡片直接进对应桶。
> 使用：**不再自己按 D+3 / D+7 排**（2026-07-28 改）。周六周报时从本库抽卡排进下一周每一天的「① 检测抽查」，你只管打开当周文件做。
> 抽查是**检测型**：给原文表达 + 一个改写，只答差在哪一维（等价/程度/时态/主体/范围/方向），不背释义。理由见 [[00阅读方法论]] §5。
> 目标：不是背「英汉大概义」，而是训练 **语境触发 → 精准义 → 干扰项排除**。
> 组织方式：按「这张卡对应哪种误读动作」分桶，不按年份。年份信息收在每张卡的 `出处` 字段里。

> [!important] 这个库对冲 [[05认知画像]] 的病灶 A，它是你最主导的病灶（约 33 例，2002—2010 每年都有）
> 抽查时**不要只回忆词义**，要回忆你当时**脑补成了什么**。A 的机制是「填一个近似义 + 置信度不降」，所以复现练习必须包含那个错误义项，否则练不到点上。
>
> 卡片里的「易错对比」字段就是为此存在的。看到 `vulnerability` 要能同时说出「漏洞」和「我当年读成了脆弱的人」。
>
> **复现约定**：某词在新真题里又没触发，加一行 `- 复现：YYYY TextN`。累计 3 次进高优先级。

## 桶1｜形近误读

> 判据：错在字母级，你把它读成了另一个拼写相近的词。

### fascination with wonder
- 核心义：对惊奇、未知和新问题的着迷与好奇。
- 本文语境：激活创造性思维、推动创新的心理条件。
- 易错对比：wonder ≠ wander；也不等于 relaxing。前者是好奇/惊奇，后两者分别是闲逛、放松。
- 真题触发器：curiosity / creative mind / mystery / innovation。
- 出处：09 T1

### game / prey
- 核心义：game 可为猎物；prey 为猎物/捕食对象。
- 考研语境义：生态/狩猎语境中 = 易被捕杀对象。
- 易错对比：game 不一定是游戏；prey ≠ pray。
- 真题触发器：large slow-growing animals were easy game。
- 出处：2006

### mortality
- 核心义：死亡；死亡率。
- 考研语境义：人口/医学/进化语境中多指「死亡率」。
- 易错对比：mortality ≠ morality（道德）。
- 真题触发器：male mortality / mortality rate / survival。
- 出处：2000-2001

### nature
- 核心义：性质、特点；也可指自然界。
- 本文语境：the chronic or repeated nature of stress = 压力具有持续、反复的性质。
- 易错对比：nature 在「the ... nature of X」结构中通常是「性质」，不是「大自然」；也别和 nurture 看混。
- 真题触发器：the political/social/chronic nature of...。
- 出处：08 T1

### precision / accuracy / prediction
- 核心义：precision 精确度、细致程度；prediction 预测。二者形近但语义无关。
- 本文语境：false precision 与 claimed accuracy 都指检测机构所宣传的精确/准确程度，因此构成语境近义替换。
- 易错对比：precision 读成 prediction 就整题跑偏；precision 与 accuracy 在技术领域不总是严格同义，这里只在本文评价命题中近义，不能机械推广。
- 真题触发器：claim / exact / reliable / measurement / testing result。
- 出处：09 T2

### predominance / predominant / prominent / preeminent
- 核心义：predominance 主导地位；prominent 突出；preeminent 卓越。
- 考研语境义：国家、产业、观点的优势地位。
- 易错对比：predominant 是「占主导」，prominent 是「显著/杰出」。
- 真题触发器：retreat from predominance / predominant role。
- 出处：2000-2001

### prosperous / prosperity / prospect / perspective
- 核心义：prosper- 繁荣；prospect 前景；perspective 视角。
- 考研语境义：经济看 prosperity，求职/未来看 prospect，观点分析看 perspective。
- 易错对比：prospect ≠ perspective。
- 真题触发器：economic prosperity / job prospects / from the perspective of。
- 出处：2000-2001

## 桶2｜程度·时态刻度

> 判据：词义方向对，但强度、时态、绝对性、量级被抹平。这是最高价值桶，抽查优先给它。

### apprehensive / indignant
- 核心义：apprehensive = 忧虑；indignant = 愤怒。
- 考研语境义：worry/fear 对应 apprehensive；angry/protest/condemn 才可能 indignant。
- 易错对比：担心不等于愤怒，情绪强度差一档就错。
- 真题触发器：态度题情绪强度匹配。
- 出处：2002-2003

### conservative estimate
- 核心义：保守估计。
- 考研语境义：估计偏低，真实情况可能更严重。
- 易错对比：conservative 不只是政治保守；「保守」的方向是低估，不是折中。
- 真题触发器：80% decline as a conservative figure。
- 出处：2006

### decline vs disappear
- 核心义：decline = 渐进性的、仍在延续的程度下降；disappear = 终结性的、彻底消失的状态。
- 本文语境：`has been an inexorable decline in the scope and seriousness of their arts coverage` = 艺术报道的广度和严肃性一直在不可阻挡地**衰退**（仍在过程中），不是已经**消失**。
- 易错对比：把 has been + decline（完成时态，强调过程仍在延续/已发生但未终结）读成了「已经消失」，是把程度渐减误判成终结状态；同类程度抹平见 inconclusive→毫无证据（05T2）、effective→有益处的（08T2）。
- 真题触发器：has been an inexorable decline / used to... 对比信号 / more（= in large part of）。
- 复现：2010 Text1（第 4 次程度抹平子型样本）。
- 出处：10 T1

### effective
- 核心义：能产生预期结果的；有效的。
- 选项语境：`an effective means` 不等于「有益的方式」，而是「确实能达到目标的手段」。
- 易错对比：effective ≠ beneficial；前者判断是否奏效，后者判断是否带来好处。
- 真题触发器：effective method / means / measure vs beneficial effect。
- 出处：08 T2

### halve
- 核心义：减半。
- 考研语境义：数量题中要画剩余量。
- 易错对比：reduced by 80% 后 halved again = 20% 再减半到 10%。
- 真题触发器：it has halved again since then。
- 出处：2006

### inconclusive
- 核心义：不能得出最终结论的。
- 考研语境义：有证据但不足以定论。
- 易错对比：inconclusive ≠ no evidence，「不足以定论」被抹平成「毫无证据」。
- 真题触发器：research / evidence / study / not enough to conclude。
- 出处：2004-2005

### lineage
- 核心义：世系、谱系；一条连续的血缘传承线。
- 本文语境：Y chromosome 或 mitochondrial DNA 通常只显示一条 lineage，而不是一个人的全部祖先。
- 易错对比：one lineage ≠ all ancestry；能沿一条线追溯很远，不等于完整覆盖每一代的所有祖先，范围被放大。
- 真题触发器：ancestor / descendant / maternal / paternal / genealogy。
- 出处：09 T2

### overestimate vs downgrade
- `overestimate`：高估，对重要性、数量或能力评价过高。
- `downgrade`：降低等级、地位或重要性；在判断题中常与「被低估 / 被降格」同向。
- 本文语境：把教育列为贫困国家经济发展的最高优先事项之一，作者认为这种重要性被 `overestimated`，而不是被 `downgraded`。
- 真题触发器：highest priority / importance / rate too highly / undervalue。
- 出处：09 T3

### prudent
- 核心义：谨慎的、审慎的。
- 考研语境义：政策/风险语境中的理性谨慎。
- 易错对比：prudent ≠ timid；谨慎不等于懦弱，别把「理性克制」降档成「畏缩」。
- 真题触发器：prudent action / prudent policy。
- 出处：2004-2005

### rewarding / successful
- 核心义：rewarding 有回报/值得；successful 成功。
- 考研语境义：successful 强调结果达成；rewarding 强调过程收获。
- 易错对比：作者用数据证明结果，优先 successful；两个选项都正面时靠「结果 vs 感受」分档。
- 真题触发器：态度题两个正面选项的强度与落点比较。
- 出处：2006

### secular trend
- 核心义：长期趋势、跨世代趋势。
- 本文语境：营养与健康改善后，人群平均身高长期上升的趋势。
- 易错对比：secular 在此不是「世俗的」，更不等于 cyclic（周期性的）；长期上升也可能随后进入平台期，别把「长期趋势」读成「一直会涨」。
- 真题触发器：a secular trend in height / prices / demographics。
- 出处：08 T3

### skeptical
- 核心义：怀疑的。
- 考研语境义：态度题中 = 对某观点/概念持怀疑态度。
- 易错对比：skeptical ≠ pessimistic；怀疑不等于悲观，态度强度不能加码。
- 真题触发器：became more skeptical of happiness。
- 出处：2006

### trace vs guide
- trace：追踪、查明；或痕迹。强调观察路径、找到来源。
- guide：引导、指导。强调主动控制方向或形成过程。
- 本文语境：文章支持有意识地建立/引导新习惯路径，不支持「新习惯的形成可以被追踪」作为同义替换；被动观察和主动控制不是一档。
- 真题触发器：formation / pathway / direct change / consciously develop。
- 出处：09 T1

### unprecedented
- 核心义：前所未有的。
- 考研语境义：程度极强，常被作者否定以反驳恐慌。
- 易错对比：not unprecedented = 并非前所未有，否定词一漏程度就反向。
- 真题触发器：neither at unprecedented levels nor...。
- 出处：2006

## 桶3｜熟词生义

> 判据：核心义你认得，但考研语境换了义项。数量最大的桶。

### aggravate
- 核心义：加重、恶化。
- 考研语境义：心理/疾病/社会问题变严重。
- 易错对比：aggravate 不只是 annoy。
- 真题触发器：aggravate symptoms/problems。
- 出处：2004-2005

### aggressive
- 核心义：强力推进的；攻击性的。
- 考研语境义：医疗/政策语境中 = 激进的、冒进的。
- 易错对比：aggressive treatment ≠ careless treatment。
- 真题触发器：aggressive treatment / aggressive policy。
- 出处：2002-2003

### assembly
- 核心义：集会；装配。
- 考研语境义：工业/机器人语境中 = 装配/组装。
- 易错对比：assembly arms = 装配臂。
- 真题触发器：assembly line / assembly arms。
- 出处：2002-2003

### assimilation / immune
- 核心义：assimilation 同化；immune 免疫/不受影响。
- 考研语境义：移民融入共同文化；不受同化力量影响。
- 易错对比：immune to culture 是社会隐喻，不是医学。
- 真题触发器：immune to the nation's assimilative power。
- 出处：2006

### astray
- 核心义：偏离正道，误入歧途。
- 考研语境义：信息/人/政策/判断走错方向。
- 易错对比：go astray = 出错/走偏，不一定是物理迷路。
- 真题触发器：go astray / lead sb astray。
- 出处：07 T4

### biomass / fishery
- 核心义：biomass 生物量；fishery 渔场/渔业。
- 考研语境义：生态/渔业文章中的核心指标。
- 易错对比：biomass 不是「生物质量」；fishery 不是单条鱼。
- 真题触发器：maximum sustainable yield from a fishery。
- 出处：2006

### cause
- 核心义：原因；事业。
- 考研语境义：动物保护/社会运动语境中 = 事业、运动。
- 易错对比：cause seeks to end... 时，cause 不是「原因」。
- 真题触发器：animal-rights cause / a noble cause。
- 出处：2002-2003

### china
- 核心义：中国；瓷器。
- 考研语境义：生活/餐具隐喻中 = 瓷器。
- 易错对比：paper plates instead of china = 功能性压过艺术性。
- 真题触发器：paper plates / china / craft。
- 出处：2004-2005

### compensation
- 核心义：补偿；报酬。
- 考研语境义：HR 语境 = 薪酬福利。
- 易错对比：不只是「赔偿」。
- 真题触发器：raise / salary / job / employer / compensation。
- 出处：2004-2005

### contend
- 核心义：争辩、主张。
- 考研语境义：某方提出论点或反击。
- 易错对比：contend that 后是立场，不是中立事实。
- 真题触发器：RSC contends that...。
- 出处：2006

### cover
- 核心义：覆盖；报道；掩盖。
- 考研语境义：media/press + cover + 事件 = 报道。
- 易错对比：cover up 才常是掩盖。
- 真题触发器：mass media cover disasters and deaths。
- 出处：2006

### cunning
- 核心义：狡猾的；精巧的。
- 考研语境义：科技/机器语境中可偏「精巧的、灵巧的」。
- 易错对比：不一定贬义。
- 真题触发器：cunning device / cunning mechanism。
- 出处：2002-2003

### dawn
- 核心义：黎明。
- 考研语境义：开端、萌芽。
- 易错对比：the dawn of X = X 的开端。
- 真题触发器：the dawn of robotics / dawn of a new era。
- 出处：2002-2003

### deference
- 核心义：尊重、服从。
- 考研语境义：社会等级/礼仪语境中 = 对上层的恭敬顺从。
- 易错对比：absence of deference = 等级敬畏消失。
- 真题触发器：casualness and absence of deference。
- 出处：2006

### denote / spontaneity / craft
- 核心义：denote 表示；spontaneity 自发性；craft 技艺。
- 考研语境义：语言变化文章中判断「随意口语化 vs 精雕表达」。
- 易错对比：spontaneity over craft = 随意性压过技艺。
- 真题触发器：talking over speaking, spontaneity over craft。
- 出处：2004-2005

### dimmest
- 核心义：最暗的；最迟钝的。
- 考研语境义：the dimmest executive = 最迟钝的高管，带讽刺/贬义。
- 易错对比：不是光线暗，而是智力/判断力弱。
- 真题触发器：obvious to the dimmest executive。
- 出处：07 T4

### document
- 核心义：文件；记录。
- 考研语境义：动词 = 记录、证明、显示。
- 易错对比：document a trend ≠ 文件一个趋势。
- 真题触发器：research/document + trend/change。
- 出处：2004-2005

### endeavor
- 核心义：努力；事业；有组织、有目标的活动。
- 本文语境：`a key element of scientific endeavor` = 科学事业/科研活动的关键要素。
- 易错对比：不是单次「尝试」；scientific endeavor 指整体科研事业。
- 真题触发器：scientific / intellectual / human endeavor。
- 出处：08 T2

### executive suite
- 核心义：公司高管层、管理层。
- 考研语境义：企业决策者/高层办公室，不是「行政套房」。
- 易错对比：suite 在商业语境里可指一组高管办公室或高管群体。
- 真题触发器：executive suite / corporate America / managers。
- 出处：07 T4

### fashion
- 核心义：时尚；塑造。
- 考研语境义：fashion measures = 制定措施。
- 易错对比：不要按「时尚措施」翻。
- 真题触发器：fashion laws/measures/policies。
- 出处：2004-2005

### fertile
- 核心义：肥沃的；能产生的。
- 考研语境义：可指「富有成果/有创造力/适合孕育某事」。
- 易错对比：不只用于土地或生育。
- 真题触发器：fertile ground for ideas/change。
- 出处：2000-2001

### frame
- 核心义：框架；体格、身材骨架。
- 本文语境：bigger, longer frames = 更高大、更修长的体格。
- 易错对比：人体语境中不是「画框/框架结构」，而是 body build。
- 真题触发器：large / slight / powerful frame；clothes fit one's frame。
- 出处：08 T3

### grievance / condemn / undervalue
- 核心义：grievance 不满/申诉；condemn 谴责；undervalue 低估价值。
- 考研语境义：公平、社会议题、职场议题中的态度词。
- 易错对比：criticize 不一定 condemn；complaint 不一定 grievance。
- 真题触发器：social grievance / condemn policy / undervalue contribution。
- 出处：2004-2005

### grip
- 核心义：抓住；控制。
- 考研语境义：困境/寒冬/危机「笼罩、侵袭」。
- 易错对比：be in the grip of = 被……控制/笼罩。
- 真题触发器：in the grip of winter/crisis。
- 出处：2002-2003

### guilty
- 核心义：有罪的；内疚的。
- 考研语境义：法律语境中优先取「有罪的」。
- 易错对比：held guilty = 被裁定有罪，不是「感到愧疚」。
- 真题触发器：court / judge / law / guilty。
- 出处：2002-2003

### handicap
- 核心义：障碍、不利条件。
- 考研语境义：社会/竞争语境中的劣势。
- 易错对比：不只指身体残障。
- 真题触发器：dreadful handicap。
- 出处：2000-2001

### hawk
- 核心义：兜售、推销；鼓吹某种产品或说法。
- 本文语境：false precision being hawked = 检测机构正在兜售/宣传一种虚假的精确性。
- 易错对比：不是名词「鹰」；也不是单纯「提出观点」，而带有商业推销和怀疑色彩。
- 真题触发器：product / claim / commercial testing / advertised precision。
- 出处：09 T2

### hold
- 核心义：拿住；认为；裁定。
- 考研语境义：法律语境中 = 裁定/判定。
- 易错对比：hold that... 可表示「裁定/认为……」。
- 真题触发器：court held that... / held guilty。
- 出处：2002-2003

### identify
- 核心义：识别身份。
- 考研语境义：报告/研究语境中 = 指出、确认、确诊。
- 易错对比：identify a problem = 指出问题。
- 真题触发器：report identified...。
- 出处：2002-2003

### ideology / agenda
- 核心义：ideology 意识形态；agenda 议程/目的。
- 考研语境义：商业文化把快乐包装成被灌输的价值观，agenda 常带操纵意味。
- 易错对比：agenda 不只是「日程」。
- 真题触发器：commercial culture / have an agenda。
- 出处：2006

### inclination
- 核心义：倾向、意愿、偏好。
- 本文语境：different inclinations when faced with stress = 面对压力时有不同倾向。
- 易错对比：inclination ≠ 泛泛的「表现/反应」；chemical response 也不能直接替换成 inclination。
- 真题触发器：inclination / tendency / preference 与 response / susceptibility 的命题区分。
- 出处：08 T1

### incompetent
- 核心义：无能力的。
- 考研语境义：法律/医疗语境中 = 无行为能力/业务不精/不能胜任。
- 易错对比：incompetent ≠ irresponsible。
- 真题触发器：incompetent patients / professional incompetence。
- 出处：2002-2003

### ironic
- 核心义：反讽的。
- 考研语境义：表层与真实评价相反，常提示作者态度。
- 易错对比：deliciously ironic 不是「好笑」而已。
- 真题触发器：deliciously ironic。
- 出处：2006

### lean
- 核心义：瘦的；倾斜。
- 考研语境义：组织/团队语境中 = 精简高效的。
- 易错对比：lean staff ≠ 瘦员工。
- 真题触发器：lean staff / lean production。
- 出处：2002-2003

### mediocrity
- 核心义：平庸；中等水平。
- 考研语境义：进化/社会语境中指差异被抹平后的「平庸化」。
- 易错对比：不是「中庸美德」，常带批评意味。
- 真题触发器：the grand mediocrity of today。
- 出处：2000-2001

### modification
- 核心义：修改、改造、改变。
- 选项语境：genetic modification = 基因改造/遗传层面的改变。
- 易错对比：modification ≠ adaptation（适应），也不是模糊的「影响、限制」；若原文谈的是 genetic ceiling，不能据此推出基因已被改造。
- 真题触发器：genetic / behavioral / policy modification。
- 出处：08 T3

### muted
- 核心义：静音的；减弱的。
- 考研语境义：影响/反应/情绪被削弱、缓和。
- 易错对比：muted effect ≠ 静音效果。
- 真题触发器：muted impact / muted response。
- 出处：2002-2003

### narrow
- 核心义：狭窄的；变窄。
- 考研语境义：动词「缩小」，如缩小差距、优势减弱。
- 易错对比：不要只按形容词「狭窄的」处理。
- 真题触发器：its primacy has narrowed / narrow the gap。
- 出处：2000-2001

### obscure
- 核心义：使模糊；遮蔽；掩盖。
- 本文语境：NBA 高个球员越来越多，可能掩盖普通美国人平均身高已经停止增长这一现实。
- 易错对比：不是「证明」或「造成」；A obscures B 表示 A 让 B 难以被看见。
- 真题触发器：surface phenomenon may obscure an underlying reality。
- 出处：08 T3

### opening
- 核心义：开口；开端；空缺。
- 考研语境义：求职语境 = 职位空缺。
- 易错对比：job opening ≠ 开口。
- 真题触发器：job/career/employer + opening。
- 出处：2004-2005

### overshadow
- 核心义：遮蔽，使黯然失色。
- 考研语境义：一件更吸睛的新闻盖过另一件更重要的事件/决定。
- 易错对比：不是简单「影子覆盖」，而是注意力/重要性被盖过。
- 真题触发器：Event A overshadowed decision/event B。
- 出处：07 T4

### paycheck
- 核心义：工资支票；一笔工资。
- 本文语境：live from paycheck to paycheck = 工资只够维持到下一次发薪，几乎没有结余。
- 易错对比：paycheck ≠ bill；也不是「从不同工作领取工资」。整体习语见 [[02搭配-句模库]]。
- 真题触发器：rent / debt / household expenses / paycheck to paycheck。
- 出处：08 T1

### peculiar institution
- 核心义：美国历史上对奴隶制的委婉称呼。
- 本文语境：the "peculiar institution" 指 slavery 本身。
- 易错对比：不能按 peculiar = 奇怪的，推出「人们认为奴隶制很奇特」；引号提示它是历史称谓或委婉语。
- 真题触发器：引号中的制度别称、政治委婉语和历史固定表达。
- 出处：08 T4

### phony / perpetual / track
- 核心义：phony 虚假；perpetual 持续；track 追踪/同步。
- 考研语境义：批判商业快乐、持续灌输、追踪某现象出现。
- 易错对比：track the emergence 可指「与出现同步发展」。
- 真题触发器：phony happiness / perpetual happiness / track the emergence。
- 出处：2006

### pressing
- 核心义：按压的；紧迫的。
- 考研语境义：紧迫的、逼近的。
- 易错对比：pressing need/problem 不按「按压」翻。
- 真题触发器：pressing need / pressing death。
- 出处：2002-2003

### procedure
- 核心义：程序；流程。
- 考研语境义：医疗语境中 = 医疗程序/手术/诊疗手段。
- 易错对比：procedure ≠ 普通过程。
- 真题触发器：medical procedure / aggressive procedure。
- 出处：2002-2003

### rage
- 核心义：强烈爆发的情绪/潮流。
- 考研语境义：风靡、狂热，不只是「愤怒」。
- 易错对比：all the rage = 风靡一时。
- 真题触发器：the rage of maturity / craze / fashion。
- 出处：2000-2001

### rate
- 核心义：比率；价格。
- 考研语境义：交通/铁路/商业语境中 = 费率、运费。
- 易错对比：rate ≠ tax。
- 真题触发器：railroad rates / freight rates。
- 出处：2002-2003

### reserved
- 核心义：保留的；预定的。
- 考研语境义：态度上 = 有保留的、谨慎的。
- 易错对比：reserved consent ≠ 预定同意。
- 真题触发器：reserved consent / reserved attitude。
- 出处：2002-2003

### retreat
- 核心义：撤退；退却。
- 考研语境义：经济/地位/影响力的衰退、退缩。
- 易错对比：不一定是军事撤退。
- 真题触发器：retreat from predominance / industrial retreat。
- 出处：2000-2001

### role
- 核心义：角色；作用、地位、影响。
- 选项语境：the role of slaves in U.S. history = 奴隶在美国历史中的作用，不是「奴隶扮演的角色」或「奴隶地位低下」。
- 易错对比：role of slaves 与 role slavery played 不是同一表达；还要继续核对 history 与 lives of the founding generation 的范围。
- 真题触发器：play a role in / the role of X in Y。
- 出处：08 T4

### saturated
- 核心义：饱和的、浸透的。
- 考研语境义：鱼线「挂满鱼」的形象表达。
- 易错对比：不是化学题才用。
- 真题触发器：longlines would have been more saturated with fish。
- 出处：2006

### sensitive personal data
- 核心义：敏感个人数据。
- 考研语境义：身份、信用卡、隐私等一旦泄露会破坏信任的数据。
- 易错对比：sensitive 不只是「情绪敏感」，也指信息敏感、需保护。
- 真题触发器：sensitive personal data get into the wrong hands。
- 出处：07 T4

### shield
- 核心义：盾牌；保护。
- 考研语境义：动词 = 庇护、保护，使免受影响。
- 易错对比：不是只作名词。
- 真题触发器：shield sb from liability/pain。
- 出处：2002-2003

### shifting baseline
- 核心义：移动的基准线。
- 考研语境义：用越来越近、越来越低的标准当「正常」，导致低估长期变化。
- 易错对比：不是基线物理移动，而是参考标准改变。
- 真题触发器：failed to detect massive changes because looking back only a short time。
- 出处：2006

### shipper
- 核心义：发货者。
- 考研语境义：货主、托运商。
- 易错对比：shipper ≠ driver。
- 真题触发器：railroad company vs shippers。
- 出处：2002-2003

### spook
- 核心义：鬼魂；吓唬。
- 考研语境义：俚语中 = 间谍/特工。
- 易错对比：看情报/政府语境，不要按鬼魂翻。
- 真题触发器：CIA spook / intelligence spook。
- 出处：2002-2003

### squeeze
- 核心义：挤压。
- 考研语境义：经济压力、利润受挤压、生活拮据。
- 易错对比：financial squeeze ≠ 物理挤压。
- 真题触发器：profit squeeze / credit squeeze。
- 出处：2002-2003

### straightforward
- 核心义：直接明了的；简单易懂、没有复杂环节的。
- 本文语境：`It used to be so straightforward.` = 过去的科研出版流程曾经相对简单清楚，引出后文 Internet 带来的模式变化。
- 易错对比：不是「坦率地说」，也不是「径直向前」；根据出版流程语境取「简单明了」。
- 真题触发器：process / procedure / explanation + straightforward。
- 出处：08 T2

### susceptible
- 核心义：易受影响的；易感染的。
- 考研语境义：心理/医学/社会语境中 = 易受……影响。
- 易错对比：susceptible to 后接风险/影响。
- 真题触发器：susceptible to nightmares/disease/influence。
- 复现：2008 Text1 再次出现「眼熟但不能快速、准确触发」，列为高优先级。
- 出处：2004-2005

### target
- 核心义：目标；靶子。
- 考研语境义：被攻击/嘲笑/批评的对象。
- 易错对比：target 不一定是主动追求的目标。
- 真题触发器：become a target of criticism。
- 出处：2002-2003

### terminally
- 核心义：终端地；末期地。
- 考研语境义：医学中 = 晚期地、临终地。
- 易错对比：terminally ill = 绝症晚期。
- 真题触发器：terminally ill patients。
- 出处：2002-2003

### the fragile nature of a country's infancy
- 核心义：一个国家初创时期的脆弱状态。
- 本文语境：美国建国早期制度和政治局势脆弱，对应选项 delicate situations。
- 易错对比：infancy 不只指婴儿期，也可指国家、制度、技术的初创阶段；fragile 可与 delicate 构成同义替换。
- 真题触发器：in its infancy / the infancy of a nation or industry。
- 出处：08 T4

### universal
- 核心义：普遍的；普遍性。
- 考研语境义：可作名词，表示「普遍现象/普遍规律」。
- 易错对比：不要只按形容词「普遍的」翻。
- 真题触发器：great universal of male mortality。
- 出处：2000-2001

### vessel
- 核心义：容器；血管；船只。
- 考研语境义：海洋/捕鱼语境中 = 船只。
- 易错对比：看领域决定义项。
- 真题触发器：fishing vessels。
- 出处：2006

### yield
- 核心义：产出；让步。
- 考研语境义：yield to = 让位于、被……取代、屈服于。
- 易错对比：yield 不只表示「产量」。整体句模 yield to B 见 [[02搭配-句模库]]。
- 真题触发器：Self-doubt has yielded to blind pride。
- 出处：2000-2001

## 桶4｜词根构词误推

> 判据：你没看错字母，也没抹平程度，而是靠词根/前后缀推出了一个不存在的义项。

### commonness
- 核心义：普通、平常；在评价语境中可指趋同、平庸化、缺乏差异。
- 本文语境：standardized testing fosters commonness = 标准化考试强化相同的分析/程序模式，压低创新与协作空间。
- 易错对比：不能从 common + -ness 推成「共同点」这一中性概念；更不能把 fosters commonness 读成 no longer emphasizes commonness。
- 真题触发器：standardized / conformity / uniformity / innovation。
- 出处：09 T1

### compliance
- 核心义：遵守、服从。
- 考研语境义：企业/监管语境中 = 合规，遵守法律、标准或监管要求。
- 易错对比：不能从 comply 直接推成单纯「顺从」，这里是制度性「合规」。
- 真题触发器：legislation / regulators / firms / corporate compliance。
- 出处：07 T4

### redundancy
- 核心义：冗余；多余；裁员。
- 考研语境义：技术/系统语境常指「冗余备份」；职场语境常指「裁员/岗位冗余」。
- 易错对比：不能只背一个义项，必须看 system 还是 employment 语境。
- 真题触发器：data security / backup / job cuts / redundancy。
- 出处：07 T4

### under- / undertreatment
- 核心义：under- 表示不足、低于。
- 考研语境义：undertreatment = 治疗不足。
- 易错对比：under- 不是「不理睬」。
- 真题触发器：underestimate / undertreatment / understate。
- 出处：2002-2003

### vulnerability
- 核心义：易受伤害性；脆弱性。
- 考研语境义：数据安全/系统语境中 = 漏洞、薄弱点、潜在风险点。
- 易错对比：vulnerabilities ≠ vulnerable people（脆弱的人）。
- 真题触发器：data security / potential vulnerabilities / system risks。
- 出处：07 T4
