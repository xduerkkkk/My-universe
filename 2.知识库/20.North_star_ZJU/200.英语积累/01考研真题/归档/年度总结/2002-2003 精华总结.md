## 一、同义替换 / 近义词精华

### 态度词精准映射（考研最爱考！）

| 原文用词               | 选项替换                 | 区分要点                        |
| ------------------ | -------------------- | --------------------------- |
| `worry` + `fear`   | `apprehensive` (忧虑的) | **不是** `indignant` (愤怒的)    |
| `arbiter`          | `judge` (裁判/裁决者)     | 34题核心替换                     |
| `reserved consent` | 有保留的赞同               | `reserved` ≠ 预定的            |
| `optimistic`       | 乐观的                  | 对应 `not to lose sleep over` |
| `subscribe to`     | `agree with` (赞同)    | 用于理论/观点                     |

## 四、重要句子结构与逻辑连接

### 1. 虚拟语气 —— 你 2003 T1 的痛点

> **Wild Bill Donovan would have loved the Internet.**

- **陷阱**：不能由此推断 Donovan 真的喜欢互联网（他生前互联网还没出现）
- **命题套路**：虚拟语气描述的是**与现实相反的假设**，选项若把它当事实陈述就是干扰项

### 2. `whereby` = by which

> Agencies avoid dramatic declarations, **whereby** they...

- 引导定语从句，相当于 "by which"
- 区别于 `thereby` (因此，表因果)

### 3. `holding that...` 现在分词作后置定语

> A centuries-old moral principle **holding that** an action...

- holding that = 认为/主张
- 这不是"拿着"，是法律/原则"持有某种观点"

### 4. `if not` 递进逻辑

> extend that forecast by decades **if not** centuries

- 甚至几百年（在几十年的基础上递进加深）
- **不是** "如果不是几百年的话"

### 5. 破折号插入语 —— 考场跳过

> The grand mediocrity of today — everyone being the same... — means that...

- 双破折号中间是插入解释，**首读时可跳过**，先抓主干

### 6. `do so / did it` 动作替代

> machines and society **did it** for us

- `did it` = `evolved`，指代前文的核心动作
- 考研极高频，必须往前找被替代的动作

### 7. 物作主语 —— 英文习惯

> The mid-1980s **brought** one inquiry after another...

- 英语习惯用时间/事物作主语，中文翻译时转化为人作主语
- "20世纪80年代中期，**人们**进行了一次又一次的调查"

### 8. 名词翻译不通 → 看它的动词

> One such **cause** now **seeks to end** biomedical research.

- `cause` 如果是"事件"，不可能发出 `seeks to end`（试图终止）的动作
- 所以 `cause` 必是人参与的活动 → **运动/事业**

## 五、做题策略提醒 🧠

> 从你做 2002-2003 阅读的错误模式中提炼的"避坑清单"。

### 🔴 定位问题
- **症状**：2002 T3 Q31 没定位到 `supply-cuts`，找了第二段伊拉克
- **药方**：**题干关键词必须在原文精准定位**，尤其是专有名词/数字/特殊符号附近。定位错 = 全文错

### 🔴 态度题精准度
- **症状1**：2003 T3 Q32 读出"不满"就选了 `indignant`(愤怒)
  - 正确：`worry` + `fear` = `apprehensive`(忧虑)
- **症状2**：2002 T4 Q39 把 `aggressive`(激进) 当成 `careless`(粗心)
  - 态度题必须找**原文情感词的同义映射**，不能凭感觉放大情绪
- **铁律**：原文 `worry/fear` → `apprehensive`；原文 `angry/protest` → `indignant`

### 🔴 命题陷阱类型

| 陷阱类型            | 案例                                                     | 识别方法                                |
| --------------- | ------------------------------------------------------ | ----------------------------------- |
| **贬义动词干扰**      | 2002 T1 Q21: `take advantage of` 在正面论述中为干扰项            | 看全文情感色彩，正面论述中贬义动词选项直接排除             |
| **概念偷换(宏观↔微观)** | 2002 T4: `hospital care`(宏观) ≠ `treatment of pain`(微观) | 问什么答什么，题干限定范围不能放大或缩小                |
| **替罪羊因果**       | 2003 T3 Q35: 表面是 `traffic growth`，实质是 `acquisition`    | 看到转折词(Yet/But)后面的内容才是真正原因           |
| **虚拟语气当事实**     | 2003 T1 Q21: `would have loved` ≠ 真的喜欢                 | `would/could/might have done` 一律是假设 |
| **法律词日常化**      | 2002 T4: `held guilty` = 裁定有罪 ≠ 感到愧疚                   | 法律/医疗/经济类文章，词汇取其领域专业义               |

### 🔴 反讽/弦外之音
- **症状**：2003 T4 Q36 "in California optional" 没读出反讽
- **药方**：首段故意夸张/反常的描述往往是**反讽**，作者的真正态度在后面会暴露

### 🔴 逻辑链断裂
- **症状**："每个单词都认识，加起来不知道在讲什么"
- **药方**（三层递进法）：
  1. 找出句子的**主谓宾主干**
  2. 找出**逻辑连接词**（because/so/but/if/whereby）
  3. 画箭头：A → B → C，看因果链
- 参考 2003 T3 两个"诊断句"的拆解方法

### 🔴 词性推断法
- 名词翻译不通 → 立刻看它的**动词搭配**（如 `cause` + `seeks to end` → 运动）
- 动词翻译不通 → 立刻看它的**宾语**（如 `deliver` + `remarks` → 发表评论）

### 🔴 你的"假性熟悉"问题
> 2002 T3 你写道："碰到一些词组发懵只能靠直觉，但看解析翻译就感觉这词组自己本来就会，一眼就能明白"

**诊断**：这不是词汇量问题，是**语境激活速度**问题。单词在大脑中是"被动存储"而非"主动可调用"。

**药方**：每做完一篇，**遮住中文，自己口头翻译一遍全文**。卡住的地方就是假性熟悉的词，把它们放进 [[#三、语境词组短语库|语境库]] 反复看。

## 七、可迁移的"命题人思维"

1. **态度题** = 精准情感映射，不放大不缩小 → 找原文情感词的同义词
2. **因果题** = 区分表面原因 vs 根本原因 → 看转折词后面的内容
3. **细节题** = 定位必须精准，不能凭印象 → 题干词对应原文词
4. **推断题** = 不能选文中直接陈述的，也不能选无中生有的
5. **主旨题** = 看首段末段 + 反复出现的概念

---

> **最后提醒**：你 2002 T3 的自我诊断非常精准 —— "做题时读文章碰到词组发懵只能靠直觉，但看解析就感觉本来就会"。这不只是词汇问题，更说明你的大脑在**限时压力下提取词义的路径还没自动化**。解决方案：持续做**遮住译文口头翻译**的训练，让语境激活速度追上你的词汇储备量。
