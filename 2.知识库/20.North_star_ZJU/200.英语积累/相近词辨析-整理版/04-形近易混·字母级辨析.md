# 04 — 形近易混·字母级辨析

> 这些词长得很像，但**词根不同、词义无关**。考研命题人最喜欢的干扰项设计方式。
> 每个条目都配有**一针见血的记忆锚点**，帮你锁定区分。

## ① complement vs compliment ⚠️ 考研完形必考

|             | complement                     | compliment                  |
| ----------- | ------------------------------ | --------------------------- |
| **含义**      | 补充；互补（使完美）                     | 赞美；恭维                       |
| **词根**      | com + ple(满) + ment → 补满       | com + pli + ment → 使满意 → 赞美 |
| **🔥 记忆锚点** | 中间 **e** → compl**e**te(完成)    | 中间 **i** → **I**(我) 最爱听赞美   |
| **搭配**      | `complement each other` 相辅相成   | `pay a compliment to sb.`   |
| **对比**      | `supplement` = 增补（单纯增加，不一定是补全） | —                           |

## ② sensitive vs sensible vs sentimental vs sensation

| | sensitive | sensible | sentimental | sensation |
|---|---|---|---|---|
| **含义** | 敏感的；灵敏的 | 明智的；理智的 | 伤感的；多愁善感的 | 感觉；轰动 |
| **记忆锚点** | 偏"易受刺激" | ▸ 唯一一个"理智"的词！源于 `make sense` | 偏"怀旧、矫情" | 偏"感官刺激/轰动" |
| **搭配** | `be sensitive to criticism` | `a sensible choice` | `sentimental value` 情感价值 | `an internet sensation` 网红 |

> 📌 **market sentiment** (市场情绪) 是考研经济类文章极高频词！

## ③ considerable vs considerate

| | considerable | considerate |
|---|---|---|
| **含义** | 相当大的；可观的 | 体贴的；考虑周到的 |
| **记忆** | -able "可…的 → 程度大到值得考虑" | -ate "具有…特质 → 体贴" |
| **搭配** | `a considerable amount` | `be considerate of others` |

---

## ④ conserve vs preserve vs reserve

| | conserve | preserve | reserve |
|---|---|---|---|
| **核心义** | 节约；保全（资源） | 保护；保存（使不变质） | 保留；预订；储备 |
| **前缀逻辑** | con(一起) → 一起保住 → 多用于资源 | pre(事先) → 事先保存 → 保鲜/防腐 | re(回) → 留作备用 |
| **搭配** | `conserve energy` | `preserve heritage` | `reserve a seat` / `reserve the right` |

---

## ⑤ conform vs confirm vs confront

| | conform | confirm | confront |
|---|---|---|---|
| **核心义** | 遵从；符合 | 证实；确认 | 面对；对抗 |
| **拆解** | con + form(形态) → 形态一致 | con + firm(坚固) → 使之坚固 → 确认 | con + front(前面) → 一起面对 |
| **搭配** | `conform to rules` | `confirm the report` | `confront the challenge` |

---

## ⑥ commend vs recommend vs command

| | commend | recommend | command |
|---|---|---|---|
| **核心义** | 表扬；推荐 | 推荐；建议 | 命令 |
| **区别** | 赞许/荐举（较正式） | re- 加强/再次 → 强调推荐 | 词形近但转义为"下命令" |
| **搭配** | `commend sb. for sth.` | `recommend that sb. do` | `command respect` |

---

## ⑦ contempt vs content vs contend vs contrast

|         | contempt        | content             | contend              | contrast               |
| ------- | --------------- | ------------------- | -------------------- | ---------------------- |
| **核心义** | 轻蔑；蔑视           | 内容；满足的              | 竞争；主张                | 对比；对照                  |
| **区别**  | tempt → "鄙视"情绪  | tent → 全部拿到手 → 满足   | tend(伸展) → 一起伸展 → 竞争 | contra(相对)+st(站) → 对着站 |
| **搭配**  | `with contempt` | `table of contents` | `contend for`        | `contrast A with B`    |

## ⑧ explicit vs implicit

| | explicit | implicit |
|---|---|---|
| **核心义** | 明确的；直截了当的 | 含蓄的；暗示的；盲从的 |
| **词根画面** | ex(外) + plic(折) → 把折叠的东西展开在外 | im(里) + plic(折) → 意思折在里面 |
| **搭配** | `explicit instructions` | `implicit assumption` / `implicit trust` |

---

## ⑨ thrive vs strive vs derive

| | thrive | strive | derive |
|---|---|---|---|
| **核心义** | 兴旺；茁壮成长 | 努力奋斗 | 源自；获得 |
| **记忆锚点** | th → "长得好" | st → "使劲儿"（多了一个 s→使劲） | de + rive(流) → 从源头流下来 |
| **搭配** | `thrive on stress` | `strive for success` | `derive from` |

## ⑩ anonymous vs autonomous

| | anonymous | autonomous |
|---|---|---|
| **核心义** | 匿名的 | 自治的；自主的 |
| **拆解** | an-(无) + onym(name名字) + ous → 没有名字的 | auto-(自己) + nom(法律) + ous → 自己管自己 |
| **搭配** | `anonymous letter` | `autonomous region` |

---

## ⑪ liable vs viable vs available vs reliable — 四大 -able 天王

| | liable | viable | available | reliable |
|---|---|---|---|---|
| **核心义** | 有责任的；可能要受…的 | 可行的；能生存的 | 可获得的；有空的 | 可靠的；可信赖的 |
| **词根** | li(绑) → 被拴在责任上 | vi(生命) → 活得下去的 | avail(有用/有利) → 可以用得上的 | re(加强)+li(靠) → 可以靠上去的 |
| **搭配** | `liable for damages` | `a viable solution` | `available resources` | `a reliable source` |

> 📌 口诀：「li-绑(责任)，vi-活(可行)，avail-可用，rely-靠谱」

## ⑫ physician vs physicist 🚨 终极视觉陷阱

| | physician | physicist |
|---|---|---|
| **含义** | **内科医生** | 物理学家 |
| **记忆诀窍** | 古希腊认为治病要顺应"自然(physi)"规律 | 研究"物理(physics)"的人 |
| **搭配** | `consult your physician` | — |
| **扩展** | psychiatrist = 精神科医生（能开药） | — |

## ⑬ ethnic vs ethic — 一字之差

| | ethnic | ethic |
|---|---|---|
| **含义** | 种族的；民族的 | 道德规范；伦理 |
| **视觉解题** | 多了 **n** = **n**ation（国家/民族） | 复数 **ethics** 考研极高频 |
| **搭配** | `ethnic minority` 少数民族 | `work ethic` 职业道德 |

## ⑭ exceed vs excel

| | exceed | excel |
|---|---|---|
| **含义** | 超过；超越 | 胜过；擅长 |
| **词根** | ex(出) + ceed(走) → 走出去超过 | ex(出) + cel(高/升) → 站得比别人高 |
| **搭配** | `exceed expectations` | `excel at/in` |

## ⑮ religion vs regime vs region — 信仰 vs 政体 vs 地区

|         | religion                  | regime                | region                  |
| ------- | ------------------------- | --------------------- | ----------------------- |
| **核心义** | 宗教                        | 政体；制度（常带贬义）           | 地区；行政区                  |
| **词根**  | re + **lig**(绑) → 把信仰绑在一起 | **reg**(统治) → 管人的条条框框 | **reg**(统治) → 王者管辖的那片土地 |
| **搭配**  | —                         | `the old regime`      | —                       |

> 📌 **同根扩展**：oblige(迫使→被责任绑住), alliance(联盟→绑在一起) | regulate(管理/调节), rectify(纠正/矫正)

## ⑯ exclusive vs inclusive vs extensive vs expensive

|         | exclusive             | inclusive           | extensive           | expensive         |
| ------- | --------------------- | ------------------- | ------------------- | ----------------- |
| **核心义** | 排他的；独家的；高档的           | 包容的；包括全部的           | 广泛的；大量的             | 昂贵的               |
| **词根**  | ex+clus(关) → 把别人关门外   | in+clus(关) → 把大家圈进来 | ex+tens(拉伸) → 向外延伸  | ex+pens(钱) → 钱交出去 |
| **搭配**  | `exclusive interview` | `all-inclusive`     | `extensive reading` | —                 |

> 📌 **同类扩展**：conclusive(结论性的→con+clus把事实全关上得出结论), seclude(隐居→把自己关起来)

## ⑰ extinct vs instinct vs distinct — -tinct 兄弟

|          | extinct                 | instinct                    | distinct                     |
| -------- | ----------------------- | --------------------------- | ---------------------------- |
| **核心义**  | 灭绝的；死寂的                 | 本能；天性                       | 明显的；截然不同的                    |
| **词根画面** | ex + stinct(熄灭) → 火彻底灭了 | in + stinct(刺/标记) → 刻在里面的标记 | di(分开) + stinct(标记) → 标记出来区分 |
| **搭配**   | `become extinct`        | `by instinct`               | `distinct from`              |
| **动词**   | extinguish(熄灭)          | —                           | distinguish(区分/辨别)           |
|          |                         |                             |                              |
|          |                         |                             |                              |

> 📌 **stimulate**(刺激/激励)也是同根 → 用尖锐的东西"刺"一下

## ⑱ solidary vs solitary vs consolidate

| | solidarity | solitary | consolidate |
|---|---|---|---|
| **核心义** | 团结一致 | 孤独的；唯一的 | 巩固；合并 |
| **词根** | solid(固体) → 像花岗岩一样团结 | sol(独自) → 只有一个人 | con+solid(固体) → 让零散变固体 |
| **搭配** | `show solidarity with` | `solitary confinement` 单人牢房 | `consolidate power` |
| **扩展** | — | solitude(独处→中性/褒义) | — |

## ⑲ 更多字母级配对 — 快速扫描

### 人/社会
| 词组                                    | 快速区分                                                                      |
| ------------------------------------- | ------------------------------------------------------------------------- |
| **arouse / rouse**                    | arouse 常接"兴趣/情绪"（`arouse interest`）；rouse 常指"叫醒"（`rouse from sleep`）      |
| **obedience / obese**                 | obedience=服从（ob+audire听）；obese=肥胖（ob+edere吃）。同源：audio/edible              |
| **decent / scent**                    | decent=体面的（同 decorate）；scent=气味/香味（同 sense 感知）                            |
| **authority / aesthetic / authentic** | authority=权威（author作者→话语权）；aesthetic=审美的；authentic=真实的（auto自己+hent做→亲手做的） |

### 动作/状态
| 词组                                | 快速区分                                                       |
| --------------------------------- | ---------------------------------------------------------- |
| **devour / devote**               | dev**our** → 吞进肚子；dev**ote** → 投入/献身（`devote oneself to`）  |
| **presumably / presume / assume** | presumably=推测口吻(副词)；presume偏"基于依据就认为/甚至擅自"；assume中性"假设"    |
| **strain / restrain / constrain** | strain=拉扯→压力/损伤；restrain=往回拉住(抑制)；constrain=一起框住(限制)       |
| **pledge / plunge**               | pledge=誓言/承诺（手按圣经）；plunge=骤降/猛冲（像铅块坠入深水）。`Prices plunged.` |
| **temple / tempt / temper**       | temple=神庙/太阳穴；tempt=诱惑（伸手摸禁果）；temper=脾气（炼钢调和的"混合"状态）       |
| **sip / dip / dig**               | sip=抿一小口；dip=蘸一下就拿出来；dig=挖（需要破开表面、最有力量感）                   |
| **crawl / crew / crow / clown**   | crawl=爬行；crew=全体工作人员(团队)；crow=乌鸦/吹牛；clown=小丑               |


### 名词/实物
| 词组                                                                | 快速区分                                                                                                 |
| ----------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| **shed / sheer / shade**                                          | shed=脱落(由内向外丢)/小棚子+shed light on=解释；sheer=纯粹的/极薄的/垂直的；shade=阴凉处（vs shadow=具体影子）                      |
| **linen / linear / liner / linger**                               | linen=亚麻布；linear=线性的；liner=班轮/班机(按固定路线)；linger=逗留/徘徊（⚠️词根是long不是line！）                               |
| **flesh / fresh / flash / flush / blush / fleet**                 | flesh=肉体；fresh=新鲜；flash=闪光；flush=脸红/冲水；blush=害羞脸红；fleet=舰队                                           |
| **canyon / canoe / cannon**                                       | 都来自 canna(芦苇杆/管子)。cannon=大炮(铁管子)；canoe=独木舟(挖空的树干)；canyon=峡谷(管状深槽)                                    |
| **biography / biology / bibliography / geography / encyclopedia** | bio+graphy=传记；bio+logy=生物学；biblio+graphy=书目；geo+graphy=地理；encyclopedia=百科全书(en+cyclo圆圈+pedia教育→知识闭环) |
| **coarse / course**                                               | coarse=粗糙的(摸砂纸)；course=课程/过程/航线/一道菜（来自currere跑）                                                      |
| **procession / possession**                                       | procession=队伍(pro+cess向前走)；possession=拥有(pos+sess坐在金币上)                                              |

### 拼写微差 → 词义迥异
| 词组                                                       | 快速区分                                                                                               |
| -------------------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| **fabric / fabricate**                                   | fabric=织物/布料；fabricate=编造/伪造（把布料"织"成谎言）                                                            |
| **fragrant / fragment / fracture / fraction / pregnant** | fragrant=芳香的（⚠️不属于破碎家族）；fragment=碎片；fracture=骨折；fraction=小部分/分数；pregnant=怀孕的（⚠️pre+gnatus出生，不是破碎！） |
| **define / definite / infinite**                         | define=定义；definite=确定的；infinite=无限的(in-否定)                                                         |
| **weep / sweep / sweat**                                 | weep=哭泣；sweep=打扫/横扫；sweat=汗水                                                                       |
| **satire / stair / steer / steel**                       | satire=讽刺文学；stair=楼梯；steer=驾驶/操控；steel=钢铁                                                          |
| **tax / wax / fax**                                      | tax=税；wax=蜡/上蜡；fax=传真                                                                              |
| **bay / hay / herb**                                     | bay=海湾；hay=干草；herb=草药                                                                              |
| **paddle / puddle / pedal / cradle / riddle / pepper**   | paddle=桨(手划)；pedal=踏板(脚踩→ped=脚)；puddle=小水洼；cradle=摇篮(→发源地)；riddle=谜语(原意筛子)；pepper=胡椒               |
| **vibrate / violate / volatile / ventilate / versatile** | vibrate=振动；violate=违反/暴力；volatile=易挥发/易变(vol=飞)；ventilate=通风(vent=风)；versatile=多才多艺(vers=转)        |

### 法律/政治 — 高危混淆词
| 词组 | 快速区分 |
|---|---|
| **defendant / plaintiff / offender / defender** | defendant=被告(defend防守→在法庭防守自己的人)；plaintiff=原告(控告别人的人)；offender=罪犯；defender=捍卫者(非法律用语!) |
| **corporate / corporation / cooperate** | corporate(adj.公司的)→`corporate culture`；corporation(n.公司实体)；cooperate(v.合作) |
| **federal / feudal / funeral** | federal=联邦的(FBI的F!)；feudal=封建的；funeral=葬礼 |
| **process / proceed / precede** | process=过程/处理；proceed=继续进行；precede=先于…发生(⚠️ "A is preceded by B" = B先发生!) |
| **sequence / subsequent / consequent** | sequence=顺序/序列；subsequent=随后的(时间上)；consequent=作为结果的(逻辑上)→consequently因此 |
| **conviction / convict / converge** | conviction=定罪/坚定信念(vict=赢)；convict=定罪/囚犯；converge=汇聚(verge=转向)→divergence=分叉 |
| **prosecute / execute** | prosecute=起诉(pro+secu在法庭紧追)；execute=执行/处决(ex+secu让结果跟出来) |
