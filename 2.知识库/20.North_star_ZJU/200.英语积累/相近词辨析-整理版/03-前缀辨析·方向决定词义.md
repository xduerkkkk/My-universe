# 03 — 前缀辨析·方向决定词义

> 相同前缀 + 不同词根 = 形近但意义迥异。考研完形填空的核心设坑逻辑。
> 本笔记按前缀聚合，每个前缀下展示：完全不同的词根如何被同一个前缀"染色"。

---

## 一、con- / com- / col- / cor- / co- —「共同」「一起」「完全」

前缀变体（取决于后接辅音），核心义都是"一起/共同"或加强语气。

### con + form vs firm — 最经典陷阱

| 词 | 核心义 | 拆解 |
|---|---|---|
| **conform** | 遵从；符合 | con(共同) + form(形态) → 形态一致。`conform to rules` |
| **confirm** | 证实；确认 | con(加强) + firm(坚固) → 使之坚固 → 确认属实。`confirm the report` |
| **confront** | 面对；对抗 | con(一起) + front(前面) → 一起面对。`confront the challenge` |

### con + flict — 打击家族

| 词 | 核心义 | 拆解 |
|---|---|---|
| **conflict** | 冲突；矛盾 | con(一起) + flict(打) → 打在一起 |
| **inflict** | 施加（痛苦/惩罚） | in(加在…上) + flict(打) → 把打击加在别人身上 |

### com + ple — 补满 vs 赞美 ⚠️ 考研完形必考

| 词 | 核心义 | 拆解 | 记忆 |
|---|---|---|---|
| **complement** | 补充；互补 | com(全部) + ple(满) → 补满 | 中间 e → complete |
| **compliment** | 赞美；恭维 | com + pli(满) → 说"满话" | 中间 **i** = **I**（我）→ 我最爱听赞美 |
| **complete** | 完成；完整的 | 同上 | com + ple(满) → 全部填满 |
| **compatible** | 兼容的；能共处的 | com(共同) + pat(感情) → 感情合得来 | `be compatible with` |

### con + tend/tain — 满足 vs 轻蔑

| 词 | 核心义 | 拆解 |
|---|---|---|
| **content** | (n.) 内容；(adj.) 满足的 | con + tent(拿) → 全拿到手 → 满足 |
| **contempt** | (n.) 轻蔑；蔑视 | con + tempt(蔑视) → `with contempt` |
| **contend** | (v.) 竞争；主张 | con + tend(伸展) → 一起伸展 → 竞争 |
| **contrast** | (n./v.) 对比；对照 | contra(相对) + st(站) → 对着站 |

### con + stitut — 站立家族

| 词 | 核心义 |
|---|---|
| **constitute** | 组成；构成 |
| **constituent** | 选民；成分 |
| **constitution** | 宪法；章程；体质 |
| 详见 [[02-词根辨析·核心词根(下)#五、sist / stitut / stitute —「站立」「建立」]] |

## 二、pre- / pro- —「前」「向前」「事先」

### pre- (在…之前)

| 词 | 核心义 | 拆解 |
|---|---|---|
| **preserve** | 保护；保存 | pre(事先) + serve(保存) → 事先保存 → 保鲜/防腐 |
| **precede** | 先于…（发生） | pre(前) + cede(走) → 走在前面 |
| **precedent** | 先例 | 同上 |
| **preceding** | 前面的；在先的 | 同上 |
| **predict** | 预测 | pre(前) + dict(说) → 提前说 |
| **prevent** | 预防；阻止 | pre(前) + vent(来) → 提前来拦住 |

### pro- (向前)

| 词              | 核心义    | 拆解                              |
| -------------- | ------ | ------------------------------- |
| **prospect**   | 前景；展望  | pro(前) + spect(看)               |
| **prosperous** | 繁荣的    | pro(前) + sper(希望) + ous → 前方有希望 |
| **prosperity** | 繁荣（名词） | 同上                              |
| **provide**    | 提供；供应  | pro(前) + vide(看) → 提前看到需求       |
| **provision**  | 供应；条款  | 同上                              |
| **propel**     | 推进     | pro(前) + pel(推)                 |
| **process**    | 过程；处理  | pro(前) + cess(走)                |
| **procession** | 行列；队伍  | 同上                              |
| **proceed**    | 继续进行   | pro(前) + ceed(走)                |
| **prosecute**  | 起诉     | pro(前) + secu(跟随) → 在法庭上紧追      |
| **propose**    | 提议     | pro(前) + pose(放) → 放到前面说        |

> 📌 **pre- vs pro-**：pre- 侧重"时间上的先"（在…之前），pro- 侧重"方向上向前"。

## 三、re- —「回」「再次」「反向」

| 词 | 核心义 | 拆解 |
|---|---|---|
| **reserve** | 保留；预订；储备 | re(回) + serve(保存) → 留作备用 |
| **restrain** | 抑制；约束 | re(回) + strain(拉紧) → 往回拉住 |
| **revise** | 修改；修订 | re(再次) + vise(看) → 回头看 |
| **retain** | 保留；保持 | re(回) + tain(拿) → 往回抓 |
| **reform** | 改革 | re(再次) + form(形态) → 重新塑形 |
| **reverse** | 反转 | re(回) + verse(转) → 转回去 |
| **reflect** | 反射；反思 | re(回) + flect(弯曲) → 弯回来 |
| **rebel** | 造反；反叛者 | re(反) + bel(战争) → 拿起武器反抗 |
| **recommend** | 推荐；建议 | re(再次/强调) + commend(推荐) |
| **rely** | 依赖 | re(加强) + ly(绑) → 紧紧地绑在上面 |
| **refract** | 折射 | re(回) + fract(断) → 光线断了折回来 |
| **revive** | 复兴；复苏 | re(再次) + vive(活) → 再次活过来 |
| **respective** | 分别的；各自的 | re(回) + spect(看) → 回头看各自那份 |

## 四、ex- / e- —「出」「向外」「超出」

| 词               | 核心义          | 拆解                                     |
| --------------- | ------------ | -------------------------------------- |
| **exclusive**   | 独有的；排外的；高档的  | ex(外) + clus(关) → 把别人关在门外              |
| **extensive**   | 广泛的；大量的      | ex(向外) + tens(拉伸) → 向外延伸               |
| **expensive**   | 昂贵的          | ex(出) + pens(钱) → 把钱交出去                |
| **explicit**    | 明确的；直截了当的    | ex(外) + plic(折) → 折叠的东西展开在外            |
| **expel**       | 开除；驱逐        | ex(向外) + pel(推) → 推出去                  |
| **expire**      | 到期；终止        | ex(出) + spire(呼吸) → 呼出最后一口气            |
| **expedite**    | 加快           | ex(出) + ped(脚) → 把脚拔出来 → 加速            |
| **extinguish**  | 熄灭；扑灭        | ex + sting(熄灭) → 让火出去                  |
| **extinct**     | 灭绝的          | ex + stinct → 火出去后的状态                  |
| **extravagant** | 奢侈的；挥霍的      | extra(超出边界) + vag(游荡) → 花钱超出边界         |
| **exaggerate**  | 夸张；夸大        | ex(超出) + agger(堆) → 堆得超出实际             |
| **excel**       | 胜过；擅长        | ex(出) + cel(高/升) → 站得比别人高              |
| **exile**       | 流放           | ex(出) + ile(走) → 离开故土                  |
| **execute**     | 执行；处决        | ex(出) + secu(跟随) → 让结果跟出来              |
| **executive**   | 高管；主管        | CEO = Chief **Executive** Officer      |
| **exceed**      | 超过           | ex(出) + ceed(走) → 走出去超过                |
| **expose**      | 暴露；使接触       | ex(出) + pose(放) → 放到外面。`be exposed to` |
| **elicit**      | 引出；探出（信息/反应） | e(出) + licit(引诱) → 把心思引诱出来             |
| **evidence**    | 证据           | e(出) + vid(看) + ence → 能看出来的事实         |

> 🚨 **exp- 家族快速辨析**：exploit(开发/剥削), explicit(明确的), expel(开除), expire(到期), expedite(加快), expound(详述) — 前两个是最高频，后几个一一记。

## 五、in- / im- —「内」「进入」「不」

前缀 in- 有两个完全不同的来源：(1) "在里面/进入" (2) "不"（否定前缀）。

### 含义1："在里面/进入"

| 词 | 核心义 | 拆解 |
|---|---|---|
| **implicit** | 含蓄的；暗示的 | im(里面) + plic(折) → 折在里面 |
| **inclusive** | 包含全部的；包容的 | in(里面) + clus(关) → 关在里面 → 圈进来 |
| **impose** | 强加；征收 | im(放到…上) + pose(放) → 放在你身上 |
| **impel** | 驱使（心理） | im(向内) + pel(推) → 推力进到内心 |
| **indicate** | 表明；暗示 | in(向内) + dic(说) + ate → 向内指出 |
| **instinct** | 本能 | in(内) + stinct(刺) → 刻在里面的标记 |
| **intrinsic** | 内在的；本质的 | intrin(内部) + sic → 长在里面的属性 |
| **introspective** | 内省的 | intro(向内) + spect(看) → 往内心看 |
| **invade** | 侵入；侵略 | in(进入) + vade(走) → 走进去 |

### 含义2："不"（否定）

| 词 | 核心义 | 拆解 |
|---|---|---|
| **improvise** | 即兴创作；临时凑合 | im(不) + pro(提前) + vise(看) → 没提前看 |
| **infinite** | 无限的 | in(不) + finite(有限的) |
| **inedible** | 不可食用的 | in(不) + edible(可吃的) |
| **illiteracy** | 文盲 | il(不) + literacy(读写能力) |

## 六、de- —「下」「离开」「完全」

| 词 | 核心义 | 拆解 |
|---|---|---|
| **detain** | 拘留；耽搁 | de(下/离开) + tain(拿) → 把人拿下扣住 |
| **defy** | 藐视；违抗 | de(离开) + fy(信任) → 离开信任 → 不服从 |
| **defiance** | 违抗（名词） | — |
| **delay** | 延迟 | de(离开) + lay(放置) → 放到一边 |
| **decay** | 腐烂；衰败 | de(离开) + cay(落) → 落下去 → 衰败 |
| **dedicate** | 致力于 | de(完全) + dic(说) + ate → 把自己完全说出去 |
| **deposit** | 存放；沉淀 | de(下) + posit(放) → 放下 |
| **derive** | 源自；获得 | de(离开) + rive(流) → 从源头流下来 |
| **delineate** | 描绘；阐述 | de(加强) + line(线) + ate → 用线画出轮廓 |
| **decent** | 体面的；像样的 | dec(合适/装饰) + ent。同源：decorate(装饰) |
| **define** | 定义 | de(完全) + fine(界限) → 划清界限 |
| **definite** | 确定的 | 同上 |
| **destruction** | 破坏 | de(相反) + struct(建造) → 反向建造 |

## 七、sub- / sup- —「下面」「次要」

| 词 | 核心义 | 拆解 |
|---|---|---|
| **subside** | 平息；减弱；下沉 | sub(下) + side(坐) → 坐下去 → 平息 |
| **subsidise** | 资助；给补贴 | sub(下) + sid(坐) → 从下面支撑你。名词：subsidy |
| **substitute** | 代替；替代品 | sub(下) + stitute(站) → 站在下面随时顶上去 |
| **subsequent** | 随后的 | sub(后) + sequ(跟随) → 时间上的跟随 |
| **submit** | 提交；屈服 | sub(下) + mit(送) → 从下面送上去 |
| **supplement** | 增补 | sup(下) + ple(满) → 从下面补上（不一定是补全） |
| **suppose** | 假设 | sup(下) + pose(放) → 放在下面默认成立 |
| **sustain** | 支撑；维持（生命） | sus(sub的变体) + tain(拿) → 在下面撑着拿 |
| **suspicious** | 怀疑的 | sus(下) + spic(看) → 从下面偷偷看 |
| **supervise** | 监督 | super(上面) + vise(看) → ⚠️ 这是 super- 不是 sub-！ |

## 八、trans- —「跨越」「转变」

| 词 | 核心义 | 拆解 |
|---|---|---|
| **transfer** | 转移；调动 | trans(跨) + fer(搬运) |
| **transform** | 改造；转变 | trans(跨) + form(形态) |
| **transit** | 运输；过境 | trans(跨) + it(走) → 走过去 |
| **transmit** | 传输；传播 | trans(跨) + mit(发送) |
| **transmission** | 传输（名词） | 同上 |
| **transparent** | 透明的；显然的 | trans(穿过) + parent(出现) → 穿过也能看到 |

## 九、inter- vs intra- / intr- —「之间」vs「内部」

| 词 | 核心义 | 拆解 |
|---|---|---|
| **intersection** | 十字路口；交集 | inter(之间) + sect(切) → 两条路相互横切 |
| **intervene** | 干涉；调停 | inter(之间) + vene(走) → 走到中间 |
| **intrinsic** | 内在的；本质的 | intrin(内部) + sic → 长在里面 |
| **introspective** | 内省的 | intro(向内) + spect(看) → 往内心看 |

> 📌 **intersection vs intrinsic**：前者是"两个外部物体相撞"，后者是"一个物体深处自带的"。

## 十、a- 双写辅音 —「朝向」「加强」

| 词 | 核心义 | 拆解 |
|---|---|---|
| **assimilate** | 同化；吸收 | as(朝向) + simil(相同) + ate → 使其变得相同 |
| **affiliate** | 使隶属；加盟 | af(朝向) + fili(儿子) + ate → 收为义子 |
| **aggregate** | 聚集；合计 | ag(朝向) + greg(群) + ate → 赶到群里 |
| **aggravate** | 加重；使恶化 | ag(加强) + grav(重) + ate → 让事情变沉重 |
| **assemble** | 集合；组装 | as(向) + semble(一起) → 拨到一起 |
| **assess** | 评估；评定 | as(向) + sess(坐) → 坐在旁边观察你 |
| **arouse** | 唤起；激起 | a(加强) + rouse(唤醒) → 常接"兴趣/情绪" |
| **anonymous** | 匿名的 | an(无) + onym(name名字) + ous → ⚠️ 这里的 an- 是否定！ |
