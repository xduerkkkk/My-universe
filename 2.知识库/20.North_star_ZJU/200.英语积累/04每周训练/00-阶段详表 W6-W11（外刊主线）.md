# 第一阶段详表 W6–W11｜外刊主线 + 老真题喂框架

> 总表见 [[00-规划一览]] 英语三阶段；卡点阈值见 [[02-english]] 三个硬门。
> **本文件只管：这六周每天做什么。** 单篇怎么做看 [[00做题框架]]，陷阱看 [[01陷阱整理]]，外刊怎么读看 [[读文献初期SOP方法论]]。
> 2026-08-31 改版落地：阅读从「一天一真题」转为「外刊长能力 + 老真题保温框架」。

## 一句话原则

- **外刊长底座**（语言流畅度 + 篇章论证分析），**老真题只保温框架**，**近年真题冻结**。
- 判断标准不是「读了几篇」，是**每篇外刊的篇章测绘有没有做出来**——测绘不做，等于只刷语感，底座不长。

## 篇章测绘：每篇外刊读完必做（3–5 分钟，不翻译全文）

> 这是外刊起效的开关。你现在卡的是「中文都反应不出角色/情感/逻辑」，这一层纯读读不出来，必须显式测绘。测绘做完信心涨、底座没涨，是本阶段最大的假进步（对应 [[01陷阱整理]] 第 7 类）。

读完当场在页边/笔记写四行，写不出就是没读懂，回原文：

1. **角色**：出场几方？各自立场一句话（`A 主张 X / B 反对 / 作者……`）。
2. **作者站哪边**：哪个词暴露态度（`certainly` 认同 / `but` 转折 / 反讽 / `seems` 保留）。
3. **转折点**：全文在哪几处拐弯？逻辑链画成箭头（`现象 → 原因 → 反驳 → 作者结论`）。
4. **一个原文证据句**：挑一句真正承载主旨的句子，抄下来——不是最长的，是最关键的。

> 这四行直接对接 [[00做题框架]] 的「定主体 / 数步数 / 观点归属」。等于每篇外刊都在练真题的映射层，而不只是背景阅读。
> 词汇：只记「在句子里绊住你」的，进主库随 App 结算；**不为外刊单建词库**（[[02-english]] 已定）。
