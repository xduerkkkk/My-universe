## 2. 单篇流程（约 60 分钟，2026-07-30 改）

|       时间 | 动作                             |
| -------: | ------------------------------ |
|    30 秒 | **抄**画像那三条清单到答题纸边上。抄，不是默念 |
|    18 分钟 | 裸答，标限时信心 H/M/L。**首答字母落笔后这栏不许动** |
|     5 分钟 | **考场检查，不查词**：先圈功能词，再梳理逻辑关系。终答记这一步的结果 |
|          | ⬇ **查词分界线**——线以上全是考场能力 |
|          | 查词，只留真正干扰做题的词 + 觉得难拆或觉得好的句子。**不标注分类**，周报时 AI 判 |
| 12—18 分钟 | 对答案，写自己的错因识别 |

**这 5 分钟检查是本流程最重要的改动。** 旧版的「8 分钟证据审判」允许查词，导致终答混着词典能力——首答 64%、终答 80%，中间那 16 个点在考场上一分都拿不到。现在终答是「裸考 + 考场检查」，**考场真的有这 5 分钟**，所以终答−首答第一次成了可迁移的数。

**痕迹写在检查阶段**：对各选项的完整思维链，想多少写多少。这是最高价值的部分。

> [!important] 首答是唯一进趋势判断的数字
> 09 T1—10 T1 五篇：**首答 16/25 = 64%，终答 20/25 = 80%**，4 题差值全部来自查词或查翻译。
> 考场没有词典、没有第二遍。**64% 才是考场数，80% 是查词能力数。**目标 85 分要求约 85% 首答率，真实缺口是 64%→85%。
> 此前所有历史记录（含画像周结算表）填的都是终答，所以首答有没有变过，无法判断。从 2026-07-28 起两栏分记。

### 分工：你记事实和自诊，AI 做跨篇分类

**你记六样**：

1. 首答字母
2. **限时信心** H / M / L —— 18 分钟里的感受
3. **检查后信心** H / M / L —— 5 分钟检查之后的感受。**这两栏必须分开**
4. 对错
5. **「靠哪一句」** —— 改答和维持原答都要写。写不出来就写「没有，只是觉得更顺」
6. **读前清单抄没抄**（勾一下）

> [!warning] 第 2、3 栏为什么必须分开
> 2009 T4 Q2/Q5 只记了一个 L，AI 读成「你最终也没把握」，误判成病灶复现。实际是限时 L、检查后 H。一栏装不下两个状态，会直接导致误判。

加上**你的错因识别**——对完答案后自己写。这一栏留着，不要因为 AI 也会分类就省掉：W1 里你写的「感觉 D 很对，所以会把 C 潜意识往不对得想吗？」比 skill 里对病灶 3 的描述更准。AI 的活是拿你的自诊跟机制比对，只标不一致处（比如你写「没把握到作者情感」，机制其实是取了 `but` 之前的态度）。

**痕迹要诚实到难看**：「我读不懂」「蒙的」「不知道啥逻辑」都是最高价值信号，不要美化成看起来像分析的样子。

**你不贴病灶编号。** 分类要靠跨年频次比对，那是 AI 的活。查词区的词和句子也**不标注分类**，标注权归 AI——只求贴在对应那道题的痕迹附近，跨篇混在一起就判不出「干扰了哪道题」。

加上你一直在写的原始推理。**痕迹要诚实到难看**：「我读不懂」「蒙的」「靠情绪猜的」「不知道啥逻辑」都是最高价值信号，不要美化成看起来像分析的样子。2007 那份是历史最好的痕迹，就因为你把「我不懂 layoff，躺平？」这种话原样写下来了。

**痕迹写完不调 AI。** 自己对答案、自己写错因识别。周六一次性喂本周 5 篇给 `/reading-review`。

理由：AI 的唯一价值是跨篇模式匹配，单篇调用恰好是它最弱的场景——它只能复述你已经知道的东西，这正是「禁止复述解析」这条规则要防的。5 篇一起喂，跨篇比对才成立。
代价是元问题最长压 5 天，中途真卡住可以单独问一句，但不走完整流程。

### 改答案门槛（2026-08-01 换过）

**改答必须写得出一句新的原文证据句。** 写不出就维持原答。

旧门槛是「只在查到新的具体词义时才改」。检查阶段改成不查词之后，没有任何改答能满足它，那条已经作废。

这不是教条，是你自己的数据。W1 新协议下 5 次改答，这条规则 3/3 预测准确：

| 改答 | 理由 | 判定 | 结果 |
|---|---|---|---|
| T3Q5 D→C | 引了 `not of a few influentials but... easily influenced people` | 放行 | 错→**对** |
| T4Q2 C→D | 引了 `more flexibility in recognizing losses` | 放行 | 错→**对** |
| T3Q1 B→D | discuss/describe 字面差异，无引句 | 拦下 | 对→**错** |
| T3Q2 a→B | 「整段作者的情感是说」，无引句 | 拦下 | 错→错 |
| T3Q4 B→D | 「结合此段逻辑」，无引句 | 拦下 | 错→错 |

放行 2 次全部有益，拦下 3 次里 1 次有害 2 次无损，**净赚 1 题**。它在考场可执行的原因是判据只有一个动作：我能不能指着一句原文。

## 3. AI 的职责边界

完整规则在 `/reading-review` skill（`.claude/skills/reading-review/SKILL.md`）。核心几条：

- **禁止复述解析。** 你已经对过答案，不需要第二份。AI 的唯一价值是跨篇模式匹配
- **周批上限 25 行**（5 篇合计）。不写逐题判决表，不写「下次动作」（会和读前清单重复）
- **AI 自己核首答计数，不抄你的汇总表。** W1 你把 T3 的 2/5 写成 3/5（首答 D、终答 C 判对的题算进了首答），整周率从 40% 虚高到 45%
- **查词区由 AI 分类**：真干扰做题的词 / 好句子 / 难拆的句子，你不标注
- **不另建周报 skill。** 数学 408 和整周综合走现有周报（[[1.工作流/10.日记文件/周报]]）；`/reading-review` 只管英语，产出物是画像更新 + 下周训练文件。英语结论摘一行进周报第三节即可
- **必须回写画像 + 必须生成下周文件。** 不回写就只是堆积，这是旧错因台账失败的直接原因
- **频次按首答判定**

## 4. 5 分钟考场检查怎么做（四问）

1. 题干问谁 / 什么？**功能词圈了吗**（题干里的 often / mainly / according to 也算）
2. 候选项的核心谓词是什么？（不许把精确词柔化成模糊大意）
3. 原文哪一句能完整支持？——**改答就靠这一问，指不出句子不许改**
4. 错误选项死在**哪个词**？——必须指出具体的词，不接受「重心不对」「感觉没用」

第 4 问是病灶 3 的直接对策，做对了也要能答出来。第 3 问是改答门槛。

## 4.5 读前 30 秒清单（对策的唯一形态，2026-08-01 改）

**事后打勾的「对策执行三选一」已删除。** W1 你的判断是「做题的时候根本不会想起这个复选框」，对——它测的是回忆，而你缺的是当场触发。

现在对策只有一个形态：**做题前 30 秒，把画像那三条抄到答题纸边上。**

1. 先圈功能词：`has been / appears / would / may / but / yet / only / ever since`
2. 抽象词和多词搭配，先写下你认为的义项再比选
3. 每题说出两个干扰项死在哪个词，做对了也说

**抄，不是默念。** 三条都直接对应本周实证的失分点，第 1 条对应四篇全中的那个动作。

周六只统计一件事：**三条各执行了几篇。** 某条 0 篇，说明那条清单本身不可执行，当场改清单——这是唯一需要改设计的信号。

## 5. 复习节奏｜走每周单文件，不进日记也不进回滚台账

英语全部收进 `200.英语积累/04每周训练/` 的当周文件，从日记和 [[1.工作流/回滚台账]] 迁出。

原因：英语排期项颗粒细、周期短（词卡抽查、错题复判），混进以数学 408 为主的按日台账会被冲掉——迁出时那张表上 3 条英语待做项全部欠着。周文件按天预排，打开就做。

### 一周排布（周日到周六，2026-08-01 改）

| 日 | 内容 |
|---|---|
| **周日** | 低压力 prep：选下周 5 篇 + 每篇 3 分钟查中文背景 + 技巧课 + 清未结账 |
| **周一至周五** | 每天 1 篇，约 60 分钟。① 检测抽查　② 新单元　③ 真题　④ 回滚 |
| **周六** | 周报日，不学新内容 |

**周日为什么值得单独占一天**：W1 的 T4（银行会计准则 + FASB/IASB 政治博弈）你的判断是「就算给我中文翻译，我也不能快速反应作者情感」——那是背景空白，不是英语问题，读前 3 分钟能填。技巧刻意练习也落在这天，因为周一到周五五篇已经占满。

周六生成下一周文件，排期项直接写进对应天的「④ 回滚」。

### 抽查改成检测型（2026-07-28）

原来的抽查是**回忆型**（遮住释义说出 decline 的意思）——你答得出来，decline 你本来就认识。10 T1 Q1 错在没察觉 `has been an inexorable decline` 和 `disappear` 之间有一格程度差加一个时态信号。**回忆型永远测不出这个缺口，因为缺口不在词库里，在限时压力下的比对动作里。**

新格式：给原文表达 + 一个改写，只答**差在哪一维**——`等价 / 程度 / 时态 / 主体 / 范围 / 方向`。每张 10 秒，每天 8 张，其中 3 张强制来自程度·时态桶。

判定三档：A（说出维度）／**B（说得出词义、说不出差异——回忆型会把这一档误判成通过）**／C（答错）。B/C 进当周 C 项清单，周六混测必抽；连续两次 B/C 进画像高危表。

### 为什么这样就不会积压

关键在于**复习对象是病灶，不是文章**。

三条病灶是所有文章共享的。写第 10 篇时，画像还是三条，只是计数变了。所以**复习量不随文章数线性增长**——这是你担心的「记不过来」的解法。

每天「④ 回滚」栏只有一项：复判昨天那篇的错题（3—5 分钟，遮住解析复述「证据位置—正确谓词—干扰项死词」，不重选字母）。词卡抽查就是「① 检测抽查」那 5 分钟。

### 周六结算（约 60 分钟，含批量分析）

顺序固定：填汇总表算首答率 → 一次性喂本周 5 篇给 `/reading-review` → 词卡入库 → 生成下周文件 → 更新画像。

画像里更新：
- 各病灶本周复现次数（**按首答判定**）→ 写进「周结算记录」表
- **本周首答率**（唯一进趋势判断的数字）
- **检查净收益**（终答−首答）。新协议下这是可迁移的数，因为考场真有那 5 分钟
- 改答账：有引句放行 / 无引句拦下，各自的对错分布
- 连续 2 周未复现 → 「观察」；连续 4 周 → 「已退役」，移出活跃区
- 扫「未结账」区，超 2 周未结的提醒

### 连做｜每月一次，不消耗任何额外真题

**缺口**：所有首答数据都是单篇、脑子新鲜、18 分钟。考场是四篇连做 70—80 分钟，T3/T4 有疲劳衰减，无间隙重置。**从未练过连做**，所以现有首答率本身偏乐观。

**便宜的做法**：把本来要分四天做的四篇，改成同一天一口气做完，75 分钟限时，只记首答，第二天再补精读。同样四篇，成本为零。

代价是当天单篇深度下降，所以**每月一次**。放在月末那一周，正好当月度体检。

- App 背单词 20 分钟保持不变
- 外刊每周 2—3 次、每次 15—20 分钟，只提炼主旨/态度/1 个关键句，不建词库
- 没有额外时间时优先保证真题

## 6. 题型与陷阱清单

**题型**：细节题（回定位句及前后句）｜推断题（只迈有证据的一小步）｜例证题（判断例子服务于哪个观点，看前后概括句）｜词句题（优先看固定表达和逻辑，不硬拆单词）｜主旨题（串各段功能，排除只覆盖局部的项）｜态度题（依据评价词、转折、论证方向）

**陷阱**：偷换主体/宾语｜无中生有｜半对半错｜跨段跨对象拼接｜程度范围可能性变化｜因果方向倒置｜局部细节冒充主旨｜真话但答非所问
