# 01 — 词根辨析·核心词根（上）

> 按词根系统分组。每个词根家族内部各词，看似相像，实则方向/动作不同。
> 考研英语一完形填空、阅读词汇题的核心出题逻辑就在词根辨析。

---

## 一、cap / capt / cept —「抓取」与「头」

这个词根有两个源头，考研最爱混在一起考。

### 【分支 A：抓取 (take/seize)】

| 词             | 词性      | 核心义          | 记忆锚点                        |
| ------------- | ------- | ------------ | --------------------------- |
| **capacity**  | n.      | 容量；能力        | cap(抓) + acity → 能"抓"住多少东西  |
| **capture**   | v./n.   | 捕获；俘获；捕捉(画面) | capt(抓) + ure → 抓住的动作       |
| **captivate** | v.      | 迷住；吸引        | capt(抓) + ivate → 注意力被"抓走"了 |
| **captive**   | n./adj. | 俘虏；被关押的      | 被"抓"住的人/动物                  |
|               |         |              |                             |

### 【分支 B：头 (head)】

| 词           | 核心义        | 记忆锚点               |
| ----------- | ---------- | ------------------ |
| **capital** | 首都；资本；大写字母 | 国家/地区的"头儿"；"头大的字母" |
| **caption** | 标题；说明文字；字幕 | 放在图片/文章"头部"的文字     |

> 📌 考研重点：capacity 作"能力"时常考搭配 `capacity for sth.`；capital 的"资本"义在经济类文章中极高频。


## 二、cede / ceed / cess —「走」

词根 `cede/ceed/cess` = go, yield（走，让步）。

| 词 | 词性 | 核心义 | 词根拆解 | 考研要点 |
|---|---|---|---|---|
| **precede** | v. | 先于…（发生/存在） | pre(前) + cede(走) | ⚠️ "A is preceded by B" = B先发生，极易搞反！ |
| **precedent** | n. | 先例；前例 | pre + ced + ent | `set a precedent` 开创先例 |
| **preceding** | adj. | 前面的；在先的 | 同上 | `in the preceding chapters` |
| **unprecedented** | adj. | 史无前例的 | un + pre + ced + ented | 🔥 考研极其高频！ |
| **proceed** | v. | 继续进行 | pro(向前) + ceed | `proceed to do sth.` |
| **process** | n./v. | 过程；处理 | pro(向前) + cess(走) | `in the process` |
| **procession** | n. | 行列；队伍 | 同上 | 一群人整齐地"向前走" |
| **exceed** | v. | 超过；超越 | ex(出) + ceed(走) | `exceed expectations` |
| **excess** | n./adj. | 过度；过量 | 同上 | `in excess of` = 超过 |
| **concede** | v. | 让步；承认 | con(一起) + cede(让步) | `concede defeat` 认输 |
| **succeed** | v. | 成功；继承 | suc(下) + ceed → 跟着走下去 | "成功"义是引申出来的！ |
| **succession** | n. | 连续；继承 | 同上 | `in succession` 接连地 |
| **access** | n./v. | 进入；通道；访问 | ac(向) + cess(走) | `have access to` |

## 三、dict / dic —「说」

词根 `dict/dic` = say（说）。

| 词 | 核心义 | 词根拆解 | 考研要点 |
|---|---|---|---|
| **indicate** | 表明；暗示 | in(向内) + dic(说) + ate | "向内指出" → 表明 |
| **dedicate** | 致力于；奉献 | de(完全) + dic(说) + ate | "把自己说出去" → 奉献。`dedicate oneself to` |
| **predict** | 预测 | pre(前) + dict(说) | "提前说" |
| **contradict** | 矛盾；反驳 | contra(反) + dict(说) | "反着说" |
| **verdict** | 裁决 | ver(真实) + dict(说) | "说出真相" → 法律用语 |

---

## 四、fer —「搬运」

词根 `fer` = carry, bring（搬运，带来）。

| 词 | 核心义 | 词根拆解 |
|---|---|---|
| **transfer** | 转移；调动 | trans(跨) + fer(搬运) → 从一处搬到另一处 |
| **refer** | 参考；提及；指的是 | re(回) + fer → "带回"到某个出处。`refer to` |
| **prefer** | 更喜欢 | pre(前) + fer → 把某个选项"拿到前面来" |
| **infer** | 推断 | in(进入) + fer → "带进"结论 |
| **differ** | 不同 | dif(分开) + fer → "分开搬运" → 分道扬镳 |
| **confer** | 商议；授予 | con(一起) + fer → "把意见带到一起" |
| **offer** | 提供 | of(向) + fer → "带给"对方 |

## 五、flict —「打击」

词根 `flict` = strike（打击）。

| 词 | 核心义 | 词根拆解 | 搭配 |
|---|---|---|---|
| **conflict** | 冲突；矛盾 | con(一起) + flict(打) → 打在一起 | `resolve a conflict` |
| **inflict** | 施加（痛苦/伤害/惩罚） | in(加在…上) + flict(打) | `inflict pain on sb.` / `inflict heavy losses` |
| **afflict** | 折磨；使痛苦 | af(向) + flict(打) | `be afflicted with` |

---

## 六、form —「形态」

词根 `form` = shape（形状，形态）。

| 词 | 核心义 | 词根拆解 |
|---|---|---|
| **transform** | 改造；转变；变形 | trans(跨) + form → 跨越形态 |
| **conform** | 遵从；符合 | con(共同) + form → 形状一致 → 符合。`conform to` |
| **reform** | 改革 | re(再次) + form → 重新塑形 |
| **perform** | 执行；表演 | per(完全) + form → 完全成形 → 执行到位 |
| **deform** | 使变形；使畸形 | de(离开) + form → 离开正常形态 |

> ⚠️ **confirm**（确认）不是 form 家族的！它是 `con + firm(坚固)`，"使之坚固" → 确认属实。

## 七、greg —「群体」

词根 `greg` = flock（羊群，群体）。

| 词 | 核心义 | 词根拆解 | 搭配 |
|---|---|---|---|
| **aggregate** | 聚集；合计；总数 | ag(向) + greg(群) + ate → 赶到一个群里 | `aggregate demand` 总需求 / `in the aggregate` 总计 |
| **gregarious** | 爱交际的；群居的 | greg + arious → 喜欢待在群体里的 | — |
| **segregate** | 隔离；种族隔离 | se(分开) + greg + ate → 把羊群分开 | `racial segregation` |

> 📌 **aggregate vs aggravate**：aggregate 关于"多"（数量的累加），aggravate 关于"坏"（程度加深）。aggravate 来自 grav(重)，不是 greg(群)！

## 八、lect / leg / lig —「选」「法」「绑」

三个同形词根，来源不同，必须区分。

### 【分支 A：lect = choose（选）】

| 词 | 核心义 |
|---|---|
| **collect** | 收集（col-一起 + 选） |
| **select** | 精选（se-分开 + 选） |
| **neglect** | 忽视（neg-不 + 选 → 没选上） |
| **intellect** | 智力（intel-在中间 + 选 → 辨别力） |
| **intellectual** | 智力的；知识分子 |

### 【分支 B：leg = law（法）】

| 词 | 核心义 | 辨析要点 |
|---|---|---|
| **legal** | 法律的；合法的 | 中性词，沾法律的都算 |
| **legislation** | 立法；法规（集合） | 强调"制定法律的过程"或"法案整体" |
| **legitimate** | 合法的；正当的；合理的 | 🔥 不强调"不违法"，而强调"合情、合理、正统"。生病请假是 `legitimate reason`，不能说 `legal reason` |
| **legit** | （口语）靠谱的 | `That guy is legit.` |

### 【分支 C：lig = bind（绑）】

| 词 | 核心义 | 词根画面 |
|---|---|---|
| **religion** | 宗教 | re(反复) + lig(绑) → 把信仰紧紧绑在一起 |
| **oblige** | 迫使；使负有义务 | ob(向) + lig(绑) → 被责任"绑住"。`be obliged to do` |
| **obligation** | 义务；责任 | 同上 |
| **alliance** | 联盟 | al(去) + li(绑) + ance → 把国家绑在一起 |
| **liable** | 有责任的；可能要受…的 | li(绑) + able → 被绳子拴在结果上，跑不掉。`liable for damages` |
| **liability** | 责任；负债 | 同上 |

## 九、mit / miss —「发送」

词根 `mit/miss` = send（发送）。

| 词 | 核心义 | 词根拆解 |
|---|---|---|
| **transmit** | 传输；传播 | trans(跨) + mit(发送) |
| **transmission** | 传输；传播（名词） | 同上 |
| **submit** | 提交；屈服 | sub(下面) + mit → 从下面送上去 |
| **commit** | 承诺；犯（罪）；致力于 | com(一起) + mit → 把承诺"发送"到位 |
| **admit** | 承认；准许进入 | ad(向) + mit → 发送进去 |
| **permit** | 允许 | per(通过) + mit → 发送通过 |
| **dismiss** | 解散；解雇；不予理会 | dis(离开) + miss(送) → 送走 |
| **mission** | 使命；任务 | miss + ion → 被"派送"出去的任务 |

## 十、magn / maj / max —「大」

词根 `magn` = great（大）。

| 词 | 核心义 | 词根拆解 | 搭配 |
|---|---|---|---|
| **magnitude** | 巨大；重要性；震级 | magn(大) + itude(状态) | `earthquake of magnitude 7.0` / `the magnitude of the problem` |
| **magnificent** | 宏伟的；壮丽的 | magn(大) + fic(做) + ent → 造得很大的 | `magnificent scenery` |
| **major** | 主要的；专业 | maj(大) + or | `major in` |

## 十一、stru / struct —「建造」

词根 `struct` = build（建造）。

| 词 | 核心义 | 辨析要点 |
|---|---|---|
| **construct** | 建造；构筑（理论） | 考研常考"构筑理论/模型"而非物理盖楼 |
| **construction** | 建设；建筑 | `under construction` |
| **destruction** | 破坏 | de(相反) + struct |
| **instruct** | 指示；教导 | in(内部) + struct → 在内部建造知识 |
| **instruction** | 指令；说明 | — |

## 十二、manu / man —「手」

词根 `manu/man` = hand（手）。

| 词 | 核心义 | 辨析要点 |
|---|---|---|
| **manufacture** | (v./n.) 制造 | manu(手) + fact(做) → 用手做 |
| **manufacturing** | (n.) 制造业（行业产业） | 区别于 manufacture 的动作义。`lump manufacturing and services together` |
| **maintain** | 维持；维修 | main(手) + tain(拿) → 用手扶着。详见 tain 家族 |
| **manual** | 手册；手工的 | manu + al → 跟手有关的 |
