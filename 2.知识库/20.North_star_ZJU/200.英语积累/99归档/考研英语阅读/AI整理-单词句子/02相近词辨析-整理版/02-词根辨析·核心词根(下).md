## 一、pel / puls —「推」

词根 `pel/puls` = push, drive（推动，驱动）。**方向前缀 + pel = 完全不同的动作。**

| 词 | 核心义 | 词根拆解 | 考研要点 |
|---|---|---|---|
| **expel** | 开除；驱逐；排出 | ex(向外) + pel(推) | 由内而外的剧烈动作。`expel from school` |
| **impel** | 驱使；迫使（心理驱动） | im(向内) + pel | 某种责任感/恐惧"推"着你行动。不同于 compel |
| **compel** | 强迫；迫使 | com(一起) + pel | 压力来自四面八方，不得不做 |
| **propel** | 推进；驱动 | pro(向前) + pel | 如螺旋桨 propeller |
| **repel** | 击退；使厌恶 | re(回) + pel | "推回去" |
| **impulse** | 冲动；脉冲 | im + puls | 内心的"推力"。`on impulse` 冲动之下 |

## 二、plic / ply / plex —「折叠」

词根 `plic/ply/plex` = fold（折叠）。**折在里面 vs 展开在外面，决定了一切。**

| 词 | 核心义 | 词根画面 | 搭配 |
|---|---|---|---|
| **implicit** | 含蓄的；暗示的；盲从的 | im(里面) + plic(折) → 意思折在里面 | `implicit assumption` / `implicit trust` |
| **explicit** | 明确的；直截了当的 | ex(外面) + plic(折) → 折叠的东西展开在外面 | `explicit instructions` |
| **imply** | 暗示 | im(里面) + ply(折) | — |
| **complicate** | 使复杂化 | com(一起) + plic + ate → 折在一起 | — |
| **comply** | 遵守；服从 | com(一起) + ply(折) → 折到同一方向 | `comply with` |
| **duplicate** | 复制 | du(二) + plic + ate → 折成两份 | — |

## 三、pose / pon —「放」

词根 `pose/pon` = put, place（放置）。**前缀决定"怎么放"。**

| 词 | 核心义 | 词根拆解 | 搭配 |
|---|---|---|---|
| **impose** | 强加；征收（税） | im(放到…上) + pose | `impose a tax` / `impose on sb.` |
| **oppose** | 反对 | op(对着) + pose → 对着放 | `oppose the plan` |
| **compose** | 组成；创作；使平静 | com(一起) + pose → 放在一起 | `be composed of` |
| **dispose** | 处理；安排；使倾向于 | dis(分开) + pose → 分开放 | `dispose of` / `be disposed to do` |
| **expose** | 暴露；使接触 | ex(出) + pose → 放到外面 | `be exposed to` |
| **suppose** | 假设；认为 | sup(下面) + pose → 放在下面（默认成立） | — |
| **propose** | 提议；求婚 | pro(前) + pose → 放到前面来说 | `propose a plan` |
| **deposit** | 存放；沉淀；押金 | de(下) + posit(放) | `deposit money` |

## 四、spect / spic —「看」

词根 `spect/spic` = look, see（看）。**看的方向决定词义。**

| 词 | 核心义 | 词根拆解 | 搭配 |
|---|---|---|---|
| **prospect** | 前景；展望 | pro(前) + spect(看) → 向前看 | `career prospects` |
| **perspective** | 视角；观点；透视法 | per(穿透) + spect(看) → 看透 | `from a historical perspective` |
| **respective** | 分别的；各自的 | re(回) + spect → 回头看各自那一份 | `respective roles` |
| **respect** | 尊重 | re(回) + spect → 回头看 → 重视 | — |
| **inspect** | 检查；视察 | in(里面) + spect → 往里面看 | — |
| **conspicuous** | 显眼的；引人注目的 | con(一起) + spic + uous → 大家都看到 | 考研高分词 |
| **suspicious** | 怀疑的 | sus(下面) + spic → 从下面偷偷看 | — |
| **conspiracy** | 阴谋；共谋 | con(一起) + spir(呼吸) → 一起密谋 | ⚠️ 不是 spect 家族！ |
| **perspicuous** | 表达清晰的 | per(穿透) + spic + uous | 补充高级词 |

## 五、sist / stitut / stitute —「站立」「建立」

词根 `sist/stitut` = stand, set up（站立，建立）。

| 词 | 核心义 | 词根拆解 | 搭配 |
|---|---|---|---|
| **constitute** | 组成；构成；设立 | con(共同) + stitute(站) → 站在一起 | `Women constitute 50% of the workforce.` |
| **constituent** | 选民；成分；构成的 | 构成整体的"小单元" | `chemical constituents` / `constituent assembly` |
| **constitution** | 宪法；章程；体质 | 国家立国之本的"建立"文件 | `the US Constitution` / `a strong constitution` |
| **substitute** | 代替；替代品；替补 | sub(下面) + stitute(站) → 站在下面随时顶上去 | `substitute A for B` |
| **institute** | 机构；学院；建立 | in(内部) + stitute → 建立在内部的体系 | — |
| **institution** | 制度；机构 | 同上 | 考研社会类文章极高频 |
| **instinct** | 本能；天性 | in(内部) + stinct(刺/标记) → 刻在骨子里的标记 | ⚠️ 不是 stitut 家族！但形近 |
| **consistent** | 一致的；始终如一的 | con + sist(站) + ent → 站在一起的 | — |
| **insist** | 坚持 | in(在上面) + sist → 站在上面（立场不退） | `insist on` |
| **persist** | 坚持；持续 | per(完全) + sist → 一直站着 | `persist in` |
| **resist** | 抵抗；抵制 | re(回) + sist → 往回站 → 不前进 | — |

| **contain**   | 包含；容纳        | con(一起) + tain → 把东西拿进一个框里     | 侧重容量和界限                      |
| **retain**    | 保留；保持        | re(回) + tain → 东西想溜，一把抓回来      | `retain the original style`  |
| **maintain**  | 维持；维修；养护     | main(手) + tain → 用手不断扶着        | `maintain order`             |
| **sustain**   | 支撑；维持（生命/生存） | sus(下面) + tain → 从下方死死撑住       | `sustainable development` 🔥 |
| **detain**    | 拘留；耽搁        | de(下/离开) + tain → 把人强行拿下来扣住    | —                            |
| **attain**    | 达到；获得（目标/成就） | at(向) + tain → 伸长手臂够到          | `attain one's goal`          |
| **obtain**    | 获得；得到        | ob(向) + tain → 拿到手             | —                            |
| **entertain** | 娱乐；招待        | enter(之间) + tain → 在客人之间"拿着"气氛 | —                            |

词根 `tract` = pull, draw（拉，拖）。

| 词 | 核心义 | 词根拆解 |
|---|---|---|
| **attract** | 吸引 | at(向) + tract → 拉过来 |
| **extract** | 提取；摘录；拔出 | ex(出) + tract → 拉出来 |

| **distract** | 分散（注意力）；使分心 | dis(分开) + tract → 把注意力拉开 |
| **abstract** | 抽象的；摘要 | abs(离开) + tract → 从具体中拉出来 |

## 十、vis / vid —「看」

词根 `vis/vid` = see（看）。**"看"的方向和时机决定词义。**

| 词 | 核心义 | 词根画面 | 搭配 |
|---|---|---|---|
| **provide** | 提供；供应 | pro(前) + vide(看) → 向前看到需求，提前准备 | `provide sb. with sth.` |
| **provision** | 供应；条款；预备 | 同上 | `make provisions for` |
| **revise** | 修改；修订；复习 | re(再次) + vise(看) → 回头看一遍 | `revise the draft` |
| **supervise** | 监督；管理 | super(上面) + vise(看) → 居高临下看 | — |
| **envisage/envision** | 展望；想象 | en(进入) + vis(看) → 在脑海中"看" | `envisage a future` |
| **evidence** | 证据 | e(出) + vid(看) + ence → 能看出来的事实 | 🔥 考研必考 |
| **evident** | 明显的 | 同上 | — |
| **improvise** | 即兴创作；临时凑合 | im(不) + pro(提前) + vise → 没提前看 | — |
| **visual** | 视觉的 | vis + ual(形容词) | `visual arts` |
| **visible** | 可见的 | vis + ible(可以…的) | — |

## ⚡ 小型词根集合

以下是不太庞大但同样重要的词根家族，从原8篇笔记中完整提取。

### cred —「信任」

| 词 | 核心义 | 辨析 |
|---|---|---|
| **credential** | (n.) 资质；资格证书 | 证明你"值得被信任"的实体材料。常用复数 `credentials` |
| **credence** | (n.) 信任；相信 | 抽象的心理状态。`give credence to a rumor` |
| **credible** | (adj.) 可靠的；可信的 | — |
| **credulous** | (adj.) 轻信的；耳根子软的 | ⚠️ 注意区别于 credible！ |

### jur / jus —「法」「正义」

| 词 | 核心义 | 搭配 |
|---|---|---|
| **jurisdiction** | (n.) 司法权；管辖权 | juris(法) + dict(说) + ion → "法律说了算的地方" |
| **jury** | (n.) 陪审团 | `the jury finds sb. guilty` |
| **judicial** | (adj.) 法庭的；司法的；公正的 | — |
| **justice** | (n.) 正义；司法；法官 | `bring sb. to justice` |
| **justify** | (v.) 证明…是正当的；辩护 | 🔥 写作高频。`justify the cost` |
| **justification** | (n.) 正当理由 | — |
| **testify** | (v.) 作证；证明 | ⚠️ 不是 jur 家族，但常混淆。`testify in court` |

### fract / frag —「破碎」

| 词 | 核心义 | 辨析 |
|---|---|---|
| **fracture** | (n./v.) 骨折；断裂 | 硬物的断裂/裂缝（X光片上的线） |

| **friction** | (n.) 摩擦；冲突 | 来自同一词源。`trade friction` |
| **fragrant** | (adj.) 芳香的 | ⚠️ 不是破碎家族！来自 fragrare(发出气味) |

| **efficient** | 高效的 | ef(出) + fic(做) → 做出成果的 |
| **sufficient** | 足够的 | suf(下面) + fic → 在下面垫够 |
| **artificial** | 人工的；人造的 | arti(艺术/技巧) + fic + ial |
| **superficial** | 表面的；肤浅的 | super(上面) + fic → 只做到表面的 |

### fleet / flex —「弯曲」

| 词 | 核心义 | 词根拆解 |

| **flexible** | 灵活的；可弯曲的 | flex(弯) + ible → 可以弯的 |
