# 
### VIS / VID 家族：核心是“视线的投射”

#### 1. Provide (向前看 → 预见需求 → 供应)

- **词源逻辑：** pro- (向前) + vide (看)。
    
- **Native 画面：** 想象一个猎人，在出发前**往前看**到了路途遥远可能会饿，于是提前准备好了干粮。
    
- **感觉：** 因为“预见”到了需要，所以**“提供/准备”**。
    
- **对比补充：**
    
    - **Provision (n.)**: 预备、条款、食物供应。
        
    - **Prudent (adj.)**: 它是 provident 的缩写。向前看的人 → **谨慎的/有远见的**。
        

#### 2. Revise (再次看 → 检查错误 → 修订)

- **词源逻辑：** re- (再次) + vise (看)。
    
- **Native 画面：** 写完作文后，你的眼睛**回过头来重新看**一遍，寻找错别字。
    
- **感觉：** **修改、修订**（英国英语中也指复习）。
    

#### 3. Supervise (从高处看 → 盯着别人干活 → 监督)

- **词源逻辑：** super- (在上面) + vise (看)。
    
- **Native 画面：** 想象监工站在二楼阳台，**居高临下地看着**下面工人的动作。
    
- **感觉：** **监督、管理、指导**。
    

#### 4. Envisage / Envision (往内看 → 在脑海中勾勒 → 想象)

- **词源逻辑：** en- (进入/使) + vis (看)。
    
- **Native 画面：** 闭上眼睛，在你的**大脑屏幕里“看”**未来的样子。
    
- **感觉：** **展望、想象、设想**（通常指对未来的美好或宏大构思）。



**1. Evidence (看出来的东西 → 证据)**

- **逻辑：** e/ex- (出来) + vid (看)。
    
- **Native 画面：** 那些摆在台面上，一眼就能**看出来**的事实。
    
- **意思：** **证据、迹象**。
    

**2. Improvise (没提前看 → 临时发挥)**

- **逻辑：** im- (不) + pro- (提前) + vise (看)。
    
- **Native 画面：** 上台前**没有预先看过**剧本，只能当场抓瞎。
    
- **意思：** **即兴创作、临时凑合**。
    

**3. Visual & Visible (能看的 vs. 看得见的)**

- **Visual**: 视觉的（强调属性，如 visual arts 视觉艺术）。
    
- **Visible**: 可见的（强调能力，-ible 表示可以被看见）。

### -TAIN 家族 —— 核心是“拿住/握住” (Root: TEN / TAIN = Hold)

想象你手里握着一件东西。前缀决定了你**“怎么握”**以及**“握在哪”**。

#### 1. Contain (拿在一起 → 包含)

- **逻辑：** con- (全部/在一起) + tain (拿)。
    
- **画面：** 把所有的水果都**拿进一个框里**。
    
- **感觉：** 侧重于**容量和界限**。这个框“包含”了这些东西。
    

#### 2. Retain (拿回来/留住 → 保留)

- **逻辑：** re- (回) + tain (拿)。
    
- **画面：** 某样东西想溜走，你一把把它**往回抓**。
    
- **感觉：** **保留、保持**。比如：Retain the original style (保留原汁原味)。
    

#### 3. Maintain (用手拿着 → 维持)

- **逻辑：** main- (源自 manu- 手) + tain (拿)。
    
- **画面：** 想象一个旋转的陀螺，你不断地**用手去拨动/扶正**，不让它倒下。
    
- **感觉：** **维修、养护、维持**（需要持续投入力量）。
    

#### 4. Sustain (在下面撑着拿 → 支撑)

- **逻辑：** sus- (在下面) + tain (拿)。
    
- **画面：** 举重运动员**从下方死死撑住**杠铃。
    
- **感觉：** **支撑、维持（生命/生存）**。
    
- **核心词：** Sustainable development (可持续发展 —— 能撑得住的发展)。
    

#### 5. Detain (拿下来/拿开 → 拘留)

- **逻辑：** de- (向下/离开) + tain (拿)。
    
- **画面：** 一个人想走，你把他**强行拿下来**扣在原地。
    
- **感觉：** **拘留、耽搁**。
    

#### 6. Attain (去拿到 → 达到)

- **逻辑：** at- (向) + tain (拿)。
    
- **画面：** 伸长手臂，**努力够到**树上的苹果。
    
- **感觉：** 通过努力**获得、达到**（目标/成就）。

### -CAP 家族 —— 两个源头：一个是“抓”，一个是“头”

这个家族最阴险，因为有两个长得一样的祖先。

#### 【分支 A：抓取 (Root: CAP / CAPT = Take/Seize)】

#### 1. Capacity (抓取量 → 容量)

- **逻辑：** cap (抓) + acity (性质)。
    
- **画面：** 一个瓶子能“抓”住多少水的**能力**。
    
- **感觉：** **容量、能力**。
    

#### 2. Capture (抓取的动作 → 捕获)

- **逻辑：** capt (抓) + ure (名词后缀)。
    
- **画面：** 警察**抓住**逃犯，或者相机**捕捉**瞬间。
    
- **感觉：** 物理上的**捕获、夺取**。
    

#### 3. Captivate (被抓住了心 → 迷住)

- **逻辑：** capt (抓) + ivate (动词后缀)。
    
- **画面：** 你的目光和注意力**被某样美丽的东西抓走了**，动弹不得。
    
- **感觉：** **迷惑、吸引**。
    

#### 4. Captive (被抓的人 → 俘虏)

- **感觉：** 被关起来的**人或动物**。
    

#### 【分支 B：头 (Root: CAP = Head)】

#### 5. Capital (头的 → 首要的)

- **逻辑：** 一个国家/地区的“头儿”。
    
- **感觉：** **首都、资本（最重要的钱）、大写字母（头大的字母）**。
    

#### 6. Caption (头部的文字 → 标题)

- **逻辑：** 放在图片或文章“头部”的解释说明。
    
- **感觉：** **说明文字、字幕、标题**。

#### 1. Procession (走在前面的一队人 → 队伍)

- **词源逻辑：** pro- (向前) + cess (走)。
    
    - **同源词：** **Proceed** (继续进行), **Process** (过程)。
        
- **Native 画面：** 想象国庆阅兵或者婚礼，人们**整齐地向前走**。
    
- **感觉：** **行列、队伍、游行**。
    
- **Precede (v.)**: pre- (在先) + cede (走)。
    
    - **意思：** **领先于、在... 之前发生**。

#### 2. Possession (坐在上面的人 → 拥有)

- **词源逻辑：** pos (力量/权力) + sess (坐)。
    
    - **同源词：** **Session** (会议 —— 坐着开会), **Obsess** (迷住 —— 坐在心上)。
        
- **Native 画面：** 想象一个地主**稳稳地坐在**一堆金币上面，展示他的力量。
    
- **感觉：** **拥有、占有、财产**。

- **Assess (v.)**: ad- (向) + sess (坐)。
    
    - **逻辑：** 坐在你旁边（观察你）。
        
    - **意思：** **评估、评定**。

#### 1. Authority (创作者的权力 → 权威)

- **词源逻辑：** 来自 **Author (作者/创始人)**。
    
- **Native 逻辑：** 谁创造了这件事，谁就有话语权。
    
- **感觉：** **权威、官方、专家**。
    

#### 2. Aesthetic (感觉的 → 审美的)

- **词源逻辑：** 源自希腊语 aisthetikos (感官知觉)。
    
- **Native 画面：** 想象你站在一幅画前，用**感官去体验**美丑。
    
- **感觉：** **审美的、美学的**。
    

#### 3. Authentic (原本的 → 真实的)

- **词源逻辑：** auto- (自己) + hent- (做)。
    
- **Native 画面：** 这是一个由作者“亲手做的”东西，不是复印件。
    
- **感觉：** **真实的、地道的、可靠的**。
    
- **搭配：** authentic Italian food (正宗的意大利菜)。


- **Autonomy (n.)**: auto- (自己) + nomy (法律/管理)。
    
    - **意思：** **自治、自主权**。

- **感觉：** **骤降、猛冲、跳水**。
    
- **搭配：** Prices plunged. (价格暴跌)

#### 1. Temple (神庙 / 太阳穴)

- **逻辑 A：** 划分出的神圣区域（神庙）。
    
- **逻辑 B：** 头部平坦的薄弱处（太阳穴）。
    

#### 2. Tempt (诱惑 / 尝试)

- **词源逻辑：** 词根意为“试探、触摸”。
    
- **Native 画面：** 想象一只手悄悄伸向禁果，想**摸一摸、试一试**。
    
- **感觉：** **引诱、诱惑**。
    

#### 3. Temper (混合 / 调理 → 脾气)

- **词源逻辑：** 意为“混合、回火”。
    
- **Native 逻辑：** 炼钢时要把硬度和韧性**混合/调节**到最佳状态。引申为人精神的“混合”状态，即**脾气**。
    
- **衍生词：** **Temperament** (气质/性格)。

- **Native 画面：** 想象一个婴儿在地上爬，或者虫子蠕动。
    
- **感觉：** 极低的高度，缓慢的速度。

- **Native 画面：**

- **引申（考研重点）：** **得意洋洋地夸口/吹牛**。想象公鸡伸长脖子大叫的样子。
    

#### 4. Clown (小丑)

- **Native 画面：** 红鼻子、夸张的表情、滑稽的动作。
    
- **感觉：** 笨拙、引人发笑的人。

subsequent

#### 1. Sequence (先后次序)

- **逻辑：** 纯粹的“跟随”状态。
    
- **Native 画面：** 1, 2, 3, 4... 一个接一个排好队。
    
- **感觉：** **顺序、序列**。
    

#### 2. Subsequent (时间上的跟随 → 随后的)

- **逻辑：** sub- (在... 之后/近) + sequ (跟随)。
    
- **Native 画面：** 事情 A 发生了，**紧接着**时间轴上出现了事情 B。
    
- **感觉：** **随后的、后来的**。
    

#### 3. Consequent (逻辑上的跟随 → 结果)

- **逻辑：** con- (随着) + sequ (跟随)。
    
- **Native 画面：** 事情 A 是因，事情 B 是果。B 是**伴随**着 A 产生的。
    
- **感觉：** **作为结果的、随之发生的**。
    
- **副词：** Consequently (因此/所以)。
    

**1. 执行计划 (Execute):**

- **Execute (v.)**: ex- (出) + secu (跟随)。
    
    - **逻辑：** 让结果**跟出来**。
        
    - **意思：** **执行、实施**（让计划变成结果）。
        

**2. 迫害/起诉 (Prosecute):**

- **Prosecute (v.)**: pro- (向前) + secu (跟随)。
    
    - **逻辑：** 在法庭上**紧追着**某人不放。
        
    - **意思：** **起诉、检举**。

#### . Course (运行的路径)

- **词源逻辑：** 来自 currere (跑)。同源词：Current (水流/电流)。
    
- **Native 画面：** 想象你在操场上**跑**，或者水在河道里**流**。
    
- **感觉：** **课程、过程、航线、一道菜**（上菜的顺序）。
    

#### 2. Coarse (粗糙的)

- **Native 画面：** 想象用手摸**砂纸**或者未经打磨的石头。
    
- **感觉：** **粗糙的、粗俗的**（指人的言行没经过打磨）。
