### VIS / VID 家族：核心是“视线的投射”

#### 1. Provide (向前看 → 预见需求 → 供应)

- **词源逻辑：** pro- (向前) + vide (看)。
    
- **Native 画面：** 想象一个猎人，在出发前**往前看**到了路途遥远可能会饿，于是提前准备好了干粮。
    
- **感觉：** 因为“预见”到了需要，所以**“提供/准备”**。
    
- **对比补充：**
    
    - **Provision (n.)**: 预备、条款、食物供应。
        
    - **Prudent (adj.)**: 它是 provident 的缩写。向前看的人 → **谨慎的/有远见的**。
        

#### 2. Revise (再次看 → 检查错误 → 修订)

- **词源逻辑：** re- (再次) + vise (看)。
    
- **Native 画面：** 写完作文后，你的眼睛**回过头来重新看**一遍，寻找错别字。
    
- **感觉：** **修改、修订**（英国英语中也指复习）。
    

#### 3. Supervise (从高处看 → 盯着别人干活 → 监督)

- **词源逻辑：** super- (在上面) + vise (看)。
    
- **Native 画面：** 想象监工站在二楼阳台，**居高临下地看着**下面工人的动作。
    
- **感觉：** **监督、管理、指导**。
    

#### 4. Envisage / Envision (往内看 → 在脑海中勾勒 → 想象)

- **词源逻辑：** en- (进入/使) + vis (看)。
    
- **Native 画面：** 闭上眼睛，在你的**大脑屏幕里“看”**未来的样子。
    
- **感觉：** **展望、想象、设想**（通常指对未来的美好或宏大构思）。



**1. Evidence (看出来的东西 → 证据)**

- **逻辑：** e/ex- (出来) + vid (看)。
    
- **Native 画面：** 那些摆在台面上，一眼就能**看出来**的事实。
    
- **意思：** **证据、迹象**。
    

**2. Improvise (没提前看 → 临时发挥)**

- **逻辑：** im- (不) + pro- (提前) + vise (看)。
    
- **Native 画面：** 上台前**没有预先看过**剧本，只能当场抓瞎。
    
- **意思：** **即兴创作、临时凑合**。
    

**3. Visual & Visible (能看的 vs. 看得见的)**

- **Visual**: 视觉的（强调属性，如 visual arts 视觉艺术）。
    
- **Visible**: 可见的（强调能力，-ible 表示可以被看见）。

### -TAIN 家族 —— 核心是“拿住/握住” (Root: TEN / TAIN = Hold)

想象你手里握着一件东西。前缀决定了你**“怎么握”**以及**“握在哪”**。

#### 1. Contain (拿在一起 → 包含)

- **逻辑：** con- (全部/在一起) + tain (拿)。
    
- **画面：** 把所有的水果都**拿进一个框里**。
    
- **感觉：** 侧重于**容量和界限**。这个框“包含”了这些东西。
    

#### 2. Retain (拿回来/留住 → 保留)

- **逻辑：** re- (回) + tain (拿)。
    
- **画面：** 某样东西想溜走，你一把把它**往回抓**。
    
- **感觉：** **保留、保持**。比如：Retain the original style (保留原汁原味)。
    

#### 3. Maintain (用手拿着 → 维持)

- **逻辑：** main- (源自 manu- 手) + tain (拿)。
    
- **画面：** 想象一个旋转的陀螺，你不断地**用手去拨动/扶正**，不让它倒下。
    
- **感觉：** **维修、养护、维持**（需要持续投入力量）。
    

#### 4. Sustain (在下面撑着拿 → 支撑)

- **逻辑：** sus- (在下面) + tain (拿)。
    
- **画面：** 举重运动员**从下方死死撑住**杠铃。
    
- **感觉：** **支撑、维持（生命/生存）**。
    
- **核心词：** Sustainable development (可持续发展 —— 能撑得住的发展)。
    

#### 5. Detain (拿下来/拿开 → 拘留)

- **逻辑：** de- (向下/离开) + tain (拿)。
    
- **画面：** 一个人想走，你把他**强行拿下来**扣在原地。
    
- **感觉：** **拘留、耽搁**。
    

#### 6. Attain (去拿到 → 达到)

- **逻辑：** at- (向) + tain (拿)。
    
- **画面：** 伸长手臂，**努力够到**树上的苹果。
    
- **感觉：** 通过努力**获得、达到**（目标/成就）。

### -CAP 家族 —— 两个源头：一个是“抓”，一个是“头”

这个家族最阴险，因为有两个长得一样的祖先。

#### 【分支 A：抓取 (Root: CAP / CAPT = Take/Seize)】

#### 1. Capacity (抓取量 → 容量)

- **逻辑：** cap (抓) + acity (性质)。
    
- **画面：** 一个瓶子能“抓”住多少水的**能力**。
    
- **感觉：** **容量、能力**。
    

#### 2. Capture (抓取的动作 → 捕获)

- **逻辑：** capt (抓) + ure (名词后缀)。
    
- **画面：** 警察**抓住**逃犯，或者相机**捕捉**瞬间。
    
- **感觉：** 物理上的**捕获、夺取**。
    

#### 3. Captivate (被抓住了心 → 迷住)

- **逻辑：** capt (抓) + ivate (动词后缀)。
    
- **画面：** 你的目光和注意力**被某样美丽的东西抓走了**，动弹不得。
    
- **感觉：** **迷惑、吸引**。
    

#### 4. Captive (被抓的人 → 俘虏)

- **感觉：** 被关起来的**人或动物**。
    

#### 【分支 B：头 (Root: CAP = Head)】

#### 5. Capital (头的 → 首要的)

- **逻辑：** 一个国家/地区的“头儿”。
    
- **感觉：** **首都、资本（最重要的钱）、大写字母（头大的字母）**。
    

#### 6. Caption (头部的文字 → 标题)

- **逻辑：** 放在图片或文章“头部”的解释说明。
    
- **感觉：** **说明文字、字幕、标题**。
