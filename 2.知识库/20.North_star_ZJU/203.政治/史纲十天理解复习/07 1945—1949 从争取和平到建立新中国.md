# 第7天｜1945—1949：从争取和平到建立新中国

> 主要依据：大李子讲义PDF第125、135—136、168—169、196—197页（印刷116、126—127、159—160、187—188页）；正文第79—85页补充。页码以PDF阅读器页码为准，括号内为讲义印刷页码。解释性串联不等于历史只有一个原因。


> [!abstract] 今天的核心问题
> 既然最后要打解放战争，为什么一开始还去重庆谈判？为什么战胜国民党不仅是军队的事，还和土地、民主党派、建国纲领有关？

## 一、先把军事、土地、建国三条线放在一起

| 阶段 | 军事与政治局势 | 土地与群众 | 国家往哪里走 |
| --- | --- | --- | --- |
| 1945—1946 | 争取和平，重庆谈判、重庆政协；内战全面爆发 | 五四指示，转向耕者有其田 | 争取和平民主，揭露独裁内战企图 |
| 1947—1948 | 战略进攻、战略决战 | 《中国土地法大纲》、纠正土改偏差 | 明确革命总路线，号召协商建国 |
| 1949 | 革命即将全国胜利 | 为新政权、生产恢复作准备 | 工作重心转城市；人民民主专政；新政协、《共同纲领》 |

## 二、逻辑带背①｜能否和平建国，要认真争取，也不能交出自卫能力

### 1. 抗战胜利后，国共想要的是同一个国家方案吗？

→ 中共提出**和平、民主、团结**，争取人民民主的新中国。国民党统治集团希望维护大地主大资产阶级利益和独裁统治。

→ 国民党一边准备内战，一边表示谈判，既要争取部署时间，也要敷衍舆论、争取让中共交出军队和解放区，或在谈判破裂后转嫁责任。

### 2. 既然有阴谋，为什么还赴重庆？

**心里问：知道对方可能毁约，就能跳过人民争取和平的要求吗？**

→ 不能。只要和平有可能，就应争取；谈判也能向全国表明诚意，团结要求民主和平的力量，使谁坚持和平、谁准备内战更清楚。

- **1945年8月25日《对目前时局的宣言》**：和平、民主、团结。
- **8月28日毛泽东赴重庆，10月10日签署《双十协定》**：确认和平建国基本方针。
- **1946年1月重庆政治协商会议**：形成政府组织、和平建国纲领、军事、国民大会、宪法草案等协议，有利于限制独裁、推动民主和平。

**谈判不等于放弃自卫，协议不等于已建立民主政权。** 讲义“重庆谈判”栏标题误标8月25日，赴重庆应记8月28日；8月25日对应时局宣言。

### 3. 为什么全面内战爆发后能够由弱转强？

**1946年6月国民党军进攻中原解放区，全面内战爆发。**

→ 国民党军事力量强和美国援助是暂时优势；战争反人民性质、人心向背，是持续发挥作用的因素。人民解放战争的正义性是获得人民支持的政治基础，但**支持要靠实际政策、组织与军事斗争来落实**。

- 军事原则：集中优势兵力，各个歼灭敌人。
- **1947年刘邓大军千里跃进大别山**：战略进攻的重要标志。
- **1948年9月—1949年1月辽沈、淮海、平津三大战役**：战略决战，基本摧毁国民党主要军事力量。
- **1949年4月渡江战役，4月23日解放南京**：国民党反动统治覆灭。

不能写“三大战役打完，全国一切国民党军队已经消灭”；之后仍需解放战争和不同方式解决剩余军队。

## 三、逻辑带背②｜为什么土地改革是胜利的重要群众基础？

### 1. 抗战结束，减租减息为什么不够了？

→ 抗战时为了联合抗日，暂不没收地主土地；战后农民要求土地，民主革命任务仍在。只有继续改变封建土地关系，才能真正维护农民利益、把农民组织起来。

| 节点                    | 核心变化                                  | 记忆区别                              |     |
| --------------------- | ------------------------------------- | --------------------------------- | --- |
| **1946年五四指示**         | 从减租减息转向实现耕者有其田                        | 是土地政策重要转变，不是1919年五四运动             |     |
| **1947《中国土地法大纲》**     | 废除封建性及半封建性剥削土地制度，实行耕者有其田；提出征收富农多余土地财产 | 全国土地会议制定的彻底反封建土地纲领；不是1950《土地改革法》  |     |
| **1948《在晋绥干部会议上的讲话》** | 明确土改总路线，纠正偏差                          | 依靠贫农、团结中农，有步骤、有分别地消灭封建剥削制度，发展农业生产 |     |

**心里问：为什么一定强调团结中农、有步骤有分别？**

→ 土改是消灭封建剥削，不是把所有有地有财产的人都当敌人；侵犯中农、打击工商业、片面追求绝对平均，会破坏生产、缩小革命同盟。

土地改革让农民把自身利益与革命胜利联系起来，支持参军、生产和支前。**不能把胜利简化为“只因分了地”，也不能把土地改革当作无关战争胜负的福利。**

### 2. 革命总路线为什么在1948年表述得更完整？

**《在晋绥干部会议上的讲话》首次完整表述新民主主义革命总路线：无产阶级领导的，人民大众的，反对帝国主义、封建主义和官僚资本主义的革命。**

- 领导：无产阶级及其政党。
- 动力：工人、农民、城市小资产阶级、民族资产阶级。
- 对象：帝国主义、封建主义、官僚资本主义。
- 性质：新式资产阶级民主革命，**不是社会主义革命**。
- 前途：社会主义。

**官僚资本主义≠一切资本主义**。没收官僚资本与保护民族工商业并行，因为现阶段要打倒的是压迫人民的三座大山，而不是直接消灭一切私有制。

> [!warning] “首次完整表述”不要扩写成其他所有“首次”
> 讲义把1948年讲话写成“第一次把官僚资本主义列为对象”，容易混淆。1947年《目前形势和我们的任务》已经论述反对官僚资本、没收官僚资本等问题。这里稳记的是**1948年完整表述革命总路线**，不能把对象相关认识全部推迟到1948年。

## 四、逻辑带背③｜打下全国以后，怎样组织和治理国家？

### 1. 民主党派为什么从第三条道路转向接受中共领导？

→ 国民党独裁与内战暴露，资本主义共和国方案缺乏现实条件；共产党坚持民主、争取团结、得到人民支持。民主党派和无党派人士逐渐在比较中作出选择。

- **1948年4月30日“五一口号”**：号召召开新政协、成立民主联合政府，揭开协商建国序幕，为多党合作和政治协商制度奠定基础。
- **1949年1月22日《对时局的意见》**：各民主党派和无党派民主人士公开自愿接受中共领导，拥护建立人民民主新中国。
- **1949年9月中国人民政协第一届全体会议**：多党合作和政治协商制度正式确立。

**三个节点：号召与响应→公开选择→制度正式确立**。1946重庆政协不是1949新政协。

### 2. 七届二中全会为什么一面谈城市和生产，一面谈“两个务必”？

**1949年3月，西柏坡。** 革命即将全国胜利，工作条件与风险都发生变化。

→ 长期农村作战的党，要管理城市、恢复生产、组织经济；因此**工作重心由乡村转向城市，以恢复和发展生产为中心任务**。

→ 要实现由农业国转变为工业国、由新民主主义社会转变为社会主义社会。

→ 胜利后仍有骄傲、腐化、脱离群众风险，所以提出**务必谦虚谨慎、不骄不躁；务必艰苦奋斗**。

“两个务必”不是和经济工作分离的道德口号，而是保证执政后不变质、能继续完成建设任务的要求。

解决国民党剩余军队的方式：天津式（战斗解决）、北平式（和平改编）、绥远式（保持原状、争取转变后改编）。不必每次全文背，知道因具体条件采用不同方式。

### 3. 三份1948—1949著作各负责哪一步？

- **《将革命进行到底》（1948年12月）**：不能因敌人“和平”姿态停止革命；公开使用人民民主专政概念。
- **《七届二中全会上的报告》（1949年3月）**：工作转城市、建设和执政准备、两个务必。
- **《论人民民主专政》（1949年6月）**：总结经验，系统说明新国家政权；**工人阶级经过共产党领导，以工农联盟为基础**，团结人民，对反动派实行专政；团结民族资产阶级、利用有利国计民生的资本主义因素；外交“一边倒”。

“民主”与“专政”是对不同对象的两面，不是对人民专政。文中强调教育农民，也反映建设不能只停留于小生产者的原有状态。

### 4. 新政协与开国大典，分别记什么？

**1949年9月新政协**：通过《共同纲领》等，选举中央人民政府委员会，确定国都、纪年、国歌、国旗等建国事项；《共同纲领》具有临时宪法作用。

**1949年10月1日开国大典，中华人民共和国成立。** 会议为建国完成重要准备，不能把国家成立日挪到9月。

人民政协是统一战线组织，**不是国家权力机关**；当时在全国人大尚未召开条件下代行全国人大职权，不等于它永久就是人大。

## 五、胜利意义要和下一天接住

新中国成立，结束半殖民地半封建社会历史，实现民族独立、人民解放，为民族复兴创造根本社会条件；为从新民主主义到社会主义、进行现代化建设创造政治前提。

**不是1949年已经完成社会主义改造、全部地区土改和工业化。** 政治前提建立后，仍要逐步完成新的经济社会任务。

## 六、90秒逻辑复述

抗战后中共争取和平民主，重庆谈判和政协表明和平建国诚意，但国民党发动全面内战，人民必须进行自卫。人民解放战争以正义性质为政治基础，通过正确军事战略、土地改革和广泛统一战线，把人民支持变成实际力量。1948年完整表述革命总路线，明确反对三座大山而非所有资本；同时以五一口号推动协商建国。七届二中全会为执政与生产建设作准备，《论人民民主专政》说明新国家性质，新政协制定建国文件，最终迎来新中国成立。

## 七、闭卷自测

1. 谈判为什么不是多余？1945宣言、赴重庆、双十协定分别哪天？
2. 五四指示、土地法大纲、晋绥讲话三件事怎样接？
3. 官僚资本与民族资本，革命政策为什么不同？
4. 五一口号、《对时局的意见》、新政协各是哪一步？
5. 七届二中全会为什么提出工作转城市和两个务必？

> [!faq]- 核对
> 1. 尊重人民和平要求、争取和平、团结力量并揭露内战；8月25、8月28、10月10。
> 2. 1946转向耕者有其田；1947彻底反封建纲领；1948提出土改总路线、强调保护中农、发展生产。
> 3. 官僚资本与帝国主义、封建势力紧密结合，是革命对象；民族资本有两面性，现阶段保护其有利部分。
> 4. 1948号召协商建国；1949年1月公开接受领导；1949年9月制度正式确立。
> 5. 从战争向全国执政转变，需要管理城市、恢复发展生产，并防止胜利后的骄傲腐化。
