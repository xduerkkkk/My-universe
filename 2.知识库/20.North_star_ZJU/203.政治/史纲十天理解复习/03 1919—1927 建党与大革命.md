# 第3天｜1919—1927：建党与大革命

> 主要依据：大李子讲义PDF第122、126—129、191—192页（印刷113、117—120、182—183页）；正文第65—68页补充。页码以PDF阅读器页码为准，括号内为讲义印刷页码。解释性串联不等于历史只有一个原因。


> [!abstract] 今天的核心问题
> 有了马克思主义、有了工人运动，为什么还必须建党、联合其他阶级？联合以后，为什么又不能交出自己的领导权？

## 一、今天的主线

**思想与工人运动结合 → 建立领导核心 → 明确现阶段革命任务 → 扩大革命同盟 → 国民革命兴起 → 领导权和武装问题没解决好，合作破裂、革命失败。**

“有党”“有正确纲领”“有牢固领导权”是三个不同层次，不能把1921年成立直接理解为后来所有问题都已解决。

## 二、逻辑带背｜一大到四大是四次回答问题

### 1. 为什么要建党？群众有反抗，不等于能自动形成全国性领导

→ 早期马克思主义者通过办刊、研究、翻译传播理论，同时深入工人、办工人学校、组织工会，把思想传播与实际斗争联系起来。

**落笔句：中国共产党是马克思列宁主义同中国工人运动相结合的产物。** 思想基础是马克思主义传播，阶级基础是工人阶级发展，干部与组织条件也逐步形成。不能写成“同农民运动结合的产物”。

**1921年7月中共一大**在上海开幕，后转至嘉兴南湖，宣告中国共产党成立；规定社会主义、共产主义奋斗目标，成立中央局，陈独秀任书记，当前实际工作集中组织工人。

**意义不是“又多了一个团体”**：反帝反封建斗争有了先进坚强的领导核心；有科学理论、坚定目标和新的组织方式，从根本上改变了此前革命缺乏坚强领导核心的局面。它代表工人阶级利益，也代表中国人民和中华民族利益。

### 2. 最高理想是共产主义，现在是不是马上推翻所有资本家？

→ 不行。中国还受帝国主义和封建主义压迫，现阶段必须先完成民主革命任务。**中共二大（1922年7月）第一次明确提出彻底反帝反封建的民主革命纲领。**

- **最高纲领**：实现社会主义、共产主义。
- **最低纲领／当前纲领**：打倒军阀，推翻国际帝国主义压迫，统一中国为真正民主共和国。
- 通过第一部党章，提出民主联合战线主张，并决定加入共产国际。

**连接词：最终目标不变，但现阶段任务要从中国国情出发。** 这就是“一大定远方，二大认眼前”的意思，不是二大放弃社会主义。

### 3. 只靠工人罢工，为什么还推不倒军阀？

→ 工人力量虽有发展，仍需争取广泛同盟。1923年京汉铁路工人罢工遭镇压，更使党认识到建立革命统一战线的必要性。

**中共三大（1923年6月）**：决定共产党员以个人身份加入国民党，实现党内合作；共产党仍须保持政治、思想、组织上的独立性。

**国民党一大（1924年1月）**：重新解释三民主义，事实上确认联俄、联共、扶助农工三大政策，标志第一次国共合作正式形成。

不要写成“中共整个组织并入国民党”，也别把三大决定合作方式和国民党一大正式形成合作混为一个节点。

### 4. 能合作的政治基础在哪里？新三民主义比旧的进在哪里？

| 项目 | 新三民主义的进步 | 与共产党的边界 |
| --- | --- | --- |
| 民族主义 | 明确反对帝国主义，对内各民族平等 | 不等于已经具有无产阶级领导的新民主主义性质 |
| 民权主义 | 强调民主权利为一般平民共有 | 仍属资产阶级民主主义范畴 |
| 民生主义 | 平均地权、节制资本，并进一步提出耕者有其田等主张 | 不等于共产党的社会主义纲领，也不能把所有表述都说成同一天提出 |

**它同中共民主革命阶段纲领基本一致，所以能够合作；不是全部理论、最终目标完全一致。**

### 5. 联合了以后谁领导？工人怎样把广大农民带进来？

→ **中共四大（1925年1月）第一次明确提出无产阶级在民主革命中的领导权和工农联盟问题。**

中国农民人数多、受压迫深，是革命主力军；无产阶级要领导革命，就必须把农民组织起来。**领导阶级≠人数最多的阶级，主力军≠领导者。**

## 三、著作不是多背两篇｜它们正在解决“敌友”和“农民”

### 《中国社会各阶级的分析》（1925）

**心里问：哪些人是依靠力量，哪些人要团结，哪些人是敌人？**

→ 分析各阶级的经济地位、政治态度和革命作用，提出**“谁是我们的敌人？谁是我们的朋友？”是革命的首要问题**。不是只靠口号划敌友。

### 《湖南农民运动考察报告》（1927）

**心里问：农民运动是破坏秩序，还是推翻封建势力不可缺的力量？**

→ 通过调查肯定农民斗争的重大作用，阐明无产阶级领导农民斗争的重要性。把“工农联盟”从名词落到现实：要打倒乡村封建势力，就不能害怕、排斥农民起来斗争。

这两篇通常归入**毛泽东思想萌芽阶段**。逻辑是先认清敌友，再看怎样发动最大多数的农民，不是已经系统形成农村包围城市理论。

## 四、大革命为什么既有巨大成就，又最终失败？

1925年五卅运动推动大革命高潮；**1926年7月北伐开始**，目标是推翻北洋军阀统治。国共合作、工农运动和革命军队共同推动革命发展，动员范围和社会内涵远超以往。

**但局面扩大，不等于领导权掌握牢固。**

- 客观上：反革命力量强大，国民党右派背叛革命。
- 主观上：党处于幼年时期，缺乏把理论与中国实际结合的经验；陈独秀右倾机会主义在领导机关占统治地位，放弃对革命、尤其武装力量的领导权，不能有效组织反击。
- 国际因素：共产国际部分错误指导造成影响；不能把一切责任都推给外部。

**1927年4月12日蒋介石反共政变；7月15日汪精卫“分共”，第一次国共合作全面破裂，大革命最终失败。**

**落笔教训：必须坚持无产阶级领导权，建立和掌握革命武装，同时建立广泛统一战线。** 不是“以后不合作”，而是“合作时保持独立自主、不能以退让换团结”。

## 五、工人运动小定位｜防止被讲义时间栏带偏

- 1922年香港海员罢工，是第一次工人运动高潮的起点。
- 1922年安源路矿工人罢工，是党领导工运的重要胜利。
- **1923年2月京汉铁路工人罢工**，第一次工人运动高潮顶点，遭军阀镇压。
- **省港大罢工在1925—1926年**，是持续时间很长的政治大罢工，**不在1922—1923年内**。讲义把它列在“1922—1923罢工运动”栏，复习时应挪回大革命背景。

中共五大在1927年4—5月召开；**首次明确规定“党的指导原则为民主集中制”的党章文本，是五大后1927年6月中央政治局通过的《中国共产党第三次修正章程决案》**。题目问大会背景与问具体文本，精度不同，别直接说五大现场通过。[核对资料：共产党员网党章史资料。]

## 六、90秒逻辑复述

五四后，马克思主义与工人运动结合，推动中国共产党成立。一大规定奋斗目标，二大依据半殖民地半封建国情提出彻底反帝反封建的民主革命纲领。为扩大力量，三大决定国共党内合作，国民党一大标志合作正式形成；四大进一步提出无产阶级领导权和工农联盟。大革命广泛发动群众、推动北伐，但党未能牢固掌握领导权和武装，国民党右派背叛又使反革命力量占据优势，革命失败。这说明联合与独立缺一不可，也把下一步的武装斗争和土地革命提到面前。

## 七、闭卷自测

1. 一大、二大、三大、四大分别回答哪个问题？
2. 三大与国民党一大，各是国共合作的哪个节点？
3. “新三民主义就是新民主主义”为什么错？
4. 《各阶级分析》与《湖南报告》分别抓哪件事？
5. 大革命失败是否说明建立统一战线本身错误？

> [!faq]- 核对
> 1. 建立党、规定奋斗目标；明确现阶段反帝反封建纲领；决定国共合作方式；明确领导权与工农联盟。
> 2. 决定合作方式；正式形成合作。
> 3. 前者仍是资产阶级民主主义，根本区别看领导阶级，不能因“新”字相同而混同。
> 4. 首要问题分清敌友；肯定农民运动、说明领导农民的极端重要性。
> 5. 不是。要广泛联合，但不能放弃党的独立性、领导权和革命武装。
