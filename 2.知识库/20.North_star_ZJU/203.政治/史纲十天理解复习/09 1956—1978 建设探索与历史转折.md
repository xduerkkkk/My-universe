# 第9天｜1956—1978：建设探索与历史转折

> 主要依据：大李子讲义PDF第137—139页（印刷128—130页）；正文第89—90页补充。1958—1976的过程在专题中较略，本篇补上必要衔接，不把补充解释冒充原表逐条内容。页码以PDF阅读器页码为准，括号内为讲义印刷页码。解释性串联不等于历史只有一个原因。


> [!abstract] 今天的核心问题
> 社会主义制度建立以后，为什么仍要探索、仍有矛盾、仍会犯严重错误？
> **制度确立不等于建设方法自动正确；必须认清社会主要矛盾，处理好人民内部矛盾，并按实际条件发展生产力。**

## 一、把这一时期看成“正确探索—偏离—纠正—新的转折”

1956年改造基本完成 → 《论十大关系》、八大探索建设道路 → 1957年提出正确处理人民内部矛盾 → 后来“左”的错误发展，出现大跃进、人民公社化等曲折 → 国民经济调整 → 文化大革命严重挫折 → 1976年结束 → 1978年思想解放与工作重心转变。

**不能把1956—1976全说成只有错误，也不能因有建设成就就否认严重错误。** 理解两面，才知道1978年到底转什么。

## 二、逻辑带背①｜不能照搬苏联，那么中国建设先处理哪些关系？

### 1. 《论十大关系》（1956年4月）为什么是良好开端？

**心里问：苏联经验能学，为什么不能完整搬来？**

→ 中国人口、经济结构、资源分布等有自身特点，照搬会损害农业轻工业、地方和群众积极性。因此要**以苏为鉴，独立自主探索适合中国情况的社会主义建设道路**。

**基本方针：调动一切积极因素，为社会主义事业服务。** 不是只有经济指标，还要把各阶级阶层、地区和国内外力量尽可能团结起来。

十大关系按“建设需要协调谁”来记：

| 层次 | 哪几组关系 | 具体怎么理解 |
| --- | --- | --- |
| 先安排经济资源（前五） | 重工业与轻工业农业；沿海与内地；经济与国防；国家、生产单位、个人；中央与地方 | 既要工业化，也要农业轻工业供给、区域协调、群众和地方积极性 |
| 再协调政治社会（中四） | 汉族与少数民族；党与非党；革命与反革命；是与非 | 扩大团结，区别对象，不能把所有分歧都当敌我斗争 |
| 最后看外部经验（后一） | 中国与外国 | 学各国长处，但不照搬 |

**第一大关系：重工业和轻工业、农业的关系。** 以重工业为重点，不等于排斥农业轻工业；增加农业、轻工业投入，反过来也有利于重工业长远发展。

> [!warning] 不把后来逐步形成的整套方针都塞进1956这一篇
> 讲义把“以农轻重为序”等表述集中放在《论十大关系》下，适合专题联想，但涉及**具体提出时间和原文归属**时，不能一律写成1956年文章已原样提出全部内容。此篇稳记：十大关系、调动积极因素、以苏为鉴、探索道路良好开端。1959年庐山会议进一步提出按农、轻、重次序安排国民经济计划，不能与1956年文章原文混同。[核对资料：中国共产党新闻网《八届八中全会简介》。]

### 2. 八大（1956年9月）为什么把发展生产力提到中心？

→ 社会主义改造基本完成，阶级关系发生重大变化，国内主要矛盾已经不再是工人阶级与资产阶级之间的矛盾。

**八大对主要矛盾的表述：**

- 人民对于建立先进工业国的要求，同落后的农业国现实之间的矛盾；
- 人民对于经济文化迅速发展的需要，同当前经济文化不能满足人民需要的状况之间的矛盾。

**实质是先进社会主义制度同落后社会生产力之间的矛盾。** 因而主要任务是集中力量发展社会生产力，实现国家工业化，逐步满足人民物质文化需要。

→ 经济方针：**既反保守又反冒进，在综合平衡中稳步前进。** 政治上发展民主、健全法制；党建上健全民主集中制。

**陈云“三个主体、三个补充”**：国家与集体经营为主体、个体经营补充；计划生产为主体、自由生产补充；国家市场为主体、自由市场补充。理解为在当时框架下兼顾不同经营生产形式，**不是1992年的社会主义市场经济目标**。

## 三、逻辑带背②｜为什么有社会主义制度，社会仍有矛盾？

### 1. 《关于正确处理人民内部矛盾的问题》（1957）先区分两种“矛盾”

- **基本矛盾**：生产力与生产关系、经济基础与上层建筑。社会主义条件下仍存在，表现为又相适应又相矛盾，可通过社会主义制度自身不断解决。
- **主要矛盾**：某一历史阶段最牵动全局的矛盾，八大有其具体表述；不是把两对基本矛盾换个名字。

**心里问：制度还不完善，是否说明只能推翻它？**

→ 不是。社会主义基本制度与生产力发展基本适应，不完善方面可以在制度自身发展中调整。后来改革的必要性也可从这里理解，但不能说1957年已提出1978年后的全部改革方案。

### 2. 人民内部有争论，是不是都要用对敌斗争办法？

→ 不是。毛泽东区分：**敌我矛盾主要是分清敌我，人民内部矛盾主要是分清是非**。分别用专政、民主的方法。人民内部矛盾一般是非对抗性的，处理不当也可能发生转化。

**总方针：用民主的方法解决人民内部矛盾。**

| 领域 | 方法 | 不要混成 |
| --- | --- | --- |
| 政治思想 | 团结—批评—团结 | 残酷斗争、无情打击 |
| 物质利益与分配 | 统筹兼顾、适当安排 | 只顾一方、不看全局 |
| 科学文化 | 百花齐放、百家争鸣 | 所有政治问题都按学术争论处理 |
| 共产党与民主党派 | 长期共存、互相监督 | 1957年已有后来完整十六字方针 |
| 民族关系 | 民族平等、团结互助 | 只防一种民族主义 |

**正确处理人民内部矛盾成为国家政治生活的主题，根本着眼点仍是团结各方、调动积极因素，把注意力转向社会主义建设。**

## 四、逻辑带背③｜为什么好的探索没有一直贯彻？

### 1. 从认清建设任务，偏离到什么地方？

→ 后来反右派斗争严重扩大化，把不少人民内部问题当成敌我问题；又夸大阶级斗争。

→ **1958年大跃进和人民公社化运动**急于求成，忽视经济规律，混淆生产关系与生产力的适应条件。不能因希望快发展，就认为高指标、浮夸和过快改变所有制能代替真实生产能力。

**解释错误，不用抽象的“左”字遮过去：不是想发展有错，而是不顾实际能不能做到，用主观愿望代替条件。**

### 2. 1961年为什么提出八字方针？

→ 严重困难要求回到调整恢复经济。

**1961年八届九中全会：调整、巩固、充实、提高。** 以此为起点，国民经济进入调整阶段。1962年七千人大会总结经验教训，发扬民主。不要把八字方针记成1978年改革开放方针。

**1964年底至1965年初第三届全国人大第一次会议**，周恩来在政府工作报告中提出建设**现代农业、现代工业、现代国防、现代科学技术**的目标。讲义以会议开幕年1964定位，答题遇到报告年份要留意跨年。

### 3. 为什么必须准确评价文化大革命？

**1966—1976年文化大革命**是由领导者错误发动、被反革命集团利用，给党、国家和各族人民带来严重灾难的内乱。它不是任何意义上的革命或社会进步。

→ 党和人民同错误进行抵制和斗争；这一时期仍取得部分建设成就，但**成就是在抵制错误、克服干扰中取得的，不是文化大革命本身带来的**。

1976年粉碎“四人帮”，文化大革命结束。**结束不等于指导思想上拨乱反正立即完成**，还需之后的思想路线纠正。

## 五、评价整个探索时期｜怎样两面都讲、又不混淆？

这一时期建立起独立的、比较完整的工业体系和国民经济体系，积累建设经验，国防科技等取得重要突破；也经历严重曲折。

**前后两个历史时期不能互相否定。** 改革开放建立在先前基本制度、物质技术和组织基础上；同时正因为总结先前经验教训，改革才能打开新局面。

分析题要落到具体关系：**肯定基础与成就，不等于为错误辩护；承认错误和改革必要性，不等于否定社会主义建设全部历史。**

## 六、把1978交到下一天｜先解决“能不能重新判断”

1978年真理标准问题讨论：**实践是检验真理的唯一标准**。不能因某一判断曾被提出，就禁止根据现实重新检验；它成为拨乱反正和改革开放的思想先导。

1978年12月十一届三中全会把工作重点转到社会主义现代化建设，实行改革开放。**1956八大正确提出建设任务，1978重新实现工作重点转变；不能把中间曲折省略，写成全程一直按同一路线平稳推进。**

## 七、90秒逻辑复述

社会主义基本制度确立后，党开始探索适合中国的建设道路。《论十大关系》强调以苏为鉴、调动积极因素，八大正确判断主要矛盾和发展生产力的任务，1957年又提出用民主方法处理人民内部矛盾。但后来“左”的错误使阶级斗争扩大化，经济建设急于求成，虽经调整仍发生文化大革命严重挫折。整个时期积累了工业和制度基础，也留下必须实事求是、尊重规律、健全民主法制的教训。1978年的思想解放为新的历史转折打开条件。

## 八、闭卷自测

1. 《十大关系》、八大、《正确处理》各回答哪一问？
2. 基本矛盾、主要矛盾、两类不同性质矛盾有什么区别？
3. 为什么大跃进错误不是简单“生产热情高”？
4. 1961八字方针是什么？四个现代化定位哪次会议？
5. 怎样同时评价建设成就与文化大革命错误，而不把两者混为因果？

> [!faq]- 核对
> 1. 协调关系调动积极因素；认清主要矛盾集中发展生产力；区分矛盾性质、用恰当办法处理。
> 2. 基本矛盾是社会基本结构关系；主要矛盾是阶段全局重点；敌我和人民内部矛盾用于区分政治关系性质和处理方法。
> 3. 它违背实际经济条件与规律，主观目标超越现实生产力，不能拿动机替代效果。
> 4. 调整、巩固、充实、提高；第三届全国人大一次会议（1964年底—1965年初）。
> 5. 成就提供后续发展基础；文化大革命是严重内乱，成就是在抵制错误、克服干扰中取得，不能归功于它。
