# 第1天｜1840—1901：救亡为什么接连失败

> 主要依据：大李子讲义PDF第165—166、182—186页（印刷156—157、173—177页）；正文第57—60页补充。页码以PDF阅读器页码为准，括号内为讲义印刷页码。解释性串联不等于历史只有一个原因。


> [!abstract] 今天只抓一个问题
> 外国打进来了，为什么农民起义、买机器练海军、请求皇帝变法，都没能把中国救出来？
> **不是中国人没有抵抗，而是抵抗没有同时解决：谁来领导、靠谁行动、要改掉什么制度。**

## 一、先把这一时期放进整部史纲

**鸦片战争打开缺口 → 不平等条约不断加深危机 → 不同阶级接连尝试救国 → 1901年清政府彻底成为列强统治中国的工具，寻找新出路更迫切。**

“半殖民地”不是一半国土被占，而是中国保留国家和政府的名义，却丧失完整独立主权；“半封建”也不是封建主义消失一半，而是自然经济受到破坏、资本主义因素发展，封建剥削和统治仍深刻存在。**两种压迫交织，所以不能只反侵略，也不能只反本国封建统治。**

由此推出两对矛盾：**帝国主义和中华民族、封建主义和人民大众**；总体上前者最主要。两大任务是：先争得民族独立、人民解放，再实现国家富强、人民富裕。前者为后者扫清障碍，后者是前者的最终目的和必然要求。

## 二、逻辑带背｜顺着“上一种办法缺了什么”往下想

### 1. 为什么不能把挨打只归结为“枪炮不如人”？

**心里问：技术落后确实会输，为什么一直落后、又为什么不能组织有效抵抗？**

→ 清政府政治腐败、压制和破坏群众抵抗，妥协求和；腐败制度又使经济技术落后的状况长期得不到改变。

**落笔句：近代中国反侵略战争失败，内部原因主要是社会制度腐败和经济技术落后，其中社会制度腐败是更根本的原因。**

不要反过来记成“根本原因只是武器落后”。也不要抹掉人民抵抗：1841年三元里抗英是近代中国人民第一次大规模反侵略武装斗争。列强最终没能瓜分中国，**最根本的原因是中华民族不屈不挠的反侵略斗争**；列强之间互相制约是重要原因。

### 2. 农民最直接的愿望是什么？有地、有饭，所以有太平天国

1851年金田起义，1853年定都天京，1864年失败。两份文件不能混：

| 文件                   | 想解决什么                                  | 为什么没落实、不能代表出路                              |
| -------------------- | -------------------------------------- | ------------------------------------------ |
| **《天朝田亩制度》（1853）**   | 按人口、好坏搭配平均分田；以土地问题为中心，反映农民否定封建土地所有制的愿望 | 追求没有商品交换的绝对平均，仍是小农业与家庭手工业结合的理想；平分土地方案未付诸实施 |
| **《资政新篇》（1859，洪仁玕）** | 学习西方，提出带有资本主义色彩的社会发展方案                 | 缺乏实施条件，未能实行；不是平均分田方案，也不能说太平天国已成为资产阶级革命     |

**心里问：既然反抗很坚决，为什么还是失败？**

→ 农民阶级有革命要求，但不是新的生产力和生产关系的代表，不能提出科学的革命纲领、形成足以持续指导革命的领导力量；宗教迷信、内部矛盾等又影响组织。**要记“阶级局限”，但脑中得有内容，不是用四个字代替解释。**

### 3. 洋务派看见枪炮差距，为什么“自强”“求富”还是救不了清朝？

19世纪60—90年代，地主阶级洋务派主张**“中体西用”**：保留封建统治的根本制度，学习西方军事技术和部分生产技术。

→ 办军用、民用企业，练新式海陆军，办新式学堂、派留学生。它是中国早期工业化、近代化的一次重要尝试，不能说“毫无作用”。

→ 但不愿改变腐败的统治制度；又有对外依赖、管理腐朽等问题。甲午战败、北洋海军覆没，宣告洋务运动失败。

**落笔句：洋务运动具有封建性、对外依赖性和管理腐朽性，其中封建性是其失败的根本原因。**

区分：洋务派办的部分民用企业具有资本主义性质，**不等于洋务运动就是资产阶级领导的运动**。裁撤绿营、废科举属于后来的清末新政，不是洋务运动。

### 4. 只学技术不够，那能不能保留皇帝、改政治制度？

→ 早期维新派开始主张既学技术又学政治经济制度。郑观应《盛世危言》提出发展民族工商业、商战、设议院、君民共主。

→ 甲午战败后危机加深，康有为、梁启超等推动维新。**1898年戊戌维新是资产阶级性质的改良运动，也是爱国救亡和思想启蒙运动。**

**为什么温和改革也失败？** 民族资产阶级力量弱，对帝国主义抱幻想、对封建势力妥协，惧怕和脱离群众，把希望主要寄托于没有实权的皇帝。实际诏令又未采纳开国会、定宪法等关键政治主张。

**落笔句：失败表明，在当时中国，企图依靠统治者自上而下改良的道路行不通。** 这里说的是特定历史条件，不是说一切改革都无效。

### 5. 民众为什么还会支持义和团？为什么又不能照单全收其主张？

→ 列强侵略、教会势力与地方冲突激化，义和团反帝斗争打击了列强瓜分中国的图谋，有爱国意义。

→ 但存在笼统排外、迷信落后、受清政府欺骗等局限。**反帝的积极作用与认识、组织上的局限可以同时存在。** 不能因局限否定抵抗，也不能把笼统排外当科学纲领。

## 三、日期不是孤立背｜四个条约对应危机加深

| 事件      | 记住的时间与条约                 | 用来定位的关键词                                                   |
| ------- | ------------------------ | ---------------------------------------------------------- |
| 第一次鸦片战争 | 1840—1842；**1842《南京条约》** | 近代史起点；<font color="#ff0000">开始沦为</font>半殖民地半封建社会           |
| 第二次鸦片战争 | 1856—1860；《天津条约》《北京条约》   | 半殖民地半封建化程度进一步加深                                            |
| 甲午中日战争  | 1894—1895；**1895《马关条约》** | 允许日本在通商口岸设厂；列强资本输出扩大；民族意识<font color="#ff0000">普遍觉醒</font> |
| 八国联军侵华  | 1900；**1901《辛丑条约》**      | 清政府成为“洋人的朝廷”；<font color="#ff0000">完全陷入</font>半殖民地半封建社会深渊  |

别把战争发生年直接当签约年。《马关条约》割地包括辽东半岛、台湾全岛及附属各岛屿、澎湖列岛；辽东半岛后因三国干涉被赎回，不能因此从条约原规定中删掉。

## 四、著作这条线｜从睁眼看世界到追问制度

- **林则徐**：近代中国睁眼看世界的第一人。
- **魏源《海国图志》**：提出“师夷长技以制夷”，重在学习先进军事、科学技术。成书、刊刻有不同版本年份，定位1840年代，不把版本年当核心。
- **郑观应《盛世危言》**：把学习推进到政治经济制度层面。
- **严复《救亡决论》（1895）、《天演论》（1898正式出版）**：救亡呼声、进化论思想与危机意识。
- **孙中山1894年兴中会**：喊出“振兴中华”；它是革命团体，1905年同盟会才是全国性资产阶级革命政党。

> [!note] 这是一条便于复习的认识线，不是整齐接力
> 农民起义、洋务、维新、革命活动在时间上有交叉。“学技术→改制度”概括的是探索逐渐深入，不能理解成上一种运动结束后，下一种才开始。

## 五、把今天连成一段｜90秒复述

鸦片战争后，中国逐渐沦为半殖民地半封建社会，反帝反封建成为革命任务。农民通过太平天国追求土地和生存，却受阶级局限，不能找到科学出路；洋务派试图在不改变封建制度的前提下学习西方技术，甲午战败暴露其根本局限；维新派进一步要求改革政治制度，却因自身软弱、依赖皇帝和脱离群众而失败。义和团有力抗击侵略，但也有笼统排外等局限。1901年《辛丑条约》使清政府的反动性进一步暴露，救国探索因而更迫切地指向推翻清王朝。

## 六、闭卷自测｜答不出再展开

1. 为什么近代要同时反帝、反封建？两大历史任务有什么关系？
2. 太平天国两份纲领，哪份讲平均分田，哪份有资本主义色彩？
3. 洋务与维新领导阶级、政治主张有什么不同？为什么都失败？
4. 甲午战败与1901年条约分别对应什么变化？
5. 列强不能瓜分中国，最根本的原因是什么？

> [!faq]- 核对
> 1. 两种压迫相互勾结；独立解放为富强富裕扫清障碍，后者是前者最终目的和必然要求。
> 2. 《天朝田亩制度》平均分田；《资政新篇》有资本主义色彩；两者都未按方案落实。
> 3. 洋务：地主阶级、中体西用、不改根本制度；维新：资产阶级改良派、君主立宪、依赖无实权皇帝而脱离群众。
> 4. 甲午：民族意识普遍觉醒、洋务失败、瓜分危机；1901：完全陷入半殖民地半封建社会深渊。全面觉醒联系五四，不是甲午。
> 5. 中华民族不屈不挠的反侵略斗争；列强互相制约不是最根本原因。
