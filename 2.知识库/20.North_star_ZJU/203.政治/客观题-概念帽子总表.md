# 客观题｜概念帽子总表

> 政治客观题的灵魂：**帽子词（唯一 / 根本 / 首要 / 基本 / 本质 / 核心 / 性质 / 特征）必须精确对应，不许串**。
> 用法：看到帽子词 → 3 秒内说出标准答案。说不出的，标记，回读对应体系串联。

## 一、马原帽子

| 帽子词（提问）                 | 标准答案       | 常见错配（直接排除） |
| ----------------------- | ---------- | ---------- |
| 马克思主义**本质属性 / 政治立场**    | 人民性        | —          |
| 人民性的**深刻基础**            | 阶级性        | —          |
| 马克思主义**首要的和基本的观点**      | 实践观点       | —          |
| 马克思主义**根本观点**           | 实事求是       | —          |
| 区别于其他理论的**根本特征 / 显著特征** | 实践性        | —          |
| 马克思主义**最鲜明 / 本质特征**     | 科学性与革命性的统一 | —          |
| 物质的**唯一特性**             | 客观实在性      | ❌ 运动       |
| 物质的**根本属性 / 存在方式**      | 运动         | ❌ 客观实在性    |
| 物质运动的**基本存在形式**         | 时间和空间      | ❌ 观念产物     |
| 设想不运动的物质                | 形而上学       | ❌ 唯心主义     |
| 设想无物质的运动                | 唯心主义       | ❌ 形而上学     |
| 运动与静止                   | 运动绝对、静止相对  | ❌ "静止是绝对的" |

### 寓于口诀（字母排序法：前面的字母"寓于"后面的字母）
- **必**然（B）寓于 **偶**然（O）
- **斗**争性（D）寓于 **同**一性（T）
- **价**值（J）寓于 **使**用价值（S）
- **普**遍性（P）寓于 **特**殊性（T）
- **绝**对真理（J）寓于 **相**对真理（X）

> 倒过来（"特殊性寓于普遍性""同一性寓于斗争性"）→ 直接打叉。

## 二、毛中特 / 新思想帽子

| 帽子词 | 标准答案 |
|---|---|
| 全面建设社会主义现代化国家的**首要任务** | 高质量发展 |
| 高质量发展的五大理念地位 | 创新=第一动力；协调=内生特点；绿色=普遍形态；开放=必由之路；共享=根本目的 |
| 教育 / 人才 / 创新 | 教育=基础；人才=第一资源；创新=第一动力、居核心位置 |
| 党的**政治建设** | 根本性建设（摆在首位） |
| 旗帜鲜明讲政治 | 根本要求 |
| 维护党中央权威和集中统一领导 | 首要任务 |
| 党的**全面领导** | 根本保证 |
| 国家安全三关系 | 人民安全=宗旨；政治安全=根本；经济安全=基础 |
| 强军目标三要素 | 听党指挥=灵魂；能打胜仗=核心；作风优良=保证 |
| "一国两制" | "一国"是根本/前提/基础，"两制"是叶末 |
| 市场与政府 | 市场在资源配置中起**决定性作用**、更好发挥政府作用（十八届三中全会首次提出） |

## 三、史纲帽子（"第一次 / 首次"系列）

| 时间 / 会议 / 文献 | 唯一认定 |
|---|---|
| 五四运动（1919） | 新民主主义革命**开端**；工人阶级首次以独立姿态登上政治舞台 |
| 李大钊《我的马克思主义观》 | 第一次系统介绍马克思主义 |
| 中共二大（1922） | 第一次提出反帝反封建的民主革命纲领 |
| 中共四大（1925） | 首次提出**无产阶级领导权 + 工农联盟** |
| 中共六大（1928） | 唯一一次在国外（莫斯科）召开 |
| 六届六中全会（1938） | 首次提出"**马克思主义中国化**" |
| 平型关大捷 | 全民族抗战以来**第一次大捷** |
| 《〈共产党人〉发刊词》（1939.10） | 第一次提出"**三大法宝**"（统一战线、武装斗争、党的建设） |
| 《中国革命和中国共产党》（1939.12） | 第一次提出"**新民主主义革命**"科学概念 |
| 《新民主主义论》（1940.1） | 第一次**完整提出新民主主义基本纲领**；标志毛泽东思想成熟 |
| 《在晋绥干部会议上的讲话》（1948.4） | 第一次**完整提出新民主主义革命总路线**（加"反对官僚资本主义"） |
| 《论十大关系》（1956） | "**第二次结合**"，开始独立自主探索建设道路 |
| 十八届三中全会（2013） | 首次提出市场起"**决定性作用**" |
