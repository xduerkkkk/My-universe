# 2015—2018选择题复盘：方法与必备知识

> [!important] 这次回收的目标
> **不是把四年的解析背下来，而是看见自己在哪一步选偏了，下一套能换一个动作。**
> 先用最少的知识守住概念，再用审题、翻译、排除补上判断。不能全靠背，也不能把技巧变成“凭词猜答案”。
> 本页不涉及2019年题目和答案。原记录按年份与题干定位；对话里的“第几题”不当作原卷题号。

## 一、进2019年前，先记住这一条做题顺序

1. **先看最后一句：问谁、问什么？** 圈出主语和限定：是“这段材料体现”，还是“某知识点包括”；是原因、结果、实质，还是某个精确称谓。
2. **把材料缩成一句话。** 谁做了什么，条件或结果有什么变化？不照抄长背景。
3. **逐项读完整句。** 看“谁＋在什么条件下＋起什么作用”，尤其读清长选项中间的定语。先排知识硬错，再判断是否答到设问。
4. **给犹豫项一个理由。** 能用知识或材料支持，就选；能指出具体错误或不符合设问，就排；暂时都做不到，就保留问号，和其他选项比较，不拿“怪、耳熟、像答案”作证据。
5. **最后复查，不凑个数。** 不因已经选了三个就删第四个，也不因只有两个就添第三个。改答案前，问自己：我发现了什么新依据？

**选一个选项，需要“说法成立＋符合本题”；排一个选项，可以因为“说法错误”，也可以因为“没有回答本题”。**

## 二、用自己的旧错，练八个具体动作

### 1．“材料没提”到底能不能选？先分清它在考什么

**你当时的卡点：** “我感觉A材料没提就没选……但有时选了，解析又说材料没提！”

不要按“马原一律抠材料，毛中特一律选好话”分科；也不要只认“表明、意义”一个词。**看完整设问，确定答案必须满足什么。**

- **问某知识点本身有哪些内容、因素、特点：** 材料可能只是引出考点。判断选项是否属于这个知识点，不要求材料逐条举例。
  - 2015年“我国经济新常态的主要特点是”：不能只收材料明确写出的增速变化，其余特点仍按该考点判断。
  - 2018年“资本积累规模取决于哪些因素”：这是因素判断，不是把题干里的“剩余价值”四个字找一遍。
- **问这段材料具体说明什么：** 选项既要正确，还要有材料事实或合理推论支持；不能把所有相关原理都装进去。
  - 2017年“灋”字题：“平之如水”支持公平，“触不直者去之”支持惩恶扬善；出现神兽，并不推出“皇帝权力来自上天”。

**下一题的动作：** 在心里补一句：“这题让我判断的是____，所以这个选项要有____依据。”

**边界：** 知识清单题也不能无视材料给出的时期、对象和条件；材料题也不要求选项必须复现原词。

回看：[[00真题笔记15-17#15|2015·经济新常态]]、[[00真题笔记15-17#17|2017·“灋”字]]、[[00真题笔记18-#18|2018·资本积累]]。

### 2．把材料换成概念，不是找相同字眼

**你当时的卡点：** 有同一个词就觉得有关；没有“生态”两个字，又觉得无关。

用下面三题感受区别：

| 旧题 | 要补上的那一步 | 为什么能判断 |
|---|---|---|
| 显微镜与科学发现 | 科学家＝实践主体；研究对象＝客体；显微镜＝中介工具 | 人借工具研究对象，所以“主体、客体依靠中介相互作用”有具体对应，不是一句空话 |
| 以人民为中心的理论基础 | 人民是历史的创造者 → 治国理政要依靠人民、为了人民 | 这是从原理推出要求；不是选项也写“主体地位”就更贴题 |
| 生态文明制度体系 | 考核评价决定干部重视什么 → 把生态要求纳入评价可约束发展行为 | “经济社会发展考核评价体系”没写“生态”，仍可能是生态制度建设的一环 |

**下一题的动作：** 写出一条短连接：“材料里的____，在原理中就是____；因此能支持____。”接不上时，再检查是不是只凭联想。

生态考核与责任追究、统一监管，确实属于相关制度建设内容；不是因为选项说得温和就选。[^生态]

回看：[[00真题笔记15-17#17|2017·显微镜]]、[[00真题笔记18-#18|2018·以人民为中心、河湖长制]]。

### 3．“决定、唯一、总是”不是错词；“可能、有利于”也不是对词

你既因为“决定”漏掉高层次信念，也因为“总是”不敢选“事物总是作为过程而存在”。这说明只按词的强弱判断，会来回失灵。

**正确检查顺序：**

1. 先问**主语是谁**：物质、意识、人民群众、个人，还是一种具体工具？
2. 再问**它对什么起什么作用**：决定、影响、促进、提供条件，不能互换。
3. 最后看**范围与条件**有没有被抹掉。

- “实践是检验真理的唯一标准”：这个“唯一”有知识依据，不因语气强就排。
- 党内政治生活的“战斗性”：是敢于坚持原则、开展批评与自我批评，不是日常语境里的动武。不能只因“和平年代怎么还讲战斗”就排除。
- “相同社会环境中的人，信念始终一致”：同样环境不等于相同认识、经历和选择；问题在把差异抹掉，不只是有“始终”。
- “杰出人物的性格等会影响社会进程”：承认影响，不等于让个人决定历史发展的基本方向。不要为了反对英雄史观，把人的作用也全部否掉。
- “不尊重他人权利，**可能**丧失自己的权利”：原题中的“可能”不能擅自读成“必然丧失一切权利”；但也不能反过来推出“凡有可能就正确”。

**下一题的动作：** 不说“这个词太绝对”，而说“它把____的作用说成了____，错在____”。

回看：[[00真题笔记15-17#15|2015·历史人物、过程]]、[[00真题笔记15-17#17|2017·信念、尊重权利]]。

### 4．长选项先拆开：好开头不保证整句对

2018年生态题，你看到了“完善……环保监督体系”，却没读住中间的**“部门职责分散交叉”**，又因A没写生态而漏选。

在题纸上可以这样拆：

> 完善／**部门职责分散交叉的**／环保监督体系。

改革要解决职责分散交叉的问题，而不是把这种问题当成需要完善、固化的制度特征。错误藏在修饰语里，不在“完善”这个好听的动词里。[^生态]

同样，2016年金融资本题，“全面私有化与放松金融监管”不能因为后半句沾边，就忽略前半句的“全面”。

**下一题的动作：** 遇到“和、与、并、从而”，把每一半都读清。通常只要一个必要组成判断错，整项就不能选；还要检查两半之间的因果是否成立。

**边界：** 褒贬和改革方向只能提醒你检查，不能代替事实。不是“凡贬义词都错”，更不是“凡正面表述都对”。

回看：[[00真题笔记18-#18|2018·生态文明制度]]、[[00真题笔记15-17#16|2016·金融资本制度条件]]。

### 5．遇到陌生因素，用一条因果链验证，不靠“看不出错”全选

2018年资本积累题，你漏了“资本家垫付资本的大小”。这类题不必背一大段故事，但要能解释各因素怎么影响结果。

先保住概念：**资本积累＝把剩余价值的一部分再转成资本。** 在其他条件相同、积累比例一定时：

- **剥削程度提高** → 剩余价值量可增加 → 可积累部分增加。
- **劳动生产率提高** → 生产资料等价值可下降 → 同量积累资金能购买更多生产要素；生活资料价值下降也与相对剩余价值生产有关。不能简化成“效率一高，工资必降”。
- **垫付资本更多** → 其中用于购买劳动力的资本可相应更多 → 获取的剩余价值量可更多 → 积累规模更大。**不是说机器自己创造剩余价值。**
- **所用与所费资本差额扩大** → 例如机器整体参加生产、价值却逐步转移 → 可继续利用其生产功能，有利于积累。不必把全部机器价值当作当期消耗。

这四项都有明确机制，才是本题全选的依据；不是“都是中性名词，所以全选”。[^积累]

**下一题的动作：** 问原因、作用、意义时，尝试补出“它改变____，所以影响____”。如果只能说“听起来有利于”，依据还不够。

回看：[[00真题笔记18-#18|2018·资本积累规模]]。

### 6．把相近词分层：谁拥有、谁经营、谁起主导作用，不是一件事

你有几道经济题，卡的不是记不住结论，而是把不同层次混在一起。

- **所有权 vs 经营管理权：** 高级职业经理可以实际控制大公司的经营活动，不等于最终拥有全部生产资料。不能因为“经理也是受雇者”，就否定其经营管理作用。
- **制度中的地位 vs 市场竞争中的地位：** 公有制为主体、国有经济起主导作用，不等于其他所有制不能依法平等参与市场竞争。
- **承包权 vs 经营权：** 原题中把土地经营权流转出去，不等于农户就失去了土地承包权。先看流转的究竟是哪项权利，不泛化成任何流转都一样。

**下一题的动作：** 先在脑中换成小问题：“这句是在问谁拥有，还是谁管理？问制度地位，还是交易规则？”

两个选项句式相似、共享关键词，只能提示你比较。**既不能规定它们必须一起选，也不能规定它们必须二选一。**

回看：[[00真题笔记18-#18|2018·职业经理]]、[[00真题笔记15-17#16|2016·所有制与市场准入]]、[[00真题笔记15-17#15|2015·农村土地流转]]。

### 7．遇到“枢纽、核心、根本宗旨”，换成精确对位，不再凭耳熟

2018年你把“理解政治经济学的枢纽”选成了剩余价值理论。这种题确实有最低记忆门槛，不能靠语感完全推出。

- **枢纽 → 劳动二重性。** 同一劳动，一面生产使用价值，一面形成价值；它把商品两个因素的分析连接起来。[^枢纽]
- **基石 → 剩余价值理论。** 不要因为它更熟，就拿来回答另一个称谓。

2018年“深化经济体制改革的重点”，则能先分层：产权、要素配置讲的是制度与资源配置规则，供给数量讲的是另一个具体问题。**这能帮助排除和定位，但最终对应仍有十九大报告原文依据；不是拆出“体制”两个字就能推出任何年份的标准表述。**[^十九大]

**下一题的动作：** 遇到精确称谓，问：“这个帽子的完整搭配是什么？”想不起来，就用定义与排除缩小范围，订正时只补这一对，不扩出整章。

回看：[[00真题笔记18-#18|2018·政经枢纽、经济体制改革重点]]。

### 8．史纲先放时间和主体，再看“首次、开始、成熟、决战”

2017年大别山题，你把“三大主力军”联想成“三大战役”，选了战略决战。先把相近字眼拆开：

> **1947年：刘邓大军千里跃进大别山，揭开战略进攻序幕。**  
> **1948—1949年：辽沈、淮海、平津三大战役，战略决战。**

看孙中山题时也要留住你的疑问：**你记得他组织过北伐，并不是全错。** 1924年确有孙中山组织的北伐；不能从“他1925年去世”推成“他从没组织过北伐”。原题要区分的是通常所指的1926年国民革命军北伐战争，不可把几次事件混成一次。[^北伐]

十一届三中全会“重新确立思想、政治、组织路线”，也不是因为“看起来伟大”才选，而是确有历史内容支撑。把拨乱反正的具体内容和三条路线对应起来，比记“这种题往往全选”可靠。[^三中全会]

**下一题的动作：** 心里排成“何时／谁／做什么／到哪一步”。“开始”不等于“完成”，“形成”不等于“成熟”，有准备不等于已经取得最后成果。

回看：[[00真题笔记15-17#17|2017·大别山、孙中山、十一届三中全会]]。

## 三、只带走这批知识，不把整张帽子表再背一遍

### A．先守住四条能反复排错的关系

1. **实践与认识：** 实践是认识的基础；实践是检验真理的唯一标准。物质生产实践是最基本的实践活动，不能因为题材是科研，就把科学实验升级成“最基本”。
2. **规律与能动性：** 尊重客观规律是正确发挥主观能动性的前提。人可以认识、利用规律，不是靠意愿改变规律。雾霾材料强调人的努力，不等于“思想活动成了根本前提”。
3. **群众与人物：** 人民群众是历史的创造者；这不排斥个人影响历史进程。判断时区分“影响、推动”与“决定历史发展的基本方向”。
4. **资本主义的调整与本质：** 福利、职工持股、管理方式变化，可以缓和矛盾，不等于消除剥削或根本解决资本主义基本矛盾。不要从“形式变了”直接跳到“制度性质变了”。

这些不是要求你看见某个词就选，而是用来检查**整句话的关系方向**。

### B．从这四年实际错处留下的防混搭配

| 先记完整主语 | 必须分清的搭配 | 下次防什么 |
|---|---|---|
| 党的根本宗旨 | 全心全意为人民服务 | 不拿立场、目标等其他表述来替代宗旨 |
| 党的建设 | 政治建设：根本性建设、摆在首位；思想建设：基础性建设[^党建] | “根本性”和“基础性”不要互换 |
| 党的思想路线 | 核心：实事求是 | 党的基本路线不是思想路线的核心 |
| 两种“生命线” | 基本路线：党和国家的生命线、人民的幸福线；群众路线：党的生命线和根本工作路线 | 不能只看见“生命线”就连线 |
| 统一战线 | 重要法宝；人民当家作主的根本保证：党的领导 | 法宝不等于根本保证 |
| 公有制与国有经济 | 公有制：主体；国有经济：主导作用 | 不把主体、主导互换，更不据此否定公平竞争 |
| 科技、人才、创新 | 科技：第一生产力；人才：第一资源；创新：第一动力 | 不把三个“第一”凭熟悉程度乱配 |
| 马克思主义政治经济学 | 枢纽：劳动二重性；基石：剩余价值理论 | 问哪个称谓，答哪个，不自动选最熟的 |

经济体制改革重点与相关基本路线等表述，可对照十九大报告；党建的两种建设另附核对来源。复盘旧题按当时语境，不把一个时期的具体政策提法推广成永远不变。[^十九大]

### C．两处要特别纠正旧解析，而不是照背

**① 机器多、效率高，不等于机器创造价值，也不等于单位商品社会价值立即下降。**

- 新价值由活劳动创造，机器等生产资料的原有价值转移到产品中。
- 商品价值量由**社会必要劳动时间**决定。某家企业率先提高效率，先降低的是其个别劳动耗费；在社会必要劳动时间未变时，不能说社会价值已随它一起降低。
- 讨论该部门社会劳动生产率普遍提高，才对应单位商品社会价值量下降。旧记录里的“效率越高，单个商品价值越低”，必须补上这个主语区别。[^价值]

**② 毛泽东思想的形成、成熟，记阶段区别，不扩成著作大清单。**

- 土地革命战争时期：农村包围城市、武装夺取政权道路理论的形成，标志初步形成。
- **新民主主义理论的系统阐明：成熟的重要标志。** 不能把“思想政治工作和文化工作理论”等某个组成部分，直接当成成熟标志。[^成熟]

## 四、旧笔记里，这些“铁律”不要继续带进考场

| 原来的说法 | 现在换成什么 |
|---|---|
| 找不出错就默认全选 | 不因陌生而排除；但要继续找知识、材料或合理推论作为选择依据 |
| 可能、有利于、之一几乎必对 | 只是语气留有余地；主语、关系和设问仍可能错 |
| 决定、唯一、总是几乎必错 | 查它有没有知识依据，是否抹掉必要条件 |
| 正面成就题，正能量选项全收 | 成就支持哪个方面，就选哪个方面；不能无限拔高 |
| 马原九成靠排原理错，不必管材料 | 排硬错很有用；剩下仍要检查是否答到本题，不使用未经统计的比例 |
| 两项长得像，就一起选／必有一假 | 分别判断，再比较区别；句式不是答案规则 |
| 短选项避开最熟的；宏观题选最熟的 | 熟悉度不算依据；精确称谓查搭配，理论基础查推理方向 |
| 只要问核心、精髓，蒙实事求是 | 先读完整主语；“谁的核心”不同，答案就可能不同 |

**最该保留的不是“大胆全选”，而是：不再凭陌生感删答案，也不再凭好听和耳熟加答案。**

## 五、合上后，拿六个问题检查自己

> [!faq]- 1．材料没有逐条写出某特点，我怎么判断它能不能选？
> 先读完整设问：是在考该知识点本身，还是这段材料具体体现什么。前者查知识范围，后者找材料事实或合理推论；两者都受时期、对象和条件约束。

> [!faq]- 2．显微镜题，我为什么漏了“主体和客体依靠中介相互作用”？
> 没把具体名词翻译成概念。科学家借显微镜研究细胞，就是主体借中介作用于客体。下次先补这条对应，不只认原词。

> [!faq]- 3．为什么“完善……环保监督体系”也会是错项？
> 要把中间的修饰语读完。本题把“职责分散交叉”放进要完善的体系特征中，方向错了；不是看到“完善、环保”就成立。

> [!faq]- 4．“垫付资本更多”与“机器不创造剩余价值”矛盾吗？
> 不矛盾。其他条件一定时，更大预付资本可包含更多用于购买劳动力的资本，从而获取更多剩余价值。结论不需要假定机器自己创造新价值。

> [!faq]- 5．“以人民为中心”为什么不是选带“主体地位”的复杂选项？
> 题目问唯物史观理论基础，要从“人民群众创造历史”推出依靠人民、为了人民。重复字眼不是这条推理。

> [!faq]- 6．遇到“决定”不敢选，遇到“可能”就想选，我该改哪个动作？
> 改成先读“谁对什么起什么作用”，再查条件和范围。强弱词只提醒检查，不代替判断。

## 六、然后就去做2019，不等到“这页全背熟”

- 做前：看第一节的五步顺序，再回想最有感的两三个旧错。不把本页变成新一轮背诵门槛。
- 做时：按原来的做题安排继续。犹豫项只在草稿上留极短理由，如“核心主人不对”“没翻译中介”“年代不合”；不强迫每题写解析。
- 核对后：先比较“我凭什么选”与正确依据。如果用了方法仍错，查是方法越界还是确实缺知识；不是简单给自己贴“又粗心”的标签。
- **只在原有记录补一句最值得保留的改法。** 不新建打卡表，不要求回头重做四年，也不提前看2019答案。
