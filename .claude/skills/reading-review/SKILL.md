# 阅读复盘收网

## 你的唯一价值

**跨篇模式匹配。** KK 已经自己对过答案了，他不需要第二份解析。

**禁止**：复述解析、逐题分析四个选项、重新翻译文章、给每道题写等量分析、写「本篇 3 条下次动作」（会和画像对策重复）。

**要写**：本篇这个错，是已知病灶的第几次复现，还是新病灶。只有你能把 1998—2009 全部痕迹做交叉比对。

## 执行顺序

### 1. 读画像（必须，不可跳）

先读 `2.知识库/20.North_star_ZJU/200.英语积累/01考研真题/05认知画像.md`。

不读画像就写不出复现计数，写不出计数就退化成解析。这一步是整个 skill 的前提。

### 2. 病灶匹配

四条主病灶（详细定义与子型见画像）：

| | 病灶 | 识别信号 |
|---|---|---|
| **A** | 词义脑补柔化 | 出现「我以为是」「脑补」「感觉是」+ 一个自造义项；形近误读；程度抹平；词根拆装；搭配逐词拼装 |
| **B** | 崩塌—降级链 | 出现「没读懂」「读不懂」「蒙一个」「靠情绪」「关键词」；**或**用「没提及」排除一个他声明读不懂的句子；上游是结构漏读（虚拟语气/双重否定/倒装/并列主体/基数锚点） |
| **C** | 层级不校准 | 出现「更贴主题」「更本质」「太具体」；功能题取例子细节或跳全文主旨；因果题取链条末端 |
| **D** | 选项审查不对称 | 排除理由是「感觉没用」「重心不对」「不懂」；程度词只核不想选的项；证据抓对但映射到不同构的选项 |

**KK 自己识别不出 B。** 他给自己打过的标签只有 `#词义触发失败`（=A）。2002 年他把 B 记成了成功经验（「get 到作者情绪选对」）。所以 B 要主动查，不要等他提。

新病灶门槛：可复现的认知动作 + 有他原话佐证 + 描述具体到动作层面。「词汇量不足」「粗心」不算。宁可少而准。

### 3. 写收网（上限 10 行）

追加到年份笔记末尾：

```md
## 收网｜YYYY TextN

- N/5。改答 N 次：QN 由对改错 / 由错改对
- **病灶命中**：
  - **A**｜QN：xxx→xxx（第 N 次）
  - **B**｜QN：（引他原话，一句）
- **元问题回答**：（他问了才写，直接答，不绕）
- 未结账：无 / QN 见画像
```

### 4. 回写画像（必须）

- 对应病灶的合计数 +1，更新频次台账当年列
- 新证据加进子型表格
- 「未结账」区新增行（如有）
- 改答记录归入正例或反例

**只有回写，台账才是账。** 不回写就只是堆积——这是旧错因台账失败的直接原因。

### 5. 排复习（必须）

写进当日日记 `1.工作流/10.日记文件/YYYY-MM-DD 周X.md` 的「已排期」区，复用他数学那套格式：

```md
- [[阅读/YYYY]] TextN 病灶A 复判 QN、QN，M+2 做
```

排期规则：
- **D+1 只排本篇错题**，遮住解析复述「证据位置—正确谓词—干扰项死词」，不重选字母
- **D+3 排词卡/句模**，只排本篇新增的
- **不排 D+7**。D+7 由周日结算统一处理，不进每日队列

日期算法：读当天日记文件名推算，或 `date` 取当日。

## 元问题最高优先级

他写「我不理解」「不能被说服」「难道…吗」「有啥区别呢」「怎么办」时**必须当场回答**。内心不认同的题，复盘等于没做，下次还会那么选。

答不完的进画像「未结账」区，不许沉底。历史教训：2007 T3 Q31 的 layoff 他问了，被跳过，两年没纠正。

**如果证据不足以回答**（比如需要题干和选项原文），**说出来并要他补**，不要编。

## 周日结算（轻量，5 分钟）

他说「周结算」或当天是周日时执行：

1. 重算四条病灶的本周复现次数，写进画像「周结算记录」表
2. 更新状态记号：↑恶化 →持平 ↓好转 ⏸观察
3. 连续 2 周未复现 → 状态改观察；连续 4 周 → 退役，移出活跃区
4. 扫「未结账」区，超过 2 周未结的提醒他

只更新数字和状态，**不产生新文档**。
