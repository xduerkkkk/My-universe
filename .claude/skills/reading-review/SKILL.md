# 阅读复盘收网｜周批

> **2026-07-28 改为周批。** 原为每篇调一次，KK 提出「单篇调用时 AI 只能复述我已经知道的东西」。
> 现在每周六一次性喂 5 篇，跨篇比对才成立。他自己对答案、自己写收网、自己答对策执行栏。

## 你的唯一价值

**跨篇模式匹配。** KK 已经自己对过答案、自己写过收网了，他不需要第二份解析。

> [!important] 一切频次按**首答**判定，不按终答
> 09 T1—10 T1 五篇：首答 16/25 = 64%，终答 20/25 = 80%，4 题差值全部来自查词。
> 考场没有词典。**查词救回来的题照样计病灶。** 此前记录混用终答，导致病灶被查词冲销。
> 每次周结算必须在画像「周结算记录」表填**本周首答率**——这是唯一进趋势判断的数字。

**禁止**：复述解析、逐题分析四个选项、重新翻译文章、给每道题写等量分析、写「本篇 3 条下次动作」（会和画像对策重复）。

**要写**：本篇这个错，是已知病灶的第几次复现，还是新病灶。只有你能把 1998—2009 全部痕迹做交叉比对。

## 执行顺序

### 1. 读画像（必须，不可跳）

先读 `2.知识库/20.North_star_ZJU/200.英语积累/01考研真题/05认知画像.md`。

不读画像就写不出复现计数，写不出计数就退化成解析。这一步是整个 skill 的前提。

### 2. 病灶匹配

四条主病灶（详细定义与子型见画像）：

| | 病灶 | 识别信号 |
|---|---|---|
| **A** | 词义脑补柔化 | 出现「我以为是」「脑补」「感觉是」+ 一个自造义项；形近误读；程度抹平；词根拆装；搭配逐词拼装 |
| **B** | 崩塌后**不回补** | 出现「没读懂」「蒙一个」「靠情绪」「关键词」，**且二遍没有回补记录**（没查词、没引证据句、没定位）。上游是结构漏读（虚拟语气/双重否定/倒装/并列主体/基数锚点） |
| **C** | 层级不校准 | 出现「更贴主题」「更本质」「太具体」；功能题取例子细节或跳全文主旨；因果题取链条末端 |
| **D** | 选项审查不对称 | 排除理由是「感觉没用」「重心不对」「不懂」；程度词只核不想选的项；证据抓对但映射到不同构的选项 |

**KK 自己识别不出 B。** 他给自己打过的标签只有 `#词义触发失败`（=A）。2002 年他把 B 记成了成功经验（「get 到作者情绪选对」）。所以 B 要主动查，不要等他提。

> [!warning] 判 B 之前先看有没有二遍回补——2026-07-25 踩过的坑
> 「限时读不懂」**不是** B。KK 的痕迹里，限时感受和二遍结论常常写在一起，「无力分析」「读不懂逻辑」多半是 18 分钟里的话。
>
> **判 B 的充分条件是：崩塌 + 二遍没回补。** 回补的标记是——查了词、拆了句、或引用了一句证据原文。
>
> 2009 T4 Q2/Q5 曾被误判成 B。实际他二遍找到了 `carriers of European culture` 和 `Our main end was to catch fish` 两句正向证据，是完整闭环。**误判的代价是让他觉得「那我也没办法啊」——把能力问题和动作问题混在一起，对策就落不了地。**
>
> 他若只记了一个信心值，先问是限时还是二遍，不要默认。

新病灶门槛：可复现的认知动作 + 有他原话佐证 + 描述具体到动作层面。「词汇量不足」「粗心」不算。宁可少而准。

### 3. 写周批收网（5 篇合计上限 25 行）

KK 已自己写过每篇收网。你**不重写单篇**，只写一份跨篇的：

```md
## 周批｜W N（YYYY TextN—TextM）

- **首答 __/25 = __%**（上周 __%），终答 __/25，查词带来 __ 题
- **跨篇模式**：本周 5 篇里 A 复现 N 次，其中 __ 篇是同一子型 → 说明什么
- **病灶计数**：A +N（第 __ 次）／B +N／C +N／D +N，均按首答
- **对策执行栏统计**：没想起来 N ／ 想起来没执行 N ／ 执行了还是错 N
  - 若「执行了还是错」≥2 → **对策本身有问题，当场改对策**，这是唯一需要改设计的信号
- **命题压缩**：15 句里压不出 N 句
- **元问题回答**：（他问了才写，直接答，不绕）
- 未结账：无 / QN 见画像
```

单篇的每题判决表**一律不写**。他已经写了。

### 4. 回写画像（必须）

- 对应病灶的合计数 +1，更新频次台账当年列
- 新证据加进子型表格
- 「未结账」区新增行（如有）
- 改答记录归入正例或反例

**只有回写，台账才是账。** 不回写就只是堆积——这是旧错因台账失败的直接原因。

### 5. 生成下一周训练文件（必须，替代原「排复习」）

**英语不再进日记，也不再进 [[1.工作流/回滚台账]]**（2026-07-28 迁出，原因：颗粒细、周期短，混进数学 408 的按日台账会被冲掉，迁出时 3 条待做项全部欠着）。

新建 `2.知识库/20.North_star_ZJU/200.英语积累/04每周训练/W{N} YYYY-MM-DD~MM-DD.md`，照抄 W1 的结构（7 个日块，每块 4 段：检测抽查 / 新单元 / 真题 / 回滚）。

**填充规则**：

- **① 检测抽查**：每天 6—8 项，格式是「原文表达 → 一个改写 → 差在哪一维」。**必须至少 3 项来自程度·时态桶**。素材来源优先级：本周 B/C 项 > 本周新入库词卡 > [[2.知识库/20.North_star_ZJU/200.英语积累/01考研真题/03真题语境辨义卡片]] 里复现≥2 的卡。每周掺 1—2 项**等价正例**，否则他会形成「凡是改写必有差异」的定式
- **② 新单元**：按 [[2.知识库/20.North_star_ZJU/200.英语积累/03六周词义辨析攻坚/00-六周背诵总表]] 的周次表取，每天 3 熟词生义 + 2 近义组 + 1 形近组（形近组取自 [[2.知识库/20.North_star_ZJU/200.英语积累/02相近词辨析-整理版/04-形近易混·字母级辨析]]）+ 2 句模。核对内容折进 `<details>`
- **③ 真题**：周一到周五各 1 篇，表头六栏（首答/限时信心/终答/二遍信心/对错/靠哪一句）+ 首答终答汇总行 + 命题压缩 3 句 + 对策执行三选一
- **④ 回滚**：D+1 复判前一天错题。**不排 D+3/D+7**，词卡抽查由①承担
- 周六是周报日（不学新内容），周日闭卷周测

**每月末那一周**：把周一到周四的四篇改成同一天 75 分钟连做，只记首答，次日补精读。不消耗额外真题，当月度体检。

### 6. 句模收录（仅当 KK 粘贴了他认为不错的句子时执行，2026 年起、2010 年真题起）

KK 会在痕迹里标出他觉得好的句子，但他自己判断不准——**分工是他挑候选，你过滤**，不是他判断好坏。

**三条过滤规则**（来自 [[0.核心/00.规划(Plan)/2.当前项目/02-english.md]]，和作文好句积累同一套标准）：

1. **能不能用来说理**——让步、因果、对比、程度递进。能接得上「因为/虽然/相比之下/越来越」的逻辑关系，留；只是描述得漂亮、没有说理功能的，丢。
2. **语域进不进考研作文**——学术长从句、插入语嵌套式的句子丢。留下的必须是考场 15 分钟内能盲写复现的复杂度。
3. **能不能提炼出带槽位的句模**——提炼不出通用槽位（换个主题就不能套）的丢。

**过滤后每篇上限 3 条**，超过时优先留因果/让步/对比类。

对通过的每一条，输出：
```md
原句（YYYY TextN）：...
句模：...（带槽位，如 What matters is not X but Y.）
作文用例：...（你写，不要 KK 写——他这步的产出是筛选,不是造句）
```

追加到 [[2.知识库/20.North_star_ZJU/200.英语积累/01考研真题/02搭配-句模库.md]] 末尾，标注年份来源。**不要另开新文件**，2010 起的句模和 2000-2009 的句模同库。

不要问「你觉得这条怎么样」——他不敢判断正是这步存在的理由，你判断，他确认或改。

## 元问题最高优先级

他写「我不理解」「不能被说服」「难道…吗」「有啥区别呢」「怎么办」时**必须回答**。内心不认同的题，复盘等于没做，下次还会那么选。

**周批模式下的取源**：周文件每天有一行「今日不服」，周六有「本周不服汇总」。**先读这两处**，再扫 5 篇痕迹里的疑问句式（他不一定会把不服都填进汇总栏）。

> [!warning] 周批把元问题的答复延迟拉到最长 5 天，所以超期提醒是硬要求
> 历史教训：2007 T3 Q31 的 layoff 他问了，被跳过，**两年没纠正**。
> **积压的真正成因不是周期长，是没有超期提醒。** 每次周批必须扫画像「未结账」区，超 2 周未结的**主动报出来**，不等他问。
> 他若说「不知道有啥元问题」——那就是真没有，别硬造。元问题的特征是让他难受，会自己浮出来。

**如果证据不足以回答**（比如需要题干和选项原文），**说出来并要他补**，不要编。

## 周六结算（周批的最后一步）

1. 填**本周首答率**进画像「周结算记录」表——第一列，最重要
2. 重算四条病灶本周复现次数（按首答），更新状态记号：↑恶化 →持平 ↓好转 ⏸观察
3. 连续 2 周未复现 → 状态改观察；连续 4 周 → 退役，移出活跃区
4. 扫「未结账」区，超过 2 周未结的提醒他
5. 连续两次判 B/C 的抽查项 → 进画像高危表

> [!warning] 别再把 B 的好转当成主要成绩
> B 的考场对策原文是「限时读不懂就降级裁决，这是对的，只标 L；二遍阶段才是真正的对策所在」。
> **所以 B 按定义是二遍纪律指标，几乎不携带限时信息。** 它在 09T4/10T1 归零的时点正好是二遍协议引入的时点——协议要求闭环，于是闭环出现了。
> 同期 A（33 例，每年都有）状态 → ，九年未动，且 10T1 唯一的首答错点就是 A。
> 报告本周成绩时，**首答率和 A 的首答复现次数放最前面**，B 的闭环比往后放。

只更新数字和状态，除下周训练文件外**不产生新文档**。
