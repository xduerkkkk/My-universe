# 阅读复盘收网｜周批

> 周六一次性喂本周 5 篇，跨篇比对才成立。他自己对答案、自己写痕迹和错因识别。
> **周为周日到周六**（2026-08-01 改）。周日低压力 prep（选题+查背景+技巧课），周一到周五各 1 篇真题，周六周报。

> [!important] 他的做题流程（2026-07-30 自己改的，别按旧版理解）
> 18 分钟裸答 → **5 分钟不查词的考场检查**（圈功能词、梳理逻辑，终答记这一步的结果）→ 查词只留真正干扰做题的词和难拆/好句 → 对答案 → 自己写错因识别。
> **终答不再含词典能力**，是「裸考 + 考场检查」。所以终答−首答这个差值第一次可迁移到考场——那 5 分钟考场真的有。

## 你的唯一价值

**跨篇模式匹配。** KK 已经自己对过答案、自己写过收网了，他不需要第二份解析。

**禁止**：复述解析、逐题分析四个选项、重新翻译文章、给每道题写等量分析、写「本篇 3 条下次动作」（会和画像清单重复）。

**要写**：这个错是已知病灶的第几次复现，还是新病灶。只有你能把 1998 至今全部痕迹做交叉比对。

> [!important] 一切频次按**首答**判定，不按终答
> 考场没有词典。**查词救回来的题照样计病灶。**
> 每次周结算必须在画像「周结算记录」表填**本周首答率**——这是唯一进趋势判断的数字。
> **自己核一遍首答计数，别抄他的汇总表。** W1 他把 T3 的 2/5 写成了 3/5（首答 D 终答 C 判对的题被算进首答），整周率从 40% 虚高到 45%。

## 执行顺序

### 1. 读画像（必须，不可跳）

先读 `2.知识库/20.North_star_ZJU/200.英语积累/05认知画像/病灶画像.md`。

不读画像就写不出复现计数，写不出计数就退化成解析。这一步是整个 skill 的前提。
九年子型大表在 `01考研真题/归档/认知画像-九年证据库.md`，只在需要某年具体案例时回查。

### 2. 病灶匹配

**三条活跃病灶**（2026-08-01 由四条重划，详细定义见画像）：

| | 病灶 | 识别信号 |
|---|---|---|
| **1** | 功能词不进计算 | 漏 `has been / appears / would / may / but / yet / only / ever since`；时态差一格；态度取了转折之前那句；程度词换成「是/否」 |
| **2** | 实词凭语感填义 | 「我以为是」「脑补」「第一反应成」+ 一个自造义项；形近误读；多词搭配逐词拼；被动搭配不识别 |
| **3** | 审查不对称 | 排除理由是「感觉没用」「重心不对」「不懂」「未提及」；程度词只核不想选的项；**改答时苛待首答、放过替代项** |

**观察区**（暂不计数，只在复现时提醒）：层级不校准（原 C，观察第 1 周）｜崩塌后不回补（原 B，观察第 2 周）｜题干嵌套误解析｜背景空白导致不敢选｜反复出现的专名不追踪。

> [!warning] 病灶 1 和病灶 2 的边界
> 同一道题可能两条都中，**按触发点归**：漏的是功能词记 1，填错的是实词记 2。
> 10T1Q1 `has been an inexorable decline`→disappear 两条都中：漏 has been 是 1，decline→disappear 的程度抹平是 2。这种题两边各记一次，不要只记一条。

新病灶门槛：可复现的认知动作 + 有他原话佐证 + 描述具体到动作层面。「词汇量不足」「粗心」不算。宁可少而准。

### 3. 算改答账（必须单列）

**门槛（2026-08-01 换过，别用旧的）**：改答必须**写得出一句新的原文证据句**。

旧门槛是「只在查到新词义时才改」。KK 2026-07-30 起把检查阶段改成**不查词**，那条门槛在新协议下没有任何改答能满足，是死条文。新门槛在考场可执行——只需问「我能不能指着一句原文」。

三档分开数：**错→对**／**对→错**／**错→错**，每档标「有引句 / 无引句」。

然后算一句：**只放行有引句的改答，本周会是几分。**

W1 新协议下 5 次改答，规则 3/3 预测准确：放行 2 次（T3Q5、T4Q2，都引了原文）全部错→对；拦下 3 次（T3Q1「discuss/describe 字面差异」、T3Q2「整段情感」、T3Q4「结合此段逻辑」，全部无引句）其中 1 次有害 2 次无损。**净赚 1 题。**

这个差值是**纪律损失，不是能力损失**，和首答率并列报。他自己算不出，因为它要求把每次改答的理由按「有没有引句」分类。

> [!warning] T1/T2 与 T3/T4 的终答不同口径
> W1 的 D1、D2（T1、T2）终答是**查词后**的；D4 起（T3、T4）是**不查词检查后**的。
> 跨周比较终答时注意 2026-07-30 是分界线，之前的终答含词典能力，之后的不含。

### 4. 分类查词区（他不标，你判）

KK 在痕迹里贴一堆词和句子，**故意不标注哪个是哪类**（2026-08-01 定，理由是他判断不准，标注权归你）。你分三桶：

| 桶 | 判据 | 去处 |
|---|---|---|
| **真干扰做题的词** | 这个词出现在某道**错题的推理链**上 | 词卡 [[03真题语境辨义卡片]]，按病灶子型分桶 + 进下周抽查 |
| **好句子** | 过 §7 三条作文过滤（说理 / 语域 / 可提槽位） | 句模库 [[02搭配-句模库]] |
| **难拆的句子** | 结构信号（倒装、省略、双重否定、名词性从句、嵌套修饰） | 下周「结构专项」 |

同一个词可以既进词卡又进抽查。**判不出「干扰了哪道题」的词，直接说判不出并要他补位置**——不要硬塞进词卡，那会把抽查池灌满无关词。

W1 可判例：`restriction`（T2Q1 错题推理链上，他第一反应成「减少」）｜`incidence`（T2Q4，想成「偶然、事件」，是忽略 D 的原因之一）｜`prevailing`（T2Q5，想成「盛行」漏了「普遍」）｜`readiness/inclination`（T3Q5 纠结点）。
W1 判不出的：D5 那批（`enormous`、`overall planning`、`the pressure to fold`、`yet`、`market prices overstate losses`）贴在「对答案到这」之后，无题号归属。

### 5. 写周批收网（5 篇合计上限 25 行）

KK 已自己写过每篇痕迹和自诊。你**不重写单篇**，只写一份跨篇的：

```md
## 周批｜W N（YYYY TextN—TextM）

- **首答 __/25 = __%**（上周 __%），终答 __/25，**检查净收益 +__ 题**（这 5 分钟考场真的有，是可迁移的数）
- **改答账**：有引句放行 __ 次（其中错→对 __）／无引句拦下 __ 次（其中对→错 __）。守住门槛本周是 __/25
- **跨篇模式**：本周 5 篇里病灶 N 复现 __ 次，其中 __ 篇是同一动作 → 说明什么
- **病灶计数**：1 +N／2 +N／3 +N，均按首答；观察区有无复现
- **你的归因 vs 机制归因**：只列不一致的（他写「没把握到作者情感」，机制是取了 but 之前的态度）
- **读前清单执行**：三条各执行了几篇。若某条 0 篇 → 那条清单本身有问题，当场改
- **元问题回答**：（他问了就必须答，直接答，不绕）
- 未结账：无 / QN 见画像
```

单篇的每题判决表**一律不写**。他已经写了，而且他的自诊常常比你准（W1 T2Q1「感觉 D 很对，所以会把 C 潜意识往不对得想吗？」比 skill 里对病灶 3 的描述更准）。**照收他的自诊，只标机制不一致处**——那是单篇看不出、跨篇才能看出的东西。

### 6. 回写画像（必须）

- 三条病灶合计数 +N，更新频次台账当年列
- 新证据进证据表（每条病灶只留最新最干净的 3—5 例，旧的挤出去进 `归档/认知画像-九年证据库.md`，**不要让表格重新膨胀到 300 行**）
- 「未结账」区新增行（如有）
- 「周结算记录」表加一行，含首答率、检查净收益、改答账、状态变化
- 观察区计周：连续 2 周无复现 → 观察；连续 4 周 → 退役移出

**只有回写，台账才是账。** 不回写就只是堆积——这是旧错因台账失败的直接原因。

### 7. 生成下一周训练文件（必须）

**英语不进日记，也不进 [[1.工作流/回滚台账]]**（颗粒细、周期短，混进数学 408 的按日台账会被冲掉）。

新建 `2.知识库/20.North_star_ZJU/200.英语积累/04每周训练/W{N} YYYY-MM-DD~MM-DD.md`，**周日到周六 7 个日块**：

| 日 | 内容 |
|---|---|
| **周日** | 低压力 prep：选下周 5 篇 + 每篇 3 分钟查中文背景（谁在跟谁吵、争什么）+ 技巧课 + 清未结账 |
| **周一至周五** | 每天 1 篇。四段：① 检测抽查　② 新单元　③ 真题　④ 回滚 |
| **周六** | 周报日，不学新内容 |

**③ 真题块的固定结构**（对齐他 2026-07-30 定的流程）：

1. **读前 30 秒**：抄画像三条清单到答题纸边上（勾一下抄没抄）
2. **18 分钟裸答** → 首答字母 + 限时信心 H/M/L，落笔后这栏不许动
3. **5 分钟考场检查**（不查词）：先圈功能词，再梳理逻辑关系 → 终答 + 检查后信心
   - **改答必须写一句原文证据句**。写不出就维持原答
4. **痕迹**：检查时对各选项的完整思维链，想多少写多少
5. **查词区**：只贴真正干扰做题的词 + 觉得难拆或觉得好的句子。**不标注分类**，周报时 AI 判
6. **对答案后**：自己写错因识别

**填充规则**：

- **① 检测抽查**：每天 6—8 项，「原文表达 → 一个改写 → 差在哪一维」（等价/程度/时态/主体/范围/方向）。**至少 3 项来自程度·时态桶**。素材优先级：本周 B/C 项 > 本周查词区判为「真干扰」的词 > [[03真题语境辨义卡片]] 里复现≥2 的卡。每周掺 1—2 项**等价正例**，否则他会形成「凡是改写必有差异」的定式
- **② 新单元**：按 [[2.知识库/20.North_star_ZJU/200.英语积累/03六周词义辨析攻坚/00-六周背诵总表]] 周次表取，每天 3 熟词生义 + 2 近义组 + 1 形近组 + 2 搭配。核对内容折进 `<details>`
- **④ 回滚**：D+1 复判前一天错题（遮解析，写「证据位置—正确谓词—干扰项死词」，不重选字母）。不排 D+3/D+7

**每月末那一周**：周一到周四四篇改成同一天 75 分钟连做，只记首答，次日补精读。不消耗额外真题，当月度体检。

### 8. 句模与搭配收录

查词区里判为「好句子」的，过三条过滤（来自 [[0.核心/00.规划(Plan)/2.当前项目/02-english.md]]，和作文好句同一套标准）：

1. **能不能用来说理**——让步、因果、对比、程度递进。接得上「因为/虽然/相比之下」的留；只是描述得漂亮的丢
2. **语域进不进考研作文**——学术长从句、插入语嵌套的丢。必须是考场 15 分钟内能盲写复现的复杂度
3. **能不能提炼出带槽位的句模**——换个主题就不能套的丢

**过滤后每篇上限 3 条**，超了优先留因果/让步/对比。输出格式：

```md
原句（YYYY TextN）：...
句模：...（带槽位，如 What matters is not X but Y.）
作文用例：...（你写，不要他写——他这步的产出是筛选，不是造句）
```

追加到 [[02搭配-句模库]] 末尾，标年份。**阅读搭配**（`scale back on`、`stake out`、`book a loss`、`be issued`）也进同一个库的搭配区，不另开文件。

**判为「难拆的句子」的**不进句模库，进下周某天的「结构专项」——只做一件事：标出结构信号词，还原正常语序。

## 元问题最高优先级

他写「我不理解」「不能被说服」「难道…吗」「有啥区别呢」「怎么办」时**必须回答**。内心不认同的题，复盘等于没做，下次还会那么选。

**取源**：周文件每天「今日不服」+ 周六汇总栏**先读**，再扫 5 篇痕迹里的疑问句式（他不一定填进汇总栏）。

> [!warning] 超期提醒是硬要求
> 历史教训：2007 T3 Q31 的 layoff 他问了，被跳过，**两年没纠正**。积压的成因不是周期长，是没有超期提醒。
> 每次周批必须扫画像「未结账」区，超 2 周未结的**主动报出来**，不等他问。
> 他若说「不知道有啥元问题」——那就是真没有，别硬造。元问题的特征是让他难受，会自己浮出来。

**证据不足以回答时**（比如需要题干和选项原文），**说出来并要他补**，不要编。

## 周六结算

1. 填**本周首答率** + **检查净收益**进画像「周结算记录」表
2. 重算三条病灶本周复现次数（按首答），更新状态：↑恶化 →持平 ↓好转 ⏸观察
3. 观察区计周，连续 4 周未复现 → 退役
4. 扫「未结账」区，超 2 周未结的报出来
5. 连续两次判 B/C 的抽查项 → 进画像高危表

只更新数字和状态，除下周训练文件外**不产生新文档**。英语结论摘一行进周报（[[1.工作流/10.日记文件/周报]]）第三节即可，**不另建周报 skill**。
