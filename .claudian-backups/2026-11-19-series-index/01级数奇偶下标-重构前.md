### 专项练习题

**【第 1 题：基础防坑——求导错位与首项孤立】**
设幂级数 $S(x) = \sum_{n=0}^{\infty} a_n x^n$ 在 $(-\infty, +\infty)$ 内收敛，且满足微分方程 $S'(x) - 2x S(x) = 0$，$S(0) = 1$。
1. 利用级数代回方程，求 $a_1$ 及系数递推公式（用 $a_{n+2}$ 与 $a_n$ 表示，标明 $n$ 的范围）；
2. 写出 $a_{2n}$ 与 $a_{2n+1}$ 的通项表达式（$n=0,1,2,\dots$）。

---

**【第 2 题：奇偶双展开——错位拼装与边界陷阱】**
已知函数 $f(x) = \frac{x}{1-x} + \frac{1}{1+x^2}$ 在 $(-1, 1)$ 内的幂级数展开式为 $\sum_{n=0}^{\infty} a_n x^n$。
求 $a_{2n}$ 与 $a_{2n+1}$ 的通项表达式（注意检查 $n=0$ 是否需要单独写！）。

---

**【第 3 题：考研真题级——三项对齐换标】**
设 $f(x) = \sum_{n=0}^{\infty} a_n x^n$ 在 $(-R, R)$（$R>0$）内收敛，满足 $(1-x^2)f'(x) - x f(x) = 1$，且 $f(0) = 0$。
1. 证明：$a_1 = 1$，$a_2 = 0$，且对任意 $n \ge 0$ 都有 $(n+2)a_{n+2} = (n+1)a_n$；
2. 由此写出 $a_{2n}$ 与 $a_{2n+1}$ 的通项公式（$n=0,1,2,\dots$）。

### 参考答案与防晕解析

#### 【第 1 题答案】
1. **核心防晕点：对齐 $x^{n+1}$ 时，$S'(x)$ 会多出一个常数项 $a_1$！**
   * $S'(x) = \sum_{n=1}^{\infty} n a_n x^{n-1} = a_1 + \sum_{n=2}^{\infty} n a_n x^{n-1}$。
     令 $k = n - 2$（从 $0$ 开始），则 $S'(x) = a_1 + \sum_{k=0}^{\infty} (k+2)a_{k+2} x^{k+1}$。
   * $2x S(x) = \sum_{k=0}^{\infty} 2a_k x^{k+1}$。
   * 代入 $S'(x) - 2x S(x) = 0$，得：
     $$a_1 + \sum_{n=0}^{\infty} \left[(n+2)a_{n+2} - 2a_n\right] x^{n+1} = 0$$
   * 由系数全为 $0$，得 **$a_1 = 0$**，且 **$(n+2)a_{n+2} = 2a_n \quad (n = 0, 1, 2, \dots)$**。
2. **求 $a_{2n}, a_{2n+1}$**：
   * 因 $a_1 = 0$，由递推式得所有奇数项 **$a_{2n+1} = 0$**（$n \ge 0$）。
   * 因 $a_0 = S(0) = 1$，偶数项满足 $a_{2n} = \frac{2}{2n}a_{2n-2} = \frac{1}{n}a_{2n-2} = \dots = \frac{1}{n!}a_0$，即 **$a_{2n} = \frac{1}{n!}$**（$n \ge 0$）。
   *(验算：原方程解为 $S(x) = e^{x^2} = \sum_{n=0}^{\infty} \frac{x^{2n}}{n!}$，完全一致！)*

---

#### 【第 2 题答案】
**核心防晕点：先改用哑指标 $m$，再按 $2n$ 和 $2n+1$ 拆项；且 $\frac{x}{1-x}$ 没有常数项 $x^0$！**
1. 把原级数临时改写下标：$\sum_{m=0}^{\infty} a_m x^m = a_0 + \sum_{n=1}^{\infty} a_{2n} x^{2n} + \sum_{n=0}^{\infty} a_{2n+1} x^{2n+1}$。
2. 分别展开两项（$|x|<1$）：
   * $\frac{x}{1-x} = \sum_{m=0}^{\infty} x^{m+1} = \sum_{m=1}^{\infty} x^m = \sum_{n=1}^{\infty} x^{2n} + \sum_{n=0}^{\infty} x^{2n+1}$（注意偶次幂从 **$n=1$** 开始！）
   * $\frac{1}{1+x^2} = \sum_{n=0}^{\infty} (-1)^n x^{2n} = 1 + \sum_{n=1}^{\infty} (-1)^n x^{2n}$
3. 合并同类幂次：
   $$f(x) = 1 + \sum_{n=1}^{\infty} \left[1 + (-1)^n\right] x^{2n} + \sum_{n=0}^{\infty} 1 \cdot x^{2n+1}$$
4. 对比系数得出结论：
   * **$a_0 = 1$**（不能代进 $1+(-1)^0=2$，必须单独写！）；
   * 当 $n \ge 1$ 时，**$a_{2n} = 1 + (-1)^n$**（即 $n$ 为偶数时为 $2$，$n$ 为奇数时为 $0$）；
   * 当 $n \ge 0$ 时，**$a_{2n+1} = 1$**。

---

#### 【第 3 题答案】
**核心防晕点：三项齐聚，统一朝 $x^k$ 对齐，并把 $k=0, 1$ 的低次项提前拆出来！**
1. 由 $f(0) = 0$ 得 $a_0 = 0$。把三项全部统一成 $x^k$ 的形式：
   * $f'(x) = \sum_{n=1}^{\infty} n a_n x^{n-1} = \sum_{k=0}^{\infty} (k+1) a_{k+1} x^k = a_1 + 2a_2 x + \sum_{k=2}^{\infty} (k+1) a_{k+1} x^k$
   * $-x^2 f'(x) = -\sum_{n=1}^{\infty} n a_n x^{n+1} = -\sum_{k=2}^{\infty} (k-1) a_{k-1} x^k$
   * $-x f(x) = -\sum_{n=0}^{\infty} a_n x^{n+1} = -a_0 x - \sum_{k=2}^{\infty} a_{k-1} x^k$
2. 代入 $(1-x^2)f'(x) - x f(x) - 1 = 0$：
   $$(a_1 - 1) + (2a_2 - a_0)x + \sum_{k=2}^{\infty} \left[(k+1)a_{k+1} - k a_{k-1}\right] x^k = 0$$
3. 令各项系数为 $0$：
   * $x^0$ 项：$a_1 - 1 = 0 \implies \mathbf{a_1 = 1}$；
   * $x^1$ 项：$2a_2 - a_0 = 0$，因 $a_0=0$，得 $\mathbf{a_2 = 0}$；
   * $x^k$ 项（$k \ge 2$）：$(k+1)a_{k+1} = k a_{k-1}$。
     **换标**：令 $n = k-1$（则 $n \ge 1$），得 $(n+2)a_{n+2} = (n+1)a_n$。
     再单独检验 $n=0$：左边 $2a_2 = 0$，右边 $1 \cdot a_0 = 0$，同样成立！故对任意 $n \ge 0$ 均成立。
4. **求 $a_{2n}, a_{2n+1}$**：
   * 由 $a_0 = 0$ 及递推式得 **$a_{2n} = 0$**（$n \ge 0$）。
   * 奇数项：$a_{2n+1} = \frac{2n}{2n+1} a_{2n-1} = \frac{2n}{2n+1} \cdot \frac{2n-2}{2n-1} \cdots \frac{2}{3} a_1$。
     因 $a_1 = 1$，故 **$a_{2n+1} = \frac{(2n)!!}{(2n+1)!!} = \frac{2^{2n}(n!)^2}{(2n+1)!}$**（$n \ge 0$，注：$n=0$ 时规定 $0!!=1$）。

---

**自查标准**：如果你做这三题时，能顺畅地先“把低次项 $x^0, x^1$ 拎出来”、再“令 $k = \text{新次幂}$ 统一下标”，并且第 2 题没漏掉 $a_0=1$，那你在这块下标转换上就已经彻底通关了！哪一步卡住了随时告诉我。














给你精选了 **3 道层层递进的考研经典真题级例题**，涵盖了考场上关于“求 $f^{(n)}(0)$ 分类讨论”的所有坑点（奇偶讨论、低阶特殊项剔除、每 3 项一循环）。

做的时候，严格执行刚才教你的**三步口诀**：
1. **展开函数，把求和字母换成 $k$**（整理成 $\sum (\text{系数}) \cdot x^{\text{关于}k\text{的次数}}$）；
2. **令 $x$ 的次数 $= n$，解出 $k$ 与 $n$ 的关系**（注意看 $k$ 从几开始，$n$ 最小是几）；
3. **写结论：$f^{(n)}(0) = n! \times (\text{对应系数})$**，不存在的项直接写 $=0$。

### 【例题区】（先自己在草稿纸上写，写完对下面答案）

*   **【例 1】（基础巩固：含奇数次幂 + 起点不为 1）**
    设 $f(x) = x^2 \ln(1 + x^2)$，求 $f^{(n)}(0) \; (n = 1, 2, \cdots)$。

*   **【例 2】（高频易错：单独多出一个低次项，需单独抠出）**
    设 $f(x) = x^2 + x \sin(2x^2)$，求 $f^{(n)}(0) \; (n = 1, 2, \cdots)$。

*   **【例 3】（拔高进阶：不再是奇偶，而是 $3k$ 的倍数讨论）**
    设 $f(x) = \frac{x}{1 + x^3}$，求 $f^{(n)}(0) \; (n = 1, 2, \cdots)$。

---
---

### 【标准规范答案与解析】

#### 【例 1】标准答案（注意看 $n=2$ 的坑！）
1. **展开并换字母为 $k$**：
   已知 $\ln(1+t) = \sum_{k=1}^{\infty} \frac{(-1)^{k-1}}{k} t^k$，将 $t = x^2$ 代入并乘以 $x^2$：
   $$f(x) = x^2 \sum_{k=1}^{\infty} \frac{(-1)^{k-1}}{k} (x^2)^k = \sum_{k=1}^{\infty} \frac{(-1)^{k-1}}{k} x^{2k+2}$$
2. **比对 $x^n$ 的系数（注意：当 $k=1$ 时，最低次幂是 $x^4$，没有 $x^2$ 项！）**：
   *   **当 $n$ 为奇数，或 $n = 2$ 时**：展开式中不含这些次幂的项，故：
       $$f^{(n)}(0) = 0$$
   *   **当 $n$ 为大于 $2$ 的偶数时**，令 $2k + 2 = n \; (k = 1, 2, \cdots)$，解得 $k = \frac{n}{2} - 1$。
       由 $\frac{f^{(n)}(0)}{n!} = \frac{(-1)^{k-1}}{k}$，得：
       $$f^{(n)}(0) = n! \cdot \frac{(-1)^{k-1}}{k} = \frac{(-1)^{\frac{n}{2}-2} \cdot n!}{\frac{n}{2} - 1} = \frac{2(-1)^{\frac{n}{2}} \cdot n!}{n - 2} \quad (n = 4, 6, 8, \cdots)$$
       *(注：如果你在考场上直接写“当 $n = 2k+2 \; (k=1,2,\cdots)$ 时，$f^{(2k+2)}(0) = \frac{(-1)^{k-1}(2k+2)!}{k}$”，完全满分且不用化简，极力推荐！)*

---

#### 【例 2】标准答案（单独项必须单独交代！）
1. **展开并换字母为 $k$**：
   已知 $\sin t = \sum_{k=0}^{\infty} \frac{(-1)^k}{(2k+1)!} t^{2k+1}$，将 $t = 2x^2$ 代入：
   $$f(x) = x^2 + x \sum_{k=0}^{\infty} \frac{(-1)^k}{(2k+1)!} (2x^2)^{2k+1} = x^2 + \sum_{k=0}^{\infty} \frac{(-1)^k \cdot 2^{2k+1}}{(2k+1)!} x^{4k+3}$$
2. **比对 $x^n$ 的系数**：
   观察上式，只有 $n=2$ 以及 $n = 4k+3 \; (k=0, 1, 2, \cdots)$ 的项存在：
   *   **当 $n = 2$ 时**：$x^2$ 的系数为 $1$，故：
       $$f''(0) = 2! \times 1 = 2$$
   *   **当 $n = 4k + 3 \; (k = 0, 1, 2, \cdots)$ 时**：
       $$f^{(4k+3)}(0) = (4k+3)! \cdot \frac{(-1)^k \cdot 2^{2k+1}}{(2k+1)!}$$
   *   **当 $n$ 取其他正整数（即 $n \ne 2$ 且 $n \ne 4k+3$）时**：
       $$f^{(n)}(0) = 0$$

---

#### 【例 3】标准答案（体会“直接用含 $k$ 的式子作答”有多爽）
1. **展开并换字母为 $k$**：
   已知 $\frac{1}{1+t} = \sum_{k=0}^{\infty} (-1)^k t^k$，将 $t = x^3$ 代入并乘以 $x$：
   $$f(x) = x \sum_{k=0}^{\infty} (-1)^k (x^3)^k = \sum_{k=0}^{\infty} (-1)^k x^{3k+1}$$
2. **比对 $x^n$ 的系数**：
   *   **当 $n = 3k + 1 \; (k = 0, 1, 2, \cdots)$ 时**：
       $x^{3k+1}$ 的系数为 $(-1)^k$，故：
       $$f^{(3k+1)}(0) = (-1)^k (3k+1)!$$
       *(如果非要写成 $n$，把 $k = \frac{n-1}{3}$ 代入即得 $f^{(n)}(0) = (-1)^{\frac{n-1}{3}} n!$)*
   *   **当 $n \ne 3k + 1 \; (k = 0, 1, 2, \cdots)$ 时**：
       $$f^{(n)}(0) = 0$$

---

### 终极应试技巧复盘
做完这三道题你会发现：**千万不要傻乎乎地去把 $k$ 反解成 $\frac{n-\dots}{\dots}$ 往里代（容易算错且写着麻烦）**！
在考场上，最聪明、最规范的写法就是直接按上面【例 2】【例 3】的格式：
*   **当 $n = \text{（关于 } k \text{ 的指数表达式）} \; (k = \dots)$ 时，$f^{(n)}(0) = n! \times (\text{含 } k \text{ 的系数})$**；
*   **当 $n$ 为其余正整数时，$f^{(n)}(0) = 0$**。
阅卷老师看到这种格式，一秒打勾给满分！
