【例 1】设 $A = E - kuu^T (k \neq 0)$ 是正交矩阵，其中 $E$ 是 3 阶单位矩阵，$u$ 是 3 维单位列向量.

(I) 求 $k$ 的值;

(II) 对于第 (I) 问中的 $k$ 值，若 $A \begin{bmatrix} 1 \\ 0 \\ 0 \end{bmatrix} = \begin{bmatrix} 0 \\ 1 \\ 0 \end{bmatrix}$，求 $A$;

(III) 对于第 (II) 问中的 $A$，求正交矩阵 $Q$ 及 $\Lambda$，使得 $Q^{-1}AQ = \Lambda$.

### IMG080
方法二：利用对称性与正交性直接“拼”出 $A$（小题/大题秒杀法）

既然你已经看出了**“$A$ 的第一列是 $(0, 1, 0)^T$”**，我们来看看 $A$ 有什么特殊性质：

1. 对称性：$A^T = (E - 2uu^T)^T = E - 2uu^T = A$。说明 $A$ 是实对称矩阵！

2. 正交性：题目已知 $A$ 是正交矩阵（每行、每列都是单位向量，且两两正交）。

3. 迹（主对角线元素之和）：你已经知道特征值是 $-1, 1, 1$，所以 $\text{tr}(A) = -1 + 1 + 1 = 1$。

现在我们来填九宫格：

* 已知第一列是 $\begin{bmatrix} 0 \\ 1 \\ 0 \end{bmatrix}$，因为对称，所以第一行也是 $\begin{bmatrix} 0 & 1 & 0 \end{bmatrix}$。此时矩阵长这样：
$$A = \begin{bmatrix} 0 & 1 & 0 \\ 1 & a & b \\ 0 & b & c \end{bmatrix}$$

* 因为是正交矩阵，每一行的模长必须等于 1：
看第二行：$1^2 + a^2 + b^2 = 1 \Rightarrow a = 0, b = 0$。
矩阵瞬间只剩下一个未知数 $c$：
$$A = \begin{bmatrix} 0 & 1 & 0 \\ 1 & 0 & 0 \\ 0 & 0 & c \end{bmatrix}$$

* 最后用迹 $\text{tr}(A) = 0 + 0 + c = 1 \Rightarrow c = 1$。直接写出答案！
