### IMG021

**[例 1.12]** 设 $y = \sin x, 0 \le x \le 2\pi$, 求其所有单调区间上的反函数.

**[分析]** 分单调区间, 分别讨论反函数 (用诱导公式).

**[解]** 当 $0 \le x \le \frac{\pi}{2}$ 时, 对于 $y = \sin x$, 有 $x = \arcsin y, y \in [0, 1]$;
[蓝色手写批注]：只有当 $x$ 落在 $[-\frac{\pi}{2}, \frac{\pi}{2}]$ 上时, 才有反函数 $x = \arcsin y, y \in [-1, 1]$. (箭头指向下一行)

当 $\frac{\pi}{2} < x \le \frac{3\pi}{2}$ 时 (见图 1-14), 有 $-\frac{\pi}{2} < x - \pi \le \frac{\pi}{2}$, 此时 $\sin(x - \pi) = -\sin(\pi - x) = -\sin x = -y$, 于是有 $x - \pi = -\arcsin y$, 故 $x = \pi - \arcsin y, y \in [-1, 1)$;
[蓝色手写批注]：(箭头指向 $x-\pi$) 放到主值区间中

当 $\frac{3\pi}{2} < x \le 2\pi$ 时 (见图 1-14), 有 $-\frac{\pi}{2} < x - 2\pi \le 0$, 此时 $\sin(x - 2\pi) = \sin x = y$, 于是有 $x - 2\pi = \arcsin y$, 故
$$x = 2\pi + \arcsin y, y \in (-1, 0].$$

### IMG022

例 1.74 严选题, D 选项可以巧用逆否命题 (反证法的本质也是逆否命题)

设有数列 $\{x_n\}$ 与 $\{y_n\}$, 以下结论正确的是 (D)
(A) 若 $\lim_{n \to \infty} x_n y_n = 0$, 则必有 $\lim_{n \to \infty} x_n = 0$ 或 $\lim_{n \to \infty} y_n = 0$.
(B) 若 $\lim_{n \to \infty} x_n y_n = \infty$, 则必有 $\lim_{n \to \infty} x_n = \infty$ 或 $\lim_{n \to \infty} y_n = \infty$.
(C) 若 $x_n y_n$ 有界, 则必有 $x_n$ 与 $y_n$ 都有界.
(D) 若 $x_n y_n$ 无界, 则必有 $x_n$ 无界或 $y_n$ 无界.

[红色手写批注]：
排除 ABC
$x_n = \begin{cases} n & n \text{为偶数} \\ 0 & n \text{为奇数} \end{cases} \quad y_n = \begin{cases} 0 & n \text{为偶数} \\ n & n \text{为奇数} \end{cases}$
$x_n = \begin{cases} n & n \text{为偶数} \\ 1 & n \text{为奇数} \end{cases} \quad y_n = \begin{cases} 1 & n \text{为偶数} \\ n & n \text{为奇数} \end{cases}$
$C: x_n = n, y_n = 0$

[蓝色手写批注]：
※ D: 逆否命题: ※ ※
若 $x_n$ 有界且 $y_n$ 有界, 则 $x_n y_n$ 有界
显然成立. 有界 $\times$ 有界 = 有界

[紫色框内手写批注]：
※ 一个命题一定等价于其逆否命题.

### IMG023

定有上界, 所以 $S_n = \sum a_n$ 一定收敛, 所以 $a_n$ 一定趋于 0
[红色手写批注]：※ 数列收敛 $\iff$ 数列极限存在
