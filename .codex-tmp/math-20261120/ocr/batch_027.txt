### IMG138

随机变量 $X \sim B(2, p), Y \sim B(3, p)$, 若 $P\{X \ge 1\} = \frac{5}{9}$, 则 $P\{Y \ge 1\} = \_\_\_\_\_\_, P\{Y \ge 2\} = \_\_\_\_\_\_$

[蓝色手写批注]：$P\{x=1\} + P\{x=2\} = \frac{5}{9}$

[红色手写批注]：
$\underline{P\{X \ge 1\} = \frac{5}{9}} \Rightarrow P\{X < 1\} = \frac{4}{9}$. 即 $P\{X = 0\} = \frac{4}{9}$ (注：下划线为蓝色)
$C_2^0 p^0 (1-p)^2 \therefore \underbrace{(1-p)^2} = \frac{4}{9} \Rightarrow p = \frac{1}{3}$ 或 $p = \frac{5}{3}$ (舍) (注：花括号处为紫色波浪线)
$P\{Y \ge 1\} = 1 - P\{Y < 1\} = 1 - P\{Y = 0\} = 1 - (1 - \frac{1}{3})^3 = \frac{19}{27}$
$P\{Y \ge 2\} = P\{Y = 2\} + P\{Y = 3\} = C_3^2 (\frac{1}{3})^2 \cdot (\frac{2}{3})^1 + (\frac{1}{3})^3 = \frac{7}{27}$
