# 级数：看到题，先决定第一步

> 用法和[[03曲线面积分，空间几何|线面框架]]一样：不是从头背一遍，而是看到题后找“我现在该先做什么”。这里负责选路；长推导留在原卡片，重做题进[[高数薄弱专题-归类]]与[[高数薄弱专题-随机训练]]。

## 先看题目问什么

| 题目在问 | 第一件事 |
| --- | --- |
| 数列、级数的关系，或“必然成立” | 圈出已知的是 $a_n$，还是 $\sum a_n$；有没有正项、绝对收敛 |
| 一个具体数项级数敛不敛 | 先看通项是否趋于0，再看正负；别上来就求比值 |
| 抽象级数相乘、平方、加括号、抽奇偶项 | 把目标的前几项或绝对值写出来，弄清改了什么 |
| 收敛半径、收敛域 | 找出真正被取 $n$ 次方的整体；半径和端点分开算 |
| 函数展开、和函数、高阶导数 | 想凑哪个熟悉的展开式；最后按实际幂次认系数 |
| 傅里叶级数在某点的和 | 先看周期延拓后，这个点左右各趋于什么 |

## 一、先别混淆：通项趋于0，不等于级数收敛

- $\sum a_n$ 收敛，必有 $a_n\to0$。反过来不行：$1/n\to0$，但 $\sum1/n$ 发散。
- 判断 $\sum a_n$，真正看的对象是部分和 $S_N=a_1+\cdots+a_N$ 有没有有限极限。
- $a_n$ 本身不趋于0，级数直接发散；不用再忙着找判敛法。
- 改动、删去有限项不改变敛散性。所以“从某一项起满足条件”通常够用。

**题目说“发散”时，不要只想趋于无穷。** 还可能振荡。例如 $(-1)^n$ 没有极限。要找反例时，这两种长相都试一下。

### 几条能直接用的关系

1. 两个收敛级数相加减，仍收敛；一个收敛、一个发散，相加减仍发散。两个都发散，不能直接判断和。
2. 绝对收敛 $\Rightarrow$ 收敛。收敛但不绝对收敛，才叫条件收敛。
3. **绝对收敛级数＋条件收敛级数，一定条件收敛。** 和先由线性运算知收敛；若它绝对收敛，减去原来的绝对收敛级数，就会把另一个也推出绝对收敛，矛盾。
4. 以上的“相加”是同一位置通项相加，**不是逐项相乘，更不是柯西乘积**。题目写什么，就按什么看。

## 二、给了具体通项：先看正负，再选判敛法

### 1. 最终非负：先想跟哪个熟悉级数比

先在草稿纸写一个参照：$\sum1/n^p$（$p>1$才收敛）或 $\sum q^n$（$|q|<1$收敛）。

- **分式、根式、三角函数里有小量**：先找通项的主要大小，再算与参照通项的比值。
  若 $u_n,v_n>0$，且 $u_n/v_n\to c\in(0,+\infty)$，两级数同敛散。
- **阶乘、连乘、指数混合**：先试 $u_{n+1}/u_n$，看能否大幅约掉。
- **整坨都被取 $n$ 次方**：先试 $\sqrt[n]{u_n}$。
- 比值或根值的极限小于1，收敛；大于1，发散；**等于1，换方法，不是“所以发散”。**
- 用不等式比较时看方向：想证收敛，就找一个收敛的大级数压住；想证发散，就找一个发散的小级数托住。

**为什么先确认非负？** 因为这套比较是在比“加起来有多大”，有正有负时还会相消，不能照搬。

### 2. 有 $(-1)^n$：分两次判断

1. 先看绝对值级数 $\sum|u_n|$。它收敛，原级数就绝对收敛，结束。
2. 若绝对值级数发散，再判断原来的正负相消能否使它收敛。
3. 若写成 $\sum(-1)^{n-1}b_n$，$b_n\ge0$，且从某项起单调下降到0，可以用莱布尼茨。
4. **看不出单调，或确实不单调，不代表原级数发散。** 可以试部分和消项，或把它准确拆成一个熟悉的收敛级数加余项。

常用拆法：
$$\frac1{1+t}=1-\frac{t}{1+t}.$$
但拆完以后，必须真正估计余项，不能只说“它更小，所以绝对收敛”。

### 3. 交错级数里，不能随便用等价通项替换

正项比较中 $u_n\sim v_n$ 可以推出同敛散；一般变号级数不行。例如
$$a_n=\frac{(-1)^n}{\sqrt n},\qquad b_n=\frac{(-1)^n}{\sqrt n}+\frac1n.$$
虽然 $b_n/a_n\to1$，但 $\sum a_n$ 收敛，$\sum b_n$ 发散。

**落笔做法**：需要比较变号级数时，优先把差写出来，检查 $\sum(b_n-a_n)$；或先转为绝对值级数再作正项比较。

## 三、只告诉我几个级数收敛：先往已知的通项上凑

### 1. 目标里有乘积、平方

已知 $a_n\to0$，则 $a_n$ 有界；从某项起还可用 $|a_n|\le1$。这给你一个具体动作：**把目标写成“已知可求和的非负项×有界因子”。**

例如已知 $a_n\to0$、$\sum|b_n|$ 收敛，要判 $\sum a_n^2b_n^2$：
1. 因 $b_n\to0$，从某项起同时有 $|a_n|\le1,|b_n|\le1$。
2. 写出 $0\le a_n^2b_n^2\le|b_n|$。
3. 右边可求和，左边收敛。

**别扩大成“有界数列乘收敛级数仍收敛”。** 若只有条件收敛，乱乘符号可能把原来的相消破坏。例：两个 $\sum(-1)^n/\sqrt n$ 都收敛，逐项相乘却得到发散的 $\sum1/n$。

### 2. 目标有 $nu_n$、$v_n/n$

别觉得它们跟 $u_nv_n$ 没关系，先写
$$u_nv_n=(nu_n)\frac{v_n}{n}.$$
再看哪一块有界、哪一块的绝对值已知可求和。**凑出来以后仍要核对条件，不能只见乘积就判收敛。**

### 3. 三角函数里藏着整数倍 $\pi$

先把角度写成 $k\pi+\varepsilon_n$，把符号和真正趋于0的部分分开，再用 $\sin\varepsilon_n\sim\varepsilon_n$ 等。若仍带交错符号，要回到上一节核对能否这样比较。

## 四、加括号、抽奇偶项：先列前几项

### 1. 连续有限项加括号

- 原级数收敛，按原顺序分成连续有限组后，仍收敛且和不变。
- 加括号收敛，去括号不一定收敛。例如 $(1-1)+(1-1)+\cdots$。
- 若各项非负，连续分组覆盖全部项，加括号与去括号同敛散。
- 一般情形若还知道原通项趋于0，且每组项数有统一上界，就可以补回组内的部分和，推出原级数收敛。不要把这条条件漏掉。

### 2. 条件收敛的交错级数

若 $u_n\ge0$，$\sum(-1)^{n-1}u_n$ 条件收敛，则
$$\sum(u_{2n-1}-u_{2n})\text{ 收敛},\qquad
\sum u_{2n-1},\ \sum u_{2n}\text{ 都发散到 }+\infty.$$
原因不是死记：正、负两部分只要有一部分可求和，利用原级数收敛就能把另一部分也推出可求和，这会变成绝对收敛，矛盾。

### 3. 通项里同时有相邻项

如 $\sum_{n=1}^\infty(-1)^{n-1}(a_n+a_{n+1})$，别先猜单调性。直接写
$$S_N=a_1+(-1)^{N-1}a_{N+1}.$$
再看最后那项是否有极限。**相消的是部分和，不是凭感觉把无穷多项拆开。**

## 五、数列和级数绑在一起：把相邻项差加起来

题目同时出现 $a_n$、$b_{n+1}-b_n$，又问 $\{b_n\}$ 与 $\sum a_n$ 的关系：

1. 先写
   $$\sum_{n=1}^N(b_{n+1}-b_n)=b_{N+1}-b_1.$$
   因而 $\{b_n\}$ 有有限极限，当且仅当差分级数收敛。**这一等价本身不要求差分为正。**
2. 再从题中关系算出 $a_n/(b_{n+1}-b_n)$，或直接比较两者大小。
3. 要用正项比较，才需要检查它们的符号，以及比值极限是否正且有限。
4. 证明“当且仅当”必须分两头。不能在还没证明 $b_n$ 收敛的一头，先设它有有限极限来使用。

对应旧题：[[01抽象级数判敛#卡片 2：数列 $\{b_n\}$ 与级数 $\sum a_n$ 联动（如【7.19】）|差分与级数联动]]；实际查找也可直接打开[[01抽象级数判敛]]。

## 六、求收敛半径：先认中心和实际指数

### 1. 标准式 $\sum a_n(x-x_0)^n$

- 若 $\lim|a_{n+1}/a_n|=L$ 存在，且比值从某项起有意义，则 $R=1/L$。
- 若 $\lim\sqrt[n]{|a_n|}=L$ 存在，则 $R=1/L$。
- $L=0$ 时 $R=+\infty$；$L=+\infty$ 时 $R=0$。
- **普通极限不存在，不是“没有收敛半径”，只是这一版公式用不了。** 可直接对整个通项用比值/根值判别，或用定义比较；一般公式中的根值要取上极限。

只知道在某点收敛，就得到 $R\ge$ 该点到中心的距离；知道在某点发散，就得到 $R\le$ 该距离。**不直接把这个距离当半径。**

### 2. 缺项、变指数

如 $\sum a_nx^{2n}$，先令 $t=x^2$，对 $\sum a_nt^n$ 求出半径 $R_t$，再解 $|x^2|<R_t$。

若用相邻两项比值，比较的是**整个通项**：
$$\left|\frac{a_{n+1}x^{2n+2}}{a_nx^{2n}}\right|
=\left|\frac{a_{n+1}}{a_n}\right||x|^2.$$
不能看到 $a_{n+1}/a_n$ 就忘了指数差2。

### 3. 已知原半径，系数变了

以 $\sum a_nx^n$ 的半径为 $R$（以下常用变换先按 $0<R<\infty$ 理解）：

| 新级数 | 半径 | 怎么记才不反 |
| --- | --- | --- |
| $\sum n^p a_nx^n$，固定实数 $p$，从 $n\ge1$ 起 | $R$ | $n$ 的固定次幂开 $n$ 次根趋于1 |
| $\sum c^na_nx^n$，$c\ne0$ | $R/|c|$ | 把 $cx$ 整体当变量 |
| $\sum a_n^2x^n$ | $R^2$ | 系数开根后的大小被平方 |
| $\sum a_nx^{kn}$，正整数 $k$ | $R^{1/k}$ | 解 $|x|^k<R$ |

**半径不变，不代表端点敛散也不变。** 求导、积分、乘除 $n$ 后，端点重新代回新级数。

## 七、递推系数、积分系数：不一定非求出通项

### 1. 给递推关系

- 能直接算出 $|a_{n+1}/a_n|$，就先算；但要确认分母不为0、极限确实存在。
- 算不出比值，题目只要求证 $R\ge r$，就先定目标：要证所有 $|x|<r$ 都绝对收敛。
- 一种够用的办法：用归纳法证明 $|a_n|\le C r^{-n}$，其中 $C$ 是不随 $n$ 变的常数。再写
  $$|a_nx^n|\le C(|x|/r)^n.$$
  右边是收敛的等比级数。
- 若恰好这个界证不出，可对每个 $0<s<r$ 分别找 $C_s$ 使 $|a_n|\le C_s s^{-n}$，同样足够。**这些是可选的充分办法，不是由 $R\ge r$ 必须推出的逐项界。**

三项递推不等于“不能精确求半径”；两项递推也不等于“无需证明就能取比值极限”。按题目要你证明什么来选。

### 2. $a_n$ 是含 $n$ 的定积分

- 像 $\int_0^1x^2(\ln x)^n\,dx$：先试分部积分，把幂次降下来，找递推；反常端点的边界项先取极限。
- 像 $\int_0^1x^ng(x)\,dx$，且 $0<m\le g(x)\le M$：先夹
  $$\frac m{n+1}\le a_n\le\frac M{n+1}.$$
  这足以推出 $\sqrt[n]{a_n}\to1$，从而相应幂级数半径为1。
- **仅有上下两个常数夹住，不能直接宣称 $a_n\sim C/n$。** 若真需要等价，须再用 $g$ 的额外条件证明。

更细的半径解释：[[01收敛半径]]。不要把它当成每次开题前都要重读的讲义。

## 八、函数展开与和函数：先想“我要凑哪一个”

### 1. 先认熟悉的展开

$$\frac1{1-t}=\sum_{n=0}^{\infty}t^n\quad(|t|<1),$$
$$\ln(1+t)=\sum_{n=1}^{\infty}\frac{(-1)^{n-1}}n t^n\quad(|t|<1),$$
$$e^t=\sum_{n=0}^{\infty}\frac{t^n}{n!},\quad
\sin t=\sum_{n=0}^{\infty}\frac{(-1)^nt^{2n+1}}{(2n+1)!},\quad
\cos t=\sum_{n=0}^{\infty}\frac{(-1)^nt^{2n}}{(2n)!}.$$

- 题目要求在 $x_0$ 处展开，第一行先设 $t=x-x_0$，把原函数改写成 $t$ 的式子，再凑上述形式。
- 分母像一次式，先提常数凑 $1-t$；复杂分式先拆分。
- 和式多出 $n$，考虑求导；多出 $1/n$，考虑积分。**先在收敛区间内部操作**，再另外处理原级数端点。
- 求导后求回原和函数，别漏积分常数；积分后除以 $x$，别忘了单独回原式核对 $x=0$。

### 2. 下标不会改，就先列两项

$\sum_{n=1}^{\infty}c_nx^n$ 从1开始，不能直接照搬从0开始的公式；若改起点，必须补减漏掉的项。

**换下标要同时改三处：系数、幂次、求和起点。** “函数里多一个 $n$，下标就减1”不是通用规则。

### 3. 求 $f^{(m)}(0)$，不用真的求 $m$ 次导

先找 $x^m$ 的系数，再乘 $m!$。

例如展开中一项为 $c_nx^{2n+2}$，就解 $2n+2=m$：有满足原起点要求的整数 $n$ 才有这一项。**不仅看奇偶，还要看最低次幂。**

你已有比较清楚的统一卡片：[[01级数奇偶下标]]。早期[[奇偶项]]里的“全部换成一个字母”可作为心算，不要因此漏掉起点限制。

### 4. 最后再定收敛域

习惯上“收敛区间”指以中心为中点的开区间，“收敛域”还要判端点；若题目用词不同，以它实际要求为准。

**端点必须代回你所求的那个级数。** 不因函数表达式在端点有意义，就认定原级数在那里收敛。

## 九、傅里叶：先画出周期内的样子，再碰系数

1. 先认周期是 $2l$，不是看到 $\sin nx$ 就永远当 $2\pi$；基频是 $\pi/l$。
2. 定义在 $[-l,l]$ 上，先判断奇偶。偶函数只算余弦系数；奇函数只算正弦系数。非奇非偶就别硬删。
3. 若题目只给 $[0,l]$ 的函数，要求正弦或余弦展开，先想清对应的奇延拓或偶延拓。
4. 在通常的狄利克雷条件下，某点级数和为周期延拓后左右极限的平均：
   $$S(x)=\frac{f(x-0)+f(x+0)}2.$$
   周期拼接处尤其不要只代原题给的单点值。
5. 用特殊点求数项级数和时，先代点，再认留下的是全部项、奇数项还是偶数项。比如偶数项常能化成全体和的 $1/2^p$，再解一个关于总和的方程。

## 做完只检查这六件事

1. 我现在判断的是数列还是级数？有没有把通项趋零当成充分条件？
2. 比较审敛前，正负号检查了吗？交错判敛的条件真的满足吗？
3. 是否只证明了一个方向，却写成“当且仅当”？
4. 半径算完后，实际变量、中心、指数、端点还对吗？
5. 展开首项、漏掉的常数、除以0时的原点值检查了吗？
6. 高阶导数乘的是目标阶数的阶乘吗？
