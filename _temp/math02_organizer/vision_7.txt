【例2.8】 设连续型随机变量 $X$ 的分布函数为
$$F(x) = \begin{cases} 0, & x < 0, \\ x^2, & 0 \le x < 1, \\ 1, & x \ge 1. \end{cases}$$
求 $X$ 的概率密度 $f(x)$.

【解】 取概率密度为 $f(x) = \begin{cases} 2x, & 0 \le x \le 1, \\ 0, & \text{其他.} \end{cases}$
或者 $f_2(x) = \begin{cases} 2x, & 0 < x < 1, \\ 0, & \text{其他.} \end{cases}$
均可.

**手写批注**：
- 左侧上部：
  $F'(x) = \begin{cases} 0, & x < 0, \\ 2x, & 0 \le x < 1 \\ \text{未定}, & x = 1, \\ 0, & x > 1 \end{cases}$
- 左侧下部：
  $F(x) = \begin{cases} 0, & x < 0, \\ \sin x, & 0 \le x < \frac{\pi}{2} \\ 1, & x \ge \frac{\pi}{2} \end{cases}$
  $\Downarrow$
  $f(x) = \begin{cases} \cos x, & 0 < x < \frac{\pi}{2}, \\ 0, & \text{其他} \end{cases}$
- 右侧图表及标记：
  - 标记“可导点”、“不可导点”
  - 标注：“概率认为 $f_1(x) = f_2(x), a.e.$ \n $\succ$ 我们不加区分.”

### **IMAGE 34 | 02[模糊]-3 | (1165, 545)**
**题目类型**：独立题目与解答

**印刷内容**：
【例3.3】已知随机变量 $X, Y$ 同分布, $X \sim \begin{pmatrix} 0 & 1 \\ \frac{1}{4} & \frac{3}{4} \end{pmatrix}$, 且 $P\{XY \ne 1\} = \frac{3}{8}$, 则 $P\{X + Y \le 1\} = (\quad)$.
(A) $\frac{1}{8}$
(B) $\frac{1}{4}$
(C) $\frac{3}{8}$
(D) $\frac{1}{2}$

【解】 $P\{XY \ne 1\} = \frac{3}{8} \Rightarrow P\{XY = 1\} = \frac{5}{8} \Rightarrow P\{X = 1, Y = 1\} = \frac{5}{8}$.
$$P\{X + Y \le 1\} = 1 - P\{X = 1, Y = 1\} = \frac{3}{8}.$$

**手写批注**：
- 解题步骤上方箭头标有：$P(A) = 1 - P(\bar{A})$
- 右侧表格（二维分布表）：
  | $X \backslash Y$ | 0 | 1 | |
  | :---: | :---: | :---: | :---: |
  | 0 | $1/8$ | $1/8$ | $1/4$ |
  | 1 | $1/8$ | $5/8$ | $3/4$ |
  | | $1/4$ | $3/4$ | |
- 底部总结：
  注：边缘分布 $\cancel{\Leftarrow} \Rightarrow$ 联合分布
