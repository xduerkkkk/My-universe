(2) 求概率 $P\{X \le Y\}$.

**[例题29 解答续]**  
**印刷内容：**  
(1) 本题中 $y=g(x)$ 不满足单调与连续，只能用定义法.  
首先，画出 $y=g(x)$ 的图像，由 $f(x) \neq 0$ 的区域是 $(0,3)$，因而本题仅考虑 $0<x<3$.  
由图中观察可知，$Y$ 的关键点是：$1,2,3,4$.  

下面分段计算分布函数.  
① 若 $y<1, F_Y(y)=P\{g(X) \le y\}=P(\varnothing)=0$;  
② 若 $1 \le y < 2$，如图所示，  
$$F_Y(y)=P\{g(X) \le y\}=P\{2 \le X < 3\}$$  
$$=\int_{2}^{3} \frac{x^2}{9} \mathrm{d}x = \left. \frac{x^3}{27} \right|_{2}^{3} = \frac{19}{27};$$

**[例题29 解答续]**  
**印刷内容：**  
③ 若 $2 \le y < 3$，如图所示，  
$$F_Y(y)=P\{g(X) \le y\}=P\left\{1 < X \le \frac{y}{2}\right\} + P\{2 \le X < 3\}$$  
$$=\int_{1}^{\frac{y}{2}} \frac{x^2}{9} \mathrm{d}x + \frac{19}{27} = \left. \frac{x^3}{27} \right|_{1}^{\frac{y}{2}} + \frac{19}{27} = \frac{y^3}{216} + \frac{2}{3};$$  

④ 若 $3 \le y < 4$，如图所示，  
$$F_Y(y)=P\{g(X) \le y\}$$  
$$=P(0<X \le 1) + P\left(1<X \le \frac{y}{2}\right) + P(2 \le X < 3)$$  
$$=\int_{0}^{1} \frac{x^2}{9} \mathrm{d}x + \frac{y^3}{216} + \frac{2}{3} = \frac{1}{27} + \frac{y^3}{216} + \frac{2}{3}$$  
$$=\frac{y^3}{216} + \frac{19}{27};$$

**[例题29 解答续]**  
**印刷内容：**  
⑤ 若 $y \ge 4, F_Y(y) = P\{g(X) \le y\} = P(\Omega) = 1$.  
综上所述，$F_Y(y)=\begin{cases} 0, & y < 1, \\ \frac{19}{27}, & 1 \le y < 2, \\ \frac{y^3}{216} + \frac{2}{3}, & 2 \le y < 3, \\ \frac{y^3}{216} + \frac{19}{27}, & 3 \le y < 4, \\ 1, & y \ge 4. \end{cases}$

(2) $P\{X \le Y\} = P\{Y - X \ge 0\}$.  

由题中条件 $Y-X = \begin{cases} 3-X, & X \le 1, \\ X, & 1 < X < 2, \\ 1-X, & X \ge 2. \end{cases}$  
得 $P\{Y - X \ge 0\}$  
$= P\{X \le 1, 3-X \ge 0\} + P\{1<X<2, X \ge 0\} + P\{X \ge 2, 1-X \ge 0\}$  
$= P\{X \le 1\} + P\{1<X<2\} + 0$  
$= P\{X < 2\} = \int_{0}^{2} \frac{x^2}{9} \mathrm{d}x = \left. \frac{x^3}{27} \right|_{0}^{2} = \frac{8}{27}$.
