### IMAGE 3 (03-2)
**[例题4 答案续写/板书]**
> *手写内容：*  
> 第一章 随机变量及其分布  
> $F(x) = P(X \le x) =$
> $$
> \begin{cases}
> P(\phi) = 0, & \text{当 } x < -1 \\
> P(X < -1) + P(X = -1) + P(-1 < X \le x) = 0 + \frac{1}{8} + \frac{5}{16}(x+1), & \text{当 } -1 \le x < 1 \\
> P(\Omega) = 1, & \text{当 } x \ge 1
> \end{cases}
> $$
> *红字批注：* “无效”（指向 $P(X \le x)$ 中间的步骤标记）

### IMAGE 5 (03-3)
**[例题11 答案续写/板书]**
> *手写批注与解答：*  
> 圈选选项：**(C)** （画红圈）  
> 涂改标注：修改题目参数为 $0.5$（划掉 $0.1$）  
> $X_1 + \cdots X_{20} \sim B(20, 0.1)$  
> $\lambda = n p = 2$  
> $T = X_1 + \cdots X_{20} \sim P(2)$  
> $P\{T \le 1\} = P\{T=0\} + P\{T=1\} = \frac{\lambda^0}{0!} e^{-\lambda} + \frac{\lambda^1}{1!} e^{-\lambda} = 3e^{-\lambda} = 3e^{-2}$
