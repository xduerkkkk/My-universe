### 图片 1
**核心内容：运用泰勒中值定理求解中值问题**
*   **方法**：将 $f(\alpha)$ 在 $\beta$ 处泰勒展开。
*   **展开点选择**：$\alpha, \beta$ 通常取区间端点 $a, b$，区间中点 $\frac{a+b}{2}$，极值点（包括最值点）$c$，或任意点 $x$。
*   **两个原则**：
    1. $\alpha, \beta$ 的选取要根据题目的条件和结论，取条件和结论中出现的点。
    2. 展开后要将结论和条件中不存在的式子消去。

### 图片 2 & 3
**题目**：函数 $f(x)$ 在 $[-1, 1]$ 上有三阶连续导数，且 $f(-1)=0, f(1)=1, f'(0)=0$，证明：存在 $\xi \in (-1, 1)$，使得 $f'''(\xi)=3$。
*   **步骤**：
    1. 在 $0$ 处展开：
       $f(1) = f(0) + f'(0) + \frac{1}{2}f''(0) + \frac{1}{6}f'''(\xi_1), \quad 0 < \xi_1 < 1$
       $f(-1) = f(0) - f'(0) + \frac{1}{2}f''(0) - \frac{1}{6}f'''(\xi_2), \quad -1 < \xi_2 < 0$
    2. 相减：$f(1) - f(-1) = 2f'(0) + \frac{1}{6}(f'''(\xi_1) + f'''(\xi_2))$
    3. 代入已知条件：$1 - 0 = 0 + \frac{1}{6}(f'''(\xi_1) + f'''(\xi_2)) \Rightarrow 3 = \frac{1}{2}[f'''(\xi_1) + f'''(\xi_2)]$
    4. 利用最值性：$\min\{f'''(\xi_1), f'''(\xi_2)\} \le \frac{1}{2}[f'''(\xi_1) + f'''(\xi_2)] \le \max\{f'''(\xi_1), f'''(\xi_2)\}$
    5. 由介值定理：$\exists \xi \in [\xi_2, \xi_1]$，使得 $f'''(\xi) = 3$。

### 图片 4
**题目**：设函数 $f(x)$ 在 $[a, b]$ 上有三阶连续导数，且 $f'(a)=f'(b)=f''(a)=f''(b)=0$，证明：
(1) 存在 $\xi \in (a, b)$，使得 $f(b)-f(a) = \frac{1}{24}(b-a)^3 f'''(\xi)$
(2) 存在 $\xi \in (a, b)$，使得 $f(b)-f(a) = \frac{1}{18}(b-a)^3 f'''(\xi)$
*   **关键点**：利用泰勒展开在 $a$ 和 $b$ 处展开，结合 $x$ 待定，通过构造 $t = \frac{x-a}{b-a}$ 求解最优展开点。

---

### 图片 5
**题目**：同图片 4。
*   **计算过程**：
    $\frac{1}{6}(x-a)^3 + \frac{1}{6}(b-x)^3 = \frac{1}{18}(b-a)^3$
    令 $t = \frac{x-a}{b-a}$，化简得 $3t^3 + 3(1-t)^3 = 1$
    解得 $t = \frac{1}{3}$ 或 $t = \frac{2}{3}$。
    从而得到 $x = a + \frac{1}{3}(b-a) = \frac{b+2a}{3}$ 或 $x = a + \frac{2}{3}(b-a) = \frac{2b+a}{3}$。

### 图片 6
**题目**：设函数 $f(x)$ 在 $[0, 1]$ 上二阶可导，且 $|f''(x)| \le 1, f(x)$ 在 $(0, 1)$ 内取到最大值 $\frac{1}{4}$，证明：$|f(0)| + |f(1)| \le 1$。
*   **思路**：设 $c$ 为最大值点，$f(c) = \frac{1}{4}, f'(c) = 0$。在 $c$ 处展开 $f(0)$ 和 $f(1)$，利用 $|f''(x)| \le 1$ 进行放缩。

### 图片 7
**题目**：设函数 $f(x)$ 在 $[a, b]$ 上二阶可导，且 $f'(a)=f'(b)=0$，证明：存在 $\xi \in (a, b)$，使得 $|f''(\xi)| \ge \frac{4}{(b-a)^2} |f(b)-f(a)|$。
*   **思路**：在 $a$ 和 $b$ 处展开，利用 $x$ 待定法，通过 $t = \frac{x-a}{b-a}$ 确定 $x = \frac{a+b}{2}$。

### 图片 8 & 9
**题目**：设函数 $f(x)$ 在 $[a, b]$ 上二阶可导，且 $f(a)=f(b)=0, |f''(x)| \ge 1$，证明：$\max_{a \le x \le b} |f(x)| \ge \frac{1}{8}(b-a)^2$。
*   **思路**：设 $c$ 为最大值点，在 $c$ 处展开 $f(a)$ 和 $f(b)$，利用 $|f''(x)| \ge 1$ 得到 $|f(c)| \ge \frac{(c-a)^2}{2}$ 和 $|f(c)| \ge \frac{(b-c)^2}{2}$，从而证明结论。

### 图片 10
**题目**：设函数 $f(x)$ 二阶可导，$f(0)=f(1)=0, \max f(x)=2$，证明：$\min_{0 \le x \le 1} f''(x) \le -16$。
*   **思路**：设 $c$ 为最大值点，$f(c)=2, f'(c)=0$。在 $c$ 处展开 $f(0)$ 和 $f(1)$，得到 $f''( \xi_1) = \frac{-4}{c^2}, f''(\xi_2) = \frac{-4}{(1-c)^2}$。通过分析 $c$ 的取值范围证明最小值 $\le -16$。

### 图片 12
**题目**：设函数 $f(x)$ 在 $(-\infty, +\infty)$ 内三阶可导，且 $|f(x)| \le M_0, |f'''(x)| \le M_3$，证明：$|f'(x)| \le \sqrt[3]{9M_0^2M_3}$。
*   **思路**：利用泰勒展开 $f(x+h)$ 和 $f(x-h)$，构造辅助函数 $g(t) = \frac{M_0}{t} + \frac{t^2}{6}M_3$ 求极值。

---

### 图片 13 & 14
**题目**：设函数 $f(x)$ 在 $(-\infty, +\infty)$ 内二阶可导，且 $|f(x)| \le M_0, |f''(x)| \le M_2$，证明：$|f'(x)| \le 2\sqrt{M_0M_2}$。
*   **思路**：利用泰勒展开 $f(x+h) = f(x) + hf'(x) + \frac{h^2}{2}f''(\xi)$，整理得 $|f'(x)| \le \frac{2M_0}{|h|} + \frac{|h|M_2}{2}$。取 $h = 2\sqrt{\frac{M_0}{M_2}}$ 得到结论。

### 图片 15
**题目**：设函数 $f(x)$ 在 $[0, 1]$ 上具有连续导数，且 $f(0)=0$，证明：存在 $\xi \in (0, 1)$，使得 $G''(\xi) = 2G(1)$，其中 $G(x) = \int_0^x f(t)dt$。
*   **步骤**：
    1. $G(0)=0, G'(0)=f(0)=0$。
    2. 在 $0$ 处对 $G(1)$ 进行二阶泰勒展开：$G(1) = G(0) + G'(0) + \frac{1}{2}G''(\xi)$。
    3. 代入条件得 $G(1) = \frac{1}{2}G''(\xi) \Rightarrow G''(\xi) = 2G(1)$。
