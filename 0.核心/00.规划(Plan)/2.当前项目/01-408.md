## 1. 为什么先做四年真题

四年真题的作用不是估计最终分数，而是提供一个受控样本，帮助建立：

- 哪些考点反复出现；
- 同一个考点如何变换问法；
- 选择题和大题分别要求什么动作；
- 自己在哪些概念、流程和计算上反复失稳。

因此，**2009–2012 年先行够做“初版框架”**；之后还需要用更晚年份的套卷验证迁移能力，并检查初版框架中没有被四年样本命中的节点。

## 2. 四年真题初版框架：固定流程

### 第一步｜按科目分块，不按四科混刷

依次处理：

1. 操作系统；
2. 计算机组成原理；
3. 数据结构；
4. 计算机网络。

每门科目选择 2009–2012 年，题源选“真题”，选择题和大题全部纳入。不要四门科目随机混在一个列表里，否则知识切换会掩盖真正的薄弱点。

### 第二步｜先做题，再看材料

第一遍做题时：

- 先独立作答；
- 不提前打开王道笔记；
- 不因为题目不会就立刻跳到完整知识点；
- 先记录“我具体卡在哪里”。

这四年是用来长出你的标注层，不是用来再次通读教材。

### 第三步｜每道题只留下四个字段

```markdown
### 2010 年·操作系统·选择题 12

- 考查考点：
- 题目触发信号：
- 正确解题动作：
- 我为什么不熟/为什么错：
```

不复制整道题，不把每个选项都改写成讲义。只保留能改变后续判断的内容。


### 第四步｜不熟考点定点补强

发现不熟后，按固定顺序补：

1. 先闭卷说出自己不会的具体位置；
2. 查看自己的王道题笔记或 AI 复盘笔记；
3. 在网站中做 2–5 道针对性巩固题；
4. 回到原真题重新完成；
5. 能解释并完成一个变式后停止扩展。

不要因为一个考点不熟，就把整章视频和全部题库重新看一遍。

### 第五步｜由重复命中合并成决策图

四年题目处理完后，把重复出现的触发信号合并为决策规则：

```markdown
# 操作系统 · 真题决策图 V1

## 看到题目先判断
- 问资源归属 → 进程
- 问执行现场、寄存器、栈 → 线程
- 问先后次序 → 同步
- 问同时访问 → 互斥
- 问循环等待 → 死锁

## 每个节点继续写
- 典型触发词：
- 需要调用的知识链：
- 选择题常见陷阱：
- 大题的书写/计算动作：
- 命中题号：
- 当前稳定度：
```

决策图只收“题目如何调用知识”，不收完整教材目录和所有题目解析。

### 第六步｜闭卷重建并冻结 V1

每门科目处理完后，合上材料重画一次：

- 主干节点是否完整；
- 四年真题命中了哪些节点；
- 哪些节点暂时没有被命中；
- 哪些节点自己仍然无法解释。

最后把缺口分成：

- **真题暴露缺口**：立即补；
- **四年未命中但大纲存在**：保留空节点，后续套卷验证；
- **只是个别题计算失误**：进入回滚，不扩写框架。

## 3. 四年初版框架的完成标准

- 2009–2012 年四门科目的选择题和大题都处理过；
- 每道题至少挂到一个考点节点，或明确记录为“暂不纳入”；
- 每门科目都有一张自己的决策图 V1；
- 不熟考点已经完成定点巩固；
- 能从空白纸复述主干，而不是只能看着笔记认出“自己见过”；
- 未被四年真题覆盖的考纲节点没有被误删，而是保留为空节点。

## 4. 现有材料的职责

| 材料 | 用法 |
| --- | --- |
| 视频笔记 | 查概念来源和完整机制 |

## 5. 本阶段的边界

- 不把四年真题重新整理成第二套王道讲义；
- 不要求每个考点都做成漂亮的 XMind；
- 不因一个陌生点重新通读整章；
- 不在四年初版阶段追求最终版；
- 不把“看懂 AI 笔记”当成“已经能闭卷调用”。

## 晚间时段：刷 AI 复盘卡片，不建导图（2026-07-25 定）

`202.计算机知识` 下已有 **8 份错题复盘卡片**：OS 五章全覆盖（综述/进程/内存/文件/IO）+ 计组三章（数据表示/存储/IO）。来自你自己一刷二刷的错题，零构建成本，且每张末尾带「下次检查」——形式与 [[05认知画像]] 的考场对策同构。

**强化阶段晚上刷卡片，骨架用现成的，真题阶段再建自己的导图。**

导图那个矛盾的解法是把它拆成两层：

- **骨架**（章节层级）来自大纲和王道目录，是标准化的。自己画一遍等于抄目录，信息增量为零 —— 这一层用别人的，或直接用王道目录
- **标注层**（每个节点被真题命中几次、错没错、考法、坑在哪）只有做题才长得出来，别人给不了

**完整骨架恰恰是"导图不完整"的解药**：真题做完后没被标注的节点会明晃晃空在那里，你能看见并判断"是真冷门还是我恰好没测过"。若树是从真题长出来的，没考过的节点根本不会出现、不留痕迹，翻遍导图也发现不了缺什么。真题命中频次本身就是信息，只有对着完整骨架才看得出来。

已有的五份导图（进程/内存/存储/指令/CPU）留作那几章骨架，不重画。7/22 你自己写的「文件这章导图很凌乱，卡很久了，先放着吧，真题阶段再完善」——这个判断是对的。

这份具体的周、天级 408 强化计划是为你量身定制的。既然你的**计组 IO 和第一章已完结**，今天（6/26）将直接进入**数据表示与运算**。
