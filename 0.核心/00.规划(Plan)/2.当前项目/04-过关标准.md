# 过关标准

> 建于 2026-07-25，2026-07-27 改为**问题式自测**。
> 本文件不再列“应该掌握什么”的目录，而是列“遮住答案后，能不能把它讲明白、做出来”的门禁问题。

## 过关标准 ≠ 指标

|       | 过关标准                | 指标                |
| ----- | ------------------- | ----------------- |
| 形态    | 二值门禁：这个问题能不能独立回答/完成 | 连续量：频次、比例、趋势      |
| 检查方式  | 闭卷费曼输出，必要时做代表题      | 跨周统计重复卡点          |
| 测什么   | **知识状态**：能否提取、解释和运用 | **认知动作**：反复在哪一步出错 |
| 英语对应物 | 无（英语没有章节门禁）         | 病灶频次台账、闭环比        |

数学和 408 的指标已有雏形：周报的「重复卡点」。攒够 3—4 期后再建跨周长表，避免把一次失误误判成病灶。

## 怎么用：问题 → 原题 → 台账

1. **只看自测问题**，不看讲义和答案，用费曼方式口述或在纸上推导。
2. 能完整回答“结论 + 条件 + 为什么/怎么做” → **过**，不要求记得它来自哪道原题。
3. 答不出、漏关键条件或只是“看着熟” → 回到对应卡片/原题，**闭卷重做一次**。
4. 原题做对且能解释 → 到此结束；原题仍错、仍靠答案提示或解释不清 → 写入 [[1.工作流/回滚台账]]。
5. 同一底层原因再次出现 → 不再重复看解析，改为重建概念模型并补一道邻近变式。

> [!important] 判断对象
> **不考“是否记得原题题面”，只考“能否从问题独立生成答案”。** 原题只是卡片失效后的二级验证器，不是背诵对象。

### 408 每周轮换检测（30—45 分钟）

1. 选本周轮到的一个知识块，随机抽 6—10 张重构版自测卡。
2. 每张先费曼输出，再展开核对，标为：A＝完整；B＝迟疑/漏条件；C＝答错/空白。
3. A 直接退场；B、C 回原题闭卷重做。
4. **只有重做仍错或仍讲不清的题进入回滚台账。**
5. 本次检测到点即停，不顺势启动整章三刷。
