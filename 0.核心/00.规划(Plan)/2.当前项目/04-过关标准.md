# 过关标准

> 建于 2026-07-25。补规划里缺的那一半 —— 原规划每格只写"学什么、几号到几号"，没有一格写"到那天我应该能做到什么"。

## 过关标准 ≠ 指标

你问的这个区别很关键，两者不能互相替代：

| | 过关标准 | 指标 |
|---|---|---|
| 形态 | 二值门禁：能/不能 | 连续量：频次、比例、趋势 |
| 检查次数 | 一次，章末 | 反复，每周重算 |
| 测什么 | **知识状态**（这块内容通了没有） | **认知动作**（你反复在哪一步出错） |
| 英语对应物 | 无（英语没有章节概念） | 病灶频次台账、闭环比 |
| 数学/408 现状 | 本文件补上 | **仍然缺**，见下 |

英语那套（病灶 A/B/C/D + 频次 + 闭环比）是**指标**，不是过关标准。它测的是"你做题时的动作模式"，跨年份跨篇目累积，会迁移。

所以本文件只解决一半。另一半 —— 数学和 408 的指标 —— 其实已经有雏形了：**周报的「重复卡点」一节就是原料**。7/11-7/25 那期已经跑出一条真病灶（方向与投影，4 次复现）。缺的只是跨周累积：

> 建议每期周报末尾追加一行到一张长表：`卡点类型 × 周次`，复现就打勾。连续 2 周不复现转观察，4 周退役 —— 规则直接抄认知画像。
>
> **别现在就建。** 攒够 3-4 期周报再建，否则样本太少，会把一次性失误当成病灶。数学第一条候选已经有了（方向与投影），408 第一条候选是指针边界与初始化（7/23，树的算法题里大概率复现）。

## Ch1 行列式｜7/27 - 7/28（周一、二）

- 不看书说出行列式的 4 类基本变形：提公因子、行列互换、倍加不变、按行拆分 —— 并各举一个用得上的题型
- 给一个含 A、B 的抽象行列式（如 `|A+B|`、`|2A|`、`|A⁻¹|`、分块），能立刻说出用哪条性质、以及**哪条性质此处不成立**（`|A+B| ≠ |A|+|B|` 这类）
- 范德蒙德行列式认得出形状，不用背公式也知道它为什么等于差的连乘
- 余子式/代数余子式：给定某行元素与**另一行**的代数余子式相乘，知道结果为 0 及其原因

> **注意**：行列式历年平均 0.8 分，是全表最低。它的价值在于给后面五章当地基，**不要在这章刷出感情**，2 天到点就走。

## Ch2 矩阵｜7/29 - 7/31（周三、四、五）

- **不看讲义画出"秩 / 可逆 / 等价"三者的相互推导链** —— 这条是整个线代的枢纽，过不了这条后面全虚
- 初等变换 ↔ 初等矩阵：左乘变行、右乘变列，能说出为什么
- 分块矩阵求逆（对角块、上三角块），以及分块乘法什么时候不能随便拆
- 伴随矩阵：`A·A* = |A|E`、`A*` 的秩在 `r(A)=n / n-1 / <n-1` 三种情形下分别是多少
- 给一个具体矩阵方程（`AXB = C` 型），能判断该左乘还是右乘、能不能约掉

## 8/1（周六）｜吸收日 —— 矩阵溢出、台账到期、周报

## Ch3 向量 + Ch4 方程组｜8/2 - 8/4（周日、一、二，合并 3 天）

> 两章合并，因为它们是同一套语言（秩、相关性、解结构）。以下 8 条按顺序自测，不分章。

- 给一组向量，**先看个数与维数的关系**再动手 —— 个数 > 维数直接判相关，这一步不许跳
- 线性相关性的三条判据（定义式、秩、行列式）各自的适用场景
- 极大无关组与秩的关系；能从一个具体矩阵里把极大无关组拎出来并把其余向量用它表示
- 向量组等价 vs 矩阵等价，区别说得清

- 齐次解结构：基础解系个数 = `n - r(A)`，能说出这个式子里每个字母的几何含义
- 非齐次：`通解 = 特解 + 齐次通解`，以及为什么解集不是子空间
- **含参方程组分类讨论**：给一个带 λ 的增广矩阵，能把讨论分支列全（无解 / 唯一解 / 无穷解各对应 r 的什么关系），不漏分支
- 两个方程组同解 / 公共解，知道怎么转成秩的语言处理

## Ch5 特征值与特征向量｜8/5 - 8/7（周三、四、五）

- 定义式 `Ax = λx` 的三种用法：求 λ、求 x、以及**反过来由已知特征值推 A 的元素**
- 相似对角化的充要条件（n 个线性无关特征向量），以及"有重根不一定不能对角化"的判断路径
- 实对称矩阵四条性质：特征值全实、不同特征值的特征向量正交、必可对角化、可正交相似对角化 —— 说得出为什么这四条让实对称矩阵成为大题主角
- 给 `A` 求 `A^k`、`f(A)`，两条路（对角化 / 特征多项式）都能走

## Ch6 二次型｜8/9 - 8/10（周日、一，**2 个整天**）

- 配方法与正交变换法**两条路都能独立走完**，并知道题目问"正交变换"时不许用配方法
- 正定的 4 个等价判定：特征值全正 / 顺序主子式全正 / 存在可逆 C 使 `A = CᵀC` / 正惯性指数 = n
