### 2. 数学每日时间模板

**整卷日：约5.5小时**
1. 限时作答：3小时。
2. 判分、订正、针对性补缺：共不超过2小时，判分也计入其中。
3. 旧错题回滚：30分钟。
4. 不再强制推进手稿。若关键问题当天未解决，转入次日优先处理，不带着大批订正直接开下一张卷。

**手稿／巩固日：约5.5小时的可用窗口，不要求机械填满**
1. 手稿：常规预留2.5小时；当天难页较多时可扩到3.5小时。
2. 旧错题回滚：30分钟。
3. 剩余1.5～2.5小时：上一张卷遗留问题、薄弱方法重做或全章节查漏。
4. 当天重点是手稿和已有漏洞，不因为提前完成就临时加一整套卷。

**手稿执行规则**
- 每周18页，原则上三科各6页；不要求每天三科各2页。
- 首周安排三个主要手稿日，每次目标6页；若难度波动，周日补齐周进度。
- 以当前未做位置为起点，按高数／线代／概率分别记录新增完成页数。
- 一遍的标准：每题都尝试并核对；不会的题定位卡点后，合上答案重做关键步骤，记录二刷标记。
- 已熟练题可简写，但涉及计算稳定性的题仍需完成必要计算；不以抄答案充当完成。
- 单道难题不无限延长研究；留下未解决点，进入后续专项与二刷。

## 四、动态调整规则

1. **先减新增卷，不减消化时间。** 数学前卷关键订正未完成时，用下一次模拟卷时段补缺；先动两套弹性模拟，不优先删手稿或回滚。
2. **手稿按周守进度。** 某天6页用时过长，不用熬夜补；记录实际完成量，在本周机动位调整。
3. **本周408按1真题＋2模拟安排。** 不再补排周一的任务。2018年真题必要时在周四、周六间调整；若仍需跨周，重新评估后续容量，不自动叠加任务。最后六天预留2套真题及其订正时间。
4. **固定模拟不等于固定欠账。** 周日模拟的深订正可以跨周，但下一周先消化再开新卷。
5. **每周日只核对四项：** 实际完成卷数、手稿分科页数、关键订正积压、旧错题独立重做表现。
6. **每天回滚不等于每天清空所有旧错题。** 时间约30分钟，优先近期反复错、典型方法和此前未能独立完成的题。
