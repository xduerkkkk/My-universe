太好了！回家过寒假是“弯道超车”或者“养精蓄锐”的最佳时期。虽然没有舞室氛围，但这正是**打磨基本功（Strength & Isolation）**的绝佳机会。

针对你**“怕麻烦组装哑铃”、“想练腹”、“为Hiphop打基础”、“饭后运动”**这几个核心点，我为你设计了一套**【居家·舞者体能重塑计划（6周）】**。

### **核心策略：极简切换 + 核心轰炸 + 舞感维持**

1.  **关于哑铃组装：** 既然觉得麻烦，我们就采用**“固定重量策略”**。找一个你做“划船”或者“深蹲”觉得合适的重量（比如单只7.5kg-10kg，或者更重），固定好之后，这6周尽量少拆卸。做小肌群（如侧平举）时，我们用**弹力带**（上次让你买的还在吧？）替代，那个不用拆卸。
2.  **关于天天练腹：** 腹肌是耐力肌群，可以高频练，但建议**“分化练”**（一天练上腹/卷腹，一天练侧腹/转体，一天练静态/平板），以免腰部过劳。
3.  **关于饭后运动：** 吃完饭半小时后，血液还在胃部，**不适合剧烈跑跳**。所以我们的安排以**力量训练**和**低冲击律动**为主，不做高强度HIIT。

### **每日40分钟详细流程**

#### **周一/周四：下肢 + 律动（为跳舞练腿）**

**目标：** Hiphop需要极强的腿部耐力和膝盖弹性。

1.  **热身 (5min)：** 关节活动，简单的原地小跑，不开合跳（怕震胃）。
2.  **哑铃力量 (20min)：**
    *   **高脚杯深蹲：** 双手捧住一个哑铃在胸前。**4组 x 12-15次**。（练大腿前侧和核心）
    *   **哑铃箭步蹲：** 双手各提一个哑铃（或者只用自重）。**3组 x 12次/每条腿**。（练平衡和臀部）
    *   **哑铃直腿硬拉：** 双手提哑铃，沿大腿下放至小腿，感受大腿后侧拉伸。**4组 x 12次**。（练大腿后侧，保护膝盖关键）
3.  **Hiphop基础律动 (10min)：**
    *   戴上耳机，放Hiphop音乐。
    *   **Up & Down Bounce：** 膝盖要有弹性，就在原地跟着拍子做最基础的Down（下沉）和Up（提气）。**这比跑步更练舞感！**
4.  **腹部收尾 (5min)：**
    *   **反向卷腹（抬腿）：** 3组 x 15次。

#### **周二/周五：上肢 + 核心（为了穿衣好看）**

**目标：** 维持肩背肌肉，防止过年吃胖。

1.  **热身 (5min)：** 肩关节环绕，扩胸。
2.  **哑铃力量 (20min) - 固定重量：**
    *   **哑铃俯身划船：** （练背厚度，不想拆哑铃就用这一个重量做）。**4组 x 12次**。
    *   **地板哑铃卧推：** 躺在瑜伽垫上推哑铃（练胸）。**4组 x 12-15次**。
    *   **弹力带侧平举：** （用弹力带代替轻哑铃练肩中束，不拆卸）。**4组 x 力竭**。
    *   **弹力带面拉：** （改善圆肩）。**3组 x 15次**。
3.  **核心轰炸 (10min)：**
    *   **卷腹 (Crunches)：** 3组 x 20次。
    *   **俄罗斯转体 (Russian Twists)：** 手拿一个轻物，左右转。3组 x 30次。
4.  **拉伸 (5min)：** 胸部和背部拉伸。

#### **周三/周日：核心 + 隔离 + 柔韧（Hiphop进阶秘籍）**

**目标：** 解决你之前提到的“上半身僵硬”问题。这一天不累，但极重要。

1.  **核心稳定性 (15min)：**
    *   **平板支撑：** 3组 x 1分钟。
    *   **侧支撑：** 2组 x 45秒/侧。
    *   **死虫式 (Dead Bug)：** 躺平，手脚对侧伸展，腰死死贴地。3组 x 12次。（极佳的核心控制训练）
2.  **身体隔离 (Isolation) (15min)：**
    *   对着镜子做！
    *   **颈部：** 前后左右平移。
    *   **胸部：** 前后左右平移（保持肩膀不动，这很难，但练Hiphop必修）。
    *   **胯部：** 前后左右律动。
    *   *每个部位练一首歌的时间。*
3.  **深度拉伸 (10min)：**
    *   重点拉伸大腿后侧、髋关节（青蛙趴）、胸椎。

### **针对你的“特殊叮嘱”**

1.  **关于“每天练腹”：**
    *   我在计划里其实把你安排得**几乎每天都动到了核心**。周一四是反向卷腹，周二五是正向卷腹和转体，周三日是平板支撑。
    *   **注意：** 腹肌是在厨房里练出来的。过年回家**控制饮食**（少吃油炸、甜食、饮料）比你做1000个卷腹更管用。

2.  **关于“饭后运动”：**
    *   因为涉及到深蹲和卷腹，**请务必确保吃完饭至少40分钟-1小时再开始**。如果只隔半小时，容易胃下垂或者反酸。
    *   如果只能隔半小时，建议把**“隔离练习”**和**“弹力带练肩”**放在最前面做，把剧烈的深蹲放在最后做。

3.  **关于“哑铃不拆卸”：**
    *   你就组装成两个 **7.5kg - 10kg** 左右的重量（根据你能完成划船和推举的能力定）。
    *   深蹲时如果觉得轻，就**放慢速度**（下蹲3秒，起立1秒），刺激感依然很强。

4.  **Hiphop基础：**
    *   家里没有老师教，最怕练歪。**多听音乐，多练Bounce（膝盖弹性）**。只要膝盖弹性和核心控制练好了，开学回舞室你会发现自己稳了很多。

**寒假快乐！这6周如果你能坚持下来，开学时你的核心力量和体脂率绝对会让同学大吃一惊。**
