# 三、方向技术壁垒

**壁垒分级：中壁垒**

**原因分析：**

- **自动驾驶 BEV 感知**：该方向在 2022-2023 年是技术前沿，但到 2026 年已相对成熟。BEVFormer、BEVFusion 等框架开源后，技术壁垒被显著降低。大量硕士以此为入门方向，人才供给充足。纯做 BEV 感知的壁垒已经从"高"降为"中低"。
- **世界模型**：概念新、落地难，目前的技术路线尚未收敛。壁垒取决于具体实现——如果是"用视频生成做世界模型"则壁垒中等（与 AIGC 方向重合），如果是"结合物理引擎+神经网络的 hybrid 世界模型"则壁垒较高。
- **具身智能 Agent**：OmniActor 走的是"通用 Agent"路线（GUI 操作+具身），这个方向目前竞争者较少、壁垒在于系统设计和环境交互的复杂性。但 2026 年做 Agent 的团队爆发式增长，长期壁垒存疑。
- **多模态大模型**：壁垒主要在算力和数据。学术界做多模态大模型往往受限于资源，真正的核心壁垒掌握在大厂手中。硕士在这个方向的竞争力更多来自"对架构和训练细节的理解"而非"不可替代的技术护城河"。

**总结：** 秦泽群的方向布局偏"跟热点"——每个方向都是当前最火的赛道，但也意味着竞争者众多、技术路线变化快。相比彭思达深耕 3D 视觉/图形学的"深井"式积累，秦泽群的方向更"宽"但"浅"一些。
