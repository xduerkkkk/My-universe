# 二、方向就业价值（最重要）

**市场需求分析：**

彭思达的核心方向可拆解为以下就业赛道：

1. **自动驾驶仿真/3D 重建方向**：当前是自动驾驶行业刚需。蔚来、理想、华为、小鹏、Waymo 等均在大量招聘仿真/3D 场景生成相关算法人才。该方向属于"端到端自动驾驶"生态中的核心模块，未来 3 年 HC 稳定增长。
2. **Spatial AI / 空间智能体**：这是 2024-2025 年产业界最火热的新赛道之一（苹果 Vision Pro、Meta Quest、具身智能），字节、腾讯、华为 XR 部门、机器人公司均在扩招。但该方向目前更多处于"研究预研→产品落地"过渡期，HC 增速快但总量尚不算巨大。
3. **3D Gaussian Splatting / NeRF / 三维视觉**：该方向近 2 年学术极热，但产业 HC 集中在自动驾驶仿真、数字人、XR 等下游应用。纯 3D 重建岗位有限，需结合具体应用场景。
4. **深度估计/逆渲染**：与 AIGC、数字人、游戏引擎相关，腾讯 IEG、网易伏羲、米哈游等有需求，但 HC 相对小众。

**综合来看：** 该方向覆盖了自动驾驶仿真、空间智能、XR 三大产业方向，市场需求真实且处于上升期。但需注意，3D 视觉方向的产业 HC 总量不如 NLP/大模型/推荐系统等主流方向大，属于"精英赛道"——竞争者少但岗位也相对精准。

**就业价值评分：★★★★☆**

（扣一星原因：相比大模型/AI Infra 等主流方向，3D 视觉的 HC 总量偏小，求职面窄一些。但单位 HC 的竞争质量高、薪资竞争力强。）

# 三、方向技术壁垒

**壁垒分级：高壁垒**

**原因分析：**

- 3D 视觉/计算机图形学方向需要扎实的数学基础（微分几何、优化理论、渲染方程）、对三维表达的深度理解、以及大量工程实现能力（CUDA、渲染管线、大规模场景处理），这些知识**极难通过短期培训班或 AI 工具速成**。
- 与"调用 API 做应用层开发"形成鲜明对比：3D 视觉从业者需要长时间的知识积累，包括多视图几何、神经隐式表达、物理仿真等底层能力。
- 该方向的核心竞争力在于"对三维世界的建模能力"，这是当前 LLM/AI Agent 无法替代的——它涉及真实物理世界的感知和理解，而非纯文本推理。
- 相比纯 CV 分类/检测等已被大模型冲击的方向，3D 视觉+图形学的壁垒保持良好。
