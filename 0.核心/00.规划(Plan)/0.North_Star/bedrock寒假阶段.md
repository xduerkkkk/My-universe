
挑两天 老题阅读精读

**核心原则**：

1. **拒绝切换**：这一天，你的大脑只加载一套上下文（Context）。
    
2. **深度优先**：不是为了凑时间，而是为了把一个板块（比如无穷级数，或者内存管理）彻底挖到底。
    

#### **周一、周四：【AI + 概率论日】**

这也是你的“学者日”。

- **09:00 - 12:00**：**概率论（数一核心）**
    
    - 为什么放这？ 概率论是AI的基石。把这两块放在一起，你的六维解码效率最高。
        
    - 任务：看教材/深度推导 -> 写深度文章。
        
- **13:30 - 17:30**：**AI 理论攻坚 (PRML)**
    
    - 任务：死磕那几章数学推导。哪怕一下午只推导了 2 页公式，也是胜利。
        
- **19:00 - 21:00**：**AI 代码实战 / 课程笔记整理**
    
    - 任务：整理你答应哥们的ML笔记，或者手撸 LLM 代码。
        
- **21:00 - 22:00**：**英语单词/阅读（轻量级维持）**。
    

#### **周二、周五：【数学日 (High Math)】**

这一天，你就是数学家。

- **09:00 - 12:00**：**高数基础推进**
    
    - 任务：极限/微分/积分。快速扫清张宇30讲的基础部分，建立骨架。
        
- **13:30 - 17:30**：**高数难点爆破（无穷级数 / 曲面积分）**
    
    - 任务：**这里不求快！** 遇到级数判敛，画图、找本质、问AI、做Obsidian笔记。这是你“构建体系”的高光时刻。
        
- **19:00 - 21:00**：**刷题与归档**
    
    - 任务：把白天的感悟，通过做题（接招）来验证。整理错题进 Obsidian。
        
- **21:00 - 22:00**：**英语单词/阅读（轻量级维持）**。
    

#### **周三、周六：【408 攻坚日 (OS + CO)】**

这一天，你就是系统架构师。

- **09:00 - 12:00**：**计算机组成原理 (CO)**
    
    - 任务：啃硬骨头。数据表示、指令流水线。最清醒的时候搞硬件逻辑。
        
- **13:30 - 17:30**：**操作系统 (OS) + 联调**
    
    - 任务：学 OS 的内存/进程，**并时刻回溯早上的 CO 知识**。打通任督二脉。
        
    - Action：画出那个跨越软件硬件的“全景思维导图”（白板复现）。
        
- **19:00 - 21:00**：**王道选择题 + 计网闪电战（前期）**
    
    - 任务：前期用这个时间段把 TCP/IP 快速过完。后期用来刷 OS/CO 的题。
        
- **21:00 - 22:00**：**英语单词/阅读（轻量级维持）**。
