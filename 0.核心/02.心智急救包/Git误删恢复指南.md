# Git 误删恢复指南 — 心智急救包

> 当你误删了重要文件/文件夹，不要慌张。按照这个流程，99% 的情况都能救回来。

---

## 🚨 情况1: 刚删除，还没 commit

**症状**: 文件夹不见了，但还没执行 `git add` 或 `git commit`

**解决方案** (最简单):
```bash
# 1. 先检查状态
git status

# 2. 如果看到 deleted: 2.知识库/20.North_star_ZJU/...
# 直接恢复所有删除
git restore .

# 或者只恢复特定文件夹
git restore "2.知识库/20.North_star_ZJU"
```

**成功标志**: 文件夹回来了 ✅

---

## 🔥 情况2: 删除后已经 commit，但还没 push

**症状**: 已经 `git commit -m "误删"`，但还在本地

**解决方案**:
```bash
# 1. 查看提交历史，找到删除前的那次提交
git log --oneline -10

# 会看到类似：
# a1b2c3d (HEAD -> main) 误操作删除
# e4f5g6h 正常的笔记更新  ← 回到这里
# ...

# 2. 回退到删除前的提交（保留工作区的其他修改）
git reset --soft e4f5g6h

# 3. 检查文件回来了吗
ls "2.知识库/20.North_star_ZJU"

# 4. 如果想完全回到删除前的状态
git reset --hard e4f5g6h  # 注意：会丢失删除后的所有新工作
```

---

## 💀 情况3: 删除、commit、push 都完成了

**症状**: 远程仓库也被更新了，GitHub 上也看不到文件夹了

**解决方案A (推荐): 从历史恢复**
```bash
# 1. 查看完整历史（包括已删除的提交）
git reflog

# 会看到类似：
# a1b2c3d HEAD@{0}: commit: 删除了文件夹
# e4f5g6h HEAD@{1}: commit: 正常更新  ← 文件夹还在这里
# ...

# 2. 只恢复那个文件夹，不影响其他工作
git checkout e4f5g6h -- "2.知识库/20.North_star_ZJU"

# 3. 提交恢复
git add "2.知识库/20.North_star_ZJU"
git commit -m "恢复误删的考研核心文件夹"
git push
```

**解决方案B (暴力): 完全回退**
```bash
# 回到删除前的提交（会丢失删除后的所有新工作）
git reset --hard e4f5g6h

# 强制推送（覆盖远程仓库）
git push --force
```

---

## 🛡️ 情况4: Git 都救不了（未跟踪的文件）

**症状**: 新建的文件还没 `git add`，就被删除了

**解决方案**:
1. ✅ **Windows 回收站**: 最直接，去找找
2. ✅ **OneDrive 版本历史**: 
   - 去 OneDrive 网页版
   - 找到 `universe` 文件夹
   - 右键 → "还原"到之前的时间点
3. ✅ **本地备份脚本**: 如果配置了自动备份，去 `D:\ObsidianBackup` 找

---

## 📋 快速决策树

```
误删了文件/文件夹
    ↓
还在回收站吗？
    ├─ 是 → 直接恢复 ✅
    └─ 否 ↓
执行过 git commit 了吗？
    ├─ 否 → 用 git restore ✅
    └─ 是 ↓
推送到 GitHub 了吗？
    ├─ 否 → 用 git reset --soft ✅
    └─ 是 → 用 git reflog + git checkout ✅
都不行？
    └─ OneDrive 版本历史 / 本地备份 ✅
```

---

## 🎯 预防措施

### 立即执行
1. **确保回收站提示开启**:
   - 右键桌面"回收站" → 属性
   - 勾选"显示删除确认对话框" ✅

2. **Obsidian 设置**:
   - 设置 → 文件与链接 → 删除文件
   - 改为"移动到 Obsidian 回收站"（`.trash` 文件夹）

### 长期优化
3. **每天提交备注清晰**:
   ```bash
   git commit -m "2026-09-24 数学强化-极限收敛性"
   # 而不是 "更新"
   ```

4. **重要节点打 tag**:
   ```bash
   # 比如每个月底
   git tag -a 2026-09 -m "9月强化阶段完成"
   git push --tags
   ```

5. **配置本地自动备份**（见备份脚本）

---

## 💡 记住

- **Git 是时间机器，不是垃圾桶** — 它保存历史，不是让你随便删
- **删除前先 commit 当前状态** — 形成快照，随时可回
- **reflog 是最后的救命稻草** — 保留了所有操作记录（默认90天）
