


#### 🍱 每日饮食系统

- **早餐**：粥（杂粮轮换）+ 鸡蛋 + 2 种蔬菜（去掉了馒头，控糖护脑）。
    
- **午餐**：1 荤（优先鸡腿/鱼/牛）+ 3 素（颜色丰富）+ 1 米饭。
    
- **晚餐**：**惊喜奖励随机决策**。原则：少面食、少油炸、荤素搭配。
    
- **水分**：每天 3-4 杯温水（SUS316 杯，确保无异味）。




|   |   |   |
|---|---|---|
|时间段|补剂名称|为什么这时候吃？|
|**早餐后**|**复合维生素 B**|B族辅助代谢，能提神，开启一天的能量，早起吃最合适。|
|**午餐中/后**|**维生素 D3 + 鱼油**|**重点！** 它们是脂溶性的，必须跟着午餐的油脂（鸡腿、红烧肉的油）才能吸收。|
|**午餐后**|**维生素 C**|随餐或餐后，减少对胃的刺激，同时帮你吸收午餐蔬菜里的铁元素。|
|**晚餐后**|**锌 (Zinc)**|锌建议和餐一起吃，防止空腹引起恶心。晚间也是身体修护期。|
