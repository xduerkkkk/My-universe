## 怎么用

1. **每天早上**：把「排期日 ≤ 今天」的项抄到 P0（见 [[0.核心/00.规划(Plan)/2.当前项目/00-规划一览#晚间优先级]]）。
2. **默认按时完成，只记异常。** 清完了什么都不用写；只有**没清完**或**需要再排一次**时才动本表：
   - 没清完 → 状态填 `欠`，明天继续排 P0，不降级。
   - 二刷还卡 → 按三档规则在「待做」新加一行，**不改旧行日期**。
3. **周六**：数一下「欠」和新增，把过期行移入已完成。
4. 新增行**六列填满**，日期统一写 `2026-08-XX`。

### 三档间隔规则

| 这次的结果 | 下次间隔 |
| --- | --- |
| ✅ 做对，过程顺（5 分钟内、无卡壳） | 上次 ×2，或直接毕业 |
| 🟡 做对但磕磕绊绊（查了笔记/卡很久） | 保持 ≈15 天 |
| ❌ 还是错 / 思路断 | **缩到 5–7 天** |

**毕业**：连续 2 次 ✅ → 出表，只在 9/3–9/10 综合查漏时抽检。
