# 三、本周核心卡点总结

## A. 数学卡点

### 1. 形式触发不够敏感

典型表现：

- 看到可配方的式子，不能快速反应；
- 看到根号下 `a² - x²`，没有立刻联想到几何面积 / 三角换元 / 圆；
- 看到绝对值、根号绝对值、四象限对称，虽然已经总结了，但还需要形成条件反射。

### 2. 对称性与坐标变换仍需压实

你这周多次提到：

- 形心公式本质是平移坐标轴后利用奇函数消元；
- 质心只是形心乘密度分布；
- 二重积分换元的雅可比可以求倒数；
- 极坐标要注意 θ 为负导致方向做反。

这些都说明，你已经接近理解本质，但还没有完全自动化。

建议下周数学回滚时，把这类题统一归为一组：

> “对称性 / 换元 / 几何意义触发题”

不要只按题号回滚，要按触发信号回滚。

### 3. 题量估计偏乐观

7/10 你写到：

> 一个标号里面有好几个同类题，以后按时间来规划二刷，题量只给大概。

这是非常关键的改进点。

以后回滚不建议写：

> 大观 10–15

而建议写：

> 大观 50min：优先 10、11，若有余力推进 12

这样不会因为“藏题”导致挫败感。

## B. 408 卡点

### 1. 容易混淆“结构”和“时间”

比如：

- 总线周期 / 流水线间隔
- 首次读出时间
- 连续读 n 个字的总时间
- 单体多字
- 交叉编址

你的问题本质是：

> 没有先判断题目问的是“结构怎么组成”，还是“稳定状态吞吐率”，还是“第一次拿到结果要多久”。

建议做题前强制问三句话：

1. 这是在问**存储组织结构**吗？
2. 这是在问**一次完整访问时间**吗？
3. 这是在问**流水线稳定输出间隔**吗？

只要这三问走完，交叉编址这类题会稳定很多。

---

### 2. Cache 概念边界不稳

本周暴露的点：

- Cache 行 / Cache 组不是实际“先按行再分组”的思路；
- 组相联应该是先确定组，再在组内全相联；
- TAG 与标记序列不同；
- Cache 行数据部分是实打实 bit，和按字节编址无关。

这个地方建议下周用一张表压住：

|概念|本质|易混点|
|---|---|---|
|Cache 行|数据搬运基本单位|不是只含数据，还常配标记信息|
|Cache 组|若干行构成的集合|组相联先定位组|
|TAG|地址高位标记|只是标记序列的一部分|
|标记序列|TAG + 有效位 + 脏位 + 置换位等|不等于 TAG|
|块内地址|定位块内字节 / 字|和主存块大小有关|

---

### 3. TLB / 页表 / Cache 顺序需要持续固化

你已经写出了关键流程：

> TLB → 页表 → 物理地址 → Cache → 主存

下周建议每次做虚拟存储 + Cache 联合题，都先画这个流程，不要直接代公式。

尤其注意：

- TLB 查的是虚页号到物理页框号；
- Cache 查的是物理地址对应的数据块；
- 页表解决地址翻译；
- Cache 解决访存速度。

一句话：

> TLB 管“地址翻译快不快”，Cache 管“拿数据快不快”。

---

### 4. ISA / 指令系统不能死背

你已经意识到：

> “什么属于 ISA”不能死记硬背，必须融汇贯通概念。

这个判断非常正确。

ISA 判断的核心标准可以先粗暴记成：

> 程序员 / 编译器能感知并依赖的机器级接口，通常属于 ISA；纯硬件实现细节，通常不属于 ISA。

例如：

- 指令格式：属于
- 寻址方式：属于
- 寄存器个数：通常属于
- Cache 容量：不属于
- 流水线级数：不属于
- 微操作控制信号：不属于

下周 CPU / 数据通路部分会继续碰到这个边界，要特别留意。

### 408 下周核心策略

> 一条指令从 PC 指向开始，如何被取出、译码、取操作数、执行、访存、写回？

- 控制器：发控制信号
- 数据通路：数据具体怎么流
