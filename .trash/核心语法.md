为了在 408 考研算法设计题中拿高分，你必须形成一套**“肌肉记忆”**。在考场上，数据结构的定义应该像写你的名字一样条件反射。

408 偏好的风格是：**严蔚敏《数据结构》C 语言版风格**。核心原则是：**简单、直接、能用数组模拟就绝不写复杂的结构体**。

以下是 408 考试中最核心的数据结构定义及考场上最实用的“手撕”用法总结，你可以直接把它当作**考前背诵清单**。

---

### 一、线性表（重中之重）

#### 1. 单链表 (Singly Linked List)
这是 408 考察频率最高的数据结构，经常要求原地逆置、寻找交点、快慢指针等。

**标准定义：**
```c
typedef struct LNode {
    int data;               // 数据域（类型视题目而定，通常是 int）
    struct LNode *next;     // 指针域
} LNode, *LinkList;
```
**考场使用套路：**
*   **新建节点：** `LNode *p = (LNode *)malloc(sizeof(LNode));`
*   **带头结点的遍历：** 
    ```c
    LNode *p = L->next; 
    while (p != NULL) { 
        // 处理 p
        p = p->next; 
    }
    ```
*   **避坑指南：** 408 的链表题**默认带有头结点（Dummy Head）**，除非题目明确说明“不带头结点”。头结点不存实际数据，`L->next` 才是第一个真实节点。

#### 2. 双向链表 (Doubly Linked List)
出现频率低于单链表，但插入和删除操作更复杂，要特别小心指针断裂。

**标准定义：**
```c
typedef struct DNode {
    int data;
    struct DNode *prior, *next; // 前驱和后继指针
} DNode, *DLinkList;
```
**考场使用套路（删除节点 p）：**
```c
p->prior->next = p->next;
if (p->next != NULL) {      // 必须检查 p 是否是尾节点！
    p->next->prior = p->prior;
}
free(p);
```

### 二、栈和队列（辅助工具）

在算法设计题中（例如图的 BFS、树的层序遍历），如果题目本身不是考你设计队列，**千万不要去写完整的队列/栈结构体！直接用数组模拟！**

#### 1. 数组模拟栈 (Stack)
用于树的非递归遍历、深度优先搜索（DFS）等。

**考场使用套路：**
```c
int stack[100];     // 1. 定义栈（大小根据题目估算，通常写个大常数如 1000 即可）
int top = -1;       // 2. 初始化栈顶指针

stack[++top] = x;   // 3. 入栈 (Push)
int y = stack[top--]; // 4. 出栈 (Pop)
if (top == -1) {}   // 5. 判断栈空
```

#### 2. 数组模拟队列 (Queue)
用于二叉树层序遍历、图的广度优先搜索（BFS）。

**考场使用套路：**
```c
BiTree queue[1000]; // 1. 定义队列（存什么类型就定义什么类型的数组）
int front = 0, rear = 0; // 2. 初始化头尾指针

queue[rear++] = x;  // 3. 入队
BiTree p = queue[front++]; // 4. 出队
if (front == rear){} // 5. 判断队空
```
*注：考场上除非题目明确要求“循环队列”，否则普通的算法辅助队列用这种“数组一直往后挪”的方式完全可以拿满分，因为节点数量通常有限，不会真的内存溢出。*

### 三、树与二叉树（必考大头）

#### 1. 二叉树 (Binary Tree)
二叉树的递归算法是每年 408 必练的重点。

**标准定义：**
```c
typedef struct BiTNode {
    int data;
    struct BiTNode *lchild, *rchild; // 左右孩子指针
} BiTNode, *BiTree;
```
**考场使用套路：**
*   **万能递归模板：**
    ```c
    void Traverse(BiTree root) {
        if (root == NULL) return; // 递归边界，极其重要！
        
        // 逻辑写在这里是前序遍历
        Traverse(root->lchild);
        // 逻辑写在这里是中序遍历
        Traverse(root->rchild);
        // 逻辑写在这里是后序遍历
    }
    ```

#### 2. 二叉树的特殊变体（如线索二叉树）
如果是线索二叉树，结构体只需加上标志位：
```c
typedef struct ThreadNode {
    int data;
    struct ThreadNode *lchild, *rchild;
    int ltag, rtag; // 0 表示指向孩子，1 表示指向线索
} ThreadNode, *ThreadTree;
```

### 四、图 (Graph)

图的算法题（如 DFS、BFS、最短路径）在 408 中一般是以**邻接矩阵**或**邻接表**的形式给出。

#### 1. 邻接矩阵 (Adjacency Matrix)
最常考！因为它好写。很多时候 408 直接在参数里传一个二维数组。

**标准定义：**
```c
#define MAX_VERTEX_NUM 100
typedef struct {
    char Vex[MAX_VERTEX_NUM];               // 顶点表
    int Edge[MAX_VERTEX_NUM][MAX_VERTEX_NUM]; // 邻接矩阵，边表
    int vexnum, arcnum;                     // 图的当前顶点数和弧数
} MGraph;
```

#### 2. 邻接表 (Adjacency List)
稍微复杂，考察你对链表数组的掌握。

**标准定义：**
```c
// 边/弧节点
typedef struct ArcNode {
    int adjvex;                 // 该弧所指向的顶点的位置
    struct ArcNode *nextarc;    // 指向下一条弧的指针
    // int weight;              // 若是网，可能还有权重
} ArcNode;

// 顶点节点
typedef struct VNode {
    char data;                  // 顶点信息
    ArcNode *firstarc;          // 指向第一条依附该顶点的弧
} VNode, AdjList[MAX_VERTEX_NUM];

// 整个图
typedef struct {
    AdjList vertices;           // 邻接表
    int vexnum, arcnum;
} ALGraph;
```
**考场使用套路（遍历邻接表某个顶点 `i` 的所有邻居）：**
```c
for (ArcNode *p = G.vertices[i].firstarc; p != NULL; p = p->nextarc) {
    int w = p->adjvex; // w 就是 i 的邻居顶点
    // 对 w 进行处理...
}
```

### 💡 408 手写代码黄金法则：
1. **不要写 `#include` 和 `main` 函数**：除非题目要求，你只需要写出核心函数。
2. **永远记得判空**：链表题上来先看 `if (L == NULL || L->next == NULL)`；树题上来先看 `if (root == NULL)`。这是阅卷老师找得分点的地方。
3. **指针操作画图辅助**：手写代码时，指针极容易飞掉。草稿纸上画 3 个方块连起来，再照着图写 `next` 赋值，绝对不会错。
4. **返回局部变量的指针是大忌**：不要在函数里 `int a[10]; return a;`，这是找死。如果要在函数内创建数组并返回，必须用 `malloc`。
