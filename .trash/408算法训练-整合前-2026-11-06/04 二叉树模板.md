# 需要从下自上传递很多参数  
### 一、复杂度对比：和“正常最优解”有区别吗？

**结论：在时间和空间复杂度上，完全没有任何区别，它本身就是最优解。**

1. **时间复杂度：严格 $O(n)$**
   * 无论是指针传参、全局变量，还是这种返回结构体的写法，遍历框架**本质上都是标准的后序遍历**（左右根）。
   * 每个结点只被访问一次，当前层所有的合并操作（加法、位运算、比较）都是常数时间 $O(1)$。
   * 因此，总时间复杂度为 $O(n)$。

2. **空间复杂度：严格 $O(h)$**
   * 有同学担心“每层都返回一个结构体，会不会额外消耗内存？”——**完全不会**。
   * 在 C 语言的调用栈机制中，`Info` 结构体通常只包含 2~3 个基本数据类型（8～16 字节）。在 x86/ARM 的 ABI 规范下，这么小的结构体甚至直接通过**CPU 寄存器**传递，即便在栈上传递，也只是当前函数栈帧上的固定局部内存（$O(1)$）。
   * 递归最大深度等于树的高度 $h$，系统调用栈的总空间为 $h \times O(1) = O(h)$。
   * **与指针出参对比**：指针出参法每层同样要在栈上传递若干个 8 字节的指针地址，内存开销完全同阶；甚至因为省去了指针解引用的指令，结构体返回在现代编译器下**常数开销往往更小**。

在 408 考场上，为了兼顾各年份编译标准，我们采用**显式声明局部变量后返回**的规范写法（最严谨的 C 风格）。

二叉树基本结点定义统一为：
```c
typedef struct BTNode {
    int data;
    struct BTNode *lchild, *rchild;
} BTNode;
```

#### 题 1：平衡二叉树判断（AVL 平衡检查）
* **规则**：任一结点左右子树高度差 $\le 1$，且左右子树均为平衡二叉树。

```c
// 1. 定义信息体
typedef struct {
    int height;
    int is_bal; // 1 为平衡，0 为不平衡
} BalInfo;

// 2. 自底向上汇报
static BalInfo checkBal(BTNode *root) {
    if (root == NULL) {
        BalInfo empty = {0, 1}; // 空树高0，合法
        return empty;
    }

    BalInfo L = checkBal(root->lchild);
    BalInfo R = checkBal(root->rchild);

    BalInfo cur;
    int diff = L.height - R.height;
    if (diff < 0) diff = -diff; // 求绝对值

    // 左右均平衡且高度差 <= 1
    cur.is_bal = (L.is_bal && R.is_bal && diff <= 1);
    cur.height = (L.height > R.height ? L.height : R.height) + 1;
    return cur;
}

// 3. 题目入口
int IsBalanced(BTNode *root) {
    return checkBal(root).is_bal;
}
```

#### 题 2：满二叉树判断（Perfect Binary Tree）
* **规则**：408 统考定义中，满二叉树所有叶子均在最底层，除叶子外度全为 2。即：**左右子树等高且左右子树自身均满**。

```c
typedef struct {
    int height;
    int is_perf; // 1 为满二叉树，0 不是
} PerfInfo;

static PerfInfo checkPerf(BTNode *root) {
    if (root == NULL) {
        PerfInfo empty = {0, 1}; // 空树高0，算满树
        return empty;
    }

    PerfInfo L = checkPerf(root->lchild);
    PerfInfo R = checkPerf(root->rchild);

    PerfInfo cur;
    // 判定：左右子树都是满的，且高度完全相等
    cur.is_perf = (L.is_perf && R.is_perf && (L.height == R.height));
    cur.height = (L.height > R.height ? L.height : R.height) + 1;
    return cur;
}

int IsPerfect(BTNode *root) {
    return checkPerf(root).is_perf;
}
```

#### 题 3：最大满子树（返回最大满子树的结点数）
* **规则**：求树中所有子树里，形态为“满二叉树”的子树中**结点数最多**的那棵的结点数。
* **信息拆解**：
  * `height`：当前子树的高度；
  * `is_perf`：以当前结点为根的子树本身是否满；
  * `size`：若当前子树满，则其自身结点数；若不满则为 0；
  * `max_size`：以当前结点为根的子树内，出现过的最大满子树结点数（历史峰值）。

```c
typedef struct {
    int height;
    int is_perf;
    int size;     // 当前满子树大小
    int max_size; // 全局最大满子树大小
} MaxPerfInfo;

static MaxPerfInfo getMaxPerf(BTNode *root) {
    if (root == NULL) {
        MaxPerfInfo empty = {0, 1, 0, 0};
        return empty;
    }

    MaxPerfInfo L = getMaxPerf(root->lchild);
    MaxPerfInfo R = getMaxPerf(root->rchild);

    MaxPerfInfo cur;
    // 1. 判断当前子树是否是满二叉树
    cur.is_perf = (L.is_perf && R.is_perf && (L.height == R.height));
    cur.height = (cur.is_perf) ? (L.height + 1) : 0;
    
    // 2. 如果当前子树满，结点数 = 左 + 右 + 根；否则为 0
    cur.size = (cur.is_perf) ? (L.size + R.size + 1) : 0;

    // 3. 汇总最大值：左右子树中的最大值 与 当前子树大小 竞争
    int max_sub = (L.max_size > R.max_size) ? L.max_size : R.max_size;
    cur.max_size = (cur.size > max_sub) ? cur.size : max_sub;

    return cur;
}

int MaxPerfectSubtreeSize(BTNode *root) {
    return getMaxPerf(root).max_size;
}
```

#### 题 4：目标可能缺失的最近公共祖先 (LCA)
* **背景**：常规 LCA 默认目标结点 $p$ 和 $q$ 必定在树中。如果 $p$ 或 $q$ **可能根本不存在于二叉树中**，必须保证两个结点都找到了，才能认定为公共祖先。
* **信息拆解**：
  * 用位掩码 `mask` 汇报存在性：`1` 表示发现 $p$，`2` 表示发现 $q$。$mask = 3$ 说明两结点都已被收集。
  * `ans`：记录最终确定的公共祖先。

```c
typedef struct {
    int mask;          // 0: 都无, 1: 有p, 2: 有q, 3: p和q都有
    BTNode *ans;       // 记录第一次合成 3 的 LCA 结点
} LCAInfo;

static LCAInfo getLCA(BTNode *root, BTNode *p, BTNode *q) {
    if (root == NULL) {
        LCAInfo empty = {0, NULL};
        return empty;
    }

    LCAInfo L = getLCA(root->lchild, p, q);
    LCAInfo R = getLCA(root->rchild, p, q);

    LCAInfo cur;
    cur.mask = L.mask | R.mask;
    if (root == p) cur.mask |= 1; // 标记找到 p
    if (root == q) cur.mask |= 2; // 标记找到 q

    // 如果子树中已经锁定了 LCA，继续向上传递
    if (L.ans != NULL) {
        cur.ans = L.ans;
    } else if (R.ans != NULL) {
        cur.ans = R.ans;
    } else if (cur.mask == 3) {
        // 关键点：本层首次将 mask 凑齐为 3，说明当前结点就是最近公共祖先
        cur.ans = root;
    } else {
        cur.ans = NULL;
    }

    return cur;
}

BTNode* LowestCommonAncestor(BTNode *root, BTNode *p, BTNode *q) {
    LCAInfo res = getLCA(root, p, q);
    // 只有最终 mask 确为 3 时，返回的祖先才有效（排除只找到了一个结点的情况）
    if (res.mask == 3) {
        return res.ans;
    }
    return NULL;
}
```

### 三、复习与应试心法总结

1. **结构体命名的自解释性**：考场上定义形如 `BalInfo`、`PerfInfo` 的结构体，阅卷老师一眼就能看懂你的逻辑分层，印象分直接拉满。
2. **基准退出条件（Base Case）**：空树的单位元一定要严密：
   * 计数类、求和类单位元通常是 `0`；
   * 连乘、连与（合法性 `ok`）的单位元通常是 `1`（空树是合法的平衡树/满树）。
3. **主接口直接解包**：主函数永远只做一件事：`return xxx(root).字段;`，两行搞定，清爽且绝对不会违背题目要求的函数签名。
