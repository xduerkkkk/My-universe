### S01 三类括号匹配

- [ ] 首次：能解释状态并写出代码
- [ ] 间隔复写：不看答案通过自测

**题干**：字符串只含 ()[]{}，长度≤CAP；判断括号配对及嵌套是否正确，空串合法。

**自测**：([]{}) → 1；([)] → 0；)( → 0；空串 → 1。

> [!faq]- 题解与完整核心代码｜尝试后再展开
> **解题步骤**
> 1. 左括号入栈。
> 2. 右括号先查栈非空，再检查栈顶类型。
> 3. 最后栈必须空。
>
> ```c
> int Brackets(const char *s) {
>     char st[CAP]; int top=0;
>     for(int i=0;s[i];i++) {
>         char c=s[i];
>         if(c=='(' || c=='[' || c=='{') st[top++]=c;
>         else {
>             if(!top) return 0;
>             char x=st[--top];
>             if(!((x=='(' && c==')') || (x=='[' && c==']') || (x=='{' && c=='}'))) return 0;
>         }
>     }
>     return top==0;
> }
> ```
>
> **时间 / 额外空间**：O(n) / O(CAP)，按 n 分配为 O(n)。
>
> **易错核对**：最后不能只看从未失配，还要看是否有未闭合左括号。

### S02 相邻相同元素反复消除

- [ ] 首次：能解释状态并写出代码
- [ ] 间隔复写：不看答案通过自测

**题干**：长度 n≤CAP 的整数数组；相邻相等两项消掉，持续至不能消，结果写入 out 返回长度。

**自测**：[1,2,2,1,3] → [3]；[1,1,1] → [1]。

> [!faq]- 题解与完整核心代码｜尝试后再展开
> **解题步骤**
> 1. 栈顶等于新项就弹栈，否则压栈。
> 2. out 直接充当栈。
>
> ```c
> int CancelPairs(int A[],int n,int out[]) {
>     int top=0;
>     for(int i=0;i<n;i++) {
>         if(top && out[top-1]==A[i]) top--;
>         else out[top++]=A[i];
>     }
>     return top;
> }
> ```
>
> **时间 / 额外空间**：O(n) / 除输出数组外 O(1)。
>
> **易错核对**：是连续抵消，不是按所有值出现次数直接保留一次。

### S03 后缀表达式求值

- [ ] 首次：能解释状态并写出代码
- [ ] 间隔复写：不看答案通过自测

**题干**：输入是已分词 Token 数组，isNum 非零为整数，其他为二元 + - * /；n≤CAP。合法运算过程不溢出 long long，且不出现 LLONG_MIN/-1。成功写 out 返回1，非法返回0。

**自测**：token 序列 8 3 - 2 * → 10；3 0 / → 失败；1 2 → 失败。

> [!faq]- 题解与完整核心代码｜尝试后再展开
> **解题步骤**
> 1. 数字压栈。
> 2. 运算弹出右操作数 b 再左操作数 a。
> 3. 最终只能剩一个值。
>
> ```c
> typedef struct { int isNum; long long value; char op; } Token;
> int Postfix(Token a[],int n,long long *out) {
>     long long st[CAP]; int top=0;
>     for(int i=0;i<n;i++) {
>         if(a[i].isNum) { st[top++]=a[i].value; continue; }
>         if(top<2) return 0;
>         long long b=st[--top],x=st[--top],v;
>         switch(a[i].op) {
>             case '+': v=x+b; break;
>             case '-': v=x-b; break;
>             case '*': v=x*b; break;
>             case '/': if(b==0) return 0; v=x/b; break;
>             default: return 0;
>         }
>         st[top++]=v;
>     }
>     if(top!=1) return 0;
>     *out=st[0]; return 1;
> }
> ```
>
> **时间 / 额外空间**：O(n) / O(CAP)，按 n 分配为 O(n)。
>
> **易错核对**：不是字符逐个当数字，支持多位和负数 token；减法除法不能把左右弹反。

### S04 非递归中序遍历

- [ ] 首次：能解释状态并写出代码
- [ ] 间隔复写：不看答案通过自测

**题干**：树结点数≤CAP；用显式栈输出中序值至 out，返回长度。

**自测**：根1、左2右3 → [2,1,3]；纯右链 → 从根到尾；空 → 长度0。

> [!faq]- 题解与完整核心代码｜尝试后再展开
> **解题步骤**
> 1. 一路向左压栈。
> 2. 弹出访问，再转向该结点右子树。
> 3. 循环条件是 p非空或栈非空。
>
> ```c
> int IterInorder(BTNode *p,int out[]) {
>     BTNode *st[CAP]; int top=0,k=0;
>     while(p || top) {
>         while(p) { st[top++]=p; p=p->lchild; }
>         p=st[--top]; out[k++]=p->data;
>         p=p->rchild;
>     }
>     return k;
> }
> ```
>
> **时间 / 额外空间**：O(n) / O(CAP)，动态按高度配置则 O(h)。
>
> **易错核对**：while(p) 单独作为外层条件会漏掉栈里还没访问的祖先。

### S05 右侧第一个更大元素

- [ ] 首次：能解释状态并写出代码
- [ ] 间隔复写：不看答案通过自测

**题干**：n≤CAP；对每个元素求其右侧第一个严格更大元素的下标，不存在 -1。

**自测**：[2,1,2,4] → [3,2,3,-1]；[2,2] → [-1,-1]。

> [!faq]- 题解与完整核心代码｜尝试后再展开
> **解题步骤**
> 1. 维护值非递增的待解决下标栈。
> 2. 新值严格大于栈顶值时为栈顶解答。
>
> ```c
> void NextGreater(int A[],int n,int ans[]) {
>     int st[CAP],top=0;
>     for(int i=0;i<n;i++) ans[i]=-1;
>     for(int i=0;i<n;i++) {
>         while(top && A[i]>A[st[top-1]]) ans[st[--top]]=i;
>         st[top++]=i;
>     }
> }
> ```
>
> **时间 / 额外空间**：O(n) / O(CAP)，按 n 分配为 O(n)。
>
> **易错核对**：“更大”严格 >；每个下标只进出栈一次。

### S06 循环数组下一个更大元素

- [ ] 首次：能解释状态并写出代码
- [ ] 间隔复写：不看答案通过自测

**题干**：循环数组 n≤CAP，每项找循环向右的第一个严格更大值下标，无解 -1。空数组无输出。

**自测**：[1,2,1] → [1,-1,1]；[3] → [-1]；n=0 不会进入循环。

> [!faq]- 题解与完整核心代码｜尝试后再展开
> **解题步骤**
> 1. 扫两轮。
> 2. 第一轮压入每个下标，第二轮只解答，不重复入栈。
>
> ```c
> void CircularGreater(int A[],int n,int ans[]) {
>     int st[CAP],top=0;
>     for(int i=0;i<n;i++) ans[i]=-1;
>     for(int k=0;k<2*n;k++) {
>         int i=k%n;
>         while(top && A[i]>A[st[top-1]]) ans[st[--top]]=i;
>         if(k<n) st[top++]=i;
>     }
> }
> ```
>
> **时间 / 额外空间**：O(n) / O(CAP)，按 n 分配为 O(n)。
>
> **易错核对**：不要第二轮继续入栈造成重复/越界；不能把自己当严格更大。
