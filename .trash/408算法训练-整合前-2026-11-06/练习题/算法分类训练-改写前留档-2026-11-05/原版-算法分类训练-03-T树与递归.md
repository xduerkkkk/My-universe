### T01 树高与平衡二叉树

- [ ] 首次：能解释状态并写出代码
- [ ] 间隔复写：不看答案通过自测

**题干**：求树高，并判断每个结点左右子树高差是否≤1。

**自测**：空树 → 高0、平衡；三个结点单链 → 高3、不平衡。

> [!faq]- 题解与完整核心代码｜尝试后再展开
> **解题步骤**
> 1. 后序。
> 2. 高度函数返回 -1 代表已经不平衡，正常高度为非负，不冲突。
>
> ```c
> int Height(BTNode *p) {
>     if(!p) return 0;
>     int l=Height(p->lchild),r=Height(p->rchild);
>     return (l>r?l:r)+1;
> }
> int BalancedHeight(BTNode *p) {
>     if(!p) return 0;
>     int l=BalancedHeight(p->lchild);
>     if(l<0) return -1;
>     int r=BalancedHeight(p->rchild);
>     if(r<0 || l-r>1 || r-l>1) return -1;
>     return (l>r?l:r)+1;
> }
> int IsBalanced(BTNode *p) { return BalancedHeight(p)>=0; }
> ```
>
> **时间 / 额外空间**：每个函数 O(n) / O(h) 递归栈。
>
> **易错核对**：不要每层再次 Height(left/right)，会重复遍历到 O(n²)。

### T02 超均结点计数

- [ ] 首次：能解释状态并写出代码
- [ ] 间隔复写：不看答案通过自测

**题干**：结点值严格大于其所有真后代值的平均数时计数；叶结点不计。整数和、乘积能用 long long 表示。

**自测**：根5、孩子1和3 → ans=1；单结点 → 0；根2、孩子1和3 → 0。

> [!faq]- 题解与完整核心代码｜尝试后再展开
> **解题步骤**
> 1. 后序返回子树 sum,count,answer。
> 2. 父结点只用左右汇总的真后代，不能把自己放进平均值。
>
> ```c
> typedef struct { long long sum,count,ans; } MeanInfo;
> MeanInfo AboveDescMean(BTNode *p) {
>     if(!p) return (MeanInfo){0,0,0};
>     MeanInfo l=AboveDescMean(p->lchild),r=AboveDescMean(p->rchild);
>     long long s=l.sum+r.sum,c=l.count+r.count;
>     long long add=c>0 && (long long)p->data*c>s;
>     return (MeanInfo){s+p->data,c+1,l.ans+r.ans+add};
> }
> ```
>
> **时间 / 额外空间**：O(n) / O(h)。
>
> **易错核对**：“后代”排除自己，叶结点不做除零。

### T03 满二叉树判断

- [ ] 首次：能解释状态并写出代码
- [ ] 间隔复写：不看答案通过自测

**题干**：满二叉树定义为每层结点数达到最大，亦称 perfect binary tree；空树按满处理。

**自测**：三层仅左侧有孙结点的严格二叉树 → 不满；根及两个叶子 → 满。

> [!faq]- 题解与完整核心代码｜尝试后再展开
> **解题步骤**
> 1. 后序同时返回高度与满性。
> 2. 左右都满且高度相等，当前才满。
>
> ```c
> typedef struct { int h,ok; } PerfectInfo;
> PerfectInfo Perfect(BTNode *p) {
>     if(!p) return (PerfectInfo){0,1};
>     PerfectInfo l=Perfect(p->lchild),r=Perfect(p->rchild);
>     return (PerfectInfo){(l.h>r.h?l.h:r.h)+1,l.ok && r.ok && l.h==r.h};
> }
> ```
>
> **时间 / 额外空间**：O(n) / O(h)。
>
> **易错核对**：不要混淆“每结点0或2个孩子”的严格二叉树与本题满二叉树。

### T04 孩子兄弟表示法树的最大度

- [ ] 首次：能解释状态并写出代码
- [ ] 间隔复写：不看答案通过自测

**题干**：BTNode 的 lchild 解释为第一个孩子、rchild 为下一个兄弟；root 是一棵树的根且无兄弟。求最大孩子数。

**自测**：根有三个孩子，其中一个有四个孩子 → 4；单根 → 0。

> [!faq]- 题解与完整核心代码｜尝试后再展开
> **解题步骤**
> 1. 每个父结点沿孩子兄弟链数孩子。
> 2. 对每个孩子递归处理其子树，保证每条孩子链只扫描常数次。
>
> ```c
> int MaxDegree(BTNode *root) {
>     if(!root) return 0;
>     int count=0,best=0;
>     for(BTNode *c=root->lchild;c;c=c->rchild) {
>         count++;
>         int d=MaxDegree(c); if(d>best) best=d;
>     }
>     return count>best?count:best;
> }
> ```
>
> **时间 / 额外空间**：O(n) / O(原树高度)。
>
> **易错核对**：本题 rchild 不是右子树；不能直接套二叉树左右递归计度。

### T05 所有结点深度之和与带权路径长度

- [ ] 首次：能解释状态并写出代码
- [ ] 间隔复写：不看答案通过自测

**题干**：根深度0。分别求所有结点深度之和，以及仅叶结点的 data×depth 之和（WPL）。

**自测**：根9、左叶2、右叶3 → DepthSum(root,0)=2，WPL(root,0)=5；单结点 → 都0。

> [!faq]- 题解与完整核心代码｜尝试后再展开
> **解题步骤**
> 1. 深度由父传子。
> 2. 深度和每个结点都贡献，WPL 只有叶子贡献。
>
> ```c
> long long DepthSum(BTNode *p,int d) {
>     if(!p) return 0;
>     return d+DepthSum(p->lchild,d+1)+DepthSum(p->rchild,d+1);
> }
> long long WPL(BTNode *p,int d) {
>     if(!p) return 0;
>     if(!p->lchild && !p->rchild) return (long long)p->data*d;
>     return WPL(p->lchild,d+1)+WPL(p->rchild,d+1);
> }
> ```
>
> **时间 / 额外空间**：O(n) / O(h)。
>
> **易错核对**：深度根取0；若原题按层数计且根为1，要改变入口而不是默默套用。

### T06 打印根到叶路径

- [ ] 首次：能解释状态并写出代码
- [ ] 间隔复写：不看答案通过自测

**题干**：逐行输出每条根到叶路径。树高≤CAP，path 为调用者提供的 CAP 长数组。

**自测**：根1、叶2和3 → 两行 1 2、1 3；空树无输出。

> [!faq]- 题解与完整核心代码｜尝试后再展开
> **解题步骤**
> 1. 进入结点写 path[len]。
> 2. 递归参数 len 按值传递，自然回退，无须全局栈指针。
>
> ```c
> void PrintPaths(BTNode *p,int path[],int len) {
>     if(!p) return;
>     path[len++]=p->data;
>     if(!p->lchild && !p->rchild) {
>         for(int i=0;i<len;i++) printf("%d%c",path[i],i+1==len?'\n':' ');
>     } else {
>         PrintPaths(p->lchild,path,len);
>         PrintPaths(p->rchild,path,len);
>     }
> }
> ```
>
> **时间 / 额外空间**：O(n+所有输出路径长度之和) / O(h) 递归栈，另需路径缓冲区。
>
> **易错核对**：调用 PrintPaths(root,path,0)；不能把输出成本省成严格 O(n)。

**自测**：根1、左2右3 → 先[1,2,3]，中[2,1,3]，后[2,3,1]。

> [!faq]- 题解与完整核心代码｜尝试后再展开
> **解题步骤**
> 1. 同一递归骨架，只移动 visit 的位置。先序先处理根，中序在两边之间，后序最后处理根。
>
> ```c
> void Preorder(BTNode *p) {
>     if(!p) return;
>     printf("%d ",p->data); Preorder(p->lchild); Preorder(p->rchild);
> }
> void Inorder(BTNode *p) {
>     if(!p) return;
>     Inorder(p->lchild); printf("%d ",p->data); Inorder(p->rchild);
> }
> void Postorder(BTNode *p) {

>     Postorder(p->lchild); Postorder(p->rchild); printf("%d ",p->data);

> ```
>
> **时间 / 额外空间**：各 O(n) / O(h) 递归栈。
>
> **易错核对**：递归左右顺序固定，不是交换左右就能把先序变中序。

### T08 删除原树全部叶结点

- [ ] 首次：能解释状态并写出代码

**题干**：只删除函数开始时的叶结点，释放空间，返回新根；新形成的叶子本轮不再删。

**自测**：根1→左2→左3 → 删除3，留下1和2；单结点 → NULL。

> [!faq]- 题解与完整核心代码｜尝试后再展开
> **解题步骤**
> 1. 先判当前是否原叶子。
> 2. 否则递归改写左右孩子。
>
> ```c
> BTNode *DeleteLeaves(BTNode *p) {
>     if(!p) return NULL;
>     if(!p->lchild && !p->rchild) { free(p); return NULL; }

### T09 收缩所有单分支结点

- [ ] 首次：能解释状态并写出代码

**题干**：删除恰有一个孩子的结点，用其孩子代替；保留叶结点和双分支结点，返回新根。

**自测**：1→左2→右3 → 只剩3；根和两个叶子 → 原样。

> 1. 先递归收缩孩子。
> 2. 当前单分支就保存唯一孩子、释放当前、返回孩子。

> ```c
> BTNode *Contract(BTNode *p) {

>         BTNode *child=p->lchild?p->lchild:p->rchild;

> **时间 / 额外空间**：O(n) / O(h)。

### T10 判断严格 BST

- [ ] 首次：能解释状态并写出代码
- [ ] 间隔复写：不看答案通过自测

**题干**：所有值可为任意 int，包括 INT_MIN；严格 BST 不允许重复键。

**自测**：根2、左1右3 → 1；根2、左2 → 0；单结点 INT_MIN → 1。

> [!faq]- 题解与完整核心代码｜尝试后再展开
> **解题步骤**
> 1. 中序递增。
> 2. 用 has 标志区分“还没有前驱”，每次调用重新初始化。
>
> ```c
> int CheckInorder(BTNode *p,int *has,int *pre) {
>     if(!p) return 1;
>     if(!CheckInorder(p->lchild,has,pre)) return 0;
>     if(*has && p->data<=*pre) return 0;
>     *pre=p->data; *has=1;
>     return CheckInorder(p->rchild,has,pre);
> }
> int IsBST(BTNode *root) { int has=0,pre=0; return CheckInorder(root,&has,&pre); }
> ```
>
> **时间 / 额外空间**：O(n) / O(h)。
>
> **易错核对**：不能仅比较父子；pre=INT_MIN 作为唯一哨兵会误伤合法最小值。

### T11 双树相等与镜像

- [ ] 首次：能解释状态并写出代码

**题干**：判断两树结构及对应值相等；另写函数判断互为镜像。

**自测**：同一非对称树与自己 → SameTree真、MirrorTree假；两空树 → 都真。

> [!faq]- 题解与完整核心代码｜尝试后再展开
> **解题步骤**
> 1. 同时为空成功，只空一个失败。
> 2. 相等同侧配对，镜像交叉配对。
>
> ```c
> int SameTree(BTNode *a,BTNode *b) {
>     if(!a || !b) return a==b;
>     return a->data==b->data && SameTree(a->lchild,b->lchild) && SameTree(a->rchild,b->rchild);
> }
> int MirrorTree(BTNode *a,BTNode *b) {
>     if(!a || !b) return a==b;
>     return a->data==b->data && MirrorTree(a->lchild,b->rchild) && MirrorTree(a->rchild,b->lchild);
> }
> ```
>
> **时间 / 额外空间**：最坏 O(min(n,m)+1) / O(min(h1,h2)+1)。
>
> **易错核对**：只比较遍历值序列不足以判断结构。

### T12 层序遍历、最大宽度与繁茂程度

- [ ] 首次：能解释状态并写出代码
- [ ] 间隔复写：不看答案通过自测

**题干**：输出层序到 out；width 输出同层实际结点数最大值；flourish 输出树高×width，树高按层数。结点数≤CAP。

**自测**：根1、左2右3、2的左4 → 层序[1,2,3,4]，宽2，高3，繁茂6。

> [!faq]- 题解与完整核心代码｜尝试后再展开
> **解题步骤**
> 1. 队列保存结点。
> 2. 每层开始用当前队长冻结本层大小，新入队属于下一层。
>
> ```c
> int LevelStats(BTNode *root,int out[],int *width,long long *flourish) {
>     BTNode *q[CAP]; int f=0,r=0,k=0,h=0;
>     *width=0; *flourish=0;
>     if(root) q[r++]=root;
>     while(f<r) {
>         int cnt=r-f; h++;
>         if(cnt>*width) *width=cnt;
>         for(int i=0;i<cnt;i++) {
>             BTNode *p=q[f++]; out[k++]=p->data;
>             if(p->lchild) q[r++]=p->lchild;

>         start[levels++]=f;

**自测**：根只有左孩子 → 真；只有右孩子 → 假；空 → 真。

> [!faq]- 题解与完整核心代码｜尝试后再展开
> **解题步骤**
> 1. 按左右孩子顺序检查。
> 2. 一旦遇到空孩子，后续任何非空孩子都非法。
>
> ```c
> int Complete(BTNode *root) {
>     BTNode *q[CAP]; int f=0,r=0,gap=0;
>     if(root) q[r++]=root;
>     while(f<r) {
>         BTNode *p=q[f++],*c[2]={p->lchild,p->rchild};
>         for(int i=0;i<2;i++) {
>             if(!c[i]) gap=1;
>             else { if(gap) return 0; q[r++]=c[i]; }
>         }
>     }
>     return 1;
> }
> ```
>
> **时间 / 额外空间**：O(n) / O(CAP)，按 n 分配为 O(n)。
>
> **易错核对**：遇空后不能再出现非空，包括跨父结点的空位。
