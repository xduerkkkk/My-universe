## 本专题公共积木

相关题目的完整辅助函数放在这里；使用时必须一起默写，不能只写一行函数调用。

> [!faq]- 公共积木｜第一次学时可打开；复写时遮住
> ```c
> LNode *ReverseList(LNode *p) {
>     LNode *pre=NULL;
>     while(p) { LNode *next=p->next; p->next=pre; pre=p; p=next; }
>     return pre;
> }
> LNode *MergeLists(LNode *a,LNode *b) {
>     LNode dummy={0,NULL},*tail=&dummy;
>     while(a && b) {
>         LNode *p;
>         if(a->data<=b->data) { p=a; a=a->next; }
>         else { p=b; b=b->next; }
>         tail->next=p; tail=p;
>     }
>     tail->next=a?a:b;
>     return dummy.next;
> }
> LNode *FirstHalfTail(LNode *h) {
>     if(!h) return NULL;
>     LNode *s=h,*f=h;
>     while(f->next && f->next->next) { s=s->next; f=f->next->next; }
>     return s;
> }
> ```

### L01 单链表原地逆置

- [ ] 首次：能解释状态并写出代码
- [ ] 间隔复写：不看答案通过自测

**题干**：返回逆置后的首结点，不能申请新数据结点。

**自测**：[] → []；[1] → [1]；[1,2,3] → [3,2,1]。

> [!faq]- 题解与完整核心代码｜尝试后再展开
> **解题步骤**
> 1. 保存 next → 改 next → 推进 pre,p。下方展开完整实现。
> 2. 本页公共积木 ReverseList 是同一算法，供组合题复用。
>
> ```c
> LNode *ReverseExercise(LNode *head) {
>     LNode *pre=NULL,*p=head;
>     while(p) {
>         LNode *next=p->next;
>         p->next=pre;
>         pre=p; p=next;
>     }
>     return pre;
> }
> ```
>
> **时间 / 额外空间**：O(n) / O(1)。
>
> **易错核对**：公共积木必须会闭卷写；不把这一行调用当作会逆置。

### L02 稳定归并两个有序链表

- [ ] 首次：能解释状态并写出代码
- [ ] 间隔复写：不看答案通过自测

**题干**：两条非递减链表，没有共享结点；复用结点返回非递减结果，相等时先取 a。

**自测**：[1,3]+[1,2] → [1(a),1(b),2,3]；空+空 → 空。

> [!faq]- 题解与完整核心代码｜尝试后再展开
> **解题步骤**
> 1. 局部哨兵+尾插。
> 2. 下方展开完整实现。
> 3. 公共积木 MergeLists 供后续排序题复用。
>
> ```c
> LNode *MergeExercise(LNode *a,LNode *b) {
>     LNode dummy={0,NULL},*tail=&dummy;
>     while(a && b) {
>         if(a->data<=b->data) { tail->next=a; a=a->next; }
>         else { tail->next=b; b=b->next; }

>     }
>     tail->next=a?a:b;

>
> **易错核对**：调用后原两链不再是独立所有者；不能释放局部哨兵。

### L03 有序链表集合并集

- [ ] 首次：能解释状态并写出代码
- [ ] 间隔复写：不看答案通过自测

**题干**：每条输入链内部可重复；复用结点，结果每种值只保留一个，释放其余结点。

**自测**：[1,1,3]+[1,2,2,3] → [1,2,3]，释放4个；空+[2,2] → [2]。

> [!faq]- 题解与完整核心代码｜尝试后再展开
> **解题步骤**
> 1. 每轮取较小首结点并先推进输入指针。
> 2. 与输出尾值相同则释放，否则尾插。
>
> ```c
> LNode *UnionLists(LNode *a,LNode *b) {
>     LNode dummy={0,NULL},*t=&dummy;
>     while(a || b) {
>         LNode *p;
>         if(!b || (a && a->data<=b->data)) { p=a; a=a->next; }
>         else { p=b; b=b->next; }
>         p->next=NULL;
>         if(t==&dummy || t->data!=p->data) { t->next=p; t=p; }
>         else free(p);
>     }
>     return dummy.next;
> }
> ```
>
> **时间 / 额外空间**：O(m+n) / O(1)。
>
> **易错核对**：一侧耗尽后仍须去重；free 后不能再读 next。

### L04 链表插入排序

- [ ] 首次：能解释状态并写出代码
- [ ] 间隔复写：不看答案通过自测

**题干**：复用结点稳定升序排序。

**自测**：[3,1,2,1] → [1,1,2,3]，两个1的相对顺序不变。

> [!faq]- 题解与完整核心代码｜尝试后再展开
> **解题步骤**
> 1. 每次取未排序首结点，扫描已排序链。
> 2. 越过所有≤当前值的结点后插入。
>
> ```c
> LNode *ListInsertionSort(LNode *head) {
>     LNode dummy={0,NULL};
>     while(head) {
>         LNode *p=head; head=head->next;
>         LNode *pre=&dummy;
>         while(pre->next && pre->next->data<=p->data) pre=pre->next;
>         p->next=pre->next; pre->next=p;
>     }
>     return dummy.next;
> }
> ```
>
> **时间 / 额外空间**：最坏 O(n²) / O(1)。
>
> **易错核对**：先保存未排序后继；稳定插入应越过相等项。

### L06 链表回文并恢复原表

- [ ] 首次：能解释状态并写出代码
- [ ] 间隔复写：不看答案通过自测

**题干**：判断数据序列是否回文；O(1) 额外空间，返回前恢复原链。

**自测**：[1,2,2,1] → 1；[1,2,3] → 0；检查返回后所有 next 与原表一致。

> [!faq]- 题解与完整核心代码｜尝试后再展开
> **解题步骤**
> 1. 找前半尾，逆置后半并比较。
> 2. 无论是否不匹配，都先恢复再返回。
>
> ```c
> int Palindrome(LNode *head) {
>     if(!head || !head->next) return 1;
>     LNode *mid=FirstHalfTail(head);
>     LNode *b=ReverseList(mid->next);
>     mid->next=b;
>     LNode *p=head,*q=b; int ok=1;
>     while(q) {
>         if(p->data!=q->data) { ok=0; break; }
>         p=p->next; q=q->next;
>     }
>     mid->next=ReverseList(b);
>     return ok;
> }
> ```
>
> **时间 / 额外空间**：O(n) / O(1)。
>
> **易错核对**：不能发现不等立即 return，漏掉恢复。

### L07 首尾交替重排

- [ ] 首次：能解释状态并写出代码
- [ ] 间隔复写：不看答案通过自测

**自测**：[1,2,3,4,5] → [1,5,2,4,3]；[1,2] 不变；不能成环。

> 2. 穿插前保存两边后继。

### L09 两个链表的第一个公共结点

- [ ] 首次：能解释状态并写出代码
- [ ] 间隔复写：不看答案通过自测

**题干**：两条无环单链表可能共享尾部；按地址找第一个公共结点，不修改、不释放。

**自测**：两条不同结点但值相同 → NULL；共享尾 [7,8] → 返回结点7的地址；一表空 → NULL。

> [!faq]- 题解与完整核心代码｜尝试后再展开
> **解题步骤**
> 1. 两个指针到尾后切换到另一表头。
> 2. 各走过相同总长度。
>
> ```c
> LNode *Intersection(LNode *a,LNode *b) {
>     LNode *p=a,*q=b;
>     while(p!=q) { p=p?p->next:b; q=q?q->next:a; }
>     return p;
> }
> ```
>
> **时间 / 额外空间**：O(m+n) / O(1)。
>
> **易错核对**：相等指地址相等，不是 data 相等。

### L12 按结点编号取模重组

- [ ] 首次：能解释状态并写出代码
- [ ] 间隔复写：不看答案通过自测

**题干**：本题特例：带头结点 L；有效结点编号从1开始，按 id%k 升序稳定分组。1≤k≤CAP，结点数可大于CAP，不新建数据结点。

**自测**：L→[4,1,5,2,3], k=3 → [5,4,2,1,3]；k=1 → 不变。

> [!faq]- 题解与完整核心代码｜尝试后再展开
> **解题步骤**
> 1. k 个头尾桶。
> 2. 先保存后继、断链，再按编号余数尾插。
> 3. 最后从余数0到k-1收集。
>
> ```c
> void ModReorder(LNode *L,int k) {
>     LNode *head[CAP]={0},*tail[CAP]={0};
>     if(!L) return;
>     LNode *p=L->next;
>     int rem=1%k;
>     while(p) {
>         LNode *next=p->next; p->next=NULL;
>         if(!head[rem]) head[rem]=p; else tail[rem]->next=p;
>         tail[rem]=p; p=next; rem=(rem+1)%k;
>     }
>     LNode *t=L; t->next=NULL;
>     for(int r=0;r<k;r++) if(head[r]) { t->next=head[r]; t=tail[r]; }
> }
> ```
>
> **时间 / 额外空间**：O(n+k+CAP) / O(CAP)固定桶；按k分配则 O(n+k) / O(k)。
>
> **易错核对**：分组依据是位置编号，不是 data%k；本题保留原头结点。

**题干**：删除原链表中数据值严格大于原表平均值的结点并释放；空表返回空，最终和及乘积可用 long long 表示。

**自测**：[1,2,6] → [1,2]；[-3,-1] → [-3]；空表 → 空。

> [!faq]- 题解与完整核心代码｜尝试后再展开
> **解题步骤**
> 1. 先统计原总和与长度。
> 2. 第二遍用 data*n>sum 避免浮点，哨兵统一删除首结点。
>
> ```c
> LNode *DeleteAboveMean(LNode *head) {
>     long long sum=0,n=0;
>     for(LNode *p=head;p;p=p->next) { sum+=p->data; n++; }
>     LNode dummy={0,head},*pre=&dummy,*p=head;
>     while(p) {
>         if((long long)p->data*n>sum) {
>             pre->next=p->next; free(p); p=pre->next;
>         } else { pre=p; p=p->next; }
>     }
>     return dummy.next;
> }
> ```
>
> **时间 / 额外空间**：O(n) / O(1)。
>
> **易错核对**：删除后 pre 不前进；平均值取原表，不随删除重算。
