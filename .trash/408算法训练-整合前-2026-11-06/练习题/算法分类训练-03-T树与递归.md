### T05 所有结点深度之和与带权路径长度

- [ ] 首次：能解释状态并写出代码
- [ ] 间隔复写：不看答案通过自测

**定位**：主练｜2014·41：WPL；所有结点深度和仅用于对照概念。

**题干**：二叉树根深度为0，叶结点 data 为权值。求 WPL=Σ(叶权×叶深度)；另写所有结点深度之和作区分。空树返回0。

**自测**：根带两个叶子，权2和3 → WPL=5；单结点 → 0；根的data无论多大，都不计入WPL。

> [!faq]- 题解与完整核心代码｜先说状态，再核对
> **变量存什么**：`depth` 是当前结点深度，沿递归参数向下传；返回值是当前子树的总贡献。
>
> **解题步骤**
> 1. 空结点贡献0。
> 2. 叶结点贡献 data×depth，注意根若也是叶子，其深度仍为0。
> 3. 非叶结点不贡献自己的权值，只返回左右子树贡献和；孩子深度加1。
> 4. 对比 DepthSum：它是每个结点都贡献 depth，不是只有叶子。
>
> **手推一遍**：根下左叶2，右孩子下有叶3和4：WPL=2×1+3×2+4×2=16；右侧内部结点的data不参加求和。
>
> ```cpp
> long long WPL(BTNode *p, int depth) {
>     if (p == NULL) return 0;
>     if (p->lchild == NULL && p->rchild == NULL) {
>         return (long long)p->data * depth;
>     }
>     return WPL(p->lchild, depth + 1) + WPL(p->rchild, depth + 1);
> }
>
> long long DepthSum(BTNode *p, int depth) {
>     if (p == NULL) return 0;
>     return depth + DepthSum(p->lchild, depth + 1)
>                  + DepthSum(p->rchild, depth + 1);
> }
> // 调用：WPL(root, 0)；DepthSum(root, 0)
> ```
>
> **时间 / 额外空间**：O(n) / O(h)，递归栈计入辅助空间。
>
> **易错核对**：只有叶子参与 WPL；根从深度0开始。不要把“树高按层数从1算”套到路径长度。

### T16 表达式树转中缀表达式

- [ ] 首次：能解释状态并写出代码
- [ ] 间隔复写：不看答案通过自测

**定位**：主练｜2017·41：按用户题型改写；用充分括号保留运算结构。

**题干**：表达式树的叶子是单字符操作数，非叶是二元运算符且恰有两个孩子。输出等价中缀表达式：除整棵树的根表达式外，每个非叶子表达式都加一对括号；不要求最少括号。

**自测**：根*，左子树a+b，右叶c → (a+b)*c；根-，右子树b-c、左叶a → a-(b-c)；单叶a → a。

> [!faq]- 题解与完整核心代码｜先说状态，再核对
> **变量存什么**：`depth` 标识是否为整棵树的根：depth=0 的根不加最外层括号，其他非叶结点加。
>
> **解题步骤**
> 1. 中序输出是“左表达式、运算符、右表达式”，但只中序会丢失运算结合关系。
> 2. 进入非根的非叶结点时，先输出左括号。
> 3. 递归左子树，输出当前字符，再递归右子树。
> 4. 离开同一个非叶结点时输出右括号；叶子不加括号。
>
> **手推一遍**：a-(b-c)：根“-”不加最外层括号；右孩子也是“-”，进入时先输出“(”，中序输出b-c，退出时输出“)”。
>
> ```cpp
> typedef struct ExprNode {
>     char data;
>     struct ExprNode *lchild, *rchild;
> } ExprNode;
>
> void PrintInfix(ExprNode *p, int depth) {
>     if (p == NULL) return;
>     bool needBrackets = depth > 0 && p->lchild != NULL;
>     if (needBrackets) printf("(");
>     PrintInfix(p->lchild, depth + 1);
>     printf("%c", p->data);
>     PrintInfix(p->rchild, depth + 1);
>     if (needBrackets) printf(")");
> }
>
> void ExpressionToInfix(ExprNode *root) {
>     PrintInfix(root, 0);
> }
> ```
>
> **时间 / 额外空间**：O(n) / O(h)，输出长度也为 O(n)。
>
> **易错核对**：本题非叶恰有两个孩子，所以可用 lchild 判断非叶。不是看到乘除才加括号；减法、除法的右子树尤其不能随便省括号。

### T17 顺序存储二叉树是否为 BST

- [ ] 首次：能解释状态并写出代码
- [ ] 间隔复写：不看答案通过自测

**定位**：主练｜2022·41：按用户题型改写；训练的数组与空标记规则明确如下。

**题干**：数组 A[0..n-1] 顺序存储一棵合法二叉树：根下标0，左右孩子2i+1、2i+2，-1为空；非空键均为非负整数，非空结点祖先必须非空。判断是否为严格 BST，不允许重复键。空树为真。

**自测**：[2,1,3] → 真；[10,5,15,-1,-1,6,20] → 假；[2,2,3] → 假；[-1]或[] → 真。

> [!faq]- 题解与完整核心代码｜先说状态，再核对
> **变量存什么**：`previous` 是中序中上一个访问的键；初值-1仅因本训练所有合法键≥0，不是适用于任意int的通用哨兵。
>
> **解题步骤**
> 1. 用下标递归代替指针递归，越界或空槽直接成功返回。
> 2. 先检查左子树，再比较当前键与上一个中序键。
> 3. 当前键必须严格更大；更新 previous 后检查右子树。
> 4. 使用引用参数把同一份 previous 沿整次中序遍历共享；原题若用不同空标记，先按题意改接口。
>
> **手推一遍**：[10,5,15,-1,-1,6,20] 的非空中序为5,10,6,15,20；访问6时发现6≤10，立即判假。
>
> ```cpp
> bool CheckArrayBST(const int A[], int n, int i, int &previous) {
>     if (i >= n || A[i] == -1) return true;
>     if (!CheckArrayBST(A, n, 2 * i + 1, previous)) return false;
>     if (A[i] <= previous) return false;
>     previous = A[i];
>     return CheckArrayBST(A, n, 2 * i + 2, previous);
> }
>
> bool IsArrayBST(const int A[], int n) {
>     int previous = -1;
>     return CheckArrayBST(A, n, 0, previous);
> }
> ```
>
> **时间 / 额外空间**：O(n) 时间上界 / O(h) 递归栈；n是存储数组长度，若空槽很多不一定访问每个槽。
>
> **易错核对**：只比较父子不够：例中6虽是15的左孩子，却落在根10右子树中，仍然违法。不要把数组下标当键比较。孩子下标运算假定不溢出int。

### T18 BST 最近键值

- [ ] 首次：能解释状态并写出代码
- [ ] 间隔复写：不看答案通过自测

**定位**：主练｜2026·41：仅依据用户提供的题型标题；下面是明示并列规则的训练版，不冒充原题全文。

**题干**：给定严格 BST 与整数 target，返回键值和 target 的绝对差最小的结点；相同差时取较小键，空树返回 NULL。不改变树，要求 O(h) 时间、O(1) 辅助空间。

**自测**：BST键{2,4,6,8,10}，target=7 → 键6；target=9 → 键8；恰好命中直接返回；空树→NULL。

> [!faq]- 题解与完整核心代码｜先说状态，再核对
> **变量存什么**：`best` 为当前最优结点；`bestDifference` 为最小绝对差；`p` 沿普通 BST 查找路径前进。
>
> **解题步骤**
> 1. 空树直接返回 NULL，否则先用根作为候选。
> 2. 每到一个结点计算绝对差，必要时更新最优候选；并列时按本训练取较小键。
> 3. target 小于当前键则走左；大于则走右；相等已经是最优，停止。
> 4. 被舍弃一侧的键只会离 target 更远或不优于当前结点，所以不用遍历整棵树。
>
> **手推一遍**：根8，左子树根4、其右孩子6，target=7：候选8差1；走到4不更优；走到6差1，依较小键规则把候选改为6。
>
> ```cpp
> BTNode *ClosestBST(BTNode *root, int target) {
>     if (root == NULL) return NULL;
>     BTNode *best = root;
>     long long bestDifference = (long long)root->data - target;
>     if (bestDifference < 0) bestDifference = -bestDifference;
>     BTNode *p = root;
>     while (p != NULL) {
>         long long difference = (long long)p->data - target;
>         if (difference < 0) difference = -difference;
>         if (difference < bestDifference ||
>             (difference == bestDifference && p->data < best->data)) {
>             best = p;
>             bestDifference = difference;
>         }
>         if (target == p->data) break;
>         if (target < p->data) p = p->lchild;
>         else p = p->rchild;
>     }
>     return best;
> }
> ```
>
> **时间 / 额外空间**：O(h) / O(1)，平衡时 h=O(log n)，退化时可为 O(n)。
>
> **易错核对**：不能因为叫BST就无条件写 O(log n)；差值先转 long long。若真实原题的并列规则/返回形式不同，按原题调整，不能据标题断定一致。

### T01 树高与平衡二叉树

- [ ] 首次：能解释状态并写出代码
- [ ] 间隔复写：不看答案通过自测

**定位**：基础积木｜递归返回值。

**题干**：空树高度0，叶结点高度1。先求树高，再判断任意结点的左右子树高差是否≤1；后者要求 O(n)。

**自测**：空树高度0且平衡；单结点高度1；连续3个左孩子形成的链不平衡。

> [!faq]- 题解与完整核心代码｜先说状态，再核对
> **变量存什么**：`leftHeight/rightHeight` 是两棵子树高度；平衡检查额外用 -1 表示这棵子树已经不平衡。
>
> **解题步骤**
> 1. 普通高度函数：空树返回0；非空返回左右高度较大值加1。
> 2. 平衡判断用后序；任一子树返回-1，就把失败向上传递。
> 3. 两个高度之差超过1也返回-1，否则返回当前真实高度。
> 4. 最终返回值不是-1则整棵树平衡。
>
> ```cpp
> int TreeHeight(BTNode *p) {
>     if (p == NULL) return 0;
>     int leftHeight = TreeHeight(p->lchild);
>     int rightHeight = TreeHeight(p->rchild);
>     return (leftHeight > rightHeight ? leftHeight : rightHeight) + 1;
> }
>
> int BalancedHeight(BTNode *p) {
>     if (p == NULL) return 0;
>     int leftHeight = BalancedHeight(p->lchild);
>     if (leftHeight == -1) return -1;
>     int rightHeight = BalancedHeight(p->rchild);
>     if (rightHeight == -1) return -1;
>     int difference = leftHeight - rightHeight;
>     if (difference > 1 || difference < -1) return -1;
>     return (leftHeight > rightHeight ? leftHeight : rightHeight) + 1;
> }
>
> bool IsBalanced(BTNode *root) {
>     return BalancedHeight(root) != -1;
> }
> ```
>
> **时间 / 额外空间**：两项分别为 O(n) / O(h)，h 为树高，退化树 h=n。
>
> **易错核对**：不要在每个结点重新遍历整棵子树求高度，否则最坏 O(n²)。

### T07 递归先中后序遍历

- [ ] 首次：能解释状态并写出代码
- [ ] 间隔复写：不看答案通过自测

**定位**：基础积木｜表达式树、WPL、BST 的递归积木。

**题干**：分别输出二叉树先序、中序、后序，每个值后输出一个空格。

**自测**：根2、左1、右3：先序2 1 3；中序1 2 3；后序1 3 2；空树无输出。

> [!faq]- 题解与完整核心代码｜先说状态，再核对
> **变量存什么**：不额外维护全局状态；访问语句相对于“递归左、递归右”的位置决定遍历次序。
>
> **解题步骤**
> 1. 先判空；空树直接返回。
> 2. 先序在递归前访问根；中序在左右递归之间访问根。
> 3. 后序在左右递归都返回后访问根。
>
> ```cpp
> void PreOrder(BTNode *p) {
>     if (p == NULL) return;
>     printf("%d ", p->data);
>     PreOrder(p->lchild);
>     PreOrder(p->rchild);
> }
>
> void InOrder(BTNode *p) {
>     if (p == NULL) return;
>     InOrder(p->lchild);
>     printf("%d ", p->data);
>     InOrder(p->rchild);
> }
>
> void PostOrder(BTNode *p) {
>     if (p == NULL) return;
>     PostOrder(p->lchild);
>     PostOrder(p->rchild);
>     printf("%d ", p->data);
> }
> ```
>
> **时间 / 额外空间**：O(n) / O(h)。
>
> **易错核对**：中序输出不自动有序，只有满足 BST 条件时才有序。

### T19 BST 区间内键值递增输出

- [ ] 首次：能解释状态并写出代码
- [ ] 间隔复写：不看答案通过自测

**定位**：迁移选练｜自编结构内迁移，不标真题年份；仅主练稳定后选做。

**题干**：严格 BST，给定 low、high。把闭区间[low,high]中的键按递增顺序写入调用者提供的 result 数组并返回个数；容量足够，low>high时返回0。

**自测**：键{1,3,5,7,9}，区间[3,7] → [3,5,7]；[10,20] → []；空树→[]。

> [!faq]- 题解与完整核心代码｜先说状态，再核对
> **变量存什么**：`count` 是已写入个数；中序保证递增，BST大小关系用于剪掉不可能满足范围的子树。
>
> **解题步骤**
> 1. 当前键>low 才需要查左子树，否则左侧不可能落在区间内。
> 2. 当前键在闭区间内就写入 result[count]，count++。
> 3. 当前键<high 才需要查右子树；递归次序保持左、根、右。
>
> ```cpp
> void CollectRange(BTNode *p, int low, int high, int result[], int &count) {
>     if (p == NULL) return;
>     if (p->data > low) CollectRange(p->lchild, low, high, result, count);
>     if (p->data >= low && p->data <= high) {
>         result[count] = p->data;
>         count++;
>     }
>     if (p->data < high) CollectRange(p->rchild, low, high, result, count);
> }
>
> int BSTRange(BTNode *root, int low, int high, int result[]) {
>     if (low > high) return 0;
>     int count = 0;
>     CollectRange(root, low, high, result, count);
>     return count;
> }
> ```
>
> **时间 / 额外空间**：O(h+k) / O(h)，k为输出数；退化时最坏 O(n)，输出数组另计。
>
> **易错核对**：这是“学过的BST＋范围条件”的小迁移，不是扩一套新算法；遍历顺序不可改成先根输出。
