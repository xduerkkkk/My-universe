## 2. 动手前只检查这四件事

1. **函数管哪一部分？** 当前子树，还是当前结点及其兄弟？
2. **返回值是什么？** 新根、计数、规模，不要混在一起。
3. **处理时机？** 要先拿到孩子结果就后序；需要深度就由父传子。
4. **改了结构吗？** 只修改局部指针变量，不代表调用者的孩子指针已改变。

> [!faq]- NT04按需基础：后序返回子树规模
> 空子树贡献0；非空子树规模＝左子树规模＋右子树规模＋1。递归过程中返回的是“以当前结点为根的全部结点数”，不是某个全局计数器。
>
> ```cpp
> int SubtreeSize(BTNode *p) {
>     if (p == NULL) return 0;
>     return SubtreeSize(p->lchild) + SubtreeSize(p->rchild) + 1;
> }
> ```
>
> 对所有结点需要这个信息时，应在一次后序中顺手使用返回值；不要在每个结点重新调用这个函数扫描其整棵子树。

### NT01 收缩所有单分支结点

**来源与定位**：旧题重写｜[[算法分类训练-改写前留档-2026-11-05/原版-算法分类训练-03-T树与递归#T09 收缩所有单分支结点|旧T09原题与批注]]；保留任务，重写推导与教材式C++。

- [ ] 首次：能解释状态并独立写出
- [ ] 间隔复写：不看答案通过自测

**题干**：二叉树采用`BTNode`二叉链表存储。删除所有恰有一个孩子的结点，并以其唯一孩子替代；保留叶结点和双分支结点。返回处理后的根指针。

所有结点由`new`创建并由本树独占，要求释放被删除结点，不申请新结点，时间复杂度为$O(n)$。空树返回`NULL`。

**自测（先手推）**

- 空树 → `NULL`；单结点 → 原结点不变。
- `1`只有左孩子`2`，`2`只有右孩子`3` → 只保留结点`3`，且地址不变。
- 根`1`有左孩子`2`、右孩子`3`，`2`只有右孩子`4` → 根仍为`1`，左孩子改为`4`，右孩子仍为`3`。

> [!faq]- 分析与408风格参考解答｜尝试后展开
>
> **为什么选这题**：旧题中有价值的“结构修改”模板，不因它不是给定真题的直接复刻就暂缓。这里练的是递归接口，而不是记住某个删除条件。
>
> **从直觉到算法**
>
> 只令局部变量`p=child`，不会自动改变父结点的`lchild/rchild`。因此先约定：**函数返回处理后这棵子树的新根**。父结点必须接住这个返回值。
>
> **变量与返回值**：`p`为当前子树根；`child`暂存将保留的唯一孩子；函数返回新根。结点被释放后不得再读取`p`。
>
> **编号步骤**
> 1. 空树返回`NULL`。
> 2. 递归处理左右子树，并分别接回返回的新根。
> 3. 当前结点恰有一个孩子时，保存该孩子，释放当前结点，再返回孩子。
> 4. 当前结点是叶或有两个孩子时，返回`p`。
> 5. 调用者必须写`root = ContractSingle(root);`。
>
> **小例子**：`1→2→3`从下往上处理：`3`是叶，返回`3`；`2`删除后返回`3`；`1`接到`3`后仍是单分支，再删除并返回`3`。不是只删一层。
>
> **正确性要点**：左右递归已保证各自没有单分支结点；当前若单分支，用已处理好的唯一孩子替代，否则保留。这样整棵返回树都满足要求。
>
> **时间／额外空间**：$O(n)$／$O(h)$递归栈，$h$为原树高度；无新数据结点。释放空间不抵扣递归栈。
>
> **易错核对**：叶结点有0个孩子，不是单分支；不能释放后再读`p->lchild`；不能遗漏根指针的更新。
>
> **完整核心代码**
>
> ```cpp
> BTNode *ContractSingle(BTNode *p) {
>     if (p == NULL) return NULL;
>     p->lchild = ContractSingle(p->lchild);
>     p->rchild = ContractSingle(p->rchild);
>     if (p->lchild != NULL && p->rchild == NULL) {
>         BTNode *child = p->lchild;
>         delete p;
>         return child;
>     }
>     if (p->lchild == NULL && p->rchild != NULL) {
>         BTNode *child = p->rchild;
>         delete p;
>         return child;
>     }
>     return p;
> }
> ```

### NT02 孩子兄弟表示法的叶结点深度和

**来源与定位**：自编概念迁移｜借用旧T04的表示法知识，不是旧T04答案；未标真题年份。

- [ ] 首次：能解释状态并独立写出
- [ ] 间隔复写：不看答案通过自测

**题干**：一棵非空树采用孩子兄弟链表存储，`firstchild`指向第一个孩子，`nextsibling`指向下一个兄弟，根没有兄弟。根深度为0，求**原树所有叶结点**的深度之和。

不得修改结构，要求时间复杂度为$O(n)$；答案可用`long long`表示。所需`CSNode`在本题代码内定义，不能按普通二叉树解释两个指针。

**自测（先手推）**

- 只有根 → `0`。
- 根`1`有三个叶孩子`2,3,4` → `1+1+1=3`。
- 根`1`有孩子`2,3`，`2`有叶孩子`4,5`，`3`为叶 → `2+2+1=5`。
- 根有很多同层叶孩子 → 每个深度仍为1，不随兄弟链长度增长。

> [!faq]- 分析与408风格参考解答｜尝试后展开
>
> **为什么选这题**：旧T04使用相同表示法求最大度；本题改为叶与层次统计。重点是读懂存储语义，不是把普通二叉树的叶判断照搬过来。
>
> **从直觉到算法**
>
> 原树叶结点的条件只有`firstchild==NULL`。它可以有下一个兄弟。兄弟之间不增加原树深度，因此不能把两个指针都当孩子并传`depth+1`。
>
> **先定义函数的责任**：`LeafDepthSum(p, depth)`只计算**以p为根的原树子树**的贡献，不包含p的兄弟。p的所有孩子由当前层循环枚举，递归只进入孩子。
>
> **变量与返回值**：`depth`为p在原树中的深度；`child`沿同一个父结点的孩子链移动；`sum`汇总这些孩子子树的结果。
>
> **编号步骤**
> 1. 空指针返回0；原题非空，这个分支用于递归接口的完整性。
> 2. 若无第一个孩子，则p是叶，直接返回`depth`。
> 3. 沿`firstchild → nextsibling → …`枚举所有孩子。
> 4. 对每个孩子传入同一个`depth+1`，累加其返回值。
> 5. 入口为`LeafDepthSum(root, 0)`。
>
> **小例子**：根的孩子是`2,3`，两次递归深度都为1。处理`2`的孩子`4,5`时，两者深度都为2；`3`仍然是深度1。
>
> **正确性要点**：叶贡献自己的深度；非叶的全部叶结点恰好分布在各孩子子树中，这些集合互不重叠，因此求和不重不漏。
>
> **时间／额外空间**：$O(n)$／$O(h)$，h为**原树高度**。此写法用循环枚举兄弟，不会因一层兄弟多而叠出一串递归栈。若另写成对`nextsibling`递归的版本，栈深度需重新分析。
>
> **易错核对**：`nextsibling`非空不妨碍p是叶；不能让兄弟深度加1；本函数不负责p的兄弟，避免父层枚举和子函数重复统计。
>
> **完整核心代码**
>
> ```cpp
> typedef struct CSNode {
>     int data;
>     struct CSNode *firstchild, *nextsibling;
> } CSNode;
>
> long long LeafDepthSum(CSNode *p, int depth) {
>     if (p == NULL) return 0;
>     if (p->firstchild == NULL) return depth;
>     long long sum = 0;
>     for (CSNode *child = p->firstchild; child != NULL;
>          child = child->nextsibling)
>         sum += LeafDepthSum(child, depth + 1);
>     return sum;
> }
> ```

### NT03 判断链式二叉树是否为小根堆

**来源与定位**：旧题重写｜[[算法分类训练-改写前留档-2026-11-05/原版-算法分类训练-03-T树与递归#T15 链式二叉树是否为小根堆|旧T15原题与批注]]；合并为一次层序检查，并展开完整代码。

- [ ] 首次：能解释状态并独立写出
- [ ] 间隔复写：不看答案通过自测

**题干**：一棵二叉树采用二叉链表存储，结点总数`n`已知且准确。判断它是否同时满足：①完全二叉树；②每个父结点的值不大于其孩子的值。允许相等。

不得改变原树；空树`n=0`按小根堆处理。要求时间复杂度为$O(n)$，可用$O(n)$辅助空间。

**自测（先手推）**

- 空树、单结点 → 真。
- 根`1`只有左孩子`2` → 真；只有右孩子`2` → 假。
- 根`1`有左`2`右`3`，右结点`3`有左孩子`4`，而`2`没有孩子 → 假（跨父结点出现空位）。
- 根`3`有左孩子`1` → 假（形状可以，堆序不符）。
- 根与两个孩子都为`2` → 真。

> [!faq]- 分析与408风格参考解答｜尝试后展开
>
> **为什么选这题**：旧T15本来就是合理的“树形状＋堆的局部约束”组合。它不是BST判断换名：堆序只约束父子，不要求左子树全部小于根。
>
> **从直觉到算法**
>
> 递归逐条比较父子只能检查堆序，不能判断完全性。要观察空位出现后是否还有结点，应按层序、每层从左到右检查孩子位置。
>
> **变量含义**：队列存待检查的非空结点；`gap`表示在整个层序孩子序列中已见过空位置，不能每换一个父结点就清零；`valid`表示两个条件是否仍成立。
>
> **编号步骤**
> 1. 空树直接返回真；否则根入队，`gap=false`。
> 2. 每取一个父结点，依次检查左孩子、右孩子。
> 3. 空孩子令`gap=true`。
> 4. 非空孩子若出现在空位之后，或值小于父结点，则失败。
> 5. 合法孩子入队；检查完后释放队列并返回结果。
>
> **小例子**：父结点`2`的左孩子为空后，`gap`已为真；接着即使处理的是另一个父结点`3`，它也不能再出现非空孩子。
>
> **正确性要点**：层序位置上“所有非空位置先于所有空位置”等价于完全二叉树的连续填充；同时逐条检查每条父子边，就覆盖了全部堆序约束。
>
> **时间／额外空间**：最坏$O(n)$／$O(n)$队列。即使提前失败，本实现的零初始化队列仍花$O(n)$时间。n为准确结点数，队列每个结点最多入队一次，不会越界。
>
> **易错核对**：只查堆序不够；不能每个父结点重置`gap`；相等允许；队列只入非空结点，无须存放空指针。
>
> **完整核心代码**
>
> ```cpp
> bool IsLinkedMinHeap(BTNode *root, int n) {
>     if (root == NULL) return true;
>     BTNode **q = new BTNode *[n]();
>     int front = 0, rear = 0;
>     bool gap = false, valid = true;
>     q[rear++] = root;
>     while (front < rear && valid) {
>         BTNode *p = q[front++];
>         BTNode *child[2] = {p->lchild, p->rchild};
>         for (int i = 0; i < 2; i++) {
>             if (child[i] == NULL) gap = true;
>             else {
>                 if (gap || p->data > child[i]->data) {
>                     valid = false;
>                     break;
>                 }
>                 q[rear++] = child[i];
>             }
>         }
>     }
>     delete[] q;
>     return valid;
> }
> ```

### NT04 删除结点后的分块规模

**来源与定位**：自编综合验收｜后序子树规模＋全局总量，不标真题年份或出题概率。

- [ ] 首次：能解释状态并独立写出
- [ ] 间隔复写：不看答案通过自测

**题干**：非空二叉树采用二叉链表存储，结点总数$n$已知且准确，结点值互不相同。

将父子关系看作无向连接。若删除某结点及其关联边后，剩余每个连通块的结点数均不超过⌊n/2⌋，则称该结点满足条件。请找出所有这样的结点。

**只分析假想删除，不得实际修改或释放结点。** 将满足条件的结点值写入容量至少为n的`out[]`，顺序不限，返回结果个数。单结点树删除后无剩余块，视为满足条件。要求时间复杂度为$O(n)$。

**自测（先手推）**

- 单结点`1` → `{1}`。
- 四结点单链`1→2→3→4` → `{2,3}`，阈值为2。
- 根`1`，左右子树各3个结点（总数7） → 只有`{1}`。
- 根`1`只有左孩子`2`，`2`有两个叶孩子`3,4` → `{2}`；不是只比较左右子树大小。

> [!faq]- 分析与408风格参考解答｜尝试后展开
>
> **为什么选这题**：用基础的子树规模汇总，解决一个不是“遍历输出／求树高／判断BST”的全新任务。不要求预先知道这个性质的专有名词。
>
> **朴素方法为什么慢**：对每个候选结点，假想删掉它，再从其邻点遍历剩余各块，最坏$O(n^2)$。实际上各候选之间存在大量可复用的子树规模。
>
> **关键拆解**：删除p后，剩余最多有三块：左子树、右子树，以及经父亲连出去的部分。设左右规模为L、R，则p整棵子树规模为`size=L+R+1`，外侧规模为`n-size`。原树无环，这三部分不会绕路重新相连。
>
> **变量与返回值**：辅助函数返回当前子树的`size`；`count`是共享的输出长度，不是子树规模；`outside`为子树外结点数。输出答案与返回规模是两条不同的信息通道。
>
> **编号步骤**
> 1. 空子树返回0。
> 2. 后序取得左右规模`leftSize/rightSize`。
> 3. 算出`size`和`outside=n-size`。
> 4. 三块最大值不超过`n/2`时，将当前值写入`out[count++]`。
> 5. 向父结点返回`size`。入口把count设为0，结束返回count。
>
> **小例子**：四结点单链中，结点`2`以下含3个结点，删除`2`后向下块大小2、向上块大小1，因此合格。根虽然右子树为空，但左块大小3，超过阈值2，不合格。
>
> **正确性要点**：每个结点被访问时，左右规模准确；三块穷尽删除后的剩余结点且互不连通。因此最大块的比较正好是题目条件。
>
> **时间／额外空间**：$O(n)$／$O(h)$递归栈，调用者的`out[]`为输出空间，单列$O(n)$容量；退化树栈可达$O(n)$。
>
> **易错核对**：别漏父亲方向；原树n在递归中固定不变；不能在每个结点重扫子树；不真的删除p；不需要结果排序。
>
> **完整核心代码**
>
> ```cpp
> int CollectBalancedCuts(BTNode *p, int n, int out[], int &count) {
>     if (p == NULL) return 0;
>     int leftSize = CollectBalancedCuts(p->lchild, n, out, count);
>     int rightSize = CollectBalancedCuts(p->rchild, n, out, count);
>     int size = leftSize + rightSize + 1;
>     int outside = n - size;
>     int largest = leftSize > rightSize ? leftSize : rightSize;
>     if (outside > largest) largest = outside;
>     if (largest <= n / 2) out[count++] = p->data;
>     return size;
> }
>
> int BalancedCuts(BTNode *root, int n, int out[]) {
>     int count = 0;
>     CollectBalancedCuts(root, n, out, count);
>     return count;
> }
> ```
