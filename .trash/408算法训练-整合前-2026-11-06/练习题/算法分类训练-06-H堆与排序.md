### H01 下滤与自底向上建堆

- [ ] 首次：能解释状态并写出代码
- [ ] 间隔复写：不看答案通过自测

**定位**：基础积木｜堆排序/最小k个数的教材积木；冲刺主线的最小k个数在 A18。

**题干**：A[0..n-1] 原地建大根堆，允许空数组。HeapAdjust 调用前，root 的左右子树已经分别成堆。全套默认0下标，因此孩子为2root+1、2root+2。

**自测**：[3,1,4,2] 建堆后满足父≥孩子；[]、[1]不变；不要求得到唯一的堆数组。

> [!faq]- 题解与完整核心代码｜先说状态，再核对
> **变量存什么**：`value` 暂存待下滤值；`child` 每次选择较大的孩子；`root` 是当前空位。
>
> **解题步骤**
> 1. 把当前根的值暂存，找到它较大的孩子。
> 2. 暂存值已经≥较大孩子时，下滤结束。
> 3. 否则把较大孩子上移到空位，空位下移，继续检查下一层。
> 4. 从最后一个非叶结点 n/2-1 向前逐个下滤；叶子天然成堆。
>
> ```cpp
> void HeapAdjust(int A[], int root, int n) {
>     int value = A[root];
>     int child = 2 * root + 1;
>     while (child < n) {
>         if (child + 1 < n && A[child + 1] > A[child]) child++;
>         if (value >= A[child]) break;
>         A[root] = A[child];
>         root = child;
>         child = 2 * root + 1;
>     }
>     A[root] = value;
> }
>
> void BuildMaxHeap(int A[], int n) {
>     for (int i = n / 2 - 1; i >= 0; i--) {
>         HeapAdjust(A, i, n);
>     }
> }
> ```
>
> **时间 / 额外空间**：一次下滤 O(log n)；自底向上建堆 O(n) / O(1)。
>
> **易错核对**：这是0下标版本，不要与教材1下标孩子2i、2i+1混用；建堆不等于已排好序。
