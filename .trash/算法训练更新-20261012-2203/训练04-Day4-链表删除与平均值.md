## 必要定义（题目已给，不用默写）

```c
typedef struct LNode {
    int data;
    struct LNode *next;
} LNode, *LinkList;
```

L 指向不存数据的头结点。数据结点由动态内存分配，可 free；假定已包含 `<stdlib.h>`。允许 L == NULL 或空表。

## 0–5 分钟｜默写删除片段

已知 p 为非空数据结点，pre->next == p。写一段：删除并释放 p，让 p 转向下一待处理结点，保持前驱关系正确。不要写整个遍历，也不要新建结点。

## 今天主练题｜删除大于原平均值的结点

删除所有值严格大于**删除之前全部数据结点平均值**的结点，释放被删结点，保持其余结点相对顺序。不在每次删除后重算平均值。允许负数。

保证总和、`结点值×结点数` 不超出 long long 范围。时间 O(n)、额外空间 O(1)。

例：`[1,5,5,1]` 原平均值为 3，结果 `[1,1]`。

```c
void DeleteGreaterThanAverage(LinkList L);
```

## 22–28 分钟｜自测与核对

方括号只表示数据结点，不含头结点：

1. `[1,5,5,1]`
2. `[]`（有头结点但无数据结点）
3. `[-3,-2]`（检查平均值截断）

> [!faq]- 卡住才看｜两个关键点
> 先统计原 sum/count，再遍历删除。比较 `(long long)p->data * count > sum` 可避免整数除法截断。删除后 pre 不动；保留时 pre 与 p 一起前进。

> [!faq]- 写完再看｜片段与完整实现
> 结果：`[1,1]`；`[]`；`[-3]`。第三例平均值 -2.5，-2 应删除。
>
> 热身片段：
>
> ```c
> pre->next = p->next;
> free(p);
> p = pre->next;
> ```
>
> ```c
> void DeleteGreaterThanAverage(LinkList L) {
>     if (L == NULL) return;
>
>     long long sum = 0;
>     int count = 0;
>     LNode *p = L->next;
>     while (p != NULL) {
>         sum += p->data;
>         count++;
>         p = p->next;
>     }
>     if (count == 0) return;
>
>     LNode *pre = L;
>     p = L->next;
>     while (p != NULL) {
>         if ((long long)p->data * count > sum) {
>             pre->next = p->next;
>             free(p);
>             p = pre->next;
>         } else {
>             pre = p;
>             p = p->next;
>         }
>     }
> }
> ```
>
> 时间 O(n)，额外空间 O(1)。不需要 malloc 新结点。
