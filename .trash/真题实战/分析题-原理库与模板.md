# 分析题｜原理库与答题模板

> 分析题 50 分，核心不是"写得多"，而是**原理定位准 + 结构完整 + 贴材料**。
> 本文件是"写"层：先把框架背熟，再每套真题往里补话术。

## 一、通用答题五步结构

> 适用于史纲 / 毛中特 / 思修的意义类、措施类大题。

**历史条件 → 主要矛盾（现实问题）→ 路线政策 → 改变了什么 → 意义**

- 第一句点题：这题问的是"什么时期的什么问题"。
- 中间展开：用材料里的关键词接原理。
- 结尾拔高：落到"党的领导 / 人民 / 民族复兴 / 时代意义"。

## 二、马原分析题原理清单（优先背）

马原分析题**几乎必考**：矛盾分析法 + 实践与认识。先把原理写全，再贴材料。

### 1. 辩证法（最常考）
- **矛盾的对立统一**：任何事物都包含既对立又统一的两个方面，斗争性 + 同一性，推动事物发展。
- **矛盾普遍性与特殊性**：普遍性寓于特殊性之中，共性通过个性表现；要具体问题具体分析。
- **主要矛盾与矛盾主要方面**：抓主要矛盾、看主流。
- **量变与质变**：量变是质变准备，质变是量变结果。
- **否定之否定**：事物发展是前进性与曲折性的统一。

### 2. 认识论（第二常考）
- **实践与认识**：实践是认识的来源、动力、目的、检验标准。
- **感性认识 → 理性认识 → 实践**：两次飞跃。
- **真理的绝对性与相对性**：真理是绝对性与相对性的统一。
- **实践是检验真理的唯一标准**。

### 3. 唯物史观
- **社会存在与社会意识**：社会存在决定社会意识，社会意识有相对独立性。
- **生产力与生产关系、经济基础与上层建筑**：社会基本矛盾。
- **人民群众是历史的创造者**：坚持人民立场。

### 定位口诀
> 看到"矛盾/对立/转化/两方面" → 辩证法；看到"认识/实践/真理/检验" → 认识论；看到"人民/社会/制度" → 唯物史观。

## 三、各科话术要点

### 马原
- 结构：**原理（先写全）+ 方法论 + 结合材料**。
- 落点词：实事求是、具体问题具体分析、实践检验。

### 毛中特 / 新思想
- 万能话术链：**党的领导 → 以人民为中心 → 改革（生产关系/体制机制）→ 高质量发展 → 民族复兴**。

### 史纲
- 考"为什么 / 意义 / 启示"：历史条件 → 道路选择 → 历史意义 → 现实启示（纪念周年优先）。

### 思修法基
- 考价值观类：见 [[思修法基-知识要点]]，把对应原理 + 个人行动建议结合。
