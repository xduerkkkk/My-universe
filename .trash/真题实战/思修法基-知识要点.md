# 思修法基｜知识要点（骨架）

> ⚠️ 本文件是**补缺口的骨架**，约 16 分（客观题为主 + 1 道分析题）。
> 内容为通用框架，**需对照你的思修讲义 / 真题核对后填充**，不要直接背这里。

## 一、六大板块框架

1. **人生观**：人生目的（人生的根本指向）、人生态度、人生价值。
   - 人生价值 = **自我价值 + 社会价值的统一**，社会价值是主导。
2. **理想信念**：理想是信念的根据和前提，信念是理想实现的重要保障。
3. **中国精神**：民族精神（核心 = **爱国主义**）+ 时代精神（核心 = **改革创新**）。
4. **社会主义核心价值观**：国家（富强民主文明和谐）、社会（自由平等公正法治）、个人（爱国敬业诚信友善）三个层面。
5. **道德**：中华传统美德 → 革命道德 → 社会公德 / 职业道德 / 家庭美德 / 个人品德。
6. **法律**：全面依法治国、法治思维、宪法是国家的根本法。

## 三、分析题套路

思修分析题通常考**价值观类**：先答对应板块原理（如人生价值 / 理想信念 / 爱国主义 / 道德），再结合材料中的个人事例，落点"个人要怎么做 + 时代意义"。
