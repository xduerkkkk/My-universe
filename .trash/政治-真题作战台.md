# 政治｜真题作战台

> 真题阶段的目标不是"再懂一点"，而是把已有的"懂"变成考场上的**准、快、写**。
> 本文件是枢纽：只装**指针和清单**，不装知识。知识在下面三层里。

## 一、试卷结构与得分策略

| 题型 | 题量 | 分值 | 抢分要点 |
|---|---|---|---|
| 单选 | 16 × 1 | 16 | 帽子题为主，3 秒定位，不纠结 |
| 多选 | 17 × 2 | 34 | 最易失分，警惕绝对化 / 偷换概念 / 张冠李戴 |
| 分析题 | 5 × 10 | 50 | 原理 + 材料 + 结构话术，按模板写 |

分析题五题固定分布：**马原 / 新思想 / 史纲 / 思修法基 / 当代时政**。
建议时间：客观题 ≤ 60 分钟，分析题 ≥ 120 分钟，留 5 分钟涂卡检查。

## 二、三层地图

### 🧭 懂（理解层）—— 把知识连成线
- [[马原-体系串联]]：世界 → 实践 → 社会 → 资本主义
- [[毛中特-体系串联]]：建国 → 改造 → 建设 → 改革开放
- [[史纲-体系串联]]：民族危机 → 革命道路 → 统一战线 → 新中国

- [[客观题-易错陷阱库]]：命题人挖坑手法 + 已踩的坑

### ✍️ 写（分析题）—— 按结构拿满
- [[分析题-原理库与模板]]：马原原理清单 + 各科答题结构

### 🩹 缺口的补丁

## 三、每科作战指引

- **马原**：客观题抓"帽子 + 易混对"（唯一特性 / 根本属性 / 寓于口诀）；分析题几乎必考**矛盾分析法 + 实践与认识**，先把原理写全再贴材料。
- **毛中特 / 新思想**：客观题抓"帽子"（首要任务 / 根本保证 / 决定性作用）；分析题背**党的领导 + 人民 + 改革 + 高质量发展**话术链。
- **史纲**：客观题抓"第一次 / 首次"系列 + 会议对应；分析题考**意义 + 现实启示**（周年纪念优先）。
- **思修法基**：客观题为主，抓人生观 / 理想信念 / 道德法律帽子；分析题考价值观类。→ [[思修法基-知识要点]]
- **时政当代**：以你手上的时政资料为准，这里只留入口，不重复造。

## 四、刷题 SOP（做完一套真题后，花 15 分钟沉淀）

1. 错题先**判类型**：帽子错？陷阱中招？原理没定位？
2. 帽子错 → 填进 [[客观题-概念帽子总表]]
3. 陷阱中招 → 填进 [[客观题-易错陷阱库]]
4. 分析题失分 → 补原理 / 话术进 [[分析题-原理库与模板]]
5. 每周通读一遍两张表，做"秒杀自查"（看到帽子词 3 秒内说出答案才算过关）
