比如 Qwen2.5-VL 技术报告里就提到，它使用动态分辨率处理、Window Attention、原生动态分辨率 ViT，以支持图像、文档和长视频理解；它还强调了目标定位、文档解析、表格/图表/版面分析等能力。

这对你的 136 很关键：**文档理解需要高分辨率视觉能力，因为小字、表格线、公式、版面结构都很容易丢。
**现在主流多模态大模型通常是这个结构：

图片  
→ Vision Encoder，例如 ViT / ConvNeXt / Swin / 专用视觉编码器  
→ 视觉 token  
→ Adapter / Projector / Q-Former  
→ 对齐到 LLM 的 token 空间  
→ LLM 统一处理图像 token + 文本 token  
→ 输出回答

可以画成这样：


```
[图片] ──► [视觉编码器 ViT] ──► [视觉 token]  
                                  │  
                                  ▼  
[用户问题] ──► [文本 token] ──► [多模态 LLM] ──► [文字答案 / 坐标 / JSON / 工具调用]
```


# 核心解决问题

一页文档不是纯文本。  
它有标题、段落、表格、图片、公式、脚注、参考文献、阅读顺序。  
模型不仅要读出字，还要理解结构和语义。

识图的核心问题是：

图里有什么？  
它们在哪里？  
它们之间是什么关系？  
图片表达了什么含义？  
能不能基于图片回答问题？
