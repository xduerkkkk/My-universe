## 1️⃣ 整理三个路线的案例对比

- **目标**：清楚展示 OCR-only / VLM-only / Hybrid 的区别
- **方法**：
    1. 找一两个示例 PDF（最好是内容复杂、包含文字+图表+表格的）
    2. 分别跑三条路线
    3. 输出表格或 Markdown 比较：
        
        |页面|OCR-only|VLM-only|Hybrid|优缺点|
        |---|---|---|---|---|
        |Page1|文字准确、无结构|语义理解强、结构概括|综合优点|Hybrid 综合表现最好|
        
    4. 可以截图 `ocr_visuals/`、`qa_visuals/` 用于展示

---

## 2️⃣ 设计小规模实验表格

- **目标**：量化对比，展示 Hybrid 的优势
- **内容示例**：
    - 准确率：OCR 文字识别、Hybrid 答案正确率
    - 证据定位：引用 OCR 编号的准确率
    - 页面理解：VLM-only vs Hybrid 对结构/图表理解准确度
- **形式**：Excel/Markdown 表格即可

---

## 3️⃣ 撰写专业实践报告

- **目标**：把整个项目逻辑、技术路线、实验结果、可视化截图整合成报告
- **结构建议**：
    1. 项目简介 & 研究目的
    2. 技术路线
        - OCR-only
        - VLM-only
        - Hybrid
        - QA 问答+证据高亮
    3. 系统实现
        - 文件结构
        - 模型选择
        - API / 配置说明
    4. 案例对比 & 小规模实验
        - 表格 + 图片
        - 分析优缺点
    5. 总结 & 未来扩展
