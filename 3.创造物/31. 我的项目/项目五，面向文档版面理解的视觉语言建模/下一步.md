## 3. 实验路线建议

你的主线可以定为：

> **基于 FUNSD 的表单字段抽取实验：比较 OCR-only、文本+位置、LayoutLMv3 三类方法。**

### 模型 1：OCR-only 文本模型

目的：作为纯文本基线。

输入：

```text
OCR tokens
```

不输入 bbox，不输入图像。

模型可以用：

```text
BERT / DistilBERT + token classification head
```

输出：

```text
B-QUESTION / I-QUESTION
B-ANSWER / I-ANSWER
B-HEADER / I-HEADER
O
```

它回答的问题是：

> 只看 OCR 文本，不看位置，模型能做多好？

---

### 模型 2：文本 + 位置模型

目的：证明 layout 信息有用。

输入：

```text
OCR tokens + normalized bbox
```

模型可以简单实现为：

```text
BERT hidden states + bbox feature embedding + classifier
```

或者：

```text
token embedding + x0/y0/x1/y1 embedding
```

它回答的问题是：

> 加入文本框坐标后，字段抽取是否提升？

这个模型很适合作为“位置信息利用优化”的拓展。

---

### 模型 3：LayoutLMv3

目的：满足“至少一种视觉语言模型”的要求。

输入：

```text
OCR tokens + bbox + page image
```

模型：

```text
LayoutLMv3ForTokenClassification
```

它回答的问题是：

> 文本、位置、图像三种信息共同输入时，效果是否最好？

## 4. 数据处理阶段必须做什么

FUNSD 处理模块建议完成这些输出：

```text
funsd_experiment/data/processed/train.json
funsd_experiment/data/processed/val.json
funsd_experiment/data/processed/test.json
```

每条样本建议统一成：

```json
{
  "id": "0001",
  "image_path": ".../0001.png",
  "width": 1000,
  "height": 1400,
  "tokens": ["Name", ":", "John", "Smith"],
  "bboxes": [[100, 120, 180, 150], [185, 120, 195, 150]],
  "bboxes_norm": [[100, 85, 180, 107], [185, 85, 195, 107]],
  "labels": ["B-QUESTION", "I-QUESTION", "B-ANSWER", "I-ANSWER"]
}
```

必须做的统计：

```text
1. train / val / test 样本数
2. 每页 token 数分布
3. 每页 bbox 数量分布
4. 各类别标签数量
5. 不同字段类别占比
6. OCR 噪声样例，例如乱码、断词、空文本
7. bbox 宽高异常、重叠框、空框数量
```

坐标归一化建议统一到 LayoutLM 系列常用格式：

```python
x0_norm = int(1000 * x0 / image_width)
y0_norm = int(1000 * y0 / image_height)
x1_norm = int(1000 * x1 / image_width)
y1_norm = int(1000 * y1 / image_height)
```

文本框排序至少实现两种，方便做拓展实验：

```text
A. 原始标注顺序
B. reading order：先按 y 坐标，再按 x 坐标排序
```
