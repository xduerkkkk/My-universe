## 3.5 Dataset Statistics


| 统计项          | 训练集    | 验证集   | 测试集   |
| ------------ | ------ | ----- | ----- |
| 样本数          | 127    | 22    | 50    |
| Token 总数     | 18,668 | 3,220 | 8,707 |
| 每页 Token 均值  | 147.0  | 146.4 | 174.1 |
| 每页 Token 中位数 | 139    | 137.5 | 177   |
| 超出 512 长度比例  | 0%     | 0%    | 0%    |

  

**类别分布（实体级）：**

  

| 类别            | 训练集   | 验证集   | 测试集   |
| ------------- | ----- | ----- | ----- |
| ANSWER        | 8,183 | 1,336 | 3,294 |
| QUESTION      | 6,231 | 1,030 | 2,654 |
| O (no entity) | 3,035 | 597   | 2,385 |
| HEADER        | 1,219 | 257   | 374   |

  

*注：数据集中 ANSWER 和 QUESTION 占比较高，HEADER 数量较少，存在类别不均衡现象。*

  
OCR 噪声情况

  

- 非打印字符比例：约 0.6%（如 ☐、☑ 等表单勾选框符号）

- 高符号比 tokens：如 `(s)`、`($)`、`+/` 等占位符和分隔符

- 总体 OCR 质量较好，未见明显长 token 异常
