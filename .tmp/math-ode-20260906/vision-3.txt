### **39**

**【原题】**

> ( I ) 若 $y = y(x)$ 为微分方程 $y' + ay = f(x)\ (a > 0)$ 的解，求 $\lim_{x \to +\infty} y(x)$.
> ( II ) 若 $y = y(x)$ 为微分方程 $y'' + ay' = f(x)\ (a > 0)$ 的解，求 $\lim_{x \to +\infty} y'(x)$ 与 $\lim_{x \to +\infty} y''(x)$.

**【解答与已知打印推导】**
> ( I ) $\frac{dy}{dx} + ay = f(x)$ 的通解为 $y = e^{-ax} \left[ \int_0^x f(t) e^{at} dt + C \right]$,
> $\lim_{x \to +\infty} y = \lim_{x \to +\infty} e^{-ax} \left[ \int_0^x f(t) e^{at} dt + C \right] = \lim_{x \to +\infty} \frac{\int_0^x f(t) e^{at} dt + C}{e^{ax}} = \lim_{x \to +\infty} \frac{f(x)}{a} = \frac{b}{a}$
> ( 2 ) $\lim_{x \to +\infty} y' = \frac{b}{a}$, $\lim_{x \to +\infty} y'' = \lim_{x \to +\infty} [f(x) - ay'] = b - a \frac{b}{a} = 0$

### **43**

**【原题】**
> **m) 26 版 1000 第十五章强化 28 >>**
> 28. 设 $y = 1, y = e^{-x}, y = 2e^{-x}$ 为某二阶常系数线性微分方程的解，则该微分方程为 ________.

**【答案与解析】**
> **28.【答案】** $y'' + y' = 0$
> **【解析】** 设二阶常系数线性微分方程为 $y'' + ay' + by = f(x)$, $a, b$ 为常数. 将 $y = 1, y = e^{-x}, y = 2e^{-x}$ 代入方程，依次得
> $f(x) = b, e^{-x} - ae^{-x} + be^{-x} = f(x), 2e^{-x} - 2ae^{-x} + 2be^{-x} = f(x)$,
> 解得 $b = 0, a = 1$. 故所求微分方程为 $y'' + y' = 0$.

### **44**

**【原题】**
> (2) (南京大学, 1993年) 设 $y_1 = e^x, y_2 = x + e^x, y_3 = x^2 + e^x$ 为某二阶线性非齐次微分方程的特解，则该微分方程为 _________.

**【解答】**
> (2) 【详解一】 由于 $y_2 - y_1 = x, y_3 - y_1 = x^2$ 为齐次方程的两个线性无关的解，故齐次方程的通解为 $y = C_1 x + C_2 x^2$.
> 由
> $\begin{cases} y = C_1 x + C_2 x^2 \\ y' = C_1 + 2C_2 x \\ y'' = 2C_2 \end{cases}$
> 消 $C_1, C_2$, 得齐次方程为 $x^2 y'' - 2x y' + 2y = 0$.
> 令非齐次方程为 $x^2 y'' - 2x y' + 2y = f(x)$, 将 $y_1 = e^x$ 代入上式，得 $f(x) = e^x (x^2 - 2x + 2)$, 故非齐次方程为 $x^2 y'' - 2x y' + 2y = e^x (x^2 - 2x + 2)$.

### **47**

**【原题】**
> **【例 4.9】** (1) (莫斯科 1975 年竞赛题) 设 $f(x)$ 满足 $f(x+y) = \frac{f(x)+f(y)}{1-f(x)f(y)}$, 且 $f'(0) = 1$, 求 $f(x)$.

**【解答】**
> 【详解】 (1) 令 $x=y=0$, 则 $f(0) = \frac{f(0)+f(0)}{1-f(0)f(0)}$, 得 $f(0) = 0$.
> 由
> $f'(x) = \lim_{\Delta x \to 0} \frac{f(x+\Delta x) - f(x)}{\Delta x} = \lim_{\Delta x \to 0} \frac{\frac{f(x)+f(\Delta x)}{1-f(x)f(\Delta x)} - f(x)}{\Delta x}$
> $= \lim_{\Delta x \to 0} \frac{f(\Delta x)}{\Delta x} \frac{1+f^2(x)}{1-f(x)f(\Delta x)} = f'(0) [1+f^2(x)] = 1+f^2(x)$,
> 得 $\int \frac{df(x)}{1+f^2(x)} = \int dx$, 故 $\arctan f(x) = x + C$. 由 $f(0) = 0$, 得 $C = 0$, 故 $f(x) = \tan x$.

### **48**

**【原题】**
> **【例 4.4】** 设 $f(x)$ 为 $\mathbf{R}$ 上有界的连续函数. 证明:
> ( I ) 微分方程 $y' + y = f(x)$ 在 $\mathbf{R}$ 上存在一个有界的解.
> ( II ) 若 $f(x)$ 以 $T$ 为周期, 则 ( I ) 中的解也以 $T$ 为周期.

**【解答与手写批注】**
> 【详解】 ( I ) 微分方程 $y' + y = f(x)$ 的通解为 $y(x) = e^{-x} \left[ \int_{-\infty}^x e^t f(t) dt + C \right]$. `[手写批注：积分下限更正为 -\infty]`
> 令 $C = 0$, 则 $y(x) = e^{-x} \int_{-\infty}^x e^t f(t) dt$. `[手写批注：\int_{-\infty}^x + \int_0^x]`
> 由于 $|f(x)| \le M$, 故 $|y(x)| = \left| e^{-x} \int_{-\infty}^x e^t f(t) dt \right| \le e^{-x} \int_{-\infty}^x e^t |f(t)| dt \le M$
>
> ( II ) 对于 ( I ) 中的解 $y(x) = e^{-x} \int_{-\infty}^x e^t f(t) dt$, 有
> $y(x+T) = e^{-(x+T)} \int_{-\infty}^{x+T} e^t f(t) dt \xrightarrow{t=u+T} e^{-(x+T)} \int_{-\infty}^x e^{u+T} f(u+T) du = e^{-x} \int_{-\infty}^x e^u f(u) du = y(x)$
> 即 $y(x) = e^{-x} \int_{-\infty}^x e^t f(t) dt$ 以 $T$ 为周期.

### **50**

**【原题】**
> **606** 设 $P(x), Q(x)$ 在 $(-\infty, +\infty)$ 内连续, 以 $T$ 为周期, 函数 $y = y(x)$ 是
> $\frac{dy}{dx} + P(x)y = Q(x)$
> 的解, 则 $y(0) = y(T)$ 是 $y = y(x)$ 以 $T$ 为周期的
> (A) 必要非充分条件.
> (B) 充分非必要条件.
> (C) 充要条件.
> (D) 既非充分又非必要条件.

---

### **51**

**【答案与解答】**
> **606 【答案】** C
> **【分析】** 若 $y = y(x)$ 以 $T$ 为周期, 显然有 $y(0) = y(T)$. 反之, 若 $y(0) = y(T)$, 考察 $\Phi(x) = y(x+T) - y(x)$, 则
> $\frac{d\Phi(x)}{dx} = y'(x+T) - y'(x)$
> $= [-P(x+T)y(x+T) + Q(x+T)] - [-P(x)y(x) + Q(x)]$
> $= -P(x)[y(x+T) - y(x)]$,
> (其中 $P(x+T) = P(x), Q(x+T) = Q(x)$), 即
> $\frac{d\Phi(x)}{dx} + P(x)\Phi(x) = 0$,
> 两边乘 $e^{\int_0^x P(t)dt}$ 得
> $\frac{d}{dx} (\Phi(x) e^{\int_0^x P(t)dt}) = 0$,
> $\Rightarrow \Phi(x) e^{\int_0^x P(t)dt} = C \quad (x \in (-\infty, +\infty))$.
> 由 $\Phi(0) = y(T) - y(0) = 0 \Rightarrow C = 0$, 即
> $\Phi(x) = 0 \quad (x \in (-\infty, +\infty))$.
> 即 $y(x)$ 以 $T$ 为周期. 因此选(C).
