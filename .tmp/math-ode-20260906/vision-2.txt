### **19**
* **原题：**
  (2) $\sin \frac{y}{x} = \frac{1}{2}x$.

* **解答/批注：**
  **【解】** 原方程为齐次微分方程，令 $u = \frac{y}{x}$，即 $y = ux$，则
  $$\frac{\mathrm{d}y}{\mathrm{d}x} = u + x \cdot \frac{\mathrm{d}u}{\mathrm{d}x} = u + \tan u.$$
  分离变量得 $\cot u \, \mathrm{d}u = \frac{\mathrm{d}x}{x}$，积分得 $\ln |\sin u| = \ln |x| + C_1$，故
  $$\sin u = \pm e^{C_1} \cdot x = Cx \quad (C \neq 0),$$
  即 $\sin \frac{y}{x} = Cx \quad (C \neq 0)$.
  又 $y = 0$ 也是原方程的解（$y = 0$ 在分离变量过程中漏掉了），故上面常数也可以为零，则原方程的通解为 $\sin \frac{y}{x} = Cx \quad (C \text{为任意常数})$.
  由 $y(1) = \frac{\pi}{6}$，得 $C = \frac{1}{2}$，故所求特解为 $\sin \frac{y}{x} = \frac{1}{2}x$.

### **26**
* **原题：**
  6 设 $y_1(x)$ 和 $y_2(x)$ 是微分方程 $y'' - y' + y = 0$ 的两个特解，则该方程的通解能表示成 $C_1 y_1(x) + C_2 y_2(x) \quad (C_1, C_2 \text{是任意常数})$ 的充分条件为（ ）
  (A) $y_1(x) y'_2(x) - y'_1(x) y_2(x) \neq 0$.
  (B) $y_1(x) y'_2(x) - y'_1(x) y_2(x) = 0$.
  (C) $y_1(x) y'_2(x) + y'_1(x) y_2(x) \neq 0$.
  (D) $y_1(x) y'_2(x) + y'_1(x) y_2(x) = 0$.

* **解答/批注：**
  **【答案】** A.
  **【解】** 根据线性微分方程的通解结构定理，若 $y_1(x)$ 与 $y_2(x)$ 线性无关，则 $C_1 y_1(x) + C_2 y_2(x)$ 能表示题设方程的通解. 并且，若 $y_1(x), y_2(x)$ 中存在零值常函数，则 $y_1(x), y_2(x)$ 线性相关，故不妨假设 $y_1(x), y_2(x)$ 均非零值常函数. 此时，$y_1(x)$ 与 $y_2(x)$ 线性无关等价于 $\frac{y_2(x)}{y_1(x)}$ 不是常数.
  又因为 $\frac{y_2(x)}{y_1(x)}$ 不是常数等价于
  $$\left[\frac{y_2(x)}{y_1(x)}\right]' = \frac{y_1(x)y'_2(x) - y'_1(x)y_2(x)}{[y_1(x)]^2} \neq 0,$$
  所以 $y_1(x)$ 与 $y_2(x)$ 线性无关等价于 $y_1(x)y'_2(x) - y'_1(x)y_2(x) \neq 0$.
  因此，$y_1(x)y'_2(x) - y'_1(x)y_2(x) \neq 0$ 是题设方程的通解能表示成 $C_1 y_1(x) + C_2 y_2(x) \quad (C_1, C_2 \text{是任意常数})$ 的充分条件，应选 A.
  **【手写批注】** 圈选了选项 A 及 $C_1 y_1(x) + C_2 y_2(x)$，划线“线性相关”，旁写有 $\frac{y_2(x)}{y_1(x)}$.

### **29**
* **原题：**
  *（接第 28 题的求解过程——解法一：一阶线性微分方程解法）*

* **解答/批注：**
  **第一步：求通解**
  原方程可化为 $\frac{\mathrm{d}y}{\mathrm{d}x} + \frac{2x}{x^2 - 1}y = \frac{\cos x}{x^2 - 1}$，
  …… 1分
  则此一阶线性微分方程的通解为：
  // 一阶线性方程 $y' + P(x)y = Q(x)$ 的通解为：
  $y = \left[ \int Q(x) e^{\int P(x)\mathrm{d}x} \mathrm{d}x + C \right] e^{-\int P(x)\mathrm{d}x}$.
  $y = \left[ \int \frac{\cos x}{x^2 - 1} e^{\int \frac{2x}{x^2 - 1} \mathrm{d}x} \mathrm{d}x + C \right] e^{-\int \frac{2x}{x^2 - 1}\mathrm{d}x}$
  …… 3分
  $= \left[ \int \frac{\cos x}{x^2 - 1} e^{\int \frac{1}{x^2 - 1} \mathrm{d}(x^2 - 1)} \mathrm{d}x + C \right] e^{-\int \frac{1}{x^2 - 1} \mathrm{d}(x^2 - 1)}$
  $= \left[ \int \frac{\cos x}{x^2 - 1} e^{\ln (x^2 - 1)} \mathrm{d}x + C \right] e^{-\ln(x^2 - 1)}$
  $= \left[ \int \frac{\cos x}{x^2 - 1} (x^2 - 1) \mathrm{d}x + C \right] \frac{1}{x^2 - 1}$
  $= [\int \cos x \mathrm{d}x + C] \frac{1}{x^2 - 1}$
  $= \frac{\sin x + C}{x^2 - 1}$，
  …… 4分
  **第二步：求特解**
  因为 $y = \frac{\sin x + C}{x^2 - 1}$，
  则当 $\left.y\right|_{x=0} = 1$ 时有：$1 = \frac{C}{-1}$，
  即 $C = -1$.
  故满足初始条件的特解是 $y = \frac{\sin x - 1}{x^2 - 1}$.
  …… 5分

### **30**
* **原题：**
  *（接第 28 题的求解过程——解法二：全微分方程解法）*

* **解答/批注：**
  **第一步：识别全微分方程**
  由于 $\frac{\partial(x^2 - 1)}{\partial x} = 2x = \frac{\partial(2xy - \cos x)}{\partial y}$，
  故 $(x^2 - 1) \mathrm{d}y + (2xy - \cos x) \mathrm{d}x = 0$ 是个全微分方程，即 $(x^2 - 1) \mathrm{d}y + (2xy - \cos x) \mathrm{d}x$ 可以视为某二元函数 $u(x, y)$ 的全微分.
  …… 1分
  **第二步：偏积分法解方程**
  那么 $\frac{\partial u}{\partial y} = x^2 - 1 \cdots\cdots (1)$
  $\frac{\partial u}{\partial x} = 2xy - \cos x \cdots\cdots (2)$
  (1) 式对 $y$ 积分得：
  // 对 $y$ 积分时，将 $x$ 看作常数，故在积分结果中要加上 $x$ 的函数 $C(x)$.
  $u(x, y) = \int (x^2 - 1) \mathrm{d}y = x^2 y - y + C(x) \cdots\cdots (3)$

  将 (3) 式对 $x$ 求导得：
  // 对 $x$ 求导时，将 $y$ 看作常数.
  $\frac{\partial u}{\partial x} = 2xy + C'(x) = 2xy - \cos x$，
  …… 3分
  那么 $C'(x) = -\cos x, C(x) = -\sin x + C$.
  于是 $u(x, y) = x^2 y - y - \sin x + C$.
  …… 4分
  把初始条件 $\left.y\right|_{x=0} = 1$ 代入上式可得：
  $0 - 1 - 0 + C = 0$，
  即有 $x^2 y - y - \sin x + 1 = 0$，
  那么满足初始条件的特解是 $y = \frac{\sin x - 1}{x^2 - 1}$.

### **32**
* **原题：**
  223 设 $y'' - y = x^2$ 的解 $y = \varphi(x)$ 是当 $x \to 0$ 时较 $x^2$ 高阶的无穷小量，则 $\varphi(x) =$
  (A) $e^x + e^{-x} - x^2 - 2$.
  (B) $e^x + e^{-x} - 2x^2$.
  (C) $e^x - e^{-x} + x^2 - 2$.
  (D) $e^x - e^{-x} + 2x^2$.

* **解答/批注：**
  223 【答案】 A
  【分析】 二阶常系数线性微分方程 $y'' - y = x^2$ 的特征方程与特征根分别是 $\lambda^2 - 1 = 0$ 与 $\lambda_1 = 1, \lambda_2 = -1$. 又方程有形如 $y^* = Ax^2 + Bx + C$ 的特解，代入方程得
  $$2A - (Ax^2 + Bx + C) = x^2,$$
  于是可确定 $A = -1, B = 0, C = 2A = -2$. 故方程 $y'' - y = x^2$ 的通解为
  $$y = C_1 e^x + C_2 e^{-x} - x^2 - 2.$$
  为了得到符合题目要求的解 $\varphi(x)$，只需从条件
  $$\lim_{x \to 0} \frac{C_1 e^x + C_2 e^{-x} - x^2 - 2}{x^2} = 0 \Longleftrightarrow \lim_{x \to 0} \frac{C_1 e^x + C_2 e^{-x} - 2}{x^2} = 1$$
  确定其中的常数 $C_1$ 和 $C_2$. 利用极限的四则运算法则有
  $$\lim_{x \to 0} \frac{(C_1 e^x + C_2 e^{-x} - 2)}{x^2} = \lim_{x \to 0} \frac{C_1 e^x + C_2 e^{-x} - 2}{x^2} \cdot x = 1 \cdot 0 = 0 \quad \text{①}$$
  $$\lim_{x \to 0} \frac{C_1 e^x + C_2 e^{-x} - 2}{x} = \lim_{x \to 0} \frac{C_1 e^x + C_2 e^{-x} - 2}{x^2} \cdot x = 1 \cdot 0 = 0 \quad \text{②}$$
  于是有
  $$0 = \lim_{x \to 0} (C_1 e^x + C_2 e^{-x} - 2) = C_1 + C_2 - 2,$$
  即 $C_1 + C_2 = 2$. 把它代入 ②，又有
  $$0 = \lim_{x \to 0} \frac{C_1 e^x + C_2 e^{-x} - 2}{x} = \lim_{x \to 0} \frac{C_1 e^x + C_2 e^{-x} - C_1 - C_2}{x}$$
  $$= C_1 \lim_{x \to 0} \frac{e^x - 1}{x} + C_2 \lim_{x \to 0} \frac{e^{-x} - 1}{x} = C_1 - C_2,$$
  即 $C_1 = C_2$，综合即得 $C_1 = C_2 = 1$. 故所求的解 $\varphi(x) = e^x + e^{-x} - x^2 - 2$.

### **35**
* **原题：**
  *（接第 34 题解答过程）*

* **解答/批注：**
  **【解】** (I) 计算 $y', y''$.
  $$y' = u'_1 \cos x - u_1 \sin x + u'_2 \sin x + u_2 \cos x \xrightarrow{u'_1 \cos x + u'_2 \sin x = 0} - u_1 \sin x + u_2 \cos x.$$
  $$y'' = (-u_1 \sin x + u_2 \cos x)' = -u'_1 \sin x - u_1 \cos x + u'_2 \cos x - u_2 \sin x.$$
  代入 $y'' + y = g(x)$ 可得，
  $$y'' + y = -u'_1 \sin x - u_1 \cos x - u_2 \sin x + u_1 \cos x + u_2 \sin x$$
  $$= -u'_1 \sin x + u'_2 \cos x = g(x).$$
  于是，$\begin{cases} u'_1 \cos x + u'_2 \sin x = 0, \\ -u'_1 \sin x + u'_2 \cos x = g(x). \end{cases}$ 解得 $\begin{cases} u'_1 = -g(x) \sin x, \\ u'_2 = g(x) \cos x. \end{cases}$ 由 $(u'_1)^2 + (u'_2)^2 = 1$ 可得，$[g(x)]^2 = 1$. 再由 $g(x) > 0$ 得 $g(x) = 1$.
  因此，$u'_1 = -\sin x, u'_2 = \cos x$. 从而 $u_1(x) = \cos x + C_1, u_2(x) = \sin x + C_2$. 结合 $u_1(0) = 1, u_2(0) = 0$ 可得 $u_1(x) = \cos x, u_2(x) = \sin x$.
  (II) 由第 (I) 问的结论可知，$y = \cos^2 x + \sin^2 x = 1$ 为 $y'' + y = 1$ 的一个特解.
  由于 $y'' + y = 0$ 可得特征方程为 $r^2 + 1 = 0$，特征根为 $r_{1,2} = \pm i$，故 $y = C_3 \cos x + C_4 \sin x + 1$ 为 $y'' + y = 1$ 的解，其中 $C_3, C_4$ 为待定常数.
  由 $y(0) = 0$ 可得，$C_3 + 1 = 0$. 解得 $C_3 = -1$. 又因为 $y'(x) = -C_3 \sin x + C_4 \cos x$，所以由 $y'(0) = 1$ 可得，$C_4 = 1$.
  因此，$y = \sin x - \cos x + 1$ 为所求特解.

### **36**
* **原题：**
  900 第六章数二A类16
  16 微分方程 $y'' + \frac{2}{x}y' = x \quad (x > 0)$ 的通解为 $y =$ _______.

* **解答/批注：**
  **【答案】** $\frac{x^3}{12} + \frac{C_1}{x} + C_2$，其中 $C_1, C_2$ 为任意常数.
  
  **【解】** 令 $y' = p$，则 $y'' = p'$，且原方程可化为 $p' + \frac{2}{x}p = x$.
  由一阶非齐次线性微分方程的通解公式可得
  $$p = e^{-\int \frac{2}{x}\mathrm{d}x} \left( \int x e^{\int \frac{2}{x}\mathrm{d}x} \mathrm{d}x + C_1 \right) = e^{-2\ln x} \left( \int x e^{2\ln x} \mathrm{d}x + C_1 \right) = \frac{1}{x^2} \left( \int x^3 \mathrm{d}x + C_1 \right)$$
  $$= \frac{1}{x^2} \left( \frac{x^4}{4} + C_1 \right) = \frac{x^2}{4} + \frac{C_1}{x^2}.$$
  继续积分可得
  $$y = \int \left( \frac{x^2}{4} + \frac{C_1}{x^2} \right) \mathrm{d}x = \frac{x^3}{12} - \frac{C_1}{x} + C_2.$$
  令 $C_1 = -C_1$，则 $y = \frac{x^3}{12} + \frac{C_1}{x} + C_2$，其中 $C_1, C_2$ 为任意常数.

  **【右侧手写演草批注】**
  $y' \cdot x^2 + y' \cdot 2x = x^3$
  $(y' \cdot x^2)' = x^3$
